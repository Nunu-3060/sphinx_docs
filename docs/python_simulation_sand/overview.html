概要

このプロジェクトでは、飛砂のシミュレーションを行い、その結果を可視化する Python スクリプトを扱います。本ドキュメントは「Python による飛砂のシミュレーションの実装」と題し、そのシミュレーションモデルと実装内容を解説します。

対象読者

このドキュメントは、Python、NumPy、Pillow (PIL) の基本的な使い方を理解している方を対象としています。そのため、これらのライブラリ自体の文法や API についての説明は省略します。

本ドキュメントは、読者の手元に実装スクリプトが無いことを前提に、必要なソースコードを本文中に直接掲載しながら解説します。別途ファイルを用意する必要はありません。

本ドキュメントの構成

実装は役割ごとに4つの層に分かれています。本ドキュメントもこれに合わせて、層ごとの詳細な解説(コード掲載あり)と、クラス・関数一覧の API リファレンスを分けて構成しています。層の一覧と依存関係は 実装概要 に、ページ全体の一覧は Python による飛砂のシミュレーションの実装 の目次にまとめています。
