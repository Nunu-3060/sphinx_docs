モデル層: Sand.py

Sand クラスは、風によって運ばれる砂(飛砂)による地形の変化を、2次元の高さ場に対する離散時間の更新規則として実装しているクラスです。GUI や画像化には一切関与せず、NumPy 配列の更新だけに専念しているため、Tkinter が使えない環境でも単体で利用できます。以下、コンストラクタと next() メソッドに分けて説明します。

高さ場の初期化

    def __init__(
        self,
        width: int = 128,
        height: int = 128,
        L0: float = 2,
        b: float = 4,
        q: float = 0.1,
        D: float = 0.2,
        seed: int | None = None
    ) -> None:
        rng: np.random.Generator = np.random.default_rng(seed)
        self.height: np.typing.NDArray[np.float64] = rng.random((height, width), np.float64)
        self.L0: float = L0
        self.b: float = b
        self.q: float = q
        self.D: float = D
        return None

コンストラクタでは、幅 width・高さ height の格子に対応する2次元配列 self.height を、[0, 1) の一様乱数で初期化します。格子の各要素 self.height[i, j] が、位置 (i, j) における砂の堆積量に相当します。

L0 / b / q / D は、次の輸送・拡散の計算で使うパラメータです。

名前

意味

既定値

L0

基本飛距離

2

b

堆積量に対する飛距離の感度

4

q

1ステップあたりの輸送量

0.1

D

拡散係数

0.2

seed は乱数生成器 numpy.random.default_rng に渡されるシード値です。同じ seed を指定すれば、初期状態を再現できます。

1ステップの更新: next()

    def next(self) -> None:
        height: int
        width: int
        height, width = self.height.shape
        length: np.typing.NDArray[np.int64] = (self.L0 + self.b * self.height).round(0).astype(np.int64)
        dest: np.typing.NDArray[np.int64] = (np.arange(width, dtype=np.int64)[None, :] - length) % width
        d: np.typing.NDArray[np.float64] = np.full(self.height.shape, -self.q)
        rows: np.typing.NDArray[np.int64] = np.repeat(np.arange(height, dtype=np.int64), width)
        np.add.at(d, (rows, dest.ravel()), self.q)
        self.height += d
        # 可読性のために PEP8 に違反した書き方をしている。
        self.height = self.height * (1-self.D) + (
            np.roll(self.height, shift=( 1,  0), axis=(0, 1)) +  # noqa: E201
            np.roll(self.height, shift=(-1,  0), axis=(0, 1)) +  # noqa: E201
            np.roll(self.height, shift=( 0,  1), axis=(0, 1)) +  # noqa: E201
            np.roll(self.height, shift=( 0, -1), axis=(0, 1))    # noqa: E201
        ) * self.D / 6 + (
            np.roll(self.height, shift=( 1,  1), axis=(0, 1)) +  # noqa: E201
            np.roll(self.height, shift=( 1, -1), axis=(0, 1)) +  # noqa: E201
            np.roll(self.height, shift=(-1,  1), axis=(0, 1)) +  # noqa: E201
            np.roll(self.height, shift=(-1, -1), axis=(0, 1))    # noqa: E201
        ) * self.D / 12
        return None

next() は、高さ場 self.height を1ステップ分更新するメソッドで、「輸送」と「拡散」の2段階から構成されています。

輸送ステップ

各セルは一定量 q の砂を風下側(列方向)へ飛ばします。飛距離(ホップ長)は、そのセル自身の堆積量に応じて次のように決まります。

\[l_{i,j} = \mathrm{round}(L_0 + b \, h_{i,j})\]

セル \((i, j)\) から飛ばされた砂は、同じ行の列 \((j - l_{i,j}) \bmod \mathrm{width}\) に着地します。すなわち、風は列方向(横方向)に一定方向へ吹くものとしてモデル化されています。

実装では、まず全セルのホップ長を length に、着地先の列インデックスを dest にまとめて計算します。そのうえで、「全セルが q を失い、着地先で q を得る」という収支を配列 d に積み上げています。

\[d_{i,j} = -q + q \times \bigl(\text{セル } (i,j) \text{ に着地した輸送元の数}\bigr)\]

全セルが必ず q を失い、失われた q はどこか1か所に必ず着地するため、輸送ステップは高さ場の合計値(総砂量)を厳密に保存します。複数のセルの飛距離が一致し、同じ着地先に集まる場合は着地量が加算されます。実装上は numpy.add.at(d, (rows, dest.ravel()), self.q) を用いることで、この重複加算(同一インデックスへの複数回の加算)を正しく処理しています(単純な配列インデックスへの代入では、重複した着地先の加算が上書きされてしまい、後から書き込んだ分しか反映されません)。

拡散ステップ

輸送後の高さ場に対して、周囲8セルとの重み付き平均による拡散を適用し、局所的に尖った砂山を滑らかにします。

\[h_{i,j} \leftarrow (1 - D)\, h_{i,j} + \frac{D}{6} \sum_{(di,dj) \in N_4} h_{i+di,\,j+dj} + \frac{D}{12} \sum_{(di,dj) \in N_8} h_{i+di,\,j+dj}\]

ここで \(N_4\) は上下左右の4近傍、\(N_8\) は斜め4方向の近傍です。自分自身の重み \((1-D)\) 、4近傍の重みの合計 \(4 \times D/6 = 2D/3\) 、斜め4近傍の重みの合計 \(4 \times D/12 = D/3\) を足し合わせるとちょうど 1 になるため、この拡散ステップも高さ場の合計値を変化させません。

境界条件には numpy.roll による周期シフトを用いており、格子は上下・左右ともにつながったトーラス状の空間として扱われます。

まとめ

輸送・拡散のいずれのステップも高さ場の合計値を変化させないため、Sand.next() を繰り返し呼び出しても、格子全体の総砂量は常に一定に保たれます。局所的な移動と均しだけを繰り返しながら、全体の量を変えずに地形が変化し続けるという性質が、このモデルの特徴です。
