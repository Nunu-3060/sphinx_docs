距離関数による形状表現

距離関数（SDF）とは

符号付き距離関数（SDF: Signed Distance Function）とは、平面上の点 \(p\) を受け取り、その点から図形の境界までの距離を、内側なら負・外側なら正・境界上ならちょうど 0 になるように返す関数 \(d(p)\) のことである。例えば中心 \(c\)、半径 \(r\) の円は次のように書ける。

\[d_{\mathrm{circle}}(p) = \lVert p - c \rVert - r\]

この関数の値の符号を見るだけで、任意の点がその図形の内側にあるか外側にあるかを判定できる。座標ごとの if 文で図形を判定するのではなく、「距離」という 1 つの連続値に落とし込んでおくことで、複数の図形の合成や、境界のなめらかな表現が驚くほど単純な演算に帰着する、というのが SDF の考え方である。

基本図形の距離関数

円のほかに、矩形と線分についても同様に距離関数を定義できる。矩形は、中心からの相対座標を各軸ごとに矩形の半径（半幅・半高さ）だけ縮めた上で、はみ出した分の長さ（外側にいる場合）と、はみ出していない分のうちもっとも浅い軸の距離（内側にいる場合）を組み合わせて求める。

examples/sdf.py の sdf_circle 関数
1def sdf_circle(
2    x: np.ndarray, y: np.ndarray, cx: float, cy: float, radius: float
3) -> np.ndarray:
4    """中心 (cx, cy)、半径 radius の円までの符号付き距離。"""
5    return np.hypot(x - cx, y - cy) - radius
examples/sdf.py の sdf_box 関数
 1def sdf_box(
 2    x: np.ndarray,
 3    y: np.ndarray,
 4    cx: float,
 5    cy: float,
 6    half_width: float,
 7    half_height: float,
 8) -> np.ndarray:
 9    """中心 (cx, cy)、半径 (half_width, half_height) の矩形までの距離。"""
10    qx: np.ndarray = np.abs(x - cx) - half_width
11    qy: np.ndarray = np.abs(y - cy) - half_height
12    outside: np.ndarray = np.hypot(np.maximum(qx, 0.0), np.maximum(qy, 0.0))
13    inside: np.ndarray = np.minimum(np.maximum(qx, qy), 0.0)
14    return outside + inside

線分までの距離は、点から線分への垂線の足が線分の範囲に収まるように、内積を使ってパラメータ h を [0, 1] にクランプしてから求める。距離の値から thickness の分だけ引いて図形を外側に太らせる（オフセットする）と、線分の周囲 thickness 分までが「内側」として扱われるようになり、線分に太さを持たせたカプセル形状としても使える。

examples/sdf.py の sdf_segment 関数
 1def sdf_segment(
 2    x: np.ndarray,
 3    y: np.ndarray,
 4    ax: float,
 5    ay: float,
 6    bx: float,
 7    by: float,
 8    thickness: float = 0.0,
 9) -> np.ndarray:
10    """端点 (ax, ay)-(bx, by) を結ぶ線分(太さ thickness)までの距離。"""
11    pax: np.ndarray = x - ax
12    pay: np.ndarray = y - ay
13    bax: float = bx - ax
14    bay: float = by - ay
15    h: np.ndarray = np.clip(
16        (pax * bax + pay * bay) / (bax * bax + bay * bay), 0.0, 1.0
17    )
18    dx: np.ndarray = pax - h * bax
19    dy: np.ndarray = pay - h * bay
20    return np.hypot(dx, dy) - thickness

ブール演算による形状の合成

距離関数どうしを min / max で組み合わせるだけで、図形の和集合・積集合・差集合が求められる。

\[d_{\mathrm{union}}(p) = \min(d_1(p), d_2(p))\]
\[d_{\mathrm{intersection}}(p) = \max(d_1(p), d_2(p))\]
\[d_{\mathrm{subtraction}}(p) = \max(d_1(p), -d_2(p))\]
examples/sdf.py の union 関数
1def union(d1: np.ndarray, d2: np.ndarray) -> np.ndarray:
2    """2つの図形の和集合(どちらかの内側なら内側)。"""
3    return np.minimum(d1, d2)
examples/sdf.py の intersection 関数
1def intersection(d1: np.ndarray, d2: np.ndarray) -> np.ndarray:
2    """2つの図形の積集合(両方の内側なら内側)。"""
3    return np.maximum(d1, d2)
examples/sdf.py の subtraction 関数
1def subtraction(d1: np.ndarray, d2: np.ndarray) -> np.ndarray:
2    """d1 から d2 の領域を取り除いた差集合。"""
3    return np.maximum(d1, -d2)

単純な min による和集合は、2 つの図形の境界がそのまま尖った継ぎ目として残ってしまう。継ぎ目をなめらかにつなぎたい場合は、min の代わりに、2 つの距離値の差に応じてなめらかに補間する smooth union を使う。

\[h = \mathrm{clip}\left(0.5 + 0.5\,\frac{d_2 - d_1}{k},\ 0,\ 1\right)\]
\[d_{\mathrm{smooth}}(p) = (1 - h)\,d_2(p) + h\,d_1(p) - k\,h\,(1 - h)\]

ここで \(k\) はなめらかさの半径で、大きくするほど継ぎ目が広い範囲でなだらかにつながる。

examples/sdf.py の smooth_union 関数
1def smooth_union(d1: np.ndarray, d2: np.ndarray, k: float) -> np.ndarray:
2    """継ぎ目を滑らかに繋いだ和集合(k は滑らかさの半径)。"""
3    h: np.ndarray = np.clip(0.5 + 0.5 * (d2 - d1) / k, 0.0, 1.0)
4    return d2 * (1.0 - h) + d1 * h - k * h * (1.0 - h)

同じ円と矩形の組み合わせを、単純な union と smooth_union それぞれで合成すると、継ぎ目の違いがはっきり分かる。

距離場の可視化：等高線とアンチエイリアス

距離関数の値そのものを画像にすると、図形の輪郭だけでなく、輪郭からの距離の分布まで可視化できる。境界付近の狭い帯の中だけ内側色と外側色をなめらかに混ぜれば、画素を増やさずに輪郭をアンチエイリアス処理できる。

examples/sdf.py の render_fill 関数
 1def render_fill(
 2    d: np.ndarray,
 3    inside_color: tuple[int, int, int] = (240, 90, 60),
 4    outside_color: tuple[int, int, int] = (255, 255, 255),
 5    aa_width: float = 1.5,
 6) -> Image.Image:
 7    """符号付き距離を、境界をアンチエイリアスした塗りつぶし画像にする。
 8
 9    ``aa_width`` 幅の帯を d=0 の周りに取り、その中だけ内側色と外側色を
10    smoothstep で滑らかに混ぜることで、超解像なしでも滑らかな境界に
11    なる。
12    """
13    t: np.ndarray = _smoothstep(aa_width / 2, -aa_width / 2, d)
14    inside: np.ndarray = np.array(inside_color, dtype=float)
15    outside: np.ndarray = np.array(outside_color, dtype=float)
16    pixels: np.ndarray = outside + (inside - outside) * t[..., np.newaxis]
17    return Image.fromarray(pixels.round().astype(np.uint8))

一定間隔ごとに線を引けば、地図の等高線のような表現になる。距離を spacing で割った余りが 0 に近い場所ほど線を濃くすることで実現している。

examples/sdf.py の render_isolines 関数
 1def render_isolines(
 2    d: np.ndarray, spacing: float = 12.0, line_width: float = 1.2
 3) -> Image.Image:
 4    """距離場を等高線状の縞模様として可視化する。
 5
 6    内側・外側で背景の濃淡を変え、距離が ``spacing`` の倍数になる
 7    位置に線を引くことで、図形の境界からの距離を視覚化する。
 8    """
 9    background: np.ndarray = np.where(d < 0.0, 210.0, 245.0)
10    distance_to_line: np.ndarray = np.abs(
11        np.mod(d + spacing / 2.0, spacing) - spacing / 2.0
12    )
13    line_strength: np.ndarray = _smoothstep(
14        line_width, 0.0, distance_to_line
15    )
16    gray: np.ndarray = background * (1.0 - line_strength)
17    rgb: np.ndarray = np.stack([gray, gray, gray], axis=-1)
18    return Image.fromarray(rgb.round().astype(np.uint8))

先ほどの smooth union した図形を等高線表示すると、内側では図形の中心に向かって、外側では図形から離れるにつれて、輪（わ）が同心円状・同心矩形状に広がっていく様子が見える。

ノイズによる形状の歪み（応用）

SDF は「座標を受け取って値を返す関数」であるため、ノイズを使った表現で扱ったドメインワーピングと同じ要領で、評価する座標そのものをノイズで歪めてから距離関数に渡すことができる。円の SDF に、fbm2d で作った歪みベクトルを加えた座標を渡すだけで、輪郭が波打った有機的なブロブ（水滴状の塊）になる。

正確な円のまま拡大縮小したい場合や、輪郭を保ったまま太らせたり細らせたりしたい場合には、歪める前に距離関数の値へ定数を足し引きするだけでよい（半径を変えるのと同じ効果になる）。座標を歪めるか、距離の値を直接いじるかで、図形の変形のしかたが変わる点は覚えておく価値がある。

円充填（サークルパッキング）

距離関数は、図形を描くだけでなく、平面の上にどれだけの隙間が残っているかを測る道具にもなる。その代表的な応用が、大きさの異なる円を互いに重ならないように敷き詰める円充填（circle packing）である。円を 1 つずつ置いていくとき、ある点を中心として置ける円の最大半径は、その点からもっとも近い既存の円の縁、またはキャンバスの端までの距離に等しい。既存の円までの距離は、全ての円の距離関数を union で合わせた和集合の距離関数そのものである。キャンバスの端までの距離は、キャンバスを表す矩形の距離関数の符号を反転したもの（内側で正になる）である。本節では、この 2 つのうち小さいほうを空き距離 \(f(p)\) と呼ぶ。

\[f(p) = \min\Bigl(-d_{\mathrm{canvas}}(p),\ \min_i d_{\mathrm{circle}, i}(p)\Bigr)\]

円を置く手順は次の通り。

  1. キャンバスの端までの距離で、空き距離の場を初期化する。

  2. 空き距離が最小半径以上の画素の中から、円の中心をランダムに 1 つ選ぶ。

  3. 半径を、その画素の空き距離から円どうしの隙間の分を引いた値と、最大半径のうち小さいほうに決めて、円を置く。

  4. 置いた円の距離関数を union で空き距離の場に重ねる。

  5. 最小半径の円を置ける画素がなくなるか、指定した個数に達するまで、2-4 を繰り返す。

examples/circle_packing.py の pack_circles 関数
 1def pack_circles(
 2    free_distance: np.ndarray,
 3    rng: np.random.Generator,
 4    max_count: int = 1000,
 5    min_radius: float = 2.0,
 6    max_radius: float = 40.0,
 7    padding: float = 1.5,
 8) -> list[tuple[float, float, float]]:
 9    """空き距離の場 ``free_distance`` の中に、重ならない円を詰める。
10
11    ``free_distance`` は画素ごとに「その画素を中心に置ける円の最大
12    半径」を表す配列で、円を置いてはいけない場所では 0 以下にしておく。
13    毎回、半径 ``min_radius`` 以上の円を置ける画素の中から中心を
14    一様にランダムに選び、半径を空き距離(から隙間 ``padding`` を
15    引いた値)と ``max_radius`` の小さいほうに決める。置いた円の
16    距離関数を ``union`` で空き距離の場に重ねてから、次の円に進む。
17
18    戻り値は、置いた円の (中心 x, 中心 y, 半径) のリスト。
19    """
20    height: int
21    width: int
22    height, width = free_distance.shape
23    xs: np.ndarray
24    ys: np.ndarray
25    xs, ys = np.meshgrid(
26        np.arange(width, dtype=float), np.arange(height, dtype=float)
27    )
28    distance: np.ndarray = free_distance.astype(float)
29    circles: list[tuple[float, float, float]] = []
30
31    for _ in range(max_count):
32        candidates: np.ndarray = np.flatnonzero(
33            distance >= min_radius + padding
34        )
35        if candidates.size == 0:
36            break  # これ以上、最小半径の円を置ける場所がない。
37
38        index: int = int(rng.choice(candidates))
39        cy: int
40        cx: int
41        cy, cx = divmod(index, width)
42        radius: float = min(float(distance[cy, cx]) - padding, max_radius)
43        circles.append((float(cx), float(cy), radius))
44
45        distance = union(distance, sdf_circle(xs, ys, cx, cy, radius))
46
47    return circles

空き距離の場は画素ごとの配列として持ち、円を 1 つ置くたびに、画像全体に対して sdf_circle と union を 1 回ずつ計算する。候補の円を試しては既存の全ての円と重なりを調べる方法と違い、円を置ける場所の判定も半径の決定も、配列を見るだけで済む。

キャンバス全体に、置ける場所がなくなるまで円を詰めると次のようになる。空き距離は円を置くたびに小さくなるため、大きな円の隙間を中くらいの円が埋め、その隙間をさらに小さな円が埋める、という入れ子状の大きさの分布が自然に生まれる。

空き距離の場の初期値を変えれば、円を置ける領域も自由に決められる。前述の円と矩形の和集合の距離関数 \(d\) について、図形の内側では符号を反転した \(-d\) を、外側では \(d\) をそのまま空き距離の初期値にする（どちらもキャンバスの端までの距離と union で合わせる）。内側と外側に別々の色で円を詰めると、色覚検査の図版のように、円の集まりだけで図形が浮かび上がる。空き距離は図形の境界までの実際の距離を超えないため、円が境界をまたぐことはない。

なお、半径を全て同じ値に固定して円をランダムに置いていく方法は、ダーツ投げ法（dart throwing）と呼ばれる素朴なポアソン円盤サンプリングにあたる。次節では、同じ性質の点配置をより効率よく作る方法を扱う。

ポアソン円盤サンプリング

次節のボロノイ図は、平面に散らした複数の種点から作られる。種点をどう配置するかによって、ボロノイ図の見た目は大きく変わる。フィロタキシスのように規則正しく並べれば整然としすぎる印象になり、単純な一様乱数で散らせば、粒が偏って固まる場所と大きな隙間ができる場所が混在してしまう。ポアソン円盤サンプリングは、この両極端の中間にあたる、「どの 2 点も最小距離以上離れているが、全体としては隙間なく埋め尽くされている」というブルーノイズ特性を持つ点配置を作る手法である。網膜の視細胞の並びなど、自然界の「均一だがランダムに見える」配置の多くがこの性質を持つ。

Bridson (2007) のアルゴリズムは、次の手順で点を追加していく。

  1. 最初の点を 1 つランダムに置き、「アクティブリスト」に入れる。

  2. アクティブリストから点を 1 つ選び、その周囲の環状領域（最小距離〜最小距離の 2 倍）から候補点を何度か試す。既存のどの点とも最小距離以上離れている候補が見つかれば採用し、アクティブリストへ加える。

  3. 一定回数試しても候補が見つからなければ、その点をアクティブリストから外す。

  4. アクティブリストが空になるまで 2-3 を繰り返す。

全ての既存点との距離を毎回総当たりで調べる方法は点数が \(n\) のとき計算量が \(O(n^2)\) になり点数が増えるにつれて遅くなるため、実装では「1 マスに点は高々 1 つしか入らない」大きさ（最小距離を \(\sqrt{2}\) で割った値を 1 辺とする正方形）の格子に点を登録しておき、候補点の周囲 5×5 マス程度だけを調べることで高速化している。

examples/poisson_disk.py の poisson_disk_sampling 関数
 1def poisson_disk_sampling(
 2    width: float,
 3    height: float,
 4    min_dist: float,
 5    rng: np.random.Generator,
 6    k: int = 30,
 7) -> np.ndarray:
 8    """Bridson (2007) のアルゴリズムで、最小距離 ``min_dist`` を
 9    保った点群を生成する。
10
11    手順は次の通り。
12
13    1. 最初の点を1つランダムに置き、「アクティブリスト」に入れる。
14    2. アクティブリストから点を1つ選び、その周囲の環状領域
15       (``min_dist`` 〜 ``2 * min_dist``) から候補点を ``k`` 回まで
16       試す。既存のどの点とも ``min_dist`` 以上離れている候補が
17       見つかれば採用し、新たにアクティブリストへ加える。
18    3. ``k`` 回試しても候補が見つからなければ、その点をアクティブ
19       リストから外す(これ以上その点の周りには新しい点を置けない
20       ということ)。
21    4. アクティブリストが空になるまで2-3を繰り返す。
22
23    全画素を総当たりで距離チェックすると低速になるため、
24    ``min_dist / sqrt(2)`` を1辺とする格子(1マスに点は高々1つしか
25    入らない大きさ)にあらかじめ点を登録しておき、候補点の周囲
26    5x5マス程度だけを調べれば十分になる、という高速化を行っている。
27    """
28    cell_size: float = min_dist / math.sqrt(2)
29    grid_w: int = int(math.ceil(width / cell_size))
30    grid_h: int = int(math.ceil(height / cell_size))
31    grid: np.ndarray = np.full((grid_h, grid_w), -1, dtype=np.int64)
32
33    points: list[np.ndarray] = []
34    active: list[int] = []
35
36    def cell_of(p: np.ndarray) -> tuple[int, int]:
37        return int(p[1] / cell_size), int(p[0] / cell_size)
38
39    first: np.ndarray = rng.uniform([0.0, 0.0], [width, height])
40    points.append(first)
41    gy, gx = cell_of(first)
42    grid[gy, gx] = 0
43    active.append(0)
44
45    while active:
46        source_idx: int = active[rng.integers(len(active))]
47        base: np.ndarray = points[source_idx]
48        accepted: bool = False
49
50        for _ in range(k):
51            angle: float = rng.uniform(0.0, 2.0 * math.pi)
52            radius: float = rng.uniform(min_dist, 2.0 * min_dist)
53            candidate: np.ndarray = base + radius * np.array(
54                [math.cos(angle), math.sin(angle)]
55            )
56            in_bounds: bool = (
57                0.0 <= candidate[0] < width and 0.0 <= candidate[1] < height
58            )
59            if not in_bounds:
60                continue
61
62            gy, gx = cell_of(candidate)
63            too_close: bool = False
64            for yy in range(max(0, gy - 2), min(grid_h, gy + 3)):
65                for xx in range(max(0, gx - 2), min(grid_w, gx + 3)):
66                    neighbor_idx = grid[yy, xx]
67                    if neighbor_idx == -1:
68                        continue
69                    gap: float = float(
70                        np.hypot(*(points[neighbor_idx] - candidate))
71                    )
72                    if gap < min_dist:
73                        too_close = True
74                        break
75                if too_close:
76                    break
77
78            if not too_close:
79                points.append(candidate)
80                grid[gy, gx] = len(points) - 1
81                active.append(len(points) - 1)
82                accepted = True
83                break
84
85        if not accepted:
86            active.remove(source_idx)
87
88    return np.array(points)

同じ点数を一様乱数とポアソン円盤サンプリングで配置して比べると、一様乱数は粒の密集と隙間が目立つのに対し、ポアソン円盤サンプリングは間隔がそろっているのが分かる。

ボロノイ図とドロネー三角形分割

ここまでは「1 つの図形までの距離」を扱ってきたが、同じ考え方は「複数の点のうちどれが一番近いか」にも一般化できる。平面上に散らした複数の種点のそれぞれについて、その点がもっとも近い種点となる領域で塗り分けたものをボロノイ図（Voronoi diagram）と呼ぶ。実装は単純で、各画素から全ての種点までの距離を求め、最小値を与えた種点の番号を採用するだけである。

examples/voronoi.py の voronoi_regions 関数
 1def voronoi_regions(
 2    points: np.ndarray, width: int, height: int, p: float = 2.0
 3) -> np.ndarray:
 4    """各画素について、最も近い種点の番号(領域ID)を求める。
 5
 6    ``points`` は形状 ``(N, 2)`` の座標配列。距離の測り方は ``p``
 7    （ミンコフスキー距離の次数）で切り替えられ、既定のユークリッド
 8    距離 (``p=2``) 以外に、マンハッタン距離 (``p=1``) やチェビシェフ
 9    距離 (``p=numpy.inf``) も指定できる。戻り値は形状
10    ``(height, width)`` の整数配列で、値は0からN-1の領域ID。
11    """
12    xs: np.ndarray
13    ys: np.ndarray
14    xs, ys = np.meshgrid(
15        np.arange(width, dtype=float), np.arange(height, dtype=float)
16    )
17    px: np.ndarray = points[:, 0, np.newaxis, np.newaxis]
18    py: np.ndarray = points[:, 1, np.newaxis, np.newaxis]
19    dx: np.ndarray = xs[np.newaxis, :, :] - px
20    dy: np.ndarray = ys[np.newaxis, :, :] - py
21    distances: np.ndarray = minkowski_distance(dx, dy, p)
22    return np.argmin(distances, axis=0)

各領域に種点ごとの色を割り当てるとモザイク状の画像に、領域の境界線だけを描くと配線図のような画像になる。

ボロノイ図で隣り合う（境界線を共有する）2 つの領域の種点どうしを線で結ぶと、その双対グラフであるドロネー三角形分割（Delaunay triangulation）が得られる。正式なドロネー三角形分割のアルゴリズムを実装する代わりに、ラスタ画像上で「隣接する画素の領域番号が異なる箇所」を総当たりで探すことで、隣接している種点のペアを求めている。

examples/voronoi.py の adjacent_pairs 関数
 1def adjacent_pairs(region_id: np.ndarray) -> set[tuple[int, int]]:
 2    """ラスタ上で隣接している領域番号の組を、ドロネーの辺として集める。
 3
 4    2つの領域が画素単位で隣接している(=ボロノイ図で境界を共有する)
 5    なら、その2つの種点はドロネー三角形分割でも辺で結ばれる、という
 6    性質を利用して、明示的な三角形分割アルゴリズムを使わずに辺を
 7    求めている。
 8    """
 9    horiz: np.ndarray = np.stack(
10        [region_id[:, :-1], region_id[:, 1:]], axis=-1
11    ).reshape(-1, 2)
12    vert: np.ndarray = np.stack(
13        [region_id[:-1, :], region_id[1:, :]], axis=-1
14    ).reshape(-1, 2)
15    all_pairs: np.ndarray = np.concatenate([horiz, vert], axis=0)
16    differing: np.ndarray = all_pairs[all_pairs[:, 0] != all_pairs[:, 1]]
17    sorted_pairs: np.ndarray = np.sort(differing, axis=1)
18    unique_pairs: np.ndarray = np.unique(sorted_pairs, axis=0)
19    return {(int(a), int(b)) for a, b in unique_pairs}

種点の配置を前節のポアソン円盤サンプリングに差し替えると、voronoi_regions や render_mosaic のコードは一切変えずに、領域の大きさがそろった、より均質なモザイクが得られる。距離関数の評価対象を変えるだけで結果が大きく変わるという点は、SDF の節で座標を歪めたのと同じ構図である。

距離の測り方を変える

これまでの距離関数は、全て普段馴染みのあるユークリッド距離（直線距離）を前提としていた。しかし「距離」の定義はこれだけではない。座標のずれ (dx, dy) から距離を計算する式を一般化したミンコフスキー距離 (|dx|^p + |dy|^p)^(1/p) を使うと、指数 p を変えるだけで異なる距離の測り方を統一的に表現できる。

\[\lVert (dx, dy) \rVert_p = \bigl(|dx|^p + |dy|^p\bigr)^{1/p}\]

  • p = 1: マンハッタン距離。斜めには進めず、東西方向・南北方向にしか移動できない場合の距離（碁盤の目状の街路を歩く距離）。

  • p = 2: ユークリッド距離。これまで使ってきた通常の直線距離。

  • \(p = \infty\): チェビシェフ距離。dx・dy のうち絶対値が大きい方だけで決まる距離（将棋の王が 1 手で到達できる範囲のイメージ）。

examples/voronoi.py の minkowski_distance 関数
 1def minkowski_distance(dx: np.ndarray, dy: np.ndarray, p: float) -> np.ndarray:
 2    """ミンコフスキー距離 ``(|dx|^p + |dy|^p)^(1/p)``。
 3
 4    ``p=1`` で **マンハッタン距離** （軸方向にしか移動できない距離、
 5    碁盤の目状の道を歩く距離）、``p=2`` で通常の **ユークリッド距離**
 6    になる。``p`` を無限大に近づけた極限は、``dx``・``dy`` のうち
 7    絶対値が大きい方だけで決まる **チェビシェフ距離** （将棋の王が
 8    1手で動ける距離、といったイメージ）に収束するため、``p`` が
 9    有限でない場合はこの極限の式を直接使う。
10    """
11    if np.isinf(p):
12        return np.maximum(np.abs(dx), np.abs(dy))
13    return (np.abs(dx) ** p + np.abs(dy) ** p) ** (1.0 / p)

voronoi_regions の距離計算をこの関数に差し替えるだけで、同じ種点の配置から全く違う印象のボロノイ図が得られる。ユークリッド距離では見慣れた凸多角形の領域になるのに対し、マンハッタン距離とチェビシェフ距離では、境界が軸方向と斜め 45 度の線分だけで構成された、角ばった領域になる。チェビシェフ距離はマンハッタン距離を 45 度回転させて縮尺を変えたものに相当するため、両者では軸方向の線分と斜めの線分の現れ方が入れ替わる。

ボロノイ図・ドロネー三角形分割はどちらも、種点の配置さえ変えれば見た目が大きく変わる。種点を格子状に配置してから位置をわずかにランダムにずらす、あるいはノイズを使った表現のフローフィールドに沿って散らす、といった工夫をすることで、有機的な区画模様や、方向性を持ったひび割れ模様のような表現にもつなげられる。距離の測り方（本節）と種点の配置（前段落）は独立に組み合わせられるため、両方を変えるとさらに表現の幅が広がる。

ロイド緩和（重心ボロノイ分割）

ポアソン円盤サンプリングは、点どうしが近づきすぎないように、点を 1 つずつ加えていく手法だった。これとは別に、既にある点の配置を少しずつ動かして均等に近づける方法として、ロイド緩和（Lloyd relaxation）がある。手順は、次の 2 つを繰り返すだけである。

  1. 現在の種点からボロノイ図を作る。

  2. 各種点を、自分のボロノイ領域の重心へ移動させる。

周りに隙間の多い種点は、領域が大きく、重心が種点から離れているため、大きく動く。逆に、密集した種点は領域が小さく、ほとんど動かない。これを繰り返すと、全ての種点が自分の領域の重心とほぼ一致する重心ボロノイ分割（centroidal Voronoi tessellation）に近づき、領域の大きさと形がそろっていく。この手順は、Stuart Lloyd が信号の量子化のために考案したもので、k-means 法の標準的な計算手順と同じである。

前節の voronoi_regions は、全ての種点と全ての画素の組み合わせについての距離を一度に配列として持つため、種点が数千個になるとメモリが足りなくなる。そこで本節の実装では、画素を数行ずつに分けて、もっとも近い種点を求めている。重心は、領域番号ごとに座標の合計を求める np.bincount で計算する。

examples/lloyd.py の nearest_seed 関数
 1def nearest_seed(
 2    points: np.ndarray, width: int, height: int, rows_per_chunk: int = 32
 3) -> np.ndarray:
 4    """各画素にもっとも近い種点の番号を、形状 (height, width) で返す。
 5
 6    :doc:`../shapes` の ``voronoi_regions`` と同じ結果になるが、種点が
 7    数千個あっても扱えるように、画素を数行ずつに分けて計算する。
 8    距離の 2 乗 ``|q - p|^2 = |q|^2 - 2 q・p + |p|^2`` のうち、画素 q
 9    だけで決まる ``|q|^2`` は最小値の比較に影響しないため省き、
10    残りを行列積で一度に求めている。
11    """
12    xs: np.ndarray = np.arange(width, dtype=float)
13    squared_norm: np.ndarray = (points**2).sum(axis=1)
14    region_id: np.ndarray = np.empty((height, width), dtype=np.int64)
15    for top in range(0, height, rows_per_chunk):
16        ys: np.ndarray = np.arange(
17            top, min(top + rows_per_chunk, height), dtype=float
18        )
19        gx: np.ndarray
20        gy: np.ndarray
21        gx, gy = np.meshgrid(xs, ys)
22        pixels: np.ndarray = np.stack([gx.ravel(), gy.ravel()], axis=1)
23        scores: np.ndarray = squared_norm - 2.0 * pixels @ points.T
24        region_id[top:top + len(ys)] = scores.argmin(axis=1).reshape(
25            len(ys), width
26        )
27    return region_id
examples/lloyd.py の weighted_centroids 関数
 1def weighted_centroids(
 2    region_id: np.ndarray, points: np.ndarray, density: np.ndarray
 3) -> np.ndarray:
 4    """各ボロノイ領域の、密度 ``density`` で重み付けした重心を返す。
 5
 6    領域内の重みの合計が 0 の種点(画素を持たない、または密度が 0 の
 7    領域だけを持つ種点)は、元の位置のまま動かさない。
 8    """
 9    height: int
10    width: int
11    height, width = region_id.shape
12    ys: np.ndarray
13    xs: np.ndarray
14    ys, xs = np.mgrid[0:height, 0:width]
15    labels: np.ndarray = region_id.ravel()
16    weight: np.ndarray = density.ravel()
17    count: int = len(points)
18
19    total: np.ndarray = np.bincount(labels, weights=weight, minlength=count)
20    sum_x: np.ndarray = np.bincount(
21        labels, weights=weight * xs.ravel(), minlength=count
22    )
23    sum_y: np.ndarray = np.bincount(
24        labels, weights=weight * ys.ravel(), minlength=count
25    )
26
27    centroids: np.ndarray = points.copy()
28    has_weight: np.ndarray = total > 0
29    centroids[has_weight, 0] = sum_x[has_weight] / total[has_weight]
30    centroids[has_weight, 1] = sum_y[has_weight] / total[has_weight]
31    return centroids
examples/lloyd.py の lloyd_relaxation 関数
 1def lloyd_relaxation(
 2    points: np.ndarray,
 3    width: int,
 4    height: int,
 5    iterations: int,
 6    density: np.ndarray | None = None,
 7) -> np.ndarray:
 8    """ボロノイ図の作成と重心への移動を ``iterations`` 回繰り返す。
 9
10    ``density`` を省略すると全ての画素の重みが等しい通常のロイド緩和、
11    形状 (height, width) の配列を渡すと重み付きのロイド緩和になる。
12    """
13    weights: np.ndarray = (
14        np.ones((height, width)) if density is None else density
15    )
16    current: np.ndarray = points.astype(float)
17    for _ in range(iterations):
18        region_id: np.ndarray = nearest_seed(current, width, height)
19        current = weighted_centroids(region_id, current, weights)
20    return current

一様乱数で置いた 60 個の種点によるボロノイ図（左）に、ロイド緩和を 30 回適用すると、次のようになる（右）。大小ばらばらだった領域が、大きさのそろった、六角形に近い形の領域に変わる。

重心を求めるときに、画素ごとの重み（密度）を掛けると、各種点は領域の中で重みの大きい側へ引き寄せられ、重みの大きい場所に種点が集まる配置になる。この重み付きのロイド緩和は、重み付きボロノイ図による点描で画像の濃淡を点の密度で表すのに使う。
