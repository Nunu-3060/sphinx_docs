進化的アルゴリズム

変異と選択による探索

はじめにで触れた通り、ジェネラティブアートの生成手法には、乱数・ノイズ関数・セルオートマトン・L-system と並んで進化的アルゴリズム（evolutionary algorithm）が数えられる。ここまでの章で扱った手法は、いずれも「決まった手続きを 1 回（あるいは反復）適用すれば結果が決まる」ものだった。進化的アルゴリズムはこれとは異なり、次の 2 つの操作を繰り返すことで、設計者が正解の手続きを直接書かなくても解を徐々に洗練させていく。

変異（mutation）

現在の解に、ランダムな小さな変化を加える。

選択（selection）

変異前後を何らかの適応度（fitness、目的に対する「良さ」）で比較し、良くなっていれば採用し、そうでなければ棄てる。

生物の進化になぞらえてこう呼ばれるが、必要なのは「適応度を数値で測れること」と「小さな変異を加えられること」だけであり、対象は絵でも音楽でもパラメータの組でも構わない。本章では、多数の半透明三角形を重ね合わせて 1 枚の目標画像に近づける、という単純な題材を通してこの考え方を実装する。

個体の表現と描画

個体（genome）を「三角形のリスト」として表現する。三角形はそれぞれ 3 頂点の座標と、RGBA の色（アルファ値を低めに抑えた半透明）を持つ。

examples/evolution.py の random_triangle 関数
 1def random_triangle(
 2    width: int, height: int, rng: np.random.Generator
 3) -> Triangle:
 4    """画面内のランダムな位置を中心とした、小ぶりな三角形を1つ作る。
 5
 6    アルファ値を低め(20-130 程度)に抑えることで、複数枚重なった
 7    ときに色が徐々に混ざり合い、単色のベタ塗りより滑らかに目標画像へ
 8    近づけるようにしている。
 9    """
10    max_radius: float = min(width, height) * 0.35
11    center: np.ndarray = rng.uniform([0.0, 0.0], [width, height])
12    angles: np.ndarray = rng.uniform(0.0, 2.0 * math.pi, size=3)
13    radii: np.ndarray = rng.uniform(0.2, 1.0, size=3) * max_radius
14    vertices: np.ndarray = center + np.stack(
15        [radii * np.cos(angles), radii * np.sin(angles)], axis=-1
16    )
17    color: tuple[int, int, int, int] = (
18        int(rng.integers(0, 256)),
19        int(rng.integers(0, 256)),
20        int(rng.integers(0, 256)),
21        int(rng.integers(20, 130)),
22    )
23    return vertices, color

個体を描画する際は、三角形ごとに画素が内部にあるかどうかを判定し、アルファ値で重みづけしながら白いキャンバスに重ね合わせる。内外判定には、3 辺それぞれについて「画素がその辺のどちら側にあるか」を表す符号付き面積（edge function）を使い、3 辺全てで符号がそろっている画素だけを内部とする。画素グリッド全体に対する 1 回の NumPy 演算で判定できるため、世代ごとに個体を描き直す本章の用途に向いている。

examples/evolution.py の triangle_mask 関数
 1def triangle_mask(
 2    vertices: np.ndarray, width: int, height: int
 3) -> np.ndarray:
 4    """三角形の内部にある画素を真とするブール配列を返す。
 5
 6    3辺それぞれについて「画素がその辺のどちら側にあるか」を表す
 7    符号付き面積(edge function)を求め、3辺すべてで符号がそろって
 8    いる画素だけを内部と判定する。PILで三角形を描いてから配列に
 9    変換するのではなく、画素グリッド全体に対する1回のNumPy演算で
10    判定できるため、世代ごとに全個体を描き直す本節の用途では
11    こちらの方が高速である。
12    """
13    xs, ys = _pixel_grid(width, height)
14    (x1, y1), (x2, y2), (x3, y3) = vertices
15
16    d1: np.ndarray = (xs - x2) * (y1 - y2) - (x1 - x2) * (ys - y2)
17    d2: np.ndarray = (xs - x3) * (y2 - y3) - (x2 - x3) * (ys - y3)
18    d3: np.ndarray = (xs - x1) * (y3 - y1) - (x3 - x1) * (ys - y1)
19
20    has_neg: np.ndarray = (d1 < 0) | (d2 < 0) | (d3 < 0)
21    has_pos: np.ndarray = (d1 > 0) | (d2 > 0) | (d3 > 0)
22    return ~(has_neg & has_pos)
examples/evolution.py の render_genome 関数
 1def render_genome(genome: Genome, width: int, height: int) -> np.ndarray:
 2    """三角形の集合を白背景に重ね合わせて描画し、RGB配列を返す。
 3
 4    三角形ごとに ``triangle_mask`` で内部画素を求め、アルファ値で
 5    重みづけしながら ``canvas = canvas * (1-a) + color * a`` という
 6    通常のアルファブレンドを行う。
 7    """
 8    canvas: np.ndarray = np.full((height, width, 3), 255.0)
 9    for vertices, color in genome:
10        inside: np.ndarray = triangle_mask(vertices, width, height)
11        alpha: float = color[3] / 255.0
12        canvas[inside] = (
13            canvas[inside] * (1 - alpha)
14            + np.array(color[:3], dtype=np.float64) * alpha
15        )
16    return canvas

目標画像との差を測る

外部の画像ファイルに頼らず、空のグラデーション・太陽・山という 3 種類の平坦な図形だけで目標画像を合成する。少数の三角形でも近似の様子が分かりやすい題材になっている。

examples/evolution.py の make_target 関数
 1def make_target(width: int, height: int) -> Image.Image:
 2    """近似の目標にする、単純な図形だけから成る画像を合成する。
 3
 4    外部の画像ファイルに頼らず、空のグラデーション・太陽・山という
 5    3種類の平坦な図形だけで構成することで、少数の三角形でも近似の
 6    様子が分かりやすい題材にしている。
 7    """
 8    top: np.ndarray = np.array([120.0, 170.0, 230.0])
 9    bottom: np.ndarray = np.array([245.0, 245.0, 250.0])
10    ys: np.ndarray = np.linspace(0.0, 1.0, height)[:, None]
11    gradient: np.ndarray = top[None, :] * (1 - ys) + bottom[None, :] * ys
12    pixels: np.ndarray = np.tile(gradient[:, None, :], (1, width, 1))
13    img: Image.Image = Image.fromarray(pixels.astype(np.uint8), "RGB")
14
15    draw: ImageDraw.ImageDraw = ImageDraw.Draw(img)
16    draw.ellipse(
17        [width * 0.62, height * 0.08, width * 0.90, height * 0.36],
18        fill=(250, 200, 80),
19    )
20    draw.polygon(
21        [(0, height), (width * 0.38, height * 0.32), (width * 0.7, height)],
22        fill=(95, 135, 95),
23    )
24    draw.polygon(
25        [
26            (width * 0.28, height),
27            (width * 0.64, height * 0.5),
28            (width, height),
29        ],
30        fill=(60, 95, 70),
31    )
32    return img

適応度は、目標画像との平均二乗誤差（小さいほど良い）で測る。

examples/evolution.py の fitness 関数
1def fitness(candidate: np.ndarray, target: np.ndarray) -> float:
2    """目標画像との平均二乗誤差(小さいほど良い)。"""
3    diff: np.ndarray = candidate - target
4    return float(np.mean(diff * diff))

(1+1) 進化戦略

集団（population）を持たず、「現在の 1 個体（親）」から変異させた「候補 1 個体（子）」だけを毎世代比較する、実装がもっとも単純な進化的アルゴリズムを (1+1) 進化戦略と呼ぶ（名前の「1+1」は、親 1 個体・子 1 個体という個体数の内訳を表す）。変異は、三角形を 1 枚追加・削除する、頂点を 1 つ少しずらす、色を少し変える、のいずれかをランダムに選んで行う。

examples/evolution.py の mutate 関数
 1def mutate(
 2    genome: Genome,
 3    rng: np.random.Generator,
 4    width: int,
 5    height: int,
 6    max_triangles: int,
 7) -> Genome:
 8    """現在の個体を複製し、1箇所だけランダムに変異させる。"""
 9    child: Genome = [
10        (vertices.copy(), color) for vertices, color in genome
11    ]
12
13    if not child:
14        child.append(random_triangle(width, height, rng))
15        return child
16
17    kind: str = _choose_mutation_kind(rng, can_add=len(child) < max_triangles)
18
19    if kind == "add":
20        child.append(random_triangle(width, height, rng))
21    elif kind == "remove":
22        remove_index: int = int(rng.integers(len(child)))
23        del child[remove_index]
24    elif kind == "vertex":
25        i: int = int(rng.integers(len(child)))
26        vertices, color = child[i]
27        vertices = vertices.copy()
28        j: int = int(rng.integers(3))
29        vertices[j] += rng.normal(0.0, min(width, height) * 0.05, size=2)
30        child[i] = (vertices, color)
31    else:  # color
32        i = int(rng.integers(len(child)))
33        vertices, color = child[i]
34        jitter: np.ndarray = rng.normal(0.0, 20.0, size=4)
35        new_color: tuple[int, int, int, int] = (
36            int(np.clip(color[0] + jitter[0], 0, 255)),
37            int(np.clip(color[1] + jitter[1], 0, 255)),
38            int(np.clip(color[2] + jitter[2], 0, 255)),
39            int(np.clip(color[3] + jitter[3], 0, 255)),
40        )
41        child[i] = (vertices, new_color)
42
43    return child

変異させた個体を描画して適応度を測り、現在の個体より良くなっていれば採用し、そうでなければ棄てて元の個体に戻る、という選択を指定世代数だけ繰り返す。

examples/evolution.py の evolve 関数
 1def evolve(
 2    target: np.ndarray,
 3    width: int,
 4    height: int,
 5    generations: int,
 6    max_triangles: int,
 7    rng: np.random.Generator,
 8    snapshot_at: tuple[int, ...] = (),
 9) -> tuple[Genome, dict[int, np.ndarray]]:
10    """(1+1)進化戦略で、三角形の集合を目標画像へ近づける。"""
11    genome: Genome = []
12    best_score: float = fitness(render_genome(genome, width, height), target)
13    snapshots: dict[int, np.ndarray] = {}
14
15    for generation in range(generations):
16        candidate: Genome = mutate(genome, rng, width, height, max_triangles)
17        candidate_image: np.ndarray = render_genome(candidate, width, height)
18        candidate_score: float = fitness(candidate_image, target)
19
20        if candidate_score < best_score:
21            genome = candidate
22            best_score = candidate_score
23
24        if generation in snapshot_at:
25            snapshots[generation] = render_genome(genome, width, height)
26
27    return genome, snapshots

世代を追うごとに三角形の集合が目標画像に近づいていく様子は、次のようになる（左から世代 30・300・1500・5999）。

6000 世代まで進めた最終結果を目標画像と比べると、三角形の粗い集合だけで山の稜線と太陽の位置がおおむね再現されているのが分かる。

本来の遺伝的アルゴリズムは、集団の中の複数個体を適応度に応じて選び出し、2 個体の遺伝子を組み合わせる交叉（crossover）を行うことで、より効率的に探索空間を進む。本章の (1+1) 進化戦略はそれを持たない最小構成だが、「改善する変異だけを採用する」という選択の核心部分は共通している。フラクタルの IFS が「あらかじめ選んだ変換をランダムに適用し続けると自然に収束する」手法だったのに対し、進化的アルゴリズムは「試行錯誤の結果を毎回評価し、良かったものだけを次に引き継ぐ」という、フィードバックを伴う探索である点が対照的である。
