はじめに

本資料の目的

ゲーム、映像、CAD、地図、データ可視化、UI など、コンピューターグラフィックス（CG）はエンジニアの身近にある。一方で、ゲームエンジンや描画ライブラリを使えば、画像が作られる仕組みを知らなくても絵を表示できる。そのため、次のような場面で困ることがある。

  • 3 次元の物体が意図しない位置や向きに表示されるが、どの変換が誤っているのか分からない。

  • 物体の手前と奥が逆に表示されたり、面がちらついたりする原因が分からない。

  • 遠くの模様がちらつく、輪郭がギザギザになるといった現象への対処方法が分からない。

  • シェーダーのコードを読んでも、計算の意味が分からない。

本資料では、CG の基本的なアルゴリズムを Python で実装しながら、画像が作られるまでの流れを学ぶ。完成するのは、三角形を Z バッファー法で描くソフトウェアレンダラーと、小さなレイトレーサーである。速さは実用には遠く及ばないが、GPU が内部で行っている処理と同じ考え方で作っている。

対象とする読者

  • CG の仕組みを基礎から理解したいエンジニア

  • ゲームエンジンや 3D ライブラリを使っていて、その内部で行われていることを知りたい人

  • シェーダーを書き始める前に、座標変換やライティングの考え方を押さえておきたい人

プログラミングの経験があり、Python と NumPy の基本的な書き方を知っていることを前提とする。数学は、高校で学ぶ三角関数とベクトルの知識があればよい。行列はベクトルと行列で必要な範囲を説明する。

サンプルコードの実行方法

サンプルコードはサンプルコード一覧から閲覧、ダウンロードできる。各スクリプトは、その章の図を作る。examples ディレクトリに移動し、図の保存先のディレクトリを引数に指定して実行する。引数を省略すると、figures ディレクトリに保存する。

1$ cd examples
2$ python raster2d.py figures

スクリプトどうしは関数を読み込み合っているので、examples ディレクトリのファイルは全て同じ場所に置いて実行すること。

本資料の約束事

本資料のコードと数式は、次の約束事にしたがう。

  • 画像は、形状が（高さ, 幅, 3）の NumPy 配列で表す。末尾の軸が R、G、B の 3 成分である。

  • 色の値は 0.0 から 1.0 の実数で扱い、画像を保存するときだけ 0 から 255 の整数に変換する。

  • 画像の座標は、左上を原点とし、x 軸は右向き、y 軸は下向きとする。

  • 3 次元の座標系は右手系とし、カメラは -z 方向を向くものとする。これは OpenGL と同じ約束事である。

  • 点やベクトルは列ベクトルとして扱い、変換は「行列 × ベクトル」の順に掛ける。
