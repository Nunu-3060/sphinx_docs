第 9 章 ライティング

現実の物体が立体的に見えるのは、光の当たり方によって面ごとに明るさが異なるためである。この章では、ライトの方向と面の向きから明るさを計算し、オブジェクトに陰影を付ける方法を説明する。

この章のサンプルコードは、examples/chapter09 フォルダーにある。

光の反射のモデル

物体の表面で反射する光は、大きく次の 3 つに分けて考えられる。

成分

内容

拡散反射

表面であらゆる方向に均等に散らばる光。見る方向によらず、同じ明るさに見える。物体の基本的な色と陰影を決める。

鏡面反射

鏡のように特定の方向に強く反射する光。見る方向によって位置が変わる、つやのあるハイライトになる。

環境光

周囲の物や空から間接的に届く光。ライトが直接当たらない面も、完全には真っ暗にならない。

ここで説明するモデルは、現実の光の振る舞いを簡略化した近似である。Unity の標準の Lit シェーダーは、より現実に近い物理ベースレンダリング（PBR）を使っている。本資料では、しくみを理解しやすい古典的なモデルを扱う。

ライティングの計算では、次のベクトルを使う。すべて表面の点から見た単位ベクトルである。

記号

意味

\(\mathbf{N}\)

法線（面の向き）

\(\mathbf{L}\)

表面からライトへ向かう方向

\(\mathbf{V}\)

表面からカメラへ向かう方向（視線の逆向き）

\(\mathbf{H}\)

\(\mathbf{L}\) と \(\mathbf{V}\) の中間の方向（ハーフベクトル）

拡散反射（Lambert 反射）

面に当たる光の量は、光が面に垂直に当たるときに最も多く、斜めに当たるほど少なくなる。光の束が斜めに当たると、同じ量の光がより広い面積に広がるためである。この関係を式にしたのが Lambert 反射である。

\[I_{diffuse} = C_{base} \, C_{light} \max(0,\ \mathbf{N} \cdot \mathbf{L})\]

\(C_{base}\) は物体の色、\(C_{light}\) はライトの色である。\(\mathbf{N}\) と \(\mathbf{L}\) はどちらも単位ベクトルなので、内積 \(\mathbf{N} \cdot \mathbf{L}\) は 2 つのなす角の余弦（cos）になる（第 2 章を参照）。面の裏側からライトが当たる場合は内積が負になるため、0 に切り詰める。

次のシェーダーは、メインライトによる Lambert 反射だけを計算する。

14            "Queue" = "Geometry"
15            "RenderPipeline" = "UniversalPipeline"
16        }
17
18        Pass
19        {
20            Name "Lambert"
21            Tags { "LightMode" = "UniversalForward" }
22
23            HLSLPROGRAM
24            #pragma vertex Vert
25            #pragma fragment Frag
26
27            // ライトの情報を取得する関数を使うため、Lighting.hlsl を読み込む
28            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
29            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
30
31            struct Attributes
32            {
33                float4 positionOS : POSITION;
34                float3 normalOS : NORMAL; // オブジェクト空間の法線
35            };
36
37            struct Varyings
38            {
39                float4 positionCS : SV_POSITION;
40                float3 normalWS : TEXCOORD0; // ワールド空間の法線
41            };
42
43            CBUFFER_START(UnityPerMaterial)
44                half4 _BaseColor;
45            CBUFFER_END
46
47            Varyings Vert(Attributes input)
48            {
49                Varyings output;
50                output.positionCS = TransformObjectToHClip(input.positionOS.xyz);
51                // 法線は位置とは異なる方法で変換する必要がある（第 3 章を参照）
52                output.normalWS = TransformObjectToWorldNormal(input.normalOS);
53                return output;
54            }
55
56            half4 Frag(Varyings input) : SV_Target
57            {
58                // 補間された法線は長さが 1 でなくなるため、正規化し直す
59                float3 normalWS = normalize(input.normalWS);
60
61                // メインライト（最も明るいディレクショナルライト）の情報を取得する。
62                // mainLight.direction は、表面からライトへ向かう単位ベクトル。
63                Light mainLight = GetMainLight();
64
65                // Lambert 反射：明るさは法線とライト方向の内積に比例する。
66                // 裏側（内積が負）は 0 にする。
67                half nDotL = saturate(dot(normalWS, mainLight.direction));
68                half3 diffuse = _BaseColor.rgb * mainLight.color * nDotL;
69
70                return half4(diffuse, 1.0);
71            }
72            ENDHLSL
73        }
74    }
75}

Lambert.shader をダウンロード

球に適用すると、ライトの方向の面が明るく、反対側が真っ暗に表示される。Directional Light を回転させると、明るい面の位置が変わる。

コードのポイントは、次のとおりである。

  • Lighting.hlsl を読み込み、ライトの情報を取得する関数を使えるようにしている。

  • 頂点シェーダーでは、TransformObjectToWorldNormal 関数で法線をワールド空間に変換し、フラグメントシェーダーに渡している。ライトの方向もワールド空間で与えられるため、同じ座標空間にそろえる必要がある。

  • フラグメントシェーダーでは、補間された法線を normalize 関数で正規化し直している（第 4 章を参照）。

  • GetMainLight 関数で、メインライトの情報を Light 構造体として取得している。direction は \(\mathbf{L}\)、color は \(C_{light}\) である。color には、ライトの Intensity を掛けた値が入っている。

  • HLSL の saturate 関数で、内積を 0～1 に切り詰めている。内積は 1 を超えないため、\(\max(0,\ \mathbf{N} \cdot \mathbf{L})\) と同じ結果になる。

注釈

メインライトは、シーンの中で最も明るい Directional Light である。Lighting ウィンドウの Sun Source でライトを指定した場合は、そのライトがメインライトになる。本資料のサンプルは、メインライト以外のライト（ほかの Directional Light、Point Light、Spot Light）を計算しない。

Half Lambert

Lambert 反射では、ライトが当たらない面が真っ暗になる。明るさの変化をなだらかにしたい場合は、内積を 0～1 の範囲に変換して使う Half Lambert がよく使われる。

\[I_{diffuse} = C_{base} \, C_{light} \left(\frac{\mathbf{N} \cdot \mathbf{L}}{2} + \frac{1}{2}\right)^2\]

Half Lambert は、物理的な根拠のない表現上の工夫である。ゲームのキャラクターなど、陰影を柔らかく見せたい場合に使われる。コードでは、nDotL を求める行を次のように変える。

half nDotL = dot(normalWS, mainLight.direction) * 0.5 + 0.5;
nDotL = nDotL * nDotL;

鏡面反射と環境光

Phong 反射

鏡面反射は、光がちょうど鏡のように反射する方向から見たときに最も強く見える。Phong 反射では、\(\mathbf{L}\) を法線に対して反射させた方向 \(\mathbf{R}\) と、視線の方向 \(\mathbf{V}\) の内積で、ハイライトの強さを求める。

\[\mathbf{R} = 2(\mathbf{N} \cdot \mathbf{L})\mathbf{N} - \mathbf{L}, \quad I_{specular} = C_{specular} \, C_{light} \max(0,\ \mathbf{R} \cdot \mathbf{V})^{s}\]

\(s\) は光沢度（Shininess）で、値が大きいほどハイライトが小さく鋭くなる。

Blinn-Phong 反射

Blinn-Phong 反射は、Phong 反射の \(\mathbf{R} \cdot \mathbf{V}\) の代わりに、ハーフベクトル \(\mathbf{H}\) と法線の内積を使う。反射ベクトルを計算するより少ない計算で済み、視線とライトの角度が大きい場合でも自然なハイライトになるため、Phong 反射より広く使われている。

\[\mathbf{H} = \mathrm{normalize}(\mathbf{L} + \mathbf{V}), \quad I_{specular} = C_{specular} \, C_{light} \max(0,\ \mathbf{N} \cdot \mathbf{H})^{s}\]

同じ光沢度では、Blinn-Phong のハイライトは Phong より大きくなる。Phong と同じくらいの大きさにするには、光沢度を 2～4 倍程度にする。

環境光

Unity では、Lighting ウィンドウの Environment Lighting の設定（スカイボックスの色など）から、あらゆる方向から届く環境光が計算される。この環境光は、球面調和関数（Spherical Harmonics、SH）と呼ばれる形式で保存されている。URP では、SampleSH 関数に法線を渡すと、その方向から届く環境光の色が得られる。

\[I_{ambient} = C_{base} \, C_{SH}(\mathbf{N})\]

最終的な色は、3 つの成分の和になる。

\[I = I_{ambient} + I_{diffuse} + I_{specular}\]

Blinn-Phong のシェーダー

次のシェーダーは、環境光、拡散反射、鏡面反射を組み合わせる。

BlinnPhong.shader
 1// 第 9 章：環境光、拡散反射（Lambert）、鏡面反射（Blinn-Phong）を組み合わせたシェーダー。
 2Shader "Introduction/Chapter09/BlinnPhong"
 3{
 4    Properties
 5    {
 6        [MainColor] _BaseColor ("Base Color", Color) = (1, 1, 1, 1)
 7        _SpecularColor ("Specular Color", Color) = (1, 1, 1, 1)
 8        // 値が大きいほどハイライトが小さく鋭くなる
 9        _Shininess ("Shininess", Range(1, 256)) = 32
10    }
11
12    SubShader
13    {
14        Tags
15        {
16            "RenderType" = "Opaque"
17            "Queue" = "Geometry"
18            "RenderPipeline" = "UniversalPipeline"
19        }
20
21        Pass
22        {
23            Name "BlinnPhong"
24            Tags { "LightMode" = "UniversalForward" }
25
26            HLSLPROGRAM
27            #pragma vertex Vert
28            #pragma fragment Frag
29
30            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
31            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
32
33            struct Attributes
34            {
35                float4 positionOS : POSITION;
36                float3 normalOS : NORMAL;
37            };
38
39            struct Varyings
40            {
41                float4 positionCS : SV_POSITION;
42                float3 positionWS : TEXCOORD0; // ワールド空間の位置（視線方向の計算に使う）
43                float3 normalWS : TEXCOORD1;
44            };
45
46            CBUFFER_START(UnityPerMaterial)
47                half4 _BaseColor;
48                half4 _SpecularColor;
49                float _Shininess;
50            CBUFFER_END
51
52            Varyings Vert(Attributes input)
53            {
54                Varyings output;
55                output.positionWS = TransformObjectToWorld(input.positionOS.xyz);
56                output.positionCS = TransformWorldToHClip(output.positionWS);
57                output.normalWS = TransformObjectToWorldNormal(input.normalOS);
58                return output;
59            }
60
61            half4 Frag(Varyings input) : SV_Target
62            {
63                float3 normalWS = normalize(input.normalWS);
64                // 表面からカメラへ向かう単位ベクトル
65                float3 viewDirWS = GetWorldSpaceNormalizeViewDir(input.positionWS);
66                Light mainLight = GetMainLight();
67
68                // 環境光：Lighting ウィンドウの Environment Lighting の設定から、
69                // 法線方向の光を取得する
70                half3 ambient = SampleSH(normalWS) * _BaseColor.rgb;
71
72                // 拡散反射（Lambert）
73                half nDotL = saturate(dot(normalWS, mainLight.direction));
74                half3 diffuse = _BaseColor.rgb * mainLight.color * nDotL;
75
76                // 鏡面反射（Blinn-Phong）：
77                // ライト方向と視線方向の中間のベクトル（ハーフベクトル）を使う
78                float3 halfDirWS = normalize(mainLight.direction + viewDirWS);
79                half nDotH = saturate(dot(normalWS, halfDirWS));
80                half3 specular = _SpecularColor.rgb * mainLight.color * pow(nDotH, _Shininess);
81
82                return half4(ambient + diffuse + specular, 1.0);
83            }
84            ENDHLSL
85        }
86    }
87}

BlinnPhong.shader をダウンロード

球に適用すると、ライトの当たる側につやのあるハイライトが表示される。ライトが当たらない側も、環境光によって真っ暗にはならない。カメラを動かすと、ハイライトの位置が変わる。

Lambert のシェーダーからの変更点は、次のとおりである。

  • 視線の方向を求めるため、頂点シェーダーでワールド空間の位置 positionWS を計算し、フラグメントシェーダーに渡している。

  • GetWorldSpaceNormalizeViewDir 関数で、表面からカメラへ向かう単位ベクトル \(\mathbf{V}\) を求めている。

  • SampleSH 関数で環境光を求め、物体の色を掛けている。

注釈

ライティングの計算を頂点シェーダーで行い、結果の色を補間する方法もある（頂点ライティング、Gouraud シェーディング）。計算の回数は減るが、頂点の少ないメッシュではハイライトの形が崩れる。本資料のサンプルは、ライティングの計算をすべてフラグメントシェーダーで行っている（ピクセルライティング）。
