第 12 章 透明と描画順

ガラスや水、煙のような半透明のものは、奥にあるものを透かして見せる必要がある。この章では、半透明の描画に必要なブレンドと描画順の考え方を説明する。また、葉や金網のように、完全に見える部分と完全に透明な部分だけがあるものを描画するアルファテストも扱う。

この章のサンプルコードは、examples/chapter12 フォルダーにある。

アルファブレンド

ブレンドは、フラグメントシェーダーが出力した色（ソース）と、画面にすでに描かれている色（デスティネーション）を合成する処理である（第 4 章を参照）。ShaderLab の Blend コマンドでは、ソースとデスティネーションにそれぞれ掛ける係数を指定する。

Blend ソースの係数 デスティネーションの係数

合成後の色は、次の式で求められる。

\[C = C_{src} \times F_{src} + C_{dst} \times F_{dst}\]

主な係数を、次の表に示す。

係数

値

One

1

Zero

0

SrcAlpha

ソースのアルファ \(\alpha_{src}\)

OneMinusSrcAlpha

\(1 - \alpha_{src}\)

DstColor

デスティネーションの色

半透明の描画で最もよく使うのは、Blend SrcAlpha OneMinusSrcAlpha である。

\[C = C_{src} \, \alpha_{src} + C_{dst} (1 - \alpha_{src})\]

アルファが 1 ならソースの色だけになり、0 ならデスティネーションの色だけになる。0.5 なら両者が半分ずつ混ざる。

ほかによく使う組み合わせを、次の表に示す。

用途

Blend One One

炎、光、火花などの光るエフェクト

Blend DstColor Zero

乗算

影や汚れなど、下の色を暗くする表現

半透明のシェーダー

次のシェーダーは、テクスチャーの色に _BaseColor を掛け、そのアルファで半透明に描画する。

Transparent.shader
 1// 第 12 章：アルファブレンドで半透明に描画するシェーダー。
 2Shader "Introduction/Chapter12/Transparent"
 3{
 4    Properties
 5    {
 6        [MainTexture] _BaseMap ("Base Map", 2D) = "white" {}
 7        // アルファ（a）の値が不透明度になる（0：完全に透明、1：不透明）
 8        [MainColor] _BaseColor ("Base Color", Color) = (1, 1, 1, 0.5)
 9    }
10
11    SubShader
12    {
13        // 不透明なオブジェクトをすべて描画したあとに描画するため、
14        // Queue を Transparent にする
15        Tags
16        {
17            "RenderType" = "Transparent"
18            "Queue" = "Transparent"
19            "RenderPipeline" = "UniversalPipeline"
20        }
21
22        Pass
23        {
24            Name "Transparent"
25            Tags { "LightMode" = "UniversalForward" }
26
27            // 出力する色 × アルファ + 画面に描かれている色 × (1 - アルファ)
28            Blend SrcAlpha OneMinusSrcAlpha
29            // 後ろにある半透明のオブジェクトが隠れないように、深度は書き込まない
30            ZWrite Off
31
32            HLSLPROGRAM
33            #pragma vertex Vert
34            #pragma fragment Frag
35
36            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
37
38            struct Attributes
39            {
40                float4 positionOS : POSITION;
41                float2 uv : TEXCOORD0;
42            };
43
44            struct Varyings
45            {
46                float4 positionCS : SV_POSITION;
47                float2 uv : TEXCOORD0;
48            };
49
50            TEXTURE2D(_BaseMap);
51            SAMPLER(sampler_BaseMap);
52
53            CBUFFER_START(UnityPerMaterial)
54                float4 _BaseMap_ST;
55                half4 _BaseColor;
56            CBUFFER_END
57
58            Varyings Vert(Attributes input)
59            {
60                Varyings output;
61                output.positionCS = TransformObjectToHClip(input.positionOS.xyz);
62                output.uv = TRANSFORM_TEX(input.uv, _BaseMap);
63                return output;
64            }
65
66            half4 Frag(Varyings input) : SV_Target
67            {
68                // テクスチャーのアルファと _BaseColor のアルファを掛けた値が、
69                // 最終的な不透明度になる
70                return SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, input.uv) * _BaseColor;
71            }
72            ENDHLSL
73        }
74    }
75}

Transparent.shader をダウンロード

マテリアルの Base Color のアルファ（A）を変えると、透け具合が変わる。

半透明のシェーダーでは、次の 3 つの設定が必要である。

  • Queue を Transparent にする：不透明なオブジェクトをすべて描画したあとに描画する。

  • Blend SrcAlpha OneMinusSrcAlpha：アルファブレンドを行う。

  • ZWrite Off：深度バッファーに書き込まない。

描画の順序と深度

半透明のオブジェクトを正しく描画するには、描画の順序が重要である。ブレンドは画面にすでに描かれている色と合成するため、奥にあるものが先に描かれていなければならない。

URP は、レンダーキュー（Queue の値）が小さいものから順に描画する。Transparent（3000）のオブジェクトは、Geometry（2000）の不透明なオブジェクトよりあとに描画されるため、不透明なオブジェクトは半透明のオブジェクトを通して見える。さらに、URP は半透明のオブジェクトどうしを、カメラから遠いものから順に並べて描画する。

ZWrite Off にするのは、半透明のオブジェクトが深度を書き込むと、その後ろに描画される半透明のオブジェクトが深度テストで破棄され、透けて見えなくなるためである。深度テスト自体は行われるので、半透明のオブジェクトは手前にある不透明なオブジェクトに正しく隠される。

重要

半透明のオブジェクトの並べ替えは、オブジェクトの中心の位置で行われる。そのため、半透明のオブジェクトが交差している場合や、1 つのメッシュの中で面が重なっている場合は、正しい順序で描画されないことがある。これは、半透明の描画の一般的な制限である。

半透明のオブジェクトどうしの順序を固定したい場合は、"Transparent+1" のようにレンダーキューを細かく指定するか、マテリアルの Render Queue を変更する（第 6 章を参照）。

アルファテスト

葉や金網、髪の毛の一部のように、完全に見える部分と完全に透明な部分だけがある場合は、アルファテストを使う。アルファテストでは、アルファがしきい値より小さいピクセルを破棄し、それ以外は不透明として描画する。

AlphaClip.shader
 1// 第 12 章：アルファテストで、
 2// アルファが一定の値より小さいピクセルを描画しないシェーダー。
 3// 葉や金網のように、「完全に見える部分」と「完全に透明な部分」だけがあるものに使う。
 4Shader "Introduction/Chapter12/AlphaClip"
 5{
 6    Properties
 7    {
 8        [MainTexture] _BaseMap ("Base Map", 2D) = "white" {}
 9        [MainColor] _BaseColor ("Base Color", Color) = (1, 1, 1, 1)
10        // アルファがこの値より小さいピクセルは描画しない
11        _Cutoff ("Alpha Cutoff", Range(0, 1)) = 0.5
12    }
13
14    SubShader
15    {
16        // 不透明なオブジェクトと同じく深度を書き込むが、
17        // 描画順は不透明なオブジェクトのあとにする
18        Tags
19        {
20            "RenderType" = "TransparentCutout"
21            "Queue" = "AlphaTest"
22            "RenderPipeline" = "UniversalPipeline"
23        }
24
25        Pass
26        {
27            Name "AlphaClip"
28            Tags { "LightMode" = "UniversalForward" }
29
30            // 板ポリゴンの裏側も描画する
31            Cull Off
32
33            HLSLPROGRAM
34            #pragma vertex Vert
35            #pragma fragment Frag
36
37            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
38
39            struct Attributes
40            {
41                float4 positionOS : POSITION;
42                float2 uv : TEXCOORD0;
43            };
44
45            struct Varyings
46            {
47                float4 positionCS : SV_POSITION;
48                float2 uv : TEXCOORD0;
49            };
50
51            TEXTURE2D(_BaseMap);
52            SAMPLER(sampler_BaseMap);
53
54            CBUFFER_START(UnityPerMaterial)
55                float4 _BaseMap_ST;
56                half4 _BaseColor;
57                half _Cutoff;
58            CBUFFER_END
59
60            Varyings Vert(Attributes input)
61            {
62                Varyings output;
63                output.positionCS = TransformObjectToHClip(input.positionOS.xyz);
64                output.uv = TRANSFORM_TEX(input.uv, _BaseMap);
65                return output;
66            }
67
68            half4 Frag(Varyings input) : SV_Target
69            {
70                half4 color = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, input.uv) * _BaseColor;
71                // clip は、引数が負のときにこのピクセルを破棄する
72                // （破棄されたピクセルには、色も深度も書き込まれない）
73                clip(color.a - _Cutoff);
74                return half4(color.rgb, 1.0);
75            }
76            ENDHLSL
77        }
78    }
79}

AlphaClip.shader をダウンロード

アルファを持つテクスチャー（葉の画像など）を Base Map に設定し、Quad に適用すると、透明な部分が切り抜かれて表示される。Alpha Cutoff を変えると、切り抜かれる範囲が変わる。

clip 関数は、引数が負のときにそのピクセルを破棄する。破棄されたピクセルには、色も深度も書き込まれない。描画されるピクセルは不透明なので、深度を書き込んでも問題がなく、半透明のような描画の順序の問題も起きない。

アルファテストのシェーダーでは、Queue を AlphaTest（2450）にする。不透明なオブジェクトを先に描画しておくと、アルファテストのオブジェクトのうち隠れる部分の処理を省けるためである。
