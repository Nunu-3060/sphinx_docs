第 11 章 影

第 9 章と第 10 章のシェーダーは、ほかのオブジェクトに影を落とさず、ほかのオブジェクトの影も受けない。この章では、シャドウマップのしくみを説明し、影を落とし、影を受けるシェーダーを作る。

この章のサンプルコードは、examples/chapter11 フォルダーにある。

シャドウマップ

URP は、シャドウマップと呼ばれる方法で影を描画する。シャドウマップの手順は、次の 2 段階である。

  1. ライトの位置からシーンを見たときの深度を、テクスチャー（シャドウマップ）に描画する。シャドウマップの各ピクセルには、ライトから最も近いオブジェクトまでの距離が記録される。

  2. カメラから見たシーンを描画するときに、各ピクセルの位置をライトから見た座標に変換し、シャドウマップの深度と比べる。シャドウマップの深度より奥にあれば、ライトとの間にほかのオブジェクトがあるので、影の中にある。

シェーダーの立場から見ると、1 つ目の段階が「影を落とす」処理、2 つ目の段階が「影を受ける」処理である。影を落とすには、シャドウマップに深度を書き込むための ShadowCaster パスが必要である。影を受けるには、色を描画するパスの中でシャドウマップを参照する必要がある。

カスケードシャドウマップ

Directional Light は、シーン全体を照らすため、1 枚のシャドウマップでシーン全体を覆うと、カメラの近くの影が粗くなる。そこで、カメラからの距離に応じて範囲を複数に分け、範囲ごとにシャドウマップを作る。この方法をカスケードシャドウマップという。分割の数は、URP Asset の Shadows の Cascade Count で設定する。

影を落とし、影を受けるシェーダー

次のシェーダーは、第 9 章の Blinn-Phong のシェーダーに、影を受ける処理と、影を落とすための ShadowCaster パスを加えたものである。さらに、カメラの深度テクスチャーに深度を書き込むための DepthOnly パスも加えている。

ShadowLit.shader
  1// 第 11 章：影を落とし（ShadowCaster パス）、
  2// 影を受ける（シャドウマップの参照）シェーダー。
  3// ライティングは第 9 章の BlinnPhong.shader と同じ計算に、影の減衰を加えたもの。
  4Shader "Introduction/Chapter11/ShadowLit"
  5{
  6    Properties
  7    {
  8        [MainColor] _BaseColor ("Base Color", Color) = (1, 1, 1, 1)
  9        _SpecularColor ("Specular Color", Color) = (1, 1, 1, 1)
 10        _Shininess ("Shininess", Range(1, 256)) = 32
 11    }
 12
 13    SubShader
 14    {
 15        Tags
 16        {
 17            "RenderType" = "Opaque"
 18            "Queue" = "Geometry"
 19            "RenderPipeline" = "UniversalPipeline"
 20        }
 21
 22        // HLSLINCLUDE の内容は、このサブシェーダーのすべてのパスの先頭に挿入される。
 23        // SRP Batcher に対応させるには、
 24        // すべてのパスで UnityPerMaterial の内容を同じにする必要がある。
 25        HLSLINCLUDE
 26        #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
 27
 28        CBUFFER_START(UnityPerMaterial)
 29            half4 _BaseColor;
 30            half4 _SpecularColor;
 31            float _Shininess;
 32        CBUFFER_END
 33        ENDHLSL
 34
 35        // 1 つ目のパス：画面に色を描画する
 36        Pass
 37        {
 38            Name "ForwardLit"
 39            Tags { "LightMode" = "UniversalForward" }
 40
 41            HLSLPROGRAM
 42            #pragma vertex Vert
 43            #pragma fragment Frag
 44
 45            // メインライトの影を受けるためのキーワード。
 46            // URP Asset の影の設定に応じて、URP がこのうち 1 つを有効にする。
 47            #pragma multi_compile _ _MAIN_LIGHT_SHADOWS _MAIN_LIGHT_SHADOWS_CASCADE
 48            // ソフトシャドウ（影の輪郭をぼかす処理）のためのキーワード
 49            #pragma multi_compile_fragment _ _SHADOWS_SOFT _SHADOWS_SOFT_LOW _SHADOWS_SOFT_MEDIUM _SHADOWS_SOFT_HIGH
 50
 51            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
 52
 53            struct Attributes
 54            {
 55                float4 positionOS : POSITION;
 56                float3 normalOS : NORMAL;
 57            };
 58
 59            struct Varyings
 60            {
 61                float4 positionCS : SV_POSITION;
 62                float3 positionWS : TEXCOORD0;
 63                float3 normalWS : TEXCOORD1;
 64            };
 65
 66            Varyings Vert(Attributes input)
 67            {
 68                Varyings output;
 69                output.positionWS = TransformObjectToWorld(input.positionOS.xyz);
 70                output.positionCS = TransformWorldToHClip(output.positionWS);
 71                output.normalWS = TransformObjectToWorldNormal(input.normalOS);
 72                return output;
 73            }
 74
 75            half4 Frag(Varyings input) : SV_Target
 76            {
 77                float3 normalWS = normalize(input.normalWS);
 78                float3 viewDirWS = GetWorldSpaceNormalizeViewDir(input.positionWS);
 79
 80                // ワールド空間の位置を、シャドウマップを参照するための座標に変換する
 81                float4 shadowCoord = TransformWorldToShadowCoord(input.positionWS);
 82                // 引数に shadowCoord を渡すと、
 83                // mainLight.shadowAttenuation に影の情報が入る
 84                // （0：完全に影の中、1：影の外）
 85                Light mainLight = GetMainLight(shadowCoord);
 86                half3 lightColor = mainLight.color * mainLight.shadowAttenuation;
 87
 88                half3 ambient = SampleSH(normalWS) * _BaseColor.rgb;
 89
 90                half nDotL = saturate(dot(normalWS, mainLight.direction));
 91                half3 diffuse = _BaseColor.rgb * lightColor * nDotL;
 92
 93                float3 halfDirWS = normalize(mainLight.direction + viewDirWS);
 94                half nDotH = saturate(dot(normalWS, halfDirWS));
 95                half3 specular = _SpecularColor.rgb * lightColor * pow(nDotH, _Shininess);
 96
 97                return half4(ambient + diffuse + specular, 1.0);
 98            }
 99            ENDHLSL
100        }
101
102        // 2 つ目のパス：シャドウマップに深度を書き込み、ほかのオブジェクトに影を落とす
103        Pass
104        {
105            Name "ShadowCaster"
106            Tags { "LightMode" = "ShadowCaster" }
107
108            ZWrite On
109            ZTest LEqual
110            // 色は書き込まない
111            ColorMask 0
112
113            HLSLPROGRAM
114            #pragma vertex ShadowVert
115            #pragma fragment ShadowFrag
116
117            // ポイントライトとスポットライトの影を描画するときに、
118            // URP が有効にするキーワード
119            #pragma multi_compile_vertex _ _CASTING_PUNCTUAL_LIGHT_SHADOW
120
121            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Shadows.hlsl"
122
123            // 影を描画しているライトの向きと位置。URP が値を設定する。
124            float3 _LightDirection;
125            float3 _LightPosition;
126
127            struct Attributes
128            {
129                float4 positionOS : POSITION;
130                float3 normalOS : NORMAL;
131            };
132
133            struct Varyings
134            {
135                float4 positionCS : SV_POSITION;
136            };
137
138            Varyings ShadowVert(Attributes input)
139            {
140                Varyings output;
141                float3 positionWS = TransformObjectToWorld(input.positionOS.xyz);
142                float3 normalWS = TransformObjectToWorldNormal(input.normalOS);
143
144            #if defined(_CASTING_PUNCTUAL_LIGHT_SHADOW)
145                float3 lightDirectionWS = normalize(_LightPosition - positionWS);
146            #else
147                float3 lightDirectionWS = _LightDirection;
148            #endif
149
150                // シャドウアクネ（表面に縞模様の影が出る現象）を防ぐため、
151                // 位置を少しずらす
152                positionWS = ApplyShadowBias(positionWS, normalWS, lightDirectionWS);
153                output.positionCS = TransformWorldToHClip(positionWS);
154
155                // ライトの近くでクリップ面より手前に出た頂点を、
156                // クリップ面の位置に押し戻す
157            #if UNITY_REVERSED_Z
158                output.positionCS.z = min(output.positionCS.z, UNITY_NEAR_CLIP_VALUE);
159            #else
160                output.positionCS.z = max(output.positionCS.z, UNITY_NEAR_CLIP_VALUE);
161            #endif
162                return output;
163            }
164
165            half4 ShadowFrag(Varyings input) : SV_Target
166            {
167                // 深度だけが必要なため、色は何を返してもよい
168                return 0;
169            }
170            ENDHLSL
171        }
172
173        // 3 つ目のパス：深度テクスチャーに深度を書き込む。
174        // カメラの深度テクスチャーを使う機能（Depth Priming や、
175        // 深度を使うエフェクトなど）で必要になる。
176        Pass
177        {
178            Name "DepthOnly"
179            Tags { "LightMode" = "DepthOnly" }
180
181            ZWrite On
182            ColorMask R
183
184            HLSLPROGRAM
185            #pragma vertex DepthVert
186            #pragma fragment DepthFrag
187
188            struct Attributes
189            {
190                float4 positionOS : POSITION;
191            };
192
193            struct Varyings
194            {
195                float4 positionCS : SV_POSITION;
196            };
197
198            Varyings DepthVert(Attributes input)
199            {
200                Varyings output;
201                output.positionCS = TransformObjectToHClip(input.positionOS.xyz);
202                return output;
203            }
204
205            half DepthFrag(Varyings input) : SV_Target
206            {
207                return input.positionCS.z;
208            }
209            ENDHLSL
210        }
211    }
212}

ShadowLit.shader をダウンロード

Plane の上に球を置き、両方にこのシェーダーのマテリアルを設定すると、球の影が Plane に落ちる。Plane だけに URP の標準の Lit シェーダーを使った場合も、球の影は Plane に落ちる。

パス間で共通の定数バッファー

このシェーダーは 3 つのパスを持つ。SRP Batcher に対応させるには、すべてのパスで UnityPerMaterial の内容を同じにする必要がある（第 5 章を参照）。そこで、HLSLINCLUDE ブロックに Core.hlsl の読み込みと UnityPerMaterial の宣言をまとめ、すべてのパスで共通に使っている。

影を受ける処理

影を受ける処理は、ForwardLit パスで行っている。

シェーダーのバリアントとキーワード

URP は、URP Asset の影の設定に応じて、_MAIN_LIGHT_SHADOWS などのキーワードを有効にする。シェーダーの中では、キーワードが有効かどうかで #if によって処理を切り替えている。Lighting.hlsl の中の影の関数も、これらのキーワードを見て、影の計算を行うかどうかを決めている。

#pragma multi_compile は、指定したキーワードごとに、シェーダーの別々の版をコンパイルする命令である。この別々の版をシェーダーのバリアントという。

#pragma multi_compile _ _MAIN_LIGHT_SHADOWS _MAIN_LIGHT_SHADOWS_CASCADE

この行では、キーワードなし（_）、_MAIN_LIGHT_SHADOWS、_MAIN_LIGHT_SHADOWS_CASCADE の 3 つのバリアントが作られる。実行時には、有効になっているキーワードに合ったバリアントが使われる。キーワードの意味は、次のとおりである。

キーワード

有効になる条件

_MAIN_LIGHT_SHADOWS

メインライトの影が有効で、カスケードが 1 つのとき

_MAIN_LIGHT_SHADOWS_CASCADE

メインライトの影が有効で、カスケードが 2 つ以上のとき

_SHADOWS_SOFT など

ソフトシャドウ（影の輪郭をぼかす処理）が有効なとき。末尾の _LOW、_MEDIUM、_HIGH は品質を表す

#pragma multi_compile_fragment は、フラグメントシェーダーだけでキーワードを使う場合の書き方である。頂点シェーダーのバリアントが増えないため、コンパイルの時間とメモリを節約できる。

バリアントの数は、キーワードの組み合わせの数だけ増える。この例では 3 × 5 = 15 個のバリアントが作られる。バリアントが多すぎる問題については、第 17 章で説明する。

注釈

URP には、画面空間で影を計算する Screen Space Shadows という機能もある。この機能を有効にすると _MAIN_LIGHT_SHADOWS_SCREEN キーワードが使われるが、サンプルは対応していない。Screen Space Shadows は既定では無効である。

シャドウマップの参照

フラグメントシェーダーでは、TransformWorldToShadowCoord 関数で、ワールド空間の位置をシャドウマップの座標に変換している。カスケードシャドウマップの場合は、どのカスケードを使うかもこの関数が決める。

その座標を GetMainLight 関数の引数に渡すと、戻り値の shadowAttenuation に、影の中にあるかどうかが 0（完全に影の中）～1（影の外）の値で入る。ライトの色に shadowAttenuation を掛けることで、影の中では拡散反射と鏡面反射が弱まる。環境光には掛けないため、影の中も真っ暗にはならない。

影を落とす処理

影を落とす処理は、ShadowCaster パスで行っている。URP は、シャドウマップを描画するときに、LightMode が ShadowCaster のパスを使う。

  • 色は必要なく深度だけを書き込むため、ColorMask 0 で色の書き込みを止めている。

  • _LightDirection と _LightPosition には、影を描画しているライトの向きと位置を、URP が設定する。ポイントライトとスポットライトの影を描画するときは、URP が _CASTING_PUNCTUAL_LIGHT_SHADOW キーワードを有効にする。

  • 頂点シェーダーでは、ApplyShadowBias 関数で頂点の位置を少しずらしている。これは、シャドウアクネと呼ばれる現象を防ぐためである。

シャドウアクネ

シャドウマップの 1 つのピクセルは、ある程度の広さを持つ。そのため、ライトに照らされている面でも、自分自身の深度と比べたときに、わずかな差で「奥にある」と判定される部分ができる。その結果、表面に縞模様の影が現れる。この現象をシャドウアクネという。

シャドウアクネを防ぐには、シャドウマップに書き込む深度をライトから少し遠ざける（深度バイアス）か、頂点を法線の逆方向に少し押し込む（法線バイアス）。ApplyShadowBias 関数は、ライトの Shadows の Bias の設定に従って、両方を適用する。バイアスが大きすぎると、影がオブジェクトから離れて見える（ピーターパン現象）。

DepthOnly パス

URP は、カメラの深度テクスチャーが必要な場合に、LightMode が DepthOnly のパスで、不透明なオブジェクトの深度を先に描画することがある。例えば、Universal Renderer Data アセットの Depth Priming Mode を有効にした場合である。DepthOnly のパスがないシェーダーは、深度テクスチャーに書き込まれないため、深度テクスチャーを使う機能で正しく扱われない。

DepthOnly のパスは、深度を書き込むだけの単純なパスである。サンプルでは、フラグメントシェーダーでクリップ空間の z を返し、ColorMask R で 1 つのチャンネルだけに書き込んでいる。

注釈

Screen Space Ambient Occlusion（SSAO）などの機能は、深度に加えて法線のテクスチャーを使う。その場合、URP は LightMode が DepthNormals のパスを使う。本資料では DepthNormals のパスは扱わない。必要な場合は、URP の Lit シェーダーの DepthNormals のパスを参考にするとよい。
