技術者倫理

本資料は、エンジニアが業務の中で直面する倫理的な問題を取り上げ、その考え方と対処の方法をまとめたものです。

本資料の目的

技術は社会に大きな便益をもたらす一方で、使い方や作り方を誤ると、人の生命や財産、権利を損ないます。技術者は、技術の中身を最もよく理解している立場として、その影響を予測し、害を防ぐ責任を負います。

本資料の目的は次の 3 点です。

  • 技術者倫理の基本的な考え方と、代表的な倫理綱領の内容を理解します。

  • 過去の事故や不正の事例から、問題が起きる仕組みを学びます。

  • セキュリティ、プライバシー、AI など、ソフトウェア開発の現場で判断に迷う場面への対処の方法を身に付けます。

対象読者

ソフトウェアやシステムの開発・運用に携わるエンジニアを対象とします。倫理学や法律の予備知識は前提としません。専門用語は用語集にまとめています。

本資料の読み方

本資料は次の順に構成しています。

章

区分

内容

第 1〜3 章

基礎

技術者倫理の考え方、倫理綱領、倫理的な判断の方法

第 4 章

事例

歴史的な事故・不正の分析

第 5〜10 章

実務

品質と安全、セキュリティ、プライバシー、知的財産、利用者の尊重、AI

第 11〜12 章

組織と法令

組織の中での振る舞い方、関連する法令

第 13〜14 章

実践

演習問題、チェックリスト

初めて読む場合は、第 1 章から順に読むことをお勧めします。特定の分野だけを確認したい場合は、第 3 章の判断の方法を読んだうえで、該当する章を参照してください。

各章で紹介するサンプルコードは、サンプルコード一覧から閲覧・ダウンロードできます。

注釈

本資料で紹介する法令の内容は概要です。法令は改正されることがあるため、実務で判断する際は最新の条文や公的機関の情報を確認し、必要に応じて法務部門や専門家に相談してください。
