制御フロー

プログラムの流れを制御する分岐や繰り返しの構文は、Python と同様に Rust でも中心的な役割を果たしますが、細部には Rust ならではの特徴があります。本章では if、loop、while、for の4つを見ていきます。

if式

Rust の if は条件分岐を行うだけでなく、値を返す「式」としても扱えるという特徴があります。

fn main() {
    let number = 6;

    if number % 4 == 0 {
        println!("4の倍数です");
    } else if number % 2 == 0 {
        println!("2の倍数です");
    } else {
        println!("奇数です");
    }
}

if は次のように値を返す式として使うこともできます。この場合、各分岐が返す値の型はすべて一致している必要があります。

fn main() {
    let condition = true;
    let x = if condition { 5 } else { 6 };
    println!("xの値は{}です", x);
}

比較演算子と論理演算子

if の条件式を書くうえで欠かせないのが、比較演算子と論理演算子です。Rust の比較演算子は == (等しい)、!= (等しくない)、<、>、<=、>= の6種類で、いずれも bool 型の値を返します。

fn main() {
    let a = 5;
    let b = 10;

    println!("{}", a == b); // false
    println!("{}", a != b); // true
    println!("{}", a < b);  // true
    println!("{}", a >= b); // false
}

複数の条件を組み合わせるには、論理演算子の && (論理積、かつ)、|| (論理和、または)、! (否定)を使います。

fn main() {
    let age = 20;
    let has_ticket = true;

    if age >= 18 && has_ticket {
        println!("入場できます");
    }

    if age < 18 || !has_ticket {
        println!("入場できません");
    }
}

&& と || は左側の結果だけで全体の真偽が決まる場合、右側を評価しない「短絡評価(short-circuit evaluation)」を行います。これは Python の and/or と同じ挙動です。

Python 経験者向けメモ

Rust の比較演算子は Python とほぼ同じ記法ですが、Python の 1 < x < 10 のような連鎖比較は Rust にはできず、1 < x && x < 10 のように && でつなぐ必要があります。また、論理演算子は Python では and/or/not というキーワードですが、Rust では &&/||/! という記号を使います。挙動面では、Python の and/or は左右どちらかの値そのもの(例: 0 or "default" が "default" を返す)を返すことがありますが、Rust の &&/|| は常に bool を返す点が異なります。短絡評価が行われる点は両者共通です。

loop

loop は明示的に break するまで無限に繰り返すループです。Rust の loop の特徴的な点は、break に値を渡すことでループ全体の返り値とできることです。

fn main() {
    let mut counter = 0;

    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2;
        }
    };

    println!("結果: {}", result); // 20
}

なお、counter += 1; のような複合代入演算子については、「変数と型」の章で説明した通りです。

while

while は条件が真である間だけ繰り返すループで、Python の while とほぼ同じ感覚で使えます。

fn main() {
    let mut number = 3;

    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }

    println!("発射!");
}

ここでも number -= 1; という複合代入演算子が使われていますが、これも「変数と型」の章で紹介したものです。

while や for の中では、continue を使うと現在の反復に残っている処理をスキップし、次の反復へ進むことができます。break がループ全体を終了させるのに対し、continue はそのループ自体は継続したまま次のサイクルへ移る点が異なります。

fn main() {
    let mut number = 0;

    while number < 5 {
        number += 1;
        if number % 2 == 0 {
            continue;
        }
        println!("奇数: {}", number);
    }
}

for とイテレータ

for はイテレータ(要素を1つずつ取り出す仕組み)を用いて繰り返し処理を行う構文です。Rust では指定した範囲を繰り返す場合、0..10 のような「範囲(Range)」を使います。

fn main() {
    for i in 0..10 {
        println!("i = {}", i);
    }
}

0..10 は 0 から 9 までの範囲(10 は含まない)を表します。10 を含めたい場合は 0..=10 のように書きます。

コレクションの要素を1つずつ処理する場合は、iter() メソッドを使ってイテレータを取得します。なお、以下の例に登場する Vec<T> (可変長ベクタ)については後の章で詳しく扱いますが、ここでは Python のリストと同じような感覚でひとまず使ってみましょう。

fn main() {
    let numbers = vec![10, 20, 30, 40, 50];

    for item in numbers.iter() {
        println!("値: {}", item);
    }
}

while で同様の処理を書くこともできますが、範囲外アクセスのリスクや書き間違いの余地があるため、Rust では for によるイテレータベースの反復が推奨されます。

Python 経験者向けメモ

Rust の for item in numbers.iter() は、Python の for item in numbers: と発想がよく似ており、どちらもイテレータを介して要素を取り出す仕組みです。一方で大きく異なるのは if の扱いです。Python の if はあくまで文であり値を返せませんが(三項演算子的に書くには a if cond else b という別の構文が必要です)、Rust の if/else はそれ自体が値を返す「式」であるため、let x = if cond { a } else { b }; のように直接変数へ束縛できます。この違いに慣れると、Rust では条件によって変わる値をより簡潔に表現できるようになります。また、Rust の if の条件式は必ず bool 型でなければならず、Python のように空リストやゼロ、空文字列などが自動的に真偽値へ変換されることはありません。

まとめ

  • if は式であり、let x = if cond { a } else { b }; のように値を返せます

  • 比較演算子は ==、!=、<、>、<=、>= の6種類で、いずれも bool を返します

  • 論理演算子は && (かつ)、|| (または)、! (否定)で、&&/|| は短絡評価されます

  • loop は無限ループで、break 値 によってループ自体に値を返せます

  • continue を使うと、現在の反復の残りをスキップして次の反復に進めます

  • while は条件が真の間繰り返す、Python と似た感覚のループです

  • for はイテレータを使った繰り返しで、0..10 のような範囲や iter() と組み合わせます

  • Rust では範囲外アクセスを避けるため for によるイテレータベースの反復が推奨されます
