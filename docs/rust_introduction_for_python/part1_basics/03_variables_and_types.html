変数と型

Rust の変数は、Python とは異なる考え方に基づいて設計されています。本章では、変数の宣言方法と、Rust が持つ基本的な型について学びます。

変数の宣言(let と mut)

Rust では let キーワードで変数を宣言します。重要な特徴は、let で宣言した変数は既定で イミュータブル(不変) であるという点です。

なお、以降のコード例には // から始まる部分が登場します。これはコメントで、// から行末までがコンパイラに無視されます。複数行にわたるコメントを書きたい場合は /* ... */ で囲む書き方もあります。

fn main() {
    let x = 5;
    println!("xの値は{}です", x);
    // x = 6; // コンパイルエラーになる
}

println! の文字列中にある {} は「プレースホルダー」と呼ばれ、後ろに続く引数の値がその位置に順番に埋め込まれます。上の例では {} の部分が x の値(5)に置き換わり、「xの値は5です」と表示されます。引数が複数ある場合は、{} の登場順と引数の順番が対応します(例: println!("{} {}", a, b) なら最初の {} が a、次が b になります)。

値を後から変更したい場合は、mut キーワードを付けて宣言する必要があります。

fn main() {
    let mut y = 5;
    println!("yの値は{}です", y);
    y = 6;
    println!("yの値は{}です", y);
}

このように「変更するつもりのある変数」を明示的にマークすることで、コードを読む人は mut の付いていない変数が途中で書き換わらないことを保証された状態で読み進められます。

なお、y = y + 1; のような「現在の値に何かを加えて代入し直す」処理は、y += 1; のように複合代入演算子でまとめて書くこともできます。同様に -=、*=、/= もよく使われます。これらは後の章のループの例(counter += 1; や number -= 1;)にも登場します。

命名規則

Rust のコミュニティには、公式のスタイルガイドで定められた命名規則があり、cargo fmt/cargo clippy (前章で紹介した公式のフォーマッタ・リンター)もこの規則を前提にしています。主なものは次のとおりです。

  • 変数・関数: snake_case (例: user_name、calculate_total)

  • 型(構造体・enum・トレイト): PascalCase (例: UserAccount、HttpError)

  • 定数: SCREAMING_SNAKE_CASE (例: MAX_RETRY_COUNT)

この規則から外れる名前を使うと、コンパイラや clippy が警告を出すことがあります。Python にも同様の慣習(PEP 8)がありますが、Rust ではツールによるチェックがより一般的に行われている点が特徴です。

シャドーイング

Rust では、同じ名前で let を使って変数を再宣言する「シャドーイング(shadowing)」という機能があります。

fn main() {
    let x = 5;
    let x = x + 1;
    let x = x * 2;
    println!("xの値は{}です", x); // 12
}

シャドーイングは mut による再代入とは異なり、新しい変数を作り直しているだけなので、型を変えることも可能です。例えば文字列を受け取って数値に変換した結果を同じ名前で束縛し直す、といった使い方がよくされます。

fn main() {
    let spaces = "   ";
    let spaces = spaces.len();
    println!("スペースの数: {}", spaces); // 3
}

このように、最初は文字列(&str)だった spaces が、2回目の let では数値(usize)として再束縛されています。

スカラー型

スカラー型は、単一の値を表す型です。Rust には主に次の4種類があります。

  • 整数型: i32, u32, i64, u64 など。先頭の i は符号あり(signed)、u は符号なし(unsigned)を表し、続く数字はビット幅です。特に指定がなければ i32 が既定の型として使われます。

  • 浮動小数点数型: f32 と f64 があり、既定は f64 です。

  • 真偽値型: bool。値は true か false のいずれかです。

  • 文字型: char。シングルクォートで囲み、Unicode のスカラー値1文字を表します(単一のコードポイントで表せる絵文字の多く(例: 😀)は1文字として扱えます)。

fn main() {
    let age: u32 = 30;
    let pi: f64 = 3.14159;
    let is_active: bool = true;
    let initial: char = 'R';
    println!("{} {} {} {}", age, pi, is_active, initial);
}

ここで、クォートの使い分けに注意してください。'R' のようにシングルクォートで囲むと1文字を表す char 型になり、"hello" のようにダブルクォートで囲むと文字列(&str)になります。Python では 'text' と "text" はどちらも同じ文字列として扱われますが、Rust ではこの2つは明確に区別される別の型であり、let c: char = "R"; のようにダブルクォートで char に代入しようとするとコンパイルエラーになります。

算術演算子

数値型に対しては、+ (加算)、- (減算)、* (乗算)、/ (除算)、% (剰余)の5つの算術演算子が使えます。

fn main() {
    let sum = 5 + 3;
    let difference = 5 - 3;
    let product = 5 * 3;
    let quotient = 5 / 2;
    let remainder = 5 % 2;
    println!("{} {} {} {} {}", sum, difference, product, quotient, remainder);
}

注意が必要なのは / の扱いです。整数型同士の / は小数点以下を切り捨てる整数除算になり、上の例の quotient は 2 になります(2.5 にはなりません)。小数を含む結果が欲しい場合は、少なくとも一方を浮動小数点数型にする必要があります。

なお、演算結果が整数型の表現範囲を超える「オーバーフロー」が発生した場合、デバッグビルドではその場で panic! を起こしてプログラムが停止します。一方、リリースビルド(cargo build --release)では既定でラップアラウンド(2の補数による折り返し)が発生し、パニックにはなりません。Python の整数は任意精度でありオーバーフロー自体が発生しない点と対照的です。

また、Rust では異なる数値型同士を直接演算したり代入したりすることはできず、自動的な型変換は行われません。型を変換したい場合は as キーワードを使って明示的にキャストします。

fn main() {
    let x: i32 = 5;
    let y = x as f64 / 2 as f64;
    println!("{}", y); // 2.5
}

Python 経験者向けメモ

Python では / は常に浮動小数点数の除算になり、5 / 2 は 2.5 になります(整数同士の切り捨て除算には別に // があります)。Rust では整数型同士の / がそのまま切り捨て除算になる点に注意してください。また、Python では int(x) や float(x) のように暗黙の変換に近い感覚で型を行き来できますが、Rust では as によるキャストを自分で書かない限り、異なる数値型同士の演算はコンパイルエラーになります。

複合型(タプルと配列)

複数の値をまとめる複合型として、タプルと配列があります。

タプルは異なる型の値をまとめて1つの値として扱える型です。なお、以下の例に登場する & については、後の「借用と参照」の章で詳しく説明します。

fn main() {
    let person: (&str, u32, bool) = ("Alice", 30, true);
    let (name, age, _active) = person;
    println!("{}は{}歳です", name, age);
    println!("2番目の要素: {}", person.1);
}

配列は同じ型の値を固定長で並べたものです。型は [T; N] (要素の型 T が N 個)のように表記します。

fn main() {
    let numbers: [i32; 5] = [1, 2, 3, 4, 5];
    println!("最初の要素: {}", numbers[0]);
    println!("要素数: {}", numbers.len());
}

なお、範囲外のインデックスにアクセスすると、プログラムは実行時に panic! を起こして異常終了します。ただし numbers[10] のようにインデックスがコンパイル時に定数だと分かる場合、Rust コンパイラはその時点で範囲外アクセスを検出しコンパイルエラーにします。実際に実行時パニックになるのは、let i = 10; numbers[i] のようにインデックスが実行時にしか決まらない場合です。この挙動については、後のエラーハンドリングの章で詳しく扱います。

なお、可変長のリストが必要な場合は、配列ではなく Vec<T> (可変長ベクタ)という型を使いますが、これは後の章で扱います。

静的型付けと型推論

Rust は静的型付け言語であり、すべての変数の型はコンパイル時に確定します。とはいえ、常に型を書く必要があるわけではなく、多くの場合コンパイラが代入される値から型を推論してくれます。

fn main() {
    let score = 100; // i32 と推論される
    let ratio = 0.5; // f64 と推論される
    println!("{} {}", score, ratio);
}

型推論ができない、あるいは意図を明確にしたい場合には、let x: i64 = 100; のように型注釈を付けます。

Python 経験者向けメモ

Python では x = 5 のあと自由に x = "hello" のように別の型の値を再代入でき、変数はいつでも書き換え可能です。Rust ではまず「変数は既定でイミュータブル」という点が大きく異なり、書き換えるには明示的に mut を付ける必要があります。さらに Rust は静的型付けであるため、一度型が決まった変数に別の型の値を代入することはできません。Python の動的型付けに慣れていると窮屈に感じるかもしれませんが、この制約のおかげでコンパイラが多くの型に関するバグを実行前に検出してくれます。

まとめ

  • // は行末までのコメント、/* ... */ は複数行のコメントです

  • let で宣言した変数は既定でイミュータブルであり、変更するには mut が必要です

  • +=、-=、*=、/= などの複合代入演算子を使うと、再代入の式を簡潔に書けます

  • 命名規則として、変数・関数は snake_case、型は PascalCase、定数は SCREAMING_SNAKE_CASE を使います

  • シャドーイングを使うと同名の変数を再宣言でき、型を変えることもできます

  • スカラー型には整数(i32 など)、浮動小数点数(f64)、真偽値(bool)、文字(char)があります

  • シングルクォート('R')は1文字の char、ダブルクォート("hello")は文字列を表し、明確に区別されます

  • 算術演算子は + - * / % の5種類で、整数型同士の / は切り捨て除算になります(Python の / は常に浮動小数点数の除算です)

  • 異なる数値型同士は自動変換されないため、as キーワードで明示的にキャストする必要があります

  • println! の {} は引数の値に置き換わるプレースホルダーで、複数ある場合は登場順に対応します

  • 複合型にはタプルと固定長配列([T; N])があります

  • 配列の範囲外アクセスは実行時に panic! を引き起こします

  • Rust は静的型付け言語ですが、多くの場面で型推論が働くため型注釈を省略できます
