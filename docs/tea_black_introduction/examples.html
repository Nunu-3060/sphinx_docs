便利なスクリプト

本付録では、紅茶を淹れるときに役立つ 2 つの Python スクリプトを紹介します。どちらも Python の標準機能だけで動くため、追加のインストールは不要です。

動かすための準備

スクリプトを動かすには、Python 3.10 以上が必要です。Python は、Python の公式サイトからダウンロードしてインストールできます。

スクリプトは、次の手順で実行します。

  1. 本ページのリンクからスクリプトをダウンロードします。

  2. Windows では「コマンドプロンプト」、macOS では「ターミナル」を開きます。

  3. cd コマンドで、スクリプトを保存したフォルダーに移動します。

  4. python コマンドの後にスクリプトのファイル名を付けて実行します。

例えば、ダウンロードフォルダーに保存した場合は、次のように入力します。macOS では python の代わりに python3 と入力してください。

1cd Downloads
2python tea_calculator.py

茶葉の量の計算（tea_calculator.py）

杯数と茶葉の種類を指定すると、茶葉の量、お湯の量、蒸らし時間の目安を表示します。計算には、「おいしい淹れ方」で紹介した式と目安を使っています。

ダウンロード：tea_calculator.py

使い方

引数を付けずに実行すると、杯数と茶葉の種類を順に尋ねられます。

1python tea_calculator.py

杯数と茶葉の種類を続けて指定すると、すぐに結果が表示されます。茶葉の種類には、次のいずれかを指定します。

  • op：OP などの大きな茶葉

  • bop：BOP などの細かい茶葉

  • ctc：BOPF や CTC などの特に細かい茶葉

例えば、BOP の茶葉で 3 杯分を淹れる場合は、次のように実行します。

1python tea_calculator.py 3 bop

実行すると、次のように表示されます。

13 杯分（BOP などの細かい茶葉）の目安
2  茶葉の量    : 9.0 g（ティースプーン約 3 杯）
3  お湯の量    : 450 ml
4  蒸らし時間  : 2.5〜3 分

ソースコード

  1"""紅茶の茶葉の量とお湯の量を計算するスクリプト。
  2
  3杯数と茶葉の種類を指定すると、ポットに入れる茶葉の量と、
  4注ぐお湯の量の目安を表示します。
  5
  6使い方:
  7    python tea_calculator.py          対話形式で入力する
  8    python tea_calculator.py 3 bop    3 杯分、BOP などの細かい茶葉
  9"""
 10
 11from __future__ import annotations
 12
 13import argparse
 14import sys
 15from dataclasses import dataclass
 16
 17# 1 杯あたりのお湯の量（ml）
 18WATER_PER_CUP_ML: int = 150
 19
 20# 一度に計算できる杯数の上限
 21MAX_CUPS: int = 20
 22
 23
 24@dataclass(frozen=True)
 25class LeafType:
 26    """茶葉の種類ごとの目安。"""
 27
 28    key: str  # コマンドラインで指定する名前
 29    name: str  # 画面に表示する名前
 30    grams_per_cup: float  # 1 杯あたりの茶葉の量（g）
 31    steep_time: str  # 蒸らし時間の目安
 32
 33
 34LEAF_TYPES: tuple[LeafType, ...] = (
 35    LeafType("op", "OP などの大きな茶葉", 3.0, "3〜4 分"),
 36    LeafType("bop", "BOP などの細かい茶葉", 3.0, "2.5〜3 分"),
 37    LeafType("ctc", "BOPF や CTC などの特に細かい茶葉", 2.5, "1.5〜2 分"),
 38)
 39
 40
 41def find_leaf_type(key: str) -> LeafType:
 42    """名前（op、bop、ctc）から茶葉の種類を探す。"""
 43    for leaf in LEAF_TYPES:
 44        if leaf.key == key:
 45            return leaf
 46    raise ValueError(f"不明な茶葉の種類です: {key}")
 47
 48
 49def ask_cups() -> int:
 50    """杯数を対話形式で入力してもらう。"""
 51    while True:
 52        text = input(f"何杯分淹れますか（1〜{MAX_CUPS}）: ")
 53        if text.isdecimal() and 1 <= int(text) <= MAX_CUPS:
 54            return int(text)
 55        print(f"1 から {MAX_CUPS} までの数字を入力してください。")
 56
 57
 58def ask_leaf_type() -> LeafType:
 59    """茶葉の種類を対話形式で選んでもらう。"""
 60    for number, leaf in enumerate(LEAF_TYPES, start=1):
 61        print(f"  {number}: {leaf.name}")
 62    while True:
 63        text = input("茶葉の種類を番号で選んでください: ")
 64        if text.isdecimal() and 1 <= int(text) <= len(LEAF_TYPES):
 65            return LEAF_TYPES[int(text) - 1]
 66        print("表示されている番号を入力してください。")
 67
 68
 69def calculate(cups: int, leaf: LeafType) -> tuple[float, int]:
 70    """茶葉の量（g）とお湯の量（ml）を計算する。"""
 71    leaf_grams = cups * leaf.grams_per_cup
 72    water_ml = cups * WATER_PER_CUP_ML
 73    return leaf_grams, water_ml
 74
 75
 76def parse_args() -> argparse.Namespace:
 77    """コマンドライン引数を解析する。"""
 78    parser = argparse.ArgumentParser(
 79        description="紅茶の茶葉の量とお湯の量を計算します。"
 80    )
 81    parser.add_argument(
 82        "cups", nargs="?", type=int, help=f"杯数（1〜{MAX_CUPS}）"
 83    )
 84    parser.add_argument(
 85        "leaf",
 86        nargs="?",
 87        choices=[leaf.key for leaf in LEAF_TYPES],
 88        help="茶葉の種類（op、bop、ctc）",
 89    )
 90    return parser.parse_args()
 91
 92
 93def main() -> int:
 94    """スクリプトの入口。"""
 95    args = parse_args()
 96
 97    cups: int | None = args.cups
 98    if cups is None:
 99        cups = ask_cups()
100    elif not 1 <= cups <= MAX_CUPS:
101        print(f"杯数は 1 から {MAX_CUPS} までで指定してください。")
102        return 1
103
104    leaf = ask_leaf_type() if args.leaf is None else find_leaf_type(args.leaf)
105
106    leaf_grams, water_ml = calculate(cups, leaf)
107    print()
108    print(f"{cups} 杯分（{leaf.name}）の目安")
109    print(f"  茶葉の量    : {leaf_grams:.1f} g（ティースプーン約 {cups} 杯）")
110    print(f"  お湯の量    : {water_ml} ml")
111    print(f"  蒸らし時間  : {leaf.steep_time}")
112    return 0
113
114
115if __name__ == "__main__":
116    sys.exit(main())

蒸らし時間のタイマー（tea_timer.py）

茶葉の種類を選ぶと、その茶葉に合った蒸らし時間をカウントダウンし、時間になったら音とメッセージで知らせます。タイマーで計る時間は、「おいしい淹れ方」で紹介した蒸らし時間の目安の中間の値です。

ダウンロード：tea_timer.py

使い方

茶葉の種類には、次のいずれかを指定します。指定しない場合は、実行後に番号で選びます。

  • op：OP などの大きな茶葉（3 分 30 秒）

  • bop：BOP などの細かい茶葉（2 分 45 秒）

  • ctc：BOPF や CTC などの特に細かい茶葉（1 分 45 秒）

  • bag：ティーバッグ（1 分 45 秒）

例えば、BOP の茶葉の蒸らし時間を計る場合は、次のように実行します。

1python tea_timer.py bop

好みの時間で計りたい場合は、--seconds の後に秒数を指定します。次の例では、200 秒（3 分 20 秒）を計ります。

1python tea_timer.py --seconds 200

実行すると、残り時間が 1 秒ごとに更新され、時間になると次のように表示されます。途中でやめたい場合は、Ctrl+C を押します。

1BOP などの細かい茶葉: 目安は 2.5〜3 分です。
22 分 45 秒を計ります。Ctrl+C で中止できます。
3残り 0 分 00 秒
4蒸らし終わりました。茶こしでこしながら注ぎましょう。

ソースコード

  1"""紅茶の蒸らし時間を計るタイマー。
  2
  3茶葉の種類を選ぶと、その茶葉に合った蒸らし時間をカウントダウンし、
  4時間になったら音とメッセージで知らせます。
  5
  6使い方:
  7    python tea_timer.py                 対話形式で茶葉の種類を選ぶ
  8    python tea_timer.py op              OP などの大きな茶葉
  9    python tea_timer.py --seconds 200   好きな秒数を指定する
 10"""
 11
 12from __future__ import annotations
 13
 14import argparse
 15import sys
 16import time
 17from dataclasses import dataclass
 18
 19
 20@dataclass(frozen=True)
 21class LeafType:
 22    """茶葉の種類ごとの蒸らし時間。"""
 23
 24    key: str  # コマンドラインで指定する名前
 25    name: str  # 画面に表示する名前
 26    seconds: int  # タイマーで計る秒数（目安の範囲の中間）
 27    steep_time: str  # 蒸らし時間の目安
 28
 29
 30LEAF_TYPES: tuple[LeafType, ...] = (
 31    LeafType("op", "OP などの大きな茶葉", 210, "3〜4 分"),
 32    LeafType("bop", "BOP などの細かい茶葉", 165, "2.5〜3 分"),
 33    LeafType("ctc", "BOPF や CTC などの特に細かい茶葉", 105, "1.5〜2 分"),
 34    LeafType("bag", "ティーバッグ", 105, "1.5〜2 分"),
 35)
 36
 37
 38def find_leaf_type(key: str) -> LeafType:
 39    """名前（op、bop、ctc、bag）から茶葉の種類を探す。"""
 40    for leaf in LEAF_TYPES:
 41        if leaf.key == key:
 42            return leaf
 43    raise ValueError(f"不明な茶葉の種類です: {key}")
 44
 45
 46def ask_leaf_type() -> LeafType:
 47    """茶葉の種類を対話形式で選んでもらう。"""
 48    for number, leaf in enumerate(LEAF_TYPES, start=1):
 49        print(f"  {number}: {leaf.name}（{leaf.steep_time}）")
 50    while True:
 51        text = input("茶葉の種類を番号で選んでください: ")
 52        if text.isdecimal() and 1 <= int(text) <= len(LEAF_TYPES):
 53            return LEAF_TYPES[int(text) - 1]
 54        print("表示されている番号を入力してください。")
 55
 56
 57def format_time(seconds: int) -> str:
 58    """秒数を「○ 分 ○○ 秒」の形式の文字列にする。"""
 59    minutes, rest = divmod(seconds, 60)
 60    return f"{minutes} 分 {rest:02d} 秒"
 61
 62
 63def count_down(seconds: int) -> None:
 64    """指定した秒数をカウントダウンし、残り時間を表示する。"""
 65    for remaining in range(seconds, 0, -1):
 66        print(f"\r残り {format_time(remaining)} ", end="", flush=True)
 67        time.sleep(1)
 68    print(f"\r残り {format_time(0)} ")
 69
 70
 71def parse_args() -> argparse.Namespace:
 72    """コマンドライン引数を解析する。"""
 73    parser = argparse.ArgumentParser(
 74        description="紅茶の蒸らし時間を計るタイマーです。"
 75    )
 76    parser.add_argument(
 77        "leaf",
 78        nargs="?",
 79        choices=[leaf.key for leaf in LEAF_TYPES],
 80        help="茶葉の種類（op、bop、ctc、bag）",
 81    )
 82    parser.add_argument(
 83        "--seconds", type=int, help="茶葉の種類の代わりに秒数を指定する"
 84    )
 85    return parser.parse_args()
 86
 87
 88def main() -> int:
 89    """スクリプトの入口。"""
 90    args = parse_args()
 91
 92    seconds: int | None = args.seconds
 93    if seconds is not None:
 94        if seconds <= 0:
 95            print("秒数には 1 以上の数を指定してください。")
 96            return 1
 97    else:
 98        if args.leaf is None:
 99            leaf = ask_leaf_type()
100        else:
101            leaf = find_leaf_type(args.leaf)
102        seconds = leaf.seconds
103        print(f"{leaf.name}: 目安は {leaf.steep_time}です。")
104
105    print(f"{format_time(seconds)}を計ります。Ctrl+C で中止できます。")
106    try:
107        count_down(seconds)
108    except KeyboardInterrupt:
109        print("\nタイマーを中止しました。")
110        return 1
111
112    # "\a" はベル文字で、対応している環境では音が鳴ります
113    print("\a蒸らし終わりました。茶こしでこしながら注ぎましょう。")
114    return 0
115
116
117if __name__ == "__main__":
118    sys.exit(main())
