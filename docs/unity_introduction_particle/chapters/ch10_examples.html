第 10 章 作例

この章では、これまでに学んだモジュールを組み合わせて、焚き火、雨、爆発、ヒットエフェクトの 4 つのエフェクトを作る。各作例の設定値は一例である。値を変えて、見た目がどう変わるかを試してほしい。

表に書いていない設定項目は、既定の値のままでよい。数値が 2 つ書いてある設定項目は、Random Between Two Constants にして、2 つの値の間のランダムな値にする（第 4 章を参照）。色は、R、G、B、A の各成分を 0～255 の値で示す。

この章のサンプルコードは、examples/chapter10 フォルダーにある。

作例では、次の 2 つのマテリアルを使う。第 7 章の手順で作成する。

独自のテクスチャーを用意できる場合は、炎や煙の形をしたテクスチャーを使うと、より本物らしくなる。

焚き火

焚き火は、炎、煙、火の粉の 3 つの Particle System を組み合わせて作る。炎を親にし、煙と火の粉を子にする。

  1. GameObject ‣ Effects ‣ Particle System で Particle System を作り、名前を「Campfire」にする。これが炎になる。Transform の Rotation の X は -90 のままにする。

  2. Campfire を右クリックし、Effects ‣ Particle System を選んで子の Particle System を 2 つ作る。名前を「Smoke」と「Sparks」にする。

  3. 子の Transform の Position と Rotation は、すべて 0 にする。親の回転を引き継ぐため、子もパーティクルを上に向かって放出する。

第 5 章の式 \(N \approx r \times L\) で、同時に存在するパーティクルの数を見積もってみる。寿命の平均を使うと、炎は \(30 \times 0.8 = 24\)、煙は \(5 \times 3.5 \approx 18\)、火の粉は \(8 \times 1.5 = 12\) で、合計でおよそ 54 個である。数十個のパーティクルでも、組み合わせ方しだいで十分に焚き火らしく見える。

雨

雨は、空の広い範囲から雨粒を降らせ、地面に当たった位置でサブエミッターから水しぶきを出して作る。

  1. 地面にする Plane を配置し、Scale を X 3、Y 1、Z 3 にする。

  2. Particle System を作り、名前を「Rain」にする。Transform の Position を X 0、Y 10、Z 0 に、Rotation を X 90、Y 0、Z 0 にする。ローカル座標の Z 軸が下向きになり、パーティクルが下に向かって放出される。

  3. Rain の Sub Emitters モジュールを有効にし、リストの + ボタンを押す。子の Particle System が作られるので、名前を「Splash」にする。

爆発

爆発は、閃光、火の玉、煙、破片の 4 つの Particle System を組み合わせて作る。すべて Bursts で一度に放出し、Main モジュールの Looping は無効にする。

  1. Particle System を作り、名前を「Explosion」にする。これが閃光になる。

  2. Explosion の子として、「Fireball」「Smoke」「Debris」の 3 つの Particle System を作る。子の Transform の Position と Rotation は、すべて 0 にする。

どの Particle System も、Emission モジュールの Rate over Time を 0 にし、Bursts を 1 つ追加して Time を 0 にする。Count は各表のとおりにする。

ヒットエフェクト

ヒットエフェクトは、弾や攻撃が当たった位置に、一瞬だけ表示するエフェクトである。ここでは、火花と閃光でヒットエフェクトを作り、プレハブにしてスクリプトから生成する。

エフェクトの作成

  1. Particle System を作り、名前を「HitEffect」にする。Transform の Rotation をすべて 0 にする。ローカル座標の Z 軸の正の向きにパーティクルが放出されるようになる。これが火花になる。

  2. HitEffect の子として Particle System を作り、名前を「Flash」にする。Transform の Position と Rotation は、すべて 0 にする。

スクリプトからの生成

次のサンプルは、クリックしたオブジェクトの表面に、ヒットエフェクトのプレハブを生成する。

HitEffectSpawner.cs
 1using UnityEngine;
 2using UnityEngine.InputSystem;
 3
 4/// <summary>
 5/// クリックしたオブジェクトの表面に、ヒットエフェクトのプレハブを生成するサンプル。
 6/// シーン内の空の GameObject にアタッチして使う。
 7/// </summary>
 8/// <remarks>
 9/// ヒットエフェクトのプレハブは、次のように設定しておく。
10/// ・Main モジュールの Looping を無効にし、Stop Action を Destroy にする（再生が終わったら自動で削除するため）。
11/// ・パーティクルがローカル座標の Z 軸の正の向きに飛ぶようにする（面の法線の向きに飛ばすため）。
12/// クリックの対象にするオブジェクトには、コライダーが必要である。
13/// </remarks>
14public class HitEffectSpawner : MonoBehaviour
15{
16    [SerializeField, Tooltip("生成するヒットエフェクトのプレハブ")]
17    private ParticleSystem _hitEffectPrefab;
18
19    [SerializeField, Tooltip("レイの最大距離")]
20    private float _maxDistance = 100f;
21
22    private Camera _camera;
23
24    private void Awake()
25    {
26        _camera = Camera.main;
27    }
28
29    private void Update()
30    {
31        Mouse mouse = Mouse.current;
32        if (mouse == null || !mouse.leftButton.wasPressedThisFrame)
33        {
34            return;
35        }
36
37        // カメラからマウスの位置に向かうレイを飛ばし、当たったコライダーを調べる。
38        Ray ray = _camera.ScreenPointToRay(mouse.position.ReadValue());
39        if (Physics.Raycast(ray, out RaycastHit hit, _maxDistance))
40        {
41            // エフェクトの Z 軸が、当たった面の法線の向きになるように回転させる。
42            Quaternion rotation = Quaternion.LookRotation(hit.normal);
43            Instantiate(_hitEffectPrefab, hit.point, rotation);
44        }
45    }
46}

HitEffectSpawner.cs をダウンロード

使う手順は次のとおりである。

  1. シーンに Cube や Plane など、コライダーを持つオブジェクトを配置する。

  2. 空の GameObject を作り、スクリプトをアタッチする。

  3. Hit Effect Prefab に、HitEffect のプレハブを設定する。

再生モードでオブジェクトをクリックすると、クリックした面から火花が飛び散る。Quaternion.LookRotation メソッドは、Z 軸が引数の向きになる回転を作る。当たった面の法線を渡すことで、HitEffect の Z 軸、つまり火花の放出の向きが面の外側を向く。

生成したエフェクトは、Stop Action の Destroy によって、再生が終わると自動で削除される。スクリプトで Destroy を呼ぶ必要はない。ただし、エフェクトを頻繁に生成と削除すると、処理が重くなることがある。この問題と対策は第 11 章で説明する。
