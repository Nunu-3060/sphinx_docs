第 5 章 放出と形状

この章では、パーティクルをどれだけの頻度で放出するかを決める Emission モジュールと、どこからどの向きに放出するかを決める Shape モジュールを説明する。

Emission モジュール

Emission モジュールは、パーティクルを放出する頻度を決める。

設定項目

内容

Rate over Time

1 秒あたりに放出するパーティクルの数。

Rate over Distance

Particle System が 1 m 移動するごとに放出するパーティクルの数。止まっている間は放出しない。

Bursts

決まった時刻に、まとめて放出するパーティクルの設定。

Rate over Distance は、移動する物体の軌跡に沿ってパーティクルを並べたいときに使う。たとえば、走るキャラクターの足元の土煙や、飛んでいく弾の後ろに残る煙である。放出したパーティクルを軌跡に残すため、Main モジュールの Simulation Space を World にしておく（第 4 章を参照）。

同時に存在するパーティクルの数

Rate over Time を \(r\)、Main モジュールの Start Lifetime を \(L\) 秒とする。放出を始めてから \(L\) 秒が経つと、放出される数と寿命で消える数がつり合い、同時に存在するパーティクルの数 \(N\) はほぼ一定になる。

\[N \approx r \times L\]

たとえば、既定の設定（\(r = 10\)、\(L = 5\)）では、約 50 個のパーティクルが同時に存在する。ただし、\(N\) は Main モジュールの Max Particles を超えない。\(r \times L\) が Max Particles を超えると、上限に達した時点で放出が止まり、設定したとおりの頻度で放出されなくなる。

同時に存在するパーティクルの数は、処理の重さに直接影響する（第 11 章を参照）。見た目を変えずに数を減らしたい場合は、寿命を短くするか、1 つ 1 つのパーティクルを大きくして放出する頻度を下げる。

Bursts

Bursts は、決まった時刻にまとめてパーティクルを放出する設定である。爆発や、打撃が当たった瞬間の火花のように、一瞬で大量のパーティクルを出すエフェクトに使う。リストの + ボタンで追加する。

設定項目

内容

Time

放出する時刻。周期の始まりからの経過時間（秒）で指定する。

Count

1 回に放出する数。

Cycles

放出する回数。

Interval

Cycles が 2 以上のときの、放出の間隔（秒）。

Probability

0～1 の値で、放出する確率を指定する。1 のとき必ず放出する。

1 つの Burst で放出する数の合計は、Count と Cycles の積である。たとえば、Count が 20、Cycles が 3、Interval が 0.1 のとき、0.1 秒おきに 20 個ずつ、合計 60 個を放出する。

1 回で終わる爆発のエフェクトは、Rate over Time を 0 にし、Time が 0 の Burst を 1 つだけ設定して作る。Main モジュールの Looping は無効にしておく。

Shape モジュール

Shape モジュールは、パーティクルを放出する範囲の形と、放出する向きを決める。放出の向きは、Main モジュールの Start Speed の速度の向きになる。

Shape モジュールを選択している間は、Scene ビューに放出する範囲の形が表示される。形の表示についているハンドルをドラッグすると、大きさを変えられる。

Shape で選べる主な形を次の表にまとめる。

形

放出の位置と向き

使いどころ

Cone

円の範囲から、円錐状に広がる向きに放出する。

炎、噴水、煙突の煙

Sphere

球の範囲から、中心から外に向かう向きに放出する。

爆発、光の粒の広がり

Hemisphere

半球の範囲から、中心から外に向かう向きに放出する。

地面での爆発、着地の衝撃

Box

直方体の範囲から、Z 軸の正の向きに放出する。

雨、雪、空間に漂うちり

Circle

円の範囲から、中心から外に向かう向きに放出する。放出の向きは円の平面の中に限られる。

地面に広がる衝撃波

Edge

線分の上から、Y 軸の正の向きに放出する。

滝、横一列に並んだ炎

Donut

ドーナツ状の範囲から放出する。

輪の形の光、魔法陣

Mesh、Mesh Renderer、Skinned Mesh Renderer

メッシュの頂点、辺、面から放出する。

キャラクターの体から立ち上るオーラ

形ごとの設定項目

形によって設定項目が異なる。よく使う設定項目を次の表にまとめる。

設定項目

内容

Angle

Cone の広がりの角度（度）。0 にすると、平行に放出する。

Radius

Cone、Sphere、Circle などの半径（m）。

Radius Thickness

0～1 の値で、放出する範囲の厚みを指定する。0 のときは表面だけから、1 のときは内部全体から放出する。

Arc

円周のうち、放出に使う範囲の角度（度）。360 で円周全体になる。

Emit from

Cone や Box で、底面、内部、表面、辺のどこから放出するかを選ぶ。

形の位置と向きの調整

どの形でも、次の設定項目で位置、向き、放出の向きを調整できる。

設定項目

内容

Position、Rotation、Scale

Particle System の GameObject に対する、形の位置、回転、拡大率。GameObject を動かさずに、放出する範囲だけを調整できる。

Align To Direction

有効にすると、パーティクルの向きを放出の向きに合わせる。

Randomize Direction

0～1 の値で、放出の向きをランダムな向きに近づける割合を指定する。

Spherize Direction

0～1 の値で、放出の向きを、形の中心から外に向かう向きに近づける割合を指定する。

Randomize Position

放出する位置を、指定した距離までランダムにずらす。

Shape モジュールを無効にすると、すべてのパーティクルが GameObject の位置から、Z 軸の正の向きに放出される。
