第 2 章 パーティクルの基礎

この章では、パーティクルエフェクトのしくみと、Unity でパーティクルを扱う 2 つの機能である Particle System と VFX Graph の違いを説明する。

パーティクルのしくみ

パーティクルエフェクトは、次の 3 つの要素でできている。

要素

役割

エミッター

パーティクルを放出する発生源。どこから、どれだけの頻度で、どの向きに放出するかを決める。

パーティクル

放出される 1 つ 1 つの粒。位置、速度、大きさ、色、回転、寿命などの値を持つ。

レンダラー

パーティクルを画面に描画するしくみ。パーティクルを板ポリゴンとして描くか、メッシュとして描くかなどを決める。

パーティクルは、次の流れで一生を終える。

  1. エミッターが、パーティクルを放出する。このとき、パーティクルの初期値（位置、速度、大きさ、色、寿命など）が決まる。

  2. 毎フレーム、パーティクルの位置を速度に従って動かし、大きさや色を経過時間に応じて変える。

  3. 放出からの経過時間が寿命に達すると、パーティクルは消える。

1 つ 1 つのパーティクルは単純な動きしかしない。しかし、少しずつ異なる初期値のパーティクルを大量に放出すると、全体として炎や煙のような複雑な形に見える。初期値をランダムにばらつかせることが、自然な見た目を作るこつである。

ビルボード

パーティクルの多くは、常にカメラの方を向く四角形の板ポリゴンとして描画する。この描画方法をビルボードという。板ポリゴンには、煙や火花などの形をしたテクスチャーを貼る。

ビルボードは、どの方向から見ても同じ形に見える。そのため、煙のように立体的な形が決まっていないものを、少ない計算量で表現できる。

Particle System と VFX Graph

Unity には、パーティクルを扱う機能として Particle System と VFX Graph の 2 つがある。

Particle System

GameObject にコンポーネントとして追加して使う。Inspector ウィンドウでモジュールと呼ばれる設定のまとまりを有効にし、値を設定してエフェクトを作る。パーティクルの計算は主に CPU で行う。Unity の標準の機能で、パッケージを追加しなくても使える。

VFX Graph

ノードをつないだグラフでエフェクトを作る。パーティクルの計算を GPU で行うため、数十万～数百万のパーティクルを扱える。Visual Effect Graph パッケージを追加して使う。

2 つの機能の違いを次の表にまとめる。

項目

Particle System

VFX Graph

編集方法

表の「扱えるパーティクルの数の目安」は、動作する環境やエフェクトの内容によって大きく変わる。あくまで両者の違いの大きさを表す目安である。

使い分けの考え方

どちらを使うか迷ったら、次のように考えるとよい。

  • パーティクルの数が数千程度までで、物理演算との連携やスクリプトからの細かい制御が必要なら、Particle System を使う。

  • 大量のパーティクルを使う派手なエフェクトや、GPU の性能を生かした表現を作りたいなら、VFX Graph を使う。

  • コンピュートシェーダーに対応しない環境（一部のスマートフォンなど）も対象にするなら、Particle System を使う。

本資料では、まず第 2 部と第 3 部で Particle System を学ぶ。Particle System で学ぶ放出、寿命、時間による変化などの考え方は、VFX Graph でもそのまま使える。VFX Graph は第 4 部で学ぶ。
