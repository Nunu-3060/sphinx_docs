2. 計算機とは何か

この章では、「計算」と「計算機」という言葉の意味を定め、本書で扱う計算機の範囲をはっきりさせます。

2.1. 「計算」とは何か

日常生活で「計算」というと、足し算や掛け算のような数の演算を思い浮かべるでしょう。しかし計算機科学では、計算をもっと広い意味で捉えます。

本書では、計算を「入力を、決められた規則に従って、出力に変換する手続き」と定義します。

この定義のポイントは次の 3 点です。

  • 入力と出力は数に限りません。文字列、画像、音声など、記号で表せるものなら何でも構いません。

  • 規則は、あらかじめ明確に決まっていなければなりません。手続きを実行する者が、その場の判断やひらめきを必要としないことが重要です。

  • 手続きは有限の手順で構成されていなければなりません。

例えば、次のような処理はどれも計算です。

どの処理も、入力を記号の並びとして表し、規則に従って別の記号の並びに変換しています。このように、規則に従って記号を操作することが計算の本質です。

このような「明確な規則に従う有限の手続き」は、一般にアルゴリズムと呼ばれます。アルゴリズムという概念を数学的に厳密に定義する方法は「計算の理論」で説明します。

2.2. 計算機の定義

計算をアルゴリズムに従って実行するのは、人間でも構いません。実際、「計算機（computer）」という英語は、もともと計算を職業とする人を指す言葉でした。20 世紀の前半までは、天文学や弾道計算のために多くの人が雇われ、手作業で計算をしていました。

本書では、計算機を「計算を自動的に実行する機械」と定義します。人間が一つ一つの手順を指示しなくても、与えられた入力から出力を自動で求める点が、そろばんのような計算道具との違いです。

2.3. アナログ計算機とデジタル計算機

計算機は、量の表し方によって 2 種類に分けられます。

アナログ計算機

数を、長さ、角度、電圧などの連続的に変化する物理量で表す計算機です。例えば計算尺は、対数目盛りの長さを足し合わせることで掛け算を行います。20 世紀前半には、歯車や電子回路で微分方程式を解く大規模なアナログ計算機も作られました。

デジタル計算機

数を、離散的な（とびとびの）記号の並びで表す計算機です。現代の計算機は、電圧が高いか低いかの 2 つの状態を 0 と 1 に対応させて、すべての情報を表します。

アナログ計算機は、物理現象をそのまま使うので特定の問題を高速に解けることがあります。しかし、物理量には必ず誤差や雑音が含まれるため、計算を重ねるほど誤差が蓄積し、精度を高めることも困難です。

一方、デジタル計算機では、信号が多少乱れても、ある閾値より高いか低いかさえ判定できれば元の 0 か 1 を正しく復元できます。そのため、何億回もの演算を重ねても誤差が蓄積しません。必要な精度は、ビット数を増やすことで好きなだけ高められます。この性質が、デジタル計算機が主流になった大きな理由です。

2.4. 専用計算機と汎用計算機

計算機は、実行できる計算の種類によっても分けられます。

専用計算機

特定の計算だけを実行するように作られた計算機です。電卓や、初期の暗号解読機などがこれに当たります。別の計算をさせるには、機械そのものを作り直す必要があります。

汎用計算機

プログラムを差し替えることで、さまざまな計算を実行できる計算機です。

プログラムとは、計算の手順を計算機が解釈できる形で書き表したものです。汎用計算機では、ハードウェア（機械）を変更せずに、ソフトウェア（プログラム）を変更するだけで、表計算にも、ゲームにも、Web サーバにもなります。

汎用計算機は、どこまでの計算を実行できるのでしょうか。驚くべきことに、ある最低限の機能を備えた汎用計算機は、どれも原理的には同じ範囲の計算を実行できることが分かっています。この性質を計算の汎用性と呼びます。詳しくは「計算の理論」で説明します。

2.5. プログラム内蔵方式

初期の汎用計算機では、プログラムを配線の繋ぎ替えやスイッチの設定で与えていました。計算の内容を変えるたびに、何日もかけて配線をやり直す必要がありました。

この問題を解決したのがプログラム内蔵方式（stored-program）です。プログラム内蔵方式では、プログラムをデータと同じように記憶装置に格納し、計算機がそれを順に読み出して実行します。プログラムもデータと同じ 0 と 1 の並びなので、記憶装置の内容を書き換えるだけでプログラムを変更できます。さらに、プログラムを読み込んで別のプログラムを生成するプログラム（コンパイラなど）も作れるようになりました。

プログラム内蔵方式は 1940 年代に考案され、今日のほぼすべての計算機がこの方式に基づいています。その経緯は「計算機の歴史」で、具体的な構成は「計算機の構成」で説明します。

2.6. 本書で扱う範囲

以上を踏まえ、本書では「プログラム内蔵方式のデジタル汎用計算機」を主な対象とします。単に「計算機」と書いた場合は、この種類の計算機を指します。パソコン、スマートフォン、サーバ、家電や自動車に組み込まれた制御用の計算機は、規模や用途は大きく異なりますが、どれもこの種類に属します。

ただし、「計算機の歴史」ではそれ以前の計算道具や計算機も紹介し、「現代の計算機」では量子計算機のような新しい原理の計算機にも触れます。
