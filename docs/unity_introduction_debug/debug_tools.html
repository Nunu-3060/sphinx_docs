3. デバッグ用ツールと機能

ログ出力は手軽ですが、確認したい値が増えるたびにコードを書き換えて再コンパイルする必要があります。本章では、コードを書き換えずにプログラムの状態を調べられるツールと、目に見えない情報を画面に表示する手法を紹介します。

3.1. IDE のデバッガーによるステップ実行

コードエディター（IDE）のデバッガーを使うと、実行中のプログラムを任意の行で一時停止し、その時点の変数の値を調べたり、1 行ずつ実行したりできます。

3.1.1. 準備

  1. Unity のメニューの Edit ‣ Preferences ‣ External Tools を開き、External Script Editor で使用する IDE を選択します。

  2. IDE に Unity 用の拡張機能を導入します。Visual Studio では Visual Studio Installer で「Unity によるゲーム開発」ワークロードを、Visual Studio Code では Unity 拡張機能をインストールします。JetBrains Rider は、Unity のサポートが標準で組み込まれています。

  3. Unity エディターのウィンドウ右下にある虫のアイコンをクリックし、コードの最適化モードを Debug Mode に切り替えます。Release Mode のままではデバッガーを接続できません。

3.1.2. デバッガーの接続と基本操作

IDE でデバッグを開始して Unity エディターに接続（アタッチ）し、Unity エディターで再生を開始します。Visual Studio では、ツールバーの Unity にアタッチ ボタンでデバッグを開始できます。

デバッガーの主な機能は次のとおりです。キーボードショートカットは Visual Studio の既定の設定です。

3.1.3. 条件付きブレークポイント

毎フレーム実行される Update にブレークポイントを設定すると、毎回停止してしまい調査になりません。このような場合は、ブレークポイントに条件を設定します。たとえば hitPoint <= 0 という条件を設定すると、HP が 0 以下になったときだけ停止します。Visual Studio では、ブレークポイントを右クリックして 条件 を選ぶと設定できます。

注釈

ブレークポイントで停止している間は、Unity エディター全体が応答しなくなります。調査が終わったら、続行するかデバッグを停止してください。

3.2. Inspector ウィンドウのデバッグモード

Inspector ウィンドウは、通常はシリアライズされたフィールド（public のフィールドや [SerializeField] 属性が付いたフィールド）だけを表示します。Inspector ウィンドウのタブの右にある ⋮ メニューから Debug を選ぶとデバッグモードに切り替わり、private のフィールドも表示されます。

デバッグモードを使うと、デバッガーを接続しなくても、再生中の private のフィールドの値を確認できます。表示を元に戻すには、同じメニューから Normal を選びます。

3.3. Gizmos と Debug.DrawLine による可視化

当たり判定の範囲や Ray の向きなど、ゲーム画面には表示されない情報が原因の不具合は、数値を見るだけでは原因をつかみにくいものです。このような情報は、線や図形として Scene ビューに表示すると理解しやすくなります。

手段

特徴

Debug.DrawLine、Debug.DrawRay

Update などから呼び出し、線を描画します。既定では 1 フレームだけ表示され、引数で表示時間を指定することもできます。

Gizmos クラス

OnDrawGizmos または OnDrawGizmosSelected の中で使い、線、球、立方体などを描画します。再生していないときも表示されるため、設定値の確認にも使えます。

どちらの方法で描画した図形も Scene ビューに表示されます。Game ビューでも、ツールバーの Gizmos ボタンを有効にすると表示されます。

GizmosExample.cs
using UnityEngine;

/// <summary>
/// Debug.DrawRay と Gizmos を使って、目に見えない情報を Scene ビューに表示するサンプルです。
/// </summary>
public class GizmosExample : MonoBehaviour
{
    [SerializeField]
    private float searchRadius = 5f;

    [SerializeField]
    private float rayLength = 10f;

    private void Update()
    {
        // 前方に Ray を飛ばし、何かに当たったかどうかで線の色を変えます。
        Vector3 origin = transform.position;
        Vector3 direction = transform.forward;
        bool isHit = Physics.Raycast(origin, direction, out RaycastHit hit, rayLength);

        Color color = isHit ? Color.red : Color.green;
        float length = isHit ? hit.distance : rayLength;

        // Debug.DrawRay で描いた線は 1 フレームだけ表示されます。
        // Scene ビューに表示され、Game ビューでも Gizmos ボタンを有効にすると表示されます。
        Debug.DrawRay(origin, direction * length, color);
    }

    /// <summary>
    /// 常に呼び出されるギズモの描画処理です。再生していないときも呼び出されます。
    /// </summary>
    private void OnDrawGizmos()
    {
        // 索敵範囲を黄色いワイヤーフレームの球で表示します。
        Gizmos.color = Color.yellow;
        Gizmos.DrawWireSphere(transform.position, searchRadius);
    }

    /// <summary>
    /// この GameObject を選択しているときだけ呼び出されるギズモの描画処理です。
    /// </summary>
    private void OnDrawGizmosSelected()
    {
        // Ray の最大距離を水色の線で表示します。
        Gizmos.color = Color.cyan;
        Gizmos.DrawLine(transform.position, transform.position + transform.forward * rayLength);
    }
}

3.4. 一時停止とフレーム送り

一瞬だけ発生する不具合は、ツールバーの一時停止ボタンとフレーム送りボタンを使うと観察しやすくなります。

  • 一時停止ボタン（Ctrl+Shift+P）で再生を一時停止すると、その時点のシーンの状態を Scene ビューや Inspector ウィンドウで調べられます。

  • 一時停止中にフレーム送りボタン（Ctrl+Alt+P）を押すと、1 フレームずつ進められます。

特定の条件になった瞬間に止めたい場合は、スクリプトから Debug.Break を呼び出します。Debug.Break を呼び出すと、そのフレームの処理が終わった時点で再生が一時停止します。

if (hitPoint <= 0)
{
    // HP が 0 以下になったフレームの終わりで一時停止します。
    Debug.Break();
}

3.5. ゲーム画面へのデバッグ情報の表示

実機では Console ウィンドウや Inspector ウィンドウを見られないため、フレームレートやキャラクターの状態などをゲーム画面に直接表示すると便利です。次のサンプルは、フレームレートと 1 フレームあたりの処理時間を画面の左上に表示します。

FpsCounter.cs
using UnityEngine;

/// <summary>
/// フレームレート（fps）と 1 フレームあたりの処理時間（ms）を画面の左上に表示するサンプルです。
/// </summary>
/// <remarks>
/// 手軽に表示するため、デバッグ用の IMGUI（OnGUI）を使っています。
/// 正確な計測には Profiler を使ってください。
/// </remarks>
public class FpsCounter : MonoBehaviour
{
    [SerializeField, Tooltip("表示を更新する間隔（秒）")]
    private float updateInterval = 0.5f;

    [SerializeField]
    private int fontSize = 32;

    private int frameCount;
    private float elapsedTime;
    private string displayText = string.Empty;
    private GUIStyle style;

    private void Update()
    {
        frameCount++;

        // Time.timeScale の影響を受けないように unscaledDeltaTime を使います。
        elapsedTime += Time.unscaledDeltaTime;

        if (elapsedTime >= updateInterval)
        {
            // 一定時間の平均を求めることで、表示のちらつきを抑えます。
            float fps = frameCount / elapsedTime;
            float frameTimeMs = elapsedTime * 1000f / frameCount;

            // 文字列の生成は GC アロケーションを伴うため、表示の更新時だけ行います。
            displayText = $"{fps:F1} fps ({frameTimeMs:F2} ms)";

            frameCount = 0;
            elapsedTime = 0f;
        }
    }

    private void OnGUI()
    {
        // GUI.skin は OnGUI の中でしか参照できないため、ここで初期化します。
        if (style == null)
        {
            style = new GUIStyle(GUI.skin.label) { fontSize = fontSize };
            style.normal.textColor = Color.white;
        }

        GUI.Label(new Rect(10, 10, 600, fontSize * 1.5f), displayText, style);
    }
}
