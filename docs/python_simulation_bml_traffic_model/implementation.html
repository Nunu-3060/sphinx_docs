実装の解説

モジュール構成

本プロジェクトの実装は、 6 個の Python ファイルで構成されています。モデルのロジックと GUI の実装を分離しており、 BML クラスは tkinter に依存せず単体で利用できる構成になっています。各ファイルの全文は 付録 からダウンロードできます。

モジュール構成

ファイル

役割

BML.py

BML モデル本体。格子の初期化と更新ロジックを numpy によるベクトル化演算で実装しています。

utility.py

HSV 表色系から RGB 表色系への変換関数 hsv2rgb を提供します。

BMLImage.py

BML を継承し、格子の状態を画像（ Pillow の Image ）に変換する機能を追加します。

FrameBML.py

BMLImage の画像を一定間隔で更新・表示する tkinter フレームです。

TkWidget.py

色選択・盤面サイズ選択・密度スケールなど、 GUI の部品となる tkinter フレーム群です。

BMLGUI.pyw

上記の部品を組み合わせたメインアプリケーションと、起動用の main 関数です。

これらのモジュールの依存関係は、 BML → BMLImage → FrameBML → BMLGUI という継承・利用関係になっており、 utility と TkWidget はそれぞれ BMLImage と BMLGUI から利用されます。

BML クラス（モデル本体）

BML クラスは、格子の状態を表す 2 次元 numpy 配列 lattice を保持し、初期化と 1 ステップ分の更新処理を提供します。

BML.py
 1import numpy as np
 2
 3
 4class BML:
 5    def __init__(
 6        self,
 7        width: int = 256,
 8        height: int = 256,
 9        probability: float = 0.6,
10        seed: int | None = None,
11    ) -> None:
12        self.lattice: np.typing.NDArray[np.int64] = np.zeros((height, width), dtype=np.int64)
13        rng: np.random.Generator = np.random.default_rng(seed)
14        p: np.typing.NDArray[np.float64] = rng.random(size=self.lattice.shape)
15        self.lattice[p < probability] = 1
16        self.lattice[p < probability * 0.5] = 2
17        return None
18
19    def next(self) -> None:
20        l0: np.typing.NDArray[np.int64] = np.zeros_like(self.lattice)
21        south: np.typing.NDArray[np.int64] = np.roll(self.lattice, shift=(-1, 0), axis=(0, 1))
22        north: np.typing.NDArray[np.int64] = np.roll(self.lattice, shift=(1, 0), axis=(0, 1))
23        l0[((self.lattice == 0) & (south == 1)) | ((self.lattice == 1) & (north != 0))] = 1
24        l0[self.lattice == 2] = 2
25        east: np.typing.NDArray[np.int64] = np.roll(l0, shift=(0, -1), axis=(0, 1))
26        west: np.typing.NDArray[np.int64] = np.roll(l0, shift=(0, 1), axis=(0, 1))
27        l1: np.typing.NDArray[np.int64] = np.zeros_like(self.lattice)
28        l1[((l0 == 0) & (west == 2)) | ((l0 == 2) & (east != 0))] = 2
29        l1[l0 == 1] = 1
30        self.lattice = l1
31        return None

コンストラクタでは、幅・高さ・密度 probability を受け取り、 BML 交通モデルの理論 で示した確率に従って各セルへ 0 ・ 1 ・ 2 の値を割り当てています。 next メソッドでは、 np.roll を用いて格子全体を上下・左右にずらした配列を作成し、ブールインデックス（条件を満たすセルだけを一括で書き換える手法）によってループを使わずに 1 ステップ分の更新を計算しています。前半で南北方向の車（値 1 ）を、後半で東西方向の車（値 2 ）を、それぞれ BML 交通モデルの理論 の更新規則に従って動かしており、 1 回の next 呼び出しで両方向の車が 1 回ずつ移動します。

utility モジュール（色変換）

BMLImage で車の色を指定する際に、直感的に調整しやすい HSV 表色系（色相・彩度・明度）を RGB 表色系に変換するための関数です。

utility.py
 1import numpy as np
 2
 3
 4def hsv2rgb(
 5    h: np.typing.NDArray[np.float64] | float,
 6    s: np.typing.NDArray[np.float64] | float,
 7    v: np.typing.NDArray[np.float64] | float,
 8) -> np.typing.NDArray[np.uint8]:
 9    phase_offsets: np.typing.NDArray[np.float64]
10    rgb: np.typing.NDArray[np.float64]
11    if isinstance(h, float) and isinstance(s, float) and isinstance(v, float):
12        phase_offsets = np.array([0, 2/3, 1/3], np.float64)
13        rgb = ((np.clip(np.abs(np.mod(h + phase_offsets, 1) * 6 - 3) - 1, 0, 1) - 1) * s + 1) * v
14    elif isinstance(h, np.ndarray) and isinstance(s, np.ndarray) and isinstance(v, np.ndarray):
15        if h.shape != s.shape or h.shape != v.shape:
16            raise TypeError("adjust the array lengths to be the same.")
17        elif len(h.shape) != 2:
18            raise TypeError("input 2D numpy array.")
19        phase_offsets = np.zeros((h.shape[0], h.shape[1], 3), np.float64)
20        phase_offsets[:, :, 1] = 2 / 3
21        phase_offsets[:, :, 2] = 1 / 3
22        hue: np.typing.NDArray[np.float64] = h[:, :, None]
23        saturate: np.typing.NDArray[np.float64] = s[:, :, None]
24        value: np.typing.NDArray[np.float64] = v[:, :, None]
25        rgb = ((np.clip(np.abs(np.mod(hue + phase_offsets, 1) * 6 - 3) - 1, 0, 1) - 1) * saturate + 1) * value
26    else:
27        text: str = "\n".join([
28            "h, s, and v must all be float or np.ndarray.",
29            f"h: {type(h).__name__}",
30            f"s: {type(s).__name__}",
31            f"v: {type(v).__name__}",
32        ])
33        raise TypeError(text)
34    rgb = np.clip(rgb, 0, 1)
35    return (rgb * 255).round(0).astype(np.uint8)

引数 h ・ s ・ v にはそれぞれ 1 つの float 値、または同じ形状の numpy 配列のいずれかを渡すことができ、配列を渡した場合は各要素に対応する RGB 値をまとめて計算します。

BMLImage クラス（可視化）

BMLImage クラスは BML を継承し、格子の状態を画像として描画する機能を追加します。

BMLImage.py
 1import numpy as np
 2from PIL import Image, ImageTk
 3
 4from BML import BML
 5from utility import hsv2rgb
 6
 7
 8class BMLImage(BML):
 9    def __init__(
10        self,
11        width: int = 256,
12        height: int = 256,
13        probability: float = 0.6,
14        seed: int | None = None,
15        c0: np.typing.NDArray[np.uint8] | None = None,
16        c1: np.typing.NDArray[np.uint8] | None = None,
17        c2: np.typing.NDArray[np.uint8] | None = None,
18        pixel: int = 2,
19    ) -> None:
20        super().__init__(width, height, probability, seed)
21        if c0 is None or c1 is None or c2 is None:
22            rng: np.random.Generator = np.random.default_rng()
23            h: float = rng.random()
24            s: float = 0.875
25            v: float = 0.875
26            c0 = hsv2rgb(h, s, 1-v)
27            c1 = hsv2rgb(h-0.125, s, v)
28            c2 = hsv2rgb(h+0.125, s, v)
29        self.c0: np.typing.NDArray[np.uint8] = c0
30        self.c1: np.typing.NDArray[np.uint8] = c1
31        self.c2: np.typing.NDArray[np.uint8] = c2
32        self.image_array: np.typing.NDArray[np.uint8] = np.zeros((height, width, 3), dtype=np.uint8)
33        self.image_size: tuple[int, int] = (pixel*width, pixel*height)
34        return None
35
36    def image_np(self) -> np.typing.NDArray[np.uint8]:
37        self.image_array[self.lattice == 0] = self.c0
38        self.image_array[self.lattice == 1] = self.c1
39        self.image_array[self.lattice == 2] = self.c2
40        return self.image_array
41
42    def image_pil(self) -> Image.Image:
43        im: Image.Image = Image.fromarray(self.image_np())
44        return im.resize(self.image_size, resample=Image.Resampling.NEAREST)
45
46    def image_tk(self) -> ImageTk.PhotoImage:
47        return ImageTk.PhotoImage(self.image_pil())

image_np メソッドで、格子の値 0 ・ 1 ・ 2 をそれぞれ色 c0 ・ c1 ・ c2 に対応させた RGB 画像配列を作成し、 image_pil メソッドで Pillow の Image オブジェクトへ変換した上で、指定した pixel 倍率に拡大します。 image_tk メソッドは、この画像を tkinter で表示できる ImageTk.PhotoImage 形式に変換します。拡大時の補間方式に最近傍法（ Image.Resampling.NEAREST ）を用いているため、格子の 1 マス 1 マスが 1 つの色の塊としてはっきり表示されます。

GUI（ TkWidget ・ FrameBML ・ BMLGUI ）

GUI 部分は 3 つのモジュールに分かれています。

FrameBML は、 BMLImage の画像を ttk.Label に表示し、 tkinter の after メソッドを用いて一定間隔（既定では 10 ミリ秒）ごとに next メソッドを呼び出して画像を更新し続けます。

FrameBML.py
 1import tkinter as tk
 2from tkinter import ttk
 3
 4from PIL import ImageTk
 5
 6from BMLImage import BMLImage
 7
 8
 9class FrameBML(ttk.Frame):
10    def __init__(
11        self,
12        master: tk.Misc | None = None,
13        bmli: BMLImage | None = None,
14        interval: int = 10,
15    ) -> None:
16        super().__init__(master)
17        if bmli is None:
18            bmli = BMLImage()
19        self.bmli: BMLImage = bmli
20        self.image: ImageTk.PhotoImage = self.bmli.image_tk()
21        self.label: ttk.Label = ttk.Label(self, image=self.image)
22        self.label.pack()
23        self.interval: int = interval
24        self.bind("<Destroy>", self._on_destroy)
25        self._after_id: str | None = None
26        self._after_id = self.after(self.interval, self.next)
27        return None
28
29    def next(self) -> None:
30        self.bmli.next()
31        self.image = self.bmli.image_tk()
32        self.label.configure(image=self.image)
33        self._after_id = self.after(self.interval, self.next)
34        return None
35
36    def _on_destroy(self, event: tk.Event) -> None:
37        if event.widget is self and self._after_id is not None:
38            self.after_cancel(self._after_id)
39            self._after_id = None
40        return None

TkWidget には、色（ HSV ）を選択する FrameHSV 、盤面サイズを選択する FrameRadioButton 、密度を選択する FrameScale の 3 つの部品クラスが定義されています。いずれも get メソッドで現在の設定値を取得し、 set メソッドで値を設定できます。

BMLGUI は、これらの部品を配置してメインウィンドウを構成するクラスです。「 start 」ボタンで新しいウィンドウを開いてシミュレーションを開始し、「 stop 」ボタンでそのウィンドウを閉じます。「 reset 」ボタンで密度・盤面サイズの設定を既定値に戻し、「 color 」ボタンで車の色をランダムに選び直すことができます。 GUI の具体的な操作方法は 実行方法 で説明します。
