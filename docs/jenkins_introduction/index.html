Jenkins & Jenkins Pipeline 入門

本書は、Python などのプログラミング経験がある読者を対象に、Jenkins と Jenkins Pipeline の基礎から実践までを解説する入門書です。

注釈

本書の各章では、実際に動かして確認できるサンプルリポジトリ sample-app のファイルを個別にダウンロード・掲載しています。すべてまとめて入手したい場合は sample-app 一式（zip） からダウンロードしてください。
