第 2 章 Unity の概要

Unity とは

Unity は、Unity Technologies が開発しているゲームエンジンです。ゲームエンジンとは、ゲームを作るときに共通して必要になる機能をまとめたソフトウェアのことです。ゲームを一から作る場合、画面への描画、音の再生、入力の受け付け、物体の衝突判定などをすべて自分で実装する必要があります。ゲームエンジンを使うと、これらの機能をすぐに利用できるため、開発者はゲームの内容そのものの制作に集中できます。

Unity には、主に次のような機能が含まれています。

機能

概要

エディター

3D 空間や 2D 空間にオブジェクトを配置し、その場で動作を確認できる開発用のアプリケーションです。

スクリプト

C# でゲームの動作を記述できます。

レンダリング

3D モデル、ライト、影、ポストエフェクトなどを描画します。

物理演算

重力、衝突、摩擦などを計算します。

UI

ボタン、テキスト、メニュー画面などを作成できます。

オーディオ

効果音や BGM を再生します。3D 空間上の位置に応じた音の聞こえ方も再現できます。

アニメーション

キャラクターの動きや、オブジェクトの位置や色の変化を再生します。

ビルド

作ったゲームを、Windows、macOS、スマートフォン、Web ブラウザーなどで動くアプリケーションに変換します。

Unity で作れるもの

Unity はゲームエンジンですが、ゲーム以外の用途にも広く使われています。

  • 2D ゲーム、3D ゲーム（スマートフォン、PC、家庭用ゲーム機向け）

  • VR（仮想現実）、AR（拡張現実）、MR（複合現実）のアプリケーション

  • 建築や製品のビジュアライゼーション

  • ロボットや自動運転のシミュレーション

  • 教育、研修用のアプリケーション

対応プラットフォーム

Unity で作ったアプリケーションは、1 つのプロジェクトから複数のプラットフォーム向けにビルドできます。主な対応プラットフォームは次のとおりです。

分類

プラットフォーム

PC

Windows、macOS、Linux

モバイル

Android、iOS

Web

Web ブラウザー（WebGL）

XR

Meta Quest、Apple Vision Pro など

家庭用ゲーム機

PlayStation、Xbox、Nintendo Switch など（各メーカーとの契約が別途必要です）

ただし、ビルドするには、対象のプラットフォームに対応したモジュールをインストールしておく必要があります（第 3 章 環境構築 を参照）。また、iOS 向けのビルドには macOS と Xcode が必要になるなど、プラットフォームごとに固有の条件があります。

ライセンスとプラン

Unity を使うには Unity ID（Unity のアカウント）が必要です。Unity には、個人向けの無料の Unity Personal と、有料の Unity Pro、Unity Enterprise などのプランがあります。個人や小規模な組織であれば、一定の条件のもとで Unity Personal を無料で利用できます。

利用できるプランの条件（収益や資金調達額の上限など）や料金は変更されることがあります。利用を始める前に、Unity の公式サイトのプランのページ で最新の情報を確認してください。
