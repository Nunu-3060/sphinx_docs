第 13 章 オーディオ

この章では、効果音や BGM を再生する方法を説明します。

この章のサンプルコードは、examples/chapter13 フォルダーにあります。

AudioClip、AudioSource、AudioListener

Unity で音を扱うには、次の 3 つの要素を使います。

要素

役割

AudioClip

音声ファイル（.wav、.mp3、.ogg など）をプロジェクトに読み込んだアセットです。

AudioSource

AudioClip を再生するコンポーネントです。音を出したい GameObject に付けます。

AudioListener

音を聞くコンポーネントです。人間の耳にあたります。通常は Main Camera に付いています。

AudioListener は、シーンに 1 つだけ置きます。複数あると、Console ウィンドウに警告が表示されます。

AudioSource の主なプロパティ

プロパティ

意味

Audio Resource

再生する AudioClip などの音声のアセットです。

Play On Awake

GameObject が有効になったときに自動的に再生するかどうかです。

Loop

最後まで再生したら、最初から繰り返すかどうかです。BGM では有効にします。

Volume

音量（0 から 1）です。

Pitch

再生速度と音の高さです。1 が元の速さです。

Spatial Blend

0 で 2D の音、1 で 3D の音になります（後述）。

BGM の再生

BGM は、スクリプトを書かなくても再生できます。

  1. 空の GameObject を作成し、名前を BGM にします。

  2. Add Component で AudioSource を追加します。

  3. Audio Resource に BGM の AudioClip を設定します。

  4. Play On Awake と Loop を有効にします。

再生すると、BGM が繰り返し流れます。

効果音の再生

効果音は、スクリプトから再生するのが一般的です。

SoundPlayer.cs
 1using System.Collections;
 2using UnityEngine;
 3
 4namespace UnityIntroduction.Chapter13
 5{
 6    /// <summary>
 7    /// 効果音の再生と、BGM のフェードアウトを行います。
 8    /// </summary>
 9    public class SoundPlayer : MonoBehaviour
10    {
11        [SerializeField, Tooltip("効果音の再生に使う AudioSource")]
12        private AudioSource _sfxSource;
13
14        [SerializeField, Tooltip("BGM の再生に使う AudioSource（Loop を有効にしておきます）")]
15        private AudioSource _bgmSource;
16
17        [SerializeField]
18        private AudioClip _clickSound;
19
20        /// <summary>
21        /// 効果音を再生します。UI のボタンなどから呼び出します。
22        /// </summary>
23        public void PlayClickSound()
24        {
25            // PlayOneShot は再生中の音を止めずに重ねて再生します。
26            _sfxSource.PlayOneShot(_clickSound);
27        }
28
29        /// <summary>
30        /// BGM を指定した秒数でフェードアウトして停止します。
31        /// </summary>
32        public void FadeOutBgm(float duration)
33        {
34            StartCoroutine(FadeOutRoutine(duration));
35        }
36
37        private IEnumerator FadeOutRoutine(float duration)
38        {
39            float startVolume = _bgmSource.volume;
40
41            for (float elapsed = 0f; elapsed < duration; elapsed += Time.deltaTime)
42            {
43                _bgmSource.volume = Mathf.Lerp(startVolume, 0f, elapsed / duration);
44                yield return null;
45            }
46
47            _bgmSource.Stop();
48
49            // 次に再生するときのために音量を戻しておきます。
50            _bgmSource.volume = startVolume;
51        }
52    }
53}

SoundPlayer.cs をダウンロード

使い方は次のとおりです。

  1. 空の GameObject を作成し、名前を SoundPlayer にして、SoundPlayer スクリプトを付けます。

  2. 同じ GameObject に AudioSource を 2 つ追加します。1 つ目は効果音用で、Play On Awake を無効にします。2 つ目は BGM 用で、Audio Resource に BGM を設定し、Play On Awake と Loop を有効にします。

  3. SoundPlayer の Sfx Source に 1 つ目の AudioSource を、Bgm Source に 2 つ目の AudioSource を、Click Sound に効果音の AudioClip を、それぞれドラッグ＆ドロップします。

AudioSource で音を再生するメソッドには、次のものがあります。

メソッド

特徴

Play()

Audio Resource に設定した音を再生します。再生中の音は止めて、最初から再生し直します。

PlayOneShot(clip)

引数の AudioClip を再生します。再生中の音を止めずに重ねて再生するため、連続して鳴る効果音に向いています。

AudioSource.PlayClipAtPoint(clip, position)

指定した位置に一時的な AudioSource を作成して、音を再生します。再生が終わると自動的に削除されます。音を鳴らす GameObject がすぐに破棄される場合に使います。

SoundPlayer の PlayClickSound を、第 12 章 UI で説明したボタンの On Click () に設定すると、ボタンをクリックしたときに効果音が鳴ります。FadeOutBgm は、コルーチンを使って BGM の音量を徐々に下げてから停止します。

3D サウンド

AudioSource の Spatial Blend を 1 にすると、音が 3D サウンド になります。3D サウンドでは、AudioListener（通常はカメラ）との位置関係によって、音の大きさと左右の聞こえ方が変わります。例えば、画面の右側にある滝の音は右から聞こえ、遠ざかると小さくなります。

音が聞こえる範囲は、3D Sound Settings の Min Distance と Max Distance で設定します。Min Distance までは最大の音量で聞こえ、それより遠くなるにつれて小さくなります。

BGM や UI の効果音のように、位置に関係なく同じように聞こえてほしい音は、Spatial Blend を 0（2D）のままにしておきます。

音量の管理

BGM と効果音の音量を別々に調整できるようにしたい場合は、Audio Mixer を使います。Audio Mixer では、AudioSource の出力先をグループ（BGM、効果音など）に分け、グループごとに音量やエフェクトを設定できます。Audio Mixer は、Project ウィンドウを右クリックし、Create ‣ Audio ‣ Audio Mixer で作成します。
