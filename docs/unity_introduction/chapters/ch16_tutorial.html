第 16 章 チュートリアル：玉転がしゲームの制作

この章では、これまでに学んだ内容を組み合わせて、簡単な 3D ゲームを作ります。各手順で使う機能の詳しい説明は、手順の中で示す章を参照してください。

この章のサンプルコードは、examples/chapter16 フォルダーにあります。

完成イメージと仕様

プレイヤーはボールを転がして、ステージ上に置かれたアイテムをすべて集めます。

項目

仕様

操作

W、A、S、D キー、矢印キー、ゲームパッドの左スティックで、ボールを前後左右に転がします。

アイテム

ステージ上で回転しています。ボールが触れると、エフェクトと効果音とともに消え、スコアが 1 増えます。

ゲームクリア

すべてのアイテムを集めると、画面に「Clear!」と表示されます。

ゲームオーバー

ボールがステージから落ちると、画面に「Game Over」と表示されます。

リトライ

ゲームクリアまたはゲームオーバーになると Retry ボタンが表示され、クリックすると最初からやり直せます。

作成するスクリプトは次の 5 つです。

スクリプト

役割

PlayerController

入力に応じてボールを転がします。

CameraFollow

カメラをボールに追従させます。

Rotator

アイテムを回転させます。

Pickup

ボールが触れたときに、アイテムを回収します。

GameManager

スコアの管理、ゲームクリアとゲームオーバーの判定、リトライを行います。

手順 1：プロジェクトとシーンの準備

  1. 第 3 章 環境構築 の手順で、Universal 3D テンプレートの新しいプロジェクトを作成します。

  2. File ‣ New Scene で Basic (URP) を選んで新しいシーンを作成し、File ‣ Save As で Assets/Scenes フォルダーに RollABall という名前で保存します。

  3. File ‣ Build Profiles を開き、Scene List に RollABall シーンを追加します。リトライのときにシーンを読み込み直すために必要です（第 15 章 シーン管理とデータの保存 を参照）。

  4. Project ウィンドウの Assets フォルダーに、Scripts、Materials、Prefabs の 3 つのフォルダーを作成します。

  5. サンプルコードの examples/chapter16 フォルダーにある 5 つのスクリプトを、Assets/Scripts フォルダーにコピーします。自分で入力する場合は、この章のコードを見ながら作成してください。

手順 2：ステージの作成

  1. GameObject ‣ 3D Object ‣ Plane で平面を作成し、名前を Ground にします。

  2. Transform の Position を (0, 0, 0)、Scale を (2, 1, 2) にします。Plane は初期状態で 10 m 四方の大きさなので、20 m 四方の地面になります。

  3. Assets/Materials フォルダーを右クリックし、Create ‣ Material でマテリアルを作成して、名前を GroundMaterial にします。Base Map の色を好きな色に設定し、Ground にドラッグ＆ドロップします。

このゲームでは、ステージの周りに壁を置きません。ボールが地面の端から落ちるとゲームオーバーになります。

手順 3：プレイヤーの作成

  1. GameObject ‣ 3D Object ‣ Sphere で球を作成し、名前を Player にします。

  2. Transform の Position を (0, 0.5, 0) にします。球の直径は 1 m なので、地面の上にちょうど乗ります。

  3. Inspector ウィンドウの Tag で Player を選びます。Pickup スクリプトは、このタグでプレイヤーを見分けます。

  4. Add Component で Rigidbody を追加し、Interpolate を Interpolate にします。カメラが追従したときに、ボールの動きがなめらかに見えるようになります（第 10 章 物理演算 を参照）。

  5. PlayerController スクリプトを Player に付けます。

  6. 手順 2 と同じようにマテリアルを作成して、Player に設定します。

PlayerController.cs
 1using UnityEngine;
 2using UnityEngine.InputSystem;
 3
 4namespace UnityIntroduction.RollABall
 5{
 6    /// <summary>
 7    /// 入力に応じてボールに力を加えて転がします。
 8    /// </summary>
 9    [RequireComponent(typeof(Rigidbody))]
10    public class PlayerController : MonoBehaviour
11    {
12        [SerializeField, Tooltip("ボールに加える力の大きさ（N）")]
13        private float _moveForce = 10f;
14
15        private Rigidbody _rigidbody;
16        private InputAction _moveAction;
17        private Vector2 _moveInput;
18        private bool _canMove = true;
19
20        private void Awake()
21        {
22            _rigidbody = GetComponent<Rigidbody>();
23
24            // プロジェクト全体のアクション（Project-wide Actions）から Move アクションを取得します。
25            _moveAction = InputSystem.actions.FindAction("Player/Move", throwIfNotFound: true);
26        }
27
28        private void Update()
29        {
30            // 入力は毎フレーム呼ばれる Update で読み取ります。
31            _moveInput = _canMove ? _moveAction.ReadValue<Vector2>() : Vector2.zero;
32        }
33
34        private void FixedUpdate()
35        {
36            // 物理演算への力の追加は、物理演算の更新に合わせて呼ばれる FixedUpdate で行います。
37            // 入力の上下（y）を、ワールド座標の前後（z）に対応させます。
38            var force = new Vector3(_moveInput.x, 0f, _moveInput.y) * _moveForce;
39            _rigidbody.AddForce(force);
40        }
41
42        /// <summary>
43        /// 操作を受け付けないようにし、ボールをその場で止めます。
44        /// </summary>
45        public void StopMoving()
46        {
47            _canMove = false;
48            _moveInput = Vector2.zero;
49            _rigidbody.linearVelocity = Vector3.zero;
50            _rigidbody.angularVelocity = Vector3.zero;
51        }
52    }
53}

PlayerController.cs をダウンロード

PlayerController は、第 9 章 入力 で説明したプロジェクト全体のアクションから Move アクションを取得し、入力の値を Update で読み取ります。そして、FixedUpdate で Rigidbody に力を加えます。StopMoving は、ゲームクリアやゲームオーバーのときに GameManager から呼ばれ、ボールを止めて操作を受け付けないようにします。

ここで一度再生して、キーボードでボールが転がることを確認してください。ボールの転がる速さは、Move Force の値で調整できます。

手順 4：カメラの追従

  1. Hierarchy ウィンドウで Main Camera を選び、Transform の Position を (0, 10, -10)、Rotation を (45, 0, 0) にします。ステージを斜め上から見下ろす視点になります。

  2. CameraFollow スクリプトを Main Camera に付け、Target に Player をドラッグ＆ドロップします。

CameraFollow.cs
 1using UnityEngine;
 2
 3namespace UnityIntroduction.RollABall
 4{
 5    /// <summary>
 6    /// 対象との位置関係を保ったまま、カメラを対象に追従させます。
 7    /// </summary>
 8    public class CameraFollow : MonoBehaviour
 9    {
10        [SerializeField, Tooltip("追従する対象")]
11        private Transform _target;
12
13        private Vector3 _offset;
14
15        private void Start()
16        {
17            // 再生開始時のカメラと対象の位置の差を覚えておきます。
18            _offset = transform.position - _target.position;
19        }
20
21        private void LateUpdate()
22        {
23            // 対象の移動が終わった後の LateUpdate でカメラを動かすと、表示のずれを防げます。
24            transform.position = _target.position + _offset;
25        }
26    }
27}

CameraFollow.cs をダウンロード

CameraFollow は、再生開始時のカメラとボールの位置の差を覚えておき、LateUpdate でカメラの位置を「ボールの位置 + 位置の差」に更新します。ボールが転がって回転しても、カメラは回転せずに同じ向きで追いかけます。

Tip

カメラの動きをもっと凝ったものにしたい場合は、第 11 章 グラフィックスの基礎 で紹介した Cinemachine を使うと、スクリプトを書かずに、なめらかな追従や、遅れて追いかける動きを設定できます。

手順 5：アイテムの作成

  1. GameObject ‣ 3D Object ‣ Cube で立方体を作成し、名前を Pickup にします。

  2. Transform の Position を (3, 0.5, 3)、Rotation を (45, 45, 45)、Scale を (0.5, 0.5, 0.5) にします。

  3. Box Collider の Is Trigger を有効にします。ボールがアイテムに触れても跳ね返らず、触れたことだけを検出するようになります。

  4. Rotator スクリプトと Pickup スクリプトを付けます。

  5. 黄色などの目立つ色のマテリアルを作成して設定します。

Rotator.cs
 1using UnityEngine;
 2
 3namespace UnityIntroduction.RollABall
 4{
 5    /// <summary>
 6    /// GameObject を一定の速さで回転させ続けます。
 7    /// </summary>
 8    public class Rotator : MonoBehaviour
 9    {
10        [SerializeField, Tooltip("各軸まわりの 1 秒あたりの回転角度（度）")]
11        private Vector3 _degreesPerSecond = new Vector3(15f, 30f, 45f);
12
13        private void Update()
14        {
15            transform.Rotate(_degreesPerSecond * Time.deltaTime);
16        }
17    }
18}

Pickup.cs
 1using System;
 2using UnityEngine;
 3
 4namespace UnityIntroduction.RollABall
 5{
 6    /// <summary>
 7    /// プレイヤーが触れると回収されるアイテムです。
 8    /// </summary>
 9    /// <remarks>
10    /// Collider（Box Collider など）を付け、Is Trigger を有効にしておきます。
11    /// Collider は抽象クラスなので、RequireComponent で自動的に追加されることはありません。
12    /// </remarks>
13    [RequireComponent(typeof(Collider))]
14    public class Pickup : MonoBehaviour
15    {
16        [SerializeField, Tooltip("回収したときに生成するエフェクト（省略可）")]
17        private ParticleSystem _effectPrefab;
18
19        [SerializeField, Tooltip("回収したときに再生する効果音（省略可）")]
20        private AudioClip _sound;
21
22        /// <summary>
23        /// いずれかの Pickup が回収されたときに発生します。
24        /// </summary>
25        /// <remarks>
26        /// static なイベントなので、Pickup を 1 つずつ参照しなくても購読できます。
27        /// </remarks>
28        public static event Action<Pickup> Collected;
29
30        private void OnTriggerEnter(Collider other)
31        {
32            if (!other.CompareTag("Player"))
33            {
34                return;
35            }
36
37            if (_effectPrefab != null)
38            {
39                Instantiate(_effectPrefab, transform.position, Quaternion.identity);
40            }
41
42            if (_sound != null)
43            {
44                // この GameObject はすぐに破棄されるため、再生用の AudioSource を一時的に生成する
45                // PlayClipAtPoint を使います。PlayClipAtPoint の音は 3D サウンドになるので、
46                // カメラの位置で再生して、距離によって音が小さくならないようにします。
47                AudioSource.PlayClipAtPoint(_sound, Camera.main.transform.position);
48            }
49
50            Collected?.Invoke(this);
51            Destroy(gameObject);
52        }
53    }
54}

Pickup.cs をダウンロード

Pickup は、トリガーに入った GameObject のタグが Player のときだけ処理を行います。Pickup には Rigidbody を付けていませんが、ボールに Rigidbody が付いているため、トリガーイベントが呼ばれます（第 10 章 物理演算 を参照）。

回収されたことは、static なイベント Collected で通知します（第 8 章 スクリプトの応用 を参照）。static なイベントは、どの Pickup が回収されても同じイベントとして通知されるため、GameManager は Pickup を 1 つずつ参照しなくても、すべての Pickup の回収を受け取れます。

アイテムを Prefab にして並べる

  1. Hierarchy ウィンドウの Pickup を Assets/Prefabs フォルダーにドラッグ＆ドロップして、Prefab にします（第 5 章 Unity の基本概念 を参照）。

  2. シーンの Pickup を選び、Ctrl + D で複製して、地面の上のさまざまな位置に配置します。8 個程度を目安にしてください。

アイテムの見た目や設定を変えたいときは、Prefab を編集すれば、すべてのアイテムに反映されます。

手順 6：エフェクトと効果音

  1. 第 11 章 グラフィックスの基礎 の「パーティクル」の手順で、火花のエフェクトの Prefab を作成し、Assets/Prefabs フォルダーに保存します。Stop Action を Destroy にすることを忘れないでください。

  2. アイテムを取ったときの効果音の音声ファイルを用意し、Assets フォルダーにドラッグ＆ドロップして読み込みます。

  3. Pickup の Prefab をダブルクリックして Prefab モードで開き、Pickup コンポーネントの Effect Prefab にエフェクトの Prefab を、Sound に効果音の AudioClip を設定します。

エフェクトと効果音は省略することもできます。設定しない場合は、アイテムが消えるだけになります。効果音には、第 13 章 オーディオ で説明した AudioSource.PlayClipAtPoint を使っています。アイテムの GameObject はすぐに破棄されるため、アイテム自身の AudioSource では最後まで再生できないからです。PlayClipAtPoint の音は 3D サウンドになり、カメラから離れた位置で鳴らすと小さく聞こえます。そのため、再生する位置にはカメラの位置（Camera.main.transform.position）を指定しています。

手順 7：UI の作成

第 12 章 UI の内容に従って、スコアとメッセージを表示する UI を作ります。

  1. GameObject ‣ UI ‣ Text - TextMeshPro でテキストを作成し、名前を ScoreText にします。TMP Importer ウィンドウが表示された場合は、Import TMP Essentials をクリックします。

  2. ScoreText の RectTransform のアンカーを、Shift と Alt を押しながら左上に設定し、位置を少し内側にずらします。

  3. もう 1 つテキストを作成して名前を MessageText にし、アンカーを中央にします。Font Size を 72 程度にし、Alignment を中央ぞろえにします。

  4. GameObject ‣ UI ‣ Button - TextMeshPro でボタンを作成し、名前を RetryButton にします。MessageText の少し下に配置し、ボタンの子の Text (TMP) の文字を Retry にします。

  5. Canvas の Canvas Scaler の UI Scale Mode を Scale With Screen Size にし、Reference Resolution を 1920 × 1080 にします。

TextMeshPro の既定のフォントは日本語を表示できないため、このゲームでは画面に表示する文字をすべて英語にしています。

  1. GameObject ‣ Create Empty で空の GameObject を作成し、名前を GameManager にします。

  2. GameManager スクリプトを付け、次の表のとおりにフィールドを設定します。

  1. RetryButton を選び、Button コンポーネントの On Click () の + をクリックします。追加された欄に GameManager の GameObject をドラッグ＆ドロップし、メソッドの一覧から GameManager ‣ Retry () を選びます。

GameManager.cs
  1using TMPro;
  2using UnityEngine;
  3using UnityEngine.SceneManagement;
  4
  5namespace UnityIntroduction.RollABall
  6{
  7    /// <summary>
  8    /// スコアの管理、ゲームクリアとゲームオーバーの判定、リトライを行います。
  9    /// </summary>
 10    public class GameManager : MonoBehaviour
 11    {
 12        [SerializeField]
 13        private PlayerController _player;
 14
 15        [SerializeField]
 16        private TextMeshProUGUI _scoreText;
 17
 18        [SerializeField]
 19        private TextMeshProUGUI _messageText;
 20
 21        [SerializeField]
 22        private GameObject _retryButton;
 23
 24        [SerializeField, Tooltip("プレイヤーがこの高さより下に落ちたらゲームオーバー")]
 25        private float _fallThreshold = -10f;
 26
 27        private int _score;
 28        private int _totalPickups;
 29        private bool _isFinished;
 30
 31        private void OnEnable()
 32        {
 33            Pickup.Collected += OnPickupCollected;
 34        }
 35
 36        private void OnDisable()
 37        {
 38            // static なイベントの購読を解除し忘れると、シーンを読み直した後も
 39            // 破棄済みの GameManager が呼ばれてしまいます。
 40            Pickup.Collected -= OnPickupCollected;
 41        }
 42
 43        private void Start()
 44        {
 45            // シーンに置かれている Pickup の数を数えます。
 46            _totalPickups = FindObjectsByType<Pickup>(FindObjectsSortMode.None).Length;
 47
 48            UpdateScoreText();
 49            _messageText.gameObject.SetActive(false);
 50            _retryButton.SetActive(false);
 51        }
 52
 53        private void Update()
 54        {
 55            if (!_isFinished && _player.transform.position.y < _fallThreshold)
 56            {
 57                Finish("Game Over");
 58            }
 59        }
 60
 61        /// <summary>
 62        /// 現在のシーンを読み込み直して、ゲームを最初からやり直します。
 63        /// </summary>
 64        /// <remarks>
 65        /// Retry ボタンの On Click () から呼び出します。
 66        /// </remarks>
 67        public void Retry()
 68        {
 69            SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
 70        }
 71
 72        private void OnPickupCollected(Pickup pickup)
 73        {
 74            if (_isFinished)
 75            {
 76                return;
 77            }
 78
 79            _score++;
 80            UpdateScoreText();
 81
 82            if (_score >= _totalPickups)
 83            {
 84                Finish("Clear!");
 85            }
 86        }
 87
 88        private void UpdateScoreText()
 89        {
 90            _scoreText.text = $"Score: {_score} / {_totalPickups}";
 91        }
 92
 93        private void Finish(string message)
 94        {
 95            _isFinished = true;
 96            _player.StopMoving();
 97
 98            _messageText.text = message;
 99            _messageText.gameObject.SetActive(true);
100            _retryButton.SetActive(true);
101        }
102    }
103}

GameManager.cs をダウンロード

GameManager の処理の流れは次のとおりです。

タイミング

処理

OnEnable

Pickup.Collected イベントの購読を開始します。

Start

シーン内の Pickup の数を FindObjectsByType で数え、スコアを表示します。メッセージと Retry ボタンは非表示にします。

Update

ボールの高さが Fall Threshold（初期値は -10 m）より下になったら、ゲームオーバーにします。

アイテムの回収時

スコアを 1 増やして表示を更新します。すべて集めたら、ゲームクリアにします。

ゲームの終了時

ボールを止め、メッセージと Retry ボタンを表示します。

Retry ボタンのクリック時

現在のシーンを読み込み直して、最初からやり直します。

OnDisable

Pickup.Collected イベントの購読を解除します。シーンを読み込み直すときにも呼ばれます。

手順 9：動作の確認

シーンを保存し、再生して次のことを確認してください。

  • ボールを転がして、アイテムに触れると消え、スコアが増える。

  • すべてのアイテムを集めると「Clear!」と Retry ボタンが表示される。

  • ボールを地面の端から落とすと「Game Over」と Retry ボタンが表示される。

  • Retry ボタンをクリックすると、最初の状態に戻る。

うまく動かない場合は、Console ウィンドウにエラーが表示されていないかを確認してください。よくある原因は次のとおりです。

症状

確認すること

ボールが動かない

Player に Rigidbody と PlayerController が付いているか。Console ウィンドウに Player/Move が見つからないというエラーが出ていないか（第 9 章 入力 を参照）。

アイテムに触れても消えない

Player のタグが Player になっているか。アイテムの Box Collider の Is Trigger が有効になっているか。

NullReferenceException が発生する

GameManager や CameraFollow のフィールドがすべて設定されているか。

Retry ボタンを押してもやり直せない

RollABall シーンが Scene List に登録されているか。シーンに EventSystem があるか。

発展課題

基本のゲームが完成したら、次のような改造に挑戦してみてください。

  • 第 9 章 入力 を参考に、Jump アクションでボールをジャンプさせる（AddForce と ForceMode.Impulse を使います）。

  • 制限時間を設け、時間内にすべて集められなかったらゲームオーバーにする。

  • 地面の上に障害物や坂道を置き、ステージを複雑にする。

  • 第 15 章 シーン管理とデータの保存 を参考に、クリアまでにかかった時間の最短記録を PlayerPrefs に保存する。

  • ステージを複数のシーンに分け、クリアしたら次のステージに進むようにする。
