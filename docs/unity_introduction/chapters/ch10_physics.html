第 10 章 物理演算

Unity の物理演算を使うと、重力による落下、物体同士の衝突や跳ね返り、摩擦などを、自分で計算しなくても再現できます。

この章のサンプルコードは、examples/chapter10 フォルダーにあります。

Rigidbody と Collider

物理演算に関わる主なコンポーネントは、Rigidbody と Collider の 2 つです。

コンポーネント

役割

Rigidbody

GameObject を物理演算で動かす対象にします。質量を持ち、重力や力を受けて動くようになります。

Collider

衝突判定に使う形状を表します。見た目の形状（メッシュ）とは別に設定します。

Collider には、形状に応じて次のような種類があります。

Collider

特徴

Box Collider

直方体の形状です。

Sphere Collider

球の形状です。衝突判定の計算が最も軽い形状です。

Capsule Collider

カプセル（円柱の両端に半球を付けた形）の形状です。人型のキャラクターによく使います。

Mesh Collider

メッシュの形状をそのまま使います。複雑な形状を正確に表せますが、計算が重くなります。Rigidbody を付けた GameObject で使う場合は、Convex を有効にする必要があります。

複雑な形状の GameObject でも、Box Collider や Sphere Collider などの単純な Collider を複数組み合わせて近似すると、計算を軽くできます。

GameObject の種類と組み合わせ

Rigidbody と Collider の組み合わせによって、GameObject の物理演算での扱いが変わります。

構成

扱い

例

Collider のみ

静的な Collider。動かない物体として扱われます。

地面、壁

Collider と Rigidbody

物理演算で動く物体として扱われます。

ボール、箱

Collider と Rigidbody（Is Kinematic を有効）

物理演算の力では動かず、スクリプトで動かす物体として扱われます。他の Rigidbody を押しのけることはできます。

動く床、エレベーター

Rigidbody の主なプロパティ

プロパティ

意味

Mass

質量（kg）です。

Linear Damping

移動の減衰の強さです。大きいほど早く止まります。

Angular Damping

回転の減衰の強さです。

Use Gravity

重力の影響を受けるかどうかです。

Is Kinematic

物理演算の力で動かさず、スクリプトで動かすかどうかです。

Interpolate

物理演算の更新と描画のタイミングの差によって動きがかくつくのを、補間によって和らげます。プレイヤーなど、カメラが追いかける GameObject では Interpolate を選ぶとなめらかに表示されます。

Collision Detection

衝突判定の方式です。高速で動く GameObject が壁をすり抜けてしまう場合は、Continuous などに変更します。

Constraints

特定の軸の移動や回転を固定します。

注釈

Unity 6 では、Rigidbody の一部のプロパティの名前が変わりました。velocity は linearVelocity に、drag は linearDamping に、angularDrag は angularDamping になっています。古い資料のコードを使う場合は注意してください。

Rigidbody を動かす

Rigidbody を付けた GameObject を transform.position で直接動かすと、物理演算を無視した移動になり、衝突がうまく処理されません。Rigidbody を付けた GameObject は、次のような方法で動かします。

方法

用途

AddForce(力, ForceMode.Force)

継続的に力を加えます。FixedUpdate で毎回呼び出して使います。

AddForce(力積, ForceMode.Impulse)

瞬間的に力を加えます。ジャンプや爆発などに使います。

linearVelocity への代入

速度を直接設定します。力の計算を介さないため、キャラクターの移動を細かく制御したい場合に使います。

MovePosition(位置)

Is Kinematic を有効にした Rigidbody を、物理演算の更新に合わせて移動させます。移動中に触れた他の Rigidbody を押しのけますが、壁などに当たっても止まりません。

衝突イベントとトリガーイベント

衝突が起きたことは、イベント関数で受け取れます。

CollisionReporter.cs
 1using UnityEngine;
 2
 3namespace UnityIntroduction.Chapter10
 4{
 5    /// <summary>
 6    /// 衝突イベントとトリガーイベントの発生をログに表示します。
 7    /// </summary>
 8    /// <remarks>
 9    /// イベントを受け取るには、衝突する 2 つの GameObject の両方に Collider があり、
10    /// 少なくとも一方に Rigidbody が付いている必要があります。
11    /// 衝突イベントの場合は、少なくとも一方の Rigidbody の Is Kinematic が無効である必要があります。
12    /// </remarks>
13    public class CollisionReporter : MonoBehaviour
14    {
15        private void OnCollisionEnter(Collision collision)
16        {
17            // relativeVelocity は衝突した瞬間の相対速度です。
18            float speed = collision.relativeVelocity.magnitude;
19            Debug.Log($"{collision.gameObject.name} と衝突しました（相対速度 {speed:F2} m/s）。");
20        }
21
22        private void OnCollisionExit(Collision collision)
23        {
24            Debug.Log($"{collision.gameObject.name} から離れました。");
25        }
26
27        private void OnTriggerEnter(Collider other)
28        {
29            Debug.Log($"{other.gameObject.name} がトリガーに入りました。");
30        }
31
32        private void OnTriggerExit(Collider other)
33        {
34            Debug.Log($"{other.gameObject.name} がトリガーから出ました。");
35        }
36    }
37}

イベント関数

呼ばれるタイミング

OnCollisionEnter

OnCollisionExit

OnTriggerEnter

トリガーの範囲に入った瞬間

OnTriggerStay

トリガーの範囲に入っている間

OnTriggerExit

トリガーの範囲から出た瞬間

Collider の Is Trigger を有効にすると、その Collider は物体を押し返さず、他の Collider が範囲に入ったことを検出するだけの トリガー になります。アイテムの取得、ゴールの判定、敵の索敵範囲などに使います。

重要

衝突イベントやトリガーイベントが呼ばれるには、次の条件を満たす必要があります。

  • 両方の GameObject に Collider が付いている。

  • 少なくとも一方の GameObject に Rigidbody が付いている。

  • 衝突イベントの場合は、少なくとも一方の Rigidbody の Is Kinematic が無効になっている（トリガーイベントは、Is Kinematic が有効でも呼ばれます）。

イベントが呼ばれない場合は、まずこの条件を確認してください。また、2D 用の Collider（Box Collider 2D など）と 3D 用の Collider は互いに衝突しません。

レイキャスト

レイキャスト は、ある点から指定した方向に光線（レイ）を飛ばし、最初に当たった Collider を調べる機能です。射撃の当たり判定、足元に地面があるかの判定、マウスでクリックした物体の特定などに使います。

ClickPusher.cs
 1using UnityEngine;
 2using UnityEngine.InputSystem;
 3
 4namespace UnityIntroduction.Chapter10
 5{
 6    /// <summary>
 7    /// クリックした位置にレイを飛ばし、当たった Rigidbody を押し出します。
 8    /// </summary>
 9    public class ClickPusher : MonoBehaviour
10    {
11        [SerializeField, Tooltip("レイが届く最大距離（m）")]
12        private float _maxDistance = 100f;
13
14        [SerializeField, Tooltip("押し出す力積の大きさ（N·s）")]
15        private float _pushImpulse = 5f;
16
17        [SerializeField, Tooltip("レイが当たる対象のレイヤー")]
18        private LayerMask _targetLayers = ~0;
19
20        private Camera _camera;
21
22        private void Awake()
23        {
24            // Camera.main は MainCamera タグが付いたカメラを返します。
25            _camera = Camera.main;
26        }
27
28        private void Update()
29        {
30            Mouse mouse = Mouse.current;
31            if (mouse == null || !mouse.leftButton.wasPressedThisFrame)
32            {
33                return;
34            }
35
36            // 画面上のマウスの位置から、カメラの奥へ向かうレイを作ります。
37            Ray ray = _camera.ScreenPointToRay(mouse.position.ReadValue());
38
39            if (!Physics.Raycast(ray, out RaycastHit hit, _maxDistance, _targetLayers))
40            {
41                return;
42            }
43
44            Debug.Log($"{hit.collider.name} に当たりました（距離 {hit.distance:F2} m）。");
45
46            // Rigidbody は UnityEngine.Object なので、?. ではなく != null で判定します。
47            if (hit.rigidbody != null)
48            {
49                hit.rigidbody.AddForceAtPosition(ray.direction * _pushImpulse, hit.point, ForceMode.Impulse);
50            }
51        }
52    }
53}

ClickPusher.cs をダウンロード

このスクリプトをシーン内の任意の GameObject に付けます。地面として Plane を配置し、その上に Rigidbody を付けた Cube を置いて再生します。Cube をクリックすると、クリックした位置からカメラの奥の方向へ押し出されます。

Camera.ScreenPointToRay は、画面上の位置から、カメラの奥へ向かうレイを作ります。Physics.Raycast はレイが Collider に当たると true を返し、当たった位置や Collider などの情報を RaycastHit に格納します。

レイヤーと衝突マトリクス

GameObject には レイヤー を 1 つ設定できます。レイヤーは、Inspector ウィンドウの右上にある Layer で設定します。新しいレイヤーは、Layer の一覧の Add Layer... から追加できます。

レイヤーを使うと、次のような設定ができます。

  • 衝突マトリクス：Edit ‣ Project Settings の Physics にある Layer Collision Matrix で、レイヤー同士が衝突するかどうかを設定できます。例えば、味方の弾が味方に当たらないようにできます。

  • レイキャストの対象の限定：Physics.Raycast の引数に LayerMask を渡すと、特定のレイヤーの Collider だけにレイを当てられます。ClickPusher の Target Layers がその例です。

  • カメラの描画対象の限定：Camera コンポーネントの Culling Mask で、描画するレイヤーを選べます。

2D の物理演算

2D ゲームでは、2D 用の物理演算を使います。コンポーネントの名前の末尾に 2D が付いている（Rigidbody 2D、Box Collider 2D など）ほかは、基本的な考え方は 3D と同じです。
