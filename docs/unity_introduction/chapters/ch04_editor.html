第 4 章 エディターの基本操作

主要なウィンドウ

Unity Editor の画面は、複数のウィンドウで構成されています。初期状態では、次のウィンドウが表示されています。

ウィンドウ

役割

Scene ビュー

シーン（ゲームの舞台となる空間）を表示し、GameObject を配置、移動、回転、拡大縮小するためのウィンドウです。

Game ビュー

カメラから見たゲームの画面を表示します。再生中は、プレイヤーが実際に見る画面になります。

Hierarchy ウィンドウ

現在開いているシーンにある GameObject を、親子関係がわかる階層構造で一覧表示します。

Inspector ウィンドウ

選択している GameObject やアセットの詳細を表示し、設定を変更するためのウィンドウです。

Project ウィンドウ

プロジェクトの Assets フォルダーと Packages フォルダーの中身を表示します。

Console ウィンドウ

ログ、警告、エラーのメッセージを表示します。スクリプトのコンパイルエラーもここに表示されます。

ウィンドウは、タブをドラッグして好きな位置に移動したり、別のウィンドウとタブでまとめたりできます。閉じてしまったウィンドウは、Window ‣ General から開き直せます。

Tip

初めのうちは、Console ウィンドウを常に表示しておくことをお勧めします。スクリプトの誤りなど、問題が起きたときの手がかりが表示されます。

Scene ビューの視点操作

Scene ビューでは、次の操作で視点を動かします。

操作

動作

マウスの右ボタンを押しながらドラッグ

視点をその場で回転させます。

マウスの右ボタンを押しながら W、A、S、D、Q、E

前後、左右、上下に視点を移動します（フライスルーモード）。Shift を押すと速く移動します。

マウスの中ボタンを押しながらドラッグ

視点を上下左右に平行移動します。

Alt とマウスの左ボタンを押しながらドラッグ

注目している点を中心に、視点を回転させます。

マウスホイール

視点を前後に移動し、拡大、縮小します。

F（GameObject を選択した状態で）

選択している GameObject が画面の中央に来るように視点を移動します。

Scene ビューの右上にある軸の表示（シーンギズモ）をクリックすると、真上や真横などの決まった方向からの視点に切り替えられます。

トランスフォームツール

GameObject の位置、回転、大きさは、Scene ビューのツールバーにあるトランスフォームツールで変更します。

ツール

キー

機能

View

Q

視点を平行移動します。GameObject は選択されません。

Move

W

GameObject を移動します。矢印をドラッグすると、その軸の方向だけに移動します。

Rotate

E

GameObject を回転させます。

Scale

R

GameObject の大きさを変えます。

Rect

T

2D の要素や UI の位置と大きさを、長方形の枠で変更します。

Transform

Y

移動、回転、拡大縮小をまとめて行います。

Move ツールで移動するときに Ctrl を押しながらドラッグすると、一定の間隔ごとに移動できます（グリッドスナップ）。また、V を押しながらドラッグすると、GameObject の頂点を別の GameObject の頂点に合わせられます（頂点スナップ）。

数値で正確に指定したい場合は、Inspector ウィンドウの Transform コンポーネントに値を入力します。

GameObject の作成と操作

簡単な GameObject を作成して、ここまでの操作を試してみましょう。

  1. GameObject ‣ 3D Object ‣ Cube を選びます。シーンに立方体が追加され、Hierarchy ウィンドウに Cube が表示されます。

  2. Hierarchy ウィンドウで Cube を選び、Scene ビューで F キーを押します。立方体が画面の中央に表示されます。

  3. W キーを押して Move ツールに切り替え、矢印をドラッグして立方体を移動します。

  4. Inspector ウィンドウの Transform コンポーネントで、Position の値がすべて 0 になるように入力します。

Hierarchy ウィンドウでは、次の操作もよく使います。

操作

方法

名前の変更

GameObject を選んで F2 キーを押します。

複製

GameObject を選んで Ctrl + D を押します。

削除

GameObject を選んで Delete キーを押します。

親子関係の設定

GameObject を別の GameObject の上にドラッグします。

元に戻す、やり直す

Ctrl + Z で元に戻し、Ctrl + Y でやり直します。macOS では、やり直しは Command + Shift + Z です。

再生モード

ツールバーの中央にある Play ボタン（▶）をクリックすると、再生モードになり、Game ビューでゲームが動き始めます。もう一度クリックすると、再生モードが終わります。Pause ボタンで一時停止、Step ボタンで 1 フレームずつ進めることもできます。

警告

再生モード中に Inspector ウィンドウなどで変更した値は、再生モードを終えると元に戻ります。これは、値を試しに変えて動作を確認するためのしくみです。残したい値は、再生モードを終えてから入力し直してください。

再生モード中であることに気付かずに作業してしまうのを防ぐため、再生モード中の画面の色を変えておくと便利です。Edit ‣ Preferences の Colors にある Playmode tint で色を設定できます。

保存

シーンの変更は、File ‣ Save（Ctrl + S）で保存します。シーンに未保存の変更があると、Hierarchy ウィンドウのシーン名の横に * が表示されます。

Unity Editor は自動では保存しないため、こまめに保存する習慣を付けてください。

レイアウトの変更と保存

ウィンドウの配置（レイアウト）は、ツールバーの右端にある Layout メニューから切り替えられます。2 by 3 や Tall など、あらかじめ用意されたレイアウトを選べるほか、自分で並べたレイアウトを Save Layout で名前を付けて保存することもできます。ウィンドウの配置がわからなくなった場合は、Default を選ぶと初期状態に戻ります。
