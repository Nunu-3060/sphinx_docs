付録 B ショートカットキー一覧

Unity Editor でよく使うショートカットキーをまとめます。macOS では、Ctrl を Command に、Alt を Option に読み替えてください。ショートカットキーは、Edit ‣ Shortcuts で確認、変更できます。

全般

キー

機能

Ctrl + S

シーンを保存する

Ctrl + Z

元に戻す

Ctrl + Y

やり直す（macOS では Command + Shift + Z）

Ctrl + P

再生を開始する、終了する

Ctrl + Shift + P

再生を一時停止する

Ctrl + Alt + P

1 フレームだけ進める

GameObject の操作

キー

機能

Ctrl + D

選択している GameObject を複製する

Delete

選択している GameObject を削除する

F2

選択している GameObject の名前を変更する

Ctrl + Shift + N

空の GameObject を作成する

F

選択している GameObject が Scene ビューの中央に来るように、視点を移動する

Transform ツール

Ctrl を押しながらドラッグ

一定の間隔ごとに移動、回転、拡大縮小する

Scene ビューの視点操作

操作

機能

マウスの右ボタンを押しながらドラッグ

視点をその場で回転させる

マウスの右ボタンを押しながら W、A、S、D、Q、E

視点を前後、左右、上下に移動する

マウスの中ボタンを押しながらドラッグ

視点を平行移動する

Alt とマウスの左ボタンを押しながらドラッグ

注目している点を中心に視点を回転させる

マウスホイール

視点を前後に移動する
