1. はじめに

1.1. 本書の目的

私たちが書くプログラムは、ほぼ例外なくオペレーティングシステム（OS）の上で動いています。ファイルを開く、メモリを確保する、ネットワークにデータを送る、別のプログラムを起動するといった処理は、どれも最終的には OS に依頼して実現されています。

普段の開発では OS の存在を意識しなくても困らないことが多いですが、次のような場面では OS の知識が直接役に立ちます。

  • プログラムが遅い原因が、CPU、メモリ、ディスク、ネットワークのどこにあるのかを切り分けたい。

  • マルチスレッドのプログラムで、まれにしか再現しない不具合を調べたい。

  • 「メモリ不足でプロセスが強制終了された」「ファイルディスクリプタが足りない」といったエラーの意味を理解したい。

  • コンテナや仮想マシンが何を隔離していて、何を共有しているのかを知りたい。

本書の目的は、こうした場面で「OS の中で何が起きているか」を想像できるようになるための基礎を身に付けることです。OS そのものを開発するための知識ではなく、OS の上でソフトウェアを作り、運用するエンジニアにとって必要な知識を中心に扱います。

1.2. 対象読者

本書は次のような読者を想定しています。

  • 何らかのプログラミング言語でプログラムを書いた経験がある。

  • Linux や Windows を日常的に使っているが、その内部の仕組みは詳しく知らない。

計算機の構成（CPU、メモリ、入出力装置）についての基本的な知識があると読みやすくなりますが、必要な事項は本文の中でも簡単に説明します。

1.4. サンプルコードの使い方

本書のサンプルコードはすべて Python で書かれており、Python 3.10 以降の標準ライブラリだけで動作します。サンプルコードの一覧は「サンプルコード一覧」にあり、そこから各ファイルをダウンロードできます。

サンプルコードは、次のようにコマンドラインから実行します。

1$ python process_info.py

サンプルコードには、次の 2 種類があります。

  • OS の機能を直接使うもの：プロセスの起動、スレッド、ファイル、ソケットなどを Python の標準ライブラリ経由で使い、OS の振る舞いを観察します。

  • OS の中の仕組みを再現するもの：CPU スケジューリングやページ置換などのアルゴリズムを、小さなシミュレーターとして実装します。

本文に示すサンプルコードの実行結果は、Windows 11 上の Python 3.14 で実行したものです。プロセス ID や処理時間など、実行環境や実行のたびに変わる値があります。

1.5. 表記について

本書では次の表記を用います。

  • OS の名前は、特に断りのない限り、Linux は Linux カーネルを使う OS 全般を、Windows は Windows NT 系の OS（Windows 2000 以降）を指します。

  • 「UNIX 系 OS」は、UNIX の設計を受け継ぐ OS（Linux、BSD 系 OS、macOS など）の総称として使います。

  • コマンドの実行例では、行頭の $ はシェルのプロンプトを表します。入力するのは $ より後の部分です。

  • 容量の単位は、2 進接頭辞（KiB = 1024 バイト、MiB = 1024 KiB など）を使います。

  • 重要な用語は「用語集」にまとめています。
