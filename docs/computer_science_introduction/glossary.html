用語集

本書に登場する主な用語の意味を示す。英字で始まる用語をアルファベット順に、それ以外の用語を五十音順に並べた。各用語の末尾には、その用語を扱っている章を示す。

英字

ACID 特性

トランザクションが満たすべき原子性（Atomicity）・一貫性（Consistency）・分離性（Isolation）・永続性（Durability）の 4 つの性質である。

関連する章: 「データベース」

ALU

算術論理演算装置（Arithmetic Logic Unit）である。CPU の中で加算・減算・論理演算・シフト・比較などを行う組み合わせ回路である。

関連する章: 「コンピュータの構成」

ASCII

英字、数字、記号、制御文字に 0〜127 の番号を割り当てた 7 ビットの文字コードである。1963 年に米国で制定された。

関連する章: 「情報の表現」

ASLR

プログラムの起動ごとに、スタック、ヒープ、ライブラリなどを置く仮想アドレスをランダムに変える緩和策である。Address Space Layout Randomization の略である。攻撃者が実行を移すべきアドレスを事前に知ることを難しくする。

関連する章: 「認証とアプリケーションのセキュリティ」

Belady の異常

ページ置換に FIFO を使うと、ページフレームを増やしたのにページフォールトの回数が増えることがある現象である。LRU や最適置換では起きない。

関連する章: 「オペレーティングシステム」

BNF

Backus-Naur Form（バッカス・ナウア記法）の略である。文脈自由文法を記述するための記法で、プログラミング言語の文法の定義に広く使われる。

関連する章: 「計算理論」

B+ 木

1 つの節点に多数のキーを持つ平衡木で、行の位置は葉にだけ格納し、葉どうしを連結する。検索・挿入・削除が \(O(\log N)\) で行え、データベースのインデックスに広く使われる。

関連する章: 「データベース」

CAP 定理

ネットワーク分断が起きているとき、線形化可能性（一貫性）と、故障していないすべてのノードが応答すること（可用性）を両立できないという定理である。分断時にどちらを優先するかの選択を意味する。

関連する章: 「分散システム」

CAS

Compare-And-Swap の略である。メモリ上の値が期待する値と等しいときだけ新しい値に書き換える操作を不可分に行うアトミック操作で、ロックフリーのデータ構造の基本となる。

関連する章: 「並行処理と入出力」

CIDR

IP アドレスのネットワーク部のビット数を「/24」のように明示してアドレスの範囲を表す方式である。Classless Inter-Domain Routing の略である。

関連する章: 「コンピュータネットワーク」

CISC

Complex Instruction Set Computer の略である。1 つの命令で複雑な処理を行える、可変長の命令を持つ命令セットの設計思想である。x86 が代表例である。

関連する章: 「コンピュータの構成」

Cookie

サーバが Set-Cookie ヘッダで指定した名前と値の組をブラウザが保存し、以後のリクエストに付けて送り返す仕組みである。セッション ID の受け渡しに使い、Secure・HttpOnly・SameSite などの属性を指定できる。

関連する章: 「認証とアプリケーションのセキュリティ」

CPU

中央処理装置（Central Processing Unit）である。メモリから命令を読み出して解釈し、演算や制御を行う。

関連する章: 「コンピュータの構成」

CRC

ビット列を多項式とみなし、生成多項式で割った余りを検査用の値とする誤り検出の方法である。巡回冗長検査とも呼ぶ。連続したビットの誤り（バースト誤り）に強く、イーサネットや ZIP、PNG で使われる。

関連する章: 「情報の表現」

DNS

ドメイン名から IP アドレスなどの情報を得る名前解決のための、階層的な分散データベースである。Domain Name System の略である。

関連する章: 「コンピュータネットワーク」

GIL

CPython が持つロックで、同時に 1 つのスレッドだけが Python のバイトコードを実行できるようにする。Global Interpreter Lock の略である。

関連する章: 「並行処理と入出力」

happened-before 関係

分散システムのイベントの因果的な前後関係である。同じプロセスで先に起きたイベント、メッセージの送信とその受信、およびそれらの推移的な組み合わせで定義され、\(a \to b\) と書く。どちら向きにも成り立たない 2 つのイベントは並行であるという。

関連する章: 「分散システム」

HTTP

クライアントがリクエストを送りサーバがレスポンスを返す、Web の基盤となるステートレスなアプリケーション層のプロトコルである。

関連する章: 「コンピュータネットワーク」

I/O 多重化

1 回のシステムコールで多数のファイル記述子を監視し、読み書きできる状態になったものだけを知る仕組みである。select、poll、epoll、kqueue などがある。

関連する章: 「並行処理と入出力」

IEEE 754

浮動小数点数の形式と演算を定めた標準規格である。64 ビットの binary64 は、符号 1 ビット、指数 11 ビット（バイアス 1023）、仮数 52 ビットからなる。

関連する章: 「情報の表現」

IP アドレス

インターネット層で機器を識別するアドレスである。IPv4 では 32 ビット、IPv6 では 128 ビットである。

関連する章: 「コンピュータネットワーク」

JIT コンパイル

プログラムの実行中に、頻繁に実行される部分を機械語にコンパイルして高速化する方式である。JIT は Just-In-Time の略である。

関連する章: 「プログラミング言語処理系」

JWT

JSON で表したクレームを、ヘッダ・ペイロード・署名の 3 つの部分を Base64URL で符号化してピリオドでつないだ形式で受け渡すトークンである。JSON Web Token の略である。署名は改ざんを検出するが、内容は暗号化されない。

関連する章: 「認証とアプリケーションのセキュリティ」

LRU キャッシュ

容量を超えたときに、最も長い間使われていない要素を追い出すキャッシュである。ハッシュ表と双方向連結リストを組み合わせると、取得と追加を平均 \(O(1)\) で行える。

関連する章: 「データ構造」

MAC アドレス

ネットワークインタフェースに割り当てられる 48 ビットのアドレスで、リンク層で同じネットワーク内の送信元と宛先を表す。

関連する章: 「コンピュータネットワーク」

MVCC

行の更新時に古い版を残して新しい版を作り、各トランザクションにスナップショットを読ませる同時実行制御の方式である。読み出しと書き込みが互いを待たない。多版型同時実行制御（Multi-Version Concurrency Control）の略である。

関連する章: 「データベース」

NAT

ルータがパケットの IP アドレス（とポート番号）を書き換え、プライベートアドレスの機器がインターネットと通信できるようにする仕組みである。Network Address Translation の略である。

関連する章: 「コンピュータネットワーク」

NP 完全

NP に属し、かつ NP 困難である問題である。どれか 1 つでも多項式時間で解ければ P = NP となる。SAT、ハミルトン閉路問題などがある。

関連する章: 「計算理論」

NP 困難

NP に属するすべての問題が多項式時間帰着できる問題である。NP に属するとは限らない。

関連する章: 「計算理論」

NTP

ネットワークを通じてコンピュータの時計を合わせるプロトコル（Network Time Protocol）である。UDP の 123 番ポートを使い、要求と応答の 4 つの時刻から時計のずれと往復の遅延を推定する。

関連する章: 「分散システム」

NULL

SQL で値が存在しない、または不明であることを表す特別な印である。NULL との比較は真でも偽でもない UNKNOWN になる（三値論理）。

関連する章: 「データベース」

NX ビット

ページテーブルの属性の 1 つで、そのページの内容を命令として実行することを禁止するものである。スタックやヒープに送り込まれた機械語の実行を防ぐ。OS の機能としては DEP とも呼ばれる。

関連する章: 「認証とアプリケーションのセキュリティ」

OAuth 2.0

利用者がパスワードを渡さずに、アプリケーションに自分のリソースへの限られた範囲のアクセスを許可するための、認可の委譲の枠組みである。認証の仕組みではない。

関連する章: 「認証とアプリケーションのセキュリティ」

OpenID Connect

OAuth 2.0 の上に認証の機能を加えた仕様である。発行者が署名した ID トークンによって、クライアントは利用者が認証されたことを確かめられる。

関連する章: 「認証とアプリケーションのセキュリティ」

OSI 参照モデル

ISO が定めた、ネットワークの機能を物理層からアプリケーション層までの 7 層に分けて整理する枠組みである。

関連する章: 「コンピュータネットワーク」

O 記法

関数の増え方の上界を、定数倍と低次の項を無視して表す記法である。\(f(n) = O(g(n))\) は、\(n\) が十分大きいとき \(f(n)\) が \(g(n)\) の定数倍以下であることを表す。オー記法、ビッグオー記法とも呼ぶ。

関連する章: 「アルゴリズムと計算量」

Raft

理解しやすさを重視して設計された合意アルゴリズムである。任期ごとに過半数の票でリーダを選び、リーダがログを複製して、過半数のノードに保存された項目をコミットする。

関連する章: 「分散システム」

ReDoS

Regular expression Denial of Service の略である。バックトラック型の正規表現エンジンで照合時間が入力長に対して指数的に増えるパターンを悪用し、細工した入力で CPU を占有させる攻撃である。

関連する章: 「計算理論」

RISC

Reduced Instruction Set Computer の略である。命令を単純で規則的な固定長のものに限定し、メモリアクセスをロード命令とストア命令に限る命令セットの設計思想である。ARM や RISC-V が代表例である。

関連する章: 「コンピュータの構成」

SIMD

1 つの命令で複数のデータに同じ演算を行う並列処理の方式である。x86-64 の SSE や AVX、ARM の NEON などの命令がある。

関連する章: 「コンピュータの構成」

SMT

1 つのコアがプログラムカウンタやレジスタを複数組持ち、複数のスレッドの命令を同時に実行する技術である。同時マルチスレッディングとも呼び、実行用の回路を共有するので性能は 2 倍にはならない。

関連する章: 「コンピュータの構成」

SQL

関係データベースを操作するための標準的な言語である。表を定義する DDL と、データを検索・更新する DML などからなる。

関連する章: 「データベース」

SQL インジェクション

利用者の入力を文字列連結で SQL に埋め込むことで、入力の一部が SQL の構文として解釈されてしまう脆弱性である。プレースホルダを使って防ぐ。

関連する章: 「データベース」、「認証とアプリケーションのセキュリティ」

TCP

IP の上で、失われず重複せず順序どおりに届く、信頼性のあるバイト列の通信を提供するトランスポート層のプロトコルである。

関連する章: 「コンピュータネットワーク」

TLB

最近使った仮想アドレスから物理アドレスへの変換結果を保持する、MMU 内の小さなキャッシュである。Translation Lookaside Buffer の略である。

関連する章: 「オペレーティングシステム」

TLS

鍵交換、証明書による認証、認証付き暗号を組み合わせて、通信の機密性・完全性・認証を提供するプロトコルである。HTTPS は HTTP を TLS で保護したものである。Transport Layer Security の略である。

関連する章: 「情報セキュリティと暗号」

TTL

DNS では、リソースレコードをキャッシュしてよい秒数である。IP ヘッダでは、ルータを通過するたびに 1 減らされ、0 になるとパケットが破棄される値を指す。Time To Live の略である。

関連する章: 「コンピュータネットワーク」

UDP

IP にポート番号と簡単な誤り検出を加えただけの、接続を確立しない軽量なトランスポート層のプロトコルである。到達や順序を保証しない。

関連する章: 「コンピュータネットワーク」

Unicode

世界中の文字に一意の番号（コードポイント）を割り当てる文字集合の標準である。範囲は U+0000〜U+10FFFF である。

関連する章: 「情報の表現」

Unicode 正規化

見た目や意味が同じでもコードポイントの列が異なる文字列を、決まった形にそろえる処理である。NFC・NFD・NFKC・NFKD の 4 つの形式がある。

関連する章: 「情報の表現」

Union-Find

要素を互いに重ならないグループに分け、グループの併合（union）と代表の検索（find）を行うデータ構造である。経路圧縮とランクによる併合を組み合わせると、1 回の操作の償却計算量は実用上ほぼ定数になる。素集合データ構造とも呼ぶ。

関連する章: 「データ構造」

UTF-8

Unicode のコードポイントを 1〜4 バイトの可変長のバイト列で表す符号化方式である。ASCII と互換性があり、Web やファイルで事実上の標準となっている。

関連する章: 「情報の表現」

あ行

i ノード

Unix 系のファイルシステムで、ファイルの大きさ、所有者、アクセス権、データの位置などの管理情報を格納する構造である。ファイル名は含まず、名前はディレクトリに記録される。

関連する章: 「オペレーティングシステム」

アセンブリ言語

機械語の各命令を、ニーモニックと呼ばれる英単語の略号で表したプログラミング言語である。アセンブラによって機械語に変換される。

関連する章: 「コンピュータの構成」

アドホック多相

同じ名前に、型ごとに別々の実装を用意する多相である。関数や演算子のオーバーロードが代表例である。

関連する章: 「プログラミング言語処理系」

アトミック操作

メモリ上の値の読み出し、変更、書き込みを、他のスレッドやコアに割り込まれずに不可分に行う操作である。ロックなどの同期の道具の土台になる。

関連する章: 「並行処理と入出力」

アムダールの法則

並列化できる部分の割合を \(p\)、コア数を \(n\) としたとき、速度向上率が \(1/((1-p)+p/n)\) になるという法則である。コアをいくら増やしても \(1/(1-p)\) を超えない。

関連する章: 「コンピュータの構成」

アルゴリズム

問題を解くための明確な手順を有限の長さで記述したものである。どの入力に対しても有限回の手順で終了し、正しい出力を返すことが求められる。

関連する章: 「アルゴリズムと計算量」

暗号学的に安全な擬似乱数生成器

それまでの出力をいくら観測しても次の出力を予測できないように設計された擬似乱数生成器である。CSPRNG と略す。鍵やトークンの生成に使い、Python では secrets モジュールや os.urandom から利用できる。

関連する章: 「情報セキュリティと暗号」

暗号学的ハッシュ関数

原像計算困難性・第 2 原像計算困難性・衝突困難性を満たすハッシュ関数である。SHA-256 が代表例である。

関連する章: 「情報の表現」、「情報セキュリティと暗号」

安定ソート

等しいキーを持つ要素の相対的な順序をソートの前後で保つソートである。Python の sorted() は安定ソートである。

関連する章: 「アルゴリズムと計算量」

イベントループ

入出力やタイマの通知を待ち、通知が来たものに対応する処理を呼ぶことを繰り返すプログラムの構造である。1 つのスレッドで多数の待ちをさばける。

関連する章: 「並行処理と入出力」

入れ子ループ結合

一方の関係の各行について、もう一方の関係の全行と結合条件を比較する結合方式である。時間計算量は \(O(NM)\) だが、任意の結合条件に使える。

関連する章: 「データベース」

インタプリタ

ソースコード、またはそれを変換したバイトコードなどを読み込み、その意味に従って直接実行するプログラムである。

関連する章: 「プログラミング言語処理系」

インデックス

表の特定の列の値から行の位置を素早く求めるための補助的なデータ構造である。検索を速くする代わりに、格納領域を使い書き込みを遅くする。

関連する章: 「データベース」

エントロピー

情報源が出す 1 記号あたりの情報量の期待値で、\(H = -\sum_i p_i \log_2 p_i\) ビットで表す。可逆圧縮で達成できる平均ビット数の下限を与える。

関連する章: 「情報の表現」

オーバーフロー

演算の結果が、そのデータ型で表現できる範囲を超えることである。固定幅の整数では、結果が \(2^n\) を法とする剰余に切り詰められることが多い。

関連する章: 「情報の表現」

オブジェクトファイル

1 つのソースファイルをコンパイルした結果のファイルである。機械語のコードとデータのほか、シンボル表と再配置情報を含む。

関連する章: 「プログラミング言語処理系」

オープンアドレス法

ハッシュ表の衝突の解決方法の 1 つである。すべての要素をバケットの配列に直接格納し、割り当てられたバケットが埋まっていれば決められた規則で別のバケットを探して格納する。

関連する章: 「データ構造」

オペレーティングシステム

論理時計

物理的な時刻を使わず、イベントの因果関係と矛盾しない値を各イベントに割り当てる仕組みである。ランポート時計やベクタ時計がある。

関連する章: 「分散システム」
