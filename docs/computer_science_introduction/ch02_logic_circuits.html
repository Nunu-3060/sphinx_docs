2. 論理回路

前章では、数値や文字がビット列として表されることを見た。この章では、ビット列に対する演算を実際に行う論理回路を学ぶ。まず、真と偽の 2 値を扱う数学であるブール代数を導入し、それを電子回路で実現する論理ゲートを紹介する。次に、ゲートを組み合わせて加算器やマルチプレクサのような組み合わせ回路を作る。最後に、値を記憶できる順序回路として、ラッチ、フリップフロップ、レジスタを扱う。CPU は、ここで学ぶ部品を膨大な数組み合わせて作られている。

2.1. ブール代数

2.1.1. ブール代数とは

19 世紀の数学者ジョージ・ブールは、論理的な推論を代数の計算として表す方法を考案した。これをブール代数（Boolean algebra）と呼ぶ。ブール代数で扱う値は 0（偽）と 1（真）の 2 つだけであり、基本的な演算は次の 3 つである。

  • 論理積（AND）: \(A \cdot B\) と書く。\(A\) と \(B\) がともに 1 のときだけ 1 になる。

  • 論理和（OR）: \(A + B\) と書く。\(A\) と \(B\) の少なくとも一方が 1 なら 1 になる。

  • 否定（NOT）: \(\overline{A}\) と書く。\(A\) が 0 なら 1、1 なら 0 になる。

記号 \(+\) と \(\cdot\) は通常の加算・乗算と同じものを使うが、\(1 + 1 = 1\) となる点が異なる。プログラミング言語の論理演算子（Python の and、or、not、C 系の言語の &&、||、!）や、前章のビット演算子（&、|、~）は、ブール代数の演算をそのまま実装したものである。

ブール代数の式の値を、入力のすべての組み合わせについて列挙した表を真理値表（truth table）と呼ぶ。入力が \(n\) 個なら、真理値表は \(2^n\) 行になる。2 つの式の真理値表がすべての行で一致すれば、それらの式は等しい。

2.1.3. ド・モルガンの法則

特に重要なのが、否定と論理積・論理和の関係を表すド・モルガンの法則（De Morgan's laws）である。

\[\overline{A \cdot B} = \overline{A} + \overline{B}, \qquad \overline{A + B} = \overline{A} \cdot \overline{B}\]

ド・モルガンの法則は、プログラムの条件式を整理するときにも役立つ。例えば if not (is_admin or is_owner): は if not is_admin and not is_owner: と書き換えられる。否定が複数重なった条件はバグの温床になりやすいので、ド・モルガンの法則で否定を内側に移したり、逆にまとめたりして、読みやすい形を選ぶとよい。SQL の WHERE NOT (a = 1 OR b = 2) を書き換えるときにも同じ法則が使える（ただし SQL では NULL を含む 3 値論理になる点に注意が必要である）。

ブール代数の法則を使うと、式を簡単にできる。例えば \(A \cdot B + A \cdot \overline{B}\) は、分配則で \(A \cdot (B + \overline{B})\) となり、補元則と恒等則で \(A\) になる。回路では式の項が少ないほどゲートの数が減るため、論理式の簡単化は回路設計の基本的な作業である。実際の設計では、カルノー図や、コンピュータによる論理合成ツールが使われる。

2.2. 論理ゲート

NAND（NOT AND）は AND の出力を反転したもの、NOR（NOT OR）は OR の出力を反転したものである。XOR（排他的論理和、\(A \oplus B\)）は 2 つの入力が異なるときに 1 になり、\(A \oplus B = A \cdot \overline{B} + \overline{A} \cdot B\) と表せる。XOR は「2 つのビットを足した結果の 1 の位」でもあり、次節の加算器の中心となる。

CMOS では、NOT は 2 個、2 入力の NAND と NOR は 4 個のトランジスタで作れる。一方、AND は NAND の後ろに NOT をつないで作るので 6 個必要になる（OR も同様である）。このため、実際の回路は NAND や NOR を基本として設計されることが多い。

2.2.2. NAND の完全性

NAND ゲートだけを組み合わせると、どんな論理関数も作れる。このように、ある演算の集合だけで任意の論理関数を表現できる性質を機能的完全性（functional completeness）と呼ぶ。

まず、AND、OR、NOT の 3 つで任意の論理関数を作れることを確かめる。真理値表で出力が 1 になる各行について、その行の入力の組み合わせのときだけ 1 になる論理積の項（例えば \(A = 1\)、\(B = 0\) の行なら \(A \cdot \overline{B}\)）を作り、それらをすべて論理和でつなげばよい（出力が 1 になる行が無ければ \(A \cdot \overline{A}\) のような常に 0 の式を使う）。この形を積和標準形と呼ぶ。

次に、AND、OR、NOT がそれぞれ NAND だけで作れることを示す。

  • NOT: \(\overline{A} = \overline{A \cdot A}\) なので、NAND の 2 つの入力に同じ信号をつなげばよい。

  • AND: \(A \cdot B = \overline{\overline{A \cdot B}}\) なので、NAND の出力を上の NOT で反転すればよい。

  • OR: ド・モルガンの法則より \(A + B = \overline{\overline{A} \cdot \overline{B}}\) なので、各入力を NOT で反転してから NAND に入れればよい。

以上から、NAND だけで任意の論理関数を作れる。双対の議論により NOR も機能的完全である。一方、AND と OR だけでは否定を作れないので、機能的完全ではない。

2.3. 組み合わせ回路

出力がその時点の入力だけで決まる回路を組み合わせ回路（combinational circuit）と呼ぶ。組み合わせ回路は記憶を持たず、同じ入力に対して常に同じ出力を返す。プログラムで言えば、副作用の無い純粋な関数にあたる。

2.3.1. 半加算器

1 ビットの数 \(A\) と \(B\) を足すことを考える。結果は 0、1、2（2 進数の 10）のいずれかなので、2 ビットで表せる。下位のビットを和 \(S\)（sum）、上位のビットを桁上げ \(C\)（carry）と呼ぶと、真理値表は次のようになる。

2.3.2. 全加算器

複数桁の加算では、各桁で \(A\)、\(B\) に加えて下の桁からの桁上げ \(C_{in}\) の 3 ビットを足す必要がある。これを行う回路を全加算器（full adder）と呼ぶ。全加算器の出力は次の式で表される。

\[S = A \oplus B \oplus C_{in}, \qquad C_{out} = A \cdot B + C_{in} \cdot (A \oplus B)\]

全加算器は半加算器 2 個と OR ゲート 1 個で作れる。1 個目の半加算器で \(A\) と \(B\) を足し、その和と \(C_{in}\) を 2 個目の半加算器で足す。2 つの半加算器のどちらかで桁上げが生じれば、全体として桁上げが生じる（両方で同時に生じることはない）ので、2 つの桁上げの OR が \(C_{out}\) になる。

2.3.3. リプルキャリー加算器

全加算器を \(n\) 個並べ、各桁の \(C_{out}\) を 1 つ上の桁の \(C_{in}\) につなぐと、\(n\) ビットの加算器ができる。最下位の桁の \(C_{in}\) は 0 にする。桁上げが下の桁から上の桁へ波（ripple）のように伝わっていくことから、これをリプルキャリー加算器（ripple-carry adder）と呼ぶ。

次のサンプルは、NAND ゲートだけを基本要素として、ここまでの回路を Python の関数で組み立てたものである。

ch02_adder.py
 1"""論理ゲートを組み合わせて加算器を作るサンプル。
 2
 3NAND ゲートだけを基本要素とし、そこから NOT・AND・OR・XOR を作る。
 4さらに半加算器・全加算器を組み立て、全加算器を n 個つないだ
 5リプルキャリー加算器で整数の加算を行う。
 6
 7実行方法: python ch02_adder.py
 8関連する章: 第 2 章「論理回路」
 9"""
10
11Bit = int  # 0 または 1 だけを値に取る
12
13
14def nand(a: Bit, b: Bit) -> Bit:
15    """NAND ゲート。両方の入力が 1 のときだけ 0 を出力する。"""
16    return 0 if a == 1 and b == 1 else 1
17
18
19def not_(a: Bit) -> Bit:
20    """NOT ゲート（NAND の 2 入力を同じ信号につなぐ）。"""
21    return nand(a, a)
22
23
24def and_(a: Bit, b: Bit) -> Bit:
25    """AND ゲート（NAND の出力を反転する）。"""
26    return not_(nand(a, b))
27
28
29def or_(a: Bit, b: Bit) -> Bit:
30    """OR ゲート（ド・モルガンの法則: A + B = NOT(NOT A ・ NOT B)）。"""
31    return nand(not_(a), not_(b))
32
33
34def xor(a: Bit, b: Bit) -> Bit:
35    """XOR ゲート（NAND 4 個による構成）。"""
36    n = nand(a, b)
37    return nand(nand(a, n), nand(b, n))
38
39
40def half_adder(a: Bit, b: Bit) -> tuple[Bit, Bit]:
41    """半加算器。(和, 桁上げ) を返す。"""
42    return xor(a, b), and_(a, b)
43
44
45def full_adder(a: Bit, b: Bit, c_in: Bit) -> tuple[Bit, Bit]:
46    """全加算器。半加算器 2 個と OR 1 個で構成し、(和, 桁上げ) を返す。"""
47    s1, c1 = half_adder(a, b)
48    s, c2 = half_adder(s1, c_in)
49    return s, or_(c1, c2)
50
51
52def to_bits(value: int, n: int) -> list[Bit]:
53    """整数を n ビットのリストにする（添字 0 が最下位ビット）。"""
54    return [(value >> i) & 1 for i in range(n)]
55
56
57def from_bits(bits: list[Bit]) -> int:
58    """ビットのリスト（添字 0 が最下位ビット）を整数に戻す。"""
59    return sum(bit << i for i, bit in enumerate(bits))
60
61
62def ripple_carry_add(a: int, b: int, n: int) -> tuple[int, Bit]:
63    """n ビットのリプルキャリー加算器。(和, 最上位からの桁上げ) を返す。"""
64    carry: Bit = 0
65    result: list[Bit] = []
66    for a_i, b_i in zip(to_bits(a, n), to_bits(b, n)):
67        s, carry = full_adder(a_i, b_i, carry)  # 桁上げを次の桁へ渡す
68        result.append(s)
69    return from_bits(result), carry
70
71
72def main() -> None:
73    """ゲートと全加算器の真理値表、および加算の例を表示する。"""
74    print("A B | AND OR XOR NAND")
75    for a in (0, 1):
76        for b in (0, 1):
77            print(f"{a} {b} |  {and_(a, b)}   {or_(a, b)}   {xor(a, b)}"
78                  f"    {nand(a, b)}")
79
80    print()
81    print("A B Cin | S Cout")
82    for a in (0, 1):
83        for b in (0, 1):
84            for c in (0, 1):
85                s, c_out = full_adder(a, b, c)
86                print(f"{a} {b}  {c}  | {s}  {c_out}")
87
88    print()
89    n = 8
90    for a, b in [(23, 42), (100, 155), (200, 100)]:
91        total, carry = ripple_carry_add(a, b, n)
92        print(f"{a:08b} + {b:08b} = {total:08b} 桁上げ={carry}"
93              f"  ({a} + {b} = {total}"
94              f"{'、桁あふれ' if carry else ''})")
95        assert total + (carry << n) == a + b
96
97
98if __name__ == "__main__":
99    main()

19 行目では、8 ビットの範囲を超えた結果の桁上げが最上位の全加算器から出ている。これは前章で述べた符号なし整数のオーバーフローであり、CPU ではこの桁上げがキャリーフラグとして記録される。

この加算器は減算にも使える。前章で見たとおり、\(a - b = a + (-b)\) であり、2 の補数の \(-b\) は「\(b\) の全ビットを反転して 1 を足す」ことで得られる。そこで、\(b\) の各ビットを XOR ゲートで反転し（XOR の一方の入力を 1 にすると NOT と同じ働きをする）、最下位の \(C_{in}\) を 1 にすれば、同じ回路で減算ができる。また、符号付き整数のオーバーフローは、最上位の桁に入る桁上げと最上位の桁から出る桁上げが異なる場合に起こるので、その 2 つの XOR で検出できる。

注釈

リプルキャリー加算器では、最上位の桁の結果が確定するまで、桁上げが最下位から順に伝わるのを待たなければならない。1 桁あたりの遅延を一定とすると、\(n\) ビットの加算にかかる時間は \(n\) に比例する。実際の CPU では、各桁で桁上げが「生成」される条件（\(g_i = a_i \cdot b_i\)）と「伝搬」される条件（\(p_i = a_i \oplus b_i\)）から、各桁への桁上げ \(c_{i+1} = g_i + p_i \cdot c_i\) を並列に先読みする桁上げ先見加算器（carry-lookahead adder）などが使われ、先読みを多段に組み合わせることで遅延を \(\log n\) に比例する程度まで短くしている。回路の量を増やして速度を得る、ハードウェア設計の典型的なトレードオフである。

2.3.4. マルチプレクサ

マルチプレクサ（multiplexer、MUX）は、複数の入力の中から、選択信号で指定された 1 つを出力に通す回路である。最も単純な 2 入力のマルチプレクサは、データ入力 \(D_0\)、\(D_1\) と選択信号 \(S\) を持ち、\(S = 0\) なら \(D_0\) を、\(S = 1\) なら \(D_1\) を出力する。論理式は次のとおりである。

\[Y = \overline{S} \cdot D_0 + S \cdot D_1\]

これはプログラムの条件式 y = d1 if s else d0 を回路にしたものと考えられる。選択信号を \(k\) ビットにすれば、\(2^k\) 個の入力から 1 つを選べる。逆に、1 つの入力を選択信号で指定した出力に振り分ける回路をデマルチプレクサ、\(k\) ビットの入力から \(2^k\) 本のうち 1 本だけを 1 にする回路をデコーダと呼ぶ。

マルチプレクサは CPU の中で至る所に使われている。例えば、ALU（演算装置）の入力として、どのレジスタの値を使うかを選ぶのはマルチプレクサである。ALU 自体も、加算器、AND、OR などの回路で同時にすべての演算を計算しておき、命令で指定された演算の結果をマルチプレクサで選んで出力する、という構成で作れる。メモリのアドレスから記憶素子を 1 つ選ぶのはデコーダの役割である。次章ではこれらの部品が CPU の中でどう組み合わされるかを見る。

2.4. 順序回路

組み合わせ回路は記憶を持たないため、計算の途中結果を保持できない。過去の入力に依存した状態を持つ回路を順序回路（sequential circuit）と呼ぶ。順序回路は、ゲートの出力を入力に戻す（フィードバックする）ことで状態を保持する。

2.4.1. SR ラッチ

最も基本的な記憶回路が SR ラッチである。2 つの NOR ゲートの出力を互いの入力につなぐ（たすき掛けにする）と、セット入力 \(S\) とリセット入力 \(R\)、出力 \(Q\) とその反転 \(\overline{Q}\) を持つ回路ができる。このように、1 ビットの状態を保持する回路のうち、入力の変化に直ちに反応するものをラッチ（latch）と呼ぶ。SR ラッチの動作は次のとおりである。

\(S = 1\) にすると \(Q\) が 1 になり、その後 \(S\) を 0 に戻しても、フィードバックによって \(Q = 1\) が保たれる。同様に \(R = 1\) で \(Q\) が 0 になり、\(R\) を戻しても 0 が保たれる。入力が両方 0 のとき、出力は直前の状態によって決まる。これが「記憶」である。同じ入力に対して状態によって異なる出力を返す点が、組み合わせ回路との本質的な違いである。

2.4.2. D ラッチと D フリップフロップ

SR ラッチには使用禁止の入力があり、扱いにくい。そこで、データ入力 \(D\) と書き込み許可信号 \(E\) を持ち、\(E = 1\) の間は \(Q\) が \(D\) に追従し、\(E = 0\) になるとその時点の値を保持する回路が作られた。これを D ラッチと呼ぶ。D ラッチは、SR ラッチの前段に「\(S = D \cdot E\)、\(R = \overline{D} \cdot E\)」となるゲートを置くことで作れ、禁止された入力の組み合わせは起こらない。

D ラッチは \(E = 1\) の間ずっと入力を通してしまうため、出力を回路の中で巡らせて入力に戻すと、1 回の書き込み許可の間に値が何度も変わってしまう。この問題を避けるため、許可信号（後述のクロック）が 0 から 1 に変わる瞬間（立ち上がりエッジ）の \(D\) の値だけを取り込み、それ以外のときは値を保持する回路が使われる。これが D フリップフロップ（flip-flop）である。D フリップフロップは、例えば 2 つの D ラッチを直列につなぎ、許可信号を互いに反転させて与えることで作れる（マスタスレーブ方式）。前段が値を取り込んでいる間は後段が閉じ、後段が開くときには前段が閉じるので、出力が変わるのはエッジの瞬間だけになる。

2.4.3. クロック

順序回路の多くは、一定の周期で 0 と 1 を繰り返すクロック（clock）信号に同期して動作する。回路全体のフリップフロップは、クロックの立ち上がりエッジで一斉に新しい値を取り込む。エッジとエッジの間に、組み合わせ回路がフリップフロップの出力を入力として次の値を計算し、次のエッジでその結果が取り込まれる。このように、すべての状態変化をクロックに揃える設計を同期式設計と呼ぶ。

クロックの周期は、フリップフロップの間にある組み合わせ回路のうち、最も遅い経路（クリティカルパス）の遅延より長くなければならない。周期が短すぎると、計算が終わる前に途中の値が取り込まれてしまう。クロック周波数 3 GHz の CPU では 1 周期が約 0.33 ナノ秒しかなく、その間に信号が通過できるゲートの段数は限られる。リプルキャリー加算器のように遅い回路を避け、桁上げ先見加算器のような並列な回路を使うのはこのためである。また、周波数を上げると消費電力と発熱が増えるため、2000 年代半ば以降は周波数の向上が頭打ちになり、複数のコアで性能を上げる方向に移った。

2.4.4. レジスタ

D フリップフロップを \(n\) 個並べ、共通のクロックを与えると、\(n\) ビットの値を記憶する回路ができる。これをレジスタ（register）と呼ぶ。64 ビットの CPU には、64 個の D フリップフロップからなるレジスタが多数含まれている。

レジスタの入力にマルチプレクサを置き、「新しい値を書き込むか、今の値を保持するか」を選べるようにすると、書き込み許可付きのレジスタになる。さらに、レジスタの出力と定数 1 を加算器に入れ、加算器の出力をレジスタの入力に戻すと、クロックのたびに値が 1 ずつ増えるカウンタができる。次章で扱うプログラムカウンタは、このようなカウンタに、分岐先のアドレスを書き込む機能を加えたものである。

組み合わせ回路と順序回路を組み合わせたこの構成は、「現在の状態と入力から、次の状態と出力を決める」という有限状態機械（「計算理論」で扱う）の考え方そのものである。CPU は巨大な有限状態機械であり、その状態はレジスタとメモリの内容である。

注釈

ここで述べた回路は、実際の設計では Verilog や VHDL などのハードウェア記述言語（HDL: Hardware Description Language）で記述され、論理合成ツールによってゲートの接続に変換される。FPGA（Field-Programmable Gate Array）を使うと、記述した回路を書き換え可能なチップ上で動かせる。ソフトウェアエンジニアが論理回路を直接設計する機会は少ないが、FPGA を使ったネットワーク機器や機械学習の推論装置のように、ソフトウェアとハードウェアの境界は身近になりつつある。

2.5. まとめ

  • ブール代数は 0 と 1 の 2 値に対する代数であり、AND、OR、NOT を基本演算とする。ド・モルガンの法則は、否定と AND・OR を入れ替える法則で、条件式の書き換えにも使える。

  • 論理ゲートはブール代数の演算を電子回路で実現したものである。NAND だけで任意の論理関数を作れる（機能的完全性）。

  • 組み合わせ回路は、出力が現在の入力だけで決まる回路である。半加算器、全加算器、リプルキャリー加算器、マルチプレクサがその例であり、2 の補数を使えば同じ加算器で減算もできる。

  • 順序回路は、フィードバックによって状態を保持する回路である。ラッチ、フリップフロップ、レジスタがその例であり、クロックに同期して状態を更新する。

  • クロック周期は組み合わせ回路の最も遅い経路で制約され、回路の並列化による高速化と回路量の増加の間にはトレードオフがある。

論理回路から CPU を組み立てる過程は [CODE] に平易に、[PH] の付録に詳しく解説されている。次の「コンピュータの構成」では、ここで学んだ部品から CPU とメモリがどのように構成されるかを見ていく。
