8. ポインターと参照

本章では、Python にはない概念であるポインターと、C++ の参照を説明します。

8.1. メモリとアドレス

プログラムが扱う値は、すべてメモリ上に置かれます。メモリの各位置には、アドレスと呼ばれる番号が付いています。

C++ のプログラムが使うメモリ領域には、主にスタック領域とヒープ領域があります。

領域

置かれるもの

寿命

スタック領域

関数内で宣言した変数（ローカル変数）

宣言したブロックを抜けると自動的に破棄される

ヒープ領域

プログラムの実行中に動的に確保したオブジェクト

明示的に解放するまで残る（解放の方法は「リソース管理」で説明する）

Python（標準の実装である CPython）では、すべてのオブジェクトがヒープ領域に置かれ、不要になると自動的に解放されます。C++ では、多くの変数がスタック領域に置かれ、ブロックを抜けると破棄されます。このように、変数が有効な期間を寿命と呼びます。

8.2. Python の変数との違い

Python の変数は、オブジェクトに付けた名前（ラベル）です。代入は、名前とオブジェクトを結び付ける操作であり、オブジェクトはコピーされません。

a = [1, 2, 3]
b = a          # b は a と同じリストを指す
b.append(4)
print(a)       # [1, 2, 3, 4]

一方、C++ の変数は、値そのものを格納する領域です。代入や初期化では、値がコピーされます。Python と同じように同じオブジェクトを指したい場合は、参照を使います。

examples/ch08/copy.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> a = {1, 2, 3};
    std::vector<int> b = a;  // 要素がすべてコピーされる
    b.push_back(4);
    std::cout << a.size() << ' ' << b.size() << '\n';  // 3 4

    std::vector<int>& c = a;  // c は a の別名
    c.push_back(4);
    std::cout << a.size() << ' ' << c.size() << '\n';  // 4 4
    return 0;
}
実行結果
3 4
4 4

b は a のコピーなので、b に要素を追加しても a は変化しません。c は a の参照なので、c に要素を追加すると a も変化します。

8.3. ポインター

ポインターは、アドレスを格納する変数です。int* は「int 型の値を指すポインター」という型を表します。

記法

意味

&x

変数 x のアドレスを取得する（アドレス演算子）

*p

ポインター p が指す先の値を読み書きする（間接参照演算子）

p->member

ポインター p が指すオブジェクトのメンバーにアクセスする。(*p).member と同じ意味

nullptr

何も指していないことを表す値
examples/ch08/pointers.cpp
#include <iostream>

int main() {
    int x = 10;
    int* p = &x;  // x のアドレスを p に格納する

    std::cout << *p << '\n';  // 10
    *p = 20;                  // p が指す先（x）を変更する
    std::cout << x << '\n';   // 20

    int& r = x;  // r は x の別名
    r = 30;
    std::cout << x << '\n';  // 30

    int* q = nullptr;  // 何も指していない
    if (q == nullptr) {
        std::cout << "q is null\n";
    }
    return 0;
}
実行結果
10
20
30
q is null

& と * は、宣言で使う場合と式で使う場合で意味が異なります。宣言の int* p の * は「ポインター型」を、式の *p の * は「間接参照」を表します。同様に、宣言の int& r の & は「参照型」を、式の &x の & は「アドレスの取得」を表します。

警告

nullptr のポインターを間接参照すると、未定義動作になります。多くの場合、プログラムは異常終了します。ポインターを使う前に nullptr でないことを確認してください。

8.4. 参照

参照は、既存の変数に付ける別名です。参照を通じて値を変更すると、元の変数が変更されます。参照は「関数」で説明した参照渡しにも使われています。

ポインターと参照の違いを以下に示します。

観点

ポインター

参照

何も指さない状態

可能（nullptr）

不可能（宣言時に必ず初期化する）

指す対象の変更

可能

不可能

使用時の記法

*p で間接参照する

通常の変数と同じ

参照のほうが制約が強い分、誤りが起こりにくくなります。関数の引数などで別の変数を指したい場合は、まず参照を使い、「何も指さない」状態が必要な場合にだけポインターを使ってください。

8.5. ダングリングポインター

寿命が終わった変数を指すポインターや参照を、ダングリングポインター（ダングリング参照）と呼びます。これらを使うと未定義動作になります。

よくある誤りは、関数内のローカル変数への参照を返すことです。

int& bad_function() {
    int x = 10;
    return x;   // x は関数を抜けると破棄されるため、破棄された変数への参照を返してしまう
}

Python では、オブジェクトは参照されている間は破棄されないため、このような問題は起こりません。C++ では、ポインターや参照が指す先の寿命をプログラマーが意識する必要があります。関数から値を返す場合は、参照ではなく値を返してください。
