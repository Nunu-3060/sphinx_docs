4. 基本文法

本章では、C++ のプログラムを構成する基本的な要素を説明します。

4.1. main 関数

Python のスクリプトは、ファイルの先頭から順に実行されます。一方、C++ のプログラムは main 関数から実行が始まり、main 関数の終わりで終了します。関数の外に処理を書くことはできず、関数の外に書けるのは変数、関数、クラスなどの宣言や定義だけです。

int main() {
    // ここに処理を書く
    return 0;
}

main 関数の戻り値は、プログラムの終了コードとして OS に返されます。0 は正常終了を表します。main 関数に限り return 0; を省略でき、省略した場合は 0 を返したものとみなされます。

Python の if __name__ == "__main__": に書く処理が、C++ の main 関数に書く処理に相当すると考えると分かりやすいでしょう。

4.2. 文とブロック

C++ では、文の終わりにセミコロン ; を書きます。複数の文は波括弧 { } で囲んでブロックにします。Python ではインデントがブロックを表しますが、C++ ではインデントに文法上の意味はありません。

examples/ch04/structure.cpp
// 1 行コメント
/* 複数行の
   コメント */
#include <iostream>

int main() {
    std::cout << "first line" << '\n';
    std::cout << "second line" << '\n';
    return 0;
}

インデントに意味がないため、すべてを 1 行に書いてもコンパイルできます。しかし、読みやすさのために、ブロックの中はインデントを揃えて書きます。インデントの幅などの書式については「コーディング規約」で説明します。

警告

セミコロンの書き忘れは、C++ を書き始めたばかりのときに最も多い誤りの 1 つです。エラーメッセージは、セミコロンを書き忘れた行ではなく、その次の行を指す場合があります。

4.3. コメント

// から行末まではコメントになります。これは Python の # に相当します。また、/* と */ で囲んだ範囲は、複数行にわたってコメントになります。

Python の # は C++ ではコメントではなく、#include などのプリプロセッサーディレクティブを表す記号である点に注意してください。

4.4. 標準入出力

C++ では、std::cout に << 演算子で値を渡して出力し、std::cin から >> 演算子で値を読み込みます。どちらも <iostream> ヘッダーで提供されます。

examples/ch04/io.cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "Name: ";
    std::getline(std::cin, name);  // 1 行を読み込む

    int age = 0;
    std::cout << "Age: ";
    std::cin >> age;               // 整数として読み込む

    std::cout << "Hello, " << name << " (" << age << ")" << '\n';
    return 0;
}
実行結果（Taro Yamada と 20 を入力した場合）
Name: Taro Yamada
Age: 20
Hello, Taro Yamada (20)

Python の print 関数と input 関数との対応を以下に示します。

Python

C++

print("x =", x)

std::cout << "x = " << x << '\n';

print("abc", end="")

std::cout << "abc";

s = input()

std::getline(std::cin, s);

n = int(input())

std::cin >> n;

print 関数と異なり、std::cout は自動的に改行したり、値の間に空白を入れたりしません。改行するには '\n' または std::endl を出力します。

std::cin >> 変数 は、空白や改行で区切られた 1 つの値を読み込み、変数の型に合わせて変換します。空白を含む 1 行全体を読み込むには std::getline を使います。

4.5. 名前空間

std::cout の std:: は、標準ライブラリの名前空間 std に属することを表します。名前空間は、名前の衝突を避けるために識別子をグループにまとめる仕組みです。Python では、モジュールごとに名前が分かれており、math.sqrt のようにモジュール名を付けて呼び出します。C++ の名前空間も、これと同じように名前を区別する役割を持ちます。

名前空間は namespace キーワードで自分で定義することもできます。

examples/ch04/namespace.cpp
#include <iostream>

namespace geometry {

const double pi = 3.14159;

double circle_area(double r) {
    return pi * r * r;
}

}  // namespace geometry

int main() {
    std::cout << geometry::circle_area(2.0) << '\n';
    return 0;
}
実行結果
12.5664

using namespace std; と書くと、std:: を省略して cout と書けるようになります。これは Python の from math import * に相当し、どの名前がどこから来たのかが分かりにくくなります。特にヘッダーファイルに書くと、そのヘッダーファイルを取り込むすべてのファイルに影響するため、ヘッダーファイルでは使わないでください。本資料では std:: を省略せずに書きます。
