12. テンプレート

本章では、型に依存しない処理を記述するためのテンプレートを説明します。

12.1. 関数テンプレート

Python では、ダックタイピングにより、1 つの関数でさまざまな型の値を扱えます。

def max_value(a, b):
    return a if a > b else b

max_value(3, 7)                # 整数
max_value("apple", "banana")   # 文字列

C++ の関数は引数の型を明記する必要があるため、このままでは型ごとに関数を定義しなければなりません。テンプレートを使うと、型を引数として受け取る関数を 1 つ定義するだけで済みます。

examples/ch12/templates.cpp
#include <iostream>
#include <string>

template <typename T>
T max_value(T a, T b) {
    return (a > b) ? a : b;
}

template <typename T>
class Box {
public:
    Box(T value) : value_(value) {}
    T get() const { return value_; }

private:
    T value_;
};

int main() {
    std::cout << max_value(3, 7) << '\n';      // 7
    std::cout << max_value(2.5, 1.5) << '\n';  // 2.5
    std::cout << max_value(std::string("apple"), std::string("banana")) << '\n';  // banana

    Box<int> b1(42);
    Box<std::string> b2("hello");
    std::cout << b1.get() << ' ' << b2.get() << '\n';  // 42 hello
    return 0;
}
実行結果
7
2.5
banana
42 hello

template <typename T> は、T という名前の型を引数として受け取ることを表します。max_value(3, 7) と呼び出すと、コンパイラーは引数の型から T を int と推論し、int 用の max_value を生成します。このように、テンプレートでは呼び出しに使われた型ごとに、コンパイラーが関数を生成します。

Python のダックタイピングとの違いは、型の検査がコンパイル時に行われることです。例えば > で比較できない型を渡すと、実行時ではなくコンパイル時にエラーになります。

また、max_value(3, 2.5) のように異なる型の引数を渡すと、T を 1 つに決められないため、コンパイルエラーになります。この場合は max_value<double>(3, 2.5) のように、型を明示して呼び出します。

注釈

2 つの値の大きいほうを返す処理は、標準ライブラリに std::max（<algorithm> ヘッダー）として用意されています。実際のプログラムでは std::max を使ってください。

12.2. クラステンプレート

クラスもテンプレートにできます。前述の templates.cpp の Box は、任意の型の値を 1 つ格納するクラステンプレートです。クラステンプレートを使うときは、Box<int> のように < > の中に型を指定します。

これまでに使ってきた std::vector<int> や std::map<std::string, int> も、クラステンプレートです。std::vector という 1 つの定義から、int を格納する std::vector<int> や std::string を格納する std::vector<std::string> が生成されます。

テンプレートの定義は、原則としてヘッダーファイルに書きます。テンプレートは使われる型が決まった時点で生成されるため、使う側のソースファイルから定義が見えている必要があるからです。

12.3. コンセプト

テンプレートに想定外の型を渡すと、テンプレートの内部でエラーが発生し、長く分かりにくいエラーメッセージが表示されることがあります。C++20 のコンセプトを使うと、テンプレート引数が満たすべき条件を記述できます。

examples/ch12/concepts.cpp
// C++20
#include <concepts>
#include <iostream>

template <typename T>
concept Number = std::integral<T> || std::floating_point<T>;

template <Number T>
T twice(T x) {
    return x * 2;
}

int main() {
    std::cout << twice(21) << '\n';   // 42
    std::cout << twice(1.5) << '\n';  // 3
    // twice("abc");  // エラー: const char* は Number を満たさない
    return 0;
}
実行結果
42
3

Number は、「整数型または浮動小数点数型である」という条件を表すコンセプトです。template <Number T> と書くと、T は Number を満たす型に限られます。条件を満たさない型を渡すと、「制約を満たさない」という分かりやすいエラーメッセージが表示されます。

コンセプトは、Python の型ヒントで typing.Protocol などを使い、引数に求める性質を表す考え方に似ています。ただし、Python の型ヒントは実行時には検査されないのに対し、C++ のコンセプトはコンパイラーによって必ず検査されます。
