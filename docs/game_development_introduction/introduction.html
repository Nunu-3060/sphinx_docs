1. はじめに

1.1. 本書の目的

ゲームを作ってみたいと考えたエンジニアが最初に戸惑うのは、プログラミングそのものよりも「何から始め、どの順に進め、どこで完成とするか」が見えないことである。業務のソフトウェア開発には要件定義・設計・実装・テスト・リリースという見慣れた流れがあるが、ゲーム制作には「面白さ」という測りにくい要件があり、遊んでみるまで良し悪しが分からないという独特の難しさがある。

本書の目的は、個人または数人の小規模チームで 2D ゲームを 1 本作り、公開するまでの流れを一通り示すことである。各工程で何を決め、何を作り、何に注意すればよいかを押さえておけば、より大きなゲームや別のゲームエンジンに取り組む際にも応用できる。

1.2. 対象読者と前提知識

本書は次のような読者を想定している。

  • Python で、クラス・関数・リストや辞書などを使ったプログラムを書ける。

  • コマンドライン（PowerShell やターミナル）で、パッケージのインストールやスクリプトの実行ができる。

  • ゲームを作った経験は無いか、ほとんど無い。

ゲーム固有の知識（ゲームループ、当たり判定、スプライトなど）は本文で説明する。数学は、三角関数とベクトルの初歩が分かれば十分である。
