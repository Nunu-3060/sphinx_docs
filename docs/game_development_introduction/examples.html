実行に必要なライブラリー

ライブラリー

使用するファイル

pygame-ce

step01_window.py から step07_polish.py まで、test_breakout.py

Pillow

make_sprites.py
リスト 1 ライブラリーのインストール
1py -m pip install pygame-ce pillow

コードの検査

サンプルコードは、ダウンロードしたファイルと setup.cfg を同じフォルダーに置き、次のコマンドで検査できる。

リスト 2 サンプルコードの検査とテスト
1py -m pip install flake8 mypy
2py -m flake8
3py -m mypy .
4py -m unittest test_breakout
