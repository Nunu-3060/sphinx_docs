用語集

本資料で使う主な用語をまとめる。用語は英字、五十音の順に並べている。本文中の用語のリンクからこのページに移動できる。各用語の詳しい説明は、末尾に示した章を参照のこと。

英字

CIE XYZ

CIE（国際照明委員会）が 1931 年に定めた表色系。人間が見分けられる全ての色を 3 つの値 X、Y、Z で表す。Y は輝度に比例する。色空間どうしの変換の中継点として使われる。（色空間）

CIELAB

CIE が 1976 年に定めた色空間。明度 \(L^*\) と、2 つの色度の軸 \(a^*\)、\(b^*\) で色を表す。座標の距離が見た目の差にほぼ比例するように作られている。\(L^*a^*b^*\) 表色系ともいう。（色空間）

CMYK

印刷に使うシアン（C）、マゼンタ（M）、イエロー（Y）、黒（K）の 4 色のインキ、またはその網点の面積率による色の指定。同じ値でも、印刷条件によって色が変わる。（印刷物の配色）

HSV

色を色相（H）、彩度（S）、明度（V）の 3 つの値で表す方法。sRGB の値から簡単な計算で求められるが、V は人間が感じる明るさを表さない。似た方法に HSL がある。（色空間）

ICC プロファイル

機器や印刷条件ごとの色の特性を記述したファイル。機器の値（RGB や CMYK）と、機器に依存しない色空間（CIELAB など）の値の対応を表す。カラーマネジメントに使う。（印刷物の配色）

OKLab

Björn Ottosson が 2020 年に発表した色空間。明度 \(L\) と 2 つの色度の軸 \(a\)、\(b\) で色を表す。CIELAB より色相のずれが小さく、見た目に均等な配色やグラデーションの作成に向いている。（色空間）

OKLCH

OKLab の \((a, b)\) 平面を極座標で表したもの。明度 \(L\)、彩度 \(C\)、色相角 \(h\) で色を指定できる。（色空間）

sRGB

ディスプレイと Web で標準的に使われる色空間。国際規格 IEC 61966-2-1 で定められている。値はガンマ補正されており、光の強さに比例しない。（色空間）

WCAG

W3C が定めた Web のアクセシビリティの指針（Web Content Accessibility Guidelines）。コントラスト比や色の使用についての達成基準を含む。（アクセシビリティ）

あ行

アクセントカラー

目立たせたい部分にだけ、小さな面積で使う色。配色の面積比の目安では、全体の 5% 程度とされる。（配色の基本）

網点

印刷で濃淡を表現するための、インキを付ける小さな点。点の大きさや密度で濃さを変える。（印刷物の配色）

か行

加法混色

光を重ねて色を作る方法。赤、緑、青を三原色とし、混ぜるほど明るくなる。ディスプレイが使う。（色の基礎）

ガマットマッピング

色域の外の色を、色域の中の色に置き換える処理。本資料では、明度と色相を保ったまま彩度を下げる方法を使う。（色空間）

カラースケール

1 つの基準の色から、明るさの異なる色を段階的に並べたもの。UI の配色では、50 から 900 までの段階の名前を付けることが多い。（パレットの作り方、実践: UI の配色設計）

カラーマップ

データの値を色に対応させる規則。連続、発散、カテゴリの 3 種類がある。（データ可視化の配色）

ガンマ補正

色の値と光の強さの関係を非線形にする変換。sRGB では、人間の目の感度に合わせて、暗い側に多くの段階を割り当てている。（色空間）

減法混色

光を吸収する色材を重ねて色を作る方法。シアン、マゼンタ、イエローを三原色とし、混ぜるほど暗くなる。印刷や絵の具が使う。（色の基礎）

コントラスト比

2 色の相対輝度から求める、明るさの差の指標。1 から 21 までの値を取る。WCAG では、通常の文字に 4.5 以上を求めている。（アクセシビリティ）

さ行

彩度

色の鮮やかさ。彩度が低いほど灰色に近づく。色の三属性の 1 つ。OKLCH では \(C\) で表す。（色の基礎）

色域

ある色空間や機器で表現できる色の範囲。sRGB の色域と印刷の色域は一致しない。（色空間、印刷物の配色）

色差

2 色の見た目の差を表す値。CIELAB の 2 色の間のユークリッド距離 \(\Delta E^*_{ab}\) がよく使われる。（色空間）

色相

赤、黄、緑、青のような色味の種類。色の三属性の 1 つ。（色の基礎）

色相環

色相を環状に並べたもの。HSV、伝統的な絵の具（RYB）、PCCS など種類があり、種類によって補色の組が変わる。（配色の基本）

条件等色

波長の成分が異なる 2 つの光が、同じ色に見える現象。メタメリズムともいう。（色の基礎）

錐体

網膜にあり、明るい場所で色を感じ取る細胞。S、M、L の 3 種類がある。（色の基礎）

相対輝度

線形な sRGB の値に重みを掛けて足した、明るさの値。黒が 0、白が 1 である。コントラスト比の計算に使う。（アクセシビリティ）

た行

同時対比

隣り合う色の影響を受けて、色が実際とは違って見える現象。明度対比、色相対比、彩度対比がある。（色の基礎）

トークン

UI の配色で、色の役割に付けた名前（text、primary など）と、その役割に割り当てた色。部品はトークンを通して色を参照する。（実践: UI の配色設計）

特色

CMYK の掛け合わせではなく、目的の色に調合したインキ。ロゴの色などを安定して再現するために使う。（印刷物の配色）

トーン

明度と彩度を組み合わせた色の調子。同じトーンの色は、色相が違っても似た印象を与える。（配色の基本）

ドットゲイン

印刷で、インキのにじみによって網点が指定より大きくなる現象。中間調が暗く刷り上がる。（印刷物の配色）

は行

白色点

色空間で白とみなす光の色。sRGB と本資料の CIELAB の計算では、昼光に近い D65 を使う。（色空間）

ベースカラー

背景など、最も広い面積に使う色。配色の面積比の目安では、全体の 70% 程度とされる。（配色の基本）

補色

色相環の上で向かい合う位置にある 2 色。互いの色味を最も強く引き立て合う。（配色の基本）

ま行

明度

色の明るさ。色の三属性の 1 つ。本資料では、人間が感じる明るさの尺度として、OKLab の \(L\) や CIELAB の \(L^*\) を使う。HSV の V とは異なる。（色の基礎、色空間）

メインカラー

全体の印象を決める主役の色。配色の面積比の目安では、全体の 25% 程度とされる。（配色の基本）

面積効果

同じ色でも、塗る面積が大きいほど明るく、鮮やかに見える現象。（色の基礎）
