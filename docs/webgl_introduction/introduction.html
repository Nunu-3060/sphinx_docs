はじめに

本書の目的

WebGL を使うと、プラグインを導入しなくても、Web ブラウザー上で GPU を使った高速な 2D・3D 描画ができます。three.js などのライブラリを使えば手軽に 3D シーンを作れますが、その内部で何が起きているかを知らないと、表示がおかしいときの原因究明や性能の改善が難しくなります。

本書は、ライブラリを使わずに WebGL 2.0 の API を直接呼び出してプログラムを書くことで、GPU による描画の仕組みを理解することを目的とします。行列の計算も自分で実装します。

対象読者と前提知識

本書は次のようなエンジニアを対象とします。

  • JavaScript の基本的な文法（関数、配列、オブジェクト、アロー関数、テンプレートリテラル、async / await）を理解しています。

  • HTML と CSS の基礎を知っています。

  • ブラウザーの開発者ツールでコンソールを確認できます。

3D グラフィックスの予備知識は前提としません。必要な数学（ベクトルと行列）は第 6 章で説明します。

動作環境

本書のサンプルは、次の環境で動作を確認しています。

  • Google Chrome、Microsoft Edge（Windows 11）

WebGL 2.0 は、現在の主要なブラウザー（Chrome、Edge、Firefox、Safari 15 以降）で利用できます。お使いのブラウザーが対応しているかどうかは、第 2 章のサンプル 01_check_support.html で確認できます。

サンプルコードの使い方

各章には、単独で動作するサンプルを用意しています。サンプルは 1 つの HTML ファイルに JavaScript とシェーダーをすべて含んでいるので、ファイルを 1 つダウンロードするだけで動作します。ただし、テクスチャ画像を使うサンプル（10_texture.html と 17_scene.html）は、画像ファイル（assets フォルダー）も必要です。

サンプルは次の 3 通りの方法で利用できます。

  • 各章の「サンプル」の節にある「ブラウザーで開く」のリンクから、その場で実行します。

  • 「ダウンロード」のリンクから、ファイルを個別にダウンロードします。

  • サンプルコード一覧から、すべてのサンプルを zip ファイルで一括ダウンロードします。

ダウンロードしたサンプルのうち、テクスチャ画像を使うものは、HTML ファイルを直接開くとブラウザーのセキュリティー制限によって動作しません。第 2 章で説明するローカルサーバーを使って開いてください。

表記の規約

本書では、次の表記を使います。

  • コードやファイル名、API の名前は gl.drawArrays のように等幅フォントで示します。

  • gl は WebGL 2.0 のコンテキスト（WebGL2RenderingContext）を表す変数です。

  • GLSL の変数名には、種類を表す接頭辞を付けます。a_ は頂点属性（attribute）、u_ は uniform 変数、v_ は頂点シェーダーからフラグメントシェーダーへ渡す変数です。

  • 用語は用語集の表記に統一します。初めて出てくる重要な用語には用語集へのリンクを付けます。
