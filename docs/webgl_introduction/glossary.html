用語集

本書で使う主な用語をまとめます。英字で始まる用語をアルファベット順に、続いて日本語の用語を五十音順に並べています。

CORS

Cross-Origin Resource Sharing。異なるオリジンのリソースの利用を、サーバーが許可するための仕組み。異なるオリジンの画像をテクスチャに使うには、サーバーが CORS に対応している必要があります。

GLSL

OpenGL Shading Language。シェーダーを記述するための C 言語に似た言語。WebGL 2.0 では GLSL ES 3.00 を使います。

OpenGL ES

組み込み機器向けの 3D グラフィックス API。WebGL 1.0 は OpenGL ES 2.0 を、WebGL 2.0 は OpenGL ES 3.0 をもとにしています。

sRGB

一般的なディスプレイや画像ファイルで使われる色空間。値と実際の明るさが比例しません。

uniform 変数

JavaScript から設定し、1 回の描画の間はすべての頂点・フラグメントで同じ値になるシェーダーの変数。uniform 修飾子を付けて宣言します。

Uniform Buffer Object

UBO。複数の uniform 変数をバッファーにまとめ、複数のプログラムで共有する仕組み。

VAO

Vertex Array Object（頂点配列オブジェクト）。頂点属性の設定とインデックスバッファーのバインドをまとめて保存するオブジェクト。

WebGL

Web ブラウザーから GPU を使って 2D・3D グラフィックスを描画するための JavaScript API。Khronos Group が策定しています。

WebGPU

WebGL の後継として W3C で策定されたグラフィックス API。コンピュートシェーダーにも対応しています。

Z ファイティング

ほぼ同じ深度にある 2 つの面の前後関係が、深度の精度不足のためにピクセルごとに入れ替わり、ちらついて見える現象。

インスタンス描画

同じ形状を、位置や色などを変えながら 1 回の描画コールで多数描画する方法。

インターリーブ配置

複数の頂点属性を、頂点ごとに交互に並べて 1 つのバッファーに格納する方法。

インデックスバッファー

三角形などを構成する頂点の番号を格納したバッファー。頂点データの重複をなくすために使います。gl.ELEMENT_ARRAY_BUFFER にバインドします。

オリジン

URL のスキーム、ホスト、ポートの組。ブラウザーはオリジンを単位としてセキュリティーの制限を行います。

外積

2 つの 3 次元ベクトルの両方に直交するベクトルを求める演算。

拡散反射

光が表面であらゆる方向に均等に散らばる反射。明るさは光が当たる角度で決まり、見る方向には依存しません。

拡張機能

WebGL の仕様に含まれない追加の機能。gl.getExtension で有効にします。

環境光

周囲からあらゆる方向に届く光を近似したもの。光源の方向によらず一定の明るさを加えます。

鏡面反射

光が鏡のように特定の方向に強く反射する成分。ハイライトとして見えます。

行列

数を長方形に並べたもの。本書では 4 × 4 の行列で座標変換を表します。

クリア

フレームバッファーの内容を、指定した値で塗りつぶすこと。

クリップ座標

頂点シェーダーが gl_Position に出力する 4 次元の座標。w 成分で割ると正規化デバイス座標になります。

光沢度

鏡面反射の計算に使う指数。大きいほどハイライトが小さく鋭くなります。

コンテキストロスト

GPU の問題などにより WebGL のコンテキストが失われ、すべてのリソースが無効になること。

シェーダー

GPU 上で実行されるプログラム。WebGL では頂点シェーダーとフラグメントシェーダーを使います。

情報ログ

シェーダーのコンパイルやプログラムのリンクに失敗したときのエラーメッセージ。gl.getShaderInfoLog と gl.getProgramInfoLog で取得します。

深度テスト

フラグメントの深度を深度バッファーの値と比較し、手前にあるフラグメントだけを書き込む処理。

深度バッファー

フレームバッファーのピクセルごとに、そこに描かれている物の深度（奥行き）を記録するバッファー。Z バッファーとも呼びます。

スウィズル

v.xy や color.bgr のように、ベクトルの成分を選んだり並べ替えたりして取り出す記法。

ステート

WebGL が内部に保持している設定。描画関数は、呼び出された時点のステートに従って描画します。

正規化

ベクトルをその長さで割り、長さ 1 の単位ベクトルにすること。

正射影

距離によって大きさが変わらない投影。

単位行列

対角成分が 1 で、それ以外が 0 の行列。何もしない変換を表します。

単位ベクトル

長さが 1 のベクトル。

頂点シェーダー

頂点ごとに実行されるシェーダー。頂点の座標を変換し、クリップ座標を出力します。

頂点属性

頂点ごとに異なる値を持つデータ（座標、色、法線、テクスチャ座標など）。頂点シェーダーで in 修飾子を付けて宣言します。

テクスチャ

シェーダーから参照できる画像などのデータ。物体の表面に模様を貼るのに使います。

テクスチャ座標

頂点に対応させるテクスチャ上の位置。左下を (0, 0)、右上を (1, 1) とします。UV 座標とも呼びます。

テクスチャユニット

テクスチャを差し込む番号付きの差し込み口。シェーダーのサンプラーには、テクスチャユニットの番号を設定します。

テクセル

テクスチャを構成する 1 つの画素。

デルタタイム

前のフレームから現在のフレームまでの経過時間。

点光源

1 点から全方向に光を放つ光源。距離に応じて減衰します。

投影行列

ビュー座標をクリップ座標に変換する行列。

同次座標

3 次元の点や方向に 4 番目の成分 w を加えた表現。点は w = 1、方向は w = 0 とします。平行移動を行列で表せるようになります。

透視除算

クリップ座標の x、y、z を w で割り、正規化デバイス座標を求める処理。GPU が自動的に行います。

透視投影

遠くの物ほど小さく見える投影。

内積

2 つのベクトルの成分ごとの積の和。2 つのベクトルのなす角の余弦に比例します。

背面カリング

カメラから見て裏を向いている三角形を描画しないようにする処理。

バインディングポイント

uniform ブロックとバッファーを結び付けるための番号付きの接続点。

バインド

バッファーやテクスチャなどのオブジェクトを、操作の対象として WebGL のターゲット（差し込み口）に結び付けること。

バッファー

GPU のメモリ上に確保したデータの領域。頂点データやインデックスなどを格納します。

ピッキング

マウスで指した位置にある物体を特定すること。

ビュー行列

ワールド座標をカメラから見たビュー座標に変換する行列。

ビューポート

正規化デバイス座標を変換する先の、フレームバッファー上の矩形の範囲。gl.viewport で指定します。

フィルタリング

テクスチャを拡大・縮小して表示するときに、テクセルから色を求める方法。

フラグメント

ラスタライズによって生成される、ピクセルごとの処理単位。

フラグメントシェーダー

フラグメントごとに実行されるシェーダー。フラグメントの色を出力します。

プリミティブ

三角形、線分、点など、描画の基本単位となる図形。

ブレンド

フラグメントシェーダーが出力した色と、フレームバッファーにすでにある色を混ぜ合わせる処理。半透明の表現に使います。

フレームバッファー

描画結果の書き込み先。canvas の描画バッファー（既定のフレームバッファー）と、プログラムで作るフレームバッファーオブジェクトがあります。

プログラム

頂点シェーダーとフラグメントシェーダーをリンクしたもの。描画の前に gl.useProgram で選びます。

平行光源

十分遠くにあり、どこでも同じ方向から光が届く光源。太陽光の表現に使います。

ベクトル

複数の数の組。位置や方向を表します。

法線

表面に垂直な単位ベクトル。ライティングの計算に使います。

法線行列

法線を変換するための行列。モデル行列の左上 3 × 3 の部分の逆行列の転置。

ポストエフェクト

描画結果をテクスチャとして読み、画像処理を施して表示する技法。

ミップマップ

テクスチャを段階的に縮小した画像の組。縮小表示の際のちらつきを防ぐ。

モデル行列

物体のモデル座標をワールド座標に変換する行列。

ライティング

光源からの光の反射を計算して、物体に陰影を付けること。

ラッピング

テクスチャ座標が 0 ～ 1 の範囲の外にあるときに、どの色を使うかの規則。

レンダーバッファー

フレームバッファーの書き込み先として使う、シェーダーから読めないバッファー。

レンダリングパイプライン

GPU が頂点データから画面のピクセルを作り出すまでの一連の処理。

ロケーション

シェーダーの頂点属性や uniform 変数を JavaScript から指定するための番号や識別子。
