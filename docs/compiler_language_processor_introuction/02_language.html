第 2 章 題材言語 Tiny の定義

この章では、本書を通して処理系を作る言語 Tiny の仕様を定めます。Tiny は、処理系の各段階で考えるべき問題がひととおり現れ、それでいて実装が大きくなりすぎないように設計した言語です。

Tiny の概要

まず、Tiny のプログラムの例を示します。

programs/fizzbuzz.tiny
 1// 1 から 15 までの FizzBuzz
 2fn fizzbuzz(n: int) -> str {
 3    if (n % 15 == 0) {
 4        return "FizzBuzz";
 5    } else if (n % 3 == 0) {
 6        return "Fizz";
 7    } else if (n % 5 == 0) {
 8        return "Buzz";
 9    }
10    return to_str(n);
11}
12
13fn main() {
14    let i = 1;
15    while (i <= 15) {
16        print(fizzbuzz(i));
17        i = i + 1;
18    }
19}

Tiny には次のような特徴があります。

  • プログラムは関数定義の並びで、main 関数から実行を始めます。main は引数も戻り値も持ちません。組み込み関数と同じ名前の関数は定義できません。

  • 値の型は、整数 int、真偽値 bool、文字列 str、配列 [T] の 4 種類です。

  • 変数は let で宣言します。型は初期値から決まりますが、let a: [int] = []; のように明示することもできます。

  • 関数の引数と戻り値には型を書きます。戻り値がない関数は -> 以降を省略します。

  • 制御構文は if / else と while だけです。

  • 大域変数、浮動小数点数、クロージャ、例外はありません。

 2function   = "fn" IDENT "(" [ param { "," param } ] ")" [ "->" type ] block ;
 3param      = IDENT ":" type ;
 4type       = "int" | "bool" | "str" | "[" type "]" ;
 5
 6block      = "{" { statement } "}" ;
 7statement  = block
 8           | "let" IDENT [ ":" type ] "=" expr ";"
 9           | if_stmt
10           | "while" "(" expr ")" block
11           | "return" [ expr ] ";"
12           | expr "=" expr ";"
13           | expr ";" ;
14if_stmt    = "if" "(" expr ")" block [ "else" ( block | if_stmt ) ] ;
15
16expr       = or_expr ;
17or_expr    = and_expr { "||" and_expr } ;
18and_expr   = eq_expr { "&&" eq_expr } ;
19eq_expr    = rel_expr { ( "==" | "!=" ) rel_expr } ;
20rel_expr   = add_expr { ( "<" | "<=" | ">" | ">=" ) add_expr } ;
21add_expr   = mul_expr { ( "+" | "-" ) mul_expr } ;
22mul_expr   = unary { ( "*" | "/" | "%" ) unary } ;
23unary      = ( "-" | "!" ) unary | postfix ;
24postfix    = primary { "(" [ expr { "," expr } ] ")" | "[" expr "]" } ;
25primary    = INT | STRING | "true" | "false" | IDENT
26           | "(" expr ")" | "[" [ expr { "," expr } ] "]" ;

代入文 expr "=" expr ";" の左辺に書けるのは、変数（x）と添字式（a[i]）だけです。また、関数呼び出しの ( の前に書けるのは関数名だけです。これらの制約は文法では表さず、構文解析器が検査します。

演算子に使える型は次のとおりです。

  • + は int どうし（加算）または str どうし（連結）に使えます。

  • -、*、/、%、<、<=、>、>= は int どうしに使えます。

  • == と != は同じ型どうしに使えます。配列の場合は要素を順に比較します。

  • &&、||、! は bool に使えます。

  • a[i] の a は配列または文字列、i は int です。文字列の添字式は長さ 1 の文字列を返します。

意味についての補足

文法と型だけでは決まらない、実行時の振る舞いを定めておきます。

  • 整数の除算 / は 0 に向かって切り捨てます（-7 / 2 は -3）。剰余 % は a == (a / b) * b + a % b を満たすように定めます（-7 % 2 は -1）。これは C 言語や Java と同じで、Python の // と % とは負の数の扱いが異なります。

  • 0 による除算や、範囲外の添字（負の添字を含む）は実行時エラーになります。

  • && と || は短絡評価を行います。左辺で結果が決まる場合、右辺は評価しません。

  • 配列は参照で扱います。関数に配列を渡して要素を変更すると、呼び出し元の配列も変わります。

  • 変数の有効範囲（スコープ）は、宣言した位置からそのブロックの終わりまでです。内側のブロックで同じ名前の変数を宣言すると、外側の変数は隠されます。

  • 値を返す関数は、すべての実行経路が return 文で終わらなければなりません。

まとめ

  • Tiny は、整数・真偽値・文字列・配列・関数を持つ静的型付きの小さな言語です。

  • 文法は EBNF で記述しました。演算子の優先順位と結合性は、文法の規則の階層で表されます。

  • 文法で表せない制約（代入の左辺、型、return の有無など）は、構文解析器と意味解析器で検査します。
