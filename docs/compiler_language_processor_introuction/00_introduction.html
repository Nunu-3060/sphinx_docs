はじめに

本書の目的

私たちが毎日使っているプログラミング言語は、言語処理系と呼ばれるソフトウェアによって実行されています。Python のソースコードは CPython がバイトコードに変換して実行し、C 言語のソースコードは GCC や Clang が機械語に変換します。言語処理系は普段は意識されませんが、そのしくみを知ると次のような場面で役に立ちます。

  • エラーメッセージの意味や、言語の仕様がそうなっている理由が分かるようになります。

  • 設定ファイルの読み込み、テンプレートエンジン、クエリ言語、ドメイン固有言語（DSL）など、小さな言語処理系を自分で作る場面に対応できます。

  • コンパイラがどのような最適化を行うかを知ることで、性能を意識したコードを書けるようになります。

  • 構文の強調表示、静的解析、自動整形など、開発ツールのしくみを理解できます。

本書の目的は、言語処理系の全体像と各段階の基本的な手法を、実際に動くコードを通して理解することです。理論は必要な範囲にとどめ、詳しい内容は付録 C の参考文献に譲ります。

対象読者と前提知識

本書は次のような読者を想定しています。

  • Python でクラス、データクラス、型ヒントを使ったプログラムを書いたことがある方

  • 再帰関数、リスト、辞書などの基本的なデータ構造を理解している方

  • コンパイラやインタプリタの内部について学んだことがない、または断片的にしか知らない方

オートマトンや形式言語の理論、アセンブリ言語の知識は前提としません。必要になったか所で説明します。

本書で作るもの

本書では、第 2 章で定義する小さな言語 Tiny の処理系を、章を追うごとに少しずつ作り上げます。次のプログラムは Tiny で書いた階乗の計算です。

 1fn fact(n: int) -> int {
 2    if (n <= 1) {
 3        return 1;
 4    }
 5    return n * fact(n - 1);
 6}
 7
 8fn main() {
 9    print("10! =", fact(10));
10}

Tiny は整数、真偽値、文字列、配列、関数を持つ静的型付き言語です。本書で作る処理系は、Tiny のプログラムを主に次の 3 つの方法で実行できます。

  • 抽象構文木を直接たどって実行する木構造インタプリタ（第 7 章）

  • 中間表現（IR）を最適化してから実行する IR インタプリタ（第 8 章、第 9 章）

  • バイトコードにコンパイルして実行する仮想マシン（第 10 章）

さらに第 11 章では、中間表現の変数を有限個のレジスタに割り当て、ネイティブコードに近い形の命令列を作ります。

動作環境

サンプルコードは Python 3.10 以降で動作します。match 文や X | None 形式の型ヒントを使うため、それより古い Python では動作しません。本書の実行例は Python 3.14 で確認したものです。サンプルコードは標準ライブラリだけを使っており、追加のパッケージは必要ありません。

サンプルコードは付録 A から閲覧・ダウンロードできます。すべてのファイルを同じディレクトリに置き、そのディレクトリで次のように実行してください。

1$ python tiny.py run programs/fib.tiny
2$ python -m unittest test_tiny.py

各ファイルは flake8 と mypy（--strict オプション付き）で検査済みです。
