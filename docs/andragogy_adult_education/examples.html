ワークシート

ワークシートは、Markdown という形式で書かれたテキストファイルです。メモ帳などのテキストエディターで開き、そのまま書き込んで使えます。印刷して手書きで使ってもかまいません。

サンプルコード

サンプルコードは、プログラミング言語 Python で書かれたプログラムです。使わなくても本書の内容は理解できますが、関心のある方は試してみてください。

実行するには、Python（3.10 以降）をインストールしておく必要があります。Python は、Python の公式サイトからダウンロードできます。追加のライブラリーは必要ありません。

ダウンロードしたファイルを置いたフォルダーで、Windows ではコマンドプロンプト、macOS ではターミナルを開き、次のように入力して実行します（macOS では python の代わりに python3 と入力します）。

1python review_schedule.py 2026-10-01
2python learning_log.py learning_log_sample.csv

復習の予定を作る（review_schedule.py）

学んだ日を入力すると、1 日後、3 日後、7 日後、14 日後、30 日後の復習の予定日を表示します。--intervals の後に日数を並べると、間隔を変えられます。考え方は年齢と学びの科学で説明しています。

review_schedule.py をダウンロード

 1"""学習した日から、復習する日の予定を作る。
 2
 3分散学習（間隔を空けて復習すること）の考え方に従い、学習した日の
 41 日後、3 日後、7 日後、14 日後、30 日後を復習日として表示する。
 5間隔は --intervals で変更できる。
 6
 7使い方::
 8
 9    python review_schedule.py 2026-10-01
10    python review_schedule.py 2026-10-01 --intervals 2 5 10
11"""
12
13import argparse
14import datetime
15
16DEFAULT_INTERVALS: list[int] = [1, 3, 7, 14, 30]
17WEEKDAYS: list[str] = ['月', '火', '水', '木', '金', '土', '日']
18
19
20def make_schedule(start: datetime.date,
21                  intervals: list[int]) -> list[datetime.date]:
22    """学習した日と間隔（日数）から、復習日のリストを返す。
23
24    Args:
25        start: 学習した日。
26        intervals: 学習した日から数えた日数のリスト。
27
28    Returns:
29        復習日のリスト。日付の早い順に並べる。
30    """
31    return sorted(start + datetime.timedelta(days=days)
32                  for days in intervals)
33
34
35def format_date(day: datetime.date) -> str:
36    """日付を「2026-10-02（金）」の形の文字列にする。"""
37    return f'{day.isoformat()}（{WEEKDAYS[day.weekday()]}）'
38
39
40def parse_args() -> argparse.Namespace:
41    """コマンドライン引数を解析する。"""
42    parser = argparse.ArgumentParser(description='復習する日の予定を作ります。')
43    parser.add_argument('start', type=datetime.date.fromisoformat,
44                        help='学習した日（例：2026-10-01）')
45    parser.add_argument('--intervals', type=int, nargs='+',
46                        default=DEFAULT_INTERVALS,
47                        help='学習した日から数えた日数（既定：1 3 7 14 30）')
48    return parser.parse_args()
49
50
51def main() -> None:
52    """復習日の予定を表示する。"""
53    args = parse_args()
54    start: datetime.date = args.start
55    intervals: list[int] = args.intervals
56    print(f'学習した日：{format_date(start)}')
57    for number, day in enumerate(make_schedule(start, intervals), start=1):
58        days = (day - start).days
59        print(f'{number} 回目の復習：{format_date(day)}（{days} 日後）')
60
61
62if __name__ == '__main__':
63    main()

学習の記録を集計する（learning_log.py）

学習の記録を書いた CSV ファイルを読み込み、テーマごとの合計時間と回数、週ごとの合計時間を表示します。使い方は自分の学びをデザインするで説明しています。

learning_log.py をダウンロード

 1"""学習の記録（CSV ファイル）を集計する。
 2
 3CSV ファイルには、次の 4 つの列を書く。1 行目は列名とする。
 4
 5* date: 学習した日（例：2026-09-01）
 6* theme: 学習のテーマ（例：英会話）
 7* minutes: 学習した時間（分）
 8* note: 学んだことや気づいたこと
 9
10テーマごとの合計時間と回数、週ごとの合計時間を表示する。
11
12使い方::
13
14    python learning_log.py learning_log_sample.csv
15"""
16
17import argparse
18import csv
19import datetime
20from collections import defaultdict
21from dataclasses import dataclass
22from pathlib import Path
23
24
25@dataclass
26class Record:
27    """学習の記録 1 件を表す。"""
28
29    date: datetime.date
30    theme: str
31    minutes: int
32    note: str
33
34
35def read_records(path: Path) -> list[Record]:
36    """CSV ファイルから学習の記録を読み込む。"""
37    with path.open(encoding='utf-8', newline='') as f:
38        return [
39            Record(date=datetime.date.fromisoformat(row['date']),
40                   theme=row['theme'],
41                   minutes=int(row['minutes']),
42                   note=row['note'])
43            for row in csv.DictReader(f)
44        ]
45
46
47def total_by_theme(records: list[Record]) -> dict[str, tuple[int, int]]:
48    """テーマごとに（合計時間（分）、回数）を求める。"""
49    minutes: dict[str, int] = defaultdict(int)
50    counts: dict[str, int] = defaultdict(int)
51    for record in records:
52        minutes[record.theme] += record.minutes
53        counts[record.theme] += 1
54    return {theme: (minutes[theme], counts[theme]) for theme in minutes}
55
56
57def total_by_week(records: list[Record]) -> dict[datetime.date, int]:
58    """週ごとの合計時間（分）を求める。週は月曜日の日付で表す。"""
59    totals: dict[datetime.date, int] = defaultdict(int)
60    for record in records:
61        monday = record.date - datetime.timedelta(days=record.date.weekday())
62        totals[monday] += record.minutes
63    return dict(sorted(totals.items()))
64
65
66def main() -> None:
67    """学習の記録を集計して表示する。"""
68    parser = argparse.ArgumentParser(description='学習の記録を集計します。')
69    parser.add_argument('csv_file', type=Path, help='学習の記録の CSV ファイル')
70    args = parser.parse_args()
71    records = read_records(args.csv_file)
72
73    print('テーマごとの合計')
74    for theme, (minutes, count) in total_by_theme(records).items():
75        print(f'  {theme}：{minutes} 分（{count} 回）')
76
77    print('週ごとの合計')
78    for monday, minutes in total_by_week(records).items():
79        print(f'  {monday.isoformat()} の週：{minutes} 分')
80
81
82if __name__ == '__main__':
83    main()
