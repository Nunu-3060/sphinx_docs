10.2. スケジュールを作成するプログラム

引越し日を入力すると、各項目を行う日付を計算して一覧にする Python のプログラムを用意しました。次のリンクからダウンロードできます。

  • moving_schedule.py

10.2.1. 使い方

Python 3.9 以降がインストールされたパソコンで、コマンドプロンプトなどから次のように実行します。引越し日は「年-月-日」の形式で指定します。--csv とファイル名を付けると、表計算ソフトで開ける CSV ファイルも保存します。

1python moving_schedule.py 2026-11-15
2python moving_schedule.py 2026-11-15 --csv schedule.csv

引越し日を 2026 年 11 月 15 日とした場合、次のように表示されます（一部を省略しています）。

1引越し日: 2026-11-15
2[ ] 2026-09-16(水)   60 日前 [住まい] 新居を探し始める
3[ ] 2026-10-01(木)   45 日前 [住まい] 今の住まいの解約を管理会社・大家に連絡する
4[ ] 2026-10-01(木)   45 日前 [業者] 引越し業者から見積もりを取る(3 社程度)
5[ ] 2026-10-06(火)   40 日前 [業者] 引越し業者を決めて予約する

やることの一覧は、プログラムの中の TASKS に書かれています。項目を追加したり、日数を変えたりして、自分の予定に合わせて使ってください。

10.2.2. プログラムの全文

  1"""引越し日から逆算して、やることリスト(スケジュール)を作成するスクリプト.
  2
  3使い方:
  4    python moving_schedule.py 2026-11-15
  5    python moving_schedule.py 2026-11-15 --csv schedule.csv
  6
  71 つ目の引数に引越し日を「年-月-日」の形式で指定します。
  8--csv を付けると、表計算ソフトで開ける CSV ファイルも保存します。
  9"""
 10
 11from __future__ import annotations
 12
 13import argparse
 14import csv
 15import datetime
 16from dataclasses import dataclass
 17
 18
 19@dataclass(frozen=True)
 20class Task:
 21    """やること 1 件分の情報."""
 22
 23    offset_days: int  # 引越し日との差(マイナスは引越し前、プラスは引越し後)
 24    category: str  # 分類
 25    title: str  # やること
 26
 27
 28# 標準的なやることの一覧です。必要に応じて追加・削除してください。
 29TASKS: list[Task] = [
 30    Task(-60, "住まい", "新居を探し始める"),
 31    Task(-45, "住まい", "今の住まいの解約を管理会社・大家に連絡する"),
 32    Task(-45, "業者", "引越し業者から見積もりを取る(3 社程度)"),
 33    Task(-40, "業者", "引越し業者を決めて予約する"),
 34    Task(-30, "学校・職場", "学校・勤務先に引越しを伝える"),
 35    Task(-30, "片付け", "粗大ごみの収集を申し込む"),
 36    Task(-21, "片付け", "荷造りを始める(使わない物から)"),
 37    Task(-14, "役所", "転出届を出す(他の市区町村へ引越す場合)"),
 38    Task(-14, "役所", "国民健康保険・児童手当などの手続きをする"),
 39    Task(-10, "郵便・通信", "郵便の転送を申し込む"),
 40    Task(-10, "郵便・通信", "インターネット回線の移転を申し込む"),
 41    Task(-7, "ライフライン", "電気・ガス・水道の停止と開始を申し込む"),
 42    Task(-1, "当日準備", "冷蔵庫の電源を切り、洗濯機の水を抜く"),
 43    Task(0, "当日", "荷物の搬出・旧居の掃除と明け渡し"),
 44    Task(0, "当日", "新居でガスの開栓に立ち会う"),
 45    Task(1, "新居", "荷物に破損や紛失がないか確認する"),
 46    Task(3, "新居", "近所へあいさつする"),
 47    Task(7, "役所", "転入届(または転居届)を出す"),
 48    Task(7, "役所", "マイナンバーカードの住所を変更する"),
 49    Task(14, "警察", "運転免許証の住所を変更する"),
 50    Task(14, "各種変更", "銀行・クレジットカード・保険などの住所を変更する"),
 51]
 52
 53
 54def parse_date(text: str) -> datetime.date:
 55    """「年-月-日」形式の文字列を日付に変換する."""
 56    try:
 57        return datetime.date.fromisoformat(text)
 58    except ValueError as error:
 59        message = f"日付は 2026-11-15 のような形式で指定してください: {text}"
 60        raise argparse.ArgumentTypeError(message) from error
 61
 62
 63def describe_offset(offset_days: int) -> str:
 64    """引越し日との差を「○日前」「当日」「○日後」の文字列にする."""
 65    if offset_days < 0:
 66        return f"{-offset_days} 日前"
 67    if offset_days == 0:
 68        return "当日"
 69    return f"{offset_days} 日後"
 70
 71
 72def build_schedule(
 73    moving_day: datetime.date, tasks: list[Task]
 74) -> list[tuple[datetime.date, Task]]:
 75    """各やることに実際の日付を割り当て、日付順に並べる."""
 76    schedule = [
 77        (moving_day + datetime.timedelta(days=task.offset_days), task)
 78        for task in tasks
 79    ]
 80    return sorted(schedule, key=lambda item: item[0])
 81
 82
 83def print_schedule(schedule: list[tuple[datetime.date, Task]]) -> None:
 84    """スケジュールを画面に表示する."""
 85    weekdays = "月火水木金土日"
 86    for day, task in schedule:
 87        weekday = weekdays[day.weekday()]
 88        timing = describe_offset(task.offset_days)
 89        print(f"[ ] {day:%Y-%m-%d}({weekday}) {timing:>7} "
 90              f"[{task.category}] {task.title}")
 91
 92
 93def save_csv(path: str, schedule: list[tuple[datetime.date, Task]]) -> None:
 94    """スケジュールを CSV ファイルに保存する(Excel で開けるよう BOM 付き)."""
 95    with open(path, "w", newline="", encoding="utf-8-sig") as file:
 96        writer = csv.writer(file)
 97        writer.writerow(["完了", "日付", "時期", "分類", "やること"])
 98        for day, task in schedule:
 99            writer.writerow(
100                ["", day.isoformat(), describe_offset(task.offset_days),
101                 task.category, task.title]
102            )
103
104
105def main() -> None:
106    """コマンドライン引数を読み取り、スケジュールを出力する."""
107    parser = argparse.ArgumentParser(
108        description="引越し日から逆算したやることリストを作成します。"
109    )
110    parser.add_argument("moving_day", type=parse_date,
111                        help="引越し日(例: 2026-11-15)")
112    parser.add_argument("--csv", metavar="FILE",
113                        help="CSV ファイルの保存先(省略可)")
114    args = parser.parse_args()
115
116    schedule = build_schedule(args.moving_day, TASKS)
117    print(f"引越し日: {args.moving_day:%Y-%m-%d}")
118    print_schedule(schedule)
119    if args.csv:
120        save_csv(args.csv, schedule)
121        print(f"CSV ファイルを保存しました: {args.csv}")
122
123
124if __name__ == "__main__":
125    main()
