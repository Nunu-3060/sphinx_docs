引越し手続きガイド

引越しには、荷物を運ぶこと以外にも、役所への届出、電気・ガス・水道の契約、郵便の転送、各種の住所変更など、たくさんの手続きがあります。本書は、初めて引越しをする方でも迷わず準備を進められるよう、引越しの前後で行うべきことを時期の順に整理したガイドです。
