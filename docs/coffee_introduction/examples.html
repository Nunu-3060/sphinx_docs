便利なスクリプト

本付録では、コーヒーを淹れるときに役立つ 2 つの Python スクリプトを紹介します。どちらも Python の標準機能だけで動くため、追加のインストールは不要です。

動かすための準備

スクリプトを動かすには、Python 3.10 以上が必要です。Python は、Python の公式サイトからダウンロードしてインストールできます。

スクリプトは、次の手順で実行します。

  1. 本ページのリンクからスクリプトをダウンロードします。

  2. Windows では「コマンドプロンプト」、macOS では「ターミナル」を開きます。

  3. cd コマンドで、スクリプトを保存したフォルダーに移動します。

  4. python コマンドの後にスクリプトのファイル名を付けて実行します。

例えば、ダウンロードフォルダーに保存した場合は、次のように入力します。macOS では python の代わりに python3 と入力してください。

1cd Downloads
2python coffee_calculator.py

粉の量の計算（coffee_calculator.py）

杯数、濃さ、焙煎度、淹れ方を指定すると、粉の量、注ぐお湯の量、お湯の温度、挽き方の目安を表示します。計算には、「おいしい淹れ方」で紹介した式と目安を使っています。1 杯分のできあがり量は 140 ml としています。

ダウンロード：coffee_calculator.py

使い方

引数を付けずに実行すると、杯数、濃さ、焙煎度、淹れ方を順に尋ねられます。濃さ、焙煎度、淹れ方は、何も入力せずに Enter キーを押すと、それぞれ「普通」「中煎り」「ハンドドリップ」になります。

1python coffee_calculator.py

杯数（1〜10）を続けて指定すると、すぐに結果が表示されます。そのほかの項目は、次のオプションで指定します。指定しない場合は、それぞれ normal、medium、drip になります。

オプション

指定できる値

--strength

濃さ。light（薄め）、normal（普通）、strong（濃いめ）

--roast

焙煎度。light（浅煎り）、medium（中煎り）、dark（深煎り）

--method

淹れ方。drip（ハンドドリップ）、press（フレンチプレス）

例えば、普通の濃さ、中煎りの豆で 2 杯分をハンドドリップで淹れる場合は、次のように実行します。

1python coffee_calculator.py 2

実行すると、次のように表示されます。

12 杯分（普通、中煎り、ハンドドリップ）の目安
2  粉の量        : 21.5 g
3  注ぐお湯の量  : 323 ml
4  できあがり量  : 約 280 ml
5  お湯の温度    : 88〜92 ℃
6  挽き方        : 中細挽き

深煎りの豆で、濃いめの 3 杯分をフレンチプレスで淹れる場合は、次のように実行します。

1python coffee_calculator.py 3 --strength strong --roast dark --method press

ソースコード

  1"""コーヒーの粉の量とお湯の量を計算するスクリプト。
  2
  3杯数、好みの濃さ、焙煎度、淹れ方を指定すると、粉の量、注ぐお湯の量、
  4お湯の温度、挽き方の目安を表示します。
  5
  6使い方:
  7    python coffee_calculator.py              対話形式で入力する
  8    python coffee_calculator.py 2            2 杯分（普通の濃さ、中煎り）
  9    python coffee_calculator.py 3 --strength strong --roast dark
 10"""
 11
 12from __future__ import annotations
 13
 14import argparse
 15import sys
 16from dataclasses import dataclass
 17
 18# 1 杯分のできあがり量（ml）
 19CUP_ML = 140
 20
 21# 粉 1 g が吸い込んで残すお湯の量（ml）
 22ABSORPTION_ML_PER_G = 2.0
 23
 24
 25@dataclass(frozen=True)
 26class Option:
 27    """選択肢の 1 つ。"""
 28
 29    key: str  # コマンドラインで指定する名前
 30    name: str  # 画面に表示する名前
 31    detail: str  # 補足情報（お湯の温度や挽き方の目安）
 32
 33
 34# 濃さ：detail は使わない
 35STRENGTHS: tuple[Option, ...] = (
 36    Option("light", "薄め", ""),
 37    Option("normal", "普通", ""),
 38    Option("strong", "濃いめ", ""),
 39)
 40
 41# 濃さごとの比率（お湯の量 ÷ 粉の量）
 42RATIOS: dict[str, int] = {"light": 17, "normal": 15, "strong": 13}
 43
 44# 焙煎度：detail はお湯の温度の目安
 45ROASTS: tuple[Option, ...] = (
 46    Option("light", "浅煎り", "90〜95 ℃"),
 47    Option("medium", "中煎り", "88〜92 ℃"),
 48    Option("dark", "深煎り", "82〜88 ℃"),
 49)
 50
 51# 淹れ方：detail は挽き方の目安
 52METHODS: tuple[Option, ...] = (
 53    Option("drip", "ハンドドリップ", "中細挽き"),
 54    Option("press", "フレンチプレス", "粗挽き"),
 55)
 56
 57
 58@dataclass(frozen=True)
 59class Recipe:
 60    """計算結果。"""
 61
 62    coffee_g: float  # 粉の量（g）
 63    water_ml: int  # 注ぐお湯の量（ml）
 64    yield_ml: int  # できあがり量（ml）
 65
 66
 67def find_option(options: tuple[Option, ...], key: str) -> Option:
 68    """名前から選択肢を探す。"""
 69    for option in options:
 70        if option.key == key:
 71            return option
 72    raise ValueError(f"不明な選択肢です: {key}")
 73
 74
 75def calculate(cups: int, ratio: float) -> Recipe:
 76    """杯数と比率から、粉の量と注ぐお湯の量を計算する。
 77
 78    できあがり量 = お湯の量 - 2 × 粉の量、お湯の量 = 比率 × 粉の量
 79    から、粉の量 = できあがり量 ÷ (比率 - 2) となります。
 80    """
 81    yield_ml = CUP_ML * cups
 82    coffee_g = yield_ml / (ratio - ABSORPTION_ML_PER_G)
 83    water_ml = round(coffee_g * ratio)
 84    return Recipe(round(coffee_g, 1), water_ml, yield_ml)
 85
 86
 87def ask_cups() -> int:
 88    """杯数を対話形式で入力してもらう。"""
 89    while True:
 90        text = input("何杯分淹れますか（1〜10）: ")
 91        if text.isdecimal() and 1 <= int(text) <= 10:
 92            return int(text)
 93        print("1 から 10 までの数を入力してください。")
 94
 95
 96def ask_option(
 97    title: str, options: tuple[Option, ...], default: int
 98) -> Option:
 99    """選択肢を番号で選んでもらう。何も入力しなければ default 番を選ぶ。"""
100    for number, option in enumerate(options, start=1):
101        print(f"  {number}: {option.name}")
102    while True:
103        text = input(f"{title}を番号で選んでください（省略時は {default}）: ")
104        if text == "":
105            return options[default - 1]
106        if text.isdecimal() and 1 <= int(text) <= len(options):
107            return options[int(text) - 1]
108        print("表示されている番号を入力してください。")
109
110
111def parse_args() -> argparse.Namespace:
112    """コマンドライン引数を解析する。"""
113    parser = argparse.ArgumentParser(
114        description="コーヒーの粉の量とお湯の量を計算します。"
115    )
116    parser.add_argument("cups", nargs="?", type=int, help="杯数（1〜10）")
117    parser.add_argument(
118        "--strength",
119        choices=[option.key for option in STRENGTHS],
120        default="normal",
121        help="濃さ（light、normal、strong）",
122    )
123    parser.add_argument(
124        "--roast",
125        choices=[option.key for option in ROASTS],
126        default="medium",
127        help="焙煎度（light、medium、dark）",
128    )
129    parser.add_argument(
130        "--method",
131        choices=[option.key for option in METHODS],
132        default="drip",
133        help="淹れ方（drip、press）",
134    )
135    return parser.parse_args()
136
137
138def main() -> int:
139    """スクリプトの入口。"""
140    args = parse_args()
141
142    if args.cups is None:
143        cups = ask_cups()
144        strength = ask_option("濃さ", STRENGTHS, 2)
145        roast = ask_option("焙煎度", ROASTS, 2)
146        method = ask_option("淹れ方", METHODS, 1)
147    else:
148        if not 1 <= args.cups <= 10:
149            print("杯数には 1 から 10 までの数を指定してください。")
150            return 1
151        cups = args.cups
152        strength = find_option(STRENGTHS, args.strength)
153        roast = find_option(ROASTS, args.roast)
154        method = find_option(METHODS, args.method)
155
156    recipe = calculate(cups, RATIOS[strength.key])
157
158    print(f"{cups} 杯分（{strength.name}、{roast.name}、{method.name}）の目安")
159    print(f"  粉の量        : {recipe.coffee_g} g")
160    print(f"  注ぐお湯の量  : {recipe.water_ml} ml")
161    print(f"  できあがり量  : 約 {recipe.yield_ml} ml")
162    print(f"  お湯の温度    : {roast.detail}")
163    print(f"  挽き方        : {method.detail}")
164    return 0
165
166
167if __name__ == "__main__":
168    sys.exit(main())

ハンドドリップのタイマー（drip_timer.py）

粉の量を指定すると、「おいしい淹れ方」で紹介したハンドドリップの手順に沿って、蒸らしと注湯のタイミングを案内します。各手順では、スケールの表示が何 g になるまでお湯を注げばよいかを表示します。注ぐお湯の合計は、粉の量の 15 倍です。

ダウンロード：drip_timer.py

使い方

粉の量（5〜60 g）を指定して実行します。指定しない場合は、実行後に入力を求められます。例えば、粉 20 g で淹れる場合は、次のように実行します。

1python drip_timer.py 20

スケールの表示を 0 g にしてから Enter キーを押すと、タイマーが始まります。次の手順までの残り時間が 1 秒ごとに表示され、手順の時刻になると、音とメッセージで知らせます。途中でやめたい場合は、Ctrl+C を押します。最後まで進むと、次のように表示されます。

1粉 20 g、お湯 300 g で淹れます。
2スケールを 0 g にしてから、Enter キーを押すと始まります。
3Ctrl+C で中止できます。
4[0:00] 蒸らし：スケールが 40 g になるまで、粉全体を湿らせるように注ぎます。
5[0:30] 1 回目：スケールが 120 g になるまで、中心から円を描くように注ぎます。
6[1:10] 2 回目：スケールが 210 g になるまで注ぎます。
7[1:50] 3 回目：スケールが 300 g になるまで注ぎます。
8[3:00] お湯が落ちきっていなくても、ドリッパーを外します。
9できあがりです。サーバーを軽く回して混ぜてから注ぎましょう。

ソースコード

  1"""ハンドドリップの蒸らしと注湯のタイミングを案内するタイマー。
  2
  3粉の量を指定すると、蒸らしから注湯の終わりまでの手順を時間に合わせて
  4表示します。各手順では、スケール（はかり）の表示が何 g になるまで
  5お湯を注げばよいかを案内します。
  6
  7使い方:
  8    python drip_timer.py         対話形式で粉の量を入力する
  9    python drip_timer.py 20      粉 20 g で淹れる
 10"""
 11
 12from __future__ import annotations
 13
 14import argparse
 15import sys
 16import time
 17from dataclasses import dataclass
 18
 19# お湯の量 ÷ 粉の量の比率
 20RATIO = 15
 21
 22# 蒸らしで注ぐお湯の量（粉の量に対する倍率）
 23BLOOM_RATE = 2
 24
 25
 26@dataclass(frozen=True)
 27class Step:
 28    """抽出の手順の 1 つ。"""
 29
 30    start: int  # 開始時刻（抽出を始めてからの秒数）
 31    message: str  # 画面に表示する案内
 32
 33
 34def make_steps(coffee_g: float) -> list[Step]:
 35    """粉の量から、抽出の手順を作る。
 36
 37    注ぐお湯の合計は粉の量の 15 倍です。蒸らしのあと 3 回に分けて、
 38    合計の 40 %、70 %、100 % になるまで注ぎます。
 39    """
 40    total = round(coffee_g * RATIO)
 41    bloom = round(coffee_g * BLOOM_RATE)
 42    first = round(total * 0.4)
 43    second = round(total * 0.7)
 44    return [
 45        Step(0, f"蒸らし：スケールが {bloom} g になるまで、"
 46                "粉全体を湿らせるように注ぎます。"),
 47        Step(30, f"1 回目：スケールが {first} g になるまで、"
 48                 "中心から円を描くように注ぎます。"),
 49        Step(70, f"2 回目：スケールが {second} g になるまで注ぎます。"),
 50        Step(110, f"3 回目：スケールが {total} g になるまで注ぎます。"),
 51        Step(180, "お湯が落ちきっていなくても、ドリッパーを外します。"),
 52    ]
 53
 54
 55def format_time(seconds: int) -> str:
 56    """秒数を「分:秒」の形式の文字列にする。"""
 57    minutes, rest = divmod(seconds, 60)
 58    return f"{minutes}:{rest:02d}"
 59
 60
 61def wait_until(start_time: float, target: int, label: str) -> None:
 62    """抽出開始から target 秒になるまで、残り時間を表示しながら待つ。"""
 63    while True:
 64        remaining = target - int(time.monotonic() - start_time)
 65        if remaining <= 0:
 66            break
 67        print(f"\r  {label}まであと {remaining:3d} 秒 ", end="", flush=True)
 68        time.sleep(0.2)
 69    print("\r" + " " * 40 + "\r", end="")
 70
 71
 72def ask_coffee_g() -> float:
 73    """粉の量を対話形式で入力してもらう。"""
 74    while True:
 75        text = input("粉の量を g で入力してください（例：20）: ")
 76        try:
 77            coffee_g = float(text)
 78        except ValueError:
 79            coffee_g = 0.0
 80        if 5 <= coffee_g <= 60:
 81            return coffee_g
 82        print("5 から 60 までの数を入力してください。")
 83
 84
 85def parse_args() -> argparse.Namespace:
 86    """コマンドライン引数を解析する。"""
 87    parser = argparse.ArgumentParser(
 88        description="ハンドドリップの手順を時間に合わせて案内します。"
 89    )
 90    parser.add_argument(
 91        "coffee_g", nargs="?", type=float, help="粉の量（g、5〜60）"
 92    )
 93    return parser.parse_args()
 94
 95
 96def main() -> int:
 97    """スクリプトの入口。"""
 98    args = parse_args()
 99
100    coffee_g: float | None = args.coffee_g
101    if coffee_g is None:
102        coffee_g = ask_coffee_g()
103    elif not 5 <= coffee_g <= 60:
104        print("粉の量には 5 から 60 までの数を指定してください。")
105        return 1
106
107    steps = make_steps(coffee_g)
108    print(f"粉 {coffee_g:g} g、お湯 {round(coffee_g * RATIO)} g で淹れます。")
109    input("スケールを 0 g にしてから、Enter キーを押すと始まります。")
110    print("Ctrl+C で中止できます。")
111
112    start_time = time.monotonic()
113    try:
114        for step in steps:
115            wait_until(start_time, step.start, format_time(step.start))
116            # "\a" はベル文字で、対応している環境では音が鳴ります
117            print(f"\a[{format_time(step.start)}] {step.message}")
118    except KeyboardInterrupt:
119        print("\nタイマーを中止しました。")
120        return 1
121
122    print("できあがりです。サーバーを軽く回して混ぜてから注ぎましょう。")
123    return 0
124
125
126if __name__ == "__main__":
127    sys.exit(main())
