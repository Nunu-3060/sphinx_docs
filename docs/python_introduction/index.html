Python 入門

このドキュメントは、プログラミング未経験の方を対象にした Python の入門資料です。環境構築から基本文法、関数、データ構造、例外処理、クラスまでを、実際に動かせるサンプルコードとともに解説します。

各章のサンプルコードは、本文中の Download リンクからダウンロードできます。手元の環境にコードを保存し、実際に実行しながら読み進めることをお勧めします。
