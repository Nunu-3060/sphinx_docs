第 12 章 クラスとオブジェクト指向

クラスとは

クラスとは、関連するデータ（属性）と処理（メソッド）をひとまとめにした設計図のようなものです。クラスから作られた実体のことを、インスタンスと呼びます。同じクラスから複数のインスタンスを作成でき、それぞれのインスタンスは独立した属性の値を持ちます。

クラスの定義

Python では、class キーワードを使ってクラスを定義します。インスタンスが作成される際に自動的に呼び出される特別なメソッドを __init__ メソッドと呼び、属性の初期化に使用します。クラスの定義の直後や、__init__ メソッドをはじめとする各メソッドの定義の直後には、第 7 章で説明した docstring を書けます。

 1class BankAccount:
 2    """銀行口座を表すクラスです。"""
 3
 4    def __init__(self, owner: str, balance: int = 0) -> None:
 5        """口座の名義人と残高を初期化します。"""
 6        self.owner: str = owner
 7        self.balance: int = balance
 8
 9    def deposit(self, amount: int) -> None:
10        """口座に指定した金額を入金します。"""
11        self.balance += amount
12
13account: BankAccount = BankAccount("伊藤", 1000)
14account.deposit(500)
15print(account.balance)  # 1500

self は、メソッドが呼び出されたインスタンス自身を指す引数です。クラス内のメソッドを定義する際は、第 1 引数として必ず self を書きます。self.owner や self.balance のように、属性にも型ヒントを付けられます。また、account: BankAccount のように、クラス自体を型ヒントとして使うこともできます。この書き方により、account に対して BankAccount クラスにない属性やメソッドを使おうとした場合に、mypy で誤りを検出できるようになります。

特殊メソッド

Python のクラスには、__str__ のように前後にアンダースコアを 2 つ付けた特殊メソッドを定義できます。__str__ メソッドを定義すると、print 関数でインスタンスを表示したときに、その戻り値が表示されるようになります。

 1class BankAccount:
 2    def __init__(self, owner: str, balance: int = 0) -> None:
 3        self.owner: str = owner
 4        self.balance: int = balance
 5
 6    def __str__(self) -> str:
 7        return f"{self.owner} の口座残高: {self.balance} 円"
 8
 9account = BankAccount("伊藤", 1000)
10print(account)  # 伊藤 の口座残高: 1000 円

特殊メソッドは、__init__ や __str__ のほかにも数多く用意されており、決められた名前と書き方に従うことで、Python の組み込みの構文や関数からクラスを扱えるようになります。代表的なものを次に示します。

特殊メソッド

呼び出される場面

__init__

インスタンスが作成されたとき

__str__

print 関数や str 関数で文字列に変換するとき

__eq__

== 演算子でインスタンス同士を比較するとき

__len__

len 関数でインスタンスの長さを取得するとき

本資料では __init__ と __str__ のみを扱いますが、必要に応じて、これら以外の特殊メソッドについても調べてみてください。

継承

継承とは、既存のクラスの属性やメソッドを引き継いで、新しいクラスを定義する仕組みです。継承元のクラスを親クラス（基底クラス）、継承先のクラスを子クラス（派生クラス）と呼びます。子クラスでは、super() を使って親クラスの __init__ メソッドを呼び出せます。

1class SavingsAccount(BankAccount):
2    def __init__(self, owner: str, balance: int = 0, interest_rate: float = 0.01) -> None:
3        super().__init__(owner, balance)
4        self.interest_rate: float = interest_rate
5
6    def add_interest(self) -> None:
7        self.balance += int(self.balance * self.interest_rate)

SavingsAccount クラスは BankAccount クラスを継承しているため、deposit メソッドや __str__ メソッドをそのまま利用できます。

サンプルコード

銀行口座を表すクラスと、それを継承した定期預金口座のクラスをまとめたサンプルコードです。

oop.py

 1"""クラスと継承の基本的な使い方を示すサンプルです。"""
 2
 3
 4class BankAccount:
 5    """銀行口座を表すクラスです。"""
 6
 7    def __init__(self, owner: str, balance: int = 0) -> None:
 8        """口座の名義人と残高を初期化します。"""
 9        self.owner: str = owner
10        self.balance: int = balance
11
12    def deposit(self, amount: int) -> None:
13        """口座に指定した金額を入金します。"""
14        self.balance += amount
15
16    def withdraw(self, amount: int) -> None:
17        """口座から指定した金額を出金します。残高が不足している場合は出金しません。"""
18        if amount > self.balance:
19            print("残高が不足しているため、出金できません。")
20            return
21        self.balance -= amount
22
23    def __str__(self) -> str:
24        """口座の情報を文字列として返します。"""
25        return f"{self.owner} の口座残高: {self.balance} 円"
26
27
28class SavingsAccount(BankAccount):
29    """利息の計算機能を持つ、普通口座を継承した定期預金口座のクラスです。"""
30
31    def __init__(self, owner: str, balance: int = 0, interest_rate: float = 0.01) -> None:
32        """口座の名義人、残高、利率を初期化します。"""
33        super().__init__(owner, balance)
34        self.interest_rate: float = interest_rate
35
36    def add_interest(self) -> None:
37        """利率に応じた利息を残高に追加します。"""
38        self.balance += int(self.balance * self.interest_rate)
39
40
41def main() -> None:
42    """口座クラスの使用例を表示します。"""
43    account: BankAccount = BankAccount("伊藤", 1000)
44    account.deposit(500)
45    account.withdraw(200)
46    print(account)
47
48    savings: SavingsAccount = SavingsAccount("渡辺", 10000, 0.05)
49    savings.add_interest()
50    print(savings)
51
52
53if __name__ == "__main__":
54    main()
