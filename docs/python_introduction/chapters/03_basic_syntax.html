第 3 章 基本文法

print 関数による出力

画面に文字列や数値を表示するには、print 関数を使用します。print 関数には、表示したい値をカンマ区切りで複数渡すことができます。

print("こんにちは")
print("合計:", 10)

コメント

Python では、行の先頭に # を書くことで、その行をコメントとして扱えます。コメントに書かれた内容はプログラムの実行に影響を与えないため、コードの説明を書き残すために利用します。

# これはコメントです。プログラムの実行には影響しません。
print("Hello")  # 行の途中からコメントを書くこともできます。

変数

変数とは、値に名前を付けて保存しておく仕組みです。Python では、次のように = 記号を使って変数に値を代入します。

name = "太郎"
age = 20

変数名を付ける際は、次のようなルールと慣習があります。

  • 使える文字は、英数字とアンダースコア（ _ ）です。

  • 数字から始めることはできません。

  • 複数の単語をつなげる場合は、user_name のようにアンダースコアで区切ります（スネークケース）。

  • 変数の内容が分かる名前を付けます。

型ヒントの基礎

Python の変数には、C 言語や Java のような型の宣言は不要です。代入した値によって、変数の型が自動的に決まります。ただし、変数に格納する値の種類を明確にしておきたい場合は、次のように型ヒント（type hint）を付けて宣言することもできます。

name: str = "太郎"
age: int = 20

型ヒントは、変数名の後ろにコロン（ : ）を挟んで型名を書くことで指定します。代表的な型ヒントには、次のようなものがあります。

型ヒント

対応するデータ型

str

文字列

int

整数

float

小数

bool

真偽値

型ヒントを付けても、実行時の動作は変わりません。型ヒントはあくまで人が読むための注釈であり、Python は実行時に型ヒントと異なる値が代入されてもエラーにはしません。ただし、mypy のような型チェックツールを使うと、型ヒントと実際の値が矛盾していないかを、プログラムを実行する前に確認できます。本資料のサンプルコードには、すべて型ヒントを付けています。関数の引数や戻り値への型ヒントの付け方は第 7 章「関数」で、リストや辞書といったデータ構造への型ヒントの付け方は第 6 章「データ構造」で、それぞれ説明します。
