第 1 章 はじめに

Python とは

Python は、シンプルで読みやすい文法を特徴とするプログラミング言語です。1991 年に Guido van Rossum 氏によって最初のバージョンが公開されて以来、世界中で幅広く使われています。文法が英語の文章に近く、初心者でも比較的短い学習期間でプログラムを書けるようになることから、プログラミング教育の入門言語としてもよく採用されています。

Python が使われている分野

Python は汎用的なプログラミング言語であり、次のような幅広い分野で利用されています。

  • Web アプリケーションの開発

  • データ分析や統計処理

  • 機械学習や人工知能の研究、開発

  • 業務の自動化やスクリプト処理

  • 教育用のプログラミング言語

このように用途が広いことも、Python が世界中の開発者から支持されている理由の 1 つです。

Python の特徴

Python には、次のような特徴があります。

読みやすい文法

インデント（字下げ）によってブロックを表現するため、誰が書いてもコードの見た目が揃いやすく、他人が書いたコードも読みやすいという特徴があります。

豊富なライブラリ

標準ライブラリに加えて、世界中の開発者が公開している外部ライブラリを利用することで、複雑な処理も少ないコードで実現できます。

多くの環境で動作する

Windows、macOS、Linux など、主要な OS 上で同じように動作します。

本資料の対象読者

本資料は、プログラミングの経験がない方や、これから Python を学び始めたい方を対象としています。プログラミングに関する用語は、初めて登場する箇所でその都度説明します。すでに他のプログラミング言語の経験がある方は、第 3 章以降から読み進めても問題ありません。

本資料の構成

本資料は、次のような構成になっています。

  1. 開発環境の準備

  2. 基本文法（変数と出力）

  3. データ型と演算子

  4. 制御構文（条件分岐と繰り返し）

  5. データ構造（リスト、タプル、辞書、集合）

  6. 関数

  7. 文字列操作

  8. ファイルの入出力

  9. 例外処理

  10. モジュールとパッケージ

  11. クラスとオブジェクト指向

  12. まとめと次のステップ

各章にはサンプルコードが用意されており、本文中のリンクからダウンロードして手元の環境で実行できます。実際にコードを動かしながら読み進めることで、理解がより深まります。

また、本資料の末尾には、登場した主な用語をまとめた「用語集」を付録として用意しています。用語の意味を確認したいときに、あわせてご利用ください。
