# シェーダーのファイルについて

このフォルダーの `.vert`（頂点シェーダー）と `.frag`（フラグメントシェーダー）は、1 つ上の examples フォルダーにある各サンプルの HTML ファイルから、シェーダーの部分だけを取り出したものです。閲覧用のファイルで、本文に掲載しているシェーダーもこのファイルから読み込んでいます。

* ファイル名は `サンプル名.vert` と `サンプル名.frag` です。1 つのサンプルに複数のシェーダーがある場合は、`08_animation_wave.vert` のように、用途を表す名前を付けています。
* これらのファイルは、HTML のビルド（build_html.bat）のたびに HTML ファイルから作り直されます。シェーダーを変更する場合は、HTML ファイルの中のシェーダーを書き換えてください。このフォルダーのファイルを直接書き換えても、次のビルドで上書きされます。
* サンプルを動かすには HTML ファイルを使ってください。ローカルに保存した HTML ファイルからは、ブラウザーのセキュリティ制限により別のファイルを読み込めないため、サンプルの HTML ファイルはシェーダーをファイルの中に含めています。
* 12_shader_editor.html のフラグメントシェーダーは、ページ上で編集する文字列として JavaScript の中にあるため、このフォルダーにはファイルがありません。
