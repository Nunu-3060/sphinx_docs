実行の方法

実行するには、次のものが必要である。

  • Python（3.10 以降）と matplotlib

  • Graphviz（dot コマンドを実行できるようにしておく）

  • 日本語のフォント（BIZ UDGothic、Yu Gothic、Meiryo などのいずれか）

ダウンロードしたファイルを置いたフォルダーで、次のように入力して実行する。--out の後に、画像を保存するフォルダーを指定する。

1pip install matplotlib
2python make_figures.py --out figures

figures フォルダーに、4 つの PNG 画像が作成される。本書をビルドするときは、Sphinx の設定ファイル（conf.py）からこのスクリプトを呼び出し、自動的に図を作成している。

図を作成するスクリプト（make_figures.py）

Graphviz の dot ファイルを PNG 画像に変換し、matplotlib で 2 つの日程の図を描く。日程の図では、転職活動を青、退職に関する活動をオレンジ、入社後の活動を緑で示している。帯の情報（見出し、開始、終了、色）をリストにまとめ、共通の関数 draw_bands で描いているため、帯の追加や期間の変更は、リストを書き換えるだけでできる。

make_figures.py をダウンロード

  1"""本書の図を作成するスクリプト。
  2
  3Graphviz の dot ファイルを PNG 画像に変換し、matplotlib で日程の図を描く。
  4作成した画像は、既定では ../source/figures に保存する。
  5
  6使い方::
  7
  8    python make_figures.py                # ../source/figures に保存する
  9    python make_figures.py --out figures  # 保存先を指定する
 10
 11必要なもの:
 12
 13* Graphviz（dot コマンドが実行できること）
 14* matplotlib
 15* 日本語のフォント（BIZ UDGothic、Yu Gothic、Meiryo などのいずれか）
 16"""
 17
 18import argparse
 19import shutil
 20import subprocess
 21from pathlib import Path
 22
 23import matplotlib
 24
 25matplotlib.use('Agg')  # 画面に表示せず、ファイルに保存する
 26
 27import matplotlib.pyplot as plt  # noqa: E402  (matplotlib.use の後に読み込む)
 28from matplotlib import font_manager  # noqa: E402
 29from matplotlib.axes import Axes  # noqa: E402
 30
 31# このスクリプトがあるフォルダー
 32HERE = Path(__file__).resolve().parent
 33
 34# 既定の保存先
 35DEFAULT_OUT_DIR = HERE.parent / 'source' / 'figures'
 36
 37# 図の色
 38BLUE = '#2a78d6'      # 転職活動
 39ORANGE = '#eb6834'    # 退職に関する活動
 40GREEN = '#3a9a6b'     # 入社後の活動
 41TEXT = '#0b0b0b'      # 文字
 42TEXT_SUB = '#52514e'  # 補助の文字
 43GRID = '#e4e3df'      # 目盛り線
 44
 45# 画像の解像度（dots per inch）
 46DPI = 150
 47
 48# 日本語を表示できるフォントの候補（先頭から順に探す）
 49JAPANESE_FONTS = [
 50    'BIZ UDGothic', 'Yu Gothic', 'Meiryo', 'Noto Sans CJK JP', 'IPAexGothic',
 51]
 52
 53# 帯 1 本分の情報：(見出し, 開始, 終了, 色)
 54Band = tuple[str, float, float, str]
 55
 56
 57def choose_font(candidates: list[str]) -> str:
 58    """候補のうち、インストールされている最初のフォントの名前を返す。"""
 59    installed = {f.name for f in font_manager.fontManager.ttflist}
 60    for name in candidates:
 61        if name in installed:
 62            return name
 63    raise RuntimeError('日本語のフォントが見つからない。')
 64
 65
 66plt.rcParams['font.family'] = choose_font(JAPANESE_FONTS)
 67plt.rcParams['axes.edgecolor'] = TEXT_SUB
 68plt.rcParams['axes.labelcolor'] = TEXT
 69plt.rcParams['xtick.color'] = TEXT_SUB
 70plt.rcParams['ytick.color'] = TEXT_SUB
 71plt.rcParams['text.color'] = TEXT
 72
 73
 74def render_dot(src: Path, dst: Path) -> None:
 75    """Graphviz の dot ファイルを PNG 画像に変換する。"""
 76    dot = shutil.which('dot')
 77    if dot is None:
 78        raise RuntimeError('Graphviz の dot コマンドが見つからない。')
 79    subprocess.run(
 80        [dot, '-Tpng', f'-Gdpi={DPI}', str(src), '-o', str(dst)],
 81        check=True,
 82    )
 83
 84
 85def style_axes(ax: Axes) -> None:
 86    """グラフの枠と目盛り線を目立たない見た目にする。"""
 87    for side in ('top', 'right', 'left'):
 88        ax.spines[side].set_visible(False)
 89    ax.tick_params(length=0)
 90    ax.grid(axis='x', color=GRID, linewidth=0.8)
 91    ax.set_axisbelow(True)
 92
 93
 94def draw_bands(ax: Axes, bands: list[Band]) -> None:
 95    """帯を上から順に描き、縦軸に見出しを付ける。"""
 96    n = len(bands)
 97    for row, (_, start, end, color) in enumerate(bands):
 98        y = n - 1 - row  # 1 つ目の帯を一番上に描く
 99        ax.barh(y, end - start, left=start, height=0.55, color=color)
100    ax.set_yticks(range(n))
101    ax.set_yticklabels([b[0] for b in reversed(bands)])
102    ax.set_ylim(-0.6, n - 0.4)
103
104
105def mark(ax: Axes, x: float, top: float, label: str) -> None:
106    """縦の点線と、その上に見出しを描く。"""
107    ax.axvline(x, color=TEXT_SUB, linewidth=1, linestyle=':')
108    ax.text(x, top, label, ha='center', va='bottom', fontsize=9, color=TEXT_SUB)
109
110
111def plot_overview(dst: Path) -> None:
112    """転職の流れと、各段階のおおよその期間の例を描く（第 2 章）。
113
114    横軸は、転職を考え始めてからの月数である。
115    """
116    bands: list[Band] = [
117        ('転職を考える・情報を集める', 0.0, 1.0, BLUE),
118        ('経歴の棚卸し・応募書類の作成', 0.5, 1.5, BLUE),
119        ('求人を探す・応募する', 1.0, 3.0, BLUE),
120        ('選考', 1.5, 3.5, BLUE),
121        ('内定・労働条件の確認', 3.0, 4.0, BLUE),
122        ('退職の申し出・引き継ぎ', 4.0, 5.5, ORANGE),
123        ('有給休暇の消化', 5.5, 6.0, ORANGE),
124        ('入社後の手続き・オンボーディング', 6.0, 9.0, GREEN),
125    ]
126    fig, ax = plt.subplots(figsize=(9, 4.2))
127    draw_bands(ax, bands)
128    top = len(bands) - 0.45
129    mark(ax, 4.0, top, '内定の承諾')
130    mark(ax, 6.0, top, '入社')
131    ax.set_xticks(range(10))
132    ax.set_xticklabels([f'{m} か月' for m in range(10)], fontsize=9)
133    ax.set_xlim(0, 9)
134    ax.set_xlabel('転職を考え始めてからの期間')
135    style_axes(ax)
136    fig.savefig(dst, dpi=DPI, bbox_inches='tight', facecolor='white')
137    plt.close(fig)
138
139
140def plot_schedule(dst: Path) -> None:
141    """内定の承諾から入社日までを逆算した日程の例を描く（第 8 章）。
142
143    横軸は、内定を承諾した週を 0 とした週数である。
144    """
145    bands: list[Band] = [
146        ('上司に退職を申し出る', 0.5, 1.0, ORANGE),
147        ('退職日の確定・退職届の提出', 1.0, 1.5, ORANGE),
148        ('引き継ぎ', 1.0, 6.0, ORANGE),
149        ('有給休暇の消化', 6.0, 9.0, ORANGE),
150        ('入社の準備', 7.0, 9.0, GREEN),
151    ]
152    fig, ax = plt.subplots(figsize=(9, 3.2))
153    draw_bands(ax, bands)
154    top = len(bands) - 0.45
155    mark(ax, 0.0, top, '内定の承諾')
156    mark(ax, 6.0, top, '最終出社日')
157    mark(ax, 9.0, top, '退職日／入社日')
158    ax.set_xticks(range(11))
159    ax.set_xticklabels([f'{w} 週' for w in range(11)], fontsize=9)
160    ax.set_xlim(-0.2, 10)
161    ax.set_xlabel('内定を承諾してからの期間')
162    style_axes(ax)
163    fig.savefig(dst, dpi=DPI, bbox_inches='tight', facecolor='white')
164    plt.close(fig)
165
166
167def make_all(out_dir: Path) -> list[Path]:
168    """すべての図を作成し、作成したファイルの一覧を返す。"""
169    out_dir.mkdir(parents=True, exist_ok=True)
170    made: list[Path] = []
171
172    for name in ('selection_flow', 'procedures'):
173        dst = out_dir / f'{name}.png'
174        render_dot(HERE / f'{name}.dot', dst)
175        made.append(dst)
176
177    plots = {
178        'overview.png': plot_overview,
179        'schedule.png': plot_schedule,
180    }
181    for filename, plot in plots.items():
182        dst = out_dir / filename
183        plot(dst)
184        made.append(dst)
185    return made
186
187
188def main() -> None:
189    """コマンドラインから実行したときの処理。"""
190    parser = argparse.ArgumentParser(description='本書の図を作成する。')
191    parser.add_argument('--out', type=Path, default=DEFAULT_OUT_DIR, help='画像の保存先のフォルダー')
192    args = parser.parse_args()
193    for path in make_all(args.out):
194        print(f'作成した：{path}')
195
196
197if __name__ == '__main__':
198    main()

選考の流れ（selection_flow.dot）

選考の段階を箱で表し、矢印でつないでいる。会社によって行う場合と行わない場合がある段階は、点線の箱にしている。rank=same で 3 つずつを同じ段に並べ、図が横に長くなりすぎないようにしている。

公的手続きの分岐（procedures.dot）

質問と共通の手続きを灰色の箱、転職先が行う手続きを青色の箱、自分で行う手続きをオレンジ色の箱で表している。箱の中の文字は、HTML に似た書き方で、見出しを太字にしている。

検査の設定（setup.cfg）

make_figures.py は、flake8（コードの書き方の検査）と mypy（型の検査）で問題がないことを確認している。setup.cfg は、その設定ファイルである。flake8 では 1 行の長さを 120 文字まで認め、mypy では最も厳しい検査（strict = True）を行う。

setup.cfg をダウンロード

1[flake8]
2max-line-length = 120
3exclude = .venv,__pycache__
4
5[mypy]
6python_version = 3.10
7strict = True

検査は、examples フォルダーで次のように入力して実行する。

1pip install flake8 mypy
2flake8 make_figures.py
3mypy make_figures.py
