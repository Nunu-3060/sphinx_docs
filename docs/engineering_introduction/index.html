工学入門

本書は、ソフトウェアエンジニアとハードウェアエンジニアの両方に向けた工学の入門書です。機械・電気・情報といった個別の分野の知識ではなく、分野をまたいで共通に使える「工学的なものの考え方」を扱います。具体的には、単位と見積もり、モデル化と近似、誤差と不確かさ、数値計算、制御、信号処理、エネルギーと熱、設計とトレードオフ、最適化、統計、検証、信頼性、安全、技術的な内容の伝え方、技術者倫理です。多くの章には Python のサンプルコードがあり、数式で説明した内容を実際に計算して確かめられます。
