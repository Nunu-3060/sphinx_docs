2. 単位と次元

工学で扱う量の多くは、数値と単位の組で表されます。「長さ 3」では意味をなさず、「長さ 3 m」で初めて量が決まります。本章では、単位系の基本、次元の考え方、桁の見積もりを説明します。

2.1. SI 単位系

2.3. デシベル

電子回路、音響、通信の分野では、比をデシベル（dB）で表すことがよくあります。デシベルは、電力のように 2 乗に比例する量と、電圧のように振幅を表す量とで定義が異なります。

(2.1)\[\begin{split}\begin{aligned} L_{\mathrm{P}} &= 10 \log_{10} \frac{P_1}{P_0} \ \mathrm{[dB]} && \text{（電力の比）} \\ L_{\mathrm{V}} &= 20 \log_{10} \frac{V_1}{V_0} \ \mathrm{[dB]} && \text{（電圧の比）} \end{aligned}\end{split}\]

電力は電圧の 2 乗に比例するため、電圧が 10 倍になると電力は 100 倍になり、どちらの式でも 20 dB になります。よく使う値を覚えておくと、計算が速くなります。

2.4. 次元と次元解析

物理量の種類を、基本的な量の組み合わせで表したものを次元と呼びます。長さを L、質量を M、時間を T で表すと、速度の次元は \(\mathrm{L\,T^{-1}}\)、力の次元は \(\mathrm{M\,L\,T^{-2}}\) です。

次元には、次の規則があります。

  • 足し算・引き算・比較ができるのは、同じ次元の量どうしだけです。

  • 掛け算・割り算をすると、次元の指数が足し引きされます。

  • 指数関数、対数関数、三角関数の引数は、無次元でなければなりません。

この規則を使うと、式の誤りを見つけられます。計算式を書いたら、両辺の次元が一致するかを確かめる習慣を付けましょう。たとえば、運動エネルギーを \(E = mv\) と書き間違えた場合、右辺の次元は \(\mathrm{M\,L\,T^{-1}}\) で、エネルギーの次元 \(\mathrm{M\,L^{2}\,T^{-2}}\) と一致しないため、誤りだと分かります。

次元解析は、式の検算だけでなく、関係式の形を推定するのにも使えます。たとえば、振り子の周期 \(T\) が、糸の長さ \(L\)、おもりの質量 \(m\)、重力加速度 \(g\) で決まると考えます。\(T = C L^{a} m^{b} g^{c}\)（\(C\) は無次元の定数）とおいて両辺の次元を比べると、次のようになります。

\[\mathrm{T} = \mathrm{L}^{a} \, \mathrm{M}^{b} \, (\mathrm{L\,T^{-2}})^{c} = \mathrm{L}^{a + c} \, \mathrm{M}^{b} \, \mathrm{T}^{-2c}\]

指数を比べると \(a + c = 0\)、\(b = 0\)、\(-2c = 1\) なので、\(a = 1/2\)、\(b = 0\)、\(c = -1/2\) です。つまり、周期は \(T = C\sqrt{L/g}\) の形で、質量によらないことが、運動方程式を解かずに分かります。定数 \(C\) は次元解析では決まりませんが、第 3 章で振れ幅が小さい場合に \(C = 2\pi\) となることを示します。

2.5. 単位の取り違えによる事故

1999 年、NASA の火星探査機マーズ・クライメイト・オービターは、火星の周回軌道に入る際に予定より低い高度を通過し、失われました。原因の 1 つは、地上のソフトウェアの 1 つが、探査機の姿勢制御で生じる力積をヤード・ポンド法の単位（ポンド重秒、lbf·s）で出力していたのに、それを受け取る軌道計算のソフトウェアは SI 単位（ニュートン秒、N·s）の値だと解釈していたことでした。1 lbf·s は約 4.45 N·s なので、力積は実際の約 4.45 分の 1 と見積もられ、軌道の予測がずれていきました。

この事故の教訓は、次のとおりです。

  • インターフェース仕様書には、すべての量の単位を明記します。

  • 単位はプログラムの中でも明示します。変数名に単位を含める（例: impulse_n_s）、単位を扱えるライブラリーや型を使う、などの方法があります。

  • 異常な値に気付いた担当者が、それを確認し解決するまで追跡する仕組みを作ります。この事故では、軌道のずれに気付いていた担当者がいたにもかかわらず、問題が解決されませんでした。

2.6. サンプルコード: 次元の検査

ch02_dimension.py は、数値と次元の指数を組にした Quantity クラスを定義し、次元の異なる量の足し算をエラーとして検出します。

44@dataclass(frozen=True)
45class Quantity:
46    """SI 単位で表した数値と、その次元の組。"""
47
48    value: float
49    dim: Dimension
50
51    def __add__(self, other: Quantity) -> Quantity:
52        if self.dim != other.dim:
53            raise DimensionError(
54                f"次元が異なる量は足せません: {format_dimension(self.dim)}"
55                f" + {format_dimension(other.dim)}")
56        return Quantity(self.value + other.value, self.dim)
57
58    def __mul__(self, other: Quantity) -> Quantity:
59        dim = tuple(a + b for a, b in zip(self.dim, other.dim))
60        return Quantity(self.value * other.value, _as_dimension(dim))
61
62    def __truediv__(self, other: Quantity) -> Quantity:
63        dim = tuple(a - b for a, b in zip(self.dim, other.dim))
64        return Quantity(self.value / other.value, _as_dimension(dim))
65
66    def __str__(self) -> str:
67        return f"{self.value:.6g} [{format_dimension(self.dim)}]"

__add__ メソッドでは、2 つの量の次元が一致しない場合に例外を送出します。__mul__ と __truediv__ メソッドでは、次元の指数を足し引きします。実行すると、次のように表示されます。

速度: 25 [L^1 T^-1]
運動エネルギー: 375000 [L^2 M^1 T^-2]  (L^2 M^1 T^-2 = J)
エラーを検出しました: 次元が異なる量は足せません: L^1 + T^1
100.0 lbf・s = 444.8 N・s
lbf・s の値を N・s と解釈すると、力積を 4.45 分の 1 に見積もります。

ただし、このクラスは「次元」を検査するだけで、「単位」は検査しません。lbf·s と N·s はどちらも力積で、次元は同じです。マーズ・クライメイト・オービターのような取り違えを防ぐには、値を内部では必ず SI 単位で持ち、入出力の境界で単位を変換する、という規則を守ることが大切です。実務では、単位まで扱えるライブラリー（Python では Pint など）の利用も検討します。

2.7. 桁の見積もり

詳しい計算の前に、答えのおおよその桁を見積もっておくと、計算の誤りや設計の破綻に早く気付けます。分からない量を、推定しやすい量の積に分解して概算する方法を、物理学者エンリコ・フェルミにちなんでフェルミ推定と呼びます。

例として、ウェブサービスのアクセスログが 1 日に何バイトになるかを見積もります。

  1. 1 秒あたりのリクエスト数: 平均 1000 件

  2. 1 日の秒数: 約 \(10^{5}\) 秒（正確には 86 400 秒）

  3. 1 件のログの大きさ: 約 500 バイト

これらを掛けると、\(10^{3} \times 10^{5} \times 500 = 5 \times 10^{10}\) バイト、つまり 1 日に約 50 GB です。1 年では約 18 TB になるため、保存期間と圧縮の方針を設計の初期に決めておく必要があると分かります。

ハードウェアの例として、スマートフォンを 1 日 1 回充電するときの年間の電力量を見積もります。

  1. 電池の容量: 約 4000 mAh、電圧は約 3.8 V → 約 15 Wh

  2. 充電の効率: 約 80 % → 1 回の充電で約 19 Wh

  3. 1 年: 365 回

これらを掛けると、約 7 kWh です。家庭の年間の電力消費量（数千 kWh）と比べると、ごくわずかだと分かります。

見積もりの精度は、桁が合っていれば十分です。各量の誤差が 2 倍程度あっても、誤差は掛け合わせる間に打ち消し合うことが多く、結果の桁は大きく外れません。見積もりと詳細な計算の結果が 1 桁以上違う場合は、どちらかに誤りがある可能性を疑います。

2.8. まとめ

  • SI 単位系は 7 つの基本単位からなり、2019 年からすべてが物理定数で定義されています。

  • 10 の累乗を表す SI 接頭語と、2 の累乗を表す 2 進接頭語を区別します。

  • 電力の比は \(10\log_{10}\)、振幅の比は \(20\log_{10}\) でデシベルに換算します。

  • 式の両辺の次元が一致するかを確かめると、多くの誤りを見つけられます。次元解析で式の形を推定することもできます。

  • 詳しい計算の前に、桁を見積もる習慣を付けます。
