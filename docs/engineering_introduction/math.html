数学の補足

本文で使った数学のうち、高校数学の範囲を超えるものを補足します。

複素数

2 乗すると \(-1\) になる数を虚数単位と呼びます。数学では \(i\) と書きますが、電気工学では電流の記号 \(i\) と区別するため \(j\) と書くのが一般的で、本書もこれに従います。

\[j^2 = -1\]

実数 \(a, b\) を使って \(z = a + jb\) と表される数を複素数と呼び、\(a\) を実部、\(b\) を虚部と呼びます。複素数は、横軸を実部、縦軸を虚部とした平面（複素平面）上の点として表せます。原点からの距離を絶対値、実軸の正の向きとなす角を偏角と呼びます。

(1)\[|z| = \sqrt{a^2 + b^2}, \qquad \arg z = \operatorname{atan2}(b, a)\]

複素数の掛け算では、絶対値は掛け合わされ、偏角は足し合わされます。この性質が、振幅と位相を同時に扱うのに便利です。Python では 1 + 2j のように複素数を書けます。絶対値は abs 関数、偏角は cmath.phase 関数や numpy.angle 関数で求められます。

オイラーの公式

指数関数と三角関数は、虚数単位を通じて次の式で結ばれています。これをオイラーの公式と呼びます。

(2)\[e^{j\theta} = \cos\theta + j\sin\theta\]

\(e^{j\theta}\) は、複素平面上で絶対値 1、偏角 \(\theta\) の点です。\(\theta = \omega t\) とおくと、\(e^{j\omega t}\) は時間とともに角速度 \(\omega\) で単位円の上を回る点を表し、その実部は \(\cos\omega t\) です。

正弦波と複素数

振幅 \(A\)、位相 \(\varphi\) の正弦波は、オイラーの公式を使って次のように表せます。

(3)\[A\cos(\omega t + \varphi) = \operatorname{Re}\left[ A e^{j\varphi} \, e^{j\omega t} \right]\]

振幅と位相の情報は、複素数 \(A e^{j\varphi}\) にまとめられています。この表し方を使うと、次の 2 つのことが簡単になります。

  • 微分: \(e^{j\omega t}\) を時間で微分すると \(j\omega e^{j\omega t}\) になります。微分が「\(j\omega\) を掛けること」に置き換わるため、微分方程式が掛け算と割り算だけの式になります。これが、第 6 章で伝達関数に \(s = j\omega\) を代入して周波数応答を求めた理由です。

  • 振幅と位相の変化: 線形時不変システムに正弦波を入力すると、出力は入力に複素数 \(G(j\omega)\) を掛けたものになります。複素数の掛け算の性質から、振幅は \(|G(j\omega)|\) 倍になり、位相は \(\arg G(j\omega)\) だけずれます。

離散フーリエ変換

第 7 章の離散フーリエ変換（式 (7.2)）の \(e^{-j 2\pi k n / N}\) は、オイラーの公式により \(\cos(2\pi k n / N) - j\sin(2\pi k n / N)\) です。つまり、離散フーリエ変換は、信号に周波数 \(k f_s / N\) の余弦波と正弦波をそれぞれ掛けて足し合わせ、信号にその周波数の成分がどれだけ含まれるかを調べる計算です。結果の \(X_k\) の絶対値がその周波数の成分の大きさ、偏角が位相を表します。

確率分布

本文では、いくつかの確率分布を使いました。連続的な値をとる確率変数の分布は、確率密度関数 \(f(x)\) で表します。\(x\) が区間 \([a, b]\) に入る確率は、\(f(x)\) をその区間で積分した値です。

各分布の関係と使い方の要点を補足します。

  • ポアソン分布と指数分布: ランダムな事象が平均して単位時間あたり \(\lambda\) 回起きるとき、一定時間に起きる回数はポアソン分布に従い、事象と事象の間隔は指数分布に従います。M/M/1 待ち行列（第 3 章）は、到着の間隔と処理時間がどちらも指数分布に従うと仮定したモデルです。

  • 指数分布の無記憶性: 指数分布では、「すでに \(t\) 時間故障していない」という情報が、その後の寿命の分布に影響しません。故障率が一定であることと同じ意味で、摩耗しないことを表しています。

  • ワイブル分布: 形状パラメーター \(m\) が 1 のとき、指数分布と一致します。\(m < 1\) で故障率が時間とともに下がり（初期故障）、\(m > 1\) で上がります（摩耗故障）。\(\eta\) は尺度パラメーターです。

独立な確率変数の和

本書では、独立なばらつきを 2 乗和の平方根で合成する計算を何度も使いました（第 4 章の不確かさの伝播、第 11 章の RSS 法）。その根拠は、次の性質です。

互いに独立な確率変数 \(X\) と \(Y\) について、和の平均は平均の和、和の分散は分散の和になります。

(4)\[E[X + Y] = E[X] + E[Y], \qquad V[X + Y] = V[X] + V[Y]\]

標準偏差は分散の平方根なので、和の標準偏差は、それぞれの標準偏差の 2 乗和の平方根になります。独立でない（相関がある）場合は、この式に共分散の項が加わります。

さらに、中心極限定理によれば、多数の独立な確率変数の和の分布は、元の分布の形によらず正規分布に近づきます。多くの小さな要因が積み重なって生じる測定値のばらつきや、多数の部品の寸法を足し合わせた結果が正規分布に近くなるのは、このためです。ただし、少数の要因が支配的な場合や、外れ値が出やすい分布では、正規分布の近似は成り立ちにくくなります。
