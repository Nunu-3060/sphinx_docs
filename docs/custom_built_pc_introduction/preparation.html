4. 組み立ての準備

本章では、組み立てを始める前に用意するものと、確認しておくことを説明する。準備を整えておくと、作業中に手が止まることが減り、失敗も防ぎやすくなる。

4.2. 静電気対策

PC のパーツは静電気で壊れることがある。人体に溜まった静電気は、触れていると気付かない程度の量でも電子部品を損傷させる場合がある。次の対策を行う。

  • 作業の前と作業中に時々、金属製のもの（電源プラグを抜いた状態のケースの金属部分など）に触れて放電する。

  • 化学繊維の衣服やカーペットの上での作業を避ける。冬など空気が乾燥する季節は特に注意する。

  • パーツは端を持ち、端子や基板上の部品に直接触れない。

  • マザーボードは、マザーボードの箱の上に置いて作業する。パーツが入っていた帯電防止袋の外側は導電性を持つ場合があり、その上に置いて通電すると短絡（ショート）の原因となる。

4.3. 作業場所

  • 机の上に、ケースを横に寝かせて置ける広さを確保する。

  • 明るい場所で作業する。

  • 近くにコンセントを用意する。動作確認でモニターも使う。

  • 小さなネジを落としても見つけやすいよう、床を片付けておく。

4.4. マニュアルで事前に確認すること

マザーボードとケースのマニュアルを読み、次の項目を確認しておく。マニュアルはメーカーの Web サイトから PDF でダウンロードできることが多く、検索しやすい。

表 4.2 事前に確認する項目

項目

確認する内容

メモリの推奨スロット

2 枚挿しの場合にどのスロットを使うか。多くのマザーボードでは CPU から 2 番目と 4 番目のスロット（A2 と B2 などと表記される）を使う。

M.2 スロット

1 枚目の SSD をどのスロットに取り付けるか。レーンの共有による制限はあるか。

フロントパネルのコネクタ

電源スイッチ、リセットスイッチ、LED のピンの配置。

CPU 補助電源のコネクタ

本数と位置。

ファン用のコネクタ

CPU クーラー、簡易水冷のポンプ、ケースファンをどこに接続するか。

スタンドオフの位置

ケースに最初から取り付けられているスタンドオフの位置が、マザーボードのネジ穴と合っているか（ケースのマニュアル）。

ファンとラジエーターの位置

取り付けられる位置と向き（ケースのマニュアル）。

4.5. 開封時の確認

  • 付属品がそろっているかを、マニュアルの付属品一覧と照らし合わせる。

  • 外観に損傷が無いかを確認する。

  • マザーボードの CPU ソケットのピンが曲がっていないかを確認する。2026 年 10 月時点の主なソケットは、ピンがマザーボード側にある LGA 方式であり、ピンは非常に細く曲がりやすい。保護カバーは CPU の取り付けまで外さない。
