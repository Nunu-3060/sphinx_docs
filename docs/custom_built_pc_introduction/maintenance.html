10. 運用・保守・アップグレード

本章では、PC を長く安定して使うための保守と、性能が足りなくなったときのアップグレードの考え方を説明する。

10.1. 清掃

ケース内に溜まったホコリは、冷却性能の低下と騒音の増加の原因となる。設置場所の環境にもよるが、3 か月から半年に 1 回を目安に清掃する。

  • 吸気口のフィルターを外して洗うか、ホコリを払う。

  • ケース内のホコリは、エアダスターで吹き飛ばす。ファンに風を当てるときは、ファンを指で押さえて回らないようにする。ファンが高速で空回りすると、軸受けを傷める原因となる。

  • 掃除機をケース内に直接入れることは避ける。静電気や、ノズルがパーツに接触する原因となる。

清掃は、電源を切り、電源ケーブルを抜いてから行う。

10.2. サーマルグリスの塗り直し

サーマルグリスは、数年の使用で劣化して冷却性能が下がることがある。以前と同じ使い方で CPU の温度が明らかに上がってきた場合は、まず清掃を行い、それでも改善しなければサーマルグリスを塗り直す。

塗り直す際は、CPU と CPU クーラーの底面から古いサーマルグリスを無水エタノールと布で拭き取ってから、新しいサーマルグリスを塗る。

10.4. アップグレード

自作 PC は、パーツ単位で性能を向上できる。アップグレードの前に、どのパーツが性能を制限しているか（ボトルネック）を確認する。

10.4.1. ボトルネックを確認する

遅いと感じる作業をしながら、各パーツの使用率を確認する。使用率が常に高い状態のパーツがボトルネックである可能性が高い。

  • Windows：タスクマネージャーの「パフォーマンス」タブ

  • Linux：top コマンドや htop コマンド（CPU とメモリ）、nvidia-smi コマンド（NVIDIA の GPU）

メモリの使用率が高く、ストレージへの読み書きが頻繁に発生している場合は、メモリ容量の不足が疑われる。

10.5. 廃棄と譲渡

PC やストレージを廃棄・譲渡する前には、ストレージのデータを確実に消去する。

  • ファイルの削除やフォーマットだけでは、データを復元できる場合がある。

  • SSD は、データの書き込み位置を内部で分散させる仕組みを持つため、ファイルの上書きによる消去が確実ではない。SSD 自体が備える消去機能を使う。マザーボードの UEFI に SSD の消去機能が用意されていることもある。

  • Linux では、NVMe SSD の消去機能を nvme-cli の nvme format コマンドで実行できる。指定したデバイスのデータは全て消えるため、デバイス名を必ず確認する。

リスト 10.1 Linux で NVMe SSD のデータを消去する
1sudo apt install nvme-cli
2# 消去する SSD のデバイス名を確認する
3sudo nvme list
4# --ses=1 はユーザーデータの消去を指定する
5sudo nvme format /dev/nvme0n1 --ses=1

Windows のライセンスは、購入形態によって別の PC へ移行できる場合がある。譲渡する前に条件を確認する。

自作 PC は、メーカーによる PC の回収の対象とならない場合がある。廃棄の方法は、住んでいる地域の自治体の案内に従う。
