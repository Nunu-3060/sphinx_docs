自作 PC 入門

本書は、PC を自作した経験のないエンジニアを対象に、パーツの選定から組み立て、OS のインストール、動作確認、運用までを解説する入門書である。

各作業の手順だけでなく、その作業を行う理由と判断の基準を説明する。手順を覚えるのではなく、自分の用途に合わせて判断できるようになることを目指す。
