2. PC を構成するパーツ

本章では、デスクトップ PC を構成する各パーツの役割と、仕様の読み方を説明する。

本書では、拡張カードとして取り付ける GPU を単に「GPU」と呼び、CPU に統合された GPU は「内蔵 GPU」と呼んで区別する。

2.1. 全体像

PC の主なパーツと、その接続関係を次の図に示す。全てのパーツはマザーボードを介して接続され、電源ユニットから電力の供給を受ける。

CPU にはメモリ、GPU、1 枚目の M.2 SSD が直接接続される。その他の機器の多くは チップセット を経由して CPU に接続される。どの機器がどの経路で接続されるかはマザーボードによって異なり、マニュアルのブロック図で確認できる。

2.2. CPU

CPU はプログラムの命令を実行する、PC の中心となるパーツである。2026 年 10 月時点のデスクトップ向け CPU は、主に Intel と AMD の 2 社が提供している。

表 2.1 CPU の主な仕様項目

項目

意味と見方

コア数 / スレッド数

同時に処理できる命令の流れの数。コンパイル、動画のエンコード、仮想マシンなど、並列化しやすい処理ほど影響が大きい。

クロック周波数

1 コアあたりの処理速度の目安。同じ世代・同じメーカーの製品同士でなければ単純に比較できない。

ソケット

マザーボードに取り付けるための端子の形状。CPU とマザーボードで一致している必要がある。

TDP と最大消費電力

TDP は冷却設計の目安となる値であり、最大消費電力ではない。電源容量や CPU クーラーの選定には最大消費電力（Intel では PL2 または最大ターボパワー、AMD では PPT）を使う。

内蔵 GPU の有無

内蔵 GPU があれば、GPU を取り付けなくても画面を表示できる。型番の末尾の記号で区別されることが多い（例：Intel の F 付きモデルは内蔵 GPU を持たない）。

対応メモリ

対応するメモリの規格（DDR4 / DDR5）と速度。

PCIe の世代とレーン数

GPU や M.2 SSD を接続するための帯域。

2026 年 10 月時点の主なソケットは、AMD が AM5、Intel が LGA1851 である。ソケットは数世代ごとに変わるため、CPU とマザーボードは必ず組み合わせて選ぶ。

CPU には、CPU クーラーが付属する製品と付属しない製品がある。付属しない製品の場合は、CPU クーラーを別に購入する必要がある。

2.3. マザーボード

マザーボードは全てのパーツを接続する基板である。使える CPU、メモリ、ストレージの数、拡張性はマザーボードによって決まる。

表 2.2 マザーボードの主な仕様項目

項目

意味と見方

ソケット

取り付けられる CPU の種類を決める。

チップセット

USB、SATA などの機能と、使える機能の上限（オーバークロックの可否、拡張スロットの数など）を決める。同じソケットでも複数のグレードがある。

フォームファクタ

基板の大きさの規格。ATX、Micro-ATX、Mini-ITX が代表的である。ケースとの対応に関わる。

メモリスロット

対応するメモリの規格とスロット数。DDR4 と DDR5 の両方に対応するマザーボードは無い。

M.2 スロット

取り付けられる M.2 SSD の枚数と、各スロットの PCIe の世代。

PCIe スロット

GPU などの拡張カードを取り付けるスロット。

背面の入出力端子

USB、有線 LAN、Wi-Fi、オーディオ、映像出力（内蔵 GPU 用）の端子。

VRM

CPU に供給する電力を作る回路。消費電力の大きい CPU では VRM の品質と冷却が重要になる。

ファン用のコネクタ

ケースファンや CPU クーラーのファンを接続する端子の数。

マザーボードの背面の映像出力端子は、内蔵 GPU を使う場合にのみ使用する。GPU を取り付けた場合は、モニターを GPU の端子に接続する。

2.4. メモリ

メモリは CPU が処理中のデータを一時的に置く場所である。容量が不足すると、OS はストレージを代わりに使うため、動作が大幅に遅くなる。デスクトップ PC では DIMM と呼ばれる形状のメモリモジュールを使う。

表 2.3 メモリの主な仕様項目

項目

意味と見方

規格

DDR4 または DDR5。2026 年 10 月時点の現行プラットフォームは DDR5 を使う。DDR4 と DDR5 は切り欠きの位置が異なり、物理的に挿せない。

容量

モジュール 1 枚あたりの容量と枚数で表される（例：16 GB × 2 枚）。

速度

転送速度。DDR5-5600 のように表記され、単位は MT/s である。

タイミング

応答の遅延を表す数値の組。値が小さいほど遅延が小さい。

XMP / EXPO

定格の速度とタイミングを記録したプロファイル。UEFI で有効にすると定格の速度で動作する（初回起動と UEFI 設定 を参照）。

容量の目安を次の表に示す。

表 2.4 メモリ容量の目安

用途

容量の目安

事務作業、Web 閲覧

16 GB

ソフトウェア開発、ゲーム

32 GB

仮想マシンを複数動かす開発、機械学習、動画編集

64 GB 以上

メモリは同じ製品の 2 枚組を購入し、デュアルチャネル で動作させるのが基本である。4 枚挿しにすると、メモリコントローラーの負荷が増えて動作速度が下がる場合がある。

2.5. ストレージ

ストレージは OS、アプリケーション、データを保存するパーツである。主な種類を次の表に示す。速度は目安である。

表 2.5 ストレージの種類

接続方式

連続読み出し速度の目安

主な用途

NVMe SSD

M.2 スロット（PCIe）

PCIe 4.0：7,000 MB/s 程度、PCIe 5.0：10,000 MB/s 以上

OS とアプリケーション。本書が推奨する主ストレージ。

SATA SSD

SATA ケーブル

M.2 は形状の規格であり、接続方式の規格ではない。M.2 の形状をした SSD にも、NVMe（PCIe 接続）のものと SATA 接続のものがある。マザーボードの M.2 スロットがどちらに対応しているかを必ず確認する。M.2 SSD の大きさは「2280」（幅 22 mm、長さ 80 mm）が最も一般的である。

2.6. GPU

GPU は画面の描画と、大量のデータを並列に処理する計算を担当するパーツである。事務作業やソフトウェア開発が中心であれば、内蔵 GPU で十分な場合が多い。ゲーム、3D 描画、機械学習、動画編集では GPU が必要となる。

表 2.6 GPU の主な仕様項目

項目

意味と見方

演算性能

世代と製品のグレードで決まる。用途ごとのベンチマーク結果で比較するのが確実である。

VRAM 容量

GPU に搭載されたメモリの容量。機械学習では扱えるモデルの大きさを直接左右するため、最も重要な項目となる。

消費電力

最大消費電力（TBP などと表記される）。電源容量の選定に使う。

補助電源コネクタ

PCIe 8 ピン、または 12V-2x6 コネクタ。電源ユニット側に対応するケーブルが必要となる。

大きさ

長さ、高さ、厚み（占有するスロット数）。ケースに収まるかを確認する。

映像出力端子

HDMI、DisplayPort の数と規格。

機械学習の主要なフレームワークは NVIDIA の CUDA を中心に開発されてきた。AMD や Intel の GPU への対応も進んでいるが、使いたいフレームワークとバージョンが対応しているかを事前に確認する。

2.7. 電源ユニット

電源ユニット（PSU）は、コンセントの交流を PC 内部で使う直流（主に 12 V、5 V、3.3 V）に変換するパーツである。電源ユニットの品質は PC 全体の安定性と寿命に影響するため、予算を削るべきではない。

表 2.7 電源ユニットの主な仕様項目

項目

意味と見方

定格容量

継続して供給できる電力。選び方は パーツ選定と互換性の確認 で説明する。

変換効率

交流から直流への変換効率。80 PLUS 認証のグレード（Bronze、Gold、Platinum、Titanium など）が目安となる。

対応規格

ATX 3.0 以降は、GPU の瞬間的な電力の変動への対応が規定されており、12V-2x6 コネクタ（ATX 3.0 では 12VHPWR）のケーブルを備える。

ケーブルの方式

必要なケーブルだけを接続できるモジュラー式、一部だけ着脱できるセミモジュラー式、全て固定の非モジュラー式がある。モジュラー式は配線を整理しやすい。

大きさ

ATX サイズが一般的である。小型のケースでは SFX サイズを使う。

2.8. CPU クーラー

CPU クーラーは CPU の熱を逃がすパーツである。主な種類を次の表に示す。

表 2.8 CPU クーラーの種類

種類

特徴

注意点

空冷（トップフロー型）

ファンが基板に向かって風を送る。背が低く、CPU の周辺も冷やせる。

冷却性能は控えめである。

空冷（サイドフロー型）

塔のような形状で、ケースの前から後ろへ風を流す。冷却性能が高い。

背が高く、ケースやメモリと干渉することがある。

簡易水冷

冷却液で熱をラジエーターに運び、ファンで冷やす。冷却液の補充は不要である。

ラジエーター（240 mm、280 mm、360 mm など）を取り付ける場所がケースに必要となる。ポンプは消耗品である。

CPU クーラーを選ぶときは、対応するソケット、高さ（空冷の場合）またはラジエーターの大きさ（簡易水冷の場合）、冷却できる消費電力の目安を確認する。

2.9. ケース

ケースは全てのパーツを収める箱である。見た目だけでなく、パーツが収まるか、冷却しやすいか、作業しやすいかで選ぶ。

表 2.9 ケースの主な仕様項目

項目

意味と見方

対応フォームファクタ

取り付けられるマザーボードの大きさ。

GPU の最大長

取り付けられる GPU の長さの上限。前面にファンやラジエーターを取り付けると短くなる場合がある。

CPU クーラーの最大高

取り付けられる空冷 CPU クーラーの高さの上限。

ラジエーターの対応

簡易水冷のラジエーターを取り付けられる位置と大きさ。

ファン

付属するファンの数と、取り付けられる位置。

前面の入出力端子

前面の USB 端子の種類（USB Type-C の有無など）。

構造

前面がメッシュ状のケースは吸気しやすい。マザーボードの裏側に配線用の空間があると、ケーブルを整理しやすい。

2.10. OS とその他の用意するもの

パーツのほかに、次のものが必要となる。

  • OS：Windows 11 はライセンスの購入が必要である。Linux は無料で使えるディストリビューションが多い。詳細は OS のインストールと初期設定 で説明する。

  • OS のインストール用 USB メモリ：8 GB 以上のもの。内容は全て消去される。

  • モニター、キーボード、マウス

  • 有線 LAN ケーブル（マザーボードが Wi-Fi に対応していない場合、または OS のインストール時に Wi-Fi が使えない場合に備えて）
