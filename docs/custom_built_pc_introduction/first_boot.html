6. 初回起動と UEFI 設定

本章では、組み上がった PC を初めて起動する際の流れと、UEFI で確認・設定する項目を説明する。UEFI はマザーボードに搭載されたファームウェアであり、従来の BIOS に代わるものである。現在でも慣習的に BIOS と呼ばれることがある。

6.1. 起動前の確認

  • モニターのケーブルを接続する端子を確認する。GPU を取り付けた場合は GPU の端子に、取り付けていない場合はマザーボードの端子に接続する。

  • 電源ユニットの背面のスイッチを「I」（オン）にする。

  • 初回は、OS のインストール用 USB メモリ以外の不要な USB 機器を外しておく。

6.2. POST とメモリトレーニング

電源ボタンを押すと、マザーボードは POST と呼ばれる自己診断を行い、CPU、メモリ、GPU などが正しく認識されているかを確認する。POST に成功すると、メーカーのロゴが表示される。

初回起動時は、POST の前に メモリトレーニング が行われる。マザーボードがメモリとの通信に最適な設定を探す処理であり、DDR5 メモリでは数十秒から数分かかることがある。その間は画面に何も表示されないが、故障ではない。途中で電源を切らずに待つこと。メモリの構成や設定を変更した後にも、再びメモリトレーニングが行われる。

5 分以上待っても画面が表示されない場合は、トラブルシューティング を参照する。

6.3. デバッグ LED の読み方

多くのマザーボードには、POST のどの段階で止まっているかを示す デバッグ LED がある。代表的な表示を次の表に示す。

表 6.1 デバッグ LED の表示と意味

点灯し続ける LED

意味

主な確認箇所

CPU

CPU を認識できない、または初期化できない。

CPU の取り付け、CPU 補助電源、UEFI の CPU への対応

初回起動時のメモリトレーニング中は、DRAM の LED がしばらく点灯する。点灯したまま数分以上変化しない場合に問題と判断する。2 桁の英数字のコードで状態を示すマザーボードもある。コードの意味はマザーボードのマニュアルに記載されている。

6.4. UEFI の画面に入る

電源を入れた直後に Delete キーまたは F2 キーを繰り返し押すと、UEFI の設定画面に入れる。キーはマザーボードによって異なるため、マニュアルで確認する。OS がインストールされていない状態では、自動的に UEFI の画面が表示されることも多い。

UEFI の画面には、主な情報を一覧する簡易表示と、全ての設定を変更できる詳細表示の 2 つがあることが多い。

6.5. 認識状況を確認する

まず、全てのパーツが正しく認識されているかを確認する。

表 6.2 UEFI で確認する項目

項目

確認する内容

CPU

型番が正しく表示されているか。

メモリ

容量が取り付けた合計と一致しているか。この時点では速度が定格より低く表示されることがある（次節を参照）。

ストレージ

取り付けた全ての SSD、HDD が表示されているか。

CPU の温度

何もしていない状態で 30 ℃ から 50 ℃ 程度か。急に上昇し続ける場合は、すぐに電源を切り、CPU クーラーの取り付けを確認する。

ファンの回転数

CPU クーラーのファン（簡易水冷の場合はポンプも）とケースファンの回転数が表示されているか。

6.6. メモリのプロファイルを有効にする

メモリは、既定では JEDEC（半導体の標準化団体）が定めた標準の速度で動作する。たとえば DDR5-6000 として販売されているメモリでも、既定では DDR5-4800 や DDR5-5600 で動作することがある。

定格の速度で動作させるには、UEFI でメモリのプロファイルを有効にする。プロファイルには、Intel が策定した XMP と AMD が策定した EXPO がある。設定項目は「XMP」「EXPO」「DOCP」などと表記され、プロファイルを選んで保存すると適用される。

プロファイルを有効にした後は、再びメモリトレーニングが行われるため、起動に時間がかかる。

メモリのプロファイルによる動作は、CPU のメーカーが保証する範囲を超えた動作として扱われる場合がある。また、CPU とメモリの組み合わせによっては不安定になることがある。動作確認と負荷テスト で不安定と判断した場合は、プロファイルを無効に戻すか、速度を 1 段階下げる。

6.7. その他の設定

表 6.3 その他の主な設定項目

項目

内容

起動順序

OS をインストールするときは、USB メモリから起動できるようにする。起動時に F11 キーや F12 キーなどで起動するデバイスを一時的に選ぶ機能（ブートメニュー）を使うと、設定を変えずに済む。

Secure Boot

署名されていないプログラムの起動を防ぐ機能。Windows 11 の要件に含まれる。主要な Linux のディストリビューションも Secure Boot が有効な状態で起動できる。

TPM

暗号鍵を安全に保管する機能。Windows 11 の要件に含まれる。CPU に内蔵された TPM（Intel では PTT、AMD では fTPM と表記される）が使われる。最近のマザーボードでは既定で有効なことが多い。

CSM

古い BIOS 方式の起動を互換的に可能にする機能。Windows 11 は UEFI 方式での起動が必要なため、無効にしておく。

ファンの制御

温度に応じたファンの回転数（ファンカーブ）を設定する。初回は既定のままでよい。騒音が気になる場合に調整する。

6.8. UEFI の更新

マザーボードのメーカーは、新しい CPU への対応、動作の安定性の改善、セキュリティの修正のために UEFI の更新版を公開している。

更新が必要となるのは、主に次の場合である。

  • 取り付けた CPU に対応するために更新が必要な場合

  • 遭遇している不具合が、更新内容に修正として記載されている場合

  • セキュリティの修正を含む場合

問題なく動作しており、上記のいずれにも当てはまらない場合は、急いで更新する必要はない。

更新は、メーカーの Web サイトから更新ファイルをダウンロードし、FAT32 でフォーマットした USB メモリに保存して、UEFI の更新機能から実行するのが一般的である。手順はマザーボードによって異なるため、必ずマニュアルに従う。

危険

UEFI の更新中に電源が切れると、マザーボードが起動しなくなるおそれがある。更新中は電源ボタンに触れず、停電の可能性が低いときに作業すること。
