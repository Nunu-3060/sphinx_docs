第 1 章 開発環境の準備

この章では、Unity とコードエディターをインストールし、Console ウィンドウに文字を表示するだけの、最初のスクリプトを動かします。

Unity のインストール

Unity は、Unity Hub というアプリケーションを使ってインストールし、管理します。Unity Hub を使うと、複数のバージョンの Unity を切り替えて使えます。

  1. Unity の公式サイト から Unity Hub をダウンロードし、インストールします。

  2. Unity Hub を起動し、Unity アカウントでサインインします。アカウントがない場合は、ここで作成します。

  3. 個人で学習する場合は、無料の Unity Personal のライセンスを取得します。

  4. Unity Hub の左側のメニューで Installs を選び、Install Editor ボタンを押します。

  5. Unity 6 の LTS 版を選んでインストールします。途中でモジュールを選ぶ画面が表示されたら、Windows では Microsoft Visual Studio Community 2022 にチェックを入れると、Visual Studio も一緒にインストールできます。

注釈

LTS（Long Term Support）版は、長期間にわたって不具合の修正が提供されるバージョンです。学習や製品の開発には LTS 版を使うことをお勧めします。

プロジェクトの作成

Unity では、ゲームを作るための一式のファイルをプロジェクトと呼びます。

  1. Unity Hub の左側のメニューで Projects を選び、New project ボタンを押します。

  2. テンプレートの一覧から Universal 3D を選びます。

  3. Project name にプロジェクトの名前（例: UnityCSharpIntro）を入力し、Location に保存先のフォルダーを指定します。

  4. Create project ボタンを押すと、プロジェクトが作成され、Unity エディターが起動します。

Unity エディターの画面

Unity エディターは、複数のウィンドウで構成されています。本書でよく使うウィンドウは次のとおりです。

ウィンドウ

役割

Scene ビュー

シーン（ゲームの 1 つの場面）を編集する画面です。オブジェクトを配置したり、動かしたりします。

Game ビュー

ゲームを実行したときに、プレイヤーに見える画面です。

Hierarchy ウィンドウ

シーンに置かれているオブジェクト（GameObject）の一覧です。

Inspector ウィンドウ

選択したオブジェクトの詳細な設定を表示・編集します。

Project ウィンドウ

プロジェクトに含まれるファイル（アセット）の一覧です。スクリプトもここで作成します。

Console ウィンドウ

スクリプトから出力したメッセージや、エラーを表示します。

Console ウィンドウが表示されていない場合は、Window > General > Console で表示できます。

コードエディターの設定

スクリプトは、Unity エディターではなくコードエディターで編集します。本書では、次のどちらかを使うことを想定しています。

コードエディター

準備

Visual Studio 2022

Visual Studio Installer で「Unity によるゲーム開発」ワークロードをインストールします。

Visual Studio Code

拡張機能の Unity（Microsoft 製）をインストールします。この拡張機能に必要な C# Dev Kit も一緒にインストールされます。

コードエディターをインストールしたら、Unity エディターで Edit > Preferences（macOS では Unity > Settings）を開き、External Tools の External Script Editor で使用するコードエディターを選びます。

注釈

コードエディターと Unity を連携させると、入力中に候補が表示される入力補完や、エラーの表示が使えるようになります。コードを書く効率が大きく変わるため、必ず設定してください。

最初のスクリプト

スクリプトの作成

Console ウィンドウに「Hello, Unity!」と表示するスクリプトを作ります。

  1. Project ウィンドウで Assets フォルダーを右クリックし、Create > Scripting > MonoBehaviour Script を選びます。

  2. ファイル名を入力する状態になるので、HelloWorld と入力して Enter キーを押します。

  3. 作成された HelloWorld をダブルクリックすると、コードエディターでファイルが開きます。

  4. ファイルの内容を次のコードに書き換えて保存します。

HelloWorld.cs
// 第 1 章 開発環境の準備
// Console ウィンドウに「Hello, Unity!」と表示するだけの、最初のスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Play ボタンを押します。
using UnityEngine;

public class HelloWorld : MonoBehaviour
{
    // Start は、最初の Update が呼ばれる直前に 1 回だけ呼ばれます。
    private void Start()
    {
        Debug.Log("Hello, Unity!");
    }
}

HelloWorld.cs をダウンロード

警告

ファイル名とクラス名（public class の後ろに書く名前）は、必ず同じにしてください。スクリプトを作成するときに入力したファイル名が、クラス名としてコードに書き込まれます。作成した後でファイル名だけを変更すると、クラス名と一致しなくなり、GameObject にアタッチできなくなります。

スクリプトの実行

作成したスクリプトは、シーン内の GameObject に取り付ける（アタッチする）ことで動きます。

  1. Hierarchy ウィンドウで右クリックし、Create Empty を選びます。GameObject という名前の空のオブジェクトが作成されます。

  2. 作成した GameObject を選択し、Project ウィンドウの HelloWorld を Inspector ウィンドウにドラッグします。Inspector ウィンドウに Hello World という項目が追加されれば、アタッチできています。

  3. Unity エディターの上部にある Play ボタン（▶）を押します。

Console ウィンドウに次のように表示されれば成功です。

実行結果
Hello, Unity!

もう一度 Play ボタンを押すと、実行が終了します。ゲームを実行している状態を Play モードと呼びます。

コードの読み方

HelloWorld.cs の各部分の意味は次のとおりです。細かい文法は、この後の章で順番に説明します。

コード

意味

// ...

コメントです。// から行末までは、プログラムとして実行されません。コードの説明を書くのに使います。

using UnityEngine;

Unity の機能（MonoBehaviour や Debug など）を使うための宣言です。

public class HelloWorld : MonoBehaviour

HelloWorld という名前のクラスを定義します。: MonoBehaviour は、このクラスが Unity のコンポーネントとして動くことを表します（第 8 章、第 10 章）。

private void Start()

Start という名前のメソッドを定義します。Start は、ゲームの開始時に Unity が自動で呼び出す特別なメソッドです（第 11 章）。

Debug.Log("Hello, Unity!");

かっこの中の文字列を Console ウィンドウに表示します。

{ と }

クラスやメソッドの範囲（ブロック）を表します。{ と } は必ず対になります。

C# のコードを書くときは、次の点に注意してください。

  • 文の終わりには ;（セミコロン）を付けます。

  • 大文字と小文字は区別されます。debug.log と書くとエラーになります。

  • 文字列は "（ダブルクォーテーション）で囲みます。

  • コードの中の記号や英数字は、半角で入力します。全角の空白が入っていると、エラーになります。

コンパイルエラー

スクリプトを保存すると、Unity はスクリプトをコンピューターが実行できる形式に変換します。この変換をコンパイルと呼びます。コードに文法の誤りがあると、コンパイルに失敗し、Console ウィンドウに赤色のエラーが表示されます。これをコンパイルエラーと呼びます。

試しに、Debug.Log("Hello, Unity!"); の最後の ; を消して保存してみてください。Console ウィンドウに次のようなエラーが表示されます。

Assets/HelloWorld.cs(11,35): error CS1002: ; expected

これは、「HelloWorld.cs の 11 行目の 35 文字目に ; が必要です」という意味です。コンパイルエラーが残っている間は、Play モードを開始できません。エラーが表示されたら、ファイル名と行番号を手がかりに修正してください。エラーの調べ方は、第 20 章 デバッグの方法 で詳しく説明します。

まとめ

  • Unity は Unity Hub を使ってインストールし、プロジェクトを作成します。

  • スクリプトは Project ウィンドウで作成し、コードエディターで編集します。

  • スクリプトは GameObject にアタッチすると、Play モードで実行されます。

  • ファイル名とクラス名は同じにします。

  • Debug.Log を使うと、Console ウィンドウにメッセージを表示できます。
