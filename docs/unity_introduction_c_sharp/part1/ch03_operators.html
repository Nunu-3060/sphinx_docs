第 3 章 演算子と式

この章では、計算や比較を行うための演算子について学びます。a + b のように、値や変数を演算子で組み合わせたものを式と呼びます。

算術演算子

演算子

意味

例

結果

+

足し算

7 + 2

9

-

引き算

7 - 2

5

*

掛け算

7 * 2

14

/

割り算

7 / 2

3

%

割り算の余り（剰余）

7 % 2

1

整数どうしの割り算

int どうしの割り算の結果は int になり、小数部分は切り捨てられます。そのため、7 / 2 は 3.5 ではなく 3 になります。小数の結果が欲しいときは、(float)7 / 2 や 7f / 2f のように、少なくとも一方を float にします。

整数の割り算の商 \(q\) と余り \(r\) は、割られる数を \(a\)、割る数を \(b\) とすると、次の関係を満たします。

\[a = b \times q + r\]

C# では、商は 0 の方向に切り捨てられ、余りの符号は割られる数 \(a\) と同じになります。たとえば、\(-7 \div 2\) の商は \(-3\)、余りは \(-1\) です。

\[-7 = 2 \times (-3) + (-1)\]

余りは、「偶数かどうか」（n % 2 == 0）や「3 回に 1 回だけ処理する」（count % 3 == 0）といった判定によく使います。

計算の優先順位

数学と同じく、*、/、% は + と - より先に計算されます。優先順位を変えたいときは、かっこ ( ) を使います。

int a = 2 + 3 * 4;      // 14
int b = (2 + 3) * 4;    // 20

代入演算子とインクリメント

変数の値を使って計算し、その結果を同じ変数に代入する処理は、短く書けます。

演算子

例

同じ意味の書き方

+=

hp += 10;

hp = hp + 10;

-=

hp -= 10;

hp = hp - 10;

*=

hp *= 2;

hp = hp * 2;

/=

hp /= 2;

hp = hp / 2;

++

count++;

count = count + 1;

--

count--;

count = count - 1;

++ と -- は、それぞれインクリメント（1 増やす）、デクリメント（1 減らす）と呼びます。

比較演算子

比較演算子は 2 つの値を比べ、結果を bool（true または false）で返します。

演算子

意味

例（age が 15 のとき）

==

等しい

age == 15 は true

!=

等しくない

age != 15 は false

<

より小さい

age < 18 は true

<=

以下

age <= 15 は true

>

より大きい

age > 18 は false

>=

以上

age >= 18 は false

警告

等しいかどうかを調べる演算子は、= ではなく == です。= は代入の演算子です。

論理演算子

論理演算子は、bool の値を組み合わせます。

演算子

意味

結果が true になる条件

&&

かつ（AND）

両方が true のとき

||

または（OR）

少なくとも一方が true のとき

!

ではない（NOT）

値が false のとき

&& は左側が false のとき、|| は左側が true のとき、結果が確定するため右側を評価しません。

小数の誤差

float や double の値は、コンピューターの内部では 2 進数で表されます。0.1 のように 2 進数では正確に表せない値は近似値として保存されるため、計算結果にわずかな誤差が生じることがあります。

そのため、小数どうしを == で比べると、数学的には等しいはずの値でも false になることがあります。float の値がほぼ等しいかどうかを調べるには、Mathf.Approximately を使います。

サンプルコード

OperatorSample.cs
// 第 3 章 演算子と式
// 算術演算子、代入演算子、比較演算子、論理演算子の動きを確認するスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Play ボタンを押して Console ウィンドウを確認します。
using UnityEngine;

public class OperatorSample : MonoBehaviour
{
    private void Start()
    {
        // ---- 算術演算子 ----
        int a = 7;
        int b = 2;
        Debug.Log($"a + b = {a + b}");
        Debug.Log($"a - b = {a - b}");
        Debug.Log($"a * b = {a * b}");
        Debug.Log($"a / b = {a / b}");
        Debug.Log($"a % b = {a % b}");

        // 整数どうしの割り算では、小数部分が切り捨てられます。
        // 小数の結果が欲しいときは、どちらかを float に変換します。
        Debug.Log($"(float)a / b = {(float)a / b}");

        // 負の数の割り算は 0 の方向へ切り捨てられ、余りの符号は割られる数と同じになります。
        Debug.Log($"-7 / 2 = {-7 / 2}");
        Debug.Log($"-7 % 2 = {-7 % 2}");

        // 掛け算は足し算より先に計算されます。かっこで順序を変えられます。
        Debug.Log($"2 + 3 * 4 = {2 + 3 * 4}");
        Debug.Log($"(2 + 3) * 4 = {(2 + 3) * 4}");

        // ---- 代入演算子とインクリメント ----
        int hp = 100;
        hp -= 25;   // hp = hp - 25 と同じ
        hp *= 2;    // hp = hp * 2 と同じ
        Debug.Log($"hp = {hp}");

        int count = 0;
        count++;    // count = count + 1 と同じ
        count++;
        Debug.Log($"count = {count}");

        // ---- 比較演算子と論理演算子 ----
        int age = 15;
        bool hasTicket = true;
        Debug.Log($"age >= 18: {age >= 18}");
        Debug.Log($"チケットがあり、かつ 12 歳以上: {hasTicket && age >= 12}");
        Debug.Log($"18 歳以上、またはチケットがある: {age >= 18 || hasTicket}");
        Debug.Log($"チケットがない: {!hasTicket}");

        // ---- 小数の誤差 ----
        // 小数は 2 進数で近似して保存されるため、わずかな誤差が生じることがあります。
        float x = 0.1f + 0.6f;
        Debug.Log($"0.1f + 0.6f == 0.7f: {x == 0.7f}");

        // float どうしがほぼ等しいかを調べるには Mathf.Approximately を使います。
        Debug.Log($"Mathf.Approximately(x, 0.7f): {Mathf.Approximately(x, 0.7f)}");
    }
}

まとめ

  • int どうしの割り算では、小数部分が切り捨てられます。

  • += や ++ を使うと、変数の値を更新する処理を短く書けます。

  • 比較演算子と論理演算子の結果は bool です。

  • 小数には誤差があるため、== で比較せず、Mathf.Approximately を使います。
