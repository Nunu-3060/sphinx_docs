第 5 章 配列とコレクション

敵の一覧や所持アイテムのように、同じ種類の値をまとめて扱いたいことがあります。この章では、複数の値をまとめて扱うための配列とコレクションについて学びます。

配列

配列は、同じ型の値を決まった数だけ並べて保存するものです。配列の中の 1 つ 1 つの値を要素と呼びます。

int[] scores = new int[3];               // 要素数 3 の int の配列を作る
string[] items = { "薬草", "毒消し", "鍵" };  // 作成と同時に要素を指定する

要素には、scores[0] のように [ ] の中に番号を指定してアクセスします。この番号をインデックス（添字）と呼びます。インデックスは 0 から始まるため、要素数 3 の配列のインデックスは 0、1、2 です。要素数は Length で取得できます。

警告

存在しないインデックス（要素数 3 の配列の scores[3] など）にアクセスすると、IndexOutOfRangeException というエラー（例外）が発生します。最後の要素のインデックスは Length - 1 です。

配列は、作成した後で要素数を変えることができません。

foreach 文

foreach 文を使うと、配列の要素を先頭から順に 1 つずつ取り出して処理できます。

foreach (int score in scores)
{
    Debug.Log(score);
}

インデックスが必要な場合は for 文を、要素を順に取り出すだけでよい場合は foreach 文を使います。

2 次元配列

int[,] のように書くと、行と列を持つ 2 次元配列を作れます。マップのマス目や盤面を表すときに使えます。各次元の要素数は GetLength(0)（行数）や GetLength(1)（列数）で取得します。

配列のサンプルコード

ArraySample.cs
// 第 5 章 配列とコレクション
// 配列の作成、要素へのアクセス、for 文と foreach 文による列挙を確認するスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Play ボタンを押して Console ウィンドウを確認します。
using UnityEngine;

public class ArraySample : MonoBehaviour
{
    private void Start()
    {
        // 要素数 3 の配列を作成します。int の要素は最初は 0 です。
        int[] scores = new int[3];
        scores[0] = 80;
        scores[1] = 65;
        scores[2] = 92;
        Debug.Log($"要素数: {scores.Length}, 先頭: {scores[0]}, 末尾: {scores[scores.Length - 1]}");

        // 作成と同時に要素を指定することもできます。
        string[] items = { "薬草", "毒消し", "鍵" };

        // for 文では、インデックス（添字）を使って要素にアクセスします。
        for (int i = 0; i < items.Length; i++)
        {
            Debug.Log($"items[{i}] = {items[i]}");
        }

        // foreach 文では、先頭から順に要素を 1 つずつ取り出します。
        int total = 0;
        foreach (int score in scores)
        {
            total += score;
        }
        Debug.Log($"合計点: {total}");

        // 2 次元配列（3 行 4 列）。マップのマス目などを表すのに使えます。
        int[,] map = new int[3, 4];
        map[1, 2] = 5;
        Debug.Log($"行数: {map.GetLength(0)}, 列数: {map.GetLength(1)}, map[1, 2] = {map[1, 2]}");
    }
}

List<T>

List<T> は、要素数を後から変えられるコレクションです。T の部分には、要素の型を指定します。たとえば、string の要素を持つリストは List<string> と書き、new List<string>() で作成します（new は第 7 章で、<T> の仕組みは第 9 章で説明します）。List<T> を使うには、ファイルの先頭に using System.Collections.Generic; を書きます。

メンバー

説明

Add(要素)

末尾に要素を追加します。

Remove(要素)

指定した要素を探して取り除きます。

RemoveAt(インデックス)

指定したインデックスの要素を取り除きます。

Contains(要素)

指定した要素が含まれていれば true を返します。

Clear()

すべての要素を取り除きます。

Count

要素数です（配列の Length にあたります）。

要素へのアクセスは、配列と同じく party[0] のように書きます。範囲外のインデックスを指定すると、例外（ArgumentOutOfRangeException）が発生します。

Dictionary<TKey, TValue>

Dictionary<TKey, TValue> は、キーと値の組を保存するコレクションです。アイテムの名前から値段を調べる、というように、キーを指定して値を取り出せます。TKey にはキーの型を、TValue には値の型を指定します。

メンバー

説明

dict[キー] = 値

キーがなければ追加し、あれば値を上書きします。

dict[キー]

キーに対応する値を取得します。キーがないと例外（KeyNotFoundException）が発生します。

Add(キー, 値)

キーと値の組を追加します。同じキーがすでにあると例外が発生します。

TryGetValue(キー, out 値)

キーがあれば true を返し、値を out の変数に入れます（out については第 6 章で説明します）。

ContainsKey(キー)

キーがあれば true を返します。

Remove(キー)

キーと値の組を取り除きます。

作成と同時に要素を指定するには、new Dictionary<string, int> { { "薬草", 8 }, { "毒消し", 10 } } のように、{ と } の中にキーと値の組を並べます。List<T> でも、new List<string> { "勇者", "僧侶" } のように書けます。

foreach 文で Dictionary の要素を取り出すと、キーと値の組（KeyValuePair<TKey, TValue>）が得られます。なお、Dictionary の要素が取り出される順番は保証されていません。順番が重要な場合は、List<T> を使います。

コレクションのサンプルコード

CollectionSample.cs
// 第 5 章 配列とコレクション
// List<T> と Dictionary<TKey, TValue> の基本的な使い方を確認するスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Play ボタンを押して Console ウィンドウを確認します。
using System.Collections.Generic;
using UnityEngine;

public class CollectionSample : MonoBehaviour
{
    private void Start()
    {
        // ---- List<T>: 要素数を後から変えられるコレクション ----
        List<string> party = new List<string>();
        party.Add("勇者");
        party.Add("魔法使い");
        party.Add("僧侶");
        party.Remove("魔法使い");
        Debug.Log($"人数: {party.Count}, 先頭: {party[0]}");
        bool hasPriest = party.Contains("僧侶");
        Debug.Log($"僧侶がいる: {hasPriest}");

        foreach (string member in party)
        {
            Debug.Log($"メンバー: {member}");
        }

        // ---- Dictionary<TKey, TValue>: キーを指定して値を取り出すコレクション ----
        Dictionary<string, int> prices = new Dictionary<string, int>
        {
            { "薬草", 8 },
            { "毒消し", 10 },
        };

        // キーがなければ追加され、あれば値が上書きされます。
        prices["鍵"] = 50;
        int herbPrice = prices["薬草"];
        Debug.Log($"薬草の値段: {herbPrice}");

        // 存在しないキーを prices["剣"] のように読み取ると例外が発生するため、TryGetValue で確認します。
        if (prices.TryGetValue("剣", out int swordPrice))
        {
            Debug.Log($"剣の値段: {swordPrice}");
        }
        else
        {
            Debug.Log("剣は売っていない。");
        }

        foreach (KeyValuePair<string, int> pair in prices)
        {
            Debug.Log($"{pair.Key}: {pair.Value} G");
        }
    }
}

警告

foreach 文で List<T> の要素を取り出している間に、その List<T> に要素を追加したり、取り除いたりすると、例外（InvalidOperationException）が発生します。Dictionary<TKey, TValue> でも同様の問題が起きるため、foreach 文の途中ではコレクションを変更しないでください。くり返しの途中で List<T> の要素を取り除きたい場合は、インデックスの大きい方から for 文で処理するなどの方法を使います。

配列と List<T> の使い分け

種類

向いている場面

例

配列

要素数が決まっている場合

曜日の名前、マップのマス目

List<T>

要素数が変わる場合

画面上の敵、所持アイテム

Dictionary<TKey, TValue>

キーで値を探す場合

アイテム名と値段の対応表

まとめ

  • 配列は、同じ型の値を決まった数だけ保存します。インデックスは 0 から始まります。

  • List<T> は、要素数を後から変えられます。

  • Dictionary<TKey, TValue> は、キーを指定して値を取り出せます。

  • foreach 文を使うと、要素を先頭から順に取り出せます。
