第 4 章 制御構文

プログラムは、基本的に上から順に 1 行ずつ実行されます。この章では、条件によって処理を分けたり、同じ処理をくり返したりするための制御構文について学びます。

if 文

if 文は、条件が true のときだけ処理を実行します。

if (条件)
{
    // 条件が true のときに実行する処理
}
else if (別の条件)
{
    // 最初の条件が false で、別の条件が true のときに実行する処理
}
else
{
    // どの条件も false のときに実行する処理
}

else if と else は省略できます。else if はいくつでも続けて書けます。条件は上から順に判定され、最初に true になったブロックだけが実行されます。そのため、score >= 80 と score >= 60 のように範囲が重なる条件を並べるときは、厳しい条件を先に書きます。

注釈

本体が 1 行だけの場合、{ と } は省略できます。しかし、後から行を追加したときに誤りが起きやすいため、本書では常に { と } を書きます。

switch 文

1 つの値がどの値と一致するかによって処理を分けるときは、switch 文を使うと読みやすくなります。

switch (値)
{
    case 値1:
        // 値が 値1 と一致したときの処理
        break;
    case 値2:
        // 値が 値2 と一致したときの処理
        break;
    default:
        // どれにも一致しなかったときの処理
        break;
}

各 case の処理の最後には break を書きます。C# では、処理の後に break がないまま次の case に進むことはできず、コンパイルエラーになります。

switch 式

条件に応じて値を 1 つ選ぶだけであれば、switch 式を使うと短く書けます。_ は、どれにも一致しなかった場合を表します。

int damage = weapon switch
{
    "Sword" => 10,
    "Bow" => 7,
    _ => 1,
};

条件演算子

条件によって 2 つの値のどちらかを選ぶときは、条件演算子 ? : を使えます。

string result = score >= 60 ? "合格" : "不合格";

条件 ? A : B は、条件が true なら A、false なら B になります。

分岐のサンプルコード

このサンプルコードでは、メソッドの外（クラスの中）に _score と _weapon という変数を宣言しています。このような変数をフィールドと呼びます（第 7 章）。フィールドに付けた [SerializeField] は、Unity エディターの Inspector ウィンドウから値を変更できるようにするための書き方です（第 12 章）。Inspector ウィンドウで Score や Weapon の値を変えてから Play ボタンを押し、結果が変わることを確かめてください。

ControlFlowSample.cs
// 第 4 章 制御構文
// if 文、switch 文、switch 式、条件演算子で処理を分岐させるスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Inspector ウィンドウで Score と Weapon の値を変えて試します。
using UnityEngine;

public class ControlFlowSample : MonoBehaviour
{
    [SerializeField] private int _score = 72;
    [SerializeField] private string _weapon = "Sword";

    private void Start()
    {
        // ---- if 文 ----
        // 上の条件から順に判定し、最初に当てはまったブロックだけが実行されます。
        if (_score >= 80)
        {
            Debug.Log("評価: A");
        }
        else if (_score >= 60)
        {
            Debug.Log("評価: B");
        }
        else
        {
            Debug.Log("評価: C");
        }

        // ---- switch 文 ----
        // 値が一致する case のブロックが実行されます。どれにも一致しなければ default が実行されます。
        switch (_weapon)
        {
            case "Sword":
                Debug.Log("剣で攻撃した。");
                break;
            case "Bow":
                Debug.Log("弓で攻撃した。");
                break;
            default:
                Debug.Log("素手で攻撃した。");
                break;
        }

        // ---- switch 式 ----
        // 条件に応じて値を 1 つ選ぶときは、switch 式を使うと簡潔に書けます。
        int damage = _weapon switch
        {
            "Sword" => 10,
            "Bow" => 7,
            _ => 1,
        };
        Debug.Log($"ダメージ: {damage}");

        // ---- 条件演算子 ----
        // 条件 ? 条件が true のときの値 : 条件が false のときの値
        string result = _score >= 60 ? "合格" : "不合格";
        Debug.Log($"判定: {result}");
    }
}

for 文

for 文は、決まった回数だけ処理をくり返すときに使います。

for (int i = 0; i < 5; i++)
{
    // 5 回くり返す処理（i は 0, 1, 2, 3, 4 と変わる）
}

for の後のかっこの中は、; で区切られた 3 つの部分でできています。

部分

意味

int i = 0

最初に 1 回だけ実行されます。くり返しの回数を数える変数（カウンター）を用意します。

i < 5

くり返しを続ける条件です。毎回の処理の前に判定され、false になるとくり返しを終えます。

i++

毎回の処理の後に実行されます。

while 文と do-while 文

while 文は、条件が true の間、処理をくり返します。くり返す回数が事前にわからないときに使います。

while (hp > 0)
{
    hp -= 30;
}

do-while 文は、処理を実行した後で条件を判定します。そのため、条件が最初から false でも、処理は必ず 1 回実行されます。最後の ; を忘れないようにしてください。

do
{
    tries++;
}
while (tries < 3);

警告

条件がいつまでも false にならないと、くり返しが終わらなくなります（無限ループ）。Unity でスクリプトが無限ループになると、Unity エディター全体が応答しなくなり、強制終了するしかなくなります。くり返しの条件が、いつか必ず false になることを確認してください。

break と continue

くり返しの途中で流れを変えるには、break と continue を使います。

文

動作

break

くり返しをその場で終了し、ループの後の処理に進みます。

continue

その回の残りの処理を飛ばし、次の回に進みます。

くり返しのサンプルコード

LoopSample.cs
// 第 4 章 制御構文
// for 文、while 文、do-while 文と、break、continue の動きを確認するスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Play ボタンを押して Console ウィンドウを確認します。
using UnityEngine;

public class LoopSample : MonoBehaviour
{
    private void Start()
    {
        // ---- for 文: 1 から 10 までの合計 ----
        int sum = 0;
        for (int i = 1; i <= 10; i++)
        {
            sum += i;
        }
        Debug.Log($"1 から 10 までの合計: {sum}");

        // ---- while 文: 条件を満たす間くり返す ----
        int hp = 100;
        int turn = 0;
        while (hp > 0)
        {
            hp -= 30;
            turn++;
        }
        Debug.Log($"{turn} ターンで HP が 0 以下になった（HP: {hp}）");

        // ---- do-while 文: 条件を後で判定するため、最低 1 回は実行される ----
        int tries = 0;
        do
        {
            tries++;
        }
        while (tries < 0);
        Debug.Log($"do-while の実行回数: {tries}");

        // ---- continue と break ----
        // continue は残りの処理を飛ばして次の周回へ進み、break はループそのものを抜けます。
        string log = "";
        for (int i = 1; i <= 10; i++)
        {
            if (i % 2 == 0)
            {
                continue;
            }
            if (i > 7)
            {
                break;
            }
            log += i + " ";
        }
        Debug.Log($"7 までの奇数: {log}");
    }
}

まとめ

  • 条件によって処理を分けるには、if 文、switch 文、switch 式、条件演算子を使います。

  • 処理をくり返すには、for 文、while 文、do-while 文を使います。

  • break はくり返しを終了し、continue は次の回に進みます。

  • 無限ループにならないように注意します。
