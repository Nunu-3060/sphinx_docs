第 15 章 ベクトルと移動・回転

ゲームでは、位置、移動の向き、速さなどを表すためにベクトルを使います。この章では、Unity でベクトルを表す Vector3 の使い方と、回転を表す Quaternion の基本を学びます。

Unity の座標系

Unity の 3D 空間は、X 軸、Y 軸、Z 軸の 3 つの軸で表されます。

軸

正の向き

定数

X 軸

右

Vector3.right（(1, 0, 0)）

Y 軸

上

Vector3.up（(0, 1, 0)）

Z 軸

前（奥）

Vector3.forward（(0, 0, 1)）

反対の向きは、Vector3.left、Vector3.down、Vector3.back で表します。すべての成分が 0 のベクトルは Vector3.zero です。Unity では、長さの単位を 1 m として扱うのが一般的です。

注釈

Unity の座標系は左手系です。左手の親指を X 軸（右）、人差し指を Y 軸（上）に向けると、中指が Z 軸（前）を向きます。

Vector3

Vector3 は、x、y、z の 3 つの float を持つ構造体です。位置を表すことも、向きと大きさ（移動量や速度）を表すこともあります。

ベクトルの演算

ベクトルの足し算と引き算は、成分ごとに計算されます。ベクトル \(\boldsymbol{a} = (a_x, a_y, a_z)\) と \(\boldsymbol{b} = (b_x, b_y, b_z)\) について、次のようになります。

\[\boldsymbol{a} + \boldsymbol{b} = (a_x + b_x,\ a_y + b_y,\ a_z + b_z)\]

ベクトルに数を掛けると、向きはそのままで、長さだけが変わります。

\[k \boldsymbol{a} = (k a_x,\ k a_y,\ k a_z)\]

「目標の位置 − 自分の位置」を計算すると、自分から目標へ向かうベクトルが得られます。これは、敵をプレイヤーに向かわせる処理などでよく使います。

長さと正規化

ベクトルの長さ（大きさ）は magnitude で得られます。

\[|\boldsymbol{a}| = \sqrt{a_x^2 + a_y^2 + a_z^2}\]

長さの 2 乗は sqrMagnitude で得られます。平方根の計算を省けるため、長さどうしを比べるだけなら sqrMagnitude を使うと効率的です。

向きはそのままで長さを 1 にしたベクトルを、単位ベクトルと呼びます。ベクトルを単位ベクトルにすることを正規化と呼び、normalized で得られます。向きだけが必要なとき（「目標の方向へ一定の速さで進む」など）は、正規化したベクトルに速さを掛けて使います。

\[\frac{\boldsymbol{a}}{|\boldsymbol{a}|}\]

2 点間の距離は、Vector3.Distance(a, b) で得られます。これは (a - b).magnitude と同じです。

内積

2 つのベクトルの内積は、Vector3.Dot(a, b) で得られます。2 つのベクトルのなす角を \(\theta\) とすると、内積は次の式で表されます。

\[\boldsymbol{a} \cdot \boldsymbol{b} = a_x b_x + a_y b_y + a_z b_z = |\boldsymbol{a}|\,|\boldsymbol{b}| \cos\theta\]

どちらも単位ベクトルの場合、内積は \(\cos\theta\) になり、同じ向きなら 1、直角なら 0、逆向きなら -1 になります。内積が正なら、2 つのベクトルの向きの差は 90° 未満です。これを使うと、「敵の正面方向と、敵からプレイヤーへ向かうベクトルの内積が正なら、プレイヤーは敵の前方にいる」と判定できます。

外積

2 つのベクトルの外積は、Vector3.Cross(a, b) で得られます。外積は、\(\boldsymbol{a}\) と \(\boldsymbol{b}\) の両方に垂直なベクトルです。

\[\boldsymbol{a} \times \boldsymbol{b} = (a_y b_z - a_z b_y,\ a_z b_x - a_x b_z,\ a_x b_y - a_y b_x)\]

外積は、面の向き（法線）を求めるときなどに使います。

線形補間

Vector3.Lerp(a, b, t) は、\(\boldsymbol{a}\) と \(\boldsymbol{b}\) の間を \(t\) の割合で分けた点を返します。\(t\) は 0 から 1 の範囲に制限されます。

\[\mathrm{Lerp}(\boldsymbol{a}, \boldsymbol{b}, t) = \boldsymbol{a} + (\boldsymbol{b} - \boldsymbol{a})\,t \quad (0 \le t \le 1)\]

ベクトルのサンプルコード

VectorSample.cs
// 第 15 章 ベクトルと移動・回転
// ベクトルの長さ、正規化、距離、内積、外積、線形補間を確認するスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Play ボタンを押して Console ウィンドウを確認します。
using UnityEngine;

public class VectorSample : MonoBehaviour
{
    private void Start()
    {
        Vector3 a = new Vector3(3f, 0f, 4f);
        Vector3 b = new Vector3(-3f, 0f, 12f);

        // 足し算と引き算は成分ごとに計算されます。
        Debug.Log($"a + b = {a + b}");
        Debug.Log($"a - b = {a - b}");

        // 長さ（大きさ）と、長さを 1 にした向きだけのベクトル（正規化）
        Debug.Log($"a の長さ: {a.magnitude}");
        Debug.Log($"a を正規化: {a.normalized}");

        // 2 点間の距離は (a - b).magnitude と同じです。
        Debug.Log($"a と b の距離: {Vector3.Distance(a, b)}");

        // 内積: 2 つのベクトルの向きがどれだけ揃っているかがわかります。
        // 正規化したベクトルどうしの内積は、同じ向きで 1、直角で 0、逆向きで -1 になります。
        Vector3 forward = Vector3.forward;
        Debug.Log($"前方と前方の内積: {Vector3.Dot(forward, Vector3.forward)}");
        Debug.Log($"前方と右の内積: {Vector3.Dot(forward, Vector3.right)}");
        Debug.Log($"前方と後方の内積: {Vector3.Dot(forward, Vector3.back)}");

        // 外積: 2 つのベクトルの両方に垂直なベクトルが得られます。
        Debug.Log($"右と上の外積: {Vector3.Cross(Vector3.right, Vector3.up)}");

        // 線形補間: t = 0 で開始点、t = 1 で終了点、t = 0.5 でちょうど中間の点になります。
        Debug.Log($"Lerp(0.5): {Vector3.Lerp(Vector3.zero, new Vector3(10f, 0f, 0f), 0.5f)}");
    }
}

Quaternion

Unity では、回転を Quaternion（クォータニオン）という型で表します。Quaternion は x、y、z、w の 4 つの成分を持ちますが、これらの値は角度ではないため、直接書き換えてはいけません。回転は、次のメソッドを使って作ります。

メソッドとプロパティ

説明

Quaternion.identity

回転していない状態です。

Quaternion.Euler(x, y, z)

X 軸、Y 軸、Z 軸まわりの角度（度）から回転を作ります。Inspector ウィンドウの Rotation と同じ表し方です。

Quaternion.LookRotation(向き)

指定した向きを正面（Z 軸の正の向き）とする回転を作ります。

Quaternion.RotateTowards(現在, 目標, 最大角度)

現在の回転から目標の回転へ、最大角度（度）だけ近づけた回転を返します。

Quaternion.Slerp(a, b, t)

2 つの回転の間を、t の割合で滑らかに補間します。

回転 * ベクトル

ベクトルを回転させます。

注釈

回転を X 軸、Y 軸、Z 軸まわりの角度で表す方法（オイラー角）は直感的ですが、回転を組み合わせたときに意図しない結果になることがあります。そのため、Unity は内部で Quaternion を使っています。オイラー角は transform.eulerAngles で読み書きできますが、計算には Quaternion のメソッドを使うのが安全です。

Transform には、回転のための便利なメソッドも用意されています。

メソッド

説明

transform.Rotate(x, y, z)

現在の回転に、指定した角度（度）の回転を加えます（第 10 章）。

transform.LookAt(目標の Transform)

目標の方向を向きます。

回転のサンプルコード

目標の方向へ少しずつ向きを変えながら近づくスクリプトです。

LookAtTarget.cs
// 第 15 章 ベクトルと移動・回転
// 目標のオブジェクトの方向へ滑らかに向きを変え、一定の距離まで近づくスクリプトです。
// 使い方: シーンに Cube を作成してアタッチし、Target にシーン内の別の GameObject を設定します。
using UnityEngine;

public class LookAtTarget : MonoBehaviour
{
    [SerializeField] private Transform _target;

    [Tooltip("1 秒あたりに回転する最大の角度（度）")]
    [SerializeField] private float _turnSpeed = 180f;

    [Tooltip("1 秒あたりに進む距離（m）")]
    [SerializeField] private float _moveSpeed = 2f;

    [Tooltip("目標にこの距離まで近づいたら止まる")]
    [SerializeField] private float _stopDistance = 1.5f;

    private void Update()
    {
        if (_target == null)
        {
            return;
        }

        // 自分から目標へ向かうベクトル（目標の位置 - 自分の位置）
        Vector3 toTarget = _target.position - transform.position;
        toTarget.y = 0f;    // 上下には傾かないように、水平方向の成分だけを使います。

        if (toTarget.sqrMagnitude < 0.0001f)
        {
            return;
        }

        // 目標の方向を向く回転を求め、現在の回転から少しずつ近づけます。
        Quaternion targetRotation = Quaternion.LookRotation(toTarget);
        transform.rotation = Quaternion.RotateTowards(transform.rotation, targetRotation, _turnSpeed * Time.deltaTime);

        // 十分に離れていれば、自分の正面（transform.forward）の方向へ進みます。
        if (toTarget.magnitude > _stopDistance)
        {
            transform.position += transform.forward * _moveSpeed * Time.deltaTime;
        }
    }
}

LookAtTarget.cs をダウンロード

toTarget.y = 0f; で上下方向の成分を 0 にしているのは、目標が高い位置にあっても、上を向いて傾かないようにするためです。また、Quaternion.LookRotation に長さ 0 のベクトルを渡すと正しい回転が得られないため、目標とほぼ同じ位置にいる場合は、sqrMagnitude で判定して処理を終えています。

まとめ

  • Unity の 3D 空間では、Y 軸が上、Z 軸が前です。

  • 「目標の位置 − 自分の位置」で、目標へ向かうベクトルが得られます。

  • normalized で向きだけのベクトルを、magnitude で長さを得られます。

  • 内積を使うと、2 つのベクトルの向きがどれだけ揃っているかがわかります。

  • 回転は Quaternion で表し、Quaternion.Euler や Quaternion.LookRotation などで作ります。
