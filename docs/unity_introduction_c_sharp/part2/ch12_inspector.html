第 12 章 Inspector ウィンドウとの連携

スクリプトのフィールドは、Inspector ウィンドウに表示して、Unity エディター上で値を設定できます。移動の速さや HP の最大値などを Inspector ウィンドウで設定できるようにしておくと、コードを書き換えずにゲームのバランスを調整できます。この章では、その方法を学びます。

シリアライズ

Unity は、コンポーネントのフィールドの値をシーンのファイルやプレハブのファイルに保存します。オブジェクトのデータを保存できる形式に変換することをシリアライズと呼びます。シリアライズされたフィールドは、Inspector ウィンドウに表示され、値を編集できます。

フィールドがシリアライズされるのは、次のどちらかの場合です。

  • public なフィールド

  • [SerializeField] 属性を付けたフィールド

public int PublicValue = 1;                           // シリアライズされる
[SerializeField] private float _moveSpeed = 5f;       // シリアライズされる（推奨）
private int _currentHp;                                // シリアライズされない

public なフィールドは、ほかのスクリプトから自由に書き換えられてしまいます。Inspector ウィンドウで設定したいだけのフィールドは、private にしたうえで [SerializeField] を付けてください。

[SerializeField] のように、[ ] で囲んでクラスやメンバーに付ける情報を、属性と呼びます。

Inspector ウィンドウの値とコードの初期値

コードに書いた初期値（= 5f の部分）が使われるのは、スクリプトを GameObject にアタッチしたときだけです。その後は、Inspector ウィンドウに表示されている値（シーンに保存された値）が使われます。

警告

アタッチした後でコードの初期値を 5f から 10f に変えても、すでにアタッチされているコンポーネントの値は 5 のままです。コードの初期値に戻したいときは、Inspector ウィンドウでコンポーネントの右上の ⋮ ボタンを押し、Reset を選びます。

表示を整える属性

次の属性を使うと、Inspector ウィンドウの表示を整えられます。

属性

効果

[Header("見出し")]

フィールドの上に見出しを表示します。

[Tooltip("説明")]

マウスカーソルを項目に重ねたときに、説明を表示します。

[Range(最小値, 最大値)]

スライダーで値を設定できるようにし、値の範囲を制限します。

[Min(最小値)]

最小値より小さい値を設定できないようにします。

[Space(高さ)]

項目の間に空白を入れます。

[TextArea(最小行数, 最大行数)]

文字列を複数行で入力できるようにします。

[HideInInspector]

シリアライズされるフィールドを、Inspector ウィンドウに表示しないようにします。

シリアライズできる型

すべての型のフィールドがシリアライズできるわけではありません。

種類

例

シリアライズできる

int、float、bool、string などの基本的な型、列挙型、Vector3 や Color などの Unity の構造体、GameObject やコンポーネントへの参照、配列、List<T>、[Serializable] 属性を付けたクラスと構造体

シリアライズできない

Dictionary<TKey, TValue>、static なフィールド、const や readonly のフィールド、プロパティ

自分で定義したクラスや構造体に [Serializable] 属性を付けると、そのフィールドが Inspector ウィンドウに折りたたみ可能な項目として表示されます。[Serializable] を使うには、ファイルの先頭に using System; を書きます。

プロパティはシリアライズされませんが、自動実装プロパティに [field: SerializeField] と書くと、そのプロパティの値を保持する内部のフィールドがシリアライズされます。

サンプルコード

InspectorSample.cs
// 第 12 章 Inspector ウィンドウとの連携
// フィールドを Inspector ウィンドウに表示する方法と、表示を整える属性を確認するスクリプトです。
// 使い方: シーン内の GameObject にアタッチし、Inspector ウィンドウの表示を確認します。
using System;
using System.Collections.Generic;
using UnityEngine;

public class InspectorSample : MonoBehaviour
{
    // public なフィールドは Inspector ウィンドウに表示されますが、ほかのスクリプトからも書き換えられてしまいます。
    public int PublicValue = 1;

    // [SerializeField] を付けると、private のまま Inspector ウィンドウに表示できます（推奨）。
    [Header("移動")]
    [Tooltip("1 秒あたりに進む距離（m）")]
    [SerializeField] private float _moveSpeed = 5f;

    // [Range] を付けると、スライダーで値を設定できます。
    [Range(0f, 1f)]
    [SerializeField] private float _volume = 0.5f;

    [Header("ステータス")]
    [Min(1)]
    [SerializeField] private int _maxHp = 100;

    [Space(10)]
    [TextArea(2, 4)]
    [SerializeField] private string _description = "説明文を入力します。";

    // 配列や List<T> も表示されます。
    [SerializeField] private string[] _tags = { "Player" };

    // [Serializable] を付けたクラスは、フィールドをまとめて表示できます。
    [SerializeField] private List<DropItem> _dropItems = new List<DropItem>();

    // Inspector ウィンドウに表示しない private なフィールドです（[SerializeField] がないため）。
    private int _currentHp;

    // 自動実装プロパティは、[field: SerializeField] を付けると表示できます。
    [field: SerializeField] public int Level { get; private set; } = 1;

    private void Start()
    {
        _currentHp = _maxHp;
        Debug.Log($"速さ: {_moveSpeed}, 音量: {_volume}, HP: {_currentHp}, レベル: {Level}");
        Debug.Log($"説明: {_description}, タグの数: {_tags.Length}, ドロップアイテムの数: {_dropItems.Count}");
    }

    // [Serializable] を付けると、このクラスの public なフィールドと [SerializeField] 付きのフィールドが保存・表示されます。
    [Serializable]
    private class DropItem
    {
        public string Name;

        [Range(0f, 1f)]
        public float Probability;
    }
}

InspectorSample.cs をダウンロード

このスクリプトを GameObject にアタッチすると、Inspector ウィンドウには Public Value、Move Speed、Volume、Max Hp、Description、Tags、Drop Items、Level の各項目が表示されます。_currentHp は [SerializeField] がないため、表示されません。

まとめ

  • public なフィールドと [SerializeField] を付けたフィールドは、シリアライズされて Inspector ウィンドウに表示されます。

  • Inspector ウィンドウで設定したいフィールドは、private にして [SerializeField] を付けます。

  • アタッチした後は、コードの初期値ではなく Inspector ウィンドウの値が使われます。

  • Dictionary<TKey, TValue> やプロパティなど、シリアライズできないものもあります。
