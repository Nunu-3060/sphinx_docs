付録 E サンプルコード一覧

本書で使ったサンプルコードの一覧である。ファイル名をクリックすると、そのファイルをダウンロードできる。すべてのファイルをまとめた examples.zip もある。ZIP ファイルを展開すると、examples フォルダーの中に次の構成でファイルが配置される。

1examples/
2├── setup.cfg      flake8 と mypy の設定
3├── hg.py          双曲平面の計算の共通モジュール
4├── hg_plot.py     図の描画の補助モジュール
5└── ch02_*.py 〜 ch10_*.py  各章のサンプル

実行と検査の方法

サンプルは examples フォルダーで実行する。図を描くサンプルは画面に図を表示し、計算をするサンプルは結果を表示する。多くのサンプルは共通モジュール hg.py と hg_plot.py を import するので、個別にダウンロードした場合は、一覧の「必要なもの」の列に示したファイルも同じフォルダーに置く。必要なパッケージ（NumPy、matplotlib）ははじめにを参照。

1$ cd examples
2$ python ch04_parallels.py

サンプルは、flake8（PEP 8 などのコーディング規約の検査）と mypy（型ヒントの検査）で違反がないことを確認している。examples フォルダーで次のコマンドを実行すると、setup.cfg の設定（行長 120 文字まで、mypy の strict モード）で検査できる。

1$ cd examples
2$ python -m flake8 .
3$ python -m mypy .

matplotlib の 3 次元グラフの機能（mpl_toolkits）は型ヒントの情報を持たないため、setup.cfg でこの import の検査を省略している。mypy は実行したフォルダーの setup.cfg を読むので、ほかのフォルダーから実行する場合は python -m mypy --config-file examples/setup.cfg examples のように設定ファイルを指定する。
