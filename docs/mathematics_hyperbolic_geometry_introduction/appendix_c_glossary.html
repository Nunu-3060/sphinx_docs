付録 C 用語集

本書で使った主な用語を、部ごとに本文に出てきた順に並べる。用語の後に英語の表記を示す。

第 I 部 双曲幾何学への入口

双曲幾何学

ユークリッド幾何学の平行線公準を「直線の外の 1 点を通り、その直線と交わらない直線が 2 本以上ある」に置き換えた幾何学。曲率が負で一定の面の幾何学でもある。ロバチェフスキー幾何学とも呼ぶ。英語：hyperbolic geometry

双曲平面

双曲幾何学が成り立つ 2 次元の空間。ガウス曲率がどこでも同じ負の値をとる、境界のない完備な面である。本書では曲率を \(-1\) とする。英語：hyperbolic plane

公準

幾何学の議論の出発点として、証明せずに認める前提。ユークリッドの『原論』では 5 つの公準が置かれている。英語：postulate

平行線公準

「直線と、その上にない点が与えられたとき、その点を通り直線と交わらない直線はちょうど 1 本ある」という前提。ユークリッドの第 5 公準と同値である。英語：parallel postulate

モデル

ユークリッド幾何学の中の具体的な集合と長さの測り方を使って、双曲平面を表したもの。上半平面モデル、ポアンカレ円板モデル、双曲面モデル、クラインモデルなどがある。英語：model

ガウス曲率

面の曲がり方を表す量。面の中の長さと角度の測定だけから決まる。球面では正、平面では 0、双曲平面では負である。英語：Gaussian curvature

擬球

牽引曲線を軸のまわりに回転させた曲面。ガウス曲率がどこでも \(-1\) であり、双曲平面の一部を 3 次元空間の中に実現する。英語：pseudosphere

ヒルベルトの定理

曲率が負で一定の完備な面の全体を、長さを変えずに 3 次元ユークリッド空間の中に滑らかな曲面として置くことはできない、という定理（1901 年）。英語：Hilbert's theorem

第 II 部 モデルと計量

計量

曲線の長さの測り方。微小な線分の長さ \(ds\) を、座標の微小な変化で表した式で与える。英語：metric

測地線

計量で測って最短となる曲線。ユークリッド幾何学の直線にあたる。英語：geodesic

上半平面モデル

複素平面の上半分 \(\Im z > 0\) を点の集合とし、計量を \(ds = |dz| / \Im z\) とする双曲平面のモデル。英語：upper half-plane model

無限遠点

モデルの境界の点（上半平面モデルでは実軸の点と \(\infty\)、円板モデルでは単位円の点）。双曲平面の点ではないが、測地線の行き着く先を表す。理想点ともいう。英語：point at infinity, ideal point

等角

モデルの図の上での角度が、双曲平面での角度と一致すること。上半平面モデルと円板モデルは等角である。英語：conformal

ポアンカレ円板モデル

単位円板 \(|z| < 1\) を点の集合とし、計量を \(ds = 2|dz| / (1 - |z|^2)\) とする双曲平面のモデル。本書では円板モデルと略す。英語：Poincaré disk model

ケーリー変換

上半平面モデルを円板モデルに移すメビウス変換 \(w = (z - i)/(z + i)\)。英語：Cayley transform

ミンコフスキーの双線形形式

\(B(x, y) = x_0 y_0 - x_1 y_1 - x_2 y_2\) で定義される双線形形式。双曲面モデルの距離と等長変換の定義に使う。英語：Minkowski bilinear form

双曲面モデル

2 葉双曲面の上半分 \(B(x, x) = 1\)、\(x_0 > 0\) を点の集合とする双曲平面のモデル。距離は \(\cosh d = B(x, y)\) で求まる。ミンコフスキーモデル、ローレンツモデルとも呼ぶ。英語：hyperboloid model

クラインモデル

単位円板を点の集合とし、測地線を弦（線分）とする双曲平面のモデル。等角ではない。ベルトラミ・クラインモデルとも呼ぶ。英語：Klein model, Beltrami–Klein model

双曲距離

双曲平面の 2 点を結ぶ曲線の、計量で測った長さの最小値。英語：hyperbolic distance

極限平行線

測地線 \(L\) と交わらず、\(L\) と無限遠点を共有する測地線。無限遠点に向かって \(L\) との距離が 0 に近づく。英語：limiting parallel, asymptotic parallel

超平行線

測地線 \(L\) と交わらず、無限遠点も共有しない測地線。\(L\) と共通の垂線をちょうど 1 本持つ。英語：ultraparallel

平行角

点から測地線に下ろした垂線と、その点を通る極限平行線のなす角。垂線の長さ \(h\) に対し \(\tan(\Pi(h)/2) = e^{-h}\) である。英語：angle of parallelism

等長変換

2 点の距離を変えない変換。英語：isometry

メビウス変換

複素数 \(a, b, c, d\) （\(ad - bc \ne 0\)）を使って \(z \mapsto (az + b)/(cz + d)\) と表される変換。一次分数変換ともいう。英語：Möbius transformation

鏡映

測地線の上の点を動かさず、測地線の両側を入れ替える等長変換。英語：reflection

ローレンツ群

ミンコフスキーの双線形形式を保つ線形変換の群。上半分の双曲面を保つものが、双曲面モデルの等長変換になる。英語：Lorentz group

第 III 部 双曲平面の図形

双曲余弦定理

双曲平面の三角形の辺と角の関係 \(\cosh c = \cosh a \cosh b - \sinh a \sinh b \cos \gamma\)。英語：hyperbolic law of cosines

双曲正弦定理

双曲平面の三角形の辺と角の関係 \(\sin\alpha / \sinh a = \sin\beta / \sinh b = \sin\gamma / \sinh c\)。英語：hyperbolic law of sines

ガウス・ボネの定理

曲面の曲率の積分と図形の角度を結びつける定理。双曲平面の三角形については、面積が \(\pi - (\alpha + \beta + \gamma)\) に等しいことを述べる。英語：Gauss–Bonnet theorem

角欠損

三角形の内角の和の \(\pi\) からの不足分 \(\pi - (\alpha + \beta + \gamma)\)。双曲平面では三角形の面積に等しい。英語：angle defect

理想三角形

3 つの頂点がすべて無限遠点にある三角形。内角はすべて 0、面積は \(\pi\) である。英語：ideal triangle

円

1 点からの双曲距離が一定の点の集まり。半径 \(r\) の円の円周は \(2\pi \sinh r\) である。英語：circle

ホロサイクル

無限遠点を中心とする「半径が無限大の円」。円板モデルでは単位円に内側から接する円として描かれる。英語：horocycle

等距離線

1 本の測地線からの距離が一定の点の集まり（測地線の片側の部分）。英語：hypercycle, equidistant curve

タイリング

同じ形の図形を、すき間なく重なりなく並べて平面を覆うこと。平面充填ともいう。英語：tiling, tessellation

シュレーフリ記号

正 \(p\) 角形を各頂点に \(q\) 枚ずつ集めたタイリングを表す記号 \(\{p, q\}\)。英語：Schläfli symbol

第 IV 部 応用と計算

双曲埋め込み

データの対象を双曲空間の点で表す埋め込み。階層構造を持つデータを低い次元で表せる。英語：hyperbolic embedding, Poincaré embedding

ハイパボリックツリー

木を円板モデルに描き、等長変換で焦点を移しながら表示する可視化の手法。英語：hyperbolic tree

ラピディティ

速さ \(v\) （光速を 1 とする）に対する \(\artanh v\)。同じ向きの速度の合成で足し算になる。英語：rapidity

スミスチャート

伝送線路の反射係数を単位円板の点として表し、インピーダンスの目盛りを描き込んだ図表。英語：Smith chart
