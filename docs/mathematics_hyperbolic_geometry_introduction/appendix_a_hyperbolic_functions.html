付録 A 双曲線関数

本書で使う双曲線関数の定義と公式をまとめる。

定義

双曲線関数は、指数関数を使って次のように定義する。

\[\cosh x = \frac{e^x + e^{-x}}{2}, \qquad \sinh x = \frac{e^x - e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}\]

それぞれハイパボリックコサイン、ハイパボリックサイン、ハイパボリックタンジェントと読む。\(\cosh x \ge 1\)、\(-1 < \tanh x < 1\) である。

三角関数の \((\cos t, \sin t)\) が単位円 \(x^2 + y^2 = 1\) の上の点を表すのと同じく、\((\cosh t, \sinh t)\) は双曲線 \(x^2 - y^2 = 1\) の右側の枝の上の点を表す。「双曲線関数」の名はこれに由来する。双曲面モデル（第 3 章）の点を \((\cosh t, \sinh t \cos\theta, \sinh t \sin\theta)\) と表せるのも、この性質による。

備考

\(\cosh^2 x - \sinh^2 x = 1\)

三角関数の \(\cos^2 x + \sin^2 x = 1\) に対応する。

\((\cosh x)' = \sinh x\)、\((\sinh x)' = \cosh x\)

三角関数と異なり、符号が変わらない。

\(\cosh(x + y) = \cosh x \cosh y + \sinh x \sinh y\)

加法定理

\(\sinh(x + y) = \sinh x \cosh y + \cosh x \sinh y\)

加法定理

\(\tanh(x + y) = \dfrac{\tanh x + \tanh y}{1 + \tanh x \tanh y}\)

相対論的な速度の合成（第 9 章）

\(\cosh 2x = 1 + 2 \sinh^2 x\)、\(\sinh 2x = 2 \sinh x \cosh x\)

倍角の公式

\(\cosh x = \dfrac{1 + t^2}{1 - t^2}\)、\(\sinh x = \dfrac{2t}{1 - t^2}\) （\(t = \tanh(x/2)\)）

円板モデルの計算（第 4 章、第 7 章）で使う。

\(\cosh x = \cos(ix)\)、\(\sinh x = -i \sin(ix)\)

球面と双曲平面の公式の対応（第 2 章）

逆関数

\(\cosh\)、\(\sinh\)、\(\tanh\) の逆関数を \(\arcosh\)、\(\arsinh\)、\(\artanh\) と書く（\(\cosh^{-1}\) などとも書く）。対数で表すと次のようになる。

\[\arcosh x = \ln \left( x + \sqrt{x^2 - 1} \right) \ (x \ge 1), \qquad \arsinh x = \ln \left( x + \sqrt{x^2 + 1} \right), \qquad \artanh x = \frac{1}{2} \ln \frac{1 + x}{1 - x} \ (|x| < 1)\]

\(\arcosh\) は \(x \ge 1\) で定義され、値が 0 以上のものをとる。Python では math.acosh()、math.asinh()、math.atanh()、NumPy では np.arccosh()、np.arcsinh()、np.arctanh() で計算できる。

円板モデルの距離の公式で、\(\cosh\) を使う形と \(\artanh\) を使う形が同じ値になることは、上の表の \(\cosh x = (1 + t^2) / (1 - t^2)\) （\(t = \tanh(x/2)\)）から確かめられる。
