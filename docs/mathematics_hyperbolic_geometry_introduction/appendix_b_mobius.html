メビウス変換

複素数 \(a, b, c, d\) で \(ad - bc \ne 0\) を満たすものに対して

\[f(z) = \frac{az + b}{cz + d}\]

の形の変換をメビウス変換（一次分数変換）という。\(z = -d/c\) は \(\infty\) に移り、\(\infty\) は \(a/c\) に移ると約束すると、メビウス変換は「複素平面に \(\infty\) を加えたもの」からそれ自身への 1 対 1 の写像になる。

メビウス変換には、次の性質がある。

  • 合成と逆変換：\(f\) を行列 \(\begin{pmatrix} a & b \\ c & d \end{pmatrix}\) で表すと、変換の合成は行列の積に、逆変換は逆行列に対応する。行列を 0 でない数倍しても同じ変換を表す。

  • 円を円に移す：直線を「\(\infty\) を通る円」とみなすと、メビウス変換は円を円に移す。

  • 等角：メビウス変換は、曲線の交わる角度を変えない。

  • 3 点で決まる：異なる 3 点 \(z_1, z_2, z_3\) を、異なる 3 点 \(w_1, w_2, w_3\) に移すメビウス変換は、ちょうど 1 つある。

  • 不動点：恒等変換でなければ、不動点（\(f(z) = z\) となる点）は 1 個か 2 個である。

これらの性質のため、メビウス変換は「測地線（実軸や単位円に直交する円）を測地線に移す」「角度を保つ」という双曲平面の等長変換の条件と相性が良い。

円に関する反転

中心 \(c\)、半径 \(\rho\) の円に関する反転は、点 \(z\) を、\(c\) から見て同じ向きにあり、\(c\) からの距離の積が \(\rho^2\) になる点に移す変換である。式では

\[z \mapsto c + \frac{\rho^2}{\bar{z} - \bar{c}}\]

と書ける。反転はメビウス変換に複素共役を合成した形をしており、円を円に移し、角度の大きさを保つが、向きを逆にする。円の上の点は動かず、円の内側と外側が入れ替わる。上半平面モデルと円板モデルで、測地線に関する鏡映は、測地線を含む円に関する反転である（第 5 章）。
