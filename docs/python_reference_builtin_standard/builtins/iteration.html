イテレーション・コレクション操作

イテラブル（リストやタプルなど反復可能なオブジェクト）を操作するための関数群。

len

オブジェクトの長さ（要素数）を返す。

>>> len([1, 2, 3])
3
>>> len("hello")
5

range

等差数列を生成するイミュータブルなシーケンス型。

>>> list(range(5))
[0, 1, 2, 3, 4]
>>> list(range(2, 10, 2))
[2, 4, 6, 8]

enumerate

イテラブルの要素にインデックスを付与したイテレータを返す。

>>> list(enumerate(["a", "b", "c"]))
[(0, 'a'), (1, 'b'), (2, 'c')]

zip

複数のイテラブルの要素を組にまとめたイテレータを返す。最も短いイテラブルの長さで打ち切られる。

>>> list(zip([1, 2, 3], ["a", "b", "c"]))
[(1, 'a'), (2, 'b'), (3, 'c')]

map

イテラブルの各要素に関数を適用したイテレータを返す。

>>> list(map(str, [1, 2, 3]))
['1', '2', '3']

注釈

Python では 内包表記（[str(x) for x in xs]）の方が読みやすいとされ、特にラムダ式を渡す場合は内包表記が推奨されることが多い。一方で map には以下のような利点があり、使い分ける価値がある。

  • str や int のような既存の名前付き関数をそのまま渡せるため、map(str, xs) のように内包表記より簡潔に書ける。

  • 戻り値が遅延評価されるイテレータのため、巨大なデータや無限イテラブルを扱う際にメモリ効率が良く、他のイテレータ処理（itertools など）とパイプライン的に繋げやすい。

  • 複数のイテラブルを同時に渡せる（map(f, a, b)）ため、zip と組み合わせる内包表記より簡潔になる場合がある。

filter

関数が True を返す要素だけを残したイテレータを返す。

>>> list(filter(lambda x: x % 2 == 0, range(10)))
[0, 2, 4, 6, 8]

注釈

map の場合と同様の理由で、内包表記より filter が適する場面がある。filter 特有の便利な使い方として、関数の代わりに None を渡す filter(None, xs) は、偽値（0、''、None など）を取り除くイディオムとしてよく使われる。

sorted

イテラブルの要素を並べ替えた新しいリストを返す。

>>> sorted([3, 1, 2])
[1, 2, 3]
>>> sorted(["banana", "apple"], key=len)
['apple', 'banana']

reversed

シーケンスを逆順にたどるイテレータを返す。

>>> list(reversed([1, 2, 3]))
[3, 2, 1]

sum

イテラブルの要素の合計を返す。

>>> sum([1, 2, 3])
6
>>> sum([1, 2, 3], 10)
16

min / max

イテラブル中の最小値・最大値を返す。

>>> min([3, 1, 2])
1
>>> max([3, 1, 2])
3
>>> max(["a", "bb", "ccc"], key=len)
'ccc'

any / all

any はいずれかの要素が真なら True、all はすべての要素が真なら True を返す。

>>> any([0, 0, 1])
True
>>> all([1, 1, 0])
False

注釈

空のイテラブルを渡した場合、any は False、all は True を返す。これは「1つでも真の要素があるか（存在）」「すべての要素が真か（全称）」という論理を、要素が0個の場合にも数学的に一貫させた結果（空真理、vacuous truth）であり、バグではない。

>>> any([])
False
>>> all([])
True

このため、all() を「対象データがすべて条件を満たしているか」の検証に使う場合、対象が1件もないと意図せず True になってしまう点に注意が必要。件数チェックを別途行うなど、空である場合の扱いを明確にしておくとよい。

iter / next

iter はイテラブルからイテレータを取得し、next はイテレータから次の要素を取り出す。

>>> it = iter([1, 2, 3])
>>> next(it)
1
>>> next(it)
2
