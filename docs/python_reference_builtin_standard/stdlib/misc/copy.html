copy

オブジェクトのコピーを作成するためのモジュール。単純な代入 b = a は同じオブジェクトを指す別名を作るだけだが、copy モジュールを使うと実体そのものを複製できる。複製の深さによって copy() （浅いコピー）と deepcopy() （深いコピー）を使い分ける。

copy() による浅いコピー

copy.copy() は新しいオブジェクトを作成するが、その中身がリストや 辞書などのミュータブルなオブジェクトである場合、内部の要素までは複製せず 元のオブジェクトと共有する。

>>> import copy
>>> a = [1, 2, [3, 4]]
>>> b = copy.copy(a)
>>> b is a
False
>>> b[0] = 100
>>> a
[1, 2, [3, 4]]

deepcopy() による深いコピー

copy.deepcopy() はネストされた要素も再帰的にすべて複製する。 元のオブジェクトと複製後のオブジェクトが、内部の要素も含めて完全に 独立したものになる。

>>> a = [1, 2, [3, 4]]
>>> c = copy.deepcopy(a)
>>> c[2] is a[2]
False
>>> c[2][0] = 999
>>> a
[1, 2, [3, 4]]
>>> c
[1, 2, [999, 4]]

浅いコピーが問題になる例

浅いコピーでは、ネストしたミュータブルなオブジェクト（リストの中のリスト など）が元のオブジェクトと共有されたままになるため、片方を変更すると もう片方にも影響が及んでしまう。

>>> original = [1, 2, [3, 4]]
>>> shallow = copy.copy(original)
>>> shallow[2].append(5)  # ネストしたリストを変更
>>> original
[1, 2, [3, 4, 5]]
>>> shallow
[1, 2, [3, 4, 5]]

このように、内側のリストは original と shallow の両方から参照されている同一オブジェクトである。ネストした構造を独立に扱いたい場合は deepcopy() を使う必要がある。

注釈

イミュータブルな要素（数値や文字列など）だけで構成されたリストの 場合は、浅いコピーでも実質的に独立したコピーとして扱える。深いコピーが 本当に必要かどうかは、扱っているデータの構造次第である。

__copy__ / __deepcopy__ によるコピー処理のカスタマイズ

ファイルハンドルやキャッシュなど、複製すべきでない外部リソースを持つ自作クラスでは、__copy__/__deepcopy__ メソッドを定義することで、copy.copy()/copy.deepcopy() が呼ばれた際の振る舞いを自分で制御できる。

class Cache:
    def __init__(self, data):
        self.data = data
        self.connection = object()  # 複製したくない外部リソースの例

    def __deepcopy__(self, memo):
        new = Cache(copy.deepcopy(self.data, memo))
        new.connection = self.connection  # 接続オブジェクトは共有する
        return new
