random

擬似乱数を生成するためのモジュール。乱数の取得、リストからのランダムな 選択、要素の並べ替えなど、ゲームやシミュレーション、シャッフル処理などで よく使われる機能を提供する。

注釈

このモジュールが生成する乱数は暗号論的に安全ではない。パスワードやトークン、セキュリティ関連の用途には、暗号論的に安全な乱数を生成する secrets モジュールを使用すること。

random.random

0.0 以上 1.0 未満の浮動小数点数を返す。

>>> import random
>>> random.random()
0.6394267984578837

random.randint

指定した範囲（両端を含む）のランダムな整数を返す。

>>> random.randint(1, 6)
4
>>> [random.randint(1, 6) for _ in range(5)]
[3, 1, 6, 2, 5]

random.choice / random.sample

choice はシーケンスから要素を1つ選ぶ。sample は重複なしで 指定した個数の要素を選ぶ。

>>> members = ["Alice", "Bob", "Carol", "Dave"]
>>> random.choice(members)
'Carol'
>>> random.sample(members, 2)
['Dave', 'Alice']

random.uniform

指定した範囲の浮動小数点数を返す。randint の浮動小数点数版で、 両端の値も含まれる可能性がある。

>>> random.uniform(1.0, 10.0)
8.599796663725433

random.choices

sample とは異なり重複を許した（同じ要素を何度でも選べる） サンプリングを行う。weights 引数で要素ごとの重みを指定すると、 重みが大きい要素ほど選ばれやすくなる（重み付きサンプリング）。

>>> members = ["Alice", "Bob", "Carol"]
>>> random.choices(members, k=5)
['Bob', 'Alice', 'Alice', 'Carol', 'Bob']
>>> # "Alice" が他の10倍選ばれやすくなる
>>> random.choices(members, weights=[10, 1, 1], k=5)
['Alice', 'Alice', 'Alice', 'Alice', 'Alice']

random.shuffle

リストの要素をその場（in-place）でランダムに並べ替える。

>>> cards = [1, 2, 3, 4, 5]
>>> random.shuffle(cards)
>>> cards
[3, 1, 5, 2, 4]

random.seed

乱数生成器の種（シード）を設定する。同じシードを与えると、以降の乱数列が 再現可能になるため、テストやデバッグに有用。

>>> random.seed(0)
>>> random.random()
0.8444218515250481
>>> random.seed(0)
>>> random.random()
0.8444218515250481
