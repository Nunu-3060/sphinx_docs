4. CSS の基礎

4.1. CSS の書き方

CSS（Cascading Style Sheets）は、HTML の要素の見た目を指定する言語である。CSS の記述は、次のようなルールの集まりである。

h1 {
  color: steelblue;
  font-size: 32px;
}
ルールを構成する部分

名前

例

意味

セレクター

h1

スタイルを適用する要素を選ぶ条件。

プロパティ

color

変更する性質。

値

steelblue

プロパティに設定する値。

宣言

color: steelblue;

プロパティと値の組。{ と } の中に、; で区切って複数書ける。

CSS のコメントは /* と */ で囲む。Python の # や JavaScript の // のような 1 行コメントの記法は無い。

CSS は宣言的な言語であり、処理の手順ではなく「どの要素をどう表示するか」を記述する。ある宣言が誤っていても、その宣言が無視されるだけで、残りの CSS は適用される。

4.2. CSS の適用方法

CSS を HTML に適用する方法は 3 つある。

CSS の適用方法

方法

書き方

用途

外部ファイル

head 要素の中に <link rel="stylesheet" href="style.css"> と書き、別ファイルの CSS を読み込む。

通常はこの方法を使う。複数のページで同じ CSS を共有できる。

style 要素

head 要素の中に <style> ～ </style> を置き、その中に CSS を書く。

1 つのページだけで使う CSS や、小さなサンプル。

style 属性

<p style="color: red;"> のように、要素に直接書く。

JavaScript で一時的に見た目を変える場合など。多用すると保守しにくい。

4.3. 主なセレクター

主なセレクター

種類

例

選ばれる要素

要素セレクター

p

すべての p 要素。

クラスセレクター

.note

class="note" を持つ要素。class 属性には空白で区切って複数のクラス名を指定できる。

ID セレクター

#title

id="title" を持つ要素。id 属性の値はページ内で一意でなければならない。

全称セレクター

*

すべての要素。

子孫セレクター

nav a

nav 要素の中にある（何階層下でもよい） a 要素。

子セレクター

ul > li

ul 要素の直接の子である li 要素。

複数のセレクター

h1, h2

h1 要素と h2 要素の両方。

属性セレクター

a[href^="https"]

href 属性の値が https で始まる a 要素。

疑似クラス

a:hover

マウスカーソルが上にある a 要素。ほかに :focus （入力中）、:nth-child(odd) （奇数番目）などがある。

疑似要素

p::first-line

p 要素の 1 行目。::before と ::after は、要素の内容の前後に content プロパティで指定した内容を追加する。

p.note のようにセレクターを空白なしでつなげると、「p 要素であり、かつ class="note" を持つ要素」という意味になる。空白を入れた p .note は子孫セレクターであり、「p 要素の中にある class="note" の要素」という別の意味になるので注意する。

実際の開発では、見た目の指定には主にクラスセレクターを使う。ID セレクターは次節で説明する詳細度が高く、後から上書きしにくいため、CSS ではあまり使わない。

examples/ch04/style.css
/* ===== 要素セレクター: すべての p 要素 ===== */
p {
  line-height: 1.7;
}

/* ===== クラスセレクター: class="note" を持つ要素 ===== */
.note {
  color: #555;
  background-color: #f5f5f5;
}

/* ===== ID セレクター: id="title" を持つ要素 (ページ内に 1 つ) ===== */
#title {
  color: steelblue;
}

/* ===== 子孫セレクター: nav の中にある a 要素 ===== */
nav a {
  margin-right: 1rem;
}

/* ===== 子セレクター: ul の直接の子である li 要素 ===== */
ul.menu > li {
  font-weight: bold;
}

/* ===== 属性セレクター: href が https で始まる a 要素 ===== */
a[href^="https"] {
  color: darkgreen;
}

/* ===== 疑似クラス: 状態によって適用される ===== */
a:hover {
  text-decoration: none;
}

li:nth-child(odd) {
  background-color: #eef4fb;
}

/* ===== 疑似要素: 要素の一部や前後に内容を追加する ===== */
.required::after {
  content: " *";
  color: crimson;
}

/* ===== 詳細度の確認: 同じ要素に複数のルールが当たる場合 ===== */
/* 詳細度 (0, 0, 1): 要素セレクター */
h2 {
  color: gray;
}

/* 詳細度 (0, 1, 0): クラスセレクターの方が優先される */
.section-title {
  color: darkorange;
}

/* ===== 継承: body に指定した font-family は子孫要素に引き継がれる ===== */
body {
  font-family: "Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif;
}
examples/ch04/selector.html

<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>セレクターの例</title>
  <!-- 外部 CSS ファイルを読み込む -->
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 id="title">セレクターの例</h1>

  <nav>
    <a href="#">ホーム</a>
    <a href="https://developer.mozilla.org/ja/">MDN (https で始まるリンク)</a>
  </nav>

  <h2>要素セレクターだけが当たる見出し (灰色)</h2>
  <h2 class="section-title">クラスセレクターも当たる見出し (オレンジ色)</h2>

  <p>普通の段落。</p>
  <p class="note">class="note" を持つ段落。</p>

  <ul class="menu">
    <li>1 番目 (奇数番目は背景色が付く)</li>
    <li>2 番目</li>
    <li>3 番目</li>
  </ul>

  <p class="required">必須項目</p>

  <!-- style 属性による指定は最も優先されるが、多用すると保守しにくい -->
  <p style="color: purple;">style 属性で色を指定した段落。</p>
</body>
</html>

4.4. カスケード・詳細度・継承

1 つの要素に複数のルールが当てはまり、同じプロパティに異なる値が指定されることがある。どの値を採用するかを決める仕組みをカスケードと呼ぶ。CSS の名前の Cascading はこれに由来する。

カスケードでは、主に次の順で優先度が決まる。

  1. !important が付いた宣言（強制的に優先させる指定。多用すると上書きできなくなるため、原則として使わない）

  2. style 属性による指定

  3. セレクターの詳細度が高いルール

  4. 詳細度が同じなら、後に書かれたルール

4.4.1. 詳細度

詳細度は、セレクターに含まれる部品の数を、次の 3 つの組で数えたものである。

詳細度の数え方

組

数える部品

A

ID セレクターの数

B

クラスセレクター・属性セレクター・疑似クラスの数

C

要素セレクター・疑似要素の数

比較は A から順に行い、A が同じ場合に限り B を、B も同じ場合に限り C を比べる。たとえば、次のようになる。

詳細度の例

セレクター

詳細度 (A, B, C)

備考

p

(0, 0, 1)

nav a

(0, 0, 2)

.note

(0, 1, 0)

要素セレクターがいくつあっても、クラスセレクター 1 つに勝てない。

ul.menu > li

(0, 1, 2)

> などの結合子は数えない。

#title

(1, 0, 0)

クラスセレクターがいくつあっても、ID セレクター 1 つに勝てない。

サンプルの selector.html では、2 つ目の h2 要素に h2 （詳細度 (0, 0, 1)）と .section-title （詳細度 (0, 1, 0)）の 2 つのルールが当てはまる。h2 のルールが後に書かれていても、詳細度が高い .section-title の色が採用される。

どのルールが採用されたかは、開発者ツールの「要素」タブで確認できる。採用されなかった宣言には取り消し線が引かれて表示される。

4.4.2. 継承

color や font-family など、文字に関する多くのプロパティは、親要素に指定した値が子孫要素に引き継がれる。これを継承と呼ぶ。body 要素にフォントを指定すれば、ページ全体のフォントが変わるのはこのためである。

一方、margin、padding、border、background-color など、配置や装飾に関するプロパティは継承されない。

4.5. 単位

長さを表す値には単位を付ける。値が 0 の場合に限り、単位を省略できる。

主な単位

単位

意味

px

ピクセル。画面上の基本的な長さの単位である。高解像度の画面では、1px が複数の物理的な画素で表示される。

%

親要素の大きさに対する割合。

em

その要素の文字の大きさに対する倍率。font-size プロパティに使った場合は、親要素の文字の大きさに対する倍率になる。

rem

ルート要素（html 要素）の文字の大きさに対する倍率。多くのブラウザの既定値は 16px なので、1rem は 16px になる。

vw ／ vh

ブラウザの表示領域の幅／高さに対する割合。100vw が表示領域の幅全体である。

em は入れ子になるたびに倍率が掛け合わされるため、意図しない大きさになりやすい。文字の大きさや余白には rem を使うと管理しやすい。

4.6. 色とフォント

4.6.1. 色の指定方法

色の指定方法

書き方

意味

steelblue

色の名前。140 種類以上の名前が定義されている。

#4682b4

16 進数による RGB の指定。# に続けて赤・緑・青の強さを 2 桁ずつ（00 ～ ff）書く。

rgb(70 130 180)

10 進数による RGB の指定。各色の強さを 0 ～ 255 で書く。

rgb(0 0 0 / 50%)

透明度付きの指定。/ の後に不透明度を書く。0% で完全に透明、100% で不透明になる。

文字の色は color プロパティ、背景色は background-color プロパティで指定する。

4.6.2. フォント

フォントに関する主なプロパティ

プロパティ

意味

font-family

フォントの種類。カンマで区切って複数書くと、利用者の環境にあるものが先頭から順に使われる。最後には sans-serif （ゴシック体）や serif （明朝体）などの総称を書く。

font-size

文字の大きさ。

font-weight

文字の太さ。bold （太字）や 400 （標準）などを指定する。

line-height

行の高さ。1.7 のように単位なしで書くと、文字の大きさに対する倍率になる。

text-align

行内での文字の揃え方。left、center、right などを指定する。

4.7. ボックスモデル

ブラウザは、すべての要素を長方形の箱（ボックス）として配置する。ボックスは、内側から順に次の 4 つの領域で構成される。これをボックスモデルと呼ぶ。

ボックスを構成する領域

領域

意味

content

内容（文字や画像）を表示する領域。大きさは width プロパティと height プロパティで指定する。

padding

content と border の間の余白。背景色は padding の領域にも塗られる。padding プロパティで指定する。

border

枠線。border: 1px solid gray; のように、太さ・線の種類・色をまとめて指定できる。

margin

border の外側の余白。隣の要素との間隔になる。margin プロパティで指定する。

padding プロパティと margin プロパティは、値の数によって指定される辺が変わる。

padding と margin の値の書き方

書き方

意味

margin: 10px;

上下左右すべてが 10px。

margin: 10px 20px;

上下が 10px、左右が 20px。

margin: 10px 20px 30px 40px;

上・右・下・左の順（時計回り）に指定する。

margin-top: 10px;

上だけを指定する。-right、-bottom、-left も同様である。

4.7.1. box-sizing

width プロパティが表す幅は、既定では content の幅である。そのため、画面上に表示されるボックスの幅は、padding と border の分だけ width より大きくなる。

content の幅を \(w\)、左右それぞれの padding を \(p\)、左右それぞれの border の太さを \(b\) とすると、表示される幅 \(W\) は次の式で求められる。

\[W = w + 2p + 2b\]

たとえば、width: 200px; padding: 20px; border: 5px solid; と指定した場合、表示される幅は次のとおり 250px になる。

\[W = 200 + 2 \times 20 + 2 \times 5 = 250\]

box-sizing: border-box; を指定すると、width プロパティが border までを含めた幅を表すようになる。上の例では表示される幅が指定どおり 200px になり、content の幅は次のとおり 150px に自動で調整される。

\[w = 200 - 2 \times 20 - 2 \times 5 = 150\]

幅の計算が直感的になるため、次のように全要素に border-box を指定しておくことが多い。

*,
*::before,
*::after {
  box-sizing: border-box;
}
examples/ch04/box_model.html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>ボックスモデルの例</title>
  <style>
    .box {
      width: 200px;
      padding: 20px;
      border: 5px solid steelblue;
      margin: 16px 0;
      background-color: #eef4fb;
    }

    /* 既定値: width は content 部分の幅を表す */
    .content-box {
      box-sizing: content-box;
    }

    /* width が border までを含む幅を表す */
    .border-box {
      box-sizing: border-box;
    }
  </style>
</head>
<body>
  <h1>ボックスモデルの例</h1>

  <!-- 表示幅 = 200 + 20 * 2 + 5 * 2 = 250px -->
  <div class="box content-box">content-box: 表示幅は 250px</div>

  <!-- 表示幅 = 200px (content の幅は 200 - 20 * 2 - 5 * 2 = 150px) -->
  <div class="box border-box">border-box: 表示幅は 200px</div>

  <p>開発者ツールで要素を選択すると、content・padding・border・margin の大きさを確認できる。</p>
</body>
</html>
