2. HTML の基礎

2.1. HTML 文書の基本構造

HTML（HyperText Markup Language）は、文書の各部分を「タグ」で囲み、それが何であるかを示す言語である。HTML 文書は、必ず次の骨組みを持つ。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>ページのタイトル</title>
</head>
<body>
  <p>ここに本文を書く。</p>
</body>
</html>
基本構造を構成する要素

記述

意味

<!DOCTYPE html>

文書型宣言。この文書が現在の HTML の仕様（HTML Living Standard）に従うことを示す。省略すると、ブラウザは古い仕様との互換モードで表示するため、必ず先頭に書く。

html 要素

文書全体を囲むルート要素。lang 属性で文書の言語を指定する。

head 要素

文書のメタ情報（文字コード、タイトル、読み込む CSS など）を書く。head 要素の内容は、title 要素がブラウザのタブに表示される以外、ページ本体には表示されない。

body 要素

ページ本体として表示される内容を書く。

2.2. 要素・タグ・属性

HTML の基本単位を要素と呼ぶ。要素は、開始タグ・内容・終了タグから構成される。

<a href="https://example.com/">example.com へ</a>

この例では、<a href="https://example.com/"> が開始タグ、example.com へ が内容、</a> が終了タグである。開始タグの中にある href="https://example.com/" は属性と呼ばれ、要素に追加の情報を与える。属性は 名前="値" の形で書き、複数ある場合は空白で区切る。

br 要素（改行）や img 要素（画像）のように、内容を持たない要素もある。これらを空要素と呼び、終了タグを書かない。

要素の中に別の要素を入れることを入れ子と呼ぶ。入れ子にするときは、内側の要素を先に閉じなければならない。

<!-- 正しい -->
<p><strong>重要</strong>な内容</p>

<!-- 誤り: strong 要素より先に p 要素を閉じている -->
<p><strong>重要</p></strong>

HTML では、誤った書き方をしてもブラウザはエラーを表示せず、推測で補って表示する。Python のように構文エラーで実行が止まることはないため、誤りに気付きにくい。この点については「HTML の検証」で改めて扱う。

2.3. テキストを表す要素

テキストを表す主な要素

要素

意味

h1 〜 h6

見出し。数字が小さいほど上位の見出しである。h1 要素はページの主題を表し、通常は 1 ページに 1 つとする。

p

段落。

strong

重要な内容。多くのブラウザでは太字で表示される。

em

強調。多くのブラウザでは斜体で表示される。

br

改行。住所や詩など、改行自体に意味がある場合に使う。

pre

整形済みテキスト。改行や空白をそのまま表示する。

code

コードの断片。

HTML のソース中の改行や連続する空白は、表示時には 1 つの空白にまとめられる。そのため、ソース中で改行しても、表示上は改行されない。段落を分けるには p 要素を使う。

見出しの大きさや太字の表示は、ブラウザが既定で適用している CSS によるものである。「文字を大きくしたいから h1 要素を使う」のではなく、「見出しだから h1 要素を使う」のが HTML の考え方である。見た目は CSS で自由に変更できる。

examples/ch02/basic_structure.html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>HTML 文書の基本構造</title>
</head>
<body>
  <h1>見出し 1: ページの主題</h1>
  <p>段落は p 要素で表す。ソース中の改行や連続する空白は、表示時には 1 つの空白にまとめられる。</p>

  <h2>見出し 2: テキストを表す要素</h2>
  <p>
    <strong>strong は重要な内容</strong>を、
    <em>em は強調</em>を表す。
    改行したい位置には<br>br 要素を置く。
  </p>

  <h2>見出し 2: ブロック要素とインライン要素</h2>
  <div>div はブロック要素なので、前後で改行される。</div>
  <div>次の div も新しい行から始まる。</div>
  <p>
    <span>span はインライン要素なので、</span>
    <span>同じ行に並ぶ。</span>
  </p>

  <h2>見出し 2: 文字参照</h2>
  <!-- < や > をそのまま書くとタグとして解釈されるため、文字参照を使う -->
  <p>&lt;p&gt; と書くと、画面には &lt;p&gt; と表示される。&amp; は &amp;amp; と書く。</p>
</body>
</html>

2.4. リンクと画像

2.4.1. リンク

リンクは a 要素で作る。href 属性にリンク先を指定する。

href 属性に指定する値

書き方

意味

https://example.com/

絶対 URL。別のサイトへのリンクに使う。

page.html

相対パス。現在の HTML ファイルと同じフォルダーにある page.html を指す。

../ch01/hello.html

相対パス。.. は 1 つ上のフォルダーを表す。

/index.html

ルート相対パス。サーバーの公開フォルダーの最上位を基準にする。file:// で開いた場合はドライブの最上位を指すため、意図どおりに動かないことが多い。

#section1

ページ内リンク。id="section1" を持つ要素の位置に移動する。

target="_blank" 属性を付けると、リンク先を新しいタブで開く。

2.4.2. 画像

画像は img 要素で表示する。src 属性に画像ファイルの場所を、alt 属性に代替テキストを指定する。代替テキストは、画像を読み込めなかったときに表示されるほか、スクリーンリーダー（画面を読み上げるソフトウェア）によって読み上げられる。

width 属性と height 属性で画像の大きさを指定しておくと、画像の読み込みが終わる前から表示領域が確保されるため、読み込み中にレイアウトがずれるのを防げる。

examples/ch02/link_image.html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>リンクと画像</title>
</head>
<body>
  <h1>リンクと画像</h1>

  <h2>リンク</h2>
  <ul>
    <!-- 相対パス: この HTML ファイルがあるフォルダーを基準にする -->
    <li><a href="basic_structure.html">同じフォルダーの basic_structure.html</a></li>
    <li><a href="../ch01/hello.html">1 つ上のフォルダーを経由して ch01/hello.html</a></li>
    <!-- 絶対 URL: 別のサイトへのリンク。target="_blank" で新しいタブに開く -->
    <li><a href="https://developer.mozilla.org/ja/" target="_blank" rel="noopener">MDN Web Docs (新しいタブ)</a></li>
    <!-- # から始まる値はページ内の id を指す -->
    <li><a href="#image-section">このページの「画像」へ移動</a></li>
  </ul>

  <h2 id="image-section">画像</h2>
  <!-- alt は画像が表示できないときや読み上げ時に使われる代替テキスト -->
  <img src="sample.svg" alt="青い円と「HTML」の文字" width="200" height="120">
</body>
</html>

link_image.html をダウンロード ／ sample.svg をダウンロード ／ ブラウザで表示

2.5. リストと表

2.5.1. リスト

順序のない箇条書きは ul 要素、番号付きの箇条書きは ol 要素で作る。どちらも、各項目を li 要素で表す。li 要素の中に、さらに ul 要素や ol 要素を入れれば、入れ子のリストになる。

2.5.2. 表

表は table 要素で作る。行を tr 要素、見出しのセルを th 要素、データのセルを td 要素で表す。thead 要素と tbody 要素で見出し部分と本体部分を分け、caption 要素で表の題名を付けられる。

表は、データを行と列で整理して示すために使う。ページのレイアウト（要素を横に並べるなど）に表を使うのは古い手法であり、現在は第 5 章で扱う CSS の Flexbox や Grid を使う。

examples/ch02/list_table.html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>リストと表</title>
  <!-- 表の枠線は CSS で付ける (CSS は第 4 章で扱う) -->
  <style>
    table { border-collapse: collapse; }
    th, td { border: 1px solid #999; padding: 4px 8px; }
  </style>
</head>
<body>
  <h1>リストと表</h1>

  <h2>順序なしリスト (ul)</h2>
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ul>

  <h2>順序付きリスト (ol)</h2>
  <ol>
    <li>HTML で構造を作る</li>
    <li>CSS で見た目を整える</li>
    <li>JavaScript で動きを付ける</li>
  </ol>

  <h2>表 (table)</h2>
  <table>
    <caption>言語と役割</caption>
    <thead>
      <tr>
        <th>言語</th>
        <th>役割</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>HTML</td>
        <td>構造</td>
      </tr>
      <tr>
        <td>CSS</td>
        <td>見た目</td>
      </tr>
      <tr>
        <td>JavaScript</td>
        <td>振る舞い</td>
      </tr>
    </tbody>
  </table>
</body>
</html>

2.6. ブロック要素とインライン要素

要素は、表示のされ方によって大きく 2 種類に分けられる。

ブロック要素とインライン要素

種類

表示のされ方

例

ブロック要素

新しい行から始まり、横幅いっぱいに広がる。

div、p、h1、ul、table

インライン要素

文章の流れの中に並び、内容の幅だけを占める。

span、a、strong、em、img

div 要素と span 要素は、それ自体は意味を持たない要素である。CSS や JavaScript で操作するために、範囲をまとめたいときに使う。div 要素はブロック要素、span 要素はインライン要素である。

この表示のされ方は、CSS の display プロパティで変更できる（第 5 章で扱う）。

2.7. 文字参照とコメント

< や > は、HTML ではタグの記号として解釈される。これらの文字をそのまま表示したい場合は、文字参照を使う。

主な文字参照

文字参照

表示される文字

備考

&lt;

<

less than の略。

&gt;

>

greater than の略。

&amp;

&

文字参照の先頭記号そのもの。

&quot;

"

属性値の中で使う。

&copy;

©

著作権表示。

HTML のコメントは <!-- と --> で囲む。コメントはブラウザには表示されないが、HTML のソースを見れば誰でも読めるため、公開すべきでない情報を書いてはならない。
