1. はじめに

1.1. 本資料の目的と対象読者

本資料の目的は、HTML・CSS・JavaScript を使って、簡単な Web ページや Web アプリを自分で作れるようになることである。

対象読者は、Python などのプログラミング言語で簡単なプログラムを書いた経験がある人とする。変数、条件分岐、ループ、関数、クラスといった概念は既に理解しているものとして扱い、JavaScript の文法は Python との違いを中心に説明する。

一方で、Web 特有の仕組み（ブラウザがページを表示する流れ、DOM、イベント駆動、非同期処理、CSS のレイアウト）は、他の言語の経験だけでは推測しにくいため、詳しく説明する。

なお、本資料ではフレームワーク（React、Vue など）やビルドツール（npm、Vite など）は扱わない。ブラウザとテキストエディタだけで動かせる範囲に限定し、Web の基礎となる仕組みの理解を優先する。

1.2. HTML・CSS・JavaScript の役割分担

Web ページは、役割の異なる 3 つの言語を組み合わせて作る。

3 つの言語の役割

言語

役割

例

HTML

構造

「ここは見出し」「ここは段落」「ここはリンク」のように、文書の構造と意味を表す。

CSS

見た目

文字の色や大きさ、余白、要素の並べ方（レイアウト）を指定する。

JavaScript

振る舞い

ボタンを押したときの処理や、サーバーからのデータ取得など、ページに動きを付ける。

HTML はプログラミング言語ではなく、文書の構造を記述するマークアップ言語である。CSS も同様に、見た目を宣言的に記述するスタイルシート言語である。条件分岐や繰り返しといった処理を記述できるのは、3 つのうち JavaScript だけである。

次の例は、3 つの言語を 1 つのファイルにまとめた最小限の Web ページである。

examples/ch01/hello.html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>はじめての Web ページ</title>
  <style>
    /* CSS: 見た目を指定する */
    h1 {
      color: steelblue;
    }
  </style>
</head>
<body>
  <!-- HTML: 文書の構造を表す -->
  <h1>Hello, World!</h1>
  <p id="message">ボタンを押すとメッセージが変わります。</p>
  <button id="greet-button" type="button">押してみる</button>

  <script>
    // JavaScript: 振る舞いを定義する
    const button = document.querySelector("#greet-button");
    const message = document.querySelector("#message");

    button.addEventListener("click", () => {
      message.textContent = "JavaScript がメッセージを書き換えました。";
    });
  </script>
</body>
</html>

hello.html をダウンロード ／ ブラウザで表示

実際の開発では、HTML・CSS・JavaScript をそれぞれ別のファイルに分けることが多い。役割ごとにファイルを分けると、見た目だけ、あるいは動きだけを修正したいときに、該当するファイルだけを編集すればよい。

1.3. Web ページが表示されるまで

ブラウザのアドレスバーに URL を入力してから、ページが表示されるまでの流れは次のとおりである。

  1. ブラウザが URL を解析し、接続先のサーバーを特定する。

  2. ブラウザがサーバーに HTTP リクエストを送る。

  3. サーバーが HTTP レスポンスとして HTML ファイルを返す。

  4. ブラウザが HTML を先頭から解析し、DOM（Document Object Model）と呼ばれる木構造を作る。

  5. HTML の中で参照されている CSS・JavaScript・画像などのファイルを、改めてサーバーに要求する。

  6. CSS を適用して各要素の位置と大きさを計算し、画面に描画する。

  7. JavaScript を実行する。JavaScript は DOM を書き換えることで、表示内容を変更できる。

ここで重要なのは、JavaScript はサーバーではなくブラウザ上で実行されるという点である。Python のプログラムは通常、Python を実行するコンピューター上で動くが、Web ページの JavaScript は、ページを閲覧している人のブラウザの中で動く。

1.3.1. URL の構成

URL は次のような部分から構成される。ここでは https://example.com:443/docs/index.html?lang=ja#intro を例とする。

URL の構成

部分

例

意味

スキーム

https

通信の方式。https は暗号化された HTTP である。

ホスト

example.com

接続先のサーバーの名前。

ポート

443

接続先のポート番号。https の既定値は 443、http の既定値は 80 であり、既定値の場合は省略できる。

パス

/docs/index.html

サーバー内のファイルやページの位置。

クエリ文字列

?lang=ja

サーバーに渡す追加の情報。キー=値 の組を & でつなぐ。

フラグメント

#intro

ページ内の位置。サーバーには送られず、ブラウザだけが使う。

1.4.2. ローカルサーバー

HTML ファイルはダブルクリックするだけでもブラウザで開ける。このとき URL は file:///C:/... のように file:// で始まる。

しかし、第 6 章で扱う JavaScript のモジュールや、第 8 章で扱う fetch によるファイルの取得は、file:// で開いたページでは動作しない。ブラウザのセキュリティ上の制約によるものである。そのため、これらのサンプルは、自分の PC 上で HTTP サーバー（ローカルサーバー）を起動し、http://localhost:8000/ のような URL で開く必要がある。

Python には、簡易的な HTTP サーバーが標準ライブラリとして含まれている。サンプルコードのフォルダーで次のコマンドを実行すると、そのフォルダーを公開するサーバーが起動する。

python -m http.server 8000

本資料では、Windows 環境でも JavaScript ファイルが正しく扱われるように設定したスクリプト serve.py を用意した。examples フォルダーの ch01 フォルダーで次のように実行し、ブラウザで http://localhost:8000/ を開く。終了するには Ctrl + C キーを押す。

python serve.py
examples/ch01/serve.py
"""サンプルコードをローカルの HTTP サーバーで公開するスクリプト.

examples フォルダーをドキュメントルートとして公開する。

使い方::

    python serve.py
    python serve.py --port 8080

起動後、ブラウザで http://localhost:8000/ を開く。Ctrl+C で終了する。
"""

import argparse
import functools
import http.server
from pathlib import Path

# このファイル (examples/ch01/serve.py) から見た examples フォルダー
DEFAULT_ROOT = Path(__file__).resolve().parent.parent


class SampleRequestHandler(http.server.SimpleHTTPRequestHandler):
    """JavaScript と JSON の MIME タイプを明示したリクエストハンドラー.

    Windows ではレジストリの設定により .js が text/plain として
    返されることがあり、その場合は JavaScript モジュールが動作しない。
    そのため、主要な拡張子の MIME タイプを明示的に指定する。
    """

    extensions_map = {
        **http.server.SimpleHTTPRequestHandler.extensions_map,
        ".html": "text/html; charset=utf-8",
        ".css": "text/css; charset=utf-8",
        ".js": "text/javascript; charset=utf-8",
        ".json": "application/json; charset=utf-8",
        ".svg": "image/svg+xml",
    }


def parse_args() -> argparse.Namespace:
    """コマンドライン引数を解析する."""
    parser = argparse.ArgumentParser(
        description="サンプルコードをローカルの HTTP サーバーで公開する。"
    )
    parser.add_argument(
        "--port", type=int, default=8000, help="待ち受けるポート番号"
    )
    parser.add_argument(
        "--root",
        type=Path,
        default=DEFAULT_ROOT,
        help="公開するフォルダー (既定値: examples フォルダー)",
    )
    return parser.parse_args()


def run_server(root: Path, port: int) -> None:
    """指定したフォルダーを公開する HTTP サーバーを起動する."""
    handler = functools.partial(SampleRequestHandler, directory=str(root))
    # 127.0.0.1 で待ち受けるため、同じ PC からしか接続できない
    address = ("127.0.0.1", port)
    with http.server.ThreadingHTTPServer(address, handler) as server:
        print(f"公開フォルダー: {root}")
        print(f"http://localhost:{port}/ を開いてください (Ctrl+C で終了)")
        try:
            server.serve_forever()
        except KeyboardInterrupt:
            print("\nサーバーを終了しました。")


def main() -> None:
    """エントリーポイント."""
    args = parse_args()
    run_server(args.root.resolve(), args.port)


if __name__ == "__main__":
    main()

serve.py をダウンロード
