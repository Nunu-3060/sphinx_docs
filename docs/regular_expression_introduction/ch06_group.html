6. グループと選択

この章では、複数のパターンのどれかに一致させる「選択」と、パターンの一部をまとめる「グループ」を説明する。グループには、量指定子をまとめて掛ける働きと、一致した部分を後から取り出す働きがある。

6.1. | で選択する

| で区切ったパターンは、そのいずれかに一致する。

リスト 6.1 選択
1def demo_alternation() -> None:
2    """| はいずれかのパターンに一致する。"""
3    print(re.findall(r"cat|dog", "cat, dog, bird"))  # -> ['cat', 'dog']
4    # | は優先順位が最も低いので、^ と $ がそれぞれ片側にしか掛からない
5    print(re.search(r"^cat|dog$", "catfish"))  # -> <re.Match object; span=(0, 3), match='cat'>
6    print(re.search(r"^(?:cat|dog)$", "catfish"))  # -> None

| は正規表現の中で最も優先順位が低い。そのため、5 行目の ^cat|dog$ は「^cat または dog$」という意味になり、catfish の先頭の cat に一致してしまう。「文字列全体が cat か dog」を表すには、6 行目のように選択の範囲をグループで囲む。(?:...) については「グループで量指定子をまとめる」の節で説明する。

6.2. 選択肢の順序

選択肢は左から順に試され、最初に一致したものが採用される。最も長く一致するものが選ばれるわけではない。

リスト 6.2 選択肢の順序による違い
1def demo_alternation_order() -> None:
2    """選択肢は左から順に試され、最初に一致したものが採用される。"""
3    print(re.findall(r"Java|JavaScript", "JavaScript"))  # -> ['Java']
4    print(re.findall(r"JavaScript|Java", "JavaScript"))  # -> ['JavaScript']

3 行目では、左の Java が先に一致するので、JavaScript 全体には一致しない。ある選択肢が別の選択肢の先頭部分になっている場合は、長いほうを左に書く。

なお、grep などで使われる POSIX 方式のエンジンは、最も長く一致する選択肢を選ぶ（第 12 章）。左から順に試すのは、Python、Perl、JavaScript などで使われるバックトラック方式のエンジンの動作である。

6.3. グループで量指定子をまとめる

第 4 章で見たとおり、量指定子は直前の 1 要素にしか掛からない。(?:...) で囲むと、その中全体が 1 要素になり、まとめて量指定子を掛けられる。

リスト 6.3 グループと量指定子
1def demo_group_quantifier() -> None:
2    """グループにまとめると、量指定子を複数の文字に掛けられる。"""
3    print(re.fullmatch(r"(?:ab)+", "ababab"))  # -> <re.Match object; span=(0, 6), match='ababab'>
4    print(re.fullmatch(r"ab+", "ababab"))  # -> None

(?:ab)+ は ab の 1 回以上の繰り返しに一致する。一方、ab+ は a の後に b が 1 個以上続く形なので、ababab 全体には一致しない。

(?:...) は、まとめる働きだけを持つグループで、非キャプチャグループと呼ぶ。次の節で説明する (...) も同じようにまとめる働きを持つが、一致した部分を記録するという働きが加わる。

6.4. キャプチャグループ

(...) で囲んだ部分は、一致した文字列が記録され、後から取り出せる。これをキャプチャグループと呼ぶ。

リスト 6.4 キャプチャグループ
1def demo_capture() -> None:
2    """(...) で囲んだ部分は後から取り出せる。"""
3    m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "日付: 2026-10-19")
4    if m:
5        print(m.group(0))  # -> 2026-10-19
6        print(m.group(1), m.group(2), m.group(3))  # -> 2026 10 19
7        print(m.groups())  # -> ('2026', '10', '19')

グループには、左から順に 1 から番号が付く。m.group(1) で 1 番目のグループが一致した文字列を取り出せる。m.group(0) はパターン全体が一致した文字列であり、m.group() と同じである。m.groups() は、すべてのグループをタプルで返す。

グループが入れ子になっている場合は、開き括弧 ( が現れる順に番号が付く。たとえば ((\d{4})-(\d{2})) では、外側のグループが 1 番、\d{4} が 2 番、\d{2} が 3 番になる。

6.5. 名前付きグループ

グループが増えると、番号では何を指しているのかが分かりにくくなる。(?P<名前>...) と書くと、グループに名前を付けられる。これを名前付きグループと呼ぶ。

リスト 6.5 名前付きグループ
1def demo_named_group() -> None:
2    """(?P<name>...) でグループに名前を付ける。"""
3    m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", "日付: 2026-10-19")
4    if m:
5        print(m.group("year"))  # -> 2026
6        print(m["month"])  # -> 10
7        print(m.groupdict())  # -> {'year': '2026', 'month': '10', 'day': '19'}

名前付きグループは、m.group("year") のように名前で取り出せる。6 行目のように m["month"] と書くこともできる。m.groupdict() は、名前をキーとする辞書を返す。名前付きグループにも番号は付くので、m.group(1) でも取り出せる。

名前付きグループの書き方は、実装によって異なる。Python の re は (?P<name>...) だけを受け付け、JavaScript などで使われる (?<name>...) には対応していない（第 12 章）。

6.6. 後方参照

パターンの中で \1 や \2 と書くと、それぞれ 1 番目、2 番目のグループが一致した文字列そのものを参照できる。これを後方参照と呼ぶ。名前付きグループは (?P=名前) で参照する。

リスト 6.6 後方参照
1def demo_backreference() -> None:
2    r"""\1 や (?P=name) で、グループが一致した文字列そのものを参照する。"""
3    m = re.search(r"\b(\w+) \1\b", "this is is a pen")
4    if m:
5        print(m.group())  # -> is is
6    html = "<b>bold</b> <i>italic</b>"
7    print(re.findall(r"<(?P<tag>\w+)>.*?</(?P=tag)>", html))  # -> ['b']

3 行目の \b(\w+) \1\b は、同じ単語が空白を挟んで 2 回続く部分に一致する。\1 は「\w+ というパターン」ではなく「1 番目のグループが実際に一致した文字列（この場合は is）」を表す点が重要である。

7 行目は、開始タグと同じ名前の終了タグで閉じられた部分だけを取り出している。<i> は </b> で閉じられているので一致しない。

6.7. findall() とグループ

re.findall() の戻り値は、パターンに含まれるキャプチャグループの数によって変わる。

リスト 6.7 findall() の戻り値の違い
1def demo_findall_with_groups() -> None:
2    """findall() の戻り値はグループの数によって変わる。"""
3    text = "2026-10-19, 2027-01-01"
4    print(re.findall(r"\d{4}-\d{2}-\d{2}", text))  # -> ['2026-10-19', '2027-01-01']
5    print(re.findall(r"(\d{4})-\d{2}-\d{2}", text))  # -> ['2026', '2027']
6    print(re.findall(r"(\d{4})-(\d{2})-\d{2}", text))  # -> [('2026', '10'), ('2027', '01')]
表 6.1 findall() の戻り値

キャプチャグループの数

戻り値

0 個

パターン全体が一致した文字列のリスト

1 個

そのグループが一致した文字列のリスト

2 個以上

各グループが一致した文字列のタプルのリスト

単にまとめるためにグループを使ったつもりが、re.findall() の結果が変わってしまうことがある。取り出す必要のないグループには、非キャプチャグループ (?:...) を使う。

6.8. 繰り返したグループ

量指定子を掛けたキャプチャグループには、最後の繰り返しで一致した文字列だけが記録される。

リスト 6.8 繰り返したグループの値
1def demo_repeated_group() -> None:
2    """繰り返したグループには最後に一致した文字列だけが残る。"""
3    m = re.fullmatch(r"(\d)+", "123")
4    if m:
5        print(m.group(1))  # -> 3
6    m = re.fullmatch(r"(\d+)", "123")
7    if m:
8        print(m.group(1))  # -> 123

3 行目の (\d)+ は 1、2、3 の順に一致するが、グループに残るのは最後の 3 だけである。繰り返した全体を取り出したい場合は、6 行目のように繰り返し全体をグループで囲む。

6.9. まとめ

  • | は最も優先順位が低い。範囲を限定するにはグループで囲む。

  • 選択肢は左から順に試され、最初に一致したものが採用される。

  • (...) はキャプチャグループ、(?:...) は非キャプチャグループ、(?P<name>...) は名前付きグループである。

  • \1 や (?P=name) は、グループが一致した文字列そのものを参照する。

  • re.findall() の戻り値はキャプチャグループの数で変わる。
