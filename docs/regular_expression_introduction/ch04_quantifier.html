4. 量指定子

この章では、直前の要素を何回繰り返すかを指定する量指定子を説明する。量指定子を使うと「数字が 1 個以上」や「英字が 2 個から 4 個」のような長さの決まっていない文字列を表せる。あわせて、正規表現エンジンの基本動作であるバックトラックも説明する。

4.1. *、+、? の基本

最もよく使う量指定子は次の 3 つである。

表 4.1 基本の量指定子

量指定子

繰り返し回数

例

*

0 回以上

ab* は a、ab、abbb などに一致する

+

1 回以上

ab+ は ab、abbb などに一致し、a には一致しない

?

0 回または 1 回

ab? は a と ab だけに一致する
リスト 4.1 基本の量指定子
1def demo_basic() -> None:
2    """*, +, ? は直前の要素の繰り返し回数を指定する。"""
3    text = "a ab abbb"
4    print(re.findall(r"ab*", text))  # -> ['a', 'ab', 'abbb']
5    print(re.findall(r"ab+", text))  # -> ['ab', 'abbb']
6    print(re.findall(r"ab?", text))  # -> ['a', 'ab', 'ab']

量指定子は直前の 1 要素だけに掛かる。ab* の * は b だけに掛かり、ab 全体には掛からない。複数の文字をまとめて繰り返す方法は第 6 章で説明する。ここでいう 1 要素とは、1 文字のほか、文字クラス [...] や \d なども含む。たとえば [0-9]+ は数字 1 個以上の並びに一致する。

4.2. {m,n} で回数を指定する

回数を数値で指定するには { と } を使う。

表 4.2 回数を指定する量指定子

量指定子

繰り返し回数

{m}

ちょうど m 回

{m,}

m 回以上

{,n}

0 回以上 n 回以下

{m,n}

m 回以上 n 回以下

* は {0,} と、+ は {1,} と、? は {0,1} と同じ意味である。{m,n} のカンマの後ろに空白を入れてはいけない。{2, 3} と書くと量指定子とは解釈されず、{2, 3} という文字列そのものに一致するパターンになる。

リスト 4.2 回数の指定
1def demo_braces() -> None:
2    """{m,n} で回数を数値で指定する。"""
3    print(re.findall(r"\d{3}-\d{4}", "〒100-0001 / 1000-001"))  # -> ['100-0001']
4    print(re.findall(r"\d{2,3}", "1 12 123 12345"))  # -> ['12', '123', '123', '45']
5    print(re.findall(r"\d{2,}", "1 12 123"))  # -> ['12', '123']

3 行目の \d{3}-\d{4} は郵便番号の形に一致する。1000-001 は桁数が合わないので一致しない。

4 行目では、12345 から 123 と 45 の 2 つが取り出されている。re.findall() は、一致した部分の直後から次の一致を探すので、一度一致した文字が別の一致に重複して含まれることはない。

4.3. 貪欲マッチとバックトラック

量指定子は、既定ではできるだけ多くの文字に一致しようとする。この性質を貪欲マッチと呼ぶ。HTML のタグを取り出そうとして、次のように書くと期待どおりにならない。

リスト 4.3 貪欲マッチと最短マッチ
 1def demo_greedy() -> None:
 2    """量指定子は既定で貪欲であり、できるだけ長く一致しようとする。"""
 3    html = "<b>bold</b>"
 4    m = re.search(r"<.+>", html)
 5    if m:
 6        print(m.group())  # -> <b>bold</b>
 7    m = re.search(r"<.+?>", html)
 8    if m:
 9        print(m.group())  # -> <b>
10    print(re.findall(r"<.+?>", html))  # -> ['<b>', '</b>']
11    print(re.findall(r"<[^>]+>", html))  # -> ['<b>', '</b>']

4 行目の <.+> は、<b> ではなく <b>bold</b> 全体に一致する。これを理解するには、正規表現エンジンがどのように一致を探すかを知る必要がある。

<.+> は、図 4.1 のような状態の遷移として考えられる。

状態 2 では、「任意の 1 文字を読んで状態 2 に留まる」か「> を読んで状態 3 に進む」かの 2 通りの選択肢がある。貪欲な量指定子は、まず留まるほう、つまり繰り返しを続けるほうを選ぶ。その結果、文字列の末尾まで読み進めてしまい、> を読む文字が残っていないので失敗する。

失敗すると、エンジンは直前の選択に戻り、別の選択肢を試す。これをバックトラックと呼ぶ。<.+> を <b>bold</b> に適用したときの手順は次のとおりである。

表 4.3 <.+> の照合手順

手順

処理

結果

1

< が先頭の < に一致する

成功

2

.+ が残りの b>bold</b> をすべて読む

成功（10 文字）

3

> を照合しようとするが、文字が残っていない

失敗

4

バックトラックして .+ が 1 文字を手放し、b>bold</b までとする

成功（9 文字）

5

> が末尾の > に一致する

全体が一致

途中にある > は . にも一致するので、手順 2 で読み飛ばされる。結果として、最後の > までが一致する。

4.4. 最短マッチ

量指定子の後ろに ? を付けると、できるだけ少ない文字に一致しようとする。これを最短マッチ（非貪欲マッチ）と呼ぶ。

上のリストの 7 行目の <.+?> では、.+? はまず最小の 1 文字 b だけを読み、次に > を試す。> が一致するので、<b> で一致が確定する。> が一致しなかった場合は、.+? が 1 文字ずつ読む範囲を広げて再び試す。

ただし、この例では 11 行目の <[^>]+> のほうが、より良い書き方である。「> 以外の文字の繰り返し」と書けば、そもそも > を読み飛ばすことがないので、貪欲か最短かを気にする必要がない。バックトラックも起きないため、処理も速い。最短マッチは手軽だが、否定文字クラスで書けるときはそちらを優先するとよい。

4.5. 強欲量指定子とアトミックグループ

Python 3.11 以降では、バックトラックを禁止する方法が 2 つ使える。量指定子の後ろに + を付けた強欲量指定子と、(?>...) で囲むアトミックグループである（括弧によるグループについては第 6 章で説明する）。どちらも、一度一致した文字を後から手放さない。

リスト 4.4 強欲量指定子とアトミックグループ
1def demo_possessive() -> None:
2    """強欲量指定子とアトミックグループはバックトラックしない (Python 3.11 以降)。"""
3    print(re.fullmatch(r"\d+0", "1230"))  # -> <re.Match object; span=(0, 4), match='1230'>
4    print(re.fullmatch(r"\d++0", "1230"))  # -> None
5    print(re.fullmatch(r"(?>\d+)0", "1230"))  # -> None
6    print(re.fullmatch(r"[a-z]++\d", "abc1"))  # -> <re.Match object; span=(0, 4), match='abc1'>

3 行目の \d+0 では、\d+ が 1230 をすべて読んだ後に 0 が一致せず、バックトラックして \d+ が 123 までとなり、最後の 0 が一致する。4 行目の \d++0 では、\d++ が 1230 を読んだ後に手放さないので、0 を照合する文字が残らず失敗する。5 行目のアトミックグループも同じ動作になる。

6 行目のように、手放す必要がない場面では、強欲量指定子を使っても結果は変わらない。[a-z] と \d は同じ文字に一致しないので、[a-z]++ が読みすぎることはない。このような場面で強欲量指定子を使うと、失敗が確定したときに無駄なバックトラックをしないので、速く失敗できる。この効果は第 11 章で詳しく見る。

4.6. 量指定子の種類のまとめ

表 4.4 量指定子の 3 つの種類

種類

書き方

動作

貪欲

* + ? {m,n}

できるだけ多く一致し、失敗したら 1 文字ずつ手放す

最短

*? +? ?? {m,n}?

できるだけ少なく一致し、失敗したら 1 文字ずつ広げる

強欲

*+ ++ ?+ {m,n}+

できるだけ多く一致し、手放さない（Python 3.11 以降）

4.7. まとめ

  • 量指定子は直前の 1 要素の繰り返し回数を指定する。

  • 量指定子は既定で貪欲であり、失敗するとバックトラックして別の可能性を試す。

  • ? を付けると最短マッチになる。ただし、否定文字クラスで書けるならそのほうが明確で速い。

  • 強欲量指定子とアトミックグループはバックトラックしない。
