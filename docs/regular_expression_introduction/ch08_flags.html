8. フラグ

フラグは、パターン全体の解釈の仕方を変える設定である。第 3 章と第 5 章で re.ASCII と re.MULTILINE を使ったが、この章ではフラグ全体を整理して説明する。

8.1. フラグの一覧

re モジュールの主なフラグを次に示す。各フラグには長い名前と 1 文字の短い名前があり、どちらを使ってもよい。

表 8.1 主なフラグ

名前

効果

re.I

re.MULTILINE

^ と $ が各行の先頭と末尾にも一致する

re.DOTALL

re.S

(?s)

. が改行にも一致する

re.VERBOSE

re.ASCII

\d、\w、\s、\b などが ASCII 文字だけを対象にする

このほか、bytes のパターンだけで使える re.LOCALE や、パターンの解析結果を表示する re.DEBUG がある。また、Python 3.11 では「フラグなし」を表す re.NOFLAG が追加された。

8.2. フラグの指定方法

フラグは、re の各関数の flags 引数に指定する。flags は必ずキーワード引数として渡すとよい。re.sub() や re.split() では、位置引数で渡すと別の引数として解釈されてしまうからである。

リスト 8.1 フラグを位置引数で渡す誤り
1# 誤り: 4 番目の位置引数は count (置換回数) なので、re.IGNORECASE (値は 2) が count になる
2re.sub(r"python", "Python", text, re.IGNORECASE)
3
4# 正しい書き方
5re.sub(r"python", "Python", text, flags=re.IGNORECASE)

Python 3.13 以降では、re.sub() などの count、maxsplit、flags を位置引数で渡すと DeprecationWarning が出る。

8.3. 大文字と小文字を区別しない

リスト 8.2 re.IGNORECASE
1def demo_ignorecase() -> None:
2    """re.IGNORECASE (re.I) は大文字と小文字を区別しない。"""
3    text = "Python PYTHON python"
4    print(re.findall(r"python", text))  # -> ['python']
5    print(re.findall(r"python", text, flags=re.IGNORECASE))  # -> ['Python', 'PYTHON', 'python']

re.IGNORECASE は、文字クラスの範囲にも効く。たとえば [a-z] は大文字にも一致するようになる。ただし、Unicode の大文字と小文字の対応に従うため、[a-z] が ſ（U+017F、ロングエス）や K（U+212A、ケルビン記号）にも一致するといった、意外な一致が起こることがある。入力値の検証で厳密に ASCII 文字だけを受け付けたい場合は、re.ASCII を併せて指定する。

8.4. . を改行にも一致させる

リスト 8.3 re.DOTALL
1def demo_dotall() -> None:
2    """re.DOTALL (re.S) を指定すると . が改行にも一致する。"""
3    text = "<p>line1\nline2</p>"
4    print(re.search(r"<p>.*</p>", text))  # -> None
5    m = re.search(r"<p>.*</p>", text, flags=re.DOTALL)
6    if m:
7        print(repr(m.group()))  # -> '<p>line1\nline2</p>'

既定では . は改行に一致しないので、4 行目のように改行をまたぐ範囲には一致しない。re.DOTALL を指定すると、. が改行を含む任意の 1 文字に一致する。

re.MULTILINE と re.DOTALL は名前が似ているが、効果はまったく異なる。re.MULTILINE は ^ と $ の動作を、re.DOTALL は . の動作を変える。

8.5. フラグを組み合わせる

複数のフラグは | でつなげて指定する。

リスト 8.4 フラグの組み合わせ
1def demo_combine() -> None:
2    """複数のフラグは | で組み合わせる。"""
3    text = "Error: disk full\nwarning: low memory\nERROR: timeout"
4    print(re.findall(r"^error: (.*)$", text, flags=re.IGNORECASE | re.MULTILINE))  # -> ['disk full', 'timeout']

re.IGNORECASE で Error と ERROR の両方に一致させ、re.MULTILINE で各行の先頭に ^ を一致させている。

8.6. インラインフラグ

フラグは、(?i) のようにパターンの中に書くこともできる。これをインラインフラグと呼ぶ。

リスト 8.5 インラインフラグ
1def demo_inline_flags() -> None:
2    """パターンの中にフラグを書くこともできる。"""
3    print(re.findall(r"(?i)python", "Python PYTHON"))  # -> ['Python', 'PYTHON']
4    print(re.findall(r"(?i:py)thon", "Python PYthon PYTHON"))  # -> ['Python', 'PYthon']
5    try:
6        re.compile(r"py(?i)thon")
7    except re.error as e:
8        print(e)  # -> global flags not at the start of the expression at position 2

3 行目のように、パターン全体に効くインラインフラグは、パターンの先頭に書かなければならない。Python 3.11 以降では、6 行目のように先頭以外に書くとエラーになる。

4 行目の (?i:py) のように (?フラグ:...) と書くと、そのグループの中だけにフラグが効く。この例では py の部分だけ大文字と小文字を区別しない。thon の部分は区別されるので、PYTHON には一致しない。

インラインフラグは、設定ファイルなどでパターンだけを受け渡す場合に便利である。

8.7. VERBOSE で読みやすく書く

re.VERBOSE を指定すると、パターン中の空白と改行が無視され、# から行末までがコメントになる。長いパターンを分割し、各部分に説明を付けられる。

リスト 8.6 re.VERBOSE
 1def demo_verbose() -> None:
 2    """re.VERBOSE (re.X) を指定すると空白とコメントを書ける。"""
 3    phone = re.compile(
 4        r"""
 5        (?P<area>0\d{1,4})   # 市外局番
 6        -
 7        (?P<local>\d{1,4})   # 市内局番
 8        -
 9        (?P<number>\d{4})    # 加入者番号
10        """,
11        flags=re.VERBOSE,
12    )
13    m = phone.fullmatch("03-1234-5678")
14    if m:
15        print(m.groupdict())  # -> {'area': '03', 'local': '1234', 'number': '5678'}

re.VERBOSE を指定したパターンで空白や # そのものに一致させたい場合は、[ ] や [#] のように文字クラスの中に書くか、\# のようにバックスラッシュでエスケープする。文字クラスの中の空白と # は無視されない。

複雑なパターンは、第 10 章の例のように、re.VERBOSE と名前付きグループを組み合わせて書くと保守しやすくなる。

8.8. ASCII 文字に限定する

リスト 8.7 re.ASCII
1def demo_ascii() -> None:
2    r"""re.ASCII (re.A) を指定すると \d, \w, \s, \b が ASCII 文字だけを対象にする。"""
3    text = "abc 東京 １２３"
4    print(re.findall(r"\w+", text))  # -> ['abc', '東京', '１２３']
5    print(re.findall(r"\w+", text, flags=re.ASCII))  # -> ['abc']

第 3 章で説明したとおり、str のパターンでは \w などが Unicode 文字にも一致する。re.ASCII を指定すると、ASCII 文字だけを対象にする。入力値の検証などで半角文字だけを受け付けたい場合に使う。

8.9. まとめ

  • フラグは flags= のキーワード引数で指定し、複数のフラグは | で組み合わせる。

  • re.MULTILINE は ^ と $ を、re.DOTALL は . の動作を変える。

  • パターン全体に効くインラインフラグは先頭に書く。(?i:...) のように一部だけに効かせることもできる。

  • 長いパターンは re.VERBOSE で分割し、コメントを付ける。
