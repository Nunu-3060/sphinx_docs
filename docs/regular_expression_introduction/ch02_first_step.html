2. 最初の一歩

この章では、Python で正規表現を使う最小限の方法と、パターンを書くうえでの 2 つの基本である「メタ文字のエスケープ」と「raw 文字列」を説明する。

2.1. re.search() でパターンを探す

Python で正規表現を使うには、標準ライブラリの re モジュールをインポートする。最もよく使う関数は re.search() で、第 1 引数にパターン、第 2 引数に対象の文字列を渡す。

リスト 2.1 re.search() の基本
1def demo_search() -> None:
2    """re.search() で文字列中からパターンを探す。"""
3    text = "I have a cat and a dog."
4    m = re.search(r"cat", text)
5    print(m)  # -> <re.Match object; span=(9, 12), match='cat'>
6    if m:
7        print(m.group())  # -> cat
8        print(m.start(), m.end())  # -> 9 12
9    print(re.search(r"bird", text))  # -> None

re.search() は、文字列を先頭から順に調べ、パターンに一致する部分を最初に見つけた時点で Match オブジェクトを返す。一致する部分がなければ None を返す。そのため、戻り値は 6 行目のように if で判定してから使うのが基本の形である。

Match オブジェクトの group() メソッドは一致した文字列を、start() と end() は一致した範囲の開始位置と終了位置を返す。終了位置は Python のスライスと同じく「一致した最後の文字の次の位置」を指す。そのため、text[9:12] が一致した文字列 'cat' になる。

re.search() 以外の関数は第 9 章で詳しく説明する。第 8 章までは、主に re.search() と、一致した部分をすべてリストで返す re.findall() を使う。文字列全体がパターンに一致するかを調べる re.fullmatch() や、置換を行う re.sub() なども使うが、それぞれ初めて使う箇所で簡単に説明する。

2.2. リテラル文字

英字や数字など、特別な意味を持たない文字は、パターンの中でその文字自身に一致する。このような文字をリテラルと呼ぶ。上の例のパターン cat は、c、a、t の 3 文字が続く部分に一致する。

リスト 2.2 大文字と小文字の区別と部分一致
1def demo_case_sensitive() -> None:
2    """既定では大文字と小文字を区別する。"""
3    print(re.search(r"cat", "Cat"))  # -> None
4    print(re.search(r"cat", "concatenate"))  # -> <re.Match object; span=(3, 6), match='cat'>

既定では大文字と小文字を区別するので、cat は Cat に一致しない（区別しない方法は第 8 章で説明する）。また、re.search() は文字列の一部が一致すればよいので、concatenate の中の cat にも一致する。単語として独立した cat だけに一致させる方法は第 5 章で説明する。

メタ文字そのものに一致させたいときは、直前に \ を置いて特別な意味を打ち消す。これをエスケープと呼ぶ。

リスト 2.3 メタ文字のエスケープ
1def demo_metachar() -> None:
2    """メタ文字はエスケープしないとリテラルとして扱われない。"""
3    text = "1+1=2"
4    print(re.search(r"1+1", text))  # -> None
5    print(re.search(r"1\+1", text))  # -> <re.Match object; span=(0, 3), match='1+1'>
6    print(re.escape("1+1=2?"))  # -> 1\+1=2\?

4 行目のパターン 1+1 では + が「直前の文字の 1 回以上の繰り返し」という意味になるので、「1 が 1 個以上続いた後に 1」、つまり 1 が 2 個以上続く部分にしか一致しない。5 行目のように \+ と書くと、+ という文字そのものに一致する。

re.escape() は、文字列中のメタ文字をすべてエスケープしたパターンを返す。利用者が入力した文字列をそのまま検索したい場合などに使う（第 9 章で再び取り上げる）。

2.4. raw 文字列でパターンを書く

\ は Python の文字列リテラルでも特別な意味を持つ。たとえば "\n" は改行文字 1 文字になる。そのため、パターンを通常の文字列で書くと、\ が Python と re の両方で解釈され、意図と異なるパターンになることがある。

先頭に r を付けた raw 文字列では、Python は \ を特別扱いしない。r"\n" は \ と n の 2 文字のままで re に渡り、re が改行と解釈する。

リスト 2.4 通常の文字列と raw 文字列の違い
1def demo_raw_string() -> None:
2    """パターンは raw 文字列で書く。"""
3    print(len("\n"), len(r"\n"))  # -> 1 2
4    # 通常の文字列では "\b" がバックスペース文字 (U+0008) になってしまう
5    print(re.search("\bcat\b", "a cat"))  # -> None
6    print(re.search(r"\bcat\b", "a cat"))  # -> <re.Match object; span=(2, 5), match='cat'>

5 行目の \b は、re では単語の境界（第 5 章）を表すが、Python の通常の文字列ではバックスペース文字になってしまう。そのため 5 行目の検索は失敗し、raw 文字列を使った 6 行目だけが成功する。

バックスラッシュそのものに一致させる場合は、さらに差がはっきりする。

表 2.2 バックスラッシュ 1 文字に一致させるパターンの書き方

書き方

説明

r"\\"

raw 文字列。re には \\ が渡り、\ 1 文字に一致する

"\\\\"

通常の文字列。Python が \\ を \ に変換するので、4 個書く必要がある

なお、Python 3.12 以降では、"\d" のように Python の文字列として無効なエスケープを通常の文字列に書くと SyntaxWarning が出る。本書では、パターンは常に raw 文字列で書く。

2.5. まとめ

  • re.search() は最初に一致した部分を Match オブジェクトで返し、一致しなければ None を返す。

  • メタ文字そのものに一致させるには \ でエスケープする。re.escape() を使うと文字列全体をエスケープできる。

  • パターンは raw 文字列 r"..." で書く。
