9. Python の re モジュール

第 8 章までは、主に re.search() と re.findall() を使って構文を説明してきた（re.fullmatch() や re.sub() なども一部で使った）。この章では、re モジュールが提供する関数と、その使い分けを整理する。

9.1. 関数の一覧

re モジュールの主な関数を次に示す。

表 9.1 re モジュールの主な関数

関数

動作

re.search(pattern, string)

文字列中で最初に一致した部分を Match オブジェクトで返す。一致しなければ None

re.match(pattern, string)

文字列の先頭から一致する場合だけ Match オブジェクトを返す

re.fullmatch(pattern, string)

文字列全体が一致する場合だけ Match オブジェクトを返す

re.findall(pattern, string)

一致した部分をすべてリストで返す

re.finditer(pattern, string)

一致した部分ごとの Match オブジェクトを順に返すイテレーターを返す

re.sub(pattern, repl, string)

一致した部分を repl で置換した文字列を返す

re.subn(pattern, repl, string)

re.sub() の結果と置換した回数をタプルで返す

re.split(pattern, string)

一致した部分で文字列を分割したリストを返す

re.compile(pattern)

パターンをパターンオブジェクトに変換する

re.escape(string)

文字列中のメタ文字をエスケープする

目的に応じた関数の選び方を図 9.1 に示す。

9.2. search()、match()、fullmatch()

この 3 つの関数は、いずれも一致すれば Match オブジェクトを、一致しなければ None を返すが、一致を調べる範囲が異なる。

リスト 9.1 search()、match()、fullmatch() の違い
1def demo_search_match_fullmatch() -> None:
2    """search(), match(), fullmatch() は一致を判定する位置が異なる。"""
3    print(re.search(r"\d+", "abc123"))  # -> <re.Match object; span=(3, 6), match='123'>
4    print(re.match(r"\d+", "abc123"))  # -> None
5    print(re.match(r"\d+", "123abc"))  # -> <re.Match object; span=(0, 3), match='123'>
6    print(re.fullmatch(r"\d+", "123abc"))  # -> None
7    print(re.fullmatch(r"\d+", "123"))  # -> <re.Match object; span=(0, 3), match='123'>

re.search() は文字列のどこかで、re.match() は文字列の先頭から、re.fullmatch() は文字列全体で一致を調べる。re.match() は、パターン全体を \A(?:...) で囲んだ re.search() と同じ動作である。

re.match() は、名前から「全体が一致するか」を調べる関数と誤解されやすい。実際には先頭部分が一致すれば成功するので、5 行目のように 123abc にも一致する。入力値の検証には re.fullmatch() を使う。

9.3. findall() と finditer()

リスト 9.2 findall() と finditer()
1def demo_findall_finditer() -> None:
2    """findall() は文字列のリストを、finditer() は Match のイテレーターを返す。"""
3    text = "x=10, y=200"
4    print(re.findall(r"\d+", text))  # -> ['10', '200']
5    for m in re.finditer(r"\d+", text):
6        print(m.group(), m.span())

re.findall() は、一致した文字列だけをリストで返す。キャプチャグループを含むパターンでは戻り値の形が変わる点は、第 6 章で説明した。

re.finditer() は、一致ごとの Match オブジェクトを順に返す。一致した位置や複数のグループを使いたい場合は、re.finditer() のほうが扱いやすい。また、結果を一度にリストに格納しないので、大きなテキストを処理する場合にも向いている。

9.4. sub() で置換する

re.sub() は、一致した部分を置換文字列で置き換える。置換文字列の中では、次の記法でグループを参照できる。

表 9.2 置換文字列で使える記法

記法

意味

\1、\2、…

番号で指定したグループが一致した文字列

\g<1>

\1 と同じ。直後に数字が続く場合に使う（\g<1>0 と \10 は意味が異なる）

\g<name>

名前付きグループが一致した文字列

\g<0>

パターン全体が一致した文字列
リスト 9.3 sub() と subn()
1def demo_sub() -> None:
2    """sub() は一致した部分を置換する。"""
3    text = "2026-10-19"
4    print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3/\2/\1", text))  # -> 19/10/2026
5    print(re.sub(r"(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})", r"\g<y>年\g<m>月\g<d>日", text))  # -> 2026年10月19日
6    print(re.sub(r"\d", "#", "a1b22c333", count=3))  # -> a#b##c333
7    print(re.subn(r"\d", "#", "a1b22c333"))  # -> ('a#b##c###', 6)

置換文字列もパターンと同様に raw 文字列で書く。6 行目のように count を指定すると、置換する回数の上限を決められる。7 行目の re.subn() は、置換後の文字列と置換した回数をタプルで返す。

9.5. 関数で置換する

re.sub() の第 2 引数には、置換文字列の代わりに関数を渡せる。関数は一致ごとに Match オブジェクトを受け取り、置換後の文字列を返す。

リスト 9.4 関数による置換
1def demo_sub_with_function() -> None:
2    """置換文字列の代わりに関数を渡すと、一致ごとに置換結果を計算できる。"""
3
4    def double(m: re.Match[str]) -> str:
5        return str(int(m.group()) * 2)
6
7    print(re.sub(r"\d+", double, "a=3, b=50"))  # -> a=6, b=100

この例では、一致した数字を 2 倍にしている。数値の計算や辞書を使った変換など、置換文字列だけでは書けない処理ができる。

9.6. split() で分割する

リスト 9.5 split()
1def demo_split() -> None:
2    """split() はパターンに一致した部分で文字列を分割する。"""
3    print(re.split(r"\s*[,;]\s*", "a, b;c ,d"))  # -> ['a', 'b', 'c', 'd']
4    print(re.split(r"\s*[,;]\s*", "a, b;c ,d", maxsplit=1))  # -> ['a', 'b;c ,d']
5    print(re.split(r"([,;])", "a,b;c"))  # -> ['a', ',', 'b', ';', 'c']

str.split() に指定できる区切りは 1 つの固定の文字列だけだが、re.split() を使うと、3 行目のように「前後の空白を含むカンマまたはセミコロン」といった柔軟な区切りで分割できる。4 行目の maxsplit は、分割する回数の上限である。

5 行目のように、パターンにキャプチャグループを含めると、区切りに一致した文字列も結果に含まれる。

9.7. compile() でパターンを再利用する

re.compile() は、パターンを解析した結果をパターンオブジェクトとして返す。パターンオブジェクトは、re の関数と同じ名前のメソッドを持つ。

リスト 9.6 compile()
1def demo_compile() -> None:
2    """compile() でパターンオブジェクトを作り、繰り返し使う。"""
3    date_pattern = re.compile(r"(\d{4})-(\d{2})-(\d{2})")
4    print(date_pattern.pattern)  # -> (\d{4})-(\d{2})-(\d{2})
5    print(date_pattern.groups)  # -> 3
6    for line in ("start: 2026-10-19", "no date", "end: 2026-12-31"):
7        m = date_pattern.search(line)
8        print(m.group() if m else "(なし)")

re.search() などの関数も、内部でパターンを解析してキャッシュしているので、同じパターンを繰り返し使っても毎回解析し直すわけではない。そのため、re.compile() の主な利点は性能よりも読みやすさにある。よく使うパターンをモジュールの定数として re.compile() しておくと、名前でパターンの意味を表せ、フラグもパターンと一緒に管理できる。

9.8. Match オブジェクト

Match オブジェクトは、一致した文字列と位置、グループの情報を持つ。

表 9.3 Match オブジェクトの主なメソッドと属性

メソッド・属性

返す値

group()、group(0)、m[0]

パターン全体が一致した文字列

group(n)、group("name")、m[n]

指定したグループが一致した文字列。一致しなかったグループは None

groups(default=None)

すべてのグループのタプル。一致しなかったグループは default の値

groupdict(default=None)

名前付きグループの辞書

start()、end()、span()

一致した範囲の開始位置、終了位置、その 2 つのタプル。引数にグループを指定することもできる

string、re

検索対象の文字列と、使われたパターンオブジェクト
リスト 9.7 Match オブジェクト
1def demo_match_object() -> None:
2    """Match オブジェクトから一致した情報を取り出す。"""
3    m = re.search(r"(?P<key>\w+)=(?P<value>\w+)?", "name=")
4    if m:
5        print(m.group(), m.start(), m.end(), m.span())  # -> name= 0 5 (0, 5)
6        print(m.groups())  # -> ('name', None)
7        print(m.groups(default=""))  # -> ('name', '')
8        print(m.groupdict())  # -> {'key': 'name', 'value': None}
9        print(m[0], m["key"])  # -> name= name

3 行目のパターンでは、value グループに ? が付いているので、グループが一致しなくても全体は一致する。一致しなかったグループの値は None になる。7 行目のように default を指定すると、None の代わりの値を決められる。

9.9. escape() で文字列をエスケープする

利用者の入力などをパターンに埋め込む場合は、必ず re.escape() でエスケープする。

リスト 9.8 escape()
 1def demo_escape() -> None:
 2    """利用者が入力した文字列をパターンに埋め込むときは escape() を使う。"""
 3    keyword = "*重要*"
 4    text = "これは *重要* な点だ"
 5    print(re.findall(re.escape(keyword), text))  # -> ['*重要*']
 6    try:
 7        re.findall(keyword, text)
 8    except re.error as e:
 9        print(e)  # -> nothing to repeat at position 0
10    # escape() しないと、エラーにならなくても意図しないパターンになることがある
11    print(re.findall("(株)", "(株)山田商店"))  # -> ['株']

7 行目のように、エスケープしない *重要* は不正なパターンになり、エラーが発生する。11 行目のように、エラーにならなくても、括弧がグループとして解釈されるなどして意図と異なる結果になることもある。こちらはエラーが出ないので、気付きにくい。

9.10. エラー処理

不正なパターンを渡すと、re.error 例外が発生する。Python 3.13 以降では re.PatternError という名前も使え、re.error はその別名になっている。

リスト 9.9 re.error
1def demo_error() -> None:
2    """不正なパターンは re.error を送出する。"""
3    try:
4        re.compile(r"(abc")
5    except re.error as e:
6        print(e.msg, e.pos)  # -> missing ), unterminated subpattern 0

例外オブジェクトの msg 属性はエラーの内容を、pos 属性はパターン中のエラーの位置を表す。利用者が入力したパターンを re.compile() する場合は、この例外を捕捉して分かりやすいメッセージを表示するとよい。

9.11. まとめ

  • 文字列のどこかを探すには re.search() を、文字列全体を検証するには re.fullmatch() を使う。re.match() は先頭部分だけを調べる。

  • すべての一致を取り出すには re.findall() か re.finditer() を使う。

  • re.sub() の置換文字列では \1 や \g<name> でグループを参照できる。関数を渡すこともできる。

  • よく使うパターンは re.compile() して名前を付けておく。

  • 外部から受け取った文字列をパターンに埋め込むときは re.escape() を使う。
