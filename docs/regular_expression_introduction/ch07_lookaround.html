7. 先読みと後読み

この章では、「直後に 円 が続く数字」や「直前に $ がある数字」のように、前後の文字列を条件にしつつ、その文字列自体は一致に含めない書き方を説明する。

7.1. 先読みと後読みの 4 種類

先読みと後読みは、第 5 章のアンカーと同じくゼロ幅アサーションであり、位置に一致して文字を消費しない。次の 4 種類がある。

表 7.1 先読みと後読み

書き方

名前

一致する位置

(?=...)

肯定先読み

直後に ... が続く位置

(?!...)

否定先読み

直後に ... が続かない位置

(?<=...)

肯定後読み

直前に ... がある位置

(?<!...)

否定後読み

直前に ... がない位置

「文字を消費しない」ことを、次の例で確かめる。

リスト 7.1 先読みは文字を消費しない
1def demo_zero_width() -> None:
2    """先読みと後読みは文字を消費しない。"""
3    m = re.search(r"\d+(?=円)", "合計 500円")
4    if m:
5        print(m.group(), m.span())  # -> 500 (3, 6)
6    m = re.search(r"\d+円", "合計 500円")
7    if m:
8        print(m.group(), m.span())  # -> 500円 (3, 7)

3 行目の \d+(?=円) は、円 が続くことを条件にするが、一致するのは 500 だけであり、範囲は (3, 6) になる。6 行目の \d+円 では、円 も一致に含まれる。

7.2. 先読み

先読みは、直後に続く文字列を条件にする。

リスト 7.2 肯定先読みと否定先読み
1def demo_lookahead() -> None:
2    """(?=...) と (?!...) は直後に続く文字列を条件にする。"""
3    text = "りんご 120円、みかん 80個、ぶどう 300円"
4    print(re.findall(r"\d+(?=円)", text))  # -> ['120', '300']
5    print(re.findall(r"\d+(?![\d円])", text))  # -> ['80']

4 行目の \d+(?=円) は、円 が続く数字だけを取り出す。

5 行目の否定先読みは、少し注意が必要である。単に \d+(?!円) と書くと、120円 に対しても一致してしまう。\d+ が 120 に一致した時点では直後が 円 なので失敗するが、バックトラックして 12 までにすると直後が 0 になり、条件を満たすからである。そこで、(?![\d円]) として「直後が数字でも 円 でもない」ことを条件にし、数字の途中で区切られないようにしている。否定の条件を書くときは、このようにバックトラックした場合の動作も考える必要がある。

7.3. 後読み

後読みは、直前にある文字列を条件にする。

リスト 7.3 肯定後読みと否定後読み
1def demo_lookbehind() -> None:
2    """(?<=...) と (?<!...) は直前にある文字列を条件にする。"""
3    text = "price: $30, qty: 5"
4    print(re.findall(r"(?<=\$)\d+", text))  # -> ['30']
5    print(re.findall(r"(?<![\d$])\d+", text))  # -> ['5']

4 行目の (?<=\$)\d+ は、$ の直後にある数字だけを取り出す。5 行目の (?<![\d$])\d+ は、直前が数字でも $ でもない数字、つまり $ が付いていない数字だけを取り出す。ここでも、否定先読みと同じ理由で、条件に \d を含めている。

7.4. 複数の条件をすべて満たす

先読みは文字を消費しないので、同じ位置に複数並べられる。これを利用すると、「すべての条件を満たす」を表せる。

リスト 7.4 パスワードの条件の検査
1def demo_password() -> None:
2    """複数の先読みを並べると「すべての条件を満たす」を表せる。"""
3    pattern = re.compile(r"(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}")
4    for password in ("password", "Passw0rd", "PASSW0RD", "Pa55"):
5        print(password, bool(pattern.fullmatch(password)))

5 行目で fullmatch() を使っているので、3 行目のパターンは文字列の先頭から照合される。まず次の 3 つの先読みを順に確かめた後、.{8,} で 8 文字以上であることを確かめる。

  • (?=.*[a-z]): どこかに小文字がある

  • (?=.*[A-Z]): どこかに大文字がある

  • (?=.*\d): どこかに数字がある

各先読みは文字を消費しないので、どれも文字列の先頭から調べられる。ただし、条件が増えるとパターンは読みにくくなる。実務では、条件ごとに re.search() を呼び出すか、文字列メソッドで判定するほうが分かりやすいことも多い。

7.5. 位置に文字を挿入する

先読みと後読みだけでパターンを作ると、文字を含まない「位置」に一致させられる。これを re.sub() と組み合わせると、特定の位置に文字を挿入できる。

リスト 7.5 3 桁ごとのカンマの挿入
1def demo_thousands_separator() -> None:
2    """先読みと後読みで「位置」を指定して 3 桁ごとにカンマを挿入する。"""
3    pattern = r"(?<=\d)(?=(?:\d{3})+(?!\d))"
4    print(re.sub(pattern, ",", "1234567"))  # -> 1,234,567
5    print(re.sub(pattern, ",", "残高 1000000 円"))  # -> 残高 1,000,000 円

3 行目のパターンは、次の 2 つの条件を満たす位置に一致する。

  • (?<=\d): 直前が数字である

  • (?=(?:\d{3})+(?!\d)): 直後に「3 桁の数字の 1 回以上の繰り返し」があり、その後に数字が続かない

つまり、「右側に残る桁数が 3 の倍数になる、数字と数字の間」に一致し、そこに , が挿入される。

これは先読みと後読みの働きを理解するための例である。数値を桁区切りで表示するだけなら、Python では f"{1234567:,}" と書くほうが簡単で確実である。

7.6. 後読みの制約

Python の re では、後読みの中に長さの決まらないパターンを書けない。

リスト 7.6 後読みは固定長に限られる
1def demo_fixed_width() -> None:
2    """Python の後読みには固定長のパターンしか書けない。"""
3    try:
4        re.compile(r"(?<=a|bc)x")
5    except re.error as e:
6        print(e)  # -> look-behind requires fixed-width pattern
7    print(re.findall(r"(?:(?<=a)|(?<=bc))x", "ax bcx dx"))  # -> ['x', 'x']

4 行目の (?<=a|bc) は、選択肢の長さが 1 文字と 2 文字で異なるのでエラーになる。\d+ や .* のような量指定子も、後読みの中には書けない。ただし、(?<=ab|cd) のように、すべての選択肢が同じ長さであれば書ける。

長さの異なる選択肢を使いたい場合は、7 行目のように後読み自体を選択肢に分ける。サードパーティの regex モジュール（第 12 章）は、長さの決まらない後読みにも対応している。

7.7. まとめ

  • 先読み (?=...) (?!...) は直後の文字列を、後読み (?<=...) (?<!...) は直前の文字列を条件にする。

  • 先読みと後読みは文字を消費しないので、一致した文字列には含まれない。

  • 否定の条件は、バックトラックで数字などの途中に一致しないよう注意して書く。

  • Python の後読みには固定長のパターンしか書けない。
