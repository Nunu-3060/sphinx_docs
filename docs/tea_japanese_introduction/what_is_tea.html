2. 日本茶とは

2.1. 茶の木から生まれるお茶

緑茶、烏龍茶、紅茶は、どれもチャノキ（茶の木）というツバキ科の植物の葉から作られます。これらの違いは、植物の種類ではなく、製造方法の違いです。

摘み取った茶葉の中では、酸化酵素の働きによって成分が酸化し、葉の色が緑から褐色に変わっていきます。この変化を、お茶の世界では「発酵」と呼びます。微生物による発酵とは異なる現象ですが、慣用的にこう呼ばれています。どの程度発酵させるかによって、お茶は次のように分類されます。

緑茶

十分に発酵させてから乾燥させます。

日本茶とは、一般に日本で作られるお茶のことで、そのほとんどが緑茶です。国内では紅茶（和紅茶）も作られていますが、本書では緑茶を中心に扱います。

2.2. 日本茶の特徴

緑茶を作るときに茶葉を加熱する方法には、蒸気で蒸す方法と、釜で炒る方法があります。中国の緑茶の多くは釜で炒って作られますが、日本の緑茶の大部分は蒸して作られます。

蒸して作った緑茶は、鮮やかな緑色と、青々とした爽やかな香りが特徴です。また、うま味を大切にすることも日本茶の特徴で、玉露や抹茶のように、うま味を引き出すために特別な方法で栽培されるお茶もあります。

2.3. 日本茶ができるまで

ここでは、日本茶の代表である煎茶ができるまでの流れを説明します。

  1. 摘採：茶葉を摘み取ります。現在は、多くの茶園で機械を使って摘み取ります。

  2. 蒸熱：摘んだ茶葉をすぐに蒸気で蒸し、酸化酵素の働きを止めます。

  3. 揉み：熱風を当てながら茶葉を揉み、水分を均一に減らしながら形を整えます。粗揉、揉捻、中揉、精揉という複数の工程に分かれており、最後の精揉で、煎茶らしい細くまっすぐな針のような形になります。

  4. 乾燥：茶葉を乾燥させ、水分を 5 % 程度まで減らします。

ここまでの工程で作られたお茶を荒茶と呼びます。荒茶は、主に茶農家や産地の工場で作られます。

2.4. 荒茶と仕上げ茶

荒茶には、大きさのそろわない葉や、茎、粉などが混じっています。また、保存性を高めるためには、さらに乾燥させる必要があります。そこで、茶問屋などが荒茶を次のように加工し、店頭に並ぶお茶に仕上げます。この工程を仕上げ加工と呼びます。

  • 選別：ふるいや機械を使って、葉、茎、粉などに分けます。

  • 火入れ：茶葉を加熱して乾燥させ、香りを引き出します。

  • 合組：読みは「ごうぐみ」です。複数の荒茶をブレンドし、味や香りを整えます。

仕上げ加工で分けられた茎や粉なども、茎茶や粉茶として商品になります。詳しくは「日本茶の種類」で説明します。
