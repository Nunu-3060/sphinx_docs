便利なスクリプト

本付録では、日本茶を淹れるときに役立つ 2 つの Python スクリプトを紹介します。どちらも Python の標準機能だけで動くため、追加のインストールは不要です。

動かすための準備

スクリプトを動かすには、Python 3.10 以上が必要です。Python は、Python の公式サイトからダウンロードしてインストールできます。

スクリプトは、次の手順で実行します。

  1. 本ページのリンクからスクリプトをダウンロードします。

  2. Windows では「コマンドプロンプト」、macOS では「ターミナル」を開きます。

  3. cd コマンドで、スクリプトを保存したフォルダーに移動します。

  4. python コマンドの後にスクリプトのファイル名を付けて実行します。

例えば、ダウンロードフォルダーに保存した場合は、次のように入力します。macOS では python の代わりに python3 と入力してください。

1cd Downloads
2python brewing_guide.py

淹れ方の目安の表示（brewing_guide.py）

お茶の種類と人数を指定すると、茶葉の量、お湯の量、湯温、浸出時間の目安を表示します。計算には、「おいしい淹れ方」で紹介した式と目安、および「抹茶を点てる」で紹介した薄茶の目安を使っています。

ダウンロード：brewing_guide.py

使い方

引数を付けずに実行すると、お茶の種類と人数を順に尋ねられます。

1python brewing_guide.py

お茶の種類と人数を続けて指定すると、すぐに結果が表示されます。人数は 1〜10 の範囲で指定します。お茶の種類には、次のいずれかを指定します。

  • sencha：上級煎茶

  • futsu：普通煎茶・深蒸し煎茶

  • gyokuro：玉露

  • bancha：番茶・ほうじ茶・玄米茶

  • matcha：抹茶（薄茶）

例えば、上級煎茶を 3 人分淹れる場合は、次のように実行します。

1python brewing_guide.py sencha 3

実行すると、次のように表示されます。

1上級煎茶 3 人分の目安
2  茶葉の量  : 6.0 g（茶さじ約 3.0 杯）
3  お湯の量  : 180 ml
4  湯温      : 70 ℃
5  浸出時間  : 1〜2 分

茶葉を量る道具は、お茶の種類によって変わります。煎茶と玉露は茶さじ（1 杯約 2 g）、番茶・ほうじ茶・玄米茶は大さじ（1 杯約 3 g）、抹茶は茶杓（1 杯約 1 g）で換算しています。

ソースコード

  1"""日本茶の淹れ方の目安を表示するスクリプト.
  2
  3お茶の種類と人数を指定すると, 茶葉の量, お湯の量, 湯温, 浸出時間の
  4目安を表示します.
  5
  6使い方:
  7    python brewing_guide.py              # 対話形式で入力する
  8    python brewing_guide.py sencha 3     # 上級煎茶を 3 人分
  9
 10Python 3.10 以上の標準ライブラリだけで動作します.
 11"""
 12
 13from __future__ import annotations
 14
 15import argparse
 16import sys
 17from dataclasses import dataclass
 18
 19
 20@dataclass(frozen=True)
 21class TeaRecipe:
 22    """1 人分の淹れ方の目安."""
 23
 24    name: str          # お茶の名前
 25    leaf_g: float      # 1 人分の茶葉の量 [g]
 26    water_ml: int      # 1 人分のお湯の量 [ml]
 27    temperature: str   # 湯温の目安
 28    steep_time: str    # 浸出時間の目安
 29    spoon: str         # 量るときに使う道具
 30    spoon_g: float     # その道具 1 杯分の重さの目安 [g]
 31
 32
 33# 本文「おいしい淹れ方」「抹茶を点てる」の表と同じ値を使う
 34RECIPES: dict[str, TeaRecipe] = {
 35    'sencha': TeaRecipe('上級煎茶', 2.0, 60, '70 ℃', '1〜2 分',
 36                        '茶さじ', 2.0),
 37    'futsu': TeaRecipe('普通煎茶・深蒸し煎茶', 2.0, 90, '80〜90 ℃',
 38                       '30 秒〜1 分', '茶さじ', 2.0),
 39    'gyokuro': TeaRecipe('玉露', 3.0, 20, '50〜60 ℃', '2〜2.5 分',
 40                         '茶さじ', 2.0),
 41    'bancha': TeaRecipe('番茶・ほうじ茶・玄米茶', 3.0, 130, '熱湯',
 42                        '30 秒', '大さじ', 3.0),
 43    'matcha': TeaRecipe('抹茶（薄茶）', 2.0, 70, '80 ℃ 前後',
 44                        '茶筅で 15〜20 秒点てる', '茶杓', 1.0),
 45}
 46
 47MAX_PEOPLE = 10
 48
 49
 50def calculate(recipe: TeaRecipe, people: int) -> tuple[float, int]:
 51    """人数分の茶葉の量 [g] とお湯の量 [ml] を返す.
 52
 53    茶葉の量 W = n × w, お湯の量 V = n × v で求める.
 54    """
 55    if not 1 <= people <= MAX_PEOPLE:
 56        raise ValueError(f'人数は 1〜{MAX_PEOPLE} で指定してください。')
 57    return recipe.leaf_g * people, recipe.water_ml * people
 58
 59
 60def format_guide(key: str, people: int) -> str:
 61    """表示用の文字列を作る."""
 62    recipe = RECIPES[key]
 63    leaf_g, water_ml = calculate(recipe, people)
 64    lines = [
 65        f'{recipe.name} {people} 人分の目安',
 66        f'  茶葉の量  : {leaf_g:.1f} g'
 67        f'（{recipe.spoon}約 {leaf_g / recipe.spoon_g:.1f} 杯）',
 68        f'  お湯の量  : {water_ml} ml',
 69        f'  湯温      : {recipe.temperature}',
 70        f'  浸出時間  : {recipe.steep_time}',
 71    ]
 72    return '\n'.join(lines)
 73
 74
 75def ask_key() -> str:
 76    """お茶の種類を番号で選んでもらう."""
 77    keys = list(RECIPES)
 78    for number, key in enumerate(keys, start=1):
 79        print(f'  {number}: {RECIPES[key].name}')
 80    while True:
 81        answer = input('お茶の種類を番号で選んでください: ').strip()
 82        if answer.isdigit() and 1 <= int(answer) <= len(keys):
 83            return keys[int(answer) - 1]
 84        print('一覧にある番号を入力してください。')
 85
 86
 87def ask_people() -> int:
 88    """人数を入力してもらう."""
 89    while True:
 90        answer = input(f'人数を入力してください（1〜{MAX_PEOPLE}）: ').strip()
 91        if answer.isdigit() and 1 <= int(answer) <= MAX_PEOPLE:
 92            return int(answer)
 93        print(f'1〜{MAX_PEOPLE} の数字を入力してください。')
 94
 95
 96def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
 97    """コマンドライン引数を解析する."""
 98    parser = argparse.ArgumentParser(
 99        description='日本茶の淹れ方の目安を表示します。')
100    parser.add_argument('tea', nargs='?', choices=list(RECIPES),
101                        help='お茶の種類')
102    parser.add_argument('people', nargs='?', type=int, help='人数')
103    return parser.parse_args(argv)
104
105
106def main(argv: list[str] | None = None) -> int:
107    """エントリーポイント."""
108    args = parse_args(argv)
109    key: str = args.tea if args.tea is not None else ask_key()
110    people: int = args.people if args.people is not None else ask_people()
111    try:
112        print(format_guide(key, people))
113    except ValueError as error:
114        print(error, file=sys.stderr)
115        return 1
116    return 0
117
118
119if __name__ == '__main__':
120    sys.exit(main())

浸出時間のタイマー（tea_timer.py）

お茶の種類と何煎目かを指定すると、湯温の目安を表示してから浸出時間をカウントダウンし、時間になったら音とメッセージで知らせます。タイマーで計る時間は、「おいしい淹れ方」で紹介した浸出時間の目安の中間の値です。

ダウンロード：tea_timer.py

使い方

お茶の種類には、次のいずれかを指定します。指定しない場合は、実行後に番号で選びます。

指定する名前

お茶の種類

1 煎目

2 煎目

3 煎目

sencha

上級煎茶

70 ℃、1 分 30 秒

80 ℃、10 秒

90 ℃、30 秒

futsu

普通煎茶・深蒸し煎茶

80〜90 ℃、45 秒

90 ℃、10 秒

熱湯、30 秒

gyokuro

玉露

50〜60 ℃、2 分 15 秒

60 ℃、30 秒

70 ℃、1 分

bancha

番茶・ほうじ茶・玄米茶

熱湯、30 秒

熱湯、15 秒

なし

何煎目かは --brew の後に指定します。省略すると 1 煎目になります。例えば、上級煎茶の 2 煎目を計る場合は、次のように実行します。

1python tea_timer.py sencha --brew 2

好みの時間で計りたい場合は、--seconds の後に秒数を指定します。次の例では、50 秒を計ります。

1python tea_timer.py --seconds 50

実行すると、残り時間が 1 秒ごとに更新され、時間になると次のように表示されます。途中でやめたい場合は、Ctrl+C を押します。

1上級煎茶の 2 煎目: 湯温は 80 ℃が目安です。
20 分 10 秒を計ります。Ctrl+C で中止できます。
3残り 0 分 00 秒
4時間になりました。最後の一滴まで注ぎ切りましょう。

ソースコード

  1"""日本茶の浸出時間を計るタイマー.
  2
  3お茶の種類と何煎目かを指定すると, 湯温の目安を表示してから
  4浸出時間をカウントダウンし, 時間になったら音とメッセージで知らせます.
  5
  6使い方:
  7    python tea_timer.py                  # 対話形式で入力する
  8    python tea_timer.py sencha           # 上級煎茶の 1 煎目
  9    python tea_timer.py sencha --brew 2  # 上級煎茶の 2 煎目
 10    python tea_timer.py --seconds 50     # 好みの秒数で計る
 11
 12Python 3.10 以上の標準ライブラリだけで動作します.
 13"""
 14
 15from __future__ import annotations
 16
 17import argparse
 18import sys
 19import time
 20from dataclasses import dataclass
 21
 22
 23@dataclass(frozen=True)
 24class Brew:
 25    """1 回分の淹れ方."""
 26
 27    temperature: str  # 湯温の目安
 28    seconds: int      # 浸出時間 [秒]
 29
 30
 31# 本文「おいしい淹れ方」の目安の中間の値を使う
 32# 2 煎目以降は湯温を上げ, 浸出時間を短くする
 33TIMERS: dict[str, tuple[str, list[Brew]]] = {
 34    'sencha': ('上級煎茶', [
 35        Brew('70 ℃', 90), Brew('80 ℃', 10), Brew('90 ℃', 30)]),
 36    'futsu': ('普通煎茶・深蒸し煎茶', [
 37        Brew('80〜90 ℃', 45), Brew('90 ℃', 10), Brew('熱湯', 30)]),
 38    'gyokuro': ('玉露', [
 39        Brew('50〜60 ℃', 135), Brew('60 ℃', 30), Brew('70 ℃', 60)]),
 40    'bancha': ('番茶・ほうじ茶・玄米茶', [
 41        Brew('熱湯', 30), Brew('熱湯', 15)]),
 42}
 43
 44
 45def format_time(seconds: int) -> str:
 46    """秒数を「m 分 ss 秒」の形にする."""
 47    minutes, rest = divmod(seconds, 60)
 48    return f'{minutes} 分 {rest:02d} 秒'
 49
 50
 51def countdown(seconds: int) -> None:
 52    """残り時間を 1 秒ごとに表示しながら待つ."""
 53    for remaining in range(seconds, 0, -1):
 54        print(f'\r残り {format_time(remaining)}', end='', flush=True)
 55        time.sleep(1)
 56    print(f'\r残り {format_time(0)}')
 57
 58
 59def ask_key() -> str:
 60    """お茶の種類を番号で選んでもらう."""
 61    keys = list(TIMERS)
 62    for number, key in enumerate(keys, start=1):
 63        print(f'  {number}: {TIMERS[key][0]}')
 64    while True:
 65        answer = input('お茶の種類を番号で選んでください: ').strip()
 66        if answer.isdigit() and 1 <= int(answer) <= len(keys):
 67            return keys[int(answer) - 1]
 68        print('一覧にある番号を入力してください。')
 69
 70
 71def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
 72    """コマンドライン引数を解析する."""
 73    parser = argparse.ArgumentParser(
 74        description='日本茶の浸出時間を計ります。')
 75    parser.add_argument('tea', nargs='?', choices=list(TIMERS),
 76                        help='お茶の種類')
 77    parser.add_argument('--brew', type=int, default=1,
 78                        help='何煎目か（既定値: 1）')
 79    parser.add_argument('--seconds', type=int,
 80                        help='好みの浸出時間 [秒]')
 81    return parser.parse_args(argv)
 82
 83
 84def main(argv: list[str] | None = None) -> int:
 85    """エントリーポイント."""
 86    args = parse_args(argv)
 87    if args.seconds is not None:
 88        if args.seconds <= 0:
 89            print('秒数は 1 以上で指定してください。', file=sys.stderr)
 90            return 1
 91        seconds: int = args.seconds
 92        print(f'{format_time(seconds)}を計ります。Ctrl+C で中止できます。')
 93    else:
 94        key: str = args.tea if args.tea is not None else ask_key()
 95        name, brews = TIMERS[key]
 96        if not 1 <= args.brew <= len(brews):
 97            print(f'{name}は {len(brews)} 煎目までです。', file=sys.stderr)
 98            return 1
 99        brew = brews[args.brew - 1]
100        seconds = brew.seconds
101        print(f'{name}の {args.brew} 煎目: 湯温は {brew.temperature}が'
102              '目安です。')
103        print(f'{format_time(seconds)}を計ります。Ctrl+C で中止できます。')
104    try:
105        countdown(seconds)
106    except KeyboardInterrupt:
107        print('\n中止しました。')
108        return 1
109    print('\a時間になりました。最後の一滴まで注ぎ切りましょう。')
110    return 0
111
112
113if __name__ == '__main__':
114    sys.exit(main())
