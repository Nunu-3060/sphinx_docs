コンピューターアーキテクチャ入門

本書は、エンジニアを対象に、コンピューターアーキテクチャの基礎を解説する入門資料です。命令セットアーキテクチャという「ソフトウェアとハードウェアの約束事」から出発し、それを実現するプロセッサの設計、パイプラインや命令レベル並列性による高速化、メモリ階層、並列アーキテクチャ、GPU までを、性能という観点から順に積み上げて説明します。
