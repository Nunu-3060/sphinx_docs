健康的な生活

本書は、成人が食事・運動・睡眠を中心とした生活習慣を見直し、無理なく続けられる形で改善していくための手引きである。厚生労働省の「健康日本21（第三次）」をはじめとする公的な指針に基づき、何をどの程度行えばよいかを具体的な目安とともに示す。
