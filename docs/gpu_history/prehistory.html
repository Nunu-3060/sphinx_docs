3. 前史：グラフィックスハードウェアの黎明（1970 年代〜1998 年）

本章では、GPU が登場する以前のグラフィックスハードウェアの発展を概観する。この時代に、画面表示の仕組み、3D 描画のアルゴリズム、描画 API といった、GPU の土台となる要素がそろった。

3.1. フレームバッファとディスプレイコントローラ

コンピュータで画像を表示する基本的な仕組みは、画面の各ピクセルの色をメモリに保持し、その内容を一定の周期でディスプレイに送り出すことである。このメモリをフレームバッファと呼ぶ。1970 年代前半には、Xerox パロアルト研究所の SuperPaint のように、フレームバッファを用いて画像を描くシステムが研究されていた[Shoup2001]。当時はメモリが高価であったため、フレームバッファを備えたシステムは研究機関や一部の専門用途に限られた。

1980 年代に入るとパーソナルコンピュータが普及し、表示機能はビデオカードとして標準化されていった。IBM PC 向けには、1981 年の MDA と CGA、1984 年の EGA、1987 年の VGA が登場し、解像度と色数が段階的に向上した。ただし、これらはフレームバッファの内容を画面に表示するディスプレイコントローラであり、描画そのものは CPU がフレームバッファに直接書き込むことで行っていた。

3.2. グラフィックスワークステーションと 3D 専用ハードウェア

3D グラフィックスのハードウェア化は、まず高価な専門機器の分野で進んだ。1968 年に設立された Evans & Sutherland は、フライトシミュレータ向けのリアルタイム 3D 表示装置を開発した。

1982 年には、スタンフォード大学の Jim Clark が、座標変換やクリッピングを行う専用 VLSI チップ「Geometry Engine」を発表した[Clark1982]。Clark は同年に Silicon Graphics（SGI）を設立し、Geometry Engine を搭載したグラフィックスワークステーションを製品化した。SGI のワークステーションは、映画の視覚効果、工業デザイン、科学技術計算の可視化などの分野で広く使われた。1992 年に発表された RealityEngine は、テクスチャマッピングをハードウェアで実行し、高品質なリアルタイム 3D 描画を実現した[Akeley1993]。

同じ 1992 年、SGI は自社の描画ライブラリ IRIS GL を基に、ベンダーに依存しない描画 API として OpenGL 1.0 を公開した[Khronos-OpenGL]。OpenGL は複数の企業で構成される ARB（Architecture Review Board）が管理する標準規格となり、後に PC の 3D グラフィックスでも使われるようになった。OpenGL は描画処理を図 2.1 のようなパイプラインとして定義しており、この考え方はその後のハードウェア設計にも大きな影響を与えた。

3.3. 2D アクセラレータと GUI

PC の世界でハードウェアによる描画の高速化が広まったきっかけは、GUI の普及である。1990 年の Windows 3.0 の登場以降、ウィンドウの移動や再描画のために、矩形領域のコピー（BitBLT）や直線の描画を高速に行う必要が生じた。1991 年に S3 が発表した 86C911 などの Windows アクセラレータは、これらの 2D 描画処理をハードウェアで実行し、CPU の負荷を大幅に減らした。

3.4. PC 向け 3D アクセラレータの登場

1990 年代半ばになると、PC ゲームで 3D グラフィックスが本格的に使われ始めた。当初は CPU がすべての描画処理を行うソフトウェアレンダリングが主流であったが、解像度や画質を上げるには CPU の性能が不足していた。

この需要に応えたのが、PC 向けの 3D アクセラレータである。1995 年には S3 の ViRGE などが 2D と 3D の両方の機能を持つチップとして登場したが、3D の性能は十分ではなかった。転機となったのは、1996 年に 3dfx Interactive が発表した Voodoo Graphics である。Voodoo Graphics は 3D 描画専用のカードで、2D 表示用のビデオカードとケーブルで接続して使用した。三角形のラスタライズとテクスチャマッピングを高速に実行し、テクスチャを滑らかに補間するバイリニアフィルタリングなどにより、それまでのソフトウェアレンダリングを大きく上回る画質と速度を実現した。3dfx は Glide という独自の API を提供し、多くのゲームが Glide に対応した。1998 年の Voodoo2 では、2 枚のカードで画面の走査線を交互に分担して描画する SLI（Scan-Line Interleave）も実現した。

同時期には多くの企業がこの市場に参入した。1993 年に設立された NVIDIA は、1995 年に最初の製品 NV1 を発表したが、三角形ではなく二次曲面を基本図形とする独自の方式が普及せず、商業的には成功しなかった。その後 NVIDIA は三角形を基本とする方式に転換し、1997 年に 2D と 3D の機能を 1 チップに統合した RIVA 128 を、1998 年に 2 つのピクセルパイプラインを持つ RIVA TNT を発表して、市場での地位を確立した。ATI Technologies は Rage シリーズで、Matrox や S3 なども独自の製品で競争した。

ハードウェアの普及に伴い、API の標準化も進んだ。Microsoft は Windows 向けのマルチメディア API 群である DirectX を 1995 年に公開し、1996 年の DirectX 2.0 で 3D 描画 API の Direct3D を追加した。PC のゲームでは、Glide、OpenGL、Direct3D の 3 つの API が並立する時期が続いたが、やがて特定のハードウェアに依存しない OpenGL と Direct3D に集約されていった。

また、1997 年には Intel がグラフィックスカード専用の拡張バスである AGP（Accelerated Graphics Port）を発表した。従来の PCI バスより高い帯域幅でメインメモリとグラフィックスカードを接続し、大量のテクスチャデータの転送を可能にした。

3.5. ゲーム機における 3D 描画

家庭用ゲーム機も 3D グラフィックスの普及に大きな役割を果たした。1994 年に発売されたソニーの PlayStation は、座標変換を高速に行う専用のコプロセッサ（GTE）を CPU に組み込み、描画専用のチップと組み合わせてリアルタイム 3D 描画を実現した。1996 年に発売された任天堂の Nintendo 64 は、SGI が設計した描画用のコプロセッサ（RCP）を搭載した。ゲーム機は、大量生産によって 3D 描画用のハードウェアを一般家庭に届けた点で、PC と並ぶ重要な市場となった。

3.6. 前史のまとめ

1998 年の時点で、PC 向けの 3D アクセラレータは、グラフィックスパイプラインのうちラスタライズ以降の処理（ラスタライズ、テクスチャマッピング、出力合成）をハードウェアで実行していた。一方、その前段にあたる頂点処理、すなわち座標変換と光源計算は、依然として CPU が担っていた。

描画するポリゴンの数が増えるにつれて、この頂点処理が性能のボトルネックになり始めた。CPU が頂点を処理する速度が、アクセラレータがピクセルを描画する速度に追いつかなくなったのである。この問題を解決するため、頂点処理もグラフィックスチップに取り込もうとする動きが、次章で述べる GPU の誕生につながった。
