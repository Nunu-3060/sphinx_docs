9. モバイル・統合 GPU とゲーム機

ここまでの章では、主に PC 向けの単体 GPU とデータセンター向けの GPU を扱ってきた。しかし、出荷台数で見れば、GPU の大部分はスマートフォンや PC の CPU に内蔵された形で使われている。本章では、消費電力やコストの制約が厳しい環境での GPU の発展と、ゲーム機の GPU について述べる。

9.1. モバイル GPU とタイルベースレンダリング

スマートフォンなどのモバイル機器では、バッテリーで動作することと、ファンを持たない小さな筐体で熱を逃がす必要があることから、消費電力が最も重要な制約となる。GPU の消費電力の中で特に大きいのは、チップの外にあるメモリ（DRAM）へのアクセスである。チップ外のメモリにデータを 1 回読み書きするエネルギーは、チップ内で演算を 1 回行うエネルギーよりはるかに大きい。

この問題に対する代表的な解決策がタイルベースレンダリングである。画面を小さな矩形の領域（タイル）に分割し、タイルごとに描画を完結させる方式で、次の手順で処理する。

  1. すべての三角形の頂点処理を行い、各三角形がどのタイルに含まれるかを記録する。

  2. タイルを 1 つずつ処理する。タイルに含まれる三角形だけを、チップ内の小容量で高速なメモリ上でラスタライズし、色や深度を計算する。

  3. タイルの描画が完了したら、最終的な色だけをチップ外のフレームバッファに書き出す。

この方式では、深度テストや色の合成のための読み書きがチップ内で完結するため、チップ外のメモリへのアクセスを大幅に減らせる。さらに、ピクセルの色を計算する前にタイル内の三角形の前後関係を調べ、最終的に見えるピクセルだけを計算する方式をタイルベース遅延レンダリング（TBDR）と呼ぶ。

タイルベースレンダリングを早くから採用したのが、英国の Imagination Technologies（旧 VideoLogic）の PowerVR である。PowerVR は 1998 年に発売されたセガの Dreamcast に採用され、その後はモバイル機器向けの GPU として広く使われた。2007 年に発売された初代 iPhone も PowerVR を搭載している。

9.3. CPU 内蔵 GPU

PC でも、すべての機器が単体の GPU を搭載しているわけではない。事務用の PC やノート PC の多くは、CPU と同じチップまたはパッケージに内蔵された GPU を使用している。

Intel は 1999 年に、グラフィックス機能をチップセット（CPU とメモリなどを接続する周辺チップ）に統合した i810 を発表した。その後、2010 年には GPU を CPU と同じパッケージに、2011 年の Sandy Bridge では CPU と同じダイに統合した。

AMD は、2006 年の ATI の買収によって得た GPU 技術を活かし、2011 年に CPU と高性能な GPU を 1 つのダイに統合した APU（Accelerated Processing Unit）を発売した。AMD は、CPU と GPU が同じメモリ空間を共有し、互いに処理を任せ合う構想を HSA（Heterogeneous System Architecture）として提唱した。

内蔵 GPU は、メインメモリを CPU と共有するため、単体 GPU と比べてメモリ帯域幅で不利である。しかし、CPU と GPU の間でデータをコピーする必要がないという利点もある。この利点を大きく活かしたのが、2020 年に Apple が発表した M1 である。M1 は CPU、GPU、NPU などを 1 つのチップに統合し、高帯域幅のメモリを全体で共有するユニファイドメモリ構成を採用した。大容量のメモリを GPU から直接利用できるため、大きなモデルを扱う機械学習の推論などにも用いられている。

9.5. モバイル・統合 GPU の意義

モバイル機器と内蔵 GPU の分野では、性能そのものよりも、消費電力あたりの性能とコストが重視されてきた。タイルベースレンダリングのように、データの移動を減らすことで電力を節約する工夫は、この分野で発展した。

データの移動が消費電力の大部分を占めるという問題は、現在ではデータセンター向けの GPU にとっても重要な課題になっている。CPU と GPU がメモリを共有する構成も、Apple の M シリーズのほか、AMD の MI300A や NVIDIA の Grace Hopper のように、データセンター向けの製品で採用されるようになった。モバイル・統合 GPU で培われた考え方は、GPU 全体の設計に影響を与えている。
