1. はじめに

1.1. 本書の目的

ゲームを作ってみたいと考えたとき、プログラムや画像に比べて後回しにされやすいのが音である。効果音や BGM の素材は配布サイトから入手することもできるが、自分の作品に合った音がいつも見つかるとは限らない。また、素材を少し調整したいと思っても、音がどのような仕組みでできているかを知らなければ手が出せない。

本書は、ゲーム制作やアセット制作の経験がないエンジニアが、8 bit ゲーム機のような音（以下、8 bit サウンド）の効果音と BGM を自分で作れるようになることを目的とする。

8 bit サウンドは入門の題材に適している。使える波形は矩形波・三角波・ノイズなどのごく単純なものに限られ、同時に鳴らせる音の数も 4 つ程度しかない。この制約のおかげで、音を作るときに考えるべき要素が少なく、仕組みを一つずつ理解しながら進められる。そのうえ、完成した音はゲームの効果音や BGM として十分に通用する。

1.2. 本書のゴール

本書を読み終えたとき、読者は次のことができるようになっている。

  • 8 bit サウンドがどのような制約から生まれ、なぜあのような音になるのかを説明できる。

  • 矩形波・三角波・ノイズを自分で生成し、WAV ファイルとして書き出せる。

  • ジャンプやアイテム取得、爆発などの典型的な効果音を、パラメータを調整して作れる。

  • 4 チャンネル構成の短いループ BGM を作り、ゲームに組み込める形式で出力できる。

  • トラッカーなどの専用ツールに移行するための基礎用語を理解している。

音を作る部分では、波形、音の加工、効果音、BGM の順に、作る対象を少しずつ大きくしていく。効果音を BGM より先に扱うのは、効果音が短く単純で、作ってすぐに結果を確かめられるからである。

音の仕組みを理解するために、本書ではツールを使わずにプログラムで音を作る。エンジニアにとってはコードが最も確実に理解できる表現であり、何をすれば音がどう変わるのかを一つずつ確かめられる。実際の制作で便利な専用ツールは、仕組みを理解した後の「制作ツールの紹介」で紹介する。

1.4. 前提知識

本書は次の知識を前提とする。

  • Python の基本的な文法（変数、関数、リスト、辞書、クラス、型ヒント）

  • 高校程度の数学（指数関数、対数、三角関数）

音響や音楽理論の知識は前提としない。必要な事柄は本文中で説明する。NumPy は配列をまとめて計算するために使うが、本書で使う機能はその都度説明する。

1.6. サンプルコードの使い方

サンプルコードの一覧とダウンロードリンクは「サンプルコード一覧」にまとめている。すべてのファイルを同じフォルダに置き、そのフォルダで次のコマンドを実行すると、本書で使うすべての音声ファイルが output フォルダに生成される。

1python make_all.py

各モジュールを単独で実行することもできる。例えば python sound_effects.py を実行すると、効果音だけが生成される。

1.7. 本書の表記

本書では次の表記を用いる。

  • 音名は「C4」のように、アルファベットとオクターブ番号で表す。表記の詳細は「最低限の音楽知識」で説明する。

  • 周波数の単位にはヘルツ（Hz）を用いる。

  • 「ファミコン」は任天堂のファミリーコンピュータを指す。海外版の NES（Nintendo Entertainment System）も、音源の仕組みは同じである。

  • 本文中の音声は、プレーヤーの再生ボタンを押すと再生できる。初めて再生するときは、音量を小さめにしておくこと。8 bit サウンドの波形は正弦波などに比べて大きく聞こえやすい。
