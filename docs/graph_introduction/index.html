グラフによる可視化入門

データや構造は、数値や文章のままでは全体像をつかみにくい。グラフにすると、傾向、ばらつき、外れ値、つながりといった性質が一目で分かるようになる。本書は、どのようなデータや構造を、どのようなグラフで可視化すればよいかを解説する入門書である。

対象読者は、Python などのプログラミングの知識があるエンジニアである。図はすべて Python のサンプルコード（matplotlib と Graphviz）で描いており、本文からコードを閲覧し、ダウンロードできる。
