書籍

内容

Dustin Boswell、Trevor Foucher 著、角征典 訳『リーダブルコード ― より良いコードを書くためのシンプルで実践的なテクニック』オライリー・ジャパン、2012 年

読みやすいコードを書くための方法を、多くの例を使って説明している。本書の第 3 章から第 8 章の内容をより詳しく学べる。

Robert C. Martin 著、花井志生 訳『Clean Code ― アジャイルソフトウェア達人の技』アスキー・メディアワークス、2009 年

名前、関数、コメント、エラー処理、テストなど、きれいなコードを書くための原則を幅広く扱っている。

Martin Fowler 著、児玉公信、友野晶夫、平澤章、梅澤真史 訳『リファクタリング ― 既存のコードを安全に改善する（第 2 版）』オーム社、2019 年

リファクタリングの考え方と、具体的な手法を体系的にまとめている。
