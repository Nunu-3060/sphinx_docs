第 4 章 基本データ構造

アルゴリズムの効率は、データをどのような形で保持するかに大きく左右される。データを保持し、決められた操作を提供する仕組みをデータ構造と呼ぶ。本章では、後の章で繰り返し使う基本的なデータ構造を、提供する操作とその計算量に注目して紹介する。

なお本書では、連結リストや木を構成する一つ一つの要素をノードと呼ぶ。グラフ理論の用語では頂点に当たる。

配列と連結リスト

配列は、要素をメモリ上に連続して並べたデータ構造である。\(i\) 番目の要素の位置は先頭の位置から計算できるので、添字によるアクセスは \(O(1)\) で行える。一方、途中に要素を挿入したり削除したりすると、後ろの要素を全てずらす必要があり \(O(n)\) 時間かかる。Python の list は、第 3 章で説明したように容量を自動的に拡張する配列（可変長配列）である。

連結リストは、各ノードが値と次のノードへの参照を持ち、参照をたどって要素を順に並べるデータ構造である。挿入や削除をしたい位置のノードが分かっていれば、参照をつなぎ替えるだけなので \(O(1)\) で済む。その代わり、\(i\) 番目の要素にたどり着くには先頭から \(i\) 回参照をたどる必要があり、\(O(i)\) 時間かかる。

実際の計算機では、連続したメモリをまとめて読み込むキャッシュの効果により、配列の方が漸近的な計算量以上に速いことが多い。

スタックとキュー

スタックは、最後に入れた要素を最初に取り出す（LIFO: Last In, First Out）データ構造であり、キューは、最初に入れた要素を最初に取り出す（FIFO: First In, First Out）データ構造である。どちらも追加と取り出しを \(O(1)\) で行える。

ハッシュテーブル

ハッシュテーブルは、キーから値を平均 \(O(1)\) 時間で引けるデータ構造であり、Python の dict と set はハッシュテーブルで実装されている。

ハッシュテーブルは、大きさ \(m\) の配列とハッシュ関数 \(h\) からなる。ハッシュ関数はキーを \(0\) 以上 \(m - 1\) 以下の整数に変換する関数であり、キー \(k\) に対応する値を配列の \(h(k)\) 番目の位置に格納する。異なるキーが同じ位置に割り当てられることを衝突と呼ぶ。衝突を処理する方法には、同じ位置に割り当てられた要素をリストでつなぐ連鎖法と、空いている別の位置を規則に従って探す開番地法がある。CPython の dict は開番地法を採用している。

要素数 \(n\) と配列の大きさ \(m\) の比 \(\lambda = n/m\) を負荷率と呼ぶ。ハッシュ関数がキーを一様に散らすと仮定すると、1 回の操作で調べる位置の数の期待値は負荷率だけで決まる。負荷率が一定値を超えたら配列を拡張して全ての要素を入れ直すことで、操作の平均計算量を \(O(1)\) に保てる。拡張にかかる時間は、list の append と同じ理由で償却すれば \(O(1)\) である。

ただし、全てのキーが同じ位置に割り当てられる最悪の場合には、1 回の操作に \(O(n)\) 時間かかる。攻撃者がそのようなキーを意図的に送り込むことを防ぐため、Python は文字列のハッシュ値の計算に、起動のたびに変わる乱数を混ぜている。

ヒープと優先度付きキュー

優先度付きキューは、要素の追加と、最小（または最大）の要素の取り出しを提供するデータ構造である。第 7 章のダイクストラ法やプリム法で使う。

優先度付きキューの代表的な実装が二分ヒープである。二分ヒープは、各ノードの値がその子の値以下であるという条件（ヒープ条件）を満たす完全二分木である。完全二分木なので、配列の添字だけで親子関係を表せる。添字 \(i\) のノードの子は添字 \(2i + 1\) と \(2i + 2\)、親は添字 \(\lfloor (i - 1)/2 \rfloor\) にある。

  • 追加: 末尾に要素を置き、親より小さい間は親と交換して上へ移動させる。

  • 最小値の取り出し: 根（添字 0）を取り出し、末尾の要素を根に移してから、子より大きい間は小さい方の子と交換して下へ移動させる。

木の高さは \(O(\log n)\) なので、どちらの操作も \(O(\log n)\) 時間で済む。Python では heapq モジュールが、list を二分ヒープとして扱う関数を提供している。

1import heapq
2
3heap: list[int] = []
4for x in [5, 1, 8, 3, 2]:
5    heapq.heappush(heap, x)
6print([heapq.heappop(heap) for _ in range(len(heap))])  # [1, 2, 3, 5, 8]

heapq は最小ヒープだけを提供する。最大値を取り出したい場合は、値の符号を反転して格納する。

二分探索木と平衡木

二分探索木は、各ノードについて「左の部分木のキーは全てそのノードのキーより小さく、右の部分木のキーは全て大きい」という条件を満たす二分木である。探索は根から始め、目的のキーと比べて左右どちらかに進むことを繰り返す。追加と削除も同様に行える。

これらの操作の計算量は木の高さ \(h\)（根から最も深い葉までの経路の辺の数）に比例し \(O(h)\) である。キーを無作為な順に追加すると高さは平均 \(O(\log n)\) になるが、整列済みの順に追加すると木が一直線に伸びて \(h = n - 1\) となり、操作は \(O(n)\) に劣化する。

この問題を解決するのが平衡二分探索木である。追加や削除のたびに回転と呼ばれる局所的な変形を行い、高さを常に \(O(\log n)\) に保つ。代表的なものに AVL 木と赤黒木がある。平衡二分探索木は、ハッシュテーブルと異なり、キーの順序を保ったまま次の操作を \(O(\log n)\) で提供できる。

  • 最小値・最大値の取得

  • あるキー以上で最小のキーの探索

  • ある範囲に含まれるキーの列挙

Python の標準ライブラリには平衡二分探索木がない。整列済みのリストに対して bisect モジュールで二分探索を行えば、探索は \(O(\log n)\) で行えるが、挿入と削除は \(O(n)\) になる。

Union-Find

Union-Find（素集合データ構造）は、要素を互いに素な集合に分けて管理し、次の 2 つの操作を提供する。

  • union(x, y): \(x\) を含む集合と \(y\) を含む集合を合併する。

  • find(x): \(x\) を含む集合の代表元を返す。2 つの要素の find の結果が等しければ、両者は同じ集合に属する。

各集合を根付き木で表し、根を代表元とする。素朴に実装すると木が一直線に伸びて find が \(O(n)\) になるが、次の 2 つの工夫を組み合わせると、1 操作あたりの償却計算量は \(O(\alpha(n))\) になる。ここで \(\alpha(n)\) は逆アッカーマン関数であり、現実的な \(n\) に対しては 4 以下なので、実質的に定数とみなせる。

  • union by size: 合併のとき、要素数の少ない木の根を、要素数の多い木の根の子にする。これだけで木の高さは \(O(\log n)\) に抑えられる。

  • 経路圧縮: find の途中で通ったノードを、全て根に直接つなぎ直す。

Union-Find は、第 2 章で述べた同値類を動的に管理するデータ構造であり、第 7 章のクラスカル法で「2 つの頂点が既に同じ木に属するか」を判定するのに使う。

ch04_union_find.py

リスト 2 ch04_union_find.py
 1"""第 4 章: Union-Find (素集合データ構造)。
 2
 3要素を互いに素な集合に分け、次の 2 つの操作を高速に行う。
 4
 5* union(x, y): x を含む集合と y を含む集合を合併する。
 6* same(x, y): x と y が同じ集合に属するかを判定する。
 7
 8経路圧縮と、小さい木を大きい木の下につなぐ工夫 (union by size) により、
 91 操作あたりの償却計算量はほぼ定数 (逆アッカーマン関数) になる。
10
11実行例::
12
13    python ch04_union_find.py
14"""
15
16from __future__ import annotations
17
18
19class UnionFind:
20    """要素 0, 1, ..., n - 1 を扱う Union-Find。"""
21
22    def __init__(self, n: int) -> None:
23        # parent[x] は x の親。根では parent[x] == x となる。
24        self.parent = list(range(n))
25        # size[r] は根 r を持つ木の要素数 (根以外では意味を持たない)。
26        self.size = [1] * n
27
28    def find(self, x: int) -> int:
29        """x を含む木の根を返す。途中の要素は根に直接つなぎ直す。"""
30        root = x
31        while self.parent[root] != root:
32            root = self.parent[root]
33        while self.parent[x] != root:  # 経路圧縮
34            self.parent[x], x = root, self.parent[x]
35        return root
36
37    def union(self, x: int, y: int) -> bool:
38        """x と y の集合を合併する。既に同じ集合なら False を返す。"""
39        rx, ry = self.find(x), self.find(y)
40        if rx == ry:
41            return False
42        if self.size[rx] < self.size[ry]:
43            rx, ry = ry, rx
44        self.parent[ry] = rx  # 小さい木を大きい木の下につなぐ
45        self.size[rx] += self.size[ry]
46        return True
47
48    def same(self, x: int, y: int) -> bool:
49        """x と y が同じ集合に属するなら True を返す。"""
50        return self.find(x) == self.find(y)
51
52
53def main() -> None:
54    uf = UnionFind(6)
55    for x, y in [(0, 1), (1, 2), (3, 4)]:
56        uf.union(x, y)
57        print(f"union({x}, {y})")
58    print("same(0, 2) =", uf.same(0, 2))  # True
59    print("same(0, 3) =", uf.same(0, 3))  # False
60    print("same(3, 4) =", uf.same(3, 4))  # True
61    print("same(5, 5) =", uf.same(5, 5))  # True
62
63
64if __name__ == "__main__":
65    main()
