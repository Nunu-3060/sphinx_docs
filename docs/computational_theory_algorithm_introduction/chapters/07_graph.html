第 7 章 グラフアルゴリズム

道路網、通信網、ソフトウェアの依存関係、SNS の友人関係など、多くの問題は「もの」と「もの同士のつながり」で表せる。第 2 章で定義したグラフはその共通の言葉であり、グラフに対するアルゴリズムは非常に幅広い場面で使われる。本章では、グラフの探索、最短経路、最小全域木、最大流という代表的な問題を扱う。

グラフの表現

グラフを計算機で扱う方法には、主に次の 2 つがある。

  • 隣接リスト：各頂点について、隣接する頂点のリストを持つ。Python では dict[str, list[str]] のような辞書で表せる。

  • 隣接行列：\(V \times V\) の行列で、頂点 \(u\) から \(v\) への辺があれば \((u, v)\) 成分を 1（重み付きグラフなら重み）、なければ 0 とする。

表 16 隣接リストと隣接行列の比較

項目

隣接リスト

隣接行列

必要な領域

\(O(V + E)\)

\(O(V^2)\)

辺 \((u, v)\) の有無の判定

\(O(\deg u)\)

\(O(1)\)

\(O(\deg u)\)

ここで \(\deg u\) は頂点 \(u\) の次数である。現実のグラフの多くは辺の数が \(V^2\) よりずっと少ない（疎である）ため、通常は隣接リストを使う。本章のサンプルコードも全て隣接リストを用いる。

幅優先探索と深さ優先探索

グラフの全ての頂点を系統的に訪問する基本的な方法が、幅優先探索と深さ優先探索である。

幅優先探索（BFS: Breadth-First Search）は、始点に近い頂点から順に訪問する。キューを使い、取り出した頂点に隣接するまだ見つけていない頂点をキューの末尾に加えていく。始点からの距離が \(d\) の頂点は、距離が \(d - 1\) 以下の頂点を全て取り出した後に取り出されるので、辺の重みがない（全て 1 とみなす）グラフでは、BFS で各頂点を最初に見つけたときの段数が始点からの最短距離になる。

深さ優先探索（DFS: Depth-First Search）は、行けるところまで進み、行き止まりになったら戻って別の道を進む。再帰呼び出し（またはスタック）で実装する。DFS は、連結成分の分解、閉路の検出、次に述べるトポロジカルソートなどの基礎になる。

どちらも各頂点を 1 回ずつ訪問し、各辺を（無向グラフでは両方向から）定数回ずつ調べるので、計算量は \(O(V + E)\) である。

トポロジカルソート

有向グラフの辺 \(u \to v\) を「\(u\) は \(v\) より先に行う」という制約と考える。全ての辺について始点が終点より前に来るように頂点を一列に並べることをトポロジカルソートと呼ぶ。タスクの実行順序の決定、パッケージのインストール順序の決定、表計算ソフトのセルの再計算順序の決定などに使われる。

トポロジカルソートができるのは、グラフが閉路を持たない（DAG である）場合に限られる。閉路があれば、閉路上の頂点はどれも他より先に置けないからである。逆に DAG であれば、次のカーンの方法で必ず並べられる。

  1. 入次数が 0 の頂点をキューに入れる。

  2. キューから頂点 \(u\) を取り出して出力し、\(u\) から出る辺を全て取り除く。これにより入次数が 0 になった頂点をキューに入れる。

  3. キューが空になるまで 2 を繰り返す。全ての頂点を出力できなければ、グラフに閉路がある。

17def bfs(graph: Graph, start: str) -> dict[str, int]:
18    """start から各頂点への最短距離 (辺の本数) を返す。O(V + E)。"""
19    dist = {start: 0}
20    queue = deque([start])
21    while queue:
22        u = queue.popleft()
23        for v in graph[u]:
24            if v not in dist:  # 初めて見つけた頂点だけをキューに入れる
25                dist[v] = dist[u] + 1
26                queue.append(v)
27    return dist
28
29
30def dfs(graph: Graph, start: str) -> list[str]:
31    """start から深さ優先で訪問した順に頂点を返す。O(V + E)。"""
32    order: list[str] = []
33    visited: set[str] = set()
34
35    def visit(u: str) -> None:
36        visited.add(u)
37        order.append(u)
38        for v in graph[u]:
39            if v not in visited:
40                visit(v)
41
42    visit(start)
43    return order
44
45
46def topological_sort(graph: Graph) -> list[str]:
47    """有向非巡回グラフの頂点をトポロジカル順に並べる (カーンの方法)。"""
48    indegree = {u: 0 for u in graph}
49    for u in graph:
50        for v in graph[u]:
51            indegree[v] += 1
52    queue = deque(u for u in graph if indegree[u] == 0)
53    order: list[str] = []
54    while queue:
55        u = queue.popleft()
56        order.append(u)
57        for v in graph[u]:
58            indegree[v] -= 1
59            if indegree[v] == 0:
60                queue.append(v)
61    if len(order) != len(graph):
62        raise ValueError("グラフに閉路がある")
63    return order

最短経路

重み付きグラフで、経路上の辺の重みの合計を経路の長さとする。2 頂点間の長さが最小の経路を最短経路と呼ぶ。本節では、1 つの始点から全ての頂点への最短経路を求める問題（単一始点最短経路問題）と、全ての頂点の組の最短経路を求める問題（全点対最短経路問題）を扱う。

最短経路のアルゴリズムは、どれも緩和と呼ばれる次の操作を基本とする。\(d[v]\) を、始点から \(v\) までのこれまでに見つかった最短距離とする。

\[\text{辺 } (u, v) \text{ の重みを } w(u, v) \text{ として、} d[u] + w(u, v) < d[v] \text{ ならば } d[v] \leftarrow d[u] + w(u, v)\]

ダイクストラ法

ダイクストラ法は、辺の重みが全て非負のときに使える単一始点最短経路アルゴリズムである。距離が確定していない頂点のうち \(d[v]\) が最小のものを選んで確定させ、そこから出る辺を緩和することを繰り返す。最小の頂点を選ぶのに優先度付きキュー（第 4 章の二分ヒープ）を使うと、計算量は \(O((V + E) \log V)\) になる。

選んだ頂点の距離を「確定」としてよいのは、重みが非負であれば、まだ確定していない他の頂点を経由しても距離が短くなることはないからである。この意味でダイクストラ法は貪欲法の一種である。負の重みの辺があるとこの議論は成り立たず、ダイクストラ法は誤った答えを返すことがある。

ベルマン-フォード法

ベルマン-フォード法は、負の重みの辺があっても使える単一始点最短経路アルゴリズムである。全ての辺の緩和を \(V - 1\) 回繰り返す。負閉路（重みの合計が負になる閉路）がなければ、最短経路は同じ頂点を 2 度通らないので辺の数は \(V - 1\) 以下であり、\(k\) 回目の繰り返しが終わった時点で、辺の数が \(k\) 以下の最短経路は全て求まっている。これは「辺の数が \(k\) 以下」という部分問題を順に解く動的計画法と見ることができる。

\(V - 1\) 回の繰り返しの後にもう一度緩和を試み、まだ距離が更新される辺があれば、始点から到達できる負閉路が存在する。負閉路があると、閉路を回るたびに距離がいくらでも小さくなるので、最短経路は定義できない。計算量は \(O(VE)\) である。

ワーシャル-フロイド法

ワーシャル-フロイド法は、全点対最短経路を求める動的計画法である。頂点に番号 \(1, 2, \ldots, V\) を付け、\(d_k[i][j]\) を「途中で経由する頂点を \(1, \ldots, k\) に限ったときの \(i\) から \(j\) への最短距離」とする。頂点 \(k\) を経由するかしないかで場合分けすると、次の漸化式が得られる。

\[d_k[i][j] = \min(d_{k-1}[i][j],\ d_{k-1}[i][k] + d_{k-1}[k][j])\]

3 重ループで表を更新するだけなので、実装は非常に簡単である。計算量は \(O(V^3)\) で、負の重みの辺があっても負閉路がなければ正しく動作する。

 1"""第 7 章: 最短経路アルゴリズム。
 2
 3* dijkstra: 辺の重みが非負のときの単一始点最短経路。O((V + E) log V)
 4* bellman_ford: 負の重みを許す単一始点最短経路と負閉路の検出。O(VE)
 5* floyd_warshall: 全点対最短経路。O(V^3)
 6
 7重み付き有向グラフは「頂点 -> (隣接頂点, 重み) のリスト」で表す。
 8
 9実行例::
10
11    python ch07_shortest_path.py
12"""
13
14from __future__ import annotations
15
16import heapq
17import math
18
19WeightedGraph = dict[str, list[tuple[str, float]]]
20
21
22def dijkstra(graph: WeightedGraph, start: str) -> dict[str, float]:
23    """start から各頂点への最短距離を返す。重みは非負でなければならない。"""
24    dist = {u: math.inf for u in graph}
25    dist[start] = 0.0
26    heap: list[tuple[float, str]] = [(0.0, start)]
27    while heap:
28        d, u = heapq.heappop(heap)
29        if d > dist[u]:
30            continue  # 既により短い距離で確定済みの古い情報は捨てる
31        for v, w in graph[u]:
32            if d + w < dist[v]:
33                dist[v] = d + w
34                heapq.heappush(heap, (dist[v], v))
35    return dist
36
37
38def bellman_ford(graph: WeightedGraph, start: str) -> dict[str, float]:
39    """負の重みを許す最短距離。start から到達できる負閉路があれば例外。"""
40    dist = {u: math.inf for u in graph}
41    dist[start] = 0.0
42    for _ in range(len(graph) - 1):  # 最短経路の辺数は高々 V - 1
43        for u in graph:
44            for v, w in graph[u]:
45                if dist[u] + w < dist[v]:
46                    dist[v] = dist[u] + w
47    for u in graph:  # V 回目でも更新できるなら負閉路がある
48        for v, w in graph[u]:
49            if dist[u] + w < dist[v]:
50                raise ValueError("負閉路がある")
51    return dist
52
53
54def floyd_warshall(graph: WeightedGraph) -> dict[str, dict[str, float]]:
55    """全ての頂点の組の最短距離を返す。"""
56    dist = {u: {v: math.inf for v in graph} for u in graph}
57    for u in graph:
58        dist[u][u] = 0.0
59        for v, w in graph[u]:
60            dist[u][v] = min(dist[u][v], float(w))
61    for k in graph:  # 経由してよい頂点を 1 つずつ増やす
62        for i in graph:
63            for j in graph:
64                if dist[i][k] + dist[k][j] < dist[i][j]:
65                    dist[i][j] = dist[i][k] + dist[k][j]
66    return dist
67
68
69def main() -> None:
70    graph: WeightedGraph = {
71        "s": [("a", 4), ("b", 1)],
72        "a": [("c", 1)],
73        "b": [("a", 2), ("c", 5)],
74        "c": [("t", 3)],
75        "t": [],
76    }
77    print("ダイクストラ法      :", dijkstra(graph, "s"))

最小全域木

連結な重み付き無向グラフ \(G\) について、\(G\) の全ての頂点を含む木で、\(G\) の辺だけからなるものを全域木と呼ぶ。全域木のうち辺の重みの合計が最小のものを最小全域木と呼ぶ。全ての拠点を最小のコストで結ぶ配線や配管の設計などに使われる。

最小全域木のアルゴリズムは、次のカット性質に基づく。頂点集合を 2 つに分けたとき、両側を結ぶ辺のうち重みが最小の辺は、ある最小全域木に含まれる。この性質により、次の 2 つの貪欲法が最小全域木を与えることが示せる。

  • クラスカル法：辺を重みの小さい順に調べ、閉路を作らないものを採用する。閉路を作るかどうかは、辺の両端点が既に同じ木に属しているかで判定でき、第 4 章の Union-Find を使うと効率よく判定できる。辺の整列が支配的で、計算量は \(O(E \log E)\) である。

  • プリム法：1 つの頂点から木を育て、木の頂点と木の外の頂点を結ぶ辺のうち最小のものを加えることを繰り返す。優先度付きキューを使うと計算量は \(O(E \log V)\) である。

 1"""第 7 章: 最小全域木 (クラスカル法とプリム法)。
 2
 3無向グラフを辺のリスト (重み, 頂点, 頂点) で与え、
 42 つの方法で求めた最小全域木の重みの合計が一致することを確かめる。
 5
 6実行例::
 7
 8    python ch07_mst.py
 9"""
10
11from __future__ import annotations
12
13import heapq
14
15Edge = tuple[int, str, str]
16
17
18def kruskal(vertices: list[str], edges: list[Edge]) -> list[Edge]:
19    """重みの小さい辺から、閉路を作らないものを採用する。O(E log E)。"""
20    parent = {v: v for v in vertices}
21
22    def find(x: str) -> str:  # 簡易版 Union-Find (経路半減)
23        while parent[x] != x:
24            parent[x] = parent[parent[x]]
25            x = parent[x]
26        return x
27
28    tree: list[Edge] = []
29    for w, u, v in sorted(edges):
30        ru, rv = find(u), find(v)
31        if ru != rv:  # 別々の木をつなぐ辺なら閉路はできない
32            parent[ru] = rv
33            tree.append((w, u, v))
34    return tree
35
36
37def prim(vertices: list[str], edges: list[Edge]) -> list[Edge]:
38    """1 頂点から木を育て、木と外を結ぶ最小の辺を加える。O(E log V)。"""
39    adjacent: dict[str, list[tuple[int, str]]] = {v: [] for v in vertices}
40    for w, u, v in edges:
41        adjacent[u].append((w, v))
42        adjacent[v].append((w, u))
43    start = vertices[0]
44    in_tree = {start}
45    heap = [(w, start, v) for w, v in adjacent[start]]
46    heapq.heapify(heap)
47    tree: list[Edge] = []
48    while heap and len(in_tree) < len(vertices):
49        w, u, v = heapq.heappop(heap)
50        if v in in_tree:
51            continue
52        in_tree.add(v)
53        tree.append((w, u, v))
54        for w2, x in adjacent[v]:
55            if x not in in_tree:
56                heapq.heappush(heap, (w2, v, x))
57    return tree
58
59
60def main() -> None:
61    vertices = ["A", "B", "C", "D", "E"]
62    edges: list[Edge] = [
63        (1, "A", "B"), (3, "A", "C"), (4, "B", "C"), (2, "B", "D"),
64        (5, "C", "D"), (6, "C", "E"), (7, "D", "E"),
65    ]
66    for name, algorithm in (("クラスカル法", kruskal), ("プリム法", prim)):
67        tree = algorithm(vertices, edges)
68        total = sum(w for w, _, _ in tree)
69        print(f"{name}: 重み {total}, 辺 {[(u, v) for _, u, v in tree]}")

最大流

各辺に容量（流せる量の上限）が付いた有向グラフをネットワークと呼ぶ。始点 \(s\) から終点 \(t\) へ、各辺の容量を超えず、かつ \(s\) と \(t\) 以外の頂点で流入量と流出量が等しくなるように流すとき、流せる量の最大値を求める問題を最大流問題と呼ぶ。輸送計画や通信網の容量設計のほか、2 部グラフのマッチングなど、一見関係のない多くの問題が最大流問題に帰着できる。

フォード-ファルカーソン法

フォード-ファルカーソン法は、次の手順で最大流を求める。

  1. 全ての辺の流量を 0 とする。

  2. 残余グラフで \(s\) から \(t\) への経路（増加路）を探す。残余グラフとは、各辺 \((u, v)\) について、あと流せる量（容量 − 流量）を容量とする辺 \((u, v)\) と、押し戻せる量（流量）を容量とする逆向きの辺 \((v, u)\) を持つグラフである。

  3. 増加路が見つかれば、その経路上の残余容量の最小値だけ流量を増やし、2 に戻る。見つからなければ終了する。

逆向きの辺により、一度流した量を後から別の経路に振り替えることができる。増加路がなくなったときの流量が最大であることは、最大流最小カット定理（\(s\) から \(t\) への最大流量は、\(s\) 側と \(t\) 側に頂点を分けたとき、\(s\) 側から \(t\) 側へ向かう辺の容量の合計の最小値に等しい）によって保証される。

増加路を幅優先探索で（辺の数が最小のものを）選ぶ方法をエドモンズ-カープ法と呼び、計算量は \(O(VE^2)\) である。

 1"""第 7 章: 最大流 (エドモンズ-カープ法)。
 2
 3フォード-ファルカーソン法のうち、増加路を幅優先探索で選ぶものを
 4エドモンズ-カープ法と呼ぶ。計算量は O(VE^2)。
 5
 6実行例::
 7
 8    python ch07_max_flow.py
 9"""
10
11from __future__ import annotations
12
13from collections import deque
14
15
16def max_flow(capacity: dict[str, dict[str, int]], s: str, t: str) -> int:
17    """容量 capacity[u][v] のネットワークで s から t への最大流量を返す。"""
18    # 残余グラフ: 逆向きの辺も容量 0 で用意しておく。
19    residual: dict[str, dict[str, int]] = {}
20    for u, targets in capacity.items():
21        for v, c in targets.items():
22            residual.setdefault(u, {})
23            residual.setdefault(v, {})
24            residual[u][v] = residual[u].get(v, 0) + c
25            residual[v].setdefault(u, 0)
26
27    flow = 0
28    while True:
29        # 残余容量が正の辺だけを通って s から t への経路を探す。
30        parent: dict[str, str] = {}
31        queue = deque([s])
32        while queue and t not in parent:
33            u = queue.popleft()
34            for v, c in residual[u].items():
35                if c > 0 and v != s and v not in parent:
36                    parent[v] = u
37                    queue.append(v)
38        if t not in parent:
39            return flow  # 増加路が無ければ現在の流量が最大
40        # 経路上の残余容量の最小値だけ流す。
41        bottleneck = min(residual[parent[v]][v] for v in path_to(parent, t))
42        for v in path_to(parent, t):
43            u = parent[v]
44            residual[u][v] -= bottleneck
45            residual[v][u] += bottleneck  # 逆辺を増やして「押し戻し」を許す
46        flow += bottleneck
47
48
49def path_to(parent: dict[str, str], t: str) -> list[str]:
50    """parent をたどって得られる経路上の頂点 (始点を除く) を返す。"""
51    path: list[str] = []
52    v = t
53    while v in parent:
54        path.append(v)
55        v = parent[v]
56    return path
57

63        "b": {"d": 9},
64        "c": {"t": 10},

この例の最大流量は 19 である。最大流最小カット定理を確かめてみよう。\(s\) 側を \(\{s, b\}\)、\(t\) 側を \(\{a, c, d, t\}\) とするカットを考えると、\(s\) 側から \(t\) 側へ横切る辺は \(s \to a\) と \(b \to d\) であり、容量の合計は \(10 + 9 = 19\) となって最大流量と一致する（辺 \(a \to b\) は \(t\) 側から \(s\) 側への辺なので数えない）。どのような流れもこのカットを横切らなければ \(t\) に届かないので、19 より多くは流せない。

章末のまとめ

  • グラフは通常、隣接リストで表す。幅優先探索と深さ優先探索は \(O(V + E)\) 時間で全頂点を訪問する。

  • 辺の重みがなければ幅優先探索、非負ならダイクストラ法、負の重みがあればベルマン-フォード法で単一始点最短経路が求まる。

  • 最小全域木は、クラスカル法やプリム法という貪欲法で求まる。

  • 最大流は、残余グラフ上で増加路を見つけて流量を増やすことを繰り返して求める。
