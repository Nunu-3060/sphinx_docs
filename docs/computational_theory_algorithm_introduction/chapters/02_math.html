第 2 章 数学的準備

本章では、本書全体で使う数学の言葉と道具をまとめる。既に知っている内容は読み飛ばし、必要になったときに戻ってくればよい。

集合・関数・関係

集合

集合はものの集まりであり、集合に含まれるものを要素と呼ぶ。\(a\) が集合 \(A\) の要素であることを \(a \in A\) と書く。集合は要素を並べて \(\{1, 2, 3\}\) のように書くか、条件を使って \(\{x \mid x \text{ は偶数}\}\) のように書く。要素を 1 つも持たない集合を空集合と呼び、\(\emptyset\) で表す。

集合に対する主な演算を次の表に示す。Python の set 型の演算子も併記する。

有限集合 \(A\) の要素数を \(|A|\) と書く。\(|A| = n\) のとき \(|2^A| = 2^n\) である。各要素について「含める」「含めない」の 2 通りを選べるからである。この「\(n\) 個の要素の部分集合は \(2^n\) 個ある」という事実は、第 11 章で総当たりの計算量を見積もるときに繰り返し使う。

関数

集合 \(A\) の各要素に集合 \(B\) の要素をちょうど 1 つ対応させる規則を、\(A\) から \(B\) への関数（写像）と呼び、\(f : A \to B\) と書く。\(A\) を定義域、\(B\) を終域と呼ぶ。異なる要素を異なる要素に移す関数を単射、\(B\) の全ての要素が何かの像になっている関数を全射、単射かつ全射である関数を全単射と呼ぶ。

関係

直積 \(A \times A\) の部分集合 \(R\) を、\(A\) 上の関係と呼ぶ。\((a, b) \in R\) を \(a R b\) とも書く。例えば整数上の「\(\le\)」は関係である。関係 \(R\) が次の 3 つの性質を全て満たすとき、\(R\) を同値関係と呼ぶ。

  • 反射律: 全ての \(a\) について \(a R a\)。

  • 対称律: \(a R b\) ならば \(b R a\)。

  • 推移律: \(a R b\) かつ \(b R c\) ならば \(a R c\)。

同値関係は集合を互いに素なグループ（同値類）に分ける。例えば「3 で割った余りが等しい」は整数上の同値関係であり、整数を余り 0、1、2 の 3 つの同値類に分ける。この考え方は第 4 章の Union-Find や、第 8 章で有限オートマトンの状態を設計するときに役立つ。

証明手法

計算理論では「このアルゴリズムは常に正しい答えを返す」「この問題を解くプログラムは存在しない」といった主張を扱う。こうした主張はテストでは確かめきれないため、証明が必要になる。ここでは本書で使う 4 つの証明手法を紹介する。

直接証明

仮定から出発し、正しい推論を積み重ねて結論を導く方法である。

例：奇数の 2 乗は奇数である。\(n\) を奇数とすると、ある整数 \(k\) を用いて \(n = 2k + 1\) と書ける。このとき \(n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1\) となり、\(n^2\) は奇数である。

背理法

結論が成り立たないと仮定して矛盾を導き、結論が成り立つことを示す方法である。

例：素数は無限に存在する。素数が有限個 \(p_1, p_2, \ldots, p_k\) しかないと仮定する。\(N = p_1 p_2 \cdots p_k + 1\) を考えると、\(N\) はどの \(p_i\) で割っても 1 余る。一方、2 以上の整数は必ず素因数を持つので、\(N\) の素因数は \(p_1, \ldots, p_k\) 以外の素数である。これは素数が \(p_1, \ldots, p_k\) だけであるという仮定に矛盾する。

数学的帰納法

自然数 \(n\) に関する主張 \(P(n)\) を、次の 2 段階で証明する方法である。

  1. 基底: \(P(0)\)（または \(P(1)\)）が成り立つことを示す。

  2. 帰納段階: \(P(n)\) が成り立つと仮定して、\(P(n + 1)\) が成り立つことを示す。

帰納段階で「\(P(0), P(1), \ldots, P(n)\) が全て成り立つ」と仮定してもよい。これを強い帰納法と呼ぶ。再帰的なアルゴリズムの正しさは、入力サイズに関する帰納法で証明することが多い。

例：\(1 + 2 + \cdots + n = n(n + 1)/2\) である。\(n = 1\) のとき両辺は 1 である。\(n\) で成り立つと仮定すると、

\[1 + 2 + \cdots + n + (n + 1) = \frac{n(n + 1)}{2} + (n + 1) = \frac{(n + 1)(n + 2)}{2}\]

となり、\(n + 1\) でも成り立つ。

対角線論法

対角線論法は、ある集合が「数え上げられない」ことや、ある種の対象が「存在しない」ことを示すための背理法の一種である。

例：自然数から \(\{0, 1\}\) への関数全体の集合 \(F\) は、自然数と 1 対 1 に対応付けられない（非可算である）。対応付けられると仮定し、\(F\) の要素を \(f_0, f_1, f_2, \ldots\) と並べる。ここで関数 \(g\) を \(g(n) = 1 - f_n(n)\) と定義する。\(g\) は \(F\) の要素だが、どの \(f_n\) とも \(n\) での値が異なるため、並べた中に含まれない。これは全ての要素を並べたという仮定に矛盾する。

グラフ

グラフ \(G = (V, E)\) は、頂点の集合 \(V\) と、頂点の組である辺の集合 \(E\) からなる。辺に向きがないグラフを無向グラフ、向きがあるグラフを有向グラフと呼ぶ。辺に数値（重み）が付いたグラフを重み付きグラフと呼ぶ。本書では頂点数を \(|V|\) または \(V\)、辺の数を \(|E|\) または \(E\) と書く。

グラフに関する主な用語を次の表にまとめる。

表 4 グラフの用語

用語

意味

隣接

頂点 \(u\) と \(v\) を結ぶ辺があるとき、\(u\) と \(v\) は隣接するという。

次数

頂点に接続する辺の本数。有向グラフでは入ってくる辺の本数を入次数、出ていく辺の本数を出次数と呼ぶ。

経路

隣接する頂点を順にたどった列 \(v_0, v_1, \ldots, v_k\)。同じ頂点を 2 度通らない経路を単純経路と呼ぶ。

閉路

始点と終点が一致する経路（辺を 1 本以上含むもの）。

連結

無向グラフで、任意の 2 頂点の間に経路があること。

木

連結で閉路を持たない無向グラフ。頂点数が \(n\) の木は辺をちょうど \(n - 1\) 本持つ。

DAG

閉路を持たない有向グラフ（Directed Acyclic Graph）。

無向グラフでは各辺が 2 つの頂点の次数に 1 ずつ寄与するので、全頂点の次数の和は \(2|E|\) に等しい。また、単純なグラフ（同じ頂点の組を結ぶ辺が 1 本以下で、自分自身への辺がないグラフ）では \(|E| \le |V|(|V| - 1)/2\) であり、\(|E| = O(|V|^2)\) となる。

漸近記法

アルゴリズムの効率は、入力サイズ \(n\) に対して実行時間がどのように増えるかで比べる。このとき、定数倍や小さい項の違いを無視して増え方だけに注目するための記法が漸近記法である。

定義

関数 \(f(n)\)、\(g(n)\) を非負の値をとる関数とする。

表 5 漸近記法の定義

記法

定義

直観的な意味

\(f(n) = O(g(n))\)

ある定数 \(c > 0\) と \(n_0\) が存在して、全ての \(n \ge n_0\) で \(f(n) \le c \cdot g(n)\)

\(f\) の増え方は \(g\) 以下

\(f(n) = \Omega(g(n))\)

ある定数 \(c > 0\) と \(n_0\) が存在して、全ての \(n \ge n_0\) で \(f(n) \ge c \cdot g(n)\)

\(f\) の増え方は \(g\) 以上

\(f(n) = \Theta(g(n))\)

\(f(n) = O(g(n))\) かつ \(f(n) = \Omega(g(n))\)

\(f\) と \(g\) の増え方は同じ

ここで「\(=\)」は等号ではなく「属する」という意味で使っている。\(O(g(n))\) を「\(g\) 以下の増え方をする関数全体の集合」と考え、\(f(n) \in O(g(n))\) と書く流儀もある。

例：\(f(n) = 3n^2 + 5n + 7\) とする。\(n \ge 1\) のとき \(f(n) \le 3n^2 + 5n^2 + 7n^2 = 15n^2\) なので、\(c = 15\)、\(n_0 = 1\) とすれば \(f(n) = O(n^2)\) である。また \(f(n) \ge 3n^2\) なので \(f(n) = \Omega(n^2)\) でもあり、合わせて \(f(n) = \Theta(n^2)\) となる。一般に、多項式は最高次の項だけで増え方が決まる。

\(O\) は上界を表すだけなので、\(n = O(n^2)\) も正しい主張である。しかし、アルゴリズムの計算量を述べるときは、できるだけ小さい（きつい）上界を示すのが普通である。

よく現れる関数の増え方

アルゴリズムの解析でよく現れる関数を、増え方の小さい順に並べる。

\[1 \ll \log n \ll \sqrt{n} \ll n \ll n \log n \ll n^2 \ll n^3 \ll 2^n \ll n!\]

ここで \(f \ll g\) は、\(n\) が大きくなると \(f(n)/g(n)\) が 0 に近づくことを表す。具体的な値で比べると違いがよく分かる。

対数と指数の性質

計算量の解析でよく使う性質をまとめる。

  • \(\log (ab) = \log a + \log b\)、\(\log a^k = k \log a\)

  • 底の変換: \(\log_a n = \log_b n / \log_b a\)。底の違いは定数倍なので、\(O(\log_a n) = O(\log_b n)\) である。

  • \(n\) を半分にする操作を繰り返して 1 にするには、約 \(\log_2 n\) 回かかる。二分探索などが \(O(\log n)\) になる理由である。

  • \(\log n! = \Theta(n \log n)\)。これは第 5 章で比較ソートの下界を示すときに使う。

  • 等比級数: \(1 + 2 + 4 + \cdots + 2^k = 2^{k+1} - 1 < 2 \cdot 2^k\)。最後の項の 2 倍未満で抑えられる。

章末のまとめ

  • 集合、関数、関係は、問題や計算の対象を正確に述べるための言葉である。

  • 背理法と数学的帰納法は、アルゴリズムの正しさや問題の性質を示す基本的な道具である。対角線論法は第 10 章で再び使う。

  • 漸近記法は、定数倍を無視して増え方だけを比べる記法である。多項式と指数関数の増え方の差は、計算機の性能向上では埋められないほど大きい。
