第 8 章 有限オートマトンと正規言語

第 3 部では、「計算とは何か」を数学的に定義し、計算で何ができて何ができないかを調べる。そのために、能力を制限した単純な計算モデルから始めて、段階的に強力なモデルへと進む。本章で扱う有限オートマトンは、有限個の状態しか記憶できない最も単純な計算モデルである。単純ではあるが、字句解析、正規表現による検索、通信プロトコルの設計など、実用上の応用は非常に多い。

アルファベット・文字列・言語

計算理論では、計算の問題を「文字列がある集合に属するかどうか」という形で表す。そのための用語を定義する。

  • アルファベット：記号の空でない有限集合。\(\Sigma\) で表すことが多い。例：\(\Sigma = \{0, 1\}\)。

  • 文字列（語）：アルファベットの記号を有限個並べた列。長さ 0 の文字列を空列と呼び、\(\varepsilon\) で表す。文字列 \(w\) の長さを \(|w|\) と書く。

  • \(\Sigma^*\)：\(\Sigma\) 上の文字列全体の集合（空列を含む）。

  • 言語：\(\Sigma^*\) の部分集合。つまり文字列の集合である。

例えば「2 進数として読んだ値が 3 の倍数である文字列の集合」や「\(0\) を \(n\) 個並べた後に \(1\) を \(n\) 個並べた文字列の集合 \(\{0^n 1^n \mid n \ge 0\}\)」は言語である。

「与えられた数は素数か」「与えられたグラフは連結か」といった、答えが「はい」か「いいえ」の問題（判定問題）は、入力を文字列で符号化すれば、「答えが『はい』になる入力の文字列全体」という言語で表せる。こうして「問題を解く」ことは「文字列が言語に属するかを判定する」ことに置き換えられる。

文字列 \(x\) と \(y\) をこの順につなげた文字列を \(xy\) と書き、\(x\) と \(y\) の連接と呼ぶ。言語 \(A\) と \(B\) についても、連接 \(AB = \{xy \mid x \in A, y \in B\}\) と、スター閉包 \(A^* = \{x_1 x_2 \cdots x_k \mid k \ge 0, x_i \in A\}\) を定義する。\(A^*\) は \(A\) の文字列を 0 個以上つなげたもの全体であり、常に空列を含む。

決定性有限オートマトン

決定性有限オートマトン（DFA: Deterministic Finite Automaton）は、次の 5 つ組 \(M = (Q, \Sigma, \delta, q_0, F)\) で定義される。

  • \(Q\)：状態の有限集合

  • \(\Sigma\)：入力アルファベット

  • \(\delta : Q \times \Sigma \to Q\)：遷移関数

  • \(q_0 \in Q\)：開始状態

  • \(F \subseteq Q\)：受理状態の集合

DFA は開始状態 \(q_0\) から始め、入力文字列を先頭から 1 文字ずつ読み、現在の状態 \(q\) と読んだ記号 \(a\) から次の状態 \(\delta(q, a)\) に移る。全ての文字を読み終えたときに受理状態にいれば入力を受理し、そうでなければ拒否する。DFA \(M\) が受理する文字列全体の集合を \(M\) が認識する言語と呼び、\(L(M)\) で表す。DFA で認識できる言語を正規言語と呼ぶ。

DFA は、状態という有限の記憶だけを持ち、入力を一方向に 1 回だけ読む計算機と考えられる。入力の長さに関係なく記憶の量が一定である点が本質的な制約である。

例：3 の倍数を判定する DFA

2 進数として読んだ値が 3 の倍数である文字列を受理する DFA を作る。値そのものを覚えておくことはできないが、「ここまで読んだ値を 3 で割った余り」だけを覚えておけば十分である。値 \(x\) の後ろにビット \(b\) を付けると値は \(2x + b\) になるので、余り \(r\) の状態からビット \(b\) を読んだら、余り \((2r + b) \bmod 3\) の状態に移ればよい。状態を \(q_0, q_1, q_2\)（添字は余り）とし、開始状態と受理状態を \(q_0\) とすると、遷移関数は次の表のようになる。

非決定性有限オートマトン

非決定性有限オートマトン（NFA: Nondeterministic Finite Automaton）は、DFA の遷移関数を次のように緩めたものである。

  • 状態と記号の組に対して、遷移先が 0 個でも複数個でもよい。つまり遷移関数は \(\delta : Q \times (\Sigma \cup \{\varepsilon\}) \to 2^Q\) である。

  • 記号を読まずに状態を移る空列遷移（\(\varepsilon\) 遷移）を許す。

NFA は、遷移先が複数あるときに「全ての可能性を同時に試す」と考える。入力を読み終えたときに、受理状態に至る遷移の選び方が 1 つでもあれば入力を受理する。言い換えると、NFA は「うまい選択を推測する」ことができる計算機である。

例：後ろから 3 文字目が 1 である文字列

アルファベット \(\{0, 1\}\) 上で、後ろから 3 文字目が 1 である文字列を受理する NFA を考える。状態 \(q_0\) で入力を読み進め、1 を読んだときに「これが後ろから 3 文字目だ」と推測したら状態 \(q_1\) に移る。その後、任意の 2 文字を読んで状態 \(q_3\) に至れば受理する。推測が外れた場合（\(q_3\) に達した後にまだ文字が残っている場合）は、遷移先がなくなってその可能性は消える。

この言語を DFA で認識するには、直近の 3 文字を全て覚えておく必要があり、\(2^3 = 8\) 個の状態が必要になる。

部分集合構成法

NFA は DFA より強力に見えるが、認識できる言語の範囲は変わらない。

定理：任意の NFA に対して、同じ言語を認識する DFA が存在する。

証明の考え方：NFA が「ある時点で取りうる状態の集合」を、DFA の 1 つの状態とみなす。NFA の状態集合を \(Q\) とすると、DFA の状態は \(Q\) の部分集合であり、高々 \(2^{|Q|}\) 個しかないので有限である。DFA の開始状態は、NFA の開始状態から空列遷移でたどり着ける状態の集合（\(\varepsilon\) 閉包）とする。DFA の状態 \(S\) から記号 \(a\) で移る先は、\(S\) の各状態から \(a\) で移れる状態を全て集め、その \(\varepsilon\) 閉包をとった集合とする。NFA の受理状態を 1 つでも含む集合を DFA の受理状態とすればよい。この構成を部分集合構成法と呼ぶ。

部分集合構成法では状態数が最大で指数的に増える。上の NFA を変換すると 8 状態の DFA になり、一般に「後ろから \(n\) 文字目が 1」という言語では、\(n + 1\) 状態の NFA に対して DFA は \(2^n\) 状態を必要とする。NFA は DFA と同じ言語しか認識できないが、ずっと簡潔に言語を表せる場合がある。

次のサンプルコードは、DFA と NFA のシミュレータと部分集合構成法を実装したものである。

ch08_dfa_nfa.py

リスト 17 ch08_dfa_nfa.py
  1"""第 8 章: DFA と NFA のシミュレータ、および部分集合構成法。
  2
  3* DFA: 決定性有限オートマトン。各状態と入力記号に対し遷移先がちょうど 1 つ。
  4* NFA: 非決定性有限オートマトン。遷移先は状態の集合で、空列 (EPS) による
  5  遷移も許す。
  6* subset_construction: NFA を、同じ言語を受理する DFA に変換する。
  7
  8実行例::
  9
 10    python ch08_dfa_nfa.py
 11"""
 12
 13from __future__ import annotations
 14
 15from dataclasses import dataclass
 16
 17EPS = ""  # 空列による遷移を表す記号
 18
 19
 20@dataclass(frozen=True)
 21class DFA:
 22    """決定性有限オートマトン。状態は任意のハッシュ可能な値で表す。"""
 23
 24    states: frozenset[object]
 25    alphabet: frozenset[str]
 26    delta: dict[tuple[object, str], object]
 27    start: object
 28    accepting: frozenset[object]
 29
 30    def accepts(self, word: str) -> bool:
 31        """word を先頭から 1 文字ずつ読み、受理状態で終われば True。"""
 32        state = self.start
 33        for symbol in word:
 34            state = self.delta[(state, symbol)]
 35        return state in self.accepting
 36
 37
 38@dataclass(frozen=True)
 39class NFA:
 40    """空列遷移付き非決定性有限オートマトン。"""
 41
 42    states: frozenset[object]
 43    alphabet: frozenset[str]
 44    delta: dict[tuple[object, str], frozenset[object]]
 45    start: object
 46    accepting: frozenset[object]
 47
 48    def eps_closure(self, states: frozenset[object]) -> frozenset[object]:
 49        """states から空列遷移だけでたどり着ける状態の集合を返す。"""
 50        closure = set(states)
 51        stack = list(states)
 52        while stack:
 53            q = stack.pop()
 54            for r in self.delta.get((q, EPS), frozenset()):
 55                if r not in closure:
 56                    closure.add(r)
 57                    stack.append(r)
 58        return frozenset(closure)
 59
 60    def step(self, states: frozenset[object],
 61             symbol: str) -> frozenset[object]:
 62        """現在の状態集合から symbol を読んだ後の状態集合を返す。"""
 63        moved: set[object] = set()
 64        for q in states:
 65            moved |= self.delta.get((q, symbol), frozenset())
 66        return self.eps_closure(frozenset(moved))
 67
 68    def accepts(self, word: str) -> bool:
 69        """取りうる状態をすべて同時に追跡し、受理状態を含めば True。"""
 70        current = self.eps_closure(frozenset({self.start}))
 71        for symbol in word:
 72            current = self.step(current, symbol)
 73        return bool(current & self.accepting)
 74
 75
 76def subset_construction(nfa: NFA) -> DFA:
 77    """NFA の状態の集合を DFA の 1 つの状態とみなして DFA を作る。"""
 78    start = nfa.eps_closure(frozenset({nfa.start}))
 79    delta: dict[tuple[object, str], object] = {}
 80    seen = {start}
 81    stack = [start]
 82    while stack:  # 開始状態から到達できる状態集合だけを作る
 83        current = stack.pop()
 84        for symbol in sorted(nfa.alphabet):
 85            target = nfa.step(current, symbol)
 86            delta[(current, symbol)] = target
 87            if target not in seen:
 88                seen.add(target)
 89                stack.append(target)
 90    accepting = frozenset(s for s in seen if s & nfa.accepting)
 91    return DFA(frozenset(seen), nfa.alphabet, delta, start,
 92               frozenset(accepting))
 93
 94
 95def divisible_by_3_dfa() -> DFA:
 96    """2 進数として読んだ値が 3 の倍数である文字列を受理する DFA。
 97
 98    状態 r は「ここまで読んだ値を 3 で割った余りが r」であることを表す。
 99    値 x の後ろに 1 ビット b を付けると値は 2x + b になる。
100    """
101    delta: dict[tuple[object, str], object] = {}
102    for r in range(3):
103        for b in "01":
104            delta[(r, b)] = (2 * r + int(b)) % 3
105    return DFA(frozenset({0, 1, 2}), frozenset("01"), delta, 0,
106               frozenset({0}))
107
108
109def third_from_last_is_1_nfa() -> NFA:
110    """後ろから 3 文字目が 1 である 0/1 の文字列を受理する NFA。
111
112    状態 0 で読み進め、「ここが後ろから 3 文字目だ」と推測した 1 で
113    状態 1 に移り、残り 2 文字を読んで受理状態 3 に至る。
114    """
115    delta: dict[tuple[object, str], frozenset[object]] = {
116        (0, "0"): frozenset({0}),
117        (0, "1"): frozenset({0, 1}),
118        (1, "0"): frozenset({2}),
119        (1, "1"): frozenset({2}),
120        (2, "0"): frozenset({3}),
121        (2, "1"): frozenset({3}),
122    }
123    return NFA(frozenset({0, 1, 2, 3}), frozenset("01"), delta, 0,
124               frozenset({3}))
125
126
127def main() -> None:
128    dfa = divisible_by_3_dfa()
129    for n in range(10):
130        word = format(n, "b")
131        print(f"{word:>4} ({n}): {'受理' if dfa.accepts(word) else '拒否'}")
132
133    nfa = third_from_last_is_1_nfa()
134    converted = subset_construction(nfa)
135    print("NFA の状態数:", len(nfa.states))
136    print("変換後の DFA の状態数:", len(converted.states))
137    for word in ["100", "0100", "1011", "0011", "11"]:
138        print(f"{word}: NFA {nfa.accepts(word)},"
139              f" DFA {converted.accepts(word)}")
140

143    main()

正規表現

正規表現は、言語を式で表す方法である。アルファベット \(\Sigma\) 上の正規表現とそれが表す言語を、次のように帰納的に定義する。

表 20 正規表現の定義

例えば \((0 \mid 1)^* 1 (0 \mid 1)(0 \mid 1)\) は、後ろから 3 文字目が 1 である文字列全体を表す。

定理（クリーネの定理）：言語が正規表現で表せることと、有限オートマトンで認識できることは同値である。

正規表現から NFA を作るには、正規表現の構造に沿って、和集合・連接・スター閉包のそれぞれに対応する NFA を空列遷移でつなぎ合わせればよい（トンプソンの構成法）。逆に有限オートマトンから正規表現を作るには、状態を 1 つずつ取り除きながら、遷移のラベルを正規表現で置き換えていけばよい。

Python の re モジュールとの関係

Python の re モジュールなどで使われる正規表現は、上で定義した理論上の正規表現を拡張したものである。+ や ?、[a-z]、{2,5} などは理論上の正規表現の略記にすぎないが、後方参照（(a+)b\1 のように、前にマッチした文字列と同じものを要求する機能）は正規言語の範囲を超える。例えば (.*)\1 は「同じ文字列を 2 回繰り返した文字列」を表すが、この言語は正規言語ではない。

また、Python の re モジュールは、NFA の可能性を 1 つずつ試すバックトラッキングで実装されている。そのため、(a+)+b のような正規表現に aaaa...a（b を含まない長い文字列）を与えると、試す可能性が指数的に増えて処理が終わらなくなる。これは ReDoS（Regular expression Denial of Service）と呼ばれる脆弱性の原因になる。部分集合構成法のように状態の集合を追跡する方式で実装すれば、入力の長さに比例する時間で照合できる。Go 言語の regexp パッケージや Google の RE2 ライブラリはこの方式を採用している。

正規言語の性質

閉包性

正規言語は、次の演算について閉じている。つまり、正規言語に次の演算を施した結果もまた正規言語である。

  • 和集合、連接、スター閉包：正規表現の定義から明らか。

  • 補集合：DFA の受理状態と非受理状態を入れ替えればよい。

  • 共通部分：\(A \cap B = \overline{\overline{A} \cup \overline{B}}\)（ド・モルガンの法則）から従う。2 つの DFA を同時に動かす直積構成で直接作ることもできる。

閉包性は、ある言語が正規であることを示したり、次に述べるポンピング補題と組み合わせて正規でないことを示したりするのに使える。

ポンピング補題

有限オートマトンは有限個の状態しか持たないので、「\(0\) の個数と \(1\) の個数が等しい」のような、際限なく数を数える必要がある言語は認識できないと予想される。これを厳密に示す道具がポンピング補題である。

補題（正規言語のポンピング補題）：\(L\) が正規言語ならば、ある正の整数 \(p\) が存在して、長さが \(p\) 以上の任意の \(w \in L\) は、次の 3 条件を満たすように \(w = xyz\) と分割できる。

  1. 全ての \(i \ge 0\) について \(x y^i z \in L\)

  2. \(|y| \ge 1\)

  3. \(|xy| \le p\)

証明：\(L\) を認識する DFA の状態数を \(p\) とする。長さ \(n \ge p\) の文字列 \(w \in L\) を読むとき、DFA は開始状態を含めて \(n + 1\) 個の状態を順に通る。最初の \(p + 1\) 個の状態の中には、鳩の巣原理により同じ状態が 2 回現れる。その 2 回の間に読んだ部分を \(y\)、それより前を \(x\)、後ろを \(z\) とすると、\(y\) を読む間に DFA は同じ状態に戻ってくるので、\(y\) を何回繰り返しても（0 回でも）最後の状態は変わらず、受理される。同じ状態が現れる 2 つの位置は異なるので \(|y| \ge 1\) であり、最初の \(p + 1\) 個の状態の中で見つけたので \(|xy| \le p\) である。

例：\(L = \{0^n 1^n \mid n \ge 0\}\) は正規言語ではない。\(L\) が正規言語であると仮定し、ポンピング補題の定数を \(p\) とする。\(w = 0^p 1^p \in L\) を考えると、条件 3 より \(xy\) は先頭の \(p\) 文字の中に収まるので、\(y\) は \(0\) だけからなる。条件 2 より \(y\) は 1 文字以上なので、\(xy^2z\) は \(0\) の個数が \(1\) の個数より多くなり、\(L\) に属さない。これは条件 1 に矛盾する。

同様にして、「対応のとれた括弧の列」も正規言語でないことが示せる。そのため、正規表現だけでは HTML やプログラミング言語の入れ子構造を正しく解析できない。入れ子構造を扱うには、第 9 章の文脈自由文法が必要になる。

応用：文字列照合と KMP 法

テキストの中からパターンが現れる位置を全て見つける問題を文字列照合と呼ぶ。素朴な方法では、テキストの各位置からパターンとの比較を始め、不一致があれば次の位置からやり直す。テキストの長さを \(n\)、パターンの長さを \(m\) とすると、最悪 \(O(nm)\) 時間かかる。

パターン \(P\) で終わる文字列全体の言語 \(\Sigma^* P\) は正規言語である。これを認識する DFA にテキストを読ませると、受理状態に入るのはちょうどパターンの出現が終わる位置なので、テキストを 1 回走査するだけで全ての出現位置が分かる。KMP 法（クヌース-モリス-プラット法）は、この DFA を \(O(m)\) 時間で前計算できるコンパクトな形で表したものである。

KMP 法では、パターンの各位置 \(i\) について、\(P[0..i]\) の真の接頭辞（それ自身を除く接頭辞）であって接尾辞でもあるもののうち最長のものの長さ fail[i] を前計算する（失敗関数）。照合中に不一致が起きたら、テキスト側は戻らずに、パターン側の位置だけを失敗関数に従って戻す。既に一致した部分の情報を捨てずに再利用するため、テキストの各文字は定数回（償却）しか比較されず、全体の計算量は \(O(n + m)\) になる。

16def failure_function(pattern: str) -> list[int]:
17    """fail[i] は pattern[:i + 1] の、真の接頭辞かつ接尾辞である最長の長さ。"""
18    fail = [0] * len(pattern)
19    k = 0  # 現在一致している接頭辞の長さ
20    for i in range(1, len(pattern)):
21        while k > 0 and pattern[i] != pattern[k]:
22            k = fail[k - 1]
23        if pattern[i] == pattern[k]:
24            k += 1

29def kmp_search(text: str, pattern: str) -> list[int]:
30    """text の中で pattern が現れる開始位置をすべて返す。"""
31    if not pattern:
32        return list(range(len(text) + 1))
33    fail = failure_function(pattern)
34    positions: list[int] = []
35    k = 0
36    for i, ch in enumerate(text):
37        while k > 0 and ch != pattern[k]:
38            k = fail[k - 1]  # テキスト側は戻らず、パターン側だけ戻る
39        if ch == pattern[k]:
40            k += 1
41        if k == len(pattern):

43            k = fail[k - 1]
44    return positions

章末のまとめ

  • 判定問題は、「答えが『はい』になる入力の文字列全体」という言語で表せる。

  • DFA と NFA は同じ言語のクラス（正規言語）を認識する。NFA から DFA への変換では、状態数が指数的に増えることがある。

  • 正規表現と有限オートマトンは等価である。実用の正規表現エンジンには、理論上の正規表現を超える機能や、バックトラッキングによる性能上の問題がある。

  • ポンピング補題を使うと、\(\{0^n 1^n\}\) のような言語が正規言語でないことを示せる。
