第 1 章 はじめに

本書の目的

ソフトウェア開発の現場では、ライブラリを組み合わせれば多くの問題が解ける。それでも、データが増えた途端に処理が終わらなくなったり、どう工夫しても速くならない問題に出会ったりすることがある。そのようなとき、次の 2 つの問いに答えられるかどうかで、取るべき行動が大きく変わる。

  • この問題を解く、より効率のよい方法はあるか。

  • そもそもこの問題は、効率よく解ける（あるいは計算機で解ける）問題なのか。

前者に答えるのがアルゴリズムの知識であり、後者に答えるのが計算理論の知識である。本書はこの 2 つを 1 冊で通して学べるように構成した。アルゴリズムの章で身につけた道具（動的計画法、グラフ探索、バックトラッキングなど）が計算理論の章で再び登場するため、両者のつながりを意識しながら読み進めてほしい。

対象読者と前提知識

本書は次のような読者を想定している。

  • Python などのプログラミング言語で、関数・リスト・辞書・クラスを使ったプログラムを書ける。

  • 高校程度の数学（式の変形、数列、指数・対数）に抵抗がない。

大学の情報系の講義で扱う離散数学の知識は前提としない。必要な数学は「第 2 章 数学的準備」でまとめて説明する。

サンプルコードについて

各章のサンプルコードは本文に掲載しており、ファイルとしてダウンロードすることもできる。全ファイルの一覧は「サンプルコード一覧」にある。サンプルコードは次の方針で書いている。

  • Python 3.10 以上の標準ライブラリだけで動作する。

  • 全ての関数に型ヒントを付け、flake8 と mypy（--strict オプション付き）で違反が出ないことを確認している。

  • 各ファイルは単独で実行でき、実行すると動作例を表示する。

例えば第 5 章のサンプルコードは、次のように実行する。

1$ python ch05_sorting.py
2insertion_sort: True
3merge_sort    : True
4...

サンプルコードは理解しやすさを優先しており、実用上の速度や入力の検査は最小限にとどめている。実務では、標準ライブラリや定評のあるライブラリの実装を使うのがよい。

表記について

本書では次の表記を用いる。

  • 用語の初出は太字で示す。主な用語は「用語集」にまとめた。

  • 数式で使う記号は「記号一覧」にまとめた。

  • 対数 \(\log n\) の底は、特に断らない限り 2 とする。漸近記法の中では底の違いは定数倍の差にしかならないため、底を省略する。

  • 本文中のコード例には行番号を付ける。
