第 10 章 チューリング機械と計算可能性

有限オートマトンは記憶が有限であり、PDA はスタックの先頭しか見られないという制約があった。本章で扱うチューリング機械は、読み書き自由な無限のテープを持つ計算モデルであり、現在の計算機で実行できるあらゆる計算を表現できると考えられている。そのチューリング機械をもってしても解けない問題が存在することを示すのが、本章の目標である。

チューリング機械

定義

チューリング機械（TM: Turing Machine）は、右方向に無限に続くテープと、テープ上の 1 マスを指すヘッド、有限個の状態を持つ制御部からなる。テープの各マスには記号が 1 つ書かれており、最初は入力文字列が左端から書かれ、残りのマスは空白記号 \(\sqcup\) で埋められている。

チューリング機械は、次の 7 つ組 \(M = (Q, \Sigma, \Gamma, \delta, q_0, q_{\mathrm{accept}}, q_{\mathrm{reject}})\) で定義される。

  • \(Q\)：状態の有限集合

  • \(\Sigma\)：入力アルファベット（空白記号を含まない）

  • \(\Gamma\)：テープアルファベット（\(\Sigma \subseteq \Gamma\)、\(\sqcup \in \Gamma\)）

  • \(\delta : Q \times \Gamma \to Q \times \Gamma \times \{L, R\}\)：遷移関数

  • \(q_0\)：開始状態

  • \(q_{\mathrm{accept}}\)：受理状態、\(q_{\mathrm{reject}}\)：拒否状態

各ステップで、チューリング機械は現在の状態 \(q\) とヘッドの位置の記号 \(a\) から \(\delta(q, a) = (q', b, D)\) を求め、ヘッドの位置に \(b\) を書き、状態を \(q'\) に変え、ヘッドを \(D\) の方向（\(L\) なら左、\(R\) なら右）に 1 マス動かす。ただし、テープの左端で左に動こうとした場合はその場にとどまる。受理状態または拒否状態に入ったら停止する。

有限オートマトンとの違いは、次の 3 点である。

  • テープに書き込める。

  • ヘッドを左右に動かせる（入力を何度でも読み直せる）。

  • テープは無限に長く、受理状態や拒否状態に入れば入力を読み終えていなくても停止する。逆に、いつまでも停止しないこともある。

最後の点が重要である。チューリング機械の入力に対する振る舞いは、「受理して停止する」「拒否して停止する」「停止しない（無限ループ）」の 3 通りがある。

例：\(\{0^n 1^n\}\) を判定するチューリング機械

 2
 3遷移関数は (状態, 読んだ記号) -> (次の状態, 書く記号, ヘッドの移動) の辞書で
 4与える。遷移が定義されていない組に出会ったら拒否状態に移ったものとみなす。
 5
 6例として、言語 { 0^n 1^n | n >= 0 } を判定する機械を動かす。
 7
 8実行例::
 9
10    python ch10_turing_machine.py
11"""
12
13from __future__ import annotations
14
15from dataclasses import dataclass, field
16
17BLANK = "_"
18ACCEPT = "q_accept"
19REJECT = "q_reject"
20
21Transition = dict[tuple[str, str], tuple[str, str, str]]
22
23
24@dataclass
25class TuringMachine:
26    """1 テープ決定性チューリング機械。移動は "L" (左) か "R" (右)。"""
27
28    delta: Transition
29    start: str
30    tape: dict[int, str] = field(default_factory=dict)
31    head: int = 0
32    state: str = ""
33
34    def run(self, word: str, max_steps: int = 10_000,
35            trace: bool = False) -> bool:
36        """word を入力として動かし、受理なら True、拒否なら False を返す。"""
37        self.tape = dict(enumerate(word))  # 書かれていないマスは空白
38        self.head = 0
39        self.state = self.start
40        for _ in range(max_steps):
41            if trace:
42                print(self.snapshot())
43            if self.state in (ACCEPT, REJECT):
44                return self.state == ACCEPT
45            symbol = self.tape.get(self.head, BLANK)
46            key = (self.state, symbol)
47            if key not in self.delta:
48                self.state = REJECT
49                continue
50            self.state, written, move = self.delta[key]
51            self.tape[self.head] = written
52            self.head += 1 if move == "R" else -1
53            self.head = max(self.head, 0)  # 左端より左には動かない
54        raise RuntimeError(f"{max_steps} ステップ以内に停止しなかった")
55
56    def snapshot(self) -> str:
57        """現在の様相 (テープの内容、状態、ヘッド位置) を文字列にする。"""
58        right = max([self.head, *self.tape.keys()]) + 1
59        cells = [self.tape.get(i, BLANK) for i in range(right + 1)]
60        cells.insert(self.head, f"[{self.state}]")
61        return " ".join(cells)
62
63

67    ("q0", "Y"): ("q3", "Y", "R"),     # 0 が残っていなければ検査へ
68    ("q0", BLANK): (ACCEPT, BLANK, "R"),  # 空列 (n = 0)
69    ("q1", "0"): ("q1", "0", "R"),     # 右へ進んで最初の 1 を探す
70    ("q1", "Y"): ("q1", "Y", "R"),
71    ("q1", "1"): ("q2", "Y", "L"),     # 対応する 1 を Y にする
72    ("q2", "0"): ("q2", "0", "L"),     # 左へ戻る
73    ("q2", "Y"): ("q2", "Y", "L"),
74    ("q2", "X"): ("q0", "X", "R"),     # X の右隣から繰り返す
75    ("q3", "Y"): ("q3", "Y", "R"),     # 残りが Y だけか確かめる

チューリング機械の変種とチャーチ-チューリングのテーゼ

チューリング機械には、次のような多くの変種がある。

  • 多テープチューリング機械：複数のテープとヘッドを持つ。

  • 非決定性チューリング機械：遷移先が複数あってよく、受理に至る遷移の選び方が 1 つでもあれば受理する。

  • テープが左右両方向に無限に続くもの、ヘッドがその場にとどまれるもの、など。

これらは全て、認識できる言語の範囲という意味で、1 テープの決定性チューリング機械と等価であることが証明されている。例えば \(k\) 本のテープの内容は、1 本のテープに区切り記号を挟んで並べて書けば模倣できる。非決定性チューリング機械は、計算の分岐を幅優先で 1 つずつ調べる決定性チューリング機械で模倣できる。ただし、模倣には時間がかかる。多テープの機械の \(t\) ステップは 1 テープの機械の \(O(t^2)\) ステップで模倣できるが、非決定性の機械の模倣には、知られている方法では指数的な時間がかかる。この時間の差が第 11 章の主題になる。

さらに、RAM モデル、ラムダ計算、Python などのプログラミング言語（無限のメモリがあると仮定したもの）も、チューリング機械と同じ計算能力を持つことが示されている。これらの事実から、次の主張が広く受け入れられている。

チャーチ-チューリングのテーゼ：直観的な意味で「アルゴリズムで計算できる」ことは、チューリング機械で計算できることと一致する。

これは「直観的な意味でのアルゴリズム」という数学的に定義されていない概念についての主張なので、定理ではなく証明もできない。しかし反例は見つかっておらず、本書でもこのテーゼを認めて、「チューリング機械で解ける」ことと「Python のプログラムで解ける」ことを同一視する。

万能チューリング機械

チューリング機械の定義（状態、遷移関数など）は有限の情報なので、文字列として符号化できる。チューリング機械 \(M\) の符号を \(\langle M \rangle\) と書く。\(\langle M \rangle\) と入力 \(w\) を受け取り、\(M\) が \(w\) に対して行う動作を模倣するチューリング機械を万能チューリング機械と呼ぶ。上のサンプルコードの TuringMachine クラスは、遷移関数を受け取って任意のチューリング機械を模倣するので、万能チューリング機械の考え方を Python で実現したものである。

万能チューリング機械は、プログラムをデータとして受け取って実行する計算機、つまりプログラム内蔵方式の計算機や、Python のインタプリタの理論的な原型である。プログラムをデータとして扱えることは、次節以降の決定不能性の証明でも本質的な役割を果たす。

決定可能言語と認識可能言語

チューリング機械は停止しないことがあるので、言語を「解く」ことについて 2 つの水準を区別する。

  • 言語 \(L\) について、\(L\) に属する入力を受理し、属さない入力では拒否するか停止しないチューリング機械が存在するとき、\(L\) は認識可能（帰納的可算）であるという。

  • 言語 \(L\) について、\(L\) に属する入力を受理し、属さない入力を拒否し、全ての入力で停止するチューリング機械が存在するとき、\(L\) は決定可能（帰納的）であるという。このチューリング機械を \(L\) の判定器と呼ぶ。

決定可能でない言語を決定不能であるという。決定可能な言語は認識可能である。また、次の定理が成り立つ。

定理：言語 \(L\) が決定可能であることと、\(L\) とその補集合 \(\overline{L}\) がともに認識可能であることは同値である。

証明の考え方：\(L\) と \(\overline{L}\) の認識器を交互に 1 ステップずつ動かす。任意の入力はどちらか一方に属するので、どちらかの認識器が必ず受理して停止する。\(L\) の認識器が受理したら受理し、\(\overline{L}\) の認識器が受理したら拒否すればよい。

停止問題

チューリング機械 \(M\) と入力 \(w\) の組で、\(M\) が \(w\) に対して停止するもの全体の言語を考える。

\[\mathit{HALT} = \{\langle M, w \rangle \mid M \text{ は入力 } w \text{ に対して停止する}\}\]

\(\mathit{HALT}\) に属するかを判定する問題を停止問題と呼ぶ。\(\mathit{HALT}\) は認識可能である。万能チューリング機械で \(M\) を \(w\) に対して動かし、停止したら受理すればよい。しかし決定可能ではない。

定理：停止問題は決定不能である。

証明：停止問題の判定器 \(H\) が存在すると仮定する。\(H\) は任意の \(\langle M, w \rangle\) に対して停止し、\(M\) が \(w\) に対して停止するなら受理、停止しないなら拒否する。\(H\) を使って、次のように動くチューリング機械 \(D\) を作る。

  1. 入力 \(\langle M \rangle\) を受け取る。

  2. \(H\) を \(\langle M, \langle M \rangle \rangle\) に対して動かす（\(M\) に自分自身の符号を入力したら停止するかを調べる）。

  3. \(H\) が受理したら無限ループに入る。\(H\) が拒否したら停止する。

\(D\) に自分自身の符号 \(\langle D \rangle\) を入力したとする。\(D\) が \(\langle D \rangle\) に対して停止するなら、\(H\) は受理するので、\(D\) は無限ループに入り停止しない。\(D\) が \(\langle D \rangle\) に対して停止しないなら、\(H\) は拒否するので、\(D\) は停止する。どちらの場合も矛盾が生じるので、\(H\) は存在しない。

この証明は第 2 章の対角線論法そのものである。行にチューリング機械 \(M_1, M_2, \ldots\) を、列に入力 \(\langle M_1 \rangle, \langle M_2 \rangle, \ldots\) を並べ、\(M_i\) が \(\langle M_j \rangle\) に対して停止するかを表にすると、\(D\) の振る舞いは対角成分を反転させたものになり、表のどの行とも一致しない。

Python で表すと次のようになる。もし halts 関数が実装できたとすると、paradox(paradox) が停止するかどうかについて矛盾が生じる。

停止問題が決定不能であることの帰結として、\(\overline{\mathit{HALT}}\)（停止しない組の言語）は認識可能でもない。\(\mathit{HALT}\) は認識可能なので、もし \(\overline{\mathit{HALT}}\) も認識可能なら、前節の定理により \(\mathit{HALT}\) は決定可能になってしまうからである。

還元とライスの定理

還元

ある問題が決定不能であることが分かると、それを使って他の問題の決定不能性を示せる。問題 \(A\) の任意の入力 \(x\) を、問題 \(B\) の入力 \(f(x)\) に変換する計算可能な関数 \(f\) があり、\(x \in A \iff f(x) \in B\) が成り立つとき、\(A\) は \(B\) に還元できるといい、\(A \le_m B\) と書く（写像還元）。

\(A \le_m B\) のとき、\(B\) が決定可能なら \(A\) も決定可能である（\(x\) を \(f(x)\) に変換して \(B\) の判定器にかければよい）。対偶をとると、\(A\) が決定不能なら \(B\) も決定不能である。還元は「\(B\) は \(A\) と同じくらい難しい」ことを示す道具であり、第 11 章では計算時間を制限した還元を使って NP 完全性を定義する。

例：空テープ停止問題（チューリング機械 \(M\) が空の入力に対して停止するか）は決定不能である。\(\langle M, w \rangle\) から、「入力を無視して、テープに \(w\) を書いてから \(M\) を模倣する」チューリング機械 \(M_w\) を作る変換 \(f\) を考える。\(M_w\) が空の入力に対して停止することと、\(M\) が \(w\) に対して停止することは同値なので、これは \(\mathit{HALT}\) から空テープ停止問題への還元である。

ライスの定理

還元を一般化すると、次の強力な定理が得られる。

定理（ライスの定理）：チューリング機械が認識する言語についての性質 \(P\) が非自明（\(P\) を満たす認識可能言語と満たさない認識可能言語がともに存在する）ならば、「与えられたチューリング機械 \(M\) が認識する言語 \(L(M)\) が性質 \(P\) を満たすか」を判定する問題は決定不能である。

例えば、「プログラムが空でない言語を認識するか」「プログラムが全ての入力に対して特定の出力を返すか」「プログラムが受理する入力は有限個か」といった、プログラムの振る舞いに関する非自明な性質は、全て決定不能である。

これは、静的解析ツールが完全には作れないことを意味する。バグ検出ツールやコンパイラの最適化は、決定不能な問題に対して「確実に分かる場合だけ答える」「誤検出を許す」などの妥協をして作られている。一方、「プログラムの文字数が 100 文字以下か」のような、振る舞いではなくプログラムの記述そのものに関する性質は、ライスの定理の対象外である。

チョムスキーが提唱した 4 つの文法のクラス（句構造文法、文脈依存文法、文脈自由文法、正規文法）による階層をチョムスキー階層と呼ぶ。上の表は、これに決定可能言語を加えたものである。線形有界オートマトンは、テープの長さが入力の長さに制限されたチューリング機械であり、文脈依存言語は全て決定可能である。

それぞれの境界には、本書で扱った例がある。

  • \(\{0^n 1^n\}\) は文脈自由言語だが正規言語ではない（第 8 章）。

  • \(\{a^n b^n c^n\}\) は文脈依存言語（したがって決定可能）だが文脈自由言語ではない（第 9 章）。

  • \(\mathit{HALT}\) は認識可能だが決定可能ではない（本章）。

  • \(\overline{\mathit{HALT}}\) は認識可能ですらない（本章）。

章末のまとめ

  • チューリング機械は、無限のテープを読み書きできる計算モデルである。多くの変種やプログラミング言語と計算能力が等しく、チャーチ-チューリングのテーゼにより「アルゴリズムで計算できる」ことの定義とみなされている。

  • 停止問題は決定不能である。証明には対角線論法を使う。

  • 還元を使うと、決定不能性を他の問題に伝えられる。ライスの定理により、プログラムの振る舞いに関する非自明な性質は全て決定不能である。
