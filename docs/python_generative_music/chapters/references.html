関連するその他のツール

本資料では扱いませんでしたが、ジェネラティブミュージックの制作に利用できるツールとして、以下のようなものも存在します。興味を持った場合は、それぞれの公式サイトを参照してください。

  • Sonic Pi: Ruby ライクな文法でライブコーディングを行える音楽制作環境。

  • FoxDot: Python 上で動作するライブコーディング用のライブラリ。

  • SuperCollider: 音響合成とアルゴリズム作曲のためのプログラミング言語および実行環境。
