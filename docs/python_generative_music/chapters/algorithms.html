アルゴリズム作曲の手法

本章では、ジェネラティブミュージックで用いられる代表的なアルゴリズム作曲の手法について説明します。

乱数を用いた手法

もっとも単純な手法は、乱数を用いて音の高さやリズムを決定する方法です。 random モジュールや numpy.random を用いることで、指定した音階の範囲からランダムに音を選択することができます。単純な乱数のみでは無秩序な音の並びになりやすいため、多くの場合はスケール（ 音階 ）や拍の長さの候補をあらかじめ制限した上で使用します。

マルコフ連鎖

マルコフ連鎖は、現在の状態から次の状態へ遷移する確率に基づいて、系列を生成する手法です。音楽生成では、ある音の後にどの音が続きやすいかという遷移確率を、既存の楽曲データから学習し、その確率に従って新しい旋律を生成します。以下は、簡易的なマルコフ連鎖による旋律生成の例です。

import random

transition_table = {
    60: [62, 64],
    62: [60, 64, 65],
    64: [62, 65, 67],
    65: [64, 67],
    67: [65, 69, 72],
    69: [67, 72],
    72: [69, 67],
}

current_note = 60
melody = [current_note]

for _ in range(15):
    next_note = random.choice(transition_table[current_note])
    melody.append(next_note)
    current_note = next_note

print(melody)

このコードでは、各音符から遷移しうる次の音符の候補を辞書で定義し、その候補の中から乱数を用いて次の音を選択しています。

セル・オートマトン

セル・オートマトンは、格子状に並んだセルが、あらかじめ定められた規則に従って世代ごとに状態を変化させる計算モデルです。有名な例として、コンウェイのライフゲーム（ Conway's Game of Life ）が挙げられます。ジェネラティブミュージックでは、セル・オートマトンの各セルの状態を音の高さやリズムに対応させることで、世代の変化を音楽として表現します。

L システム

L システム（ Lindenmayer System ）は、文字列の書き換え規則を繰り返し適用することで、植物の成長のようなフラクタル構造を生成する仕組みです。生成された文字列の各記号を、音の高さや長さ、休符などに対応させることで、自己相似的な構造を持つ旋律を生成することができます。

ユークリッドリズム

ここまでに紹介した手法は、主に音の高さの並びを生成する手法でした。ここからは、リズムパターンを生成する手法として、ユークリッドリズムを紹介します。ユークリッドリズムは、 Godfried Toussaint が提唱した手法で、指定した拍数（ パルス数 ）を、指定したステップ数の中へできるだけ均等に配置するというものです。たとえば、 8 ステップの中に 3 拍を均等に配置すると「 x..x..x. 」（ x が拍のあるステップ、 . が拍のないステップを表す ）という、キューバ音楽などで知られるトレシージョに近いリズムパターンが得られます。同様に、 8 ステップの中に 5 拍を配置すると「 x.xx.xx. 」というシンキーヨと呼ばれるリズムに近いパターンが得られます。

この配置は、 Bjorklund のアルゴリズムと呼ばれる手法によって計算することができます。 Bjorklund のアルゴリズムは、パルスを表すグループと、休符を表すグループを、余りがなくなるまで再帰的にペアにしていくことで、拍を均等に分散させます。単純な乱数による生成とは異なり、少ないパラメータ（ パルス数とステップ数 ）から、規則性と複雑さを兼ね備えたリズムパターンを得られる点が特徴です。具体的な実装は、次章の「実装例」で紹介します。

手法の組み合わせ

実際のジェネラティブミュージックの制作では、これらの手法を単独で用いるだけでなく、複数の手法を組み合わせることも多くあります。たとえば、マルコフ連鎖で旋律の骨格を生成し、乱数によってリズムに変化を加えるといった方法が考えられます。
