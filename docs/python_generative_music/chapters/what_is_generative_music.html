ジェネラティブミュージックとは

ジェネラティブミュージックとは、規則やアルゴリズム、確率、外部からの入力データなどを用いて、演奏のたびに異なる結果を生み出しうる音楽のことです。作曲者はすべての音を直接指定するのではなく、音楽を生成するための「仕組み」を設計します。

歴史的な背景

ジェネラティブミュージックの考え方自体は新しいものではなく、サイコロを使って旋律を組み立てる 18 世紀の作曲技法や、確率を用いた現代音楽の作曲手法にもその源流を見ることができます。近年ではコンピューターの計算能力の向上により、リアルタイムで複雑な音楽を生成することが容易になりました。作曲家のブライアン・イーノ（ Brian Eno ）が発表したアンビエント作品は、ジェネラティブミュージックを広く知らしめた代表例として知られています。

代表的な生成手法

ジェネラティブミュージックには、さまざまな生成手法が存在します。

  • 確率的手法： サイコロや乱数を用いて、音の高さやリズムを確率的に決定する手法です。

  • マルコフ連鎖： 過去の音の並びから次の音が出現する確率を計算し、それに基づいて旋律を生成する手法です。

  • セル・オートマトン： セル・オートマトンの状態遷移を、音の高さやリズムに変換する手法です。

  • L システム： 植物の成長を模したフラクタル生成規則を、旋律やリズムパターンの生成に応用する手法です。

  • ユークリッドリズム： 指定した拍数をステップ数の中へ均等に配置し、リズムパターンを生成する手法です。

音楽理論の基礎用語

前述の生成手法の多くは、無秩序な音の並びを避けるため、音楽理論上の枠組みの中で音を選択します。以降の章にもたびたび登場する基本用語を、ここで簡単に説明します。

  • スケール（ 音階 ）： 一定の規則に従って選び出した音の集合です。たとえば、「実装例」の章で紹介するハ長調のメジャースケールは、もっとも基本的なスケールの一つです。

  • 調（ 調性 ）： 楽曲の基準となる音（ 主音 ）と、それに基づくスケールの組み合わせです。主音を変えることで、同じ種類のスケールからでも異なる調が得られます。

  • 和音（ コード ）： 高さの異なる複数の音を同時に鳴らしたものです。

  • コード進行： 和音を時間軸に沿って並べたもので、楽曲の雰囲気や展開の土台となります。

本資料で紹介する実装例は旋律やリズムの生成が中心であり、和音やコード進行を直接生成するものではありませんが、「主要な Python ライブラリ」の章で紹介する music21 を用いると、これらの概念に基づいた解析や生成を行うことも可能です。

Python がジェネラティブミュージックに適している理由

Python は文法が平易であり、数値計算やデータ処理のためのライブラリが充実しています。加えて、 MIDI データの生成や音声信号の処理に特化したライブラリも数多く公開されており、少ないコード量でアルゴリズム作曲を試すことができます。これらの理由から、 Python はジェネラティブミュージックの学習や試作に広く利用されています。
