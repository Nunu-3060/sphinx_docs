はじめに

本資料は、 Python によるジェネラティブミュージック（ 生成音楽 ）の制作方法について解説する入門資料です。

ジェネラティブミュージックとは、あらかじめ決められた楽譜をそのまま演奏するのではなく、アルゴリズムや確率、外部データなどを用いて音楽をその場で生成する手法です。 Python は文法がシンプルであり、音楽制作に利用できるライブラリも豊富であることから、ジェネラティブミュージックの学習や実践に適した言語です。

本資料では、ジェネラティブミュージックの基本概念から始まり、 Python の開発環境の準備、音楽制作に用いるライブラリの紹介、 MIDI データの取り扱い、代表的なアルゴリズム作曲の手法、そして実際にコードを用いた実装例までを順に解説します。

対象読者

本資料は、以下のような読者を対象としています。

  • Python の基本的な文法を理解している方

  • 音楽制作やプログラミングによる作曲に興味がある方

  • ジェネラティブミュージックという分野を初めて学ぶ方
