主要な Python ライブラリ

本章では、ジェネラティブミュージックの制作に利用される、代表的な Python ライブラリを紹介します。

mido

mido は、 MIDI メッセージの送受信や MIDI ファイルの読み書きを行うためのライブラリです。低レベルな MIDI 操作を、シンプルな Python の API で行うことができます。生成した音符情報を MIDI ファイルとして出力する際によく利用されます。

pretty_midi

pretty_midi は、 MIDI データをより高レベルに扱うためのライブラリです。音符の開始時刻や終了時刻、音の高さ、音量などを、扱いやすいオブジェクトとして操作できます。生成したメロディを MIDI ファイルへ変換する際に適しています。

music21

music21 は、音楽理論に基づいた解析や生成を行うためのライブラリです。和音やスケール、調性などの音楽理論的な概念を扱うことができ、生成した音符列が特定の調やコード進行に沿っているかを検証する用途にも利用できます。

numpy

numpy は、数値計算のための汎用ライブラリです。乱数の生成や、確率分布に基づいたサンプリング、行列演算などに利用します。マルコフ連鎖の遷移確率を計算する際や、セル・オートマトンの状態を配列として扱う際に活用するほか、「音声合成の基礎」の章で解説するサイン波などの音声波形データを生成する際にも利用します。

python-rtmidi

python-rtmidi は、リアルタイムの MIDI 入出力を行うためのライブラリです。生成した音符をリアルタイムに外部音源やソフトウェア音源へ送信する際に利用します。

wave （ 標準ライブラリ ）

wave は、 Python の標準ライブラリに含まれる、 WAV 形式の音声ファイルを読み書きするためのモジュールです。追加のインストールを行うことなく利用でき、 numpy で生成した波形データを WAV ファイルとして出力する際に利用します。

ライブラリの選び方

MIDI ファイルの生成のみを行う場合は、 mido または pretty_midi があれば十分です。音楽理論に基づいた検証や解析を行いたい場合は music21 を、リアルタイム演奏を行いたい場合は python-rtmidi を組み合わせて利用することを推奨します。波形そのものを合成したい場合は、 numpy と wave を組み合わせて利用します。
