5. プログラムの基本要素

言語によって書き方は異なるが、ほとんどの言語のプログラムは、共通するいくつかの要素から組み立てられている。この章では、Python を例に、プログラムを構成する基本要素を説明する。

5.1. 変数と型

変数とは、値に名前を付けて保持する仕組みである。変数に値を結び付けることを代入と呼び、Python では = で表す。変数を使えば、計算の途中結果を保持したり、同じ値を何度も使ったりできる。

値には型がある。Python の代表的な型を次に示す。

型

例

説明

int

3、-42

整数

float

120.5、0.1

浮動小数点数

str

"りんご"

文字列

bool

True、False

真偽値（条件が成り立つかどうか）

5.2. 式と演算子

値や変数を演算子で組み合わせたものを式と呼ぶ。式を評価すると 1 つの値が得られる。算術演算子（+、-、*、/ など）、比較演算子（==、< など）、論理演算子（and、or、not）が代表的である。

 1"""変数と型、式と演算子の例。"""
 2
 3
 4def main() -> None:
 5    """代表的な型の値を変数に代入し、演算の結果を表示する。"""
 6    count: int = 3
 7    price: float = 120.5
 8    name: str = "りんご"
 9    in_stock: bool = True
10
11    total = count * price
12    print(f"{name}を {count} 個買うと {total} 円")  # りんごを 3 個買うと 361.5 円
13    print(type(count), type(price), type(name), type(in_stock))
14
15    print(7 / 2)  # 3.5（除算の結果は float になる）
16    print(7 // 2)  # 3（切り捨て除算）
17    print(7 % 2)  # 1（剰余）
18    print(2 ** 10)  # 1024（べき乗）
19    print(count > 2 and in_stock)  # True（比較演算子と論理演算子）
20
21
22if __name__ == "__main__":
23    main()

6〜9 行目では、変数に型ヒントを付けて値を代入している。11 行目では int 型と float 型の値を掛け、float 型の値を得ている。15〜16 行目が示すように、Python の / は整数どうしでも結果が float 型になり、切り捨て除算には // を使う。演算子の意味は言語によって異なることがあるため、新しい言語を使うときは確認が必要である。

5.3. 制御構造

プログラムの実行の流れを決める仕組みを制御構造と呼ぶ。コンピュータとプログラミングの歴史で述べたように、どのような手順も次の 3 つの構造の組み合わせで表せる。

構造

Python の構文

説明

順次

文を並べる

上から順に 1 つずつ実行する。

分岐

if、elif、else

条件によって、実行する処理を選ぶ。

反復

for、while

同じ処理を繰り返す。for は決まった範囲の要素について、while は条件が成り立つ間、処理を繰り返す。

 
 1"""制御構造（順次・分岐・反復）の例。"""
 2
 3
 4def grade(score: int) -> str:
 5    """点数を A・B・C の評価に変換する（分岐）。"""
 6    if score >= 80:
 7        return "A"
 8    elif score >= 60:
 9        return "B"
10    else:
11        return "C"
12
13
14def sum_up_to(n: int) -> int:
15    """1 から n までの整数の合計を求める（回数が決まった反復）。"""
16    total = 0
17    for i in range(1, n + 1):
18        total += i
19    return total
20
21
22def count_digits(n: int) -> int:
23    """0 以上の整数の桁数を求める（条件を満たす間の反復）。"""
24    digits = 1
25    while n >= 10:
26        n //= 10
27        digits += 1
28    return digits
29
30
31def main() -> None:
32    """各関数を順に呼び出す（順次）。"""
33    print(grade(85))  # A
34    print(grade(59))  # C
35    print(sum_up_to(100))  # 5050
36    print(count_digits(2026))  # 4
37
38
39if __name__ == "__main__":
40    main()

grade 関数（4〜11 行目）は分岐の例であり、点数によって返す評価を選ぶ。sum_up_to 関数（14〜19 行目）は for 文による反復の例であり、1 から n までの整数を順に足す。count_digits 関数（22〜28 行目）は while 文による反復の例であり、10 で割れる間だけ処理を繰り返して桁数を数える。main 関数（31〜36 行目）は、各関数を上から順に呼び出す順次の例である。

5.4. 関数

関数とは、一連の処理をまとめて名前を付けたものである。関数は入力として引数を受け取り、処理の結果を戻り値として返す。処理を関数にまとめると、同じ処理を何度も書かずに済み、処理の内容を名前で表せるため、プログラムが読みやすくなる。

関数が戻り値を返す以外に外部の状態を変えることを副作用と呼ぶ。画面への表示、ファイルへの書き込み、引数として受け取ったリストの書き換えなどが副作用にあたる。副作用のない関数は、同じ引数に対して常に同じ戻り値を返すため、動作を予測しやすく、テストもしやすい。

 1"""関数の定義と呼び出し、副作用の例。"""
 2
 3
 4def rectangle_area(width: float, height: float) -> float:
 5    """長方形の面積を返す（副作用のない関数）。"""
 6    return width * height
 7
 8
 9def add_item(items: list[str], item: str) -> None:
10    """リストに要素を追加する（引数を書き換える副作用のある関数）。"""
11    items.append(item)
12
13
14def greet(name: str, greeting: str = "こんにちは") -> str:
15    """挨拶の文字列を返す（greeting には既定値がある）。"""
16    return f"{greeting}、{name}さん"
17
18
19def main() -> None:
20    """関数を呼び出し、戻り値と副作用を確かめる。"""
21    print(rectangle_area(3.0, 4.0))  # 12.0
22
23    fruits = ["りんご"]
24    add_item(fruits, "みかん")
25    print(fruits)  # ['りんご', 'みかん']（呼び出し元のリストが変わる）
26
27    print(greet("佐藤"))  # こんにちは、佐藤さん
28    print(greet("佐藤", "おはよう"))  # おはよう、佐藤さん
29
30
31if __name__ == "__main__":
32    main()

rectangle_area 関数（4〜6 行目）は副作用のない関数である。add_item 関数（9〜11 行目）は、引数として受け取ったリストに要素を追加するため、24 行目で呼び出したあと、呼び出し元の fruits の内容が変わっている。greet 関数（14〜16 行目）の引数 greeting には既定値があり、27 行目のように省略すると既定値が使われる。

5.5. データ構造

複数の値をまとめて扱うための形式をデータ構造と呼ぶ。Python には、次のようなデータ構造が組み込まれている。

データ構造

Python の型

特徴

リスト

list

値を順序付きで並べたもの。位置（インデックス）を指定して値を取り出せる。作成後に要素を追加・変更できる。

タプル

tuple

値を順序付きで並べたもの。作成後は変更できない。座標のように、組として扱う値に使う。

辞書

dict

キーと値の組を集めたもの。キーを指定して値を取り出せる。

 
 1"""代表的なデータ構造（リスト・タプル・辞書）の例。"""
 2
 3
 4def main() -> None:
 5    """各データ構造を作成し、基本的な操作を行う。"""
 6    # リスト：順序があり、後から変更できる
 7    scores: list[int] = [72, 85, 90]
 8    scores.append(64)
 9    print(scores[0], len(scores))  # 72 4
10
11    # タプル：順序があり、作成後は変更できない
12    point: tuple[int, int] = (3, 4)
13    x, y = point
14    print(x, y)  # 3 4
15
16    # 辞書：キーから値を引く
17    prices: dict[str, int] = {"りんご": 150, "みかん": 80}
18    prices["ぶどう"] = 400
19    print(prices["みかん"])  # 80
20    for name, price in prices.items():
21        print(f"{name}: {price} 円")
22
23
24if __name__ == "__main__":
25    main()

どのデータ構造を選ぶかによって、プログラムの書きやすさと処理の速さが変わる。たとえば、リストから特定の値を探すには先頭から順に調べる必要があるが、辞書ではキーから値をすぐに取り出せる。この違いは、アルゴリズムと計算量で扱う計算量の違いとして説明できる。

5.6. エラー処理

プログラムの実行中には、不正な入力や存在しないファイルの読み込みなど、正常に処理を続けられない状況が起こる。Python では、このような状況を例外という仕組みで扱う。例外が送出されると通常の処理は中断され、try 文の except 節で捕捉されれば、そこに書いた処理が実行される。捕捉されなければ、プログラムはエラーメッセージを表示して終了する。

 1"""例外によるエラー処理の例。"""
 2
 3
 4def parse_age(text: str) -> int:
 5    """文字列を年齢として解釈する。不正な値なら ValueError を送出する。"""
 6    age = int(text)  # 数字でなければ int() が ValueError を送出する
 7    if age < 0:
 8        raise ValueError(f"年齢は 0 以上でなければならない: {age}")
 9    return age
10
11
12def main() -> None:
13    """正しい入力と誤った入力を与え、例外を捕捉する。"""
14    for text in ["30", "abc", "-5"]:
15        try:
16            age = parse_age(text)
17        except ValueError as error:
18            print(f"入力 {text!r} は不正: {error}")
19        else:
20            print(f"入力 {text!r} は {age} 歳")
21
22
23if __name__ == "__main__":
24    main()

parse_age 関数は、数字でない文字列を受け取ると 6 行目の int 関数が ValueError を送出し、負の値を受け取ると 8 行目で自ら ValueError を送出する。main 関数は、15〜20 行目の try 文で例外を捕捉し、入力が不正であることを表示する。例外が送出されなかった場合は、else 節（19〜20 行目）が実行される。

実行すると、次のように表示される。

1入力 '30' は 30 歳
2入力 'abc' は不正: invalid literal for int() with base 10: 'abc'
3入力 '-5' は不正: 年齢は 0 以上でなければならない: -5

エラー処理を書くときは、「何が起こりうるか」「起きたときにどうすべきか」を考える必要がある。プログラミングとは何かで述べたように、例外的な状況まで扱うことは、プログラムに求められる重要な性質である。
