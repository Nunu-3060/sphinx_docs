用語集

本書で用いる主な用語を、英字、五十音の順に示す。

CPU

Central Processing Unit の略。中央処理装置。メモリから命令を読み出して解釈し、演算を実行する装置。

アセンブリ言語

機械語の命令を、ADD や LOAD のような短い記号で書けるようにした言語。機械語とほぼ 1 対 1 に対応する。

アルゴリズム

問題を解くための明確な手順。有限回の手順で終了し、各手順が曖昧さなく定められている必要がある。

インタフェース

部品の利用者に対して約束する使い方。関数であれば、名前、引数、戻り値がこれにあたる。

インタプリタ

プログラムを読み込みながら、その場で解釈して実行する言語処理系。

演算子

+ や == のように、値に対する演算を表す記号。

オブジェクト指向プログラミング

データとそれを操作する手続きをオブジェクトとしてまとめ、オブジェクトどうしのやり取りとしてプログラムを組み立てる考え方。

型

値の種類と、その値に対して行える操作を定めたもの。整数、浮動小数点数、文字列などがある。

型ヒント

Python で、変数や関数の引数、戻り値に型の情報を書き添える仕組み。実行時には検査されないが、mypy などの静的解析ツールで検査できる。

関数

一連の処理をまとめて名前を付けたもの。引数を受け取り、戻り値を返す。

機械語

CPU が直接解釈して実行できる命令の形式。CPU の種類ごとに異なる。

継続的インテグレーション

変更が記録されるたびに、ビルド、テスト、静的解析を自動で実行する仕組み。CI（Continuous Integration）とも呼ぶ。

計算量

入力の大きさに対して、アルゴリズムの処理の手間がどのように増えるかを表したもの。一般に O 記法で表す。

高水準言語

人間の考え方に近い形で処理を書けるプログラミング言語。CPU の種類に依存せずに書ける。

構造化プログラミング

順次、分岐、反復の 3 つの構造を組み合わせてプログラムを組み立てる考え方。

コードレビュー

書いたプログラムを、他の人が読んで確認すること。

コンパイラ

プログラム全体を、実行前に機械語などの別の形式に変換する言語処理系。

制御構造

プログラムの実行の流れを決める仕組み。順次、分岐、反復がある。

静的解析

プログラムを実行せずに、ソースコードを解析して問題を見つけること。

抽象化

詳細を隠し、本質だけを扱えるようにすること。

データ構造

複数の値をまとめて扱うための形式。リスト、辞書などがある。

テスト

プログラムが意図どおりに動くことを確かめる作業。

デバッグ

プログラムの誤り（バグ）を見つけて修正する作業。

ノイマン型コンピュータ

プログラム内蔵方式に基づくコンピュータ。現在のコンピュータの多くがこれにあたる。

バイト

8 ビットをまとめた単位。

バイトコード

仮想的な機械向けの命令の形式。Python や Java の処理系は、プログラムをバイトコードに変換してから実行する。

バグ

プログラムの誤り。意図と異なる動作の原因となる。

バージョン管理

ファイルの変更の履歴を記録し、過去の状態に戻したり、変更の内容を比べたりできるようにする仕組み。

ビット

0 または 1 を表す、情報の最小の単位。

副作用

関数が戻り値を返す以外に、外部の状態を変えること。画面への表示や、引数として受け取ったリストの書き換えなどがある。

浮動小数点数

小数を含む数を、符号、指数、仮数の組で近似的に表現する形式。

プログラミング

解きたい問題を、コンピュータが実行できる手順に落とし込む行為。

プログラミング言語

プログラムを書き表すための言語。

プログラム

コンピュータに実行させる命令を、実行する順序に従って並べたもの。

プログラム内蔵方式

プログラムをデータと同じくメモリに格納して実行する方式。

変数

値に名前を付けて保持する仕組み。

メモリ

実行中のプログラムと、そのプログラムが扱うデータを記憶する装置。主記憶装置とも呼ぶ。

文字コード

文字と数値の対応を定めた規則。Unicode と UTF-8 の組み合わせが広く使われている。

例外

正常に処理を続けられない状況を知らせ、通常の処理を中断して対処する仕組み。

レジスタ

CPU の内部にある、小容量で高速な記憶領域。
