2. 中国茶とは

2.1. チャノキと世界のお茶

緑茶も烏龍茶も紅茶も、すべて「チャノキ」というツバキ科の植物の葉から作られます。チャノキの原産地は、中国の南西部（雲南省の周辺）とされています。中国茶、日本茶、紅茶の違いは、植物の違いではなく、主に葉の加工方法の違いです。

ただし、品種や育つ土地によっても茶の性質は変わります。チャノキには、葉が小さく寒さに強い中国種と、葉が大きく暑い地域で育つアッサム種があります。中国茶の多くは中国種から作られますが、雲南省のプーアル茶や紅茶には、葉の大きい品種（大葉種）が使われます。

2.2. 「発酵」とは何か

お茶の種類を理解するために欠かせないのが「発酵」という言葉です。ただし、お茶の世界でいう発酵の多くは、パンやみそのように微生物が働く発酵とは異なります。

摘んだ茶葉の中では、茶葉自身が持つ酵素の働きによって、カテキンなどの成分が酸素と結び付き、葉の色や香りが変わっていきます。これを酸化発酵と呼びます。切ったリンゴが茶色くなるのと同じ仕組みです。

酸化発酵は、茶葉を加熱して酵素の働きを止めると、そこで止まります。この加熱の工程を殺青と呼びます。いつ殺青するか（あるいは殺青しないか）によって、お茶の色や香りが大きく変わります。

一方、黒茶の一部は、殺青の後に微生物の働きによって発酵させます。これは本来の意味での発酵で、後発酵と呼ばれます。

2.3. 六大茶類

中国では、お茶を作り方の違いによって 6 つに分類します。これを六大茶類と呼びます。分類の名前は、茶葉や水色（淹れたお茶の色）に由来しています。

茶類

発酵の度合い

特徴

緑茶

不発酵茶

摘んですぐに殺青するため、茶葉の緑色が残ります。中国で最も多く飲まれているお茶です。

白茶

弱発酵茶

殺青も揉むこともせず、しおれさせて乾燥させるだけで作ります。

黄茶

弱後発酵茶

殺青の後に茶葉を包んで蒸らし、ゆっくりと黄色く変化させます。生産量の少ない希少なお茶です。

青茶

半発酵茶

酸化発酵を途中で止めて作ります。烏龍茶は青茶の一種です。

紅茶

完全発酵茶

酸化発酵を十分に進めてから乾燥させます。

黒茶

後発酵茶

殺青の後に、微生物の働きで発酵させたり、長い時間をかけて熟成させたりします。プーアル茶が代表です。

このほかに、六大茶類のお茶に花の香りを付けた花茶（ジャスミン茶など）や、茶葉を糸で縛って形を作った工芸茶があります。これらは、六大茶類のお茶をもとに作るため、再加工茶と呼ばれます。

英語の「black tea」は紅茶のことで、中国の黒茶とは別のお茶です。黒茶は英語では「dark tea」と呼ばれます。名前が似ているので注意してください。

2.4. お茶ができるまで

お茶は、摘んだ茶葉に次のような工程を組み合わせて作ります。

工程

内容

摘採

茶葉を摘みます。品質の高いお茶には、新芽の先端の一芯二葉などの若い葉を使います。

萎凋

摘んだ茶葉を広げて、水分を減らしてしおれさせます。香りが生まれる大切な工程です。

做青

青茶だけの工程です。茶葉を揺すって葉の縁を傷付け、酸化発酵を部分的に進めます。

殺青

茶葉を釜で炒るなどして加熱し、酵素の働きを止めて酸化発酵を止めます。

揉捻

茶葉を揉んで形を整えます。茶葉の組織が壊れ、お湯に成分が溶け出しやすくなります。

悶黄

黄茶だけの工程です。殺青した茶葉を布や紙で包み、蒸らして黄色く変化させます。

渥堆

黒茶の工程です。茶葉を積み上げて水分を加え、微生物の働きで発酵させます。

乾燥

茶葉を乾燥させて、保存できる状態にします。青茶などでは、さらに焙煎して香ばしさを加えることもあります。

茶類ごとの主な工程の流れは、次のとおりです。

茶類

主な工程

緑茶

摘採 → 殺青 → 揉捻 → 乾燥

白茶

摘採 → 萎凋 → 乾燥

黄茶

摘採 → 殺青 → 揉捻 → 悶黄 → 乾燥

青茶

摘採 → 萎凋 → 做青 → 殺青 → 揉捻 → 乾燥

紅茶

摘採 → 萎凋 → 揉捻 → 酸化発酵 → 乾燥

黒茶

摘採 → 殺青 → 揉捻 → 渥堆 → 乾燥

実際の製法は銘柄ごとに異なり、例えば黄茶の中には揉捻をしないものもあります。上の表は、全体の流れをつかむための目安です。

2.5. 日本の緑茶との違い

日本の緑茶（煎茶）の多くは、殺青のときに茶葉を蒸気で蒸します。一方、中国の緑茶の多くは、釜で炒って殺青します。蒸した緑茶は青々とした香りとうま味が強く、釜で炒った緑茶は香ばしい香りと、すっきりした味わいが特徴です。
