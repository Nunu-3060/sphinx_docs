便利なスクリプト

本付録では、中国茶を淹れるときに役立つ 2 つの Python スクリプトを紹介します。どちらも Python の標準機能だけで動くため、追加のインストールは不要です。

動かすための準備

スクリプトを動かすには、Python 3.10 以上が必要です。Python は、Python の公式サイトからダウンロードしてインストールできます。

スクリプトは、次の手順で実行します。

  1. 本ページのリンクからスクリプトをダウンロードします。

  2. Windows では「コマンドプロンプト」、macOS では「ターミナル」を開きます。

  3. cd コマンドで、スクリプトを保存したフォルダーに移動します。

  4. python コマンドの後にスクリプトのファイル名を付けて実行します。

例えば、ダウンロードフォルダーに保存した場合は、次のように入力します。macOS では python の代わりに python3 と入力してください。

1cd Downloads
2python brewing_guide.py

どちらのスクリプトでも、茶類は次の名前で指定します。

淹れ方の目安の表示（brewing_guide.py）

茶類と器の容量を指定すると、茶葉の量、湯温、煎ごとの浸出時間の目安を表示します。計算には、「おいしい淹れ方」で紹介した、蓋碗や茶壺で淹れる場合の目安と式を使っています。

ダウンロード：brewing_guide.py

使い方

引数を付けずに実行すると、茶類と器の容量を順に尋ねられます。

1python brewing_guide.py

茶類と器の容量（ml）を続けて指定すると、すぐに結果が表示されます。器の容量には、30〜500 の整数を指定します。例えば、容量 120 ml の蓋碗で青茶を淹れる場合は、次のように実行します。

1python brewing_guide.py oolong 120

実行すると、次のように表示されます。

 1青茶（烏龍茶）を 120 ml の器で淹れる目安
 2  茶葉の量  : 7.2 g
 3  湯温      : 95〜100 ℃
 4  浸出時間  :
 5    1 煎目  0 分 30 秒
 6    2 煎目  0 分 40 秒
 7    3 煎目  0 分 50 秒
 8    4 煎目  1 分 00 秒
 9    5 煎目  1 分 10 秒
10    6 煎目  1 分 20 秒

ソースコード

  1"""中国茶の淹れ方の目安を表示するスクリプト。
  2
  3茶類と器の容量を指定すると、茶葉の量、湯温、煎ごとの浸出時間の
  4目安を表示します。
  5
  6使い方:
  7    python brewing_guide.py              対話形式で入力する
  8    python brewing_guide.py oolong 120   青茶（烏龍茶）を 120 ml の器で淹れる
  9
 10Python 3.10 以上の標準ライブラリだけで動作します。
 11"""
 12
 13from __future__ import annotations
 14
 15import argparse
 16import sys
 17from dataclasses import dataclass
 18
 19
 20@dataclass(frozen=True)
 21class TeaKind:
 22    """茶類ごとの淹れ方の目安（蓋碗や茶壺で淹れる場合）。"""
 23
 24    key: str  # コマンドラインで指定する名前
 25    name: str  # 画面に表示する名前
 26    leaf_g: float  # 容量 100 ml あたりの茶葉の量 [g]
 27    temperature: str  # 湯温の目安
 28    first_seconds: int  # 1 煎目の浸出時間 [秒]
 29    step_seconds: int  # 1 煎ごとに延ばす時間 [秒]
 30    infusions: int  # 楽しめる煎数の目安
 31
 32
 33# 本文「おいしい淹れ方」の表と同じ値を使う
 34TEA_KINDS: tuple[TeaKind, ...] = (
 35    TeaKind("green", "緑茶", 2.0, "80 ℃ 前後", 60, 15, 3),
 36    TeaKind("white", "白茶", 4.0, "85〜90 ℃", 45, 15, 5),
 37    TeaKind("yellow", "黄茶", 2.0, "80 ℃ 前後", 60, 15, 3),
 38    TeaKind("oolong", "青茶（烏龍茶）", 6.0, "95〜100 ℃", 30, 10, 6),
 39    TeaKind("black", "紅茶", 3.0, "90〜95 ℃", 40, 15, 4),
 40    TeaKind("dark", "黒茶（プーアル茶）", 5.0, "100 ℃", 20, 10, 8),
 41    TeaKind("jasmine", "花茶（ジャスミン茶）", 3.0, "85〜90 ℃", 60, 15, 3),
 42)
 43
 44MIN_CAPACITY = 30  # 器の容量の下限 [ml]
 45MAX_CAPACITY = 500  # 器の容量の上限 [ml]
 46
 47
 48def find_tea_kind(key: str) -> TeaKind:
 49    """名前（green、oolong など）から茶類を探す。"""
 50    for kind in TEA_KINDS:
 51        if kind.key == key:
 52            return kind
 53    raise ValueError(f"不明な茶類です: {key}")
 54
 55
 56def leaf_amount(kind: TeaKind, capacity: int) -> float:
 57    """器の容量 c [ml] に合った茶葉の量 W [g] を返す。
 58
 59    W = c × w / 100 で求める（w は 100 ml あたりの茶葉の量）。
 60    """
 61    if not MIN_CAPACITY <= capacity <= MAX_CAPACITY:
 62        raise ValueError(
 63            f"器の容量は {MIN_CAPACITY}〜{MAX_CAPACITY} ml で"
 64            "指定してください。"
 65        )
 66    return capacity * kind.leaf_g / 100
 67
 68
 69def infusion_seconds(kind: TeaKind, number: int) -> int:
 70    """number 煎目の浸出時間 t [秒] を返す。
 71
 72    t = t1 + (number - 1) × Δt で求める。
 73    """
 74    if number < 1:
 75        raise ValueError("煎数には 1 以上の数を指定してください。")
 76    return kind.first_seconds + (number - 1) * kind.step_seconds
 77
 78
 79def format_time(seconds: int) -> str:
 80    """秒数を「○ 分 ○○ 秒」の形式の文字列にする。"""
 81    minutes, rest = divmod(seconds, 60)
 82    return f"{minutes} 分 {rest:02d} 秒"
 83
 84
 85def format_guide(kind: TeaKind, capacity: int) -> str:
 86    """淹れ方の目安を、画面に表示する文字列にする。"""
 87    lines = [
 88        f"{kind.name}を {capacity} ml の器で淹れる目安",
 89        f"  茶葉の量  : {leaf_amount(kind, capacity):.1f} g",
 90        f"  湯温      : {kind.temperature}",
 91        "  浸出時間  :",
 92    ]
 93    for number in range(1, kind.infusions + 1):
 94        seconds = infusion_seconds(kind, number)
 95        lines.append(f"    {number} 煎目  {format_time(seconds)}")
 96    return "\n".join(lines)
 97
 98
 99def ask_tea_kind() -> TeaKind:
100    """茶類を対話形式で選んでもらう。"""
101    for number, kind in enumerate(TEA_KINDS, start=1):
102        print(f"  {number}: {kind.name}")
103    while True:
104        text = input("茶類を番号で選んでください: ")
105        if text.isdecimal() and 1 <= int(text) <= len(TEA_KINDS):
106            return TEA_KINDS[int(text) - 1]
107        print("表示されている番号を入力してください。")
108
109
110def ask_capacity() -> int:
111    """器の容量を対話形式で入力してもらう。"""
112    while True:
113        text = input("器の容量 [ml] を入力してください: ")
114        if text.isdecimal() and MIN_CAPACITY <= int(text) <= MAX_CAPACITY:
115            return int(text)
116        print(f"{MIN_CAPACITY}〜{MAX_CAPACITY} の整数を入力してください。")
117
118
119def parse_args() -> argparse.Namespace:
120    """コマンドライン引数を解析する。"""
121    parser = argparse.ArgumentParser(
122        description="中国茶の淹れ方の目安を表示します。"
123    )
124    parser.add_argument(
125        "kind",
126        nargs="?",
127        choices=[kind.key for kind in TEA_KINDS],
128        help="茶類",
129    )
130    parser.add_argument(
131        "capacity", nargs="?", type=int, help="器の容量 [ml]"
132    )
133    return parser.parse_args()
134
135
136def main() -> int:
137    """スクリプトの入口。"""
138    args = parse_args()
139    kind = ask_tea_kind() if args.kind is None else find_tea_kind(args.kind)
140    capacity: int = (
141        ask_capacity() if args.capacity is None else args.capacity
142    )
143    try:
144        print(format_guide(kind, capacity))
145    except ValueError as error:
146        print(error)
147        return 1
148    return 0
149
150
151if __name__ == "__main__":
152    sys.exit(main())

煎ごとのタイマー（infusion_timer.py）

茶類を指定すると、1 煎目から順に浸出時間をカウントダウンします。煎を重ねるごとに浸出時間が延びる、中国茶の淹れ方に合わせたタイマーです。計る時間は、brewing_guide.py で表示される浸出時間と同じです。

ダウンロード：infusion_timer.py

使い方

茶類を指定しない場合は、実行後に番号で選びます。例えば、ジャスミン茶の浸出時間を計る場合は、次のように実行します。

1python infusion_timer.py jasmine

お湯を注いだら Enter キーを押すと、カウントダウンが始まります。時間になると、音とメッセージで知らせます。続けて次の煎のお湯を注いだら、もう一度 Enter キーを押します。途中で終わりたい場合は、Enter キーの代わりに q を入力して Enter キーを押すか、Ctrl+C を押します。

途中の煎から計りたい場合は、-s の後に煎数を指定します。次の例では、ジャスミン茶の 2 煎目から計ります。

1python infusion_timer.py jasmine -s 2

実行すると、次のように表示されます。残り時間は、1 秒ごとに同じ行で更新されます。

1花茶（ジャスミン茶）: 3 煎目まで計ります。Ctrl+C で中止できます。
22 煎目: お湯を注いだら Enter を押してください（q で終了）:
3  残り 0 分 00 秒
4  2 煎目の時間です。茶海に注ぎ切りましょう。
53 煎目: お湯を注いだら Enter を押してください（q で終了）:
6  残り 0 分 00 秒
7  3 煎目の時間です。茶海に注ぎ切りましょう。
8目安の煎数に達しました。味が薄くなるまで楽しめます。

ソースコード

  1"""中国茶の煎ごとの浸出時間を計るタイマー。
  2
  3茶類を選ぶと、1 煎目から順に浸出時間をカウントダウンします。
  4煎を重ねるごとに浸出時間が延びる、中国茶の淹れ方に合わせています。
  5
  6使い方:
  7    python infusion_timer.py               対話形式で茶類を選ぶ
  8    python infusion_timer.py oolong        青茶（烏龍茶）
  9    python infusion_timer.py oolong -s 3   青茶（烏龍茶）の 3 煎目から計る
 10
 11Python 3.10 以上の標準ライブラリだけで動作します。
 12"""
 13
 14from __future__ import annotations
 15
 16import argparse
 17import sys
 18import time
 19from dataclasses import dataclass
 20
 21
 22@dataclass(frozen=True)
 23class TeaKind:
 24    """茶類ごとの浸出時間の目安（蓋碗や茶壺で淹れる場合）。"""
 25
 26    key: str  # コマンドラインで指定する名前
 27    name: str  # 画面に表示する名前
 28    first_seconds: int  # 1 煎目の浸出時間 [秒]
 29    step_seconds: int  # 1 煎ごとに延ばす時間 [秒]
 30    infusions: int  # 楽しめる煎数の目安
 31
 32
 33# 本文「おいしい淹れ方」の表と同じ値を使う
 34TEA_KINDS: tuple[TeaKind, ...] = (
 35    TeaKind("green", "緑茶", 60, 15, 3),
 36    TeaKind("white", "白茶", 45, 15, 5),
 37    TeaKind("yellow", "黄茶", 60, 15, 3),
 38    TeaKind("oolong", "青茶（烏龍茶）", 30, 10, 6),
 39    TeaKind("black", "紅茶", 40, 15, 4),
 40    TeaKind("dark", "黒茶（プーアル茶）", 20, 10, 8),
 41    TeaKind("jasmine", "花茶（ジャスミン茶）", 60, 15, 3),
 42)
 43
 44
 45def find_tea_kind(key: str) -> TeaKind:
 46    """名前（green、oolong など）から茶類を探す。"""
 47    for kind in TEA_KINDS:
 48        if kind.key == key:
 49            return kind
 50    raise ValueError(f"不明な茶類です: {key}")
 51
 52
 53def ask_tea_kind() -> TeaKind:
 54    """茶類を対話形式で選んでもらう。"""
 55    for number, kind in enumerate(TEA_KINDS, start=1):
 56        print(f"  {number}: {kind.name}")
 57    while True:
 58        text = input("茶類を番号で選んでください: ")
 59        if text.isdecimal() and 1 <= int(text) <= len(TEA_KINDS):
 60            return TEA_KINDS[int(text) - 1]
 61        print("表示されている番号を入力してください。")
 62
 63
 64def infusion_seconds(kind: TeaKind, number: int) -> int:
 65    """number 煎目の浸出時間 t [秒] を返す。
 66
 67    t = t1 + (number - 1) × Δt で求める。
 68    """
 69    return kind.first_seconds + (number - 1) * kind.step_seconds
 70
 71
 72def format_time(seconds: int) -> str:
 73    """秒数を「○ 分 ○○ 秒」の形式の文字列にする。"""
 74    minutes, rest = divmod(seconds, 60)
 75    return f"{minutes} 分 {rest:02d} 秒"
 76
 77
 78def count_down(seconds: int) -> None:
 79    """指定した秒数をカウントダウンし、残り時間を表示する。"""
 80    for remaining in range(seconds, 0, -1):
 81        print(f"\r  残り {format_time(remaining)} ", end="", flush=True)
 82        time.sleep(1)
 83    print(f"\r  残り {format_time(0)} ")
 84
 85
 86def wait_for_start(number: int) -> bool:
 87    """お湯を注ぐ準備ができるまで待つ。続ける場合は True を返す。"""
 88    text = input(
 89        f"{number} 煎目: お湯を注いだら Enter を押してください"
 90        "（q で終了）: "
 91    )
 92    return text.strip().lower() != "q"
 93
 94
 95def parse_args() -> argparse.Namespace:
 96    """コマンドライン引数を解析する。"""
 97    parser = argparse.ArgumentParser(
 98        description="中国茶の煎ごとの浸出時間を計るタイマーです。"
 99    )
100    parser.add_argument(
101        "kind",
102        nargs="?",
103        choices=[kind.key for kind in TEA_KINDS],
104        help="茶類",
105    )
106    parser.add_argument(
107        "-s", "--start", type=int, default=1, help="何煎目から計るか"
108    )
109    return parser.parse_args()
110
111
112def main() -> int:
113    """スクリプトの入口。"""
114    args = parse_args()
115    kind = ask_tea_kind() if args.kind is None else find_tea_kind(args.kind)
116    start: int = args.start
117    if not 1 <= start <= kind.infusions:
118        print(f"煎数には 1〜{kind.infusions} を指定してください。")
119        return 1
120
121    print(f"{kind.name}: {kind.infusions} 煎目まで計ります。"
122          "Ctrl+C で中止できます。")
123    try:
124        for number in range(start, kind.infusions + 1):
125            if not wait_for_start(number):
126                print("タイマーを終了しました。")
127                return 0
128            count_down(infusion_seconds(kind, number))
129            # "\a" はベル文字で、対応している環境では音が鳴ります
130            print(f"\a  {number} 煎目の時間です。茶海に注ぎ切りましょう。")
131    except (KeyboardInterrupt, EOFError):
132        print("\nタイマーを中止しました。")
133        return 1
134
135    print("目安の煎数に達しました。味が薄くなるまで楽しめます。")
136    return 0
137
138
139if __name__ == "__main__":
140    sys.exit(main())
