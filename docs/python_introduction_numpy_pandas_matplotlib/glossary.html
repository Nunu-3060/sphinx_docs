用語集

本ドキュメントに登場する主な用語をまとめます。詳しい説明は、各用語に示したページを参照してください。

英字

axis

numpy や pandas で、集計や結合を行う方向を指定する引数です。2 次元配列では、axis=0 を指定すると行方向に集約して列ごとの結果が得られ、axis=1 を指定すると列方向に集約して行ごとの結果が得られます。詳しくは「集約関数」を参照してください。

Axes

matplotlib で、1 つのグラフを描画する領域です。1 つの Figure の中に複数の Axes を配置できます。詳しくは「matplotlib とは」を参照してください。

DataFrame

pandas の表形式の 2 次元データです。複数の Series を列として持ちます。詳しくは「DataFrame の基本」を参照してください。

dtype

ndarray の要素や、pandas の列が持つデータ型です。int64、float64、str などがあります。詳しくは「配列の作成」を参照してください。

Figure

matplotlib で、グラフ全体を表す図です。内部に 1 つ以上の Axes を持ちます。詳しくは「matplotlib とは」を参照してください。

MultiIndex

pandas で、複数の階層を持つインデックスです。複数の列で groupby を行った結果などで使われます。詳しくは「集計とグルーピング」を参照してください。

NaN

Not a Number の略で、pandas では欠損値を表すために使われます。詳しくは「欠損値の処理と重複の除去」を参照してください。

ndarray

numpy が提供する多次元配列です。同じ dtype の要素を連続したメモリ領域に格納するため、要素ごとの演算を高速に実行できます。詳しくは「numpy とは」を参照してください。

rcParams

matplotlib の既定の設定をまとめて保持している、辞書のようなオブジェクトです。フォントサイズや線の太さなどを一括で変更できます。詳しくは「rcParams による見た目の調整」を参照してください。

Series

pandas のラベル（インデックス）付きの 1 次元データです。詳しくは「Series の基本」を参照してください。

ufunc

ユニバーサル関数とも呼ばれ、np.sin や np.sqrt のように配列の要素ごとに処理を行う numpy の関数です。詳しくは「配列の演算」を参照してください。

かな・漢字

アクセサ

pandas の Series から、特定の種類のデータ向けのメソッドを呼び出すための仕組みです。文字列用の .str、日付・時刻用の .dt、カテゴリ型用の .cat などがあります。詳しくは「Series の基本」と「日付・時刻データの扱い」を参照してください。

移動平均

時系列データで、各時点について直近 N 件の値の平均をとったものです。日々のばらつきをならして、大まかな傾向をつかむために使います。詳しくは「日付・時刻データの扱い」を参照してください。

インデックス

pandas で、各行に付けられたラベルです。既定では 0 始まりの連番ですが、set_index で任意の列をインデックスに設定できます。詳しくは「行・列の選択」を参照してください。

回帰直線

2 つの変数の関係を \(y = ax + b\) の形の直線で表したものです。最小二乗法で求めます。詳しくは「2 変数の相関と回帰直線」を参照してください。

仮想環境

プロジェクトごとに独立したパッケージのインストール先を用意する仕組みです。Python では venv で作成します。詳しくは「環境構築」を参照してください。

カテゴリ型

値の種類が少ない列を、整数のコードとカテゴリの対応表として保持する pandas のデータ型です。メモリ使用量を削減できます。詳しくは「DataFrame の基本」を参照してください。

行列積

数学的な意味での行列の掛け算です。numpy では @ 演算子または np.matmul で計算します。要素ごとの掛け算を行う * とは異なります。詳しくは「配列の演算」を参照してください。

クロス集計

2 つの項目を行と列に配置して、その組み合わせごとに値を集計した表です。pandas では pivot_table や unstack で作成します。詳しくは「集計とグルーピング」を参照してください。

欠損値

データの中で値が存在しない箇所です。pandas では NaN で表されます。詳しくは「欠損値の処理と重複の除去」を参照してください。

決定係数

回帰直線などのモデルがデータにどの程度当てはまっているかを表す、0 から 1 までの値です。1 に近いほどよく当てはまっていることを表します。詳しくは「2 変数の相関と回帰直線」を参照してください。

コピー

元の配列とは別のメモリ領域に作成された配列です。コピーを変更しても元の配列は変わりません。ビューと対になる用語です。詳しくは「インデックスとスライス」を参照してください。

最小二乗法

実際の値とモデルによる予測値の差の 2 乗の合計が最小になるように、モデルの係数を決める方法です。回帰直線を求める際に使います。詳しくは「2 変数の相関と回帰直線」を参照してください。

シード

乱数生成器に与える初期値です。同じシードを指定すると、実行するたびに同じ乱数列を再現できます。詳しくは「乱数生成」を参照してください。

相関係数

2 つの変数の間にある直線的な関係の強さを、-1 から 1 までの値で表す統計量です。numpy では np.corrcoef、pandas では corr メソッドで計算します。詳しくは「2 変数の相関と回帰直線」を参照してください。

縦持ち・横持ち

表の形式を表す用語です。項目の組み合わせごとに 1 行ずつ並べた形式を「縦持ち」、一方の項目を列に展開した形式を「横持ち」と呼びます。詳しくは「集計とグルーピング」を参照してください。

外れ値

他の大多数の値から大きく離れた値です。センサーの不具合や記録ミスなどが原因で混入することがあります。詳しくは「センサーデータの統計処理と外れ値の除外」を参照してください。

ビュー

元の配列と同じメモリを共有する配列です。スライスで得られる配列はビューになるため、ビューを変更すると元の配列も変わります。詳しくは「インデックスとスライス」を参照してください。

ブールインデックス

真偽値の配列を使って、True に対応する要素や行だけを抽出する方法です。詳しくは「インデックスとスライス」と「条件によるフィルタリング」を参照してください。

ブロードキャスト

形状の異なる配列同士の演算で、一定のルールに従って自動的に形状を揃えてから演算を行う仕組みです。詳しくは「ブロードキャスト」を参照してください。

ベクトル化

for ループで要素を 1 つずつ処理する代わりに、配列や列全体に対する演算としてまとめて処理を記述することです。numpy や pandas では、ベクトル化した方が高速に動作します。詳しくは「行・列に対する反復処理」を参照してください。
