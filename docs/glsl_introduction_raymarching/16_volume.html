第 16 章 ボリュームレンダリング

雲、煙、霧のように、はっきりした表面を持たず、空間に広がって光を吸収・散乱する物体を関与媒質と呼ぶ。関与媒質を描くには、表面の 1 点ではなく、レイが媒質の中を通過する区間全体で光の変化を積分する必要がある。この手法を ボリュームレンダリング と呼ぶ。この章では、SDF とノイズで雲の形を定義し、レイマーチングで光の吸収と散乱を積分して描く。最後に、同じ考え方を大気全体に適用し、空の色を求める。

関与媒質による光の減衰と散乱

吸収と散乱

関与媒質の中を進む光は、媒質中の粒子によって次のように変化する。

  • 吸収: 光のエネルギーが粒子に吸収されて失われる。

  • 外への散乱: 光が粒子に当たって別の方向に進路を変え、レイの方向から失われる。

  • 内への散乱: 別の方向から来た光（例えば太陽光）が粒子に当たり、レイの方向に進路を変えて加わる。

単位長さあたりに吸収される割合を吸収係数 \(\sigma_a\)、散乱される割合を散乱係数 \(\sigma_s\) と呼び、両者の和 \(\sigma_t = \sigma_a + \sigma_s\) を消散係数と呼ぶ。

透過率

消散係数 \(\sigma_t\) の媒質の中を、点 \(\mathbf{p}(0)\) から \(\mathbf{p}(t)\) まで進んだ光が失われずに残る割合を透過率と呼ぶ。透過率は、第 7 章のフォグと同じくランベルト・ベールの法則で表される。

\[T(t) = \exp\left(-\int_0^t \sigma_t\bigl(\mathbf{p}(s)\bigr)\, ds\right)\]

第 7 章では媒質が一様（\(\sigma_t\) が定数）だったので \(T = e^{-\sigma t}\) となった。雲のように濃さが場所によって異なる媒質では、この積分を数値的に求める。

ボリュームレンダリング方程式

内への散乱として太陽光が 1 回だけ散乱される場合（単一散乱）だけを考えると、視点に届く光 \(L\) は次のように表せる。

\[L = \int_0^{t_{\max}} T(t)\, \sigma_s\bigl(\mathbf{p}(t)\bigr)\, L_s\bigl(\mathbf{p}(t)\bigr)\, dt + T(t_{\max})\, L_{\text{bg}}\]

第 1 項は、レイ上の各点で散乱されてレイの方向に加わった光 \(L_s\) が、視点に届くまでに \(T(t)\) だけ減衰したものの総和である。第 2 項は、媒質を透過して見える背景 \(L_{\text{bg}}\) （空）の光である。

点 \(\mathbf{p}\) で散乱される光 \(L_s\) は、太陽から \(\mathbf{p}\) までの透過率 \(T_{\text{light}}\) と、位相関数 \(p(\theta)\) で決まる。

\[L_s(\mathbf{p}) = p(\theta)\, T_{\text{light}}(\mathbf{p})\, L_{\text{sun}} + L_{\text{ambient}}\]

\(\theta\) は太陽光の進行方向と散乱後の方向（視点に向かう方向）のなす角である。\(L_{\text{ambient}}\) は、空から届く光による散乱を定数で近似した項である。

位相関数

位相関数 \(p(\theta)\) は、光が散乱される方向の分布を表す。全方向に均等に散乱される場合は \(p = 1/(4\pi)\) である。雲の水滴は光を前方（元の進行方向に近い方向）に強く散乱する性質があり、太陽の方を向いて雲を見ると、雲の縁が明るく輝いて見える。この性質は、次の Henyey-Greenstein 位相関数でよく表される。

\[p(\theta) = \frac{1}{4\pi} \frac{1 - g^2}{\bigl(1 + g^2 - 2g\cos\theta\bigr)^{3/2}}\]

\(g \in (-1, 1)\) は散乱の偏りを表し、正の値ほど前方に散乱しやすい。サンプルでは、計算を簡単にするために、定数とべき乗の和で前方散乱を近似した関数を使っている。

雲の形の定義

雲の密度は、大まかな形を SDF で、細かな凹凸をノイズで表す。

ノイズ

細かな凹凸には、第 10 章の値ノイズと fBm を 3 次元に拡張したものを使う。2 次元では正方形の 4 頂点の値を補間したが、3 次元では立方体の 8 頂点の値を補間する。ハッシュ関数は第 10 章と同じ PCG ハッシュで、3 つの座標を順にハッシュ関数に通して組み合わせる。

16_volume.frag（抜粋）
16// PCG ハッシュ (Jarzynski and Olano, 2020)
17uint pcgHash(uint v)
18{
19    uint state = v * 747796405u + 2891336453u;
20    uint word = ((state >> ((state >> 28u) + 4u)) ^ state) * 277803737u;
21    return (word >> 22u) ^ word;
22}
23
24// 3 次元の整数の格子点 p に 0 以上 1 未満の乱数を割り当てる
25float hash31(vec3 p)
26{
27    uvec3 q = uvec3(ivec3(p));
28    return float(pcgHash(q.x + pcgHash(q.y + pcgHash(q.z)))) / 4294967296.0;
29}
30
31// 3 次元の値ノイズ: 立方体の 8 頂点の乱数を 3 次のエルミート補間でつなぐ
32float valueNoise(vec3 x)
33{
34    vec3 i = floor(x);
35    vec3 f = fract(x);
36    vec3 u = f * f * (3.0 - 2.0 * f);
37    vec2 e = vec2(1.0, 0.0);
38    return mix(mix(mix(hash31(i + e.yyy), hash31(i + e.xyy), u.x),
39                   mix(hash31(i + e.yxy), hash31(i + e.xxy), u.x), u.y),
40               mix(mix(hash31(i + e.yyx), hash31(i + e.xyx), u.x),
41                   mix(hash31(i + e.yxx), hash31(i + e.xxx), u.x), u.y),
42               u.z);
43}
44
45// フラクタルブラウン運動: 周波数を 2 倍、振幅を半分にしながらノイズを重ねる
46float fbm(vec3 p)
47{
48    float value = 0.0;
49    float amplitude = 0.5;
50    for (int i = 0; i < 5; i++) {
51        value += amplitude * valueNoise(p);
52        p *= 2.02;
53        amplitude *= 0.5;
54    }
55    return value;
56}

雲の密度は陰影に直接は現れないため、補間には計算の軽い 3 次のエルミート補間を使っている。fBm では、オクターブごとの格子点が揃わないように、周波数の倍率を 2 ではなく 2.02 にしている。

密度

3 つの球を smooth min でつないだ SDF を雲の大まかな形とし、その値を fBm で揺らしてから密度に変換する。

16_volume.frag（抜粋）
71// 雲の大まかな形 (3 つの球を滑らかにつないだもの)
72float sdCloudShape(vec3 p)
73{
74    float d = sdSphere(p - vec3(0.0, 0.0, 0.0), 1.0);
75    d = smin(d, sdSphere(p - vec3(1.1, -0.2, 0.2), 0.75), 0.6);
76    d = smin(d, sdSphere(p - vec3(-1.1, -0.3, -0.1), 0.7), 0.6);
77    return d;
78}
79
80// ノイズで削る量の最大値。SDF がこれより大きい場所には雲が無い
81const float EROSION = 0.5;
82
83// 位置 p での密度 (0 以上)
84float density(vec3 p)
85{
86    vec3 q = p + vec3(0.15 * iTime, 0.0, 0.0);  // ノイズを流して形を変化させる
87    float d = sdCloudShape(p) + EROSION * (fbm(3.0 * q) - 0.5) * 2.0;
88    return clamp(-d * 2.0, 0.0, 1.0);
89}

ノイズで揺らした SDF が負になる場所を雲の内部とし、内部に入るほど密度が大きくなるようにしている。ノイズの項 EROSION * (fbm(3.0 * q) - 0.5) * 2.0 は \(-\mathrm{EROSION}\) 以上なので、大まかな形の SDF が EROSION より大きい場所では密度は必ず 0 になる。この性質は、後で空の空間を飛ばすときに使う。

積分の計算

離散化

ボリュームレンダリング方程式の積分は、レイを一定の歩幅 \(\Delta t\) で進みながら、区間ごとの寄与を足し合わせて求める。区間 \(i\) の中で密度が一定とみなすと、その区間で吸収・散乱される割合は \(\alpha_i = 1 - e^{-\sigma_t \Delta t}\) である。サンプルでは、散乱係数と消散係数が等しい（吸収が無い）と仮定し、次の手順で積分する。

\[L \mathrel{+}= T\, \alpha_i\, L_s(\mathbf{p}_i), \qquad T \mathrel{\times}= 1 - \alpha_i\]

最後に、残った透過率 \(T\) を背景の空の色に掛けて加える。雲の奥まで進んで \(T\) がほぼ 0 になったら、それ以降の寄与は無視できるので、ループを打ち切る。

16_volume.frag（抜粋）
113vec3 render(vec3 ro, vec3 rd, float jitter)
114{
115    vec3 col = vec3(0.0);        // 雲から視点に届く光の合計
116    float transmittance = 1.0;   // 視点から現在位置までの透過率
117
118    // 光が進行方向の前方に散乱しやすいことを近似する位相関数
119    float mu = dot(rd, LIGHT_DIR);
120    float phase = 0.6 + 0.8 * pow(max(mu, 0.0), 4.0);
121
122    float t = jitter * STEP_SIZE;
123    for (int i = 0; i < VOLUME_STEPS; i++) {
124        vec3 p = ro + t * rd;
125        float shape = sdCloudShape(p);
126        if (shape > EROSION) {
127            // 雲の外: SDF を使って空の空間を一気に飛ばす
128            t += max(shape - EROSION, STEP_SIZE);
129        } else {
130            float dens = density(p);
131            if (dens > 0.0) {
132                // この区間で吸収・散乱される割合
133                float absorbed = 1.0 - exp(-SIGMA * dens * STEP_SIZE);
134                vec3 light = SUN_COLOR * lightTransmittance(p) * phase +
135                             AMBIENT;
136                col += transmittance * absorbed * light;
137                transmittance *= 1.0 - absorbed;
138                if (transmittance < 0.01) {
139                    break;   // ほとんど光が届かないので打ち切る
140                }
141            }
142            t += STEP_SIZE;
143        }
144        if (t > 20.0) {
145            break;
146        }
147    }
148    // 雲を透過した分だけ背景の空が見える
149    return col + transmittance * skyColor(rd);
150}

SDF による空の空間の飛ばし

一定の歩幅で進むと、雲の外の何も無い空間でも多くの反復を費やしてしまう。そこで、雲の外では大まかな形の SDF を使って、密度が 0 であることが保証された距離だけ一気に進む。前節で述べたとおり、大まかな形の SDF が EROSION より大きい場所では密度が 0 なので、shape - EROSION だけ進んでも雲を飛ばすことはない。スフィアトレーシングとボリュームレンダリングを組み合わせることで、計算量を大きく減らせる。

太陽光の透過率

各点での太陽光の透過率 \(T_{\text{light}}\) も、光源の方向に少しずつ進んで密度を足し合わせて求める。

16_volume.frag（抜粋）
 91// 点 p から光源の方向に進み、途中の密度から光の透過率を求める
 92float lightTransmittance(vec3 p)
 93{
 94    float sum = 0.0;
 95    const float stepSize = 0.15;
 96    for (int i = 1; i <= LIGHT_STEPS; i++) {
 97        sum += density(p + LIGHT_DIR * stepSize * float(i));
 98    }
 99    return exp(-SIGMA * sum * stepSize);
100}

視線方向の反復 1 回ごとにこの反復が入るため、計算量は両者の反復回数の積になる。光源に向かう方向の反復回数 LIGHT_STEPS は、見た目が大きく変わらない範囲でなるべく小さくする。

縞模様の抑制

一定の歩幅で進むと、すべてのピクセルでサンプリングする位置が揃うため、雲の中に等高線のような縞模様が現れる。サンプルでは、ピクセルの座標とフレーム番号をハッシュ関数に通して得た乱数 jitter で開始位置をずらし、縞模様を細かいノイズに置き換えている。ノイズは縞模様よりも目立ちにくく、複数のフレームを平均すれば消える。

ここで使っている乱数は、ハッシュ関数で作った白色ノイズ（第 10 章）で、隣り合うピクセルの値に相関が無い。そのため、たまたま近い値が固まった場所が、粗い斑点として見える。これに対し、隣り合うピクセルの値がなるべく異なるように並べた乱数を ブルーノイズ と呼ぶ。ブルーノイズは低い周波数の成分が少なく、高い周波数の成分だけからなるため、同じサンプル数でもノイズが細かく均一に見え、目立ちにくい。ブルーノイズは計算で作るのが難しいので、あらかじめ作成したテクスチャ（Peters による公開データなど）を読み込んで使うのが一般的である。ジッターのほか、第 17 章のパストレーシングのサンプリングや、ディザリングにも使われる。

大気の散乱

第 7 章では、空の色を地平線から天頂への単純なグラデーションで描いた。実際の空の色は、太陽の光が大気中の分子やエアロゾル（微粒子）で散乱されることで生まれる。この章の関与媒質の考え方を大気全体に適用すると、昼の青空から夕焼けまでを 1 つのモデルで描ける。この手法は Nishita ら（1993）による単一散乱のモデルに基づく。

2 種類の散乱

大気による散乱は、粒子の大きさによって性質が大きく異なる。

昼の空が青いのは、青い光がレイリー散乱で空全体に散らばるためである。夕方に太陽が地平線に近づくと、太陽の光は大気の中を長い距離通ってくるため、青い光が途中で散乱されて失われ、残った赤や橙の光が届く。

大気のモデル

地球を半径 \(R_E = 6360\) km の球、大気の上端を半径 \(R_A = 6420\) km の球とする。粒子の密度は高さ \(h\) とともに指数関数的に減少するとし、レイリー散乱とミー散乱のそれぞれについて、海面での散乱係数 \(\beta\) とスケールハイト \(H\) （密度が \(1/e\) になる高さ）で表す。

\[\beta_R(h) = \beta_R(0)\, e^{-h/H_R}, \qquad \beta_M(h) = \beta_M(0)\, e^{-h/H_M}\]

サンプルでは、\(\beta_R(0) = (5.8, 13.5, 33.1) \times 10^{-6}\ \text{m}^{-1}\) （RGB）、\(H_R = 8\) km、\(\beta_M(0) = 21 \times 10^{-6}\ \text{m}^{-1}\)、\(H_M = 1.2\) km としている。

単一散乱の積分

視点から方向 \(\hat{\mathbf{d}}\) を見たときに届く光は、この章の前半で説明したボリュームレンダリング方程式と同じ形で書ける。視線上の各点 \(\mathbf{p}\) で、太陽から \(\mathbf{p}\) まで届いた光が散乱され、\(\mathbf{p}\) から視点までの間で減衰する。

\[L = \int_0^{t_{\max}} \bigl(\beta_R(h)\, P_R(\theta) + \beta_M(h)\, P_M(\theta)\bigr)\, T(\text{太陽} \to \mathbf{p} \to \text{視点})\, E_{\text{sun}}\, dt\]

\(P_R, P_M\) はそれぞれの位相関数、\(\theta\) は視線と太陽の方向のなす角、\(T\) は太陽から \(\mathbf{p}\) を経て視点に至る経路全体の透過率である。透過率は、経路上の光学的深さ（密度 × 距離の積分）から求める。

\[T = \exp\Bigl(-\beta_R(0)\, D_R - 1.1\, \beta_M(0)\, D_M\Bigr)\]

\(D_R, D_M\) は、それぞれの密度（海面を 1 とする）を経路に沿って積分した値である。ミー散乱の係数に掛けている 1.1 は、エアロゾルによる吸収を含めた消散係数を散乱係数から近似するための係数である。

16_atmosphere.frag（抜粋）
57// 視点 ro から方向 rd を見たときに届く、散乱された太陽光
58vec3 skyRadiance(vec3 ro, vec3 rd, vec3 sunDir)
59{
60    // 大気の中を進む区間を求める。地面に当たる場合は地面まで
61    float tEnd = raySphere(ro, rd, ATMOSPHERE_RADIUS).y;
62    vec2 ground = raySphere(ro, rd, EARTH_RADIUS);
63    if (ground.x > 0.0) {
64        tEnd = ground.x;
65    }
66    float ds = tEnd / float(VIEW_SAMPLES);
67
68    vec3 sumRayleigh = vec3(0.0);
69    vec3 sumMie = vec3(0.0);
70    vec2 depthView = vec2(0.0);   // 視点からサンプル点までの光学的深さ
71    for (int i = 0; i < VIEW_SAMPLES; i++) {
72        vec3 p = ro + (float(i) + 0.5) * ds * rd;
73        vec2 density = densityAt(p) * ds;
74        depthView += density;
75        // 太陽の光が地球に遮られる点は、散乱に寄与しない
76        if (raySphere(p, sunDir, EARTH_RADIUS).x > 0.0) {
77            continue;
78        }
79        vec2 depthSun = opticalDepthToSun(p, sunDir);
80        // 太陽 → サンプル点 → 視点 の経路の透過率 (ランベルト・ベールの法則)
81        vec2 depth = depthView + depthSun;
82        vec3 tau = BETA_RAYLEIGH * depth.x + 1.1 * BETA_MIE * depth.y;
83        vec3 transmittance = exp(-tau);
84        sumRayleigh += transmittance * density.x;
85        sumMie += transmittance * density.y;
86    }
87
88    // 位相関数: レイリー散乱は前後に対称、ミー散乱は前方に強い
89    float mu = dot(rd, sunDir);
90    float phaseRayleigh = 3.0 / (16.0 * PI) * (1.0 + mu * mu);
91    float g2 = MIE_G * MIE_G;
92    float phaseMie = 3.0 / (8.0 * PI) * ((1.0 - g2) * (1.0 + mu * mu)) /
93                     ((2.0 + g2) * pow(1.0 + g2 - 2.0 * MIE_G * mu, 1.5));
94
95    return SUN_INTENSITY * (sumRayleigh * BETA_RAYLEIGH * phaseRayleigh +
96                            sumMie * BETA_MIE * phaseMie);
97}

視線方向の積分では 16 点、各点から太陽の方向の積分では 8 点で密度を評価している。大気と地面の範囲は、レイと球の交点を解析的に求めて決める（関数 raySphere）。形状が単純な球なので、ここではスフィアトレーシングを使う必要がない。

位相関数には、レイリー散乱に \(P_R(\theta) = \frac{3}{16\pi}(1 + \cos^2\theta)\) を、ミー散乱に Henyey-Greenstein 位相関数を改良した Cornette-Shanks の式を使っている。ミー散乱の \(g = 0.76\) は、太陽のまわりの明るいかさを作る。

この単一散乱のモデルでは、一度散乱された光がもう一度散乱される多重散乱を無視している。そのため、日没後の空や、エアロゾルの多いかすんだ空は、実際より暗くなる。多重散乱まで含めて計算した結果を、あらかじめテクスチャに保存しておく方法（Bruneton and Neyret, 2008 など）が、ゲームなどで広く使われている。
