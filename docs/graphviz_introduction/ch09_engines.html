9. レイアウトエンジン

Graphviz には、ノードの配置の方式が異なる複数のレイアウトエンジンがあります。これまでの章で使ってきた dot は、そのうちの 1 つです。この章では、各レイアウトエンジンの特徴と使い分けを説明します。

9.1. レイアウトエンジンの一覧

エンジン

配置の方式

向いている図

dot

ノードを段に分けて、エッジの向きに沿って並べます。

有向グラフ全般。フローチャート、依存関係図、ツリー図など。

neato

ノード間の距離が、グラフ上の距離（経由するエッジの数）に近くなるように配置します。

100 ノード程度までの無向グラフ。ネットワーク図など。

fdp

エッジをばね、ノードどうしを反発する粒子とみなした力学モデルで配置します。

neato と同様の図。クラスターにも対応しています。

sfdp

fdp を大規模なグラフ向けに改良した方式です。

数千ノード以上の大規模なグラフ。

circo

ノードを円周上に並べます。

環状の構造を持つグラフ。

twopi

中心のノードから同心円状に広がるように配置します。

1 つのノードを中心とする放射状の図。

osage

クラスターを入れ子の箱として詰めて配置します。

クラスターが中心のグラフ。

patchwork

クラスターとノードを、面積で大きさを表すツリーマップとして描きます。

大きさの比率を見せる図。

9.2. レイアウトエンジンの指定方法

レイアウトエンジンは、次のいずれかの方法で指定します。

方法

例

dot コマンドの -K オプション

dot -Kneato -Tsvg in.dot -o out.svg

エンジンと同じ名前のコマンド

neato -Tsvg in.dot -o out.svg

グラフの layout 属性

DOT ファイルに layout=neato; と書きます。

layout 属性を使うと、DOT ファイルだけで使用するレイアウトエンジンがわかるので、ほかの人に DOT ファイルを渡す場合に便利です。

9.3. 同じグラフを描き比べる

次のグラフを、各レイアウトエンジンで描いてみます。

examples/dot/ch09_engines.dot
// レイアウトエンジンの比較に使うグラフ
graph engines {
    node [shape=circle, width=0.4, fixedsize=true, style=filled,
          fillcolor=lightblue];

    a -- {b c d e};
    b -- {f g};
    c -- {h i};
    d -- {j k};
    e -- {l m};
    f -- g;
    h -- i;
}

9.3.1. dot

エッジの向きがない無向グラフでも、dot はノードを段に分けて配置します。a から枝分かれする構造が、ツリーのように上から下へ描かれます。

9.3.2. neato

エッジでつながったノードどうしが近くに、つながっていないノードどうしが離れて配置されます。段の構造がないため、グラフの形そのものが見えやすくなります。

9.3.3. fdp

neato と似た配置になりますが、計算の方式が異なるため、ノードの位置は同じにはなりません。

9.3.4. sfdp

小さなグラフでは fdp と大きな違いはありません。数千ノードを超えるグラフでも、現実的な時間で配置できる点が特徴です。

9.3.5. circo

環状の部分（b、f、g や c、h、i）が円として描かれます。

9.3.6. twopi

中心のノードから外側へ広がるように配置されます。中心のノードは、グラフの root 属性で指定できます。指定しない場合は、Graphviz が自動的に選びます。

9.3.7. osage

osage と patchwork は、クラスターの構造を見せるためのレイアウトエンジンなので、クラスターのないこのグラフには向きません。代わりに、8 章のクラスターの例を osage で描くと次のようになります。クラスターが入れ子の箱として詰めて並べられます。

patchwork は、ノードの area 属性で指定した面積の比率で、クラスターとノードを長方形のタイルとして敷き詰めます。ディスクの使用量のように、階層と大きさを同時に見せる図に使います。

9.4. レイアウトエンジンの選び方

迷った場合は、次のように選ぶとよいでしょう。

  • エッジに向きがあり、流れや階層を見せたい場合は dot を使います。多くの図はこれで足ります。

  • エッジに向きがなく、つながりの構造を見せたい場合は neato を使います。

  • ノードが数千を超える場合は sfdp を使います。

  • 中心となるノードがある場合は twopi を、環状の構造を見せたい場合は circo を試します。

neato、fdp、sfdp では、ノードが重なって描かれることがあります。その場合は、グラフに overlap=false を指定すると、重なりを取り除くようにノードの位置が調整されます。

また、7 章で説明した rankdir、rank、weight（dot での意味）などは dot 専用の属性で、ほかのレイアウトエンジンでは無視されるか、別の意味になります。レイアウトエンジンを切り替えたら、属性の効果も確認し直してください。
