1. はじめに

1.1. Graphviz とは

Graphviz は、グラフを自動的に配置して描画するオープンソースのソフトウェアです。ここでいうグラフは、棒グラフや折れ線グラフのようなデータのグラフではなく、ノード（点）とエッジ（線）で「もの」と「もののつながり」を表す図のことです。AT&T の研究所で開発が始まり、現在はオープンソースのプロジェクトとして開発が続けられています。

Graphviz では、図を DOT 言語というテキストで記述します。たとえば、次の 3 行は「Hello から World へ矢印を引く」という図を表します。

// 最初のグラフ：2 つのノードを 1 本のエッジで結ぶ
digraph hello {
    Hello -> World;
}

このテキストを Graphviz に渡すと、ノードの位置やエッジの経路が自動的に計算され、次のような図が出力されます。

利用者が記述するのは「どのノードがあり、どのノードとどのノードがつながっているか」だけです。ノードをどこに置くか、エッジをどう曲げるかといった配置は Graphviz が決めます。

1.2. Graphviz で描ける図

ノードとエッジで表せるものであれば、どのような図でも描けます。エンジニアの業務では、たとえば次のような図に使われます。

図の種類

例

依存関係図

モジュールやパッケージの import の関係、タスクの実行順序

状態遷移図

注文やチケットの状態の移り変わり

フローチャート

処理の流れや分岐

構成図

システムのコンポーネントと、その間の通信

ER 図、クラス図

データベースのテーブルの関係、クラスの継承関係

ツリー図

フォルダーの構成、組織図、決定木

1.3. テキストで図を書く利点

作図ソフトウェアでマウスを使って図を描く方法と比べて、Graphviz には次の利点があります。

  • 配置を考えなくてよい：ノードを追加しても、全体の配置が自動的に計算し直されます。手作業でノードを並べ直す必要はありません。

  • 差分を管理できる：図がテキストなので、Git などのバージョン管理システムで変更の差分を確認したり、レビューしたりできます。

  • プログラムで生成できる：DOT はテキストなので、どのプログラミング言語からでも簡単に出力できます。ソースコードやデータベースの定義から図を自動生成すれば、図が実態と食い違うこともなくなります。

一方で、ノードを思いどおりの位置に置くことは得意ではありません。配置はあくまで Graphviz に任せ、属性でおおまかな方向を指示する、という使い方が基本になります。配置を調整する方法は 7 章で説明します。
