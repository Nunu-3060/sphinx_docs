2. 環境構築

p5.js のスケッチを動かす方法は、大きく分けて次の 2 つです。

方法

特徴

向いている場面

p5.js Web Editor

ブラウザーだけで編集と実行ができる。インストールは不要。

手軽に試したいとき、作品を共有したいとき

ローカル環境

手元のエディターでファイルを編集し、ブラウザーで開く。

複数のファイルを扱うとき、普段の開発環境で書きたいとき

まずは Web Editor で動かしてみて、慣れてきたらローカル環境に移るのがおすすめです。

2.1. p5.js Web Editor

p5.js Web Editor は、p5.js の公式のオンラインエディターです。開くと、次のようなコードがすでに入力されています。

1function setup() {
2  createCanvas(400, 400);
3}
4
5function draw() {
6  background(220);
7}

画面上部の再生ボタン（▶）を押すと、右側のプレビューに灰色の正方形が表示されます。これが キャンバス です。コードを書き換えて再生ボタンを押すと、結果が更新されます。

アカウントを登録すると、スケッチを保存したり、URL で他の人と共有したりできます。

2.2. ローカル環境

ローカル環境では、次の 2 つのファイルを 1 つのフォルダーに置きます。

ファイル

役割

index.html

ブラウザーが最初に開くファイル。p5.js 本体とスケッチを読み込む。

sketch.js

スケッチ本体。p5.js の関数を使って描画の処理を書く。

index.html の内容は次のとおりです。本書のサンプルは、すべてこの形をしています。

リスト 2.1 ch02_hello/index.html
 1<!DOCTYPE html>
 2<html lang="ja">
 3<head>
 4  <meta charset="utf-8">
 5  <meta name="viewport" content="width=device-width, initial-scale=1">
 6  <title>第 2 章 はじめてのスケッチ</title>
 7  <!-- p5.js 本体を CDN から読み込む（バージョンを固定する） -->
 8  <script src="https://cdn.jsdelivr.net/npm/p5@2.3.4/lib/p5.min.js"></script>
 9  <style>
10    body { margin: 0; }
11  </style>
12</head>
13<body>
14  <!-- スケッチ本体。p5.js より後に読み込む -->
15  <script src="sketch.js"></script>
16</body>
17</html>

8 行目で p5.js 本体を CDN から読み込み、15 行目でスケッチ本体の sketch.js を読み込んでいます。sketch.js は p5.js が提供する関数を使うため、必ず p5.js より後に読み込みます。

URL の p5@2.3.4 の部分はバージョンの指定です。バージョンを固定しておくと、p5.js が更新されてもスケッチの動作が変わりません。

sketch.js には、マウスに付いてくる円を描くコードを書きます。

リスト 2.2 ch02_hello/sketch.js
 1// はじめてのスケッチ：マウスに付いてくる円を描く
 2
 3function setup() {
 4  // 幅 400 ピクセル、高さ 400 ピクセルのキャンバスを作る
 5  createCanvas(400, 400);
 6}
 7
 8function draw() {
 9  // 毎フレーム、背景を明るい灰色で塗りつぶす
10  background(220);
11  // マウスの位置に直径 50 ピクセルの円を描く
12  circle(mouseX, mouseY, 50);
13}

index.html をダブルクリックしてブラウザーで開き、キャンバスの上でマウスを動かすと、円が付いてきます。コードの意味は スケッチの基本構造 で詳しく説明します。

エディターは何を使ってもかまいません。Visual Studio Code などの、JavaScript の入力補完や構文の色分けに対応したエディターを使うと便利です。

2.3. ローカルサーバー

index.html をダブルクリックして開くと、ブラウザーのアドレス欄は file:// で始まります。この状態では、ブラウザーのセキュリティ制限により、JSON などの外部ファイルを読み込めません。画像・テキスト・外部データ のように外部ファイルを使うスケッチは、ローカルサーバー を経由して開く必要があります。

Python がインストールされていれば、標準ライブラリの http.server モジュールでローカルサーバーを起動できます。サンプルのフォルダーで次のコマンドを実行します。

1python -m http.server 8000

ブラウザーで http://localhost:8000/ を開くと、フォルダーの中身が一覧表示されます。終了するには、コマンドを実行した端末で Ctrl+C を押します。

本書のサンプルには、同じことをするスクリプト serve.py も含めています。serve.py は、起動と同時にブラウザーを開き、JavaScript ファイルを正しい MIME タイプで返します。Windows では、レジストリの設定によって .js ファイルが text/plain として返され、スクリプトが動かない場合があるため、その対策を入れています。

リスト 2.3 serve.py
 1"""p5.js のサンプルをローカルで確認するための HTTP サーバー。
 2
 3使い方::
 4
 5    python serve.py              # このファイルがあるフォルダーを公開する
 6    python serve.py --port 8080  # ポート番号を指定する
 7
 8起動すると既定のブラウザーで http://localhost:8000/ が開きます。
 9終了するには Ctrl+C を押します。
10"""
11
12import argparse
13import functools
14import http.server
15import webbrowser
16from pathlib import Path
17
18DEFAULT_PORT = 8000
19
20
21class SketchRequestHandler(http.server.SimpleHTTPRequestHandler):
22    """JavaScript と JSON を正しい MIME タイプで返すハンドラー。
23
24    Windows では、レジストリの設定によって .js が text/plain として
25    返される場合があるため、明示的に指定する。
26    """
27
28    extensions_map = {
29        **http.server.SimpleHTTPRequestHandler.extensions_map,
30        ".js": "text/javascript",
31        ".json": "application/json",
32    }
33
34
35def parse_args() -> argparse.Namespace:
36    """コマンドライン引数を解析する。"""
37    parser = argparse.ArgumentParser(
38        description="p5.js のサンプルを配信する HTTP サーバー"
39    )
40    parser.add_argument(
41        "--port",
42        type=int,
43        default=DEFAULT_PORT,
44        help=f"待ち受けるポート番号（既定値: {DEFAULT_PORT}）",
45    )
46    parser.add_argument(
47        "--directory",
48        type=Path,
49        default=Path(__file__).resolve().parent,
50        help="公開するフォルダー（既定値: このファイルがあるフォルダー）",
51    )
52    parser.add_argument(
53        "--no-browser",
54        action="store_true",
55        help="起動時にブラウザーを開かない",
56    )
57    return parser.parse_args()
58
59
60def serve(directory: Path, port: int, open_browser: bool) -> None:
61    """指定したフォルダーを HTTP で公開し、Ctrl+C が押されるまで待つ。"""
62    handler = functools.partial(SketchRequestHandler, directory=str(directory))
63    address = ("localhost", port)
64    with http.server.ThreadingHTTPServer(address, handler) as httpd:
65        url = f"http://localhost:{port}/"
66        print(f"{directory} を {url} で公開しています（Ctrl+C で終了）")
67        if open_browser:
68            webbrowser.open(url)
69        try:
70            httpd.serve_forever()
71        except KeyboardInterrupt:
72            print("\nサーバーを終了しました")
73
74
75def main() -> None:
76    """エントリポイント。"""
77    args = parse_args()
78    serve(args.directory, args.port, not args.no_browser)
79
80
81if __name__ == "__main__":
82    main()

  • ダウンロード：serve.py

serve.py を置いたフォルダーで次のように実行します。

1python serve.py
2python serve.py --port 8080

2.4. 開発者ツール

スケッチが思ったとおりに動かないときは、ブラウザーの 開発者ツール を開きます。Chrome や Edge では F12 キー、macOS では Command+Option+I キーで開けます。

開発者ツールの「コンソール」タブには、次の内容が表示されます。

  • JavaScript のエラー（エラーが起きたファイル名と行番号を含む）

  • console.log() で出力した値

console.log() は Python の print() に相当し、変数の値を確認するのに使います。

1console.log('x の値:', x);

p5.js には、よくある間違いを分かりやすいメッセージで教えてくれる Friendly Error System（FES）があります。ただし、FES は圧縮版の p5.min.js では無効になっています。学習中にエラーの原因が分からないときは、index.html の読み込み先を圧縮していない p5.js に変えると、詳しいメッセージが表示されます。

1<script src="https://cdn.jsdelivr.net/npm/p5@2.3.4/lib/p5.js"></script>
