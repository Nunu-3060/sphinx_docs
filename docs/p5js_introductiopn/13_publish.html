13. 作品の保存と公開

この章では、作ったスケッチを画像や動画として保存する方法と、Web で公開する方法を説明します。

13.1. 画像として保存する

saveCanvas() を呼ぶと、その時点のキャンバスを画像ファイルとして保存できます。ブラウザーのダウンロード機能でファイルが保存されます。

1function keyPressed() {
2  if (key === 's') {
3    saveCanvas('my-sketch', 'png');  // my-sketch.png として保存
4  }
5}

2 番目の引数には 'png' または 'jpg' を指定します。インタラクション のお絵かきツールでも、この方法で絵を保存しています。

saveCanvas() を draw() の中で無条件に呼ぶと、毎フレーム画像が保存されてしまいます。上の例のように、キー操作などのイベント関数の中で呼びます。

13.2. GIF アニメーションとして保存する

saveGif() を使うと、スケッチの動きを GIF アニメーションとして保存できます。2 番目の引数は、記録する長さ（秒）です。

1function keyPressed() {
2  if (key === 'g') {
3    saveGif('my-animation', 3);  // 3 秒分を記録して保存
4  }
5}

記録中は画面に進捗が表示され、終わると GIF ファイルが保存されます。キャンバスが大きいほど、また記録時間が長いほど、処理に時間がかかり、ファイルも大きくなります。

13.3. Web Editor で共有する

p5.js Web Editor でアカウントを登録してスケッチを保存すると、スケッチごとに URL が割り当てられます。この URL を共有すれば、他の人もブラウザーでスケッチを閲覧・実行できます。

13.4. GitHub Pages で公開する

スケッチは HTML と JavaScript だけで動くため、静的なファイルを配信できる Web サーバーであれば、どこにでも置けます。ここでは、GitHub が提供する無料のホスティングサービスである GitHub Pages を使う方法の概略を説明します。

  1. GitHub にリポジトリを作成し、index.html と sketch.js などのファイルをアップロード（プッシュ）する。

  2. リポジトリの「Settings」から「Pages」を開き、公開に使うブランチとフォルダーを選んで保存する。

  3. しばらく待つと、https://ユーザー名.github.io/リポジトリ名/ でスケッチが公開される。

GitHub Pages は、既定では Jekyll という静的サイト生成ツールでファイルを処理してから公開します。Jekyll は、名前が _（アンダースコア）で始まるフォルダーやファイルを公開対象から除外します。そのため、_ で始まるフォルダーに画像などを置いていると、公開後に読み込めなくなります。

この処理を無効にするには、リポジトリの公開フォルダーに .nojekyll という名前の空のファイルを置きます。本書の HTML も、Sphinx が出力する _static などのフォルダーを含むため、.nojekyll を出力する設定でビルドしています。

13.5. 公開前の確認

公開する前に、次の点を確認します。

  • ローカルサーバー経由で開いて、エラーなく動作するか。

  • 外部ファイルのパスが、公開先のフォルダー構成と合っているか。パスの大文字と小文字も区別されるため、ファイル名と完全に一致させる。

  • p5.js のバージョンを固定しているか。
