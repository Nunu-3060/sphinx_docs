11. ベクトルとオブジェクト指向

この章では、位置や速度をまとめて扱う p5.Vector と、JavaScript のクラスを組み合わせて、多数の粒子が動く パーティクル を作ります。

11.1. p5.Vector

アニメーション では、位置と速度を x、y、vx、vy という別々の変数で扱いました。動かす物体が増えたり、力を扱ったりするようになると、変数が増えてコードが読みにくくなります。

p5.Vector は、x 成分と y 成分をまとめて 1 つの ベクトル として扱うクラスです。createVector() で作成します。

1const position = createVector(100, 200);
2const velocity = createVector(3, -2);
3position.add(velocity);       // position は (103, 198) になる
4console.log(position.x, position.y);

主なメソッドを次の表に示します。

メソッド

動作

v.add(w)

v に w を加える。

v.sub(w)

v から w を引く。

v.mult(s)

v を s 倍する。

v.mag()

v の大きさ（長さ）を返す。

v.normalize()

v の向きを変えずに、大きさを 1 にする。

v.limit(max)

v の大きさが max を超えないように制限する。

v.heading()

v の向き（x 軸からの角度）を返す。

v.copy()

v の複製を返す。

add() や mult() などのメソッドは、新しいベクトルを返すのではなく、v 自身の値を書き換えます。元のベクトルを残したいときは、v.copy().add(w) のように複製してから計算するか、p5.Vector.add(v, w) のように静的メソッドを使います。静的メソッドは、計算結果を新しいベクトルとして返します。

11.2. 位置・速度・加速度

ベクトルを使うと、重力などの力を受けて動く物体を簡潔に表現できます。フレームごとに、次の順で値を更新します。

\[\boldsymbol{v} \leftarrow \boldsymbol{v} + \boldsymbol{a}, \quad \boldsymbol{p} \leftarrow \boldsymbol{p} + \boldsymbol{v}\]

ここで \(\boldsymbol{p}\) は位置、\(\boldsymbol{v}\) は速度、\(\boldsymbol{a}\) は加速度です。重力のように一定の加速度を加え続けると、物体は放物線を描いて落下します。

11.3. クラスで粒子を表す

1 つの粒子が持つデータ（位置、速度、寿命）と処理（更新、描画）を、クラスにまとめます。

リスト 11.1 ch11_particles/sketch.js（Particle クラス）
 7class Particle {
 8  constructor(x, y) {
 9    this.position = createVector(x, y);
10    // 上向きを基本に、ランダムな向きと速さを与える
11    this.velocity = createVector(random(-1, 1), random(-5, -3));
12    this.life = 255;  // 残りの寿命（透明度としても使う）
13  }
14
15  // 速度に重力を加え、位置に速度を加える
16  update() {
17    this.velocity.add(gravity);
18    this.position.add(this.velocity);
19    this.life -= 3;
20  }
21
22  show() {
23    noStroke();
24    fill(255, 150, 0, this.life);
25    circle(this.position.x, this.position.y, 10);
26  }
27
28  isDead() {
29    return this.life <= 0;
30  }
31}

this.life は粒子の残りの寿命で、フレームごとに 3 ずつ減ります。この値を透明度にも使っているため（24 行目）、粒子は時間とともに薄くなって消えていきます。

11.4. 配列で多数の粒子を管理する

粒子は配列に入れて管理します。毎フレーム新しい粒子を追加し、寿命が尽きた粒子を配列から削除します。

配列から要素を削除するには splice(添字, 個数) を使います。ループの途中で要素を削除すると、それより後ろの要素の添字が 1 つずつ前にずれます。前から順に処理していると、削除した要素の次の要素が処理されずに飛ばされてしまいます。そのため、配列の後ろから前に向かって処理します。

11.5. サンプル

噴水のように粒子が噴き出すサンプルです。マウスボタンを押している間は、マウスの位置から粒子が出ます。

リスト 11.2 ch11_particles/sketch.js
 1// p5.Vector とクラスを使ったパーティクル（粒子）の噴水
 2// マウスボタンを押している間は、マウスの位置から粒子が出る
 3
 4const particles = [];
 5let gravity;  // 重力を表すベクトル（createVector() は setup() 以降で使う）
 6
 7class Particle {
 8  constructor(x, y) {
 9    this.position = createVector(x, y);
10    // 上向きを基本に、ランダムな向きと速さを与える
11    this.velocity = createVector(random(-1, 1), random(-5, -3));
12    this.life = 255;  // 残りの寿命（透明度としても使う）
13  }
14
15  // 速度に重力を加え、位置に速度を加える
16  update() {
17    this.velocity.add(gravity);
18    this.position.add(this.velocity);
19    this.life -= 3;
20  }
21
22  show() {
23    noStroke();
24    fill(255, 150, 0, this.life);
25    circle(this.position.x, this.position.y, 10);
26  }
27
28  isDead() {
29    return this.life <= 0;
30  }
31}
32
33function setup() {
34  createCanvas(400, 400);
35  gravity = createVector(0, 0.1);
36}
37
38function draw() {
39  background(20);
40
41  // 粒子の発生位置（マウスボタンを押している間はマウスの位置）
42  let originX = width / 2;
43  let originY = height - 80;
44  if (mouseIsPressed) {
45    originX = mouseX;
46    originY = mouseY;
47  }
48
49  // 毎フレーム、新しい粒子を 3 個追加する
50  for (let i = 0; i < 3; i++) {
51    particles.push(new Particle(originX, originY));
52  }
53
54  // 後ろから順に処理すると、途中で要素を削除しても添字がずれない
55  for (let i = particles.length - 1; i >= 0; i--) {
56    const particle = particles[i];
57    particle.update();
58    particle.show();
59    if (particle.isDead()) {
60      particles.splice(i, 1);  // 配列から i 番目の要素を削除する
61    }
62  }
63
64  fill(255);
65  textSize(14);
66  text(`粒子の数: ${particles.length}`, 10, 20);
67}

  • 実行する

  • ダウンロード：index.html、sketch.js

5 行目の gravity は、宣言だけを関数の外で行い、値は setup() の中で代入しています（35 行目）。createVector() は p5.js の初期化が終わってから使える関数であるため、関数の外では呼べないからです。

左上に表示される粒子の数は、追加と削除がつり合うと一定になります。寿命を 255 から 3 ずつ減らしているため、1 つの粒子は 85 フレームで消えます。毎フレーム 3 個ずつ追加するので、画面上の粒子はおよそ \(85 \times 3 = 255\) 個で安定します。
