用語集

本書で使う主な用語を説明します。

CDN

Content Delivery Network の略。ライブラリなどのファイルを、世界中のサーバーから高速に配信する仕組み。本書では p5.js 本体を jsDelivr という CDN から読み込む。

Friendly Error System

p5.js が持つ、初心者向けのエラーメッセージ表示機能。FES と略す。関数の引数の誤りなどを分かりやすく知らせる。圧縮版の p5.min.js では無効になる。

HSB

色を色相（Hue）、彩度（Saturation）、明度（Brightness）の 3 つの要素で表す方法。色合いだけを変えるといった操作がしやすい。

Promise

JavaScript で、時間のかかる処理の「将来の結果」を表すオブジェクト。await を付けると、結果が得られるまで待てる。

当たり判定

マウスの位置や物体どうしが重なっているかどうかを調べること。

アルファ値

色の透明度を表す値。p5.js の既定の設定では、0 で完全に透明、255 で完全に不透明。

アロー関数

(x) => x * 2 のように => を使って書く JavaScript の関数。

インスタンスモード

スケッチ全体を 1 つの関数として書き、p5.js の関数や変数を引数経由で使う書き方。名前の衝突を避けられ、1 つのページに複数のスケッチを置ける。

開発者ツール

ブラウザーに組み込まれた、Web ページの調査やデバッグのための機能。JavaScript のエラーや console.log() の出力をコンソールで確認できる。

キャンバス

p5.js が図形を描く領域。createCanvas() で作成する。

グローバルモード

setup() や draw() をグローバルな関数として定義する書き方。p5.js の関数や変数をそのままの名前で使える。

コールバック関数

他の関数に引数として渡し、後で呼び出してもらう関数。

座標変換

translate()、rotate()、scale() によって、図形を描く座標系そのものを移動・回転・拡大縮小すること。

ジェネラティブアート

プログラムやアルゴリズムによって、自律的に生成される作品。乱数やノイズを使うことが多い。

システム変数

mouseX や width など、p5.js があらかじめ用意し、値を自動的に更新する変数。

スケッチ

p5.js や Processing で作るプログラムの呼び方。

種

乱数やノイズの列を決める初期値。シードとも呼ぶ。同じ種を使うと、同じ乱数の列が得られる。

パーティクル

多数の小さな粒子を個別に動かして、煙や火花、噴水などを表現する手法。

パーリンノイズ

Ken Perlin が考案した、滑らかに変化する疑似乱数を生成する手法。p5.js の noise() で使われている。

非同期処理

時間のかかる処理の完了を待たずに、次の処理に進む実行方式。ファイルの読み込みやネットワーク通信で使われる。

フレーム

アニメーションを構成する 1 枚 1 枚の絵。p5.js では draw() が 1 回呼ばれるごとに 1 フレームが描かれる。

フレームレート

1 秒間に描かれるフレームの数。単位は fps（frames per second）。p5.js の既定値は 60。

ベクトル

大きさと向きを持つ量。p5.js では p5.Vector で表し、位置・速度・加速度などに使う。

ラジアン

角度の単位の 1 つ。半径と同じ長さの円弧に対する中心角を 1 ラジアンとする。\(\pi\) ラジアンが 180 度にあたる。

ローカルサーバー

自分のコンピューター上で動かす Web サーバー。file:// で開いたときのブラウザーの制限を避けるために使う。
