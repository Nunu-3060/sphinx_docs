付録 B　Pyxel Editor の操作一覧

Pyxel Editor 2.9.9 の主な操作をまとめる。macOS では Ctrl キーの代わりに Command キーを、Alt キーの代わりに Option キーを使う。詳しくは Pyxel Editor Manual を参照してほしい。

共通の操作

操作

動作

Ctrl + S

保存する。

Ctrl + Z

元に戻す。

Ctrl + Y

やり直す。

Alt + ← / →

エディタを切り替える。

Shift + Ctrl + C / X / V

編集対象（イメージバンク全体など）をまるごとコピー、切り取り、貼り付けする。

Shift + クリック（[+] / [-] ボタン）

番号を 10 ずつ増減する。

.pyxres ファイルをドラッグ & ドロップ

そのファイルを読み込む（編集中の内容は上書きされる）。

イメージエディタとタイルマップエディタ

操作

動作

S

選択ツール

P

ペンツール（Shift を押しながらドラッグすると直線）

R / Shift + R

四角形の枠 / 塗りつぶした四角形

C / Shift + C

楕円の枠 / 塗りつぶした楕円

B

塗りつぶしツール

1 ～ 8 / Shift + 1 ～ 8

色 0 ～ 7 / 色 8 ～ 15 を選ぶ（イメージエディタ）。

キャンバスを右クリック

その位置の色（タイルマップエディタではタイル）を選ぶ。

右ドラッグ

表示範囲を移動する。

矢印キー

編集範囲を移動する。

Shift + 矢印キー

選んでいるタイルを移動する（タイルマップエディタ）。

Ctrl + A / C / X / V

全体を選択 / コピー / 切り取り / 貼り付け（選択ツール使用時）。

H / V

選んだ範囲を左右反転 / 上下反転（選択ツール使用時）。

画像ファイルをドラッグ & ドロップ

編集範囲の位置に画像を読み込む（イメージエディタ）。

サウンドエディタとミュージックエディタ

操作

動作

スペース

再生 / 停止

Shift + スペース

カーソルの位置から再生する。

L

ループ再生を切り替える。

↑ / ↓

ピアノロールと TON、VOL、EFX の行を切り替える（サウンドエディタ）。編集するチャンネルを切り替える（ミュージックエディタ）。

← / →

カーソルを移動する。

Z S X D C V G B H N J M

下のオクターブのド ～ シ（サウンドエディタ）

Q 2 W 3 E R 5 T 6 Y 7 U

上のオクターブのド ～ シ（サウンドエディタ）

A

休符（サウンドエディタ）

上記のキー + Enter

カーソルの位置にノートを入力する（サウンドエディタ）。

PageUp / PageDown

鍵盤のオクターブを上げる / 下げる（サウンドエディタ）。

T / S / P / N

音色を入力する（TON の行）。

0 ～ 7

音量を入力する（VOL の行）。

N / S / V / F / H / Q

エフェクトを入力する（EFX の行）。

BackSpace / Delete

カーソルの前 / 位置のノートを削除する。

Ctrl + U / D

選んだ範囲の音を半音上げる / 下げる（サウンドエディタ）。
