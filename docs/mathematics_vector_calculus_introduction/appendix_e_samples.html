付録 E サンプルコード一覧

本書で使ったサンプルコードの一覧である。ファイル名をクリックすると、そのファイルをダウンロードできる。すべてのファイルをまとめた examples.zip もある。ZIP ファイルを展開すると、examples フォルダーの中に次の構成でファイルが配置される。

1examples/
2├── setup.cfg      flake8 と mypy の設定
3├── vc_plot.py     図の描画の補助モジュール
4└── ch01_*.py 〜 ch18_*.py  各章のサンプル

実行と検査の方法

サンプルは examples フォルダーで実行する。図を描くサンプルは画面に図を表示し、計算をするサンプルは結果を表示する。多くのサンプルは補助モジュール vc_plot.py を import するので、個別にダウンロードした場合は、一覧の「必要なもの」の列に示したファイルも同じフォルダーに置く。必要なパッケージ（NumPy、matplotlib、SciPy、SymPy）は第 1 章を参照。

1$ cd examples
2$ python ch05_gradient_contour.py

サンプルは、flake8（PEP 8 などのコーディング規約の検査）と mypy（型ヒントの検査）で違反がないことを確認している。examples フォルダーで次のコマンドを実行すると、setup.cfg の設定（行長 120 文字まで、mypy の strict モード）で検査できる。

1$ cd examples
2$ python -m flake8 .
3$ python -m mypy .

SciPy、SymPy、matplotlib の 3 次元グラフの機能（mpl_toolkits）は型ヒントの情報を持たないため、setup.cfg でこれらの import の検査を省略している。
