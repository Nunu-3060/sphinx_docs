SQL 入門

本資料は、Python・NumPy・pandas などを使ったプログラミングの経験がある方を対象に、データベースを操作するための言語である SQL の基礎を解説します。SQL の実行には、Python に標準で付属している SQLite を使用するため、追加のソフトウェアをインストールせずに学習を始められます。
