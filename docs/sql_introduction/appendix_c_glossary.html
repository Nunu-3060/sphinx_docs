付録 C 用語集

本資料で使用した主な用語をまとめます。括弧内は、説明している章です。

用語

説明

ACID 特性

トランザクションが備えるべき 4 つの性質（原子性、一貫性、独立性、永続性）。（12 章）

CTE（共通テーブル式）

WITH 句で名前を付けて定義した、一時的なクエリの結果。（8 章）

DBMS

データベースを管理するソフトウェア。Database Management System の略。（2 章）

NULL

値が存在しないこと、または不明であることを表す特別な値。（5 章）

ORM

Python などのクラスとテーブルを対応づけ、オブジェクトの操作としてデータベースを扱う仕組み。（14 章）

SQL インジェクション

入力された文字列が SQL 文の一部として解釈され、意図しない SQL が実行される攻撃。（14 章）

UPSERT

行がなければ追加し、あれば更新する処理。（10 章）

インデックス

特定の列の値から行をすばやく見つけるためのデータ構造。（13 章）

ウィンドウ関数

行をまとめずに、関連する行の範囲（ウィンドウ）に対して集計や順位付けを行う関数。（9 章）

外部キー

別のテーブル（または同じテーブル）の主キーを参照する列。参照先に存在しない値を許さない制約として設定できます。（2 章、11 章）

外部結合

相手のテーブルに一致する行がない行も、相手の列を NULL にして結果に残す結合。LEFT JOIN など。（7 章）

カバリングインデックス

クエリに必要な列をすべて含み、テーブル本体を読まずに結果を返せるインデックス。（13 章）

行

テーブルの 1 件分のデータ。レコードとも呼びます。（2 章）

クエリ

データベースに対する問い合わせ。主に SELECT 文を指します。（2 章）

結合

複数のテーブルの行を、条件に基づいて組み合わせる操作。（7 章）

三値論理

TRUE、FALSE、UNKNOWN の 3 つの値をとる論理。SQL の条件式の評価に使われます。（5 章）

自動コミット

BEGIN を実行せずに実行した文が、1 文ごとに自動的に確定される動作。（12 章）

集約関数

複数の行の値から 1 つの値を求める関数。COUNT()、SUM() など。（6 章）

主キー

テーブルの各行を一意に識別するための列（または列の組）。（2 章、11 章）

正規化

情報の重複をなくすように、テーブルを分割して設計すること。（11 章）

制約

テーブルに格納できる値に対する規則。NOT NULL、UNIQUE、CHECK など。（11 章）

全件走査

テーブルのすべての行を順に調べて、条件に合う行を探すこと。フルスキャンとも呼びます。（13 章）

相関サブクエリ

外側のクエリの列を参照するサブクエリ。（8 章）

サブクエリ

SQL 文の中に括弧で囲んで書いた SELECT 文。（8 章）

実行計画

DBMS が SQL 文を実行する手順。SQLite では EXPLAIN QUERY PLAN で確認できます。（13 章）

テーブル

列と行で構成される、リレーショナルデータベースのデータの格納単位。（2 章）

トランザクション

すべて成功するか、すべて取り消されるかのどちらかになる、一連の処理のまとまり。（12 章）

内部結合

条件に一致する行どうしだけを組み合わせる結合。INNER JOIN。（7 章）

ビュー

SELECT 文に名前を付けて保存し、テーブルと同じように参照できるようにしたもの。（11 章）

プレースホルダー

SQL 文の中で、後から値を渡す位置を表す記号。sqlite3 モジュールでは ? など。（14 章）

分離レベル

同時に実行されるトランザクションどうしを、どの程度分離するかの段階。（12 章）

列

テーブルのデータの項目。名前とデータ型を持ちます。カラムとも呼びます。（2 章）

ロールバック

トランザクション内の変更をすべて取り消すこと。ROLLBACK 文で行います。（12 章）
