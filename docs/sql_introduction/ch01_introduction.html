1. はじめに

1.1. 本資料の目的

データ分析やアプリケーション開発では、データベースに保存されたデータを扱う場面が数多くあります。多くのデータベースは SQL という言語で操作するため、SQL を読み書きできることはプログラマーにとって重要な技能の一つです。

本資料の目的は、SQL を初めて学ぶ方が次のことをできるようになることです。

  • SELECT 文を使って、必要なデータを絞り込み、集計し、複数のテーブルから組み合わせて取り出すこと

  • テーブルを作成し、データを追加・更新・削除すること

  • トランザクションとインデックスの役割を理解し、安全で効率的な SQL を書くこと

  • Python のプログラムから SQL を安全に実行すること

1.2. 対象読者と前提知識

本資料は、次のような方を対象としています。

  • Python で関数やクラスを使ったプログラムを書ける方

  • NumPy や pandas で表形式のデータを扱ったことがある方

  • SQL やデータベースについては、ほとんど知識がない方

本文では、SQL の考え方を説明する際に、Python や pandas で同じ処理を書いた場合との比較を適宜示します。pandas を使ったことがない方は、その部分を読み飛ばしても差し支えありません。

1.5. 表記について

本資料では、次の表記を使用します。

  • SQL のキーワード（SELECT や FROM など）は大文字で、テーブル名や列名は小文字で記述します。SQL はキーワードの大文字と小文字を区別しないため、小文字で書いても同じように動作します。

  • SQL の実行結果は表形式で示します。値が NULL（5 章で説明します）のセルは NULL と表示します。

  • 本文で「Python」と書いた場合は、Python 3.12 以上を指します。
