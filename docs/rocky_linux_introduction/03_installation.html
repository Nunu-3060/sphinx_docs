3. インストール

この章では、仮想マシンに Rocky Linux 10 をインストールする手順を説明します。物理サーバーにインストールする場合も、仮想マシンの準備を除いて手順は同じです。

3.1. システム要件

Rocky Linux 10（x86_64 版）をインストールするには、次の要件を満たす必要があります。

表 3.1 システム要件

項目

本書の推奨値

補足

CPU

x86-64-v3 に対応した 2 コア以上

Intel は第 4 世代 Core（Haswell）以降、AMD は Excavator 以降のマイクロアーキテクチャがおおむね対応しています

メモリ

4 GiB 以上

最小構成なら 2 GiB でも動作します。GUI を使う場合は 4 GiB 以上が必要です

ディスク

40 GiB 以上

最小構成なら 20 GiB でもインストールできます

ファームウェア

UEFI

従来の BIOS でもインストールできます

x86-64-v3 は、AVX2 などの比較的新しい CPU 命令をまとめた規格です（「Rocky Linux 10 の主な変更点」を参照）。対応していない CPU では、インストーラーの起動直後にエラーで停止します。

既存の Linux 環境があれば、次のコマンドで CPU が x86-64-v3 に対応しているかを確認できます。x86-64-v3 (supported, searched) と表示されれば対応しています。

1$ /lib64/ld-linux-x86-64.so.2 --help | grep x86-64-v
2  x86-64-v4
3  x86-64-v3 (supported, searched)
4  x86-64-v2 (supported, searched)

注釈

仮想マシンでは、ホストの CPU が対応していても、仮想化ソフトウェアの設定によっては AVX2 などの命令がゲストに公開されず、インストールできないことがあります。その場合は、仮想化ソフトウェアのバージョンや、CPU の互換モードの設定を確認してください。

3.2. インストールメディアの入手

インストールメディア（ISO イメージ）は、Rocky Linux の公式サイトからダウンロードします。次の 3 種類があります。

表 3.2 ISO イメージの種類

種類

内容

DVD

すべての標準パッケージを含むイメージです。インターネットに接続できない環境でもインストールできます。本書ではこのイメージを使います。

Minimal

最小構成に必要なパッケージのみを含むイメージです。

Boot

インストーラーのみを含むイメージです。パッケージはインストール時にネットワーク経由で取得します。

3.3. ISO イメージのチェックサムの検証

ダウンロードした ISO イメージが壊れていないか、改ざんされていないかを、チェックサム（SHA-256 のハッシュ値）で確認します。公式サイトで公開されている CHECKSUM ファイルの値と、手元で計算した値が一致することを確認してください。

Windows の PowerShell では、次のように計算します。

1PS> Get-FileHash .\Rocky-10.2-x86_64-dvd1.iso -Algorithm SHA256

Linux では sha256sum コマンドを使います。

1$ sha256sum Rocky-10.2-x86_64-dvd1.iso

ファイル名はダウンロードしたマイナーバージョンに合わせて読み替えてください。

3.4. 仮想マシンの準備

仮想マシンを作成する際は、次の設定を目安にしてください。

表 3.3 仮想マシンの設定例

項目

設定

仮想 CPU

2 個

メモリ

4 GiB

仮想ディスク

40 GiB（容量可変）

ネットワーク

クライアント PC から SSH で接続できる設定（ブリッジ接続、または NAT とポート転送）

起動メディア

ダウンロードした ISO イメージ

Hyper-V を使う場合は、「第 2 世代」の仮想マシンとして作成し、Secure Boot のテンプレートを「Microsoft UEFI 証明機関」に変更してください。既定の「Microsoft Windows」のままでは、Linux のブートローダーが起動しません。

Secure Boot は、署名されたブートローダーやカーネルだけを起動できるようにする UEFI の機能です。Rocky Linux は Secure Boot が有効な環境でもそのままインストールして起動できます。ただし、NVIDIA の GPU のドライバーなど、Rocky Linux に含まれていない外部のカーネルモジュールを使う場合は、追加の作業が必要になります（「GPU の利用」を参照）。

3.5. インストールの手順

Rocky Linux のインストーラーは Anaconda と呼ばれ、GUI で操作します。手順は次のとおりです。

  1. 仮想マシンを ISO イメージから起動し、起動メニューで「Install Rocky Linux 10.2」を選びます。

  2. 言語の選択画面で「日本語」を選び、「続行」を選びます。

  3. 「インストール概要」の画面が表示されます。この画面で、警告の表示されている項目をすべて設定します（次の表を参照）。

  4. すべての設定が終わったら「インストールの開始」を選びます。

  5. インストールが完了したら「システムの再起動」を選びます。再起動後は、仮想マシンから ISO イメージを取り外してください。

「インストール概要」の画面では、次の項目を設定します。

表 3.4 インストール概要の設定項目

項目

設定内容

キーボード

使用するキーボードの配列を選びます。日本語キーボードの場合は「日本語」を選びます。

言語サポート

追加の言語が必要な場合に選びます。手順 2 で日本語を選んでいれば変更不要です。

時刻と日付

地域を「アジア」、都市を「東京」にします。「ネットワーク時刻」を有効にすると、インストール後に時刻が自動で同期されます。

インストールソース

DVD イメージを使う場合は変更不要です。

ソフトウェアの選択

ベース環境を選びます。本書では「最小限のインストール」（Minimal Install）を選びます。GUI を使う場合の選択肢は「デスクトップ環境の利用」で説明します。

インストール先

インストールするディスクを選びます。「ストレージの設定」を「自動構成」にすると、LVM を使った標準的なパーティション構成が作成されます。

ネットワークとホスト名

ネットワークインターフェイスを「オン」にし、ホスト名を入力します。オフのままだと、インストール後にネットワークに接続されません。

root アカウント

既定では無効です。次の節を参照してください。

ユーザーの作成

普段使う一般ユーザーを作成します。「このユーザーを管理者にする」に必ずチェックを入れます。

3.6. root アカウントの扱い

Linux には、すべての操作を行える特別なユーザーとして root が存在します。Rocky Linux 10 のインストーラーでは、root アカウントは既定で無効（ロックされた状態）になっています。代わりに、インストール時に作成した一般ユーザーを「管理者」として wheel グループに所属させ、管理作業は sudo コマンドを使って行います（「初期設定」を参照）。

この方式には次の利点があります。

  • root のパスワードを推測する攻撃の対象になりません。

  • 誰がどの管理操作を行ったかが、ユーザーごとに記録されます。

  • 管理者権限が必要な操作を、必要なときだけ実行する習慣が身につきます。

特別な理由がない限り、root アカウントは無効のままにしておくことをお勧めします。root アカウントを有効にしてパスワードを設定した場合でも、既定の SSH の設定では root でのパスワード認証によるログインは許可されません。

警告

「このユーザーを管理者にする」にチェックを入れずにインストールすると、root アカウントも無効なため、管理者権限が必要な操作ができなくなります。その場合は「トラブルシューティング」の手順でパスワードを再設定するか、インストールをやり直してください。

3.7. クラウドイメージ

Rocky Linux は、パブリッククラウドや仮想化基盤向けのイメージも提供しています。

  • AWS、Microsoft Azure、Google Cloud などの主要なクラウドで、公式のイメージを選んで仮想マシンを作成できます。

  • KVM や OpenStack 向けには、qcow2 形式の GenericCloud イメージが提供されています。

クラウドイメージではインストール作業が不要で、初回起動時に cloud-init というツールが SSH の公開鍵やホスト名を自動で設定します。多くのクラウドで、初期ユーザー名は rocky です。

3.8. Kickstart による自動インストール

多数のサーバーに同じ構成でインストールする場合は、Kickstart を使うとインストールを自動化できます。Kickstart では、インストール概要の画面で設定する内容をテキストファイルに記述しておき、インストーラーがそのファイルを読み込んで自動でインストールします。

インストールが完了したシステムには、そのとき選んだ設定が /root/anaconda-ks.cfg として保存されています。このファイルを元に Kickstart ファイルを作成すると簡単です。次に、最小構成でインストールする Kickstart ファイルの例を示します。

リスト 3.1 minimal.ks
 1# ------------------------------------------------------------
 2# minimal.ks - 最小構成で Rocky Linux 10 をインストールする Kickstart ファイル
 3#
 4# 第 3 章「インストール」で使用します。
 5# インストーラーの起動時にカーネルパラメーターとして
 6#   inst.ks=http://<Web サーバー>/minimal.ks
 7# を指定すると、このファイルの内容に従って自動でインストールされます。
 8#
 9# 使用前に必ず変更する箇所:
10#   - user 行の --password: 次のコマンドで作成したハッシュ値に置き換える
11#       openssl passwd -6
12#   - sshkey 行: 自分の公開鍵に置き換える
13#
14# 注意: clearpart --all はディスクの内容をすべて消去します。
15# ------------------------------------------------------------
16
17# インストール元 (インストールメディア)
18cdrom
19
20# テキストモードで実行し、完了後に再起動する
21text
22reboot
23
24# 言語、キーボード、タイムゾーン
25lang ja_JP.UTF-8
26keyboard --vckeymap=jp --xlayouts='jp'
27timezone Asia/Tokyo --utc
28
29# ネットワーク (DHCP) とホスト名
