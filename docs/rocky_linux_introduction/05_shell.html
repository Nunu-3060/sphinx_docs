5. シェルの基本操作

この章では、Linux を操作するうえで欠かせないシェルの基本操作を説明します。すでに Linux のコマンド操作に慣れている場合は、「環境変数と設定ファイル」以降の節だけを確認すれば十分です。

5.1. シェルとは

シェルは、ユーザーが入力したコマンドを解釈して実行するプログラムです。Rocky Linux の既定のシェルは bash です。ログインすると、次のようなプロンプトが表示され、コマンドの入力を待つ状態になります。

1[admin@web01 ~]$

プロンプトには、ユーザー名、ホスト名、現在のディレクトリが表示されます。~ は自分のホームディレクトリ（/home/admin など）を表します。

コマンドは、コマンド名、オプション、引数の順に、空白で区切って入力します。

1$ ls -l /etc/hosts
2-rw-r--r--. 1 root root 158  6月 23  2024 /etc/hosts

この例では、ls がコマンド名、-l がオプション（詳細表示）、/etc/hosts が引数（対象のファイル）です。

便利なキー操作として、次のものを覚えておくと効率よく操作できます。

表 5.1 bash の便利なキー操作

キー

動作

Tab

コマンド名やファイル名を補完する

↑ / ↓

過去に入力したコマンドを呼び出す

Ctrl+R

過去に入力したコマンドを検索する

Ctrl+C

実行中のコマンドを中断する

Ctrl+L

画面を消去する

5.2. ディレクトリ構成

Linux のファイルは、/ （ルートディレクトリ）を頂点とする 1 つの木構造で管理されます。Windows のように、ドライブごとに別の木構造を持つことはありません。主なディレクトリの役割は次のとおりです。

表 5.2 主なディレクトリ

ディレクトリ

役割

/etc

システムやソフトウェアの設定ファイル

/home

一般ユーザーのホームディレクトリ

/root

root のホームディレクトリ

/var

ログ（/var/log）など、運用中に変化するデータ

/usr

コマンド、ライブラリ、ドキュメントなど、パッケージで導入されるファイル

/opt

5.4. パーミッションと所有者

Linux のファイルには、所有者（ユーザー）、所有グループ、パーミッション（アクセス権）が設定されています。ls -l の出力で確認できます。

1$ ls -l report.txt
2-rw-r-----. 1 admin developers 1024 10月  6 10:00 report.txt

先頭の -rw-r----- がパーミッションです。1 文字目はファイルの種類（- は通常のファイル、d はディレクトリ、l はシンボリックリンク）を表し、残りの 9 文字を 3 文字ずつ区切って、所有者、所有グループ、その他のユーザーの権限を表します。末尾の . は、SELinux のラベルが付いていることを表します（「セキュリティ」を参照）。

表 5.4 パーミッションの記号

記号

数値

ファイルに対する意味

ディレクトリに対する意味

r

4

内容を読める

中のファイルを一覧表示できる

w

2

内容を変更できる

中にファイルを作成・削除できる

x

1

プログラムとして実行できる

中に移動（cd）できる

パーミッションは、各権限の数値を足し合わせた 3 桁の 8 進数でも表せます。例えば rwxr-x--- は、所有者が \(4 + 2 + 1 = 7\)、所有グループが \(4 + 0 + 1 = 5\)、その他が \(0\) なので 750 になります。一般に、権限の数値 \(p\) は次の式で求められます。

\[p = 4r + 2w + x \qquad (r, w, x \in \{0, 1\})\]

パーミッションは chmod、所有者は chown で変更します。

1$ chmod 640 report.txt
2$ chmod u+x script.sh
3$ sudo chown admin:developers report.txt

2 行目の u+x は「所有者（u）に実行権限（x）を追加する」という意味です。g は所有グループ、o はその他のユーザー、a は全員を表します。

新しく作成したファイルのパーミッションは、umask という値で決まります。Rocky Linux の一般ユーザーの既定値は 0022 で、新しいファイルは 644 （rw-r--r--）、新しいディレクトリは 755 （rwxr-xr-x）になります。

5.5. リダイレクトとパイプ

コマンドの出力をファイルに保存したり、別のコマンドに渡したりできます。

表 5.5 リダイレクトとパイプ

書き方

動作

command > file

標準出力をファイルに書き込む（上書き）

command >> file

標準出力をファイルに追記する

command 2> file

標準エラー出力をファイルに書き込む

command > file 2>&1

標準出力と標準エラー出力の両方をファイルに書き込む

command < file

ファイルの内容を標準入力として渡す

command1 | command2

command1 の標準出力を command2 の標準入力に渡す（パイプ）

sudo を使って root しか書き込めないファイルに書き込む場合、sudo echo "text" > /etc/file は失敗します。リダイレクトは sudo で権限が切り替わる前に、現在のユーザーの権限で処理されるためです。この場合は tee コマンドを使います。

1$ echo "192.168.10.30 db01" | sudo tee -a /etc/hosts

5.6. テキスト処理

Linux の設定ファイルやログの多くはテキストファイルです。テキストを処理するコマンドをパイプで組み合わせると、さまざまな集計や抽出ができます。

表 5.6 テキスト処理のコマンド

コマンド

動作

grep <パターン> <ファイル>

パターンに一致する行を表示する。-i で大文字と小文字を区別しない、-v で一致しない行を表示する、-r でディレクトリ内を再帰的に検索する

sed 's/<置換前>/<置換後>/g'

文字列を置換する。-i を付けるとファイルを直接書き換える

awk '{print $1}'

空白で区切られた列のうち、1 列目を表示する

sort

行を並べ替える。-n で数値として並べ替える

uniq -c

連続する同じ行をまとめ、件数を表示する

wc -l

行数を数える

次の例は、nginx のアクセスログから、アクセス数の多いクライアントの IP アドレスを上位 5 件表示します。

1$ awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -n 5

設定ファイルから、コメント行と空行を除いて有効な設定だけを表示するには、次のようにします。

1$ grep -Ev '^\s*(#|$)' /etc/chrony.conf

5.7. 環境変数と設定ファイル

環境変数は、シェルやそこから起動されるプログラムが参照する設定値です。

1$ echo $PATH
2/home/admin/.local/bin:/home/admin/bin:/usr/local/bin:/usr/bin:/usr/local/sbin:/usr/sbin
3$ export EDITOR=vi
4$ env | grep EDITOR
5EDITOR=vi

PATH は、コマンドを探すディレクトリの一覧です。コマンド名だけを入力すると、PATH に含まれるディレクトリを先頭から順に探して実行します。どのファイルが実行されるかは which コマンドや type コマンドで確認できます。

export で設定した環境変数は、ログアウトすると消えます。常に設定しておきたい場合は、次の設定ファイルに記述します。

表 5.7 bash の設定ファイル

ファイル

読み込まれるタイミングと用途

~/.bash_profile

ログイン時に 1 回読み込まれる。環境変数の設定に使う

~/.bashrc

bash を起動するたびに読み込まれる。エイリアスや関数の定義に使う

/etc/profile.d/*.sh

全ユーザーのログイン時に読み込まれる。システム全体の環境変数の設定に使う

設定ファイルを変更した後は、source ~/.bashrc で現在のシェルに反映できます。

5.8. アーカイブと圧縮

複数のファイルを 1 つにまとめる（アーカイブする）には tar コマンドを使います。tar は圧縮も同時に行えます。

1$ tar -czf backup.tar.gz /etc/nginx
2$ tar -tzf backup.tar.gz
3$ tar -xzf backup.tar.gz -C /tmp/restore

1 行目でディレクトリを gzip 形式で圧縮したアーカイブを作成し、2 行目で内容を一覧表示し、3 行目で /tmp/restore に展開しています。主なオプションの意味は次のとおりです。

表 5.8 tar の主なオプション

オプション

意味

-c

アーカイブを作成する

-t

アーカイブの内容を一覧表示する

-x

アーカイブを展開する

-z

gzip 形式で圧縮・展開する（-J は xz 形式）

-f <ファイル>

アーカイブのファイル名を指定する

-C <ディレクトリ>

展開先のディレクトリを指定する

バックアップでの使い方は「ストレージ管理」で説明します。

5.9. vi の最低限の操作

設定ファイルの編集には、どの Linux 環境にもほぼ必ず含まれている vi（Rocky Linux では vim）を使えると便利です。vi には、文字を入力する「挿入モード」と、カーソルの移動や保存などを行う「ノーマルモード」があります。起動直後はノーマルモードです。

5.10. マニュアルの引き方

コマンドの使い方は、man コマンドでマニュアルを表示して確認できます。

1$ man ls
2$ ls --help
3$ man -k firewall

man -k は、説明文にキーワードを含むマニュアルを検索します。最小構成ではマニュアルが導入されていないことがあるため、表示されない場合は sudo dnf install man-db man-pages で導入してください。
