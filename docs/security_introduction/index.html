セキュリティ入門

本書は、セキュリティを専門としないエンジニアに向けて、ソフトウェアを安全に作り、運用するための基礎知識をまとめた入門書です。「なぜ危ないのか」と「どう防ぐのか」を、手元で動かせる Python のサンプルコードとともに説明します。
