3. 対話で使う

本章では、claude.ai（https://claude.ai/）とデスクトップアプリで Claude と対話する方法を説明します。API を使う予定の読者にとっても、対話で Claude の得意不得意をつかんでおくと、プロンプトの設計に役立ちます。

3.1. 基本操作

claude.ai にログインし、入力欄に質問や依頼を書いて送信すると、Claude が応答します。1 つの会話の中では過去のやり取りが文脈として引き継がれるため、「さっきの案をもう少し短くして」のように続けて指示できます。

話題が変わったら、新しい会話を始めるのが基本です。無関係なやり取りが文脈に残っていると、応答の質が下がったり、利用量の上限に早く達したりします。

入力欄の近くにあるメニューからは、使用するモデルの切り替えや、Web 検索などの機能の有効化ができます。

3.2. ファイルの添付

PDF、Word 文書、表計算ファイル、画像、ソースコードなどのファイルを添付し、その内容について質問できます。

  • 仕様書の PDF を添付し、要点の要約や疑問点の洗い出しを依頼します

  • エラー画面のスクリーンショットを添付し、原因の候補を尋ねます

  • CSV ファイルを添付し、集計やグラフの作成を依頼します

表計算ファイルの分析やグラフの作成では、Claude が内部でプログラムを実行して結果を求めます。計算を伴う作業は、暗算で答えさせるより、このようにコードを実行させるほうが正確です。

3.3. プロジェクト

プロジェクトは、関連する会話、資料、指示をまとめて管理する機能です。プロジェクトに資料（ナレッジ）と指示を登録しておくと、そのプロジェクト内のすべての会話で共有されます。

例えば、「社内規程 Q&A」というプロジェクトに規程集の PDF と「回答には根拠となる条番号を必ず付ける」という指示を登録しておけば、会話を始めるたびに資料を添付し直す必要がありません。Team プランと Enterprise プランでは、プロジェクトを組織内のメンバーと共有できます。

3.4. アーティファクト

アーティファクトは、会話の中で作成した文書、コード、Web ページ、図などを、会話とは別の領域に表示して編集できるようにする機能です。

例えば「タスク管理の Web ページを作って」と依頼すると、動作する HTML がアーティファクトとして表示され、その場で操作を試せます。「完了したタスクを灰色にして」のように続けて指示すると、アーティファクトが更新されます。作成したアーティファクトは公開して他の人と共有することもできます。

3.5. 外部サービスとの連携

claude.ai は、コネクターを通じて外部のサービスと連携できます。Google ドライブ、Gmail、カレンダー、Slack、課題管理サービスなどを接続すると、Claude がそれらの情報を検索したり、操作したりできるようになります。コネクターの多くは、MCP によるツール連携で説明する Model Context Protocol で実装されています。

接続したサービスに対して Claude が何をしてよいかは、利用者が管理できます。書き込みや送信を伴う操作は、実行前に確認を求める設定にしておくと安全です。

3.7. 業務で利用する際の注意

  • 入力した情報の扱い（学習への利用の有無、保存期間など）は、契約しているプランと設定によって異なります。業務で使う前に、組織のルールと Anthropic の規約を確認してください。

  • 個人情報や機密情報を入力してよいかは、組織のルールに従ってください。組織向けのプランでは、管理者がデータの扱いを一元的に設定できます。

  • Claude の出力は必ず人が確認してから利用してください。特に、数値、固有名詞、法令、医療、セキュリティに関わる内容は、一次情報で裏付けを取ることが重要です。
