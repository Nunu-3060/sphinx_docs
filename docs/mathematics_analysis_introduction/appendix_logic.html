付録 B 論理と証明の基本

解析学の定義や定理は、「任意の」「存在する」「ならば」といった言葉を組み合わせて書かれる。本付録では、それらを正確に読み書きするための最低限の論理と、本書で使う証明の方法をまとめる。特に、ε-N 論法や ε-δ 論法の否定を正しく作れることは、反例を示したり背理法を使ったりするために欠かせない。

命題と論理記号

真か偽かが定まる主張を命題という。たとえば「\(2 < 3\)」は真の命題、「\(\sqrt{2}\) は有理数である」は偽の命題である。命題 \(P, Q\) から、次のような新しい命題を作ることができる。

表 8 論理記号

記号

読み方

真となる条件

\(\neg P\)

\(P\) でない

\(P\) が偽のとき

\(P \land Q\)

\(P\) かつ \(Q\)

\(P\) と \(Q\) がともに真のとき

\(P \lor Q\)

\(P\) または \(Q\)

\(P\) と \(Q\) の少なくとも一方が真のとき

\(P \Rightarrow Q\)

\(P\) ならば \(Q\)

\(P\) が偽であるか、\(Q\) が真であるとき

\(P \Leftrightarrow Q\)

\(P\) と \(Q\) は同値

\(P\) と \(Q\) の真偽が一致するとき

数学の「または」は、両方が成り立つ場合を含む。また、\(P \Rightarrow Q\) は \(P\) が偽ならば \(Q\) の真偽によらず真とみなす。「\(x > 2\) ならば \(x^2 > 4\)」という命題は、\(x = 1\) のように仮定を満たさない場合には何も主張していない、と考えればよい。

\(P \Rightarrow Q\) が真であるとき、\(P\) は \(Q\) であるための十分条件、\(Q\) は \(P\) であるための必要条件であるという。\(P \Leftrightarrow Q\) のときは必要十分条件であるという。

否定については、次のド・モルガンの法則が基本である。

\[\neg (P \land Q) \Leftrightarrow (\neg P) \lor (\neg Q), \qquad \neg (P \lor Q) \Leftrightarrow (\neg P) \land (\neg Q)\]

また、\(P \Rightarrow Q\) の否定は「\(P\) であるのに \(Q\) でない」、すなわち \(P \land \neg Q\) である。

逆・裏・対偶

命題 \(P \Rightarrow Q\) に対して、\(Q \Rightarrow P\) を逆、\(\neg P \Rightarrow \neg Q\) を裏、\(\neg Q \Rightarrow \neg P\) を対偶という。もとの命題と対偶は常に真偽が一致するが、逆や裏は一致するとは限らない。

例 B.1

「数列が収束するならば、その数列は有界である」（定理 2.2）は真である。その対偶「数列が有界でないならば、その数列は収束しない」も真である。一方、逆「有界な数列は収束する」は偽であり、\((-1)^n\) が反例となる。

量化子

「任意の \(x\) について \(P(x)\)」を \(\forall x,\ P(x)\) と書き、「ある \(x\) が存在して \(P(x)\)」を \(\exists x,\ P(x)\) と書く。\(\forall\) を全称量化子、\(\exists\) を存在量化子という。

量化子の順序

量化子が複数あるときは、その順序が意味を大きく変える。次の 2 つの命題を比べる。

\[\text{(a)}\ \ \forall x \in \mathbb{R},\ \exists y \in \mathbb{R},\ y > x \qquad \text{(b)}\ \ \exists y \in \mathbb{R},\ \forall x \in \mathbb{R},\ y > x\]

  1. は「どの実数 \(x\) に対しても、それより大きい \(y\) がある」という意味であり、真である（\(y = x + 1\) とすればよい）。(b) は「すべての実数より大きい \(y\) がある」という意味であり、偽である。(a) では \(y\) を \(x\) に応じて選んでよいが、(b) では \(y\) を先に 1 つ決めなければならない。

数列の収束の定義（定義 2.1）は \(\forall \varepsilon > 0,\ \exists N,\ \forall n \geq N,\ |a_n - \alpha| < \varepsilon\) である。ここで \(N\) は \(\varepsilon\) に応じて選んでよい。

量化子を含む命題の否定

量化子を含む命題の否定は、次の規則で作る。

\[\neg (\forall x,\ P(x)) \Leftrightarrow \exists x,\ \neg P(x), \qquad \neg (\exists x,\ P(x)) \Leftrightarrow \forall x,\ \neg P(x)\]

「すべての \(x\) で \(P(x)\) が成り立つ」の否定は「\(P(x)\) が成り立たない \(x\) がある」であり、「\(P(x)\) を満たす \(x\) がある」の否定は「どの \(x\) も \(P(x)\) を満たさない」である。量化子が複数ある場合は、この規則を外側から順に適用する。結果として、すべての \(\forall\) と \(\exists\) を入れ替え、最後の条件を否定することになる。

ε-N 論法の否定

以上の規則を使って、「数列 \((a_n)\) は \(\alpha\) に収束しない」を書き下す。収束の定義は次のとおりである。

\[\forall \varepsilon > 0,\ \exists N \in \mathbb{N},\ \forall n \geq N,\ |a_n - \alpha| < \varepsilon\]

量化子を入れ替え、最後の不等式を否定すると、次を得る。

(1)\[\exists \varepsilon > 0,\ \forall N \in \mathbb{N},\ \exists n \geq N,\ |a_n - \alpha| \geq \varepsilon\]

言葉で言えば、「ある正の数 \(\varepsilon\) があって、どんなに大きい \(N\) をとっても、\(N\) 以降に \(\alpha\) から \(\varepsilon\) 以上離れた項が現れる」ということである。\(|a_n - \alpha| < \varepsilon\) の否定が \(|a_n - \alpha| \geq \varepsilon\)（\(>\) ではない）であることにも注意する。

例 B.2

\(a_n = (-1)^n\) がどの実数 \(\alpha\) にも収束しないことを、式 (1) に沿って示す。\(\varepsilon = 1\) とし、任意の \(N\) をとる。\(a_N\) と \(a_{N+1}\) の一方は \(1\)、他方は \(-1\) である。もし両方とも \(|a_n - \alpha| < 1\) を満たすなら、\(2 = |a_N - a_{N+1}| \leq |a_N - \alpha| + |\alpha - a_{N+1}| < 2\) となって矛盾する。したがって \(n = N\) または \(n = N + 1\) のどちらかで \(|a_n - \alpha| \geq 1\) となる。

同じ方法で、ほかの定義の否定も作れる。たとえば、関数 \(f\) が点 \(a\) で連続であること（ε-δ 論法、第 4 章）は

\[\forall \varepsilon > 0,\ \exists \delta > 0,\ \forall x,\ \bigl( |x - a| < \delta \Rightarrow |f(x) - f(a)| < \varepsilon \bigr)\]

であり、その否定「\(f\) は \(a\) で連続でない」は、\(P \Rightarrow Q\) の否定が \(P \land \neg Q\) であることに注意すると、次のようになる。

\[\exists \varepsilon > 0,\ \forall \delta > 0,\ \exists x,\ \bigl( |x - a| < \delta \land |f(x) - f(a)| \geq \varepsilon \bigr)\]

証明の方法

本書で使う主な証明の方法をまとめる。

直接証明

仮定 \(P\) から出発し、既知の事実を組み合わせて結論 \(Q\) を導く方法である。ε-N 論法による収束の証明は、多くの場合「\(\varepsilon > 0\) を任意にとる」から始め、条件を満たす \(N\) を具体的に作って示す直接証明である。

対偶による証明

\(P \Rightarrow Q\) の代わりに、同値な対偶 \(\neg Q \Rightarrow \neg P\) を示す方法である。

例 B.3

整数 \(n\) について「\(n^2\) が偶数ならば \(n\) は偶数」を示す。対偶「\(n\) が奇数ならば \(n^2\) は奇数」を示せばよい。\(n = 2k + 1\) とすると \(n^2 = 2(2k^2 + 2k) + 1\) であり、奇数である。

背理法

結論 \(Q\) を否定した \(\neg Q\) を仮定し、矛盾を導くことで \(Q\) を示す方法である。定理 1.1（\(\sqrt{2}\) の無理性）や定理 2.1（極限の一意性）は背理法による証明である。背理法では、結論の否定を正確に作ることが出発点になる。

数学的帰納法

自然数 \(n\) に関する命題 \(P(n)\) がすべての \(n \in \mathbb{N}\) で成り立つことを示すには、次の 2 つを示せばよい。

  1. \(P(1)\) が成り立つ。

  2. 任意の \(n\) について、\(P(n)\) が成り立つならば \(P(n + 1)\) も成り立つ。

例 B.4

\(1 + 2 + \cdots + n = n(n + 1)/2\) を示す。\(n = 1\) では両辺とも \(1\) である。\(n\) で成り立つと仮定すると、\(1 + \cdots + n + (n + 1) = n(n + 1)/2 + (n + 1) = (n + 1)(n + 2)/2\) となり、\(n + 1\) でも成り立つ。

漸化式で定まる数列の性質（例 2.6 など）や、ベルヌーイの不等式（補題 2.6）は、数学的帰納法で示される。

反例

「すべての \(x\) について \(P(x)\)」が偽であることを示すには、\(P(x)\) が成り立たない \(x\) を 1 つ挙げればよい。これを反例という。本書では、定理の仮定を外すと結論が成り立たなくなることを、反例によって繰り返し示す。
