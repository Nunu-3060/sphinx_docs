検査の設定

すべてのスクリプトは flake8 と mypy（strict モード）で検査している。設定ファイルは次のとおりである。

setup.cfg

1[flake8]
2max-line-length = 120
3
4[mypy]
5strict = True

examples ディレクトリで次のコマンドを実行すると検査できる。

1python -m flake8 .
2python -m mypy .
