ソフトウェア工学入門

本書は、プログラミングの経験はあるがソフトウェア工学を体系的に学んだことのないエンジニアを対象とした入門書である。要求の定義から設計、実装、テスト、保守に至るソフトウェア開発の全体像と、それを支える品質管理・プロジェクト管理の基本的な考え方を説明する。

各章の末尾には演習問題と発展課題を設けており、解答例は付録にまとめている。各章のサンプルコードは Python で記述しており、本文中の該当箇所または「サンプルコード一覧」からダウンロードできる。
