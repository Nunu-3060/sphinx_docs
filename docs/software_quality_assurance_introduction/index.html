ソフトウェア品質保証入門

はじめに

本書の目的

本書は、ソフトウェアの品質を保証するための考え方と実践方法を、体系的に学ぶための入門書です。「テストを書いているが、それで十分なのか分からない」「レビューやテストを何のために行うのかを説明できない」といった疑問を持つエンジニアが、品質保証の全体像をつかみ、日々の開発で使える手法を身に付けることを目指します。

品質保証はテストだけを指す言葉ではありません。本書では、品質を「つくり込む」活動（要求・設計の確認、静的解析、レビュー）、品質を「確かめる」活動（テスト）、品質を「管理し改善する」活動（計画、リリース判定、運用、測定）を順に取り上げます。

対象読者と前提知識

本書は、Python などのプログラミング言語でソフトウェアを開発した経験があり、品質保証を体系的に学んだことのないエンジニアを対象としています。次の知識を前提とします。

  • Python の基本的な文法（関数、クラス、例外、型ヒント）

  • Git の基本的な操作（コミット、ブランチ、プルリクエスト）

  • コマンドラインの基本的な操作

本書は 13 の章と付録で構成されています。各章の位置付けは次のとおりです。

本文中の専門用語の多くは用語集にまとめています。

サンプルコードの実行環境

本書のサンプルコードは Python 3.12 以上で動作を確認しています。サンプルコードはサンプルコード一覧からダウンロードできます。開発用ツールは、サンプルコードと同じフォルダーにある requirements-dev.txt を使って次のようにインストールします。

1$ python -m venv .venv
2$ source .venv/bin/activate      # Windows の場合は .venv\Scripts\activate
3$ python -m pip install -r requirements-dev.txt
