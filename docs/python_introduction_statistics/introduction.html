1. はじめに

1.1. 本資料の目的

本資料の目的は、統計学の基本的な考え方を理解し、Python で実際にデータを分析できるようになることです。各章では、概念と数式を説明したあと、Python のプログラムで計算し、その結果の読み方を説明します。平均値や分散などの基本的な値は、まず定義どおりに計算し、次に NumPy などのライブラリの関数で計算して、両者が一致することを確かめます。

1.2. 対象読者

本資料は、次のような人を対象としています。

  • Python の基本的な文法（変数、関数、リスト、for 文など）を理解している人

  • 統計学を初めて学ぶ人、または学び直したい人

高校数学の範囲を超える数学の知識は前提としません。ただし、総和記号 \(\sum\) は使うため、記号の一覧も参照してください。

1.5. ライブラリのインストール

ライブラリは pip でインストールします。コマンドプロンプトやターミナルで次のコマンドを実行してください。

pip install numpy scipy pandas matplotlib

1.6. サンプルコードの使い方

各章のサンプルコードは、各章の本文からダウンロードできます。すべてのファイルの一覧はサンプルコードの一覧にあります。サンプルコードはサンプルデータ data/scores.csv を読み込むため、ダウンロードしたファイルは次のフォルダー構成で保存してください。

examples/
├── ch02_data_basics.py
├── ch03_descriptive_statistics.py
├── （中略）
├── ch10_correlation_regression.py
└── data/
    └── scores.csv

サンプルコードは、examples フォルダーで次のように実行します。

python ch03_descriptive_statistics.py

グラフを作成するサンプルコード（4 章、5 章、6 章、10 章）は、グラフを PNG ファイルとして保存します。保存先のフォルダーは --outdir オプションで指定でき、指定しない場合は実行したフォルダーの下の output フォルダーに保存します。

python ch04_visualization.py --outdir output

乱数を使うサンプルコードでは、乱数のシード（乱数の出発点となる値）を固定しています。そのため、同じバージョンのライブラリで実行すれば、本資料に記載した結果と同じ結果が得られます。
