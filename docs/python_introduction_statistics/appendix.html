サンプルデータの作成方法

サンプルデータ scores.csv は、次のプログラムで作成しました。乱数のシードを固定しているため、実行するたびに同じデータが作成されます。

make_scores_data.py をダウンロードする

 1"""本資料で使うサンプルデータ（架空の生徒の成績）を作成する。
 2
 3実行すると、このファイルと同じフォルダーにある data/scores.csv を
 4作成（上書き）する。乱数のシードを固定しているため、何度実行しても
 5同じデータになる。
 6"""
 7
 8from pathlib import Path
 9
10import numpy as np
11import pandas as pd
12
13SEED = 2024
14STUDENTS_PER_CLASS = 50
15OUTPUT_PATH = Path(__file__).parent / "data" / "scores.csv"
16
17
18def make_scores(rng: np.random.Generator) -> pd.DataFrame:
19    """2 クラス分の架空の成績データを作成する。
20
21    Args:
22        rng: 乱数生成器
23
24    Returns:
25        列 student_id, class, club, study_hours, math, english を持つ表
26    """
27    n = STUDENTS_PER_CLASS * 2
28    classes = np.repeat(["A", "B"], STUDENTS_PER_CLASS)
29    clubs = rng.choice(["sports", "culture", "none"], size=n,
30                       p=[0.4, 0.3, 0.3])
31    # 1 日あたりの平均学習時間（0.0 ～ 6.0 時間、0.1 時間刻み）
32    study_hours = np.round(rng.uniform(0.0, 6.0, size=n), 1)
33
34    # 学習時間が長いほど点数が高くなるようにし、クラスと部活動の影響も
35    # 少し加える。最後に 0 ～ 100 点の整数に丸める。
36    class_effect = np.where(classes == "B", 5.0, 0.0)
37    club_effect = np.where(clubs == "culture", 4.0, 0.0)
38    math = (35.0 + 6.0 * study_hours + class_effect + club_effect
39            + rng.normal(0.0, 10.0, size=n))
40    english = 40.0 + 4.0 * study_hours + rng.normal(0.0, 12.0, size=n)
41
42    return pd.DataFrame({
43        "student_id": np.arange(1, n + 1),
44        "class": classes,
45        "club": clubs,
46        "study_hours": study_hours,
47        "math": np.clip(np.round(math), 0, 100).astype(int),
48        "english": np.clip(np.round(english), 0, 100).astype(int),
49    })
50
51
52def main() -> None:
53    """サンプルデータを作成して CSV ファイルに保存する。"""
54    rng = np.random.default_rng(SEED)
55    scores = make_scores(rng)
56    OUTPUT_PATH.parent.mkdir(parents=True, exist_ok=True)
57    scores.to_csv(OUTPUT_PATH, index=False)
58    print(f"{OUTPUT_PATH} を作成しました（{len(scores)} 行）。")
59
60
61if __name__ == "__main__":
62    main()

各列は次のように作成しています。

  • クラスは、生徒番号 1 ～ 50 を A クラス、51 ～ 100 を B クラスとしています。

  • 部活動は、運動部 40 %、文化部 30 %、所属なし 30 % の確率で無作為に割り当てています。クラスとは無関係に割り当てているため、クラスと部活動は独立です。

  • 学習時間は、0.0 ～ 6.0 時間の一様分布に従う乱数を、小数第 1 位に丸めた値です。

  • 数学の点数は、\(35 + 6 \times \text{学習時間}\) に、B クラスなら 5 点、文化部なら 4 点を加え、さらに平均値 0、標準偏差 10 の正規分布に従う誤差を加えた値です。

  • 英語の点数は、\(40 + 4 \times \text{学習時間}\) に、平均値 0、標準偏差 12 の正規分布に従う誤差を加えた値です。

  • 点数は整数に丸め、0 ～ 100 点の範囲に収めています。
