7. 推定

この章では、標本から母集団の平均値（母平均）を推定する方法を学びます。1 つの値で推定する点推定と、幅を持たせて推定する区間推定を扱います。

7.1. 点推定

母平均や母分散などの母集団の性質を表す値を母数といいます。母数を 1 つの値で推定することを点推定、推定に使う統計量を推定量といいます。

推定量の期待値が母数に一致する性質を不偏性といい、不偏性を持つ推定量を不偏推定量といいます。標本分布と中心極限定理で見たように \(E[\bar{X}] = \mu\) であるため、標本平均は母平均の不偏推定量です。

母分散 \(\sigma^2\) については、不偏分散 \(u^2\) が不偏推定量です（\(E[u^2] = \sigma^2\)）。一方、標本分散 \(s^2\) の期待値は \(\frac{n - 1}{n} \sigma^2\) であり、母分散より小さくなります。これは、偏差を計算するときに母平均 \(\mu\) の代わりに標本平均 \(\bar{x}\) を使っているためです。\(\bar{x}\) は標本のデータの中心にあるため、標本のデータからの距離は \(\mu\) からの距離より平均的に小さくなります。\(n\) ではなく \(n - 1\) で割ることで、この偏りを補正します。

7.2. 区間推定

点推定の値は、標本によって変わるため、母数にちょうど一致することはまずありません。そこで、「母数はこの範囲にあると考えられる」という区間を求めます。これを区間推定といい、求めた区間を信頼区間といいます。信頼区間を求める方法が母数を含む区間を作る確率を信頼係数といい、95 % がよく使われます。

7.2.1. 母分散が既知の場合

母集団が正規分布に従う場合、または標本の大きさ \(n\) が大きい場合は、中心極限定理により、標本平均を標準化した値

\[Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}\]

は、標準正規分布に従うとみなせます。標準正規分布では \(P(-1.96 \le Z \le 1.96) = 0.95\) であるため、これを \(\mu\) について解くと、母平均の 95 % 信頼区間が得られます。

\[\bar{x} - 1.96 \frac{\sigma}{\sqrt{n}} \le \mu \le \bar{x} + 1.96 \frac{\sigma}{\sqrt{n}}\]

7.2.2. 母分散が未知の場合

実際には、母分散 \(\sigma^2\) がわかっていることはほとんどありません。そこで、\(\sigma\) の代わりに不偏分散の平方根 \(u\) を使います。母集団が正規分布に従うとき、次の統計量 \(T\) は自由度 \(n - 1\) の t 分布に従います。

\[T = \frac{\bar{X} - \mu}{u / \sqrt{n}}\]

t 分布は、標準正規分布と同じく 0 を中心とした左右対称の分布ですが、標準正規分布より裾が厚い分布です。\(\sigma\) を推定値 \(u\) で置き換えたことによる不確かさの分だけ、ばらつきが大きくなるためです。自由度が大きくなるほど、t 分布は標準正規分布に近づきます。

自由度 \(n - 1\) の t 分布で上側の確率が 0.025 になる値を \(t_{0.025}(n - 1)\) と書くと、母平均の 95 % 信頼区間は次のようになります。

\[\bar{x} - t_{0.025}(n - 1) \frac{u}{\sqrt{n}} \le \mu \le \bar{x} + t_{0.025}(n - 1) \frac{u}{\sqrt{n}}\]

\(u / \sqrt{n}\) は、標準誤差 \(\sigma / \sqrt{n}\) の推定値です。母集団が正規分布に従わない場合でも、\(n\) が十分に大きければ、この信頼区間を近似的に使えます。

7.2.3. 信頼区間の解釈

95 % 信頼区間は、「母平均が 95 % の確率でこの区間に入る」という意味ではありません。母平均は決まった 1 つの値であり、確率的に変わるのは標本から計算した区間のほうです。正しくは、「同じ方法で標本の取り出しと区間の計算を何度も繰り返すと、そのうち約 95 % の区間が母平均を含む」という意味です。

7.3. Python で計算する

次のプログラムは、A クラスの 50 人の数学の点数を母集団からの標本とみなし、母平均の 95 % 信頼区間を求めます。また、母平均が 50 の正規分布から大きさ 20 の標本を 1,000 回取り出し、そのたびに信頼区間を求めて、母平均を含んだ割合を調べます。

ch07_estimation.py をダウンロードする

  1"""第 7 章: 推定。
  2
  3A クラスの数学の点数を標本とみなし、母平均の 95 % 信頼区間を求める。
  4また、シミュレーションで信頼区間の意味を確かめる。
  5"""
  6
  7from pathlib import Path
  8
  9import numpy as np
 10import numpy.typing as npt
 11import pandas as pd
 12from scipy import stats
 13
 14DATA_PATH = Path(__file__).parent / "data" / "scores.csv"
 15SEED = 7
 16CONFIDENCE = 0.95
 17
 18FloatArray = npt.NDArray[np.float64]
 19
 20
 21def t_interval(sample: FloatArray,
 22               confidence: float = CONFIDENCE) -> tuple[float, float]:
 23    """母分散が未知のときの母平均の信頼区間を、t 分布を使って計算する。
 24
 25    Args:
 26        sample: 標本
 27        confidence: 信頼係数（0.95 なら 95 % 信頼区間）
 28
 29    Returns:
 30        信頼区間の下限と上限
 31    """
 32    n = len(sample)
 33    mean = float(sample.mean())
 34    se = float(sample.std(ddof=1)) / np.sqrt(n)  # 標準誤差の推定値
 35    t_crit = float(stats.t.ppf((1 + confidence) / 2, df=n - 1))
 36    return mean - t_crit * se, mean + t_crit * se
 37
 38
 39def z_interval(sample: FloatArray, sigma: float,
 40               confidence: float = CONFIDENCE) -> tuple[float, float]:
 41    """母標準偏差 sigma が既知のときの母平均の信頼区間を計算する。
 42
 43    Args:
 44        sample: 標本
 45        sigma: 母標準偏差
 46        confidence: 信頼係数
 47
 48    Returns:
 49        信頼区間の下限と上限
 50    """
 51    n = len(sample)
 52    mean = float(sample.mean())
 53    z_crit = float(stats.norm.ppf((1 + confidence) / 2))
 54    half_width = z_crit * sigma / np.sqrt(n)
 55    return mean - half_width, mean + half_width
 56
 57
 58def coverage_rate(rng: np.random.Generator, repetitions: int = 1_000,
 59                  sample_size: int = 20) -> float:
 60    """母平均が 50 の正規母集団から標本を繰り返し取り出し、
 61    信頼区間が母平均を含む割合を求める。
 62
 63    Args:
 64        rng: 乱数生成器
 65        repetitions: 標本を取り出す回数
 66        sample_size: 標本の大きさ
 67
 68    Returns:
 69        信頼区間が母平均を含んだ割合
 70    """
 71    true_mean = 50.0
 72    hits = 0
 73    for _ in range(repetitions):
 74        sample = rng.normal(true_mean, 10.0, size=sample_size)
 75        lower, upper = t_interval(sample)
 76        if lower <= true_mean <= upper:
 77            hits += 1
 78    return hits / repetitions
 79
 80
 81def main() -> None:
 82    """第 7 章のサンプルをすべて実行する。"""
 83    scores = pd.read_csv(DATA_PATH)
 84    sample = scores.loc[scores["class"] == "A", "math"].to_numpy(
 85        dtype=np.float64)
 86
 87    print("--- A クラスの数学の点数 ---")
 88    print(f"標本の大きさ: {len(sample)}")
 89    print(f"標本平均: {sample.mean():.2f}")
 90    print(f"不偏分散から求めた標準偏差: {sample.std(ddof=1):.2f}")
 91    print()
 92
 93    lower, upper = t_interval(sample)
 94    print(f"95 % 信頼区間（t 分布）: [{lower:.2f}, {upper:.2f}]")
 95    lower, upper = stats.t.interval(
 96        CONFIDENCE, df=len(sample) - 1, loc=sample.mean(),
 97        scale=stats.sem(sample))
 98    print(f"95 % 信頼区間（scipy）: [{lower:.2f}, {upper:.2f}]")
 99    lower, upper = z_interval(sample, sigma=15.0)
100    print(f"95 % 信頼区間（母標準偏差 15 が既知の場合）: "
101          f"[{lower:.2f}, {upper:.2f}]")
102    print()
103
104    rng = np.random.default_rng(SEED)
105    rate = coverage_rate(rng)
106    print(f"信頼区間が母平均を含んだ割合: {rate:.3f}")
107
108
109if __name__ == "__main__":
110    main()

t_interval 関数の stats.t.ppf((1 + confidence) / 2, df=n - 1) は、自由度 \(n - 1\) の t 分布で下側の確率が 0.975 になる値、つまり \(t_{0.025}(n - 1)\) を計算します。main 関数では、同じ信頼区間を SciPy の stats.t.interval でも計算しています。stats.sem は、標準誤差の推定値 \(u / \sqrt{n}\) を計算する関数です。

実行結果は次のとおりです。

--- A クラスの数学の点数 ---
標本の大きさ: 50
標本平均: 52.00
不偏分散から求めた標準偏差: 15.10

95 % 信頼区間（t 分布）: [47.71, 56.29]
95 % 信頼区間（scipy）: [47.71, 56.29]
95 % 信頼区間（母標準偏差 15 が既知の場合）: [47.84, 56.16]

信頼区間が母平均を含んだ割合: 0.952

7.4. 結果の読み方

  • A クラスの数学の点数の母平均の 95 % 信頼区間は、47.71 点から 56.29 点です。定義どおりに計算した区間と、SciPy で計算した区間は一致しています。

  • 仮に母標準偏差が 15 とわかっている場合の信頼区間は、t 分布を使った区間よりわずかに狭くなっています。これは、\(t_{0.025}(49) \approx 2.01\) が 1.96 より大きいことと、この標本では \(u = 15.10\) が 15 よりわずかに大きいことによります。

  • シミュレーションでは、1,000 個の信頼区間のうち 95.2 % が母平均 50 を含んでいました。これは、信頼係数 95 % の意味のとおりの結果です。

信頼区間の幅は、標準誤差 \(u / \sqrt{n}\) に比例します。そのため、標本の大きさを 4 倍にすると、信頼区間の幅はおよそ半分になります。
