1. はじめに

1.1. エディター拡張とは

Unity エディターは、C# スクリプトで機能を追加したり、表示を変更したりできます。これを「エディター拡張」と呼びます。エディター拡張を使うと、次のようなことができます。

  • メニューに独自のコマンドを追加する

  • Inspector ウィンドウの表示を、入力しやすい形に変更する

  • 独自のウィンドウを作成する

  • Scene ビューに補助線やハンドルを表示する

  • アセットの作成や設定を自動化する

ゲームの開発では、同じ操作を何度も繰り返したり、決まった手順を守ったりする場面が多くあります。こうした作業をエディター拡張で道具にしておくと、作業時間を短くできるだけでなく、手作業による誤りも減らせます。

1.2. 対象読者

本書は、次のような人を対象にしています。

  • Unity の基本操作（シーンの編集、コンポーネントの追加など）ができる

  • MonoBehaviour を継承した C# スクリプトを書いたことがある

  • エディター拡張を書いたことがない、または少ししか書いたことがない

C# の文法や Unity の基本操作は説明しません。

1.5. サンプルコードの使い方

サンプルコードは、トップページのリンクから zip ファイルでまとめてダウンロードできます。Unity で動かす手順は次のとおりです。

  1. Unity 6 で新しいプロジェクトを作成します。テンプレートは「Universal 3D」など、どれでもかまいません。

  2. ダウンロードした zip ファイルを展開し、examples/Assets/EditorIntro フォルダーを、プロジェクトの Assets フォルダーの直下にコピーします。

  3. Unity エディターに戻るとスクリプトのコンパイルが始まります。コンパイルが終わると、メニューバーに Tools ‣ Editor Intro が追加されます。

サンプルコードのフォルダー構成は次のとおりです。

フォルダー

内容

Assets/EditorIntro/Runtime

ゲームオブジェクトに追加するコンポーネントなど、ゲーム本体に含まれるスクリプト

Assets/EditorIntro/Editor

エディター拡張のスクリプト

Assets/EditorIntro/Editor/UI

第 8 章で使う UXML ファイルと USS ファイル

注釈

サンプルコードでは、ゲーム本体側の名前空間を EditorIntro、エディター拡張側の名前空間を EditorIntro.EditorScripts にしています。エディター拡張側の名前空間を EditorIntro.Editor のように「Editor」で終わる名前にすると、カスタムエディターの基底クラスである UnityEditor.Editor と名前が衝突し、コンパイルエラーの原因になります。

1.6. 表記について

本書では、次の表記を使います。

表記

意味

Tools ‣ Editor Intro ‣ Hello

メニューバーの「Tools」から「Editor Intro」、「Hello」の順に選択する操作

MenuItem

クラス名、メソッド名、ファイル名などのコード上の名前

Inspector ウィンドウ、Scene ビュー

Unity エディターのウィンドウ名（エディターの表示に合わせて英語で表記）

サンプルコードのメニュー名は、Unity エディターのほかのメニューに合わせて英語にしています。ボタンのラベルやメッセージは日本語にしています。
