10. アセットの操作

この章では、スクリプトからアセットを作成・検索・変更する方法と、アセットのインポート時に処理を加える方法を説明します。

10.1. ScriptableObject

ScriptableObject は、ゲームオブジェクトに追加しなくても、単独のアセットとしてデータを保存できるクラスです。アイテムや敵のパラメーターなど、複数の場所から参照する設定データを保存するのに向いています。

Runtime/ItemData.cs
 1using UnityEngine;
 2
 3namespace EditorIntro
 4{
 5    /// <summary>
 6    /// 第 10 章のサンプルです。
 7    /// CreateAssetMenu 属性により、Project ウィンドウの「Create」メニューからアセットを作成できます。
 8    /// </summary>
 9    [CreateAssetMenu(fileName = "NewItemData", menuName = "Editor Intro/Item Data")]
10    public class ItemData : ScriptableObject
11    {
12        [SerializeField] private string itemName = "Potion";
13
14        [Min(0)]
15        [SerializeField] private int price = 100;
16
17        public string ItemName => itemName;
18        public int Price => price;
19    }
20}

CreateAssetMenu 属性を付けると、Project ウィンドウの右クリックメニューから、Create ‣ Editor Intro ‣ Item Data を選択してアセットを作成できます。

引数

意味

fileName

作成されるアセットの既定のファイル名

menuName

Create メニューの下の、項目のパス

メニュー内での表示順（省略可）

ScriptableObject は UnityEngine 名前空間のクラスであり、ビルドしたゲームからもアセットのデータを読み込めます。ただし、アセットの作成や変更の保存はエディターでだけ行えます。

10.2. AssetDatabase

AssetDatabase は、プロジェクト内のアセットをスクリプトから操作するためのクラスです。

Editor/AssetUtility.cs
 1using UnityEditor;
 2using UnityEngine;
 3
 4namespace EditorIntro.EditorScripts
 5{
 6    /// <summary>
 7    /// 第 10 章のサンプルです。
 8    /// AssetDatabase を使って、アセットの作成・検索・変更を行います。
 9    /// </summary>
10    public static class AssetUtility
11    {
12        // アセットを作成するフォルダーです。「Assets」から始まるパスで指定します。
13        private const string OutputFolder = "Assets";
14
15        [MenuItem("Tools/Editor Intro/Assets/Create Item Data")]
16        private static void CreateItemData()
17        {
18            // ScriptableObject は new ではなく CreateInstance で作成します。
19            var item = ScriptableObject.CreateInstance<ItemData>();
20
21            // 同じ名前のファイルがあれば「NewItemData 1.asset」のような重複しないパスを返します。
22            var path = AssetDatabase.GenerateUniqueAssetPath($"{OutputFolder}/NewItemData.asset");
23            AssetDatabase.CreateAsset(item, path);
24            AssetDatabase.SaveAssets();
25
26            // 作成したアセットを選択し、Project ウィンドウで強調表示します。
27            Selection.activeObject = item;
28            EditorGUIUtility.PingObject(item);
29        }
30
31        [MenuItem("Tools/Editor Intro/Assets/List Item Data")]
32        private static void ListItemData()
33        {
34            // 「t:型名」で、指定した型のアセットを検索します。結果は GUID の配列です。
35            var guids = AssetDatabase.FindAssets("t:ItemData");
36            Debug.Log($"ItemData アセットが {guids.Length} 個見つかりました。");
37
38            foreach (var guid in guids)
39            {
40                var path = AssetDatabase.GUIDToAssetPath(guid);
41                var item = AssetDatabase.LoadAssetAtPath<ItemData>(path);
42                Debug.Log($"{path}：{item.ItemName}（{item.Price} G）");
43            }
44        }
45
46        [MenuItem("Tools/Editor Intro/Assets/Double Price Of Selected Item Data", true)]
47        private static bool ValidateDoublePrice()
48        {
49            return Selection.GetFiltered<ItemData>(SelectionMode.Assets).Length > 0;
50        }
51
52        [MenuItem("Tools/Editor Intro/Assets/Double Price Of Selected Item Data")]
53        private static void DoublePrice()
54        {
55            foreach (var item in Selection.GetFiltered<ItemData>(SelectionMode.Assets))
56            {
57                // SerializedObject 経由で変更すると、Undo への記録と変更済みの印付けが自動で行われます。
58                var itemObject = new SerializedObject(item);
59                var priceProperty = itemObject.FindProperty("price");
60                priceProperty.intValue *= 2;
61                itemObject.ApplyModifiedProperties();
62
63                // 変更をすぐにファイルへ書き込みます。
64                // 呼ばない場合は、プロジェクトの保存時（File > Save Project など）に書き込まれます。
65                AssetDatabase.SaveAssetIfDirty(item);
66            }
67        }
68    }
69}

このサンプルコードは、Tools ‣ Editor Intro ‣ Assets の下に 3 つのメニュー項目を追加します。

10.2.1. アセットのパス

AssetDatabase では、アセットの場所を「Assets/」から始まるパスで指定します。区切り文字は、Windows でも「/」を使います。

Assets/Data/Potion.asset

10.2.2. アセットを作成する

ScriptableObject のインスタンスは、new ではなく ScriptableObject.CreateInstance で作成します。作成したインスタンスを AssetDatabase.CreateAsset に渡すと、指定したパスにアセットとして保存されます。

var item = ScriptableObject.CreateInstance<ItemData>();
var path = AssetDatabase.GenerateUniqueAssetPath("Assets/NewItemData.asset");
AssetDatabase.CreateAsset(item, path);
AssetDatabase.SaveAssets();

AssetDatabase.CreateAsset は、同じパスに既にアセットがあると上書きします。AssetDatabase.GenerateUniqueAssetPath を使うと、同じ名前のファイルがある場合に「NewItemData 1.asset」のような重複しないパスが返されるため、誤って上書きするのを防げます。

10.2.3. アセットを検索する

AssetDatabase.FindAssets は、検索条件に合うアセットの GUID の配列を返します。GUID は、アセットごとに割り当てられる一意の識別子です。GUID は AssetDatabase.GUIDToAssetPath でパスに変換し、AssetDatabase.LoadAssetAtPath でアセットを読み込みます。

var guids = AssetDatabase.FindAssets("t:ItemData");
foreach (var guid in guids)
{
    var path = AssetDatabase.GUIDToAssetPath(guid);
    var item = AssetDatabase.LoadAssetAtPath<ItemData>(path);
}

検索条件には、次のような書き方ができます。

検索条件

意味

t:ItemData

型が ItemData のアセット

Potion

名前に「Potion」を含むアセット

Potion t:ItemData

名前に「Potion」を含み、型が ItemData のアセット

l:Weapon

ラベル「Weapon」が付いたアセット

第 2 引数にフォルダーのパスの配列を渡すと、検索範囲をそのフォルダーの中に限定できます。

10.2.4. アセットを変更して保存する

アセットの値を変更する方法は、第 5 章で説明したシーン上のオブジェクトの場合と同じです。サンプルコードでは、SerializedObject を使って価格を 2 倍にしています。

変更したアセットは、メモリー上では変更済みになりますが、ファイルにはすぐには書き込まれません。プロジェクトを保存したとき（File ‣ Save Project を選択したときなど）に書き込まれます。すぐに書き込みたい場合は、AssetDatabase.SaveAssetIfDirty（指定したアセットだけ）または AssetDatabase.SaveAssets（変更済みのすべてのアセット）を呼びます。

警告

アセットのファイルを移動・削除・名前変更するときは、System.IO のクラスではなく、AssetDatabase.MoveAsset、AssetDatabase.DeleteAsset、AssetDatabase.RenameAsset を使ってください。System.IO で操作すると、.meta ファイルが一緒に処理されず、アセットの参照が切れる原因になります。

10.3. AssetPostprocessor

AssetPostprocessor を継承したクラスを作成すると、アセットのインポートの前後に処理を加えられます。例えば、特定のフォルダーに追加された画像のインポート設定を、自動的に変更できます。

Editor/TextureImportProcessor.cs
 1using UnityEditor;
 2
 3namespace EditorIntro.EditorScripts
 4{
 5    /// <summary>
 6    /// 第 10 章のサンプルです。
 7    /// 「Sprites」フォルダーに追加されたテクスチャーを、自動的にスプライトとしてインポートします。
 8    /// </summary>
 9    public class TextureImportProcessor : AssetPostprocessor
10    {
11        // テクスチャーのインポート処理の直前に呼ばれます。
12        private void OnPreprocessTexture()
13        {
14            // .meta ファイルが無い（初めてインポートされる）ときだけ設定します。
15            // こうしておくと、ユーザーが後から Inspector ウィンドウで変更した設定を上書きしません。
16            if (!assetImporter.importSettingsMissing)
17            {
18                return;
19            }
20
21            // パスに「/Sprites/」を含むテクスチャーだけを対象にします。
22            if (!assetPath.Contains("/Sprites/"))
23            {
24                return;
25            }
26
27            var importer = (TextureImporter)assetImporter;
28            importer.textureType = TextureImporterType.Sprite;
29            importer.spriteImportMode = SpriteImportMode.Single;
30        }
31    }
32}

TextureImportProcessor.cs をダウンロード

このサンプルコードは、パスに「/Sprites/」を含むフォルダーに画像を追加したとき、その画像の「Texture Type」を「Sprite (2D and UI)」にします。

AssetPostprocessor では、決まった名前のメソッドを定義すると、対応するタイミングで呼ばれます。

メソッド

呼ばれるタイミング

OnPreprocessTexture

テクスチャーのインポートの直前

OnPostprocessTexture

テクスチャーのインポートの直後

OnPreprocessModel

3D モデルのインポートの直前

OnPreprocessAudio

オーディオのインポートの直前

OnPostprocessAllAssets

任意のアセットのインポート・削除・移動の後（static メソッドとして定義する）

インポート対象のアセットのパスは assetPath プロパティで、インポートの設定を持つ AssetImporter は assetImporter プロパティで取得できます。テクスチャーの場合、assetImporter は TextureImporter 型なので、キャストして設定を変更します。

インポートの処理は、画像を追加したときだけでなく、再インポートしたときや、インポートの設定を変更したときにも実行されます。何も考えずに設定を変更すると、ユーザーが Inspector ウィンドウで変更した設定が、次のインポートで元に戻ってしまいます。サンプルコードでは、assetImporter.importSettingsMissing で .meta ファイルが無い（初めてインポートされる）ことを確認し、このときだけ設定を変更しています。

注釈

AssetPostprocessor のコードを変更しても、既にインポート済みのアセットには反映されません。反映するには、対象のアセットを右クリックして Reimport を選択します。GetVersion メソッドをオーバーライドしてバージョン番号を返すようにしておくと、番号を変えたときに、対象のアセットが自動で再インポートされます。
