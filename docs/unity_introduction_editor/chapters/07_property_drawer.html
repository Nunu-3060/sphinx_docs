7. PropertyDrawer と DecoratorDrawer

第 6 章のカスタムエディターは、コンポーネント単位で表示をカスタマイズする仕組みでした。これに対して PropertyDrawer は、フィールド単位で表示をカスタマイズする仕組みです。一度作成すれば、どのコンポーネントのフィールドにも適用されます。

仕組み

カスタマイズの単位

適用される場所

カスタムエディター

コンポーネント（またはアセット）の型

指定した型の Inspector ウィンドウ全体

PropertyDrawer

フィールドの型、または属性

その型のフィールド、またはその属性を付けたフィールド

DecoratorDrawer

属性

その属性を付けたフィールドの上

7.1. サンプルコード

PropertyDrawer と DecoratorDrawer が適用されるフィールドを持つコンポーネントです。

Runtime/DrawerExample.cs
 1using UnityEngine;
 2
 3namespace EditorIntro
 4{
 5    /// <summary>
 6    /// 第 7 章のサンプルです。
 7    /// 自作の PropertyDrawer と DecoratorDrawer が適用されるフィールドを持ちます。
 8    /// </summary>
 9    public class DrawerExample : MonoBehaviour
10    {
11        // NoteAttribute → NoteDrawer（DecoratorDrawer）で補足説明を表示します。
12        // MinMaxRange 型 → MinMaxRangeDrawer（PropertyDrawer）で表示します。
13        [Note("敵が出現する間隔（秒）を、最小値と最大値で指定します。")]
14        [SerializeField] private MinMaxRange spawnInterval = new MinMaxRange(1f, 3f);
15
16        // TagSelectorAttribute → TagSelectorDrawer（PropertyDrawer）で表示します。
17        [TagSelector]
18        [SerializeField] private string targetTag = "Player";
19
20        public MinMaxRange SpawnInterval => spawnInterval;
21        public string TargetTag => targetTag;
22    }
23}

DrawerExample.cs をダウンロード

このコンポーネントをゲームオブジェクトに追加すると、Inspector ウィンドウは次のように表示されます。

  • 「Spawn Interval」の上に、補足説明が表示される

  • 「Spawn Interval」の最小値と最大値が 1 行に並び、最小値が最大値を超えると警告が表示される

  • 「Target Tag」が、タグを選択するドロップダウンになる

7.2. 型に対する PropertyDrawer

最小値と最大値の組を表す MinMaxRange 構造体を例に、独自の型の表示をカスタマイズします。

Runtime/MinMaxRange.cs
 1using System;
 2using UnityEngine;
 3
 4namespace EditorIntro
 5{
 6    /// <summary>
 7    /// 最小値と最大値の組を表す型です。
 8    /// 第 7 章の MinMaxRangeDrawer で、Inspector ウィンドウの表示をカスタマイズします。
 9    /// </summary>
10    [Serializable]
11    public struct MinMaxRange
12    {
13        [SerializeField] private float min;
14        [SerializeField] private float max;
15
16        public MinMaxRange(float min, float max)
17        {
18            this.min = min;
19            this.max = max;
20        }
21
22        public float Min => min;
23        public float Max => max;
24
25        /// <summary>min 以上 max 以下の乱数を返します。</summary>
26        public float GetRandomValue()
27        {
28            return UnityEngine.Random.Range(min, max);
29        }
30    }
31}

MinMaxRange.cs をダウンロード

独自の型をシリアライズするには、型に Serializable 属性を付けます。PropertyDrawer を作成しない場合、この型のフィールドは、折りたたみ可能な見出しの下に「Min」と「Max」が縦に並んで表示されます。

この表示を 1 行にまとめる PropertyDrawer が次のコードです。

Editor/MinMaxRangeDrawer.cs
 1using UnityEditor;
 2using UnityEditor.UIElements;
 3using UnityEngine.UIElements;
 4
 5namespace EditorIntro.EditorScripts
 6{
 7    /// <summary>
 8    /// 第 7 章のサンプルです。
 9    /// MinMaxRange 型のフィールドを「ラベル・最小値・最大値」の 1 行で表示します。
10    /// </summary>
11    [CustomPropertyDrawer(typeof(MinMaxRange))]
12    public class MinMaxRangeDrawer : PropertyDrawer
13    {
14        public override VisualElement CreatePropertyGUI(SerializedProperty property)
15        {
16            // MinMaxRange 構造体の中にある private フィールドを取得します。
17            var minProperty = property.FindPropertyRelative("min");
18            var maxProperty = property.FindPropertyRelative("max");
19
20            var root = new VisualElement();
21
22            var row = new VisualElement();
23            row.style.flexDirection = FlexDirection.Row;
24            root.Add(row);
25
26            var label = new Label(property.displayName);
27            label.style.width = 120;
28            label.style.unityTextAlign = UnityEngine.TextAnchor.MiddleLeft;
29            row.Add(label);
30
31            row.Add(CreateFloatField("最小", minProperty));
32            row.Add(CreateFloatField("最大", maxProperty));
33
34            // 最小値が最大値を超えているときだけ警告を表示します。
35            var warning = new HelpBox("最小値が最大値を超えています。", HelpBoxMessageType.Warning);
36            root.Add(warning);
37
38            void UpdateWarning()
39            {
40                var isInvalid = minProperty.floatValue > maxProperty.floatValue;
41                warning.style.display = isInvalid ? DisplayStyle.Flex : DisplayStyle.None;
42            }
43
44            UpdateWarning();
45            root.TrackPropertyValue(minProperty, _ => UpdateWarning());
46            root.TrackPropertyValue(maxProperty, _ => UpdateWarning());
47
48            return root;
49        }
50
51        private static FloatField CreateFloatField(string label, SerializedProperty property)
52        {
53            var field = new FloatField(label);
54
55            // BindProperty で、入力欄と SerializedProperty を結び付けます。
56            field.BindProperty(property);
57
58            // 残りの幅を 2 つの入力欄で等分し、短いラベルが入力欄を圧迫しないようにします。
59            field.style.flexGrow = 1;
60            field.style.flexBasis = 0;
61            field.labelElement.style.minWidth = 0;
62            return field;
63        }
64    }
65}

PropertyDrawer は、次の手順で作成します。

  1. PropertyDrawer クラスを継承したクラスを、エディター専用のアセンブリに作成します。

  2. クラスに CustomPropertyDrawer 属性を付け、対象の型を指定します。

  3. CreatePropertyGUI メソッドをオーバーライドし、表示する UI を作成して返します。

CreatePropertyGUI の引数には、表示の対象となるフィールドの SerializedProperty が渡されます。構造体やクラスの中のフィールドは、FindPropertyRelative にフィールド名を指定して取得します。

入力欄と SerializedProperty を結び付けるには、BindProperty メソッドを使います。

var field = new FloatField(label);
field.BindProperty(property);

最小値が最大値を超えたときの警告は、第 6 章と同じく TrackPropertyValue を使って表示を切り替えています。

7.3. 属性に対する PropertyDrawer

PropertyDrawer は、型ではなく属性に対しても作成できます。属性に対する PropertyDrawer を使うと、同じ string 型のフィールドでも、属性を付けたものだけ表示を変えられます。

まず、PropertyAttribute を継承した属性クラスを作成します。属性はゲーム本体側のスクリプトで使うため、ゲーム本体側のアセンブリに置きます。

Runtime/TagSelectorAttribute.cs
 1using UnityEngine;
 2
 3namespace EditorIntro
 4{
 5    /// <summary>
 6    /// string 型のフィールドに付けると、タグをドロップダウンで選択できるようになる属性です。
 7    /// 表示の処理は第 7 章の TagSelectorDrawer に記述します。
 8    /// </summary>
 9    public class TagSelectorAttribute : PropertyAttribute
10    {
11    }
12}

TagSelectorAttribute.cs をダウンロード

次に、この属性に対する PropertyDrawer を、エディター専用のアセンブリに作成します。CustomPropertyDrawer 属性には、属性クラスの型を指定します。

Editor/TagSelectorDrawer.cs
 1using UnityEditor;
 2using UnityEditor.UIElements;
 3using UnityEngine.UIElements;
 4
 5namespace EditorIntro.EditorScripts
 6{
 7    /// <summary>
 8    /// 第 7 章のサンプルです。
 9    /// TagSelector 属性が付いた string 型のフィールドを、タグのドロップダウンで表示します。
10    /// </summary>
11    [CustomPropertyDrawer(typeof(TagSelectorAttribute))]
12    public class TagSelectorDrawer : PropertyDrawer
13    {
14        public override VisualElement CreatePropertyGUI(SerializedProperty property)
15        {
16            // string 型以外のフィールドに付けられた場合は、エラーメッセージを表示します。
17            if (property.propertyType != SerializedPropertyType.String)
18            {
19                return new HelpBox(
20                    $"{property.displayName}：TagSelector 属性は string 型のフィールドにだけ使用できます。",
21                    HelpBoxMessageType.Error);
22            }
23
24            // TagField は、プロジェクトに登録されているタグを選択肢に持つドロップダウンです。
25            var field = new TagField(property.displayName);
26            field.BindProperty(property);
27
28            // ほかのフィールドとラベルの幅をそろえます。
29            field.AddToClassList(BaseField<string>.alignedFieldUssClassName);
30            return field;
31        }
32    }
33}

TagSelectorDrawer.cs をダウンロード

属性は、どの型のフィールドにも付けられてしまいます。サンプルコードでは、propertyType でフィールドの型を調べ、string 型以外に付けられた場合はエラーメッセージを表示しています。

TagField は、プロジェクトに登録されているタグを選択肢に持つドロップダウンです。UI Toolkit には、このほかにもエディター用の入力欄が用意されています。

要素

内容

TagField

タグを選択するドロップダウン

LayerField

レイヤーを選択するドロップダウン

ObjectField

オブジェクトの参照を指定する入力欄

ColorField

色を指定する入力欄

BaseField<string>.alignedFieldUssClassName は、Inspector ウィンドウでほかのフィールドとラベルの幅をそろえるための USS クラス名です。PropertyField が作成する入力欄には自動で付きますが、自分で作成した入力欄には付かないため、明示的に追加しています。

7.4. DecoratorDrawer

DecoratorDrawer は、フィールドの上に装飾を加えるための仕組みです。第 4 章の Header 属性や Space 属性も、DecoratorDrawer で実現されています。

Runtime/NoteAttribute.cs
 1using UnityEngine;
 2
 3namespace EditorIntro
 4{
 5    /// <summary>
 6    /// フィールドの上に補足説明を表示する属性です。
 7    /// 表示の処理は第 7 章の NoteDrawer に記述します。
 8    /// </summary>
 9    public class NoteAttribute : PropertyAttribute
10    {
11        public NoteAttribute(string text)
12        {
13            Text = text;
14        }
15
16        public string Text { get; }
17    }
18}

Editor/NoteDrawer.cs
 1using UnityEditor;
 2using UnityEngine.UIElements;
 3
 4namespace EditorIntro.EditorScripts
 5{
 6    /// <summary>
 7    /// 第 7 章のサンプルです。
 8    /// Note 属性が付いたフィールドの上に、補足説明を表示します。
 9    /// </summary>
10    [CustomPropertyDrawer(typeof(NoteAttribute))]
11    public class NoteDrawer : DecoratorDrawer
12    {
13        // DecoratorDrawer はフィールドの値を扱わないため、引数に SerializedProperty がありません。
14        public override VisualElement CreatePropertyGUI()
15        {
16            var note = (NoteAttribute)attribute;
17            return new HelpBox(note.Text, HelpBoxMessageType.Info);
18        }
19    }
20}

NoteDrawer.cs をダウンロード

DecoratorDrawer はフィールドの値を扱わないため、CreatePropertyGUI に引数がありません。属性に渡した値は、attribute プロパティから取得します。

PropertyDrawer と違い、DecoratorDrawer は 1 つのフィールドに複数適用できます。サンプルコードの spawnInterval フィールドでは、Note 属性による DecoratorDrawer と、MinMaxRange 型に対する PropertyDrawer が同時に適用されています。

7.5. PropertyDrawer を作るときの注意点

7.5.1. PropertyDrawer の中で、同じフィールドの PropertyField を作らない

属性に対する PropertyDrawer の中で、引数の property をそのまま PropertyField に渡すと、その PropertyField にも同じ PropertyDrawer が適用される可能性があります。サンプルコードの TagSelectorDrawer のように、TagField などの具体的な入力欄を作成してください。

一方、FindPropertyRelative で取得した子のフィールドを PropertyField で表示するのは問題ありません。

7.5.2. IMGUI の Inspector ウィンドウでは表示されない

CreatePropertyGUI は UI Toolkit 用のメソッドです。Unity 6 の既定の Inspector ウィンドウは UI Toolkit で表示されるため、通常は問題ありません。ただし、IMGUI の OnInspectorGUI で作られたカスタムエディターの中では CreatePropertyGUI は使われず、代わりに IMGUI 用の OnGUI メソッドが呼ばれます。OnGUI を実装していない場合は、「No GUI Implemented」と表示されます。
