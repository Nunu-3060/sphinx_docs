12. 実践：一括リネームツールを作る

この章では、これまでに説明した内容を組み合わせて、Hierarchy ウィンドウで選択した複数のゲームオブジェクトの名前を、連番付きで一括変更するツールを作成します。

12.1. ツールの仕様

作成するツールの仕様は次のとおりです。

  • Tools ‣ Editor Intro ‣ Batch Rename を選択すると、専用のウィンドウが開く

  • 接頭辞、開始番号、桁数を指定すると、「接頭辞 + 連番」の名前を付けられる（例：Item_01、Item_02、…）

  • 変更前と変更後の名前をプレビューで確認できる

  • 名前は Hierarchy ウィンドウの表示順に割り当てる

  • 変更は Ctrl + Z で元に戻せる

  • 接頭辞、開始番号、桁数の初期値は、Project Settings ウィンドウで設定できる

各機能と、それを説明した章の対応は次のとおりです。

機能

関連する章

メニューからウィンドウを開く

第 3 章（メニューの追加）、第 8 章（EditorWindow）

名前の変更を Undo に記録する

第 5 章（SerializedObject と Undo）

選択の変更に合わせてプレビューを更新する

第 8 章（EditorWindow）

初期値を Project Settings ウィンドウで設定する

第 11 章（設定の保存）

12.2. サンプルコード

Editor/BatchRenameWindow.cs
  1using System.Collections.Generic;
  2using System.Linq;
  3using UnityEditor;
  4using UnityEngine;
  5using UnityEngine.UIElements;
  6
  7namespace EditorIntro.EditorScripts
  8{
  9    /// <summary>
 10    /// 第 12 章のサンプルです。
 11    /// Hierarchy ウィンドウで選択したゲームオブジェクトの名前を、連番付きで一括変更します。
 12    /// </summary>
 13    public class BatchRenameWindow : EditorWindow
 14    {
 15        private TextField prefixField;
 16        private IntegerField startNumberField;
 17        private SliderInt digitsField;
 18        private ScrollView previewList;
 19        private Button renameButton;
 20
 21        [MenuItem("Tools/Editor Intro/Batch Rename")]
 22        public static void Open()
 23        {
 24            var window = GetWindow<BatchRenameWindow>();
 25            window.titleContent = new GUIContent("Batch Rename");
 26            window.minSize = new Vector2(320, 240);
 27        }
 28
 29        private void CreateGUI()
 30        {
 31            // 入力欄の初期値は、Project Settings ウィンドウで設定した値（第 11 章）を使います。
 32            var settings = BatchRenameSettings.instance;
 33
 34            var root = rootVisualElement;
 35            root.style.paddingLeft = 6;
 36            root.style.paddingRight = 6;
 37            root.style.paddingTop = 6;
 38            root.style.paddingBottom = 6;
 39
 40            prefixField = new TextField("接頭辞") { value = settings.Prefix };
 41            startNumberField = new IntegerField("開始番号") { value = settings.StartNumber };
 42            digitsField = new SliderInt("桁数", BatchRenameSettings.MinDigits, BatchRenameSettings.MaxDigits)
 43            {
 44                value = settings.Digits,
 45                showInputField = true,
 46            };
 47
 48            // 入力が変わるたびにプレビューを更新します。
 49            prefixField.RegisterValueChangedCallback(_ => RefreshPreview());
 50            startNumberField.RegisterValueChangedCallback(evt =>
 51            {
 52                // 開始番号に負の値を入力できないようにします。
 53                if (evt.newValue < 0)
 54                {
 55                    startNumberField.SetValueWithoutNotify(0);
 56                }
 57
 58                RefreshPreview();
 59            });
 60            digitsField.RegisterValueChangedCallback(_ => RefreshPreview());
 61
 62            root.Add(prefixField);
 63            root.Add(startNumberField);
 64            root.Add(digitsField);
 65
 66            var previewLabel = new Label("プレビュー");
 67            previewLabel.style.unityFontStyleAndWeight = FontStyle.Bold;
 68            previewLabel.style.marginTop = 8;
 69            root.Add(previewLabel);
 70
 71            // プレビューは残りの高さいっぱいに広げ、はみ出した分はスクロールで表示します。
 72            previewList = new ScrollView();
 73            previewList.style.flexGrow = 1;
 74            root.Add(previewList);
 75
 76            renameButton = new Button(Rename) { text = "名前を変更" };
 77            renameButton.style.height = 24;
 78            root.Add(renameButton);
 79
 80            RefreshPreview();
 81        }
 82
 83        // 選択が変わったときと、Hierarchy ウィンドウの内容が変わったとき（名前や並び順の変更など）にプレビューを更新します。
 84        private void OnSelectionChange()
 85        {
 86            RefreshPreview();
 87        }
 88
 89        private void OnHierarchyChange()
 90        {
 91            RefreshPreview();
 92        }
 93
 94        private void RefreshPreview()
 95        {
 96            // CreateGUI より前に呼ばれた場合は何もしません。
 97            if (previewList == null)
 98            {
 99                return;
100            }
101
102            previewList.Clear();
103
104            var targets = GetTargets();
105            if (targets.Count == 0)
106            {
107                previewList.Add(new HelpBox(
108                    "Hierarchy ウィンドウで、名前を変更するゲームオブジェクトを選択してください。",
109                    HelpBoxMessageType.Info));
110                renameButton.SetEnabled(false);
111                return;
112            }
113
114            for (var i = 0; i < targets.Count; i++)
115            {
116                previewList.Add(new Label($"{targets[i].name} → {CreateName(i)}"));
117            }
118
119            renameButton.SetEnabled(true);
120        }
121
122        private void Rename()
123        {
124            var targets = GetTargets();
125
126            // 複数のオブジェクトの変更を、1 回の Undo 操作で元に戻せるようにまとめて記録します。
127            Undo.RecordObjects(targets.ToArray(), "Batch Rename");
128
129            for (var i = 0; i < targets.Count; i++)
130            {
131                targets[i].name = CreateName(i);
132
133                if (PrefabUtility.IsPartOfPrefabInstance(targets[i]))
134                {
135                    PrefabUtility.RecordPrefabInstancePropertyModifications(targets[i]);
136                }
137            }
138
139            RefreshPreview();
140        }
141
142        /// <summary>
143        /// 選択中のゲームオブジェクトのうち、シーン上にあるものを Hierarchy ウィンドウの表示順で返します。
144        /// </summary>
145        private static List<GameObject> GetTargets()
146        {
147            // IsPersistent はアセット（Project ウィンドウで選択したプレハブなど）のとき true になります。
148            var targets = Selection.gameObjects
149                .Where(go => !EditorUtility.IsPersistent(go))
150                .ToList();
151
152            // Selection.gameObjects の順序は決まっていないため、表示順に並べ替えます。
153            targets.Sort(CompareHierarchyOrder);
154            return targets;
155        }
156
157        private string CreateName(int index)
158        {
159            // 例：接頭辞「Item_」、開始番号 1、桁数 2 のとき → Item_01、Item_02、…
160            var number = startNumberField.value + index;
161            return prefixField.value + number.ToString($"D{digitsField.value}");
162        }
163
164        /// <summary>
165        /// 2 つのゲームオブジェクトを、Hierarchy ウィンドウの表示順で比較します。
166        /// 複数のシーンを開いている場合、シーンをまたいだ順序は考慮しません。
167        /// </summary>
168        private static int CompareHierarchyOrder(GameObject a, GameObject b)
169        {
170            var pathA = GetSiblingIndexPath(a.transform);
171            var pathB = GetSiblingIndexPath(b.transform);
172
173            var length = Mathf.Min(pathA.Count, pathB.Count);
174            for (var i = 0; i < length; i++)
175            {
176                if (pathA[i] != pathB[i])
177                {
178                    return pathA[i].CompareTo(pathB[i]);
179                }
180            }
181
182            // 一方が他方の親の場合は、親を先にします。
183            return pathA.Count.CompareTo(pathB.Count);
184        }
185
186        /// <summary>
187        /// ルートから対象までの、各階層での並び順（兄弟の中での番号）のリストを返します。
188        /// </summary>
189        private static List<int> GetSiblingIndexPath(Transform transform)
190        {
191            var path = new List<int>();
192            for (var current = transform; current != null; current = current.parent)
193            {
194                path.Insert(0, current.GetSiblingIndex());
195            }
196
197            return path;
198        }
199    }
200}

BatchRenameWindow.cs をダウンロード

このツールは、第 11 章の BatchRenameSettings.cs と BatchRenameSettingsProvider.cs も使います。

12.3. 使い方

  1. Tools ‣ Editor Intro ‣ Batch Rename を選択して、ウィンドウを開きます。

  2. Hierarchy ウィンドウで、名前を変更するゲームオブジェクトを複数選択します。

  3. 「接頭辞」「開始番号」「桁数」を入力し、プレビューで変更後の名前を確認します。

  4. 「名前を変更」ボタンをクリックします。

  5. 元に戻す場合は、Ctrl + Z を押します。

12.4. コードの解説

12.4.1. UI の作成

このツールでは、UXML を使わず、C# のコードだけで UI を作成しています。入力欄が少ない場合は、ファイルを分けないほうが全体を把握しやすくなります。

入力欄の初期値には、第 11 章の BatchRenameSettings.instance の値を使っています。SliderInt の showInputField を true にすると、スライダーの横に数値の入力欄が表示されます。

previewList（ScrollView）の style.flexGrow を 1 にすることで、プレビューがウィンドウの残りの高さいっぱいに広がり、ボタンはウィンドウの下端に配置されます。

12.4.2. プレビューの更新

プレビューは、次のタイミングで RefreshPreview メソッドを呼んで更新しています。

タイミング

呼び出し元

入力欄の値が変わったとき

各入力欄の RegisterValueChangedCallback

選択が変わったとき

OnSelectionChange

ゲームオブジェクトの名前や並び順が変わったとき

OnHierarchyChange

名前を変更した直後

Rename

対象のゲームオブジェクトが無いときは、プレビューの代わりに案内のメッセージを表示し、SetEnabled(false) でボタンをクリックできないようにしています。

12.4.3. 対象の取得と並べ替え

GetTargets メソッドは、名前を変更する対象を取得します。

Selection.gameObjects には、Project ウィンドウで選択したプレハブのアセットも含まれます。EditorUtility.IsPersistent はアセットのときに true を返すため、これを使ってシーン上のゲームオブジェクトだけに絞り込んでいます。

また、Selection.gameObjects の順序は Hierarchy ウィンドウの表示順と一致するとは限りません。そこで、CompareHierarchyOrder メソッドで表示順に並べ替えています。このメソッドは、各ゲームオブジェクトについて、ルートから自身までの各階層での並び順（Transform.GetSiblingIndex の値）のリストを作成し、リストを先頭から比べます。

例えば、次の階層構造で「B」と「A-2」を比べる場合を考えます。

A         … [0]
├ A-1     … [0, 0]
└ A-2     … [0, 1]
B         … [1]

「A-2」のリストは [0, 1]、「B」のリストは [1] です。先頭の要素を比べると 0 < 1 なので、「A-2」が先になります。

12.4.4. 名前の変更

Rename メソッドでは、名前を変更する前に Undo.RecordObjects を呼び、すべての対象の変更を 1 回の Undo 操作にまとめて記録しています。ゲームオブジェクトの名前は name プロパティとして公開されているため、第 5 章の Undo.RecordObject の方法を使っています。

プレハブのインスタンスの名前を変更した場合に備えて、PrefabUtility.RecordPrefabInstancePropertyModifications も呼んでいます。

連番の文字列は、int.ToString に書式指定文字列「D」と桁数を渡して作成しています。例えば 7.ToString("D3") は「007」を返します。

12.5. 発展課題

このツールをさらに便利にするために、次のような機能を追加してみてください。

  • 接尾辞を指定できるようにする

  • 元の名前を残し、その後ろに連番を付けるモードを追加する

  • 同じ名前のゲームオブジェクトがあるときに警告を表示する

  • Project ウィンドウで選択したアセットの名前も変更できるようにする（AssetDatabase.RenameAsset を使う）
