4. 属性による Inspector 表示の調整

Inspector ウィンドウの表示は、フィールドに属性を付けるだけでもある程度調整できます。エディター拡張のスクリプトを書く前に、まずこの方法で足りないかを検討しましょう。

この章で扱う属性はすべて UnityEngine 名前空間にあるため、ゲーム本体側のスクリプトに直接書けます。

4.1. サンプルコード

Runtime/AttributeExample.cs
 1using UnityEngine;
 2
 3namespace EditorIntro
 4{
 5    /// <summary>
 6    /// 第 4 章のサンプルです。
 7    /// 属性を付けるだけで Inspector ウィンドウの表示を調整できることを示します。
 8    /// </summary>
 9    public class AttributeExample : MonoBehaviour
10    {
11        public enum Difficulty
12        {
13            // InspectorName 属性で、Inspector ウィンドウに表示する名前を変更できます。
14            [InspectorName("かんたん")] Easy,
15            [InspectorName("ふつう")] Normal,
16            [InspectorName("むずかしい")] Hard,
17        }
18
19        [Header("基本情報")]
20        [Tooltip("キャラクターの名前です。マウスカーソルを重ねると、この説明が表示されます。")]
21        [SerializeField] private string characterName = "Hero";
22
23        [Min(1)]
24        [SerializeField] private int level = 1;
25
26        [SerializeField] private Difficulty difficulty = Difficulty.Normal;
27
28        [Space(12)]
29        [Header("能力値")]
30        [Range(0f, 100f)]
31        [SerializeField] private float hitRate = 80f;
32
33        [Range(1, 10)]
34        [SerializeField] private int attackCount = 1;
35
36        [Header("説明文")]
37        [TextArea(2, 5)]
38        [SerializeField] private string profile = "";
39
40        // public フィールドは SerializeField 属性を付けなくても保存・表示されます。
41        public Color themeColor = Color.white;
42
43        // HideInInspector 属性を付けると、保存はされますが表示されません。
44        [HideInInspector] public int hiddenValue;
45
46        public string CharacterName => characterName;
47        public int Level => level;
48        public Difficulty CurrentDifficulty => difficulty;
49        public float HitRate => hitRate;
50        public int AttackCount => attackCount;
51        public string Profile => profile;
52    }
53}

このコンポーネントをゲームオブジェクトに追加すると、Inspector ウィンドウに見出しや説明、スライダーなどが表示されます。

4.2. Inspector ウィンドウに表示されるフィールド

Inspector ウィンドウには、Unity がシリアライズ（保存）するフィールドが表示されます。シリアライズされるかどうかは、主に次の規則で決まります。

ほかのクラスから変更されたくない値は、public にせず、private フィールドに SerializeField 属性を付けるのが一般的です。サンプルコードでは、値を読み取るための読み取り専用プロパティを別に用意しています。

なお、static、const、readonly の付いたフィールドはシリアライズされません。

4.3. 表示を調整する属性

属性

効果

Header("見出し")

フィールドの上に太字の見出しを表示します。

Space(高さ)

フィールドの上に、指定した高さ（ピクセル）の余白を入れます。

Tooltip("説明")

フィールド名にマウスカーソルを重ねたときに説明を表示します。

InspectorName("表示名")

列挙型の要素に付けると、ドロップダウンに表示する名前を変更できます。

Header 属性と Space 属性は、関連するフィールドをまとめて見やすくするのに役立ちます。Tooltip 属性は、フィールド名だけでは意味が伝わりにくい値に付けておくと、ほかの人がコンポーネントを使うときの助けになります。

4.4. 入力方法を変える属性

属性

効果

Range(最小値, 最大値)

int 型や float 型のフィールドをスライダーで表示し、入力できる値を範囲内に制限します。

Min(最小値)

int 型や float 型のフィールドに、指定した値より小さい値を入力できないようにします。

TextArea(最小行数, 最大行数)

string 型のフィールドを複数行の入力欄で表示します。行数が最大行数を超えるとスクロールバーが表示されます。

Multiline(行数)

string 型のフィールドを、指定した行数の入力欄で表示します。

Range 属性や Min 属性は、Inspector ウィンドウでの入力を制限するだけです。スクリプトから範囲外の値を代入することは防げない点に注意してください。

4.5. 属性の組み合わせ

1 つのフィールドに複数の属性を付けることもできます。サンプルコードの hitRate フィールドには、Header 属性、Range 属性、SerializeField 属性を付けています。

[Space(12)]
[Header("能力値")]
[Range(0f, 100f)]
[SerializeField] private float hitRate = 80f;

Header 属性や Space 属性のようにフィールドの上に装飾を加える属性は、複数を組み合わせられます。一方、Range 属性や TextArea 属性のように入力欄そのものを変える属性は、1 つのフィールドに 1 つだけ付けてください。複数付けた場合、有効になるのは 1 つだけです。

4.6. 属性で足りない場合

属性だけでは、次のようなことはできません。

  • 値に応じて警告を表示する

  • ボタンを配置して処理を実行する

  • 独自の型を、専用の入力欄で表示する

このような場合は、第 6 章のカスタムエディターや、第 7 章の PropertyDrawer を使います。
