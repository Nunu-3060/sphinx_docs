Unity エディター拡張入門

本書は、Unity のエディター拡張を初めて学ぶ人のための入門資料です。メニューへの項目の追加から、Inspector ウィンドウのカスタマイズ、独自のウィンドウや Scene ビューの拡張、アセットの操作までを順に説明し、最後にこれらを組み合わせた小さなツールを作成します。

本書のサンプルコードは、次のリンクからまとめてダウンロードできます。各章のページからも、ファイルごとに閲覧・ダウンロードできます。
