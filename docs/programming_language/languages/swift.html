4.8. Swift

4.8.1. 基本情報

登場年

2014 年（2015 年にオープンソース化）

設計者

クリス・ラトナー（Apple）。現在は Apple とオープンソースのコミュニティが開発を担う。

標準仕様

The Swift Programming Language（公式のリファレンス）と、Swift Evolution による提案の手続き

主な処理系

Swift コンパイラ（バックエンドに LLVM を使用）。macOS、iOS、Linux、Windows に対応する。

2026 年時点の状況

2024 年の Swift 6 で、データ競合をコンパイル時に検出する言語モードが導入された。

4.8.2. 誕生の背景と設計思想

Apple のプラットフォームでは、長らく Objective-C が標準の言語であった。Objective-C は C の上に Smalltalk 風のメッセージ送信を加えた言語であり、C から受け継いだ安全性の問題と、独特で冗長な構文を抱えていた。LLVM の開発者でもあるクリス・ラトナーは 2010 年に Swift の開発を始め、Apple は 2014 年の開発者会議 WWDC で Swift を発表した。

Swift は「安全」「高速」「表現力が高い」ことを目標とする。Objective-C との相互運用性を保ちながら、型安全性、null 安全、値型の重視といった現代的な設計を取り入れた。2015 年にはオープンソース化され、Linux や Windows でも使えるようになった。

4.8.3. 主な特徴

  • 静的型付けと型推論：強力な型推論を備え、型注釈の多くを省略できる。

  • オプショナル：値がないことを Int? のようなオプショナル型で表し、null 安全を実現する。オプショナルの値を使うには、if let や guard let で中身を取り出す必要がある。

  • 値型の重視：構造体（struct）と列挙型（enum）は値型であり、標準ライブラリの配列や文字列も値型である。コピーオンライトの最適化により、値型のコピーのコストを抑えている。

  • ARC によるメモリ管理：クラスのインスタンスは自動参照カウント（ARC）で管理される。GC による停止は発生しないが、循環参照は weak などで開発者が断ち切る必要がある（参照カウント）。

  • プロトコル指向：プロトコル（ほかの言語のインタフェースやトレイトに相当）とその拡張を中心に設計することが推奨されている。

  • 構造化された並行処理：Swift 5.5 で async/await と actor が導入され、Swift 6 の言語モードではデータ競合の可能性をコンパイル時にエラーとして検出する。

4.8.4. コード例

リスト 4.8 word_count.swift
 1// 文章中の単語の出現回数を数え、上位の単語を表示するサンプル
 2
 3/// 英単語を小文字にそろえて出現回数を数える。
 4func countWords(in text: String) -> [String: Int] {
 5    var counts: [String: Int] = [:]
 6    for word in text.lowercased().split(whereSeparator: { !$0.isLetter }) {
 7        counts[String(word), default: 0] += 1
 8    }
 9    return counts
10}
11
12/// 出現回数の降順、同数なら単語の昇順で上位 limit 件を返す。
13func topWords(_ counts: [String: Int], limit: Int) -> [(word: String, count: Int)] {
14    let sorted = counts.sorted { lhs, rhs in
15        lhs.value != rhs.value ? lhs.value > rhs.value : lhs.key < rhs.key
16    }
17    return sorted.prefix(limit).map { (word: $0.key, count: $0.value) }
18}
19
20let text = "The quick brown fox jumps over the lazy dog. The dog sleeps."
21for (word, count) in topWords(countWords(in: text), limit: 3) {
22    print("\(word): \(count)")
23}

Swift では、関数の引数に呼び出し側で使う名前（引数ラベル）を付けられる。4 行目の countWords(in text: String) は、呼び出し側で countWords(in: text) （21 行目）と英語の文のように読める形にするためのものである。13 行目の _ は引数ラベルを省略する指定である。7 行目の counts[String(word), default: 0] += 1 は、キーがなければ既定値 0 から数え始める辞書の操作である。13 行目の戻り値の型 [(word: String, count: Int)] は、名前付きの要素を持つタプルの配列である。

4.8.5. 主な用途

  • iOS、iPadOS、macOS、watchOS、visionOS などの Apple プラットフォーム向けアプリ

  • UI フレームワーク SwiftUI を使ったアプリ開発

  • サーバサイド（Vapor など）

  • 組込みソフトウェア（Embedded Swift）

4.8.6. エコシステム

  • ビルドツールとパッケージマネージャ：Swift Package Manager。Apple のプラットフォーム向けアプリでは Xcode のプロジェクトも使われる。

  • 主要なフレームワーク：SwiftUI、UIKit、Combine、Vapor

  • 開発環境：Xcode、Visual Studio Code（Swift の拡張機能）

4.8.7. 長所と短所

長所

  • 安全性と性能を両立し、読みやすい構文を持つ。

  • Apple のプラットフォームでは第一の言語であり、最新の API やフレームワークを利用できる。

  • ARC により、GC による停止がなく、メモリ使用量も予測しやすい。

短所

  • 利用の大部分が Apple のプラットフォームに集中しており、ほかの分野では採用例が少ない。

  • 型推論の複雑な式でコンパイルが遅くなることがある。

  • 言語の進化が速く、バージョン間の移行の負担が生じることがある。
