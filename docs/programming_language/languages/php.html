4.13. PHP

4.13.1. 基本情報

登場年

1995 年

設計者

ラスマス・ラードフ。PHP 3 以降はアンディ・ガトマンスとゼエヴ・スラスキが中心となって処理系を作り直し、現在は PHP Foundation とコミュニティが開発を担う。

標準仕様

公式の処理系の挙動が事実上の仕様である。言語の変更は RFC として提案され、投票で決まる。

主な処理系

Zend Engine を中核とする公式の処理系

2026 年時点の状況

毎年 11 月ごろに新しいマイナーバージョンが公開される。2025 年 11 月に公開された PHP 8.5 では、パイプ演算子（|>）が導入された。

4.13.2. 誕生の背景と設計思想

PHP は、ラスマス・ラードフが自身の Web ページへのアクセスを記録するために C で書いた CGI プログラムの集まり「Personal Home Page Tools」から始まった。HTML の中に処理を埋め込んで Web ページを動的に生成できる手軽さから、Web 開発の言語として急速に普及した。現在の名称は、再帰的な頭字語「PHP: Hypertext Preprocessor」である。

PHP は、言語として体系的に設計されたというより、Web 開発の現場の要求に応えて機能が追加されてきた言語である。そのため、初期の版には関数名や引数の順序の不統一、安全でない既定の設定などの問題があった。一方で、「書いてすぐに動く」手軽さと、多くのレンタルサーバで利用できる導入のしやすさが、PHP を Web で最も広く使われるサーバサイド言語に押し上げた。

PHP 7（2015 年）で処理系が大幅に高速化され、スカラー型の宣言も導入された。PHP 8（2020 年）以降は、JIT コンパイラ、ユニオン型、名前付き引数、match 式、列挙型、読み取り専用プロパティなどが追加され、現代的な言語へと大きく進化している。

4.13.3. 主な特徴

  • Web 向けの実行モデル：基本的に HTTP リクエストごとに処理を開始し、応答を返すと状態を破棄する（シェアードナッシング）。リクエスト間で状態が残らないため、メモリリークなどの影響が限定され、水平方向の拡張も容易である。

  • 動的型付けと型宣言：変数の型は動的に決まるが、関数の引数、戻り値、プロパティに型を宣言できる。ファイルの先頭で declare(strict_types=1); を指定すると、スカラー型の暗黙の変換を禁止できる。

  • メモリ管理：参照カウントを基本とし、循環参照を回収する GC を併用する。

  • 実行方式：ソースコードを中間コード（オペコード）にコンパイルして実行する。OPcache によってコンパイル結果をキャッシュし、PHP 8 からは JIT コンパイルも利用できる。

  • 配列：PHP の配列は、リストと連想配列（順序付きのハッシュ表）を兼ねた汎用的なデータ構造である。

4.13.4. コード例

リスト 4.13 word_count.php
 1<?php
 2
 3declare(strict_types=1);
 4
 5// 文章中の単語の出現回数を数え、上位の単語を表示するサンプル
 6
 7/**
 8 * 英単語を小文字にそろえて出現回数を数える。
 9 *
10 * @return array<string, int>
11 */
12function countWords(string $text): array
13{
14    preg_match_all('/[a-z]+/', strtolower($text), $matches);
15    return array_count_values($matches[0]);
16}
17
18/**
19 * 出現回数の降順、同数なら単語の昇順で上位 limit 件を返す。
20 *
21 * @param array<string, int> $counts
22 * @return array<string, int>
23 */
24function topWords(array $counts, int $limit): array
25{
26    uksort($counts, fn(string $a, string $b): int => [$counts[$b], $a] <=> [$counts[$a], $b]);
27    return array_slice($counts, 0, $limit, true);
28}
29
30$text = 'The quick brown fox jumps over the lazy dog. The dog sleeps.';
31foreach (topWords(countWords($text), 3) as $word => $count) {
32    echo "{$word}: {$count}\n";
33}

3 行目の declare(strict_types=1); は、型宣言に合わない値の暗黙の変換を禁止する指定である。14〜15 行目では、preg_match_all で単語を切り出し、array_count_values で値ごとの出現回数を数えている。26 行目では、キーを比較する関数 uksort にアロー関数を渡し、宇宙船演算子 <=> で「出現回数と単語の組」を比較している。[$counts[$b], $a] と [$counts[$a], $b] のように比較する要素を入れ替えることで、出現回数は降順、単語は昇順となる。

4.13.5. 主な用途

  • Web サイト、Web アプリケーションのサーバサイド

  • CMS（コンテンツ管理システム）：WordPress、Drupal など。WordPress は、Web サイト全体の 4 割以上で使われている。

  • EC サイト（Magento、EC-CUBE など）

  • 社内システム、業務アプリケーション

4.13.6. エコシステム

  • パッケージマネージャ：Composer

  • パッケージリポジトリ：Packagist

  • 主要なフレームワーク：Laravel、Symfony、CakePHP

  • 開発ツール：PHPStan・Psalm（静的解析）、PHPUnit（テスト）、PHP-CS-Fixer（整形）

  • コーディング規約：PHP-FIG による PSR-12 と、その後継の PER Coding Style

4.13.7. 長所と短所

長所

  • Web 開発に特化しており、手軽に始められる。

  • 多くのレンタルサーバやホスティングサービスで利用でき、導入の障壁が低い。

  • WordPress や Laravel などの実績ある資産が豊富で、技術者も多い。

  • PHP 7 以降は実行性能が大きく向上し、言語機能も現代的になった。

短所

  • 標準関数の名前や引数の順序に一貫性がないなど、歴史的な経緯による癖が残っている。

  • 古い書き方の情報やコードが多く、脆弱性を含むコードが生まれやすい。

  • Web 以外の用途（デスクトップアプリ、常駐プロセスなど）にはあまり向かない。
