4.6. C#

4.6.1. 基本情報

登場年

2000 年（2002 年に .NET Framework 1.0 とともに C# 1.0）

設計者

アンダース・ヘルスバーグ（マイクロソフト）

標準仕様

ECMA-334、ISO/IEC 23270。最新の言語機能はマイクロソフトの言語仕様とオープンソースの設計の議論で決まる。

主な処理系

.NET（旧称 .NET Core）、.NET Framework（Windows 専用。保守のみ）、Unity のランタイム

2026 年時点の状況

.NET は毎年 11 月に新しいバージョンが公開され、偶数番号のバージョンが LTS 版となる。最新の LTS 版は .NET 10（2025 年 11 月、C# 14）である。

4.6.2. 誕生の背景と設計思想

C# は、マイクロソフトの新しい開発基盤 .NET Framework の中核となる言語として設計された。設計者のアンダース・ヘルスバーグは、Turbo Pascal と Delphi の設計者でもある。当初は Java と比較されることが多かったが、その後は言語機能の面で先進的な取り組みを続けてきた。

C# は、生産性、型安全性、実行性能のバランスを重視している。また、新しい言語機能を積極的に取り入れつつ、既存のコードとの互換性を保つことを方針としている。ジェネリクス（C# 2.0）、LINQ（C# 3.0）、async・await （C# 5.0、2012 年）などは、ほかの主要言語に先駆けて実用化された機能であり、特に async/await は JavaScript、Python、Rust、Swift などに広く取り入れられた。

4.6.3. 主な特徴

  • CLR 上での実行：C# のソースコードは中間言語（IL）にコンパイルされ、.NET のランタイム（CLR）が JIT コンパイルして実行する。事前に機械語へコンパイルする Native AOT も利用できる。

  • 型システム：値型（struct）と参照型（class）を区別する。ジェネリクスの型引数は実行時にも保持され、値型に対しては専用のコードが生成される。C# 8.0 で導入された null 許容参照型を有効にすると、null の扱い漏れをコンパイル時に警告できる。

  • LINQ：コレクション、データベース、XML などに対する問い合わせを、言語に統合された統一的な構文で記述できる。

  • async/await：非同期処理を同期処理と同じような見た目で記述できる。

  • 豊富な言語機能：プロパティ、イベント、ラムダ式、パターンマッチ、レコード、拡張メソッドなどを備える。

2016 年に公開された .NET Core によって、.NET はオープンソースかつクロスプラットフォーム（Windows、Linux、macOS）となった。2020 年の .NET 5 で .NET Framework と .NET Core の系統が統合され、名称も「.NET」に統一された。

4.6.4. コード例

リスト 4.6 WordCount.cs
 1// 文章中の単語の出現回数を数え、上位の単語を表示するサンプル
 2using System;
 3using System.Collections.Generic;
 4using System.Linq;
 5using System.Text.RegularExpressions;
 6
 7namespace WordCountSample;
 8
 9public static class Program
10{
11    /// <summary>英単語を小文字にそろえて出現回数を数える。</summary>
12    public static Dictionary<string, int> CountWords(string text) =>
13        Regex.Matches(text.ToLowerInvariant(), "[a-z]+")
14            .GroupBy(match => match.Value)
15            .ToDictionary(group => group.Key, group => group.Count());
16
17    /// <summary>出現回数の降順、同数なら単語の昇順で上位 limit 件を返す。</summary>
18    public static List<KeyValuePair<string, int>> TopWords(Dictionary<string, int> counts, int limit) =>
19        counts.OrderByDescending(pair => pair.Value)
20            .ThenBy(pair => pair.Key, StringComparer.Ordinal)
21            .Take(limit)
22            .ToList();
23
24    public static void Main()
25    {
26        const string text = "The quick brown fox jumps over the lazy dog. The dog sleeps.";
27        foreach (var (word, count) in TopWords(CountWords(text), 3))
28        {
29            Console.WriteLine($"{word}: {count}");
30        }
31    }
32}

13〜15 行目と 19〜22 行目は LINQ のメソッドを連ねた書き方であり、グループ化、集計、並べ替え、件数の制限を宣言的に記述している。12 行目や 18 行目の => は、本体が 1 つの式だけのメソッドを簡潔に書く式形式のメンバーである。27 行目では、KeyValuePair を (word, count) に分解して受け取っている。

4.6.5. 主な用途

  • 業務アプリケーション、Web アプリケーション（ASP.NET Core）

  • Windows のデスクトップアプリ（WPF、Windows Forms、WinUI）

  • ゲーム開発（Unity のスクリプト言語）

  • クラウドサービス（Microsoft Azure など）

  • クロスプラットフォームのアプリ（.NET MAUI）

4.6.6. エコシステム

  • ビルドツール：dotnet コマンド（CLI）、MSBuild

  • パッケージマネージャとリポジトリ：NuGet

  • 主要なフレームワーク：ASP.NET Core、Entity Framework Core、Blazor

  • 開発環境：Visual Studio、JetBrains Rider、Visual Studio Code

4.6.7. 長所と短所

長所

  • 言語機能が豊富で、生産性が高い。

  • JIT コンパイルにより実行性能が高い。

  • Visual Studio をはじめとする開発ツールが充実している。

  • Unity によるゲーム開発で広く使われている。

短所

  • 言語機能が多く、すべてを把握するのは容易でない。

  • Windows 中心の技術という印象が残っており、Linux 中心の環境では採用例が Java や Go ほど多くない。

  • Unity のランタイムは最新の .NET に追随するまでに時間がかかることがある。
