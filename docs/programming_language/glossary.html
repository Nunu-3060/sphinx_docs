用語集

本書で用いる主な用語を、英字で始まるもの、五十音順の順に示す。

ABI

Application Binary Interface の略。関数の呼び出し規約やデータの配置など、コンパイル済みのプログラム同士が機械語の水準で連携するための取り決めである。

AOT コンパイル

Ahead-Of-Time コンパイルの略。プログラムの実行前に、ソースコードを機械語に変換する方式である。

async/await

非同期処理を、同期処理と同じような逐次的な見た目で記述するための構文である。async を付けた関数の中で、await によって非同期処理の完了を待つ。

CSP

Communicating Sequential Processes の略。アントニー・ホーアが提唱した並行計算のモデルであり、独立した処理がチャネルを介したメッセージの送受信によって協調する。Go の goroutine とチャネルの基礎となっている。

FFI

Foreign Function Interface の略。ある言語から、別の言語（多くの場合 C）で書かれた関数を呼び出すための仕組みである。

GIL

Global Interpreter Lock の略。CPython などの処理系で、同時に 1 つのスレッドしかバイトコードを実行できないようにするロックである。Ruby の処理系では GVL（Global VM Lock）と呼ぶ。

JIT コンパイル

Just-In-Time コンパイルの略。プログラムの実行中に、頻繁に実行される部分などを機械語に変換する方式である。実行時の情報を使った最適化ができる。

LTS

Long-Term Support の略。通常より長い期間、セキュリティ修正などの保守が提供されるバージョンである。

null 安全

null（値が存在しないこと）になり得る型とそうでない型を型システムで区別し、null の参照による実行時エラーをコンパイル時に防ぐ性質である。

ORM

Object-Relational Mapping の略。オブジェクト指向の言語のオブジェクトと、リレーショナルデータベースの表とを対応付ける仕組み、またはそのためのライブラリである。

RAII

Resource Acquisition Is Initialization の略。資源の確保をオブジェクトの初期化と、資源の解放をオブジェクトの破棄と結び付け、スコープを抜けた時点で資源を自動的に解放する手法である。C++ で広く使われる。

SQL インジェクション

アプリケーションが利用者の入力をそのまま SQL 文に連結することで、攻撃者が意図しない SQL 文を実行できてしまう脆弱性である。

WebAssembly

Web ブラウザなどで動作する、CPU に依存しないバイナリ形式の命令セットである。Wasm と略される。C、C++、Rust などからコンパイルして利用する。

アクターモデル

状態を持つ「アクター」が、互いにメッセージを送り合うことで計算を進める並行計算のモデルである。アクターの状態には外部から直接アクセスできず、メッセージは 1 つずつ処理される。

イベントループ

発生したイベント（I/O の完了、タイマーなど）を待ち受け、対応する処理（コールバック）を順に実行する仕組みである。JavaScript の実行環境の中核をなす。

インタプリタ

ソースコード、またはそれを変換した中間表現を、逐次解釈しながら実行する処理系である。

仮想マシン

特定の CPU に依存しない命令（バイトコード）を実行するソフトウェアである。VM と略される。Java の JVM、.NET の CLR などがある。

型消去

ジェネリクスの型引数の情報を、型検査の後に取り除く実装方式である。実行時には型引数を参照できない。

型推論

型注釈が省略された式や変数の型を、処理系が文脈から自動的に決定する仕組みである。

ガベージコレクション

プログラムから到達できなくなったメモリを、実行時に自動的に検出して解放する仕組みである。GC と略される。

グリーンスレッド

OS ではなく、言語のランタイムが管理する軽量なスレッドである。Go の goroutine や Java の仮想スレッドがこれにあたる。

クロージャ

関数と、その関数が定義された環境（外側のスコープの変数）を組にしたものである。関数の外側の変数を捕捉して保持できる。

構造的部分型

型が持つメソッドやプロパティの構造によって、型の互換性を判定する方式である。Go のインタフェースや TypeScript で採用されている。

コルーチン

処理の途中で実行を中断し、後で再開できる関数である。非同期処理や、値を順に生成する処理の実装に使われる。

サプライチェーン攻撃

ソフトウェアが依存するライブラリや開発ツール、配布経路などに悪意のあるコードを混入させ、それを利用するソフトウェアを攻撃する手法である。

参照カウント

オブジェクトを参照している箇所の数を数え、その数が 0 になった時点でオブジェクトを解放するメモリ管理の方式である。

ジェネリクス

型を引数として受け取ることで、さまざまな型に対して同じ処理やデータ構造を型安全に記述する仕組みである。

借用

Rust において、値の所有権を移さずに、値への参照を一時的に受け取ることである。共有参照（読み取り専用）と可変参照がある。

所有権

Rust において、各値をただ 1 つの変数（所有者）が所有し、所有者がスコープを抜けた時点で値を解放する仕組みである。

宣言型プログラミング

処理の手順ではなく、求める結果の性質を記述するプログラミングの様式である。SQL が代表例である。

漸進的型付け

動的型付けの言語に、任意で型注釈を加えられるようにし、注釈を書いた部分だけを静的に検査する方式である。

第一級関数

関数を、数値や文字列と同じように、変数への代入、引数としての受け渡し、戻り値として返すことができる性質である。

代数的データ型

複数の型のいずれか（直和型）や、複数の型の組（直積型）を組み合わせて定義するデータ型である。Rust の enum や Swift の enum が該当する。

単相化

ジェネリクスの実装方式の 1 つで、使われた型引数ごとに専用のコードを生成する方式である。

データ競合

複数のスレッドが同じメモリに同時にアクセスし、そのうち少なくとも 1 つが書き込みであり、かつアクセスが同期されていない状態である。予測できない結果を引き起こす。

トランスパイル

ある言語のソースコードを、別の言語（または同じ言語の別のバージョン）のソースコードに変換することである。

トレイト

型が備えるべきメソッドなどの振る舞いを定義したものである。Rust で用いられ、ほかの言語のインタフェースに近い。

バイトコード

仮想マシンやインタプリタが実行するための、CPU に依存しない中間的な命令列である。

パターンマッチ

値の構造や種類に応じて処理を分岐し、同時に値の構成要素を取り出す構文である。

プロトタイプベース

クラスを使わず、既存のオブジェクト（プロトタイプ）から性質を受け継いで新しいオブジェクトを作るオブジェクト指向の方式である。JavaScript が採用している。

ミックスイン

クラスの継承関係とは別に、複数のクラスで共有したいメソッドの集まりを取り込む仕組みである。Ruby のモジュールが代表例である。

未定義動作

言語仕様が動作を定めていない操作である。C や C++ では、配列の範囲外アクセスなどが該当し、プログラムがどのように振る舞うかは保証されない。

名目的部分型

型の名前と、継承やインタフェースの実装の宣言によって、型の互換性を判定する方式である。Java や C# で採用されている。

メタプログラミング

プログラムが、プログラム自身の構造（クラスやメソッドなど）を生成したり変更したりする技法である。
