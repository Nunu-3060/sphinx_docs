舞台芸術を鑑賞する
==================

舞台芸術は、俳優や歌手、ダンサーが観客の前で演じる芸術である。同じ演目でも公演ごとに演技が少しずつ異なり、観客の反応が舞台に影響を与えることもある。本章では、主な舞台芸術の種類と、初めて観劇するときの選び方を紹介する。

主な舞台芸術
------------

演劇
   俳優がせりふと動作で物語を演じる。大劇場での商業演劇から、小劇場での実験的な作品まで幅広い。古典の名作を上演するものもあれば、現代の社会を題材にした新作もある。

ミュージカル
   歌とダンスとせりふで物語を進める。音楽が親しみやすく、物語も分かりやすいものが多いため、初めての観劇に向いている。海外の作品を日本語で上演するもののほか、日本で生まれた作品もある。

オペラ
   物語のほぼすべてを歌で表現する総合芸術である。歌手の歌唱と、オーケストラの演奏、舞台美術、衣装を一度に楽しめる。原語（イタリア語、ドイツ語など）で歌われることが多いが、日本での公演では舞台の横や上に日本語の字幕が表示されることが多い。

バレエ・ダンス
   せりふを使わず、踊りと音楽で物語や感情を表現する。古典バレエでは「白鳥の湖」「くるみ割り人形」などがよく知られる。決まった形式にとらわれないコンテンポラリーダンスもある。

伝統芸能
--------

日本には、長い歴史を持つ舞台芸術が今も受け継がれている。能楽（能と狂言）、人形浄瑠璃文楽、歌舞伎は、ユネスコの無形文化遺産にも登録されている。

能・狂言
   能は、主役（シテ）が面（おもて）を付けて、謡（うたい）と囃子（はやし）に合わせて舞う歌舞劇である。動きは少なく、象徴的な表現で物語を伝える。狂言は、日常の出来事を題材にしたせりふ劇で、笑いを誘う内容が多い。能と狂言は同じ舞台で交互に上演されることが多い。

文楽
   太夫（たゆう）の語りと三味線の演奏に合わせて、人形を操って物語を演じる。主な人形は 3 人で 1 体を操り、人形とは思えない細やかな表情や仕草を見せる。

歌舞伎
   江戸時代に庶民の娯楽として発展した演劇である。華やかな衣装と化粧、見得（みえ）と呼ばれる決めの姿勢、舞台装置の仕掛けなどが見どころである。

落語
   演者が一人で座布団に座り、扇子と手ぬぐいだけを使って、複数の人物を演じ分けながら話を進める話芸である。寄席（よせ）と呼ばれる演芸場では、落語のほか、漫才や手品、曲芸などの演芸も楽しめる。

伝統芸能は難しそうに思えるが、初心者向けの工夫が多い。あらすじや見どころを解説する「鑑賞教室」の公演や、上演中に解説を聞けるイヤホンガイド、字幕表示を用意している劇場もある。歌舞伎座には、一つの幕だけを安く観られる一幕見席もある。

初めての観劇の選び方
--------------------

* 知っている物語や、映画化された作品を選ぶと、内容を追いやすい。
* 上演時間を確認する。休憩を含めて 3 時間前後の公演も多く、移動を含めると半日がかりになる。
* あらすじを事前に読んでおくと、言葉が聞き取りにくい場面でも楽しめる。特にオペラや伝統芸能では効果が大きい。
* 地域の劇場やホールの公演、地域の劇団の公演は、料金が手ごろで、気軽に足を運びやすい。

チケットの取り方
----------------

チケットは、劇場や公演団体の Web サイト、チケット販売サイト、プレイガイドなどで購入する。人気の公演では、発売日にすぐ売り切れたり、抽選販売になったりすることがある。劇場や公演団体の会員になると、一般の発売より先に購入できることが多い。

席の位置によって料金が異なり、一般に舞台に近い席や中央の席ほど高い。後方の席や上の階の席でも舞台全体を見渡せるという利点があり、オペラグラス（観劇用の小型の双眼鏡）があると表情まで見られる。

観劇のマナー
------------

* 開演前に携帯電話の電源を切る。
* 上演中は話をしない。飲食は劇場の規則に従う。
* 帽子は脱ぎ、身を乗り出さない。後ろの席の人の視界を遮らないためである。
* 録音・撮影はしない。
* 拍手やかけ声は、作品や芸能の慣習に従う。たとえば、歌舞伎の「大向こう（おおむこう）」と呼ばれるかけ声は、慣れた観客が行うものであり、初心者は控えるのが無難である。

向いている人
------------

* 物語やドラマが好きな人
* 非日常の華やかな雰囲気を味わいたい人
* 日本の伝統文化に関心がある人
* 演劇やダンスを自分でもやってみたいと考えている人
