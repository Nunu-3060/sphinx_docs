はじめに
========================================

Rust は、Graydon Hoare 氏が2006年に個人プロジェクトとして開発を始め、2009年から Mozilla 社がスポンサーとなって開発が進められてきたシステムプログラミング言語です。2015年に安定版がリリースされて以降、パフォーマンス・信頼性・生産性を兼ね備えた言語として急速に普及し、開発者向け調査でも高く評価され続けています。本書では、Python を使いこなせるものの Rust やシステムプログラミングは未経験、という読者を対象に、Rust の基礎から実践的な使い方までを解説していきます。

Rust とは何か
----------------------------------------

Rust は C や C++ のような低レベルな制御(メモリレイアウトやポインタの扱い)を可能にしつつ、「所有権(ownership)」という独自の仕組みによって、ガベージコレクタなしでメモリ安全性を保証する言語です。主な特徴は次のとおりです。

- **パフォーマンス**: コンパイル時に最適化されたネイティブコードを生成するため、C/C++に匹敵する実行速度を発揮します。
- **メモリ安全性**: コンパイラが所有権と借用のルールを検査するため、null参照外れや二重解放、データ競合といったバグの多くをコンパイル時に検出できます。
- **並行処理安全性**: 「恐れることのない並行処理(fearless concurrency)」と呼ばれるように、コンパイラがスレッド間のデータ共有を検査してくれます。
- **WebAssembly**: Rust は WebAssembly (Wasm) へのコンパイルと非常に相性がよく、ブラウザ上で高速に動作するコードを書けます。
- **CLIツールやサーバー**: ``ripgrep`` や ``fd`` のような高速なコマンドラインツール、Webサーバーのバックエンドなど幅広い分野で採用されています。
- **組み込み・OS開発**: ガベージコレクタを持たないため、OSカーネルや組み込み機器のようなリソース制約の厳しい環境でも利用できます。

なぜ Rust を学ぶのか
----------------------------------------

Python は書きやすく生産性の高い言語ですが、実行速度や、大規模で長期運用されるソフトウェアにおける型の安全性という点では課題があります。Rust を学ぶことで、次のようなメリットが得られます。

- Python で書いた処理を高速化したいとき、Rust で拡張モジュールを書くという選択肢が持てる
- 「コンパイラに指摘されながら覚える」プロセスを通じて、メモリ管理や型システムへの理解が深まる
- WebAssemblyやCLIツール、組み込みなど、Python が不得手とする領域に手を広げられる

環境構築
----------------------------------------

Rust の開発環境は ``rustup`` というツールチェイン管理ツールを使ってセットアップします。``rustup`` は Python における ``pyenv`` のような役割を果たし、複数バージョンの Rust コンパイラの切り替えを容易にします。

- **Windows**: ``https://rustup.rs/`` からインストーラをダウンロードして実行するか、後述のコマンドを利用します。
- **macOS / Linux**: ターミナルで次のコマンドを実行します。

.. code-block:: bash

   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

インストールが完了したら、ターミナル(またはコマンドプロンプト)を開き直し、以下のコマンドでバージョンを確認します。

.. code-block:: bash

   rustc --version
   cargo --version

``rustc`` は Rust のコンパイラ本体、``cargo`` はビルドやパッケージ管理を担うツールです。両方のコマンドがバージョン番号を表示すれば、インストールは成功です。

なお、本書の ``Cargo.toml`` の例には ``edition = "2024"`` のような記述が登場します。エディション(edition)とは、既存のコードを壊すことなく、クレート単位で選択的に後方互換性のない言語仕様の変更を取り込めるようにする Rust の仕組みです。

エディタの設定
----------------------------------------

Rust を快適に書くには、エディタに ``rust-analyzer`` という公式の言語サーバーを組み込むことを強くおすすめします。``rust-analyzer`` は入力中のコード補完、型情報の表示、エラー・警告のリアルタイム表示、定義へのジャンプなどを提供してくれます。

- **VSCode**: 拡張機能マーケットプレイスから ``rust-analyzer`` 拡張機能をインストールするだけで使えるようになります。最も手軽な組み合わせです。
- **JetBrains系(RustRover など)**: Rust サポートが標準または拡張機能として提供されており、同様に ``rust-analyzer`` ベースの補完が利用できます。

本書のサンプルコードを実際に手元で試す際は、こうしたエディタ環境を用意しておくと、コンパイルエラーの内容をその場で確認しながら学習を進められます。

.. admonition:: Python 経験者向けメモ
   :class: tip

   Python は ``python script.py`` のようにソースコードをその場でインタプリタに渡して実行できますが、Rust はあらかじめ ``rustc`` (または ``cargo``)でソースコードを機械語にコンパイルし、生成された実行可能ファイルを実行するという手順を踏みます。そのため「ソースを書いて即実行」という感覚ではなく、「書く→コンパイルする→実行する」というサイクルに慣れる必要があります。最初は手間に感じるかもしれませんが、コンパイラが多くのバグを事前に検出してくれるため、実行時エラーに悩まされる場面は Python よりも少なくなります。

まとめ
----------------------------------------

- Rust はメモリ安全性と高いパフォーマンスを両立するシステムプログラミング言語です
- ガベージコレクタなしで安全性を保証する「所有権」という仕組みが最大の特徴です
- パフォーマンスが求められる処理、CLIツール、WebAssembly、組み込みなど幅広い場面で活用されています
- 環境構築には ``rustup`` を使い、``rustc --version`` / ``cargo --version`` で導入を確認します
- エディタには ``rust-analyzer`` を組み込むと、補完やエラー表示が快適になります
- Rust はコンパイル言語であり、Python のような即時実行はできません
