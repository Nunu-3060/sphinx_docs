関数
========================================

関数はプログラムをまとまった単位に分割するための基本的な仕組みです。Rust の関数は Python の関数と似た見た目をしていますが、型に関するルールがより厳格です。

関数の定義
----------------------------------------

Rust では ``fn`` キーワードを使って関数を定義します。関数名は慣習的にスネークケース(``snake_case``)で書きます。なお、以下の例に登場する ``&str`` については、後の「借用と参照」の章で詳しく説明します。

.. code-block:: rust

   fn main() {
       greet("Alice");
       let sum = add(3, 5);
       println!("合計: {}", sum);
   }

   fn greet(name: &str) {
       println!("こんにちは、{}さん!", name);
   }

   fn add(a: i32, b: i32) -> i32 {
       a + b
   }

``fn`` の後に関数名、続けて丸括弧の中に引数リスト、必要であれば矢印 ``->`` の後に戻り値の型を書きます。Rust では関数は呼び出される前に定義されていなくても構いません(``main`` から呼び出す ``greet`` や ``add`` は ``main`` より下に定義されています)。これに対し Python ではトップレベルのコードが上から順に実行されるため、``def`` より前でその関数を呼び出そうとすると ``NameError`` になります。

型注釈の必須化
----------------------------------------

Rust の関数では、引数の型注釈は必須です。また戻り値がある場合は ``-> 型`` という形で戻り値の型を明示しなければなりません。

.. code-block:: rust

   fn multiply(x: i32, y: i32) -> i32 {
       x * y
   }

もし型注釈を省略すると、コンパイラは「型を推論できません」というエラーを出して教えてくれます。関数の引数や戻り値の型は、関数を呼び出す側にとって重要な「契約」であるため、Rust では省略を許さない設計になっています。

文と式、戻り値
----------------------------------------

Rust のコードは「文(statement)」と「式(expression)」に分けられます。文は何らかの処理を行いますが値を返さず、式は評価されて値になります。この違いを理解するうえで重要なポイントの1つが、セミコロン ``;`` の有無です。

.. code-block:: rust

   fn square(x: i32) -> i32 {
       let result = x * x; // これは文(let文)
       result             // これは式であり、そのまま戻り値になる
   }

関数の本体の最後に、セミコロンを付けずに式だけを書くと、その式の評価結果がそのまま関数の戻り値になります。これにより ``return`` キーワードを省略できます。もちろん、途中で早期リターンしたい場合には明示的に ``return`` を使うこともできます。

.. code-block:: rust

   fn absolute_value(x: i32) -> i32 {
       if x < 0 {
           return -x;
       }
       x
   }

注意点として、最終式の末尾にうっかりセミコロンを付けてしまうと、それは式ではなく文として扱われ、戻り値が ``()`` (ユニット型、Python でいう ``None`` に近い空の値)になってしまいコンパイルエラーになります。

.. admonition:: Python 経験者向けメモ
   :class: tip

   Python では ``def add(a: int, b: int) -> int:`` のように型ヒントを書くことができますが、これはあくまで補助的な情報であり、書かなくても実行時エラーにはなりません(型チェッカーを使わない限り、実行時には無視されます)。一方 Rust では、引数と戻り値の型注釈は文法上必須であり、書かなければコンパイルが通りません。この違いは一見面倒に思えますが、関数のシグネチャを見るだけで「何を渡し、何が返ってくるか」が誰の目にも明らかになるという利点があります。また、Python の関数は最後まで実行しても明示的な ``return`` がなければ ``None`` を返しますが、Rust では関数本体の最後の式(セミコロンなし)がそのまま戻り値になるという設計になっています。さらに、Python のようなデフォルト引数・キーワード引数・可変長引数(``*args``/``**kwargs``)は Rust の関数には存在せず、引数は常に個数と型が固定された位置引数として渡す必要があります。

まとめ
----------------------------------------

- 関数は ``fn`` キーワードで定義し、慣習的にスネークケースの名前を付けます
- 引数の型注釈と、戻り値がある場合の ``-> 型`` は省略できません
- セミコロンのない式は値を返し、セミコロンを付けると文になり値を返しません
- 関数本体の最終式がそのまま戻り値になるため、多くの場合 ``return`` を省略できます
- 早期リターンしたい場合は明示的に ``return`` を使うこともできます
