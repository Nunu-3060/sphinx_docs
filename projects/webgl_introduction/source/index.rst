WebGL 入門
==========

本書は、Web ブラウザーで 3D グラフィックスを描画するための API である WebGL 2.0 を、ライブラリを使わずに基礎から学ぶための入門書です。三角形を 1 つ描くところから始め、座標変換、テクスチャ、ライティングを経て、マウスで操作できる 3D シーンを作るところまでを扱います。
