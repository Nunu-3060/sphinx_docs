日本茶のアレンジ
================

日本茶は、そのまま飲むだけでなく、牛乳と合わせたり、料理に使ったりすることもできます。本章では、家庭で手軽にできるアレンジを紹介します。

抹茶ラテ
--------

材料（1 杯分）
^^^^^^^^^^^^^^

* 抹茶：2 g
* お湯（80 ℃ 前後）：20 ml
* 牛乳：150 ml
* 砂糖：好みの量

作り方
^^^^^^

#. 抹茶を茶こしでふるいながらカップに入れます。好みで砂糖も入れます。
#. お湯を注ぎ、茶筅やスプーンでよく混ぜて、だまのないペースト状にします。
#. 温めた牛乳を注ぎ、よく混ぜます。

冷たい抹茶ラテにする場合は、手順 2 の後に、氷と冷たい牛乳を加えます。抹茶をお湯で溶いてから牛乳を加えることが、だまを作らないコツです。

ほうじ茶ラテ
------------

材料（1 杯分）
^^^^^^^^^^^^^^

* ほうじ茶：6 g（大さじ 2 杯）
* 熱湯：50 ml
* 牛乳：150 ml
* 砂糖：好みの量

作り方
^^^^^^

#. 小鍋に熱湯とほうじ茶を入れ、蓋をして 2 分ほど置き、濃いほうじ茶を作ります。
#. 牛乳を加えて弱火にかけ、沸騰直前まで温めます。
#. 茶こしでこしながらカップに注ぎます。好みで砂糖を加えます。

ほうじ茶の香ばしさと牛乳のまろやかさがよく合います。牛乳を加えると薄く感じやすいため、お茶を普段より濃く淹れることがポイントです。

お茶漬け
--------

お茶漬けは、ご飯に具を載せて、お茶を注いで食べる料理です。煎茶やほうじ茶、玄米茶など、普段飲んでいるお茶で作れます。

#. 茶碗にご飯を盛り、梅干し、焼き鮭のほぐし身、海苔、塩昆布などの具を載せます。
#. 熱めに淹れたお茶を、ご飯がひたる程度に注ぎます。
#. 好みでわさびやあられを添え、塩やしょうゆで味を調えます。

煎茶を使うとすっきりとした味に、ほうじ茶を使うと香ばしい味になります。

茶殻の活用
----------

日本茶の茶殻には、まだ多くの成分が残っています。2 煎、3 煎と楽しんだ後の茶殻も、捨てずに活用できます。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 活用方法
     - 内容
   * - おひたし・和え物
     - 煎茶や玉露の柔らかい茶殻に、しょうゆやポン酢をかけて食べます。かつお節を添えるのもおすすめです。
   * - ふりかけ・佃煮
     - 茶殻の水気をよく絞り、フライパンで炒って水分を飛ばし、かつお節、ごま、しょうゆなどで味付けします。
   * - 消臭
     - 茶殻をよく乾燥させ、お茶パックなどに入れて、靴箱や冷蔵庫に置きます。

食べる場合は、その日に出た茶殻を使い、作ったものは冷蔵庫で保存して早めに食べ切ります。乾燥が不十分な茶殻は、かびやすいため注意します。
