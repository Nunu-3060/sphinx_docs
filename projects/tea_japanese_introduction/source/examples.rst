便利なスクリプト
================

本付録では、日本茶を淹れるときに役立つ 2 つの Python スクリプトを紹介します。どちらも Python の標準機能だけで動くため、追加のインストールは不要です。

動かすための準備
----------------

スクリプトを動かすには、Python 3.10 以上が必要です。Python は、`Python の公式サイト <https://www.python.org/downloads/>`_\ からダウンロードしてインストールできます。

スクリプトは、次の手順で実行します。

#. 本ページのリンクからスクリプトをダウンロードします。
#. Windows では「コマンドプロンプト」、macOS では「ターミナル」を開きます。
#. ``cd`` コマンドで、スクリプトを保存したフォルダーに移動します。
#. ``python`` コマンドの後にスクリプトのファイル名を付けて実行します。

例えば、ダウンロードフォルダーに保存した場合は、次のように入力します。macOS では ``python`` の代わりに ``python3`` と入力してください。

.. code-block:: text
   :linenos:

   cd Downloads
   python brewing_guide.py

淹れ方の目安の表示（brewing_guide.py）
--------------------------------------

お茶の種類と人数を指定すると、茶葉の量、お湯の量、湯温、浸出時間の目安を表示します。計算には、「:doc:`brewing`」で紹介した式と目安、および「:doc:`matcha`」で紹介した薄茶の目安を使っています。

ダウンロード：:download:`brewing_guide.py <../examples/brewing_guide.py>`

使い方
^^^^^^

引数を付けずに実行すると、お茶の種類と人数を順に尋ねられます。

.. code-block:: text
   :linenos:

   python brewing_guide.py

お茶の種類と人数を続けて指定すると、すぐに結果が表示されます。人数は 1〜10 の範囲で指定します。お茶の種類には、次のいずれかを指定します。

* ``sencha``：上級煎茶
* ``futsu``：普通煎茶・深蒸し煎茶
* ``gyokuro``：玉露
* ``bancha``：番茶・ほうじ茶・玄米茶
* ``matcha``：抹茶（薄茶）

例えば、上級煎茶を 3 人分淹れる場合は、次のように実行します。

.. code-block:: text
   :linenos:

   python brewing_guide.py sencha 3

実行すると、次のように表示されます。

.. code-block:: text
   :linenos:

   上級煎茶 3 人分の目安
     茶葉の量  : 6.0 g（茶さじ約 3.0 杯）
     お湯の量  : 180 ml
     湯温      : 70 ℃
     浸出時間  : 1〜2 分

茶葉を量る道具は、お茶の種類によって変わります。煎茶と玉露は茶さじ（1 杯約 2 g）、番茶・ほうじ茶・玄米茶は大さじ（1 杯約 3 g）、抹茶は茶杓（1 杯約 1 g）で換算しています。

浸出時間のタイマー（tea_timer.py）
----------------------------------

お茶の種類と何煎目かを指定すると、湯温の目安を表示してから浸出時間をカウントダウンし、時間になったら音とメッセージで知らせます。タイマーで計る時間は、「:doc:`brewing`」で紹介した浸出時間の目安の中間の値です。

ダウンロード：:download:`tea_timer.py <../examples/tea_timer.py>`

使い方
^^^^^^

お茶の種類には、次のいずれかを指定します。指定しない場合は、実行後に番号で選びます。

.. list-table::
   :header-rows: 1
   :widths: 16 30 18 18 18

   * - 指定する名前
     - お茶の種類
     - 1 煎目
     - 2 煎目
     - 3 煎目
   * - ``sencha``
     - 上級煎茶
     - 70 ℃、1 分 30 秒
     - 80 ℃、10 秒
     - 90 ℃、30 秒
   * - ``futsu``
     - 普通煎茶・深蒸し煎茶
     - 80〜90 ℃、45 秒
     - 90 ℃、10 秒
     - 熱湯、30 秒
   * - ``gyokuro``
     - 玉露
     - 50〜60 ℃、2 分 15 秒
     - 60 ℃、30 秒
     - 70 ℃、1 分
   * - ``bancha``
     - 番茶・ほうじ茶・玄米茶
     - 熱湯、30 秒
     - 熱湯、15 秒
     - なし

何煎目かは ``--brew`` の後に指定します。省略すると 1 煎目になります。例えば、上級煎茶の 2 煎目を計る場合は、次のように実行します。

.. code-block:: text
   :linenos:

   python tea_timer.py sencha --brew 2

好みの時間で計りたい場合は、``--seconds`` の後に秒数を指定します。次の例では、50 秒を計ります。

.. code-block:: text
   :linenos:

   python tea_timer.py --seconds 50

実行すると、残り時間が 1 秒ごとに更新され、時間になると次のように表示されます。途中でやめたい場合は、:kbd:`Ctrl+C` を押します。

.. code-block:: text
   :linenos:

   上級煎茶の 2 煎目: 湯温は 80 ℃が目安です。
   0 分 10 秒を計ります。Ctrl+C で中止できます。
   残り 0 分 00 秒
   時間になりました。最後の一滴まで注ぎ切りましょう。
