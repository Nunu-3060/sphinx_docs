用語集
======

本書に登場する主な用語をまとめます。数字と英字で始まる用語を先にアルファベット順に、その後に日本語の用語を五十音順に並べています。

.. glossary::

   2 の補数
      最上位ビットの重みを :math:`-2^{n-1}` とする、符号付き整数の表現です。加算回路を符号なし整数と共用できます。

   ABI
      Application Binary Interface の略です。呼び出し規約、データ型の大きさとアラインメント、実行ファイルの形式などを含む、機械語のレベルでのソフトウェア間のインターフェースです。

   ALU
      Arithmetic Logic Unit（算術論理演算装置）の略です。加減算、論理演算、比較などを行う組合せ回路です。

   ASID
      Address Space Identifier の略です。TLB のエントリにアドレス空間の識別子を付けることで、プロセスを切り替えるたびに TLB を消去しなくて済むようにする仕組みです。

   BF16
      指数部 8 ビット、仮数部 7 ビットの 16 ビット浮動小数点数の形式です。単精度と同じ範囲の値を表せるため、深層学習で使われます。

   CISC
      Complex Instruction Set Computer の略です。可変長で、メモリオペランドを取れる複雑な命令を多数持つ ISA の設計思想、またはそのような ISA の総称です。

   CPI
      Cycles Per Instruction の略です。1 命令あたりの平均クロックサイクル数です。逆数を IPC（Instructions Per Cycle）と呼びます。

   CUDA
      NVIDIA が 2007 年に公開した、GPU で汎用の計算を行うためのプログラミング環境です。

   CXL
      Compute Express Link の略です。PCI Express の物理層を使い、CPU、アクセラレーター、メモリをキャッシュコヒーレントに接続する規格です。

   DMA
      Direct Memory Access の略です。プロセッサを介さずに、デバイスと主記憶の間で直接データを転送する方式です。

   DRAM
      Dynamic Random Access Memory の略です。1 ビットを 1 つのトランジスタと 1 つのコンデンサで記憶するメモリです。集積度が高く安価ですが、定期的なリフレッシュが必要で、SRAM より遅いため主記憶に使われます。

   DVFS
      Dynamic Voltage and Frequency Scaling の略です。負荷に応じて動作周波数と電源電圧を動的に変え、消費電力を抑える技術です。

   ECC
      Error Correcting Code（誤り訂正符号）の略です。データに冗長な検査ビットを加えて、誤りを検出・訂正できるようにする符号です。メモリでは SECDED 符号が広く使われます。

   false sharing
      偽共有とも呼びます。別々のコアが使う別々の変数が同じキャッシュラインに載っているために、コア間でラインの無効化が繰り返され、性能が落ちる現象です。

   FPGA
      Field-Programmable Gate Array の略です。LUT と配線の設定を書き換えることで、製造後に回路を再構成できる集積回路です。

   gshare
      分岐命令のアドレスと大域分岐履歴の排他的論理和で、2 ビット飽和カウンタの表を引く分岐予測器です。

   HBM
      High Bandwidth Memory の略です。DRAM のダイを TSV（シリコン貫通電極）で積層し、プロセッサと同じパッケージ内で非常に広いデータ幅で接続した、広帯域のメモリです。

   IEEE 754
      浮動小数点数の表現と演算を定めた標準規格です。符号、バイアス付きの指数部、暗黙の 1 を省いた仮数部で数を表します。

   ISA
      Instruction Set Architecture（命令セットアーキテクチャ）の略です。プロセッサが実行できる命令、レジスタ、データの表現、メモリモデル、例外などを定めた、ソフトウェアとハードウェアの間の約束事です。

   LL/SC
      Load-Linked と Store-Conditional の組です。読み出したアドレスを予約し、その後ほかのコアが書き込んでいなければ条件付きストアが成功する、アトミック操作の実現方式です。RISC-V では lr 命令と sc 命令が該当します。

   Meltdown
      2018 年に公表された、権限の検査が確定する前に後続の命令が読み出した値を使ってしまう実装上の問題を突き、ユーザーモードからカーネルのメモリの内容を読み出す攻撃です。KPTI などで対策されます。

   MESI プロトコル
      キャッシュラインに Modified、Exclusive、Shared、Invalid の 4 つの状態を持たせる、無効化型のキャッシュコヒーレンスプロトコルです。

   NaN
      Not a Number の略です。0 を 0 で割るなど、値を定義できない演算の結果を表す IEEE 754 の特殊な値です。自分自身とも等しくありません。

   NPU
      Neural Processing Unit の略です。ニューラルネットワークの推論を低電力で行うために SoC に搭載されるアクセラレーターです。

   NUMA
      Non-Uniform Memory Access の略です。コアとメモリの位置関係によって、主記憶へのアクセス時間が異なる共有メモリの構成です。

   NVMe
      PCI Express に接続するフラッシュストレージ向けのインターフェース規格です。多数の深いキューを持ち、並列なアクセスを効率よく処理できます。

   NX ビット
      ページテーブルエントリに置く実行禁止のビットです（No-eXecute。Intel は XD ビットと呼びます）。書き込めるページを実行させない W^X の方針を実現できます。

   PCI Express
      レーンを束ねて帯域を増やす、Point-to-Point の高速シリアル接続のインターコネクトです。GPU や SSD などの接続に使われます。

   RISC
      Reduced Instruction Set Computer の略です。単純な固定長の命令とロード／ストアアーキテクチャによって、パイプラインで高速に実行することをめざす ISA の設計思想です。

   RISC-V
      2010 年にカリフォルニア大学バークレー校で開発が始まった、オープンでロイヤリティフリーの RISC 型 ISA です。基本命令セットに M、A、F、D、C、V などの拡張を組み合わせて使います。

   Rowhammer
      DRAM のある行を短時間に繰り返し活性化すると、隣接する行のビットが反転する現象です。2014 年に報告されました。

   SECDED
      Single Error Correction, Double Error Detection の略です。ハミング符号に全体パリティを加え、1 ビットの誤りを訂正し 2 ビットの誤りを検出する符号です。メモリでは 64 ビットのデータに 8 ビットの検査ビットを加えた (72,64) 符号が使われます。

   SIMD
      Single Instruction, Multiple Data の略です。1 つの命令で複数のデータに同じ演算を行う方式です。

   SIMT
      Single Instruction, Multiple Threads の略です。GPU の実行方式で、ワープ内の多数のスレッドが同じ命令を同時に実行します。各スレッドは独自のレジスタを持ち、分岐はマスクによって扱われます。

   SMT
      Simultaneous Multithreading（同時マルチスレッディング）の略です。1 つのコアで複数のスレッドの命令を同時に発行・実行する技術です。Intel はハイパースレッディングと呼んでいます。

   SoC
      System on a Chip の略です。CPU、GPU、NPU、メモリコントローラ、入出力回路などを 1 つのチップに集積したものです。

   Spectre
      2018 年に公表された、分岐予測を誤らせて被害者のプログラムに本来通らない経路を投機的に実行させ、その痕跡をキャッシュのタイミングから読み取る攻撃です。

   SRAM
      Static Random Access Memory の略です。交差接続したインバータからなるラッチ回路（1 ビットあたり 6 トランジスタが一般的）で 1 ビットを記憶するメモリです。高速ですが面積が大きいため、キャッシュなどに使われます。

   TEE
      Trusted Execution Environment（信頼できる実行環境）の略です。CPU が作る保護された実行環境で、OS やハイパーバイザーからもその中のコードとデータを読み書きできないようにします。Intel の SGX や TDX、AMD の SEV、Arm の TrustZone や CCA などがあります。

   TLB
      Translation Lookaside Buffer の略です。最近使ったアドレス変換の結果を保持する、アドレス変換専用のキャッシュです。

   TPU
      Tensor Processing Unit の略です。Google が深層学習のために開発した、シストリックアレイを中心とするドメイン特化型アーキテクチャです。

   TSO
      Total Store Order の略です。ストアとその後のロードの順序の入れ替わりだけを許すメモリ一貫性モデルです。x86 が採用しています。

   VLIW
      Very Long Instruction Word の略です。並列に実行できる複数の操作をコンパイラが 1 つの長い命令語にまとめる方式です。

   アウトオブオーダー実行
      プログラムの順序ではなく、オペランドがそろった命令から実行する方式です。結果はリオーダーバッファによってプログラムの順にコミットされます。

   アムダールの法則
      全体の実行時間のうち割合 :math:`f` の部分を :math:`s` 倍速くしたときの全体の速度向上率が :math:`1 / ((1 - f) + f / s)` になるという法則です。改良しない部分が速度向上の上限を決めます。

   アラインメント
      :math:`k` バイトのデータを :math:`k` の倍数のアドレスに配置することです。

   演算強度
      メモリとの間で転送する 1 バイトあたりの演算回数（FLOP/バイト）です。ルーフラインモデルで使います。

   拡張（RISC-V）
      RISC-V の基本命令セットに追加する命令群です。乗除算の M、アトミック命令の A、浮動小数点数の F と D、圧縮命令の C、ベクトル命令の V などがあります。

   仮想記憶
      プログラムが使う仮想アドレスを物理アドレスに変換することで、プロセスごとに独立したアドレス空間とメモリの保護を提供する仕組みです。

   キャッシュ
      プロセッサと主記憶の間に置く、小容量で高速なメモリです。最近使ったデータとその近くのデータを保持し、メモリアクセスの平均時間を短くします。

   キャッシュコヒーレンス
      各コアがそれぞれキャッシュを持っていても、1 つのアドレスに対してはすべてのコアが矛盾のない値を読めることを保証する性質です。

   キャッシュライン
      キャッシュの中でブロックを格納する場所、またはキャッシュと下位の階層の間でやり取りする固定長のデータの単位（ブロック）です。64 バイトが一般的です。

   局所性
      最近アクセスしたデータ（時間的局所性）や、その近くのデータ（空間的局所性）に再びアクセスしやすいというプログラムの性質です。キャッシュはこの性質を利用しています。

   組合せ回路
      出力がその時点の入力だけで決まる論理回路です。

   クリティカルパス
      レジスタからレジスタまでの組合せ回路の経路のうち、最も遅いものです。最大クロック周波数を決めます。

   サイドチャネル攻撃
      処理時間、消費電力、電磁波などの副次的な情報から秘密を推測する攻撃です。キャッシュのヒットとミスの時間差を利用するキャッシュタイミング攻撃が代表例です。

   シストリックアレイ
      単純な演算要素を格子状に並べ、データを隣の要素へ規則正しく送りながら計算する構成です。行列積の計算に適しています。

   順序回路
      内部状態を持ち、出力が入力と内部状態で決まる論理回路です。

   スーパースカラ
      1 サイクルに複数の命令を発行して実行するプロセッサの方式です。

   ストール
      ハザードを避けるために、パイプラインの進行を止めることです。

   スループット
      単位時間あたりに完了する処理の量です。

   正確な例外
      例外を起こした命令より前の命令はすべて完了し、それ以降の命令は何も実行されていない状態で例外処理に入ることです。

   セットアソシアティブ
      アドレスのインデックス部で選んだセットの中の、複数のライン（ウェイ）のどれにでもブロックを置けるキャッシュの構成です。

   ダークシリコン
      電力と発熱の制約のために、チップ上のすべてのトランジスタを同時に全速力で動かせず、一部を止めておかざるをえない状態、またはその止めている部分です。

   チップレット
      1 つの大きなチップの機能を分割して作った小さなダイです。複数のチップレットを 1 つのパッケージ内で接続して製品を構成します。

   データパス
      プロセッサの中でデータが流れて処理される部分です。プログラムカウンタ、レジスタファイル、ALU、メモリなどからなります。

   デナード・スケーリング
      トランジスタの寸法と電圧を同じ比率で縮小すれば、単位面積あたりの電力を一定に保ったまま高速化できるという関係です。2000 年代半ばに成り立たなくなりました。

   電力の壁
      電源電圧を下げられなくなったために、クロック周波数やトランジスタ数を増やすと消費電力と発熱が増え、冷却の限界が性能を制約するようになったことです。

   投機実行
      分岐予測などに基づいて結果が確定する前に先の命令を実行し、予測が誤っていたら結果を取り消す技術です。

   特権モード
      CPU が現在どの程度の権限で命令を実行しているかを表す状態です。RISC-V の M・S・U モード、x86-64 のリング、AArch64 の例外レベル（EL）がこれにあたります。

   ドメイン特化型アーキテクチャ
      Domain-Specific Architecture（DSA）とも呼びます。特定の分野の計算に合わせて設計し、汎用性と引き換えに高い性能と電力効率を得るアーキテクチャです。

   ハーバード型
      命令とデータを別々のメモリに置き、別々の経路で読み出す構成です。

   パイプライン
      命令の処理を複数の段に分け、複数の命令を 1 段ずつずらして同時に処理する手法です。

   ハザード
      次の命令を予定どおりのサイクルで実行できなくなる状況です。構造ハザード、データハザード、制御ハザードの 3 種類があります。

   ハミング符号
      複数のパリティビットを組み合わせ、シンドロームから誤りの位置を特定して 1 ビットの誤りを訂正できる符号です。1950 年にハミングが発表しました。

   バンクコンフリクト
      GPU の共有メモリで、複数のスレッドが同じバンクの異なるワードにアクセスし、アクセスが順番に処理されることです。

   フォワーディング
      演算結果をレジスタファイルに書き戻す前に、パイプラインレジスタから後続の命令の演算器の入力へ直接送ることで、データハザードによるストールを減らす技術です。

   分岐ダイバージェンス
      GPU のワープ内で分岐の条件がスレッドごとに分かれ、両方の経路をマスク付きで順に実行することです。

   分岐予測
      分岐命令の結果が確定する前に、その方向と分岐先を予測する仕組みです。

   ページテーブル
      仮想ページ番号から物理ページ番号への対応と、保護の情報を記録する表です。

   ページフォールト
      アクセスしたページが主記憶にない場合や、許されないアクセスを行った場合に発生し、OS が処理する例外です。

   マイクロアーキテクチャ
      ISA を実現するプロセッサ内部の具体的な構成です。パイプラインの段数、キャッシュの構成、分岐予測器などが含まれます。

   マイクロオペレーション
      μop とも書きます。x86 などのプロセッサが、複雑な命令を分解して内部で実行する単純な操作です。

   マイクロプログラム制御
      制御信号の列をマイクロ命令として制御記憶に格納し、それを読み出してプロセッサを制御する方式です。1951 年にウィルクスが提案しました。

   ムーアの法則
      集積回路に載るトランジスタの数が、約 2 年ごとに倍増するという経験則です。

   メモリアクセスの合体
      コアレッシングとも呼びます。GPU のワープ内のスレッドのメモリアクセスを、できるだけ少ない数のメモリトランザクションにまとめることです。

   メモリ一貫性モデル
      異なるアドレスへのメモリ操作が、ほかのコアからどのような順序で見えるかを定める規則です。

   メモリウォール
      プロセッサの速度向上に主記憶（DRAM）のレイテンシの改善が追いつかず、両者の速度差が性能向上の壁になることです。

   メモリバリア
      フェンスとも呼びます。その前後のメモリ操作の順序を強制する命令です。

   メモリマップト I/O
      物理アドレス空間の一部をデバイスのレジスタに割り当て、通常のロード命令とストア命令でデバイスを操作する方式です。

   リオーダーバッファ
      ROB（Reorder Buffer）とも呼びます。発行した命令をプログラムの順に保持し、アウトオブオーダーに実行した結果をプログラムの順にコミットするための循環バッファです。

   ルーフラインモデル
      到達可能な性能を、ピーク演算性能と「メモリ帯域 × 演算強度」の小さいほうで見積もるモデルです。

   レイテンシ
      1 つの処理を始めてから終わるまでにかかる時間です。

   レジスタリネーミング
      プログラム中の論理レジスタを物理レジスタに割り当て直すことで、WAR と WAW の依存を取り除く技術です。

   ロード／ストアアーキテクチャ
      メモリにアクセスできる命令をロード命令とストア命令だけに限り、演算はレジスタの間だけで行う ISA の方式です。

   ワープ
      NVIDIA の GPU で、同じ命令を同時に実行する 32 スレッドのまとまりです。AMD の GPU ではウェーブフロントと呼びます。

   割り込み
      タイマーや入出力装置など、実行中の命令とは無関係な外部の事象をプロセッサに知らせ、実行中の処理を中断してハンドラを実行させる仕組みです。
