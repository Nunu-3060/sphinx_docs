はじめに
========

この章では、本書の目的と対象読者、前提とする知識、全体の構成を説明します。また、サンプルコードの使い方と、本書で使う表記の決まりをまとめます。本文を読み始める前に一度目を通しておくと、後の章が読みやすくなります。

本書の目的
----------

私たちが書いたプログラムは、最終的にはプロセッサが実行する機械語の命令の列になります。その命令がどのような仕組みで実行され、なぜある書き方は速く、別の書き方は遅いのかを理解するための学問が\ **コンピューターアーキテクチャ**\ （Computer Architecture）です。

本書の目的は、エンジニアが日々の仕事で出会う「性能」「並行性」「セキュリティ」といった問題の背景にあるハードウェアの仕組みを、正確かつ具体的に理解できるようにすることです。本書を読み終えると、次のことができるようになります。

* 命令セットアーキテクチャ（ISA）が何を定めているかを説明でき、簡単な RISC-V の機械語を読めます。
* パイプライン、分岐予測、アウトオブオーダー実行といったプロセッサの高速化技術の考え方を説明できます。
* キャッシュや仮想記憶の仕組みを理解し、メモリアクセスのパターンが性能に与える影響を見積もれます。
* マルチコアや GPU、アクセラレーターの特徴を理解し、処理に適したハードウェアを選べます。
* 性能を式と数値で議論できます（実行時間の式、アムダールの法則、ルーフラインモデルなど）。

本書は回路設計者を育てるための教科書ではありません。プロセッサを自分で設計する読者よりも、プロセッサの上で動くソフトウェアを書く読者を想定し、「ソフトウェアから見てどう効くか」を重視して説明します。一方で、仕組みを曖昧なまま済ませることはせず、式や数値例を使って定量的に説明します。

対象読者と前提知識
------------------

本書は、次のような読者を対象としています。

* 何らかのプログラミング言語でプログラムを書いた経験があるエンジニアや学生。
* プログラムの性能チューニングや、並行プログラミング、組み込み開発などでハードウェアの知識が必要になった人。
* 情報系の授業でコンピューターアーキテクチャを学ぶ前後に、全体像をつかみたい人。

前提知識として、次のことを大まかに知っていることを想定しています。

* 2 進数と 16 進数の読み方。
* CPU がプログラムを実行し、メモリがデータを記憶するという役割分担。
* C 言語や Python のような言語での変数、配列、関数、ループ。

論理回路の知識は前提としません。必要な範囲は「:doc:`08_digital_logic`」で復習します。オペレーティングシステム（OS）は、仮想記憶や入出力など、ハードウェアとの境界に関わる部分だけを扱います。OS そのものの詳しい仕組みは本書の範囲外です。

サンプルコードの使い方
----------------------

本書には、本文の内容を数値で確かめるための Python のサンプルコードが付いています。サンプルコードは付録「:doc:`appendix_examples`」からダウンロードできます。

* Python 3.10 以降で動作します。
* 標準ライブラリだけを使っています。追加のパッケージをインストールする必要はありません。
* どのサンプルも引数なしで実行でき、結果を標準出力に表示します。

たとえば「:doc:`04_performance`」のサンプルは、次のように実行します。

.. code-block:: text
   :linenos:

   python performance_calc.py

本文には、サンプルの全文を行番号付きで掲載し、要点を行番号で示して解説します。実行結果も実際の出力をそのまま掲載しています。ただし、実行時間の測定値のように環境によって変わる値は「実行例」と明記しています。

.. note::

   Windows の一部の環境では、日本語の出力が文字化けすることがあります。その場合は、環境変数 ``PYTHONIOENCODING`` に ``utf-8`` を設定するか、``python -X utf8 performance_calc.py`` のように実行してください。

表記の決まり
------------

例に使う命令セットアーキテクチャ
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

本書では、例に使う ISA として主に **RISC-V** の 32 ビット整数の基本命令セット **RV32I** を使います。RISC-V は仕様が公開されていて誰でも自由に使え、命令の種類が少なく規則的なので、学習に適しているからです。比較のために、パソコンやサーバーで広く使われている **x86-64** と、スマートフォンや Apple シリコンなどで使われている **AArch64**\ （Arm の 64 ビットアーキテクチャ）も適宜紹介します。RV32I の命令の一覧は付録「:doc:`appendix_riscv`」にあります。

RISC-V のアセンブリ言語は次のように書きます。命令名の後に、結果を格納するレジスタ、入力のレジスタの順にオペランドを並べます。

.. code-block:: text
   :linenos:

   add  x5, x6, x7     # x5 = x6 + x7
   lw   x10, 8(x2)     # x10 = メモリの (x2 + 8) 番地から読んだ 32 ビット

数値の表記
^^^^^^^^^^

数値は、特に断りのない限り 10 進数で書きます。16 進数と 2 進数は、C 言語や Python と同じく接頭辞を付けて区別します。

.. list-table:: 数値の表記
   :header-rows: 1
   :widths: 20 30 50

   * - 基数
     - 表記の例
     - 説明
   * - 10 進数
     - 255
     - 接頭辞を付けません。
   * - 16 進数
     - 0xFF
     - 接頭辞 ``0x`` を付けます。A〜F は大文字で書きます（Python の出力をそのまま示す場合を除く）。
   * - 2 進数
     - 0b1111_1111
     - 接頭辞 ``0b`` を付けます。長い場合は 4 桁ごとに ``_`` で区切ることがあります。

ビットの番号は、最下位ビット（Least Significant Bit：LSB）を 0 番とし、上位に向かって 1、2、…と数えます。たとえば 32 ビットの値のビット 31 は最上位ビット（Most Significant Bit：MSB）です。

単位の接頭辞
^^^^^^^^^^^^

コンピューターの世界では、k（キロ）、M（メガ）、G（ギガ）といった接頭辞が、10 の累乗の意味でも 2 の累乗の意味でも使われてきたため、混乱が起きがちです。本書では、IEC（国際電気標準会議）が定めた 2 進接頭辞を使って両者を区別します。

.. list-table:: 10 進接頭辞と 2 進接頭辞
   :header-rows: 1
   :widths: 20 25 20 35

   * - 10 進接頭辞
     - 値
     - 2 進接頭辞
     - 値
   * - k（キロ）
     - :math:`10^3 = 1{,}000`
     - Ki（キビ）
     - :math:`2^{10} = 1{,}024`
   * - M（メガ）
     - :math:`10^6`
     - Mi（メビ）
     - :math:`2^{20} = 1{,}048{,}576`
   * - G（ギガ）
     - :math:`10^9`
     - Gi（ギビ）
     - :math:`2^{30} \approx 1.074 \times 10^9`
   * - T（テラ）
     - :math:`10^{12}`
     - Ti（テビ）
     - :math:`2^{40} \approx 1.100 \times 10^{12}`

本書での使い分けは次のとおりです。

* メモリやキャッシュの容量、アドレス空間の大きさのように、本来 2 の累乗で決まる量には 2 進接頭辞を使います（例: 32 KiB の L1 キャッシュ、4 KiB のページ）。
* クロック周波数（GHz）、転送速度（GB/s）、演算性能（GFLOP/s）のように、時間あたりの量には 10 進接頭辞を使います。たとえば 1 GB/s は毎秒 :math:`10^9` バイトです。
* 製品の仕様書や他の文献を引用するときは、元の表記に従うことがあります。

用語の表記
^^^^^^^^^^

専門用語を初めて使うときは太字で示し、括弧内に英語表記を添えます。主な用語は付録「:doc:`appendix_glossary`」にまとめてあります。製品名や企業名は、原則として広く使われている表記（Intel、AMD、NVIDIA、Arm など）に従います。

この章のまとめ
--------------

* 本書は、ソフトウェアを書くエンジニアが、性能や並行性、セキュリティの背景にあるハードウェアの仕組みを定量的に理解することを目的としています。
* 前提知識は、プログラミングの経験と、2 進数や CPU・メモリの役割の大まかな理解です。
* 本書は 20 章と付録からなり、性能の測り方と ISA、プロセッサの内部、メモリ階層、並列化と GPU・アクセラレーター、セキュリティ、最新の動向の順に進みます。
* サンプルコードは Python 3.10 以降の標準ライブラリだけで動作し、付録「:doc:`appendix_examples`」からダウンロードできます。
* 例に使う ISA は主に RISC-V（RV32I）です。16 進数には ``0x``、2 進数には ``0b`` を付け、容量には KiB などの 2 進接頭辞を使います。
