ソフトウェアテスト入門
======================

本書は、Python などでプログラムを書いた経験はあるものの、テストを体系的に学んだことのないエンジニアを対象に、ソフトウェアテストの考え方と実践方法を解説する。第 I 部でテストの目的や設計技法といった基礎を学び、第 II 部でそれを Python のテストフレームワーク pytest で実装する。第 III 部では、テスト駆動開発や継続的インテグレーションなど、テストを開発の中で活かす方法を扱う。
