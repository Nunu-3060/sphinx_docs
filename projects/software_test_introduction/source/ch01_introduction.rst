1. はじめに
===========

1.1 本書の目的
--------------

プログラムを書いたら、思いどおりに動くかを確かめる。多くのエンジニアは、関数を呼び出して結果を表示したり、画面を操作して動きを見たりして、これを日常的に行っている。しかし、何をどこまで確かめれば十分なのか、確かめる作業をどうすれば繰り返し行えるのかを、体系的に学ぶ機会は多くない。

本書の目的は、ソフトウェアテストの基本的な考え方と、それを実際の開発で使うための技術を身に付けることである。具体的には、読み終えたときに次のことができるようになることを目指す。

* テストの目的と限界を説明できる。
* 仕様やコードの構造から、少ない数で効果の高いテストケースを設計できる。
* pytest を使って、自動で繰り返し実行できるテストを書ける。
* テストしやすいようにコードを設計し直せる。
* テストを開発の流れに組み込み、継続的に運用できる。

1.2 対象読者と前提知識
----------------------

本書は、Python の基本的な文法（関数、クラス、例外、モジュールの import など）を理解しているエンジニアを対象とする。Python 以外の言語が主な仕事の言語であっても、第 I 部と第 III 部の内容はそのまま役立つ。

テストについての予備知識は必要ない。一方で、Python の文法の説明は省略する。型ヒント（``list[int]`` や ``str | None`` など）もサンプルコード全体で使うが、読めれば十分である。

1.3 本書の構成
--------------

本書は 3 つの部と付録で構成する。

.. list-table::
   :header-rows: 1
   :widths: 25 15 60

   * - 部
     - 章
     - 内容
   * - 第 I 部 テストの基礎
     - 2～5 章
     - テストの目的、分類、テストケースの設計技法。特定の言語やツールに依存しない内容である。
   * - 第 II 部 Python によるテストの実践
     - 6～14 章
     - unittest と pytest によるテストの書き方、テストダブル、テストしやすい設計、結合テスト、静的解析、カバレッジの計測。第 I 部で設計したテストケースを実装する。
   * - 第 III 部 テストの進め方
     - 15～18 章
     - テスト駆動開発、よいテストの書き方、テストの自動化、テストの計画と管理。
   * - 付録
     - A～D
     - 用語集、早見表、サンプルコードの一覧、参考文献。

初めて読む場合は、最初から順に読むことを勧める。第 I 部の設計技法は第 II 部の例題で使うため、第 II 部から読み始めた場合も、必要に応じて第 I 部を参照してほしい。

1.4 題材
--------

本書では、全編を通して小さなネットショップの機能を題材にする。題材のコードは、サンプルコードの ``shop`` パッケージにまとめてある。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - モジュール
     - 内容
   * - ``shop/shipping.py``
     - 注文金額と会員の種類、配送先から送料を計算する（4 章で仕様を示す）。
   * - ``shop/cart.py``
     - 商品と数量を保持するショッピングカート（6 章で紹介する）。
   * - ``shop/member.py``
     - 累計購入金額と会員歴から会員ランクを判定する（5 章で紹介する）。
   * - ``shop/order.py``
     - 注文の状態（受付済み、支払い済み、発送済みなど）を管理する（4 章で仕様を示す）。

同じ題材を繰り返し使うことで、設計技法で導いたテストケースがどのようにテストコードになるかを追いやすくしている。

1.5 実行環境の準備
------------------

本書のサンプルコードは、次の環境で動作を確認している。

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - ソフトウェア
     - バージョン
   * - Python
     - 3.14.6（3.12 以降であれば動作する）
   * - pytest
     - 9.1.1
   * - Hypothesis
     - 6.168.3
   * - coverage.py
     - 7.16.2
   * - httpx
     - 0.28.1
   * - flake8
     - 7.4.1
   * - mypy
     - 2.3.1

Python 以外のパッケージは、次のコマンドでまとめてインストールできる。

.. code-block:: console
   :linenos:

   $ python -m pip install pytest hypothesis coverage httpx flake8 mypy

仮想環境（``venv``）の中にインストールすると、ほかのプロジェクトとパッケージのバージョンが衝突しない。仮想環境の作り方は Python の公式文書を参照してほしい。

1.6 サンプルコードの使い方
--------------------------

サンプルコードは、:download:`examples.zip <../build/extra/examples.zip>` から一括でダウンロードできる。個別のファイルは、付録 C の一覧からダウンロードできる。展開すると、次の構成のフォルダーができる。

.. code-block:: text

   examples/
   ├── pyproject.toml         pytest、mypy、coverage.py の設定
   ├── setup.cfg              flake8 の設定
   ├── shop/                  題材のパッケージ
   ├── ch06_unittest/         6 章のテスト
   ├── ch07_pytest_basics/    7 章のテスト
   └── ...                    以降の章のテスト

テストは ``examples`` フォルダーで実行する。``pyproject.toml`` の設定により、``examples`` フォルダーが import の起点になるため、どの章のテストからも ``shop`` パッケージを読み込める。

.. code-block:: console
   :linenos:

   $ cd examples
   $ python -m pytest

1.7 本書の表記
--------------

本書では、次の表記を用いる。

* コマンドの入力例は、先頭に ``$`` を付けて示す。``$`` は入力しない。Windows の PowerShell やコマンドプロンプトでも、同じコマンドを実行できる。
* コードとコマンドの例には行番号を付ける。説明の中で「3 行目」のように行番号で参照することがある。
* 実行結果は、行番号を付けずに示す。実行結果の中のパスの区切り文字やメモリー上のアドレスなどは、環境によって異なることがある。
* 用語集に載せた用語は、本文の初出などで付録 A の用語集へのリンクを付ける。
