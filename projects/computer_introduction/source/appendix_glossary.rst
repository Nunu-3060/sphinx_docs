用語集
======

本書に登場する主な用語をまとめます。英字で始まる用語を先に、その後に五十音順に並べています。

.. glossary::

   ALU
      Arithmetic Logic Unit（算術論理演算装置）の略です。CPU の中で、加算や減算などの算術演算と、AND や OR などの論理演算を行う回路です。

   ASCII
      英字、数字、記号、制御文字の合計 128 文字を 7 ビットで表す文字コードです。

   CPU
      Central Processing Unit（中央処理装置）の略です。命令を解読して実行する、計算機の中心となる装置です。制御装置と演算装置からなります。

   DMA
      Direct Memory Access の略です。CPU を介さずに、入出力装置と主記憶の間で直接データを転送する方式です。

   GPU
      Graphics Processing Unit の略です。もともとは画像の描画用のプロセッサですが、多数の演算器を使った並列計算が得意なため、機械学習や科学技術計算にも使われています。

   IEEE 754
      浮動小数点数の表現と演算を定めた国際的な規格です。

   OS
      オペレーティングシステムの略です。ハードウェアを管理し、アプリケーションに共通の機能を提供するソフトウェアです。

   SIMD
      Single Instruction, Multiple Data の略です。1 つの命令で複数のデータに同じ演算を行う方式です。

   SoC
      System on a Chip の略です。CPU、GPU、メモリコントローラなど、計算機に必要な多くの機能を 1 個のチップに集積したものです。

   UTF-8
      Unicode の文字を 1〜4 バイトの可変長で表す文字符号化方式です。ASCII と互換性があります。

   アセンブリ言語
      機械語の命令を、人間が読めるニーモニックで表した言語です。原則として機械語の命令と 1 対 1 に対応します。

   アムダールの法則
      プログラムの一部だけを並列化したときの、全体の速度向上率の上限を示す法則です。

   アルゴリズム
      問題を解くための、明確で有限な手順です。

   インタプリタ
      ソースコードを機械語に変換せずに、解釈しながら実行するプログラムです。

   オーバーフロー
      計算結果が、決められたビット数で表せる範囲を超えることです。

   仮想化
      1 台の物理的な計算機の上で、複数の仮想的な計算機を動かす技術です。

   仮想記憶
      各プロセスに、専用の広大な主記憶があるかのように見せる仕組みです。仮想アドレスを物理アドレスに変換して実現します。

   キャッシュメモリ
      CPU と主記憶の間に置かれる、高速で小容量の記憶装置です。最近使ったデータの写しを保持します。

   局所性
      プログラムのメモリアクセスが、時間的・空間的に偏る性質です。一度使ったデータを再び使う時間的局所性と、近くのアドレスを続けて使う空間的局所性があります。

   組合せ回路
      出力が現在の入力だけで決まる論理回路です。加算器やマルチプレクサがその例です。

   クロック
      回路の動作のタイミングを揃えるための周期的な信号です。1 秒間の周期の数をクロック周波数と呼びます。

   計算量
      問題を解くのに必要な時間や記憶容量を、入力の大きさの関数として表したものです。

   コンテナ
      OS のカーネルを共有しながら、アプリケーションの実行環境を隔離する技術です。

   コンパイラ
      高級言語のプログラムを、実行前に機械語などに変換するプログラムです。

   システムコール
      アプリケーションが OS のカーネルに処理を依頼するための仕組みです。

   順序回路
      出力が現在の入力だけでなく、内部に記憶した状態にも依存する論理回路です。フリップフロップやレジスタがその例です。

   スーパースカラ
      複数のパイプラインを持ち、1 クロックに複数の命令を同時に実行する方式です。

   スレッド
      1 つのプロセスの中で、記憶領域を共有しながら並行して動く実行の流れです。

   チャーチ＝チューリングのテーゼ
      直感的な意味で計算可能な関数は、チューリングマシンで計算可能な関数と一致するという主張です。

   チューリング完全
      万能チューリングマシンを模倣できる計算能力を持つことです。一般的なプログラミング言語はチューリング完全です。

   チューリングマシン
      テープ、ヘッド、有限個の状態、遷移規則からなる、計算を数学的に定義するための仮想的な機械です。

   停止問題
      任意のプログラムと入力について、そのプログラムが停止するかどうかを判定する問題です。この問題を解くアルゴリズムは存在しません。

   デナード・スケーリング
      トランジスタを微細化すると、電力密度を一定に保ったままクロック周波数を上げられるという関係です。2000 年代半ばに成り立たなくなりました。

   トランジスタ
      電気信号によって電流のオン・オフを切り替える半導体素子です。論理ゲートを作る基本的な部品です。

   2 の補数表現
      負の数 :math:`-x` を :math:`2^n - x` で表す、符号付き整数の表現方法です。加算と減算を同じ回路で計算できます。

   ノイマン型アーキテクチャ
      プログラムとデータを同じ記憶装置に格納し、命令を順に読み出して実行する計算機の構成です。

   バイト
      8 ビットをまとめた単位です。

   パイプライン
      命令の処理をいくつかの段階に分け、複数の命令の異なる段階を重ねて実行する方式です。

   万能チューリングマシン
      テープに書かれた他のチューリングマシンの記述を読み込み、その動作を模倣できるチューリングマシンです。

   ビット
      0 または 1 の値をとる、情報の最小単位です。

   ブール代数
      0 と 1 の 2 つの値と、AND、OR、NOT などの演算を扱う代数です。

   浮動小数点数
      数を、符号、指数部、仮数部で表す方式です。非常に大きな数から非常に小さな数までを扱えます。

   フリップフロップ
      1 ビットの値を記憶する順序回路です。

   プログラム内蔵方式
      プログラムをデータと同じように記憶装置に格納し、計算機が読み出して実行する方式です。

   プロセス
      実行中のプログラムです。OS はプロセスごとに独立した記憶領域を割り当てます。

   マイクロコントローラ
      CPU、メモリ、周辺回路を 1 個のチップに集積した、組込み機器の制御用の計算機です。

   マイクロプロセッサ
      CPU の機能を 1 個の集積回路に収めたものです。

   ムーアの法則
      集積回路に載せられるトランジスタの数が約 2 年ごとに 2 倍になるという経験則です。

   命令セットアーキテクチャ
      CPU が実行できる命令の種類や形式、レジスタの構成などを定めた仕様です。ハードウェアとソフトウェアの境界を定めます。ISA とも呼びます。

   メモリ階層
      高速で小容量の記憶装置と、低速で大容量の記憶装置を階層的に組み合わせた構成です。

   量子ビット
      0 と 1 の重ね合わせの状態をとれる、量子計算機の情報の単位です。

   レジスタ
      CPU の内部にある、少数の高速な記憶回路です。

   論理ゲート
      AND、OR、NOT などの論理演算を行う電子回路です。

   割り込み
      入出力装置などからの信号によって、CPU が実行中のプログラムを一時中断し、別の処理を行う仕組みです。
