はじめに
========

本書の目的
----------

私たちは毎日のように計算機を使い、プログラムを書いています。しかし「計算機とは何か？」と改めて問われると、答えに詰まるのではないでしょうか。CPU やメモリといった部品の名前は知っていても、それらがなぜその形で組み合わされているのか、そもそも「計算」とは何なのかを説明できる人は多くありません。

本書の目的は、この問いに対して筋の通った答えを示すことです。そのために、次の 5 つの問いを順に考えていきます。

#. 計算とは何か。何が計算でき、何が計算できないのか。
#. 数や文字といった情報を、計算機の中でどう表すのか。
#. 0 と 1 の信号から、どうやって計算を行う回路を作るのか。
#. 回路をどう組み立てると、プログラムを実行できる計算機になるのか。
#. 計算機の上で、ソフトウェアはどのように動くのか。

これらの問いに答えた後で、計算機の歴史と現代の計算機を見渡し、今日の計算機がなぜ今の姿をしているのかを理解することを目指します。

対象読者と前提知識
------------------

本書は、次のような読者を想定しています。

* 業務でプログラムを書いているが、計算機の仕組みを体系的に学んだことがないエンジニア
* 情報系以外の分野からソフトウェア開発に携わるようになったエンジニア
* 計算機の基礎を一通り復習したいエンジニア

前提知識として、何らかのプログラミング言語で簡単なプログラムを書けることを想定しています。サンプルコードは Python で書かれていますが、Python に詳しくなくても読めるように、各ファイルに説明のコメントを付けています。計算機の内部（理論・ハードウェア）については、前提知識がなくても読めるように説明します。数式は高校数学の範囲にとどめています。

本書の構成と読み方
------------------

本書の各章の内容は次のとおりです。

.. list-table:: 本書の構成
   :header-rows: 1
   :widths: 30 70

   * - 章
     - 内容
   * - 計算機とは何か
     - 「計算」と「計算機」を定義し、本書で扱う範囲を定めます。
   * - 計算機の歴史
     - 計算道具から現代のマイクロプロセッサまでの歩みをたどります。
   * - 計算の理論
     - チューリングマシンを使って、計算できることとできないことの境界を考えます。
   * - 情報の表現
     - 整数、実数、文字などを 0 と 1 で表す方法を説明します。
   * - 論理回路
     - 論理ゲートから加算器と記憶素子を組み立てます。
   * - 計算機の構成
     - CPU、メモリ、入出力装置がどのように協調してプログラムを実行するかを説明します。
   * - ソフトウェアと計算機
     - 機械語、プログラミング言語、オペレーティングシステムの役割を説明します。
   * - 現代の計算機
     - マルチコア、GPU、組込み計算機、クラウド、量子計算機などを紹介します。
   * - まとめ
     - 全体を振り返り、次に学ぶべきことを示します。

「計算の理論」から「ソフトウェアと計算機」までの各章は、前の章の内容を使って次の章を説明する構成になっているため、順に読むことをお勧めします。「計算機の歴史」と「現代の計算機」は比較的独立しているので、興味に応じて先に読んでも構いません。ただし、歴史の章には後の章で説明する用語が登場します。分からない用語があれば「:doc:`appendix_glossary`」を参照してください。

サンプルコードの使い方
----------------------

本書のサンプルコードは Python 3.10 以降で動作します。外部ライブラリは使用していません。各章の本文からサンプルコードを閲覧・ダウンロードできます。一覧は「:doc:`appendix_examples`」にまとめています。

ダウンロードしたファイルは、次のように実行します。

.. code-block:: console
   :linenos:

   $ python turing_machine.py

Windows でコマンドプロンプトを使う場合は、``python`` の代わりに ``py`` と入力する必要がある場合があります。

表記について
------------

本書では、次の表記を使います。

* 2 進数は 0b、16 進数は 0x を先頭に付けて表します（例：0b1010、0xFF）。10 進数には何も付けません。
* 単位の接頭辞には、10 のべき乗を表す k（キロ、:math:`10^3`）、M（メガ、:math:`10^6`）、G（ギガ、:math:`10^9`）、T（テラ、:math:`10^{12}`）と、10 の負のべき乗を表す m（ミリ、:math:`10^{-3}`）、µ（マイクロ、:math:`10^{-6}`）、n（ナノ、:math:`10^{-9}`）を使います。
* 人名は原則としてカタカナで表記し、必要に応じて初出時に原綴を併記します。
