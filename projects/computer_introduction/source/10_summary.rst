まとめ
======

本書では、「計算機とは何か？」という問いに答えるために、計算の理論からハードウェア、ソフトウェア、そして現代の計算機までを見てきました。この章では全体を振り返り、次に学ぶべきことを紹介します。

各章の要点
----------

.. list-table:: 各章の要点
   :header-rows: 1
   :widths: 25 75

   * - 章
     - 要点
   * - 計算機とは何か
     - 計算とは、入力を決められた規則に従って出力に変換する手続きです。本書で扱う計算機は、プログラム内蔵方式のデジタル汎用計算機です。
   * - 計算機の歴史
     - 計算の自動化は、機械式、リレー式、電子式と進み、1940 年代にプログラム内蔵方式が確立しました。素子は真空管、トランジスタ、集積回路と進歩し、計算機は小型化と高速化を続けてきました。
   * - 計算の理論
     - チューリングマシンによって計算が数学的に定義されました。チューリング完全な計算機は原理的に同じ範囲の問題を解けますが、停止問題のように計算できない問題も存在します。
   * - 情報の表現
     - すべての情報はビット列で表され、その意味は解釈によって決まります。整数は 2 の補数表現、実数は浮動小数点数、文字は Unicode などで表します。
   * - 論理回路
     - 論理ゲートを組み合わせて、加算器などの組合せ回路と、レジスタなどの順序回路を作れます。これらを組み合わせると ALU になります。
   * - 計算機の構成
     - CPU は命令サイクルを繰り返してプログラムを実行します。メモリ階層とキャッシュが CPU と主記憶の速度差を埋め、パイプラインなどの工夫が CPU を高速化しています。
   * - ソフトウェアと計算機
     - 高級言語のプログラムは、コンパイラやインタプリタによって機械語の世界とつながります。OS はハードウェアを抽象化し、安全に共有できるようにします。
   * - 現代の計算機
     - クロック周波数の向上が止まった後、性能向上は並列化と専用化によって実現されています。計算機は、組込み機器からデータセンターまで多様な形で使われています。

「計算機とは何か？」への答え
----------------------------

以上を踏まえると、本書の問いには次のように答えられます。

   計算機とは、0 と 1 で表された記号を、記憶装置に格納されたプログラムに従って自動的に操作する機械である。その計算能力は原理的にチューリングマシンと等しく、プログラムを替えるだけで、計算可能なあらゆる問題を解くことができる。

そして、現実の計算機は、この単純な原理の上に、トランジスタから論理回路、CPU、OS、プログラミング言語、アプリケーションまでの抽象化の階層を積み重ねることで作られています。各階層の工夫は、限られた時間、記憶容量、電力の中で、できるだけ多くの計算を行うためのものです。

本書で見てきた原理は、計算機の形がスマートフォンになっても、データセンターになっても変わりません。新しい技術に出会ったときは、それが抽象化のどの階層に位置し、どの制約を克服しようとしているのかを考えると、その本質を理解しやすくなるでしょう。

次に学ぶべきこと
----------------

本書で扱った各テーマは、それぞれが計算機科学の一分野であり、さらに深く学べます。興味に応じて、次のテーマに進むことをお勧めします。参考になる文献は「:doc:`appendix_references`」に挙げています。

計算機アーキテクチャ
   CPU の設計、パイプライン、キャッシュ、並列処理の詳細を学びます。実際に簡単な CPU を設計してみるのも理解を深める良い方法です。

オペレーティングシステム
   プロセスの管理、スケジューリング、仮想記憶、ファイルシステムの仕組みを学びます。

計算理論とアルゴリズム
   計算可能性と計算量の理論、効率のよいアルゴリズムの設計方法を学びます。

コンパイラと言語処理系
   字句解析、構文解析、最適化、コード生成の手法を学びます。

ネットワークと分散システム
   計算機同士が通信する仕組みと、多数の計算機を協調させる方法を学びます。

また、論理ゲートから CPU、コンパイラ、OS までを自分の手で作りながら学ぶ教材もあります。本書のサンプルコードを改造して、簡易 CPU に命令を追加したり、チューリングマシンに別の計算をさせたりすることも、理解を深めるよい練習になります。
