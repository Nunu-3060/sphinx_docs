発展的な話題
============

本章では、本書の範囲を超える発展的な話題のうち、今後のエンジニアにとって特に重要なものを概観する。詳細は\ :doc:`references`\ に挙げた文献を参照してほしい。

量子計算機と暗号
----------------

量子計算機は、量子力学の重ね合わせや干渉を利用して計算を行う計算機である。暗号にとって重要なのは、次の 2 つの量子アルゴリズムである。

* **ショアのアルゴリズム**\ （1994 年）：素因数分解問題と離散対数問題（楕円曲線離散対数問題を含む）を多項式時間で解く。大規模な量子計算機が実現すれば、RSA、DH、楕円曲線暗号は全て安全でなくなる。
* **グローバーのアルゴリズム**\ （1996 年）：:math:`N` 個の候補からの探索を約 :math:`\sqrt{N}` 回の計算で行う。鍵長 :math:`\ell` ビットの共通鍵暗号の全数探索が :math:`2^{\ell}` から :math:`2^{\ell/2}` 程度に短縮されるため、共通鍵暗号は鍵長を 2 倍にすれば対処できる。AES-256 であれば、量子計算機に対しても十分な安全性を保てると考えられている。

現在の量子計算機は、暗号を破るにはまだ規模も精度も大きく不足している。しかし、攻撃者が今のうちに暗号化された通信を記録しておき、将来量子計算機が実現してから復号する「今収集し、後で解読する」（harvest now, decrypt later）攻撃が懸念されている。長期間秘密にしておく必要がある情報については、すでに対策が必要な段階にある。

耐量子暗号
----------

標準化の状況
^^^^^^^^^^^^

量子計算機でも効率よく解けないと考えられている問題に基づく公開鍵暗号を\ :term:`耐量子暗号`\ （post-quantum cryptography、PQC）と呼ぶ。NIST は 2016 年から公開のコンペティションによる選定を進め、2024 年 8 月に最初の 3 つの標準を発行した。

.. list-table:: NIST が標準化した耐量子暗号
   :header-rows: 1
   :widths: 25 20 30 25

   * - 規格
     - 名称
     - 種類
     - 元になった方式
   * - FIPS 203 [FIPS203]_
     - ML-KEM
     - 鍵カプセル化（格子暗号）
     - CRYSTALS-Kyber
   * - FIPS 204 [FIPS204]_
     - ML-DSA
     - デジタル署名（格子暗号）
     - CRYSTALS-Dilithium
   * - FIPS 205 [FIPS205]_
     - SLH-DSA
     - デジタル署名（ハッシュ関数ベース）
     - SPHINCS+

このほか、格子暗号に基づく署名方式 FN-DSA（元は Falcon）の標準化が進められており、格子暗号とは異なる問題に基づく予備の鍵カプセル化方式として HQC が 2025 年に選定された。

鍵カプセル化メカニズム
^^^^^^^^^^^^^^^^^^^^^^

ML-KEM は、公開鍵暗号でも DH 型の鍵共有でもなく、鍵カプセル化メカニズム（key encapsulation mechanism、KEM）と呼ばれる形をしている。KEM は次の 3 つのアルゴリズムからなる。

* 鍵生成：公開鍵 :math:`pk` と秘密鍵 :math:`sk` を生成する。
* カプセル化 :math:`\mathsf{Encaps}(pk) \to (ct, K)`：ランダムな共有する鍵 :math:`K` と、それを公開鍵で包んだ暗号文 :math:`ct` を生成する。
* カプセル化解除 :math:`\mathsf{Decaps}(sk, ct) \to K`：秘密鍵で暗号文から共有する鍵 :math:`K` を取り出す。

:doc:`rsa` のハイブリッド暗号で、ランダムなセッション鍵を公開鍵で暗号化して送る部分を抽象化したものと考えればよい。

格子暗号の考え方
^^^^^^^^^^^^^^^^

ML-KEM と ML-DSA の安全性は、格子上の問題、具体的には LWE（learning with errors）問題とその変種に基づいている。LWE 問題は、大まかには次のような問題である。ランダムな行列 :math:`A` と、秘密のベクトル :math:`s` と、小さな誤差のベクトル :math:`e` を使って

.. math::

   b = A s + e \pmod{q}

を作る。:math:`A` と :math:`b` から :math:`s` を求めよ。誤差 :math:`e` がなければ、連立一次方程式として掃き出し法で簡単に解ける。しかし小さな誤差を加えるだけで、量子計算機を使っても効率よく解く方法は知られていない問題になる。

移行の課題と現状
^^^^^^^^^^^^^^^^

耐量子暗号は、従来の公開鍵暗号に比べて鍵や暗号文、署名が大きい。例えば ML-KEM-768 の公開鍵は 1184 バイト、暗号文は 1088 バイトであり、ML-DSA-65 の公開鍵は 1952 バイト、署名は 3309 バイトである。X25519 の公開鍵が 32 バイト、Ed25519 の署名が 64 バイトであることと比べると、通信量や保存領域への影響は無視できない。

また、耐量子暗号は歴史が浅く、従来の暗号ほど長い解析の実績がない。そこで、移行期には従来の方式と耐量子暗号を組み合わせ、両方が破られない限り安全とするハイブリッド方式が使われている。TLS では、X25519 と ML-KEM-768 を組み合わせた鍵共有（X25519MLKEM768）が主要なブラウザや CDN ですでに広く使われている。

ゼロ知識証明
------------

ゼロ知識証明とは、ある命題が正しいことを、それ以外の情報を一切明かさずに相手に納得させる手法である。例えば、パスワードそのものを送らずに、パスワードを知っていることだけを証明できる。

代表的な例として、離散対数の知識を証明するシュノア（Schnorr）の識別プロトコルを紹介する。素数位数 :math:`q` の群の生成元を :math:`g` とし、証明者は :math:`y = g^x` を満たす秘密の :math:`x` を知っていることを、:math:`x` を明かさずに検証者に示したい。

#. 証明者は乱数 :math:`r` を選び、:math:`t = g^r` を検証者に送る（コミットメント）。
#. 検証者は乱数 :math:`c` を選び、証明者に送る（チャレンジ）。
#. 証明者は :math:`s = r + c x \bmod q` を検証者に送る（レスポンス）。
#. 検証者は :math:`g^s = t \cdot y^c` が成り立つかを確かめる。

:math:`x` を知っている証明者は必ず検証に通る（完全性。completeness の意味であり、本書のほかの箇所の完全性（integrity）とは異なる）。:math:`x` を知らない者は、:math:`c` を事前に予測できない限り正しい :math:`s` を作れない（健全性）。そして、やり取りされる :math:`(t, c, s)` は、:math:`x` を知らなくても同じ分布で作り出せるため、検証者は :math:`x` について何も学ばない（ゼロ知識性）。

ゼロ知識証明は、プライバシーを保護する認証、暗号資産の取引の秘匿、計算結果の正しさの証明（zk-SNARK など）に応用されている。

準同型暗号
----------

準同型暗号とは、暗号文のまま演算を行うと、その結果を復号したものが平文に対して演算を行った結果と一致する暗号である。:doc:`rsa` で見た教科書的 RSA の可鍛性 :math:`E(m_1) E(m_2) = E(m_1 m_2)` は、掛け算に関する準同型性そのものである。暗号の安全性の観点からは可鍛性は欠点であったが、うまく使えば、データを暗号化したまま第三者（クラウドなど）に計算を任せられる。

足し算だけ、あるいは掛け算だけができる準同型暗号は以前から知られていた（足し算ができる Paillier 暗号など）。足し算と掛け算の両方を何度でも行える完全準同型暗号（fully homomorphic encryption、FHE）は、2009 年に Craig Gentry によって初めて構成された。FHE は現在でも通常の計算に比べて数千倍以上遅いが、性能は年々改善されており、医療データや金融データの秘匿計算などへの応用が研究されている。

秘密分散
--------

秘密分散とは、秘密の情報を複数の断片（シェア）に分け、一定数以上のシェアが集まったときだけ元の秘密を復元できるようにする手法である。1979 年に Adi Shamir が提案した :math:`(k, n)` しきい値法では、秘密を :math:`n` 個のシェアに分け、そのうち任意の :math:`k` 個から秘密を復元できる。:math:`k - 1` 個以下のシェアからは、秘密について何の情報も得られない。

シャミアの方法は、「:math:`k` 個の点が決まれば :math:`k - 1` 次多項式が 1 つに決まる」という性質を使う。素数 :math:`p` を決め、秘密を :math:`s` として、係数 :math:`a_1, \ldots, a_{k-1}` をランダムに選んだ多項式

.. math::

   f(x) = s + a_1 x + a_2 x^2 + \cdots + a_{k-1} x^{k-1} \pmod{p}

を作る。:math:`i = 1, 2, \ldots, n` について :math:`(i, f(i))` を :math:`i` 番目のシェアとする。:math:`k` 個のシェア :math:`(x_j, y_j)` が集まれば、ラグランジュ補間によって :math:`f(0) = s` が求まる。

.. math::

   s = f(0) = \sum_{j=1}^{k} y_j \prod_{m \neq j} \frac{x_m}{x_m - x_j} \pmod{p}

秘密分散は、重要な秘密鍵を複数の管理者で分担して保管する用途（ルート CA の鍵や暗号資産のウォレットなど）に使われている。
