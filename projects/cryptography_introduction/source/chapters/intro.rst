はじめに
========

本書の目的
----------

暗号は、Web の通信（HTTPS）、パスワードの保存、ソフトウェアの更新、電子決済など、日常的に使うシステムのほとんどを支えている。一方で、暗号は誤った使い方をしても「動いているように見える」ため、脆弱性に気付きにくい技術でもある。ECB モードでの暗号化、ハッシュ値だけによるパスワードの保存、使い回されたナンスなど、実際に起きた事故の多くは暗号アルゴリズムそのものではなく、その使い方の誤りが原因である。

本書の目的は、暗号を自作できるようになることではなく、暗号を\ **正しく使える**\ ようになるための基礎を身に付けることである。そのために、各章で次の 3 段階を繰り返す。

#. 数式を使って、暗号方式の原理と安全性の根拠を説明する。
#. Python で小さな実装（以下、おもちゃ実装と呼ぶ）を作り、動作を確かめる。
#. 実務では標準ライブラリや ``cryptography`` ライブラリをどう使えばよいかを示す。

対象読者と前提知識
------------------

本書は次の読者を想定している。

* Python で簡単なプログラムを書いたり読んだりできる。
* 工学系大学の 1 〜 2 年程度の数学（整数の割り算、指数、対数、確率の初歩）を理解している。

整数論（剰余演算、素数、フェルマーの小定理など）や群・有限体の知識は前提としない。必要な内容は\ :doc:`math`\ で説明する。

サンプルコードについて
----------------------

実行環境
^^^^^^^^

サンプルコードは Python 3.11 以上を対象とし、Python 3.14 で動作を確認している。標準ライブラリだけで動くものと、``cryptography`` ライブラリを必要とするものがある。``cryptography`` は次のコマンドでインストールできる。

.. code-block:: console
   :linenos:

   pip install cryptography

各サンプルコードは本文中に掲載しており、掲載箇所のリンクからダウンロードできる。一覧は\ :doc:`examples_list`\ にまとめた。各ファイルは単体で実行でき、冒頭の docstring に目的と実行方法を書いている。

.. _toy-warning:

おもちゃ実装に関する注意
^^^^^^^^^^^^^^^^^^^^^^^^

.. warning::

   ファイル名が ``toy_`` で始まるサンプルなど、暗号アルゴリズムを自分で実装したコードは学習専用である。これらはサイドチャネル攻撃への対策や入力値の検証が不十分であり、実際のシステムで使ってはならない。実務では、:doc:`pitfalls`\ で紹介する検証済みのライブラリを使うこと。

表記
----

本書では次の表記を使う。

.. list-table:: 本書で使う記号
   :header-rows: 1
   :widths: 30 70

   * - 記号
     - 意味
   * - :math:`a \bmod n`
     - :math:`a` を :math:`n` で割った余り（:math:`0` 以上 :math:`n` 未満）
   * - :math:`a \equiv b \pmod{n}`
     - :math:`a - b` が :math:`n` で割り切れる（:math:`a` と :math:`b` は法 :math:`n` で合同である）
   * - :math:`\gcd(a, b)`
     - :math:`a` と :math:`b` の最大公約数
   * - :math:`\mathbb{Z}_n`
     - :math:`n` を法とする剰余類の集合 :math:`\{0, 1, \ldots, n-1\}`
   * - :math:`\oplus`
     - ビットごとの排他的論理和（XOR）
   * - :math:`x \| y`
     - バイト列 :math:`x` と :math:`y` の連結
   * - :math:`\{0, 1\}^n`
     - 長さ :math:`n` のビット列全体の集合
   * - :math:`x \xleftarrow{\$} S`
     - 集合 :math:`S` から一様ランダムに :math:`x` を選ぶ

暗号の登場人物には、慣例に従って次の名前を使う。送信者を Alice、受信者を Bob、通信を盗聴する攻撃者を Eve、通信を改ざんする能動的な攻撃者を Mallory と呼ぶ。

さらに学ぶために
----------------

本書は入門書であり、安全性の厳密な定義と証明には深入りしない。暗号理論を体系的に学びたい読者には [KL20]_ や [BS23]_ を、実務の観点から学びたい読者には [Aum24]_ を薦める。アルゴリズムの詳細を調べるには [MOV96]_ が、数式を使わずに全体像をつかむには [Yuki15]_ が役に立つ。各アルゴリズムの正確な仕様は、:doc:`references`\ に挙げた規格を参照してほしい。
