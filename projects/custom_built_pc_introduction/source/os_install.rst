OS のインストールと初期設定
===========================

本章では、Windows 11 と Linux のインストール方法と、インストール後の初期設定を説明する。Linux は Ubuntu を例とする。

インストールメディアを作成する
------------------------------

OS のインストールには、インストーラーを書き込んだ USB メモリ（インストールメディア）を使う。作成には、すでに動作している別の PC が必要となる。USB メモリの内容は全て消去されるため、必要なデータは事前に退避しておく。

Windows 11
^^^^^^^^^^

Microsoft の Web サイトの Windows 11 のダウンロードページから「メディア作成ツール」をダウンロードして実行し、画面の指示に従って USB メモリを作成する。8 GB 以上の USB メモリが必要である。

Linux（Ubuntu）
^^^^^^^^^^^^^^^

1. Ubuntu の Web サイトから、デスクトップ版のインストールイメージ（ISO ファイル）をダウンロードする。
2. ダウンロードしたファイルが壊れていないことを、公開されているチェックサム（SHA-256）と比較して確認する。
3. ISO ファイルを USB メモリに書き込む。

チェックサムは次のコマンドで計算できる。ファイル名はダウンロードしたものに置き換える。

.. code-block:: powershell
   :linenos:
   :caption: Windows（PowerShell）でチェックサムを計算する

   Get-FileHash .\ubuntu-desktop-amd64.iso -Algorithm SHA256

.. code-block:: bash
   :linenos:
   :caption: Linux でチェックサムを計算する

   sha256sum ubuntu-desktop-amd64.iso

USB メモリへの書き込みには、Windows では Rufus などの書き込みツールを使う。ISO ファイルをコピーしただけでは起動できない。

Linux では dd コマンドでも書き込める。dd コマンドは書き込み先を確認しないため、必ず lsblk コマンドで USB メモリのデバイス名を確認してから実行する。デバイス名を間違えると、別のディスクの内容が消える。

.. code-block:: bash
   :linenos:
   :caption: Linux で USB メモリに書き込む

   # USB メモリのデバイス名（例：/dev/sdb）を確認する
   lsblk
   # /dev/sdX を確認したデバイス名に置き換えて実行する
   sudo dd if=ubuntu-desktop-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync

Windows 11 をインストールする
-----------------------------

ライセンス
^^^^^^^^^^

Windows 11 のライセンスには、Home と Pro のエディションがあり、パッケージ版、ダウンロード版、パーツとセットで販売される DSP 版などの購入形態がある。購入形態によって、別の PC へ移行できるかどうかなどの条件が異なるため、購入前に確認する。なお、Windows 10 のサポートは 2025 年 10 月に終了しているため、新しく組む PC には Windows 11 をインストールする。

インストールの流れ
^^^^^^^^^^^^^^^^^^

1. インストールメディアを接続して電源を入れ、ブートメニューから USB メモリを選んで起動する。
2. 言語とキーボードの種類を選ぶ。
3. プロダクトキーを入力する。後で入力することもできる。
4. インストールするエディションを選ぶ。購入したライセンスと同じエディションを選ぶこと。
5. インストール先のドライブを選ぶ。
6. インストールが終わると何度か再起動した後、初期設定の画面が表示される。画面の指示に従って地域、ネットワーク、アカウントを設定する。

最近の Windows 11 では、初期設定の途中でインターネットへの接続と Microsoft アカウントでのサインインを求められる。

.. note::

   新しいマザーボードの有線 LAN や Wi-Fi は、Windows のインストーラーが対応するドライバーを持っておらず、初期設定でネットワークに接続できないことがある。マザーボードのメーカーの Web サイトから LAN のドライバーを別の USB メモリに保存しておくと、初期設定の画面からインストールできる。

インストール先のドライブが表示されない場合は、:doc:`troubleshooting` を参照する。

Linux（Ubuntu）をインストールする
---------------------------------

1. インストールメディアを接続して電源を入れ、ブートメニューから USB メモリを選んで起動する。
2. 起動メニューで Ubuntu を選ぶ。
3. 言語、キーボード、ネットワークを設定する。
4. インストールの種類を選ぶ。ディスク全体を使う場合は、ディスクを消去してインストールする項目を選ぶ。
5. インストール先のディスク、タイムゾーン、ユーザーを設定し、インストールを開始する。
6. 完了したら、USB メモリを外して再起動する。

Ubuntu は Secure Boot が有効な状態でもインストールできる。

デュアルブートの注意点
----------------------

1 台の PC に Windows と Linux の両方をインストールし、起動時に選ぶ構成をデュアルブートと呼ぶ。デュアルブートでは次の点に注意する。

* OS ごとに別のストレージにインストールするのが最も安全である。1 台のストレージを分割すると、片方の OS の更新や再インストールがもう片方に影響することがある。
* 先に Windows を、後から Linux をインストールする。Linux のインストーラーは Windows を検出し、起動時に選択できるように設定する。
* Windows の「高速スタートアップ」を無効にする。有効なままだと、Windows が完全に終了しないため、Linux から Windows のドライブを安全に読み書きできない。
* 時計がずれる場合がある。Windows はマザーボードの時計を現地時刻として扱い、Linux は協定世界時（UTC）として扱うためである。Linux 側で次のコマンドを実行すると、現地時刻として扱うように変更できる。

.. code-block:: bash
   :linenos:
   :caption: Linux でマザーボードの時計を現地時刻として扱う

   sudo timedatectl set-local-rtc 1

ドライバーと更新プログラム
--------------------------

OS のインストール後は、まず更新プログラムを全て適用する。その後、必要なドライバーをインストールする。

Windows
^^^^^^^

* Windows Update を実行し、更新がなくなるまで繰り返す。多くのドライバーも Windows Update で入る。
* チップセットのドライバーを、マザーボードまたは CPU のメーカーの Web サイトからダウンロードしてインストールする。
* GPU のドライバーを、GPU のメーカーの Web サイトからダウンロードしてインストールする。

Linux（Ubuntu）
^^^^^^^^^^^^^^^

Linux では、多くのドライバーがカーネルに含まれているため、個別のインストールは基本的に不要である。NVIDIA の GPU を使う場合は、メーカー製のドライバーをインストールする。Ubuntu では次のコマンドで、推奨されるドライバーを確認し、インストールできる。

.. code-block:: bash
   :linenos:
   :caption: Ubuntu で更新を適用し、ドライバーをインストールする

   sudo apt update
   sudo apt full-upgrade
   # 推奨されるドライバーを表示する
   ubuntu-drivers devices
   # 推奨されるドライバーをインストールする
   sudo ubuntu-drivers install

ドライバーをインストールした後は再起動する。
