用語集
======

本書で使う主な用語を、英字、五十音の順に示す。

.. glossary::
   :sorted:

   12V-2x6
      GPU に電力を供給するためのコネクタの規格。1 本で最大 600 W を供給できる。12VHPWR を改良したもので、ATX 3.1 で採用された。

   80 PLUS
      電源ユニットの変換効率の認証制度。効率の高い順に Titanium、Platinum、Gold、Silver、Bronze などのグレードがある。

   BTO
      Build To Order の略。注文を受けてから組み立てる PC であり、注文時に一部のパーツを選べる。

   DIMM
      デスクトップ PC で使われるメモリモジュールの形状。

   EXPO
      AMD が策定した、メモリの定格の速度とタイミングを記録するプロファイルの規格。UEFI で有効にすると、メモリが定格の速度で動作する。

   LGA
      Land Grid Array の略。CPU 側には平らな接点があり、ピンはマザーボードのソケット側にある方式。

   M.2
      SSD などの拡張カードの形状の規格。接続方式には PCIe（NVMe）と SATA がある。

   NVMe
      PCIe で接続する SSD のための通信規格。SATA 接続の SSD より高速である。

   PCIe
      PCI Express の略。GPU や NVMe SSD などを接続するための規格。世代（4.0、5.0 など）が上がるごとに帯域が約 2 倍になる。x16、x4 などのレーン数で帯域の幅を表す。

   POST
      Power-On Self-Test の略。電源を入れた直後に、マザーボードがパーツの状態を確認する処理。

   PSU
      Power Supply Unit の略。電源ユニットのこと。

   QVL
      Qualified Vendor List の略。マザーボードのメーカーが動作を確認したパーツ（主にメモリ）の一覧。

   SATA
      ストレージを接続するための規格。SATA SSD や HDD の接続に使われる。

   Secure Boot
      UEFI の機能の 1 つ。署名されていないプログラムが起動時に実行されることを防ぐ。

   TDP
      Thermal Design Power の略。CPU の冷却設計の目安となる値であり、最大消費電力とは異なる。

   TPM
      Trusted Platform Module の略。暗号鍵などを安全に保管するための機能。Windows 11 の要件の 1 つである。

   UEFI
      マザーボードに搭載されたファームウェアの規格。従来の BIOS に代わるもので、慣習的に BIOS と呼ばれることもある。

   VRM
      Voltage Regulator Module の略。電源ユニットからの 12 V を、CPU が使う低い電圧に変換するマザーボード上の回路。

   XMP
      Extreme Memory Profile の略。Intel が策定した、メモリの定格の速度とタイミングを記録するプロファイルの規格。

   エアフロー
      ケース内の空気の流れ。前面や底面から吸気し、背面や天面から排気するのが基本である。

   サーマルグリス
      CPU と CPU クーラーの間の微小な隙間を埋め、熱を伝えやすくするためのペースト。

   サーマルスロットリング
      温度が上限に達したときに、CPU や GPU が動作周波数を下げて発熱を抑える機能。

   ソケット
      CPU をマザーボードに取り付けるための端子。CPU とマザーボードでソケットの種類が一致している必要がある。

   チップセット
      マザーボード上で、USB、SATA などの機能を提供し、CPU と各機器の間を仲介するチップ。

   デバッグ LED
      マザーボード上で、POST のどの段階で問題が起きているかを示す LED。

   デュアルチャネル
      2 枚のメモリに同時にアクセスして帯域を広げる方式。メモリを推奨スロットに 2 枚取り付けると有効になる。

   フォームファクタ
      マザーボードやケースなどの大きさと形状の規格。ATX、Micro-ATX、Mini-ITX など。

   ボトルネック
      システム全体の性能を制限している部分。

   メモリトレーニング
      マザーボードがメモリとの通信に最適な設定を探す処理。初回起動時やメモリの設定変更後に行われる。
