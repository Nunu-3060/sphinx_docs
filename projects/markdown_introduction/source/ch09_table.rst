表
==

この章では、GFM で追加された表の書き方を説明する。表は README や仕様書でよく使われるが、Markdown の表にはできないことも多い。

表の書き方
----------

表は、``|`` で列を区切って書く。1 行目が見出しの行、2 行目が見出しと本体を区切る行で、3 行目以降が本体の行になる。HTML では ``<table>`` に変換される。

.. md-example::
   :github:

   | 名前 | 役割 | 担当 |
   | --- | --- | --- |
   | 佐藤 | リーダー | 設計 |
   | 鈴木 | 開発者 | 実装、テスト |

2 行目の区切りの行は省略できない。区切りの行には、列ごとに ``-`` を 1 個以上書く。区切りの行の列の数は、見出しの行の列の数と同じにする。列の数が合わないと、表にならずに普通の段落として表示される。

本体の行の列の数が見出しの行と異なる場合は、表として扱われる。列が足りない行は空のセルで補われ、多すぎる列は表示されない。

行の先頭と末尾の ``|`` は省略できる。また、``|`` の位置をそろえる必要もない。次のソースも、上の例と同じ表になる。

.. md-example::
   :github:

   名前 | 役割 | 担当
   --- | --- | ---
   佐藤 | リーダー | 設計
   鈴木 | 開発者 | 実装、テスト

ただし、先頭と末尾の ``|`` を書いたほうが、ソースのまま読んでも表であることが分かりやすい。本書では先頭と末尾の ``|`` を書く。

表の前には空行を入れる。段落の直後に空行なしで表を書いた場合の扱いは、変換プログラムによって異なる。

列の配置
--------

区切りの行の ``-`` の左右に ``:`` を付けると、その列の文字をそろえる位置を指定できる。

.. list-table:: 列の配置の指定
   :header-rows: 1
   :widths: 30 70

   * - 区切りの行の書き方
     - 配置
   * - ``---``
     - 指定なし（多くの場合は左寄せになる）
   * - ``:---``
     - 左寄せ
   * - ``:---:``
     - 中央寄せ
   * - ``---:``
     - 右寄せ

.. md-example::
   :github:

   | 商品 | 個数 | 価格（円） |
   | :--- | :---: | ---: |
   | りんご | 3 | 450 |
   | みかん | 10 | 1,200 |
   | ぶどう | 1 | 980 |

数値の列は右寄せにすると、桁がそろって比べやすくなる。

セルの中に書けるもの
--------------------

セルの中には、強調、インラインコード、リンクなど、文中で使う記法（\ :term:`インライン要素`\ ）を書ける。一方、箇条書きやコードブロックなどのブロック要素は書けない。

セルの中で ``|`` を文字として使いたいときは、``\|`` とエスケープする。GFM では、インラインコードの中の ``|`` もエスケープが必要である。エスケープしないと、列の区切りとして扱われる。

.. md-example::
   :github:

   | 記法 | 意味 |
   | --- | --- |
   | **強調** | 強い強調 |
   | [リンク](https://example.com/) | リンク |
   | `a \| b` | インラインコードの中の縦線 |
   | A \| B | 文字としての縦線 |

表の制限
--------

Markdown の表には次のような制限がある。

- 1 つのセルの中で改行できない。セルの内容は 1 行で書く必要がある。GitHub など HTML を書ける場所では、``<br>`` で改行を表示できる。
- 複数のセルを結合できない。
- 見出しの行のない表は書けない。
- 列の幅は指定できない。列の幅は、内容に合わせて自動で決まる。

複雑な表が必要なときは、HTML の ``<table>`` を直接書く方法もあるが、ソースが非常に読みにくくなる。表を簡単にするか、箇条書きで書けないか、先に検討するとよい。

表の整形はツールに任せる
------------------------

``|`` の位置をそろえた表は、ソースのままでも読みやすい。しかし、セルの内容を書き換えるたびに、空白の数を調整して位置をそろえ直すのは手間がかかる。特に日本語の文字は、半角文字の 2 文字分の幅で表示されることが多く、手でそろえるのは難しい。

``|`` の位置は、そろえなくても表示結果には影響しない。そろえたい場合は、エディタの拡張機能や、第 12 章で紹介する Prettier などの整形ツールに任せる。VS Code では、Markdown の表を整形する拡張機能（Markdown All in One など）を入れると、キー操作 1 つで表を整形できる。

よくある間違い
--------------

.. list-table:: 表のよくある間違い
   :header-rows: 1
   :widths: 35 30 35

   * - 間違い
     - 結果
     - 正しい書き方
   * - 区切りの行を書かない
     - 表にならない
     - 見出しの行の次に区切りの行を書く
   * - 区切りの行と見出しの行の列の数が合わない
     - 表にならない
     - 列の数をそろえる
   * - セルの中で ``|`` をそのまま書く
     - 列が増える
     - ``\|`` とエスケープする
   * - セルの中で改行しようとする
     - 次の行が表の新しい行として扱われ、表が崩れる
     - ``<br>`` を使うか、内容を短くする
