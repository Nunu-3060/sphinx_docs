リスト
======

この章では、項目を並べる箇条書きと番号付きリスト、リストの入れ子、GFM のタスクリストを説明する。リストは手軽に使える一方で、入れ子にするときの字下げの規則でつまずきやすい。

箇条書き
--------

行頭に ``-`` と半角空白を書くと、箇条書きの項目になる。HTML では ``<ul>`` と ``<li>`` に変換される。

.. md-example::

   - りんご
   - みかん
   - ぶどう

``-`` の代わりに ``*`` や ``+`` も使える。ただし、1 つのリストの途中で記号を変えると、そこで別のリストとして扱われる。

.. md-example::

   - りんご
   - みかん
   * ぶどう

表示結果では見分けにくいが、3 行目からは別のリストになっている。2 つのリストの間に余白が入るなど、意図しない表示になることがあるので、使う記号は 1 種類にそろえる。本書では ``-`` を使う。

番号付きリスト
--------------

行頭に数字、``.``、半角空白を書くと、番号付きリストの項目になる。HTML では ``<ol>`` と ``<li>`` に変換される。

.. md-example::

   1. 材料を切る
   2. 鍋で炒める
   3. 水を入れて煮込む

表示される番号は、リストの最初の項目に書いた数字から始まる連番になる。2 番目以降の項目に書いた数字は使われない。

.. md-example::

   1. 材料を切る
   1. 鍋で炒める
   1. 水を入れて煮込む

.. md-example::

   3. 3 番から始まる
   8. 数字を飛ばしても
   2. 連番になる

なお、2 つの番号付きリストを空行だけで区切って続けて書くと、1 つのリストの続きとして扱われる。別のリストとして表示したいときは、間に段落などを挟む。

すべての項目を ``1.`` と書いておけば、途中に項目を追加したり、順番を入れ替えたりしても、番号を書き直す必要がない。一方で、ソースを読むときに番号が分からなくなるので、項目が少ないうちは正しい番号を書くほうが読みやすい。どちらの書き方にするかは、文書の中で統一すればよい。

``.`` の代わりに ``)`` を使って ``1)`` と書くこともできる。ただし、記号を変えると別のリストになるのは、箇条書きと同じである。

リストの入れ子
--------------

項目の下に字下げして項目を書くと、リストを入れ子にできる。

.. md-example::

   - 果物
     - りんご
     - みかん
   - 野菜
     - にんじん

字下げの量には規則がある。CommonMark では、子の項目は「親の項目の本文が始まる位置」まで字下げする。箇条書きは ``-`` と空白で 2 文字なので、子は 2 文字字下げする。番号付きリストは ``1.`` と空白で 3 文字なので、子は 3 文字字下げする。

   :align: center

       node [shape=plaintext, fontname="Consolas"];
       t [label=<
         <table border="0" cellborder="1" cellspacing="0" cellpadding="6">

           <tr><td>-</td><td>␣</td><td bgcolor="#dcfce7">親</td><td bgcolor="#dcfce7"> </td><td></td><td></td><td></td></tr>
           <tr><td> </td><td> </td><td bgcolor="#dcfce7">-</td><td>␣</td><td>子</td><td></td><td></td></tr>
           <tr><td colspan="7" border="0"> </td></tr>
           <tr><td colspan="7" border="0"><font face="Meiryo">番号付きリスト（3 文字字下げ）</font></td></tr>
           <tr><td>1</td><td>.</td><td>␣</td><td bgcolor="#dcfce7">親</td><td></td><td></td><td></td></tr>

         </table>

   }

図の ``␣`` は半角空白を表し、緑の列が親の本文の開始位置を表す。字下げが足りないと、入れ子にならずに別のリストになる。

.. md-example::

   1. 親の項目
     - 2 文字しか字下げしていない

番号付きリストの子を 2 文字だけ字下げしたため、子の項目が入れ子にならず、別の箇条書きになった。親の本文の開始位置（行頭から 3 文字分）までの字下げが必要である。

字下げに 4 文字を使う方言や、多めに字下げしても入れ子として扱う変換プログラムもあるが、「親の本文の開始位置にそろえる」と覚えておけば、どの場所でもほぼ正しく表示される。タブ文字による字下げは、エディタによって幅が異なり、表示が崩れる原因になるので、半角空白を使う。

リスト項目の中に段落やコードブロックを入れる
--------------------------------------------

1 つの項目の中に複数の段落を書きたいときは、空行を入れ、続きの段落を親の本文の開始位置まで字下げする。コードブロック（第 7 章）なども同じように字下げすれば、項目の中に入れられる。

.. md-example::

   1. パッケージをインストールする

      仮想環境を有効にしてから実行すること。

   2. 次のコマンドを実行する

      ```
      python -m pip install requests
      ```

   3. 動作を確かめる

続きの段落を字下げしないと、リストが終わったとみなされ、その後の項目は新しいリストとして扱われる。リストが 2 つに分かれ、間隔などの表示が変わる。すべての項目を ``1.`` と書いている場合は、番号も 1 から振り直される。

項目の間に空行を 1 か所でも入れると、そのリストのすべての項目の中身が段落（HTML の ``<p>``）として扱われ、リスト全体の項目の間隔が広く表示される。項目を詰めて表示したいときは、項目の間に空行を入れない。

段落の直後にリストを書く
------------------------

CommonMark では、段落の直後の行に空行を入れずに箇条書きを書いても、リストとして扱われる。ただし、番号付きリストの場合は、``1.`` で始まるときだけ段落の直後でもリストになり、それ以外の数字で始まると段落の続きとして扱われる。これは、文中で行の先頭にたまたま数字が来た場合に、誤ってリストにしないための規則である。

.. md-example::

   買うものは次のとおり。
   - 牛乳
   - 卵

   手順は 2 番目から始める。
   2. 鍋を温める
   3. 油をひく

また、方言によっては、段落の直後に空行なしで書いたリストを認めないものもある。段落とリストの間には空行を入れる習慣を付けておくとよい。

タスクリスト
------------

箇条書きの記号の後に ``[ ]`` または ``[x]`` を書くと、チェックボックスの付いた\ :term:`タスクリスト`\ になる。``[ ]`` は未完了、``[x]`` は完了を表す。タスクリストは GFM で追加された記法である。

.. md-example::
   :github:

   - [x] 要件を確認する
   - [x] 設計書を書く
   - [ ] 実装する
   - [ ] テストする

``[`` と ``]`` の間には半角空白を 1 個入れ、``]`` の後にも半角空白を入れる。番号付きリストでも使える。

GitHub の Issue やプルリクエストの本文にタスクリストを書くと、画面上でチェックボックスをクリックして完了と未完了を切り替えられ、ソースの ``[ ]`` と ``[x]`` も自動で書き換わる。``.md`` ファイルのタスクリストは、画面上では切り替えられない。本書の表示結果のチェックボックスも操作できない。

よくある間違い
--------------

.. list-table:: リストのよくある間違い
   :header-rows: 1
   :widths: 35 30 35

   * - 間違い
     - 結果
     - 正しい書き方
   * - ``-`` の後に空白を入れない（``-項目``）
     - リストにならず、普通の段落になる
     - ``- 項目`` のように空白を入れる
   * - 番号付きリストの子を 2 文字だけ字下げする
     - 入れ子にならない
     - 親の本文の開始位置（行頭から 3 文字分）まで字下げする
   * - 項目の中の段落やコードブロックを字下げしない
     - リストが途中で 2 つに分かれる
     - 親の本文の開始位置まで字下げする
   * - 1 つのリストの途中で記号を変える
     - 別のリストになる
     - 記号を 1 種類にそろえる
   * - ``[]`` のように括弧の間の空白を省く
     - タスクリストにならない
     - ``[ ]`` と書く
