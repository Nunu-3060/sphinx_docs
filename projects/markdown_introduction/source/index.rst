Markdown 入門
=============

本書は、プログラミングを学び始めた人や経験の浅いエンジニアを対象に、Markdown の書き方を一から解説する入門書である。Markdown は、記号をいくつか覚えるだけで見出しやリスト、表を含む文書を書けるので、README、Issue、技術メモなど、エンジニアが日常的に書く文書の多くで使われている。

本書では、書く環境の用意から始めて、記法を 1 つずつ説明し、最後に README を書く実践と、表示する場所による違いを扱う。記法の説明には、Markdown のソース（書き方）と、それを変換した結果（表示結果）を並べて示す。
