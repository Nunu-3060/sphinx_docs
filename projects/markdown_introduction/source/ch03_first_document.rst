はじめての Markdown 文書
========================

この章では、細かい規則はいったん置いて、短い自己紹介の文書を 1 つ書いてみる。Markdown でどのように文書を書くのか、全体の流れをつかむことが目的である。ここで使う記法の詳しい規則は、第 4 章以降で説明する。

ファイルを作る
--------------

VS Code で新しいファイルを作り、``self_introduction.md`` という名前で保存する。保存したら、第 2 章で説明した ``Ctrl+K`` の後に ``V`` の操作で、プレビューをエディタの横に開いておく。

見出しと段落を書く
------------------

まず、文書のタイトルと最初の文章を書く。

.. md-example::

   # 自己紹介

   はじめまして。プログラミングを学び始めて 3 か月になる。

1 行目のように行頭に ``#`` と空白を書くと、その行は\ :term:`見出し`\ になる。3 行目のように記号を付けずに書いた文章は\ :term:`段落`\ になる。見出しと段落の間には空行を 1 行入れる。

項目を並べる
------------

次に、小見出しを付けて、好きなものを箇条書きで並べる。

.. md-example::

   ## 好きなもの

   - コーヒー
   - 散歩
   - 本を読むこと

``#`` を 2 個にすると、1 段下のレベルの見出しになる。行頭に ``-`` と空白を書くと、その行は箇条書きの項目になる。

文字を強調する
--------------

箇条書きの 2 番目の項目に説明を加え、一部を目立たせる。

.. md-example::

   - コーヒー
   - **散歩**（毎朝 30 分歩く）
   - 本を読むこと

``**`` で挟んだ部分は強調され、太字で表示される。

リンクを張る
------------

最後に、もう 1 つ小見出しを加え、Web ページへのリンクを含む文章を書く。

.. md-example::

   ## 今学んでいること

   いまは Python を学んでいる。教材には [Python の公式チュートリアル](https://docs.python.org/ja/3/tutorial/) を使っている。

``[`` と ``]`` で囲んだ文字が\ :term:`リンク`\ として表示され、その直後の ``(`` と ``)`` で囲んだ URL がリンク先になる。

できあがった文書
----------------

ここまでの内容をまとめると、次のような文書になる。このファイルは :download:`ch03_first_document.md <../examples/ch03_first_document.md>` からダウンロードできる。

.. md-example::
   :file: ../examples/ch03_first_document.md

ソースを読み返すと、使った記号は ``#``、``-``、``**``、``[]()`` の 4 種類だけである。それでも、見出しで区切られ、箇条書きと強調、リンクを含む、整った文書になっている。

この章で使った記法を、どの章で詳しく説明するかを次の表にまとめる。

.. list-table:: この章で使った記法
   :header-rows: 1
   :widths: 30 40 30

   * - 記法
     - 意味
     - 詳しく説明する章
   * - ``#``、``##``
     - 見出し
     - 第 4 章
   * - 空行で区切った文章
     - 段落
     - 第 4 章
   * - ``**...**``
     - 強調
     - 第 5 章
   * - ``-``
     - 箇条書き
     - 第 6 章
   * - ``[...](...)``
     - リンク
     - 第 8 章
