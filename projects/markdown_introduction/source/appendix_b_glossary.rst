付録 B 用語集
=============

本書で使った主な用語を、英字、五十音の順に並べる。

.. glossary::

   CommonMark
      Markdown の記法の規則を厳密に定めた仕様。方言による解釈の違いを解消するために 2014 年に作られ、多くのサービスやツールの基礎になっている。

   GFM
      GitHub Flavored Markdown。GitHub が公開している Markdown の仕様で、CommonMark に表、取り消し線、タスクリスト、拡張自動リンクなどを加えたもの。

   HTML
      HyperText Markup Language。Web ページを記述するためのマークアップ言語。Markdown のソースは、表示される前に HTML に変換される。

   markdownlint
      Markdown のソースが、決められた書き方のルールに沿っているかを検査するツール。VS Code の拡張機能としても使える。

   Pandoc
      文書の形式を相互に変換するコマンドラインのツール。Markdown を HTML、Word、PDF などに変換できる。

   README
      プログラムやリポジトリの概要、使い方などを説明する文書。GitHub では、リポジトリの一番上のフォルダに置いた ``README.md`` がリポジトリのページに表示される。

   reStructuredText
      軽量マークアップ言語の一つ。Python のドキュメントや、Sphinx で作る文書に使われる。本書も reStructuredText で書かれている。

   YAML
      データを「名前: 値」の形で書き表す形式の一つ。フロントマターや設定ファイルに使われる。

   アンカー
      文書の中の特定の位置（見出しなど）を、リンク先として指定するための名前。GitHub では見出しから自動で作られる。

   インラインコード
      文中の一部をコードとして等幅のフォントで表示する記法。バッククォートで挟んで書く。

   インライン要素
      段落などの中で、文字の一部に対して使う要素。強調、インラインコード、リンク、画像などがある。

   エスケープ
      記号の直前にバックスラッシュを書き、記法として解釈させずに記号のまま表示させること。

   拡張自動リンク
      ``<`` と ``>`` で囲まなくても、``https://`` や ``www.`` で始まる文字列を自動でリンクにする機能。GFM で追加された。

   強制改行
      段落を分けずに、段落の中のその位置で改行すること。行末にバックスラッシュまたは半角空白 2 個を書く。

   軽量マークアップ言語
      少ない記号で手軽に書けるように作られたマークアップ言語。Markdown、reStructuredText、AsciiDoc などがある。

   コードブロック
      複数行のコードを、記法を解釈させずに等幅のフォントで表示するブロック要素。フェンスで囲むか、行頭に 4 個以上の空白を入れて書く。

   シンタックスハイライト
      コードを、プログラミング言語の文法に合わせて色分けして表示すること。コードブロックに言語名を指定すると行われる。

   静的サイトジェネレーター
      Markdown などで書いた文書から、Web サイトを構成する HTML のファイル群を生成するツール。MkDocs、Jekyll、Hugo などがある。

   代替テキスト
      画像を表示できないときや、画面の読み上げソフトウェアを使うときに、画像の代わりに使われる文章。

   タグ
      HTML で、要素の始まりと終わりを示す記号。``<h1>`` と ``</h1>`` のように書く。

   タスクリスト
      チェックボックスの付いた箇条書き。GFM で追加された記法で、``- [ ]`` と ``- [x]`` で書く。

   段落
      空行で区切られた、ひとまとまりの文章。Markdown で記号を付けずに書いた文章は段落になる。

   フェンス
      コードブロックの前後を囲む、バッククォートまたはチルダを 3 個以上並べた行。

   フォーマッター
      ソースの見た目（空白、記号の種類など）を、決められた規則に従って自動で整えるツール。Prettier などがある。

   ブロック要素
      段落、見出し、リスト、引用、コードブロック、表など、文書を縦に区切って構成する要素。

   フロントマター
      文書の先頭に ``---`` の行で囲んで書く、タイトルやタグなどの情報。静的サイトジェネレーターや技術記事の投稿サービスで使われる。

   方言
      解釈の細部や使える記法が少しずつ異なる、Markdown の変種。

   マークアップ
      文書の構造や書式を、決められた記号で書き表すこと。

   見出し
      文書の章や節の題名。Markdown では行頭に ``#`` を書いて表す。

   約物
      句読点、括弧、記号など、文字や数字以外の文章に使う記号。CommonMark では、強調の記号の前後に約物があるかどうかで、強調になるかどうかが変わる。

   リンク
      クリックすると、別の Web ページや文書の別の位置へ移動する文字。

   レンダリング
      Markdown のソースを HTML に変換したり、変換した結果を画面に表示したりすること。
