付録 C 参考文献
===============

本書を書くにあたって参照した資料と、さらに学ぶための資料を示す。

Markdown の仕様
---------------

- John Gruber, `Markdown <https://daringfireball.net/projects/markdown/>`_ ：Markdown を考案した Gruber による、元の Markdown の説明。
- `CommonMark <https://commonmark.org/>`_ ：CommonMark の公式サイト。10 分で Markdown を学べるチュートリアルもある。
- `CommonMark Spec <https://spec.commonmark.org/>`_ ：CommonMark の仕様。強調の規則などの細部を確かめたいときに読む。
- `GitHub Flavored Markdown Spec <https://github.github.com/gfm/>`_ ：GFM の仕様。

GitHub のドキュメント
---------------------

- `基本的な書き方とフォーマットの構文 <https://docs.github.com/ja/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax>`_ ：GitHub での Markdown の書き方。見出し、リンク、アラート、脚注などを説明している。
- `表を使用して情報を整理する <https://docs.github.com/ja/get-started/writing-on-github/working-with-advanced-formatting/organizing-information-with-tables>`_ ：GitHub での表の書き方。
- `数式の記述 <https://docs.github.com/ja/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions>`_ ：GitHub での数式の書き方。
- `図の作成 <https://docs.github.com/ja/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams>`_ ：GitHub で Mermaid などの図を使う方法。

ツール
------

- `Visual Studio Code の Markdown のドキュメント <https://code.visualstudio.com/docs/languages/markdown>`_ ：VS Code での Markdown のプレビューや編集の機能。
- `markdownlint <https://github.com/DavidAnson/markdownlint>`_ ：markdownlint のルールの一覧と説明。
- `Prettier <https://prettier.io/>`_ ：Prettier の公式サイト。
- `Pandoc <https://pandoc.org/>`_ ：Pandoc の公式サイト。マニュアルには、Pandoc が対応する Markdown の記法も説明されている。
- `Mermaid <https://mermaid.js.org/>`_ ：Mermaid の公式サイト。図の種類ごとの書き方を説明している。
- `markdown-it-py <https://markdown-it-py.readthedocs.io/en/latest/>`_ ：本書の表示結果の作成と、第 13 章のプログラムで使った Python のライブラリ。
- `mdit-py-plugins <https://mdit-py-plugins.readthedocs.io/en/latest/>`_ ：markdown-it-py の拡張機能を集めたライブラリ。
- `MyST Parser <https://myst-parser.readthedocs.io/en/latest/>`_ ：Sphinx で Markdown を使うための拡張機能。
