解析学入門
==========

本書は、エンジニアと工学系の大学生を対象とした解析学の入門書である。高校から大学初年次にかけて道具として使ってきた微分積分が「なぜ正しく動くのか」を、厳密な定義と証明によって理解することを目標とする。あわせて、数値計算の誤差や反復法の収束判定など、工学の現場で出会う問題との関係を、Python による数値実験を交えて説明する。
