はじめに
========

本書の目的
----------

微分や積分の計算方法は、高校や大学初年次の授業ですでに身に付けている読者が多いだろう。導関数を求め、置換積分を行い、テイラー展開で近似式を作る。こうした計算は、工学のあらゆる分野で日常的に使われている。

しかし、その計算が\ **なぜ正しいのか**、**どのような条件のもとで正しいのか**\ を説明できるだろうか。たとえば「微分と積分の順序は交換してよいか」「無限個の項の和を並べ替えてよいか」「数値計算の反復はいつ止めてよいか」といった問いに答えるには、計算の手順ではなく、その背後にある理論が必要になる。解析学は、極限という概念を厳密に定義し、その上に微分積分の理論を組み立て直す学問である。

本書の目的は、エンジニアと工学系の大学生が、解析学の基本的な考え方を身に付けることである。そのために、次の 3 点を重視する。

1. **厳密化の動機**：直感的な議論が破綻する具体例を示し、厳密な定義が必要な理由を納得できるようにする。
2. **工学との接続**：数値計算の誤差、近似の精度保証、反復法の収束判定など、実務で出会う問題と理論を結び付ける。
3. **計算による確認**：Python による数値実験を行い、定理の主張を数値やグラフで確かめられるようにする。

主要な定理には証明を付ける。証明は、定理の主張を覚えるためではなく、「どの仮定がどこで効いているのか」を理解するために読んでほしい。仮定を 1 つ外すと定理が成り立たなくなる例も、あわせて紹介する。

対象読者と前提知識
------------------

本書は、エンジニアと工学系の大学生を対象とする。前提とする知識は次のとおりである。

* 高校数学（数学 III まで）の微分積分の計算
* Python の基本的な文法（サンプルコードを読み、実行するため）
* 第 9 章と第 10 章では、行列とベクトルの基本的な計算（行列の積、行列式、内積、対称行列の固有値）

集合論や論理学の予備知識は仮定しない。証明に必要な論理の基本は、:doc:`appendix_logic`\ にまとめた。

エンジニアが解析学を学ぶ理由
----------------------------

解析学は純粋数学の一分野であるが、その考え方は工学の現場と深く関わっている。いくつかの例を挙げる。

* **0.1 を 10 回足しても 1 にならない。** Python で ``sum([0.1] * 10) == 1.0`` を評価すると ``False`` になる。計算機が扱う数は実数そのものではなく、有限個の有理数で実数を近似したものだからである。実数とは何か、計算機上の数とどう違うのかを第 1 章で扱う。
* **数値微分の刻み幅は小さければよいわけではない。**\ 導関数 :math:`f'(x)` を差分商 :math:`(f(x + h) - f(x))/h` で近似するとき、:math:`h` を小さくしすぎると、かえって誤差が大きくなる。極限 :math:`h \to 0` と丸め誤差のせめぎ合いを第 5 章で調べる。
* **無限級数は並べ替えると和が変わることがある。** :math:`1 - 1/2 + 1/3 - 1/4 + \cdots` は :math:`\log 2` に収束するが、項の順序を並べ替えると別の値に収束させることができる。有限和の常識が無限和では通用しない理由を第 3 章で説明する。
* **反復法の停止条件は収束を保証しない。**\ 「前回との差が十分小さくなったら停止する」という条件を満たしても、数列が収束しているとは限らない。収束とは何か、収束の速さをどう測るかを第 2 章で扱う。
* **関数列の極限と積分の順序は交換できるとは限らない。**\ 各点で収束する関数列でも、極限をとってから積分した値と、積分してから極限をとった値が一致しないことがある。フーリエ級数の部分和が不連続点の近くで行き過ぎを起こすギブズ現象も、収束の仕方が問題になる例である。関数列の収束にはいくつかの種類があり、その違いが重要になる。第 8 章で各点収束と一様収束を比較する。

いずれも、極限を正しく扱うことの重要性を示している。解析学の議論に慣れると、数値計算の結果を鵜呑みにせず、その精度や信頼性を自分で評価できるようになる。

本書の読み方
------------

記号と用語
^^^^^^^^^^

本書で使う記号は\ :doc:`appendix_symbols`\ に、主な用語は\ :doc:`glossary`\ にまとめた。特に断らない限り、自然数全体 :math:`\mathbb{N} = \{1, 2, 3, \ldots\}` は :math:`0` を含まないものとする。

定義・定理などの表示
^^^^^^^^^^^^^^^^^^^^

本文中の定義や定理は、種類ごとに色分けした枠で示す（:numref:`intro-tab-boxes`）。番号は章ごとに付け、「定義」「定理・命題・補題・系」「例」「問題」でそれぞれ独立に数える。たとえば「定理 5.2」は第 5 章の 2 番目の定理（または命題・補題・系）を表す。

.. list-table:: 枠の種類
   :name: intro-tab-boxes
   :header-rows: 1
   :widths: 25 75

   * - 枠の種類
     - 内容
   * - 定義
     - 用語や記号の意味を正確に定めるもの
   * - 公理
     - 証明なしに正しいと認める性質（第 1 章の実数の連続性）
   * - 定理・命題・補題・系
     - 証明によって正しさが保証される主張。命題は定理より小規模な主張、補題はほかの定理の証明に使う補助的な主張、系は直前の定理から直ちに導かれる主張である
   * - 証明
     - 直前の定理などの証明。末尾に ∎ を付ける
   * - 例
     - 定義や定理の具体例、反例
   * - 注意
     - 誤解しやすい点や補足事項
   * - 問題・略解
     - 各章末の演習問題とその略解

演習問題
^^^^^^^^

各章末に演習問題と略解を付けた。略解は方針と要点だけを示したものなので、細部は自分で補ってほしい。ε-δ 論法などの議論は、読むだけでなく自分で書いてみることで初めて身に付く。

読書案内
--------

本書は入門書であり、解析学のすべてを扱うわけではない。より詳しく学びたい読者のために、標準的な教科書を挙げる。

和書では、杉浦光夫『解析入門 I』 [Sugiura1980]_ と『解析入門 II』 [Sugiura1985]_ が、厳密さと網羅性の両面で定評のある教科書である。高木貞治『定本 解析概論』 [Takagi2010]_ は長く読み継がれてきた古典であり、小平邦彦『解析入門』 [Kodaira2003]_ は丁寧な説明で知られる。笠原晧司『微分積分学』 [Kasahara1974]_ は、ε-δ 論法の扱いが分かりやすい。斎藤毅『微積分』 [Saito2013]_ は、現代的な視点から簡潔にまとめられている。

洋書では、Rudin の *Principles of Mathematical Analysis* [Rudin1976]_ が世界的に標準的な教科書である。Abbott の *Understanding Analysis* [Abbott2015]_ は、定理の動機付けを重視した読みやすい入門書である。Tao の *Analysis I* [Tao2016a]_ と *Analysis II* [Tao2016b]_ は、自然数から出発して実数を構成するところまで丁寧に扱っている。Spivak の *Calculus* [Spivak2008]_ は、1 変数の微分積分を厳密に学ぶための定番である。

本書を読み終えた後に進む分野については、第 11 章（:doc:`further_study`）で紹介する。
