さらに学ぶために
================

本書では、実数の性質から出発して、数列・級数・連続性・微分・積分・関数列、そして多変数関数の微分積分までを、厳密な定義と証明に基づいて学んだ。本書の内容は、より進んだ解析学の諸分野の土台である。本章では、次に学ぶとよい分野を、それぞれが「何を解決するために」生まれたのかという観点から紹介する。工学の各分野で使われている手法の多くは、これらの理論に支えられている。

ルベーグ積分
------------

本書で学んだリーマン積分には、いくつかの弱点がある。たとえば、有理数で 1、無理数で 0 をとるディリクレの関数は、どの小区間でも上限が 1、下限が 0 なので、リーマン積分可能でない。より実用上重要なのは、極限と積分の交換の問題である。:doc:`function_sequences`\ で見たように、リーマン積分では極限と積分の交換に一様収束という強い条件が必要であり、各点収束する関数列の極限がリーマン積分可能かどうかも保証されない。

ルベーグ積分は、定義域ではなく値域を分割するという発想で積分を定義し直す。これにより、単調収束定理や優収束定理といった、各点収束だけで極限と積分を交換できる強力な定理が得られる。また、2 乗して積分可能な関数全体が「完備」な空間（コーシー列が必ず収束する空間）になり、関数解析やフーリエ解析の土台となる。確率論も、ルベーグ積分の言葉（測度論）で記述される。入門書としては [Ito1963]_ が定評がある。

関数解析
--------

関数解析は、関数を「無限次元のベクトル」とみなし、線形代数と解析学を融合させる分野である。ノルムをもつ完備なベクトル空間（バナッハ空間）や、内積をもつ完備なベクトル空間（ヒルベルト空間）の上で、線形作用素の性質を調べる。

工学では、偏微分方程式の解の存在や、有限要素法による近似解の誤差評価の理論が、関数解析の上に組み立てられている。また、:doc:`continuity`\ で証明し、:doc:`multivariable_differentiation`\ でも触れた縮小写像の原理は、バナッハ空間で一般的に成り立ち、方程式の解の存在や反復法の収束を示す基本的な道具となる。ルベーグ積分を学んだ後に進むとよい。

複素解析
--------

複素数を変数とする関数の微分積分を扱うのが複素解析である。複素数の意味で微分可能な関数（正則関数）は驚くほど強い性質をもち、1 回微分可能なら無限回微分可能で、さらにべき級数に展開できる。:doc:`taylor`\ で見た「無限回微分可能でもテイラー展開できない」実関数のような現象は、正則関数では起こらない。

工学では、留数定理による実積分の計算、ラプラス変換の逆変換、制御工学における安定判別（ナイキストの安定判別法）、2 次元の流体や静電場の解析（等角写像）などに使われる。教科書としては [SteinShakarchi2003b]_ がある。

フーリエ解析
------------

フーリエ解析は、関数を三角関数（正弦波）の重ね合わせとして表し、その性質を調べる分野である。:doc:`function_sequences`\ で紹介したフーリエ級数とギブズ現象は、その入り口にあたる。フーリエ級数がどのような意味で元の関数に収束するのか、という問題は 19 世紀の解析学の中心的な課題であり、リーマン積分や一様収束の概念は、この問題をきっかけに整備された。

信号処理、画像処理、振動解析、通信工学では、フーリエ変換と高速フーリエ変換（FFT）が欠かせない。偏微分方程式（熱方程式や波動方程式）を解く手法としても重要である。教科書としては [SteinShakarchi2003a]_ がある。

常微分方程式
------------

運動方程式、電気回路の方程式、化学反応の速度式など、物理現象の多くは常微分方程式で記述される。解を具体的な式で求められる方程式はごく一部であり、多くの場合は数値的に解くことになる。そのとき、そもそも解が存在するのか、ただ 1 つに定まるのかが問題となる。

解の存在と一意性を保証する基本定理（ピカール・リンデレフの定理）は、本書の内容で理解できる。その証明では、関数がリプシッツ連続であること（:doc:`continuity`）を仮定し、近似解の関数列を反復で作って、それが一様収束すること（:doc:`function_sequences`）を示す。さらに進むと、平衡点の安定性、周期解、カオスなどの理論があり、制御工学や力学系の解析に直結する。

ベクトル解析
------------

ベクトル解析は、ベクトル場（各点にベクトルが割り当てられたもの）の微分積分を扱う。勾配・発散・回転という微分演算と、線積分・面積分が中心となり、ガウスの発散定理やストークスの定理によって、領域内部の積分と境界上の積分が結び付けられる。これらは 1 変数の\ :ref:`微分積分学の基本定理 <ch07-thm-ftc>`\ の多次元版とみなせる。

電磁気学のマクスウェル方程式、流体力学の連続の式やナビエ・ストークス方程式、熱伝導方程式は、すべてベクトル解析の言葉で書かれている。本書の\ :doc:`multivariable_differentiation`\ と\ :doc:`multivariable_integration`\ が直接の前提となる。微分形式を用いてこれらの定理を統一的に扱う教科書として [Spivak1965]_ がある。

数値解析
--------

本書では各章で、浮動小数点数の誤差、反復法の収束、数値微分・数値積分の誤差、モンテカルロ積分などを数値実験で確かめた。これらを体系的に扱うのが数値解析である。方程式の数値解法、連立 1 次方程式の解法、補間と近似、数値積分、常微分方程式の数値解法（ルンゲ・クッタ法など）、偏微分方程式の数値解法（差分法・有限要素法）を、誤差と安定性の観点から学ぶ。

数値解析の理論は、本書で学んだテイラーの定理、平均値の定理、一様収束、実数の完備性（コーシー列が収束すること）などを道具として組み立てられている。教科書として [BurdenFaires2011]_ が、計算機で計算するうえでの実践的な注意点については [IriFujino1985]_ が参考になる。

おわりに
--------

解析学の厳密な議論は、一見すると工学の実務から遠いように思えるかもしれない。しかし、数値計算の結果を信頼してよいのか、近似はどの程度正確なのか、反復はいつ止めてよいのかといった問いに答えるには、本書で学んだ考え方が欠かせない。本書で身に付けた「定義に立ち返って考える」姿勢が、読者が専門分野の理論を学び、使いこなすうえでの助けとなれば幸いである。
