第 9 章 グラフ彩色
==================

大学の期末試験の日程を組むとき、同じ学生が受ける 2 つの科目は同じ時間帯に置けない。科目を頂点とし、共通の受験者がいる科目同士を辺で結ぶと、「隣接する頂点に異なる時間帯を割り当てる」問題になる。時間帯を色とみなせば、これはグラフの頂点を色分けする問題である。本章では、このグラフ彩色の理論とアルゴリズムを学ぶ。

頂点彩色と彩色数
----------------

.. admonition:: 定義 9.1（彩色・彩色数）

   グラフ :math:`G` の各頂点に色を 1 つずつ割り当て、隣接する頂点が異なる色になるようにしたものを :math:`G` の\ **彩色**\ （正確には頂点彩色）という。:math:`k` 色以下で彩色できるとき :math:`G` は **k-彩色可能**\ であるという。:math:`G` を彩色するのに必要な色の最小数を :math:`G` の\ **彩色数**\ といい、:math:`\chi(G)` と書く。

色は 1, 2, …… や 0, 1, …… の番号で表すことが多い。同じ色の頂点の集合は、どの 2 頂点も隣接しないので独立集合（第 5 章）である。つまり :math:`k`-彩色とは、頂点集合を :math:`k` 個の独立集合に分割することである。

いくつかのグラフの彩色数はすぐに分かる。

* 完全グラフ：:math:`\chi(K_n) = n`。すべての頂点が互いに隣接しているからである。
* 二部グラフ：辺を 1 本以上持てば :math:`\chi(G) = 2`。定義から 2 色で塗れる。逆に 2 色で塗れれば二部グラフである。
* 閉路グラフ：:math:`n` が偶数なら :math:`\chi(C_n) = 2`、奇数なら :math:`\chi(C_n) = 3`。奇数長の閉路は二部グラフでない（定理 5.1）。
* 木：頂点が 2 個以上あれば :math:`\chi = 2`。木は二部グラフである。

彩色数の下界と上界
------------------

彩色数を正確に求めるのは一般に難しいが、上下から評価することはできる。

**下界**\ ：:math:`G` の最大のクリーク（完全部分グラフ）の頂点数を\ **クリーク数** :math:`\omega(G)`、最大の独立集合の大きさを\ **独立数** :math:`\alpha(G)` という。クリークの頂点はすべて異なる色が必要なので :math:`\chi(G) \ge \omega(G)` である。また、各色の頂点は独立集合で高々 :math:`\alpha(G)` 個なので、:math:`\chi(G) \ge n / \alpha(G)` である。

ただし、:math:`\chi(G)` は :math:`\omega(G)` よりずっと大きくなりうる。三角形を含まない（:math:`\omega = 2`）のに彩色数がいくらでも大きいグラフが存在することが知られている。ピーターセングラフは三角形を含まないが、5-閉路を含むので 2 色では塗れない。

**上界**\ ：次の貪欲彩色の議論から、:math:`\chi(G) \le \Delta(G) + 1` が成り立つ。

.. admonition:: 定理 9.1

   任意のグラフ :math:`G` について、:math:`\chi(G) \le \Delta(G) + 1` である。

**証明**\ ：頂点を任意の順に 1 つずつ塗る。各頂点を塗るとき、すでに塗られた隣接頂点は高々 :math:`\Delta(G)` 個なので、それらが使っていない色が :math:`\Delta(G) + 1` 色の中に必ず残っている。□

連結グラフでこの上界が等号になるのは、完全グラフと奇数長の閉路の場合だけであることが知られている。

.. admonition:: 定理 9.2（ブルックスの定理）

   連結グラフ :math:`G` が完全グラフでも奇数長の閉路でもなければ、:math:`\chi(G) \le \Delta(G)` である。

たとえばピーターセングラフは :math:`\Delta = 3` で完全グラフでも閉路でもないので、ブルックスの定理から :math:`\chi \le 3` が分かる。5-閉路を含むことと合わせて :math:`\chi = 3` が確定する。

貪欲彩色
--------

定理 9.1 の証明で使った方法を\ **貪欲彩色**\ という。頂点を決まった順に調べ、隣接頂点が使っていない最小番号の色を割り当てる（サンプルコード ``coloring.py``）。

.. literalinclude:: ../examples/coloring.py
   :language: python
   :linenos:
   :pyobject: greedy_coloring
   :caption: 貪欲彩色

貪欲彩色は :math:`O(n + m)` 時間で動作するが、使う色の数は頂点の順序に大きく依存する。:numref:`fig-ch09-crown` の\ **王冠グラフ**\ は、上段の頂点 :math:`a_i` と下段の頂点 :math:`b_j` を :math:`i \ne j` のときに結んだ二部グラフであり、2 色で塗れる。ところが :math:`a_1, b_1, a_2, b_2, \ldots` の順に貪欲彩色を行うと、:math:`a_i` と :math:`b_i` はどちらも色 :math:`i` で塗られ、全部で :math:`n` 色を使ってしまう。

.. code-block:: text

   王冠グラフ (悪い順序): 4 色
   王冠グラフ (良い順序): 2 色

一方、上段をすべて塗ってから下段を塗れば 2 色で済む。実は、どんなグラフにも「その順序で貪欲彩色すると :math:`\chi(G)` 色で塗れる」順序が存在する（最適な彩色で色 1 の頂点、色 2 の頂点、…… の順に並べればよい）。しかし、その順序を見つけることは彩色数を求めることと同じくらい難しい。

実用上は、次数の大きい頂点ほど制約が厳しいので先に塗る\ **ウェルシュ・パウエル法**\ （largest first）などの経験的な順序がよく使われる。NetworkX の ``nx.greedy_color`` では、``strategy`` 引数で順序の決め方を選べる。

彩色数の計算
------------

グラフが 3 色で彩色可能かを判定する問題は NP 完全であることが知られている。したがって、彩色数を求める効率的なアルゴリズムは期待できない。小さなグラフなら、:math:`k = 1, 2, \ldots` について :math:`k` 色で塗れるかをバックトラックで調べればよい。

平面的グラフの彩色と四色定理
----------------------------

地図の国々を、国境を接する国が異なる色になるように塗り分ける問題を考える。国を頂点とし、国境を接する国同士を辺で結ぶと、平面的グラフの彩色問題になる（このグラフは第 8 章の双対グラフにあたる）。「どんな地図も 4 色で塗り分けられるか」という問いは 1852 年に提起され、長く未解決であった。

.. admonition:: 定理 9.3（四色定理）

   任意の平面的グラフは 4-彩色可能である。

四色定理は 1976 年にアッペルとハーケンによって証明された。証明は、約 2000 個の「避けられない配置」の一つ一つについて、それを含む最小の反例が存在しないことをコンピュータで検証するものであり、コンピュータを本質的に用いた初めての大定理の証明として議論を呼んだ。現在では、より整理された証明が知られており、定理証明支援系 Coq による形式的な検証も行われている。

4 色の証明は難しいが、6 色なら簡単に示せる。

.. admonition:: 定理 9.4（六色定理）

   任意の平面的グラフは 6-彩色可能である。

**証明**\ ：頂点数に関する帰納法で示す。頂点数が 6 以下なら明らかである。平面的グラフ :math:`G` には次数 5 以下の頂点 :math:`v` が存在する（第 8 章）。:math:`G - v` も平面的なので、帰納法の仮定により 6 色で塗れる。:math:`v` の隣接頂点は高々 5 個なので、それらが使っていない色が 6 色の中に残っており、それで :math:`v` を塗ればよい。□

この議論をもう少し工夫すると五色定理が証明できるが、ここでは省略する。

辺彩色
------

辺に色を割り当て、端点を共有する 2 辺が異なる色になるようにしたものを\ **辺彩色**\ という。必要な色の最小数を\ **辺彩色数**\ といい、:math:`\chi'(G)` と書く。辺彩色は、線グラフ :math:`L(G)` の頂点彩色と同じである（第 5 章）。

1 つの頂点に接続する辺はすべて異なる色が必要なので、:math:`\chi'(G) \ge \Delta(G)` である。頂点彩色とは異なり、辺彩色数はほぼ :math:`\Delta(G)` で決まる。

.. admonition:: 定理 9.5（ヴィジングの定理）

   任意の単純グラフ :math:`G` について、:math:`\Delta(G) \le \chi'(G) \le \Delta(G) + 1` である。

さらに、二部グラフでは :math:`\chi'(G) = \Delta(G)` が成り立つ（ケーニッヒの辺彩色定理）。それでも、一般のグラフで :math:`\chi'(G)` が :math:`\Delta(G)` と :math:`\Delta(G) + 1` のどちらであるかを判定する問題は NP 完全である。

辺彩色の典型的な応用は、総当たり戦の日程作成である。:math:`n` チームの総当たり戦は完全グラフ :math:`K_n` の辺（試合）で表され、同じ色の辺は 1 チームが 1 日に 1 試合しかしない「同じ日に行える試合」になる。:math:`n` が偶数なら :math:`\chi'(K_n) = n - 1` なので、:math:`n - 1` 日で全試合を終えられる。

彩色多項式
----------

グラフ :math:`G` を :math:`k` 色以下で彩色する方法の数を :math:`P(G, k)` と書く。たとえば完全グラフでは、1 つ目の頂点に :math:`k` 通り、2 つ目に :math:`k - 1` 通り、…… と塗れるので、次のようになる。

.. math::

   P(K_n, k) = k(k-1)(k-2) \cdots (k-n+1)

:math:`n` 頂点の木では、根を :math:`k` 通りに塗った後、各頂点を親と異なる :math:`k - 1` 通りに塗れるので、:math:`P(T, k) = k(k-1)^{n-1}` である。

一般のグラフでは、次の\ **削除縮約公式**\ が成り立つ。辺 :math:`e = uv` について、:math:`G - e` は :math:`e` を削除したグラフ、:math:`G / e` は :math:`e` を縮約した（:math:`u` と :math:`v` を 1 つの頂点にまとめた）グラフである。

.. math::

   P(G, k) = P(G - e, k) - P(G / e, k)

:math:`G - e` の彩色は、:math:`u` と :math:`v` が異なる色の彩色（これが :math:`G` の彩色）と、同じ色の彩色（これは :math:`G / e` の彩色と 1 対 1 に対応する）に分けられることから分かる。この公式を辺がなくなるまで繰り返し適用すると、:math:`P(G, k)` は :math:`k` の多項式であることが分かる。これを\ **彩色多項式**\ という。彩色数は :math:`P(G, k) > 0` となる最小の正整数 :math:`k` である。

.. literalinclude:: ../examples/coloring.py
   :language: python
   :linenos:
   :pyobject: chromatic_polynomial
   :caption: 削除縮約公式による彩色多項式の計算

.. code-block:: text
   :linenos:

   C4 の彩色多項式: k^4 - 4k^3 + 6k^2 - 3k
   K4 の彩色多項式: k^4 - 6k^3 + 11k^2 - 6k

:math:`C_4` の結果は :math:`(k-1)^4 + (k-1)` に等しく、:math:`K_4` の結果は :math:`k(k-1)(k-2)(k-3)` に等しい。:math:`k = 2` を代入すると、:math:`C_4` は 2 通り、:math:`K_4` は 0 通りとなり、彩色数がそれぞれ 2 と 4 であることと合っている。削除縮約公式は辺の数に関して指数時間かかるので、大きなグラフには使えない。

彩色の応用
----------

グラフ彩色は、「衝突するものを別のグループに分ける」問題に広く使われる。

.. list-table:: グラフ彩色の応用例
   :header-rows: 1
   :widths: 22 26 26 26

   * - 応用
     - 頂点
     - 辺
     - 色
   * - 試験の日程
     - 科目
     - 共通の受験者がいる
     - 時間帯
   * - レジスタ割り当て
     - 変数
     - 同時に生存している
     - CPU のレジスタ
   * - 周波数の割り当て
     - 無線局
     - 電波が干渉する
     - 周波数
   * - 数独
     - マス
     - 同じ行・列・ブロック
     - 数字 1～9

コンパイラのレジスタ割り当てでは、同時に値を保持する必要がある変数同士を結んだ\ **干渉グラフ**\ を作り、レジスタの数を色の数として彩色する。彩色できない場合は、一部の変数をメモリに退避させる。

まとめ
------

* 頂点彩色は頂点集合を独立集合に分割することであり、必要な色の最小数を彩色数 :math:`\chi(G)` という。
* :math:`\omega(G) \le \chi(G) \le \Delta(G) + 1` が成り立ち、ブルックスの定理により完全グラフと奇数長の閉路を除けば :math:`\chi(G) \le \Delta(G)` である。
* 貪欲彩色は高速だが、結果は頂点の順序に依存する。彩色数を正確に求める問題は NP 困難である。
* 平面的グラフは 4 色で彩色できる（四色定理）。6 色で十分であることは簡単に証明できる。
* 辺彩色数は :math:`\Delta(G)` または :math:`\Delta(G) + 1` である（ヴィジングの定理）。
* 彩色の方法の数は彩色多項式で表され、削除縮約公式で計算できる。
