第 1 章 グラフ理論とは
======================

鉄道の路線図、インターネットの接続、SNS の友人関係、ソフトウェアのモジュール間の依存関係は、見た目も分野もまったく異なる。しかし、いずれも「もの」と「もの同士のつながり」という共通の構造を持つ。この構造を抽象化した数学的対象が\ **グラフ**\ であり、グラフの性質を調べる数学の分野を\ **グラフ理論**\ という。本章では、グラフ理論の始まりとされる問題を紹介し、グラフが工学のどのような場面で使われるかを概観する。

なお、本書でいう「グラフ」は関数のグラフや棒グラフのような図表ではなく、頂点と辺からなる構造のことである。

ケーニヒスベルクの橋の問題
--------------------------

18 世紀のプロイセンの都市ケーニヒスベルク（現在のロシアのカリーニングラード）には、プレーゲル川が流れ、川の中洲と両岸を結ぶ 7 本の橋が架かっていた。町の人々の間では「7 本の橋をすべてちょうど 1 回ずつ渡って散歩することはできるか」という問題が話題になっていた。

1736 年、数学者オイラー（Leonhard Euler）はこの問題が不可能であることを示した。オイラーの着眼点は、陸地の形や橋の長さは問題に関係なく、「どの陸地とどの陸地が何本の橋で結ばれているか」だけが重要だという点にある。陸地を点、橋を線で表すと、:numref:`fig-ch01-konigsberg` のような図になる。

散歩の途中で、ある陸地を通過するときは「入る橋」と「出る橋」を 1 本ずつ使う。したがって、出発点と到着点を除くすべての陸地では、そこにつながる橋の本数が偶数でなければならない。ところが :numref:`fig-ch01-konigsberg` では、A に 3 本、B に 3 本、C に 5 本、D に 3 本と、4 つの陸地すべてに奇数本の橋がつながっている。出発点と到着点の 2 か所を除いても奇数の陸地が残るので、そのような散歩は存在しない。

この議論は、橋の配置を点と線の「つながり方」だけで捉えた点で画期的であった。これがグラフ理論の始まりとされる。この問題は第 7 章で一般化し、どのようなグラフで「すべての線をちょうど 1 回ずつ通る道」が存在するかを完全に特徴付ける。

グラフで表せるもの
------------------

グラフは、対象とその間の関係を扱う多くの問題の共通言語になる。:numref:`table-ch01-applications` に、工学で現れる例を示す。

.. _table-ch01-applications:

.. list-table:: グラフで表せる対象の例
   :header-rows: 1
   :widths: 22 26 26 26

   * - 分野
     - 頂点
     - 辺
     - 典型的な問題
   * - 交通
     - 駅・交差点
     - 線路・道路
     - 最短経路、渋滞の解析
   * - 通信ネットワーク
     - ルーター・ホスト
     - 通信回線
     - 経路制御、障害に強い構成
   * - ソフトウェア
     - モジュール・タスク
     - 依存関係
     - ビルド順序の決定、循環依存の検出
   * - 電気回路
     - 節点
     - 素子
     - 回路方程式の立式
   * - SNS
     - ユーザー
     - フォロー・友人関係
     - 影響力の大きい人物の発見、コミュニティ検出
   * - Web
     - ページ
     - リンク
     - ページの重要度の評価（PageRank）
   * - スケジューリング
     - 授業・作業
     - 同時に実施できない関係
     - 必要な時間枠の数の最小化（彩色）
   * - 割り当て
     - 作業者・仕事
     - 担当できる関係
     - 最大数の割り当て（マッチング）

これらの問題は、グラフとして定式化すると、分野によらず同じ理論とアルゴリズムで扱える。たとえばカーナビの経路探索とネットワークのパケット経路制御は、どちらも第 12 章の最短経路問題に帰着する。

本書の構成
----------

本書は次の 4 部からなる。

* **第 I 部 基礎**\ （第 2 章～第 5 章）：グラフの定義と用語、コンピュータ上での表現方法、道と連結性、代表的なグラフの種類を学ぶ。以降のすべての章の土台になる。
* **第 II 部 構造**\ （第 6 章～第 10 章）：木、オイラー路とハミルトン路、平面グラフ、彩色、マッチングという、グラフ理論の古典的な主題を扱う。
* **第 III 部 アルゴリズム**\ （第 11 章～第 13 章）：探索、最短経路、ネットワークフローという、実用上特に重要なアルゴリズムを扱う。
* **第 IV 部 発展**\ （第 14 章～第 16 章）：隣接行列などの行列の固有値を使ってグラフを調べる代数的グラフ理論と、現実の大規模ネットワークの性質を調べるネットワーク科学を紹介する。

第 I 部を読んだ後は、関心のある章から読んでもよい。ただし、第 II 部と第 III 部には互いに参照する箇所がある。たとえば第 6 章のプリム法は第 12 章のダイクストラ法と、第 10 章のマッチングは第 13 章のネットワークフローと関係が深い。

本書の進め方と記法
------------------

各章では、まず定義と定理を述べ、図で直観的な意味を説明する。証明は、短く理解の助けになるものは本文に載せ、長いものは主張と意味の説明にとどめる。主要なアルゴリズムは Python で実装し、実行結果を確認する。

本書で用いる主な記法を :numref:`table-ch01-notation` に示す。一覧は付録 A にもまとめてある。

.. _table-ch01-notation:

.. list-table:: 本書の主な記法
   :header-rows: 1
   :widths: 30 70

   * - 記法
     - 意味
   * - :math:`G = (V, E)`
     - 頂点集合 :math:`V`、辺集合 :math:`E` のグラフ
   * - :math:`n = |V|`, :math:`m = |E|`
     - 頂点数、辺数
   * - :math:`uv` または :math:`\{u, v\}`
     - 頂点 :math:`u` と :math:`v` を結ぶ無向辺
   * - :math:`(u, v)`
     - :math:`u` から :math:`v` への有向辺
   * - :math:`\deg(v)`
     - 頂点 :math:`v` の次数
   * - :math:`N(v)`
     - 頂点 :math:`v` に隣接する頂点の集合
   * - :math:`d(u, v)`
     - 頂点 :math:`u` と :math:`v` の距離

アルゴリズムの計算量は :math:`O` 記法で表す。:math:`O(f(n))` は、入力の大きさ :math:`n` が十分大きいとき、実行時間が定数倍を除いて :math:`f(n)` 以下で抑えられることを意味する。グラフのアルゴリズムでは、頂点数 :math:`n` と辺数 :math:`m` の両方を使って :math:`O(n + m)` のように表すことが多い。

Python の環境
-------------

本書のサンプルコードは Python 3.10 以降を想定しており、Python 3.14 と NetworkX 3.6 で動作を確認している。標準ライブラリに加えて、次のパッケージを使う。

.. list-table:: 使用するパッケージ
   :header-rows: 1
   :widths: 25 75

   * - パッケージ
     - 用途
   * - NetworkX
     - グラフの作成・解析のライブラリ。本書では自作した実装の結果を照合するために使う。
   * - NumPy
     - 行列の計算。隣接行列や固有値の計算に使う。
   * - SciPy
     - NetworkX の一部の関数（PageRank、全域木の数え上げなど）が内部で使う。

これらは次のコマンドでインストールできる。

.. code-block:: text
   :linenos:

   pip install networkx numpy scipy

NetworkX を使えば、本書で扱うアルゴリズムの多くは 1 行で呼び出せる。それでも本書では、原理を理解するためにアルゴリズムを標準ライブラリだけで実装し、NetworkX は答え合わせに使う。サンプルコードの一覧とダウンロードリンクは付録 D にある。

NetworkX でグラフを作り、頂点と辺の数を調べる最小限の例を次に示す。

.. code-block:: python
   :linenos:

   import networkx as nx

   g = nx.Graph()  # 無向グラフ
   g.add_edges_from([("A", "B"), ("B", "C"), ("C", "A"), ("C", "D")])
   print(g.number_of_nodes(), g.number_of_edges())  # 4 4
   print(list(g.neighbors("C")))  # ['B', 'A', 'D']
   print(dict(g.degree()))  # {'A': 2, 'B': 2, 'C': 3, 'D': 1}

まとめ
------

* グラフは「もの」と「つながり」を抽象化した構造であり、交通、通信、ソフトウェア、SNS など多くの分野に現れる。
* グラフ理論は、オイラーによるケーニヒスベルクの橋の問題の解決に始まる。
* 本書では、定義と定理を図で説明し、アルゴリズムを Python で実装して確かめる。
