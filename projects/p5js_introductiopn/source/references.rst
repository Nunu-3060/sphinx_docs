参考文献
========

本書の執筆にあたって参照した資料と、さらに学ぶための資料を示します。

p5.js
-----

* `p5.js 公式サイト <https://p5js.org/>`__：p5.js の公式サイト。
* `p5.js リファレンス <https://p5js.org/reference/>`__：すべての関数と変数の説明と使用例。
* `p5.js チュートリアル <https://p5js.org/tutorials/>`__：公式のチュートリアル集。
* `p5.js Web Editor <https://editor.p5js.org/>`__：ブラウザーで使える公式のエディター。
* `p5.js の GitHub リポジトリ <https://github.com/processing/p5.js>`__：ソースコードと変更履歴。
* `p5.js-compatibility <https://github.com/processing/p5.js-compatibility>`__：1.x と 2.x の違いと、互換性アドオンの説明。

JavaScript
----------

* `MDN Web Docs：JavaScript <https://developer.mozilla.org/ja/docs/Web/JavaScript>`__：JavaScript の言語仕様と標準ライブラリの解説。
* `MDN Web Docs：async function <https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Statements/async_function>`__：``async`` と ``await`` の解説。

クリエイティブコーディング
--------------------------

* Daniel Shiffman, `The Nature of Code <https://natureofcode.com/>`__：ベクトル、力、パーティクルなど、自然現象のシミュレーションを p5.js で解説した書籍。Web 上で全文を読める。
* `Processing <https://processing.org/>`__：p5.js の元になった Java ベースのプログラミング環境。
* `py5 <https://py5coding.org/>`__：Processing を Python から使うためのライブラリ。
