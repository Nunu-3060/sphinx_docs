はじめに
========

本書の目的
----------

現在のソフトウェアの多くは、ネットワークを介して動いています。Web ブラウザーはサーバーからページを取得し、スマートフォンのアプリは API を呼び出し、サーバー側のアプリケーションはデータベースやキャッシュ、別のサービスと通信しています。そして、多くのサービスは 1 台のコンピューターではなく、ネットワークでつながった多数のコンピューターの上で動く分散システムとして作られています。

ネットワークや分散システムの仕組みは、普段はライブラリやクラウドサービスに隠されています。しかし、次のような場面では、その仕組みの知識が直接役に立ちます。

* 「接続がタイムアウトした」「名前解決に失敗した」といったエラーの原因を切り分けるとき
* 通信が遅い原因が、帯域幅、遅延、サーバーの処理のどこにあるのかを見極めるとき
* リトライを実装したら、同じ注文が 2 回処理されてしまったとき
* データベースのレプリカから、書き込んだはずのデータが読めなかったとき
* 一部のサーバーが故障しても止まらないシステムを設計するとき

本書の目的は、こうした場面で「ネットワークの中で何が起きているか」「複数のコンピューターの間で何が起こり得るか」を想像できるようになるための基礎を身に付けることです。ネットワーク機器の設定や分散データベースの実装そのものではなく、ネットワークの上でソフトウェアを作り、運用するエンジニアにとって必要な知識を中心に扱います。

対象読者
--------

本書は次のような読者を想定しています。

* 何らかのプログラミング言語でプログラムを書いた経験があります。
* Web アプリケーションやサーバーアプリケーションを使ったり作ったりした経験はありますが、ネットワークや分散システムを体系的に学んだことはありません。

Python の基本的な文法を知っていると、サンプルコードを読みやすくなります。

本書の構成
----------

本書は 2 部で構成されています。

第 1 部ではネットワークを扱います。データがどのような階層を通ってケーブルや電波を流れ、相手のプログラムに届くのかを、下の層から順に説明します。その上で、ソケットを使ったプログラミングと、ネットワークの障害の調べ方を説明します。

第 2 部では分散システムを扱います。第 1 部で見るとおり、ネットワークを介した通信は遅れたり、失われたり、順序が入れ替わったりします。また、通信相手のコンピューターは予告なく停止します。第 2 部では、こうした不確実な環境の上で、複数のコンピューターが協調して正しく動くための考え方と技術を説明します。

サンプルコードの使い方
----------------------

本書のサンプルコードはすべて Python で書かれており、Python 3.10 以降の標準ライブラリだけで動作します。サンプルコードの一覧は「:doc:`appendix_examples`」にあり、そこから各ファイルをダウンロードできます。

サンプルコードは、次のようにコマンドラインから実行します。

.. code-block:: console
   :linenos:

   $ python transfer_time.py

サンプルコードには、次の 2 種類があります。

* ネットワークを実際に使うもの：ソケット、HTTP、DNS、TLS などを Python の標準ライブラリから使い、通信の様子を観察します。多くは自分のコンピューターの中（localhost）だけで完結します。
* 仕組みを再現するもの：TCP の輻輳制御、論理時計、クォーラム、Raft のリーダー選出などを、1 つのプロセスの中で動く小さなシミュレーターとして実装します。

``dns_query.py`` と ``tls_inspect.py`` の 2 つは、インターネットに接続できる環境で実行してください。それ以外のサンプルコードは、インターネットに接続していなくても動作します。

本文に示すサンプルコードの実行結果は、Windows 11 上の Python 3.14 で実行したものです。ポート番号や処理時間など、実行環境や実行のたびに変わる値があります。

表記について
------------

本書では次の表記を用います。

* コマンドの実行例では、行頭の ``$`` はシェルのプロンプトを表します。入力するのは ``$`` より後の部分です。Windows のコマンドプロンプトの場合は ``>`` で表します。
* 例として示す IP アドレスやドメイン名には、文書用に予約されたもの（``192.0.2.0/24``、``198.51.100.0/24``、``203.0.113.0/24``、``2001:db8::/32``、``example.com`` など）を使います。
* 通信速度の単位は、ビット毎秒（bps）を使います。1 Mbps は 1,000,000 bps です。データの大きさはバイトで表し、1 バイトは 8 ビットです。
* 重要な用語は「:doc:`appendix_glossary`」にまとめています。
