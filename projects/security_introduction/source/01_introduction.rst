はじめに
========

本書の目的
----------

ソフトウェアの脆弱性は、特別な攻撃技術よりも、開発者が「知らなかった」ことから生まれる場合がほとんどです。例えば、利用者の入力を文字列連結で SQL 文に埋め込む、パスワードを高速なハッシュ関数でそのまま保存する、クラウドのストレージを誤って公開設定にする、といった誤りです。いずれも、仕組みを知っていれば防げます。

本書を読み終えると、日々の設計・実装・運用の中で、次のことができるようになります。

* よく知られた脅威と脆弱性の仕組みを説明できます。
* 自分の担当するシステムで、どこが危ないかの見当を付けられます。
* 標準的な対策を選び、正しく実装できます。
* より詳しい情報を、信頼できる情報源から調べられます。

対象読者と前提知識
------------------

本書は、セキュリティを専門としないソフトウェアエンジニアを対象としています。次の知識があることを前提とします。

* Python の基本的な文法を読めること
* HTTP、HTML、SQL の基本的な仕組みを知っていること
* コマンドラインでプログラムを実行できること

暗号やネットワークの専門知識は前提としません。必要な事項は各章で説明します。

     - argon2-cffi、bandit、cryptography、Flask、pip-audit、PyJWT

多くのサンプルは標準ライブラリだけで動作します。追加ライブラリが必要なサンプルは、ファイル冒頭の説明と本文に明記しています。追加ライブラリは、次のコマンドでまとめて導入できます。

.. code-block:: console
   :linenos:

   python -m pip install -r requirements.txt

requirements.txt は、サンプルコードと同じ場所にあります。サンプルコードの一覧とダウンロード方法は、付録の\ :doc:`examples`\ を参照してください。

.. note::

   ライブラリは仮想環境に導入することをお勧めします。仮想環境は ``python -m venv .venv`` で作成できます。

倫理と法令
----------

本書では、脆弱性の仕組みを理解するために、攻撃の手順を説明したり、攻撃を再現するコードを示したりします。これらは防御のための知識です。次の点を必ず守ってください。

* 攻撃の手法を試すのは、自分が管理する環境か、管理者から書面で許可を得た環境に限ってください。
* 他人のシステムの脆弱性を、許可なく調査しないでください。善意であっても、法令に違反する場合があります。
* 偶然に脆弱性を見つけた場合は、それ以上の調査をやめ、:doc:`12_operations`\ で説明する窓口に報告してください。

日本では、主に次の法令が関係します。

.. list-table:: 主な関係法令
   :header-rows: 1
   :widths: 35 65

   * - 法令
     - 概要
   * - 不正アクセス禁止法
     - 他人の ID とパスワードを無断で使ってログインする行為や、アクセス制御の不備を突いて保護された機能を利用する行為を禁止しています。他人の ID とパスワードを無断で第三者に提供する行為なども処罰の対象です。
   * - 刑法（不正指令電磁的記録に関する罪）
     - 正当な理由なく、他人のコンピューターで意図に反する動作をさせるプログラム（いわゆるコンピューターウイルス）を作成、提供、取得、保管する行為を処罰の対象としています。
   * - 刑法（電子計算機損壊等業務妨害罪）
     - コンピューターやデータを壊したり、不正な指令を与えたりして業務を妨害する行為を処罰の対象としています。サービスを停止させる攻撃もこれに当たる場合があります。

組織として守るべき法令や規格は、:doc:`02_basic_concepts`\ で説明します。
