ウイスキーとは
==============

ウイスキーの定義
----------------

ウイスキーは、大麦・トウモロコシ・ライ麦・小麦などの穀物を原料とし、糖化・発酵・蒸留したうえで木の樽で熟成させた蒸留酒である。主な特徴は次の 3 つである。

* **原料が穀物であること**：ブドウなどの果実を原料とするブランデーや、サトウキビを原料とするラムと異なる。
* **蒸留酒であること**：発酵させた液体を蒸留し、アルコール分を濃縮する。瓶詰めの時点のアルコール度数は 40 % 以上のものが多い。
* **木の樽で熟成させること**：琥珀（こはく）色の色合いや、バニラ・ドライフルーツのような香りの多くは、樽の中で過ごす年月から生まれる。

大まかにいえば、ウイスキーの製法は「ホップを使わないビールのような液体を造り、それを蒸留して樽で寝かせる」ものである。製造工程の詳細は\ :doc:`02_how_whisky_is_made`\ で説明する。

Whisky と Whiskey
-----------------

英語の綴りには Whisky と Whiskey の 2 通りがある。一般に、スコットランド・カナダ・日本では Whisky、アイルランドとアメリカでは Whiskey と綴ることが多い。ただし、これは慣習であり、アメリカでも Whisky と綴る銘柄がある（例：メーカーズマーク）。本書では、日本語の表記として「ウイスキー」を用いる。

名前の由来
----------

ウイスキーの語源は、ゲール語（スコットランドやアイルランドの古い言語）で「命の水」を意味する「ウシュクベーハ（uisge beatha）」である。これは、中世ヨーロッパで蒸留酒を指したラテン語「アクア・ヴィテ（aqua vitae、命の水）」を訳した言葉である。ウシュクベーハは、時代とともに「ウスケボー」「ウイスキー」のように短く変化していった。

法律上の定義
------------

何をウイスキーと呼べるかは、国ごとに法律で決められている。主な産地では、穀物を原料とすること、木の樽で一定期間以上熟成させること、瓶詰めの時点のアルコール度数が一定以上であることなどが定められている。たとえば、スコッチウイスキーはスコットランドの法令により、スコットランド国内でオーク樽を使って 3 年以上熟成させる必要がある。各産地の定義は\ :doc:`04_regions`\ で比較する。

日本の酒税法では、ウイスキーは「発芽させた穀類（麦芽）と水を原料として糖化・発酵させたものを蒸留したもの」などと定義されている。ただし、酒税法には樽での熟成期間の定めがない。また、ウイスキー原酒にアルコールやスピリッツなどを加えたものでも、ウイスキー原酒のアルコール分が全体のアルコール分の 10 % 以上であればウイスキーとして扱われる。このため、日本の業界団体は 2021 年に「ジャパニーズウイスキー」と表示するための自主基準を定めた（\ :doc:`04_regions`\ を参照）。
