はじめに
==========================================

本書の目的
------------------------------------------

本書の目的は、読者が Claude の全体像を把握し、次の 3 つの使い方のいずれでも実務に取りかかれる状態になることです。

* Web 画面やデスクトップアプリで Claude と対話し、調査や文書作成に使います
* Claude API を呼び出すプログラムを書き、自社のアプリケーションに組み込みます
* Claude Code を使い、コードの調査、実装、テストといった開発作業を任せます

対象読者と前提知識
------------------------------------------

本書は、プログラムを書くエンジニアを主な読者として想定しています。前提知識は次のとおりです。

* Python の基本的な文法（関数、クラス、型ヒント、例外処理）を理解しています
* コマンドライン（ターミナル）で基本的な操作ができます
* HTTP や JSON の概要を知っています

生成 AI や機械学習の専門知識は必要ありません。必要な用語は本文中で説明し、:doc:`glossary`\ にもまとめています。

本書の構成
------------------------------------------

本書は、使い方の難易度が低いものから高いものへと段階的に進むように構成しています。

.. list-table:: 各章の内容
   :header-rows: 1
   :widths: 30 70

   * - 章
     - 内容
   * - :doc:`overview`
     - Claude とは何か、モデルの種類と選び方、利用経路
   * - :doc:`chat`
     - claude.ai とデスクトップアプリでの対話の基本
   * - :doc:`prompting`
     - 意図どおりの出力を得るための指示の書き方
   * - :doc:`api_basics`
     - Python SDK を使った API 呼び出しの基本、エラー処理、トークンと料金
   * - :doc:`api_advanced`
     - 思考と effort、構造化出力、画像と PDF、プロンプトキャッシュ、バッチ処理
   * - :doc:`tool_use`
     - Claude に外部の関数やサービスを呼び出させる仕組み
   * - :doc:`mcp`
     - ツール連携の標準規格 Model Context Protocol と MCP サーバーの作り方
   * - :doc:`claude_code`
     - ターミナルで動くコーディングエージェント Claude Code の使い方
   * - :doc:`agents`
     - 自律的に作業を進めるエージェントの設計と、構築手段の選び方
   * - :doc:`operations`
     - 品質評価、セキュリティ、コスト管理など本番運用で注意すべき点

API を使わず対話だけで利用する読者は、:doc:`overview`、:doc:`chat`、:doc:`prompting`\ を読めば十分です。Claude Code だけを使いたい読者は、これらに加えて :doc:`claude_code`\ を読んでください。

サンプルコード
------------------------------------------

本書で使うサンプルコードは\ :doc:`examples`\ からダウンロードできます。サンプルコードの実行環境は次のとおりです。

* Python 3.10 以上
* ``anthropic`` パッケージ 1.11 以上（Claude API の公式 Python SDK）
* ``mcp`` パッケージ 2.3 以上（:doc:`mcp`\ のサンプルのみ）

サンプルコードは、どれも flake8 と mypy（strict モード）で違反が検出されないことを確認しています。

本書の表記
------------------------------------------

* ``claude-opus-5-5`` のような等幅の文字列は、コード、コマンド、モデル ID、パラメーター名を表します。
* 料金は米ドルで、特に断りがない限り 100 万トークンあたりの金額です。
* モデルの種類、料金、機能は頻繁に更新されます。本書の内容は 2026 年 10 月時点の情報に基づいています。最新の情報は\ :doc:`references`\ に挙げた公式ドキュメントで確認してください。
