用語集
==========================================

.. glossary::

   CLAUDE.md
      Claude Code にプロジェクトの情報や作業のルールを伝えるためのファイル。プロジェクト直下などに置いたものは、セッションの開始時に自動的に読み込まれます。

   effort
      思考の深さと応答の丁寧さを調整する API のパラメーター。``low``、``medium``、``high``、``xhigh``、``max`` の段階があります。

   few-shot プロンプト
      入力と出力の例をいくつか含めたプロンプト。出力の形式や判断の基準を例で示します。

   MCP
      Model Context Protocol の略。AI アプリケーションと外部のツールやデータを接続するための標準規格。

   Messages API
      メッセージを送って Claude の応答を受け取る API。Claude API の中心となるエンドポイント（``POST /v1/messages``）。

   エージェント
      目標を与えられ、どのツールをどの順で使うかを自ら判断しながら作業を進める仕組み。

   権限モード
      Claude Code が利用者の許可なしにどこまで操作してよいかを決める設定。

   構造化出力
      応答が指定した JSON スキーマに必ず従うようにする機能。

   コンテキストウィンドウ
      モデルが 1 回の処理で扱える入力と出力の合計トークン数の上限。

   コンテンツブロック
      API の入出力を構成する単位。テキスト、画像、思考、ツールの呼び出し、ツールの結果などの種類があります。

   サブエージェント
      メインのエージェントから作業を任され、独立したコンテキストで作業して結果だけを返すエージェント。

   システムプロンプト
      会話全体に適用される役割や方針を指定する入力。API では ``system`` 引数に渡します。

   スキル
      特定の作業の手順や知識をまとめたもの。Claude は関連する作業のときに読み込んで利用します。

   ステートレス
      サーバーが過去のやり取りを記憶しない性質。Messages API では、会話を続けるために履歴を毎回送ります。

   ストリーミング
      生成された応答を、完成を待たずに少しずつ受け取る方式。

   大規模言語モデル
      大量のテキストで訓練され、テキストの続きを予測することで文章を生成するモデル。LLM（Large Language Model）とも呼びます。

   ツール利用
      Claude に外部の関数やサービスを呼び出させる仕組み。関数呼び出し（function calling）とも呼びます。

   適応的思考
      回答の前に行う検討の量を、問題の難しさに応じてモデル自身が決める仕組み。

   トークン
      モデルがテキストを処理する単位。料金や入出力の上限はトークン数で決まります。

   ハルシネーション
      モデルが、もっともらしいが事実と異なる内容を生成すること。

   評価
      テストケースに対してプロンプトやモデルを実行し、品質を数値で測る仕組み。eval とも呼びます。

   フック
      Claude Code の動作の特定の時点で、指定したコマンドを自動的に実行する仕組み。

   プロンプト
      モデルに与える指示や入力の文章。

   プロンプトインジェクション
      モデルが処理する外部の内容に指示を紛れ込ませ、意図しない動作に誘導する攻撃。

   プロンプトキャッシュ
      入力の共通部分の処理結果をサーバーに一時保存して再利用し、料金と応答時間を削減する機能。
