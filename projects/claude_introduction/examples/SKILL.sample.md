# リリースノートの作成手順

1. `git log --oneline <前回のタグ>..HEAD` で対象のコミットを一覧にする
2. コミットを「新機能」「改善」「不具合修正」「その他」に分類する
3. 利用者に影響のない変更 (リファクタリング、テストのみの変更) は省く
4. 下記の形式で `docs/release-notes.md` の先頭に追記する

## 形式

    ## v<バージョン> (<リリース日>)

    ### 新機能
    - ...

    ### 不具合修正
    - ...
