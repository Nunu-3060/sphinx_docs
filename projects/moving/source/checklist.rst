==============

スケジュールを作成するプログラム
--------------------------------

引越し日を入力すると、各項目を行う日付を計算して一覧にする Python のプログラムを用意しました。次のリンクからダウンロードできます。

* :download:`moving_schedule.py <../examples/moving_schedule.py>`

使い方
~~~~~~

Python 3.9 以降がインストールされたパソコンで、コマンドプロンプトなどから次のように実行します。引越し日は「年-月-日」の形式で指定します。``--csv`` とファイル名を付けると、表計算ソフトで開ける CSV ファイルも保存します。

.. code-block:: text
   :linenos:

   python moving_schedule.py 2026-11-15
   python moving_schedule.py 2026-11-15 --csv schedule.csv

引越し日を 2026 年 11 月 15 日とした場合、次のように表示されます（一部を省略しています）。

.. code-block:: text
   :linenos:

   引越し日: 2026-11-15
   [ ] 2026-09-16(水)   60 日前 [住まい] 新居を探し始める
   [ ] 2026-10-01(木)   45 日前 [住まい] 今の住まいの解約を管理会社・大家に連絡する
   [ ] 2026-10-01(木)   45 日前 [業者] 引越し業者から見積もりを取る(3 社程度)
   [ ] 2026-10-06(火)   40 日前 [業者] 引越し業者を決めて予約する

やることの一覧は、プログラムの中の ``TASKS`` に書かれています。項目を追加したり、日数を変えたりして、自分の予定に合わせて使ってください。
