引越し当日にすること
====================

引越し当日は、旧居での搬出と明け渡し、新居での搬入と確認を行います。作業が予定どおり進むよう、立ち会う人と役割を事前に決めておきます。

旧居での作業
------------

#. 引越し業者の到着前に、通路や玄関の周りを片付けておきます。
#. 作業の開始前に、運んでほしい物、運ばない物、壊れやすい物を作業員に伝えます。
#. 搬出が終わったら、押し入れや収納、ベランダなどに荷物が残っていないか確認します。
#. 部屋を掃除し、電気のブレーカーを落とし、水道の元栓を閉めます。管理会社などから指示がある場合は、それに従ってください。
#. 賃貸住宅の場合は、管理会社または大家と退去の立会いを行い、鍵を返却します。

退去の立会いでは、部屋の傷や汚れについて、誰が修繕の費用を負担するかを確認します。その場で納得できない点があるときは、署名を急がず、説明を求めてください（:doc:`trouble` を参照）。

新居での作業
------------

#. 搬入の前に、部屋の傷や汚れを確認し、スマートフォンなどで写真を撮っておきます。退去時の :term:`原状回復` をめぐるトラブルを防ぐのに役立ちます。
#. 家具や家電を置く場所を作業員に伝えます。
#. 搬入が終わったら、荷物の数と、家具や建物に傷がないかを作業員と一緒に確認します。
#. 電気のブレーカーを上げ、水道の元栓を開けます。
#. 予約した時刻にガス会社の開栓に立ち会います。
#. 料金を当日支払う契約の場合は、支払いをして領収書を受け取ります。

.. tip::

   冷蔵庫は、運んだ直後に電源を入れても使えますが、機種によっては数時間おいてから電源を入れるよう取扱説明書で求めているものがあります。取扱説明書を確認してください。

近所へのあいさつ
----------------

近所へのあいさつは義務ではありませんが、生活を始めるうえで良い関係を築くきっかけになります。行う場合は、引越し当日から 1 週間以内をめどに、両隣と上下の部屋の方などにあいさつするとよいでしょう。旧居でも、作業の騒音などでお世話になった方へ、引越しの前にあいさつしておくと丁寧です。
