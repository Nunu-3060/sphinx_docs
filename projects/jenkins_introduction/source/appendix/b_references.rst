==========
参考資料
==========

公式ドキュメント
====================

* `Jenkins User Documentation <https://www.jenkins.io/doc/>`_ ── Jenkins 公式のユーザー向けドキュメント全般。
* `Pipeline Syntax Reference <https://www.jenkins.io/doc/book/pipeline/syntax/>`_ ── Declarative/Scripted Pipeline の構文リファレンス。
* `Pipeline Steps Reference <https://www.jenkins.io/doc/pipeline/steps/>`_ ── インストール済みプラグインごとの Pipeline ステップ一覧。
* `Using a Jenkinsfile <https://www.jenkins.io/doc/book/pipeline/jenkinsfile/>`_ ── Jenkinsfile の基本的な使い方。
* `Extending with Shared Libraries <https://www.jenkins.io/doc/book/pipeline/shared-libraries/>`_ ── 共有ライブラリの公式ガイド。
* `Jenkins Configuration as Code Plugin <https://www.jenkins.io/projects/jcasc/>`_ ── JCasC の公式プロジェクトページ。

Groovy 関連
====================

* `Apache Groovy Documentation <https://groovy-lang.org/documentation.html>`_ ── Groovy 言語そのものの公式ドキュメント。

本書との対応
====================

本書の各章で扱った内容の、より詳細な公式情報が必要な場合は、以下を目安に参照してください。

* Declarative Pipeline の各ディレクティブの網羅的な仕様（:doc:`../chapters/05_pipeline_syntax`）→ Pipeline Syntax Reference
* 共有ライブラリのディレクトリ構成の詳細（:doc:`../chapters/08_shared_libraries`）→ Extending with Shared Libraries
* Jenkins 自体の設定のコード化（:doc:`../chapters/10_best_practices`）→ Jenkins Configuration as Code Plugin
