Python 入門
===========

本資料は、プログラミング未経験者を対象とした Python の入門資料である。環境構築から基本文法、関数、データ構造、例外処理、クラスまでを、実際に動かせるサンプルコードとともに解説する。本資料は Python 3.11 以降を対象としており、サンプルコードは Python 3.14 で動作を確認している。

各章のサンプルコードは、本文中のファイル名のリンクからダウンロードできる。手元の環境にコードを保存し、実際に実行しながら読み進めるとよい。
