第 5 章 制御構文
================

条件分岐（if 文）
-----------------

``if`` 文を使うと、条件に応じて実行する処理を切り替えられます。条件が真のときに実行したい処理は、インデント（字下げ）して記述します。

.. code-block:: python
   :linenos:

   score = 85

   if score >= 80:
       print("合格です。")
   elif score >= 60:
       print("再試験です。")
   else:
       print("不合格です。")

``if`` の後ろの条件が真であれば、その直後のブロックが実行されます。条件が偽の場合は、``elif`` の後ろの条件が順番に判定され、最初に真になったブロックだけが実行されます。``else`` のブロックは、どの条件も真にならなかった場合に実行されます。``elif`` と ``else`` は必要な場合にだけ書けばよく、``elif`` は複数並べることもできます。上記のコードでは ``score`` が 85 であり、最初の条件 ``score >= 80`` が真になるため、「合格です。」と表示されます。

Python では、``{`` や ``}`` の代わりにインデントによって処理のまとまり（ブロック）を表します。インデントの幅がそろっていないと、エラーが発生する点に注意してください。インデントの幅は、半角空白 4 つを使うのが Python の標準的な書き方です。タブ文字を使うこともできますが、半角空白とタブ文字を混在させるとエラーの原因になるため、どちらか一方に統一してください。本資料のサンプルコードは、すべて半角空白 4 つでインデントしています。

条件式（三項演算子）
--------------------

条件によって異なる値のどちらかを選び、その結果を 1 つの式として使いたい場合は、条件式（三項演算子と呼ばれることもあります）を使用します。``真の場合の値 if 条件 else 偽の場合の値`` のように書くと、条件が真であれば前者の値、偽であれば後者の値が得られます。

.. code-block:: python
   :linenos:

   score = 85
   result = "合格" if score >= 60 else "不合格"
   print(result)  # 合格

上記は、次の ``if`` 文と同じ結果になります。

.. code-block:: python
   :linenos:

   score = 85
   if score >= 60:
       result = "合格"
   else:
       result = "不合格"
   print(result)  # 合格

条件式は、条件によって決まる値をそのまま変数に代入したい場合などに、簡潔に書けます。条件やそれぞれの処理が複雑になる場合は、通常の ``if`` 文を使ったほうが読みやすくなります。

条件分岐（match 文）
--------------------

Python 3.10 以降では、``match`` 文を使って条件分岐を書くこともできます。``match`` 文は、1 つの値を複数のパターンと比較して処理を分けたい場合に、``if`` 文よりも見通しよく書けることがあります。

.. code-block:: python
   :linenos:

   number = 2

   match number:
       case 0:
           print("ゼロです。")
       case 1 | 2 | 3:
           print("1 から 3 の数値です。")
       case _:
           print("その他の数値です。")

``match`` の後ろに比較したい値を書き、``case`` に続けてパターンを書くと、値がそのパターンに一致した場合の処理が実行されます。パターンは上から順番に比較され、最初に一致した ``case`` のブロックだけが実行されます。``case 1 | 2 | 3`` のように ``|`` でパターンを区切ると、「1、2、3 のいずれかに一致した場合」という意味になります。``case _`` は、どのパターンにも一致しなかった場合に実行される、デフォルトの分岐を表します。比較したい値の候補が少ない場合は ``if`` 文、1 つの値を多くの候補と比較したい場合は ``match`` 文というように、状況に応じて使い分けてください。

繰り返し（for 文）
------------------

``for`` 文は、複数の値が集まったものから要素を 1 つずつ取り出し、取り出した要素ごとに同じ処理を繰り返す構文です。``for 変数 in 繰り返しの対象:`` のように書くと、取り出された要素が順番に変数へ代入され、インデントしたブロックの処理が要素の数だけ実行されます。

range 関数を使った繰り返し
^^^^^^^^^^^^^^^^^^^^^^^^^^

指定した回数だけ処理を繰り返したい場合は、``range`` 関数と組み合わせます。

.. code-block:: python
   :linenos:

   for i in range(3):
       print("i の値:", i)

``range(3)`` は、0、1、2 という 3 つの数値を順番に生成します。そのため、上記のコードでは変数 ``i`` に 0、1、2 が順番に代入され、``print`` 関数が 3 回実行されます。数値は 1 からではなく 0 から始まり、指定した数値（この例では 3）自体は含まれない点に注意してください。

``range(開始, 終了)`` のように 2 つの数値を指定すると、開始の数値から、終了の数値の 1 つ手前までの数値を生成します。

.. code-block:: python
   :linenos:

   for day in range(1, 8):
       print(day)  # 1 から 7 までの数値が順番に表示される

文字列を使った繰り返し
^^^^^^^^^^^^^^^^^^^^^^

``for`` 文の繰り返しの対象には、文字列を指定することもできます。その場合は、文字列の先頭から 1 文字ずつ取り出されます。

.. code-block:: python
   :linenos:

   for char in "Python":
       print(char)  # P、y、t、h、o、n が 1 文字ずつ表示される

リストを使った繰り返し
^^^^^^^^^^^^^^^^^^^^^^

``for`` 文は、リストと組み合わせて使われることもよくあります。リストは、複数の値を 1 つにまとめて扱うためのデータ構造で、角括弧 ``[]`` の中に値をカンマ ``,`` で区切って並べて作成します。リストの作り方や操作方法は、:ref:`第 6 章「データ構造」の「リスト」 <data-structures-list>` で詳しく説明します。ここでは、「複数の値を並べてまとめたもの」と理解しておけば十分です。

.. code-block:: python
   :linenos:

   fruits = ["りんご", "みかん", "ぶどう"]
   for fruit in fruits:
       print(fruit)

上記のコードでは、リスト ``fruits`` の要素が先頭から順番に変数 ``fruit`` に代入され、「りんご」「みかん」「ぶどう」が 1 行ずつ表示されます。

繰り返し（while 文）
--------------------

``while`` 文は、指定した条件が真である間、処理を繰り返す構文です。条件が偽になるまでの繰り返し回数があらかじめ分からない場合に適しています。

.. code-block:: python
   :linenos:

   count = 0
   while count < 3:
       print("カウント:", count)
       count += 1

``count += 1`` は、``count = count + 1`` と同じ意味で、変数 ``count`` の値に 1 を加えた結果を、改めて ``count`` に代入します（:ref:`第 4 章「データ型と演算子」の「複合代入演算子」 <compound-assignment-operators>` を参照）。

上記のコードでは、``count`` の値が 0、1、2 と増えていき、3 になった時点で条件 ``count < 3`` が偽になるため、繰り返しが終了します。条件がいつまでも偽にならないと、繰り返しが永遠に終わらなくなる（無限ループになる）ため、繰り返しの中で条件に関わる変数を更新し忘れないように注意してください。

繰り返しの制御
--------------

繰り返しの途中で処理を制御したい場合は、``break`` 文と ``continue`` 文を使用します。``break`` 文は繰り返しそのものを終了させ、``continue`` 文はその回の処理だけを飛ばして次の繰り返しに進みます。

.. code-block:: python
   :linenos:

   for number in range(10):
       if number == 5:
           break  # number が 5 になった時点で繰り返しを終了する
       if number % 2 == 0:
           continue  # 偶数のときは以降の処理を飛ばす
       print(number)  # 1、3 が表示される

``number`` が 0 から順番に増えていき、偶数（0、2、4）のときは ``continue`` 文によって ``print`` 関数が飛ばされます。``number`` が 5 になると ``break`` 文によって繰り返し全体が終了するため、6 以降の数値は処理されません。その結果、表示されるのは 1 と 3 だけです。
