第 4 章 データ型と演算子
========================

代表的なデータ型
----------------

Python の代表的なデータ型には、次のようなものがある。

.. list-table::
   :header-rows: 1

   * - データ型
     - 説明
     - 例
   * - ``int``
     - 整数
     - ``10``、``-5``
   * - ``float``
     - 小数（浮動小数点数）
     - ``3.14``、``-0.5``
   * - ``str``
     - 文字列
     - ``"こんにちは"``
   * - ``bool``
     - 真偽値（真または偽）
     - ``True``、``False``

変数がどのデータ型であるかは、``type`` 関数で確認できる。

.. code-block:: python
   :linenos:

   print(type(10))       # <class 'int'>
   print(type(3.14))     # <class 'float'>
   print(type("こんにちは"))  # <class 'str'>
   print(type(True))     # <class 'bool'>

None 型
-------

Python には、値が存在しないことを表す特別な値として ``None`` が用意されている。関数が戻り値を返さない場合や、変数にまだ具体的な値を決められないことを示したい場合などに使用する。

.. code-block:: python
   :linenos:

   result = None
   print(result)       # None
   print(type(None))   # <class 'NoneType'>

戻り値を持たない関数を定義する場合は、戻り値の型ヒントに ``None`` を指定する。本資料のサンプルコードに繰り返し登場する ``def main() -> None:`` の ``-> None`` は、この意味である。関数の定義方法自体は、第 7 章「関数」で説明する。

変数の値が ``None`` かどうかを判定する際は、``==`` ではなく ``is`` を使うのが Python の慣習である。

.. code-block:: python
   :linenos:

   print(result is None)       # True
   print(result is not None)   # False

条件によって処理を分岐させる方法（``if`` 文）は、第 5 章「制御構文」で説明する。

複数の型を許容する型ヒント
--------------------------

変数や引数が複数の種類の値を取り得る場合は、``|`` を使って型ヒントをつなげる。次の例では、``nickname`` という変数が、文字列（``str`` 型）または ``None`` のどちらの値も持てることを表している。

.. code-block:: python
   :linenos:

   nickname: str | None = None
   print(nickname)  # None

   nickname = "たなか"
   print(nickname)  # たなか

``str | None`` のように、ある型と ``None`` を組み合わせた型ヒントは、「値が指定されているかもしれないし、指定されていないかもしれない」という状況を表す際によく使われる。``None`` に限らず、``int | str`` のように複数の型同士を組み合わせることもできる。関数の引数のデフォルト値として ``None`` を使う実践的な例は、第 7 章「関数」で説明する。

算術演算子
----------

Python では、次の算術演算子を使って数値の計算を行う。

.. list-table::
   :header-rows: 1

   * - 演算子
     - 説明
     - 例
   * - ``+``
     - 加算
     - ``7 + 3``
   * - ``-``
     - 減算
     - ``7 - 3``
   * - ``*``
     - 乗算
     - ``7 * 3``
   * - ``/``
     - 除算（結果は小数）
     - ``7 / 3``
   * - ``//``
     - 除算（小数点以下を切り捨てた商）
     - ``7 // 3``
   * - ``%``
     - 剰余
     - ``7 % 3``
   * - ``**``
     - べき乗
     - ``7 ** 3``

``/`` 演算子は、割り切れる場合でも常に小数（``float`` 型）の結果を返す点に注意が必要である。たとえば、``6 / 3`` の結果は ``2`` ではなく ``2.0`` になる。整数の商だけを求めたい場合は ``//`` 演算子を使用する。``7 // 3`` の結果は ``2``、``7 % 3`` の結果は ``1`` である。

複合代入演算子
--------------

プログラムでは、「変数の値に 1 を加える」のように、変数の現在の値をもとに計算した結果を、同じ変数に改めて代入する処理がよく登場する。この処理は、``=`` を使って次のように書ける。

.. code-block:: python
   :linenos:

   count = 0
   count = count + 1
   print(count)  # 1

``count = count + 1`` は、「``count`` の現在の値（0）に 1 を加えた結果（1）を、改めて ``count`` に代入する」という意味である。数学の等式とは異なり、``=`` は右辺の計算結果を左辺の変数に代入する記号である点に注意が必要である。

同じ処理は、算術演算子と ``=`` を組み合わせた複合代入演算子を使うと、次のように短く書ける。

.. code-block:: python
   :linenos:

   count = 0
   count += 1
   print(count)  # 1

Python では、次の複合代入演算子を使用できる。

.. list-table::
   :header-rows: 1

   * - 演算子
     - 例
     - 同じ意味の書き方
   * - ``+=``
     - ``x += 3``
     - ``x = x + 3``
   * - ``-=``
     - ``x -= 3``
     - ``x = x - 3``
   * - ``*=``
     - ``x *= 3``
     - ``x = x * 3``
   * - ``/=``
     - ``x /= 3``
     - ``x = x / 3``
   * - ``//=``
     - ``x //= 3``
     - ``x = x // 3``
   * - ``%=``
     - ``x %= 3``
     - ``x = x % 3``
   * - ``**=``
     - ``x **= 3``
     - ``x = x ** 3``

``/=`` を使った場合は、``/`` 演算子と同じく、結果が小数（``float`` 型）になる。複合代入演算子は、第 5 章「制御構文」で説明する繰り返しの処理の中で、回数を数えたり合計を求めたりする際によく使われる。

比較演算子と論理演算子
----------------------

条件を判定する際には、比較演算子と論理演算子を使用する。比較演算子は結果として ``True`` または ``False`` を返す。

.. list-table::
   :header-rows: 1

   * - 演算子
     - 説明
   * - ``==``
     - 等しい
   * - ``!=``
     - 等しくない
   * - ``>``
     - より大きい
   * - ``<``
     - より小さい
   * - ``>=``
     - 以上
   * - ``<=``
     - 以下

複数の条件を組み合わせるには、論理演算子である ``and``、``or``、``not`` を使用する。``and`` は両方の条件が真のときに真となり、``or`` はどちらか一方でも真であれば真となり、``not`` は真偽値を反転する。

.. code-block:: python
   :linenos:

   age = 20
   print(age >= 18)               # True
   print(age >= 18 and age < 65)  # True
   print(age < 18 or age >= 65)   # False
   print(not age >= 18)           # False

文字列の結合
------------

Python では、``+`` 演算子を使って文字列同士を結合できる。数値と文字列を直接 ``+`` で結合しようとすると ``TypeError`` という例外（エラー）が発生するため、その場合は ``str`` 関数を使って数値を文字列に変換してから結合する。数値を含む文字列をより簡潔に組み立てる方法（f 文字列）は、第 8 章「文字列操作」で説明する。

.. code-block:: python
   :linenos:

   name = "花子"
   greeting = "こんにちは、" + name + "さん"
   print(greeting)  # こんにちは、花子さん

   age = 20
   message = "年齢は " + str(age) + " 歳です。"
   print(message)  # 年齢は 20 歳です。
