参考文献
========

本資料の作成にあたって参考にした資料と、本資料を読み終えた後の学習に役立つ資料をまとめる。いずれも Web 上で無償で閲覧できる。

Python 公式ドキュメント
-----------------------

* `Python 公式ドキュメント（日本語） <https://docs.python.org/ja/3/>`_

  * Python の言語仕様や標準ライブラリについての公式の説明である。

* `Python チュートリアル <https://docs.python.org/ja/3/tutorial/index.html>`_

  * Python 公式のチュートリアルである。本資料で扱った内容を、より詳しく学べる。

* `Python 標準ライブラリ <https://docs.python.org/ja/3/library/index.html>`_

  * ``pathlib`` や ``tempfile`` など、標準ライブラリの各モジュールの説明である。

* `Python on Windows <https://docs.python.org/ja/3/using/windows.html>`_

  * Windows での Python のインストール方法（Python install manager）の説明である。

* `venv --- 仮想環境の作成 <https://docs.python.org/ja/3/library/venv.html>`_

  * 第 11 章で説明した仮想環境の作成方法の詳細である。

* `Status of Python versions <https://devguide.python.org/versions/>`_

  * Python の各バージョンの公開日と保守期間（EOL）の一覧である。

コーディング規約と型チェック
----------------------------

* `PEP 8 -- Style Guide for Python Code <https://peps.python.org/pep-0008/>`_

  * Python のコードの書き方についての標準的な規約である。本資料のサンプルコードは、この規約に従って書いている。

* `PEP 484 -- Type Hints <https://peps.python.org/pep-0484/>`_

  * 型ヒントの仕様を定めた文書である。

* `mypy documentation <https://mypy.readthedocs.io/en/stable/>`_

  * 型チェックツール ``mypy`` の公式ドキュメントである。

* `flake8 documentation <https://flake8.pycqa.org/en/latest/>`_

  * コードが PEP 8 に従っているかを確認するツール ``flake8`` の公式ドキュメントである。

開発環境
--------

* `Python 公式サイト <https://www.python.org/>`_

  * Python のダウンロードや最新情報を確認できる。

* `Visual Studio Code <https://code.visualstudio.com/>`_

  * 第 2 章で紹介したエディターの公式サイトである。
