第 2 章 開発環境の準備
======================

Python のインストール
----------------------

Python でプログラムを書くには、まず使用するパソコンに Python をインストールする必要がある。インストール方法は OS によって異なる。

Windows の場合
^^^^^^^^^^^^^^

Windows では、Python 公式の「Python install manager」を使って Python をインストールする。Python install manager は、`Python 公式サイトのダウンロードページ <https://www.python.org/downloads/windows/>`_ または Microsoft Store から入手できる。Python install manager をインストールすると、コマンドラインで ``python`` コマンドと ``py`` コマンドを使えるようになる。

Python install manager のインストール後、コマンドラインで次のコマンドを実行すると、指定したバージョンの Python（この例では Python 3.14）がインストールされる。

.. code-block:: console

   $ py install 3.14

以前は、Python のバージョンごとに用意されたインストーラーを使い、インストール画面で「Add Python to PATH」のチェックボックスをオンにする方法が一般的だった。この従来のインストーラーは Python 3.16 以降では提供されなくなるため、本資料では Python install manager を使う方法を説明している。

macOS、Linux の場合
^^^^^^^^^^^^^^^^^^^

macOS では、`Python 公式サイトのダウンロードページ <https://www.python.org/downloads/macos/>`_ からインストーラーをダウンロードし、画面の指示に従ってインストールする。Linux では、多くのディストリビューションで Python があらかじめインストールされているか、ディストリビューションのパッケージ管理ツールでインストールできる。

macOS や Linux では、``python`` コマンドの代わりに ``python3`` コマンドを使う場合が多い。本資料では ``python`` コマンドで説明するため、macOS や Linux では必要に応じて ``python3`` に読み替えること。

インストールの確認
------------------

インストールが完了したら、コマンドラインで次のコマンドを実行し、バージョンが表示されることを確認する。

.. code-block:: console

   $ python --version
   Python 3.14.6

表示されるバージョン番号は、インストールしたバージョンによって異なる。``Python 3.11`` 以降のバージョン番号が表示されれば、本資料の内容を学習できる。コマンドが見つからないというエラーが表示された場合は、コマンドラインを開き直すか、パソコンを再起動してから、もう一度確認する。

pip の確認
----------

Python には、外部ライブラリをインストールするための ``pip`` というツールが標準で付属している。次のコマンドを実行し、バージョンが表示されることを確認する。

.. code-block:: console

   $ python -m pip --version
   pip 26.2.2 from ... (python 3.14)

``python -m pip`` は、``python`` コマンドで起動する Python に付属した ``pip`` を実行する書き方である。``pip`` コマンドを直接実行する方法もあるが、複数のバージョンの Python がインストールされている場合に、意図しない Python の ``pip`` が実行されることがあるため、本資料では ``python -m pip`` を使う。``pip`` の具体的な使い方は、第 11 章「モジュールとパッケージ」で説明する。

エディターの準備
----------------

Python のプログラムは、テキストエディターで作成する。初心者には、無償で利用でき、豊富な拡張機能を持つ Visual Studio Code が使いやすい。Visual Studio Code に Python の拡張機能を追加すると、コードの色分けや入力補完、実行結果の確認などが行いやすくなる。

Python のファイル（拡張子 ``.py``）を保存する際は、文字コードを UTF-8 にする。UTF-8 は Python のソースコードの既定の文字コードであり、本資料のサンプルコードのように日本語のコメントや docstring を含む場合、ほかの文字コードで保存すると、実行時に文字化けや ``SyntaxError`` が発生することがある。Visual Studio Code をはじめとする多くのエディターでは、既定の保存形式が UTF-8 になっている。

サンプルコードの構成について
----------------------------

先ほどのサンプルコードには、ファイルの先頭にある ``"""..."""`` という文字列や、``def main() -> None:`` という記述、``if __name__ == "__main__":`` という記述があった。本資料のサンプルコードは、この後の章でも、すべて同じ構成で統一している。ここでは、それぞれが何を表しているかを簡単に説明する。詳しい説明は、あわせて示す章で行う。

``"""..."""``
    関数やファイルの説明を書く docstring である。書き方の詳細は、第 7 章「関数」で説明する。

``def 関数名(...) -> 型:``
    一連の処理をまとめた「関数」を定義する書き方である。定義方法や引数の書き方は、第 7 章「関数」で説明する。

``変数名: 型 = 値``
    変数が持つ値の種類を示す型ヒントである。詳しくは、第 3 章「基本文法」で説明する。

``if __name__ == "__main__":``
    ファイルが直接実行されたときにだけ、``main`` 関数を呼び出すための書き方である。

``if __name__ == "__main__":`` の仕組みについては、もう少し詳しく説明する。Python では、ファイルが直接実行されたときに、変数 ``__name__`` へ ``"__main__"`` という文字列が自動的に設定される。一方、そのファイルが別のファイルから ``import`` された場合、``__name__`` にはモジュール名（拡張子を除いたファイル名）が設定される。この違いを利用することで、ファイルを直接実行したときにだけ ``main`` 関数を呼び出し、他のファイルから ``import`` されたときは呼び出さない、という制御ができる。

サンプルコードの中には、``main`` 関数以外にも、計算処理などをまとめた関数が定義されていることがある。これらの関数も、呼び出すとその中に書かれた処理がまとめて実行される、という点は同じである。定義方法は第 7 章で詳しく説明するため、それまでは大まかな動作のイメージを持てれば十分である。次の章から、Python の文法を順番に学んでいこう。
