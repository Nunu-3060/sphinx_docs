第 2 章 開発環境の準備
======================

Python のインストール
----------------------

Python でプログラムを書くには、まずお使いのパソコンに Python をインストールする必要があります。公式サイト（https://www.python.org/）からインストーラーをダウンロードし、画面の指示に従ってインストールしてください。Windows でインストールする場合は、インストール画面で表示される「Add Python to PATH」のチェックボックスを必ずオンにしてください。このチェックボックスをオンにすることで、コマンドラインからどのフォルダにいても python コマンドを実行できるようになります。

インストールの確認
------------------

インストールが完了したら、コマンドラインで次のコマンドを実行し、バージョンが表示されることを確認してください。

.. code-block:: console

   $ python --version
   Python 3.14.6

バージョン番号が表示されれば、インストールは正常に完了しています。表示されない場合は、パソコンを再起動してから、もう一度確認してください。

pip の確認
----------

Python には、外部ライブラリをインストールするための ``pip`` というツールが標準で付属しています。次のコマンドを実行し、バージョンが表示されることを確認してください。

.. code-block:: console

   $ pip --version
   pip 25.0 from ... (python 3.14)

``pip`` の具体的な使い方は、第 11 章「モジュールとパッケージ」で説明します。

エディターの準備
----------------

Python のプログラムは、テキストエディターで作成します。初心者の方には、無償で利用でき、豊富な拡張機能を持つ Visual Studio Code をお勧めします。Visual Studio Code に Python の拡張機能を追加すると、コードの色分けや入力補完、実行結果の確認などが行いやすくなります。

Python のファイル（拡張子 ``.py``）を保存する際は、文字コードを UTF-8 にしてください。UTF-8 は Python 3 の既定の文字コードであり、本資料のサンプルコードのように日本語のコメントや docstring を含む場合、ほかの文字コードで保存すると、実行時に文字化けや ``SyntaxError`` が発生することがあります。Visual Studio Code をはじめとする多くのエディターでは、既定の保存形式が UTF-8 になっています。

準備が整ったら、実際に簡単なプログラムを実行してみましょう。次のサンプルコードをダウンロードし、任意のフォルダに保存してください。

:download:`hello.py <../../examples/ch02_setup/hello.py>`

.. literalinclude:: ../../examples/ch02_setup/hello.py
   :language: python3

サンプルコードの構成について
----------------------------

先ほどのサンプルコードをよく見ると、``def main() -> None:`` という記述や、ファイルの先頭にある ``"""..."""`` という文字列、``if __name__ == "__main__":`` という記述がありました。本資料のサンプルコードは、この後の章でも、すべて同じ構成で統一しています。ここでは、それぞれが何を表しているかを簡単に説明します。詳しい説明は、あわせて示す章で行います。

``def 関数名(...) -> 型:``
    一連の処理をまとめた「関数」を定義する書き方です。定義方法や引数の書き方は、第 7 章「関数」で説明します。

``"""..."""``
    関数やファイルの説明を書く docstring です。書き方の詳細は、第 7 章「関数」で説明します。

``変数名: 型 = 値``
    変数が持つ値の種類を示す型ヒントです。詳しくは、第 3 章「基本文法」で説明します。

``if __name__ == "__main__":``
    ファイルが直接実行されたときにだけ、``main`` 関数を呼び出すための書き方です。

``if __name__ == "__main__":`` の仕組みについては、もう少し詳しく説明します。Python では、ファイルが直接実行されたときに、変数 ``__name__`` へ ``"__main__"`` という文字列が自動的に設定されます。一方、そのファイルが別のファイルから ``import`` された場合、``__name__`` にはファイル名（モジュール名）が設定されます。この違いを利用することで、ファイルを直接実行したときにだけ ``main`` 関数を呼び出し、他のファイルから ``import`` されたときは呼び出さない、という制御ができます。

サンプルコードの中には、``main`` 関数以外にも、計算処理などをまとめた関数が定義されていることがあります。これらの関数も、呼び出すとその中に書かれた処理がまとめて実行される、という点は同じです。定義方法は第 7 章で詳しく説明しますので、それまでは大まかな動作のイメージを持てれば十分です。次の章から、Python の文法を順番に学んでいきましょう。
