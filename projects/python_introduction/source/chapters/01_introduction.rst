第 1 章 はじめに
================

Python とは
-----------

Python は、シンプルで読みやすい文法を特徴とするプログラミング言語である。1991 年に Guido van Rossum 氏によって最初のバージョンが公開されて以来、世界中で幅広く使われている。文法が英語の文章に近く、初心者でも比較的短い学習期間でプログラムを書けるようになることから、プログラミング教育の入門言語としてもよく採用されている。

Python が使われている分野
-------------------------

Python は汎用的なプログラミング言語であり、次のような幅広い分野で利用されている。

* Web アプリケーションの開発
* データ分析や統計処理
* 機械学習や人工知能の研究、開発
* 業務の自動化やスクリプト処理
* 教育用のプログラミング言語

このように用途が広いことも、Python が世界中の開発者から支持されている理由の 1 つである。

Python の特徴
-------------

Python には、次のような特徴がある。

読みやすい文法
    インデント（字下げ）によってブロックを表現するため、誰が書いてもコードの見た目がそろいやすく、他人が書いたコードも読みやすい。

豊富なライブラリ
    標準ライブラリに加えて、世界中の開発者が公開している外部ライブラリを利用することで、複雑な処理も少ないコードで実現できる。

多くの環境で動作する
    Windows、macOS、Linux など、主要な OS 上で同じように動作する。

Python のバージョン
-------------------

Python は、おおむね 1 年に 1 回、新しいバージョン（3.13、3.14、3.15 など）が公開される。各バージョンは公開から約 5 年間保守され、その期間が終わる（EOL: End of Life と呼ぶ）と、不具合やセキュリティ上の問題が見つかっても修正されなくなる。たとえば、Python 3.10 は 2026 年 10 月に EOL を迎えた。これから Python を学ぶ場合は、保守期間中の新しいバージョンを使うのがよい。

本資料は Python 3.11 以降を対象としており、サンプルコードは Python 3.14 で動作を確認している。各バージョンの保守期間は、Python 公式の `Status of Python versions <https://devguide.python.org/versions/>`_ で確認できる。

本資料の対象読者
----------------

本資料は、プログラミングの経験がない人や、これから Python を学び始めたい人を対象としている。プログラミングに関する用語は、初めて登場する箇所でその都度説明する。すでに他のプログラミング言語の経験がある人は、第 3 章から読み進めても問題ない。
