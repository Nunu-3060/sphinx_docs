用語集
======

本資料で使用した主な用語を、登場した章の順にまとめる。用語の意味を確認したいときに利用するとよい。詳しい説明は、それぞれの用語が最初に登場する章を参照すること。

.. glossary::

   EOL（End of Life）
      Python の各バージョンの保守期間が終了することである。EOL を迎えたバージョンは、不具合やセキュリティ上の問題が見つかっても修正されない。詳しくは :doc:`01_introduction` を参照。

   pip
      外部ライブラリをインストールするための、Python に標準で付属しているツールである。詳しくは :doc:`02_setup` と :doc:`11_modules` を参照。

   変数
      値に名前を付けて保存しておく仕組みである。詳しくは :doc:`03_basic_syntax` を参照。

   型ヒント
      変数や引数、戻り値がどのような種類の値を扱うかを示す注釈である。詳しくは :doc:`03_basic_syntax` を参照。

   データ型
      値の種類を表す分類である。``int``\ （整数）、``float``\ （小数）、``str``\ （文字列）、``bool``\ （真偽値）などがある。詳しくは :doc:`04_data_types` を参照。

   None
      値が存在しないことを表す特別な値である。詳しくは :doc:`04_data_types` を参照。

   演算子
      加算や比較など、値同士を計算したり比較したりするための記号である。詳しくは :doc:`04_data_types` を参照。

   複合代入演算子
      ``+=`` や ``-=`` のように、算術演算子と ``=`` を組み合わせて、変数の値をもとに計算した結果を同じ変数に代入する演算子である。詳しくは :doc:`04_data_types` を参照。

   if 文
      条件によって実行する処理を切り替える構文である。詳しくは :doc:`05_control_flow` を参照。

   match 文
      1 つの値を複数のパターンと比較して処理を分ける構文である。詳しくは :doc:`05_control_flow` を参照。

   条件式（三項演算子）
      条件によって異なる値のどちらかを選び、その結果を 1 つの式として使う書き方である。詳しくは :doc:`05_control_flow` を参照。

   for 文
      リストや文字列などの要素を 1 つずつ取り出しながら処理を繰り返す構文である。詳しくは :doc:`05_control_flow` を参照。

   while 文
      指定した条件が真である間、処理を繰り返す構文である。詳しくは :doc:`05_control_flow` を参照。

   リスト
      複数の値を順序付けて格納できる、要素の追加や変更ができるデータ構造である。詳しくは :doc:`06_data_structures` を参照。

   タプル
      複数の値を順序付けて格納できる、一度作成すると要素を変更できないデータ構造である。詳しくは :doc:`06_data_structures` を参照。

   辞書
      キーと値の組み合わせでデータを格納するデータ構造である。詳しくは :doc:`06_data_structures` を参照。

   集合
      重複しない値の集まりを表すデータ構造である。詳しくは :doc:`06_data_structures` を参照。

   内包表記
      既存のリストや、``for`` 文と ``if`` 文による繰り返しと条件分岐を、角括弧や波括弧を使って 1 行で書ける構文である。詳しくは :doc:`06_data_structures` を参照。

   関数
      一連の処理をひとまとまりにして、名前を付けたものである。詳しくは :doc:`07_functions` を参照。

   引数
      関数を呼び出す際に、関数へ渡す値である。詳しくは :doc:`07_functions` を参照。

   戻り値
      関数の処理結果として、``return`` 文で呼び出し元に返す値である。詳しくは :doc:`07_functions` を参照。

   docstring
      関数やファイル、クラスの説明を書くために、三重引用符で囲んで書く文字列である。詳しくは :doc:`07_functions` を参照。

   デフォルト引数
      あらかじめ値を設定しておくことで、呼び出し時に省略できる引数である。詳しくは :doc:`07_functions` を参照。

   キーワード引数
      関数を呼び出す際に、``引数名=値`` の形で指定して渡す引数である。詳しくは :doc:`07_functions` を参照。

   可変長引数
      ``*`` を付けることで、数があらかじめ決まっていない引数を受け取れるようにしたものである。関数の内部ではタプルとして扱われる。詳しくは :doc:`07_functions` を参照。

   可変長のキーワード引数
      ``**`` を付けることで、数があらかじめ決まっていないキーワード引数を受け取れるようにしたものである。関数の内部では辞書として扱われる。詳しくは :doc:`07_functions` を参照。

   ラムダ式
      ``lambda`` を使って、名前を付けずにその場限りの小さな関数を作成する書き方である。詳しくは :doc:`07_functions` を参照。

   f 文字列（f-string）
      文字列の前に ``f`` を付け、波括弧の中に変数や式を書くことで、文字列と変数を組み合わせられる書き方である。詳しくは :doc:`08_strings` を参照。

   スライス
      ``文字列[開始位置:終了位置]`` のように書いて、文字列の一部を取り出す操作である。詳しくは :doc:`08_strings` を参照。

   例外
      プログラムの実行中に発生するエラーのことである。詳しくは :doc:`10_exceptions` を参照。

   トレースバック
      対処されなかった例外の内容を Python が表示する、エラーメッセージの形式である。詳しくは :doc:`10_exceptions` を参照。

   モジュール
      関数やクラスなどをまとめて記述した、1 つの Python ファイルのことである。詳しくは :doc:`11_modules` を参照。

   パッケージ
      複数のモジュールをフォルダにまとめたものである。詳しくは :doc:`11_modules` を参照。

   仮想環境
      プログラムごとに独立したライブラリの置き場所を持つ Python の実行環境である。標準ライブラリの ``venv`` モジュールで作成する。詳しくは :doc:`11_modules` を参照。

   クラス
      関連するデータ（属性）と処理（メソッド）をひとまとめにした設計図のようなものである。詳しくは :doc:`12_oop` を参照。

   インスタンス
      クラスから作られた実体のことである。詳しくは :doc:`12_oop` を参照。

   特殊メソッド
      ``__str__`` のように前後にアンダースコアを 2 つ付けた、決められた名前と書き方に従うメソッドである。詳しくは :doc:`12_oop` を参照。

   継承
      既存のクラスの属性やメソッドを引き継いで、新しいクラスを定義する仕組みである。詳しくは :doc:`12_oop` を参照。
