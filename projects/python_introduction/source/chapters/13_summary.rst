第 13 章 まとめと次のステップ
=============================

本資料の振り返り
----------------

本資料では、プログラミング未経験者を対象に、Python の基礎を次の順序で学んできた。

* 第 2 章 開発環境の準備
* 第 3 章 基本文法（変数と出力）
* 第 4 章 データ型と演算子
* 第 5 章 制御構文（条件分岐と繰り返し）
* 第 6 章 データ構造（リスト、タプル、辞書、集合）
* 第 7 章 関数
* 第 8 章 文字列操作
* 第 9 章 ファイルの入出力
* 第 10 章 例外処理
* 第 11 章 モジュールとパッケージ
* 第 12 章 クラスとオブジェクト指向

ここまでの内容を理解できていれば、簡単なプログラムを自分で作成できる状態になっている。実際に手を動かしてサンプルコードを実行し、少しずつ内容を変更しながら試すことで、理解がより一層深まる。

次のステップ
------------

Python の基礎を学び終えたら、次のような分野に進むとよい。

Web アプリケーション開発
    Flask や Django といったフレームワークを使うと、Web アプリケーションを Python で開発できる。

データ分析
    NumPy や pandas といったライブラリを使うと、大量のデータを効率よく処理、分析できる。

自動化とスクリプト
    ファイルの整理やデータの集計など、日常の定型作業を自動化するスクリプトを作成できる。

テストの書き方
    標準ライブラリの ``unittest`` や、外部ライブラリの ``pytest`` を使うことで、書いたプログラムが正しく動作するかを自動的に確認できるようになる。

学習を続けるために
-------------------

プログラミングの学習では、書籍やインターネット上の資料を読むだけでなく、実際に手を動かしてコードを書くことが大切である。エラーが発生した際は、エラーメッセージをよく読み、何が問題なのかを 1 つずつ確認する習慣を身に付けることが大切である。本資料が、皆さんの Python 学習の第一歩として役立てば幸いである。

学習に役立つ資料は、:doc:`15_references` にまとめている。
