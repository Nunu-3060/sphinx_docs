次のステップ
============

ここまでで、ゲームを 1 本、企画から公開まで作り上げた。最後に、次に挑戦するとよいことを紹介する。

題材ゲームを拡張する
--------------------

第 2 章で「作らないもの」とした機能などを加えてみよう。どれも、本書で学んだことの組み合わせで実現できる。

.. list-table:: 題材ゲームの拡張のアイデア
   :header-rows: 1
   :widths: 30 70

   * - アイデア
     - 実現のヒント
   * - パワーアップ
     - 倒した敵がまれにアイテムを落とすようにする。アイテムは ``Entity`` の子クラスとして作り、自機と重なったらショットの数を増やす。
   * - ボム
     - ボタンを押すと、画面上の敵の弾をすべて消し、敵に大きなダメージを与える。回数に制限を付ける。
   * - ステージごとの変化
     - ステージごとに背景のタイルマップ、BGM、敵の出現の順番を変える。敵の出現を「何フレーム目に、どの敵を、どこに出すか」という表（リスト）で定義すると、コードを変えずにステージを作れる。
   * - 2 人同時プレイ
     - ``Player`` に操作するキーのリストを渡せるようにし、``pyxel.GAMEPAD2_BUTTON_A`` などを使う 2 人目の自機を作る。
   * - 設定画面
     - 新しいシーンとして作る。BGM の音量を変えるには、``pyxel.channels`` の各チャンネルの ``gain`` を変更する。

コードを整理する
----------------

完成版の ``main.py`` は 600 行を超えている。これ以上機能を増やす場合は、コードを複数のファイルに分けるとよい。たとえば、物体のクラスを ``entities.py`` に、シーンのクラスを ``scenes.py`` に移す。同じディレクトリに置いたファイルは、``pyxel package`` でまとめてパッケージに含まれる。

また、敵の出現のタイミングや敵の性能のような数値を、コードから切り離してデータとして持つと、調整がしやすくなる。調整するたびにコードを読まなくて済むからである。

ほかのジャンルに挑戦する
------------------------

本書で学んだゲームループ、シーン、当たり判定、スプライト、タイルマップは、ほかのジャンルでもそのまま使える。

* **横スクロールアクション**：重力とジャンプは、第 3 章の速度と加速度で実現できる。足場との当たり判定には、タイルマップのタイルを調べる方法が使える。Pyxel 2.9.9 の ``Tilemap.collide()`` は、移動量を与えると、指定したタイルにめり込まないように調整した移動量を返してくれる。付属のサンプル ``10_platformer.py`` も参考になる。
* **パズル**：盤面を 2 次元のリストで表し、入力に応じて書き換える。描画は盤面のリストを読んで行う。状態の更新と描画を分ける考え方が特に役立つ。
* **RPG**：マップはタイルマップで作り、会話や戦闘はシーンとして作る。扱うデータの量が多くなるので、データをコードから切り離す工夫が重要になる。

最初は、本書の題材ゲームと同じくらい小さな規模にとどめるとよい。完成させた経験の数が、そのまま次の作品の力になる。

学びを続ける
------------

* **Pyxel の公式のリポジトリ**：`GitHub の kitao/pyxel <https://github.com/kitao/pyxel>`__ には、ユーザーガイド、API リファレンス、Pyxel Editor のマニュアルがある。最新の機能はここで確かめる。
* **付属のサンプル**：``pyxel copy_examples`` でコピーされるサンプルには、本書で扱わなかった機能（3D 風の描画、独自フォント、PCM 音声の再生など）の使い方が含まれている。
* **Pyxel Code Maker**：`Pyxel Code Maker <https://kitao.github.io/pyxel/web/code-maker/>`__ を使うと、ブラウザだけで Pyxel のプログラムを書いて動かせる。手元に開発環境がない場所でも試せる。
* **ゲームジャム**：決められた期間とテーマでゲームを作るイベントを、ゲームジャムと呼ぶ。itch.io などで多数開催されている。締め切りがあると、作品を小さくまとめて完成させる力が付く。

本書が、あなたの最初の 1 本と、その次の 1 本を作るきっかけになれば幸いである。
