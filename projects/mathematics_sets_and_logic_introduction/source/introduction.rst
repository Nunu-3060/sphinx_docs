はじめに
========

本書の目的
----------

プログラムの条件分岐、データベースの検索条件、テストケースの網羅条件、仕様書の記述など、エンジニアの日常業務には論理と集合の考え方がいたるところに現れる。たとえば、次の 2 つの条件式は常に同じ結果になる。

.. code-block:: python
   :linenos:

   if not (is_admin or is_owner):
       deny()

   if not is_admin and not is_owner:
       deny()

これは第 3 章で扱うド・モルガンの法則の一例である。こうした書き換えを「なんとなく」ではなく根拠を持って行えるようになることが、論理を学ぶ実利の一つである。

また、数学や情報科学の教科書・論文は、集合・写像・関係の言葉と「ならば」「すべての」「ある」を組み合わせた証明で書かれている。本書は、それらを読み書きするための基礎体力を身に付けることを目的とする。

対象読者と前提知識
------------------

本書は、Python などのプログラミング言語の知識を持つエンジニアや工学系の大学生を対象とする。高校数学の範囲の整数・実数の計算ができれば、それ以上の数学の知識は前提としない。

プログラミングの経験は理解の足場として使う。ただし、Python の挙動と数学の定義は必ずしも一致しない。両者が異なる箇所では、その違いを明示する。

記法の約束
----------

本書では次の約束に従う。

* 命題の真理値は、真を T、偽を F で表す。
* 自然数全体の集合 :math:`\mathbb{N}` は :math:`0` を含むものとする。すなわち :math:`\mathbb{N} = \{0, 1, 2, \ldots\}` である。:math:`0` を含めない流儀の文献も多いので、他の本を読むときは注意する。
* 整数全体の集合を :math:`\mathbb{Z}`、有理数全体の集合を :math:`\mathbb{Q}`、実数全体の集合を :math:`\mathbb{R}` で表す。
* 定義・定理は枠で囲んで示す。証明の終わりは □ で示す。
* 数学の対象としての対応には「写像」、Python の ``def`` で定義するものには「関数」という語を用いる。

サンプルコードについて
----------------------

各章のサンプルコードは、本文中に行番号付きで掲載し、ダウンロードもできるようにした。サンプルコードは次の条件で作成している。

* Python 3.11 以上で動作し、標準ライブラリだけを使う。
* flake8（行長の上限は 120 文字）と mypy（``strict = True``）の検査を通過している。検査の設定ファイルは :download:`setup.cfg <../examples/setup.cfg>` である。

サンプルコードは、ダウンロードしたファイルを置いたディレクトリで次のように実行する。

.. code-block:: console
   :linenos:

   $ python truth_table.py
