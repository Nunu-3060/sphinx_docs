命題と論理演算
==============

本章では、論理の最小単位である命題と、命題どうしを組み合わせる論理演算を導入する。

命題
----

.. admonition:: 定義（命題）

   真であるか偽であるかが定まる主張を命題という。命題が真であるか偽であるかを、その命題の真理値という。

本書では、真理値の真を T、偽を F で表す。次の例を見てみよう。

* 「2 は素数である」は真の命題である。
* 「10 は 3 で割り切れる」は偽の命題である。
* 「このプログラムは速い」は、何をもって速いとするかが決まっていないため命題ではない。
* 「:math:`x > 3`」は、:math:`x` の値が決まるまで真偽が定まらないため、このままでは命題ではない。このように変数を含む主張は、第 5 章で述語として扱う。

個々の命題の中身に立ち入らず、命題を記号 :math:`P`、:math:`Q`、:math:`R` などで表して議論することが多い。このような記号を命題変数という。

論理演算
--------

既存の命題から新しい命題を作る操作を論理演算といい、論理演算を表す記号を論理記号という。基本的な論理演算は次の 5 つである。

.. list-table::
   :header-rows: 1
   :widths: 15 20 25 40

   * - 名称
     - 記号
     - 読み方
     - 真になる条件
   * - 否定
     - :math:`\neg P`
     - :math:`P` でない
     - :math:`P` が偽のとき
   * - 論理積
     - :math:`P \land Q`
     - :math:`P` かつ :math:`Q`
     - :math:`P` と :math:`Q` がともに真のとき
   * - 論理和
     - :math:`P \lor Q`
     - :math:`P` または :math:`Q`
     - :math:`P` と :math:`Q` の少なくとも一方が真のとき
   * - 含意
     - :math:`P \to Q`
     - :math:`P` ならば :math:`Q`
     - :math:`P` が偽であるか、:math:`Q` が真であるとき
   * - 同値
     - :math:`P \leftrightarrow Q`
     - :math:`P` と :math:`Q` は同値
     - :math:`P` と :math:`Q` の真理値が一致するとき

論理和は、両方が真の場合も真になる。日常語の「または」は「どちらか一方だけ」の意味で使われることもあるが、論理和はそうではない。一方だけが真のときに真になる演算は排他的論理和と呼ばれ、:math:`P \oplus Q` と書く。

含意の真理値
------------

含意 :math:`P \to Q` において、:math:`P` を前件、:math:`Q` を後件という。含意の真理値表で戸惑いやすいのは、前件 :math:`P` が偽のとき、後件 :math:`Q` の真偽にかかわらず :math:`P \to Q` が真になる点である。

これは「約束が破られたかどうか」と考えると納得しやすい。「雨が降ったら試合を中止する」という約束が破られるのは、雨が降ったのに試合を中止しなかった場合だけである。雨が降らなかった場合は、試合を中止しても中止しなくても、約束を破ったことにはならない。含意 :math:`P \to Q` が偽になるのも、:math:`P` が真で :math:`Q` が偽の場合だけである。

また、含意は因果関係を表すものではない。「1 + 1 = 2 ならば、東京は日本の首都である」は、前件と後件に何の関係もないが、どちらも真なので含意としては真である。含意はあくまで真理値だけで決まる演算である。

なお、真理値表から分かるとおり、:math:`P \to Q` は :math:`\neg P \lor Q` と同じ真理値をとる。

論理式と結合の強さ
------------------

命題変数と論理記号を組み合わせて作った式を論理式という。たとえば :math:`(P \to Q) \land (Q \to P)` は論理式である。

括弧を減らすため、論理記号の結合の強さを :math:`\neg`、:math:`\land`、:math:`\lor`、:math:`\to`、:math:`\leftrightarrow` の順に強いものとする。たとえば :math:`\neg P \lor Q \land R` は :math:`(\neg P) \lor (Q \land R)` を表す。:math:`\to` を続けて書く場合など、紛らわしいときは括弧を省略しない。

     - :math:`Q`
     - :math:`P \to Q`
     - :math:`Q \to P`
     - :math:`(P \to Q) \land (Q \to P)`
     - :math:`P \leftrightarrow Q`

Python の論理演算子との対応
---------------------------

Python の ``bool`` 型の値 ``True`` と ``False`` を真理値とみなすと、論理演算は次のように書ける。

.. list-table::
   :header-rows: 1
   :widths: 30 35 35

   * - 論理演算
     - Python の式
     - 備考
   * - :math:`\neg P`
     - ``not p``
     -
   * - :math:`P \land Q`
     - ``p and q``
     -
   * - :math:`P \lor Q`
     - ``p or q``
     -
   * - :math:`P \to Q`
     - ``not p or q``
     - 含意を表す演算子は無い。``bool`` 型どうしなら ``p <= q`` でもよい。
   * - :math:`P \leftrightarrow Q`
     - ``p == q``
     -
   * - :math:`P \oplus Q`
     - ``p != q``
     - ``bool`` 型どうしなら ``p ^ q`` でもよい。

``p <= q`` で含意を表せるのは、Python では ``False < True`` であり、``p <= q`` が偽になるのは ``p`` が ``True`` で ``q`` が ``False`` の場合だけだからである。ただし、意図が読み取りにくいので、実際のコードでは ``not p or q`` と書くほうがよい。

Python の論理演算子は、数学の論理演算と次の点で異なる。

**短絡評価**

``and`` と ``or`` は左の被演算子から評価し、結果が確定した時点で右の被演算子を評価しない。これを短絡評価という。真理値の計算結果は数学の論理演算と同じだが、右の被演算子に副作用がある場合や、評価すると例外が発生する場合に違いが現れる。

.. code-block:: python
   :linenos:

   def check(name: str, value: bool) -> bool:
       print(name, "を評価した")
       return value


   result = check("左", False) and check("右", True)
   # 「左 を評価した」だけが表示される。左が偽なので、右は評価されない。

この性質は、``if x is not None and x.value > 0:`` のように、前の条件が成り立つときだけ後の条件を評価したい場合に利用される。数学の :math:`P \land Q` には評価の順序という概念が無く、:math:`P \land Q` と :math:`Q \land P` は常に同じ真理値をとる。

**被演算子をそのまま返す**

``and`` と ``or`` の結果は ``bool`` 型とは限らず、どちらかの被演算子がそのまま返る。たとえば ``0 or "abc"`` の値は ``"abc"`` であり、``[] and 1`` の値は ``[]`` である。Python では ``0``、空文字列、空のリストなどが偽として扱われる（このような値を falsy という）ためである。論理演算として扱う場合は、被演算子を ``bool`` 型にそろえておくとよい。

**ビット演算子との混同**

``&``、``|``、``~`` はビット演算子であり、論理演算子ではない。``bool`` 型どうしの ``&`` と ``|`` は論理積・論理和と同じ結果になるが、``~True`` の値は ``False`` ではなく ``-2`` になる。``bool`` 型が整数型 ``int`` の派生型であり、``~`` は整数のビット反転として計算されるためである。否定には必ず ``not`` を使う。
