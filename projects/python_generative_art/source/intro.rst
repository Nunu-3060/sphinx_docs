はじめに
========

ジェネラティブアートとは
------------------------

ジェネラティブアート（生成芸術）とは、アルゴリズム・ルール・乱数など、何らかの自律的なシステムを使って作品の一部または全部を生成する芸術表現を指す。作家が全ての線や色を直接指定するのではなく、「どのようなプロセスで作品を生み出すか」を設計する点が特徴である。

その起源は、1960 年代にコンピュータや数式、あるいはプロッターを使って図形を生成した Vera Molnár や Frieder Nake、Georg Nees らの作品に遡る。以降、乱数・ノイズ関数・セルオートマトン・L-system・進化的アルゴリズムなど、多様な生成手法が発展してきた。近年は Processing や p5.js、Python のようなプログラミング環境の普及により、個人が手軽にこれらの手法を試せるようになっている。

本資料の目的
------------

本資料は、Python を使ってジェネラティブアートの代表的な手法を実装しながら学ぶことを目的とする。具体的には、次の手法を扱う。

- **色彩設計**: HSB による配色パターン、PCCS トーン、パレット生成、OKLab による知覚的に均等な補間、配色の模様への適用
- **タイリングパターン**: トルシェ・タイルによるグリッド配置、編み込み表現、正三角形・正六角形格子、ワン・タイル、Wave Function Collapse、迷路生成アルゴリズム、再帰的分割（矩形分割・四分木）、ペンローズ・タイル、極座標・対数極座標変換、対称性・万華鏡表現、双曲タイリング（ポアンカレディスク）
- **螺旋と曲線**: フィロタキシス、黄金比・白銀比などの貴金属比、対数螺旋・アルキメデスの螺旋・双曲螺旋、サイクロイド・スピログラフ、リサージュ曲線・ハーモノグラフ、バラ曲線、スーパーフォーミュラ、ベジェ曲線・Catmull-Rom スプライン
- **ノイズ関数**: パーリンノイズ、ドメインワーピング、Worley ノイズ、フローフィールド、カールノイズ
- **距離関数**: SDF による形状の合成・可視化、円充填（サークルパッキング）、ポアソン円盤サンプリング、ボロノイ図とドロネー三角形分割、ロイド緩和
- **フラクタル**: L-system、マンデルブロ・ジュリア集合、反復関数系、ストレンジアトラクター
- **セルオートマトンと反応拡散系**: 1 次元・2 次元セルオートマトン、Gray-Scott モデル
- **パーティクルシステム**: Boids による群れ、格子による近傍探索、物理法則（重力・衝突）、Verlet 積分による拘束（ロープ・クロス）
- **進化的アルゴリズム**: 半透明三角形の変異と選択による画像近似
- **画像を素材にした生成技法**: ハーフトーン、誤差拡散法によるディザリング、重み付きボロノイ図による点描、ピクセルソート

いずれの手法も、外部の専用ライブラリに頼るのではなく、NumPy を中心とした基本的なライブラリのみで自前実装することに重点を置く。仕組みを理解した上で使うことで、既存ライブラリにない独自の変種を作れるようになることを目指す。

一方で、Processing 系（py5）やベクター描画（pycairo）といった出力手段の選択肢には触れるものの、それらの詳細な API リファレンスや、UI・リアルタイムのインタラクション・音楽との連携といった応用領域は扱わない。アニメーションについては、:ref:`animation`\ で静止画の生成コードから GIF を書き出す基本に触れるにとどめる。

**py5 / Processing.py** は、Processing / p5.js 系のクリエイティブコーディング環境の Python 版である。``setup()`` / ``draw()`` というフレームベースの描画ループを標準で持ち、マウスやキーボードからのインタラクションを扱いやすい。PIL が「1 枚の画像を都度組み立てて保存する」静的な用途に向くのに対し、py5 はアニメーションやリアルタイム性のある作品に向く。本資料のコード例は基本的に PIL/NumPy による静止画生成で統一しているため、py5 特有の API は扱わない。

**cairo / pycairo** は、解像度に依存しないベクターグラフィックスライブラリである。PIL がラスター画像（ピクセルの配列）を直接扱うのに対し、pycairo はパス（線分・曲線・塗りつぶし領域）を記述し、最終的にラスターだけでなく SVG や PDF にも出力できる。線が交差する複雑な図形を拡大しても劣化させたくない場合や、印刷向けの成果物が必要な場合に適している。

想定読者
--------

Python、NumPy、Pillow（PIL）、matplotlib について、基本的な使い方は既に理解していることを前提とする。これらのライブラリ自体の入門的な説明（配列操作、画像オブジェクトの扱い方など）は本資料では行わない。

一方で、ジェネラティブアート特有の話題（ノイズ関数、フラクタル、パーティクルシステムなど）については前提知識を仮定せず、都度説明する。
