タイリングパターン
====================

トルシェ・タイル
------------------

**トルシェ・タイル**\ （Truchet tiles）は、正方形の格子に決まった数種類の「タイル」を 1 枚ずつ並べていくだけの単純な仕組みでありながら、タイルごとの向き（回転）を変えるだけで、迷路のように入り組んだ連続的な模様が生まれる技法である。:doc:`basics`\ で触れた「パラメータを格子状に変えながら同じ描画関数を繰り返し呼び出す」というグリッド配置の考え方を、そのまま具体的な作品に落とし込んだものと言える。

古典的なトルシェ・タイルは、正方形の対角線上にある 2 つの角を中心とした、半径がタイルの半分の四分円弧 2 本から成る。弧の両端は必ず辺の中点に来るため、どちらの対角線に弧を配置するか（2 通りの向き）をタイルごとに選ぶだけで、隣り合うタイルの弧がつながり、途切れない曲線の連なりになる。

タイルの中身を変える
----------------------

タイルの模様そのものを差し替えるだけで、生成される模様の印象はまったく違うものになる。四分円弧の代わりに対角線 1 本だけを引くタイルにすると、弧のようにはなめらかにつながらず、山型・谷型が入り組んだジグザグ模様（ヘリンボーンに近い見た目）になる。

タイルの向きをノイズで決める
-------------------------------

向きの選び方を一様乱数からパーリンノイズに変えると、模様の印象が大きく変わる。:doc:`noise`\ の ``fbm2d`` の値の符号（正か負か）でタイルの向きを決めると、ノイズが近傍でなめらかに変化する性質がそのままタイルの向きの空間的なまとまりに反映され、ランダム配置のような無秩序さではなく、渦を巻いて流れるような有機的な模様になる。

   :language: python
   :pyobject: render_noise_tiling
   :caption: examples/truchet.py の render_noise_tiling 関数

.. image:: _static/gallery/truchet_noise.png
   :alt: パーリンノイズの符号でタイルの向きを決めたトルシェ・タイルパターン。流れるような有機的な模様になる

同じ「格子状にタイルを並べる」という骨格でも、(1) タイルの模様そのもの、(2) タイルの向きを決める規則、の 2 つを差し替えるだけで表現の幅は大きく広がる。タイルの種類を増やす（例えば直線・曲線・無地を混在させる）、あるいは向きの選び方に別の規則（例えば\ :doc:`shapes`\ のボロノイ図の領域ごとに向きをそろえる）を組み込むといった発展も考えられる。

組み紐模様（編み込み表現）
-----------------------------

ここまでの向きの選び方（乱数・ノイズ）は、いずれもタイル 1 枚 1 枚を独立に選んでよかった。しかし、タイルどうしが「上下関係」を持つような模様――例えば編み込みやバスケット編みのような表現――では、隣り合うタイルの選択が独立ではいられない。あるタイルで縦帯が横帯の上を通っていれば、その右隣・下隣のタイルでは、同じ縦帯・横帯が逆に下を通っていないと、編み目としてのつじつまが合わなくなるためである。

そこで、タイルごとに縦横どちらを上にするかを、``(row + col) % 2`` という市松模様の規則で決め打ちにする。ランダムに選んでしまうと、同じ帯が 2 マス連続で「上」になってしまい、編み込みが破綻する。

正方形以外のタイリング
------------------------

平面を隙間なく敷き詰められる正多角形は、正方形だけではない。正三角形・正方形・正六角形の 3 種類だけが、単独で平面を隙間なく埋め尽くせる正多角形であることが知られている（内角がそれぞれ 60 度・90 度・120 度で、頂点の周りにちょうど 360 度分並べられるため）。ここではトルシェ・タイルからいったん離れ、三角形・六角形それぞれの格子を作り、セルごとにランダムな色を塗ってみる。

正三角形格子は、上向き・下向きの三角形を交互に並べることで作れる。1 行に ``cols * 2`` 枚の三角形を並べ、それを ``rows`` 行分積み重ねる。

正方形は角が 4 つとも直角で規則正しい反面、やや硬い印象になりやすい。三角形はより鋭く動きのある、六角形はより有機的で自然物（蜂の巣、亀の甲羅など）を思わせる印象になる。トルシェ・タイルの弧や対角線を三角形・六角形のセルに合わせて設計し直せば、この 2 つの技法を組み合わせることもできる。

ワン・タイル（辺の制約充足）
------------------------------

ここまでのタイル選択は、乱数任せか、市松模様のような単純な決め打ちのどちらかだった。**ワン・タイル**\ （Wang tiles）は、これとは異なる第 3 の考え方――隣り合うタイルの辺が必ず一致するように配置する、制約充足に基づくタイリングを示す。

本来のワン・タイルは、あらかじめ用意したタイル集合の中から、周囲の制約を満たすタイルを探索して 1 枚ずつ配置していく。ここでは探索を行わない簡単な方法として、格子の内部にある縦線・横線それぞれに先にラベル（色）をランダムに割り当ててしまう。各タイルは、上下左右の境界線のラベルに従って 4 枚の三角形に塗り分けられるため、隣接するタイルの境界では、共有する線のラベルを通じて自動的に色が一致する。

隣接するタイルの同じ色の三角形どうしがつながり、タイルの境界をまたいだひし形の模様が浮かび上がる。トルシェ・タイルが「1 枚のタイルの中で完結する模様」だったのに対し、ワン・タイルは「タイルをまたいで初めて模様が完結する」という違いがある。

.. _wfc:

Wave Function Collapse（制約の伝播）
--------------------------------------

ワン・タイルの節では、辺のラベルを先に全て決めてしまうことで、探索をせずに隣接の制約を満たした。しかし、使えるタイルの種類が限られている場合、この方法は使えない。例えば、管が 1 辺にしかつながらない「行き止まり」のタイルを含まない配管タイルの組では、辺のラベルを独立に決めると、行き止まりのタイルが必要なセルが生じてしまう。**Wave Function Collapse**\ （WFC）は、Maxim Gumin が 2016 年に公開した手法で、こうした制約を満たすタイルの配置を、セルを 1 つずつ確定させながら求めていく。名前は量子力学の「波動関数の収縮」にちなむが、その中身は、制約充足問題の解法として知られる「制約の伝播」と「選択肢の少ない変数から決める」という工夫の組み合わせである。

WFC では、格子の各セルに、まだ置ける可能性のあるタイルの集合（候補）を持たせる。最初は全てのセルが全てのタイルを候補に持ち、次の 2 つの操作を、全てのセルの候補が 1 つになるまで繰り返す。

観測（observe）
   候補がもっとも少ないセルを 1 つ選び、候補の中から 1 枚をランダムに選んで確定させる。選択肢の少ないセルを後回しにすると、周りが先に決まって候補がなくなりやすいため、候補の少ないセルから決めていく。Gumin の実装では、候補の数の代わりに、タイルの重みを考慮したエントロピーがもっとも小さいセルを選ぶ。

伝播（propagate）
   確定したセルの隣のセルから、辺がつながらなくなった候補を取り除く。候補が減ると、さらにその隣のセルでも、つながる相手を失う候補が出ることがある。そのため、候補が変化しなくなるまで、この削減を連鎖的に繰り返す。

ここでは、上下左右の各辺に管がつながるかどうか（1 か 0）で決まる配管タイルを使う。4 辺の組み合わせ 16 通りのうち、行き止まりの 4 通りを除いた 12 枚で、隣り合うタイルは、接する辺の値が一致していなければならない。

   :width: 570px

伝播では、確定したセル（または候補が減ったセル）に残っている候補のどれか 1 つとでもつながるタイルだけを、隣のセルの候補に残す。候補が減ったセルはスタックに積み、スタックが空になるまで同じ処理を続ける。

格子の外周のセルは、外側へ向かう辺に管がつながらないタイルだけを候補として始める。そのため、管は全て画面の中で閉じる。途中で候補が 1 つも残らないセルが出る（矛盾する）と、それ以上は進められないため、本実装では最初からやり直している。この配管タイルの組では、作例と同じ条件で 50 回試しても矛盾は起きなかったが、タイルの組によっては矛盾が起きやすくなる。

タイルを選ぶときの重みを変えるだけで、同じ制約から印象の異なる模様が得られる。全てのタイルを同じ重みで選ぶと、管が密に入り組んだ網目になる（左）。空白と直線のタイルの重みを大きくし、分岐（T 字と十字）の重みを小さくすると、長い管がまばらに走る模様になる（右）。

Gumin の WFC には、本節で扱ったタイルの辺だけで隣接関係を決める方式（simple tiled model）のほかに、見本の画像から小さな局所パターンを切り出し、その重なり方を制約として使う方式（overlapping model）もある。後者を使うと、見本の画像に似た模様を任意の大きさで生成できる。

迷路生成アルゴリズム
-----------------------

ワン・タイルと WFC は、隣接するタイルの辺が一致するという制約を満たすようにタイルを選んでいた。**迷路**\ もまた、「隣り合うセルの間に壁を残すか、通路として開けるか」を、迷路全体が行き止まりなく 1 つにつながるように決める、セル間の関係を無視できないタイリングの一種として捉えられる。ここでは\ **再帰的バックトラッキング法**\ で迷路を生成する。

1. 全てのセルを未訪問、全ての壁をありとする。
2. 適当なセルから出発し、隣接する未訪問セルへランダムに移動しながら、通った壁を取り除く。今いるセルをスタックに積んでおく。
3. 未訪問の隣接セルがなくなったら、スタックを 1 つ戻って続きを探す。
4. スタックが空になったら終了する。

深さ優先探索でスタックに退避と復帰を繰り返しながら穴を掘り進めるこの手順は、スタックに「後で戻ってくる場所」を記録しながら木構造をたどる探索に共通する骨格を持つ（同じ考え方は、後の\ :doc:`fractals`\ で扱う L-system が ``[`` ``]`` でタートルの位置を退避・復帰させながら枝分かれを描く場面にも登場する）。実際、この手順は必ず「閉路を持たない、行き止まりのない 1 本道が張り巡らされた木構造の迷路」を作る。

迷路が閉路を持たない木構造であることから、2 点を結ぶ経路はそもそも 1 本しかない。したがって、幅優先探索でその唯一の経路を見つけるだけで最短経路（かつ唯一の経路）が求まる。

ワン・タイルや WFC が「隣接するタイルの辺の情報」から模様を決めていたのに対し、迷路生成は「これまでに訪れたセルの履歴」というスタックに依存する点が異なる。同じ格子を土台にしていても、セル間の関係をどう設計するか（独立に選ぶか、ラベルを一致させるか、制約を伝播させるか、訪問履歴を参照するか）によって、生成される構造の性質がまったく変わってくる。

.. _subdivision:

再帰的分割
------------

ここまでのタイリングは、大きさのそろったセルを格子状に並べることを出発点にしていた。**再帰的分割**\ （recursive subdivision）は逆に、画面全体を 1 つの領域とみなしてそれを分け、分けた領域それぞれにまた同じ分割を適用する、という再帰的な手続きで画面を区切っていく。分割を続けるか止めるかの規則を変えるだけで、区画の大きさの分布を自由に設計できる。

もっとも単純な例は、矩形を 2 つに分け続ける方法である。本実装では、矩形の長いほうの辺を、その 30〜70% の位置で分割する。分割が深くなるほど分割を止める確率を上げ（ただし最初の 2 段は必ず分割する）、辺が短くなりすぎる場合にも分割を止める。こうすると、大きな矩形と小さな矩形が混ざった構成になる。

   :caption: examples/subdivision.py の split_rect 関数

ペンローズ・タイル（非周期タイリング）
------------------------------------------

**ペンローズ・タイル**\ （Penrose tiling）は、2 種類のひし形だけを使いながら、どれだけ広げても平行移動に対して周期的にはならない、**非周期タイリング**\ の代表例である。5 回対称性（星形に象徴される、五角形由来の対称性）を持つ一方、通常の結晶格子のような並進対称性は持たない、という数学的に興味深い性質で知られる。

実装には、黄金比 :math:`\varphi = (1+\sqrt{5})/2` に基づく 2 種類の二等辺三角形（Robinson 三角形）を使う。細い三角形・太い三角形それぞれに決まった細分割規則を適用すると、1 枚の三角形が 2〜3 枚のより小さな三角形に分かれる。

.. math::

   \varphi = \frac{1 + \sqrt{5}}{2}

.. literalinclude:: ../examples/penrose.py
   :language: python
   :pyobject: subdivide_penrose
   :caption: examples/penrose.py の subdivide_penrose 関数

原点を囲むように細い三角形 10 枚を並べた「太陽」型の初期状態から出発し、この細分割を数回（作例では 6 回）繰り返すと、細分割のたびに三角形の数が増えながら、全体としては非周期的なペンローズ・タイリングに収束していく。

   :language: python

   :caption: examples/penrose.py の initial_sun 関数

隣接する同じ色の三角形 2 枚が、ペンローズ・タイルの太いひし形・細いひし形 1 枚に対応する。「小さな単位を規則に従って繰り返し書き換える」という発想は、後の\ :doc:`fractals`\ で扱う L-system の文字列書き換えとも共通するが、L-system が 1 次元の文字列を書き換えるのに対し、ペンローズ・タイルは 2 次元の三角形を書き換える点が異なる。

座標変換による放射状・渦巻き状パターン
------------------------------------------

ここまでの模様は、画素を全て直交座標 :math:`(x, y)` のまま扱ってきた。:doc:`basics`\ の「座標系の正規化」で触れた通り、座標をどう解釈するかは自由に設計できる。ある画像の各画素を、中心からの角度 :math:`\theta` と距離 :math:`r` という\ **極座標**\ に読み替えてから、既存の模様（横方向に継ぎ目なく繰り返せるもの）を読み出すと、横方向の繰り返しが中心の周りをぐるりと取り囲む放射状の模様に化ける。

.. math::

   \theta = \operatorname{atan2}(y - c_y,\ x - c_x)

.. math::

   r = \sqrt{(x - c_x)^2 + (y - c_y)^2}

.. literalinclude:: ../examples/polar_remap.py
   :language: python
   :pyobject: polar_remap
   :caption: examples/polar_remap.py の polar_remap 関数

トルシェ・タイルを横に長い帯状に敷き詰めた画像を土台にして、この関数で極座標に読み替えると、中心から放射状に広がる模様になる。

.. image:: _static/gallery/polar_remap.png
   :alt: 横長のトルシェ・タイル帯を極座標に読み替えて放射状にした画像
   :width: 350px

距離 :math:`r` の代わりに :math:`\log r` を使う\ **対数極座標**\ に切り替えると、印象はさらに変わる。対数を取ると、中心に近い場所ほど :math:`r` の小さな変化が :math:`\log r` の大きな変化として引き伸ばされるため、中心付近では模様が急激に圧縮され、外周に近づくほど元の模様がそのままの密度で見えるようになる。

.. image:: _static/gallery/polar_remap_log.png
   :alt: 同じ帯を対数極座標に読み替えた画像。中心に向かって模様が圧縮される
   :width: 350px

対数極座標は「距離が 2 倍になっても模様の見え方が変わらない」という\ **自己相似**\ （拡大縮小しても同じ形が繰り返し現れる性質）を持つ。この性質は、後の\ :doc:`fractals`\ で扱うフラクタル図形の中心的な特徴でもあり、対数極座標もまた拡大縮小に対して不変な構造を作れる一例だと言える。

対称性・万華鏡表現
--------------------

``polar_remap`` は、角度をソース画像の横方向にそのまま対応させることで、模様を中心の周りに 1 周分引き伸ばしていた。角度を ``2*pi/segments`` で割った余りに読み替えるだけで、ソース画像の同じ範囲が周囲に ``segments`` 回繰り返される回転対称模様になる。これは万華鏡の「筒を回すと同じ模様が繰り返し現れる」効果に対応する。

.. literalinclude:: ../examples/symmetry.py
   :language: python
   :pyobject: kaleidoscope_remap
   :caption: examples/symmetry.py の kaleidoscope_remap 関数

回転方向に単純に繰り返すだけでは、扇形の境界で模様が急に途切れてしまう。余りをさらに扇形の中点を頂点とした三角波として折り返す（``a -> wedge/2 - |a - wedge/2|``）と、隣り合う扇形どうしがちょうど鏡に映したように反転してつながり、境界がなめらかにつながる、実物の万華鏡そのものの見た目になる。

.. image:: _static/gallery/kaleidoscope_rotation.png
   :alt: 8 分割した扇形を回転方向にそのまま繰り返した模様。扇形の境界に継ぎ目が見える
   :width: 300px

.. image:: _static/gallery/kaleidoscope_mirror.png
   :alt: 同じ 8 分割を扇形の中点で鏡映してつないだ万華鏡模様。境界がなめらかにつながっている
   :width: 300px

同じ「座標を折り返してから模様を評価する」という発想は、平面を鏡映・回転で敷き詰める\ **壁紙群**\ （wallpaper group）の分類とも地続きである。ここでは中心 1 点からの角度を折り返したが、直交する 2 方向の座標をそれぞれ独立に鏡映すれば、正方形タイル 1 枚から市松模様のように敷き詰められる別の対称性も作れる。対称性の軸をどこに置き、何を折り返すかという選択肢の広さが、この技法の面白さになっている。

平面を平行移動で隙間なく敷き詰める模様がどのような対称性を持てるかは、数学的に完全に分類されており、可能な組み合わせはちょうど 17 種類しかないことが知られている（**壁紙群**、あるいは平面結晶群）。回転・鏡映・映進（鏡映と平行移動を組み合わせたもの）を平行移動と組み合わせられる自由度は無限にあるように思えるが、平面を隙間なく埋め尽くすという制約から、許される回転の対称性は 2 回・3 回・4 回・6 回のいずれかに限られる（5 回や 7 回以上の回転対称は、正五角形や正七角形が単独では平面を隙間なく敷き詰められないのと同じ理由で、周期的な壁紙模様とは両立しない）。この制限（**結晶学的制限定理**）のおかげで、組み合わせの総数が 17 という有限の数に収まる。

日本の伝統的な\ **和柄**\ には、この 17 種類のうちのいくつかを目で見て確かめられる実例が多い。市松模様は、色の違いを無視すれば正方形の格子がそのまま持つ対称性（4 回回転に加え、鏡映軸を格子線上と対角線上の両方に持つ、正方形格子の中でもっとも対称性の高い壁紙群 p4m）を体現しているし、麻の葉模様や亀甲模様は正六角形格子に由来する 6 回対称の壁紙群（p6m）、青海波のように同じ扇形模様を半個分ずつ横にずらしながら重ねていく模様は、扇形の中心を通る縦の鏡映軸と、その間を通る映進軸を持ち、回転対称を持たない壁紙群（cm）にそれぞれ対応する。どの和柄がどの壁紙群に属するかは、模様の中に回転中心・鏡映軸・映進軸がそれぞれ何種類あるかを数え上げれば判定でき、使う図形（正方形・六角形・扇形など）が違っていても、対称性という尺度で見れば同じ分類に属する模様どうしを結びつけられる。本資料ではこれ以上立ち入らないが、対称性による分類は、後の「双曲タイリング」で触れる\ **コクセター群**\ という、より一般的な鏡映群の枠組みの入り口にあたる。

双曲タイリング（ポアンカレディスク）
----------------------------------------

ここまでのタイリングは、正方形・正三角形・正六角形のように、1 つの頂点の周りに正多角形の内角がちょうど 360 度分だけ集まることで平面を隙間なく埋め尽くしていた。では、正五角形や正七角形ではどうなるだろうか。正五角形を 3 枚集めても内角の合計は 324 度にしかならず 360 度に届かず、逆に正七角形を 3 枚集めると約 385.7 度で 360 度を超えてしまう。平らな（ユークリッド）平面上では、この過不足はどうやっても解消できない。

しかし、平面を球面のように丸めれば内角の不足分を吸収でき（正五角形 3 枚は正十二面体の頂点に対応する）、逆に平面を鞍型に反らせれば内角の超過分を吸収できる。この「内角が 360 度を超える」タイリングが成り立つ空間が\ **双曲平面**\ であり、**ポアンカレディスク模型**\ は、この双曲平面全体を単位円板の内部に押し込めて平面上に描く方法である。円板の中心から境界に近づくほど、同じ双曲的な大きさの図形がユークリッド的にはどんどん小さく見える（境界そのものには到達できない、無限遠にあたる）という特徴があり、双曲的な直線（測地線）は、円板の中心を通る直線か、円板の境界に直交する円弧のどちらかとして現れる。

正 :math:`p` 角形を、1 つの頂点に :math:`q` 枚集めて双曲的に敷き詰めるタイリング :math:`\{p, q\}` を考える。中心・頂点・辺の中点の 3 点がなす直角三角形（角度は中心で :math:`\pi/p`、頂点で :math:`\pi/q`、辺の中点で直角）に双曲的な余弦定理を適用すると、最初の正多角形の外接円半径（ポアンカレディスク上でのユークリッド距離）が求まる。

.. math::

   r = \sqrt{\frac{\cos(\pi/p + \pi/q)}{\cos(\pi/p - \pi/q)}}

.. literalinclude:: ../examples/hyperbolic_tiling.py
   :language: python
   :pyobject: polygon_circumradius
   :caption: examples/hyperbolic_tiling.py の polygon_circumradius 関数

:math:`1/p + 1/q` が :math:`1/2` ちょうどなら平面（正方形や正六角形のタイリング）、:math:`1/2` を超えれば球面、:math:`1/2` 未満なら双曲平面になることが知られている。上の式は :math:`1/p+1/q < 1/2` のとき :math:`r` が実数かつ 1 未満になり、単位円板の内側に正しく収まる。

.. literalinclude:: ../examples/hyperbolic_tiling.py
   :language: python
   :pyobject: fundamental_polygon
   :caption: examples/hyperbolic_tiling.py の fundamental_polygon 関数

最初の正多角形ができたら、あとは先ほどのペンローズ・タイルが細分割によって内側から模様を増やしたのとは対照的に、この多角形を各辺に関して鏡映することでタイリングを中心から外側へ広げていく。円板境界に直交する円弧（または原点を通る直線に退化した特別な場合）に関する鏡映は、その円に関する反転として実装できる。測地線は単位円板に関する反転で不変という性質を使うと、2 頂点だけから鏡映に使う円を決定できる。

.. literalinclude:: ../examples/hyperbolic_tiling.py
   :language: python
   :pyobject: geodesic_reflection
   :caption: examples/hyperbolic_tiling.py の geodesic_reflection 関数

生成した多角形の重心座標を使って既出の多角形を除きながら、幅優先探索（本章で扱った迷路の経路探索と同じ考え方）で鏡映を繰り返し適用すると、中心から外側へ層状にタイリングが広がっていく。

.. literalinclude:: ../examples/hyperbolic_tiling.py
   :language: python
   :pyobject: generate_tiling
   :caption: examples/hyperbolic_tiling.py の generate_tiling 関数

:math:`\{7, 3\}`\ （七角形を 1 頂点に 3 枚）と :math:`\{6, 4\}`\ （六角形を 1 頂点に 4 枚）を、中心からの層の深さで暖色から寒色へ色を変えながら描画すると、次のようになる。境界に近づくほど多角形が指数的に小さくなっていく様子が、双曲平面をユークリッド平面に押し込めたことの現れである。

.. image:: _static/gallery/hyperbolic_7_3.png
   :alt: {7,3} 双曲タイリング。七角形を 1 頂点に 3 枚集めた非ユークリッドな敷き詰め模様
   :width: 350px

.. image:: _static/gallery/hyperbolic_6_4.png
   :alt: {6,4} 双曲タイリング。六角形を 1 頂点に 4 枚集めた敷き詰め模様
   :width: 350px

正多角形を辺に関して鏡映で敷き詰めるこの操作は、直前の対称性・万華鏡表現で扱った角度の折り返しや、壁紙群による平面の敷き詰めと同じ「鏡映を繰り返して模様を広げる」という発想の延長線上にある。こうした鏡映の繰り返しが生成する対称性の構造は、数学的には\ **コクセター群**\ （Coxeter group）と呼ばれる枠組みで統一的に扱われる。平面の壁紙群も、双曲平面のこの :math:`\{p, q\}` タイリングも、球面上の正多面体の対称性も、いずれも「いくつかの鏡映を生成元とする群」というコクセター群の特別な場合にあたる。
