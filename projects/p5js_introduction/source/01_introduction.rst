はじめに
========

p5.js とは
----------

p5.js は、ブラウザー上で図形を描いたり、アニメーションさせたり、マウスやキーボードの操作に反応させたりするプログラムを手軽に作るための JavaScript ライブラリです。Java ベースのプログラミング環境である Processing の考え方を Web に持ち込んだもので、Processing Foundation が中心となってオープンソースで開発しています。

p5.js では、数行のコードで絵を描き、それを動かせます。そのため、次のような用途で広く使われています。

* ジェネラティブアートやメディアアートの制作
* データの可視化やシミュレーションの試作
* プログラミング教育
* Web ページに埋め込む小さなインタラクティブコンテンツ

p5.js で作るプログラムは「:term:`スケッチ`」と呼ばれます。スケッチは HTML ファイルと JavaScript ファイルだけで構成され、ブラウザーさえあればどこでも動きます。

対象読者と前提知識
------------------

本書は次のような読者を想定しています。

* Python などで変数・関数・ループ・クラスを使ったプログラムを書いたことがある。
* JavaScript や HTML の経験はほとんどない。
* 絵や動きのあるプログラムを手軽に作ってみたい。

プログラミングの一般的な概念の説明は省略し、JavaScript と Python の違い、および p5.js 特有の考え方に重点を置いて説明します。

本書で扱うバージョン
--------------------

本書は p5.js 2.3.4 を対象とします。p5.js は 2025 年にバージョン 2.0 が公開され、外部ファイルの読み込み方法など、一部の書き方が 1.x 系から変わりました。Web 上の記事や書籍には 1.x 系を前提としたものがまだ多いため、主な違いを :doc:`appendix_a_versions` にまとめています。

サンプルの使い方
----------------

各章のサンプルには、次の 2 種類のリンクを付けています。

* **実行する**：ブラウザーでサンプルを開きます。
* **ダウンロード**：``sketch.js`` などのファイルを保存します。

サンプルは、章ごとに ``index.html`` と ``sketch.js`` を 1 つのフォルダーにまとめた構成です。ダウンロードしたファイルの使い方は :doc:`02_setup` で説明します。すべてのサンプルをまとめた `examples.zip <examples.zip>`__ も利用できます。

動作環境
--------

サンプルは、最新版の Google Chrome、Microsoft Edge、Mozilla Firefox、Safari で動作します。p5.js 本体はインターネット上の :term:`CDN` から読み込むため、実行時にはインターネット接続が必要です。

2 章で紹介するローカルサーバーを使う場合は、Python 3.10 以降が必要です。
