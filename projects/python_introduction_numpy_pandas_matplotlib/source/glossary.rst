用語集
======

本ドキュメントに登場する主な用語をまとめる。詳しい説明は、各用語に示したページを参照すること。

英字
----

.. glossary::

   axis
      numpy や pandas で、集計や結合を行う方向を指定する引数である。2 次元配列では、``axis=0`` を指定すると行方向に集約して列ごとの結果が得られ、``axis=1`` を指定すると列方向に集約して行ごとの結果が得られる。詳しくは「:doc:`numpy/aggregation`」を参照すること。

   Axes
      matplotlib で、1 つのグラフを描画する領域である。1 つの :term:`Figure` の中に複数の ``Axes`` を配置できる。詳しくは「:doc:`matplotlib/intro`」を参照すること。

   DataFrame
      pandas の表形式の 2 次元データである。複数の :term:`Series` を列として持つ。詳しくは「:doc:`pandas/dataframe`」を参照すること。

   dtype
      ``ndarray`` の要素や、pandas の列が持つデータ型である。``int64``、``float64``、``str`` などがある。詳しくは「:doc:`numpy/creation`」を参照すること。

   Figure
      matplotlib で、グラフ全体を表す図である。内部に 1 つ以上の :term:`Axes` を持つ。詳しくは「:doc:`matplotlib/intro`」を参照すること。

   MultiIndex
      pandas で、複数の階層を持つインデックスである。複数の列で ``groupby`` を行った結果などで使われる。詳しくは「:doc:`pandas/groupby`」を参照すること。

   NaN
      Not a Number の略で、pandas では\ :term:`欠損値`\ を表すために使われる。詳しくは「:doc:`pandas/missing`」を参照すること。

   ndarray
      numpy が提供する多次元配列である。同じ :term:`dtype` の要素を連続したメモリ領域に格納するため、要素ごとの演算を高速に実行できる。詳しくは「:doc:`numpy/intro`」を参照すること。

   rcParams
      matplotlib の既定の設定をまとめて保持している、辞書のようなオブジェクトである。フォントサイズや線の太さなどを一括で変更できる。詳しくは「:doc:`matplotlib/rcparams`」を参照すること。

   Series
      pandas のラベル（インデックス）付きの 1 次元データである。詳しくは「:doc:`pandas/series`」を参照すること。

   ufunc
      ユニバーサル関数とも呼ばれ、``np.sin`` や ``np.sqrt`` のように配列の要素ごとに処理を行う numpy の関数である。詳しくは「:doc:`numpy/operations`」を参照すること。

かな・漢字
----------

.. glossary::

   アクセサ
      pandas の ``Series`` から、特定の種類のデータ向けのメソッドを呼び出すための仕組みである。文字列用の ``.str``、日付・時刻用の ``.dt``、カテゴリ型用の ``.cat`` などがある。詳しくは「:doc:`pandas/series`」と「:doc:`pandas/datetime`」を参照すること。

   移動平均
      時系列データで、各時点について直近 N 件の値の平均をとったものである。日々のばらつきをならして、大まかな傾向をつかむために使う。詳しくは「:doc:`pandas/datetime`」を参照すること。

   インデックス
      pandas で、各行に付けられたラベルである。既定では 0 始まりの連番であるが、``set_index`` で任意の列をインデックスに設定できる。詳しくは「:doc:`pandas/selection`」を参照すること。

   回帰直線
      2 つの変数の関係を :math:`y = ax + b` の形の直線で表したものである。:term:`最小二乗法`\ で求める。詳しくは「:doc:`practice/correlation`」を参照すること。

   仮想環境
      プロジェクトごとに独立したパッケージのインストール先を用意する仕組みである。Python では ``venv`` で作成する。詳しくは「:doc:`setup/index`」を参照すること。

   カテゴリ型
      値の種類が少ない列を、整数のコードとカテゴリの対応表として保持する pandas のデータ型である。メモリ使用量を削減できる。詳しくは「:doc:`pandas/dataframe`」を参照すること。

   行列積
      数学的な意味での行列の掛け算である。numpy では ``@`` 演算子または ``np.matmul`` で計算する。要素ごとの掛け算を行う ``*`` とは異なる。詳しくは「:doc:`numpy/operations`」を参照すること。

   クロス集計
      2 つの項目を行と列に配置して、その組み合わせごとに値を集計した表である。pandas では ``pivot_table`` や ``unstack`` で作成する。詳しくは「:doc:`pandas/groupby`」を参照すること。

   欠損値
      データの中で値が存在しない箇所である。pandas では :term:`NaN` で表される。詳しくは「:doc:`pandas/missing`」を参照すること。

   決定係数
      回帰直線などのモデルがデータにどの程度当てはまっているかを表す、0 から 1 までの値である。1 に近いほどよく当てはまっていることを表す。詳しくは「:doc:`practice/correlation`」を参照すること。

   コピー
      元の配列とは別のメモリ領域に作成された配列である。コピーを変更しても元の配列は変わらない。:term:`ビュー`\ と対になる用語である。詳しくは「:doc:`numpy/indexing`」を参照すること。

   最小二乗法
      実際の値とモデルによる予測値の差の 2 乗の合計が最小になるように、モデルの係数を決める方法である。:term:`回帰直線`\ を求める際に使う。詳しくは「:doc:`practice/correlation`」を参照すること。

   シード
      乱数生成器に与える初期値である。同じシードを指定すると、実行するたびに同じ乱数列を再現できる。詳しくは「:doc:`numpy/random`」を参照すること。

   相関係数
      2 つの変数の間にある直線的な関係の強さを、-1 から 1 までの値で表す統計量である。numpy では ``np.corrcoef``、pandas では ``corr`` メソッドで計算する。詳しくは「:doc:`practice/correlation`」を参照すること。

   縦持ち・横持ち
      表の形式を表す用語である。項目の組み合わせごとに 1 行ずつ並べた形式を「縦持ち」、一方の項目を列に展開した形式を「横持ち」と呼ぶ。詳しくは「:doc:`pandas/groupby`」を参照すること。

   外れ値
      他の大多数の値から大きく離れた値である。センサーの不具合や記録ミスなどが原因で混入することがある。詳しくは「:doc:`practice/sensor`」を参照すること。

   ビュー
      元の配列と同じメモリを共有する配列である。スライスで得られる配列はビューになるため、ビューを変更すると元の配列も変わる。詳しくは「:doc:`numpy/indexing`」を参照すること。

   ブールインデックス
      真偽値の配列を使って、``True`` に対応する要素や行だけを抽出する方法である。詳しくは「:doc:`numpy/indexing`」と「:doc:`pandas/filtering`」を参照すること。

   ブロードキャスト
      形状の異なる配列同士の演算で、一定のルールに従って自動的に形状を揃えてから演算を行う仕組みである。詳しくは「:doc:`numpy/broadcasting`」を参照すること。

   ベクトル化
      ``for`` ループで要素を 1 つずつ処理する代わりに、配列や列全体に対する演算としてまとめて処理を記述することである。numpy や pandas では、ベクトル化した方が高速に動作する。詳しくは「:doc:`pandas/iteration`」を参照すること。
