インデックスとスライス
=======================

``ndarray`` の要素へのアクセスは、Python の list と似た記法に加えて、numpy 独自の便利な記法が用意されています。

基本的なインデックスとスライス
--------------------------------

.. code-block:: python

   import numpy as np

   a: np.ndarray = np.array([10, 20, 30, 40, 50])

   a[0]
   # 10

   a[-1]
   # 50  末尾の要素

   a[1:3]
   # array([20, 30])

多次元配列でのアクセス
------------------------

多次元配列では、``a[行, 列]`` のようにカンマ区切りで各次元を指定します。

.. code-block:: python

   m: np.ndarray = np.array([[1, 2, 3], [4, 5, 6]])

   m[0, 2]
   # 3  0 行目・2 列目の要素

   m[1, :]
   # array([4, 5, 6])  1 行目をすべて取得

   m[:, 1]
   # array([2, 5])  1 列目をすべて取得

ブールインデックス
--------------------

条件式から得られる真偽値の配列を使って、条件に合う要素だけを抽出できます。

.. code-block:: python

   a: np.ndarray = np.array([10, 20, 30, 40, 50])

   a > 25
   # array([False, False,  True,  True,  True])

   a[a > 25]
   # array([30, 40, 50])

np.where による値の作り分け
------------------------------

ブールインデックスは「条件に合う要素だけを抽出する」ものですが、「条件に応じて別の値に置き換えた、元と同じ形状の配列を作りたい」場合は ``np.where`` を使います。

.. code-block:: python

   temps: np.ndarray = np.array([18, 25, 31, 22, 35])

   np.where(temps >= 30, "hot", "normal")
   # array(['normal', 'normal', 'hot', 'normal', 'hot'], dtype='<U6')

``np.where(condition, x, y)`` は、``condition`` が ``True`` の要素には ``x``、``False`` の要素には ``y`` を割り当てた新しい配列を返します。``x`` / ``y`` にはスカラー値だけでなく、``condition`` と同じ形状の配列を渡すこともできます。

ファンシーインデックス
-------------------------

インデックスの配列（または ``list``）を指定すると、任意の位置の要素をまとめて取得できます。

.. code-block:: python

   a: np.ndarray = np.array([10, 20, 30, 40, 50])

   a[[0, 2, 4]]
   # array([10, 30, 50])

.. note::

   スライスで得られた配列は元の配列と同じメモリを共有する「ビュー」ですが、ブールインデックスやファンシーインデックスで得られる配列は元とは別の新しい配列（コピー）になります。

ビューを変更すると元の配列も変わる
-------------------------------------

「ビュー」は元の配列とメモリを共有しているため、ビュー側の要素を書き換えると、元の配列の値も一緒に変わってしまいます。意図せず元のデータを壊してしまわないよう、注意が必要です。

.. code-block:: python

   a: np.ndarray = np.array([10, 20, 30, 40, 50])

   view: np.ndarray = a[1:4]
   view[0] = 999

   print(view)
   # [999  30  40]

   print(a)
   # [ 10 999  30  40  50]  元の配列も変わってしまう

元の配列を変えずに済ませたい場合は、``copy()`` を使って明示的にコピーを作成してください。

.. code-block:: python

   safe_view: np.ndarray = a[1:4].copy()
   safe_view[0] = 999

   print(a)
   # [10 20 30 40 50]  copy() を使えば元の配列は変わらない
