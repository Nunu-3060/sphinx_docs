集約関数
========

配列全体に対する集計
----------------------

合計や平均、最大・最小などを計算する関数が用意されています。

.. code-block:: python

   import numpy as np

   a: np.ndarray = np.array([[1, 2, 3], [4, 5, 6]])

   a.sum()
   # 21

   a.mean()
   # 3.5

   a.max()
   # 6

   a.min()
   # 1

   a.std()
   # 標準偏差

axis を指定した集計
----------------------

多次元配列では、``axis`` 引数を指定することで、行方向・列方向など特定の方向についてのみ集計できます。

.. code-block:: python

   a: np.ndarray = np.array([[1, 2, 3], [4, 5, 6]])

   a.sum(axis=0)
   # array([5, 7, 9])  列ごとの合計（行方向に集約）

   a.sum(axis=1)
   # array([ 6, 15])  行ごとの合計（列方向に集約）

``axis=0`` は「0 番目の次元（行）に沿って集約する」という意味になり、結果として各列の値がまとめられます。``axis=1`` はその逆で、各行の値がまとめられます。慣れないうちは、実際に小さな配列で試してみると理解しやすくなります。

その他の集計関数
------------------

最大値・最小値そのものだけでなく、その「位置（インデックス）」を知りたい場合は ``argmax`` / ``argmin`` を使います。また、中央値や分散も専用の関数・メソッドで計算できます。

.. code-block:: python

   a: np.ndarray = np.array([[1, 5, 2], [8, 3, 9]])

   a.argmax()
   # 5  全体を 1 次元とみなしたときの最大値の位置

   a.argmax(axis=1)
   # array([1, 2])  各行における最大値の位置

   a.argmin()
   # 0  全体を 1 次元とみなしたときの最小値の位置

   np.median(a)
   # 4.0  中央値

   a.var()
   # 分散

.. note::

   ``argmax`` / ``argmin`` は ``ndarray`` のメソッドとして呼び出せますが、``median`` はメソッドではなく ``np.median()`` のように関数として呼び出す点に注意してください。

累積計算
----------

``sum`` や ``mean`` はすべての要素を 1 つの値にまとめますが、``cumsum`` / ``cumprod`` は「そこまでの累積値」を、元の配列と同じ要素数の配列として返します。

.. code-block:: python

   a: np.ndarray = np.array([[1, 5, 2], [8, 3, 9]])

   a.cumsum()
   # array([ 1,  6,  8, 16, 19, 28])  累積和

   np.array([1, 2, 3, 4]).cumprod()
   # array([ 1,  2,  6, 24])  累積積

``cumsum`` / ``cumprod`` も ``axis`` 引数を指定することで、行方向・列方向を指定して累積計算できます。
