numpy/pandas/matplotlib 入門
================================

このドキュメントは numpy、pandas、matplotlib の基本的な使い方を学ぶための入門資料である。

本ドキュメントの目的
----------------------

numpy と pandas を用いてデータの数値計算・集計を行い、その結果を matplotlib で可視化するという一連の流れを習得することを目的としている。

対象読者
--------

本ドキュメントは、以下を満たす人を対象としている。

- Python の基本的な使用方法（変数、関数、制御構文など）を理解している人
- Windows 環境を使用している人
- 基本的な統計量（平均、標準偏差、正規分布など）の意味を理解している人
