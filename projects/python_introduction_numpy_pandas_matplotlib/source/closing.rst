おわりに
========

これまでの振り返り
--------------------

本ドキュメントでは、numpy で数値データを配列として扱い、pandas で表形式のデータを集計し、その結果を matplotlib でグラフとして可視化するという一連の流れを紹介してきた。環境構築から始まり、各ライブラリの基本的な使い方を経て、最後の「実務での活用例」では、これらを組み合わせて実際のデータ分析に近い形の例に取り組んだ。ここまでの内容で、自分の手元にあるデータを読み込み、集計し、グラフにまとめるという一連の作業を進められるようになっているはずである。

実務で困ったときの調べ方
--------------------------

numpy、pandas、matplotlib は、本ドキュメントで紹介した以外にも非常に多くの機能を持っている。本ドキュメントに載っていない機能に出会ったときは、まず公式サイトのドキュメントを調べてみるとよい。

- `numpy 公式サイト <https://numpy.org/>`_
- `pandas 公式サイト <https://pandas.pydata.org/>`_
- `matplotlib 公式サイト <https://matplotlib.org/>`_

特に pandas と matplotlib は API が豊富なので、「やりたいこと」をそのまま検索したり、公式サイトのサンプルギャラリー（matplotlib であれば「matplotlib gallery」）を眺めたりすると、目的のグラフや処理の手がかりが見つかることがよくある。

つまずいたときによく出会うエラー・警告には、次のようなものがある。エラーメッセージやクラス名で検索すると、原因と対処法が見つかることがほとんどである。

- ``KeyError``: 存在しない列名やラベルを指定したときに発生する。
- ``ValueError``\ （``operands could not be broadcast together`` や ``shapes ... not aligned`` など）: numpy の配列同士の形状が合わず、ブロードキャストや行列積ができないときに発生する。
- ``ChainedAssignmentError``: ``df["age"][0] = 31`` のように ``[]`` を連ねて値を代入（連鎖代入）したときに出る警告である。pandas 3.0 以降ではこの書き方で元の ``DataFrame`` は変更されないため、``df.loc[0, "age"] = 31`` のように ``loc`` を使って 1 回で代入すること。
- ``Pandas4Warning``: pandas 4.0 で削除・変更が予定されている機能を使ったときに出る警告である。たとえば ``inplace=True`` を指定すると出る。警告メッセージに示された代わりの書き方（``inplace`` であれば戻り値の代入）に書き換えること。

次のステップ
--------------

本ドキュメントでは扱わなかったが、実務でデータを扱っていくと、次のような話題に出会うことがある。興味を持ったキーワードから調べてみると、理解の幅が広がる。

- **pandas のマルチインデックスの応用**: 複数キーの ``groupby`` の結果が ``MultiIndex`` になることや、``loc`` での階層アクセス、``unstack``/``stack`` の基本は「:doc:`pandas/groupby`」で扱ったが、列側を階層化した ``MultiIndex`` や、階層の順序を入れ替える ``swaplevel``、特定の階層だけを取り出す ``xs`` など、より高度な使い方もある。
- **pandas の resample**: 時系列データを「週単位」「月単位」のようにまとめ直す機能。本ドキュメントで扱った ``rolling`` と合わせて使われる。
- **seaborn**: matplotlib をベースにした、統計的なグラフ（分布の比較や相関関係の可視化など）を簡潔に描けるライブラリ。
- **numpy の線形代数（np.linalg）の応用**: 内積・逆行列・行列式・連立一次方程式の解法といった基本は「:doc:`numpy/linalg`」で扱ったが、固有値・固有ベクトル（``np.linalg.eig``）や特異値分解（``np.linalg.svd``）など、より高度な行列計算の機能もある。
- **scipy**: numpy の配列を土台に、より高度な科学技術計算（最適化、統計、信号処理、より充実した線形代数など）を提供するライブラリ。``np.linalg`` で物足りなくなったら次に検討する選択肢である。
- **statsmodels**: 回帰分析などの統計モデルを扱うライブラリ。「:doc:`practice/correlation`」で扱った回帰直線に加えて、複数の変数を使う重回帰分析や、係数が統計的に意味を持つかどうかの検定などを行える。
- **scikit-learn**: numpy、pandas、scipy を基盤にした機械学習ライブラリ。集計・可視化の次のステップとして、データからの予測や分類に取り組みたくなったときに使う。
- **Jupyter Notebook**: numpy、pandas、matplotlib を対話的に試しながら分析を進めるための実行環境。本ドキュメントではコンソールでのスクリプト実行を前提にしてきたが、実際のデータ分析では Notebook 上で試行錯誤しながら進めることも多くある。

最後に
--------

ライブラリの使い方は、実際に自分の手元にあるデータで試してみることで一番早く身につく。本ドキュメントの内容を土台に、ぜひ自分のデータで numpy、pandas、matplotlib を使ってみてほしい。
