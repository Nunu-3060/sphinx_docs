用語集
======

本資料で使う主な用語をまとめる。用語は英字、五十音の順に並べている。本文中の用語のリンクからこのページに移動できる。各用語の詳しい説明は、末尾に示した章を参照のこと。

英字
----

.. glossary::

   CIE XYZ
      CIE（国際照明委員会）が 1931 年に定めた表色系。人間が見分けられる全ての色を 3 つの値 X、Y、Z で表す。Y は輝度に比例する。色空間どうしの変換の中継点として使われる。（:doc:`color_spaces`）

   CIELAB
      CIE が 1976 年に定めた色空間。明度 :math:`L^*` と、2 つの色度の軸 :math:`a^*`、:math:`b^*` で色を表す。座標の距離が見た目の差にほぼ比例するように作られている。:math:`L^*a^*b^*` 表色系ともいう。（:doc:`color_spaces`）

   CMYK
      印刷に使うシアン（C）、マゼンタ（M）、イエロー（Y）、黒（K）の 4 色のインキ、またはその網点の面積率による色の指定。同じ値でも、印刷条件によって色が変わる。（:doc:`print`）

   HSV
      色を色相（H）、彩度（S）、明度（V）の 3 つの値で表す方法。sRGB の値から簡単な計算で求められるが、V は人間が感じる明るさを表さない。似た方法に HSL がある。（:doc:`color_spaces`）

   ICC プロファイル
      機器や印刷条件ごとの色の特性を記述したファイル。機器の値（RGB や CMYK）と、機器に依存しない色空間（CIELAB など）の値の対応を表す。カラーマネジメントに使う。（:doc:`print`）

   OKLab
      Björn Ottosson が 2020 年に発表した色空間。明度 :math:`L` と 2 つの色度の軸 :math:`a`、:math:`b` で色を表す。CIELAB より色相のずれが小さく、見た目に均等な配色やグラデーションの作成に向いている。（:doc:`color_spaces`）

   OKLCH
      OKLab の :math:`(a, b)` 平面を極座標で表したもの。明度 :math:`L`、彩度 :math:`C`、色相角 :math:`h` で色を指定できる。（:doc:`color_spaces`）

   sRGB
      ディスプレイと Web で標準的に使われる色空間。国際規格 IEC 61966-2-1 で定められている。値はガンマ補正されており、光の強さに比例しない。（:doc:`color_spaces`）

   WCAG
      W3C が定めた Web のアクセシビリティの指針（Web Content Accessibility Guidelines）。コントラスト比や色の使用についての達成基準を含む。（:doc:`accessibility`）

あ行
----

.. glossary::

   アクセントカラー
      目立たせたい部分にだけ、小さな面積で使う色。配色の面積比の目安では、全体の 5% 程度とされる。（:doc:`harmony`）

   網点
      印刷で濃淡を表現するための、インキを付ける小さな点。点の大きさや密度で濃さを変える。（:doc:`print`）

か行
----

.. glossary::

   加法混色
      光を重ねて色を作る方法。赤、緑、青を三原色とし、混ぜるほど明るくなる。ディスプレイが使う。（:doc:`basics`）

   ガマットマッピング
      色域の外の色を、色域の中の色に置き換える処理。本資料では、明度と色相を保ったまま彩度を下げる方法を使う。（:doc:`color_spaces`）

   カラースケール
      1 つの基準の色から、明るさの異なる色を段階的に並べたもの。UI の配色では、50 から 900 までの段階の名前を付けることが多い。（:doc:`palette`、:doc:`ui`）

   カラーマップ
      データの値を色に対応させる規則。連続、発散、カテゴリの 3 種類がある。（:doc:`dataviz`）

   ガンマ補正
      色の値と光の強さの関係を非線形にする変換。sRGB では、人間の目の感度に合わせて、暗い側に多くの段階を割り当てている。（:doc:`color_spaces`）

   減法混色
      光を吸収する色材を重ねて色を作る方法。シアン、マゼンタ、イエローを三原色とし、混ぜるほど暗くなる。印刷や絵の具が使う。（:doc:`basics`）

   コントラスト比
      2 色の相対輝度から求める、明るさの差の指標。1 から 21 までの値を取る。WCAG では、通常の文字に 4.5 以上を求めている。（:doc:`accessibility`）

さ行
----

.. glossary::

   彩度
      色の鮮やかさ。彩度が低いほど灰色に近づく。色の三属性の 1 つ。OKLCH では :math:`C` で表す。（:doc:`basics`）

   色域
      ある色空間や機器で表現できる色の範囲。sRGB の色域と印刷の色域は一致しない。（:doc:`color_spaces`、:doc:`print`）

   色差
      2 色の見た目の差を表す値。CIELAB の 2 色の間のユークリッド距離 :math:`\Delta E^*_{ab}` がよく使われる。（:doc:`color_spaces`）

   色相
      赤、黄、緑、青のような色味の種類。色の三属性の 1 つ。（:doc:`basics`）

   色相環
      色相を環状に並べたもの。HSV、伝統的な絵の具（RYB）、PCCS など種類があり、種類によって補色の組が変わる。（:doc:`harmony`）

   条件等色
      波長の成分が異なる 2 つの光が、同じ色に見える現象。メタメリズムともいう。（:doc:`basics`）

   錐体
      網膜にあり、明るい場所で色を感じ取る細胞。S、M、L の 3 種類がある。（:doc:`basics`）

   相対輝度
      線形な sRGB の値に重みを掛けて足した、明るさの値。黒が 0、白が 1 である。コントラスト比の計算に使う。（:doc:`accessibility`）

た行
----

.. glossary::

   同時対比
      隣り合う色の影響を受けて、色が実際とは違って見える現象。明度対比、色相対比、彩度対比がある。（:doc:`basics`）

   トークン
      UI の配色で、色の役割に付けた名前（text、primary など）と、その役割に割り当てた色。部品はトークンを通して色を参照する。（:doc:`ui`）

   特色
      CMYK の掛け合わせではなく、目的の色に調合したインキ。ロゴの色などを安定して再現するために使う。（:doc:`print`）

   トーン
      明度と彩度を組み合わせた色の調子。同じトーンの色は、色相が違っても似た印象を与える。（:doc:`harmony`）

   ドットゲイン
      印刷で、インキのにじみによって網点が指定より大きくなる現象。中間調が暗く刷り上がる。（:doc:`print`）

は行
----

.. glossary::

   白色点
      色空間で白とみなす光の色。sRGB と本資料の CIELAB の計算では、昼光に近い D65 を使う。（:doc:`color_spaces`）

   ベースカラー
      背景など、最も広い面積に使う色。配色の面積比の目安では、全体の 70% 程度とされる。（:doc:`harmony`）

   補色
      色相環の上で向かい合う位置にある 2 色。互いの色味を最も強く引き立て合う。（:doc:`harmony`）

ま行
----

.. glossary::

   明度
      色の明るさ。色の三属性の 1 つ。本資料では、人間が感じる明るさの尺度として、OKLab の :math:`L` や CIELAB の :math:`L^*` を使う。HSV の V とは異なる。（:doc:`basics`、:doc:`color_spaces`）

   メインカラー
      全体の印象を決める主役の色。配色の面積比の目安では、全体の 25% 程度とされる。（:doc:`harmony`）

   面積効果
      同じ色でも、塗る面積が大きいほど明るく、鮮やかに見える現象。（:doc:`basics`）
