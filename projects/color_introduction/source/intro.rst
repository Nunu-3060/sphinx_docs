はじめに
========

本資料の目的
------------

アプリケーションの画面、グラフ、図解、CG の作品など、色を使う場面は多い。色を感覚だけで決めると、次のような問題が起こりやすい。

* 色の数が増えるほど、画面全体のまとまりがなくなる。
* 画面を暗い背景の配色（ダークテーマ）に切り替えたときに、文字が読みにくくなる。
* グラフの色の違いが、見る人によっては区別できない。
* データの値の大小と、色から受ける印象の強弱が一致しない。

本資料では、これらの問題を避けるために、色を「数値で扱えるもの」として理解し、配色を根拠をもって決める方法を学ぶ。色彩学の理論だけでなく、Python で色を計算して図を作る例も示す。

対象とする読者
--------------

* UI やグラフの配色を自分で決める必要があるエンジニア
* 配色の良し悪しを、感覚ではなく言葉と数値で説明したい人
* Python で画像やグラフを生成し、その色を調整したい人

プログラミングの経験があり、Python と NumPy の基本的な書き方を知っていることを前提とする。色彩学やデザインの予備知識は必要ない。

実行環境
--------

サンプルコードは次の環境で動作を確認している。型ヒントの書き方とフォントの読み込み方の都合で、Python 3.10 以降、Pillow 10.1 以降を必要とする。

.. list-table::
   :header-rows: 1
   :widths: 25 25 50

   * - ソフトウェア
     - バージョン
     - 用途
   * - Python
     - 3.14.6
     - サンプルコードの実行
   * - NumPy
     - 2.5.1
     - 色の変換の計算
   * - Pillow
     - 12.3.0
     - 画像の作成と保存

必要なパッケージは次のコマンドでインストールできる。

.. code-block:: console

   pip install numpy pillow

各スクリプトは、図の画像を保存するディレクトリをコマンドライン引数で受け取る。引数を省略すると、カレントディレクトリの ``output`` に保存する。

.. code-block:: console

   cd examples
   python color_basics.py

どのスクリプトも、色の変換に共通モジュールの ``color_utils.py`` を使う。そのため、スクリプトは ``color_utils.py`` と同じディレクトリに置いて実行する。サンプルコードは\ :doc:`code`\ からまとめてダウンロードできる。

表記について
------------

本資料では、次のように表記する。

* sRGB の各成分の値は、特に断らない限り 0.0 から 1.0 の実数で表す。画像ファイルに保存する 0 から 255 の整数の値は、255 で割ると 0.0 から 1.0 の値になる。
* 色は ``#2f6fb0`` のような 16 進数のカラーコードで示すことがある。先頭から 2 桁ずつが R、G、B の値（00 から ff）を表す。
* 図の中のラベルは、画像の生成に使ったフォントの都合で英語で記す。
