色彩設計入門
============

本資料は、画面やグラフ、画像の色を根拠をもって決めるための基礎知識と手法をまとめたものである。色が見える仕組みと色空間の考え方から始め、配色の基本、パレットの作り方、データ可視化とアクセシビリティへの配慮を経て、UI の配色設計と印刷物の配色までを扱う。
