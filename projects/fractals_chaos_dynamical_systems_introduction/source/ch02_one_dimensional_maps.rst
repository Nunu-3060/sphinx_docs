第 2 章 1 次元写像の反復
========================

状態が 1 つの実数で表される、最も簡単な離散時間の力学系 :math:`x_{n+1} = f(x_n)` を調べる。1 次元写像は簡単だが、固定点の安定性、周期軌道、そして第 4 章以降で扱うカオスまで、力学系の重要な概念がほぼすべて現れる。また、グラフを使って反復の様子を目で追えるので、直観を養うのに適している。

クモの巣図
----------

写像の反復を図で追う方法に、\ **クモの巣図**\ （cobweb plot）がある。横軸を :math:`x_n`、縦軸を :math:`x_{n+1}` とする平面に、関数 :math:`y = f(x)` のグラフと対角線 :math:`y = x` を描き、次の手順で線を引く。

1. 横軸上の初期値 :math:`x_0` から縦に進み、グラフ上の点 :math:`(x_0, f(x_0)) = (x_0, x_1)` に至る。
2. そこから横に進み、対角線上の点 :math:`(x_1, x_1)` に至る。対角線の上では縦と横の座標が等しいので、これで :math:`x_1` を横軸の値に移したことになる。
3. そこから縦に進み、グラフ上の点 :math:`(x_1, x_2)` に至る。以下、2 と 3 を繰り返す。

この手順を実装したのが次の関数である。点 :math:`(x, x)` から :math:`(x, f(x))`、:math:`(f(x), f(x))` へと順に進む折れ線の頂点を、リスト ``px`` と ``py`` に追加していく。

グラフと対角線が交わる点では :math:`f(x) = x` が成り立つ。つまり、交点は固定点である。クモの巣図を描くと、軌道が固定点に吸い込まれるのか、固定点から離れていくのかが一目で分かる。

固定点の安定性
--------------

線形写像
^^^^^^^^

まず、最も簡単な線形写像 :math:`f(x) = a x` を考える。固定点は :math:`x^* = 0` で、軌道は :math:`x_n = a^n x_0` となる。したがって、

* :math:`|a| < 1` なら、:math:`x_n` は 0 に近づく。
* :math:`|a| > 1` なら、:math:`|x_n|` は限りなく大きくなる。
* :math:`a < 0` なら、:math:`x_n` の符号が毎回反転し、0 の両側を交互に行き来する。

:numref:`fig-ch02-linear` は、:math:`a = 0.5`、:math:`-0.5`、1.5、:math:`-1.5` の 4 つの場合のクモの巣図である。:math:`a > 0` では軌道は階段状に、:math:`a < 0` では渦巻き状になる。

   :name: fig-ch02-linear

   線形写像 :math:`f(x) = a x` のクモの巣図。:math:`|a| < 1` では固定点 0 に近づき、:math:`|a| > 1` では離れていく。

一般の写像と線形化
^^^^^^^^^^^^^^^^^^

一般の写像 :math:`f` についても、固定点 :math:`x^*` のごく近くでは、:math:`f` を 1 次式で近似できる（:ref:`付録 A <appendix-a>` のテイラー展開を参照）。

.. math::

   f(x) \approx f(x^*) + f'(x^*)(x - x^*) = x^* + f'(x^*)(x - x^*)

固定点からのずれを :math:`\varepsilon_n = x_n - x^*` とおくと、:math:`\varepsilon_{n+1} \approx f'(x^*)\,\varepsilon_n` となる。これは係数が :math:`a = f'(x^*)` の線形写像である。このように、固定点の近くの振る舞いを 1 次式で近似することを\ **線形化**\ （linearization）という。線形写像の結果から、次の判定法が得られる。

.. math::
   :label: eq-ch02-stability

   |f'(x^*)| < 1 \;\Rightarrow\; \text{安定}, \qquad |f'(x^*)| > 1 \;\Rightarrow\; \text{不安定}

近くの軌道を引き寄せる固定点を\ **安定**\ （stable）な固定点、または\ **吸引的**\ （attracting）な固定点という。近くの軌道を遠ざける固定点を\ **不安定**\ （unstable）な固定点、または\ **反発的**\ （repelling）な固定点という。:math:`|f'(x^*)| = 1` のときは、1 次の近似だけでは安定性を判定できない。このような場合は、次の節で見るように、パラメータを変えたときに振る舞いが質的に変わる境目になることが多い。

ロジスティック写像の固定点
--------------------------

第 1 章で紹介したロジスティック写像

.. math::

   f(x) = r x (1 - x), \qquad 0 \le x \le 1,\quad 0 < r \le 4

の固定点を調べる。:math:`r x (1 - x) = x` を解くと、固定点は :math:`x^* = 0` と :math:`x^* = 1 - 1/r` の 2 つである（後者は :math:`r > 1` のときに区間 :math:`[0, 1]` に入る）。微分は :math:`f'(x) = r(1 - 2x)` なので、

* :math:`x^* = 0` では :math:`f'(0) = r`。:math:`r < 1` で安定、:math:`r > 1` で不安定。
* :math:`x^* = 1 - 1/r` では :math:`f'(x^*) = 2 - r`。:math:`1 < r < 3` で安定、:math:`r > 3` で不安定。

:numref:`fig-ch02-logistic` は、:math:`r = 2.8`、3.2、3.9 のクモの巣図である。

.. figure:: ../build/generated/figures/ch02_cobweb_logistic.png
   :name: fig-ch02-logistic
   :width: 100%

   ロジスティック写像のクモの巣図（初期値 :math:`x_0 = 0.1`）

:math:`r = 2.8` では、軌道は渦を巻きながら固定点に近づく。:math:`f'(x^*) = -0.8` が負なので、固定点の両側を交互に行き来しながら近づく。:math:`r = 3.2` では :math:`f'(x^*) = -1.2` となり、固定点は不安定になる。軌道は固定点から離れていくが、無限に遠くへ行くわけではなく、四角形の経路を繰り返しなぞるようになる。これは 2 つの値を交互にとる周期軌道である。:math:`r = 3.9` では、軌道は一定の経路に落ち着かず、区間のあちこちを不規則に動き回る。

周期軌道
--------

:math:`f(p) = q`、:math:`f(q) = p`\ （:math:`p \ne q`）を満たす 2 点 :math:`p, q` は、軌道 :math:`p, q, p, q, \ldots` を作る。このような軌道を\ **周期 2 の軌道**\ といい、:math:`p` と :math:`q` を\ **周期点**\ （periodic point）という。一般に、:math:`f^k(p) = p` を満たす最小の正の整数 :math:`k` を、周期点 :math:`p` の周期という。

周期 2 の点は、2 回反復した写像 :math:`f^2 = f \circ f` の固定点である。したがって、周期軌道の問題は、:math:`f^2` の固定点の問題に帰着できる。:numref:`fig-ch02-second` は、:math:`r = 3.2` のロジスティック写像 :math:`f` と :math:`f^2` のグラフである。:math:`f^2` のグラフは対角線と 4 点で交わる。そのうち 2 点は :math:`f` の固定点（0 と :math:`1 - 1/r`）で、残りの 2 点が周期 2 の点 :math:`p, q` である。

.. figure:: ../build/generated/figures/ch02_cobweb_second.png
   :name: fig-ch02-second
   :width: 70%

   :math:`r = 3.2` のロジスティック写像 :math:`f` と、2 回反復した写像 :math:`f^2`

周期軌道の安定性も、:math:`f^2` の固定点としての安定性で判定できる。合成関数の微分の公式（連鎖律）から、

.. math::

   (f^2)'(p) = f'(f(p))\,f'(p) = f'(q)\,f'(p)

である。この値は :math:`p` と :math:`q` のどちらで計算しても同じになり、軌道全体の安定性を表す。ロジスティック写像では、:math:`p, q` は :math:`r^2 x^2 - r(r + 1)x + (r + 1) = 0` の 2 つの解で、計算すると :math:`f'(p)\,f'(q) = -r^2 + 2r + 4` となる。:math:`r = 3.2` では 0.16 となり、周期 2 の軌道は安定である。この値の絶対値が 1 未満になるのは :math:`3 < r < 1 + \sqrt{6} \approx 3.449` のときである。:math:`r` が :math:`1 + \sqrt{6}` を超えると周期 2 の軌道も不安定になり、次は周期 4 の軌道が現れる。この現象は第 4 章で詳しく扱う。

ニュートン法を力学系として見る
------------------------------

方程式 :math:`g(x) = 0` を数値的に解く\ **ニュートン法**\ （Newton's method）は、写像

.. math::

   N(x) = x - \frac{g(x)}{g'(x)}

の反復である。:math:`g(x^*) = 0` なら :math:`N(x^*) = x^*` なので、方程式の解は :math:`N` の固定点である。:math:`N` を微分すると :math:`N'(x) = g(x)\,g''(x) / g'(x)^2` となり、解では :math:`N'(x^*) = 0`\ （:math:`g'(x^*) \ne 0` の場合）である。微分係数が 0 の固定点を\ **超安定**\ （superstable）な固定点という。超安定な固定点の近くでは、:math:`\varepsilon_{n+1} \approx C\,\varepsilon_n^2`\ （:math:`C` は定数）となり、誤差が 1 回ごとに 2 乗で小さくなる。

:math:`g(x) = x^2 - 2` とすると :math:`N(x) = (x + 2/x)/2` となり、反復は :math:`\sqrt{2}` に収束する。:numref:`fig-ch02-newton` はそのクモの巣図、次の出力は、初期値 1 から 50 桁の精度で反復した結果である（図と出力では初期値が違うが、どちらも同じように収束する）。誤差の指数がほぼ 2 倍ずつ増え、正しい桁数が 1 回ごとにほぼ倍になる様子が分かる。

ニュートン法は、解の近くから始めれば非常に速く収束する。しかし、解が複数ある方程式を複素数の範囲で解くと、どの解に収束するかが初期値によって複雑に入り組み、フラクタルな境界が現れる。これは第 9 章で扱う。

まとめ
------

* クモの巣図を使うと、1 次元写像の反復をグラフ上で追える。グラフと対角線の交点が固定点である。
* 固定点 :math:`x^*` は、:math:`|f'(x^*)| < 1` なら安定、:math:`|f'(x^*)| > 1` なら不安定である。
* 周期 :math:`k` の点は :math:`f^k` の固定点であり、その安定性は軌道上の微分係数の積で判定できる。
* ロジスティック写像は、:math:`r` が 3 を超えると固定点が不安定になり、周期 2 の軌道が現れる。
* ニュートン法は、解を超安定な固定点とする写像の反復であり、誤差が 2 乗で小さくなる。
