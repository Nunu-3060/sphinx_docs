はじめに
========

本書の目的
----------

ジェネラティブアートの作品には、ストレンジアトラクタ、マンデルブロ集合、L-system の植物、反応拡散の模様など、「単純な規則から複雑な形が生まれる」題材が繰り返し登場する。これらの題材は、見た目は違っても、数学的には同じ土台の上にある。それが力学系（dynamical system）の理論である。

本書の目的は、次の 3 つの分野を、1 本の流れとしてつなげて理解することである。

* **力学系**：状態を規則に従って更新し続ける仕組み。写像の反復や微分方程式で表す。
* **カオス**：力学系が、決定論的（偶然の要素がない）であるにもかかわらず、長期的には予測できない振る舞いを示す現象。
* **フラクタル**：どこまで拡大しても細かな構造が現れる図形。カオス的な力学系は、ストレンジアトラクタやジュリア集合のようなフラクタルを生み出す。

本書を読み終えると、次のことができるようになる。

* 写像の反復と微分方程式を Python で計算し、時系列、相空間の軌道、分岐図を描ける。
* カオスを、初期値鋭敏性やリアプノフ指数によって定量的に判定できる。
* フラクタルの次元を、定義に従って計算し、数値的に推定できる。
* ストレンジアトラクタ、IFS、ジュリア集合などを、作品として見栄えよく描くための技法を使える。

対象読者と前提知識
------------------

本書は、創発やジェネラティブアートに興味があり、Python でプログラムを書けるエンジニアを対象とする。次の知識を前提とする。

* Python の基本的な文法と、NumPy の配列、matplotlib のグラフの基本的な使い方
* 高校数学程度の知識（関数、微分の意味、ベクトル、複素数の四則演算）

線形代数（固有値）、複素数の極形式、テイラー展開は、本文で必要な範囲を説明し、:ref:`付録 A <appendix-a>` で補う。微分方程式の解き方の知識は必要ない。本書では、微分方程式を数値的に解く方法（第 3 章）だけを使う。

本書の構成
----------

本書は 4 部 12 章と付録からなる。前の章の内容を使って次の章を説明するので、初めて読む場合は順に読むとよい。作品づくりの技法を先に知りたい場合は、第 12 章から読み、必要に応じて前の章に戻ってもよい。

.. list-table:: 本書の構成
   :header-rows: 1
   :widths: 22 78

   * - 部
     - 内容
   * - 第 I 部 力学系の基礎
     - 第 1 章で力学系の基本的な考え方を説明する。第 2 章では 1 次元の写像の反復と安定性、第 3 章では微分方程式の数値解法と相空間を扱う。
   * - 第 II 部 カオス
     - 第 4 章でロジスティック写像がカオスに至る道筋を追い、第 5 章でカオスを定量的に特徴付ける。第 6 章では、ローレンツ方程式などのストレンジアトラクタを調べる。
   * - 第 III 部 フラクタル
     - 第 7 章でフラクタルと次元を定義し、第 8 章で反復関数系（IFS）と L-system を、第 9 章でジュリア集合とマンデルブロ集合を扱う。第 10 章では、カオスとフラクタルがどう結び付くかを調べる。
   * - 第 IV 部 応用と表現
     - 第 11 章で自然や工学の中のカオスとフラクタル、反応拡散系などを紹介する。第 12 章では、ジェネラティブアートとして描くための技法をまとめる。
   * - 付録
     - 数学の補足、用語集、参考文献、サンプルコードの一覧。

表記
----

本書では、次の表記を使う。

.. list-table:: 本書の表記
   :header-rows: 1
   :widths: 30 70

   * - 表記
     - 意味
   * - :math:`x_n`
     - 離散時間の力学系で、時刻 :math:`n`\ （:math:`n = 0, 1, 2, \ldots`）の状態
   * - :math:`x(t)`
     - 連続時間の力学系で、時刻 :math:`t` の状態
   * - :math:`f^n`
     - 写像 :math:`f` を :math:`n` 回合成した写像（:math:`f^2(x) = f(f(x))`）。:math:`f` の :math:`n` 乗ではない
   * - :math:`\dot{x}`
     - :math:`x` の時間微分 :math:`dx/dt`
   * - :math:`x^*`
     - 固定点（平衡点）
   * - :math:`\mathbb{R}`、:math:`\mathbb{C}`
     - 実数全体の集合、複素数全体の集合
   * - :math:`\log`
     - 自然対数（底は :math:`e`）。底が 2 の対数は :math:`\log_2` と書く

用語は、初出のときに英語を併記する。主な用語は :ref:`付録 B <appendix-b>` の用語集にまとめた。

サンプルコードの実行環境
------------------------

サンプルコードは、次の環境で動作を確認した。

.. list-table:: 動作を確認した環境
   :header-rows: 1
   :widths: 30 70

   * - ソフトウェア
     - バージョン
   * - Python
     - 3.14
   * - NumPy
     - 2.5
   * - matplotlib
     - 3.11
   * - Pillow
     - 13.0

型ヒントの書き方（``list[float]``、``X | None`` など）に Python 3.10 以降の文法を使っているので、Python 3.10 以降が必要である。必要なパッケージは、次のコマンドでインストールできる。

.. code-block:: console
   :linenos:

   $ python -m pip install numpy matplotlib pillow

サンプルは ``examples`` フォルダーに置いた Python ファイルで、各章のサンプルのファイル名は ``ch章番号_内容.py`` の形をしている。``examples`` フォルダーで次のように実行すると、計算結果と図を画面に表示する。``--save`` で保存先のフォルダーを指定すると、図を PNG ファイルとして保存する。アニメーションを作るサンプルは、``--save`` を指定したときだけ GIF ファイルを保存する。

.. code-block:: console
   :linenos:

   $ cd examples
   $ python ch04_logistic.py
   $ python ch04_logistic.py --save output

すべてのサンプルの一覧とダウンロードのリンクは、:ref:`付録 D <appendix-d>` にある。本文には、サンプルの一部を行番号付きで示す。行番号は、サンプルのファイルの中での行番号である。
