はじめに
========

本書の目的
----------

日々の開発では、ライブラリやフレームワーク、クラウドサービスが多くの複雑さを隠してくれる。しかし、浮動小数点数の計算結果がわずかにずれる、データ量が増えたとたんに処理が遅くなる、複数のスレッドから更新した値が壊れる、といった問題に直面したとき、その原因は隠された下位の層にあることが多い。本書の目的は、こうした問題を「なぜそうなるのか」から理解できるように、計算機科学の基礎を一通り身に付けることである。

本書は各分野の入口に立つことを目指しており、厳密な証明や網羅的な解説は扱わない。より深く学ぶための文献は「:doc:`references`」にまとめた。

対象読者
--------

本書は次のような読者を想定している。

* 何らかのプログラミング言語で業務や個人の開発をした経験がある。
* 計算機科学を体系的に学ぶ機会がなかった、または学び直したい。
* Python の基本的な文法（関数、クラス、リスト、辞書）を読める。

数学の知識は高校程度を前提とする。数式を使う箇所では、記号の意味を本文で説明する。

本編の後の「:doc:`conclusion`」では、本書で扱わなかった分野と、次に学ぶための文献を紹介する。付録には、本文に登場する用語をまとめた「:doc:`glossary`」、「:doc:`references`」、「:doc:`examples`」を収録した。

サンプルコードについて
----------------------

本書のサンプルコードはすべて Python で書かれており、各章の本文に掲載している。掲載箇所のリンクまたは「:doc:`examples`」からファイルをダウンロードできる。

サンプルコードは次の方針で作成した。

* Python 3.12 以降で動作し、標準ライブラリだけを使う。
* 型ヒントを付け、flake8 と mypy（strict モード）で警告が出ないことを確認している。
* 仕組みを理解しやすくすることを優先しており、実運用での性能や安全性は考慮していない。特に第 13 章の暗号のサンプルコードは学習用であり、実際のシステムで使ってはならない。

サンプルコードは、ダウンロードしたファイルがあるフォルダで次のように実行する。

.. code-block:: console
   :linenos:

   $ python ch01_number_bases.py

Windows で ``python`` コマンドが見つからない場合は、``python`` の代わりに ``py`` を使う。

表記について
------------

本書では、次の表記を用いる。

* 外来語の語末の長音は、技術文書で広く使われている表記に合わせて省略する（例: コンピュータ、メモリ、サーバ、ユーザ、コンパイラ）。ただし、短い語では省略しない（例: キー、エラー）。
* プログラム中の名前や入力する文字列は ``print()`` のように等幅フォントで示す。
* 数式中の :math:`\log n` は、特に断らない限り底が 2 の対数を表す。
