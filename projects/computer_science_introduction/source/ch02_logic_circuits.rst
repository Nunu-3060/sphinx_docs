論理回路
========

前章では、数値や文字がビット列として表されることを見た。この章では、ビット列に対する演算を実際に行う論理回路を学ぶ。まず、真と偽の 2 値を扱う数学であるブール代数を導入し、それを電子回路で実現する論理ゲートを紹介する。次に、ゲートを組み合わせて加算器やマルチプレクサのような組み合わせ回路を作る。最後に、値を記憶できる順序回路として、ラッチ、フリップフロップ、レジスタを扱う。CPU は、ここで学ぶ部品を膨大な数組み合わせて作られている。

ブール代数
----------

ブール代数とは
^^^^^^^^^^^^^^

19 世紀の数学者ジョージ・ブールは、論理的な推論を代数の計算として表す方法を考案した。これを\ :term:`ブール代数`\ （Boolean algebra）と呼ぶ。ブール代数で扱う値は 0（偽）と 1（真）の 2 つだけであり、基本的な演算は次の 3 つである。

* 論理積（AND）: :math:`A \cdot B` と書く。:math:`A` と :math:`B` がともに 1 のときだけ 1 になる。
* 論理和（OR）: :math:`A + B` と書く。:math:`A` と :math:`B` の少なくとも一方が 1 なら 1 になる。
* 否定（NOT）: :math:`\overline{A}` と書く。:math:`A` が 0 なら 1、1 なら 0 になる。

記号 :math:`+` と :math:`\cdot` は通常の加算・乗算と同じものを使うが、:math:`1 + 1 = 1` となる点が異なる。プログラミング言語の論理演算子（Python の ``and``、``or``、``not``、C 系の言語の ``&&``、``||``、``!``）や、前章のビット演算子（``&``、``|``、``~``）は、ブール代数の演算をそのまま実装したものである。

ブール代数の式の値を、入力のすべての組み合わせについて列挙した表を\ :term:`真理値表`\ （truth table）と呼ぶ。入力が :math:`n` 個なら、真理値表は :math:`2^n` 行になる。2 つの式の真理値表がすべての行で一致すれば、それらの式は等しい。

基本法則
^^^^^^^^

ブール代数には次のような法則が成り立つ。いずれも、真理値表を書けば確かめられる。

.. list-table:: ブール代数の基本法則
   :header-rows: 1
   :widths: 25 37 38

   * - 法則
     - 論理積の形
     - 論理和の形
   * - 恒等則
     - :math:`A \cdot 1 = A`
     - :math:`A + 0 = A`
   * - 零元則
     - :math:`A \cdot 0 = 0`
     - :math:`A + 1 = 1`
   * - べき等則
     - :math:`A \cdot A = A`
     - :math:`A + A = A`
   * - 補元則
     - :math:`A \cdot \overline{A} = 0`
     - :math:`A + \overline{A} = 1`
   * - 交換則
     - :math:`A \cdot B = B \cdot A`
     - :math:`A + B = B + A`
   * - 結合則
     - :math:`(A \cdot B) \cdot C = A \cdot (B \cdot C)`
     - :math:`(A + B) + C = A + (B + C)`
   * - 分配則
     - :math:`A \cdot (B + C) = A \cdot B + A \cdot C`
     - :math:`A + B \cdot C = (A + B) \cdot (A + C)`
   * - 吸収則
     - :math:`A \cdot (A + B) = A`
     - :math:`A + A \cdot B = A`
   * - 二重否定
     - :math:`\overline{\overline{A}} = A`
     - :math:`\overline{\overline{A}} = A`

表の 2 つの列は、:math:`\cdot` と :math:`+`、0 と 1 を入れ替えた関係にある。これを双対性と呼び、ある法則が成り立てば、その双対の法則も成り立つ。通常の代数と異なり、論理和の形の分配則 :math:`A + B \cdot C = (A + B) \cdot (A + C)` も成り立つことに注意してほしい。

ド・モルガンの法則
^^^^^^^^^^^^^^^^^^

特に重要なのが、否定と論理積・論理和の関係を表す\ :term:`ド・モルガンの法則`\ （De Morgan's laws）である。

.. math::

   \overline{A \cdot B} = \overline{A} + \overline{B}, \qquad \overline{A + B} = \overline{A} \cdot \overline{B}

言葉で言えば、「A かつ B」でないことは「A でない、または B でない」ことと等しく、「A または B」でないことは「A でなく、かつ B でない」ことと等しい。次の真理値表で、1 つ目の法則の両辺が一致することを確かめられる。

     - :math:`\overline{A}`
     - :math:`\overline{A} + \overline{B}`

ド・モルガンの法則は、プログラムの条件式を整理するときにも役立つ。例えば ``if not (is_admin or is_owner):`` は ``if not is_admin and not is_owner:`` と書き換えられる。否定が複数重なった条件はバグの温床になりやすいので、ド・モルガンの法則で否定を内側に移したり、逆にまとめたりして、読みやすい形を選ぶとよい。SQL の ``WHERE NOT (a = 1 OR b = 2)`` を書き換えるときにも同じ法則が使える（ただし SQL では ``NULL`` を含む 3 値論理になる点に注意が必要である）。

ブール代数の法則を使うと、式を簡単にできる。例えば :math:`A \cdot B + A \cdot \overline{B}` は、分配則で :math:`A \cdot (B + \overline{B})` となり、補元則と恒等則で :math:`A` になる。回路では式の項が少ないほどゲートの数が減るため、論理式の簡単化は回路設計の基本的な作業である。実際の設計では、カルノー図や、コンピュータによる論理合成ツールが使われる。

論理ゲート
----------

基本的なゲート
^^^^^^^^^^^^^^

ブール代数の演算を電子回路で実現したものを\ :term:`論理ゲート`\ （logic gate）と呼ぶ。現在の集積回路では、論理ゲートは CMOS（Complementary Metal-Oxide-Semiconductor）と呼ばれる構造のトランジスタの組み合わせで作られ、電圧の高い状態を 1、低い状態を 0 として扱う。主な論理ゲートとその真理値表を次に示す。

NAND（NOT AND）は AND の出力を反転したもの、NOR（NOT OR）は OR の出力を反転したものである。XOR（排他的論理和、:math:`A \oplus B`）は 2 つの入力が異なるときに 1 になり、:math:`A \oplus B = A \cdot \overline{B} + \overline{A} \cdot B` と表せる。XOR は「2 つのビットを足した結果の 1 の位」でもあり、次節の加算器の中心となる。

CMOS では、NOT は 2 個、2 入力の NAND と NOR は 4 個のトランジスタで作れる。一方、AND は NAND の後ろに NOT をつないで作るので 6 個必要になる（OR も同様である）。このため、実際の回路は NAND や NOR を基本として設計されることが多い。

NAND の完全性
^^^^^^^^^^^^^

NAND ゲートだけを組み合わせると、どんな論理関数も作れる。このように、ある演算の集合だけで任意の論理関数を表現できる性質を\ :term:`機能的完全性`\ （functional completeness）と呼ぶ。

まず、AND、OR、NOT の 3 つで任意の論理関数を作れることを確かめる。真理値表で出力が 1 になる各行について、その行の入力の組み合わせのときだけ 1 になる論理積の項（例えば :math:`A = 1`、:math:`B = 0` の行なら :math:`A \cdot \overline{B}`）を作り、それらをすべて論理和でつなげばよい（出力が 1 になる行が無ければ :math:`A \cdot \overline{A}` のような常に 0 の式を使う）。この形を積和標準形と呼ぶ。

次に、AND、OR、NOT がそれぞれ NAND だけで作れることを示す。

* NOT: :math:`\overline{A} = \overline{A \cdot A}` なので、NAND の 2 つの入力に同じ信号をつなげばよい。
* AND: :math:`A \cdot B = \overline{\overline{A \cdot B}}` なので、NAND の出力を上の NOT で反転すればよい。
* OR: ド・モルガンの法則より :math:`A + B = \overline{\overline{A} \cdot \overline{B}}` なので、各入力を NOT で反転してから NAND に入れればよい。

以上から、NAND だけで任意の論理関数を作れる。双対の議論により NOR も機能的完全である。一方、AND と OR だけでは否定を作れないので、機能的完全ではない。

組み合わせ回路
--------------

出力がその時点の入力だけで決まる回路を\ :term:`組み合わせ回路`\ （combinational circuit）と呼ぶ。組み合わせ回路は記憶を持たず、同じ入力に対して常に同じ出力を返す。プログラムで言えば、副作用の無い純粋な関数にあたる。

半加算器
^^^^^^^^

1 ビットの数 :math:`A` と :math:`B` を足すことを考える。結果は 0、1、2（2 進数の 10）のいずれかなので、2 ビットで表せる。下位のビットを和 :math:`S`\ （sum）、上位のビットを桁上げ :math:`C`\ （carry）と呼ぶと、真理値表は次のようになる。

     - :math:`S`

表を見ると、:math:`S` は XOR、:math:`C` は AND と同じである。したがって、:math:`S = A \oplus B`、:math:`C = A \cdot B` であり、XOR ゲートと AND ゲート 1 個ずつで 1 ビットの加算器を作れる。これを\ :term:`半加算器`\ （half adder）と呼ぶ。「半」と呼ぶのは、下の桁からの桁上げを受け取れないためである。

全加算器
^^^^^^^^

複数桁の加算では、各桁で :math:`A`、:math:`B` に加えて下の桁からの桁上げ :math:`C_{in}` の 3 ビットを足す必要がある。これを行う回路を\ :term:`全加算器`\ （full adder）と呼ぶ。全加算器の出力は次の式で表される。

.. math::

   S = A \oplus B \oplus C_{in}, \qquad C_{out} = A \cdot B + C_{in} \cdot (A \oplus B)

全加算器は半加算器 2 個と OR ゲート 1 個で作れる。1 個目の半加算器で :math:`A` と :math:`B` を足し、その和と :math:`C_{in}` を 2 個目の半加算器で足す。2 つの半加算器のどちらかで桁上げが生じれば、全体として桁上げが生じる（両方で同時に生じることはない）ので、2 つの桁上げの OR が :math:`C_{out}` になる。

リプルキャリー加算器
^^^^^^^^^^^^^^^^^^^^

全加算器を :math:`n` 個並べ、各桁の :math:`C_{out}` を 1 つ上の桁の :math:`C_{in}` につなぐと、:math:`n` ビットの加算器ができる。最下位の桁の :math:`C_{in}` は 0 にする。桁上げが下の桁から上の桁へ波（ripple）のように伝わっていくことから、これを\ :term:`リプルキャリー加算器`\ （ripple-carry adder）と呼ぶ。

19 行目では、8 ビットの範囲を超えた結果の桁上げが最上位の全加算器から出ている。これは前章で述べた符号なし整数のオーバーフローであり、CPU ではこの桁上げがキャリーフラグとして記録される。

この加算器は減算にも使える。前章で見たとおり、:math:`a - b = a + (-b)` であり、2 の補数の :math:`-b` は「:math:`b` の全ビットを反転して 1 を足す」ことで得られる。そこで、:math:`b` の各ビットを XOR ゲートで反転し（XOR の一方の入力を 1 にすると NOT と同じ働きをする）、最下位の :math:`C_{in}` を 1 にすれば、同じ回路で減算ができる。また、符号付き整数のオーバーフローは、最上位の桁に入る桁上げと最上位の桁から出る桁上げが異なる場合に起こるので、その 2 つの XOR で検出できる。

.. note::

   リプルキャリー加算器では、最上位の桁の結果が確定するまで、桁上げが最下位から順に伝わるのを待たなければならない。1 桁あたりの遅延を一定とすると、:math:`n` ビットの加算にかかる時間は :math:`n` に比例する。実際の CPU では、各桁で桁上げが「生成」される条件（:math:`g_i = a_i \cdot b_i`）と「伝搬」される条件（:math:`p_i = a_i \oplus b_i`）から、各桁への桁上げ :math:`c_{i+1} = g_i + p_i \cdot c_i` を並列に先読みする桁上げ先見加算器（carry-lookahead adder）などが使われ、先読みを多段に組み合わせることで遅延を :math:`\log n` に比例する程度まで短くしている。回路の量を増やして速度を得る、ハードウェア設計の典型的なトレードオフである。

マルチプレクサ
^^^^^^^^^^^^^^

:term:`マルチプレクサ`\ （multiplexer、MUX）は、複数の入力の中から、選択信号で指定された 1 つを出力に通す回路である。最も単純な 2 入力のマルチプレクサは、データ入力 :math:`D_0`、:math:`D_1` と選択信号 :math:`S` を持ち、:math:`S = 0` なら :math:`D_0` を、:math:`S = 1` なら :math:`D_1` を出力する。論理式は次のとおりである。

.. math::

   Y = \overline{S} \cdot D_0 + S \cdot D_1

これはプログラムの条件式 ``y = d1 if s else d0`` を回路にしたものと考えられる。選択信号を :math:`k` ビットにすれば、:math:`2^k` 個の入力から 1 つを選べる。逆に、1 つの入力を選択信号で指定した出力に振り分ける回路をデマルチプレクサ、:math:`k` ビットの入力から :math:`2^k` 本のうち 1 本だけを 1 にする回路をデコーダと呼ぶ。

マルチプレクサは CPU の中で至る所に使われている。例えば、ALU（演算装置）の入力として、どのレジスタの値を使うかを選ぶのはマルチプレクサである。ALU 自体も、加算器、AND、OR などの回路で同時にすべての演算を計算しておき、命令で指定された演算の結果をマルチプレクサで選んで出力する、という構成で作れる。メモリのアドレスから記憶素子を 1 つ選ぶのはデコーダの役割である。次章ではこれらの部品が CPU の中でどう組み合わされるかを見る。

順序回路
--------

組み合わせ回路は記憶を持たないため、計算の途中結果を保持できない。過去の入力に依存した状態を持つ回路を\ :term:`順序回路`\ （sequential circuit）と呼ぶ。順序回路は、ゲートの出力を入力に戻す（フィードバックする）ことで状態を保持する。

SR ラッチ
^^^^^^^^^

最も基本的な記憶回路が SR ラッチである。2 つの NOR ゲートの出力を互いの入力につなぐ（たすき掛けにする）と、セット入力 :math:`S` とリセット入力 :math:`R`、出力 :math:`Q` とその反転 :math:`\overline{Q}` を持つ回路ができる。このように、1 ビットの状態を保持する回路のうち、入力の変化に直ちに反応するものを\ :term:`ラッチ`\ （latch）と呼ぶ。SR ラッチの動作は次のとおりである。

.. list-table:: SR ラッチ（NOR 構成）の動作
   :header-rows: 1
   :widths: 15 15 25 45

   * - :math:`S`
     - :math:`R`
     - 次の :math:`Q`
     - 意味
   * - 0
     - 0
     - 直前の :math:`Q`
     - 保持
   * - 1
     - 0
     - 1
     - セット
   * - 0
     - 1
     - 0
     - リセット
   * - 1
     - 1
     - （使用禁止）
     - 両方の出力が 0 になり、入力を 0 に戻したときの状態が定まらない

:math:`S = 1` にすると :math:`Q` が 1 になり、その後 :math:`S` を 0 に戻しても、フィードバックによって :math:`Q = 1` が保たれる。同様に :math:`R = 1` で :math:`Q` が 0 になり、:math:`R` を戻しても 0 が保たれる。入力が両方 0 のとき、出力は直前の状態によって決まる。これが「記憶」である。同じ入力に対して状態によって異なる出力を返す点が、組み合わせ回路との本質的な違いである。

D ラッチと D フリップフロップ
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

SR ラッチには使用禁止の入力があり、扱いにくい。そこで、データ入力 :math:`D` と書き込み許可信号 :math:`E` を持ち、:math:`E = 1` の間は :math:`Q` が :math:`D` に追従し、:math:`E = 0` になるとその時点の値を保持する回路が作られた。これを D ラッチと呼ぶ。D ラッチは、SR ラッチの前段に「:math:`S = D \cdot E`、:math:`R = \overline{D} \cdot E`」となるゲートを置くことで作れ、禁止された入力の組み合わせは起こらない。

D ラッチは :math:`E = 1` の間ずっと入力を通してしまうため、出力を回路の中で巡らせて入力に戻すと、1 回の書き込み許可の間に値が何度も変わってしまう。この問題を避けるため、許可信号（後述のクロック）が 0 から 1 に変わる瞬間（立ち上がりエッジ）の :math:`D` の値だけを取り込み、それ以外のときは値を保持する回路が使われる。これが D :term:`フリップフロップ`\ （flip-flop）である。D フリップフロップは、例えば 2 つの D ラッチを直列につなぎ、許可信号を互いに反転させて与えることで作れる（マスタスレーブ方式）。前段が値を取り込んでいる間は後段が閉じ、後段が開くときには前段が閉じるので、出力が変わるのはエッジの瞬間だけになる。

クロック
^^^^^^^^

順序回路の多くは、一定の周期で 0 と 1 を繰り返す\ :term:`クロック`\ （clock）信号に同期して動作する。回路全体のフリップフロップは、クロックの立ち上がりエッジで一斉に新しい値を取り込む。エッジとエッジの間に、組み合わせ回路がフリップフロップの出力を入力として次の値を計算し、次のエッジでその結果が取り込まれる。このように、すべての状態変化をクロックに揃える設計を同期式設計と呼ぶ。

クロックの周期は、フリップフロップの間にある組み合わせ回路のうち、最も遅い経路（クリティカルパス）の遅延より長くなければならない。周期が短すぎると、計算が終わる前に途中の値が取り込まれてしまう。クロック周波数 3 GHz の CPU では 1 周期が約 0.33 ナノ秒しかなく、その間に信号が通過できるゲートの段数は限られる。リプルキャリー加算器のように遅い回路を避け、桁上げ先見加算器のような並列な回路を使うのはこのためである。また、周波数を上げると消費電力と発熱が増えるため、2000 年代半ば以降は周波数の向上が頭打ちになり、複数のコアで性能を上げる方向に移った。

レジスタ
^^^^^^^^

D フリップフロップを :math:`n` 個並べ、共通のクロックを与えると、:math:`n` ビットの値を記憶する回路ができる。これを\ :term:`レジスタ`\ （register）と呼ぶ。64 ビットの CPU には、64 個の D フリップフロップからなるレジスタが多数含まれている。

レジスタの入力にマルチプレクサを置き、「新しい値を書き込むか、今の値を保持するか」を選べるようにすると、書き込み許可付きのレジスタになる。さらに、レジスタの出力と定数 1 を加算器に入れ、加算器の出力をレジスタの入力に戻すと、クロックのたびに値が 1 ずつ増えるカウンタができる。次章で扱うプログラムカウンタは、このようなカウンタに、分岐先のアドレスを書き込む機能を加えたものである。

組み合わせ回路と順序回路を組み合わせたこの構成は、「現在の状態と入力から、次の状態と出力を決める」という有限状態機械（「:doc:`ch06_theory_of_computation`」で扱う）の考え方そのものである。CPU は巨大な有限状態機械であり、その状態はレジスタとメモリの内容である。

.. note::

   ここで述べた回路は、実際の設計では Verilog や VHDL などのハードウェア記述言語（HDL: Hardware Description Language）で記述され、論理合成ツールによってゲートの接続に変換される。FPGA（Field-Programmable Gate Array）を使うと、記述した回路を書き換え可能なチップ上で動かせる。ソフトウェアエンジニアが論理回路を直接設計する機会は少ないが、FPGA を使ったネットワーク機器や機械学習の推論装置のように、ソフトウェアとハードウェアの境界は身近になりつつある。

まとめ
------

* ブール代数は 0 と 1 の 2 値に対する代数であり、AND、OR、NOT を基本演算とする。ド・モルガンの法則は、否定と AND・OR を入れ替える法則で、条件式の書き換えにも使える。
* 論理ゲートはブール代数の演算を電子回路で実現したものである。NAND だけで任意の論理関数を作れる（機能的完全性）。
* 組み合わせ回路は、出力が現在の入力だけで決まる回路である。半加算器、全加算器、リプルキャリー加算器、マルチプレクサがその例であり、2 の補数を使えば同じ加算器で減算もできる。
* 順序回路は、フィードバックによって状態を保持する回路である。ラッチ、フリップフロップ、レジスタがその例であり、クロックに同期して状態を更新する。
* クロック周期は組み合わせ回路の最も遅い経路で制約され、回路の並列化による高速化と回路量の増加の間にはトレードオフがある。

論理回路から CPU を組み立てる過程は [CODE]_ に平易に、[PH]_ の付録に詳しく解説されている。次の「:doc:`ch03_computer_architecture`」では、ここで学んだ部品から CPU とメモリがどのように構成されるかを見ていく。
