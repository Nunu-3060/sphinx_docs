======================
第 21 章　次のステップ
======================

本書では、Godot で 2D ゲームを作るための基本を一通り学んだ。最後の章では、さらに学ぶための題材と、情報の探し方を紹介する。

学んだことの振り返り
====================

.. list-table:: 本書で学んだこと
   :header-rows: 1
   :widths: 30 70

   * - 分野
     - 内容
   * - 基本概念
     - ノードとシーンでゲームを組み立てる。シグナルで部品どうしを疎につなぐ。ゲームループの中で ``delta`` を使って時間を扱う。
   * - GDScript
     - Python に似た文法で、型を指定して安全に書く。``await`` で時間の経過を伴う処理を書く。
   * - ゲームの構成要素
     - 入力アクション、ベクトル、物理ボディと ``Area2D``、アニメーション、タイルマップ、UI、サウンド、シーンの切り替え、データの保存
   * - 実践
     - シェーダーで見た目の効果を作る。1 本のゲームを完成させ、デバッグし、エクスポートする。

次に学ぶ題材
============

作りたいゲームに応じて、次の題材に進むとよい。

.. list-table:: 次に学ぶ題材
   :header-rows: 1
   :widths: 30 70

   * - 題材
     - 内容
   * - ナビゲーション
     - ``NavigationAgent2D`` などを使い、敵が障害物を避けてプレイヤーを追いかける経路探索を実装する。
   * - アニメーションの状態管理
     - ``AnimationTree`` で、待機、歩行、ジャンプなどのアニメーションの切り替えを状態遷移として管理する。
   * - 多言語対応
     - 文字列を翻訳ファイル（CSV や PO 形式）に分け、``tr()`` で表示する言語を切り替える。
   * - ネットワーク対戦
     - Godot の高レベルマルチプレイヤー機能（``MultiplayerSpawner``、``MultiplayerSynchronizer``、RPC）を使い、複数のプレイヤーで遊べるゲームを作る。
   * - エディターの拡張
     - ``@tool`` を付けたスクリプトや ``EditorPlugin`` で、ステージの編集を助けるツールをエディターに追加する。
   * - C#
     - .NET 版の Godot で、C# でスクリプトを書く。既存の .NET のライブラリを使える。
   * - GDExtension
     - C++ などで書いたネイティブのライブラリをエンジンに組み込み、処理速度が重要な部分を高速化する。
   * - テスト
     - GUT や gdUnit4 などのアドオンで、GDScript の単体テストを書く。
   * - シェーダーの応用
     - 3D の ``spatial`` シェーダー、ライトの計算（``light()`` 関数）、ポストエフェクトなどに進む。

情報の探し方
============

公式ドキュメント
----------------

最も信頼できる情報源は、`Godot の公式ドキュメント <https://docs.godotengine.org/en/stable/>`_ である。入門用のチュートリアルから、各機能の解説、全クラスのリファレンスまでそろっている。中でも「Your first 2D game」は、本書の第 17 章と同じく、落ちてくる敵をよけるゲームを作るチュートリアルで、本書の復習によい。

公式ドキュメントのページは、上部のメニューでバージョンを切り替えられる。古いバージョン（特に Godot 3 系）の情報と混同しないよう、使っているバージョンに合ったページを見る。

公式のデモプロジェクト
----------------------

`Godot のデモプロジェクト集 <https://github.com/godotengine/godot-demo-projects>`_ には、2D、3D、GUI、オーディオ、ネットワークなどの分野ごとに、多数のサンプルプロジェクトが収められている。エディターの「AssetLib」画面からも、一部のデモを直接ダウンロードできる。動くコードを読むのは、新しい機能を学ぶ近道である。

コミュニティ
------------

* `Godot Forum <https://forum.godotengine.org/>`_：公式のフォーラム。質問を投稿したり、過去の質問と回答を検索したりできる。
* `Godot Asset Library <https://godotengine.org/asset-library/asset>`_：プラグイン、サンプル、素材などのアセットを探せる。
* `Godot Shaders <https://godotshaders.com/>`_：コミュニティが作ったシェーダーの作例集。:ref:`ch16` の次の一歩に役立つ。

質問するときは、Godot のバージョン、やりたいこと、試したこと、エラーメッセージ、関係するコードやシーンの構成を添えると、回答を得やすい。

ゲームを完成させる練習
======================

ゲーム制作の上達には、小さなゲームを数多く完成させることが効果的である。最初から大きなゲームを目指すと、完成する前に挫折しやすい。

* **小さく作って完成させる**：遊びの中心となる仕組みを 1 つ決め、数日で完成できる規模にする。
* **既存のゲームをまねる**：ブロック崩し、シューティング、パズルなど、ルールがよく知られたゲームを作ってみる。設計の判断に悩む時間を減らし、作ることに集中できる。
* **ゲームジャムに参加する**：決められた期間（48 時間など）とテーマでゲームを作るイベントである。`itch.io のゲームジャムの一覧 <https://itch.io/jams>`_ で、Godot を使うジャムも多く見つかる。期限があることで、完成させる経験を積める。

本書が、読者がゲームを作る楽しさを知るきっかけになれば幸いである。
