==========
Godot 入門
==========

本書は、ゲーム制作の経験はないが Python などでプログラムを書いた経験があるエンジニアに向けた、ゲームエンジン Godot の入門書である。Godot 4.7.2 と GDScript を使い、2D ゲームの基本的な作り方を一通り学ぶ。後半ではシェーダーと 3D の入り口にも触れる。
