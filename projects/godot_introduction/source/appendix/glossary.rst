.. _glossary:

==============
付録 A　用語集
==============

本書で使った主な用語を、五十音順（英字で始まるものは末尾）にまとめる。括弧内は説明している章である。

.. glossary::
   :sorted:

   アクション
      → 入力アクション

   アンカー
      ``Control`` の配置の基準となる、親の領域の中の位置。0.0 が左端（上端）、1.0 が右端（下端）を表す。（:ref:`ch13`）

   イージング
      値を変化させるときの、時間に対する変化の仕方。一定の速さ、滑らかに減速、行き過ぎて戻る、などがある。（:ref:`ch12`）

   インスタンス化
      シーンから実際のノードの木構造を作ること。また、シーンを別のシーンの中に部品として配置すること。（:ref:`ch05`）

   インスペクター
      選んだノードやリソースのプロパティを表示・編集するドック。（:ref:`ch04`）

   エクスポート
      ゲームを、Godot がなくても動く実行形式に書き出すこと。（:ref:`ch19`）

   エクスポートテンプレート
      エクスポートに使う、プラットフォームごとのエンジン本体。エディターとは別にダウンロードする。（:ref:`ch19`）

   オーディオバス
      音の通り道。音量の調整やエフェクトをまとめて適用する。（:ref:`ch14`）

   オートロード
      ゲームの起動時に自動で作られ、シーンを切り替えても残るノード。どのスクリプトからも名前でアクセスできる。（:ref:`ch15`）

   グループ
      ノードに付けるタグ。グループに属するノードをまとめて取得したり、まとめてメソッドを呼んだりできる。（:ref:`ch05`）

   ゲームループ
      入力の読み取り、状態の更新、描画を繰り返す、ゲームの基本的な処理の流れ。（:ref:`ch08`）

   コリジョンマスク
      物体が、どのレイヤーに属する相手を検出するかの設定。（:ref:`ch11`）

   コリジョンレイヤー
      物体が、衝突判定のどのグループに属するかの設定。（:ref:`ch11`）

   コンテナー
      子の ``Control`` ノードを自動で並べる UI ノード。``VBoxContainer`` など。（:ref:`ch13`）

   シーン
      ノードの木構造をファイル（``.tscn``）に保存したもの。再利用できる部品の単位である。（:ref:`ch05`）

   シーンツリー
      ノードの木構造。特に、実行中のゲームのすべてのノードを管理する ``SceneTree`` を指す。（:ref:`ch05`）

   シーン固有名
      シーンの中でノードに付ける一意な名前。``%名前`` で、階層に関係なくノードを取得できる。（:ref:`ch05`）

   シェーダー
      GPU の上で動き、頂点やピクセルごとの位置や色を計算する小さなプログラム。（:ref:`ch16`）

   シグナル
      ノードが出来事をほかのノードに知らせる仕組み。関数を接続しておくと、発行されたときにその関数が呼ばれる。（:ref:`ch07`）

   スプライト
      ゲームの画面に表示する 2D の画像。Godot では ``Sprite2D`` ノードで表示する。（:ref:`ch12`）

   タイルマップ
      小さな正方形の画像（タイル）を格子状に並べて、ステージなどを作る仕組み。``TileMapLayer`` ノードを使う。（:ref:`ch12`）

   ドック
      エディターの画面を構成する区画。シーンドック、インスペクターなど。（:ref:`ch04`）

   入力アクション
      「ジャンプ」などの操作に付けた名前。実際のキーやボタンをインプットマップで割り当てる。（:ref:`ch09`）

   ノード
      ゲームを組み立てる最小の部品。種類ごとに 1 つの役割を持つ。（:ref:`ch05`）

   フレーム
      ゲームループの 1 回分の処理。また、その結果として描画される 1 枚の画面。（:ref:`ch08`）

   フレームレート
      1 秒間に処理するフレームの数。単位は FPS。（:ref:`ch08`）

   物理ボディ
      衝突判定に参加し、互いにすり抜けない物体。``StaticBody2D``、``CharacterBody2D``、``RigidBody2D`` など。（:ref:`ch11`）

   ベクトル
      向きと大きさを持つ量。位置や速度を表すのに使う。2D では ``Vector2`` 型で表す。（:ref:`ch10`）

   ポーリング
      毎フレーム、入力の状態を問い合わせる方法。（:ref:`ch09`）

   マテリアル
      物体の見た目（質感やシェーダー）を決めるリソース。（:ref:`ch16`、:ref:`ch20`）

   UV 座標
      テクスチャ上の位置を表す座標。左上が (0, 0)、右下が (1, 1) である。（:ref:`ch16`）

   リソース
      シーン、画像、音声、マテリアルなど、ファイルとして保存できるデータ。参照カウントで管理され、同じファイルを読み込むと共有される。（:ref:`ch15`）

   レンダラー
      画面を描画する方式。Godot 4 には Forward+、モバイル、互換性の 3 種類がある。（:ref:`ch03`）

   delta
      前のフレーム（または前回の物理演算）からの経過時間（秒）。速さに掛けて移動量を求める。（:ref:`ch08`）

   GDScript
      Godot 専用のスクリプト言語。Python に似た文法を持つ。（:ref:`ch06`）

   HUD
      ゲーム画面に重ねて表示する、スコアや体力などの情報表示。（:ref:`ch17`）

   PCK ファイル
      エクスポートしたゲームのデータ（シーン、スクリプト、素材など）をまとめたファイル。（:ref:`ch19`）

   ``res://``
      プロジェクトのフォルダーを表すパス。（:ref:`ch04`）

   Tween
      プロパティの値を、時間をかけて開始値から終了値まで変化させる仕組み。（:ref:`ch12`）

   ``user://``
      ユーザーごとのデータ保存用フォルダーを表すパス。セーブデータの保存に使う。（:ref:`ch04`、:ref:`ch15`）
