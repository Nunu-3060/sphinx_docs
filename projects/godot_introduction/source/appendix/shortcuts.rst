==============================
付録 B　ショートカットキー一覧
==============================

Godot 4.7.2 のエディターの既定のショートカットキーのうち、よく使うものをまとめる。ショートカットキーは「エディター」→「エディター設定」の「ショートカット」タブで確認・変更できる。

全般
====

.. list-table:: 全般のショートカットキー
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 操作
   * - :kbd:`F5`
     - プロジェクトを実行
   * - :kbd:`F6`
     - 現在のシーンを実行
   * - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`F5`
     - 特定のシーンを実行
   * - :kbd:`F7`
     - 実行中のプロジェクトを一時停止
   * - :kbd:`F8`
     - プロジェクトの実行を停止
   * - :kbd:`Ctrl` + :kbd:`N`
     - 新規シーン
   * - :kbd:`Ctrl` + :kbd:`O`
     - シーンを開く
   * - :kbd:`Ctrl` + :kbd:`S`
     - シーンを保存
   * - :kbd:`Ctrl` + :kbd:`Z`
     - 元に戻す
   * - :kbd:`Ctrl` + :kbd:`Y`、:kbd:`Ctrl` + :kbd:`Shift` + :kbd:`Z`
     - やり直す
   * - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`P`
     - コマンドパレット
   * - :kbd:`Ctrl` + :kbd:`P`
     - ファイルを素早く開く
   * - :kbd:`F1`
     - ヘルプを検索
   * - :kbd:`Ctrl` + :kbd:`F1` ～ :kbd:`Ctrl` + :kbd:`F5`
     - メイン画面を「2D」「3D」「スクリプト」「ゲーム」「AssetLib」に切り替える。

シーンドック
============

.. list-table:: シーンドックのショートカットキー
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 操作
   * - :kbd:`Ctrl` + :kbd:`A`
     - 子ノードを追加
   * - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`A`
     - 子シーンをインスタンス化
   * - :kbd:`F2`
     - 名前を変更
   * - :kbd:`Ctrl` + :kbd:`D`
     - 複製
   * - :kbd:`Delete`
     - 削除

2D ビューポート
===============

.. list-table:: 2D ビューポートのショートカットキー
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 操作
   * - :kbd:`Q`
     - 選択モード
   * - :kbd:`W`
     - 移動モード
   * - :kbd:`E`
     - 回転モード
   * - :kbd:`R`
     - 拡大縮小モード
   * - :kbd:`Shift` + :kbd:`F`
     - 選んだノードを中央に表示

スクリプトエディター
====================

.. list-table:: スクリプトエディターのショートカットキー
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 操作
   * - :kbd:`Ctrl` + :kbd:`F`
     - 検索
   * - :kbd:`F3`、:kbd:`Shift` + :kbd:`F3`
     - 次を検索、前を検索
   * - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`F`
     - 複数ファイル内を検索
   * - :kbd:`Ctrl` + :kbd:`K`
     - コメントアウト / 解除
   * - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`D`
     - 選択範囲を複製
   * - :kbd:`Ctrl` + :kbd:`Space`
     - 補完の候補を表示
   * - :kbd:`Ctrl` + クリック
     - 定義やドキュメントへ移動
   * - :kbd:`F9`
     - ブレークポイントの切り替え
