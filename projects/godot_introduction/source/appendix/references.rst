ゲームプログラミングとシェーダー
================================

.. list-table:: ゲームプログラミングとシェーダーの資料
   :header-rows: 1
   :widths: 40 60

   * - 資料
     - 内容
   * - Robert Nystrom 著、武舎広幸 監訳、『ゲームプログラミングのデザインパターン』、インプレス、2015 年
     - ゲームループ、コンポーネント、オブザーバー（シグナル）、オブジェクトプールなど、ゲームでよく使う設計の考え方を解説している。原著は `Game Programming Patterns <https://gameprogrammingpatterns.com/>`_ として Web で公開されている。
   * - `The Book of Shaders <https://thebookofshaders.com/?lan=jp>`_
     - ピクセルシェーダーの考え方を、動く作例とともに段階的に学べる Web の教材。日本語訳がある。
   * - `Godot Shaders <https://godotshaders.com/>`_
     - Godot 用のシェーダーの作例集
