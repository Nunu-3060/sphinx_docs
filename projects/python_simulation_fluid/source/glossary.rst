用語集
======

本書で使う主な用語を、アルファベット順、五十音順にまとめる。

.. glossary::

   CFL 条件
      陽解法の差分法が安定であるための、時間刻み幅の条件。1 ステップの間に情報が格子間隔より遠くへ伝わってはならないことを表す。移流方程式では :math:`c\Delta t/\Delta x \le 1` となる。

   SPH
      Smoothed Particle Hydrodynamics(平滑化粒子流体力学)の略。流体を粒子で表し、カーネル関数による重み付き平均で物理量を計算する粒子法。

   圧力投影
      ポアソン方程式を解いて求めた量の勾配を速度場から引き、非圧縮条件を満たす速度場にする操作。

   移流
      流れによって物理量が運ばれること。ナビエ-ストークス方程式の移流項 :math:`-(\mathbf{u}\cdot\nabla)\mathbf{u}` は、流れが速度そのものを運ぶ効果を表す。

   陰解法
      未知の新しい時刻の値を含む式を、連立方程式として解く時間積分法。時間刻み幅の安定性の制約が緩い(または無い)代わりに、連立方程式を解く手間がかかる。

   オイラー的視点
      空間に固定した点で流体の物理量を観測する記述の方法。格子法はこの視点にもとづく。

   カーネル関数
      SPH で、周囲の粒子の値を重み付きで平均するための重み関数。距離が影響半径を超えると 0 になる。

   拡散数
      拡散方程式の陽解法で使う無次元数 :math:`r = \nu\Delta t/\Delta x^2`。1 次元では :math:`r \le 1/2` が安定の条件である。

   緩和時間
      格子ボルツマン法の BGK 衝突則で、分布関数が平衡分布関数に近づく遅さを表す定数 :math:`\tau`。動粘性係数と :math:`\nu = (\tau - 1/2)/3` の関係にある。

   近傍探索
      ある粒子から一定の距離以内にある粒子(近傍)をすべて見つける処理。

   クーラン数
      1 ステップの間に流れが何格子分進むかを表す無次元数 :math:`C = c\Delta t/\Delta x`。

   格子収束
      格子を細かくするにつれて、計算結果が一定の値に近づいていくこと。格子法の結果を信頼するための基本的な確認事項である。

   格子ボルツマン法
      格子の上を飛び移りながら衝突する仮想的な粒子の分布関数を計算し、その平均として流体の運動を再現する方法。LBM とも呼ぶ。

   ゴーストセル
      境界条件を扱いやすくするために、計算領域の外側に加える仮想的なセル。壁の内側の値から、境界条件に合うように値を決める。

   個別要素法
      粒子 1 個 1 個の運動と、粒子どうしの接触力を計算して粒子の集まりの振る舞いを調べる方法。DEM(Discrete Element Method)とも呼ぶ。

   時間刻み幅
      時間積分で 1 ステップに進める時間の幅 :math:`\Delta t`。

   弱圧縮性 SPH
      流体をわずかに圧縮できるものとみなし、状態方程式で密度から圧力を直接計算する SPH。WCSPH とも呼ぶ。

   射影法
      圧力以外の項で仮の速度を求め、圧力のポアソン方程式を解いて速度を修正する、非圧縮性流体の計算法。フラクショナルステップ法とも呼ぶ。圧力投影と同じ考え方にもとづく。

   人工粘性
      SPH で、近づき合う粒子の組にだけ働く減衰の力を加えて、計算を安定にするための項。

   シンプレクティック積分法
      エネルギーに近い量を長時間にわたって保存する性質を持つ時間積分法。半陰的オイラー法や速度ベルレ法がこれにあたる。

   数値拡散
      差分法などの離散化の誤差によって、元の方程式にはない拡散の効果が生じ、波形がなまる現象。

   数値分散
      離散化の誤差によって、波長ごとに波の進む速さがずれ、不連続の近くなどに振動が生じる現象。

   ストローハル数
      物体の後ろから渦が放出される周波数 :math:`f` を表す無次元数 :math:`\mathrm{St} = fD/U`。

   滑りなし条件
      壁の上で、流体の速度が壁の速度に等しいという境界条件。

   セミラグランジュ法
      格子点から流れを逆にたどった出発点の値を補間して、移流を計算する方法。無条件に安定だが、数値拡散が大きい。

   セル分割法
      空間を探索半径と同じ大きさのセルに分割し、周囲のセルの中だけを調べることで近傍探索を高速化する方法。セルリスト法とも呼ぶ。

   動粘性係数
      粘性係数 :math:`\mu` を密度 :math:`\rho` で割った量 :math:`\nu = \mu/\rho`。単位は :math:`\mathrm{m^2/s}`。

   ナビエ-ストークス方程式
      粘性を持つ流体の運動を表す方程式。流体粒子の加速度が、圧力・粘性・外力によって決まることを表す。

   跳ね返り境界
      格子ボルツマン法で、壁に入ってきた粒子を来た向きに跳ね返すことで、滑りなし条件を実現する方法。

   半陰的オイラー法
      先に速度を更新し、新しい速度で位置を更新する時間積分法。シンプレクティック・オイラー法とも呼ぶ。

   反発係数
      衝突の前後での相対速度の大きさの比。1 なら完全に弾み、0 なら全く弾まない。

   非圧縮条件
      速度場の発散が 0(:math:`\nabla\cdot\mathbf{u} = 0`)であるという条件。密度が一定の流体が満たす。

   分離解法
      方程式の項ごとに計算を分け、順番に計算して 1 ステップを進める方法。Stable Fluids 法や射影法がこれにあたる。

   平衡分布関数
      格子ボルツマン法で、衝突を十分繰り返して落ち着いた状態の分布関数。密度と速度から計算できる。

   ベンチマーク問題
      信頼できる結果が公表されており、計算法の検証に使われる標準的な問題。

   ポアソン方程式
      :math:`\nabla^2 p = b` の形の偏微分方程式。非圧縮性流体の計算では、圧力を求めるために解く。

   陽解法
      既知の現在の時刻の値だけを使って、新しい時刻の値を直接計算する時間積分法。計算は簡単だが、時間刻み幅に安定性の制約がある。

   ラグランジュ的視点
      流体とともに動く流体粒子を追跡して物理量を記述する方法。粒子法はこの視点にもとづく。

   レイノルズ数
      慣性の効果と粘性の効果の比を表す無次元数 :math:`\mathrm{Re} = UL/\nu`。流れが層流になるか乱流になるかなど、流れの性質を決める。

   連続の式
      流体の質量保存則を表す方程式。非圧縮性流体では非圧縮条件になる。
