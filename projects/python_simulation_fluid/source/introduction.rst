はじめに
========

本書のねらい
------------

水の流れ、煙の広がり、砂粒の積み重なりなど、身の回りの「流れ」や「粒の集まり」の振る舞いは、コンピューターで再現できる。こうした数値シミュレーションは、工学の設計計算から映画やゲームの映像表現まで、幅広い分野で使われている。

一方で、数値シミュレーションの入門は敷居が高いと感じられやすい。教科書の多くは偏微分方程式の理論から始まり、実際に動くコードにたどり着くまでが長い。逆に、ネット上の短いコードを動かしてみても、なぜそれで流れが再現できるのか、結果をどこまで信用してよいのかが分からないまま終わりがちである。

本書は、その中間を目指す。手法を実装する各章では、次の 4 つの手順を踏む。

#. **モデル化**: 現象を方程式で表す。理論は実装に必要な最小限にとどめ、式の各項が何を表しているかを直感的に説明する。
#. **離散化**: 連続的な方程式を、コンピューターで計算できる有限個の数の更新式に置き換える。
#. **実装**: 更新式を Python と NumPy のコードにする。サンプルコードは単体で実行でき、数秒から数分で結果が出る規模にする。
#. **検証**: 厳密解、保存則、既知の実験値やベンチマーク値と比べて、結果が正しいかを確かめる。

特に 4 番目の検証を重視する。数値シミュレーションは、間違っていても「それらしい」結果を出してしまうことが多い。結果を疑い、確かめる習慣は、手法そのものと同じくらい重要である。

対象読者
--------

本書は、次の知識を持つエンジニアを対象とする。

* Python の基本的な文法(関数、クラス、型ヒント)を理解している。
* NumPy の配列演算(スライス、ブロードキャスト)と matplotlib のグラフ描画を使ったことがある。
* 微分・積分とベクトルの基礎(高校から大学初年程度)を知っている。

流体力学や数値解析の予備知識は仮定しない。偏微分やベクトル解析の記号は、使うところで説明する。

本書の表記
----------

* 本文中に掲載するコードには行番号を付ける。サンプルコードから抜粋したものは、ファイル中の行番号をそのまま示す。
* ベクトルは太字で :math:`\mathbf{u}` のように書く。時刻 :math:`t` における量を、時刻の番号 :math:`n` を使って :math:`x^n` のように上付きの添字で表すことがある。これはべき乗ではない。
* 格子点の番号は下付きの添字で :math:`u_i` や :math:`u_{i,j}` のように書く。
* 使える文字の数には限りがあるため、同じ記号を章によって別の意味で使うことがある(例: :math:`h` は第 7・8 章では格子間隔、第 9 章ではカーネル関数の大きさを表す)。記号の意味は各章で定義する。
* 本書で使う主な用語は\ :doc:`glossary`\ にまとめた。
