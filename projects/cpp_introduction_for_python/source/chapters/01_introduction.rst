はじめに
============================================================

本章では、本資料の目的と読み方を説明します。

本資料の目的
------------------------------------------------------------

本資料の目的は、Python の知識を足がかりに、C++ で簡単なプログラムを書き、ビルドして実行できるようになることです。C++ のすべての機能を網羅するのではなく、現代的な C++ で日常的に使う機能に絞って説明します。

C++ は機能が多く、古い書き方と新しい書き方が混在している言語です。本資料では C++17 を基準とし、古い書き方よりも、安全で簡潔な新しい書き方を優先して紹介します。

本資料の読み方
------------------------------------------------------------

各章は前の章の内容を前提としているため、先頭から順に読むことを推奨します。多くの節では、まず Python での書き方を示し、次に対応する C++ の書き方と両者の違いを説明します。

サンプルコードは、実際にコンパイルして動かしながら読むと理解が深まります。コンパイルの方法は「:doc:`03_environment`」で説明します。

前提とする環境
------------------------------------------------------------

本資料のサンプルコードは、C++17 に対応したコンパイラーで動作します。一部の節では C++20 の機能を紹介しており、そのサンプルコードには C++20 に対応したコンパイラーが必要です。該当するサンプルコードには、先頭に ``// C++20`` というコメントを付けています。

すべてのサンプルコードは、Visual Studio 2026（MSVC 19.51）で動作を確認しています。

------------------------------------------------------------
