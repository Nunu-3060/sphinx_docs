関数
============================================================

本章では、C++ での関数の定義方法と、引数の渡し方を説明します。

関数の定義
------------------------------------------------------------

C++ では、関数を定義するときに戻り値の型と引数の型を明記します。

.. code-block:: python

   def add(a, b):
       return a + b

.. code-block:: cpp

   int add(int a, int b) {
       return a + b;
   }

戻り値がない関数では、戻り値の型を ``void`` にします。Python では ``return`` 文のない関数は ``None`` を返しますが、C++ の ``void`` の関数は値を返しません。

戻り値の型を ``auto`` にすると、``return`` 文の式から戻り値の型を推論させることもできます。ただし、関数の型は利用者にとって重要な情報であるため、本資料では原則として明記します。

宣言と定義
------------------------------------------------------------

C++ のコンパイラーはソースコードを先頭から順に読むため、関数を呼び出す箇所より前に、その関数が宣言されている必要があります。関数の本体を後に書きたい場合は、本体を持たない宣言（プロトタイプ宣言）を先に書きます。

.. literalinclude:: ../../examples/ch07/declaration.cpp
   :language: cpp
   :caption: examples/ch07/declaration.cpp

.. code-block:: text
   :caption: 実行結果

   25

宣言は何度書いてもかまいませんが、定義は原則としてプログラム全体で 1 つだけにする必要があります。この規則は、後述のヘッダーファイルの使い方に関係します。

引数の渡し方
------------------------------------------------------------

Python では、関数の引数としてオブジェクトへの参照が渡されます。そのため、関数内でリストを変更すると、呼び出し元のリストも変更されます。

C++ の引数の渡し方には、値渡し、参照渡し、const 参照渡しの 3 種類があります。

.. list-table::
   :header-rows: 1
   :widths: 25 35 40

   * - 渡し方
     - 書き方
     - 意味と用途
   * - 値渡し
     - ``void f(int x)``
     - 引数のコピーが作られる。関数内で変更しても呼び出し元には影響しない。``int`` や ``double`` など、コピーのコストが小さい型に使う
   * - 参照渡し
     - ``void f(std::string& s)``
     - 呼び出し元の変数そのものが渡される。関数内で引数を変更したい場合に使う
   * - const 参照渡し
     - ``void f(const std::string& s)``
     - 呼び出し元の変数そのものが渡されるが、変更はできない。``std::string`` や ``std::vector`` など、コピーのコストが大きい型を読み取るだけの場合に使う

型名の後ろの ``&`` は参照を表します。参照については「:doc:`08_pointers_and_references`」で詳しく説明します。

.. warning::

   C++ で ``std::vector`` などを値渡しにすると、要素がすべてコピーされます。Python と同じ感覚で書くと、意図せず大量のコピーが発生したり、関数内の変更が呼び出し元に反映されなかったりします。変更しない引数は const 参照渡しにするのが基本です。

デフォルト引数とオーバーロード
------------------------------------------------------------

Python と同様に、C++ でも引数に既定値（デフォルト引数）を指定できます。デフォルト引数は、引数リストの後ろの引数にしか指定できません。

また、C++ では、引数の型や個数が異なれば、同じ名前の関数を複数定義できます。これをオーバーロードと呼びます。呼び出し時には、実引数の型に最も合う関数が選ばれます。Python では同じ名前の関数を定義すると後の定義で上書きされるため、この点は大きく異なります。

.. literalinclude:: ../../examples/ch07/functions.cpp
   :language: cpp
   :caption: examples/ch07/functions.cpp

.. code-block:: text
   :caption: 実行結果

   3
   3.75
   Hello, Alice
   Hi, Bob
   0
   1

``increment_copy`` は値渡しのため、呼び出し元の ``n`` は変化しません。``increment_ref`` は参照渡しのため、呼び出し元の ``n`` が変化します。

Python の ``greet(name="Alice")`` のようなキーワード引数は、C++ にはありません。引数は常に定義した順に渡します。

ヘッダーファイルとソースファイル
------------------------------------------------------------

プログラムが大きくなると、ソースコードを複数のファイルに分割します。C++ では、関数の宣言をヘッダーファイル（``.h`` または ``.hpp``）に書き、定義をソースファイル（``.cpp``）に書くのが一般的です。関数を使う側のファイルは、ヘッダーファイルを ``#include`` して宣言を取り込みます。

.. literalinclude:: ../../examples/ch07/multi/geometry.h
   :language: cpp
   :caption: examples/ch07/multi/geometry.h

.. literalinclude:: ../../examples/ch07/multi/geometry.cpp
   :language: cpp
   :caption: examples/ch07/multi/geometry.cpp

.. literalinclude:: ../../examples/ch07/multi/main.cpp
   :language: cpp
   :caption: examples/ch07/multi/main.cpp

コンパイル時には、すべてのソースファイルを指定します。ヘッダーファイルは ``#include`` によって取り込まれるため、指定しません。

.. code-block:: console

   $ g++ -std=c++17 -Wall -Wextra -o geometry main.cpp geometry.cpp
   $ ./geometry
   3.14159
   6

``#include`` の後のファイル名は、標準ライブラリのヘッダーファイルでは ``< >`` で、自分で作成したヘッダーファイルでは ``" "`` で囲みます。

ヘッダーファイルの先頭の ``#pragma once`` は、同じヘッダーファイルが 1 つのソースファイルに複数回取り込まれることを防ぐ指示です。これをインクルードガードと呼びます。``#pragma once`` は規格で定められたものではありませんが、主要なコンパイラーはすべて対応しています。

Python では ``import`` するだけで別のファイルの関数を使えますが、C++ では宣言（ヘッダーファイル）と定義（ソースファイル）が分かれており、定義はリンクの段階で結び付けられます。ヘッダーファイルに宣言だけを書いて定義を書き忘れると、コンパイルは成功しますがリンクエラーになります。
