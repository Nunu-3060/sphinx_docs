C++ の概要
============================================================

本章では、C++ がどのような言語であるかを、Python と比較しながら説明します。

C++ とは
------------------------------------------------------------

C++ は、C 言語を拡張して作られた汎用プログラミング言語です。実行速度が求められるソフトウェア（ゲームエンジン、Web ブラウザー、数値計算ライブラリなど）で広く使われています。NumPy などの Python ライブラリも、内部の多くは C や C++ で実装されています。

C++ の特徴は、ハードウェアに近い低水準の操作と、クラスやテンプレートによる高水準の抽象化を両立できることです。その代わり、プログラマーが意識しなければならないこと（型、メモリ、オブジェクトの寿命など）が Python よりも多くなります。

Python との主な違い
------------------------------------------------------------

同じ処理を Python と C++ で書いた例を以下に示します。

.. code-block:: python

   def average(values):
       return sum(values) / len(values)

   print(average([1.0, 2.0, 3.0]))

.. code-block:: cpp

   #include <iostream>
   #include <numeric>
   #include <vector>

   double average(const std::vector<double>& values) {
       return std::accumulate(values.begin(), values.end(), 0.0) / values.size();
   }

   int main() {
       std::cout << average({1.0, 2.0, 3.0}) << '\n';
   }

C++ では、引数と戻り値の型を明記すること、使用するライブラリを ``#include`` で取り込むこと、プログラムの実行が ``main`` 関数から始まることなどが Python と異なります。主な違いを以下に示します。各項目の詳細は後の章で説明します。

.. list-table::
   :header-rows: 1
   :widths: 20 40 40

   * - 観点
     - Python
     - C++
   * - 実行方式
     - インタープリターがソースコードを読み込んで実行する
     - コンパイラーが機械語に変換し、生成された実行ファイルを実行する
   * - 型付け
     - 動的型付け（型は実行時に決まる）
     - 静的型付け（型はコンパイル時に決まる）
   * - メモリ管理
     - 参照カウントとガベージコレクションによる自動管理
     - スコープとデストラクターによる管理（RAII）
   * - ブロックの表現
     - インデント
     - 波括弧 ``{ }``
   * - 文の区切り
     - 改行
     - セミコロン ``;``
   * - 誤りの検出
     - 型の誤りの多くは実行時に検出される
     - 型の誤りはコンパイル時に検出される
   * - 実行速度
     - 比較的遅い
     - 一般に Python より大幅に速い

C++ の規格
------------------------------------------------------------

C++ は ISO によって規格化されており、おおむね 3 年ごとに改訂されています。規格は「C++17」のように、制定された年の下 2 桁で呼ばれます。本資料では C++17 を基準とし、C++20 以降の機能は必要に応じて補足します。

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - 規格
     - 主な追加機能
   * - C++11
     - auto、ラムダ式、スマートポインター、ムーブセマンティクス、範囲 for 文
   * - C++14
     - ジェネリックラムダ、std::make_unique
   * - C++17
     - 構造化束縛、std::optional、初期化式付きの if 文
   * - C++20
     - コンセプト、Ranges、モジュール、コルーチン
   * - C++23
     - std::print、std::expected

C++11 より前の規格で書かれたコードは、現在では推奨されない書き方を多く含んでいます。Web 上の古い解説を参照する際は、どの規格を前提とした記述かに注意してください。
