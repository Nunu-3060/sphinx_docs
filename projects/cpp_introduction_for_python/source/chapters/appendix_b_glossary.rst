用語集
============================================================

本資料で使用する主な用語を示します。日本語の用語は五十音順に並べ、英字の用語は末尾に置きます。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 用語
     - 説明
   * - イテレーター
     - コンテナの要素を指し示し、要素を順にたどるためのオブジェクト
   * - インクルードガード
     - 同じヘッダーファイルが複数回取り込まれることを防ぐ仕組み。``#pragma once`` などで実現する
   * - オーバーロード
     - 引数の型や個数が異なる同名の関数を複数定義すること
   * - オブジェクトファイル
     - コンパイルによって生成される、リンク前の機械語のファイル
   * - 仮想関数
     - ``virtual`` を付けたメンバー関数。基底クラスの参照やポインターを通じて呼び出すと、実際のオブジェクトの型に応じた関数が呼ばれる
   * - キャプチャー
     - ラムダ式の外側にある変数を、ラムダ式の中で使えるように取り込むこと
   * - コンストラクター
     - オブジェクトの生成時に呼ばれるメンバー関数。Python の ``__init__`` に相当する
   * - コンテナ
     - 複数の値をまとめて格納するクラス。``std::vector`` や ``std::map`` など
   * - コンパイラー
     - ソースコードを機械語に変換するプログラム
   * - 参照
     - 既存の変数に付ける別名
   * - 寿命
     - 変数やオブジェクトが有効である期間
   * - スマートポインター
     - 指しているオブジェクトを自動的に解放するクラス。``std::unique_ptr`` や ``std::shared_ptr`` など
   * - 静的型付け
     - 変数や式の型がコンパイル時に決まる方式
   * - 宣言
     - 名前と型をコンパイラーに知らせる記述。関数の宣言は本体を持たない
   * - ダングリングポインター
     - 寿命が終わったオブジェクトを指しているポインター
   * - 抽象クラス
     - 純粋仮想関数を持ち、オブジェクトを生成できないクラス
   * - 定義
     - 関数の本体や変数の実体を与える記述
   * - デストラクター
     - オブジェクトが破棄されるときに自動的に呼ばれるメンバー関数
   * - テンプレート
     - 型を引数として受け取り、型に依存しない関数やクラスを定義する仕組み
   * - 名前空間
     - 名前の衝突を避けるために識別子をまとめる仕組み。標準ライブラリは ``std`` 名前空間に属する
   * - 標準ライブラリ
     - C++ の規格で定められた、すべての処理系で使用できるライブラリ
   * - ビルド
     - ソースコードから実行ファイルを作る作業。プリプロセス、コンパイル、リンクから成る
   * - プリプロセス
     - ``#include`` などのディレクティブを処理する、コンパイルの前段階
   * - ポインター
     - アドレスを格納する変数
   * - 未定義動作
     - 規格で結果が定められていない操作。結果は予測できない
   * - ムーブ
     - コピーを作らずに、リソースの所有権を別のオブジェクトへ移すこと
   * - ラムダ式
     - その場で定義する名前のない関数
   * - リンク
     - オブジェクトファイルとライブラリを結合し、実行ファイルを生成すること
   * - RAII
     - リソースの取得をオブジェクトの初期化で行い、解放をデストラクターで行う考え方
