クラス
============================================================

本章では、C++ のクラスを Python のクラスと比較しながら説明します。

クラスの定義
------------------------------------------------------------

2 次元の点を表すクラスを、Python と C++ で書いた例を以下に示します。

.. code-block:: python

   class Point:
       def __init__(self, x, y):
           self._x = x
           self._y = y

       def move(self, dx, dy):
           self._x += dx
           self._y += dy

C++ のクラスは ``class`` キーワードで定義し、定義の最後にセミコロンを書きます。クラスが持つ変数をメンバー変数、関数をメンバー関数と呼びます。C++ ではメンバー変数をクラスの定義内で宣言する必要があり、Python のようにインスタンスへ後から属性を追加することはできません。

メンバー関数の中では、メンバー変数を ``self.`` を付けずに直接参照できます。本資料では、メンバー変数とほかの変数を区別するために、メンバー変数の名前の末尾に ``_`` を付けています。

オブジェクトは ``Point p(1.0, 2.0);`` のように、型名の後に変数名と引数を書いて生成します。Python の ``p = Point(1.0, 2.0)`` に相当します。

Python との対応を以下に示します。

.. list-table::
   :header-rows: 1
   :widths: 30 35 35

   * - 概念
     - Python
     - C++
   * - 初期化
     - ``__init__``
     - コンストラクター
   * - 自分自身
     - ``self``\ （明示的な引数）
     - ``this``\ （暗黙のポインター、通常は省略する）
   * - 文字列表現
     - ``__str__``
     - ``operator<<`` のオーバーロード
   * - 演算子の定義
     - ``__add__`` など
     - ``operator+`` など
   * - 非公開の属性
     - 名前の先頭に ``_`` を付ける（慣習）
     - ``private`` の下に宣言する

アクセス指定子
------------------------------------------------------------

``public:`` の後に宣言したメンバーはクラスの外から使用でき、``private:`` の後に宣言したメンバーはクラスの中からしか使用できません。``protected:`` の後に宣言したメンバーは、クラスの中と、そのクラスを継承したクラスの中から使用できます。

Python の先頭アンダースコアは「外から使わないでほしい」という慣習にすぎませんが、C++ のアクセス指定子はコンパイラーによって強制されます。``private`` のメンバーにクラスの外からアクセスすると、コンパイルエラーになります。メンバー変数は ``private`` にし、必要な操作だけを ``public`` のメンバー関数として公開するのが基本です。

``class`` の代わりに ``struct`` キーワードでもクラスを定義できます。両者の違いは、アクセス指定子を省略した場合の既定が ``class`` では ``private``、``struct`` では ``public`` であることだけです（継承の方式を省略した場合の既定も同様に異なります）。一般に、データをまとめるだけの単純な型には ``struct`` を使います。

コンストラクターとデストラクター
------------------------------------------------------------

コンストラクターは、オブジェクトの生成時に呼ばれるメンバー関数で、Python の ``__init__`` に相当します。コンストラクターはクラスと同じ名前で定義し、戻り値の型は書きません。

``point.cpp`` のコンストラクターにある ``: x_(x), y_(y)`` は、メンバー初期化子リストと呼ばれ、メンバー変数を初期化します。コンストラクターの本体で ``x_ = x;`` と代入することもできますが、初期化子リストを使うのが一般的です。

デストラクターは、オブジェクトが破棄されるときに自動的に呼ばれるメンバー関数で、``~Point()`` のようにクラス名の前に ``~`` を付けて定義します。デストラクターの役割は「:doc:`11_resource_management`」で説明します。

const メンバー関数
------------------------------------------------------------

``point.cpp`` の ``double x() const`` のように、引数リストの後に ``const`` を付けたメンバー関数を const メンバー関数と呼びます。const メンバー関数の中では、メンバー変数を変更できません。

const 参照で受け取ったオブジェクトに対しては、const メンバー関数しか呼び出せません。例えば ``operator<<`` は ``const Point& p`` を受け取るため、その中で ``p.move(...)`` を呼び出すとコンパイルエラーになります。オブジェクトの状態を変更しないメンバー関数には ``const`` を付けてください。

演算子のオーバーロード
------------------------------------------------------------

``operator+`` のような名前のメンバー関数を定義すると、自作のクラスに演算子を使えるようになります。Python の ``__add__`` に相当します。

``std::cout << p`` で出力できるようにするには、``std::ostream& operator<<(std::ostream& os, const Point& p)`` という関数をクラスの外に定義します。これは Python の ``__str__`` に相当する役割を持ちます。

継承と仮想関数
------------------------------------------------------------

既存のクラスを基にして新しいクラスを定義することを継承と呼びます。継承元のクラスを基底クラス、継承したクラスを派生クラスと呼びます。C++ では ``class Rectangle : public Shape`` のように書きます。

Python のメソッドは、常に派生クラスで上書き（オーバーライド）できます。一方、C++ で基底クラスの参照やポインターを通じて呼び出したときに、実際のオブジェクトの型に応じた関数が呼ばれるのは、``virtual`` を付けた関数（仮想関数）だけです。

   :caption: examples/ch10/shapes.cpp

.. code-block:: text
   :caption: 実行結果

   6
   3.14159

``print_area`` は ``const Shape&`` を受け取りますが、``shape.area()`` では、実際の型である ``Rectangle`` や ``Circle`` の ``area`` が呼ばれます。

派生クラスで仮想関数を上書きする場合は、``override`` を付けます。``override`` を付けておくと、関数名や引数の型を誤って基底クラスの関数を上書きできていない場合に、コンパイルエラーで知らせてくれます。

また、継承して使うことを想定したクラスでは、``virtual ~Shape() = default;`` のようにデストラクターを仮想関数にします。これを忘れると、基底クラスのポインターを通じてオブジェクトを破棄したときに、派生クラスのデストラクターが呼ばれません。

抽象クラス
------------------------------------------------------------

``shapes.cpp`` の ``virtual double area() const = 0;`` のように、``= 0`` を付けて本体を持たない仮想関数を、純粋仮想関数と呼びます。純粋仮想関数を持つクラスを抽象クラスと呼び、抽象クラスのオブジェクトは生成できません。

抽象クラスは、Python の ``abc`` モジュールで ``@abstractmethod`` を付けたメソッドを持つ抽象基底クラスに相当します。派生クラスは、すべての純粋仮想関数を上書きしなければオブジェクトを生成できません。
