変数と型
============================================================

本章では、C++ の変数と型を説明します。C++ は静的型付けの言語であり、変数の型は宣言時に決まり、後から変更できません。

変数の宣言と初期化
------------------------------------------------------------

Python では、値を代入するだけで変数が作られ、後から別の型の値を代入することもできます。

.. code-block:: python

   x = 10
   x = "hello"  # 別の型の値を代入できる

C++ では、変数を使う前に型を指定して宣言します。宣言した変数には、その型の値しか代入できません。

.. code-block:: cpp

   int x = 10;
   x = 20;         // OK
   x = "hello";    // コンパイルエラー: int 型の変数に文字列は代入できない

初期化の書き方には、``=`` を使う書き方と波括弧 ``{ }`` を使う書き方があります。

.. code-block:: cpp

   int a = 10;
   int b{10};
   int c = 3.7;   // コンパイルできるが、c の値は 3 になる（警告が出る場合がある）
   int d{3.7};    // コンパイルエラー: 値が失われる変換は波括弧の初期化では禁止されている

波括弧による初期化では、値が失われる変換（縮小変換）がコンパイルエラーになります。意図しない変換を防げるため、波括弧による初期化を好む人も多くいます。

.. warning::

   関数内で宣言した ``int`` や ``double`` などの変数を初期化しない場合、その値は不定です。Python のように未定義の変数を使うとエラーになるのではなく、何らかの値が読み出されてしまいます。変数は宣言時に必ず初期化してください。

基本型
------------------------------------------------------------

代表的な基本型を以下に示します。型のサイズは処理系によって異なる場合があります。表のサイズは、一般的な 64 ビット環境での値です。

.. list-table::
   :header-rows: 1
   :widths: 20 20 60

   * - 型
     - サイズ
     - 用途
   * - ``bool``
     - 1 バイト
     - 真偽値（``true`` または ``false``）
   * - ``char``
     - 1 バイト
     - 1 バイトの文字（``'A'`` のように単一引用符で囲む）
   * - ``int``
     - 4 バイト
     - 整数
   * - ``long long``
     - 8 バイト
     - 大きな整数
   * - ``double``
     - 8 バイト
     - 浮動小数点数（Python の ``float`` に相当）

C++ では、単一引用符 ``' '`` と二重引用符 ``" "`` の意味が異なります。``'A'`` は ``char`` 型の 1 文字、``"A"`` は文字列を表します。Python ではどちらも文字列を表すため、注意してください。文字列を扱う ``std::string`` 型については「:doc:`09_containers`」で説明します。

.. literalinclude:: ../../examples/ch05/types.cpp
   :language: cpp
   :caption: examples/ch05/types.cpp

.. code-block:: text
   :caption: 実行結果

   10 0.5 1 A Alice
   sizeof(int): 4
   int max: 2147483647
   int min: -2147483648

``bool`` 型の値は、既定では ``1`` または ``0`` と出力されます。``true`` または ``false`` と出力するには、先に ``std::cout << std::boolalpha;`` を実行します。``sizeof`` 演算子は、型や変数のサイズをバイト単位で返します。

整数の範囲とオーバーフロー
------------------------------------------------------------

Python の ``int`` は任意の大きさの整数を扱えますが、C++ の整数型が表せる範囲は有限です。例えば 32 ビットの ``int`` が表せる範囲は :math:`-2^{31}` 以上 :math:`2^{31} - 1` 以下、すなわち -2147483648 以上 2147483647 以下です。

.. warning::

   符号付き整数の演算結果が表せる範囲を超えることをオーバーフローと呼びます。C++ では、符号付き整数のオーバーフローは未定義動作です。Python のように大きな整数へ自動的に拡張されることはなく、エラーも報告されません。大きな値を扱う可能性がある場合は、``long long`` など範囲の広い型を使ってください。

未定義動作については「:doc:`14_error_handling`」で説明します。

auto による型推論
------------------------------------------------------------

``auto`` を使うと、初期値から変数の型をコンパイラーに推論させることができます。

.. literalinclude:: ../../examples/ch05/auto_const.cpp
   :language: cpp
   :caption: examples/ch05/auto_const.cpp

.. code-block:: text
   :caption: 実行結果

   42 3.14 3 43 100

``auto`` を使っても、変数の型はコンパイル時に決まります。``auto x = 42;`` の ``x`` は ``int`` 型であり、後から文字列を代入することはできません。``auto`` は、型名が長い場合や、型が初期値から明らかな場合に使うと効果的です。

const と constexpr
------------------------------------------------------------

値を変更しない変数には ``const`` を付けます。``const`` を付けた変数に代入しようとすると、コンパイルエラーになります。Python には言語仕様としての定数がなく、大文字の変数名で定数であることを示す慣習があるだけです。C++ の ``const`` は、コンパイラーによって変更が禁止されます。

``constexpr`` を付けると、値をコンパイル時に確定させることができます。``const`` の変数は実行時に決まる値でも初期化できますが、``constexpr`` の変数はコンパイル時に計算できる値でしか初期化できません。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 指定子
     - 意味
   * - ``const``
     - 初期化した後に値を変更できない
   * - ``constexpr``
     - 値がコンパイル時に確定し、かつ変更できない

変更する必要がない変数には、できるだけ ``const`` を付けてください。値が変わらないことが明示され、読み手の理解を助けます。

型変換
------------------------------------------------------------

C++ では、異なる型の値を組み合わせると暗黙の型変換が行われます。例えば ``int`` と ``double`` の演算では、``int`` の値が ``double`` に変換されてから計算されます。

一方、整数同士の演算の結果は整数になります。そのため、``7 / 2`` の結果は Python では ``3.5`` ですが、C++ では ``3`` です。小数の結果が必要な場合は、``static_cast`` で明示的に型を変換します。

.. literalinclude:: ../../examples/ch05/conversion.cpp
   :language: cpp
   :caption: examples/ch05/conversion.cpp

.. code-block:: text
   :caption: 実行結果

   3
   3.5
   3

``static_cast<型>(値)`` は、Python の ``float(a)`` や ``int(d)`` に相当する明示的な型変換です。C 言語由来の ``(double)a`` という書き方もありますが、変換の意図が分かりにくいため、``static_cast`` を使ってください。
