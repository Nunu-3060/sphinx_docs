演算子と制御構文
============================================================

本章では、演算子と、条件分岐および繰り返しの構文を説明します。

演算子
------------------------------------------------------------

算術演算子（``+``、``-``、``*``、``/``、``%``）と比較演算子（``==``、``!=``、``<``、``<=``、``>``、``>=``）は、Python とほぼ同じように使えます。Python と記号が異なる主な演算子を以下に示します。

.. list-table::
   :header-rows: 1
   :widths: 30 35 35

   * - 演算
     - Python
     - C++
   * - 論理積、論理和、否定
     - ``and``、``or``、``not``
     - ``&&``、``||``、``!``
   * - 整数の除算
     - ``//``
     - ``/``\ （両辺が整数の場合）
   * - べき乗
     - ``**``
     - ``std::pow`` 関数（``<cmath>`` ヘッダー）
   * - 1 の加算、1 の減算
     - ``x += 1``、``x -= 1``
     - ``++x``、``--x``\ （``x += 1`` なども使える）
   * - 条件式
     - ``a if cond else b``
     - ``cond ? a : b``

``++x`` はインクリメント演算子、``--x`` はデクリメント演算子と呼ばれます。``x++`` と後ろに書くこともできますが、式の値が異なります。``++x`` は加算した後の値、``x++`` は加算する前の値を返します。単独の文として使う場合はどちらも同じ結果になります。

Python の ``1 < x < 10`` のような比較の連鎖は、C++ では意図どおりに動作しません。C++ では ``1 < x`` の結果（``true`` または ``false``）と ``10`` が比較されるためです。``1 < x && x < 10`` と書いてください。

整数の除算と剰余
------------------------------------------------------------

両辺が整数の場合、``/`` は整数の除算になり、``%`` は剰余を返します。ただし、負の数を含む場合の結果は Python と異なります。

.. literalinclude:: ../../examples/ch06/division.cpp
   :language: cpp
   :caption: examples/ch06/division.cpp

.. code-block:: text
   :caption: 実行結果

   3 1
   -3 -1

.. warning::

   Python の ``//`` は負の無限大方向に丸めますが、C++ の整数除算は 0 方向に丸めます。そのため、Python の ``-7 // 2`` は ``-4`` ですが、C++ の ``-7 / 2`` は ``-3`` です。剰余も同様に、Python の ``-7 % 2`` は ``1`` ですが、C++ の ``-7 % 2`` は ``-1`` です。

条件分岐
------------------------------------------------------------

``if`` 文では、条件式を丸括弧で囲み、実行する処理を波括弧で囲みます。Python の ``elif`` は、C++ では ``else if`` と書きます。

``switch`` 文は、整数などの値に応じて処理を分岐します。Python 3.10 以降の ``match`` 文に近い構文ですが、``switch`` 文では各 ``case`` の最後に ``break`` を書く必要があります。``break`` を書かないと、次の ``case`` の処理も続けて実行されます。どの ``case`` にも一致しない場合は ``default`` の処理が実行されます。

.. literalinclude:: ../../examples/ch06/if_switch.cpp
   :language: cpp
   :caption: examples/ch06/if_switch.cpp

.. code-block:: text
   :caption: 実行結果

   B
   Weekday

``switch`` 文で分岐できるのは、``int`` や ``char`` などの整数系の型の値だけです。文字列で分岐する場合は ``if`` 文を使います。

繰り返し
------------------------------------------------------------

C++ には、``while`` 文、``for`` 文、範囲 ``for`` 文の 3 種類の繰り返し構文があります。

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Python
     - C++
   * - ``for i in range(5):``
     - ``for (int i = 0; i < 5; ++i) { }``
   * - ``for x in values:``
     - ``for (int x : values) { }``
   * - ``while n < 100:``
     - ``while (n < 100) { }``

``for`` 文は、丸括弧の中にセミコロンで区切って「初期化」「継続条件」「更新処理」を書きます。最初に初期化を 1 回実行し、継続条件が真である間、ブロックの処理と更新処理を繰り返します。

範囲 ``for`` 文は、コンテナの要素を先頭から順に取り出して処理します。Python の ``for x in values:`` に相当します。

ループの途中で抜ける ``break`` と、次の繰り返しに進む ``continue`` は、Python と同じ意味で使えます。

.. literalinclude:: ../../examples/ch06/loops.cpp
   :language: cpp
   :caption: examples/ch06/loops.cpp

.. code-block:: text
   :caption: 実行結果

   0 1 2 3 4
   10 20 30
   128
   1 3 5 7

Python の ``for`` 文にある ``else`` 節は、C++ にはありません。
