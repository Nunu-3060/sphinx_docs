見出しは、文字列の下（または上下）に記号の行を置いて表します。記号の種類と登場順で階層が決まります。

段落とインライン記法
====================

段落は空行で区切ります。日本語の段落は途中で改行せず、1 行で書くと余計な空白が入りません。

*強調*、**強い強調**、``リテラル`` のように書きます。

`Sphinx の公式サイト <https://www.sphinx-doc.org/>`_ へのリンクも書けます。

リスト
======

- 箇条書きの項目 1
- 箇条書きの項目 2

  - 入れ子の項目は、親の項目の本文にそろえて字下げします。

1. 番号付きリストの項目 1
2. 番号付きリストの項目 2

#. 番号を自動で振る項目
#. 番号を自動で振る項目

用語
   定義リストでは、次の行を字下げして説明を書きます。
