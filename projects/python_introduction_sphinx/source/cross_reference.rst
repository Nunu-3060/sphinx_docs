.. _ch-cross-reference:

========
相互参照
========

Sphinx では、章や図表、用語、Python のオブジェクトなど、ドキュメントのさまざまな要素を\ :term:`相互参照`\ できます。参照先の見出しや番号は自動で埋め込まれるため、見出しを変更しても参照元を書き直す必要がありません。この章では、相互参照の方法と、ファイルのダウンロードリンクや外部へのリンクの書き方を説明します。

.. _sec-ref:

章や節への参照
==============

章や節を参照するには、見出しの直前に\ :term:`ラベル`\ を書き、``ref`` ロールでそのラベルを指定します。ラベルは ``..`` と半角空白の後に、``_`` で始まり ``:`` で終わる名前を書いて定義します。

.. code-block:: rst
   :linenos:

   .. _sec-install:

   インストール
   ============

   インストールの手順は :ref:`sec-install` を参照してください。
   詳しくは :ref:`こちら <sec-install>` を参照してください。

5 行目のように書くと、参照先の見出し「インストール」がリンクの文字列になります。6 行目のように ``表示する文字列 <ラベル>`` の形で書くと、リンクの文字列を指定できます。

ラベルはプロジェクト全体で共有されるため、別のソースファイルの見出しも同じ方法で参照できます。その代わり、プロジェクトの中で同じ名前のラベルを 2 回定義することはできません。本書では、章のラベルを ``ch-``、節のラベルを ``sec-``、図のラベルを ``fig-``、表のラベルを ``table-`` で始めて、名前の重複を防いでいます。

存在しないラベルを指定すると、ビルド時に「undefined label」という警告が出ます。見出しを変更しても、ラベルを変更しない限り参照は壊れません。

ドキュメントへの参照
====================

ソースファイル単位で参照するには、``doc`` ロールを使います。拡張子を省いたパスで指定し、参照先のドキュメントのタイトルがリンクの文字列になります。

.. code-block:: rst
   :linenos:

   :doc:`install` を参照してください。
   :doc:`/install` を参照してください。

1 行目は、参照元のソースファイルからの相対パスです。2 行目のように ``/`` で始めると、ソースディレクトリからのパスになります。

.. _sec-numref:

図表の番号による参照
====================

``conf.py`` に ``numfig = True`` と書くと、図、表、キャプション付きのコードに番号が振られます。番号の付いた要素は、``numref`` ロールで参照できます。

.. code-block:: rst
   :linenos:

   .. _fig-build-flow:

   .. figure:: images/build_flow.svg

      Sphinx がドキュメントを生成する流れ

   処理の流れを :numref:`fig-build-flow` に示します。
   :numref:`処理の流れ（図 %s） <fig-build-flow>` を参照してください。

7 行目は「処理の流れを\ :numref:`fig-build-flow` に示します。」のように表示されます。8 行目のように書くと、``%s`` の部分が番号に置き換わります。表に番号を振るには、``list-table`` にタイトルを付けます。

``toctree`` に ``:numbered:`` を指定している場合、図表の番号には章の番号が付きます。本書の図表の番号が「図 1.1」のようになっているのはこのためです。

.. _sec-glossary-term:

用語集と用語への参照
====================

``glossary`` ディレクティブで用語集を作り、``term`` ロールで用語を参照できます。用語集の書き方は定義リストと同じです。

.. code-block:: rst
   :linenos:

   .. glossary::
      :sorted:

      ビルダー
         doctree を特定の形式に変換して出力する部品。

      doctree
         ソースファイルを解析して作られる木構造のデータ。

   :term:`ビルダー` は出力形式ごとに用意されています。

``:sorted:`` オプションを付けると、用語が五十音順やアルファベット順に並べ替えられます。本書の\ :ref:`ch-glossary`\ も ``glossary`` ディレクティブで作っており、本文中の用語から用語集へリンクしています。

ファイルのダウンロード
======================

``download`` ロールを使うと、ファイルをダウンロードするためのリンクを作れます。指定したファイルはビルド時に出力先の ``_downloads`` ディレクトリへコピーされます。

.. code-block:: rst
   :linenos:

   :download:`サンプルコード <../examples/sample_package/shapes.py>`

このソースファイルは「:download:`サンプルコード <../examples/sample_package/shapes.py>`」のように表示されます。ソースディレクトリの外にあるファイルも指定できるため、サンプルコードを別のディレクトリで管理したまま配布できます。

.. _sec-external-link:

外部へのリンク
==============

Web ページへのリンクは、表示する文字列と URL をバッククォートで囲み、末尾に ``_`` を付けて書きます。同じ URL を何度も使う場合は、リンク先に名前を付けて定義しておくと、本文を短く書けます。

.. code-block:: rst
   :linenos:

   `Sphinx の公式ドキュメント <https://www.sphinx-doc.org/ja/master/>`_ を参照してください。

   `Sphinx 公式`_ を参照してください。

   .. _Sphinx 公式: https://www.sphinx-doc.org/ja/master/

1 行目は URL をその場で指定する書き方です。3 行目はリンク先の名前だけを書き、5 行目でその名前と URL を対応付けています。

.. _sec-intersphinx:

外部のドキュメントへの相互参照（intersphinx）
=============================================

:term:`intersphinx` 拡張機能を使うと、Python の公式ドキュメントなど、Sphinx で作られた外部のドキュメントの要素を相互参照できます。``conf.py`` で拡張機能を有効にし、参照するドキュメントの URL を ``intersphinx_mapping`` に登録します。

.. code-block:: python
   :linenos:

   extensions = ["sphinx.ext.intersphinx"]

   intersphinx_mapping = {
       "python": ("https://docs.python.org/3", None),
   }

登録すると、Python のオブジェクトを参照するロールで、外部のドキュメントの要素にリンクできます。

.. code-block:: rst
   :linenos:

   :py:func:`print` 関数と :py:class:`pathlib.Path` クラスを使います。

このソースファイルは「:py:func:`print` 関数と :py:class:`pathlib.Path` クラスを使います。」のように表示され、それぞれ Python の公式ドキュメントの説明へのリンクになります。

Python のオブジェクトを参照するロールの一覧を\ :numref:`table-py-roles` に示します。これらのロールは Python の\ :term:`ドメイン`\ に属しています。Python ドメインは既定のドメインのため、``py:`` を省いて ``:func:`print``` のように書くこともできます。

.. _table-py-roles:

.. list-table:: Python のオブジェクトを参照するロール
   :header-rows: 1
   :widths: 30 70

   * - ロール
     - 参照先
   * - ``:py:mod:``
     - モジュール
   * - ``:py:func:``
     - 関数
   * - ``:py:class:``
     - クラス
   * - ``:py:meth:``
     - メソッド
   * - ``:py:attr:``
     - 属性
   * - ``:py:data:``
     - モジュールの変数

外部のドキュメントで参照できる名前の一覧は、次のコマンドで確認できます。

.. code-block:: text
   :linenos:

   python -m sphinx.ext.intersphinx https://docs.python.org/3/objects.inv

intersphinx は、ビルド時に外部のドキュメントの ``objects.inv`` というファイルをダウンロードします。インターネットに接続していない環境では、参照がリンクにならず、警告が出ます。また、ダウンロードを待つ時間には既定では上限がないため、ネットワークの状態によってはビルドが止まったように見えることがあります。``conf.py`` に ``intersphinx_timeout = 30`` のように書くと、待つ時間の上限を秒単位で指定できます。本書もこの設定を使っています。
