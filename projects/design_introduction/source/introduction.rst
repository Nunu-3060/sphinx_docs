はじめに
========

本書の目的
----------

エンジニアが作るものの多くは、誰かに何かを伝えるためのものです。測定結果のグラフ、会議で使う資料、同僚が毎日使う業務ツールの画面などがその例です。内容が正しくても、見た目が整理されていなければ、読み手は要点を見落としたり、操作を誤ったりします。

本書でいう「デザイン」は、見た目を飾ることではありません。伝えたい情報を、読み手が迷わず、誤解なく受け取れるように形を決めることです。そのための原則の多くは、人の視覚や認知の性質に基づいて説明できます。本書では、原則を紹介するだけでなく、なぜそうするとよいのかという理由と、Python で実装する方法をあわせて説明します。

対象読者
--------

Python、numpy、pandas、matplotlib、Pillow、tkinter の基本的な使い方を知っているエンジニアを対象とします。デザインを専門的に学んだ経験は必要ありません。

サンプルコードの使い方
----------------------

各章のサンプルコードは、その章の末尾と\ :doc:`samples`\ からダウンロードできます。どのサンプルも単独で実行でき、画像を保存するサンプルは ``--outdir`` で保存先フォルダーを指定できます（tkinter のサンプルは、``--screenshot`` で保存先のファイルを指定します）。省略した場合は、サンプルコードと同じフォルダーにある ``output`` フォルダーに保存します。

.. code-block:: console

   python ch01_principles.py --outdir output

画像に日本語を描画するため、サンプルコードは次の順にフォントを探します。見つからない場合は既定のフォントを使うため、日本語が正しく表示されません。

* Windows：游ゴシック、メイリオ
* macOS：ヒラギノ角ゴシック
* Linux：Noto Sans CJK JP

サンプルコードはすべて PEP 8 に沿って書かれており、flake8 と mypy（``--strict`` 相当）で警告が出ないことを確認しています。確認に使った設定ファイルも\ :doc:`samples`\ からダウンロードできます。

表記について
------------

* 色は ``#rrggbb`` 形式の 16 進数で表します。たとえば ``#1f5fbf`` は、赤 31、緑 95、青 191（各 0〜255）の青色です。
* 画面上の大きさはピクセル（px）で表します。文字の大きさは、Pillow で描画する場合は px で、matplotlib と tkinter では pt で指定します。96 dpi の画面では 1 pt が約 1.33 px に相当します。
* 図の「改善前」と「改善後」は、同じ内容を異なる方法で表したものです。
