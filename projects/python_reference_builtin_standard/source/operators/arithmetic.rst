算術演算子
==========

数値（``int`` や ``float`` など）に対して四則演算やべき乗を行うための演算子群。

``+`` / ``-`` / ``*``
----------------------

加算・減算・乗算を行う。

.. code-block:: python

   >>> 3 + 5
   8
   >>> 10 - 4
   6
   >>> 3 * 4
   12
   >>> 2.5 * 2
   5.0

``/`` ``//`` ``%``
--------------------

``/`` は真の除算（true division）を行い、常に ``float`` を返す。``//`` は切り捨て除算（floor division）で商の小数部を切り捨て、``%`` は剰余（modulo）を返す。

.. code-block:: python

   >>> 7 / 2
   3.5
   >>> 8 / 4
   2.0
   >>> 7 // 2
   3
   >>> 7 % 2
   1

.. note::

   ``/`` は両方のオペランドが ``int`` であっても結果は必ず ``float`` になる。一方 ``//`` と ``%`` は負の数に対して「除数の符号に揃える」規則で動作するため、直感的な結果と異なる場合がある。

   .. code-block:: python

      >>> -7 // 2
      -4
      >>> -7 % 2
      1

   これは、常に ``(a // b) * b + (a % b) == a`` という関係が成り立つように定義されているためである。

``**``
------

べき乗を計算する。右結合であり、単項マイナスより優先順位が高い。

.. code-block:: python

   >>> 2 ** 10
   1024
   >>> 2 ** 0.5
   1.4142135623730951
   >>> -2 ** 2
   -4

.. note::

   組み込み関数 :doc:`../builtins/numeric` の ``pow()`` は ``**`` と同じ計算を行うが、第3引数（法）を渡すと剰余演算まで含めて効率的に計算できる点が異なる（``pow(2, 10, 1000)`` は ``2 ** 10 % 1000`` と同じ結果を返す）。

単項 ``+`` / ``-``
--------------------

数値の符号をそのまま示す単項プラス、符号を反転する単項マイナス。

.. code-block:: python

   >>> x = 5
   >>> -x
   -5
   >>> +x
   5
   >>> -(-x)
   5
