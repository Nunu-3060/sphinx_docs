ビット演算子
============

整数をビット列として扱い、ビットごとの論理演算やビットシフトを行うための演算子。フラグの管理やビットマスクを使った処理などで利用される。

``&`` / ``|`` / ``^``
------------------------

``&`` はビットごとの論理積（AND）、``|`` はビットごとの論理和（OR）、``^`` はビットごとの排他的論理和（XOR）を計算する。``0b`` 接頭辞を使った二進数リテラルで書くとビットパターンが分かりやすい。

.. code-block:: python

   >>> 0b1010 & 0b0110
   2
   >>> bin(0b1010 & 0b0110)
   '0b10'
   >>> bin(0b1010 | 0b0110)
   '0b1110'
   >>> bin(0b1010 ^ 0b0110)
   '0b1100'

``~``
------

ビットごとの否定（NOT）を行う単項演算子。各ビットを反転させる。

.. code-block:: python

   >>> ~0b1010
   -11
   >>> ~5
   -6
   >>> ~0
   -1

.. note::

   Python の整数は2の補数表現で解釈されるため、``~x`` は ``-x - 1`` と等しくなる。ビットをすべて反転すると符号が反転し、さらに1だけずれるためである。

   .. code-block:: python

      >>> x = 5
      >>> ~x == -x - 1
      True

``<<`` / ``>>``
------------------

``<<`` は左シフト、``>>`` は右シフトを行う。左シフトは値を2のべき乗倍することに相当し、右シフトは2のべき乗で割った商（切り捨て）に相当する。

.. code-block:: python

   >>> 1 << 3
   8
   >>> 1 << 10
   1024
   >>> 20 >> 2
   5

左シフトを使うと、フラグ用のビットマスクを見やすく定義できる。

.. code-block:: python

   >>> READ = 1 << 0    # 0b0001
   >>> WRITE = 1 << 1   # 0b0010
   >>> EXEC = 1 << 2    # 0b0100
   >>> perm = READ | WRITE
   >>> bool(perm & WRITE)
   True
   >>> bool(perm & EXEC)
   False
