比較演算子
==========

2つのオブジェクトの値やその大小関係を比較し、``bool`` 値を返す演算子群。

``==`` / ``!=``
------------------

値が等しいか、等しくないかを判定する。

.. code-block:: python

   >>> 1 == 1.0
   True
   >>> [1, 2] == [1, 2]
   True
   >>> "abc" != "abd"
   True

.. note::

   ``==`` はオブジェクトの「値」を比較する（内部的には ``__eq__`` メソッドが呼ばれる）。これは「同一のオブジェクトかどうか」を調べる ``is`` 演算子とは異なる概念であり、値が等しくても ``is`` では ``False`` になることがある。``is`` による同一性の比較については :doc:`membership_identity` で詳しく扱う。

   .. code-block:: python

      >>> a = [1, 2]
      >>> b = [1, 2]
      >>> a == b
      True
      >>> a is b
      False

``<`` / ``>`` / ``<=`` / ``>=``
----------------------------------

大小関係を判定する。数値だけでなく、文字列やタプルなど順序付け可能な型にも使用できる。

.. code-block:: python

   >>> 3 < 5
   True
   >>> 5 <= 5
   True
   >>> "apple" < "banana"
   True
   >>> (1, 2) < (1, 3)
   True

連鎖比較
--------

``a < b < c`` のように比較演算子を連ねて書くと、``a < b and b < c`` と同じ意味になる（``a`` や ``b`` が2回評価されない点にも注意）。数学的な区間の表記に近い書き方ができる。

.. code-block:: python

   >>> 1 < 2 < 3
   True
   >>> 1 < 3 < 2
   False
   >>> a = 5
   >>> 0 < a < 10
   True

.. note::

   連鎖比較は ``(a < b) < c`` のように左から順に評価して結果の ``bool`` を次の比較に使う、という意味では **ない**。あくまで各項どうしの比較を ``and`` でつないだものと等価である。

   .. code-block:: python

      >>> 5 < 3 < 1          # 連鎖比較: (5 < 3) and (3 < 1) と同じ
      False
      >>> (5 < 3) < 1        # 左の結果 False (== 0) を 1 と比較すると True になってしまう
      True
