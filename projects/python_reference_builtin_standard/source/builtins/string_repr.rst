文字列表現・フォーマット
========================

オブジェクトを文字列として表現・整形するための関数群。

repr
----

オブジェクトの開発者向けの文字列表現を返す。``str`` が人間にとって読みやすい表示用の文字列を返すのに対し、``repr`` は曖昧さのない表現を返し、組み込み型の多くではその文字列をそのままソースコードに書けば同じ値を再現できる。

.. code-block:: python
   :linenos:

   >>> repr("hello")
   "'hello'"
   >>> repr([1, 2, 3])
   '[1, 2, 3]'

format
------

値をフォーマット指定子に従って整形した文字列を返す。

.. code-block:: python
   :linenos:

   >>> format(3.14159, ".2f")
   '3.14'
   >>> format(255, "x")
   'ff'

ascii
-----

``repr`` と同様だが、非 ASCII 文字を ``\x``、``\u``、``\U`` エスケープに置き換える。

.. code-block:: python
   :linenos:

   >>> ascii("こんにちは")
   "'\\u3053\\u3093\\u306b\\u3061\\u306f'"
