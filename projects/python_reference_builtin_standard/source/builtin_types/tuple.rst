tuple
=====

Python のタプル型 ``tuple`` が持つメソッド群。``tuple`` は ``list`` と同様に複数の要素を順序付けて保持するが、イミュータブル（変更不可）である点が異なる。そのため、要素の追加や削除を行うメソッドは存在せず、持っているメソッドは ``count`` と ``index`` の 2 つだけである。

tuple.count / tuple.index
------------------------------

``count`` は指定した値がタプル中に何個含まれるかを数える。``index`` は指定した値が最初に現れる位置（インデックス）を返し、見つからない場合は ``ValueError`` を発生させる。

.. code-block:: python

   >>> t = (1, 2, 3, 2, 1)
   >>> t.count(1)
   2
   >>> t.count(5)
   0
   >>> t.index(3)
   2
   >>> t.index(5)
   Traceback (most recent call last):
       ...
   ValueError: tuple.index(x): x not in tuple

タプルのアンパック
-------------------

タプルの各要素を複数の変数に一度に代入できる。これを「アンパック」と呼ぶ。先頭に ``*`` を付けた変数を使うと、残りの要素をまとめてリストとして受け取ることもできる（拡張アンパック）。

.. code-block:: python

   >>> a, b = 1, 2
   >>> a
   1
   >>> b
   2
   >>> point = (10, 20, 30)
   >>> x, y, z = point
   >>> x, y, z
   (10, 20, 30)
   >>> first, *rest = [1, 2, 3, 4]
   >>> first
   1
   >>> rest
   [2, 3, 4]
   >>> *init, last = (1, 2, 3, 4)
   >>> init
   [1, 2, 3]
   >>> last
   4

.. note::

   ``tuple`` のメソッドが ``count`` と ``index`` しかないのは、イミュータブルであるため ``list`` の ``append`` や ``remove`` のような、要素をその場で変更するメソッドが存在しないからである。固定長で内容を変更しないデータ（例えば座標や DB のレコードのような、異なる型の値の組）を表す場合や、辞書のキーとして使いたい場合（``tuple`` はハッシュ可能だが ``list`` はハッシュ不可能）には、``list`` よりも ``tuple`` を選ぶとよい。
