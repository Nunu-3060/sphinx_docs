Python コア機能・標準ライブラリ解説書
=========================================

このドキュメントは、Python の組み込み型・演算子・組み込み関数・標準モジュールについて、実務でよく使われるものを中心にまとめた解説書である。

本書は Python 3.11 以降を対象とする。特定のバージョンで追加・変更された機能には、その旨を本文中に記載している。コード例の出力は Python 3.14 で確認したものであり、エラーメッセージや ``repr`` の表示などはバージョンによって多少異なることがある。
