音声合成の基礎
====================================================

これまでの章では、 MIDI という形式で演奏情報を生成する方法を扱ってきました。 MIDI データは音の高さやタイミングといった演奏情報のみを表し、実際の音そのものは音源やソフトウェアシンセサイザーが生成します。本章では、これとは異なるアプローチとして、 Python を用いて波形そのものを合成し、音声ファイルとして出力する方法を説明します。

デジタルオーディオの基礎
----------------------------------------------------

コンピューターで音を扱う際には、連続的な音の波形を、一定の間隔でサンプリング（ 標本化 ）した数値の列として表現します。 1 秒間に何回サンプリングするかを表す値をサンプリングレートと呼び、 CD 音質では 44100 （ Hz ）が用いられます。また、各サンプルの値をどれだけの精度で記録するかを表す値をビット深度と呼び、一般的な WAV ファイルでは 16 ビットが用いられます。

サイン波の生成
----------------------------------------------------

もっとも基本的な音の波形はサイン波です。 ``numpy`` を用いると、以下のように任意の周波数のサイン波を数値の配列として生成することができます。

.. code-block:: python

   import numpy as np

   sample_rate = 44100
   frequency = 440.0
   duration = 1.0

   sample_count = int(sample_rate * duration)
   times = np.linspace(0, duration, sample_count, endpoint=False)
   samples = np.sin(2 * np.pi * frequency * times)

このコードでは、 440 Hz （ 音楽で用いられる基準音、いわゆる A4 の音 ）のサイン波を、 1 秒間分だけ生成しています。

ADSR エンベロープ
----------------------------------------------------

サイン波をそのまま鳴らすと、音の始まりと終わりで急激に音量が変化し、不自然なクリック音が発生します。実際の楽器の音は、発音してから減衰するまでの間に音量が滑らかに変化しており、この音量変化を近似するためにアタック（ Attack ）、ディケイ（ Decay ）、サステイン（ Sustain ）、リリース（ Release ）の 4 段階からなる ADSR エンベロープがよく用いられます。

* **アタック**： 発音してから最大音量に達するまでの時間。
* **ディケイ**： 最大音量からサステインレベルまで音量が下がる時間。
* **サステイン**： 音を維持している間の音量レベル。
* **リリース**： 発音を止めてから音量が 0 になるまでの時間。

波形データに、これら 4 段階の音量変化を表す配列を掛け合わせることで、自然な音量変化を持つ音を合成することができます。

WAV ファイルへの出力
----------------------------------------------------

生成した波形データは、 Python の標準ライブラリである ``wave`` モジュールを用いて、 WAV ファイルとして出力することができます。 ``wave`` モジュールは -1.0 から 1.0 の範囲の浮動小数点数ではなく、整数のバイト列を扱うため、出力前に 16 ビット整数の範囲へ変換する必要があります。

具体的な実装例は、次章の「実装例」で紹介します。

生成音楽における音声合成の位置付け
----------------------------------------------------

MIDI による生成が「どの高さの音を、いつ鳴らすか」という演奏情報の生成であるのに対し、本章で紹介した音声合成は「どのような音色で鳴らすか」という、より低いレベルでの音作りに相当します。両者を組み合わせることで、アルゴリズムによって決定された演奏情報を、自ら合成した音色で鳴らすといった、より自由度の高いジェネラティブミュージックの制作が可能になります。
