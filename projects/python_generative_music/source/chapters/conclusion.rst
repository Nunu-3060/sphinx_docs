まとめ
====================================================

本資料では、 Python によるジェネラティブミュージックの制作方法について解説しました。

まず、ジェネラティブミュージックの概念と歴史的な背景を確認し、その後、 Python における開発環境の準備方法と、制作に利用できる代表的なライブラリを紹介しました。続いて、 MIDI データの基礎知識と、 ``pretty_midi`` を用いた基本的な操作方法を説明した後、 ``numpy`` と ``wave`` を用いてサイン波を合成し、 WAV ファイルとして出力する音声合成の基礎を解説しました。さらに、乱数、マルコフ連鎖、セル・オートマトン、 L システム、ユークリッドリズムといった代表的なアルゴリズム作曲の手法を紹介し、最後に、これらの内容を踏まえた 4 つの実装例を示しました。

今後の学習に向けて
----------------------------------------------------

ジェネラティブミュージックの分野は、本資料で紹介した手法以外にも、機械学習を用いた旋律生成や、リアルタイムの音声信号処理を組み合わせた手法など、さまざまな発展の方向性があります。また、本資料の実装例は旋律やリズムの生成が中心でしたが、「ジェネラティブミュージックとは」の章で触れた和音やコード進行の考え方を取り入れ、 ``music21`` を用いて調やコード進行に基づいた生成へ発展させることも、次のステップとして考えられます。本資料で紹介した実装例を出発点として、独自のアルゴリズムや表現手法を試していくことを推奨します。
