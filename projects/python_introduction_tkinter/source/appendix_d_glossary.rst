付録 D 用語集
=============

本資料で使う主な用語を、英字、五十音の順に示します。各用語の詳しい説明は、「参照」に示した節を読んでください。

.. glossary::

   Tcl/Tk
      Tcl はスクリプト言語で、Tk は Tcl のために作られた GUI ツールキットです。tkinter は、Python から Tcl のインタープリターを通して Tk を操作します。

      参照: :ref:`tcl-tk`

   ttk
      Tk 8.5 で追加された、テーマに従って描画されるウィジェットの集まりです。Python では ``tkinter.ttk`` モジュールとして提供されます。

      参照: :ref:`tk-ttk`

   イベント
      マウスのクリックやキー入力、ウィンドウの大きさの変更など、アプリケーションが対応する出来事です。

      参照: :ref:`event-driven`

   イベントシーケンス
      ``bind`` メソッドで、どのイベントに関数を結び付けるかを指定する文字列です。``<Button-1>`` や ``<Control-s>`` のように書きます。

      参照: :ref:`event-sequence`

   イベントループ
      イベントの発生を待ち、イベントに対応する処理を呼び出すことを繰り返す仕組みです。``mainloop`` メソッドで開始します。

      参照: :ref:`event-loop`

   インデックス
      Text の中の文字の位置を表す文字列です。``"1.0"`` のように ``"行.列"`` の形式で書くほか、``"end"`` や ``"insert"`` などの名前も使えます。

      参照: :ref:`text-widget`

   ウィジェット
      ボタンや入力欄など、ウィンドウに配置する GUI の部品です。

      参照: :ref:`widget-common`

   仮想イベント
      ``<<ListboxSelect>>`` のように、二重の山かっこで囲んで表すイベントです。ウィジェットが独自に発生させるほか、``event_generate`` メソッドで発生させることもできます。

      参照: :ref:`event-sequence`

   コールバック関数
      ボタンが押されたときなど、特定の操作やイベントが発生したときに呼び出されるように登録しておく関数です。

      参照: :ref:`event-driven`

   コンテキストメニュー
      右クリックしたときに、マウスポインターの位置に表示されるメニューです。

      参照: :ref:`context-menu`

   ジオメトリマネージャー
      ウィジェットの位置と大きさを決める仕組みです。tkinter には ``pack``、``grid``、``place`` の 3 種類があります。

      参照: :ref:`geometry-manager`

   スタイル
      ttk のウィジェットの色やフォントなどの外観をまとめて定義したものです。``ttk.Style`` で設定します。

      参照: :ref:`style-basics`

   テーマ
      ttk のウィジェット全体の描画方法を決めるものです。``vista`` や ``clam`` などがあり、切り替えると見た目がまとめて変わります。

      参照: :ref:`theme`

   名前付きフォント
      名前を付けて作成したフォントです。設定を変更すると、そのフォントを使っているすべてのウィジェットの表示が更新されます。

      参照: :ref:`font-color`

   バインドタグ
      1 つのイベントに対して、どこに ``bind`` された関数を、どの順番で呼び出すかを決める名前の並びです。

      参照: :ref:`bindtags`

   フォーカス
      ウィジェットがキーボードからの入力を受け付けている状態です。キーボードのイベントは、フォーカスを持つウィジェットに送られます。

      参照: :ref:`entry`

   変数クラス
      ``StringVar`` や ``IntVar`` など、ウィジェットの表示内容と連動する tkinter の特別な変数です。

      参照: :ref:`variable-class`

   メインウィンドウ
      ``tk.Tk()`` で作成する、アプリケーションの最初のウィンドウです。すべてのウィジェットの親（根）になります。

      参照: :ref:`main-window`

   メインスレッド
      ``tk.Tk()`` を作成したスレッドです。ウィジェットや変数クラスの操作は、メインスレッドだけで行います。

      参照: :ref:`threading`

   モーダルダイアログ
      閉じるまで、元のウィンドウを操作できないようにしたダイアログです。

      参照: :ref:`modal-dialog`
