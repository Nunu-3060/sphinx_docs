はじめに
========

本資料の目的
------------

本資料は、Python の標準ライブラリである tkinter を使って、GUI（グラフィカルユーザーインターフェース）を持つアプリケーションを作成する方法を解説します。小さな部品の使い方から順に学び、:doc:`第 12 章 <12_practice_memo_app>`\ で簡易メモ帳アプリケーションを完成させることを目標とします。

想定読者
--------

本資料は、次のような方を対象としています。

* Python の基本文法（変数、制御構文、関数、クラス、モジュールの import）を理解している方
* GUI プログラミングの経験がない方

サンプルコードには型ヒントを付けています。型ヒントはプログラムの動作には影響しないため、なじみのない方は読み飛ばしてもかまいません。

サンプルコードの使い方
----------------------

各章のサンプルコードは本文に掲載しており、本文中のリンクからダウンロードできます。すべてのサンプルコードの一覧は\ :doc:`付録 C <appendix_c_examples>` にあります。

ダウンロードしたファイルは、コマンドプロンプトやターミナルで次のように実行します。

.. code-block:: console

   python ch02_hello_window.py

Windows で ``python`` コマンドが見つからない場合は、``py`` コマンドを使ってください。

どのサンプルコードも、処理を ``main`` 関数にまとめ、ファイルの末尾で ``if __name__ == "__main__":`` から呼び出す形式で書いています。

本資料の表記
------------

コード中の ``tk`` と ``ttk`` は、次のように import したモジュールを表します。

.. code-block:: python

   import tkinter as tk
   from tkinter import ttk

本資料で使う主な用語の意味は、:doc:`付録 D <appendix_d_glossary>` の用語集にまとめています。
