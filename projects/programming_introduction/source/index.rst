プログラミング入門
==================

本書は、エンジニアを対象に「プログラミングとは何か」を解説する入門資料である。特定の言語の文法を網羅するのではなく、コンピュータが動く仕組みから、プログラミング言語、プログラムの基本要素、アルゴリズム、抽象化、品質、開発工程までを順に積み上げ、プログラミングという行為の全体像をつかむことを目的とする。
