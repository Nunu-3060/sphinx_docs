はじめに
========

本書の目的
----------

本書の目的は、「プログラミングとは何か」という問いに、エンジニアが納得できる形で答えることである。プログラムを書いた経験がある人でも、それがコンピュータの中でどのように実行されるのか、なぜ現在のような言語や書き方が使われているのかを体系的に説明できる人は多くない。本書では、個々の文法よりも、プログラミングを支える考え方とその背景を重視する。

対象読者
--------

本書は次のような読者を想定している。

* インフラ、ハードウェア、品質保証など、ソフトウェア開発以外の分野のエンジニア
* プログラムを書いた経験はあるが、体系的に学んだことがないエンジニア
* 新人や他部署のメンバーに、プログラミングの全体像を説明する立場のエンジニア

前提知識は特に必要としない。ただし、コマンドラインでコマンドを実行する程度の操作は説明なしに扱う。

サンプルコード
--------------

本書のサンプルコードはすべて Python で記述している。Python を選んだ理由は、文法が簡潔で、本書で扱う概念を少ない記述量で示せるためである。サンプルコードは\ :doc:`examples`\ からダウンロードできる。

サンプルコードは Python 3.10 以降で動作する。また、すべてのサンプルコードに\ :term:`型ヒント`\ を付け、flake8 と mypy による検査で違反が出ないことを確認している。サンプルコードを実行するには、ファイルを保存したフォルダーで次のように入力する。

.. code-block:: console
   :linenos:

   $ python hello.py
   Hello, World!

表記規則
--------

本書では次の表記規則を用いる。

* コード、ファイル名、コマンドは ``hello.py`` のように等幅フォントで表記する。
* コード例には行番号を付ける。本文で「3 行目」のように行を示すときは、この行番号を指す。
* 実行結果は、コード中のコメント（``#`` 以降）に示すか、コード例の直後に示す。
* ``$`` で始まる行は、コマンドラインに入力するコマンドを表す。``$`` 自体は入力しない。
