コンピュータはどう動くか
========================

プログラムを理解するには、それを実行するコンピュータの仕組みを知っておく必要がある。この章では、コンピュータの基本的な構成と、プログラムやデータがコンピュータの内部でどのように表現されるかを説明する。

コンピュータの構成
------------------

現在のコンピュータの多くは、次の装置から構成される。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 装置
     - 役割
   * - :term:`CPU`
     - 命令を読み出して解釈し、演算を実行する。内部に\ :term:`レジスタ`\ と呼ばれる小容量で高速な記憶領域を持つ。
   * - :term:`メモリ`
     - 実行中のプログラムと、そのプログラムが扱うデータを記憶する。主記憶装置とも呼ぶ。電源を切ると内容は失われる。
   * - 補助記憶装置
     - SSD や HDD など。電源を切っても内容が失われないため、プログラムやデータをファイルとして保存しておく。
   * - 入出力装置
     - キーボード、ディスプレイ、ネットワークインタフェースなど。外部とデータをやり取りする。

プログラムを実行するときは、補助記憶装置に保存されたプログラムをメモリに読み込み、CPU がメモリから命令を 1 つずつ読み出して実行する。このように、プログラムをデータと同じくメモリに格納して実行する方式を\ :term:`プログラム内蔵方式`\ と呼ぶ。この方式に基づくコンピュータは、方式を報告書にまとめた数学者ジョン・フォン・ノイマンの名をとって\ :term:`ノイマン型コンピュータ`\ と呼ばれる。プログラム内蔵方式が生まれた経緯は\ :doc:`03_history`\ で扱う。

命令の実行
----------

CPU は、次の 3 つの段階を繰り返して命令を実行する。この繰り返しを命令サイクルと呼ぶ。

#. フェッチ：プログラムカウンタ（次に実行する命令のアドレスを保持するレジスタ）が指すメモリ上の位置から、命令を読み出す。
#. デコード：読み出した命令が何をする命令なのかを解釈する。
#. 実行：演算やデータの転送を行い、プログラムカウンタを次の命令に進める。

CPU が直接解釈できる命令の形式を\ :term:`機械語`\ と呼ぶ。機械語の命令は、「メモリからレジスタへ値を読み込む」「2 つのレジスタの値を足す」「レジスタの値をメモリに書き込む」「条件を満たせば別の位置の命令へ移る」といった単純な操作だけを表す。たとえば ``c = a + b`` という計算は、次のような命令の並びになる。ここでは説明のために、架空の CPU の命令を人間が読める形で示す。

.. code-block:: text
   :linenos:

   LOAD  R1, [a]     ; メモリ上の a の値をレジスタ R1 に読み込む
   LOAD  R2, [b]     ; メモリ上の b の値をレジスタ R2 に読み込む
   ADD   R1, R2      ; R1 と R2 を足し、結果を R1 に格納する
   STORE [c], R1     ; R1 の値をメモリ上の c に書き込む

どれほど複雑なプログラムも、最終的にはこのような単純な命令の並びとして実行される。条件分岐や繰り返しも、「条件を満たせば別の位置の命令へ移る」というジャンプ命令によって実現される。

データの表現
------------

ビットとバイト
~~~~~~~~~~~~~~

コンピュータの内部では、すべての情報が 0 と 1 の並びで表現される。0 または 1 を表す最小の単位を\ :term:`ビット`\ と呼び、8 ビットをまとめたものを\ :term:`バイト`\ と呼ぶ。:math:`n` ビットで表せる値は :math:`2^n` 通りあり、1 バイトなら :math:`2^8 = 256` 通りである。

2 進数と 16 進数
~~~~~~~~~~~~~~~~

0 と 1 だけで数を表す方法を 2 進数と呼ぶ。:math:`n` 桁の 2 進数 :math:`(b_{n-1} \cdots b_1 b_0)_2` が表す値は、次の式で求められる。

.. math::

   (b_{n-1} \cdots b_1 b_0)_2 = \sum_{i=0}^{n-1} b_i \times 2^i

たとえば 2 進数の 1011 は、次のように 10 進数の 11 を表す。

.. math::

   (1011)_2 = 1 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 8 + 0 + 2 + 1 = 11

2 進数は桁数が多くなり、人間には読みにくい。そこで、2 進数の 4 桁を 1 桁にまとめた 16 進数がよく使われる。16 進数では 0〜9 と A〜F の 16 種類の記号を使う。たとえば :math:`(1111\,1111)_2 = (\mathrm{FF})_{16} = 255` である。

負の整数は、多くの場合「2 の補数」と呼ばれる方式で表現される。この方式では、:math:`n` ビットで :math:`-2^{n-1}` 以上 :math:`2^{n-1} - 1` 以下の整数を表せる。たとえば 8 ビットなら -128 以上 127 以下である。なお、Python の整数（``int`` 型）はメモリが許す限り桁数を増やせるため、この範囲の制限を受けない。

文字
~~~~

文字も数値として表現される。文字と数値の対応を定めた規則を\ :term:`文字コード`\ と呼ぶ。現在は、世界中の文字に番号を割り当てた Unicode と、その番号をバイト列に変換する方式である UTF-8 の組み合わせが広く使われている。たとえば「あ」には U+3042 という番号が割り当てられており、UTF-8 では 3 バイトの列 ``E3 81 82`` で表現される。

浮動小数点数
~~~~~~~~~~~~

小数を含む数は、多くの場合\ :term:`浮動小数点数`\ として表現される。代表的な規格である IEEE 754 の倍精度（64 ビット）形式では、符号 :math:`s` に 1 ビット、指数 :math:`e` に 11 ビット、仮数 :math:`f` に 52 ビットを割り当て、通常の値を次の式で表す。

.. math::

   (-1)^s \times (1.f)_2 \times 2^{e - 1023}

この形式で正確に表せるのは、2 進数で有限桁に収まる値だけである。10 進数の 0.1 は 2 進数では無限に続く小数になるため、近似値として記憶される。その結果、次のサンプルコードで示すように ``0.1 + 0.2`` は ``0.3`` と等しくならない。浮動小数点数を比較するときは、``==`` ではなく、誤差を許容する ``math.isclose`` などを使う。金額のように誤差が許されない計算では、整数で計算するか、10 進数で計算する ``decimal`` モジュールを使う。
