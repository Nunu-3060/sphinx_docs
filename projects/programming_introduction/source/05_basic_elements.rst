プログラムの基本要素
====================

言語によって書き方は異なるが、ほとんどの言語のプログラムは、共通するいくつかの要素から組み立てられている。この章では、Python を例に、プログラムを構成する基本要素を説明する。

変数と型
--------

:term:`変数`\ とは、値に名前を付けて保持する仕組みである。変数に値を結び付けることを代入と呼び、Python では ``=`` で表す。変数を使えば、計算の途中結果を保持したり、同じ値を何度も使ったりできる。

値には\ :term:`型`\ がある。Python の代表的な型を次に示す。

.. list-table::
   :header-rows: 1
   :widths: 15 25 60

   * - 型
     - 例
     - 説明
   * - ``int``
     - ``3``、``-42``
     - 整数
   * - ``float``
     - ``120.5``、``0.1``
     - 浮動小数点数
   * - ``str``
     - ``"りんご"``
     - 文字列
   * - ``bool``
     - ``True``、``False``
     - 真偽値（条件が成り立つかどうか）

式と演算子
----------

値や変数を\ :term:`演算子`\ で組み合わせたものを式と呼ぶ。式を評価すると 1 つの値が得られる。算術演算子（``+``、``-``、``*``、``/`` など）、比較演算子（``==``、``<`` など）、論理演算子（``and``、``or``、``not``）が代表的である。

制御構造
--------

プログラムの実行の流れを決める仕組みを\ :term:`制御構造`\ と呼ぶ。:doc:`03_history`\ で述べたように、どのような手順も次の 3 つの構造の組み合わせで表せる。

.. list-table::
   :header-rows: 1
   :widths: 15 25 60

   * - 構造
     - Python の構文
     - 説明
   * - 順次
     - 文を並べる
     - 上から順に 1 つずつ実行する。
   * - 分岐
     - ``if``、``elif``、``else``
     - 条件によって、実行する処理を選ぶ。
   * - 反復
     - ``for``、``while``
     - 同じ処理を繰り返す。``for`` は決まった範囲の要素について、``while`` は条件が成り立つ間、処理を繰り返す。

   :language: python
   :linenos:

``grade`` 関数（4〜11 行目）は分岐の例であり、点数によって返す評価を選ぶ。``sum_up_to`` 関数（14〜19 行目）は ``for`` 文による反復の例であり、1 から ``n`` までの整数を順に足す。``count_digits`` 関数（22〜28 行目）は ``while`` 文による反復の例であり、10 で割れる間だけ処理を繰り返して桁数を数える。``main`` 関数（31〜36 行目）は、各関数を上から順に呼び出す順次の例である。

関数
----

:term:`関数`\ とは、一連の処理をまとめて名前を付けたものである。関数は入力として引数を受け取り、処理の結果を戻り値として返す。処理を関数にまとめると、同じ処理を何度も書かずに済み、処理の内容を名前で表せるため、プログラムが読みやすくなる。

関数が戻り値を返す以外に外部の状態を変えることを\ :term:`副作用`\ と呼ぶ。画面への表示、ファイルへの書き込み、引数として受け取ったリストの書き換えなどが副作用にあたる。副作用のない関数は、同じ引数に対して常に同じ戻り値を返すため、動作を予測しやすく、テストもしやすい。

データ構造
----------

複数の値をまとめて扱うための形式を\ :term:`データ構造`\ と呼ぶ。Python には、次のようなデータ構造が組み込まれている。

.. list-table::
   :header-rows: 1
   :widths: 15 20 65

   * - データ構造
     - Python の型
     - 特徴
   * - リスト
     - ``list``
     - 値を順序付きで並べたもの。位置（インデックス）を指定して値を取り出せる。作成後に要素を追加・変更できる。
   * - タプル
     - ``tuple``
     - 値を順序付きで並べたもの。作成後は変更できない。座標のように、組として扱う値に使う。
   * - 辞書
     - ``dict``
     - キーと値の組を集めたもの。キーを指定して値を取り出せる。

.. literalinclude:: ../examples/data_structures.py
   :language: python
   :linenos:

どのデータ構造を選ぶかによって、プログラムの書きやすさと処理の速さが変わる。たとえば、リストから特定の値を探すには先頭から順に調べる必要があるが、辞書ではキーから値をすぐに取り出せる。この違いは、:doc:`06_algorithms`\ で扱う計算量の違いとして説明できる。

エラー処理
----------

プログラムの実行中には、不正な入力や存在しないファイルの読み込みなど、正常に処理を続けられない状況が起こる。Python では、このような状況を\ :term:`例外`\ という仕組みで扱う。例外が送出されると通常の処理は中断され、``try`` 文の ``except`` 節で捕捉されれば、そこに書いた処理が実行される。捕捉されなければ、プログラムはエラーメッセージを表示して終了する。

.. literalinclude:: ../examples/error_handling.py
   :language: python
   :linenos:

``parse_age`` 関数は、数字でない文字列を受け取ると 6 行目の ``int`` 関数が ``ValueError`` を送出し、負の値を受け取ると 8 行目で自ら ``ValueError`` を送出する。``main`` 関数は、15〜20 行目の ``try`` 文で例外を捕捉し、入力が不正であることを表示する。例外が送出されなかった場合は、``else`` 節（19〜20 行目）が実行される。

実行すると、次のように表示される。

.. code-block:: text
   :linenos:

   入力 '30' は 30 歳
   入力 'abc' は不正: invalid literal for int() with base 10: 'abc'
   入力 '-5' は不正: 年齢は 0 以上でなければならない: -5

エラー処理を書くときは、「何が起こりうるか」「起きたときにどうすべきか」を考える必要がある。:doc:`01_what_is_programming`\ で述べたように、例外的な状況まで扱うことは、プログラムに求められる重要な性質である。
