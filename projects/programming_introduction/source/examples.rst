サンプルコード一覧
==================

本書で使用したサンプルコードの一覧を示す。ファイル名をクリックすると、ファイルをダウンロードできる。内容は、各章の本文で行番号付きで掲載している。

サンプルコードは Python 3.10 以降で動作する。``measure_search.py`` と ``test_binary_search.py`` は、同じフォルダーにある ``linear_search.py`` や ``binary_search.py`` を読み込むため、すべてのファイルを同じフォルダーに置いて実行する。
