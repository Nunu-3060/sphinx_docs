プログラミング言語
==================

:doc:`03_history`\ で見たように、プログラミング言語は、人間が扱う表現と機械が実行する表現との距離を埋めるために発展してきた。この章では、プログラミング言語を分類するための代表的な観点を説明する。

言語の水準
----------

プログラミング言語は、機械にどれだけ近いかによって、次のように分類できる。

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - 分類
     - 特徴
   * - :term:`機械語`
     - CPU が直接実行できる命令の形式。CPU の種類ごとに異なり、数値の列として表される。
   * - :term:`アセンブリ言語`
     - 機械語の命令を短い記号で書けるようにした言語。機械語とほぼ 1 対 1 に対応する。
   * - :term:`高水準言語`
     - 人間の考え方に近い形で処理を書ける言語。CPU の種類に依存せずに書ける。C、Java、Python などが該当する。

高水準言語で書いたプログラムは、そのままでは CPU が実行できない。実行するには、次節で説明する方法で機械語に変換するか、変換しながら実行する必要がある。

実行方式
--------

高水準言語のプログラムを実行する方式は、大きく 2 つに分けられる。

:term:`コンパイラ`
   プログラム全体を、実行前に機械語などの別の形式に変換する。この変換をコンパイルと呼ぶ。実行時に変換の手間がかからないため、一般に高速に動作する。C、C++、Go、Rust などが、この方式を主に用いる。

:term:`インタプリタ`
   プログラムを読み込みながら、その場で解釈して実行する。コンパイルの手順が不要なため、書いてすぐに試せる。

実際の言語処理系の多くは、両者を組み合わせている。たとえば Python の標準の処理系である CPython は、プログラムを実行する前に、仮想的な機械向けの命令である\ :term:`バイトコード`\ にコンパイルし、それをインタプリタで実行する。Java も同様にバイトコードにコンパイルし、Java 仮想マシン（JVM）上で実行する。JVM は、頻繁に実行される部分を実行中に機械語へ変換する JIT（Just-In-Time）コンパイルによって高速化を図っている。

Python のバイトコードは、標準ライブラリの ``dis`` モジュールで確認できる。

   :linenos:

型システム
----------

:term:`型`\ とは、値の種類と、その値に対して行える操作を定めたものである。たとえば整数どうしは足し算できるが、整数と文字列をそのまま足すことはできない。型を検査する時期によって、言語は次の 2 つに分けられる。

静的型付け
   プログラムを実行する前に型を検査する。型の誤りを実行前に発見できる。C、Java、Go、Rust などが該当する。

動的型付け
   プログラムを実行しながら型を検査する。変数の型を宣言する必要がなく、簡潔に書ける。一方、型の誤りは、その部分が実行されるまで発見できない。Python、JavaScript、Ruby などが該当する。

Python は動的型付けの言語であるが、変数や関数の引数に型の情報を書き添える\ :term:`型ヒント`\ の仕組みを持つ。型ヒントは実行時には検査されないが、mypy などの\ :term:`静的解析`\ ツールを使えば、実行前に型の誤りを発見できる。本書のサンプルコードには、すべて型ヒントを付けている。

プログラミングパラダイム
------------------------

プログラムをどのような考え方で組み立てるかを、プログラミングパラダイムと呼ぶ。代表的なパラダイムを次に示す。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - パラダイム
     - 考え方
   * - 手続き型
     - 命令を順に実行し、変数の値（状態）を書き換えながら結果を求める。:doc:`02_how_computers_work`\ で見た CPU の動作に近い。
   * - :term:`オブジェクト指向プログラミング`
     - データとそれを操作する手続きを「オブジェクト」としてまとめ、オブジェクトどうしのやり取りとしてプログラムを組み立てる。
   * - 関数型
     - 状態の書き換えを避け、値を受け取って値を返す関数の組み合わせとしてプログラムを組み立てる。

多くの言語は、複数のパラダイムを取り入れている。Python も、手続き型、オブジェクト指向、関数型のいずれの書き方もできる。次のサンプルコードは、1 から 10 までの偶数の 2 乗の合計を、手続き型と関数型の 2 通りの書き方で求める。

代表的な言語
------------

代表的な言語の特徴を次に示す。

.. list-table::
   :header-rows: 1
   :widths: 15 15 25 45

   * - 言語
     - 型付け
     - 主な実行方式
     - 主な用途
   * - C
     - 静的
     - コンパイル
     - OS、組み込みソフトウェア
   * - C++
     - 静的
     - コンパイル
     - ゲーム、高い性能が必要なアプリケーション
   * - Java
     - 静的
     - バイトコード（JVM）
     - 業務システム、Android アプリケーション
   * - JavaScript
     - 動的
     - インタプリタ（JIT コンパイル）
     - Web ブラウザ、Web サーバ
   * - Python
     - 動的
     - バイトコード（CPython）
     - データ分析、機械学習、自動化、Web サーバ
   * - Go
     - 静的
     - コンパイル
     - Web サーバ、コマンドラインツール
   * - Rust
     - 静的
     - コンパイル
     - OS、組み込みソフトウェア、高い性能と安全性が必要なアプリケーション

言語を選ぶときは、言語そのものの特徴だけでなく、用途に合ったライブラリがそろっているか、チームに経験者がいるか、既存のシステムとの整合性がとれるかといった点も考慮する。
