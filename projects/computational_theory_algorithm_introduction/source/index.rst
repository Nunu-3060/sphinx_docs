計算理論・アルゴリズム入門
==========================

本書は、Python などでプログラムを書けるエンジニアに向けて、アルゴリズムと計算理論の基礎をまとめた入門書である。前半では問題を効率よく解く方法（アルゴリズム）を、後半では「計算機で何が解けるのか」「どれだけ難しいのか」という問い（計算理論）を扱う。各章には Python のサンプルコードを用意しており、理論を手元で確かめながら読み進められる。
