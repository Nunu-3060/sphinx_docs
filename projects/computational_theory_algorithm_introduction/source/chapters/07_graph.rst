第 7 章 グラフアルゴリズム
==========================

道路網、通信網、ソフトウェアの依存関係、SNS の友人関係など、多くの問題は「もの」と「もの同士のつながり」で表せる。第 2 章で定義したグラフはその共通の言葉であり、グラフに対するアルゴリズムは非常に幅広い場面で使われる。本章では、グラフの探索、最短経路、最小全域木、最大流という代表的な問題を扱う。

グラフの表現
------------

グラフを計算機で扱う方法には、主に次の 2 つがある。

* **隣接リスト**\ ：各頂点について、隣接する頂点のリストを持つ。Python では ``dict[str, list[str]]`` のような辞書で表せる。
* **隣接行列**\ ：\ :math:`V \times V` の行列で、頂点 :math:`u` から :math:`v` への辺があれば :math:`(u, v)` 成分を 1（重み付きグラフなら重み）、なければ 0 とする。

.. list-table:: 隣接リストと隣接行列の比較
   :header-rows: 1
   :widths: 40 30 30

   * - 項目
     - 隣接リスト
     - 隣接行列
   * - 必要な領域
     - :math:`O(V + E)`
     - :math:`O(V^2)`
   * - 辺 :math:`(u, v)` の有無の判定
     - :math:`O(\deg u)`
     - :math:`O(1)`
   * - 頂点 :math:`u` に隣接する頂点の列挙
     - :math:`O(\deg u)`
     - :math:`O(V)`

ここで :math:`\deg u` は頂点 :math:`u` の次数である。現実のグラフの多くは辺の数が :math:`V^2` よりずっと少ない（\ **疎**\ である）ため、通常は隣接リストを使う。本章のサンプルコードも全て隣接リストを用いる。

幅優先探索と深さ優先探索
------------------------

グラフの全ての頂点を系統的に訪問する基本的な方法が、幅優先探索と深さ優先探索である。

**幅優先探索**\ （BFS: Breadth-First Search）は、始点に近い頂点から順に訪問する。キューを使い、取り出した頂点に隣接するまだ見つけていない頂点をキューの末尾に加えていく。始点からの距離が :math:`d` の頂点は、距離が :math:`d - 1` 以下の頂点を全て取り出した後に取り出されるので、辺の重みがない（全て 1 とみなす）グラフでは、BFS で各頂点を最初に見つけたときの段数が始点からの最短距離になる。

**深さ優先探索**\ （DFS: Depth-First Search）は、行けるところまで進み、行き止まりになったら戻って別の道を進む。再帰呼び出し（またはスタック）で実装する。DFS は、連結成分の分解、閉路の検出、次に述べるトポロジカルソートなどの基礎になる。

どちらも各頂点を 1 回ずつ訪問し、各辺を（無向グラフでは両方向から）定数回ずつ調べるので、計算量は :math:`O(V + E)` である。

トポロジカルソート
^^^^^^^^^^^^^^^^^^

有向グラフの辺 :math:`u \to v` を「\ :math:`u` は :math:`v` より先に行う」という制約と考える。全ての辺について始点が終点より前に来るように頂点を一列に並べることを\ **トポロジカルソート**\ と呼ぶ。タスクの実行順序の決定、パッケージのインストール順序の決定、表計算ソフトのセルの再計算順序の決定などに使われる。

トポロジカルソートができるのは、グラフが閉路を持たない（DAG である）場合に限られる。閉路があれば、閉路上の頂点はどれも他より先に置けないからである。逆に DAG であれば、次の\ **カーンの方法**\ で必ず並べられる。

1. 入次数が 0 の頂点をキューに入れる。
2. キューから頂点 :math:`u` を取り出して出力し、\ :math:`u` から出る辺を全て取り除く。これにより入次数が 0 になった頂点をキューに入れる。
3. キューが空になるまで 2 を繰り返す。全ての頂点を出力できなければ、グラフに閉路がある。

最短経路
--------

重み付きグラフで、経路上の辺の重みの合計を経路の長さとする。2 頂点間の長さが最小の経路を\ **最短経路**\ と呼ぶ。本節では、1 つの始点から全ての頂点への最短経路を求める問題（単一始点最短経路問題）と、全ての頂点の組の最短経路を求める問題（全点対最短経路問題）を扱う。

最短経路のアルゴリズムは、どれも\ **緩和**\ と呼ばれる次の操作を基本とする。\ :math:`d[v]` を、始点から :math:`v` までのこれまでに見つかった最短距離とする。

.. math::

   \text{辺 } (u, v) \text{ の重みを } w(u, v) \text{ として、} d[u] + w(u, v) < d[v] \text{ ならば } d[v] \leftarrow d[u] + w(u, v)

ダイクストラ法
^^^^^^^^^^^^^^

**ダイクストラ法**\ は、辺の重みが全て非負のときに使える単一始点最短経路アルゴリズムである。距離が確定していない頂点のうち :math:`d[v]` が最小のものを選んで確定させ、そこから出る辺を緩和することを繰り返す。最小の頂点を選ぶのに優先度付きキュー（第 4 章の二分ヒープ）を使うと、計算量は :math:`O((V + E) \log V)` になる。

選んだ頂点の距離を「確定」としてよいのは、重みが非負であれば、まだ確定していない他の頂点を経由しても距離が短くなることはないからである。この意味でダイクストラ法は貪欲法の一種である。負の重みの辺があるとこの議論は成り立たず、ダイクストラ法は誤った答えを返すことがある。

ベルマン-フォード法
^^^^^^^^^^^^^^^^^^^

**ベルマン-フォード法**\ は、負の重みの辺があっても使える単一始点最短経路アルゴリズムである。全ての辺の緩和を :math:`V - 1` 回繰り返す。負閉路（重みの合計が負になる閉路）がなければ、最短経路は同じ頂点を 2 度通らないので辺の数は :math:`V - 1` 以下であり、\ :math:`k` 回目の繰り返しが終わった時点で、辺の数が :math:`k` 以下の最短経路は全て求まっている。これは「辺の数が :math:`k` 以下」という部分問題を順に解く動的計画法と見ることができる。

:math:`V - 1` 回の繰り返しの後にもう一度緩和を試み、まだ距離が更新される辺があれば、始点から到達できる負閉路が存在する。負閉路があると、閉路を回るたびに距離がいくらでも小さくなるので、最短経路は定義できない。計算量は :math:`O(VE)` である。

ワーシャル-フロイド法
^^^^^^^^^^^^^^^^^^^^^

**ワーシャル-フロイド法**\ は、全点対最短経路を求める動的計画法である。頂点に番号 :math:`1, 2, \ldots, V` を付け、\ :math:`d_k[i][j]` を「途中で経由する頂点を :math:`1, \ldots, k` に限ったときの :math:`i` から :math:`j` への最短距離」とする。頂点 :math:`k` を経由するかしないかで場合分けすると、次の漸化式が得られる。

.. math::

   d_k[i][j] = \min(d_{k-1}[i][j],\ d_{k-1}[i][k] + d_{k-1}[k][j])

3 重ループで表を更新するだけなので、実装は非常に簡単である。計算量は :math:`O(V^3)` で、負の重みの辺があっても負閉路がなければ正しく動作する。

最小全域木
----------

連結な重み付き無向グラフ :math:`G` について、\ :math:`G` の全ての頂点を含む木で、\ :math:`G` の辺だけからなるものを\ **全域木**\ と呼ぶ。全域木のうち辺の重みの合計が最小のものを\ **最小全域木**\ と呼ぶ。全ての拠点を最小のコストで結ぶ配線や配管の設計などに使われる。

最小全域木のアルゴリズムは、次の\ **カット性質**\ に基づく。頂点集合を 2 つに分けたとき、両側を結ぶ辺のうち重みが最小の辺は、ある最小全域木に含まれる。この性質により、次の 2 つの貪欲法が最小全域木を与えることが示せる。

* **クラスカル法**\ ：辺を重みの小さい順に調べ、閉路を作らないものを採用する。閉路を作るかどうかは、辺の両端点が既に同じ木に属しているかで判定でき、第 4 章の Union-Find を使うと効率よく判定できる。辺の整列が支配的で、計算量は :math:`O(E \log E)` である。
* **プリム法**\ ：1 つの頂点から木を育て、木の頂点と木の外の頂点を結ぶ辺のうち最小のものを加えることを繰り返す。優先度付きキューを使うと計算量は :math:`O(E \log V)` である。

最大流
------

各辺に容量（流せる量の上限）が付いた有向グラフを\ **ネットワーク**\ と呼ぶ。始点 :math:`s` から終点 :math:`t` へ、各辺の容量を超えず、かつ :math:`s` と :math:`t` 以外の頂点で流入量と流出量が等しくなるように流すとき、流せる量の最大値を求める問題を\ **最大流問題**\ と呼ぶ。輸送計画や通信網の容量設計のほか、2 部グラフのマッチングなど、一見関係のない多くの問題が最大流問題に帰着できる。

フォード-ファルカーソン法
^^^^^^^^^^^^^^^^^^^^^^^^^

**フォード-ファルカーソン法**\ は、次の手順で最大流を求める。

1. 全ての辺の流量を 0 とする。
2. **残余グラフ**\ で :math:`s` から :math:`t` への経路（\ **増加路**\ ）を探す。残余グラフとは、各辺 :math:`(u, v)` について、あと流せる量（容量 − 流量）を容量とする辺 :math:`(u, v)` と、押し戻せる量（流量）を容量とする逆向きの辺 :math:`(v, u)` を持つグラフである。
3. 増加路が見つかれば、その経路上の残余容量の最小値だけ流量を増やし、2 に戻る。見つからなければ終了する。

逆向きの辺により、一度流した量を後から別の経路に振り替えることができる。増加路がなくなったときの流量が最大であることは、\ **最大流最小カット定理**\ （\ :math:`s` から :math:`t` への最大流量は、\ :math:`s` 側と :math:`t` 側に頂点を分けたとき、\ :math:`s` 側から :math:`t` 側へ向かう辺の容量の合計の最小値に等しい）によって保証される。

増加路を幅優先探索で（辺の数が最小のものを）選ぶ方法を\ **エドモンズ-カープ法**\ と呼び、計算量は :math:`O(VE^2)` である。

この例の最大流量は 19 である。最大流最小カット定理を確かめてみよう。\ :math:`s` 側を :math:`\{s, b\}`\ 、\ :math:`t` 側を :math:`\{a, c, d, t\}` とするカットを考えると、\ :math:`s` 側から :math:`t` 側へ横切る辺は :math:`s \to a` と :math:`b \to d` であり、容量の合計は :math:`10 + 9 = 19` となって最大流量と一致する（辺 :math:`a \to b` は :math:`t` 側から :math:`s` 側への辺なので数えない）。どのような流れもこのカットを横切らなければ :math:`t` に届かないので、19 より多くは流せない。

章末のまとめ
------------

* グラフは通常、隣接リストで表す。幅優先探索と深さ優先探索は :math:`O(V + E)` 時間で全頂点を訪問する。
* 辺の重みがなければ幅優先探索、非負ならダイクストラ法、負の重みがあればベルマン-フォード法で単一始点最短経路が求まる。
* 最小全域木は、クラスカル法やプリム法という貪欲法で求まる。
* 最大流は、残余グラフ上で増加路を見つけて流量を増やすことを繰り返して求める。
