第 2 章 数学的準備
==================

本章では、本書全体で使う数学の言葉と道具をまとめる。既に知っている内容は読み飛ばし、必要になったときに戻ってくればよい。

集合・関数・関係
----------------

集合
^^^^

**集合**\ はものの集まりであり、集合に含まれるものを\ **要素**\ と呼ぶ。\ :math:`a` が集合 :math:`A` の要素であることを :math:`a \in A` と書く。集合は要素を並べて :math:`\{1, 2, 3\}` のように書くか、条件を使って :math:`\{x \mid x \text{ は偶数}\}` のように書く。要素を 1 つも持たない集合を\ **空集合**\ と呼び、\ :math:`\emptyset` で表す。

集合に対する主な演算を次の表に示す。Python の ``set`` 型の演算子も併記する。

.. list-table:: 集合の演算
   :header-rows: 1
   :widths: 20 25 35 20

   * - 演算
     - 記法
     - 意味
     - Python
   * - 和集合
     - :math:`A \cup B`
     - :math:`A` と :math:`B` の少なくとも一方に属する要素の集合
     - ``A | B``
   * - 共通部分
     - :math:`A \cap B`
     - :math:`A` と :math:`B` の両方に属する要素の集合
     - ``A & B``
   * - 差集合
     - :math:`A \setminus B`
     - :math:`A` に属し :math:`B` に属さない要素の集合
     - ``A - B``
   * - 部分集合
     - :math:`A \subseteq B`
     - :math:`A` の要素が全て :math:`B` に属する
     - ``A <= B``
   * - 直積
     - :math:`A \times B`
     - 組 :math:`(a, b)`\ （\ :math:`a \in A, b \in B`\ ）の集合
     - ``itertools.product(A, B)``
   * - べき集合
     - :math:`2^A`
     - :math:`A` の部分集合全体の集合
     - なし

有限集合 :math:`A` の要素数を :math:`|A|` と書く。\ :math:`|A| = n` のとき :math:`|2^A| = 2^n` である。各要素について「含める」「含めない」の 2 通りを選べるからである。この「\ :math:`n` 個の要素の部分集合は :math:`2^n` 個ある」という事実は、第 11 章で総当たりの計算量を見積もるときに繰り返し使う。

関数
^^^^

集合 :math:`A` の各要素に集合 :math:`B` の要素をちょうど 1 つ対応させる規則を、\ :math:`A` から :math:`B` への\ **関数**\ （写像）と呼び、\ :math:`f : A \to B` と書く。\ :math:`A` を定義域、\ :math:`B` を終域と呼ぶ。異なる要素を異なる要素に移す関数を\ **単射**\ 、\ :math:`B` の全ての要素が何かの像になっている関数を\ **全射**\ 、単射かつ全射である関数を\ **全単射**\ と呼ぶ。

関係
^^^^

直積 :math:`A \times A` の部分集合 :math:`R` を、\ :math:`A` 上の\ **関係**\ と呼ぶ。\ :math:`(a, b) \in R` を :math:`a R b` とも書く。例えば整数上の「\ :math:`\le`\ 」は関係である。関係 :math:`R` が次の 3 つの性質を全て満たすとき、\ :math:`R` を\ **同値関係**\ と呼ぶ。

* 反射律: 全ての :math:`a` について :math:`a R a`\ 。
* 対称律: :math:`a R b` ならば :math:`b R a`\ 。
* 推移律: :math:`a R b` かつ :math:`b R c` ならば :math:`a R c`\ 。

同値関係は集合を互いに素なグループ（同値類）に分ける。例えば「3 で割った余りが等しい」は整数上の同値関係であり、整数を余り 0、1、2 の 3 つの同値類に分ける。この考え方は第 4 章の Union-Find や、第 8 章で有限オートマトンの状態を設計するときに役立つ。

証明手法
--------

計算理論では「このアルゴリズムは常に正しい答えを返す」「この問題を解くプログラムは存在しない」といった主張を扱う。こうした主張はテストでは確かめきれないため、証明が必要になる。ここでは本書で使う 4 つの証明手法を紹介する。

直接証明
^^^^^^^^

仮定から出発し、正しい推論を積み重ねて結論を導く方法である。

**例**\ ：奇数の 2 乗は奇数である。\ :math:`n` を奇数とすると、ある整数 :math:`k` を用いて :math:`n = 2k + 1` と書ける。このとき :math:`n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1` となり、\ :math:`n^2` は奇数である。

背理法
^^^^^^

結論が成り立たないと仮定して矛盾を導き、結論が成り立つことを示す方法である。

**例**\ ：素数は無限に存在する。素数が有限個 :math:`p_1, p_2, \ldots, p_k` しかないと仮定する。\ :math:`N = p_1 p_2 \cdots p_k + 1` を考えると、\ :math:`N` はどの :math:`p_i` で割っても 1 余る。一方、2 以上の整数は必ず素因数を持つので、\ :math:`N` の素因数は :math:`p_1, \ldots, p_k` 以外の素数である。これは素数が :math:`p_1, \ldots, p_k` だけであるという仮定に矛盾する。

数学的帰納法
^^^^^^^^^^^^

自然数 :math:`n` に関する主張 :math:`P(n)` を、次の 2 段階で証明する方法である。

1. 基底: :math:`P(0)`\ （または :math:`P(1)`\ ）が成り立つことを示す。
2. 帰納段階: :math:`P(n)` が成り立つと仮定して、\ :math:`P(n + 1)` が成り立つことを示す。

帰納段階で「\ :math:`P(0), P(1), \ldots, P(n)` が全て成り立つ」と仮定してもよい。これを\ **強い帰納法**\ と呼ぶ。再帰的なアルゴリズムの正しさは、入力サイズに関する帰納法で証明することが多い。

**例**\ ：:math:`1 + 2 + \cdots + n = n(n + 1)/2` である。\ :math:`n = 1` のとき両辺は 1 である。\ :math:`n` で成り立つと仮定すると、

.. math::

   1 + 2 + \cdots + n + (n + 1) = \frac{n(n + 1)}{2} + (n + 1) = \frac{(n + 1)(n + 2)}{2}

となり、\ :math:`n + 1` でも成り立つ。

対角線論法
^^^^^^^^^^

対角線論法は、ある集合が「数え上げられない」ことや、ある種の対象が「存在しない」ことを示すための背理法の一種である。

**例**\ ：自然数から :math:`\{0, 1\}` への関数全体の集合 :math:`F` は、自然数と 1 対 1 に対応付けられない（\ **非可算**\ である）。対応付けられると仮定し、\ :math:`F` の要素を :math:`f_0, f_1, f_2, \ldots` と並べる。ここで関数 :math:`g` を :math:`g(n) = 1 - f_n(n)` と定義する。\ :math:`g` は :math:`F` の要素だが、どの :math:`f_n` とも :math:`n` での値が異なるため、並べた中に含まれない。これは全ての要素を並べたという仮定に矛盾する。

.. list-table:: 対角線論法の考え方（\ :math:`g` は対角成分を反転させて作る）
   :header-rows: 1
   :widths: 20 20 20 20 20

   * -
     - :math:`n = 0`
     - :math:`n = 1`
     - :math:`n = 2`
     - :math:`\cdots`
   * - :math:`f_0`
     - **0**
     - 1
     - 0
     - :math:`\cdots`
   * - :math:`f_1`
     - 1
     - **1**
     - 0
     - :math:`\cdots`
   * - :math:`f_2`
     - 0
     - 0
     - **1**
     - :math:`\cdots`
   * - :math:`g`
     - 1
     - 0
     - 0
     - :math:`\cdots`

プログラムは有限の長さの文字列なので、全てのプログラムを長さの順に並べることができる（可算である）。一方、上の議論から、自然数上の「はい・いいえ」問題（\ :math:`F` の要素）は非可算個ある。したがって、どのプログラムでも解けない問題が必ず存在する。第 10 章では、同じ論法を使って「停止問題」という具体的な問題が解けないことを示す。

グラフ
------

**グラフ** :math:`G = (V, E)` は、\ **頂点**\ の集合 :math:`V` と、頂点の組である\ **辺**\ の集合 :math:`E` からなる。辺に向きがないグラフを\ **無向グラフ**\ 、向きがあるグラフを\ **有向グラフ**\ と呼ぶ。辺に数値（重み）が付いたグラフを\ **重み付きグラフ**\ と呼ぶ。本書では頂点数を :math:`|V|` または :math:`V`\ 、辺の数を :math:`|E|` または :math:`E` と書く。

グラフに関する主な用語を次の表にまとめる。

.. list-table:: グラフの用語
   :header-rows: 1
   :widths: 25 75

   * - 用語
     - 意味
   * - 隣接
     - 頂点 :math:`u` と :math:`v` を結ぶ辺があるとき、\ :math:`u` と :math:`v` は隣接するという。
   * - 次数
     - 頂点に接続する辺の本数。有向グラフでは入ってくる辺の本数を入次数、出ていく辺の本数を出次数と呼ぶ。
   * - 経路
     - 隣接する頂点を順にたどった列 :math:`v_0, v_1, \ldots, v_k`\ 。同じ頂点を 2 度通らない経路を単純経路と呼ぶ。
   * - 閉路
     - 始点と終点が一致する経路（辺を 1 本以上含むもの）。
   * - 連結
     - 無向グラフで、任意の 2 頂点の間に経路があること。
   * - 木
     - 連結で閉路を持たない無向グラフ。頂点数が :math:`n` の木は辺をちょうど :math:`n - 1` 本持つ。
   * - DAG
     - 閉路を持たない有向グラフ（Directed Acyclic Graph）。

無向グラフでは各辺が 2 つの頂点の次数に 1 ずつ寄与するので、全頂点の次数の和は :math:`2|E|` に等しい。また、単純なグラフ（同じ頂点の組を結ぶ辺が 1 本以下で、自分自身への辺がないグラフ）では :math:`|E| \le |V|(|V| - 1)/2` であり、\ :math:`|E| = O(|V|^2)` となる。

漸近記法
--------

アルゴリズムの効率は、入力サイズ :math:`n` に対して実行時間がどのように増えるかで比べる。このとき、定数倍や小さい項の違いを無視して増え方だけに注目するための記法が\ **漸近記法**\ である。

定義
^^^^

関数 :math:`f(n)`\ 、\ :math:`g(n)` を非負の値をとる関数とする。

.. list-table:: 漸近記法の定義
   :header-rows: 1
   :widths: 20 50 30

   * - 記法
     - 定義
     - 直観的な意味
   * - :math:`f(n) = O(g(n))`
     - ある定数 :math:`c > 0` と :math:`n_0` が存在して、全ての :math:`n \ge n_0` で :math:`f(n) \le c \cdot g(n)`
     - :math:`f` の増え方は :math:`g` 以下
   * - :math:`f(n) = \Omega(g(n))`
     - ある定数 :math:`c > 0` と :math:`n_0` が存在して、全ての :math:`n \ge n_0` で :math:`f(n) \ge c \cdot g(n)`
     - :math:`f` の増え方は :math:`g` 以上
   * - :math:`f(n) = \Theta(g(n))`
     - :math:`f(n) = O(g(n))` かつ :math:`f(n) = \Omega(g(n))`
     - :math:`f` と :math:`g` の増え方は同じ

ここで「\ :math:`=`\ 」は等号ではなく「属する」という意味で使っている。\ :math:`O(g(n))` を「\ :math:`g` 以下の増え方をする関数全体の集合」と考え、\ :math:`f(n) \in O(g(n))` と書く流儀もある。

**例**\ ：:math:`f(n) = 3n^2 + 5n + 7` とする。\ :math:`n \ge 1` のとき :math:`f(n) \le 3n^2 + 5n^2 + 7n^2 = 15n^2` なので、\ :math:`c = 15`\ 、\ :math:`n_0 = 1` とすれば :math:`f(n) = O(n^2)` である。また :math:`f(n) \ge 3n^2` なので :math:`f(n) = \Omega(n^2)` でもあり、合わせて :math:`f(n) = \Theta(n^2)` となる。一般に、多項式は最高次の項だけで増え方が決まる。

:math:`O` は上界を表すだけなので、\ :math:`n = O(n^2)` も正しい主張である。しかし、アルゴリズムの計算量を述べるときは、できるだけ小さい（きつい）上界を示すのが普通である。

よく現れる関数の増え方
^^^^^^^^^^^^^^^^^^^^^^

アルゴリズムの解析でよく現れる関数を、増え方の小さい順に並べる。

.. math::

   1 \ll \log n \ll \sqrt{n} \ll n \ll n \log n \ll n^2 \ll n^3 \ll 2^n \ll n!

ここで :math:`f \ll g` は、\ :math:`n` が大きくなると :math:`f(n)/g(n)` が 0 に近づくことを表す。具体的な値で比べると違いがよく分かる。

.. list-table:: 関数の値の比較
   :header-rows: 1
   :widths: 16 14 14 14 14 14 14

   * - :math:`n`
     - :math:`\log n`
     - :math:`n`
     - :math:`n \log n`
     - :math:`n^2`
     - :math:`n^3`
     - :math:`2^n`
   * - 10
     - 3.3
     - 10
     - 33
     - 100
     - 1,000
     - 1,024
   * - 100
     - 6.6
     - 100
     - 664
     - 10,000
     - :math:`10^6`
     - :math:`1.3 \times 10^{30}`
   * - 1,000
     - 10
     - 1,000
     - 9,966
     - :math:`10^6`
     - :math:`10^9`
     - :math:`1.1 \times 10^{301}`
   * - :math:`10^6`
     - 20
     - :math:`10^6`
     - :math:`2 \times 10^7`
     - :math:`10^{12}`
     - :math:`10^{18}`
     - 約 :math:`10^{301030}`

1 秒間に :math:`10^9` 回の基本操作ができる計算機を考える。\ :math:`n = 10^6` のとき、\ :math:`n \log n` 回の操作は 0.02 秒で終わるが、\ :math:`n^2` 回の操作には約 17 分かかる。\ :math:`2^n` 回の操作は :math:`n = 100` でさえ宇宙の年齢をはるかに超える時間がかかる。多項式で表せる増え方と指数関数的な増え方の間にあるこの決定的な差が、第 11 章で扱う「効率よく解ける問題」の定義の背景にある。

対数と指数の性質
^^^^^^^^^^^^^^^^

計算量の解析でよく使う性質をまとめる。

* :math:`\log (ab) = \log a + \log b`\ 、\ :math:`\log a^k = k \log a`
* 底の変換: :math:`\log_a n = \log_b n / \log_b a`\ 。底の違いは定数倍なので、\ :math:`O(\log_a n) = O(\log_b n)` である。
* :math:`n` を半分にする操作を繰り返して 1 にするには、約 :math:`\log_2 n` 回かかる。二分探索などが :math:`O(\log n)` になる理由である。
* :math:`\log n! = \Theta(n \log n)`\ 。これは第 5 章で比較ソートの下界を示すときに使う。
* 等比級数: :math:`1 + 2 + 4 + \cdots + 2^k = 2^{k+1} - 1 < 2 \cdot 2^k`\ 。最後の項の 2 倍未満で抑えられる。

章末のまとめ
------------

* 集合、関数、関係は、問題や計算の対象を正確に述べるための言葉である。
* 背理法と数学的帰納法は、アルゴリズムの正しさや問題の性質を示す基本的な道具である。対角線論法は第 10 章で再び使う。
* 漸近記法は、定数倍を無視して増え方だけを比べる記法である。多項式と指数関数の増え方の差は、計算機の性能向上では埋められないほど大きい。
