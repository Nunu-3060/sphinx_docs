用語集
======

本書で使った主な用語を、英字、五十音の順に並べた。括弧内は、主に説明している章である。

.. glossary::

   assertion-evidence
      スライドのタイトルに主張を 1 文で書き、本文にはその主張を裏付ける図や写真などの証拠を置くスライドの作り方。Alley が提唱した。本書のアクションタイトルと同じ考え方である（4 章）。

   LT
      ライトニングトーク（lightning talk）の略。5 分程度の短い発表。1 つのメッセージに絞って話す（4 章）。

   Marp
      Markdown でスライドを作るためのツール群。VS Code の拡張機能 Marp for VS Code と、コマンドラインツールの Marp CLI などがある（7 章）。

   Marp CLI
      Marp のスライドを HTML、PDF、PPTX、画像に変換するコマンドラインツール。Node.js で動き、npm でインストールする。コマンド名は ``marp`` である（7 章）。

   PREP
      Point（結論）、Reason（理由）、Example（具体例）、Point（結論）の順に話す構成の型。短い報告や質問への回答に向く（4 章、10 章）。

   python-pptx
      Python で PowerPoint のファイル（PPTX）を作成・編集するためのライブラリ（7 章）。

   SCQA
      Situation（状況）、Complication（問題）、Question（問い）、Answer（答え）の順に話す構成の型。Minto が導入部の構成として提案した（4 章）。

   WCAG
      Web Content Accessibility Guidelines の略。W3C が定める Web コンテンツのアクセシビリティの指針。文字と背景のコントラスト比の基準を定めている（5 章）。

   アウトライン
      発表の構成を、見出しと箇条書きで書いたもの。スライドを作る前にテキストで作る（4 章）。

   アクションタイトル
      スライドのタイトルを、話題の名前ではなく、そのスライドで言いたいことを表す文にしたもの（4 章）。

   アクセントカラー
      最も強調したい箇所にだけ使う色。面積を小さくするほど強調の効果が高い（5 章）。

   キーメッセージ
      発表全体で最も伝えたいことを、主張のある 1 文で表したもの（3 章）。

   グリッド
      要素を配置するために、スライドを縦横に等分して想定する見えない格子（5 章）。

   ゴール
      本書では、発表が終わったときに聞き手がどうなっていればよいかを、聞き手の状態や行動で表したもの（3 章）。

   コントラスト比
      2 つの色の明るさの差を表す値。1 : 1 から 21 : 1 の範囲をとる。WCAG では、通常の文字に 4.5 : 1 以上を求めている（5 章）。

   冗長性の原則
      図と話で説明するとき、話と同じ文章を画面にも表示すると、かえって学習の成果が下がる場合があるという原則。Mayer が示した（2 章）。

   スポットディレクティブ
      Marp で、ローカルディレクティブの名前の前に ``_`` を付けて書くディレクティブ。書いたスライドだけに適用される（7 章）。

   スライドマスター
      PowerPoint で、資料全体のデザイン（背景、フォント、色、要素の位置と大きさ）を定義する場所。Google スライドではテーマビルダーが相当する（7 章）。

   相対輝度
      色の明るさを、人の目の感度に合わせて 0（黒）から 1（白）の値で表したもの。コントラスト比の計算に使う（5 章）。

   ディレクティブ
      Marp で、スライドのテーマ、ページ番号、ヘッダー、背景色などを指定する設定。フロントマターか HTML のコメントの中に書く（7 章）。

   テーマ CSS
      Marp のスライドのデザインを定義する CSS ファイル。先頭に ``/* @theme テーマ名 */`` と書く（7 章）。

   デザインの 4 原則
      Williams が示した、近接（関係のある要素を近くに置く）、整列（要素を見えない線にそろえる）、反復（同じ種類の要素に同じデザインを使う）、コントラスト（異なるものをはっきり異ならせる）の 4 つの原則（5 章）。

   ドキュメント型スライド
      発表者がいなくても、読めば内容が分かるように作ったスライド。配布や事前の共有に向く（2 章）。

   ハイブリッド
      会場の聞き手とオンラインの聞き手が混在する発表の形式（11 章）。

   発表者ツール
      PowerPoint で、手元の画面に現在のスライド、次のスライド、発表者ノート、経過時間を表示する機能。Google スライドではプレゼンター表示が相当する（7 章）。

   発表者ノート
      スライドごとに書く、発表者向けのメモ。スライドショーでは聞き手には表示されない（7 章、8 章）。

   ピラミッド構造
      頂点に結論を置き、その下に結論を支える根拠、さらにその下に根拠を支える事実やデータを置いて、話を整理する方法。Minto が体系化した（4 章）。

   フィラー
      「えー」「あのー」のように、意味を持たずに話の間を埋める言葉（9 章）。

   プレースホルダー
      PowerPoint や Google スライドのレイアウトで、タイトルや本文、図などを入れるために用意された枠（7 章）。

   フロントマター
      Markdown ファイルの先頭に ``---`` で囲んで書く設定の部分。Marp では ``marp: true`` やグローバルディレクティブを書く（7 章）。

   ベースカラー
      背景や広い面積に使う色（5 章）。

   ペチャクチャ
      PechaKucha。20 枚のスライドを 1 枚 20 秒で自動的に送る発表の形式（4 章）。

   メインカラー
      タイトルや図の主要な要素に使い、資料の印象を決める色（5 章）。

   予備のスライド
      質疑応答で使うために、本編の後ろに付録として用意しておくスライド（8 章）。

   ワーキングメモリ
      情報を一時的に意識の中に保持しながら処理する働き。一度に扱える量に限りがある（2 章）。
