スライド作成・プレゼンテーション入門
====================================

本書は、Python などのプログラミングの知識はあるが、スライドの作り方や発表の仕方を体系的に学んだことのないエンジニアに向けた入門書である。進捗報告、設計レビュー、社内勉強会、LT など、エンジニアが発表する場面を例に、目的と聞き手の決め方、話の組み立て方、スライドのデザイン、図表の見せ方、ツールの使い方、リハーサル、話し方、質疑応答までを順に説明する。

ツールは PowerPoint、Google スライド、Marp を扱う。特に Marp は、Markdown でスライドを書き、Git で管理できるため、エンジニアに向いた選択肢として詳しく説明する。本書で使う Marp のサンプルスライドは、HTML と PDF で閲覧でき、元の Markdown もダウンロードできる。
