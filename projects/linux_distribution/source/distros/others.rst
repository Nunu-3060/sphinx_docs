その他の注目すべきディストリビューション
========================================

本節では、ここまでに取り上げたもの以外で、特徴的な設計や特定の用途で注目されているディストリビューションを簡単に紹介する。

.. list-table:: その他の注目すべきディストリビューション
   :header-rows: 1
   :widths: 20 20 60

   * - 名称
     - 分類
     - 概要
   * - NixOS
     - 独立系
     - Nix パッケージマネージャを基盤とし、システム全体の構成を設定ファイルに宣言的に記述する。同じ設定ファイルから同じ環境を再現でき、更新前の構成（世代）に容易に戻せる。毎年 5 月と 11 月に安定版を公開する。
   * - Fedora CoreOS
     - Red Hat 系
     - コンテナの実行に特化したイミュータブル OS である。Ignition による初回起動時の自動構成と、自動更新を特徴とする。2020 年にサポートを終了した CoreOS Container Linux の後継にあたる。
   * - Flatcar Container Linux
     - 独立系
     - CoreOS Container Linux から派生したコンテナ向けのイミュータブル OS である。Kubernetes のノードの OS などに使われる。
   * - Kali Linux
     - Debian 系
     - セキュリティ診断やペネトレーションテスト用のツールを多数収録している。
   * - Raspberry Pi OS
     - Debian 系
     - シングルボードコンピュータ Raspberry Pi の公式 OS である。

イミュータブル OS は、システム領域を読み取り専用とし、OS イメージ全体を単位として更新する。更新が成功するか失敗するかのどちらかになるため、更新途中の不整合が起こりにくく、問題があれば更新前のイメージに戻せる。コンテナホストや、多数の端末を同じ構成で運用する用途で採用が進んでいる。
