製造工程
========

全体の流れ
----------

畑で刈り取ったルイボスは、工場や作業場で加工されて茶葉になる。一般的なレッドルイボスとグリーンルイボスの製造工程は、次のとおりである。

   :caption: ルイボスの製造工程
   :align: center

       ferment [label="発酵（酸化）\n水を含ませて積み上げ、\n半日ほど置く", fillcolor="#fbeee6", color="#a0462b"];
       sundry [label="天日乾燥\n薄く広げて日に干す", fillcolor="#fbeee6", color="#a0462b"];
       quickdry [label="速やかな乾燥\n酸化が進まないうちに乾かす", fillcolor="#eef7ee", color="#3a8a3a"];
       sort [label="選別・等級付け\nふるいにかけ、異物を除く"];
       sterilize [label="殺菌\n蒸気で殺菌する"];
       pack [label="包装\nリーフやティーバッグにする"];

       harvest -> cut;
       cut -> ferment [label=" レッドルイボス"];
       ferment -> sundry;
       cut -> quickdry [label=" グリーンルイボス"];
       sundry -> sort;
       quickdry -> sort;
       sort -> sterilize -> pack;
   }

各工程の内容
------------

収穫
~~~~

収穫は主に夏から秋（南半球のため、1〜4 月ごろ）に行う。株の根元を残して、葉のついた枝を刈り取る。刈り取った枝は束ねて、すぐに加工場へ運ぶ。

裁断
~~~~

運び込んだ枝を機械で数 mm の長さに細かく刻む。ルイボスの茶葉に細い棒状のものが混ざっているのは、葉と一緒に枝（茎）も刻むためである。

発酵（酸化）
~~~~~~~~~~~~

レッドルイボスを作る場合は、刻んだルイボスに水を含ませ、作業場の地面に積み上げて半日ほど置く。この間に、ルイボスに含まれる酵素の働きで成分が酸化し、緑色だった葉が赤褐色に変わる。同時に、ルイボス特有の甘い香りが生まれる。

この工程は一般に「発酵」と呼ばれるが、微生物の働きによる発酵ではなく、酵素による酸化である。紅茶の「発酵」と同じ考え方である。

乾燥
~~~~

発酵を終えたルイボスは、地面に薄く広げて天日で乾燥させる。産地の夏は日差しが強く乾燥しているため、天日乾燥に適している。

グリーンルイボスを作る場合は、発酵の工程を行わない。刻んだ後、酸化が進まないうちに、熱風などを使って速やかに乾燥させる。

選別・等級付け
~~~~~~~~~~~~~~

乾燥したルイボスをふるいにかけ、大きさをそろえるとともに、砂や小石などの異物を取り除く。さらに、葉と茎の割合、色、香り、味などを確かめて、等級を付ける（\ :doc:`types`\ を参照）。

殺菌
~~~~

ルイボスは屋外で天日乾燥させるため、微生物が付着している可能性がある。そこで、出荷前に蒸気を当てて殺菌し、再び乾燥させる。この工程により、ルイボスは衛生的な食品として出荷される。

包装
~~~~

殺菌したルイボスは大袋に詰めて出荷され、輸入先の国でリーフやティーバッグなどの製品に加工されることが多い。産地でティーバッグなどの製品に加工してから輸出することもある。
