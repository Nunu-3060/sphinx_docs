各言語の概要
============

本章では、14 の言語を 1 節ずつ解説する。各節は次の共通の見出しで構成する。

* **基本情報**：登場年、設計者、標準仕様、主な処理系、2026 年時点の状況
* **誕生の背景と設計思想**：どのような課題を解決するために作られたか
* **主な特徴**：型システム、実行方式、メモリ管理、並行処理などの特徴
* **コード例**：\ :ref:`sample-program`\ の実装と解説
* **主な用途**：代表的な利用分野と製品
* **エコシステム**：ビルドツール、パッケージマネージャ、主要なフレームワーク
* **長所と短所**
