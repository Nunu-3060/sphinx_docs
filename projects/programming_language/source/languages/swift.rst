Swift
=====

基本情報
--------

     - 2014 年（2015 年にオープンソース化）
   * - 設計者
     - クリス・ラトナー（Apple）。現在は Apple とオープンソースのコミュニティが開発を担う。
   * - 標準仕様
     - The Swift Programming Language（公式のリファレンス）と、Swift Evolution による提案の手続き

誕生の背景と設計思想
--------------------

Apple のプラットフォームでは、長らく Objective-C が標準の言語であった。Objective-C は C の上に Smalltalk 風のメッセージ送信を加えた言語であり、C から受け継いだ安全性の問題と、独特で冗長な構文を抱えていた。LLVM の開発者でもあるクリス・ラトナーは 2010 年に Swift の開発を始め、Apple は 2014 年の開発者会議 WWDC で Swift を発表した。

Swift は「安全」「高速」「表現力が高い」ことを目標とする。Objective-C との相互運用性を保ちながら、型安全性、null 安全、値型の重視といった現代的な設計を取り入れた。2015 年にはオープンソース化され、Linux や Windows でも使えるようになった。

主な特徴
--------

* **静的型付けと型推論**\ ：強力な型推論を備え、型注釈の多くを省略できる。
* **オプショナル**\ ：値がないことを ``Int?`` のようなオプショナル型で表し、null 安全を実現する。オプショナルの値を使うには、``if let`` や ``guard let`` で中身を取り出す必要がある。
* **値型の重視**\ ：構造体（``struct``）と列挙型（``enum``）は値型であり、標準ライブラリの配列や文字列も値型である。コピーオンライトの最適化により、値型のコピーのコストを抑えている。
* **ARC によるメモリ管理**\ ：クラスのインスタンスは自動参照カウント（ARC）で管理される。GC による停止は発生しないが、循環参照は ``weak`` などで開発者が断ち切る必要がある（:term:`参照カウント`）。
* **プロトコル指向**\ ：プロトコル（ほかの言語のインタフェースや\ :term:`トレイト`\ に相当）とその拡張を中心に設計することが推奨されている。
* **構造化された並行処理**\ ：Swift 5.5 で async/await と actor が導入され、Swift 6 の言語モードではデータ競合の可能性をコンパイル時にエラーとして検出する。

主な用途
--------

* iOS、iPadOS、macOS、watchOS、visionOS などの Apple プラットフォーム向けアプリ
* UI フレームワーク SwiftUI を使ったアプリ開発
* サーバサイド（Vapor など）
* 組込みソフトウェア（Embedded Swift）

エコシステム
------------

* **ビルドツールとパッケージマネージャ**\ ：Swift Package Manager。Apple のプラットフォーム向けアプリでは Xcode のプロジェクトも使われる。
* **主要なフレームワーク**\ ：SwiftUI、UIKit、Combine、Vapor
* **開発環境**\ ：Xcode、Visual Studio Code（Swift の拡張機能）

長所と短所
----------

長所

* 安全性と性能を両立し、読みやすい構文を持つ。
* Apple のプラットフォームでは第一の言語であり、最新の API やフレームワークを利用できる。
* ARC により、GC による停止がなく、メモリ使用量も予測しやすい。

短所

* 利用の大部分が Apple のプラットフォームに集中しており、ほかの分野では採用例が少ない。
* 型推論の複雑な式でコンパイルが遅くなることがある。
* 言語の進化が速く、バージョン間の移行の負担が生じることがある。
