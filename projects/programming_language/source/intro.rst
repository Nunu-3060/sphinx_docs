はじめに
========

本書の目的と対象読者
--------------------

プログラミング言語は、それぞれ異なる時代背景と課題意識のもとで設計されてきた。ある言語が得意とする領域や、逆に苦手とする領域は、その言語の設計思想と密接に結び付いている。本書の目的は、代表的なプログラミング言語について、誕生の背景・設計思想・特徴・用途を整理し、言語同士を共通の観点で比較できるようにすることである。

対象読者は、少なくとも 1 つのプログラミング言語で実務の経験があるエンジニアである。変数・関数・制御構文といったプログラミングの基本や、コンパイルと実行の大まかな流れは既知のものとして扱う。各言語の文法を網羅的に解説することはせず、言語の選定や設計判断に役立つ観点を中心に述べる。

本書の構成と読み方
------------------

本書は次の章で構成する。

* :doc:`concepts`\ では、言語を比較するための共通の観点（パラダイム、型システム、実行方式、メモリ管理、並行処理、エラー処理）を説明する。
* :doc:`history`\ では、1950 年代から現在までの言語の変遷と、言語間の影響関係を示す。
* :doc:`languages/index`\ では、14 の言語を 1 章ずつ、共通の見出し構成で解説する。
* :doc:`comparison`\ では、各言語の特徴を表にまとめて横断的に比較する。
* :doc:`selection`\ では、用途に応じた言語の選び方を述べる。
* :doc:`trends`\ では、言語を取り巻く近年の動向を述べる。

付録として\ :doc:`glossary`、:doc:`references`、:doc:`examples`\ を付ける。基礎概念を把握している読者は、:doc:`languages/index`\ や\ :doc:`comparison`\ から読み始めてもよい。

取り上げる言語
--------------

本書では、利用者の多さ、産業界での重要性、言語設計上の特色を考慮して、次の 14 言語を取り上げる。分類は主な用途に基づく便宜的なものであり、たとえば Go や Rust でアプリケーションを書くことも、Python でシステムの管理ツールを書くことも一般的である。

.. list-table:: 本書で取り上げる言語
   :header-rows: 1
   :widths: 20 40 40

   * - 分類
     - 言語
     - 主な用途の例
   * - システム
     - C、C++、Rust、Go
     - OS、組込み、ミドルウェア、インフラ、高性能が求められるソフトウェア
   * - アプリケーション
     - Java、C#、Kotlin、Swift
     - 業務システム、モバイルアプリ、デスクトップアプリ、ゲーム
   * - スクリプト・Web
     - Python、JavaScript、TypeScript、Ruby、PHP
     - Web 開発、データ分析、機械学習、自動化
   * - データベース
     - SQL
     - リレーショナルデータベースの操作

FORTRAN、COBOL、LISP など、現在の言語に大きな影響を与えた歴史的な言語は\ :doc:`history`\ で扱う。

表記について
------------

* 記載内容は 2026 年時点の情報に基づく。言語の最新バージョンや利用動向は変化するため、最新の情報は各言語の公式サイトで確認してほしい。
* 言語の「登場年」は、最初の実装または最初の発表の年のうち、一般に広く引用されるものとする。正式版（1.0 など）の公開年が異なる場合は、各言語の章で併記する。
* 本文中のコード例には行番号を付ける。各言語の章では、共通の題材（:ref:`sample-program`）を実装したサンプルコードを掲載する。
* 本文中の用語のうち\ :doc:`glossary`\ に載せたものは、初出の箇所などから用語集へリンクする。

.. _sample-program:

共通のサンプルプログラム
------------------------

各言語の書き味を比べるため、:doc:`languages/index`\ では同じ仕様のプログラムを各言語で実装して示す。仕様は次のとおりである。

#. 英文 ``The quick brown fox jumps over the lazy dog. The dog sleeps.`` を入力とする。
#. 英字の並びを単語として切り出し、小文字にそろえる。
#. 単語ごとの出現回数を数える。
#. 出現回数の降順、出現回数が同じ場合は単語の辞書順（昇順）で並べ、上位 3 件を表示する。

期待される出力は次のとおりである（SQL のみ表形式で結果を返す）。

.. code-block:: text
   :linenos:

   the: 3
   dog: 2
   brown: 1

この題材は小さいながら、文字列処理、正規表現、連想配列（辞書）、並べ替え、高階関数といった、言語ごとの差が表れやすい要素を含む。サンプルコードの一覧と検査方法は\ :doc:`examples`\ にまとめる。
