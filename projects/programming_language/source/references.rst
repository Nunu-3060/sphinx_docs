参考文献
========

本書の執筆にあたって参照した資料と、各言語の公式の情報源を示す。URL は 2026 年 10 月時点のものである。

書籍
----

* Brian W. Kernighan, Dennis M. Ritchie. *The C Programming Language*, 2nd ed. Prentice Hall, 1988.
* Bjarne Stroustrup. *The Design and Evolution of C++*. Addison-Wesley, 1994.
* Robert W. Sebesta. *Concepts of Programming Languages*, 12th ed. Pearson, 2018.
* Benjamin C. Pierce. *Types and Programming Languages*. MIT Press, 2002.
* Steve Klabnik, Carol Nichols. *The Rust Programming Language*. No Starch Press. 公開版：https://doc.rust-lang.org/book/
* Alan A. A. Donovan, Brian W. Kernighan. *The Go Programming Language*. Addison-Wesley, 2015.
