言語の選び方
============

本章では、プロジェクトで使う言語を選ぶ際の観点と、用途ごとの選択の例を示す。言語の選択に唯一の正解はなく、技術的な特性だけでなく、チームや組織の事情も含めて総合的に判断する必要がある。

選定の観点
----------

.. list-table:: 言語を選ぶ際の主な観点
   :header-rows: 1
   :widths: 25 75

   * - 観点
     - 検討する内容
   * - 対象の分野とプラットフォーム
     - 動作させる環境によって、選択肢が事実上決まることがある。Web ブラウザでは JavaScript（または TypeScript）、iOS アプリでは Swift、Android アプリでは Kotlin が第一の選択肢となる。
   * - ライブラリとフレームワーク
     - 必要な機能を持つライブラリが成熟しているかどうかは、開発効率を大きく左右する。機械学習における Python のように、ライブラリの充実度が言語の選択を決めることも多い。
   * - 性能と資源の制約
     - 応答時間、処理量、メモリ使用量、起動時間の要件を確認する。厳しい要件がある場合は、C、C++、Rust などのコンパイル型の言語が候補となる。
   * - 安全性と信頼性
     - メモリ安全性、型による誤りの検出、null 安全などが、障害や脆弱性のリスクに影響する。
   * - 開発効率と保守性
     - 記述の簡潔さ、ツールの充実度、コードの読みやすさ、長期的な保守のしやすさを考慮する。
   * - チームと採用
     - チームの経験、学習にかかる時間、技術者の採用のしやすさは、技術的な特性と同じくらい重要である。
   * - 長期的な継続性
     - 言語や主要なライブラリの開発体制、後方互換性の方針、サポート期間を確認する。

用途別の選択例
--------------

次の表は、用途ごとによく選ばれる言語の例である。あくまで一般的な傾向であり、既存のシステムや組織の状況によって最適な選択は異なる。

.. list-table:: 用途ごとの言語の選択例
   :header-rows: 1
   :widths: 22 28 50

   * - 用途
     - 主な候補
     - 理由
   * - Web フロントエンド
     - TypeScript、JavaScript
     - ブラウザで動作する標準の言語であり、大規模な開発では型を持つ TypeScript が主流である。
   * - Web バックエンド
     - Java、Kotlin、C#、Go、Python、TypeScript、Ruby、PHP
     - 選択肢が最も多い分野である。大規模な業務システムでは Java や C#、マイクロサービスでは Go、迅速な開発では Ruby、Python、PHP がよく選ばれる。
   * - モバイルアプリ
     - Kotlin（Android）、Swift（iOS）
     - 各プラットフォームの公式の言語である。両方に対応するには Kotlin Multiplatform や、Dart（Flutter）、TypeScript（React Native）などのクロスプラットフォームの技術も使われる。
   * - データ分析・機械学習
     - Python、SQL
     - Python はライブラリの充実度で他を圧倒している。データの抽出や集計には SQL が欠かせない。
   * - クラウドインフラ・CLI ツール
     - Go、Rust
     - 単一の実行ファイルとして配布でき、性能も高い。
   * - OS・組込み
     - C、C++、Rust
     - ハードウェアを直接制御でき、ランタイムが小さい。新規の開発では、メモリ安全性の観点から Rust の採用も増えている。
   * - ゲーム
     - C++、C#
     - Unreal Engine は C++、Unity は C# を使う。
   * - 高性能が求められるシステム
     - C++、Rust
     - 低遅延の取引システム、データベース、ブラウザなど、性能が最優先される分野で使われる。
   * - 業務の自動化・スクリプト
     - Python、シェル、PowerShell
     - 手軽に書け、標準ライブラリやライブラリが充実している。

学習の順序の例
--------------

これからプログラミング言語を学ぶ、あるいは新しい言語を学ぶ場合には、すでに知っている言語と性格の異なる言語を選ぶと、視野を広げる効果が大きい。目的別に、学習の順序の例を示す。

Web アプリケーションの開発を目指す場合
   JavaScript で Web の基本を学び、TypeScript で静的型付けを身に付ける。次に、バックエンドの言語（Python、Go、Java など）とデータベースを操作する SQL を学ぶ。

データ分析・機械学習を目指す場合
   Python と SQL を学ぶ。性能が求められる処理を理解するために、のちに C++ や Rust に触れるとよい。

システムプログラミングを目指す場合
   C でメモリやポインタの仕組みを理解したうえで、C++ または Rust を学ぶ。

言語の幅を広げたい場合
   普段使う言語とは異なるパラダイムの言語を学ぶ。たとえば、オブジェクト指向の言語に慣れた人は、Rust や Haskell で関数型の考え方や型システムの表現力に触れると、普段の言語での設計にも役立つ。
