はじめに
========

本資料の目的
------------

本資料の目的は、Git を使って自分のコードの変更履歴を管理し、他の人と共同で開発できるようになることです。本資料を読み終えると、次のことができるようになります。

* Git の基本的な仕組み（ワーキングツリー、ステージングエリア、リポジトリ）を説明できます。
* 変更をコミットし、履歴を確認し、誤った変更を取り消せます。
* ブランチを作成してマージし、コンフリクトを解消できます。
* GitHub などのリモートリポジトリを使って、他の人とコードを共有できます。

対象読者
--------

本資料は、次のような方を対象としています。

* Python などのプログラミング言語でコードを書いた経験があります。
* コマンドプロンプトや PowerShell、端末などでコマンドを実行した経験があります。
* Git を使ったことがない、または見よう見まねでしか使ったことがありません。

表記について
------------

本資料では、コマンドの実行例を次のように表記します。行頭の ``$`` はプロンプトを表しているため、入力する必要はありません。

.. code-block:: console

   $ git --version
   git version 2.40.0.windows.1

コマンドの実行例は、Windows では Git for Windows に付属する Git Bash、macOS や Linux では標準の端末で実行することを想定しています。

Windows の PowerShell でも、``git`` コマンドは同じように入力できます。本資料では、PowerShell での入力が Git Bash と異なる箇所にだけ、次のように行頭に ``PS>`` を付けた PowerShell の実行例を併記します。PowerShell を使う場合の注意点と、サンプルスクリプトの PowerShell 版は :doc:`powershell` にまとめています。

.. code-block:: ps1con

   PS> git --version
   git version 2.40.0.windows.1

本資料の内容は Git 2.40 で動作を確認しています。``git switch`` と ``git restore`` は Git 2.23 以降、``git init -b`` は Git 2.28 以降で使えるコマンドです。古いバージョンの Git を使っている場合は、最新のバージョンに更新してください。

サンプルファイル
----------------
