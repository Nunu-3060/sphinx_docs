プロシージャル生成入門
============================================================

本書は、テクスチャ・形状・アニメーション・映像を、手作業ではなく手続き（アルゴリズム）とパラメーターで作る\ **プロシージャル生成**\ の入門書である。乱数で面白い絵を出すだけで終わらせず、生成の仕組みを理解し、結果を意図どおりに制御できるようになることを目指す。

対象読者は、Python や GLSL でプログラムを書けるが、ゲーム制作や 3D モデリングの経験は無い、または浅いエンジニアや工学系の学生である。創発やジェネラティブアートに興味がある読者を想定し、単純な規則から複雑な結果が生まれる例を各部に置いた。
