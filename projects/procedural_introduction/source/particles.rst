第 13 章　群れと粒子
============================================================

火花、煙、雨、鳥の群れ、紐や布のように、たくさんの小さな要素が集まって 1 つの現象に見えるものは、要素を 1 つずつ手で動かすことができない。本章では、各要素に単純な規則を与え、全体の動きを計算で作る方法を扱う。第 1 章の分類ではシミュレーション型に当たる。状態を持ち、前の時刻の状態から次の時刻の状態を計算する。

本章の図と動画は、次のスクリプトで作っている。

* :download:`particle_system.py <../examples/python/particle_system.py>`: パーティクルシステム
* :download:`boids.py <../examples/python/boids.py>`: ボイドと近傍探索
* :download:`verlet_cloth.py <../examples/python/verlet_cloth.py>`: ベルレ積分による紐と布
* :download:`flow_field.py <../examples/python/flow_field.py>`: ノイズから作る流れ場

パーティクルシステム
------------------------------------------------------------

**パーティクルシステム**\ は、たくさんの粒子（パーティクル）を発生させ、力で動かし、一定の時間で消す仕組みである。Reeves が 1983 年の論文で、映画『Star Trek II: The Wrath of Khan』（1982 年）で炎が惑星の表面に広がる場面を作った方法として発表した。火花、煙、雨、魔法のエフェクトなど、輪郭のはっきりしない現象を表すのに、現在もゲームや映像で広く使われている。

発生・寿命・力
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

パーティクルシステムは、次の 3 つの部分から成る。

* **エミッター**\ （発生源）: 1 秒あたりに発生させる数、発生させる位置、初速の向きと大きさの範囲、寿命の範囲を持ち、毎フレーム新しい粒子を加える。
* **更新**: 重力や空気抵抗などの力で、各粒子の速度と位置を進める。経過時間が寿命に達した粒子を取り除く。
* **描画**: 各粒子を点や小さな画像として描く。経過時間に応じて色・大きさ・不透明度を変える。

粒子の状態は、粒子ごとのオブジェクトではなく、位置・速度・経過時間・寿命のそれぞれを配列にして持つ。こうすると NumPy や GPU で全粒子をまとめて計算できる。

.. literalinclude:: ../examples/python/particle_system.py
   :language: python
   :pyobject: Emitter
   :lineno-match:
   :caption: examples/python/particle_system.py（Emitter）

発生数 ``rate × dt`` は 1 フレームあたりでは整数にならないことが多い。端数を ``carry`` に繰り越すと、フレームレートによらず 1 秒あたりの発生数が正しくなる。また、1 フレームの間に発生した粒子を全部同じ位置から出すと、フレームごとの塊に見える。そこで、発生した時刻を 1 フレームの中でばらつかせ、その分だけ進めた位置に置いている。エミッターの速度の一部を粒子の初速に加えると、動くエミッターの後ろに尾を引く。

   :language: python
   :pyobject: update
   :lineno-match:
   :caption: examples/python/particle_system.py（update）

空気抵抗は、速度に比例して逆向きに働く力 :math:`-k \boldsymbol{v}` とした。この力だけなら速度は時間 :math:`\Delta t` で :math:`e^{-k \Delta t}` 倍になるので、その式で減らしている（第 12 章の時間あたりの割合と同じ考え方）。重力と空気抵抗の両方が働くと、粒子は終端速度 :math:`g / k` に近づき、軌跡は放物線から、途中で真下に落ちる形に変わる（:numref:`fig-particles-params` 左）。:math:`k` が大きいほど、粒子はすぐに勢いを失う。煙や埃のような軽いものは :math:`k` を大きく、火花や石のような重いものは小さくする。

寿命に応じた色
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

経過時間を寿命で割った割合（0〜1）を第 2 章のグラデーションマップに通すと、粒子の色が時間とともに変わる。火花なら、白 → 黄 → 橙 → 暗い赤のように、温度が下がる色の並びにする。あわせて明るさを割合とともに下げると、粒子は消える前に暗くなり、突然消えたようには見えない。

.. figure:: _generated/particle_system/particle_params.png
   :alt: 空気抵抗の係数を 0 から 4 まで変えた放物線の軌跡と、寿命の割合に応じた色の帯と明るさの曲線

   空気抵抗の強さと粒子の軌跡（左）、寿命に応じた色と明るさ（右）

火花のような光る粒子は、粒子の色を画像に\ **加算**\ して描く。重なった所ほど明るくなり、光が集まって見える。加算した画像をぼかして元の画像に足すと、光のにじみ（グロー）になる。さらに、各粒子を 1 フレームの間に動いた線分として描くと（モーションブラー）、速い粒子が筋を引いて見える。

ボイド
------------------------------------------------------------

パーティクルシステムの粒子は互いに影響しない。鳥や魚の群れのように、各個体が周りの仲間を見て動きを変える場合は、個体どうしの相互作用を規則にする。

3 つの規則
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Reynolds は 1987 年の論文で、群れの動きを、各個体（\ **ボイド**\ 、boid）が近くの仲間だけを見て従う次の 3 つの規則で作った。

* **分離**\ （separation）: 近すぎる仲間から離れる。衝突を避ける。
* **整列**\ （alignment）: 近くの仲間の平均の速度に、自分の速度を合わせる。
* **結合**\ （cohesion）: 近くの仲間の平均の位置へ向かう。群れから離れない。

群れ全体の形や向きはどこにも指定されていない。それでも、個体が局所的な規則に従うだけで、まとまって流れる群れが生まれる。単純な規則から全体の秩序が生まれる\ **創発**\ の代表的な例である。

各規則は、加速度のベクトルとして計算し、重みを付けて足す。近くの仲間を見つける処理（後述）で距離が半径以内の組 :math:`(i, j)` の一覧を作り、組ごとの量を各個体に集計する。

.. literalinclude:: ../examples/python/boids.py
   :language: python
   :pyobject: steer
   :lineno-match:
   :caption: examples/python/boids.py（steer）

分離の力は、仲間との距離の 2 乗に反比例させ、近いほど強く離れるようにした。速度は毎ステップ、最小と最大の速さの間に収める（``step`` 関数）。空間は、上下・左右の端がつながったトーラスとし、端をまたぐ仲間との差分は、近いほうの向きで測る（``wrap_offset`` 関数）。

.. video:: _generated/boids/boids.mp4
   :width: 640

   400 体のボイド。色は進む向き（OKLCH の色相、第 2 章）を表す

規則の重みを変えると、群れの性格が変わる（:numref:`fig-particles-boids-params`）。整列を無くすと、個体は集まっても向きがそろわず、群れとして流れない。結合を無くすと、向きのそろった流れはできるが、まとまった塊にならず、帯状に広がる。3 つの規則がそろって、はじめて群れらしい塊が生まれる。

.. figure:: _generated/boids/boids_params.png
   :alt: 整列なし、標準、結合なしの 3 つの設定で 15 秒間動かした後のボイドの位置と向き

   規則の重みと群れの形（同じ初期状態から 15 秒後）

.. list-table:: ボイドのパラメーター（boids.py の Rules）
   :header-rows: 1
   :widths: 25 15 60

   * - パラメーター
     - 値
     - 効果

   * - ``separation_radius``

   * - ``separation``・``alignment``・``cohesion``

実際の生き物に近づけるには、後ろの仲間は見えないようにする（視野の制限）、障害物を避ける規則、群れ全体を目的地へ導く規則などを加える。どれも、加速度を 1 つ足すだけで追加できる。

近傍探索による高速化
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

近くの仲間を見つけるには、素朴にはすべての組の距離を調べればよい。しかし組の数は :math:`n(n-1)/2` なので、計算の量は個体数 :math:`n` の 2 乗に比例する。個体数が 10 倍になると、計算は 100 倍になる。

ボイドの各個体が見るのは半径以内の仲間だけなので、空間を区切って、遠い個体をまとめて調べずに済ませられる。ここでは SciPy の k-d 木（``scipy.spatial.cKDTree``）を使う。k-d 木は、点の集まりを座標軸に沿って再帰的に 2 つに分けた木構造で、ある範囲に入る点を、全部の点を調べずに見つけられる。``boxsize`` を指定すると、トーラス状につながった空間でも探索できる。

.. literalinclude:: ../examples/python/boids.py
   :language: python
   :pyobject: pairs_kdtree
   :lineno-match:
   :caption: examples/python/boids.py（pairs_kdtree）

:numref:`fig-particles-neighbor-timing` は、個体の密度を一定にして（1 体あたりの仲間の数をほぼ同じにして）個体数を増やしたときの、近傍探索 1 回の時間である。総当たり（NumPy で距離をまとめて計算）は個体数の 2 乗に比例して増え、筆者の環境では 4000 体で約 0.9 秒かかった。k-d 木はほぼ個体数に比例し、4000 体で約 3 ms、32000 体でも約 30 ms だった。

   :alt: 個体数に対する近傍探索の時間を両対数で表したグラフ。総当たりは傾き 2、k-d 木は傾き 1 程度の直線になる

   総当たりと k-d 木による近傍探索の時間（筆者の環境での測定。両対数）

GPU で計算する場合は、空間を一様な格子に区切り、各個体を格子の升目に振り分けておき、自分の升目と隣の升目だけを調べる方法がよく使われる。考え方は同じで、遠い個体を調べる手間を省く。

ベルレ積分による紐・布
------------------------------------------------------------

紐や布は、たくさんの点を、伸び縮みしない棒でつないだものとみなせる。Jakobsen は 2001 年の講演「Advanced Character Physics」で、ゲーム「Hitman: Codename 47」に使った、この形の物体を安定に計算する方法を紹介した。位置ベルレ積分と、距離の拘束の繰り返しによる解消を組み合わせる方法である。

位置ベルレ積分
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

**位置ベルレ積分**\ は、速度を変数として持たず、現在の位置 :math:`\boldsymbol{x}` と 1 ステップ前の位置 :math:`\boldsymbol{x}_\mathrm{prev}` から次の位置を求める。

.. math::

   \boldsymbol{x}_\mathrm{next} = \boldsymbol{x} + (\boldsymbol{x} - \boldsymbol{x}_\mathrm{prev}) + \boldsymbol{a} \Delta t^2

:math:`\boldsymbol{x} - \boldsymbol{x}_\mathrm{prev}` が 1 ステップの間の移動、つまり速度 × :math:`\Delta t` の役割を果たす。速度を持たないことの利点は、位置を直接書き換えても、それが自動的に速度に反映されることである。点を床の上に押し戻せば、その点は以後、押し戻された分だけ動きが変わる。次の拘束の解消は、この性質を使う。移動の項に :math:`1 - \text{減衰}` を掛けると、動きが少しずつ収まる。

距離の拘束の反復
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

積分で点を動かすと、つながった点の距離が元の長さからずれる。そこで、各棒について、2 点の距離が元の長さになるように 2 点を棒の方向へ動かす。固定した点（質量が無限大、質量の逆数が 0）は動かさず、ほかの点は質量の逆数の比で動かす。

1 本の棒の長さを直すと、隣の棒の長さがずれる。そこで、すべての棒について直す処理を何回か繰り返す。厳密に全部の長さを満たすわけではないが、繰り返すほど元の長さに近づく。本格的な連立方程式を解く代わりに、単純な処理の繰り返しで近似する方法である。

.. literalinclude:: ../examples/python/verlet_cloth.py
   :language: python
   :pyobject: satisfy_constraints
   :lineno-match:
   :caption: examples/python/verlet_cloth.py（satisfy_constraints）

棒を 1 本ずつ順に直すと、Python では遅い。一方、全部の棒をまとめて直すと、同じ点に付いた複数の棒の修正がぶつかる。そこで、点を共有しない棒どうしを同じグループにまとめておき、グループごとにまとめて直す。同じグループの棒は互いに独立なので、まとめて直しても 1 本ずつ直したのと同じ結果になる。グループ分けは、各棒に、両端の点でまだ使われていない最小の番号を順に割り当てて決める（\ ``color_edges`` 関数。グラフの辺の彩色と呼ばれる問題）。本章の紐なら 2 グループ、布なら 12 グループになる。

:numref:`fig-particles-rope` は、左端を固定して水平に放した紐（30 個の点）を、反復の回数を変えて計算したものである。反復が少ないと、棒の長さを直しきれず、紐はゴムのように伸びる。反復を増やすほど伸びは小さくなるが、計算は反復の回数に比例して増える。点の数が多いほど、端から端まで修正が伝わるのに多くの反復が要る。この反復の回数が、布の硬さと計算の重さを決める主なパラメーターになる。

.. figure:: _generated/verlet_cloth/rope_iterations.png
   :alt: 反復 1 回、4 回、16 回で計算した紐の形と、反復の回数ごとの紐の全長の変化のグラフ

   拘束を解消する反復の回数と紐の伸び。反復が 1 回だと、全長は最大で元の 2.5 倍近くまで伸びる

布
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

布は、点を格子状に並べ、次の 3 種類の棒でつないで作る。

* **構造の棒**: 縦と横の隣どうし。布が伸びないようにする。
* **せん断の棒**: 斜めの隣どうし。四角形が菱形につぶれないようにする。
* **曲げの棒**: 1 つ飛ばしの点どうし。布が鋭く折れ曲がらないようにする。

衝突も、位置を直接書き換える拘束として扱う。球の中に入った点を、球の表面まで押し出すだけでよい。押し出した分は、ベルレ積分によって自動的に速度に反映される。

.. video:: _generated/verlet_cloth/cloth.mp4
   :width: 640

   上の辺を留めた布（28 × 20 点）。風をノイズで揺らし、4〜9 秒の間は後ろから球で押す

動画の布は、留める間隔を布の幅より狭くしてたるみ（ひだ）を作り、風の強さを第 3 章の 3 次元ノイズ（位置と時刻）で揺らしている。描画は、四角形を奥から順に塗り重ねている（画家のアルゴリズム）。

流れ場に沿った運動
------------------------------------------------------------

空間の各点に速度のベクトルを決めたものを\ **ベクトル場**\ （流れ場）と呼ぶ。粒子を流れ場の速度に従って動かすと、煙や水の流れのような動きや、ジェネラティブアートでよく見る流れる線の模様が作れる。流れ場はノイズから作れる。

角度場
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

最も手軽なのは、ノイズの値を角度とみなし、その向きの単位ベクトルを速度にする方法である。

.. literalinclude:: ../examples/python/flow_field.py
   :language: python
   :pyobject: angle_field
   :lineno-match:
   :caption: examples/python/flow_field.py（angle_field）

粒子の位置は、中点法（2 次のルンゲ＝クッタ法）で進める。今の位置の速度で半歩進んだ点の速度を使って 1 歩進める方法で、今の位置の速度だけで進めるより、曲がった流れに沿って正確に進む。

.. literalinclude:: ../examples/python/flow_field.py
   :language: python
   :pyobject: advect
   :lineno-match:
   :caption: examples/python/flow_field.py（advect）

:numref:`fig-particles-flow` の左上は、ランダムな位置から出発した粒子の軌跡である。軌跡は何本もの太い流れに合流していく。角度場には、周りから流れが集まる場所（吸い込み）と、流れが湧き出す場所があるためである。左下は、一様に並べた粒子を長く流した結果で、粒子はほとんどが 1 本の線の上に集まってしまう。線の模様としては面白いが、煙や水の動きとしては不自然で、粒子が一部に偏ると画面に隙間ができる。

カールノイズ
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

流れが集まったり湧き出したりする量を、ベクトル場の\ **発散**\ （divergence）と呼ぶ。速度 :math:`\boldsymbol{v} = (v_x, v_y)` の発散は :math:`\nabla \cdot \boldsymbol{v} = \partial v_x / \partial x + \partial v_y / \partial y` で、正なら湧き出し、負なら吸い込みである。水のような縮まない流体の流れは、発散がどこでも 0 になる。

Bridson らは 2007 年に、ノイズから発散が 0 の流れ場を作る\ **カールノイズ**\ を発表した。2 次元では、ノイズ :math:`\psi(x, y)` を\ **流れ関数**\ とみなし、その勾配を 90° 回した次のベクトルを速度にする。

.. math::

   \boldsymbol{v} = \left( \frac{\partial \psi}{\partial y}, \; -\frac{\partial \psi}{\partial x} \right)

このベクトル場の発散は

.. math::

   \nabla \cdot \boldsymbol{v} = \frac{\partial^2 \psi}{\partial x \partial y} - \frac{\partial^2 \psi}{\partial y \partial x} = 0

となり、:math:`\psi` が滑らかであれば、どこでも 0 になる。速度は :math:`\psi` の等高線に沿う向きを持つので、粒子は等高線の上を回る。:math:`\psi` の勾配が急な所ほど流れが速い。3 次元では、3 つのノイズを並べたベクトルの回転（カール）を取る。

.. literalinclude:: ../examples/python/flow_field.py
   :language: python
   :pyobject: curl_field
   :lineno-match:
   :caption: examples/python/flow_field.py（curl_field）

偏微分は、少しずらした 2 点の値の差（中心差分）で近似している。第 3 章のノイズの微分を式で求めて使えば、より速く正確になる。注意したいのは、速さをそろえようとして速度を正規化（長さを 1 に）すると、発散が 0 でなくなることである。速さを変えたい場合は、場全体に一定の倍率を掛ける。

:numref:`fig-particles-flow` の右は、同じノイズから作ったカールノイズの結果である。軌跡は合流せずに渦を巻き、長く流しても粒子は一様に散らばったまま偏らない。

   * - 速さ
     - 一定（向きだけが変わる）
     - ノイズの勾配の大きさで変わる
   * - 発散
     - 0 ではない（吸い込み・湧き出しがある）
     - 0（流体のように縮まない）
   * - 向く用途
     - 合流する線の模様、ジェネラティブアート
     - 煙・水・粒子の漂い

流れ場を時間とともに変えたい場合は、ノイズに時刻の次元を加える（第 3 章の 3 次元ノイズ）。カールノイズでは、時刻を加えても各時刻の場の発散は 0 のままである。

まとめ
------------------------------------------------------------

* パーティクルシステムは、エミッターが粒子を発生させ、力で動かし、寿命で消す仕組みである。発生数・初速・寿命・空気抵抗・寿命に応じた色がパラメーターになる。
* ボイドは、分離・整列・結合の 3 つの局所的な規則から群れの動きを生む。規則の重みで群れの性格が変わる。
* 近傍探索を総当たりで行うと計算が個体数の 2 乗に比例する。k-d 木や一様な格子で、遠い個体を調べる手間を省く。
* 位置ベルレ積分と距離の拘束の反復で、紐や布を安定に計算できる。反復の回数が硬さと計算の重さを決める。
* ノイズの値を向きにした角度場は流れが合流する。ノイズを流れ関数としたカールノイズは発散が 0 で、粒子が偏らない。
