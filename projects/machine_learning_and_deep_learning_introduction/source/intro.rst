はじめに
========

本書の目的
----------

機械学習のライブラリは非常に使いやすくなり、数行のコードでモデルを学習できるようになった。一方で、仕組みを知らずにライブラリを使うと、評価の方法を誤って性能を過大に見積もる、うまく学習できない原因が分からない、といった問題に直面しやすい。

本書の目的は、機械学習と深層学習の基本的な仕組みを理解し、実務で使うときに判断を誤らないための土台を作ることである。そのために、次の方針で説明する。

* 手法の羅列ではなく、「損失関数を定義し、その値が小さくなるようにパラメータを調整する」という共通の枠組みを軸に説明する。
* 重要な手法は NumPy で一から実装し、その後で scikit-learn や PyTorch などのライブラリで同じことを行う。
* 数式は必要最小限にとどめ、図とコードで意味を補う。

対象読者と前提知識
------------------

本書は次のような読者を想定している。

* Python でプログラムを書いた経験があり、関数・クラス・リスト内包表記などを理解している。
* NumPy の配列を少し触ったことがある（なくても読み進められるように第 2 章で補う）。
* 高校程度の数学（関数のグラフ、微分、ベクトル）を学んだことがある。忘れていても構わない。

人工知能や統計学の予備知識は仮定しない。

本書で扱わないこと
------------------

入門書としての分量を保つため、次の内容は概要の紹介にとどめるか、扱わない。

* 強化学習の詳細（第 1 章で概要のみ紹介する）
* 大規模言語モデルの構築や生成 AI サービスの利用方法（第 12 章で仕組みとの関係のみ説明する）
* 数学的に厳密な証明
* 個別のクラウドサービスや製品の操作方法

----------

本書は大きく 4 つの部分に分かれる。章の依存関係を次の図に示す。

* 第 1 章〜第 3 章では、機械学習の全体像と、以降の章で必要になる数学とデータの扱い方を説明する。
* 第 4 章〜第 8 章では、回帰・分類・モデルの評価・決定木・教師なし学習といった古典的な機械学習を説明する。深層学習を学ぶ場合でも、第 6 章の評価の考え方は必ず押さえてほしい。
* 第 9 章〜第 12 章では、ニューラルネットワークの仕組みから CNN や Transformer までの深層学習を説明する。
* 第 13 章では、実務で機械学習を使う際の注意点をまとめる。

巻末には用語集、記号一覧、サンプルコード一覧、参考文献を付けた。本文中でリンクになっている用語は、用語集の説明にジャンプできる。

サンプルコード
--------------

本書のサンプルコードは各章の本文に掲載しており、本文中のリンクからダウンロードできる。一覧は「:doc:`appendix_examples`」にまとめた。

サンプルコードは次の環境で動作を確認した。

.. list-table:: 動作確認環境
   :header-rows: 1
   :widths: 40 60

   * - ソフトウェア
     - バージョン
   * - Python
     - 3.14
   * - NumPy
     - 2.5
   * - pandas
     - 3.0
   * - matplotlib
     - 3.11
   * - scikit-learn
     - 1.9
   * - PyTorch
     - 2.14

必要なライブラリは次のコマンドでインストールできる。PyTorch は GPU の有無などによってインストール方法が異なるため、詳しくは PyTorch の公式サイト [PyTorchDoc]_ を参照してほしい。サンプルコードはすべて CPU だけで数十秒以内に実行できる。

.. code-block:: console
   :linenos:

   pip install numpy pandas matplotlib scikit-learn torch

サンプルコードは、型ヒントを付けたうえで flake8 と mypy（strict モード）による検査を通過している。データセットには scikit-learn に同梱されているものか、プログラム内で生成するものだけを使っているため、インターネットに接続しなくても実行できる。

実行結果は本文に掲載している。乱数のシードを固定しているが、GPU を使う場合など、実行環境によっては結果がわずかに異なることがある。

各サンプルは単独で実行できる。たとえば第 4 章のサンプルは次のように実行する。

.. code-block:: console
   :linenos:

   python ch04_linear_regression_scratch.py

さらに学ぶために
----------------

本書の内容をさらに深く学びたい読者には、次の書籍を勧める。書誌情報は「:doc:`appendix_references`」にまとめた。

* 深層学習の理論を体系的に学ぶには [Goodfellow2016]_ がよい。
* 機械学習の理論を統計学の立場から学ぶには [Bishop2006]_ や [Hastie2009]_ がよい。
* 深層学習を NumPy で一から実装しながら学ぶには [Saito2016]_ がよい。
* scikit-learn や深層学習のフレームワークを使った実践的な手法を学ぶには [Geron2022]_ がよい。
