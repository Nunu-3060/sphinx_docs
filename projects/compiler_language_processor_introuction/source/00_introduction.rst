本書の目的
================================================================

私たちが毎日使っているプログラミング言語は、:term:`言語処理系`\ と呼ばれるソフトウェアによって実行されています。Python のソースコードは CPython がバイトコードに変換して実行し、C 言語のソースコードは GCC や Clang が機械語に変換します。言語処理系は普段は意識されませんが、そのしくみを知ると次のような場面で役に立ちます。

* エラーメッセージの意味や、言語の仕様がそうなっている理由が分かるようになります。
* 設定ファイルの読み込み、テンプレートエンジン、クエリ言語、ドメイン固有言語（DSL）など、小さな言語処理系を自分で作る場面に対応できます。
* コンパイラがどのような最適化を行うかを知ることで、性能を意識したコードを書けるようになります。
* 構文の強調表示、静的解析、自動整形など、開発ツールのしくみを理解できます。

本書の目的は、言語処理系の全体像と各段階の基本的な手法を、実際に動くコードを通して理解することです。理論は必要な範囲にとどめ、詳しい内容は\ :doc:`付録 C <appendix_c_references>` の参考文献に譲ります。

対象読者と前提知識
================================================================

本書は次のような読者を想定しています。

* Python でクラス、データクラス、型ヒントを使ったプログラムを書いたことがある方
* 再帰関数、リスト、辞書などの基本的なデータ構造を理解している方
* コンパイラやインタプリタの内部について学んだことがない、または断片的にしか知らない方

オートマトンや形式言語の理論、アセンブリ言語の知識は前提としません。必要になったか所で説明します。

本書で作るもの
================================================================

本書では、:doc:`第 2 章 <02_language>`\ で定義する小さな言語 Tiny の処理系を、章を追うごとに少しずつ作り上げます。次のプログラムは Tiny で書いた階乗の計算です。

.. code-block:: tiny
   :linenos:

   fn fact(n: int) -> int {
       if (n <= 1) {
           return 1;
       }
       return n * fact(n - 1);
   }

   fn main() {
       print("10! =", fact(10));
   }

Tiny は整数、真偽値、文字列、配列、関数を持つ静的型付き言語です。本書で作る処理系は、Tiny のプログラムを主に次の 3 つの方法で実行できます。

* 抽象構文木を直接たどって実行する木構造インタプリタ（:doc:`第 7 章 <07_interpreter>`）
* 中間表現（IR）を最適化してから実行する IR インタプリタ（:doc:`第 8 章 <08_ir>`、:doc:`第 9 章 <09_optimization>`）
* バイトコードにコンパイルして実行する仮想マシン（:doc:`第 10 章 <10_vm>`）

さらに\ :doc:`第 11 章 <11_runtime>`\ では、中間表現の変数を有限個のレジスタに割り当て、ネイティブコードに近い形の命令列を作ります。

動作環境
================================================================

サンプルコードは Python 3.10 以降で動作します。``match`` 文や ``X | None`` 形式の型ヒントを使うため、それより古い Python では動作しません。本書の実行例は Python 3.14 で確認したものです。サンプルコードは標準ライブラリだけを使っており、追加のパッケージは必要ありません。

サンプルコードは\ :doc:`付録 A <appendix_a_examples>` から閲覧・ダウンロードできます。すべてのファイルを同じディレクトリに置き、そのディレクトリで次のように実行してください。

.. code-block:: console
   :linenos:

   $ python tiny.py run programs/fib.tiny
   $ python -m unittest test_tiny.py

各ファイルは flake8 と mypy（``--strict`` オプション付き）で検査済みです。

本書の構成
================================================================

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 章
     - 内容
   * - :doc:`第 1 章 <01_overview>`
     - 言語処理系の種類と、処理の流れ（フェーズ）の全体像
   * - :doc:`第 2 章 <02_language>`
     - 題材とする言語 Tiny の仕様と文法
   * - :doc:`第 3 章 <03_lexer>`
     - 字句解析：文字の列をトークンの列に変換する
   * - :doc:`第 4 章 <04_parsing>`
     - 構文解析の理論：文脈自由文法、再帰下降構文解析、Pratt 構文解析、LR 構文解析
   * - :doc:`第 5 章 <05_ast>`
     - 抽象構文木の設計と Tiny の構文解析器
   * - :doc:`第 6 章 <06_semantic>`
     - 意味解析：名前解決とスコープ、型検査
   * - :doc:`第 7 章 <07_interpreter>`
     - 抽象構文木を直接実行する木構造インタプリタ
   * - :doc:`第 8 章 <08_ir>`
     - 中間表現：三番地コード、制御フローグラフ、支配関係、SSA 形式
   * - :doc:`第 9 章 <09_optimization>`
     - 最適化：定数伝播、共通部分式除去、不要コード除去、データフロー解析
   * - :doc:`第 10 章 <10_vm>`
     - バイトコードの生成とスタック型仮想マシン
   * - :doc:`第 11 章 <11_runtime>`
     - 実行時環境（スタックフレーム、ガベージコレクション）とレジスタ割り当て
   * - :doc:`第 12 章 <12_advanced>`
     - JIT コンパイル、LLVM、言語サーバなどの発展的な話題

第 1 章と第 2 章で全体像をつかんだ後は、基本的に順番に読み進めてください。第 3 章から第 7 章までで、Tiny のプログラムを実行できる最小限の処理系が完成します。第 8 章以降はコンパイラの「後半」にあたる内容で、第 7 章までの知識を前提とします。
