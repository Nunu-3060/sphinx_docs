はじめに
========

本書の目的と対象読者
--------------------

本書の目的は、Unity に用意されているアニメーションの仕組みを理解し、キャラクターやオブジェクトを思いどおりに動かせるようになることである。個々の機能の使い方だけでなく、どの場面でどの機能を選ぶべきかも説明する。

対象読者は、次の内容を理解している初学者である。

* Unity エディターの基本操作（シーンの作成、GameObject の配置、コンポーネントの追加）
* C# スクリプトを作成して GameObject に追加する方法
* C# の基本的な文法（変数、if 文、for 文、クラス、メソッド）

動作環境
--------

本書は次の環境を想定している。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - 内容
   * - Unity
     - Unity 6 LTS（6000.0 系）
   * - 入力
     - Input System パッケージ
   * - Timeline
     - Timeline パッケージ（第 8 章で使用）

サンプルコードのキーボード入力には Input System パッケージを使用する。Unity 6 の多くのプロジェクトテンプレートには Input System パッケージが導入済みである。導入されていない場合は、Package Manager ウィンドウから Input System をインストールする。

.. note::

   本書では、Unity エディターのメニュー名、ウィンドウ名、コンポーネント名、プロパティ名は英語表記のまま記載する。メニューの階層は「Window > Animation > Animation」のように「>」で区切って表す。

サンプルコードの使い方
----------------------

各章のサンプルコードは、本文中に全文を掲載し、ダウンロード用のリンクも用意している。サンプルコードの一覧は :doc:`appendix` にまとめている。

サンプルコードを使う手順は次のとおりである。

#. ファイルをダウンロードし、Unity プロジェクトの Assets フォルダー内の任意の場所に配置する。
#. ファイル名とクラス名は一致させたまま使用する。Unity は、ファイル名とクラス名が一致しない MonoBehaviour を GameObject に追加できない。
#. 各ファイルの先頭のコメントに記載した手順に従って、GameObject に追加する。

サンプルコードでは、Inspector ウィンドウから値を設定するフィールドを ``[SerializeField]`` 属性付きの private フィールドとして宣言している。public フィールドにしなくても Inspector ウィンドウで編集でき、ほかのスクリプトから不用意に書き換えられることを防げる。
