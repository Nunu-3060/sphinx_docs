====
概要
====

本資料について
===============

本資料では、Conway のライフゲーム（Conway's Game of Life）を題材として、セルオートマトンの基礎理論から Python (NumPy) による実装までを解説する。

対象読者
========

本資料は、Python の基本文法に加え、NumPy・Pillow (PIL)・Tkinter の基本的な使い方を理解している読者を想定している。これらのライブラリ自体の入門的な説明は行わず、ライフゲームの実装に固有の部分（アルゴリズムやライブラリの使い方の工夫）を中心に解説する。特に、以下のような関心を持つ読者にとって有益である。

* セルオートマトンの基本的な考え方を学びたい人
* NumPy を用いた配列演算による高速なシミュレーション実装に興味がある人
* Tkinter を用いた GUI アプリケーションの構成に興味がある人

本資料の構成
============

本資料は大きく分けて以下の内容から構成される。

* セルオートマトンの理論（近傍・ルール・境界条件など）
* 実装の全体構成（モジュールの依存関係、使用ライブラリ）
* ライフゲームの中核ロジックの実装
* シミュレーション結果の可視化・画像出力
* Tkinter を用いた GUI アプリケーションの実装
* アプリケーションの実行方法・操作方法

実装コードの全文および各モジュールの API リファレンスは巻末の :doc:`scripts`・:doc:`api` から閲覧・ダウンロードでき、本資料内でも適宜引用しながら解説する。
