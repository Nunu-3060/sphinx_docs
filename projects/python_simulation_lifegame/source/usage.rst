========
実行方法
========

アプリケーションの起動
=======================

本実装は Python 標準ライブラリの Tkinter に加え、NumPy と Pillow に依存している。あらかじめ以下のコマンドでインストールしておく。

.. code-block:: console

   pip install numpy pillow

アプリケーション本体は :download:`LifeGameGUI.pyw <../script/LifeGameGUI.pyw>` である。以下のようにコマンドラインから実行する。

.. code-block:: console

   python LifeGameGUI.pyw

拡張子が ``.pyw`` になっているのは、Windows 環境で実行した際にコンソールウィンドウを表示させないためである。Windows では、このファイルをエクスプローラーから直接ダブルクリックして起動することもできる。

操作方法
=========

アプリケーションを起動すると、以下の設定項目が並んだメインウィンドウが表示される。

#. **色（color）**: 生存セル（live）・死滅セル（dead）それぞれの色を、色相・彩度・明度のスライダーで指定する（:doc:`visualization` を参照）。
#. **ルール（rule）**: 誕生条件（birth）・生存条件（survive）を、0〜8 の近傍セル数のチェックボタンで指定する（:doc:`core` を参照）。既定では誕生 = 3、生存 = 2, 3 の標準ルールが選択されている。
#. **ループ・サイズ・確率（loop）**: 上下・左右それぞれの境界を周期境界にするかどうか（既定は両方とも周期境界）、盤面のサイズ（128 / 256 / 512、既定は 256）、セルの初期生存確率（既定は 0.3）を指定する（:doc:`core` を参照）。

各設定を行ったうえで、下部のボタンで操作する。

* **start**: 現在の設定でシミュレーションを開始し、新しいウィンドウでアニメーションを表示する。
* **stop**: 実行中のシミュレーションウィンドウを閉じる。
* **reset**: ルール・ループ・サイズ・確率を既定値に戻す。
* **color**: 生存色・死滅色をランダムな新しい色に設定し直す。

start を押すとボタン自体が無効化され、stop を押すかシミュレーションウィンドウを閉じるまでは再度 start できない。異なる設定で改めて実行したい場合は、一度ウィンドウを閉じてから設定を変更し、再度 start を押す。
