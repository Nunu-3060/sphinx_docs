########################################################################
実践：一括リネームツールを作る
########################################################################

この章では、これまでに説明した内容を組み合わせて、Hierarchy ウィンドウで選択した複数のゲームオブジェクトの名前を、連番付きで一括変更するツールを作成します。

ツールの仕様
========================================================================

作成するツールの仕様は次のとおりです。

* :menuselection:`Tools --> Editor Intro --> Batch Rename` を選択すると、専用のウィンドウが開く
* 接頭辞、開始番号、桁数を指定すると、「接頭辞 + 連番」の名前を付けられる（例：Item_01、Item_02、…）
* 変更前と変更後の名前をプレビューで確認できる
* 名前は Hierarchy ウィンドウの表示順に割り当てる
* 変更は Ctrl + Z で元に戻せる
* 接頭辞、開始番号、桁数の初期値は、Project Settings ウィンドウで設定できる

各機能と、それを説明した章の対応は次のとおりです。

.. list-table::
   :header-rows: 1
   :widths: 50 50

   * - 機能
     - 関連する章
   * - メニューからウィンドウを開く
     - 第 3 章（メニューの追加）、第 8 章（EditorWindow）
   * - 名前の変更を Undo に記録する
     - 第 5 章（SerializedObject と Undo）
   * - 選択の変更に合わせてプレビューを更新する
     - 第 8 章（EditorWindow）
   * - 初期値を Project Settings ウィンドウで設定する
     - 第 11 章（設定の保存）

使い方
========================================================================

#. :menuselection:`Tools --> Editor Intro --> Batch Rename` を選択して、ウィンドウを開きます。
#. Hierarchy ウィンドウで、名前を変更するゲームオブジェクトを複数選択します。
#. 「接頭辞」「開始番号」「桁数」を入力し、プレビューで変更後の名前を確認します。
#. 「名前を変更」ボタンをクリックします。
#. 元に戻す場合は、Ctrl + Z を押します。

コードの解説
========================================================================

UI の作成
------------------------------------------------------------------------

このツールでは、UXML を使わず、C# のコードだけで UI を作成しています。入力欄が少ない場合は、ファイルを分けないほうが全体を把握しやすくなります。

入力欄の初期値には、第 11 章の ``BatchRenameSettings.instance`` の値を使っています。``SliderInt`` の ``showInputField`` を ``true`` にすると、スライダーの横に数値の入力欄が表示されます。

``previewList``\ （``ScrollView``）の ``style.flexGrow`` を 1 にすることで、プレビューがウィンドウの残りの高さいっぱいに広がり、ボタンはウィンドウの下端に配置されます。

プレビューの更新
------------------------------------------------------------------------

プレビューは、次のタイミングで ``RefreshPreview`` メソッドを呼んで更新しています。

.. list-table::
   :header-rows: 1
   :widths: 50 50

   * - タイミング
     - 呼び出し元
   * - 入力欄の値が変わったとき
     - 各入力欄の ``RegisterValueChangedCallback``
   * - 選択が変わったとき
     - ``OnSelectionChange``
   * - ゲームオブジェクトの名前や並び順が変わったとき
     - ``OnHierarchyChange``
   * - 名前を変更した直後
     - ``Rename``

対象のゲームオブジェクトが無いときは、プレビューの代わりに案内のメッセージを表示し、``SetEnabled(false)`` でボタンをクリックできないようにしています。

対象の取得と並べ替え
------------------------------------------------------------------------

``GetTargets`` メソッドは、名前を変更する対象を取得します。

``Selection.gameObjects`` には、Project ウィンドウで選択したプレハブのアセットも含まれます。``EditorUtility.IsPersistent`` はアセットのときに ``true`` を返すため、これを使ってシーン上のゲームオブジェクトだけに絞り込んでいます。

また、``Selection.gameObjects`` の順序は Hierarchy ウィンドウの表示順と一致するとは限りません。そこで、``CompareHierarchyOrder`` メソッドで表示順に並べ替えています。このメソッドは、各ゲームオブジェクトについて、ルートから自身までの各階層での並び順（``Transform.GetSiblingIndex`` の値）のリストを作成し、リストを先頭から比べます。

例えば、次の階層構造で「B」と「A-2」を比べる場合を考えます。

.. code-block:: text

   A         … [0]
   ├ A-1     … [0, 0]
   └ A-2     … [0, 1]
   B         … [1]

「A-2」のリストは [0, 1]、「B」のリストは [1] です。先頭の要素を比べると 0 < 1 なので、「A-2」が先になります。

名前の変更
------------------------------------------------------------------------

``Rename`` メソッドでは、名前を変更する前に ``Undo.RecordObjects`` を呼び、すべての対象の変更を 1 回の Undo 操作にまとめて記録しています。ゲームオブジェクトの名前は ``name`` プロパティとして公開されているため、第 5 章の ``Undo.RecordObject`` の方法を使っています。

プレハブのインスタンスの名前を変更した場合に備えて、``PrefabUtility.RecordPrefabInstancePropertyModifications`` も呼んでいます。

連番の文字列は、``int.ToString`` に書式指定文字列「D」と桁数を渡して作成しています。例えば ``7.ToString("D3")`` は「007」を返します。

発展課題
========================================================================

このツールをさらに便利にするために、次のような機能を追加してみてください。

* 接尾辞を指定できるようにする
* 元の名前を残し、その後ろに連番を付けるモードを追加する
* 同じ名前のゲームオブジェクトがあるときに警告を表示する
* Project ウィンドウで選択したアセットの名前も変更できるようにする（``AssetDatabase.RenameAsset`` を使う）
