数学の補足
==========

本文で使った数学のうち、高校数学の範囲を超えるものを補足します。

複素数
------

2 乗すると :math:`-1` になる数を虚数単位と呼びます。数学では :math:`i` と書きますが、電気工学では電流の記号 :math:`i` と区別するため :math:`j` と書くのが一般的で、本書もこれに従います。

.. math::

   j^2 = -1

実数 :math:`a, b` を使って :math:`z = a + jb` と表される数を複素数と呼び、:math:`a` を実部、:math:`b` を虚部と呼びます。複素数は、横軸を実部、縦軸を虚部とした平面（複素平面）上の点として表せます。原点からの距離を絶対値、実軸の正の向きとなす角を偏角と呼びます。

.. math::
   :label: eq-complex-polar

   |z| = \sqrt{a^2 + b^2}, \qquad \arg z = \operatorname{atan2}(b, a)

複素数の掛け算では、絶対値は掛け合わされ、偏角は足し合わされます。この性質が、振幅と位相を同時に扱うのに便利です。Python では ``1 + 2j`` のように複素数を書けます。絶対値は ``abs`` 関数、偏角は ``cmath.phase`` 関数や ``numpy.angle`` 関数で求められます。

オイラーの公式
--------------

指数関数と三角関数は、虚数単位を通じて次の式で結ばれています。これをオイラーの公式と呼びます。

.. math::
   :label: eq-euler

   e^{j\theta} = \cos\theta + j\sin\theta

:math:`e^{j\theta}` は、複素平面上で絶対値 1、偏角 :math:`\theta` の点です。:math:`\theta = \omega t` とおくと、:math:`e^{j\omega t}` は時間とともに角速度 :math:`\omega` で単位円の上を回る点を表し、その実部は :math:`\cos\omega t` です。

正弦波と複素数
^^^^^^^^^^^^^^

振幅 :math:`A`、位相 :math:`\varphi` の正弦波は、オイラーの公式を使って次のように表せます。

.. math::
   :label: eq-phasor

   A\cos(\omega t + \varphi) = \operatorname{Re}\left[ A e^{j\varphi} \, e^{j\omega t} \right]

振幅と位相の情報は、複素数 :math:`A e^{j\varphi}` にまとめられています。この表し方を使うと、次の 2 つのことが簡単になります。

* **微分**: :math:`e^{j\omega t}` を時間で微分すると :math:`j\omega e^{j\omega t}` になります。微分が「:math:`j\omega` を掛けること」に置き換わるため、微分方程式が掛け算と割り算だけの式になります。これが、第 6 章で伝達関数に :math:`s = j\omega` を代入して周波数応答を求めた理由です。
* **振幅と位相の変化**: 線形時不変システムに正弦波を入力すると、出力は入力に複素数 :math:`G(j\omega)` を掛けたものになります。複素数の掛け算の性質から、振幅は :math:`|G(j\omega)|` 倍になり、位相は :math:`\arg G(j\omega)` だけずれます。

離散フーリエ変換
^^^^^^^^^^^^^^^^

第 7 章の離散フーリエ変換（:eq:`eq-dft`）の :math:`e^{-j 2\pi k n / N}` は、オイラーの公式により :math:`\cos(2\pi k n / N) - j\sin(2\pi k n / N)` です。つまり、離散フーリエ変換は、信号に周波数 :math:`k f_s / N` の余弦波と正弦波をそれぞれ掛けて足し合わせ、信号にその周波数の成分がどれだけ含まれるかを調べる計算です。結果の :math:`X_k` の絶対値がその周波数の成分の大きさ、偏角が位相を表します。

確率分布
--------

本文では、いくつかの確率分布を使いました。連続的な値をとる確率変数の分布は、確率密度関数 :math:`f(x)` で表します。:math:`x` が区間 :math:`[a, b]` に入る確率は、:math:`f(x)` をその区間で積分した値です。

.. list-table::
   :header-rows: 1
   :widths: 18 35 22 25

   * - 分布
     - 確率密度関数（または確率）
     - 平均と分散
     - 本書で使った場面
   * - 一様分布
     - 区間 :math:`[a, b]` で一定 :math:`\dfrac{1}{b - a}`
     - :math:`\dfrac{a + b}{2}`, :math:`\dfrac{(b - a)^2}{12}`
     - 量子化誤差（第 7 章）、B タイプの不確かさ（第 4 章）
   * - 正規分布
     - :math:`\dfrac{1}{\sqrt{2\pi}\sigma} \exp\left(-\dfrac{(x - \mu)^2}{2\sigma^2}\right)`
     - :math:`\mu`, :math:`\sigma^2`
     - 測定値のばらつき、公差解析（第 11 章）
   * - 二項分布
     - :math:`\dbinom{n}{k} p^k (1 - p)^{n - k}`
     - :math:`np`, :math:`np(1 - p)`
     - k-out-of-n 系（第 13 章）
   * - ポアソン分布
     - :math:`\dfrac{\lambda^k e^{-\lambda}}{k!}`
     - :math:`\lambda`, :math:`\lambda`
     - 一定時間に起きるランダムな事象の数（到着数、故障数）
   * - 指数分布
     - :math:`\lambda e^{-\lambda x}` （:math:`x \ge 0`）
     - :math:`\dfrac{1}{\lambda}`, :math:`\dfrac{1}{\lambda^2}`
     - 到着の間隔（第 3 章）、故障率が一定の寿命（第 13 章）
   * - ワイブル分布
     - :math:`\dfrac{m}{\eta}\left(\dfrac{x}{\eta}\right)^{m - 1} \exp\left[-\left(\dfrac{x}{\eta}\right)^m\right]`
     - （省略）
     - 製品の寿命（第 13 章）
   * - 三角分布
     - 最小値 :math:`a`、最頻値 :math:`c`、最大値 :math:`b` の三角形
     - :math:`\dfrac{a + b + c}{3}`, （省略）
     - 作業日数の見積もり（第 9 章）

各分布の関係と使い方の要点を補足します。

* **ポアソン分布と指数分布**: ランダムな事象が平均して単位時間あたり :math:`\lambda` 回起きるとき、一定時間に起きる回数はポアソン分布に従い、事象と事象の間隔は指数分布に従います。M/M/1 待ち行列（第 3 章）は、到着の間隔と処理時間がどちらも指数分布に従うと仮定したモデルです。
* **指数分布の無記憶性**: 指数分布では、「すでに :math:`t` 時間故障していない」という情報が、その後の寿命の分布に影響しません。故障率が一定であることと同じ意味で、摩耗しないことを表しています。
* **ワイブル分布**: 形状パラメーター :math:`m` が 1 のとき、指数分布と一致します。:math:`m < 1` で故障率が時間とともに下がり（初期故障）、:math:`m > 1` で上がります（摩耗故障）。:math:`\eta` は尺度パラメーターです。

独立な確率変数の和
------------------

本書では、独立なばらつきを 2 乗和の平方根で合成する計算を何度も使いました（第 4 章の不確かさの伝播、第 11 章の RSS 法）。その根拠は、次の性質です。

互いに独立な確率変数 :math:`X` と :math:`Y` について、和の平均は平均の和、和の分散は分散の和になります。

.. math::
   :label: eq-sum-variance

   E[X + Y] = E[X] + E[Y], \qquad V[X + Y] = V[X] + V[Y]

標準偏差は分散の平方根なので、和の標準偏差は、それぞれの標準偏差の 2 乗和の平方根になります。独立でない（相関がある）場合は、この式に共分散の項が加わります。

さらに、中心極限定理によれば、多数の独立な確率変数の和の分布は、元の分布の形によらず正規分布に近づきます。多くの小さな要因が積み重なって生じる測定値のばらつきや、多数の部品の寸法を足し合わせた結果が正規分布に近くなるのは、このためです。ただし、少数の要因が支配的な場合や、外れ値が出やすい分布では、正規分布の近似は成り立ちにくくなります。
