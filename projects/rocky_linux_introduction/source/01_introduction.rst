はじめに
========

本書の目的
----------

本書の目的は、Rocky Linux を初めて扱うエンジニアが、サーバーを 1 台構築し、日常的に運用できるようになることです。コマンドの羅列ではなく「なぜその操作が必要なのか」を理解できるよう、仕組みの説明と実際の操作を組み合わせて解説します。

対象読者
--------

本書は次のような読者を想定しています。

* Windows を中心に開発してきたが、Linux サーバーを扱う必要が出てきたエンジニア
* Ubuntu などの他のディストリビューションの経験があり、Rocky Linux（RHEL 系）の作法を知りたいエンジニア
* CentOS Linux を使っていて、後継として Rocky Linux への移行を検討しているエンジニア

前提知識
--------

次の知識があることを前提とします。

* ファイル、ディレクトリ、プロセスといったコンピューターの基本的な概念
* IP アドレス、ポート番号、DNS といったネットワークの基本的な概念
* 何らかのプログラミング言語やスクリプト言語の使用経験

Linux のコマンド操作の経験は前提としません。基本的な操作は「:ref:`ch-shell`」で説明します。

表記規則
--------

本書では次の表記規則を使用します。

.. list-table:: 表記規則
   :header-rows: 1
   :widths: 30 70

   * - 表記
     - 意味
   * - ``$ command``
     - 一般ユーザーで実行するコマンドです。先頭の ``$`` は入力しません。
   * - ``$ sudo command``
     - 管理者権限が必要なコマンドです。``sudo`` については「:ref:`ch-initial-setup`」で説明します。
   * - ``<ホスト名>``
     - 山括弧で囲んだ部分は、実際の値に置き換えます。山括弧は入力しません。
   * - ``# command``
     - root のシェルで実行するコマンドです。緊急モードなど、root としてシェルを操作する場合にだけ使います。先頭の ``#`` は入力しません。
   * - ``# コメント``
     - 設定ファイルやスクリプト中の ``#`` 以降は説明のためのコメントです。

コマンドの実行例では、入力するコマンドの行の先頭に ``$`` を付け、出力は ``$`` を付けずに示します。出力は環境によって異なる場合があり、また紙面の都合で一部を省略している場合があります。

.. code-block:: console
   :linenos:

   $ cat /etc/rocky-release
   Rocky Linux release 10.2 (Red Quartz)

本文中のコード例には、説明のために行番号を付けています。行番号は入力しません。

想定環境
--------

本書は次の環境を想定しています。

.. list-table:: 想定環境
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - 内容
   * - OS
     - Rocky Linux 10（x86_64 版）
   * - 実行環境
     - 仮想マシン（Hyper-V、VirtualBox、KVM のいずれか）または物理サーバー。「:ref:`ch-gpu`」のみ、NVIDIA の GPU を搭載した物理マシン
   * - インストール構成
     - 最小構成（Minimal Install）。「:ref:`ch-desktop`」のみ GUI を含む構成
   * - 操作する端末
     - Windows 11 などのクライアント PC から SSH で接続

本書の実行例は、執筆時点の最新のマイナーバージョンである Rocky Linux 10.2 を想定しています。マイナーバージョンによって、パッケージのバージョンや出力が本書と異なる場合があります。また、Rocky Linux 9 との主な違いは「:ref:`ch-overview`」で説明します。
