.. _ch-shell:

シェルの基本操作
================

この章では、Linux を操作するうえで欠かせないシェルの基本操作を説明します。すでに Linux のコマンド操作に慣れている場合は、「:ref:`sec-env-vars`」以降の節だけを確認すれば十分です。

シェルとは
----------

シェルは、ユーザーが入力したコマンドを解釈して実行するプログラムです。Rocky Linux の既定のシェルは bash です。ログインすると、次のようなプロンプトが表示され、コマンドの入力を待つ状態になります。

.. code-block:: console
   :linenos:

   [admin@web01 ~]$

プロンプトには、ユーザー名、ホスト名、現在のディレクトリが表示されます。``~`` は自分のホームディレクトリ（``/home/admin`` など）を表します。

コマンドは、コマンド名、オプション、引数の順に、空白で区切って入力します。

.. code-block:: console
   :linenos:

   $ ls -l /etc/hosts
   -rw-r--r--. 1 root root 158  6月 23  2024 /etc/hosts

この例では、``ls`` がコマンド名、``-l`` がオプション（詳細表示）、``/etc/hosts`` が引数（対象のファイル）です。

便利なキー操作として、次のものを覚えておくと効率よく操作できます。

.. list-table:: bash の便利なキー操作
   :header-rows: 1
   :widths: 25 75

   * - キー
     - 動作
   * - :kbd:`Tab`
     - コマンド名やファイル名を補完する
   * - :kbd:`↑` / :kbd:`↓`
     - 過去に入力したコマンドを呼び出す
   * - :kbd:`Ctrl+R`
     - 過去に入力したコマンドを検索する
   * - :kbd:`Ctrl+C`
     - 実行中のコマンドを中断する
   * - :kbd:`Ctrl+L`
     - 画面を消去する

ディレクトリ構成
----------------

Linux のファイルは、``/`` （ルートディレクトリ）を頂点とする 1 つの木構造で管理されます。Windows のように、ドライブごとに別の木構造を持つことはありません。主なディレクトリの役割は次のとおりです。

.. list-table:: 主なディレクトリ
   :header-rows: 1
   :widths: 20 80

   * - ディレクトリ
     - 役割
   * - ``/etc``
     - システムやソフトウェアの設定ファイル
   * - ``/home``
     - 一般ユーザーのホームディレクトリ
   * - ``/root``
     - root のホームディレクトリ
   * - ``/var``
     - ログ（``/var/log``）など、運用中に変化するデータ
   * - ``/usr``
     - コマンド、ライブラリ、ドキュメントなど、パッケージで導入されるファイル
   * - ``/opt``
     - パッケージ管理の対象外のソフトウェアを導入する場所
   * - ``/srv``
     - Web サーバーなどが公開するデータ
   * - ``/tmp``
     - 一時ファイル。再起動時などに削除される
   * - ``/boot``
     - カーネルやブートローダーなど、起動に必要なファイル
   * - ``/proc``、``/sys``
     - カーネルの情報をファイルとして見せる仮想的なファイルシステム
   * - ``/dev``
     - ディスクなどのデバイスを表すファイル

ファイルとディレクトリの操作
----------------------------

ファイルとディレクトリを操作する基本的なコマンドを次に示します。

.. list-table:: ファイルとディレクトリを操作するコマンド
   :header-rows: 1
   :widths: 30 70

   * - コマンド
     - 動作
   * - ``pwd``
     - 現在のディレクトリを表示する
   * - ``cd <ディレクトリ>``
     - 現在のディレクトリを移動する。引数を省略するとホームディレクトリに移動する
   * - ``ls -la``
     - 隠しファイル（名前が ``.`` で始まるファイル）を含めて詳細を一覧表示する
   * - ``mkdir -p <ディレクトリ>``
     - ディレクトリを作成する。``-p`` を付けると途中のディレクトリもまとめて作成する
   * - ``cp -a <コピー元> <コピー先>``
     - ファイルやディレクトリを、属性を保ったままコピーする
   * - ``mv <移動元> <移動先>``
     - ファイルを移動する。名前の変更にも使う
   * - ``rm <ファイル>``
     - ファイルを削除する。``-r`` を付けるとディレクトリごと削除する
   * - ``cat <ファイル>``
     - ファイルの内容を表示する
   * - ``less <ファイル>``
     - ファイルの内容を 1 画面ずつ表示する。:kbd:`q` で終了する
   * - ``head -n 20 <ファイル>``
     - ファイルの先頭 20 行を表示する
   * - ``tail -f <ファイル>``
     - ファイルの末尾を表示し、追記されるたびに表示を更新する。ログの監視に使う
   * - ``find <ディレクトリ> -name <名前>``
     - 条件に一致するファイルを検索する

.. warning::

   ``rm`` で削除したファイルは、Windows の「ごみ箱」のような場所には移動されず、すぐに削除されます。特に ``sudo rm -rf`` は、指定を誤るとシステムを破壊するため、実行前に対象を必ず確認してください。

パーミッションと所有者
----------------------

Linux のファイルには、所有者（ユーザー）、所有グループ、パーミッション（アクセス権）が設定されています。``ls -l`` の出力で確認できます。

.. code-block:: console
   :linenos:

   $ ls -l report.txt
   -rw-r-----. 1 admin developers 1024 10月  6 10:00 report.txt

先頭の ``-rw-r-----`` がパーミッションです。1 文字目はファイルの種類（``-`` は通常のファイル、``d`` はディレクトリ、``l`` はシンボリックリンク）を表し、残りの 9 文字を 3 文字ずつ区切って、所有者、所有グループ、その他のユーザーの権限を表します。末尾の ``.`` は、SELinux のラベルが付いていることを表します（「:ref:`ch-security`」を参照）。

.. list-table:: パーミッションの記号
   :header-rows: 1
   :widths: 15 15 35 35

   * - 記号
     - 数値
     - ファイルに対する意味
     - ディレクトリに対する意味
   * - ``r``
     - 4
     - 内容を読める
     - 中のファイルを一覧表示できる
   * - ``w``
     - 2
     - 内容を変更できる
     - 中にファイルを作成・削除できる
   * - ``x``
     - 1
     - プログラムとして実行できる
     - 中に移動（``cd``）できる

パーミッションは、各権限の数値を足し合わせた 3 桁の 8 進数でも表せます。例えば ``rwxr-x---`` は、所有者が :math:`4 + 2 + 1 = 7`、所有グループが :math:`4 + 0 + 1 = 5`、その他が :math:`0` なので ``750`` になります。一般に、権限の数値 :math:`p` は次の式で求められます。

.. math::

   p = 4r + 2w + x \qquad (r, w, x \in \{0, 1\})

パーミッションは ``chmod``、所有者は ``chown`` で変更します。

.. code-block:: console
   :linenos:

   $ chmod 640 report.txt
   $ chmod u+x script.sh
   $ sudo chown admin:developers report.txt

2 行目の ``u+x`` は「所有者（u）に実行権限（x）を追加する」という意味です。``g`` は所有グループ、``o`` はその他のユーザー、``a`` は全員を表します。

新しく作成したファイルのパーミッションは、umask という値で決まります。Rocky Linux の一般ユーザーの既定値は ``0022`` で、新しいファイルは ``644`` （``rw-r--r--``）、新しいディレクトリは ``755`` （``rwxr-xr-x``）になります。

リダイレクトとパイプ
--------------------

コマンドの出力をファイルに保存したり、別のコマンドに渡したりできます。

.. list-table:: リダイレクトとパイプ
   :header-rows: 1
   :widths: 30 70

   * - 書き方
     - 動作
   * - ``command > file``
     - 標準出力をファイルに書き込む（上書き）
   * - ``command >> file``
     - 標準出力をファイルに追記する
   * - ``command 2> file``
     - 標準エラー出力をファイルに書き込む
   * - ``command > file 2>&1``
     - 標準出力と標準エラー出力の両方をファイルに書き込む
   * - ``command < file``
     - ファイルの内容を標準入力として渡す
   * - ``command1 | command2``
     - ``command1`` の標準出力を ``command2`` の標準入力に渡す（パイプ）

``sudo`` を使って root しか書き込めないファイルに書き込む場合、``sudo echo "text" > /etc/file`` は失敗します。リダイレクトは ``sudo`` で権限が切り替わる前に、現在のユーザーの権限で処理されるためです。この場合は ``tee`` コマンドを使います。

.. code-block:: console
   :linenos:

   $ echo "192.168.10.30 db01" | sudo tee -a /etc/hosts

テキスト処理
------------

Linux の設定ファイルやログの多くはテキストファイルです。テキストを処理するコマンドをパイプで組み合わせると、さまざまな集計や抽出ができます。

.. list-table:: テキスト処理のコマンド
   :header-rows: 1
   :widths: 30 70

   * - コマンド
     - 動作
   * - ``grep <パターン> <ファイル>``
     - パターンに一致する行を表示する。``-i`` で大文字と小文字を区別しない、``-v`` で一致しない行を表示する、``-r`` でディレクトリ内を再帰的に検索する
   * - ``sed 's/<置換前>/<置換後>/g'``
     - 文字列を置換する。``-i`` を付けるとファイルを直接書き換える
   * - ``awk '{print $1}'``
     - 空白で区切られた列のうち、1 列目を表示する
   * - ``sort``
     - 行を並べ替える。``-n`` で数値として並べ替える
   * - ``uniq -c``
     - 連続する同じ行をまとめ、件数を表示する
   * - ``wc -l``
     - 行数を数える

次の例は、nginx のアクセスログから、アクセス数の多いクライアントの IP アドレスを上位 5 件表示します。

.. code-block:: console
   :linenos:

   $ awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -n 5

設定ファイルから、コメント行と空行を除いて有効な設定だけを表示するには、次のようにします。

.. code-block:: console
   :linenos:

   $ grep -Ev '^\s*(#|$)' /etc/chrony.conf

環境変数と設定ファイル
----------------------

環境変数は、シェルやそこから起動されるプログラムが参照する設定値です。

.. code-block:: console
   :linenos:

   $ echo $PATH
   /home/admin/.local/bin:/home/admin/bin:/usr/local/bin:/usr/bin:/usr/local/sbin:/usr/sbin
   $ export EDITOR=vi
   $ env | grep EDITOR
   EDITOR=vi

``PATH`` は、コマンドを探すディレクトリの一覧です。コマンド名だけを入力すると、``PATH`` に含まれるディレクトリを先頭から順に探して実行します。どのファイルが実行されるかは ``which`` コマンドや ``type`` コマンドで確認できます。

``export`` で設定した環境変数は、ログアウトすると消えます。常に設定しておきたい場合は、次の設定ファイルに記述します。

.. list-table:: bash の設定ファイル
   :header-rows: 1
   :widths: 35 65

   * - ファイル
     - 読み込まれるタイミングと用途
   * - ``~/.bash_profile``
     - ログイン時に 1 回読み込まれる。環境変数の設定に使う
   * - ``~/.bashrc``
     - bash を起動するたびに読み込まれる。エイリアスや関数の定義に使う
   * - ``/etc/profile.d/*.sh``
     - 全ユーザーのログイン時に読み込まれる。システム全体の環境変数の設定に使う

設定ファイルを変更した後は、``source ~/.bashrc`` で現在のシェルに反映できます。

アーカイブと圧縮
----------------

複数のファイルを 1 つにまとめる（アーカイブする）には ``tar`` コマンドを使います。``tar`` は圧縮も同時に行えます。

.. code-block:: console
   :linenos:

   $ tar -czf backup.tar.gz /etc/nginx
   $ tar -tzf backup.tar.gz
   $ tar -xzf backup.tar.gz -C /tmp/restore

1 行目でディレクトリを gzip 形式で圧縮したアーカイブを作成し、2 行目で内容を一覧表示し、3 行目で ``/tmp/restore`` に展開しています。主なオプションの意味は次のとおりです。

.. list-table:: tar の主なオプション
   :header-rows: 1
   :widths: 20 80

   * - オプション
     - 意味
   * - ``-c``
     - アーカイブを作成する
   * - ``-t``
     - アーカイブの内容を一覧表示する
   * - ``-x``
     - アーカイブを展開する
   * - ``-z``
     - gzip 形式で圧縮・展開する（``-J`` は xz 形式）
   * - ``-f <ファイル>``
     - アーカイブのファイル名を指定する
   * - ``-C <ディレクトリ>``
     - 展開先のディレクトリを指定する

バックアップでの使い方は「:ref:`ch-storage`」で説明します。

vi の最低限の操作
-----------------

設定ファイルの編集には、どの Linux 環境にもほぼ必ず含まれている vi（Rocky Linux では vim）を使えると便利です。vi には、文字を入力する「挿入モード」と、カーソルの移動や保存などを行う「ノーマルモード」があります。起動直後はノーマルモードです。

.. list-table:: vi の最低限の操作
   :header-rows: 1
   :widths: 25 75

   * - 操作
     - 動作
   * - ``vi <ファイル>``
     - ファイルを開く
   * - :kbd:`i`
     - 挿入モードに切り替える（カーソルの位置から入力する）
   * - :kbd:`Esc`
     - ノーマルモードに戻る
   * - ``:w``
     - 保存する
   * - ``:q``
     - 終了する
   * - ``:wq``
     - 保存して終了する
   * - ``:q!``
     - 保存せずに終了する
   * - ``/文字列``
     - 文字列を検索する。:kbd:`n` で次を検索する
   * - :kbd:`d` :kbd:`d`
     - 1 行削除する
   * - :kbd:`u`
     - 直前の操作を取り消す

vi に慣れていない場合は、操作の簡単な nano を ``sudo dnf install nano`` で導入して使うこともできます。

マニュアルの引き方
------------------

コマンドの使い方は、``man`` コマンドでマニュアルを表示して確認できます。

.. code-block:: console
   :linenos:

   $ man ls
   $ ls --help
   $ man -k firewall

``man -k`` は、説明文にキーワードを含むマニュアルを検索します。最小構成ではマニュアルが導入されていないことがあるため、表示されない場合は ``sudo dnf install man-db man-pages`` で導入してください。
