文字クラス
==========

第 2 章のパターンは、決まった文字の並びにしか一致しなかった。この章では「数字のどれか 1 文字」や「英字以外の 1 文字」のように、1 文字分の候補を指定する\ :term:`文字クラス`\ を説明する。

[...] で候補を列挙する
----------------------

``[`` と ``]`` で文字を囲むと、囲んだ文字のうちどれか 1 文字に一致する。

.. literalinclude:: ../examples/ch03_char_class.py
   :language: python
   :pyobject: demo_char_set
   :linenos:
   :caption: 文字クラスの基本

``gr[ae]y`` は「``g``、``r``、``a`` か ``e`` のどちらか 1 文字、``y``」の並びに一致する。文字クラス全体で 1 文字分であることに注意する。``[ae]`` は ``ae`` という 2 文字の並びには一致しない。

ハイフンで範囲を指定する
------------------------

連続する文字は、``[0-9]`` や ``[a-z]`` のようにハイフンで範囲として書ける。範囲と個別の文字は、1 つの文字クラスの中に混ぜて書いてよい。

.. literalinclude:: ../examples/ch03_char_class.py
   :language: python
   :pyobject: demo_range
   :linenos:
   :caption: 範囲の指定

4 行目の ``[A-Fa-f0-9]`` は 16 進数の 1 桁に一致する。``G`` は範囲外なので一致しない。

範囲は文字コード（Unicode のコードポイント）の順序で決まる。そのため ``[A-z]`` と書くと、``Z`` と ``a`` の間にある ``[``、``\``、``]``、``^``、``_``、バッククォートの 6 文字も含まれてしまう。英字の大文字と小文字をまとめて指定するときは ``[A-Za-z]`` と書く。

^ で候補以外を指定する
----------------------

``[`` の直後に ``^`` を置くと、「列挙した文字以外の 1 文字」に一致する。これを否定文字クラスと呼ぶ。

.. literalinclude:: ../examples/ch03_char_class.py
   :language: python
   :pyobject: demo_negation
   :linenos:
   :caption: 否定文字クラス

否定文字クラスは「何もない」には一致しない。``[^0-9]`` は「数字ではない文字が 1 文字ある」という意味であり、文字列の末尾のように文字そのものがない位置には一致しない。また、改行文字も「数字以外」に含まれるため、``[^0-9]`` は改行にも一致する。

文字クラスの中のメタ文字
------------------------

文字クラスの中では、第 2 章で挙げたメタ文字の多くが特別な意味を失い、ただの文字として扱われる。文字クラスの中で特別な意味を持つのは次の 4 つだけである。

.. list-table:: 文字クラスの中で特別な意味を持つ文字
   :header-rows: 1
   :widths: 20 50 30

   * - 文字
     - 特別な意味を持つ条件
     - その文字自身を指定する方法
   * - ``]``
     - ``[`` や ``[^`` の直後以外（文字クラスの終わり）
     - ``\]``
   * - ``\``
     - 常に（エスケープ）
     - ``\\``
   * - ``^``
     - ``[`` の直後に置いたとき（否定）
     - ``\^``、または先頭以外に置く
   * - ``-``
     - 2 つの文字の間に置いたとき（範囲）
     - ``\-``、または先頭か末尾に置く

.. literalinclude:: ../examples/ch03_char_class.py
   :language: python
   :pyobject: demo_metachar_in_class
   :linenos:
   :caption: 文字クラスの中のメタ文字

3 行目の ``[.+*]`` は、ピリオド、プラス、アスタリスクのどれか 1 文字に一致する。文字クラスの外ではエスケープが必要な文字も、中ではそのまま書ける。4 行目の ``[a-]`` は、末尾にハイフンを置いているので範囲にはならない。5 行目では ``]`` と ``\`` をエスケープしている。

. は任意の 1 文字に一致する
---------------------------

文字クラスの外に書いたピリオド ``.`` は、改行文字 ``\n`` 以外の任意の 1 文字に一致する。

.. literalinclude:: ../examples/ch03_char_class.py
   :language: python
   :pyobject: demo_dot
   :linenos:
   :caption: 任意の 1 文字

``c.t`` は ``cat`` や ``cut`` だけでなく、空白を挟んだ ``c t`` にも一致する。一方、``c`` と ``t`` の間が改行の部分には一致しない。``.`` を改行にも一致させる方法は第 8 章で説明する。

``.`` は便利だが、「何でもよい」は多くの場合、意図より広すぎる。何に一致させたいかがはっきりしているときは、``[0-9]`` や ``[^,]`` のように具体的な文字クラスを使うほうがよい。

定義済みの文字クラス
--------------------

よく使う文字クラスには、``\`` で始まる短い書き方が用意されている。

.. list-table:: 定義済みの文字クラス
   :header-rows: 1
   :widths: 15 45 40

   * - 記法
     - 一致する文字
     - ASCII の範囲に限った場合の同等の表記
   * - ``\d``
     - 数字（digit）
     - ``[0-9]``
   * - ``\w``
     - 単語を構成する文字（word）。英数字とアンダースコア
     - ``[a-zA-Z0-9_]``
   * - ``\s``
     - 空白文字（space）。半角空白、タブ、改行など
     - ``[ \t\n\r\f\v]``
   * - ``\D``
     - ``\d`` 以外の文字
     - ``[^0-9]``
   * - ``\W``
     - ``\w`` 以外の文字
     - ``[^a-zA-Z0-9_]``
   * - ``\S``
     - ``\s`` 以外の文字
     - ``[^ \t\n\r\f\v]``

大文字にすると否定になる、と覚えるとよい。これらは文字クラスの中にも書ける。たとえば ``[\d,]`` は数字またはカンマの 1 文字に一致する。

Unicode 文字との関係
--------------------

上の表の「同等の表記」は、ASCII の範囲に限った場合の目安である。Python の ``re`` では、パターンが ``str`` のとき、``\d``、``\w``、``\s`` は Unicode の文字全体を対象にする。そのため、全角数字や漢字にも一致する。

.. literalinclude:: ../examples/ch03_char_class.py
   :language: python
   :pyobject: demo_unicode
   :linenos:
   :caption: Unicode 文字との一致

4 行目のとおり、``\d`` は全角数字 ``１２３`` にも一致する。``\d`` が一致するのは、Unicode で「10 進数字」に分類される文字すべてであり、アラビア文字の数字なども含む。``\w`` は漢字やひらがなにも一致し、``\s`` は全角空白（U+3000）にも一致する。

日本語の文章から単語や数字を拾う場合には、この性質が役に立つ。一方、「半角数字だけを受け付ける」ような入力値の検証では問題になる。その場合は、5 行目のように ``[0-9]`` と書くか、6 行目のように ``re.ASCII`` フラグ（第 8 章）を指定して、対象を ASCII 文字に限る。

なお、パターンが ``bytes`` の場合は、``\d`` などは常に ASCII 文字だけを対象にする。

まとめ
------

* ``[...]`` は列挙した文字のどれか 1 文字に、``[^...]`` は列挙した文字以外の 1 文字に一致する。
* ``.`` は改行以外の任意の 1 文字に一致する。
* ``\d``、``\w``、``\s`` は Unicode 文字にも一致する。ASCII 文字に限るときは ``[0-9]`` のように書くか、``re.ASCII`` を指定する。
