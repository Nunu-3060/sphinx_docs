付録 B 用語集
=============

本書で使った主な用語を、英字、五十音の順に並べる。

.. glossary::

   BRE
      Basic Regular Expression（基本正規表現）。POSIX で定められた正規表現の一種で、grep と sed の既定の構文。グループや回数指定の括弧に ``\`` を付けて ``\(...\)``、``\{m,n\}`` と書く。

   ERE
      Extended Regular Expression（拡張正規表現）。POSIX で定められた正規表現の一種で、``grep -E`` や ``sed -E`` で使う。括弧や ``+``、``?``、``|`` を ``\`` なしで書ける。

   Match オブジェクト
      ``re.search()`` などが一致したときに返すオブジェクト。一致した文字列、位置、グループの値を持つ。

   PCRE
      Perl Compatible Regular Expressions。Perl と互換性を持つ正規表現の C 言語ライブラリ。PHP や GNU grep の ``-P`` オプションなどで使われる。

   raw 文字列
      先頭に ``r`` を付けた Python の文字列リテラル（例: ``r"\d+"``）。``\`` をエスケープの始まりとして扱わない。正規表現のパターンを書くときに使う。

   ReDoS
      Regular expression Denial of Service。破滅的バックトラックを起こす入力を送り付け、正規表現の処理で CPU を占有させる攻撃。

   アトミックグループ
      ``(?>...)`` で表すグループ。中のパターンが一度一致すると、後からバックトラックで一致の範囲を変えない。Python 3.11 以降で使える。

   後読み
      ``(?<=...)`` と ``(?<!...)`` で表すゼロ幅アサーション。直前に指定したパターンがある（ない）位置に一致する。

   アンカー
      文字ではなく位置に一致する要素。``^``、``$``、``\A``、``\Z``、``\b`` など。

   エスケープ
      メタ文字の直前に ``\`` を置き、特別な意味を打ち消してその文字自身を表すこと。

   キャプチャグループ
      ``(...)`` で表すグループ。一致した文字列が記録され、後から番号で取り出せる。

   後方参照
      パターン中で、前にあるグループが一致した文字列そのものを参照すること。``\1`` や ``(?P=name)`` と書く。

   強欲量指定子
      量指定子の後ろに ``+`` を付けたもの（例: ``*+``、``++``）。できるだけ多く一致し、バックトラックで手放さない。Python 3.11 以降で使える。

   最短マッチ
      量指定子の後ろに ``?`` を付けたときの動作。できるだけ少ない文字に一致しようとする。非貪欲マッチともいう。

   先読み
      ``(?=...)`` と ``(?!...)`` で表すゼロ幅アサーション。直後に指定したパターンが続く（続かない）位置に一致する。

   正規表現
      文字列の形を記述するための小さな言語。また、その言語で書かれた個々の記述（パターン）を指すこともある。

   ゼロ幅アサーション
      文字を消費せず、条件を満たす位置に一致する要素。アンカー、先読み、後読みがこれに当たる。

   貪欲マッチ
      量指定子の既定の動作。できるだけ多くの文字に一致しようとし、失敗した場合はバックトラックで 1 文字ずつ手放す。

   名前付きグループ
      ``(?P<name>...)`` で表すキャプチャグループ。番号に加えて名前でも取り出せる。

   パターン
      正規表現で書かれた、文字列の形の記述。

   パターンオブジェクト
      ``re.compile()`` が返すオブジェクト。パターンを解析した結果を持ち、``search()`` などのメソッドを持つ。

   バックトラック
      照合に失敗したときに、直前の選択に戻って別の選択肢を試すこと。Python の ``re`` など Perl 系のエンジンの基本動作。

   破滅的バックトラック
      バックトラックで試す組み合わせが入力の長さに対して指数関数的、または高次の多項式的に増え、照合が実質的に終わらなくなる現象。

   非キャプチャグループ
      ``(?:...)`` で表すグループ。パターンをまとめるだけで、一致した文字列を記録しない。

   フラグ
      パターン全体の解釈の仕方を変える設定。``re.IGNORECASE`` など。

   メタ文字
      正規表現の中で特別な意味を持つ文字。``.``、``^``、``$``、``*``、``+``、``?``、``{``、``}``、``[``、``]``、``\``、``|``、``(``、``)`` の 14 文字。

   文字クラス
      1 文字分の候補の集合を表す構文。``[abc]`` や ``\d`` など。

   リテラル
      パターンの中で、特別な意味を持たずにその文字自身に一致する文字。

   量指定子
      直前の要素の繰り返し回数を指定する構文。``*``、``+``、``?``、``{m,n}`` など。
