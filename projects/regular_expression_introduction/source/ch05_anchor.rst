アンカーと境界
==============

これまでのパターンは、文字列のどこにあっても一致した。この章では、「文字列の先頭」や「単語の区切り」のような位置を指定する\ :term:`アンカー`\ を説明する。アンカーは文字ではなく文字と文字の間の位置に一致し、文字を消費しない。このような要素を\ :term:`ゼロ幅アサーション`\ と呼ぶ。

^ と $
------

``^`` は文字列の先頭に、``$`` は文字列の末尾に一致する。

.. literalinclude:: ../examples/ch05_anchor.py
   :language: python
   :pyobject: demo_caret_dollar
   :linenos:
   :caption: 先頭と末尾のアンカー

3 行目の ``^\d+`` は先頭の数字の並びだけに、4 行目の ``\d+$`` は末尾の数字の並びだけに一致する。5 行目のように ``^`` と ``$`` で挟むと、文字列全体がパターンの形になっているかを調べられる。ただし、検証の目的では ``re.fullmatch()`` を使うほうがよい。その理由は後述する。

文字クラスの中の ``^``\ （否定）と、文字クラスの外の ``^``\ （先頭）は、同じ記号だがまったく別の意味である点に注意する。

複数行の文字列と re.MULTILINE
-----------------------------

既定では、``^`` と ``$`` は文字列全体の先頭と末尾にしか一致しない。``re.MULTILINE`` フラグを指定すると、各行の先頭（改行の直後）と各行の末尾（改行の直前）にも一致するようになる。

.. literalinclude:: ../examples/ch05_anchor.py
   :language: python
   :pyobject: demo_multiline
   :linenos:
   :caption: re.MULTILINE による行単位の照合

4 行目は、文字列全体が ``\w+`` だけで構成されていないので一致しない。5 行目では、各行がそれぞれ ``^\w+$`` に一致する。

``re.MULTILINE`` を指定しても常に文字列全体の先頭だけに一致させたい場合は、6 行目のように ``\A`` を使う。同様に、常に文字列全体の末尾だけに一致する ``\Z`` もある。

$ と末尾の改行
--------------

``$`` には注意すべき性質がある。``$`` は文字列の末尾だけでなく、末尾にある改行文字の直前にも一致する。

.. literalinclude:: ../examples/ch05_anchor.py
   :language: python
   :pyobject: demo_trailing_newline
   :linenos:
   :caption: 末尾の改行と $

3 行目では、文字列 ``"123\n"`` が ``^\d+$`` に一致する。ファイルから読み込んだ行は末尾に改行を含むので、この性質は便利な場面もある。しかし、入力値の検証で ``^...$`` を使うと、末尾に改行が付いた不正な値を受け付けてしまう。

文字列全体を厳密に検証するには、4 行目のように ``\A`` と ``\Z`` を使うか、5 行目のように ``re.fullmatch()`` を使う。本書では、意図が最も明確な ``re.fullmatch()`` を推奨する。

.. list-table:: 先頭と末尾のアンカーの比較
   :header-rows: 1
   :widths: 15 40 45

   * - アンカー
     - 既定の動作
     - re.MULTILINE を指定した場合
   * - ``^``
     - 文字列の先頭
     - 文字列の先頭と、各改行の直後
   * - ``$``
     - 文字列の末尾と、末尾の改行の直前
     - 文字列の末尾と、各改行の直前
   * - ``\A``
     - 文字列の先頭
     - 変わらない
   * - ``\Z``
     - 文字列の末尾
     - 変わらない

Python 3.14 では、``\Z`` と同じ意味の ``\z`` も使えるようになった。他の多くの実装では ``\z`` が「文字列の末尾」を表し、``\Z`` は ``$`` と同様に末尾の改行の直前にも一致する（第 12 章）。Python の ``\Z`` は他の実装の ``\z`` に相当する点に注意する。

単語の境界 \\b
--------------

``\b`` は単語の境界に一致する。単語の境界とは、``\w`` に一致する文字と ``\W`` に一致する文字の間、および文字列の先頭か末尾で ``\w`` に一致する文字と接する位置である。``\B`` はその逆で、単語の境界ではない位置に一致する。

.. literalinclude:: ../examples/ch05_anchor.py
   :language: python
   :pyobject: demo_word_boundary
   :linenos:
   :caption: 単語の境界

4 行目の ``\bcat\b`` は、独立した単語の ``cat`` だけに一致し、``concat`` や ``cats`` の中の ``cat`` には一致しない。末尾の ``cat.`` の ``cat`` は、後ろが ``.``\ （``\W`` の文字）なので一致する。5 行目の ``\Bcat`` は、前に単語の文字が続く ``cat``、つまり ``concat`` の中の ``cat`` だけに一致する。

日本語の文章では注意が必要である。第 3 章で見たとおり、ひらがなや漢字も ``\w`` に一致する。そのため、6 行目の ``ねこcat`` では ``こ`` と ``c`` の間が単語の境界にならず、``\bcat\b`` は一致しない。7 行目のように ``re.ASCII`` を指定すると、ひらがなは ``\W`` 扱いになるので一致する。日本語と英単語が混在する文章で ``\b`` を使うときは、この動作を意識しておく必要がある。

まとめ
------

* アンカーは文字ではなく位置に一致する。
* ``^`` と ``$`` は文字列の先頭と末尾に一致し、``re.MULTILINE`` を指定すると各行の先頭と末尾にも一致する。
* ``$`` は末尾の改行の直前にも一致する。文字列全体の検証には ``re.fullmatch()`` を使う。
* ``\b`` は単語の境界に一致する。日本語の文字も ``\w`` に含まれる点に注意する。
