グループと選択
==============

この章では、複数のパターンのどれかに一致させる「選択」と、パターンの一部をまとめる「グループ」を説明する。グループには、量指定子をまとめて掛ける働きと、一致した部分を後から取り出す働きがある。

``|`` で選択する
-----------------

``|`` で区切ったパターンは、そのいずれかに一致する。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_alternation
   :linenos:
   :caption: 選択

``|`` は正規表現の中で最も優先順位が低い。そのため、5 行目の ``^cat|dog$`` は「``^cat`` または ``dog$``」という意味になり、``catfish`` の先頭の ``cat`` に一致してしまう。「文字列全体が ``cat`` か ``dog``」を表すには、6 行目のように選択の範囲をグループで囲む。``(?:...)`` については「グループで量指定子をまとめる」の節で説明する。

選択肢の順序
------------

選択肢は左から順に試され、最初に一致したものが採用される。最も長く一致するものが選ばれるわけではない。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_alternation_order
   :linenos:
   :caption: 選択肢の順序による違い

3 行目では、左の ``Java`` が先に一致するので、``JavaScript`` 全体には一致しない。ある選択肢が別の選択肢の先頭部分になっている場合は、長いほうを左に書く。

なお、grep などで使われる POSIX 方式のエンジンは、最も長く一致する選択肢を選ぶ（第 12 章）。左から順に試すのは、Python、Perl、JavaScript などで使われるバックトラック方式のエンジンの動作である。

グループで量指定子をまとめる
----------------------------

第 4 章で見たとおり、量指定子は直前の 1 要素にしか掛からない。``(?:...)`` で囲むと、その中全体が 1 要素になり、まとめて量指定子を掛けられる。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_group_quantifier
   :linenos:
   :caption: グループと量指定子

``(?:ab)+`` は ``ab`` の 1 回以上の繰り返しに一致する。一方、``ab+`` は ``a`` の後に ``b`` が 1 個以上続く形なので、``ababab`` 全体には一致しない。

``(?:...)`` は、まとめる働きだけを持つグループで、:term:`非キャプチャグループ`\ と呼ぶ。次の節で説明する ``(...)`` も同じようにまとめる働きを持つが、一致した部分を記録するという働きが加わる。

キャプチャグループ
------------------

``(...)`` で囲んだ部分は、一致した文字列が記録され、後から取り出せる。これを\ :term:`キャプチャグループ`\ と呼ぶ。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_capture
   :linenos:
   :caption: キャプチャグループ

グループには、左から順に 1 から番号が付く。``m.group(1)`` で 1 番目のグループが一致した文字列を取り出せる。``m.group(0)`` はパターン全体が一致した文字列であり、``m.group()`` と同じである。``m.groups()`` は、すべてのグループをタプルで返す。

グループが入れ子になっている場合は、開き括弧 ``(`` が現れる順に番号が付く。たとえば ``((\d{4})-(\d{2}))`` では、外側のグループが 1 番、``\d{4}`` が 2 番、``\d{2}`` が 3 番になる。

名前付きグループ
----------------

グループが増えると、番号では何を指しているのかが分かりにくくなる。``(?P<名前>...)`` と書くと、グループに名前を付けられる。これを\ :term:`名前付きグループ`\ と呼ぶ。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_named_group
   :linenos:
   :caption: 名前付きグループ

名前付きグループは、``m.group("year")`` のように名前で取り出せる。6 行目のように ``m["month"]`` と書くこともできる。``m.groupdict()`` は、名前をキーとする辞書を返す。名前付きグループにも番号は付くので、``m.group(1)`` でも取り出せる。

名前付きグループの書き方は、実装によって異なる。Python の ``re`` は ``(?P<name>...)`` だけを受け付け、JavaScript などで使われる ``(?<name>...)`` には対応していない（第 12 章）。

後方参照
--------

パターンの中で ``\1`` や ``\2`` と書くと、それぞれ 1 番目、2 番目のグループが一致した文字列そのものを参照できる。これを\ :term:`後方参照`\ と呼ぶ。名前付きグループは ``(?P=名前)`` で参照する。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_backreference
   :linenos:
   :caption: 後方参照

3 行目の ``\b(\w+) \1\b`` は、同じ単語が空白を挟んで 2 回続く部分に一致する。``\1`` は「``\w+`` というパターン」ではなく「1 番目のグループが実際に一致した文字列（この場合は ``is``）」を表す点が重要である。

7 行目は、開始タグと同じ名前の終了タグで閉じられた部分だけを取り出している。``<i>`` は ``</b>`` で閉じられているので一致しない。

findall() とグループ
--------------------

``re.findall()`` の戻り値は、パターンに含まれるキャプチャグループの数によって変わる。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_findall_with_groups
   :linenos:
   :caption: findall() の戻り値の違い

.. list-table:: findall() の戻り値
   :header-rows: 1
   :widths: 30 70

   * - キャプチャグループの数
     - 戻り値
   * - 0 個
     - パターン全体が一致した文字列のリスト
   * - 1 個
     - そのグループが一致した文字列のリスト
   * - 2 個以上
     - 各グループが一致した文字列のタプルのリスト

単にまとめるためにグループを使ったつもりが、``re.findall()`` の結果が変わってしまうことがある。取り出す必要のないグループには、非キャプチャグループ ``(?:...)`` を使う。

繰り返したグループ
------------------

量指定子を掛けたキャプチャグループには、最後の繰り返しで一致した文字列だけが記録される。

.. literalinclude:: ../examples/ch06_group.py
   :language: python
   :pyobject: demo_repeated_group
   :linenos:
   :caption: 繰り返したグループの値

3 行目の ``(\d)+`` は ``1``、``2``、``3`` の順に一致するが、グループに残るのは最後の ``3`` だけである。繰り返した全体を取り出したい場合は、6 行目のように繰り返し全体をグループで囲む。

まとめ
------

* ``|`` は最も優先順位が低い。範囲を限定するにはグループで囲む。
* 選択肢は左から順に試され、最初に一致したものが採用される。
* ``(...)`` はキャプチャグループ、``(?:...)`` は非キャプチャグループ、``(?P<name>...)`` は名前付きグループである。
* ``\1`` や ``(?P=name)`` は、グループが一致した文字列そのものを参照する。
* ``re.findall()`` の戻り値はキャプチャグループの数で変わる。
