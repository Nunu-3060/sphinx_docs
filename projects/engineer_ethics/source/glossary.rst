用語集
======

本資料で使う主な用語を、アルファベット順、五十音順に並べています。

.. glossary::

   HMAC
      秘密鍵とハッシュ関数を組み合わせて、データの改ざんの検出などに使う値を計算する方式です。鍵を知らない人は同じ値を計算できないため、識別子の仮名化にも使えます。

   SQL インジェクション
      利用者の入力を SQL 文に直接埋め込むことで、攻撃者が任意の SQL を実行できてしまう脆弱性です。プレースホルダーを使うことで防げます。

   逸脱の常態化
      本来は許容されない小さな異常が、問題が起きないまま繰り返されるうちに、次第に正常なこととして受け入れられていく現象です。社会学者の Diane Vaughan が、チャレンジャー号の事故の分析で提唱しました。

   営業秘密
      秘密として管理され（秘密管理性）、事業活動に有用で（有用性）、公然と知られていない（非公知性）技術上・営業上の情報です。不正競争防止法で保護されます。

   仮名化
      氏名などの識別子を別の値に置き換え、そのデータだけでは個人を識別しにくくする加工です。対応表や鍵があれば元に戻せるため、引き続き個人情報として管理する必要があります。

   仮名加工情報
      個人情報保護法で定められた、他の情報と照合しない限り特定の個人を識別できないように加工した個人に関する情報です。事業者の内部での分析などに利用できます。

   義務論
      行為の結果にかかわらず、守るべき義務や規則に従うことを正しいとする倫理学の考え方です。

   競合状態
      複数の処理が同じデータに同時にアクセスするとき、処理が実行される順序やタイミングによって結果が変わってしまう不具合です。レースコンディションともいいます。

   公益通報
      事業者の一定の法令違反行為を、不正の目的でなく、事業者内部の窓口、行政機関、報道機関などに通報することです。公益通報者保護法によって、通報者は不利益な取り扱いから保護されます。

   功利主義
      行為の結果に注目し、関係者全体の幸福を最大にする行為を正しいとする倫理学の考え方です。

   個人情報
      個人情報保護法で定められた、生存する個人に関する情報で、氏名や生年月日などによって特定の個人を識別できるものです。他の情報と容易に照合して個人を識別できるものや、個人識別符号（マイナンバーなど）を含むものも該当します。

   コピーレフト
      ソフトウェアを改変・再頒布する際に、派生物にも元のライセンスと同じ条件を適用することを求める考え方です。GNU GPL が代表的です。

   志向倫理
      技術を使って社会をより良くすることを目指す倫理の側面です。予防倫理と対になる考え方です。

   集団浅慮
      集団で意思決定をするときに、合意を優先するあまり、異論や批判的な検討が抑えられ、誤った判断をしてしまう現象です。

   職務著作
      会社の発意に基づき、従業員が職務上作成した著作物について、一定の条件の下で会社が著作者となる制度です。

   心理的安全性
      チームの中で、懸念や誤り、反対意見を率直に伝えても、責められたり不利益を受けたりしないと感じられる状態です。

   責任ある開示
      脆弱性を発見した人が、まず製品の開発者に非公開で連絡し、修正の準備が整ってから脆弱性の情報を公表する手順です。協調的な脆弱性開示ともいいます。

   説明責任
      自らの判断や行為について、その理由や結果を関係者に説明し、責任を負うことです。アカウンタビリティともいいます。

   線引き法
      判断に迷う事例を、明らかに許される事例と明らかに許されない事例の間に位置付けて評価する方法です。

   創造的中道法
      対立する複数の要求を、できるだけ多く同時に満たす解決策を探す方法です。

   ソルト
      パスワードをハッシュ化する前に付け加える、利用者ごとに異なるランダムな値です。同じパスワードから同じハッシュ値ができることを防ぎ、事前に計算したハッシュ値の表を使った攻撃を困難にします。

   ディフィートデバイス
      試験などの特定の条件を検知したときだけ、製品の性能や動作を変える仕組みです。排出ガス規制の分野では、排出ガスの浄化装置の働きを不正に弱める仕組みを指します。

   データ最小化
      目的の達成に必要な最小限の個人データだけを収集・保存する原則です。

   徳倫理
      行為そのものより、行為者の人柄や品性に注目し、「徳のある人ならどう行動するか」を基準にする倫理学の考え方です。

   匿名化
      データを、特定の個人を識別できず、元に戻せないように加工することです。

   匿名加工情報
      個人情報保護法で定められた、特定の個人を識別できず、元の個人情報に戻せないように加工した個人に関する情報です。一定の条件の下で、本人の同意なく第三者に提供できます。

   内部告発
      組織の内部の人が、組織の不正や危険を、組織の外部に知らせることです。

   バイアス
      データや判断に含まれる系統的な偏りです。AI は学習データのバイアスを学習し、特定の属性の人を不利に扱うことがあります。

   ハルシネーション
      生成 AI が、事実と異なる内容や存在しない情報を、もっともらしく出力する現象です。

   フェイルセーフ
      故障や誤操作が起きたときに、システムが安全な状態になるように設計する考え方です。

   プライバシー・バイ・デザイン
      プライバシーの保護を、システムの企画・設計の段階から組み込むという考え方です。

   予防倫理
      不正や事故を起こさないことに重点を置く倫理の側面です。志向倫理と対になる考え方です。

   利益相反
      技術者が負う職務上の責任と、技術者自身や第三者の利益とが対立する状況です。

   利害関係者
      ある活動や決定によって影響を受ける、または影響を与える人や組織です。ステークホルダーともいいます。

   倫理綱領
      専門職の団体が、その職業に携わる人が守るべき行動の原則を明文化したものです。
