8 bit Game Sound 作成入門
=========================

本書は、ゲーム制作やアセット制作の経験がないエンジニアに向けて、ファミコン時代のゲーム機のような「8 bit サウンド」の効果音と BGM を自分で作れるようになることを目指す入門書である。

音源チップの仕組みを理解したうえで、Python と NumPy を使って波形を一から合成し、効果音とループ BGM を WAV ファイルとして書き出すところまでを扱う。本文中の音声はすべて本書のサンプルコードで生成したものであり、ブラウザ上でそのまま再生できる。
