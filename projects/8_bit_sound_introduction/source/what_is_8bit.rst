8 bit サウンドとは
==================

この章では、8 bit サウンドという言葉が何を指すのか、そしてなぜあのような独特の音になったのかを、歴史的な背景とともに説明する。

「8 bit」が意味するもの
-------------------------

「8 bit サウンド」の「8 bit」は、ゲーム機やパソコンの CPU が一度に扱えるデータの幅に由来する呼び方である。1980 年代の家庭用ゲーム機やパソコンの多くは 8 bit の CPU を搭載しており、その時代のゲーム機の音が「8 bit サウンド」と呼ばれるようになった。

注意したいのは、8 bit は音声データの細かさ（「:ref:`ch-digital-audio`」で説明する\ :term:`量子化ビット数`）を表しているわけではないことである。例えば、ファミコンの音源の矩形波チャンネルは音量を 4 bit（16 段階）で、三角波チャンネルは波形を 4 bit で表している。「8 bit サウンド」は技術的に厳密な用語ではなく、「8 bit 機の時代の音源チップが出していたような音」を指す呼び名と考えるとよい。

音源チップと PCM 方式
---------------------

現在のゲーム機やパソコンは、あらかじめ録音または制作した音声データ（:term:`PCM`）を再生して音を出す。効果音も BGM も、基本的には WAV や Ogg Vorbis などの音声ファイルとして用意され、それを再生する。

一方、1980 年代のゲーム機には、音声データを大量に保存しておくだけのメモリがなかった。例えば、本書で作る 1 秒間の効果音は WAV ファイルで約 88 KB になるが、ファミコンのカートリッジの容量は、初期のもので数十 KB しかなかった。

そこで使われたのが\ :term:`音源チップ`\ である。音源チップは、波形を生成する回路を内蔵した専用の部品であり、CPU は「どの高さの音を、どの音量で、どの波形で鳴らすか」という少量の設定値を書き込むだけでよい。音そのものはチップが回路で作り出すため、音声データを保存しておく必要がない。

制約が音色を決めた
------------------

音源チップが作り出せる波形は、回路で簡単に作れるものに限られていた。代表的なものは次の 3 つである。

* :term:`矩形波` : 2 つの値を交互に出力するだけの波形。明るく鋭い音になる。
* :term:`三角波` : 値を一定の段階で上げ下げする波形。やわらかく丸い音になる。
* :term:`ノイズ` : でたらめな値を出力する波形。打楽器や爆発音に使う。

また、同時に鳴らせる音の数（:term:`チャンネル`\ 数）も 3 から 5 程度に限られていた。和音を鳴らしたくても、メロディ、ベース、打楽器にチャンネルを割り当てると、和音に使えるチャンネルはほとんど残らない。

当時の作曲者は、こうした制約の中で工夫を重ねた。素早く音程を切り替えて 1 チャンネルで和音のように聞かせる\ :term:`アルペジオ`、同じメロディを別のチャンネルで少し遅らせて鳴らすエコー、ノイズの音色を変えて複数の打楽器を表現する方法などである。8 bit サウンドの独特の響きは、単純な波形だけでなく、こうした制約を乗り越えるための手法から生まれたものである。本書では、これらの手法を「:ref:`ch-shaping`」と「:ref:`ch-bgm`」で実際に作ってみる。

代表的な音源チップ
------------------

8 bit 機の時代には、さまざまな音源チップが使われた。代表的なものを次の表に示す。

.. list-table:: 8 bit 機の時代の代表的な音源
   :header-rows: 1
   :widths: 22 28 50

   * - 音源
     - 主な搭載機種
     - チャンネル構成
   * - ファミコンの APU（CPU の 2A03 に内蔵）
     - ファミコン（1983 年）、NES（1985 年）
     - 矩形波 2、三角波 1、ノイズ 1、DPCM 1
   * - ゲームボーイの音源（CPU に内蔵）
     - ゲームボーイ（1989 年）
     - 矩形波 2、波形メモリ 1、ノイズ 1
   * - AY-3-8910
     - MSX など
     - 矩形波 3、ノイズ 1（ノイズは矩形波のチャンネルに混ぜて使う）
   * - SN76489
     - SG-1000、セガ・マークIII など
     - 矩形波 3、ノイズ 1
   * - SID（MOS 6581）
     - コモドール 64（1982 年）
     - 3 チャンネル（矩形波・三角波・のこぎり波・ノイズを選択、フィルター付き）

本書では、このうちファミコンの音源を手本にする。チャンネルごとに役割がはっきり分かれていて構成を理解しやすく、技術資料も豊富だからである。ファミコンの音源の詳細は「:ref:`ch-sound-chip`」で説明し、その章の最後で他の音源と比較する。

チップチューン
--------------

8 bit 機が現役を退いた後も、その音は消えなかった。当時の音源チップ、またはその音を再現するソフトウェアを使って作られた音楽は\ :term:`チップチューン`\ と呼ばれ、現在も一つの音楽ジャンルとして親しまれている。

現在のゲームで 8 bit サウンドが使われる理由には、次のようなものがある。

* レトロな見た目のゲーム（ドット絵のゲームなど）と雰囲気が合う。
* 単純な波形でできているため、音が聞き取りやすく、効果音として何が起きたかが伝わりやすい。
* 少ない要素で作れるため、小規模な開発でも音をそろえやすい。

現在のゲームは、音源チップではなく PCM 方式で音を鳴らす。そのため、8 bit サウンドも WAV などの音声ファイルとして用意すればよい。本書で作る音も、最終的には WAV ファイルとして書き出してゲームに組み込む。
