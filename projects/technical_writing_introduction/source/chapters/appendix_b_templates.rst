付録 B テンプレート集
=====================

「:doc:`07_document_types`」で説明した文書のうち、README、設計書、手順書、障害報告書のテンプレートを Markdown 形式で収録した。``<`` と ``>`` で囲まれた箇所を、内容に合わせて書き換えて使う。不要な項目は削除してよいが、削除する前に、その項目が本当に読者に不要かどうかを検討する。
