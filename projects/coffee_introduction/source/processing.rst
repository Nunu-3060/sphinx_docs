精製方法
========

精製とは
--------

収穫したコーヒーチェリーから果肉や殻を取り除き、乾燥させて生豆にする工程を\ :term:`精製`\ と呼びます。精製は、豆を保存や輸送ができる状態にするための工程ですが、同時にコーヒーの味にも大きく影響します。

精製方法は、産地の気候や水の手に入りやすさ、生産者の考え方によって選ばれます。主な精製方法は、次の 4 つです。

ナチュラル（乾燥式）
--------------------

:term:`ナチュラル`\ は、収穫したコーヒーチェリーを、実のまま天日などで乾燥させる方法です。最も古くから行われている方法で、エチオピアやブラジル、イエメンなどで多く採用されています。

#. 収穫したコーヒーチェリーを、地面や棚に広げて干します。
#. 数週間かけて、実がからからになるまで乾燥させます。
#. 乾燥した実の外皮と果肉、殻を機械で一度に取り除き、生豆を取り出します。

実のまま乾燥させるため、果肉の甘みや香りが豆に移り、果物のような甘い香りと、しっかりしたコクが生まれます。一方で、乾燥にむらが出やすく、品質がそろいにくいという面もあります。

ウォッシュト（水洗式）
----------------------

:term:`ウォッシュト`\ は、水を使って果肉などを取り除いてから乾燥させる方法です。中南米やケニアなど、水の豊富な産地で多く採用されています。

#. 収穫したコーヒーチェリーを水に入れ、浮いた未熟な実や異物を取り除きます。
#. 機械で外皮と果肉を取り除きます。
#. 殻の周りに残ったミューシレージを、水槽で発酵させて分解し、水で洗い流します。
#. 殻の付いた状態（パーチメントコーヒー）で乾燥させます。
#. 乾燥後に殻を取り除き、生豆を取り出します。

果肉を早い段階で取り除くため、雑味が少なく、すっきりとした味わいと、はっきりとした酸味が特徴です。品質がそろいやすい一方で、多くの水と設備が必要です。

ハニー（パルプドナチュラル）
----------------------------

:term:`ハニー`\ は、ナチュラルとウォッシュトの中間の方法です。中米のコスタリカなどで多く採用されています。ブラジルでは「パルプドナチュラル」と呼ばれます。

#. 機械で外皮と果肉を取り除きます。
#. ミューシレージを残したまま、殻の付いた状態で乾燥させます。
#. 乾燥後に殻を取り除き、生豆を取り出します。

ミューシレージが蜂蜜のようにべたつくことから、この名前が付きました。蜂蜜を加えるわけではありません。ミューシレージの甘みが豆に移り、ウォッシュトのすっきりさと、ナチュラルの甘さを併せ持った味わいになります。

スマトラ式
----------

:term:`スマトラ式`\ は、インドネシアのスマトラ島などで行われている独特の方法です。

#. 機械で外皮と果肉を取り除き、殻の付いた状態で短時間だけ乾燥させます。
#. 豆がまだ水分を多く含んでいるうちに殻を取り除きます。
#. 生豆の状態で、さらに乾燥させます。

雨が多く、乾燥に時間をかけにくい地域で生まれた方法です。酸味が少なく、重厚なコクと、土やハーブのような独特の香りが生まれます。マンデリンの個性的な味わいは、この精製方法によるところが大きいといわれています。

精製方法による味の違い
----------------------

4 つの精製方法の特徴を、次の表にまとめます。

.. list-table::
   :header-rows: 1
   :widths: 22 26 26 26

   * - 精製方法
     - 乾燥させる状態
     - 味の傾向
     - 主な産地
   * - ナチュラル
     - 実のまま
     - 果物のような甘い香り、しっかりしたコク
     - エチオピア、ブラジル、イエメン
   * - ウォッシュト
     - 果肉とミューシレージを取り除いた状態
     - すっきりとした味わい、はっきりとした酸味
     - コロンビア、ケニア、グアテマラ
   * - ハニー
     - 果肉を取り除き、ミューシレージを残した状態
     - 甘みとすっきりさのバランスが良い
     - コスタリカ、ブラジル
   * - スマトラ式
     - 殻を早く取り除き、生豆の状態
     - 酸味が少なく、重厚なコク、独特の香り
     - インドネシア

同じ産地の豆でも、精製方法が違えば味わいは大きく変わります。豆を選ぶときは、産地だけでなく精製方法にも注目すると、好みの豆を見つけやすくなります。
