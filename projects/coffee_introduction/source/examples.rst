便利なスクリプト
================

本付録では、コーヒーを淹れるときに役立つ 2 つの Python スクリプトを紹介します。どちらも Python の標準機能だけで動くため、追加のインストールは不要です。

動かすための準備
----------------

スクリプトを動かすには、Python 3.10 以上が必要です。Python は、`Python の公式サイト <https://www.python.org/downloads/>`_\ からダウンロードしてインストールできます。

スクリプトは、次の手順で実行します。

#. 本ページのリンクからスクリプトをダウンロードします。
#. Windows では「コマンドプロンプト」、macOS では「ターミナル」を開きます。
#. ``cd`` コマンドで、スクリプトを保存したフォルダーに移動します。
#. ``python`` コマンドの後にスクリプトのファイル名を付けて実行します。

例えば、ダウンロードフォルダーに保存した場合は、次のように入力します。macOS では ``python`` の代わりに ``python3`` と入力してください。

.. code-block:: text
   :linenos:

   cd Downloads
   python coffee_calculator.py

粉の量の計算（coffee_calculator.py）
------------------------------------

杯数、濃さ、焙煎度、淹れ方を指定すると、粉の量、注ぐお湯の量、お湯の温度、挽き方の目安を表示します。計算には、「:doc:`brewing`」で紹介した式と目安を使っています。1 杯分のできあがり量は 140 ml としています。

ダウンロード：:download:`coffee_calculator.py <../examples/coffee_calculator.py>`

使い方
^^^^^^

引数を付けずに実行すると、杯数、濃さ、焙煎度、淹れ方を順に尋ねられます。濃さ、焙煎度、淹れ方は、何も入力せずに Enter キーを押すと、それぞれ「普通」「中煎り」「ハンドドリップ」になります。

.. code-block:: text
   :linenos:

   python coffee_calculator.py

杯数（1〜10）を続けて指定すると、すぐに結果が表示されます。そのほかの項目は、次のオプションで指定します。指定しない場合は、それぞれ ``normal``\ 、\ ``medium``\ 、\ ``drip`` になります。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - オプション
     - 指定できる値
   * - ``--strength``
     - 濃さ。\ ``light``\ （薄め）、\ ``normal``\ （普通）、\ ``strong``\ （濃いめ）
   * - ``--roast``
     - 焙煎度。\ ``light``\ （浅煎り）、\ ``medium``\ （中煎り）、\ ``dark``\ （深煎り）
   * - ``--method``
     - 淹れ方。\ ``drip``\ （ハンドドリップ）、\ ``press``\ （フレンチプレス）

例えば、普通の濃さ、中煎りの豆で 2 杯分をハンドドリップで淹れる場合は、次のように実行します。

.. code-block:: text
   :linenos:

   python coffee_calculator.py 2

実行すると、次のように表示されます。

.. code-block:: text
   :linenos:

   2 杯分（普通、中煎り、ハンドドリップ）の目安
     粉の量        : 21.5 g
     注ぐお湯の量  : 323 ml
     できあがり量  : 約 280 ml
     お湯の温度    : 88〜92 ℃
     挽き方        : 中細挽き

深煎りの豆で、濃いめの 3 杯分をフレンチプレスで淹れる場合は、次のように実行します。

.. code-block:: text
   :linenos:

   python coffee_calculator.py 3 --strength strong --roast dark --method press

ハンドドリップのタイマー（drip_timer.py）
-----------------------------------------

粉の量を指定すると、「:doc:`brewing`」で紹介したハンドドリップの手順に沿って、蒸らしと注湯のタイミングを案内します。各手順では、スケールの表示が何 g になるまでお湯を注げばよいかを表示します。注ぐお湯の合計は、粉の量の 15 倍です。

ダウンロード：:download:`drip_timer.py <../examples/drip_timer.py>`

使い方
^^^^^^

粉の量（5〜60 g）を指定して実行します。指定しない場合は、実行後に入力を求められます。例えば、粉 20 g で淹れる場合は、次のように実行します。

.. code-block:: text
   :linenos:

   python drip_timer.py 20

スケールの表示を 0 g にしてから Enter キーを押すと、タイマーが始まります。次の手順までの残り時間が 1 秒ごとに表示され、手順の時刻になると、音とメッセージで知らせます。途中でやめたい場合は、:kbd:`Ctrl+C` を押します。最後まで進むと、次のように表示されます。

.. code-block:: text
   :linenos:

   粉 20 g、お湯 300 g で淹れます。
   スケールを 0 g にしてから、Enter キーを押すと始まります。
   Ctrl+C で中止できます。
   [0:00] 蒸らし：スケールが 40 g になるまで、粉全体を湿らせるように注ぎます。
   [0:30] 1 回目：スケールが 120 g になるまで、中心から円を描くように注ぎます。
   [1:10] 2 回目：スケールが 210 g になるまで注ぎます。
   [1:50] 3 回目：スケールが 300 g になるまで注ぎます。
   [3:00] お湯が落ちきっていなくても、ドリッパーを外します。
   できあがりです。サーバーを軽く回して混ぜてから注ぎましょう。
