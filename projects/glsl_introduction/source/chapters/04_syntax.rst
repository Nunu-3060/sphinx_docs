第 4 章 GLSL の基本文法
=======================

この章では、GLSL の文法を説明します。GLSL の文法は C 言語に似ていますが、ベクトルと行列の型が組み込まれている点や、暗黙の型変換がない点など、C 言語と異なる部分もあります。

この章のコード片は、:ref:`サンプル 12（シェーダーエディター） <sample-list>` のフラグメントシェーダーの ``main`` 関数の中などに書き加えて試すことができます。

シェーダーの基本構造
--------------------

シェーダーのソースコードは、おおよそ次の順に書きます。

.. code-block:: glsl

   #version 300 es              // (1) バージョンの指定（必ず先頭行）
   precision highp float;       // (2) 精度の指定

   uniform vec2 uResolution;    // (3) 入出力の変数、定数、関数の宣言
   out vec4 outColor;

   float square(float x) {      // 自作の関数
       return x * x;
   }

   void main() {                // (4) main 関数（実行の開始点）
       outColor = vec4(1.0);
   }

``main`` 関数が実行の開始点です。GPU は頂点やフラグメントごとに ``main`` 関数を 1 回呼び出します。

コメントは C 言語と同じく、``//`` から行末までと、``/*`` から ``*/`` までです。

プリプロセッサ
--------------

C 言語と同じように、``#define``、``#if``、``#ifdef``、``#endif`` などのプリプロセッサ命令を使えます。``#include`` はありません。

.. code-block:: glsl

   #define PI 3.14159265
   #define USE_FOG 1

   #if USE_FOG
       color = mix(color, fogColor, fogAmount);
   #endif

データ型
--------

スカラー型
~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - 型
     - 内容
   * - ``bool``
     - 真偽値（``true`` または ``false``）
   * - ``int``
     - 符号付き 32 ビット整数
   * - ``uint``
     - 符号なし 32 ビット整数。定数は ``3u`` のように末尾に ``u`` を付けて書きます。
   * - ``float``
     - 32 ビット浮動小数点数。定数は ``1.0``、``0.5``、``1e-3`` のように書きます。

``double`` 型はありません（デスクトップ向けの GLSL 4.00 以降にはあります）。

ベクトル型
~~~~~~~~~~

2〜4 個の成分を持つベクトルの型が組み込まれています。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 型
     - 内容
   * - ``vec2``、``vec3``、``vec4``
     - ``float`` を 2〜4 個持つベクトル
   * - ``ivec2``、``ivec3``、``ivec4``
     - ``int`` を 2〜4 個持つベクトル
   * - ``uvec2``、``uvec3``、``uvec4``
     - ``uint`` を 2〜4 個持つベクトル
   * - ``bvec2``、``bvec3``、``bvec4``
     - ``bool`` を 2〜4 個持つベクトル

ベクトルは、位置（x, y, z）、色（R, G, B, A）、テクスチャ座標など、さまざまな値を表すのに使います。

行列型
~~~~~~

``float`` の行列の型が組み込まれています。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 型
     - 内容
   * - ``mat2``、``mat3``、``mat4``
     - 2 × 2、3 × 3、4 × 4 の正方行列
   * - ``mat2x3`` など
     - ``matCxR`` の形で、C 列 R 行の行列を表します。例えば ``mat2x3`` は 2 列 3 行の行列です。

行列は主に座標変換に使います（第 7 章）。

サンプラー型
~~~~~~~~~~~~

``sampler2D`` などのサンプラー型は、テクスチャを参照するための型です。サンプラー型の変数は uniform 変数として宣言して使います（関数の引数にすることもできます）。詳しくは第 9 章で説明します。

リテラルと型変換
----------------

GLSL ES 3.00 には、C 言語のような暗黙の型変換がありません。例えば、``float`` の変数に ``int`` の定数を代入するとコンパイルエラーになります。

.. code-block:: glsl

   float a = 1;      // エラー：1 は int の定数
   float b = 1.0;    // 正しい
   float c = 2.0 * 3;  // エラー：float と int の演算はできない

型を変換するには、変換先の型の名前を関数のように使います。これをコンストラクターと呼びます。

.. code-block:: glsl

   int i = 3;
   float f = float(i);     // 3.0
   int j = int(2.7);       // 2（小数点以下は切り捨て）
   bool b = bool(i);       // true（0 以外は true）

.. note::

   デスクトップ向けの GLSL（1.20 以降）では、``int`` から ``float`` への暗黙の型変換が行われます。デスクトップ向けに書かれたシェーダーを WebGL に移植すると、この違いでエラーになることがよくあります。

ベクトルと行列のコンストラクター
--------------------------------

ベクトルと行列も、コンストラクターで作ります。引数の成分は前から順に詰められます。

.. code-block:: glsl

   vec3 a = vec3(1.0, 2.0, 3.0);
   vec3 b = vec3(0.5);             // すべての成分が 0.5：(0.5, 0.5, 0.5)
   vec4 c = vec4(a, 1.0);          // (1.0, 2.0, 3.0, 1.0)
   vec4 d = vec4(0.1, a.xy, 0.9);  // (0.1, 1.0, 2.0, 0.9)
   vec2 e = vec2(c);               // 先頭の 2 成分：(1.0, 2.0)

   mat3 m = mat3(1.0);             // 単位行列（対角成分が 1.0、それ以外は 0.0）
   mat3 n = mat3(
       1.0, 0.0, 0.0,              // 1 列目
       0.0, 1.0, 0.0,              // 2 列目
       2.0, 3.0, 1.0);             // 3 列目
   mat3 upper = mat3(mat4(1.0));   // 4 × 4 行列の左上 3 × 3 部分

行列のコンストラクターに成分を並べる場合、**列ごとに** 詰められる点に注意してください（列優先）。上の ``n`` は、数学の表記では次の行列です。

.. math::

   n = \begin{pmatrix} 1 & 0 & 2 \\ 0 & 1 & 3 \\ 0 & 0 & 1 \end{pmatrix}

成分へのアクセスとスウィズル
----------------------------

ベクトルの成分は、名前または添字で読み書きできます。成分の名前には 3 つの組があり、どれを使っても同じ成分を指します。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 名前の組
     - 主な用途
   * - ``x``、``y``、``z``、``w``
     - 位置や方向
   * - ``r``、``g``、``b``、``a``
     - 色
   * - ``s``、``t``、``p``、``q``
     - テクスチャ座標

成分の名前を複数並べると、それらの成分からなる新しいベクトルを作れます。この書き方をスウィズル（swizzle）と呼びます。同じ成分を繰り返したり、順序を入れ替えたりすることもできます。

.. code-block:: glsl

   vec4 v = vec4(1.0, 2.0, 3.0, 4.0);
   float a = v.x;        // 1.0
   float b = v[1];       // 2.0（添字は 0 から）
   vec2 c = v.xy;        // (1.0, 2.0)
   vec3 d = v.zyx;       // (3.0, 2.0, 1.0)
   vec4 e = v.xxyy;      // (1.0, 1.0, 2.0, 2.0)
   vec3 f = v.rgb;       // (1.0, 2.0, 3.0)

   v.xy = vec2(0.0);     // x と y だけに代入：(0.0, 0.0, 3.0, 4.0)

次のような書き方はエラーになります。

.. code-block:: glsl

   vec3 g = v.xgb;       // エラー：異なる組の名前を混ぜている
   v.xx = vec2(1.0);     // エラー：代入先に同じ成分を 2 回指定している
   vec2 h = c.z;         // エラー：vec2 には z 成分がない

行列の要素は、``m[列][行]`` の順に添字を指定します。``m[2]`` は 3 列目のベクトル（``vec3`` や ``vec4``）を表します。

演算子
------

算術演算子（``+``、``-``、``*``、``/``）はベクトルにも使え、成分ごとに計算されます。

.. code-block:: glsl

   vec3 a = vec3(1.0, 2.0, 3.0);
   vec3 b = vec3(4.0, 5.0, 6.0);
   vec3 c = a + b;       // (5.0, 7.0, 9.0)
   vec3 d = a * b;       // (4.0, 10.0, 18.0)：成分ごとの積（内積ではない）
   vec3 e = a * 2.0;     // (2.0, 4.0, 6.0)：ベクトルとスカラーの演算
   vec3 f = a + 1.0;     // (2.0, 3.0, 4.0)

一方、行列を含む ``*`` は、数学の行列の積になります。

.. code-block:: glsl

   mat4 m;
   vec4 p;
   vec4 q = m * p;       // 行列とベクトルの積（p を列ベクトルとして扱う）
   mat4 n = m * m;       // 行列と行列の積

成分ごとの積を求めたい場合は、組み込み関数 ``matrixCompMult`` を使います。

そのほかの演算子は次のとおりです。

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 演算子
     - 内容
   * - ``%``
     - 剰余。``int`` と ``uint`` だけに使えます。``float`` には組み込み関数 ``mod`` を使います。
   * - ``&``、``|``、``^``、``~``、``<<``、``>>``
     - ビット演算。``int`` と ``uint`` だけに使えます。
   * - ``==``、``!=``
     - 比較。ベクトルに使うと、すべての成分が等しいかどうかを 1 つの ``bool`` で返します。
   * - ``<``、``>``、``<=``、``>=``
     - 比較。スカラーだけに使えます。ベクトルの成分ごとの比較には ``lessThan`` などの関数を使います（第 5 章）。
   * - ``&&``、``||``、``^^``、``!``
     - 論理演算。``bool`` だけに使えます。``^^`` は排他的論理和です。
   * - ``? :``
     - 条件演算子

整数の除算は、C 言語と同じく小数点以下が切り捨てられます。例えば ``7 / 2`` は ``3`` です。

制御構文
--------

``if``、``else``、``for``、``while``、``do`` 〜 ``while``、``switch``、``break``、``continue``、``return`` を、C 言語と同じように使えます。条件式は ``bool`` 型である必要があり、C 言語のように整数を条件にすることはできません。

.. code-block:: glsl

   int count = 0;
   for (int i = 0; i < 10; i++) {
       if (i == 5) {
           continue;
       }
       count += i;
   }

   switch (mode) {      // mode は int または uint
   case 0:
       color = vec3(1.0, 0.0, 0.0);
       break;
   default:
       color = vec3(0.0);
       break;
   }

フラグメントシェーダーでは、そのフラグメントを捨てる ``discard`` も使えます（第 8 章）。

.. note::

   GLSL ES 1.00（WebGL 1.0）では、``for`` 文の繰り返し回数を定数で決める必要があるなど、ループに強い制限がありました。GLSL ES 3.00 ではこの制限はなくなり、uniform 変数などを使って繰り返し回数を決められます。

関数
----

関数は C 言語と同じように定義します。関数は、呼び出す場所より前に定義するか、前にプロトタイプ宣言を書く必要があります。

.. code-block:: glsl

   float square(float x);       // プロトタイプ宣言

   void main() {
       float y = square(3.0);
   }

   float square(float x) {
       return x * x;
   }

GLSL の関数には、次の特徴があります。

* 引数の型が異なる同じ名前の関数を定義できます（オーバーロード）。
* 再帰呼び出し（関数が自分自身を呼び出すこと）はできません。
* ポインターはありません。引数は常に値として渡されます。配列や構造体も、コピーが渡されます。

関数から複数の値を返したい場合は、引数に修飾子を付けます。

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - 修飾子
     - 内容
   * - ``in``
     - 呼び出し元から値を受け取ります（既定）。関数の中で変更しても、呼び出し元には反映されません。
   * - ``out``
     - 関数の終了時に、引数の値が呼び出し元の変数に書き戻されます。関数の開始時の値は不定です。
   * - ``inout``
     - 呼び出し元から値を受け取り、関数の終了時に書き戻します。

.. code-block:: glsl

   // 極座標 (半径, 角度) に変換する
   void toPolar(vec2 p, out float radius, out float angle) {
       radius = length(p);
       angle = atan(p.y, p.x);
   }

   void main() {
       float r, a;
       toPolar(vec2(1.0, 1.0), r, a);
   }

変数と修飾子
------------

変数の宣言には、次のような修飾子を付けることがあります。

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - 修飾子
     - 内容
   * - ``const``
     - 定数。宣言時に値を決め、変更できません。
   * - ``in``
     - シェーダーへの入力（第 6 章）
   * - ``out``
     - シェーダーからの出力（第 6 章）
   * - ``uniform``
     - JavaScript から設定する、描画 1 回の間は変わらない値（第 6 章）

.. code-block:: glsl

   const float PI = 3.14159265;
   const vec3 RED = vec3(1.0, 0.0, 0.0);

関数の外で宣言した変数（グローバル変数）は、``in``、``out``、``uniform`` の修飾子がなければ、そのシェーダーの 1 回の実行の中だけで使える変数になります。ほかの頂点やフラグメントの実行と値を共有することはありません。

精度修飾子
----------

GLSL ES では、変数の計算精度を ``highp``、``mediump``、``lowp`` の 3 段階で指定できます。精度を下げると、スマートフォンなどの GPU で計算が速くなったり、消費電力が減ったりすることがあります。

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - 精度
     - 内容
   * - ``highp``
     - 高精度。``float`` は 32 ビット浮動小数点数相当です。
   * - ``mediump``
     - 中精度。``float`` は 16 ビット浮動小数点数相当（有効数字は 10 進数で 3 桁程度）以上です。
   * - ``lowp``
     - 低精度。色（0.0〜1.0）を扱える程度の精度以上です。

精度は変数ごとに指定するか、``precision`` 文で型ごとの既定値を指定します。

.. code-block:: glsl

   precision highp float;       // この後の float の既定の精度を highp にする
   mediump vec3 color;          // この変数だけ mediump にする

頂点シェーダーでは、``float`` と ``int`` の既定の精度は ``highp`` です。フラグメントシェーダーでは ``float`` の既定の精度が決まっていないため、``precision`` 文を必ず書く必要があります。本書のサンプルでは、フラグメントシェーダーで常に ``precision highp float;`` を指定しています。

.. note::

   精度の指定は、GPU が必ずその精度で計算することを保証するものではありません。「少なくともこの精度が必要」という指示です。多くのデスクトップ PC の GPU は、``mediump`` を指定しても 32 ビットで計算します。そのため、精度が不足する問題は、スマートフォンなどで初めて見つかることがあります。

構造体と配列
------------

構造体と配列も使えます。

.. code-block:: glsl

   struct Light {
       vec3 direction;
       vec3 color;
   };

   Light light = Light(vec3(0.0, 1.0, 0.0), vec3(1.0));  // 構造体のコンストラクター
   vec3 c = light.color;

   float weights[3] = float[3](0.25, 0.5, 0.25);         // 配列のコンストラクター
   int n = weights.length();                             // 要素数：3

配列は 1 次元だけです（GLSL ES 3.10 以降では配列の配列が使えます）。配列の範囲外を読み書きした場合の結果は保証されないので、添字の範囲に注意してください。
