用語集
======

本資料で使用した用語を五十音順に並べ、英字で始まる用語は最後にまとめています。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 用語
     - 意味
   * - エッジ
     - ノードとノードを結ぶ線。辺とも呼びます。
   * - クラスター
     - 名前が ``cluster`` で始まるサブグラフ。所属するノードがまとめて配置され、枠で囲んで描かれます（8 章）。
   * - グラフ
     - ノードとエッジからなる図。本資料では、データの値を表す棒グラフなどではなく、この意味で使います。
   * - サブグラフ
     - グラフの中のノードやエッジをまとめたグループ。属性の適用範囲の限定や、配置の制約の指定に使います（8 章）。
   * - 属性
     - グラフ、ノード、エッジの見た目や配置を指定する名前と値の組（5 章）。
   * - 段（ランク）
     - dot がノードを並べる層。有向グラフでは、エッジの始点が終点より上の段に置かれます（7 章）。
   * - ノード
     - グラフを構成する点。頂点とも呼びます。図では、楕円や箱などの形で描かれます。
   * - ポート
     - エッジをつなぐノードの位置。方角や、record シェイプのフィールド、HTML 風ラベルのセルで指定します（7 章）。
   * - 無向グラフ
     - エッジに向きがないグラフ。DOT では ``graph`` で記述し、エッジを ``--`` で書きます（4 章）。
   * - 有向グラフ
     - エッジに向きがあるグラフ。DOT では ``digraph`` で記述し、エッジを ``->`` で書きます（4 章）。
   * - ラベル
     - ノードやエッジに表示する文字（6 章）。
   * - レイアウトエンジン
     - ノードの配置とエッジの経路を計算するプログラム。dot、neato、fdp などがあります（9 章）。
   * - DOT
     - Graphviz でグラフを記述するための言語。また、その言語で書かれたファイル（4 章）。
   * - HTML 風ラベル
     - HTML に似たタグで記述するラベル。表形式のノードを作れます（6 章）。
   * - ID
     - ノードやグラフの名前、属性の値などに使う文字列（4 章）。
   * - record シェイプ
     - ラベルを ``|`` で区切って、ノードを複数のフィールドに分割する形（6 章）。
