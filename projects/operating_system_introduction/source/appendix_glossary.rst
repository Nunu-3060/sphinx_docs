用語集
======

本書に登場する主な用語をまとめます。英字で始まる用語を先に、その後に五十音順に並べています。

.. glossary::

   ABI
      Application Binary Interface の略です。関数の呼び出し規約、データの配置、実行ファイルの形式など、機械語のレベルでのプログラム同士の取り決めです。

   API
      Application Programming Interface の略です。プログラムが OS やライブラリの機能を使うためのインターフェースです。UNIX 系 OS の POSIX、Windows の Win32 API などがあります。

   ASLR
      Address Space Layout Randomization の略です。プログラムやライブラリ、スタック、ヒープを置くアドレスを起動のたびにランダムに変え、攻撃を難しくする防御機構です。

   cgroup
      Linux カーネルの機能で、プロセスのグループごとに CPU 時間やメモリなどの資源の使用量を制限、計測します。コンテナの実現に使われます。

   DEP
      Data Execution Prevention の略です。データを置くメモリのページを実行禁止にし、データとして送り込まれた機械語のコードの実行を防ぐ防御機構です。

   DMA
      Direct Memory Access の略です。CPU を介さずに、入出力装置とメモリの間で直接データを転送する方式です。

   I/O 多重化
      多数のファイルディスクリプタのうち、読み書きできる状態になったものを 1 回の待ちでまとめて知る方式です。``select``、``epoll``、``kqueue`` などのシステムコールで実現されます。

   inode
      UNIX 系 OS のファイルシステムで、ファイル 1 つにつき 1 つある管理用のデータ構造です。ファイルのメタデータとデータの位置を記録しますが、ファイル名は含みません。

   MMU
      Memory Management Unit の略です。CPU がメモリにアクセスするたびに、論理アドレスを物理アドレスに変換するハードウェアです。

   namespace
      Linux カーネルの機能で、プロセス ID、ファイルシステムのマウント、ネットワークなど、プロセスから見えるシステムの資源をグループごとに分離します。コンテナの実現に使われます。

   OOM Killer
      Linux で、物理メモリとスワップ領域が不足したときに、プロセスを選んで強制終了させ、メモリを空ける仕組みです。

   PCB
      Process Control Block（プロセス制御ブロック）の略です。カーネルがプロセスごとに持つ、プロセスの状態やレジスタの値、資源の情報などを記録したデータ構造です。

   POSIX
      Portable Operating System Interface の略です。UNIX 系 OS の API などを標準化した規格です。

   TLB
      Translation Lookaside Buffer の略です。最近使ったページ番号とフレーム番号の対応を保存しておく、アドレス変換用の高速なキャッシュです。

   アクセス制御
      誰が、どの資源に、どの操作を行えるかを決める仕組みです。所有者が決める任意アクセス制御（DAC）と、システム全体の方針で決める強制アクセス制御（MAC）があります。

   アドレス空間
      プロセスから見えるメモリのアドレスの範囲です。プロセスごとに独立しており、他のプロセスのアドレス空間には直接アクセスできません。

   カーネル
      OS の中核部分で、ハードウェアを直接管理し、プロセス管理、メモリ管理、ファイルシステム、デバイスドライバなどの機能を提供します。

   カーネルモード
      CPU の動作モードの 1 つで、すべての命令を実行でき、すべてのメモリと装置にアクセスできます。特権モードとも呼ばれます。カーネルはこのモードで動きます。

   仮想記憶
      使われていないページをストレージに置くことで、物理メモリよりも大きなメモリがあるようにプロセスに見せる仕組みです。

   競合状態
      複数のスレッドやプロセスが共有データを読み書きするとき、実行のタイミングによって結果が変わってしまう状況です。

   クリティカルセクション
      共有データにアクセスするコードのうち、同時に複数のスレッドが実行してはならない部分です。

   コピーオンライト
      データの複製を、実際に書き込みが行われるまで遅らせる方式です。``fork`` によるメモリの複製や、一部のファイルシステムで使われます。

   コンテキストスイッチ
      CPU で実行するスレッドを切り替える操作です。実行中のスレッドの状態を保存し、次に実行するスレッドの状態を復元します。

   コンテナ
      1 つのカーネルを共有したまま、プロセスのグループごとに隔離された実行環境を作る技術です。

   サンドボックス
      プログラムを、ほかの部分から隔離された限られた環境に閉じ込めて実行する仕組みです。

   シェル
      利用者が入力したコマンドを解釈して実行するプログラムです。bash、zsh、PowerShell などがあります。

   システムコール
      アプリケーションがカーネルに処理を依頼するための仕組みです。ユーザーモードからカーネルモードへの切り替えを伴います。

   ジャーナリング
      ファイルシステムを書き換える前に変更内容をジャーナルに記録しておき、クラッシュの後でも整合性を保てるようにする方式です。

   スケジューラ
      どのスレッドに、いつ、どれだけの時間 CPU を割り当てるかを決める、カーネルの部分です。

   スラッシング
      プロセスのワーキングセットの合計が物理メモリに収まらず、ページの読み書きにほとんどの時間を費やして処理が進まなくなる状態です。

   スレッド
      プロセスの中の処理の流れです。同じプロセスのスレッドは、アドレス空間や開いているファイルを共有します。

   セマフォ
      0 以上の整数のカウンタを持つ同期機構です。同時に資源を使えるスレッドの数を制限するのに使います。

   ゾンビプロセス
      UNIX 系 OS で、終了したものの、親プロセスに終了ステータスをまだ受け取られていないプロセスです。

   タイムシェアリング
      CPU の時間を短く区切って複数の利用者やプログラムに順に割り当て、多数の利用者が同時に対話的に計算機を使えるようにする方式です。

   デッドロック
      複数のスレッドが、互いに相手が持っている資源の解放を待ち続け、どのスレッドも先に進めなくなる状態です。

   デバイスドライバ
      特定の入出力装置を操作するためのプログラムです。装置ごとの違いを吸収し、OS の他の部分に共通のインターフェースを提供します。

   排他制御
      クリティカルセクションを、同時に 1 つのスレッドしか実行できないようにする制御です。相互排除とも呼ばれます。

   ハイパーバイザー
      仮想マシンを作り、管理するソフトウェアです。ハードウェアの上で直接動くタイプ 1 と、通常の OS の上で動くタイプ 2 があります。

   バッチ処理
      複数のジョブをまとめて計算機に読み込ませ、利用者とのやり取りなしに順に実行する方式です。

   ファイルシステム
      ストレージ装置のブロックの集まりの上に、ファイルとディレクトリを実現するためのデータ構造と、それを扱うソフトウェアです。

   ファイルディスクリプタ
      UNIX 系 OS で、プロセスが開いているファイルやソケットなどを指す小さな整数です。Windows ではハンドルが同じ役割を果たします。

   プリエンプション
      実行中のスレッドから、OS が強制的に CPU を取り上げることです。横取りとも呼ばれます。

   プロセス
      実行中のプログラムです。独立したアドレス空間、レジスタの値、開いているファイルなどの資源をまとめた単位です。

   ページ
      ページングで、論理アドレス空間を分割する固定の大きさのブロックです。多くの場合 4 KiB です。物理メモリ側のブロックはページフレームと呼びます。

   ページキャッシュ
      ファイルの内容をメモリに保持しておき、ストレージ装置へのアクセスを減らす OS のキャッシュです。

   ページテーブル
      プロセスごとに用意される、ページ番号からフレーム番号への対応を記録した表です。

   ページフォールト
      ページテーブルで物理メモリ上にないとされているページや、アクセスが許されていないページにアクセスしたときに発生する例外です。

   マルチプログラミング
      メモリに複数のプログラムを置き、あるプログラムが入出力を待っている間に別のプログラムに CPU を使わせる方式です。

   ミューテックス
      排他制御のための基本的な同期機構で、ロックとも呼ばれます。同時に 1 つのスレッドだけが取得できます。

   メモリマップトファイル
      ファイルの内容をプロセスのアドレス空間に対応付け、メモリへのアクセスとしてファイルを読み書きする仕組みです。

   ユーザーモード
      CPU の動作モードの 1 つで、装置の操作などの危険な操作が禁止されています。アプリケーションはこのモードで動きます。

   ユーザーランド
      OS のうち、カーネル以外の部分です。ユーザー空間とも呼ばれます。シェル、ライブラリ、各種のコマンドなどが含まれます。

   ラウンドロビン
      実行可能なプロセスに、タイムクォンタムと呼ばれる一定の時間ずつ順番に CPU を割り当てるスケジューリングの方式です。

   リアルタイム OS
      処理を決められた時間内に完了することを保証することを重視した OS です。組込み機器などで使われます。

   ワーキングセット
      プロセスが一定の期間にアクセスするページの集合です。
