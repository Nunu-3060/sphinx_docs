推定
====

この章では、標本から母集団の平均値（**母平均**）を推定する方法を学びます。1 つの値で推定する点推定と、幅を持たせて推定する区間推定を扱います。

.. _estimation-point:

点推定
------

母平均や母分散などの母集団の性質を表す値を\ **母数**\ といいます。母数を 1 つの値で推定することを\ **点推定**、推定に使う統計量を\ **推定量**\ といいます。

推定量の期待値が母数に一致する性質を\ **不偏性**\ といい、不偏性を持つ推定量を\ **不偏推定量**\ といいます。:doc:`sampling_distribution`\ で見たように :math:`E[\bar{X}] = \mu` であるため、標本平均は母平均の不偏推定量です。

母分散 :math:`\sigma^2` については、不偏分散 :math:`u^2` が不偏推定量です（:math:`E[u^2] = \sigma^2`）。一方、標本分散 :math:`s^2` の期待値は :math:`\frac{n - 1}{n} \sigma^2` であり、母分散より小さくなります。これは、偏差を計算するときに母平均 :math:`\mu` の代わりに標本平均 :math:`\bar{x}` を使っているためです。:math:`\bar{x}` は標本のデータの中心にあるため、標本のデータからの距離は :math:`\mu` からの距離より平均的に小さくなります。:math:`n` ではなく :math:`n - 1` で割ることで、この偏りを補正します。

区間推定
--------

点推定の値は、標本によって変わるため、母数にちょうど一致することはまずありません。そこで、「母数はこの範囲にあると考えられる」という区間を求めます。これを\ **区間推定**\ といい、求めた区間を\ **信頼区間**\ といいます。信頼区間を求める方法が母数を含む区間を作る確率を\ **信頼係数**\ といい、95 % がよく使われます。

母分散が既知の場合
^^^^^^^^^^^^^^^^^^

母集団が正規分布に従う場合、または標本の大きさ :math:`n` が大きい場合は、中心極限定理により、標本平均を標準化した値

.. math::

   Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}

は、標準正規分布に従うとみなせます。標準正規分布では :math:`P(-1.96 \le Z \le 1.96) = 0.95` であるため、これを :math:`\mu` について解くと、母平均の 95 % 信頼区間が得られます。

.. math::

   \bar{x} - 1.96 \frac{\sigma}{\sqrt{n}} \le \mu \le \bar{x} + 1.96 \frac{\sigma}{\sqrt{n}}

母分散が未知の場合
^^^^^^^^^^^^^^^^^^

実際には、母分散 :math:`\sigma^2` がわかっていることはほとんどありません。そこで、:math:`\sigma` の代わりに不偏分散の平方根 :math:`u` を使います。母集団が正規分布に従うとき、次の統計量 :math:`T` は自由度 :math:`n - 1` の **t 分布**\ に従います。

.. math::

   T = \frac{\bar{X} - \mu}{u / \sqrt{n}}

t 分布は、標準正規分布と同じく 0 を中心とした左右対称の分布ですが、標準正規分布より裾が厚い分布です。:math:`\sigma` を推定値 :math:`u` で置き換えたことによる不確かさの分だけ、ばらつきが大きくなるためです。自由度が大きくなるほど、t 分布は標準正規分布に近づきます。

自由度 :math:`n - 1` の t 分布で上側の確率が 0.025 になる値を :math:`t_{0.025}(n - 1)` と書くと、母平均の 95 % 信頼区間は次のようになります。

.. math::

   \bar{x} - t_{0.025}(n - 1) \frac{u}{\sqrt{n}} \le \mu \le \bar{x} + t_{0.025}(n - 1) \frac{u}{\sqrt{n}}

:math:`u / \sqrt{n}` は、標準誤差 :math:`\sigma / \sqrt{n}` の推定値です。母集団が正規分布に従わない場合でも、:math:`n` が十分に大きければ、この信頼区間を近似的に使えます。

信頼区間の解釈
^^^^^^^^^^^^^^

95 % 信頼区間は、「母平均が 95 % の確率でこの区間に入る」という意味ではありません。母平均は決まった 1 つの値であり、確率的に変わるのは標本から計算した区間のほうです。正しくは、「同じ方法で標本の取り出しと区間の計算を何度も繰り返すと、そのうち約 95 % の区間が母平均を含む」という意味です。

結果の読み方
------------

* A クラスの数学の点数の母平均の 95 % 信頼区間は、47.71 点から 56.29 点です。定義どおりに計算した区間と、SciPy で計算した区間は一致しています。
* 仮に母標準偏差が 15 とわかっている場合の信頼区間は、t 分布を使った区間よりわずかに狭くなっています。これは、:math:`t_{0.025}(49) \approx 2.01` が 1.96 より大きいことと、この標本では :math:`u = 15.10` が 15 よりわずかに大きいことによります。
* シミュレーションでは、1,000 個の信頼区間のうち 95.2 % が母平均 50 を含んでいました。これは、信頼係数 95 % の意味のとおりの結果です。

信頼区間の幅は、標準誤差 :math:`u / \sqrt{n}` に比例します。そのため、標本の大きさを 4 倍にすると、信頼区間の幅はおよそ半分になります。
