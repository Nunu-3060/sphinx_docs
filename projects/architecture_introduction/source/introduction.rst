はじめに
========

本資料の目的
------------

プログラムを書き始めたばかりのころは、「動くこと」が最大の目標です。しかし、同じプログラムを何か月も使い続け、機能を追加したり不具合を直したりしていると、別の問題に直面します。1 か所を直すと別の場所が壊れる、どこを直せばよいのか分からない、テストを書こうとしても書けない、といった問題です。

これらの問題の多くは、コードの **設計** に原因があります。本資料の目的は、「動くコード」から「変更しやすいコード」へ進むための考え方と技法を身に付けることです。原則やパターンの名前を覚えることよりも、「この書き方は何が良くて、何が悪いのか」を自分で判断できるようになることを重視します。

対象読者
--------

本資料は、次のような方を対象としています。

* Python の基本的な文法（関数、クラス、モジュール、例外、型ヒント）を理解している方
* 数百行程度のプログラムを書いた経験があり、コードが大きくなるにつれて扱いにくくなった経験のある方
* 設計の原則やデザインパターンという言葉は聞いたことがあるが、実際のコードにどう生かせばよいのか分からない方

Python 以外の言語の経験がある方にも読めるように書いていますが、説明には Python に特有の機能（``dataclass``、``typing.Protocol``、デコレーターなど）も使います。

本資料の構成
------------

本資料は、4 つの部と付録で構成しています。小さな単位（関数）から大きな単位（システム全体）へ順に進み、前の章の考え方を次の章で使えるように並べています。

.. list-table::
   :header-rows: 1
   :widths: 20 30 50

   * - 部
     - 章
     - 内容
   * - 第 1 部　設計の考え方
     - :doc:`what_is_design`、:doc:`metrics`
     - 設計の目的と、設計の良し悪しを判断する基準を説明します。以降の章では、この基準を使って書き換えの効果を説明します。
   * - 第 2 部　コードレベルの設計
     - :doc:`functions`、:doc:`data`、:doc:`oop`、:doc:`solid`、:doc:`patterns`
     - 関数、データ、クラスの設計と、設計の原則、デザインパターンを説明します。
   * - 第 3 部　モジュールとアーキテクチャ
     - :doc:`modules`、:doc:`dependency`、:doc:`architecture`、:doc:`domain`
     - モジュールの分け方と依存関係の管理、システム全体の構成（アーキテクチャ）、業務の知識をコードに表す方法を説明します。
   * - 第 4 部　設計を支える実践
     - :doc:`testing`、:doc:`refactoring`、:doc:`documentation`、:doc:`exercise`
     - テスト、リファクタリング、設計の記録を説明し、最後に総合演習で全体を振り返ります。
   * - 付録
     - :doc:`checklist`、:doc:`glossary`、:doc:`references`、:doc:`examples`
     - 設計レビューで使う確認項目、用語集、参考文献、サンプルコードの一覧です。

本資料の読み方
--------------

初めて読む場合は、第 1 部と第 2 部を順に読むことをお勧めします。第 3 部と第 4 部は、第 2 部の内容を前提にしています。第 3 部の各章は比較的独立しているので、必要な章から読んでも構いません。

各章では、同じ処理を「悪い例」と「良い例」の 2 通りで実装したサンプルコードを示します。「悪い例」は、動作はするものの変更しにくい、よく見かける書き方です。どちらも実際に実行できるので、手元で動かし、書き換えて、違いを確かめてください。

分からない用語は :doc:`glossary` を参照してください。

.. note::

   設計に唯一の正解はありません。本資料で「良い例」として示すのは、多くの場合に有効な考え方の一例です。プログラムの規模や寿命、チームの状況によっては、「悪い例」の書き方で十分なこともあります。この判断の基準は :doc:`what_is_design` で説明します。

動作環境
--------

サンプルコードは、次の環境で動作を確認しています。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - ソフトウェア
     - バージョン
   * - Python
     - 3.14.6（3.10 以降で動作するように書いています）
   * - flake8
     - 7.4.1
   * - mypy
     - 2.3.1

サンプルコードは Python の標準ライブラリだけを使うので、追加のパッケージをインストールする必要はありません。flake8 と mypy は、サンプルコードの検査に使っているツールです。サンプルコードを実行するだけであれば必要ありません。

サンプルコードの入手と実行
--------------------------

サンプルコードは、各章の本文にあるリンクから 1 ファイルずつダウンロードできます。すべてのサンプルコードの全文、それらをまとめた zip ファイル、実行方法は :doc:`examples` を参照してください。
