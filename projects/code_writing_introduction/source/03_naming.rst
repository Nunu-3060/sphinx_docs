==========================================
名前の付け方
==========================================

変数、関数、クラスなどの名前は、コードを読む人が最初に目にする情報である。適切な名前が付いていれば、中身を細かく読まなくても何をしているのかが分かる。逆に、名前が不適切だと、読む人は中身をすべて追わなければならない。

名前で役割を伝える
==========================================

名前は、それが「何であるか」「何をするか」を表すように付ける。

.. list-table:: 名前の付け方の目安
   :header-rows: 1
   :widths: 25 35 40

   * - 対象
     - 付け方
     - 例
   * - 変数
     - 中に入っている値を表す名詞にする。
     - ``score``、``user_name``、``total_price``
   * - リストなどの集まり
     - 複数形にする。
     - ``scores``、``users``
   * - 関数
     - 処理の内容を表す動詞から始める。
     - ``count_passed``、``calculate_total``、``load_config``
   * - 真偽値（``True`` か ``False``）
     - ``is_``、``has_``、``can_`` などで始め、「はい」か「いいえ」で答えられる形にする。
     - ``is_perfect``、``has_permission``、``can_edit``

リストを複数形にしておくと、``for score in scores:`` のように、1 つずつ取り出す変数に単数形を使える。これにより「集まり」と「その中の 1 つ」の区別が付きやすくなる。

具体的な名前を選ぶ
==========================================

``data``、``info``、``value``、``tmp``、``result`` のような名前は、どんな値にも当てはまってしまうため、ほとんど情報を持たない。できるだけ具体的な名前を選ぶ。

.. code-block:: python
   :linenos:
   :caption: 悪い例

   data = load("users.csv")
   tmp = data[0]

.. code-block:: python
   :linenos:
   :caption: 良い例

   users = load("users.csv")
   first_user = users[0]

単位や種類を名前に含める
==========================================

数値に単位がある場合は、名前に単位を含めると誤解を防げる。

.. code-block:: python
   :linenos:
   :caption: 悪い例

   timeout = 30     # 秒なのかミリ秒なのか分からない
   size = 2048      # バイトなのかキロバイトなのか分からない

.. code-block:: python
   :linenos:
   :caption: 良い例

   timeout_seconds = 30
   file_size_bytes = 2048

省略しすぎない
==========================================

``usr``、``cnt``、``calc_ttl_prc`` のような省略形は、書く人にとっては短くて便利だが、読む人には意味が伝わりにくい。名前は多少長くなっても、省略せずに書く方がよい。

ただし、広く知られた略語（``id``、``url``、``html`` など）は使ってよい。また、数行で終わる短いループの中だけで使う変数であれば、``i`` のような短い名前でも問題にならないことが多い。目安として、変数を使う範囲が広いほど、説明的な名前を付ける。

マジックナンバーを定数にする
==========================================

コードの中に直接書かれた数値は、その意味が読み取れないことが多い。意味のある数値には名前を付けて :term:`定数` にする。Python には変更できない定数の仕組みは無いが、すべて大文字の名前を付けて「この値は変更しない」ことを示す習慣がある。

.. code-block:: python
   :linenos:
   :caption: 悪い例

   if len(password) < 8:
       print("パスワードが短すぎる")

.. code-block:: python
   :linenos:
   :caption: 良い例

   MIN_PASSWORD_LENGTH = 8

   if len(password) < MIN_PASSWORD_LENGTH:
       print("パスワードが短すぎる")

定数にすると、次の利点がある。

* 数値の意味が名前から分かる。
* 同じ数値を複数の場所で使っていても、値を変更するときは 1 か所を直すだけで済む。

なお、``0`` や ``1`` のように意味が明らかな数値まで、すべて定数にする必要はない。

Python の命名規則
==========================================

Python には、コーディングスタイルの指針である :term:`PEP 8` があり、名前の書き方についても次のように定めている。

.. list-table:: PEP 8 の主な命名規則
   :header-rows: 1
   :widths: 25 35 40

   * - 対象
     - 書き方
     - 例
   * - 変数、関数
     - 小文字の単語を ``_`` でつなぐ（スネークケース）。
     - ``user_name``、``count_passed``
   * - 定数
     - 大文字の単語を ``_`` でつなぐ。
     - ``MAX_SIZE``、``PASSING_SCORE``
   * - クラス
     - 各単語の先頭を大文字にしてつなぐ（パスカルケース）。
     - ``Book``、``OrderStatus``

決まった書き方にそろえておくと、名前を見ただけで、それが変数なのか、定数なのか、クラスなのかが区別できる。

まとめ
==========================================

* 名前は、それが何であるか、何をするかが伝わるように付ける。
* ``data`` や ``tmp`` のようなあいまいな名前を避け、具体的な名前を選ぶ。
* 必要に応じて、単位や種類を名前に含める。
* 意味のある数値には名前を付けて定数にする。
* PEP 8 の命名規則に従う。
