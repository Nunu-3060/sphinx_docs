はじめに
========

セル・オートマトンとは
----------------------

セル・オートマトン（以下、CA と略す）は、格子状に並んだ多数の「セル」が、それぞれ有限個の状態の 1 つをとり、離散的な時刻ごとに一斉に状態を更新していく計算モデルである。各セルの次の状態は、そのセル自身とすぐ近くのセルの現在の状態だけから、全セル共通の規則によって決まる。

例として、1 列に並んだセルが白（0）か黒（1）のどちらかの状態をとり、「左右の隣のセルの状態が異なれば次の時刻に黒、同じなら白になる」という規則で更新される CA を考える。中央の 1 セルだけを黒にして時間発展させると、各時刻の配置を上から順に並べた図に、シェルピンスキー・ガスケットと呼ばれるフラクタル図形が現れる（第 4 章「\ :doc:`one_dimensional`\ 」で扱うルール 90 である）。規則は 1 行で書けるほど単純なのに、全体としては規則から直ちには予想しにくい模様が生じる。この「局所的で単純な規則から大域的で複雑な振る舞いが生まれる」という性質が、CA が多くの分野で研究されてきた主な理由である。

CA には、主に次の 3 つの側面がある。

* **計算モデル**\ ：チューリング機械と同等の計算能力を持つ CA が存在し、計算とは何か、自己増殖とは何かを考える道具として使われてきた。
* **物理・生物現象のモデル**\ ：流体、交通流、結晶成長、生物の模様など、多数の要素が局所的に相互作用する系を、微分方程式を使わずに直接シミュレーションする手法として使われる。
* **数学の対象**\ ：CA の時間発展を、無限個のセルの配置全体の上の写像（力学系）とみなして、その性質を調べることができる。

前提知識
--------

本書は次の知識を前提とする。

* Python の基本的な文法と、NumPy の配列操作の基礎
* 集合・写像・2 進数などの、大学初年級の離散数学の基礎

チューリング機械や位相空間の知識があれば第 6 章をより深く理解できるが、必須ではない。必要な用語は本文中で簡単に説明する。

サンプルコードについて
----------------------

本書のサンプルコードは Python 3.10 以降で動作し、NumPy と matplotlib を使う。各サンプルは付録の「\ :doc:`examples`\ 」から閲覧・ダウンロードできる。本文中の図の多くは、これらのサンプルコードを使って本書のビルド時に生成したものである。

各サンプルはコマンドラインから次のように実行する。

.. code-block:: console
   :linenos:

   pip install numpy matplotlib
   python elementary_ca.py 30

表記について
------------

本書では次のように表記を統一する。

* 時刻は :math:`t = 0, 1, 2, \ldots` のように 0 から数える。ライフゲームでは、慣例に従い時刻を「世代」とも呼ぶ。
* セルの状態は、特に断らない限り 0 と 1 の 2 状態とし、図では 0 を白、1 を黒（または濃い色）で示す。
* 1 次元 CA の時空図は、横軸をセルの位置、縦軸を時刻とし、上から下へ時間が進むように描く。
* 人名は原則としてカタカナで表記し、初出時に原綴りを併記する。
