セル・オートマトンの理論と歴史
==============================

本書は、セル・オートマトン（Cellular Automaton、CA）の基本的な考え方、その誕生から現在までの歴史、および計算能力・可逆性などの理論的な性質を解説する。対象読者は、Python などのプログラミングの知識を持つエンジニアと工学系の大学生である。数学的な定義は正確に示すが、定理の証明は考え方の紹介にとどめ、図と Python のサンプルコードで具体的に確かめられるようにした。
