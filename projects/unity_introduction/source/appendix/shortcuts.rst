付録 B ショートカットキー一覧
=============================

Unity Editor でよく使うショートカットキーをまとめます。macOS では、:kbd:`Ctrl` を :kbd:`Command` に、:kbd:`Alt` を :kbd:`Option` に読み替えてください。ショートカットキーは、:menuselection:`Edit --> Shortcuts` で確認、変更できます。

全般
----

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 機能
   * - :kbd:`Ctrl` + :kbd:`S`
     - シーンを保存する
   * - :kbd:`Ctrl` + :kbd:`Z`
     - 元に戻す
   * - :kbd:`Ctrl` + :kbd:`Y`
     - やり直す（macOS では :kbd:`Command` + :kbd:`Shift` + :kbd:`Z`）
   * - :kbd:`Ctrl` + :kbd:`P`
     - 再生を開始する、終了する
   * - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`P`
     - 再生を一時停止する
   * - :kbd:`Ctrl` + :kbd:`Alt` + :kbd:`P`
     - 1 フレームだけ進める

GameObject の操作
-----------------

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 機能
   * - :kbd:`Ctrl` + :kbd:`D`
     - 選択している GameObject を複製する
   * - :kbd:`Delete`
     - 選択している GameObject を削除する
   * - :kbd:`F2`
     - 選択している GameObject の名前を変更する
   * - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`N`
     - 空の GameObject を作成する
   * - :kbd:`F`
     - 選択している GameObject が Scene ビューの中央に来るように、視点を移動する

トランスフォームツール
----------------------

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - キー
     - 機能
   * - :kbd:`Q`
     - View ツール
   * - :kbd:`W`
     - Move ツール
   * - :kbd:`E`
     - Rotate ツール
   * - :kbd:`R`
     - Scale ツール
   * - :kbd:`T`
     - Rect ツール
   * - :kbd:`Y`
     - Transform ツール
   * - :kbd:`Ctrl` を押しながらドラッグ
     - 一定の間隔ごとに移動、回転、拡大縮小する
   * - :kbd:`V` を押しながらドラッグ
     - 頂点を別の GameObject の頂点に合わせる

Scene ビューの視点操作
----------------------

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - 操作
     - 機能
   * - マウスの右ボタンを押しながらドラッグ
     - 視点をその場で回転させる
   * - マウスの右ボタンを押しながら :kbd:`W`、:kbd:`A`、:kbd:`S`、:kbd:`D`、:kbd:`Q`、:kbd:`E`
     - 視点を前後、左右、上下に移動する
   * - マウスの中ボタンを押しながらドラッグ
     - 視点を平行移動する
   * - :kbd:`Alt` とマウスの左ボタンを押しながらドラッグ
     - 注目している点を中心に視点を回転させる
   * - マウスホイール
     - 視点を前後に移動する
