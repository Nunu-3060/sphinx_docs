付録 C トラブルシューティング
=============================

Unity を使い始めたときによく起きる問題と、その対処の方法をまとめます。

スクリプト
----------

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 症状
     - 原因と対処
   * - :guilabel:`Play` ボタンを押しても再生モードにならない
     - スクリプトにコンパイルエラーがあります。Console ウィンドウの赤いエラーメッセージをダブルクリックし、エラーの箇所を修正してください。すべてのエラーを直すまで再生できません。
   * - スクリプトを GameObject に付けられない
     - ファイル名とクラス名が一致していない、クラスが ``MonoBehaviour`` を継承していない、またはコンパイルエラーがある可能性があります（第 7 章）。
   * - ``Start`` や ``Update`` が呼ばれない
     - メソッド名の大文字と小文字が間違っていないか（``update`` ではなく ``Update``）、スクリプトが GameObject に付いているか、コンポーネントや GameObject が無効になっていないかを確認してください。
   * - ``NullReferenceException`` が発生する
     - 何も設定されていない変数を使っています。Inspector ウィンドウでフィールドが設定されているか、``GetComponent`` で取得しようとしたコンポーネントが実際に付いているかを確認してください（第 8 章）。
   * - スクリプトの初期値を変えたのに反映されない
     - Inspector ウィンドウで設定した値が優先されます。コンポーネントのメニュー（⋮）から :guilabel:`Reset` を選ぶか、Inspector ウィンドウで値を変更してください（第 7 章）。
   * - ``InvalidOperationException`` で、``UnityEngine.Input`` クラスを使っているという内容のエラーが出る
     - Input System を有効にしたプロジェクトで、旧方式の入力のコードを使っています。Input System の書き方に置き換えてください（第 9 章）。
   * - コードエディターでコード補完が働かない
     - :menuselection:`Edit --> Preferences` の :guilabel:`External Tools` で、使用するコードエディターが選ばれているかを確認してください。その後、同じ画面の :guilabel:`Regenerate project files` をクリックすると解決することがあります（第 3 章）。

エディター
----------

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 症状
     - 原因と対処
   * - 再生中に行った変更が消えた
     - 再生モード中の変更は、再生を終えると元に戻ります。残したい変更は、再生を終えてから行ってください（第 4 章）。
   * - ウィンドウの配置が崩れた、ウィンドウが見当たらない
     - ツールバーの :guilabel:`Layout` メニューから :guilabel:`Default` を選ぶと、初期状態に戻ります。個別のウィンドウは :menuselection:`Window --> General` から開けます（第 4 章）。
   * - マテリアルがマゼンタ（ピンク色）で表示される
     - プロジェクトのレンダーパイプラインに対応していないシェーダーを使っています。URP 用のシェーダーに変更してください（第 11 章）。
   * - アセット間の参照が切れた
     - ``.meta`` ファイルが失われた可能性があります。Assets フォルダー内のファイルの移動や名前の変更は、Project ウィンドウで行ってください（第 3 章）。

物理演算
--------

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 症状
     - 原因と対処
   * - 衝突イベントやトリガーイベントが呼ばれない
     - 両方の GameObject に Collider があり、少なくとも一方に Rigidbody が付いているかを確認してください。衝突イベントの場合は、少なくとも一方の Rigidbody の :guilabel:`Is Kinematic` が無効である必要があります。3D の Collider と 2D の Collider は互いに衝突しません（第 10 章）。
   * - 速く動く GameObject が壁をすり抜ける
     - Rigidbody の :guilabel:`Collision Detection` を :guilabel:`Continuous` などに変更してください（第 10 章）。
   * - GameObject が地面をすり抜けて落ちる
     - 地面に Collider が付いているかを確認してください。Mesh Collider を使う場合は、メッシュが正しく設定されているかも確認してください（第 10 章）。
   * - カメラで追いかけると、動きがかくつく
     - 追いかける GameObject の Rigidbody の :guilabel:`Interpolate` を :guilabel:`Interpolate` にしてください。また、カメラを動かす処理は ``LateUpdate`` に書いてください（第 10 章、第 16 章）。

UI
--

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 症状
     - 原因と対処
   * - 日本語の文字が四角形で表示される
     - TextMeshPro の既定のフォントには日本語の文字が含まれていません。日本語を含むフォントからフォントアセットを作成してください（第 12 章）。
   * - ボタンをクリックしても反応しない
     - シーンに EventSystem があるかを確認してください。また、ボタンの上に別の UI 要素が重なって、クリックを遮っていないかも確認してください（第 12 章）。

ビルド
------

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 症状
     - 原因と対処
   * - シーンを読み込もうとするとエラーになる
     - 読み込むシーンが Build Profiles ウィンドウの Scene List に登録されているかを確認してください（第 15 章）。
   * - IL2CPP でのビルドが失敗する
     - Visual Studio の「C++ によるデスクトップ開発」ワークロードがインストールされているかを確認してください（第 17 章）。
   * - ビルドが失敗し、``UnityEditor`` に関するエラーが出る
     - ``UnityEditor`` 名前空間を使うスクリプトが、``Editor`` フォルダー以外に置かれています。``Editor`` フォルダーに移動してください（第 8 章）。
   * - Web ブラウザー向けのビルドが動かない
     - ``index.html`` をファイルとして直接開いても動きません。Web サーバー経由で開いてください（第 17 章）。
