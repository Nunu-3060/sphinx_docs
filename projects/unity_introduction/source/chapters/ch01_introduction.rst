第 1 章 はじめに
================

本資料の目的
------------

本資料の目的は、Unity を初めて使う方が、ゲーム開発の基本的な流れを一通り体験し、自分で調べながら開発を進められるようになることです。具体的には、次のことができるようになることを目指します。

* Unity Editor の基本操作ができる。
* GameObject、Component、Prefab などの Unity の基本概念を説明できる。
* C# スクリプトで GameObject を動かし、入力や衝突に反応させられる。
* 物理演算、UI、サウンドなどの機能を組み合わせて、簡単な 3D ゲームを完成させられる。
* 作ったゲームを Windows などのプラットフォーム向けにビルドできる。

対象読者と前提知識
------------------

本資料は、次のような方を対象としています。

* 変数、条件分岐、繰り返し、関数（メソッド）といったプログラミングの基礎を理解している方
* Unity を使ったことがない、または少し触ったことがある程度の方

C# の経験は必須ではありません。C# 以外の言語（Python、Java、JavaScript など）の経験があれば本資料のサンプルコードを読めるように書いています。ただし、クラス、継承、ジェネリックなどの C# の文法そのものの解説は最小限にとどめています。必要に応じて、Microsoft の `C# のドキュメント <https://learn.microsoft.com/ja-jp/dotnet/csharp/>`_ を参照してください。

本資料の構成
------------

本資料は 5 部 19 章と付録で構成されています。前の章で説明した内容を使って次の章を説明するため、初めての方は第 1 章から順に読み進めてください。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 部
     - 内容
   * - 第 1 部 導入
     - Unity の概要と、開発環境の準備を説明します。
   * - 第 2 部 エディターと基本概念
     - エディターの操作、Unity の基本概念、ゲーム開発に必要な 3D 数学を説明します。
   * - 第 3 部 スクリプティング
     - C# スクリプトの書き方と、入力の扱い方を説明します。
   * - 第 4 部 ゲームを構成する機能
     - 物理演算、グラフィックス、UI、オーディオ、アニメーション、シーン管理を説明します。
   * - 第 5 部 実践
     - それまでの内容を使って簡単なゲームを作り、ビルドします。デバッグと最適化の基本、学習を続けるための情報も紹介します。

想定する環境
------------

本資料は、次の環境を想定して記述しています。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - 内容
   * - OS
     - Windows 11 または macOS
   * - Unity

表記規則
--------

本資料では、次の表記規則を用います。

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - 表記
     - 意味
   * - :menuselection:`File --> Save`
     - メニューの項目です。この例では、:guilabel:`File` メニューの :guilabel:`Save` を選ぶことを表します。
   * - :guilabel:`Play`
     - ボタンやプロパティなど、画面に表示される名前です。
   * - :kbd:`Ctrl` + :kbd:`S`
     - キーボードの操作です。この例では、:kbd:`Ctrl` キーを押しながら :kbd:`S` キーを押すことを表します。
   * - ``Update``
     - C# のコード、クラス名、メソッド名、ファイル名などです。

Unity Editor の画面は英語で表示されるため、メニュー、ウィンドウ、ボタン、コンポーネントの名前は、画面の表示に合わせて英語で記載します。例えば、Inspector ウィンドウ、Rigidbody コンポーネントのように表記します。

ショートカットキーは Windows の表記で記載します。macOS では、:kbd:`Ctrl` を :kbd:`Command` に、:kbd:`Alt` を :kbd:`Option` に読み替えてください。

サンプルコード
--------------

本資料に掲載している C# のサンプルコードは、各コードの下にあるリンクから個別にダウンロードできます。すべてのサンプルコードをまとめてダウンロードする場合は、次のリンクを使用してください。

* :download:`サンプルコード一式（zip 形式） <../_generated/unity_introduction_examples.zip>`

サンプルコードは、`Microsoft の C# のコーディング規則 <https://learn.microsoft.com/ja-jp/dotnet/csharp/fundamentals/coding-style/coding-conventions>`_ に沿って記述しています。zip ファイルに含まれる ``.editorconfig`` は、この規則をコードエディターに設定するためのファイルです。主な規則は次のとおりです。

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - 対象
     - 規則
   * - クラス、メソッド、プロパティ、イベント、定数
     - PascalCase（例：``PlayerController``、``MaxSpeed``）
   * - private フィールド
     - 先頭に ``_`` を付けた camelCase（例：``_moveSpeed``）
   * - ローカル変数、引数
     - camelCase（例：``moveInput``）
   * - 波かっこ
     - 改行してから書き、1 行の if 文でも省略しない

サンプルコードは、章ごとに名前空間を分けています（例：``UnityIntroduction.Chapter07``。第 16 章は ``UnityIntroduction.RollABall``）。そのため、複数の章のサンプルコードを 1 つのプロジェクトに入れても、クラス名が衝突することはありません。
