第 4 章 エディターの基本操作
============================

主要なウィンドウ
----------------

Unity Editor の画面は、複数のウィンドウで構成されています。初期状態では、次のウィンドウが表示されています。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - ウィンドウ
     - 役割
   * - Scene ビュー
     - シーン（ゲームの舞台となる空間）を表示し、GameObject を配置、移動、回転、拡大縮小するためのウィンドウです。
   * - Game ビュー
     - カメラから見たゲームの画面を表示します。再生中は、プレイヤーが実際に見る画面になります。
   * - Hierarchy ウィンドウ
     - 現在開いているシーンにある GameObject を、親子関係がわかる階層構造で一覧表示します。
   * - Inspector ウィンドウ
     - 選択している GameObject やアセットの詳細を表示し、設定を変更するためのウィンドウです。
   * - Project ウィンドウ
     - プロジェクトの Assets フォルダーと Packages フォルダーの中身を表示します。
   * - Console ウィンドウ
     - ログ、警告、エラーのメッセージを表示します。スクリプトのコンパイルエラーもここに表示されます。

ウィンドウは、タブをドラッグして好きな位置に移動したり、別のウィンドウとタブでまとめたりできます。閉じてしまったウィンドウは、:menuselection:`Window --> General` から開き直せます。

.. tip::

   初めのうちは、Console ウィンドウを常に表示しておくことをお勧めします。スクリプトの誤りなど、問題が起きたときの手がかりが表示されます。

Scene ビューの視点操作
----------------------

Scene ビューでは、次の操作で視点を動かします。

.. list-table::
   :header-rows: 1
   :widths: 45 55

   * - 操作
     - 動作
   * - マウスの右ボタンを押しながらドラッグ
     - 視点をその場で回転させます。
   * - マウスの右ボタンを押しながら :kbd:`W`、:kbd:`A`、:kbd:`S`、:kbd:`D`、:kbd:`Q`、:kbd:`E`
     - 前後、左右、上下に視点を移動します（フライスルーモード）。:kbd:`Shift` を押すと速く移動します。
   * - マウスの中ボタンを押しながらドラッグ
     - 視点を上下左右に平行移動します。
   * - :kbd:`Alt` とマウスの左ボタンを押しながらドラッグ
     - 注目している点を中心に、視点を回転させます。
   * - マウスホイール
     - 視点を前後に移動し、拡大、縮小します。
   * - :kbd:`F`\ （GameObject を選択した状態で）
     - 選択している GameObject が画面の中央に来るように視点を移動します。

Scene ビューの右上にある軸の表示（シーンギズモ）をクリックすると、真上や真横などの決まった方向からの視点に切り替えられます。

トランスフォームツール
----------------------

GameObject の位置、回転、大きさは、Scene ビューのツールバーにあるトランスフォームツールで変更します。

.. list-table::
   :header-rows: 1
   :widths: 20 20 60

   * - ツール
     - キー
     - 機能
   * - View
     - :kbd:`Q`
     - 視点を平行移動します。GameObject は選択されません。
   * - Move
     - :kbd:`W`
     - GameObject を移動します。矢印をドラッグすると、その軸の方向だけに移動します。
   * - Rotate
     - :kbd:`E`
     - GameObject を回転させます。
   * - Scale
     - :kbd:`R`
     - GameObject の大きさを変えます。
   * - Rect
     - :kbd:`T`
     - 2D の要素や UI の位置と大きさを、長方形の枠で変更します。
   * - Transform
     - :kbd:`Y`
     - 移動、回転、拡大縮小をまとめて行います。

Move ツールで移動するときに :kbd:`Ctrl` を押しながらドラッグすると、一定の間隔ごとに移動できます（グリッドスナップ）。また、:kbd:`V` を押しながらドラッグすると、GameObject の頂点を別の GameObject の頂点に合わせられます（頂点スナップ）。

数値で正確に指定したい場合は、Inspector ウィンドウの Transform コンポーネントに値を入力します。

GameObject の作成と操作
-----------------------

簡単な GameObject を作成して、ここまでの操作を試してみましょう。

#. :menuselection:`GameObject --> 3D Object --> Cube` を選びます。シーンに立方体が追加され、Hierarchy ウィンドウに :guilabel:`Cube` が表示されます。
#. Hierarchy ウィンドウで :guilabel:`Cube` を選び、Scene ビューで :kbd:`F` キーを押します。立方体が画面の中央に表示されます。
#. :kbd:`W` キーを押して Move ツールに切り替え、矢印をドラッグして立方体を移動します。
#. Inspector ウィンドウの Transform コンポーネントで、:guilabel:`Position` の値がすべて 0 になるように入力します。

Hierarchy ウィンドウでは、次の操作もよく使います。

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - 操作
     - 方法
   * - 名前の変更
     - GameObject を選んで :kbd:`F2` キーを押します。
   * - 複製
     - GameObject を選んで :kbd:`Ctrl` + :kbd:`D` を押します。
   * - 削除
     - GameObject を選んで :kbd:`Delete` キーを押します。
   * - 親子関係の設定
     - GameObject を別の GameObject の上にドラッグします。
   * - 元に戻す、やり直す
     - :kbd:`Ctrl` + :kbd:`Z` で元に戻し、:kbd:`Ctrl` + :kbd:`Y` でやり直します。macOS では、やり直しは :kbd:`Command` + :kbd:`Shift` + :kbd:`Z` です。

再生モード
----------

ツールバーの中央にある :guilabel:`Play` ボタン（▶）をクリックすると、再生モードになり、Game ビューでゲームが動き始めます。もう一度クリックすると、再生モードが終わります。:guilabel:`Pause` ボタンで一時停止、:guilabel:`Step` ボタンで 1 フレームずつ進めることもできます。

.. warning::

   再生モード中に Inspector ウィンドウなどで変更した値は、再生モードを終えると元に戻ります。これは、値を試しに変えて動作を確認するためのしくみです。残したい値は、再生モードを終えてから入力し直してください。

   再生モード中であることに気付かずに作業してしまうのを防ぐため、再生モード中の画面の色を変えておくと便利です。:menuselection:`Edit --> Preferences` の :guilabel:`Colors` にある :guilabel:`Playmode tint` で色を設定できます。

保存
----

シーンの変更は、:menuselection:`File --> Save`\ （:kbd:`Ctrl` + :kbd:`S`）で保存します。シーンに未保存の変更があると、Hierarchy ウィンドウのシーン名の横に ``*`` が表示されます。

Unity Editor は自動では保存しないため、こまめに保存する習慣を付けてください。

レイアウトの変更と保存
----------------------

ウィンドウの配置（レイアウト）は、ツールバーの右端にある :guilabel:`Layout` メニューから切り替えられます。:guilabel:`2 by 3` や :guilabel:`Tall` など、あらかじめ用意されたレイアウトを選べるほか、自分で並べたレイアウトを :guilabel:`Save Layout` で名前を付けて保存することもできます。ウィンドウの配置がわからなくなった場合は、:guilabel:`Default` を選ぶと初期状態に戻ります。
