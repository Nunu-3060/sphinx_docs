実装概要
========

``script`` ディレクトリには、飛砂のシミュレーション本体と、それを Tkinter で可視化・操作するための GUI が実装されています。実装は役割ごとに次の4つの層に整理されており、本ドキュメントでも同じ区分で解説します。

.. list-table::
   :header-rows: 1

   * - 層
     - モジュール
     - 役割
   * - モデル層
     - ``Sand``
     - 高さ場の更新ロジック本体
   * - 可視化層
     - ``SandImage``
     - 高さ場を画像に変換する
   * - GUI 部品層
     - ``TkWidget`` / ``FrameSand``
     - 汎用的な Tkinter 部品と、それを使ったアニメーション表示
   * - アプリケーション層
     - ``SandGUI``
     - 上記すべてを組み合わせたアプリケーション本体

依存関係
--------

上の層は下の層を利用しますが、逆方向の依存はありません。

.. list-table::
   :header-rows: 1

   * - モジュール
     - 依存先
     - 関係
   * - ``SandGUI``
     - ``TkWidget`` の部品 / ``FrameSand``
     - 利用(部品を組み立ててアプリケーションを構成する)
   * - ``FrameSand``
     - ``SandImage``
     - 保持(インスタンスを1つ持つコンポジション)
   * - ``SandImage``
     - ``Sand``
     - 継承(高さ場の計算はそのまま利用する)
   * - ``TkWidget``
     - なし
     - ``Sand`` / ``SandImage`` に依存しない独立した部品

なお、GUI を介さず直接シミュレーションを実行するバッチスクリプト ``sand_fullHD_0000`` は、上記の層構成には含まれない独立したエントリポイントです。

--------------
