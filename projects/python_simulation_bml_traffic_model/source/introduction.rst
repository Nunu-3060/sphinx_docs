はじめに
========

本資料の目的
============

本資料は、 Biham-Middleton-Levine 交通モデル（以下、 BML モデルと表記します）の理論と、本プロジェクトが提供する Python 実装の両方を解説することを目的とします。理論の説明にとどまらず、実装の詳細や GUI アプリケーションの操作方法まで含めて解説します。

対象読者
========

本資料は、以下のような方を対象読者として想定しています。

* セルオートマトンによる交通流モデルに興味がある方
* Python と numpy を用いたシミュレーション実装の例を知りたい方
* 本プロジェクトの GUI アプリケーションの使い方を知りたい方

BML モデルとは
==============

BML モデルは、 Ofer Biham 、 Alan Middleton 、 David Levine の 3 名が 1992 年に発表した、格子上を移動する車によって交通流を表現する単純なセルオートマトンモデルです（参考文献は :doc:`appendix` を参照してください）。正方格子上に東西方向・南北方向へ移動する 2 種類の車を配置し、単純な更新規則を繰り返し適用することで、車の密度に応じて「自由流」と「渋滞」という 2 つの定常状態が現れることを示したモデルとして知られています。単純な規則から複雑な集団的挙動が生まれる例として、セルオートマトンや交通流理論の入門的な題材としてよく取り上げられます。

本資料の構成
============

本資料は以下の章から構成されます。

* :doc:`theory` では、 BML モデルの理論的な定義について説明します。
* :doc:`implementation` では、本プロジェクトにおける Python 実装について解説します。
* :doc:`usage` では、 GUI アプリケーションの実行方法・操作方法を説明します。
* :doc:`results` では、シミュレーション例とその考察を示します。
* :doc:`summary` では、本資料のまとめと発展的な話題を紹介します。
* :doc:`appendix` では、ソースコード一覧と参考文献を掲載します。
