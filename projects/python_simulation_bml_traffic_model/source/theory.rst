====================
BML 交通モデルの理論
====================

格子と境界条件
==============

BML モデルでは、幅 :math:`W` ・高さ :math:`H` の 2 次元正方格子を用います。格子の各セルは、行番号 :math:`i` （ :math:`0 \leq i < H` ）と列番号 :math:`j` （ :math:`0 \leq j < W` ）の組で表されます。本資料では、行番号は格子の北端から南端に向かって、列番号は西端から東端に向かって増加するものとします。

格子の四辺は周期境界条件（トーラス状の境界条件）でつながっており、最も北の行から北へ 1 マス進むと最も南の行に、最も東の列から東へ 1 マス進むと最も西の列に、それぞれつながります。

車の初期配置と密度
==================

格子の各セルは、空きセルまたは車のいずれかの状態を取ります。車には、南北方向に移動する車と、東西方向に移動する車の 2 種類があります。それぞれのセルには、密度パラメータ :math:`p` （ :math:`0 \leq p \leq 1` ）を用いて、以下の確率で初期状態が割り当てられます。

.. math::

   P(\text{空きセル}) = 1 - p, \qquad P(\text{南北方向の車}) = P(\text{東西方向の車}) = \frac{p}{2}

すなわち、格子全体としての車の密度が :math:`p` となるように、南北方向の車と東西方向の車が同じ割合で配置されます。

.. list-table:: 格子の値と車の種類
   :header-rows: 1
   :widths: 10 30 20 40

   * - 値
     - 種類
     - 移動方向
     - 割合
   * - 0
     - 空きセル
     - （移動しない）
     - :math:`1 - p`
   * - 1
     - 南北方向の車
     - 北
     - :math:`p / 2`
   * - 2
     - 東西方向の車
     - 東
     - :math:`p / 2`

更新規則
========

BML モデルの更新は、南北方向の車の移動と東西方向の車の移動という 2 つの段階に分けて行われます。

まず、南北方向の車について、以下の規則に従って全セルを同時に更新します。南北方向の車は、自分から見て北隣のセルが空きセルであれば北へ 1 マス移動し、そうでなければその場にとどまります。時刻 :math:`t` における行 :math:`i` ・列 :math:`j` のセルの値を :math:`L(i, j, t)` とすると、この段階の更新は次のように表されます。

.. math::

   L(i, j, t + \tfrac{1}{2}) =
   \begin{cases}
     1 & L(i, j, t) = 0 \ \text{かつ} \ L(i + 1, j, t) = 1 \ \text{の場合} \\
     1 & L(i, j, t) = 1 \ \text{かつ} \ L(i - 1, j, t) \neq 0 \ \text{の場合} \\
     L(i, j, t) & \text{それ以外の場合}
   \end{cases}

続いて、更新後の格子 :math:`L(i, j, t + \tfrac{1}{2})` を用いて、東西方向の車についても同様に、東隣のセルが空きセルであれば東へ 1 マス移動する規則を全セルへ同時に適用します。

.. math::

   L(i, j, t + 1) =
   \begin{cases}
     2 & L(i, j, t + \tfrac{1}{2}) = 0 \ \text{かつ} \ L(i, j - 1, t + \tfrac{1}{2}) = 2 \ \text{の場合} \\
     2 & L(i, j, t + \tfrac{1}{2}) = 2 \ \text{かつ} \ L(i, j + 1, t + \tfrac{1}{2}) \neq 0 \ \text{の場合} \\
     L(i, j, t + \tfrac{1}{2}) & \text{それ以外の場合}
   \end{cases}

本プロジェクトの実装では、この 2 段階の更新をまとめて 1 回のメソッド呼び出しで行っています。詳細は :doc:`implementation` で解説します。

自由流と渋滞
============

BML モデルの最も興味深い性質は、密度 :math:`p` の値によって、シミュレーションの定常状態が大きく異なる点です。

密度が十分に低い場合、車同士がほとんど衝突せず、すべての車が滞りなく移動し続ける「自由流」状態になります。一方、密度がある閾値（臨界密度）を超えると、車同士が互いの進路を塞ぎ合う状態に陥り、最終的にどの車も動けなくなる「渋滞」状態（デッドロック）へ収束します。この、密度の変化に伴って定常状態の性質が急激に変化する現象は相転移と呼ばれ、 BML モデルは単純な規則からこのような相転移が生じることを示した代表例として知られています。

臨界密度の値は格子の形状や境界条件によって変化しますが、正方格子・周期境界条件の場合、一般に 0.3 台前半程度であるとされています。本プロジェクトの GUI アプリケーションが既定値として用いている密度 :math:`p = 0.6` は、この臨界密度を上回っているため、既定の設定のままシミュレーションを開始すると、比較的早い段階で渋滞状態に至ります。密度による挙動の違いについては、 :doc:`results` で具体例を示します。
