========
実行方法
========

必要な環境
==========

GUI アプリケーションの実行には、以下が必要です。

.. list-table:: 必要な環境
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - 内容
   * - Python
     - 3.10 以降を想定しています。標準ライブラリの tkinter を使用します。
   * - numpy
     - 格子の状態管理と更新処理に使用します。
   * - Pillow
     - 格子の状態を画像として描画するために使用します。

起動方法
========

:doc:`appendix` からダウンロードした ``BMLGUI.pyw`` を実行すると、 GUI アプリケーションが起動します。コマンドラインから実行する場合は、 ``BMLGUI.pyw`` を配置したディレクトリで次のコマンドを実行します。

.. code-block:: console

   python BMLGUI.pyw

起動すると、車の色設定・盤面サイズ・密度を調整するための設定画面が表示されます。

GUI の操作方法
==============

設定画面には、以下の部品が配置されています。

.. list-table:: GUI の操作部品
   :header-rows: 1
   :widths: 20 20 60

   * - 部品
     - 名称
     - 説明
   * - 色設定
     - None ／ car one ／ car two
     - それぞれ空きセル・南北方向の車・東西方向の車の色を、色相・彩度・明度のスライダーで調整します。
   * - 盤面サイズ
     - size
     - 格子の一辺の大きさを 3 段階（ 128 ／ 256 ／ 512 ）から選択します。
   * - 密度
     - probability
     - 車の密度（ 0 から 1 までの値）をスライダーで調整します。
   * - start ボタン
     - start
     - 現在の設定で新しいウィンドウを開き、シミュレーションを開始します。
   * - stop ボタン
     - stop
     - シミュレーションを表示しているウィンドウを閉じます。
   * - reset ボタン
     - reset
     - 密度・盤面サイズの設定を既定値（密度 0.6 、サイズ 256 ）に戻します。
   * - color ボタン
     - color
     - 車の色をランダムに選び直します。

シミュレーションを開始すると、格子の状態を表示する新しいウィンドウが開き、一定間隔で自動的に更新され続けます。ウィンドウを閉じる、または設定画面の「 stop 」ボタンを押すと、シミュレーションが停止します。設定画面で密度や盤面サイズを変更してから「 start 」ボタンを押すと、変更後の設定で新しいシミュレーションを開始できます。低密度と高密度でそれぞれ試すと、 :doc:`theory` で説明した自由流と渋滞の違いを実際に観察できます。
