本資料のまとめ
==============

本資料では、 BML 交通モデルについて、理論と Python 実装の両方の観点から解説しました。 :doc:`theory` では、格子と境界条件、車の初期配置と密度、南北・東西 2 段階の更新規則、そして密度によって自由流と渋滞という 2 つの定常状態が現れる相転移現象について説明しました。 :doc:`implementation` では、 ``BML`` クラスによるモデル本体の実装、 ``BMLImage`` クラスによる可視化、 tkinter を用いた GUI アプリケーションの構成について解説しました。 :doc:`usage` では GUI の操作方法を、 :doc:`results` では密度による移動率の違いを実際の数値で示し、理論と実装・実行結果が整合していることを確認しました。

発展的な話題
============

本資料では扱いませんでしたが、 BML モデルには以下のような発展的な話題があります。興味のある方は、 :doc:`appendix` に挙げた参考文献等を参照してください。

* 南北方向の車と東西方向の車の密度を非対称にした場合の挙動
* 正方格子以外の格子形状や、周期境界条件以外の境界条件を用いた場合の挙動
* 渋滞状態からの回復（信号機やランダムな車線変更などのルールを追加した拡張モデル）
* セルオートマトンによる他の交通流モデル（例えばナゲル・シュレッケンベルグモデルなど）との比較
