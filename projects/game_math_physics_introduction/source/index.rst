ゲームのための数学・物理入門
============================

ゲームの中で物が動き、回り、ぶつかり、跳ね返る。その裏側にある数学と物理を、Python のコードと図で学ぶ入門書である。ゲーム制作の経験は無いが Python を書けるエンジニアや工学系の学生を対象とし、2D ゲームを中心に、ベクトル・三角関数・行列・補間・乱数・運動の法則・衝突判定と応答を扱う。最後に、それらをまとめて 2D プラットフォーマー（横スクロールのアクションゲーム）を作る。
