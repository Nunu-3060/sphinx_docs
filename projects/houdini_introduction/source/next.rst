次のステップ
============

本資料では、Houdini の基本的な考え方と、モデリング、スクリプト、レンダリング、シミュレーションの入り口を扱った。この章では、扱わなかった分野と、これから学ぶときの進め方を紹介する。

本資料で扱わなかった分野
------------------------

.. list-table:: 本資料で扱わなかった主な分野
   :header-rows: 1
   :widths: 25 75

   * - 分野
     - 内容
   * - KineFX、APEX
     - キャラクターの骨格（リグ）を作り、動かす仕組み。モーションキャプチャーのデータの加工もできる。
   * - Copernicus（COP）
     - 画像を処理し、合成するネットワーク。GPU で高速に処理できる。
   * - PDG、TOP
     - 作業（タスク）を分割し、並列に実行する仕組み。大量のバリエーションの生成や、シミュレーションとレンダリングの一連の作業の自動化に使う。
   * - 地形（Heightfield）
     - 高さの格子データで地形を作り、浸食などの処理を行う。
   * - Crowds
     - 大量のキャラクター（群衆）を動かす。
   * - Houdini Engine
     - デジタルアセットを、Unreal Engine、Unity、Maya などの他のソフトウェアの中で動かす仕組み。Apprentice で作ったデジタルアセットは使えない。
   * - SideFX Labs
     - ゲーム開発などに役立つツール集。Houdini Launcher から追加でインストールできる。

学習の進め方
------------

* **作例を改造する。** 本資料の作例のパラメーターを変えたり、ノードを追加したりして、結果がどう変わるかを試す。例えば、建物群の各建物に屋根や窓を付ける、階段に手すりを付ける、といった課題が考えられる。
* **ノードのヘルプを読む。** 各ノードのヘルプには、パラメーターの説明のほかに、使い方の例が載っていることが多い。ヘルプの中には、サンプルのシーンを開くリンクが付いているものもある。
* **VEX の関数を覚える。** 多くの処理は、Attribute Wrangle と少しの VEX で書ける。VEX の関数の一覧に目を通しておくと、使える道具が増える。
* **公式のチュートリアルを見る。** SideFX 社のウェブサイトの学習用のページ（SideFX Learn）には、多くのチュートリアルが無料で公開されている（:doc:`references`）。
* **自分の作業を Python で自動化する。** 繰り返す操作はシェルフツールにし、ネットワークの組み立てはスクリプトにする。エンジニアの強みが最も活きる部分である。
