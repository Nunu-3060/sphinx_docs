デジタルアセット
================

ネットワークがある程度の大きさになると、使う人に見せたいパラメーターは数個だけで、中の細かいノードは隠しておきたくなる。また、作ったネットワークを別のシーンでも使いたくなる。Houdini では、ネットワークを 1 個の新しい種類のノードとしてまとめられる。これをデジタルアセット（Houdini Digital Asset、HDA）と呼ぶ。

デジタルアセットとは
--------------------

デジタルアセットは、プログラミングで言えば関数やライブラリの定義に当たる。

* **定義（ノードの種類）**: 中のネットワークと、外に見せるパラメーター（インターフェース）の組。ファイルに保存される。
* **インスタンス（ノード）**: 定義から作った個々のノード。Box ノードと同じように、Tab メニューからいくつでも作れる。パラメーターの値はインスタンスごとに違ってよい。

定義を変更すると、その定義から作った全てのインスタンスに変更が反映される。関数の中身を直すと、その関数を呼んでいる全ての場所の動作が変わるのと同じである。

デジタルアセットの定義は、ライブラリファイルに保存する。商用版の拡張子は ``.hda`` だが、Apprentice では ``.hdanc`` になる。

名前とバージョン
----------------

デジタルアセットには、内部名とラベルを付ける。

* **ラベル**: Tab メニューなどの画面に表示される名前。例えば ``Intro Stairs``。後から変えられる。
* **内部名**: ノードの種類を区別する名前。``intro::stairs::1.0`` のように、名前空間、名前、バージョンを ``::`` でつなぐ。作った後は変えられない。

名前空間は、自分の作ったノードの名前が、Houdini に付属するノードや他の人の作ったノードの名前と重ならないようにするためのものである。バージョンは、インターフェースを互換性の無い形で変えたいときに、古いバージョンを残したまま新しいバージョンを作るために使う。:doc:`python` で見た ``polybevel::3.0`` も、同じ仕組みでバージョンが付けられている。

作例: 階段をデジタルアセットにする
----------------------------------

:doc:`procedural` で作った階段を、デジタルアセットにする。完成すると、:guilabel:`Step Count`、:guilabel:`Step Height`、:guilabel:`Step Depth`、:guilabel:`Width` の 4 個のパラメーターだけを持つ ``Intro Stairs`` ノードができる。サンプルコードの ``build_hda.py`` でも同じものを作れる。

サブネットワークにまとめる
^^^^^^^^^^^^^^^^^^^^^^^^^^

#. :doc:`procedural` で作った ``/obj/stairs`` を開く。
#. ``step_points``、``unit_box``、``copy_steps`` の 3 個のノードを選ぶ（``OUT`` は含めない）。
#. 選んだノードの上で RMB をクリックし、:menuselection:`Actions --> Collapse to Subnet` を選ぶ。3 個のノードが、1 個の Subnetwork ノードの中に移される。
#. Subnetwork ノードの名前を ``stairs`` にする。

Subnetwork ノードは、ノードをまとめて入れておくための入れ物である。この時点では、まだ新しい種類のノードにはなっていない。

デジタルアセットを作る
^^^^^^^^^^^^^^^^^^^^^^

#. ``stairs`` の上で RMB をクリックし、:guilabel:`Create Digital Asset` を選ぶ。
#. 開いたウィンドウで、次のように入力する。

   * :guilabel:`Label`: ``Intro Stairs``
   * :guilabel:`Internal Name`: ``intro::stairs::1.0``\ （名前空間 ``intro``、名前 ``stairs``、バージョン ``1.0``）
   * :guilabel:`Save To`: ライブラリファイルの保存先。既定の場所（ユーザーの Houdini の設定ディレクトリの中）のままでよい。

#. :guilabel:`Create` を押す。デジタルアセットが作られ、``stairs`` ノードはその最初のインスタンスになる。続いて、ノードの種類の設定を行う Type Properties ウィンドウが開く。

パラメーターを公開する
^^^^^^^^^^^^^^^^^^^^^^

作ったばかりのデジタルアセットには、パラメーターが無い。中の ``step_points`` のパラメーターを、デジタルアセットのパラメーターとして外に出す。これをパラメーターの昇格（promote）と呼ぶ。

#. Type Properties ウィンドウを開いたまま、ネットワークエディターで ``stairs`` の中に入り、``step_points`` を選ぶ。パラメーターエディターに、:guilabel:`Step Count` などが表示される。
#. Type Properties ウィンドウの :guilabel:`Parameters` タブを開く。パラメーターエディターの :guilabel:`Step Count` のラベルを、:guilabel:`Parameters` タブのパラメーターの一覧にドラッグする。:guilabel:`Step Height`、:guilabel:`Step Depth`、:guilabel:`Width` も同じようにドラッグする。
#. :guilabel:`Accept` を押す。

ドラッグで追加したパラメーターは、デジタルアセットのパラメーターとして作られる。同時に、中の ``step_points`` の元のパラメーターには、新しいパラメーターを参照する式（``ch("../step_count")`` のような式）が設定される。

``stairs`` の外に出て ``stairs`` ノードを選ぶと、4 個のパラメーターだけが表示される。値を変えると階段の形が変わる。

インスタンスを増やす
^^^^^^^^^^^^^^^^^^^^

Tab メニューで ``Intro Stairs`` を検索すると、新しいノードとして作れる。2 個目のインスタンスを作り、:guilabel:`Width` を ``3`` にすると、幅 3 m の階段ができる。1 個目のインスタンスの値は変わらない。

デジタルアセットを編集する
--------------------------

デジタルアセットのインスタンスは、通常は中のネットワークを編集できないようにロックされている。定義を編集するには、次の操作を行う。

#. インスタンスの上で RMB をクリックし、:guilabel:`Allow Editing of Contents` を選ぶ。中のネットワークを編集できるようになる。
#. 中のネットワークを編集する。
#. インスタンスの上で RMB をクリックし、:guilabel:`Save Node Type` を選ぶ。編集した内容が定義として保存され、他の全てのインスタンスにも反映される。

編集を取り消して保存済みの定義に戻すには、:guilabel:`Match Current Definition` を選ぶ。パラメーターの追加や並べ替えは、Type Properties ウィンドウ（インスタンスの RMB メニューの :guilabel:`Type Properties`）で行う。

デジタルアセットを使う
----------------------

既定の保存先のライブラリファイルは、Houdini の起動時に自動的に読み込まれる。別の場所に保存したライブラリファイルは、:menuselection:`File --> Import --> Houdini Digital Asset` で読み込む。読み込まれているライブラリファイルとデジタルアセットの一覧は、:menuselection:`Windows --> Asset Manager` で確かめられる。

デジタルアセットの中で別のネットワークの値を参照する場合は、``/obj/table/top`` のような絶対パスではなく、``../top`` のような相対パスを使う。絶対パスで参照すると、別のシーンに持っていったときに参照先が見つからなくなる。

画面の操作ではパラメーターをドラッグするだけで参照が作られたが、スクリプトでは参照を自分で設定する。``step_points`` の VEX のコードは ``chi("step_count")`` のように ``step_points`` 自身のパラメーターを読むので、``step_points`` に同じ名前のパラメーターを作り、そこにデジタルアセットのパラメーターを参照する Hscript の式 ``ch("../step_count")`` を設定している。Hscript の ``ch()`` は整数のパラメーターにも使える（Hscript に ``chi()`` という関数は無い）。

Apprentice での制限
-------------------

Apprentice で作ったデジタルアセットは、Apprentice の形式（``.hdanc``）で保存される。:doc:`overview` で述べたとおり、Houdini Engine（Unreal Engine や Unity などの中でデジタルアセットを動かす仕組み）では使えない。商用版の Houdini で読み込むと、その Houdini が非商用の扱いになる点にも注意する。
