本書の目的と対象読者
================================================================

本書の目的は、Unity のスクリプトを自分で読み書きできるようになることです。そのために必要な C# の文法と、Unity でスクリプトを書くときの基本的な考え方を解説します。

本書は、次のような人を対象としています。

* プログラミングの経験がほとんどない人
* ほかのプログラミング言語の経験はあるが、C# と Unity は初めての人

本書を読み終えると、次のことができるようになります。

* C# の基本的な文法を理解し、簡単なクラスやメソッドを書ける。
* Unity のコンポーネントとして動くスクリプトを書き、GameObject を動かしたり、入力や衝突に反応させたりできる。
* 簡単な 3D ゲームを 1 本完成させられる。

動作環境
================================================================

本書は、次の環境を前提としています。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - 内容
   * - Unity
     - Unity 6 の LTS 版（6000.0 LTS 以降）
   * - C# のバージョン
     - C# 9.0（Unity 6 が対応しているバージョン）
   * - 入力
     - Input System パッケージ
   * - コードエディター
     - Visual Studio 2022 または Visual Studio Code
   * - OS
     - Windows または macOS

Unity はバージョンによってメニューの名前や API が変わることがあります。本書と異なる表示になっている場合は、使用している Unity のバージョンを確認してください。

本書の構成
================================================================

本書は 3 部構成です。

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 部
     - 内容
   * - 第 1 部 C# の基礎
     - 変数、制御構文、メソッド、クラスなど、C# の文法を学びます。サンプルコードは Unity で実行しますが、Unity 固有の機能はほとんど使いません。
   * - 第 2 部 Unity で使う C#
     - コンポーネント、イベント関数、入力、物理演算、コルーチンなど、Unity でスクリプトを書くために必要な知識を学びます。
   * - 第 3 部 実践
     - 第 1 部と第 2 部で学んだことを使って簡単なゲームを作り、エラーの調べ方を学びます。

C# の文法を先に学ぶのは、うまく動かないときに「C# の書き方の問題」なのか「Unity の使い方の問題」なのかを区別できるようにするためです。プログラミングの経験がある人は、第 1 部を読み飛ばしてもかまいません。

サンプルコード
================================================================

本書のサンプルコードは、各章の本文中からファイルごとにダウンロードできます。すべてのサンプルコードをまとめた zip ファイルは、次のリンクからダウンロードできます。

:download:`サンプルコード一式（unity_csharp_examples.zip） <_generated/unity_csharp_examples.zip>`

zip ファイルの examples フォルダーには、章ごとのフォルダー（ch01 から ch20）があります。サンプルコードを使うときは、Unity のプロジェクトの Assets フォルダーの中にファイルをコピーしてください。すべてのサンプルコードはクラス名が重複しないように作られているため、1 つのプロジェクトにまとめてコピーしてもかまいません。

各ファイルの冒頭には、対応する章と使い方をコメントで記載しています。また、サンプルコードは :doc:`appendix/a_coding_conventions` で説明するコーディング規約に従って書かれています。
