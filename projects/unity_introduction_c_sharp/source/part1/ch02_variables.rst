################################################################
第 2 章 変数と型
################################################################

この章では、値を記憶しておくための変数と、値の種類を表す型について学びます。

変数とは
================================================================

変数は、値を入れておく名前付きの箱のようなものです。ゲームでは、プレイヤーの HP、移動の速さ、スコアなど、さまざまな値を変数に入れて管理します。

変数を使うには、まず宣言します。宣言では、型と変数名を書きます。

.. code-block:: csharp

   int hp;         // int 型の変数 hp を宣言する
   hp = 100;       // hp に 100 を代入する
   int mp = 50;    // 宣言と同時に代入する（初期化）

``=`` は「等しい」ではなく、「右辺の値を左辺の変数に入れる」という意味です。これを代入と呼びます。宣言と同時に最初の値を代入することを初期化と呼びます。

変数名の付け方
----------------------------------------------------------------

変数名には、次の決まりがあります。

* 使える文字は、英字、数字、``_``\ （アンダースコア）です。
* 数字から始めることはできません。
* ``int`` や ``class`` など、C# で特別な意味を持つ単語（キーワード）は使えません。
* 大文字と小文字は区別されます。``score`` と ``Score`` は別の変数です。

本書では、ローカル変数（メソッドの中で宣言する変数）の名前は、``playerName`` のように最初の単語を小文字で始め、2 つ目以降の単語の先頭を大文字にします。この書き方を camelCase と呼びます。変数名は、``a`` や ``x`` のような短い名前より、中身がわかる名前にしてください。

主な型
================================================================

C# では、変数に入れられる値の種類が型によって決まります。よく使う型は次のとおりです。

.. list-table::
   :header-rows: 1
   :widths: 15 35 50

   * - 型
     - 表す値
     - 例
   * - ``int``
     - 整数（約 -21 億から約 21 億まで）
     - ``int hp = 100;``
   * - ``float``
     - 小数（有効桁数は約 7 桁）
     - ``float speed = 3.5f;``
   * - ``double``
     - 小数（有効桁数は約 15 桁）
     - ``double rate = 0.125;``
   * - ``bool``
     - 真偽値（``true`` または ``false``）
     - ``bool isAlive = true;``
   * - ``char``
     - 1 文字
     - ``char rank = 'A';``
   * - ``string``
     - 文字列
     - ``string playerName = "Alice";``

Unity では、座標や時間などの小数には、主に ``float`` を使います。``float`` の値を書くときは、``3.5f`` のように数値の後ろに ``f`` を付けます。``f`` を付けずに ``3.5`` と書くと ``double`` の値として扱われ、``float`` の変数に代入しようとするとコンパイルエラーになります。

``char`` の値は ``'``\ （シングルクォーテーション）で、``string`` の値は ``"``\ （ダブルクォーテーション）で囲みます。

文字列の扱い
================================================================

文字列は ``+`` でつなげられます。文字列と数値を ``+`` でつなぐと、数値は文字列に変換されてから連結されます。

.. code-block:: csharp

   string message = "HP: " + 100;    // "HP: 100"

文字列の前に ``$`` を付けると、``{`` と ``}`` で囲んだ部分に変数や式の値を埋め込めます。これを文字列補間と呼びます。本書のサンプルコードでは、``Debug.Log`` で値を表示するときに、主に文字列補間を使います。

.. code-block:: csharp

   int hp = 100;
   string message = $"HP は {hp} です。";    // "HP は 100 です。"

型変換
================================================================

ある型の値を、別の型の値に変換することを型変換と呼びます。

.. list-table::
   :header-rows: 1
   :widths: 25 40 35

   * - 種類
     - 説明
     - 例
   * - 暗黙的な型変換
     - 情報が失われない変換は、自動で行われます。
     - ``float f = 7;``
   * - 明示的な型変換（キャスト）
     - 情報が失われる可能性がある変換は、``(型)`` を付けて明示します。
     - ``int i = (int)9.8f;``
   * - 文字列から数値への変換
     - ``int.Parse`` などのメソッドを使います。
     - ``int n = int.Parse("250");``
   * - 数値から文字列への変換
     - ``ToString`` メソッドを使います。
     - ``string s = 250.ToString();``

``float`` を ``int`` にキャストすると、小数部分は切り捨てられます。最も近い整数に丸めたいときは ``Mathf.RoundToInt`` を使います。ただし、``Mathf.RoundToInt`` は、2.5 のようにちょうど中間の値を偶数の側に丸めます（2.5 は 2、3.5 は 4 になります）。

var による型の推論
================================================================

変数を宣言するときに型の代わりに ``var`` と書くと、右辺の値から型が自動的に決まります。これを型推論と呼びます。

.. code-block:: csharp

   var level = 5;          // int になる
   var name = "Alice";     // string になる

``var`` で宣言しても、型が決まった変数であることに変わりはありません。``level`` に後から文字列を代入することはできません。本書では、型を意識して学べるように、原則として型を明示して書きます。

定数
================================================================

``const`` を付けて宣言すると、後から値を変更できない定数になります。ゲームの最大レベルのように、変わることのない値に使います。

.. code-block:: csharp

   private const int MaxLevel = 99;

サンプルコードでは、定数をメソッドの外（クラスの中）に書いています。このように書いた定数は、クラスの中のすべてのメソッドから使えます。``private`` の意味は第 7 章で説明します。定数の値を変更しようとすると、コンパイルエラーになります。

変数の有効範囲
================================================================

メソッドの中で宣言した変数（ローカル変数）は、宣言した ``{`` と ``}`` の範囲（ブロック）の中でだけ使えます。この範囲をスコープと呼びます。

.. code-block:: csharp

   private void Start()
   {
       int score = 10;
       if (score > 5)
       {
           int bonus = 3;
           Debug.Log(score + bonus);    // 使える
       }
       Debug.Log(bonus);                // エラー: bonus はこのスコープに存在しない
   }

``if`` 文については、第 4 章で説明します。

まとめ
================================================================

* 変数は「型 変数名 = 値;」の形で宣言し、初期化します。
* Unity では、小数には主に ``float`` を使い、値の後ろに ``f`` を付けます。
* 文字列補間（``$"...{変数}..."``）を使うと、文字列に値を埋め込めます。
* 情報が失われる可能性がある型変換には、キャストが必要です。
* ``const`` を付けると、値を変更できない定数になります。
