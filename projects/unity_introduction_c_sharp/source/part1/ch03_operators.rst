################################################################
第 3 章 演算子と式
################################################################

この章では、計算や比較を行うための演算子について学びます。``a + b`` のように、値や変数を演算子で組み合わせたものを式と呼びます。

算術演算子
================================================================

.. list-table::
   :header-rows: 1
   :widths: 15 25 30 30

   * - 演算子
     - 意味
     - 例
     - 結果
   * - ``+``
     - 足し算
     - ``7 + 2``
     - ``9``
   * - ``-``
     - 引き算
     - ``7 - 2``
     - ``5``
   * - ``*``
     - 掛け算
     - ``7 * 2``
     - ``14``
   * - ``/``
     - 割り算
     - ``7 / 2``
     - ``3``
   * - ``%``
     - 割り算の余り（剰余）
     - ``7 % 2``
     - ``1``

整数どうしの割り算
----------------------------------------------------------------

``int`` どうしの割り算の結果は ``int`` になり、小数部分は切り捨てられます。そのため、``7 / 2`` は ``3.5`` ではなく ``3`` になります。小数の結果が欲しいときは、``(float)7 / 2`` や ``7f / 2f`` のように、少なくとも一方を ``float`` にします。

整数の割り算の商 :math:`q` と余り :math:`r` は、割られる数を :math:`a`、割る数を :math:`b` とすると、次の関係を満たします。

.. math::

   a = b \times q + r

C# では、商は 0 の方向に切り捨てられ、余りの符号は割られる数 :math:`a` と同じになります。たとえば、:math:`-7 \div 2` の商は :math:`-3`、余りは :math:`-1` です。

.. math::

   -7 = 2 \times (-3) + (-1)

余りは、「偶数かどうか」（``n % 2 == 0``）や「3 回に 1 回だけ処理する」（``count % 3 == 0``）といった判定によく使います。

計算の優先順位
----------------------------------------------------------------

数学と同じく、``*``、``/``、``%`` は ``+`` と ``-`` より先に計算されます。優先順位を変えたいときは、かっこ ``( )`` を使います。

.. code-block:: csharp

   int a = 2 + 3 * 4;      // 14
   int b = (2 + 3) * 4;    // 20

代入演算子とインクリメント
================================================================

変数の値を使って計算し、その結果を同じ変数に代入する処理は、短く書けます。

.. list-table::
   :header-rows: 1
   :widths: 20 40 40

   * - 演算子
     - 例
     - 同じ意味の書き方
   * - ``+=``
     - ``hp += 10;``
     - ``hp = hp + 10;``
   * - ``-=``
     - ``hp -= 10;``
     - ``hp = hp - 10;``
   * - ``*=``
     - ``hp *= 2;``
     - ``hp = hp * 2;``
   * - ``/=``
     - ``hp /= 2;``
     - ``hp = hp / 2;``
   * - ``++``
     - ``count++;``
     - ``count = count + 1;``
   * - ``--``
     - ``count--;``
     - ``count = count - 1;``

``++`` と ``--`` は、それぞれインクリメント（1 増やす）、デクリメント（1 減らす）と呼びます。

比較演算子
================================================================

比較演算子は 2 つの値を比べ、結果を ``bool``\ （``true`` または ``false``）で返します。

.. list-table::
   :header-rows: 1
   :widths: 20 40 40

   * - 演算子
     - 意味
     - 例（``age`` が 15 のとき）
   * - ``==``
     - 等しい
     - ``age == 15`` は ``true``
   * - ``!=``
     - 等しくない
     - ``age != 15`` は ``false``
   * - ``<``
     - より小さい
     - ``age < 18`` は ``true``
   * - ``<=``
     - 以下
     - ``age <= 15`` は ``true``
   * - ``>``
     - より大きい
     - ``age > 18`` は ``false``
   * - ``>=``
     - 以上
     - ``age >= 18`` は ``false``

.. warning::

   等しいかどうかを調べる演算子は、``=`` ではなく ``==`` です。``=`` は代入の演算子です。

論理演算子
================================================================

論理演算子は、``bool`` の値を組み合わせます。

.. list-table::
   :header-rows: 1
   :widths: 20 30 50

   * - 演算子
     - 意味
     - 結果が ``true`` になる条件
   * - ``&&``
     - かつ（AND）
     - 両方が ``true`` のとき
   * - ``||``
     - または（OR）
     - 少なくとも一方が ``true`` のとき
   * - ``!``
     - ではない（NOT）
     - 値が ``false`` のとき

``&&`` は左側が ``false`` のとき、``||`` は左側が ``true`` のとき、結果が確定するため右側を評価しません。

小数の誤差
================================================================

``float`` や ``double`` の値は、コンピューターの内部では 2 進数で表されます。0.1 のように 2 進数では正確に表せない値は近似値として保存されるため、計算結果にわずかな誤差が生じることがあります。

そのため、小数どうしを ``==`` で比べると、数学的には等しいはずの値でも ``false`` になることがあります。``float`` の値がほぼ等しいかどうかを調べるには、``Mathf.Approximately`` を使います。

サンプルコード
================================================================

.. literalinclude:: ../../examples/ch03/OperatorSample.cs
   :language: csharp
   :caption: OperatorSample.cs

:download:`OperatorSample.cs をダウンロード <../../examples/ch03/OperatorSample.cs>`

.. code-block:: text
   :caption: 実行結果

   a + b = 9
   a - b = 5
   a * b = 14
   a / b = 3
   a % b = 1
   (float)a / b = 3.5
   -7 / 2 = -3
   -7 % 2 = -1
   2 + 3 * 4 = 14
   (2 + 3) * 4 = 20
   hp = 150
   count = 2
   age >= 18: False
   チケットがあり、かつ 12 歳以上: True
   18 歳以上、またはチケットがある: True
   チケットがない: False
   0.1f + 0.6f == 0.7f: False
   Mathf.Approximately(x, 0.7f): True

``0.1f + 0.6f`` の結果は、``0.7f`` とわずかに異なる値になるため、``==`` による比較は ``False`` になります。

まとめ
================================================================

* ``int`` どうしの割り算では、小数部分が切り捨てられます。
* ``+=`` や ``++`` を使うと、変数の値を更新する処理を短く書けます。
* 比較演算子と論理演算子の結果は ``bool`` です。
* 小数には誤差があるため、``==`` で比較せず、``Mathf.Approximately`` を使います。
