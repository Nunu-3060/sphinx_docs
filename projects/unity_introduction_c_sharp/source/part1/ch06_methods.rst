################################################################
第 6 章 メソッド
################################################################

この章では、処理をひとまとめにして名前を付けるメソッドについて学びます。メソッドを使うと、同じ処理を何度も書かずに済み、コードが読みやすくなります。

メソッドの定義と呼び出し
================================================================

メソッドは、次の形で定義します。

.. code-block:: text

   アクセス修飾子 戻り値の型 メソッド名(引数の型 引数名, ...)
   {
       // 処理
       return 戻り値;
   }

例として、2 つの整数を足した結果を返すメソッドを定義します。

.. code-block:: csharp

   private int Add(int x, int y)
   {
       return x + y;
   }

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - 部分
     - 意味
   * - ``private``
     - アクセス修飾子です。このメソッドを、クラスの外から呼び出せないようにします（第 7 章）。
   * - ``int``
     - 戻り値（メソッドが返す結果）の型です。
   * - ``Add``
     - メソッド名です。本書では、メソッド名は ``TakeDamage`` のように各単語の先頭を大文字にします。この書き方を PascalCase と呼びます。
   * - ``(int x, int y)``
     - 引数です。メソッドに渡す値を受け取る変数です。
   * - ``return x + y;``
     - ``return`` の後の値を戻り値として返し、メソッドを終了します。

定義したメソッドは、``int sum = Add(3, 4);`` のように、メソッド名の後のかっこに引数の値を指定して呼び出します。

戻り値がないメソッドは、戻り値の型の代わりに ``void`` と書きます。``void`` のメソッドでも、``return;`` と書くと、その時点でメソッドを終了できます。

.. note::

   第 1 章から使ってきた ``Start`` も、戻り値のないメソッドです。``Start`` は自分で呼び出さなくても、Unity が適切なタイミングで自動的に呼び出します（第 11 章）。

オーバーロード
================================================================

引数の型や数が異なれば、同じ名前のメソッドを複数定義できます。これをオーバーロードと呼びます。呼び出すときに渡した引数の型によって、どのメソッドが呼ばれるかが決まります。

.. code-block:: csharp

   private int Add(int x, int y) { ... }
   private float Add(float x, float y) { ... }

既定値付き引数と名前付き引数
================================================================

引数に既定値を指定しておくと、呼び出すときにその引数を省略できます。既定値付きの引数は、引数の並びの最後に書きます。

.. code-block:: csharp

   private void Greet(string name, string greeting = "こんにちは") { ... }

   Greet("Alice");               // greeting は "こんにちは"
   Greet("Bob", "おはよう");     // greeting は "おはよう"

呼び出すときに ``greeting: "こんばんは"`` のように引数名を指定すると、引数を順番どおりに書かなくても渡せます。これを名前付き引数と呼びます。引数が多いメソッドで、どの値が何を意味するのかを明確にしたいときにも便利です。

ref と out
================================================================

通常、メソッドの引数には値のコピーが渡されます。メソッドの中で引数に別の値を代入しても、呼び出し元の変数は変わりません（クラスの値を渡した場合の動きは、第 7 章の「値型と参照型」で説明します）。

``ref`` や ``out`` を付けると、呼び出し元の変数そのものをメソッドに渡せます。

.. list-table::
   :header-rows: 1
   :widths: 15 85

   * - キーワード
     - 説明
   * - ``ref``
     - 呼び出し元の変数を、メソッドの中で読み書きできます。渡す変数には、あらかじめ値を代入しておく必要があります。
   * - ``out``
     - メソッドから結果を受け取るために使います。メソッドの中で必ず値を代入する必要があります。

``out`` は、2 つ以上の結果を返したいときや、第 5 章の ``TryGetValue`` のように「成功したかどうか」を戻り値で、「結果」を ``out`` 引数で返すときによく使います。呼び出すときは、``out int quotient`` のように、その場で変数を宣言できます。受け取る必要のない結果は、``out _`` と書いて捨てられます。

式形式のメンバー
================================================================

処理が 1 つの式だけのメソッドは、``=>`` を使って短く書けます。

.. code-block:: csharp

   private int Square(int x) => x * x;

これは、``{ return x * x; }`` と書いた場合と同じ意味です。

まとめ
================================================================

* メソッドは、処理をひとまとめにして名前を付けたものです。
* 戻り値のないメソッドには ``void`` と書きます。
* 引数の型や数が異なれば、同じ名前のメソッドを定義できます（オーバーロード）。
* ``ref`` と ``out`` を使うと、呼び出し元の変数そのものをメソッドに渡せます。
