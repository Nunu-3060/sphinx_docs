################################################################
第 15 章 ベクトルと移動・回転
################################################################

ゲームでは、位置、移動の向き、速さなどを表すためにベクトルを使います。この章では、Unity でベクトルを表す ``Vector3`` の使い方と、回転を表す ``Quaternion`` の基本を学びます。

Unity の座標系
================================================================

Unity の 3D 空間は、X 軸、Y 軸、Z 軸の 3 つの軸で表されます。

.. list-table::
   :header-rows: 1
   :widths: 20 30 50

   * - 軸
     - 正の向き
     - 定数
   * - X 軸
     - 右
     - ``Vector3.right``\ （(1, 0, 0)）
   * - Y 軸
     - 上
     - ``Vector3.up``\ （(0, 1, 0)）
   * - Z 軸
     - 前（奥）
     - ``Vector3.forward``\ （(0, 0, 1)）

反対の向きは、``Vector3.left``、``Vector3.down``、``Vector3.back`` で表します。すべての成分が 0 のベクトルは ``Vector3.zero`` です。Unity では、長さの単位を 1 m として扱うのが一般的です。

.. note::

   Unity の座標系は左手系です。左手の親指を X 軸（右）、人差し指を Y 軸（上）に向けると、中指が Z 軸（前）を向きます。

Vector3
================================================================

``Vector3`` は、``x``、``y``、``z`` の 3 つの ``float`` を持つ構造体です。位置を表すことも、向きと大きさ（移動量や速度）を表すこともあります。

ベクトルの演算
----------------------------------------------------------------

ベクトルの足し算と引き算は、成分ごとに計算されます。ベクトル :math:`\boldsymbol{a} = (a_x, a_y, a_z)` と :math:`\boldsymbol{b} = (b_x, b_y, b_z)` について、次のようになります。

.. math::

   \boldsymbol{a} + \boldsymbol{b} = (a_x + b_x,\ a_y + b_y,\ a_z + b_z)

ベクトルに数を掛けると、向きはそのままで、長さだけが変わります。

.. math::

   k \boldsymbol{a} = (k a_x,\ k a_y,\ k a_z)

「目標の位置 − 自分の位置」を計算すると、自分から目標へ向かうベクトルが得られます。これは、敵をプレイヤーに向かわせる処理などでよく使います。

長さと正規化
----------------------------------------------------------------

ベクトルの長さ（大きさ）は ``magnitude`` で得られます。

.. math::

   |\boldsymbol{a}| = \sqrt{a_x^2 + a_y^2 + a_z^2}

長さの 2 乗は ``sqrMagnitude`` で得られます。平方根の計算を省けるため、長さどうしを比べるだけなら ``sqrMagnitude`` を使うと効率的です。

向きはそのままで長さを 1 にしたベクトルを、単位ベクトルと呼びます。ベクトルを単位ベクトルにすることを正規化と呼び、``normalized`` で得られます。向きだけが必要なとき（「目標の方向へ一定の速さで進む」など）は、正規化したベクトルに速さを掛けて使います。

.. math::

   \frac{\boldsymbol{a}}{|\boldsymbol{a}|}

2 点間の距離は、``Vector3.Distance(a, b)`` で得られます。これは ``(a - b).magnitude`` と同じです。

内積
----------------------------------------------------------------

2 つのベクトルの内積は、``Vector3.Dot(a, b)`` で得られます。2 つのベクトルのなす角を :math:`\theta` とすると、内積は次の式で表されます。

.. math::

   \boldsymbol{a} \cdot \boldsymbol{b} = a_x b_x + a_y b_y + a_z b_z = |\boldsymbol{a}|\,|\boldsymbol{b}| \cos\theta

どちらも単位ベクトルの場合、内積は :math:`\cos\theta` になり、同じ向きなら 1、直角なら 0、逆向きなら -1 になります。内積が正なら、2 つのベクトルの向きの差は 90° 未満です。これを使うと、「敵の正面方向と、敵からプレイヤーへ向かうベクトルの内積が正なら、プレイヤーは敵の前方にいる」と判定できます。

外積
----------------------------------------------------------------

2 つのベクトルの外積は、``Vector3.Cross(a, b)`` で得られます。外積は、:math:`\boldsymbol{a}` と :math:`\boldsymbol{b}` の両方に垂直なベクトルです。

.. math::

   \boldsymbol{a} \times \boldsymbol{b} = (a_y b_z - a_z b_y,\ a_z b_x - a_x b_z,\ a_x b_y - a_y b_x)

外積は、面の向き（法線）を求めるときなどに使います。

線形補間
----------------------------------------------------------------

``Vector3.Lerp(a, b, t)`` は、:math:`\boldsymbol{a}` と :math:`\boldsymbol{b}` の間を :math:`t` の割合で分けた点を返します。:math:`t` は 0 から 1 の範囲に制限されます。

.. math::

   \mathrm{Lerp}(\boldsymbol{a}, \boldsymbol{b}, t) = \boldsymbol{a} + (\boldsymbol{b} - \boldsymbol{a})\,t \quad (0 \le t \le 1)

Quaternion
================================================================

Unity では、回転を ``Quaternion``\ （クォータニオン）という型で表します。``Quaternion`` は ``x``、``y``、``z``、``w`` の 4 つの成分を持ちますが、これらの値は角度ではないため、直接書き換えてはいけません。回転は、次のメソッドを使って作ります。

.. list-table::
   :header-rows: 1
   :widths: 45 55

   * - メソッドとプロパティ
     - 説明
   * - ``Quaternion.identity``
     - 回転していない状態です。
   * - ``Quaternion.Euler(x, y, z)``
     - X 軸、Y 軸、Z 軸まわりの角度（度）から回転を作ります。Inspector ウィンドウの Rotation と同じ表し方です。
   * - ``Quaternion.LookRotation(向き)``
     - 指定した向きを正面（Z 軸の正の向き）とする回転を作ります。
   * - ``Quaternion.RotateTowards(現在, 目標, 最大角度)``
     - 現在の回転から目標の回転へ、最大角度（度）だけ近づけた回転を返します。
   * - ``Quaternion.Slerp(a, b, t)``
     - 2 つの回転の間を、``t`` の割合で滑らかに補間します。
   * - ``回転 * ベクトル``
     - ベクトルを回転させます。

.. note::

   回転を X 軸、Y 軸、Z 軸まわりの角度で表す方法（オイラー角）は直感的ですが、回転を組み合わせたときに意図しない結果になることがあります。そのため、Unity は内部で ``Quaternion`` を使っています。オイラー角は ``transform.eulerAngles`` で読み書きできますが、計算には ``Quaternion`` のメソッドを使うのが安全です。

Transform には、回転のための便利なメソッドも用意されています。

.. list-table::
   :header-rows: 1
   :widths: 45 55

   * - メソッド
     - 説明
   * - ``transform.Rotate(x, y, z)``
     - 現在の回転に、指定した角度（度）の回転を加えます（第 10 章）。
   * - ``transform.LookAt(目標の Transform)``
     - 目標の方向を向きます。

まとめ
================================================================

* Unity の 3D 空間では、Y 軸が上、Z 軸が前です。
* 「目標の位置 − 自分の位置」で、目標へ向かうベクトルが得られます。
* ``normalized`` で向きだけのベクトルを、``magnitude`` で長さを得られます。
* 内積を使うと、2 つのベクトルの向きがどれだけ揃っているかがわかります。
* 回転は ``Quaternion`` で表し、``Quaternion.Euler`` や ``Quaternion.LookRotation`` などで作ります。
