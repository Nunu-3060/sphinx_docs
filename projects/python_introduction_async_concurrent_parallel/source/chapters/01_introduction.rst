第 1 章 はじめに
================

本書の目的
----------

プログラムを速くしたい、多数の通信を効率よくさばきたいという場面で、「スレッドを使う」「``asyncio`` を使う」「プロセスを使う」といった選択肢が挙がる。しかし、これらは得意な処理がまったく異なる。処理の性質に合わない手法を選ぶと、コードが複雑になるだけで速くならず、むしろ遅くなることもある。

本書の目的は、次の 2 つができるようになることである。

* 処理の性質を見極め、非同期処理・並行処理・並列処理のどれを使うべきか（あるいは使わないべきか）を判断できる。
* 選んだ手法を、Python の標準ライブラリを使って正しく実装できる。

そのため本書では、個々の API を網羅的に紹介するよりも、「なぜその手法が速くなるのか」「どのような場面で問題が起きるのか」という仕組みの理解に重点を置く。

対象読者と前提知識
------------------

本書は、Python で関数やクラスを書いた経験があるエンジニアを対象とする。次の知識を前提とする。

* Python の基本文法（関数、クラス、例外処理、``with`` 文）
* 型ヒントの基本的な読み方
* コマンドラインでのプログラムの実行方法

並行処理や並列処理の経験は問わない。OS のプロセスやスレッドについても、必要な範囲は本書の中で説明する。

対象とする Python のバージョン
------------------------------

本書は Python 3.11 以降を対象とする。Python 3.11 では、非同期処理で使う ``asyncio.TaskGroup`` や ``asyncio.timeout()``、複数の例外をまとめて扱う ``ExceptionGroup`` と ``except*`` 構文が追加された。本書ではこれらを標準的な書き方として扱う。

その後のバージョンでも、並行処理・並列処理に関わる大きな変更が続いている。代表的なものを次に示す。

.. list-table:: 並行処理・並列処理に関わる主な変更
   :header-rows: 1
   :widths: 15 85

   * - バージョン
     - 主な変更
   * - 3.11
     - ``asyncio.TaskGroup``、``asyncio.timeout()``、``ExceptionGroup`` と ``except*`` の追加
   * - 3.12
     - サブインタプリタごとに独立した GIL を持てるようになった（C API のみ）
   * - 3.13
     - GIL を無効にした free-threaded ビルドが実験的に提供された
   * - 3.14
     - free-threaded ビルドが正式にサポートされた。サブインタプリタを Python から使う ``concurrent.interpreters`` モジュールと ``InterpreterPoolExecutor`` が追加された。``python -m asyncio ps`` などのタスクを調べるコマンドが追加された。macOS 以外の POSIX 系 OS で ``multiprocessing`` の既定の起動方式が fork から forkserver に変わった

バージョンによって使える機能が異なる箇所では、本文中にバージョンを明記する。サンプルコードは Python 3.14.6（Windows 11）で動作を確認している。

本書の構成
----------

本書は次の構成になっている。

* :doc:`02_concepts` では、逐次・並行・並列・非同期という用語を定義し、CPU バウンドと I/O バウンドという処理の分類を説明する。
* :doc:`03_gil` では、Python のスレッドの性質を決める GIL について説明する。
* :doc:`04_choosing` では、処理の性質から手法を選ぶ判断基準を示す。本書の中心となる章である。
* :doc:`05_threads`、:doc:`06_processes`、:doc:`07_futures` では、スレッドとプロセスを使った実装方法を説明する。
* :doc:`08_asyncio_basics` と :doc:`09_asyncio_practice` では、``asyncio`` による非同期処理を説明する。
* :doc:`10_new_options` では、free-threaded ビルドとサブインタプリタを紹介する。
* :doc:`11_debugging` では、デバッグ、テスト、性能計測の方法を説明する。
* :doc:`12_case_studies` では、実践的な 3 つの題材で手法の選び方と実装を確認する。
* :doc:`13_summary` では、判断のためのチェックリストを示して全体をまとめる。

用語の意味は :doc:`14_glossary` にまとめている。:doc:`04_choosing` を先に読み、必要に応じて各手法の章に進む読み方もできる。

サンプルコードの実行方法
------------------------

各章のサンプルコードは、本文中のファイル名のリンクからダウンロードできる。サンプルコードは標準ライブラリだけで動作するため、追加のパッケージをインストールする必要はない。ダウンロードしたファイルは、次のように実行する。

.. code-block:: console

   python cpu_vs_io.py

macOS や Linux では ``python`` の代わりに ``python3`` を使う場合がある。

本文に示す実行結果や計測値は、執筆環境（Windows 11、CPU 16 コア、Python 3.14.6）で実行したときのものである。経過時間は CPU の性能やコア数、OS、ほかに動いているプログラムによって変わるため、目安として扱ってほしい。手元の環境で実行し、自分の環境での傾向を確かめることを勧める。
