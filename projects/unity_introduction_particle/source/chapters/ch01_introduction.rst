第 1 章 はじめに
================

本資料の目的
------------

ゲームの画面では、炎、煙、爆発、雨、魔法の光など、形が定まらずに刻々と変化するものが数多く登場する。こうした表現は、小さな粒をたくさん放出し、1 つ 1 つの粒の位置や色を時間とともに変えることで作る。この粒をパーティクル、パーティクルを使った表現をパーティクルエフェクトという。

本資料の目的は、Unity でパーティクルエフェクトを作るための基本を身に付けることである。本資料を読み終えると、次のことができるようになる。

* Particle System のモジュールを組み合わせて、炎や爆発などのエフェクトを作る。
* パーティクルの見た目を決めるマテリアルを URP で設定する。
* C# スクリプトから Particle System を再生・停止し、パラメーターを変更する。
* パーティクルが多すぎて処理が重くなる原因を理解し、対策する。
* VFX Graph で、GPU を使って大量のパーティクルを扱う。

対象読者
--------

本資料は、次のような人を対象にしている。

* Unity のエディターの基本操作（シーン、GameObject、コンポーネント、Inspector ウィンドウ、プレハブ）が分かる。
* C# の基本文法（クラス、メソッド、if 文、for 文）が分かる。C# は、第 9 章以降のスクリプトを扱う部分で使う。

シェーダーの知識は必要ない。パーティクルの見た目に関わるシェーダーの設定は、第 7 章で必要な範囲だけを説明する。

--------

本資料は、次の環境を前提にしている。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - 内容
   * - Unity

レンダーパイプラインについて
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

レンダーパイプラインは、シーンを画面に描画する一連の処理である。Unity 6 には、主に次の 3 つのレンダーパイプラインがある。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - レンダーパイプライン
     - 特徴
   * - Universal Render Pipeline（URP）
     - スマートフォンから PC、家庭用ゲーム機まで、幅広い環境で動くように作られたレンダーパイプライン。本資料で扱う。
   * - High Definition Render Pipeline（HDRP）
     - 高性能な PC や家庭用ゲーム機向けに、写実的な描画を目指したレンダーパイプライン。
   * - Built-in Render Pipeline
     - URP と HDRP が登場する前から使われている、従来のレンダーパイプライン。古いプロジェクトや、古い資料で使われていることが多い。

Particle System は、3 つのレンダーパイプラインのどれでも使える。ただし、パーティクルの描画に使うシェーダーの名前が異なる（第 7 章を参照）。インターネット上の資料には Built-in Render Pipeline を前提にしたものも多いため、読むときはどのレンダーパイプラインの資料かを確認するとよい。

一方、第 4 部で扱う VFX Graph は、URP と HDRP でだけ使える。Built-in Render Pipeline では使えない。

本資料の構成
------------

本資料は、4 つの部と付録で構成している。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 部
     - 内容
   * - 第 1 部 基礎
     - パーティクルの考え方と、Particle System の基本操作を学ぶ（第 1 章～第 3 章）。
   * - 第 2 部 Particle System のモジュール
     - Particle System を構成するモジュールを、役割ごとに学ぶ（第 4 章～第 8 章）。
   * - 第 3 部 スクリプトと実践
     - C# スクリプトからの制御、エフェクトの作例、パフォーマンスの考え方を学ぶ（第 9 章～第 11 章）。
   * - 第 4 部 VFX Graph
     - GPU でパーティクルを扱う VFX Graph の基礎と使い方を学ぶ（第 12 章、第 13 章）。
   * - 付録
     - 用語集、よくあるトラブルと対処法、参考資料をまとめる。

第 2 部までは、スクリプトを書かずに Inspector ウィンドウでの設定だけでエフェクトを作る。初めて Particle System に触れる場合は、第 1 部から順に読み進めてほしい。

表記の約束
----------

本資料では、次の表記を使う。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 表記
     - 意味
   * - :menuselection:`GameObject --> Effects --> Particle System`
     - メニューの項目を、上の階層から順に選ぶ。
   * - :guilabel:`Start Lifetime`
     - Inspector ウィンドウなどに表示される、ボタンや設定項目の名前。
   * - ``ParticleSystem``
     - C# のクラス名、メソッド名、変数名などのコード。

Unity のエディターは英語の表示を前提にしている。設定項目の名前は、Unity のエディターの表示に合わせて英語で書く。

サンプルコード
--------------

本資料のサンプルコードは、各章の本文で閲覧・ダウンロードできる。すべてのサンプルをまとめた zip ファイルは、トップページからダウンロードできる。

zip ファイルの ``examples`` フォルダーには、章ごとに ``chapter09`` のような名前のフォルダーがあり、その章で使う C# スクリプトが入っている。使うときは、スクリプトを Unity のプロジェクトの ``Assets`` フォルダーの中にコピーする。``examples`` フォルダーの ``.editorconfig`` は、サンプルコードの書式を定めた設定ファイルである。Unity での動作には必要ない。
