Unity パーティクル入門
======================

本資料は、Unity の基本操作を身に付けた人が、パーティクルを使ったエフェクトを作れるようになるための入門資料である。Unity 6 の Universal Render Pipeline（URP）を対象に、組み込みの Particle System の使い方を一通り学び、C# スクリプトからの制御とパフォーマンスの考え方を身に付ける。最後に、GPU で大量のパーティクルを扱う VFX Graph を学ぶ。

サンプルコードは、各章の本文から閲覧・ダウンロードできる。すべてのサンプルをまとめた zip ファイルは、:download:`こちら <_generated/unity_introduction_particle_examples.zip>` からダウンロードできる。
