.. _ch04:

第 4 章 距離と測地線
====================

この章では、第 3 章で導入した計量から、曲線の長さと 2 点の距離を求める。さらに、測地線の性質と、双曲幾何学を特徴づける平行線のふるまいを調べる。

曲線の長さ
----------

計量 :math:`ds` が与えられると、曲線の長さは :math:`ds` を曲線に沿って積分して求まる。上半平面モデルでは、曲線を :math:`z(t) = x(t) + i y(t)` （:math:`a \le t \le b`）と表すと、その双曲的な長さは

.. math::
   :label: eq-ch04-length

   L = \int_a^b \frac{|z'(t)|}{y(t)} \, dt = \int_a^b \frac{\sqrt{x'(t)^2 + y'(t)^2}}{y(t)} \, dt

である。

最も簡単な例として、虚軸上の点 :math:`ia` から :math:`ib` （:math:`0 < a < b`）への線分を考える。:math:`z(t) = it` （:math:`a \le t \le b`）とすると :math:`|z'(t)| = 1`、:math:`y(t) = t` なので

.. math::

   L = \int_a^b \frac{dt}{t} = \ln \frac{b}{a}

となる。たとえば :math:`i` から :math:`2i` までの長さは :math:`\ln 2 \approx 0.693` であり、:math:`2i` から :math:`4i` までの長さも同じ :math:`\ln 2` である。ユークリッドの長さは 2 倍になっているが、双曲的な長さは等しい。上に行くほど、同じ双曲的な長さに対応するユークリッドの長さが長くなる。逆に実軸に向かって下りていくと、:math:`a \to 0` で :math:`L \to \infty` となり、実軸には有限の長さでは届かない。実軸が「無限遠」であるのはこの意味である。

この線分は、:math:`ia` と :math:`ib` を結ぶ最短の曲線である。:math:`ia` から :math:`ib` への任意の曲線について、:math:`|z'(t)| \ge |y'(t)|` であるから

.. math::

   L \ge \int_a^b \frac{|y'(t)|}{y(t)} \, dt \ge \int_a^b \frac{y'(t)}{y(t)} \, dt = \ln \frac{b}{a}

が成り立つ。等号は、曲線が虚軸に沿ってまっすぐ上るときに限られる。こうして、虚軸（一般に実軸に垂直な半直線）が測地線であることが確かめられる。

.. _ch04-formula:

距離の公式
----------

2 点 :math:`z`、:math:`w` を結ぶ曲線の長さの最小値を、2 点の\ :term:`双曲距離`\ :math:`d(z, w)` という。上半平面モデルでは、次の式で求まる。

.. math::
   :label: eq-ch04-half-plane-distance

   \cosh d(z, w) = 1 + \frac{|z - w|^2}{2 \Im z \, \Im w}

この式は、次の 2 段階で確かめられる。

1. 2 点が虚軸上にあるとき（:math:`z = ia`、:math:`w = ib`）、右辺は :math:`1 + (b - a)^2 / (2ab) = (a^2 + b^2) / (2ab)` である。一方、:math:`\cosh (\ln (b/a)) = (b/a + a/b) / 2` も同じ値なので、前節の結果と一致する。
2. 双曲平面には、距離を変えずに点を動かす変換（等長変換、\ :ref:`第 5 章 <ch05>`\ ）が豊富にあり、任意の 2 点を虚軸上の 2 点に移せる。右辺の式は、それらの変換で値が変わらないことが計算で確かめられる。

同じ距離を、:math:`\artanh` を使って

.. math::

   d(z, w) = 2 \artanh \left| \frac{z - w}{z - \bar{w}} \right|

と書くこともできる（\ :ref:`付録 A <appendix-a>`\ の公式で、式 :eq:`eq-ch04-half-plane-distance` と同じ値になることが確かめられる）。

ほかのモデルの距離の公式もまとめておく。

.. list-table:: 各モデルの距離の公式
   :name: tab-ch04-distance
   :header-rows: 1
   :widths: 20 80

   * - モデル
     - 距離 :math:`d`
   * - 上半平面
     - :math:`\cosh d = 1 + \dfrac{|z - w|^2}{2 \Im z \, \Im w}`
   * - 円板
     - :math:`\cosh d = 1 + \dfrac{2 |z - w|^2}{(1 - |z|^2)(1 - |w|^2)}`、または :math:`d = 2 \artanh \left| \dfrac{z - w}{1 - \bar{w} z} \right|`
   * - 双曲面
     - :math:`\cosh d = B(x, y) = x_0 y_0 - x_1 y_1 - x_2 y_2`
   * - クライン
     - :math:`\cosh d = \dfrac{1 - k \cdot m}{\sqrt{(1 - |k|^2)(1 - |m|^2)}}`

円板モデルで、中心 :math:`0` から点 :math:`z` までの距離は、:math:`w = 0` とおいて

.. math::
   :label: eq-ch04-disk-origin

   d(0, z) = 2 \artanh |z| = \ln \frac{1 + |z|}{1 - |z|}

となる。逆に、中心から双曲距離 :math:`r` の点は、ユークリッドの半径 :math:`\tanh (r/2)` の円周上にある。:math:`r = 1, 2, 3, 5, 10` に対して :math:`\tanh (r/2) \approx 0.462, 0.762, 0.905, 0.987, 0.99991` であり、遠い点ほど境界に押し込められる。

数値で確かめる
--------------

計量 :eq:`eq-ch04-length` の積分を数値計算し、距離の公式と比べる。上半平面の曲線を細かい折れ線で近似し、各区間のユークリッドの長さを、区間の中点の高さで割って足し合わせる。

.. literalinclude:: ../examples/ch04_length.py
   :pyobject: curve_length
   :lineno-match:
   :caption: ch04_length.py の curve_length()

次の 3 本の曲線の長さを計算した。

* :math:`i` から :math:`2i` への垂直な線分（測地線）
* :math:`-1 + i` から :math:`1 + i` への水平な線分
* 同じ 2 点を結ぶ、中心 :math:`0`、半径 :math:`\sqrt{2}` の半円の弧（測地線）

.. literalinclude:: ../build/outputs/ch04_length.txt
   :language: text
   :caption: ch04_length.py の実行結果

サンプルの全体：:download:`ch04_length.py <../examples/ch04_length.py>`

水平な線分は、上半平面の図の上では 2 点を結ぶ最短の線に見えるが、双曲的な長さは 2 であり、半円の弧の長さ :math:`\arcosh 3 \approx 1.763` より長い。半円の弧は、いったん上（:math:`y` が大きく、双曲的には「短く測れる」場所）へ回り込むことで、全体の長さを短くしている。

同じ大きさの図形の見え方
------------------------

双曲距離が等しくても、モデルの上での見かけの大きさは場所によって違う。\ :numref:`fig-ch04-equal-circles`\ は、双曲的な半径がどれも 0.5 の円を、2 つのモデルのいろいろな位置に描いたものである。

.. figure:: ../build/figures/ch04_equal_circles.svg
   :name: fig-ch04-equal-circles
   :width: 95%
   :align: center

   双曲的な半径 0.5 の円を、上半平面モデル（左）と円板モデル（右）に描いたもの

サンプルの全体：:download:`ch04_equal_circles.py <../examples/ch04_equal_circles.py>`

双曲平面の円は、どちらのモデルでもユークリッドの円として描かれる。ただし、ユークリッドの円の中心は双曲的な円の中心と一致しない。上半平面モデルでは、中心 :math:`x + iy`、双曲的な半径 :math:`r` の円は、中心 :math:`x + iy \cosh r`、半径 :math:`y \sinh r` のユークリッドの円になり、上方にずれる。

左の図で、各段の円は高さが 2 倍ずつ違い、横の間隔も高さに比例させてある。どの円も双曲平面では同じ大きさであり、\ :ref:`第 5 章 <ch05>`\ で示すように、:math:`z \mapsto 2z` は距離を変えない変換である。右の図では、境界に近い円ほど小さく描かれている。円板モデルの住人から見れば、どの円も同じ大きさであり、境界に近づいても世界の「果て」は見えない。

測地線の性質
------------

双曲平面の測地線は、ユークリッド平面の直線と多くの性質を共有する。

* 異なる 2 点を通る測地線は、ちょうど 1 本ある。
* 測地線は、両方向に限りなく延びる（長さが無限である）。
* 測地線は双曲平面を 2 つの部分に分ける。

モデルの上では、測地線の両端は 2 つの無限遠点にある。逆に、異なる 2 つの無限遠点を結ぶ測地線は、ちょうど 1 本ある。たとえば円板モデルでは、境界の 2 点で単位円に直交する円弧が 1 本だけ決まる。

.. _ch04-parallels:

平行線
------

いよいよ、平行線公準が成り立たないことを確かめる。測地線 :math:`L` と、その上にない点 :math:`P` を考える。:math:`P` から :math:`L` に下ろした垂線の長さを :math:`h` とする。

円板モデルで、:math:`P` を中心 :math:`0` に置いた図が\ :numref:`fig-ch04-parallels`\ である。:math:`P` を通る測地線は円板の直径であり、:math:`L` は :math:`P` から距離 :math:`h = 1` の位置にある円弧（黒の太線）である。

.. figure:: ../build/figures/ch04_parallels.svg
   :name: fig-ch04-parallels
   :width: 60%
   :align: center

   点 :math:`P` を通る測地線と、測地線 :math:`L` の関係（:math:`h = 1`）

サンプルの全体：:download:`ch04_parallels.py <../examples/ch04_parallels.py>`

:math:`P` を通る測地線は、:math:`L` との関係によって 3 種類に分かれる。

* 青の破線：:math:`L` と交わる測地線。
* 赤の太線：:math:`L` の端の無限遠点（赤の点）を通る測地線。:math:`L` とは交わらないが、無限遠点に向かって :math:`L` との距離が限りなく 0 に近づく。これを :math:`L` の\ :term:`極限平行線`\ という。:math:`P` を通る極限平行線は、:math:`L` の両端に向かう 2 本がある。
* 緑の線：2 本の極限平行線の間にあり、:math:`L` と交わらず、無限遠点も共有しない測地線。これを :math:`L` の\ :term:`超平行線`\ という。超平行線は無数にある。

ユークリッド平面では、極限平行線と超平行線の区別はなく、:math:`P` を通る平行線は 1 本だけである。双曲平面では、:math:`L` と交わらない測地線が無数にある。

垂線と極限平行線のなす角 :math:`\Pi(h)` を\ :term:`平行角`\ という。ロバチェフスキーが見いだしたように、平行角は距離 :math:`h` だけで決まり、

.. math::
   :label: eq-ch04-parallel-angle

   \tan \frac{\Pi(h)}{2} = e^{-h}, \qquad \text{同値な形として} \quad \cos \Pi(h) = \tanh h

が成り立つ。:math:`h \to 0` で :math:`\Pi(h) \to \pi/2` （ユークリッドの場合と同じく、平行線は垂線に直角）、:math:`h \to \infty` で :math:`\Pi(h) \to 0` となる。:math:`h = 1` では :math:`\Pi(1) \approx 0.705` （約 40.4 度）であり、\ :numref:`fig-ch04-parallels`\ の赤の線と、上向きの垂線（点線）のなす角がこれにあたる。:math:`L` から遠い点ほど、:math:`L` と交わる測地線の範囲が狭くなる。

2 本の測地線の関係は、まとめると次の 3 通りである。

.. list-table:: 2 本の測地線の関係
   :header-rows: 1
   :widths: 25 75

   * - 関係
     - 性質
   * - 交わる
     - 1 点で交わる。交点から離れるほど、測地線の間の距離は増える。
   * - 極限平行
     - 無限遠点を 1 つ共有する。その無限遠点に向かって距離が 0 に近づき、反対側では距離が限りなく増える。
   * - 超平行
     - 共通の垂線をちょうど 1 本持ち、その垂線の位置で最も近い。そこから両側に離れるほど、距離が限りなく増える。

この章のまとめ
--------------

* 曲線の長さは計量の積分で求まる。上半平面モデルで垂直な線分の長さは :math:`\ln (b/a)` である。
* 2 点の距離は、各モデルで簡単な式で求まる（\ :numref:`tab-ch04-distance`\ ）。
* 双曲的に同じ大きさの図形でも、モデルの上では境界に近いほど小さく見える。
* 直線の外の 1 点を通り、その直線と交わらない測地線は無数にある。その境目が極限平行線であり、平行角は :math:`\tan (\Pi(h)/2) = e^{-h}` で決まる。
