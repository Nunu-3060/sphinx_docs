はじめに
========

本書の目的
----------

双曲幾何学は、平面幾何学から平行線公準（\ :ref:`第 1 章 <ch01>`\ ）だけを取り替えて得られる幾何学である。「三角形の内角の和が 180 度より小さい」「円周が半径に対して指数関数的に長くなる」など、ユークリッド幾何学とは異なる性質を持つ。

双曲幾何学の教科書の多くは、公理系やリーマン幾何学から説明を始める。本書はエンジニア向けに、次の方針をとる。

* 双曲平面を、複素数の座標と長さの測り方（計量）を持つ具体的な「モデル」として扱う。
* 定理の証明は要点だけを示し、公式の意味と使い方を中心に説明する。
* ユークリッド平面、球面と常に比べ、違いを「曲率の符号の違い」として理解する。
* 公式は Python で数値的に確かめ、図を描いて目で確認する。

本書を読み終えると、双曲平面の 4 つの代表的なモデルの間を行き来しながら、距離、角度、面積を計算できるようになる。また、機械学習やネットワーク科学の論文に現れる「双曲空間」の考え方を理解する準備が整う。

対象読者と前提知識
------------------

対象読者は、工学系の大学生とエンジニアである。次の知識を前提とする。

* 微分積分（1 変数の積分、偏微分の基礎）
* 線形代数（行列の積、行列式、トレース）
* 複素数（極形式 :math:`re^{i\theta}`、複素共役、絶対値）
* Python の基本的な文法と、NumPy、matplotlib の基本的な使い方

双曲線関数（:math:`\cosh`、:math:`\sinh`、:math:`\tanh`）とメビウス変換は本文で使うので、なじみがなければ先に\ :ref:`付録 A <appendix-a>`\ と\ :ref:`付録 B <appendix-b>`\ を読むとよい。リーマン幾何学や微分幾何学の知識は仮定しない。

記法と約束
----------

本書では次の記法を使う。

.. list-table:: 本書の記法
   :header-rows: 1
   :widths: 30 70

   * - 記法
     - 意味
   * - :math:`K`
     - ガウス曲率。断りがなければ双曲平面の曲率は :math:`K = -1` とする。
   * - :math:`\HH`
     - 上半平面 :math:`\{ z \in \CC \mid \Im z > 0 \}`
   * - :math:`\DD`
     - 単位円板 :math:`\{ z \in \CC \mid |z| < 1 \}`
   * - :math:`d(z, w)`
     - 2 点 :math:`z`、:math:`w` の双曲的な距離
   * - :math:`\bar{z}`
     - 複素数 :math:`z` の複素共役
   * - :math:`\arcosh`、:math:`\artanh`
     - :math:`\cosh`、:math:`\tanh` の逆関数（\ :ref:`付録 A <appendix-a>`\ ）

曲率を :math:`K = -1` に固定するのは、公式を簡単にするためである。ユークリッド幾何学で長さの単位を自由に選べるのと異なり、双曲幾何学には長さの「自然な単位」がある。曲率が :math:`K = -1/R^2` の双曲平面は、:math:`K = -1` の双曲平面の長さをすべて :math:`R` 倍したものであり、:math:`K = -1` の公式の長さ :math:`\ell` を :math:`\ell / R` に置き換えれば得られる（面積は :math:`R^2` 倍になる）。

本書では、ユークリッド幾何学での「直線」にあたる双曲平面の曲線を\ :term:`測地線`\ と呼ぶ。モデルの図の上では曲がって見えるが、双曲平面の中では最短経路であり、まっすぐな線である。

サンプルコード
--------------

本文の図と計算結果は、すべて ``examples`` フォルダーの Python のサンプルで作成している。文書をビルドするたびにサンプルが実行され、図と実行結果が作り直される。各節の「サンプルの全体」のリンクからファイルを閲覧・ダウンロードでき、\ :ref:`付録 E <appendix-e>`\ に一覧がある。

サンプルの実行には、次のパッケージが必要である。

.. code-block:: console
   :linenos:

   $ python -m pip install numpy matplotlib

本書の執筆時には Python 3.14、NumPy 2.5、matplotlib 3.11 で動作を確認している。
