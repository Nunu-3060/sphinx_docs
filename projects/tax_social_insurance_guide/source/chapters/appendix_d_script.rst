付録 D 手取り概算スクリプト
============================================================================

この付録では、給与収入（年収）から社会保険料・所得税・住民税・手取り額を概算する Python のスクリプトを紹介する。本書の :doc:`02_overview` と :doc:`13_income_walls` のグラフも、このスクリプトを使って作成している。

スクリプトは次のリンクからダウンロードできる。

* :download:`take_home_pay.py <../../examples/take_home_pay.py>`

計算の前提
----------------------------------------------------------------------------

このスクリプトは、仕組みを理解するための概算を目的としている。次の前提を置いているため、実際の金額とは異なる場合がある。

.. list-table:: 計算の前提
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - 前提
   * - 対象とする収入
     - 2026 年中の給与収入だけがある会社員またはパートタイマー。賞与はなく、毎月同じ額の給与を受け取る
   * - 社会保険
     - 協会けんぽと厚生年金保険に加入する。健康保険料率は全国平均の 9.9 %、介護保険料率は 1.62 %（40 歳以上 65 歳未満）、子ども・子育て支援金率は 0.23 %、厚生年金保険料率は 18.3 %、雇用保険料率（本人負担）は 0.5 %
   * - 標準報酬月額
     - 等級表は使わず、月給をそのまま標準報酬月額とみなす（上限と下限は考慮する）
   * - 所得控除
     - 基礎控除と社会保険料控除のみ（扶養親族はない）
   * - 所得税
     - 2026 年分の制度で計算する（給与所得控除の最低保障額 74 万円、基礎控除最大 104 万円、復興特別所得税 2.1 %）
   * - 住民税
     - 2026 年の所得に対して 2027 年度に課される額を計算する。均等割は森林環境税を含めて 5,000 円とし、非課税限度額は単身・1 級地の基準（合計所得金額 45 万円）を使う
   * - 扶養に入る場合
     - ``--no-social-insurance`` を指定すると、社会保険料を負担しないものとして計算する

使い方
----------------------------------------------------------------------------

Python 3.10 以上が必要である。標準ライブラリだけを使っているため、追加のパッケージは不要である。コマンドプロンプトやターミナルで、スクリプトを保存したフォルダに移動し、次のように実行する。

.. code-block:: text
   :linenos:

   python take_home_pay.py 5000000
   python take_home_pay.py 5000000 --age 45
   python take_home_pay.py 1200000 --no-social-insurance

1 行目は年収 500 万円（30 歳）の場合、2 行目は年収 500 万円で 45 歳（介護保険料を負担する）の場合、3 行目は年収 120 万円で家族の扶養に入っている場合の計算である。

1 行目を実行すると、次のように表示される。

.. code-block:: text
   :linenos:

   年収（給与収入）           5,000,000 円

     健康保険料                 247,500 円
     介護保険料                       0 円
     子ども・子育て支援金         5,748 円
     厚生年金保険料             457,500 円
     雇用保険料                  25,000 円
   社会保険料の合計             735,748 円

     所得税（復興税を含む）      91,000 円
     住民税                     241,900 円
   税金の合計                   332,900 円

   手取り（概算）             3,931,352 円（年収の 78.6 %）

スクリプトの構成は次のとおりである。

.. list-table:: 主な関数
   :header-rows: 1
   :widths: 35 65

   * - 関数
     - 役割
   * - ``social_insurance``
     - 年収と年齢から、本人が負担する各社会保険料を計算する
   * - ``salary_income_deduction``
     - 給与所得控除額を計算する
   * - ``basic_deduction_income_tax``
     - 所得税の基礎控除額（2026 年分）を求める
   * - ``income_tax``
     - 所得税と復興特別所得税を計算する
   * - ``resident_tax``
     - 住民税（所得割と均等割）を計算する
   * - ``calculate``
     - 上記を組み合わせて、計算結果をまとめる
   * - ``report``
     - 計算結果を表示用の文字列にする

料率や控除額は、ファイルの先頭の ``Assumptions`` クラスと定数にまとめている。自分の加入する健康保険の料率に合わせたい場合や、制度が改正された場合は、これらの値を書き換えればよい。たとえば、健康保険料率を 10.0 % にする場合は ``health_rate`` を ``0.100`` に変更する。
