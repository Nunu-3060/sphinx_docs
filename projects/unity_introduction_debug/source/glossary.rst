.. _glossary:

用語集
======

本資料で使用する主な用語を、五十音順（英字で始まる用語はアルファベット順で先頭）にまとめます。

.. glossary::

   fps
      frames per second の略で、1 秒間に画面を更新する回数（フレームレート）を表す単位です。

   GC アロケーション
      C# のスクリプトで、マネージドヒープにメモリを確保することです。多いとガベージコレクションが頻繁に実行されます。

   LOD
      Level of Detail の略で、カメラからの距離に応じて、詳細度の異なるメッシュを切り替えて描画する仕組みです。

   SetPass コール
      描画に使うシェーダーなどの設定を切り替える処理です。CPU の負荷が大きい処理です。

   イベント関数
      ``Awake``、``Start``、``Update`` など、Unity から自動的に呼び出される MonoBehaviour のメソッドです。

   オーバードロー
      同じピクセルが、1 フレームの中で何度も描画されることです。

   オブジェクトプール
      使い終わったオブジェクトを破棄せずに保管し、再利用する手法です。

   ガベージコレクション
      使われなくなったマネージドメモリを探して解放する処理です。実行中はメインスレッドの処理が止まります。

   カリング
      描画する必要のないオブジェクトを、描画の対象から外す処理です。

   シリアライズ
      Inspector ウィンドウで設定した値などを、シーンやプレハブのファイルに保存する仕組みです。

   スタックトレース
      例外やログが発生した時点での、メソッドの呼び出しの履歴です。

   スパイク
      特定のフレームだけ処理時間が突出して長くなることです。画面のカクつきとして感じられます。

   ドローコール
      CPU が GPU に送る描画の指示です。

   バッチング
      複数のオブジェクトの描画をまとめて、描画の指示にかかるコストを減らす仕組みです。

   ブレークポイント
      デバッガーで、実行を一時停止する位置として指定したコードの行です。

   プロファイリング
      プログラムの処理時間やメモリの使用量を計測し、ボトルネックを特定する作業です。

   ボトルネック
      処理時間の大部分を占め、全体の性能を制限している部分です。

   マネージドヒープ
      C# のスクリプトで生成したオブジェクトや配列が置かれるメモリ領域です。ガベージコレクターが管理します。

   ミップマップ
      テクスチャを縮小表示するときのために、あらかじめ段階的に縮小して用意した画像の集まりです。
