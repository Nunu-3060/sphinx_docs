ゲームデザイン・レベルデザイン入門
==================================

本書は、ゲーム制作は未経験だが Python などのプログラミングの知識があるエンジニアや工学系の大学生に向けて、ゲームデザインとレベルデザインの基本的な考え方を解説する入門書である。

「面白さ」は感性だけで決まるものではない。本書では、ゲームを状態と規則からなるシステムとして捉え、仮説を立て、作って確かめ、直すという設計の手順でゲームとレベルを組み立てる方法を学ぶ。理論は具体的なゲームの例と Python のサンプルコードで確かめながら進める。
