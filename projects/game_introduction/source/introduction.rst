はじめに
========

本書の目的
----------

ゲームは、誰もが一度は遊んだことのある身近なものである。しかし「ゲームとは何か」「なぜ面白いのか」と聞かれて、筋道を立てて答えられる人は多くない。本書は、この問いに次の 3 段階で答えることを目的とする。

.. list-table:: 本書の構成
   :header-rows: 1
   :widths: 20 40 40

   * - 部
     - 内容
     - 問い
   * - 第 1 部　ゲームを知る
     - 定義、歴史、種類
     - ゲームとは何か。どこから来て、どのような種類があるか
   * - 第 2 部　ゲームの仕組み
     - 制作、数理、デザイン
     - ゲームはどう作られ、何が面白さを生むのか
   * - 第 3 部　ゲームを遊ぶ
     - 遊び方、分析的に遊ぶ、社会
     - 実際に遊んで、学んだことを確かめる

本書の中心は第 3 部である。第 1 部と第 2 部は、第 3 部でゲームを選び、遊び、分析するための道具をそろえる役割を持つ。1〜8 章の終わりには、遊んで確かめる短い演習を置いた。

対象読者
--------

本書は次のような読者を想定する。

* Python などのプログラミングの経験があるエンジニア、または工学系の大学生
* ゲーム制作の経験は無い、または浅い
* アナログゲームとデジタルゲームの両方を楽しむ

ゲーム制作の知識は前提としない。数理の章（5 章）では高校程度の確率と、二進数の排他的論理和を使う。

読み方
------

最初から順に読むことを想定しているが、早く第 3 部に進みたい場合は、:doc:`part1_know/overview` → :doc:`part2_mechanism/design` → :doc:`part3_play/how_to_play` → :doc:`part3_play/analytical_play` の順に読み、必要に応じて他の章に戻ってもよい。

本書では、テレビゲーム、ビデオゲーム、コンピューターゲームなどと呼ばれるものをまとめて\ **デジタルゲーム**\ と呼ぶ。また、ボードゲーム、カードゲーム、TRPG など、コンピューターを必要としないゲームをまとめて\ **アナログゲーム**\ と呼ぶ。商用の作品は名前と説明だけで取り上げ、図はすべて本書のために作成した。

動作確認環境
------------

サンプルコードは、2026 年時点の次の環境で動作を確認した。

.. list-table:: 動作確認環境（2026 年時点）
   :header-rows: 1
   :widths: 30 70

   * - ソフトウェア
     - 版と用途
   * - Python
     - 3.14。2、4、5、8 章のサンプル（計算、シミュレーション、小さなゲーム）に使う（3.12 以降で動作する）
   * - numpy、matplotlib
     - 2026 年時点の最新版。``rps.py`` が numpy を、``difficulty_plot.py`` が matplotlib を使う。その他のサンプルは標準ライブラリだけで動く
   * - Godot
     - 4.7.2。4 章と 8 章のサンプルゲーム ``dodge_lab`` に使う

サンプルコードは :doc:`appendix/samples` からダウンロードできる。Python のサンプルは、ダウンロードしたフォルダーで ``py tictactoe.py`` のようにコマンドラインから実行する（macOS や Linux では ``python3 tictactoe.py``）。
