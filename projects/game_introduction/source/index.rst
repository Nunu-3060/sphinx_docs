ゲーム入門
==========

本書は、プログラミングの経験はあるがゲーム制作の経験はあまり無いエンジニアや工学系の学生に向けて、「ゲームとは何か」を、知る、仕組みを理解する、遊んで確かめる、の 3 段階で説明する入門書である。アナログゲーム（ボードゲーム、カードゲームなど）とデジタルゲーム（ビデオゲーム）を区別せずに並べて扱う。
