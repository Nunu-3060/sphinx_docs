第 7 章 確率変数と期待値
========================

第 6 章では事象の確率を扱った。しかし実際に知りたいのは「サイコロの目の和」「アルゴリズムの比較回数」「待ち時間」のように、試行の結果によって決まる\ **数値**\ であることが多い。本章では、試行の結果に数値を対応させる確率変数を導入し、その平均的な値である期待値と、ばらつきの大きさを表す分散を学ぶ。特に、期待値の線形性と指示確率変数を組み合わせる技法は、第 12 章のアルゴリズム解析で中心的な役割を果たす。

確率変数
--------

離散確率空間 :math:`(\Omega, P)` において、各根元事象 :math:`\omega \in \Omega` に実数 :math:`X(\omega)` を対応させる写像 :math:`X\colon \Omega \to \mathbb{R}` を\ :term:`確率変数`\ という。本書の標本空間は有限または可算なので、確率変数のとる値も有限個または可算個であり、このような確率変数を\ **離散確率変数**\ という。

**例**：2 個のサイコロを投げる試行で :math:`\Omega = \{1, \ldots, 6\}^2` とし、根元事象 :math:`\omega = (a, b)` に目の和 :math:`S(\omega) = a + b` を対応させると、:math:`S` は 2 から 12 までの値をとる確率変数である。

確率変数 :math:`X` が値 :math:`x` をとるという事象 :math:`\{\omega \in \Omega \mid X(\omega) = x\}` を、:math:`\{X = x\}` と略記する。その確率は :math:`P(X = x)` と書く。同様に、:math:`P(X \le x)` や :math:`P(a \le X \le b)` などの記法も用いる。

確率質量関数と累積分布関数
--------------------------

離散確率変数 :math:`X` のとりうる値の集合を :math:`\{x_1, x_2, \ldots\}` とする。各値 :math:`x_i` に確率 :math:`P(X = x_i)` を対応させる関数

.. math::

   p_X(x) = P(X = x)

を :math:`X` の\ :term:`確率質量関数`\ という。確率質量関数は :math:`p_X(x) \ge 0` と :math:`\sum_i p_X(x_i) = 1` を満たす。確率変数の値と確率の対応関係を、確率変数の\ **分布**\ （確率分布）という。

また、実数 :math:`x` に対して

.. math::

   F_X(x) = P(X \le x) = \sum_{x_i \le x} p_X(x_i)

で定まる関数を :math:`X` の\ :term:`累積分布関数`\ という。離散確率変数の累積分布関数は、各値 :math:`x_i` で :math:`p_X(x_i)` だけ跳ね上がる階段状の関数である。累積分布関数は単調非減少であり、:math:`x \to -\infty` で 0、:math:`x \to \infty` で 1 に近づく。また、:math:`P(a < X \le b) = F_X(b) - F_X(a)` が成り立つ。

**例**：2 個のサイコロの目の和 :math:`S` の確率質量関数は次のとおりである。

期待値
------

定義
~~~~

離散確率変数 :math:`X` の\ :term:`期待値`\ を次で定める。

.. math::

   E[X] = \sum_{i} x_i \, P(X = x_i)

期待値は、とりうる値をその確率で重み付けした平均である。試行を何度も繰り返したときの :math:`X` の値の平均は :math:`E[X]` に近づく（第 10 章の大数の法則）。:math:`X` が可算無限個の値をとる場合は、右辺の級数が絶対収束するとき（:math:`\sum_i |x_i| P(X = x_i) < \infty` のとき）に限って期待値が存在するという。本書で扱う確率変数の期待値はすべて存在する。

根元事象ごとに足し合わせると、同じ値が次のように書ける。

.. math::

   E[X] = \sum_{\omega \in \Omega} X(\omega) \, p(\omega)

右辺の和を :math:`X(\omega)` の値ごとにまとめると定義の式になるので、両者は等しい。

**例**：サイコロ 1 個の目 :math:`X` の期待値は :math:`E[X] = (1 + 2 + \cdots + 6)/6 = 7/2` である。期待値 :math:`7/2` は :math:`X` がとりうる値ではない。期待値は「最も出やすい値」ではなく、あくまで重み付き平均である。

確率変数の関数の期待値
~~~~~~~~~~~~~~~~~~~~~~

関数 :math:`g` に対して :math:`g(X)` も確率変数であり、その期待値は :math:`g(X)` の分布を求めなくても、:math:`X` の分布から次のように計算できる。

.. math::

   E[g(X)] = \sum_{i} g(x_i) \, P(X = x_i)

たとえば :math:`E[X^2] = \sum_i x_i^2 \, P(X = x_i)` である。一般に :math:`E[g(X)] \ne g(E[X])` であることに注意する。たとえばサイコロの目 :math:`X` では、:math:`E[X^2] = 91/6` であるが、:math:`(E[X])^2 = 49/4` である。

期待値の線形性
~~~~~~~~~~~~~~

**定理（期待値の線形性）**：確率変数 :math:`X, Y` と定数 :math:`a, b, c` について

.. math::

   E[aX + bY + c] = a E[X] + b E[Y] + c

が成り立つ。

**証明**：根元事象ごとの和の表示を使うと

.. math::

   E[aX + bY + c] = \sum_{\omega} (a X(\omega) + b Y(\omega) + c) \, p(\omega) = a \sum_{\omega} X(\omega) p(\omega) + b \sum_{\omega} Y(\omega) p(\omega) + c \sum_{\omega} p(\omega)

であり、:math:`\sum_\omega p(\omega) = 1` より結論が得られる。

この定理で重要なのは、:math:`X` と :math:`Y` が独立である必要がない点である。確率変数がどのように依存し合っていても、和の期待値は期待値の和になる。帰納法により、:math:`n` 個の確率変数についても :math:`E[X_1 + \cdots + X_n] = E[X_1] + \cdots + E[X_n]` が成り立つ。

**例**：2 個のサイコロの目の和 :math:`S = X_1 + X_2` の期待値は、:math:`S` の分布を求めなくても :math:`E[S] = E[X_1] + E[X_2] = 7/2 + 7/2 = 7` と分かる。

指示確率変数
------------

事象 :math:`A` に対して、:math:`A` が起これば 1、起こらなければ 0 をとる確率変数

.. math::

   I_A(\omega) = \begin{cases} 1 & (\omega \in A) \\ 0 & (\omega \notin A) \end{cases}

を :math:`A` の\ :term:`指示確率変数`\ という。指示確率変数の期待値は、事象の確率に等しい。

.. math::

   E[I_A] = 1 \cdot P(A) + 0 \cdot P(\overline{A}) = P(A)

「何かが起こる回数」は、指示確率変数の和として表せる。これと期待値の線形性を組み合わせると、回数の分布を求めなくても期待値を簡単に計算できる。

**例 1**：サイコロを 3 回投げて 6 が出る回数 :math:`X` の期待値を求める。:math:`A_i` を「:math:`i` 回目に 6 が出る」とすると :math:`X = I_{A_1} + I_{A_2} + I_{A_3}` なので、:math:`E[X] = 3 \times (1/6) = 1/2` である。

**例 2（順列の不動点）**：:math:`1, \ldots, n` をランダムに並べ替えたとき（:math:`n!` 通りの順列が同様に確からしいとする）、自分の位置に来る数の個数 :math:`X` の期待値を求める。:math:`A_i` を「数 :math:`i` が :math:`i` 番目の位置に来る」とすると、:math:`P(A_i) = (n - 1)!/n! = 1/n` である。:math:`X = \sum_{i=1}^{n} I_{A_i}` なので

.. math::

   E[X] = \sum_{i=1}^{n} P(A_i) = n \times \frac{1}{n} = 1

となる。:math:`n` がいくつであっても、平均してちょうど 1 個の数が自分の位置に来る。:math:`A_i` 同士は独立でない（たとえば :math:`n - 1` 個が自分の位置に来れば、残りの 1 個も必ず自分の位置に来る）が、期待値の線形性は独立性を必要としないので、この計算は正しい。なお、:math:`P(X = 0)` は第 4 章の攪乱順列の割合 :math:`D(n)/n!` であり、:math:`1/e` に近づく。

分散と標準偏差
--------------

期待値が同じでも、値のばらつき方は確率変数によって異なる。:math:`\mu = E[X]` とするとき、ばらつきの大きさを表す量として、:math:`X` の\ :term:`分散`\ を次で定める。

.. math::

   V[X] = E[(X - \mu)^2]

分散の正の平方根 :math:`\sigma = \sqrt{V[X]}` を\ **標準偏差**\ という。標準偏差は :math:`X` と同じ単位を持つので、ばらつきの大きさを直感的に把握しやすい。

期待値の線形性を使って展開すると、計算に便利な次の公式が得られる。

.. math::

   V[X] = E[X^2 - 2\mu X + \mu^2] = E[X^2] - 2\mu E[X] + \mu^2 = E[X^2] - (E[X])^2

また、定数 :math:`a, b` について :math:`V[aX + b] = a^2 V[X]` が成り立つ。定数 :math:`b` を加えても分布が平行移動するだけでばらつきは変わらず、:math:`a` 倍するとばらつきは :math:`|a|` 倍（分散は :math:`a^2` 倍）になる。

**例**：サイコロ 1 個の目 :math:`X` について、:math:`E[X^2] = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6` なので

.. math::

   V[X] = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{35}{12} \approx 2.92, \qquad \sigma = \sqrt{35/12} \approx 1.71

である。

期待値と異なり、分散は一般に線形ではない。:math:`V[X + Y] = V[X] + V[Y]` は :math:`X` と :math:`Y` が独立な場合などに限って成り立つ。この点は第 9 章で共分散を導入して詳しく扱う。

まとめ
------

* 確率変数は根元事象に実数を対応させる写像であり、その分布は確率質量関数または累積分布関数で表される。
* 期待値 :math:`E[X] = \sum_i x_i P(X = x_i)` は値の重み付き平均である。
* 期待値の線形性 :math:`E[X + Y] = E[X] + E[Y]` は、確率変数が独立でなくても成り立つ。
* 回数は指示確率変数の和で表せる。指示確率変数の期待値は事象の確率に等しいので、回数の期待値は確率の和で求められる。
* 分散 :math:`V[X] = E[X^2] - (E[X])^2` はばらつきの大きさを表し、:math:`V[aX + b] = a^2 V[X]` を満たす。

確率変数と期待値については [Ross2019]_ に詳しい。指示確率変数を使った計算の例は [Mitzenmacher2017]_ に多く収められている。
