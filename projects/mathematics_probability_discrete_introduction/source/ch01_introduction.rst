第 1 章 はじめに
================

本書のねらい
------------

ソフトウェアを作る仕事の中には、離散数学と確率論が姿を変えて現れる場面が多い。たとえば次のような問いは、いずれも本書で扱う道具で答えられる。

* テストケースの組合せは全部で何通りあるか（数え上げ）
* ネットワーク上の 2 地点を結ぶ最短の経路はどれか（グラフ理論）
* 32 ビットのハッシュ値は、何件のデータを登録すると衝突しやすくなるか（確率）
* 乱択アルゴリズムの計算量は平均してどの程度か（期待値）
* 罹患者の 99% を陽性と判定できる検査で陽性と出た人が、本当に罹患している確率はどの程度か（条件付き確率）

本書は、これらの問いに答えるための基礎を、数式による定義と Python による検証の両面から身につけることを目的とする。数式だけでは実感しにくい結果も、全列挙やシミュレーションで数値を確かめると理解しやすくなる。逆に、シミュレーションだけでは「なぜその値になるのか」が分からないので、数式による導出も省略しない。

本書の構成
----------

本書は 3 部からなる。第 I 部では、確率論の土台となる離散数学（集合と論理、写像と関係、数え上げ、グラフ）を学ぶ。第 II 部では、第 I 部の数え上げを使って離散確率を定義し、確率変数・代表的な分布・極限定理・マルコフ連鎖へと進む。第 III 部では、それまでの道具を組み合わせてアルゴリズムの性能を解析する。各章の依存関係を\ :numref:`fig-ch01-dependency` に示す。

各章は、おおむね次の流れで構成している。

#. 導入：その章の道具が何の役に立つか
#. 定義と定理：数式による正確な記述と、短い証明または導出
#. 例題：具体的な数値での計算
#. Python で確かめる：サンプルコードによる全列挙やシミュレーション
#. まとめ

前提知識
--------

数学については、高校数学（数列、:math:`\Sigma` 記号、指数関数・対数関数）の知識を前提とする。微分積分は第 10 章で正規分布を扱う箇所でのみ使い、詳しい計算は行わない。Python については、関数・リスト・辞書・内包表記・クラスの基本と、型ヒントの読み方を前提とする。

実行環境
--------

サンプルコードは Python 3.11 以上を想定している。標準ライブラリに加えて、次のライブラリを使用する。

.. list-table:: 使用するライブラリ
   :header-rows: 1
   :widths: 25 75

   * - ライブラリ
     - 用途
   * - NumPy
     - 配列計算、行列計算、乱数生成
   * - SciPy
     - 確率分布（scipy.stats）の確率質量関数・期待値・分散の計算
   * - matplotlib
     - 本文中の図の作成（サンプルコード自体では使用しない）

サンプルコードは、各章の「Python で確かめる」節からダウンロードできる。実行方法と型検査の方法は\ :doc:`appendix_examples`\ にまとめた。サンプルコードの実行結果のうち乱数を使うものは、乱数の種（シード）を固定しているので、同じ環境では本文と同じ結果が得られる。ただし、ライブラリのバージョンによっては異なる値になることがある。

記法について
------------

本書で用いる主な記号は\ :doc:`appendix_symbols`\ にまとめた。本書では自然数 :math:`\mathbb{N}` に 0 を含めず、:math:`\mathbb{N} = \{1, 2, 3, \ldots\}` とする。対数 :math:`\log` は自然対数（底が :math:`e`）を表す。また、重要な用語は初出時に\ :doc:`glossary`\ へのリンクを付けた。
