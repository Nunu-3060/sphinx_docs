第 5 章 グラフ理論入門
======================

鉄道の路線図、コンピュータネットワーク、SNS の友人関係、モジュールの依存関係などは、いずれも「もの」と「もの同士のつながり」で表せる。このような構造を抽象化したものが\ :term:`グラフ`\ である。グラフは第 11 章のマルコフ連鎖の状態遷移を表す道具にもなる。本章では、グラフの基本的な用語と性質、および最も基本的な探索アルゴリズムである幅優先探索を学ぶ。

グラフの定義
------------

無向グラフ
~~~~~~~~~~

**頂点**\ の集合 :math:`V` と、2 つの頂点を結ぶ\ **辺**\ の集合 :math:`E` の組 :math:`G = (V, E)` を\ **グラフ**\ という。辺に向きがないグラフを\ **無向グラフ**\ といい、頂点 :math:`u, v` を結ぶ辺を :math:`\{u, v\}` と書く。辺 :math:`\{u, v\}` があるとき、:math:`u` と :math:`v` は\ **隣接**\ しているという。

同じ頂点の組を結ぶ辺が複数あるとき、それらを\ **多重辺**\ という。また、ある頂点からそれ自身に戻る辺を\ **自己ループ**\ という。多重辺も自己ループも持たないグラフを\ **単純グラフ**\ という。本書では、特に断らない限りグラフは有限（頂点も辺も有限個）とする。

有向グラフと重み付きグラフ
~~~~~~~~~~~~~~~~~~~~~~~~~~

辺に向きがあるグラフを\ **有向グラフ**\ といい、:math:`u` から :math:`v` への辺を :math:`(u, v)` と書く。一方通行の道路や、タスクの依存関係、Web ページのリンクなどは有向グラフで表される。また、各辺に数値（距離、コスト、確率など）を割り当てたグラフを\ **重み付きグラフ**\ という。第 11 章で扱うマルコフ連鎖の状態遷移図は、辺に遷移確率を割り当てた重み付き有向グラフである。

次数と握手補題
--------------

無向グラフで、頂点 :math:`v` に接続する辺の本数を :math:`v` の\ **次数**\ といい、:math:`\deg(v)` と書く（自己ループは 2 本と数える）。:numref:`fig-ch05-example` の無向グラフ :math:`G` では、:math:`\deg(A) = 2`、:math:`\deg(B) = 3`、:math:`\deg(F) = 1` である。

**定理（握手補題）**：任意の無向グラフ :math:`G = (V, E)` について

.. math::

   \sum_{v \in V} \deg(v) = 2 |E|

が成り立つ。

**証明**：各辺 :math:`\{u, v\}` は、:math:`u` の次数と :math:`v` の次数にそれぞれ 1 ずつ寄与する。したがって、次数の総和では各辺がちょうど 2 回数えられる。

この結果から、次数が奇数の頂点の個数は必ず偶数であることが分かる（次数の総和が偶数なので）。この定理の名前は、パーティーで握手した回数を全員分足すと、握手の総数の 2 倍になることに由来する。これを\ :term:`握手補題`\ という。

道と連結性
----------

頂点の列 :math:`v_0, v_1, \ldots, v_k` で、隣り合う頂点がすべて辺で結ばれているものを、:math:`v_0` から :math:`v_k` への\ **歩道**\ といい、:math:`k` をその\ **長さ**\ という。頂点に重複のない歩道を\ **道**、:math:`v_0 = v_k` で、それ以外の頂点に重複のない長さ 3 以上の歩道を\ **閉路**\ という。

任意の 2 頂点の間に道があるグラフを\ **連結**\ であるという。頂点 :math:`u` から :math:`v` への道のうち、長さが最小のものを\ **最短路**\ といい、その長さを :math:`u` と :math:`v` の\ **距離**\ という。

木
--

連結で閉路を持たない無向グラフを\ :term:`木`\ という。木は、ファイルシステムのディレクトリ構造、構文木、探索木など、情報科学のいたるところに現れる。頂点数 :math:`n` の無向グラフについて、次の条件は互いに同値である。

* 木である（連結で閉路を持たない）。
* 連結で、辺の本数が :math:`n - 1` である。
* 閉路を持たず、辺の本数が :math:`n - 1` である。
* 任意の 2 頂点の間に道がただ 1 つ存在する。

連結グラフ :math:`G` のすべての頂点を含み、:math:`G` の辺の一部からなる木を、:math:`G` の\ **全域木**\ という。全域木は「すべての地点を最小限の配線でつなぐ」といった問題に現れる。

オイラー路
----------

グラフのすべての辺をちょうど 1 回ずつ通る歩道を\ :term:`オイラー路`\ という。同じ頂点は何度通ってもよい。始点と終点が一致するオイラー路を\ **オイラー閉路**\ という。

グラフ理論の起源とされるのが、18 世紀のケーニヒスベルク（現在のカリーニングラード）の橋の問題である。市内を流れる川に 7 本の橋が架かっており、「すべての橋をちょうど 1 回ずつ渡って散歩できるか」が問われた。オイラーは、陸地を頂点、橋を辺とする多重グラフ（:numref:`fig-ch05-konigsberg`）を考え、これが不可能であることを示した。

   :align: center

**定理（オイラー）**：辺を持つ連結な無向グラフについて、

* オイラー閉路が存在するための必要十分条件は、すべての頂点の次数が偶数であることである。
* オイラー路が存在するための必要十分条件は、次数が奇数の頂点が 0 個または 2 個であることである。

必要性は次のように分かる。オイラー路の途中で頂点を通過するたびに、「入る辺」と「出る辺」を 1 本ずつ使う。したがって、始点と終点以外の頂点の次数は偶数でなければならない。ケーニヒスベルクのグラフでは 4 つの頂点すべての次数が奇数なので、オイラー路は存在しない。

二部グラフ
----------

頂点集合を 2 つの集合 :math:`V_1, V_2` に分割し、すべての辺が :math:`V_1` の頂点と :math:`V_2` の頂点を結ぶようにできるグラフを\ :term:`二部グラフ`\ という。たとえば「応募者」と「求人」を頂点とし、応募可能な組を辺で結んだグラフは二部グラフである。

**定理**：グラフが二部グラフであるための必要十分条件は、長さが奇数の閉路を持たないことである。

二部グラフであることは、隣接する頂点を異なる 2 色で塗り分けられることと同じである。長さ 3 の閉路（三角形）は 2 色で塗り分けられないので、二部グラフではない。

グラフの表現
------------

グラフをプログラムで扱うには、主に次の 2 つの表現を使う。頂点を :math:`1, \ldots, n` と番号付けたとする。

* **隣接行列**：:math:`n \times n` 行列 :math:`A` で、頂点 :math:`i` と :math:`j` が隣接していれば :math:`A_{ij} = 1`、そうでなければ :math:`A_{ij} = 0` とする。無向グラフでは対称行列になる。2 頂点が隣接しているかを定数時間で判定できるが、:math:`n^2` に比例するメモリを使う。
* **隣接リスト**：各頂点について、隣接する頂点のリストを持つ。メモリは頂点数と辺の本数の和に比例し、辺の少ないグラフに向いている。

隣接行列には、:math:`A^k` の :math:`(i, j)` 成分が「頂点 :math:`i` から :math:`j` への長さ :math:`k` の歩道の個数」に等しいという性質がある。この性質は、第 11 章で遷移行列のべき乗が「:math:`n` ステップ後の遷移確率」を表すことと対応している。

幅優先探索
----------

辺に重みがないグラフで、ある頂点 :math:`s` から各頂点への最短路を求めるには\ **幅優先探索**\ （BFS：breadth-first search）を使う。幅優先探索では、:math:`s` から距離 0 の頂点、距離 1 の頂点、距離 2 の頂点、……の順に、キュー（先入れ先出しの待ち行列）を使って頂点を訪問する。

#. :math:`s` の距離を 0 とし、:math:`s` をキューに入れる。
#. キューが空でない間、次を繰り返す。

   #. キューの先頭から頂点 :math:`u` を取り出す。
   #. :math:`u` に隣接する頂点 :math:`w` のうち、まだ距離が決まっていないものについて、距離を「:math:`u` の距離 + 1」とし、:math:`w` をキューに入れる。

各頂点と各辺を定数回ずつしか調べないので、計算量は頂点数と辺の本数の和に比例する。幅優先探索を少し変更すると、二部グラフの判定（隣接する頂点に交互に色を付けていき、矛盾が生じないかを調べる）や連結性の判定もできる。

まとめ
------

* グラフは頂点と辺の組であり、無向グラフ・有向グラフ・重み付きグラフがある。
* 握手補題により、次数の総和は辺の本数の 2 倍に等しい。
* 木は連結で閉路を持たないグラフであり、頂点数 :math:`n` の木の辺の本数は :math:`n - 1` である。
* 連結グラフがオイラー路を持つための必要十分条件は、次数が奇数の頂点が 0 個または 2 個であることである。
* 二部グラフは、奇数長の閉路を持たないグラフであり、2 色で塗り分けられる。
* 重みのないグラフの最短路は、幅優先探索で頂点数と辺の本数の和に比例する時間で求められる。

グラフ理論をさらに学ぶには [Rosen2019]_ や [Diestel2017]_ を参照するとよい。
