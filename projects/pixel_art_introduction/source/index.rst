ドット絵作成入門
================

本書は、ゲーム制作の経験は無いが Python などのプログラミングの知識はあるエンジニアに向けて、ドット絵の描き方を基礎から説明する入門書である。ドット絵を「センス」ではなく、判断の基準と手順の積み重ねとして説明する。描く作業は専用のエディタで行い、仕組みの確認や後処理には Python を使う。
