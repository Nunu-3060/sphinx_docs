.. _introduction:

はじめに
========

本書の目的
----------

現在の GPU は、ゲームの描画だけでなく、科学技術計算や機械学習、特に大規模言語モデルの学習と推論を支える中核的な計算資源になっている。しかし、GPU は最初から汎用の並列プロセッサとして設計されたわけではない。3D グラフィックスを高速に描画するという特定の目的のために生まれ、その目的を追求する過程で得た性質が、後に別の分野で価値を持つようになった。

本書は、この変化の過程をたどることで、現在の GPU がなぜ今の形をしているのかを理解することを目的とする。各時代について、次の観点から記述する。

* 背景：どのような需要や制約があったか
* 技術：アーキテクチャやプログラミングモデルの何が変わったか
* 代表的な製品と API
* 影響：次の時代に何を残したか

対象読者
--------

本書は、CPU やメモリの仕組み、並列処理の基礎といった計算機の一般的な知識を持つエンジニアを対象とする。GPU のプログラミング経験やグラフィックスの専門知識は前提としない。必要な基礎知識は「:ref:`basics`」でまとめて説明する。

本書における「GPU」の定義
-------------------------

「GPU」という言葉は、1999 年に NVIDIA が GeForce 256 を発表した際に用いたものである。NVIDIA は GPU を「座標変換、光源計算、三角形のセットアップとクリッピング、レンダリングの各エンジンを 1 つのチップに統合し、毎秒 1,000 万ポリゴン以上を処理できるプロセッサ」と定義した（詳細は「:ref:`fixed_function`」で述べる）。

その後 GPU の役割は大きく広がり、現在では「多数の演算器を持ち、大量のデータを並列に処理することに特化したプロセッサ」という意味で使われることが多い。本書では次のように用語を使い分ける。

.. list-table:: 本書での呼称
   :header-rows: 1
   :widths: 25 75

   * - 呼称
     - 対象
   * - グラフィックスアクセラレータ
     - 1999 年より前の、描画処理の一部をハードウェアで高速化する装置
   * - GPU
     - GeForce 256 以降の、描画パイプラインの大部分を 1 チップで処理するプロセッサ、およびそこから発展した並列プロセッサ

表記について
------------

本書では次の方針で表記を統一する。

* 年は、原則として製品や規格が発表された年を示す。発売や出荷が翌年以降になったものもある。
* 製品の仕様は各社が公表した公称値を用いる。同じ製品でも構成（ボード形状やメモリ容量）によって値が異なる場合は、代表的な構成の値を示す。
* 外来語の語末の長音は、「シェーダ」「メモリ」「コンピュータ」のように省略する。ただし、「データセンター」のように長音を付けた形が定着している語は慣用に従う。
* 製品名、規格名、API 名は各社の正式な表記に従う。本書に記載されている会社名、製品名は、各社の商標または登録商標である。
