グラフィックスの現代化（2013 年〜）
===================================

前章では AI 向けの GPU の発展を述べたが、同じ時期にグラフィックスの分野でも大きな変化が起きた。本章では、低オーバーヘッドの描画 API、リアルタイムレイトレーシング、AI を用いた画像生成技術、新しいジオメトリ処理について述べる。

低オーバーヘッド API
--------------------

2010 年代前半には、GPU の性能が向上する一方で、CPU 側の処理がボトルネックになる場面が増えていた。従来の OpenGL や DirectX 11 では、ドライバがメモリの管理や処理の順序の調整などを暗黙のうちに行っており、描画命令 1 つあたりの CPU の処理量（オーバーヘッド）が大きかった。また、描画命令の発行を複数の CPU コアに分散させることも難しかった。

この問題を解決するため、ドライバの役割を最小限にし、アプリケーションが GPU をより直接的に制御する低オーバーヘッドの API が登場した。

.. list-table:: 主な低オーバーヘッド API
   :header-rows: 1
   :widths: 20 15 65

   * - API
     - 公開年
     - 概要
   * - Mantle
     - 2013 年
     - AMD が開発した API。後の Vulkan の基礎となった。
   * - Metal
     - 2014 年
     - Apple が iOS 向けに導入し、後に macOS にも提供した API。
   * - DirectX 12
     - 2015 年
     - Microsoft が Windows 10 とともに提供した API。
   * - Vulkan
     - 2016 年
     - Khronos Group が策定した、ベンダーやプラットフォームに依存しない API\ [Khronos-Vulkan]_。

これらの API では、アプリケーションがメモリの割り当て、処理の同期、描画命令の記録と送信を明示的に管理する。描画命令を複数のスレッドで並行して記録できるため、マルチコアの CPU を有効に活用できる。その代わり、アプリケーションの開発者には GPU の動作に関するより深い理解が求められるようになった。

リアルタイムレイトレーシング
----------------------------

:term:`レイトレーシング`\ は、視点から画面の各ピクセルに向けて光線（レイ）を飛ばし、光線が物体に当たった点から、さらに光源や他の物体に向けて光線を追跡することで、反射、屈折、影などを物理的に正確に表現する手法である。映画などのオフラインレンダリングでは以前から使われていたが、計算量が膨大であるため、リアルタイムの描画では長らく実用的ではなかった。ゲームでは、ラスタライズを基本とし、反射や影を様々な近似手法で表現するのが一般的であった。

レイトレーシングの計算の大部分は、光線がどの三角形に当たるかを調べる交差判定である。シーンに含まれる数百万の三角形を総当たりで調べることはできないため、三角形を階層的な箱（バウンディングボリューム）で囲んだ :term:`BVH`\ （Bounding Volume Hierarchy）という木構造を用いて、調べる候補を絞り込む。この処理は、木構造をたどるためのメモリアクセスと分岐が多く、従来の GPU の演算器では効率よく実行できなかった。

2018 年、Microsoft は DirectX 12 にレイトレーシングの機能を追加する DirectX Raytracing（DXR）を発表した。同年、NVIDIA は Turing 世代の GeForce RTX 20 シリーズを発表し、BVH の探索と光線と三角形の交差判定を専用回路で実行する :term:`RT コア`\ を搭載した。これにより、ゲームでリアルタイムレイトレーシングを利用できるようになった。2020 年には、AMD の RDNA 2 アーキテクチャがレイトレーシング用の専用回路を搭載し、同年に発売された PlayStation 5 と Xbox Series X|S でも採用された。Vulkan も同年にレイトレーシングの拡張機能を正式に導入している。

当初は、ラスタライズで描画した画像の一部（反射や影など）にだけレイトレーシングを用いるハイブリッド方式が主流であった。その後、ハードウェアの性能向上と後述する AI 技術の組み合わせにより、画面全体の光の伝わり方をレイトレーシングで計算するパストレーシングを採用したゲームも登場している。

AI による超解像とフレーム生成
-----------------------------

レイトレーシングは計算量が多く、高い解像度で十分なフレームレートを得ることは、専用回路を用いても容易ではない。この問題に対して、深層学習の技術をグラフィックスに応用する手法が登場した。

NVIDIA は 2018 年に、低い解像度で描画した画像をニューラルネットワークで高い解像度に変換する技術 DLSS（Deep Learning Super Sampling）を発表した。DLSS は、GPU の Tensor コアを用いてニューラルネットワークの推論を実行する。2020 年の DLSS 2 では、過去のフレームの情報も利用することで画質を大きく改善した。2022 年の DLSS 3 では、描画したフレームの間に新しいフレームを生成するフレーム生成機能を追加し、2025 年の DLSS 4 では、1 枚の描画フレームから複数のフレームを生成できるようにした。

他社も同様の技術を提供している。AMD は 2021 年に FSR（FidelityFX Super Resolution）を公開した。当初はニューラルネットワークを用いない方式で、多くの GPU で動作することを特徴としたが、2025 年の FSR 4 では機械学習を用いる方式に移行した。Intel は 2022 年に XeSS を公開した。

これらの技術により、GPU が描画するピクセルの一部だけを従来の方法で計算し、残りを AI で推定するという考え方が一般的になった。深層学習のために発展した Tensor コアが、グラフィックスの性能向上にも寄与するようになったのである。

ジオメトリ処理の刷新
--------------------

従来のグラフィックスパイプラインでは、頂点処理、テッセレーション、ジオメトリシェーダといった固定的な段階の組み合わせでジオメトリ（形状）を処理していた。これに対し、2018 年の Turing 世代で導入された\ :term:`メッシュシェーダ`\ は、コンピュートシェーダに近い柔軟なプログラミングモデルで、ジオメトリの生成と加工を行う。メッシュシェーダを使えば、画面に映らない部分を GPU 上で細かい単位で除外するなど、大量のジオメトリを効率よく処理できる。

2020 年に Microsoft が発表した DirectX 12 Ultimate は、レイトレーシング（DXR 1.1）、メッシュシェーダ、画面の領域ごとにピクセルシェーダの実行頻度を変える可変レートシェーディング（VRS）などを、PC と Xbox Series X|S の共通の機能としてまとめた\ [Microsoft-DX12U]_。

グラフィックス向け GPU の動向
-----------------------------

この時代のグラフィックス向け GPU の主なアーキテクチャを\ :numref:`table-consumer` に示す。

.. _table-consumer:

.. list-table:: 主なグラフィックス向け GPU のアーキテクチャ
   :header-rows: 1
   :widths: 15 25 60

   * - 年
     - アーキテクチャ
     - 主な特徴
   * - 2018 年
     - NVIDIA Turing
     - RT コアと Tensor コアを搭載し、GeForce RTX ブランドを開始した。
   * - 2019 年
     - AMD RDNA
     - GCN に代わるグラフィックス向けアーキテクチャ。32 スレッドのウェーブフロントを導入した。
   * - 2020 年
     - NVIDIA Ampere、AMD RDNA 2
     - RDNA 2 がレイトレーシング用の回路を搭載した。新世代のゲーム機にも採用された。
   * - 2022 年
     - NVIDIA Ada Lovelace、AMD RDNA 3、Intel Xe-HPG（Arc）
     - RDNA 3 は、グラフィックス向け GPU で初めてチップレット構成を採用した。Intel は単体 GPU 市場に本格参入した。
   * - 2025 年
     - NVIDIA Blackwell、AMD RDNA 4
     - GDDR7 メモリの採用（NVIDIA）、機械学習を用いた超解像（両社）が進んだ。

グラフィックス向け GPU のメモリには、HBM ではなく GDDR 系のメモリが主に使われている。GDDR は HBM より帯域幅で劣るが、安価で、通常のプリント基板上に実装できるためである（「:ref:`trends`」を参照）。

グラフィックスの現代化の意義
----------------------------

この時代に、グラフィックスの処理は「ラスタライズを中心に、すべてのピクセルを地道に計算する」方式から、「レイトレーシングで物理的に正確な光を計算し、その不足を AI で補う」方式へと移行し始めた。そのための専用回路として、RT コアと Tensor コアが GPU に加わった。

固定機能から汎用の演算器へと進んできた GPU が、再び特定の処理に特化した専用回路を取り込み始めたことは興味深い。ただし、これは固定機能の時代への逆戻りではない。プログラマブルな演算器を中心に置き、効果の大きい処理だけを専用回路で高速化するという、汎用性と効率を両立させる設計である。
