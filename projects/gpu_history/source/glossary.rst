.. _glossary:

付録 B 用語集
=============

本書で用いた主な用語を、アルファベット順、五十音順に示す。

.. glossary::

   APU
      Accelerated Processing Unit の略。AMD が用いる名称で、CPU と GPU を 1 つのチップまたはパッケージに統合したプロセッサを指す。

   BVH
      Bounding Volume Hierarchy の略。物体を階層的な箱で囲んだ木構造で、レイトレーシングで光線と交差する可能性のある三角形を効率よく絞り込むために用いる。

   CUDA
      Compute Unified Device Architecture の略。NVIDIA が 2006 年に発表した、GPU で汎用計算を行うためのプラットフォームとプログラミングモデル。C / C++ を拡張した言語でプログラムを記述する。

   Direct3D
      Microsoft の DirectX に含まれる 3D 描画用の API。1996 年の DirectX 2.0 で追加された。DirectX 12 などの版番号は DirectX 全体の版番号で表すことが多い。

   FLOPS
      Floating-point Operations Per Second の略。1 秒あたりに実行できる浮動小数点演算の回数で、演算性能の指標として用いる。GFLOPS（:math:`10^9`）、TFLOPS（:math:`10^{12}`）、PFLOPS（:math:`10^{15}`）、EFLOPS（:math:`10^{18}`）などの単位を用いる。

   GDDR
      Graphics Double Data Rate の略。グラフィックス用に最適化された DRAM の規格群。GPU とは別のチップとして基板上に実装する。

   GPGPU
      General-Purpose computation on GPUs の略。GPU を描画以外の汎用的な計算に利用すること。

   GPU
      Graphics Processing Unit の略。1999 年に NVIDIA が GeForce 256 の発表時に用いた名称。現在では、多数の演算器を持ち、大量のデータを並列に処理することに特化したプロセッサを広く指す。

   HBM
      High Bandwidth Memory の略。複数の DRAM チップを積層し、GPU と同じパッケージ内に実装するメモリの規格。非常に広いバス幅により高い帯域幅を実現する。

   MIG
      Multi-Instance GPU の略。NVIDIA の A100 以降の GPU で、1 つの GPU を最大 7 つの独立したインスタンスに分割する機能。

   NPU
      Neural Processing Unit の略。ニューラルネットワークの推論を低消費電力で実行するための専用プロセッサ。

   NVLink
      NVIDIA が開発した、GPU 同士や GPU と CPU を高速に接続するためのインタフェース。2016 年の P100 で初めて搭載された。

   OpenCL
      Open Computing Language の略。Khronos Group が策定した、GPU や CPU などで並列計算を行うためのベンダーに依存しない標準規格。

   OpenGL
      ベンダーに依存しない 2D / 3D 描画 API の標準規格。1992 年に SGI が公開し、現在は Khronos Group が管理している。

   RT コア
      NVIDIA の GPU に搭載された、レイトレーシングの BVH の探索と、光線と三角形の交差判定を行う専用回路。2018 年の Turing 世代で導入された。

   SIMD
      Single Instruction, Multiple Data の略。1 つの命令で複数のデータを同時に処理する方式。

   SIMT
      Single Instruction, Multiple Threads の略。NVIDIA が用いる名称で、プログラマには個々のスレッドが独立して動作しているように見せつつ、ハードウェアでは一定数のスレッドをまとめて 1 つの命令で実行する方式。

   SM
      Streaming Multiprocessor の略。NVIDIA の GPU で、演算器、レジスタファイル、共有メモリなどをまとめた処理単位。AMD の CU（Compute Unit）に相当する。

   T&L
      Transform and Lighting の略。頂点の座標変換（Transform）と光源計算（Lighting）を合わせた呼称。1999 年の GeForce 256 でハードウェア化された。

   Tensor コア
      NVIDIA の GPU に搭載された、行列の積和演算を専門に行う演算器。2017 年の V100 で導入された。

   VRAM
      Video RAM の略。GPU に直結された専用のメモリ。

   ウェーブフロント
      AMD の GPU で、1 つの命令でまとめて実行されるスレッドの集団。GCN では 64 スレッド、RDNA では 32 スレッドまたは 64 スレッドである。NVIDIA のワープに相当する。

   演算強度
      メモリから読み書きするデータ 1 バイトあたりの演算回数。単位は FLOP/B。ある処理の性能が演算性能とメモリ帯域幅のどちらで制約されるかを判断するために用いる。

   グラフィックスパイプライン
      3D グラフィックスの描画処理を、頂点処理、ラスタライズ、ピクセル処理、出力合成などの段階に分けて順に実行する処理の流れ。

   固定機能パイプライン
      グラフィックスパイプラインの各段階が専用の回路で実装され、あらかじめ用意された機能の選択とパラメータの設定しかできない構造。

   混合精度
      複数の精度の数値形式を組み合わせて計算する手法。低い精度で計算を高速化しつつ、累積など誤差の影響が大きい部分を高い精度で行う。

   シェーダ
      グラフィックスパイプラインの特定の段階で GPU が実行するプログラム。頂点シェーダ、ピクセルシェーダ、コンピュートシェーダなどの種類がある。

   シェーダモデル
      DirectX において、GPU が対応すべきシェーダの機能水準を示す版番号。

   スループット
      単位時間あたりに処理できる仕事の量。

   タイルベースレンダリング
      画面を小さな矩形の領域（タイル）に分割し、タイルごとにチップ内のメモリ上で描画を完結させる方式。チップ外のメモリへのアクセスを減らし、消費電力を抑える。

   チップレット
      1 つの大きなチップの代わりに複数の小さなチップを製造し、パッケージ内で接続して 1 つのプロセッサとして動作させる手法。また、その個々の小さなチップ。

   頂点シェーダ
      頂点ごとに実行され、座標変換などの頂点処理を行うシェーダ。

   テクスチャ
      物体の表面に貼り付ける画像。GPGPU では、計算用のデータを格納する入れ物としても用いられた。

   データ並列性
      同じ種類の処理を、大量のデータに対して互いに独立に適用できる性質。

   統合シェーダ
      頂点シェーダ、ピクセルシェーダなどの種類を問わず、同じ汎用の演算器でシェーダを実行するアーキテクチャ。

   ピクセルシェーダ
      ピクセルごとに実行され、色の計算などを行うシェーダ。OpenGL ではフラグメントシェーダと呼ぶ。

   フレームバッファ
      画面に表示する画像の各ピクセルの色を保持するメモリ。

   ポリゴン
      3D モデルの表面を構成する多角形。リアルタイム 3D グラフィックスでは主に三角形を用いる。

   ムーアの法則
      半導体チップに集積されるトランジスタの数が、約 2 年ごとに 2 倍になるという経験則。

   メッシュシェーダ
      コンピュートシェーダに近い柔軟なプログラミングモデルで、ジオメトリの生成と加工を行うシェーダ。従来の頂点シェーダなどの段階を置き換える。

   ユニファイドメモリ
      CPU と GPU などの複数のプロセッサが、同じ物理メモリを共有する構成。

   ラスタライズ
      三角形などの図形を、画面上のピクセルの集まりに変換する処理。また、この処理を中心とする描画方式。

   レイテンシ
      処理を開始してから結果が得られるまでの時間。メモリアクセスの場合は、要求を出してからデータが届くまでの時間を指す。

   レイトレーシング
      光線の経路を追跡して、反射、屈折、影などを物理的に正確に計算する描画手法。

   ワープ
      NVIDIA の GPU で、1 つの命令でまとめて実行される 32 個のスレッドの集団。
