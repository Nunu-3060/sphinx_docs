深層学習と GPU（2012 年〜）
===========================

本章では、深層学習の普及によって GPU の主な用途が大きく変わった時代について述べる。この時代の GPU は、グラフィックスの性能だけでなく、行列演算の性能、低精度の数値形式、GPU 同士を結ぶ通信の性能を競うようになり、データセンター向けの製品が GPU 市場の中心となった。

深層学習が GPU を必要とした理由
-------------------------------

深層学習で用いるニューラルネットワークの計算の大部分は、行列の積である。全結合層は入力ベクトルと重み行列の積で、畳み込み層も行列の積に変換して計算できる。また、学習では大量のデータを小さなまとまり（ミニバッチ）に分けて処理するため、行列の積はさらに大きくなる。行列の積は、:math:`n \times n` の行列同士の場合に :math:`2n^3` 回の演算に対して :math:`3n^2` 個の要素の読み書きで済み、演算強度が高い。つまり、深層学習の計算は、データ並列性が高く、演算性能を引き出しやすいという、GPU に非常に適した性質を持っていた。

GPU をニューラルネットワークの学習に用いる研究は 2000 年代後半から行われていた。2009 年には、スタンフォード大学の Raina らが、GPU を用いることで大規模なニューラルネットワークの学習を CPU に比べて最大 70 倍程度高速化できることを示した\ [Raina2009]_。

AlexNet の衝撃
--------------

GPU と深層学習の結び付きを決定的にしたのが、2012 年の画像認識コンテスト ILSVRC（ImageNet Large Scale Visual Recognition Challenge）である。トロント大学の Alex Krizhevsky、Ilya Sutskever、Geoffrey Hinton が開発した畳み込みニューラルネットワーク（後に AlexNet と呼ばれる）は、上位 5 候補の誤り率で 15.3 % を記録し、2 位の 26.2 % を大きく引き離して優勝した\ [Krizhevsky2012]_。

AlexNet は、NVIDIA の GeForce GTX 580（メモリ 3 GB）2 枚を用いて、約 5〜6 日間で学習された。GPU 1 枚のメモリにネットワーク全体が収まらなかったため、ネットワークを 2 つに分けてそれぞれの GPU に割り当てるという工夫も行われていた。ゲーム用の GPU と CUDA という、誰でも入手できる環境で画期的な成果が得られたことは、多くの研究者が GPU を使って深層学習に取り組むきっかけとなった。

ソフトウェア基盤の整備
----------------------

深層学習の普及に合わせて、GPU を活用するためのソフトウェアが急速に整備された。NVIDIA は 2014 年に、深層学習でよく使われる畳み込みなどの処理を GPU 向けに最適化したライブラリ cuDNN を公開した。Caffe（2014 年）、TensorFlow（2015 年）、PyTorch（2016 年）といった深層学習フレームワークは、いずれも CUDA と cuDNN を基盤として GPU に対応した。

これらのフレームワークを使えば、利用者は CUDA のプログラムを書かなくても GPU の性能を活用できる。同時に、フレームワークが NVIDIA の GPU を最優先で支援したことで、深層学習の分野では NVIDIA の GPU が事実上の標準となった。

HBM と NVLink
~~~~~~~~~~~~~

2016 年の P100 は、\ :term:`HBM`\ （High Bandwidth Memory）を採用した。HBM は、複数の DRAM チップを積み重ね、GPU と同じパッケージ内に配置するメモリである。GPU と HBM はシリコン製の中継基板（インターポーザ）上の多数の配線で接続され、従来の GDDR メモリよりも広いバス幅と高い電力効率を実現する。HBM は 2015 年に AMD の Radeon R9 Fury X で初めて GPU に採用され、P100 以降のデータセンター向け GPU では標準となった。

また P100 は、GPU 同士や GPU と CPU を高速に接続する独自のインタフェース :term:`NVLink` を搭載した。深層学習の大規模な学習では、複数の GPU で計算を分担し、計算結果を頻繁に交換する必要がある。PCI Express の帯域幅ではこの通信がボトルネックになるため、専用の高速な接続が必要になった。NVLink の帯域幅は世代ごとに向上し、H100 では GPU 1 基あたり 900 GB/s、B200 では 1.8 TB/s に達した。

Tensor コア
~~~~~~~~~~~

2017 年の V100 は、行列の積和演算を専門に行う演算器である :term:`Tensor コア`\ を搭載した。Tensor コアは、小さな行列 :math:`A`、:math:`B`、:math:`C` に対して次の演算を 1 命令で実行する。

.. math::

   D = A \times B + C

V100 の Tensor コアは、:math:`4 \times 4` の行列を単位とし、:math:`A` と :math:`B` を半精度（FP16）で、累積を単精度（FP32）で行う。通常の演算器が 1 回の命令で 1 回の積和演算を実行するのに対し、Tensor コアは 1 回の命令で 64 回の積和演算を実行する。V100 は 640 個の Tensor コアにより、深層学習向けの演算で 125 TFLOPS のピーク性能を実現した\ [NVIDIA-Volta]_。

Tensor コアの登場は、GPU の設計思想の大きな転換点であった。それまでの GPU は、多数の汎用的な演算器で様々な処理を実行することを目指していたが、Tensor コアは特定の演算に特化した専用回路である。行列の積という深層学習の中心的な演算に回路を特化させることで、汎用の演算器よりはるかに高い性能と電力効率を得た。その後の世代では、Tensor コアの性能向上がデータセンター向け GPU の性能向上の大部分を占めるようになった。

低精度の数値形式
~~~~~~~~~~~~~~~~

深層学習は、科学技術計算と比べて数値の精度が低くても結果に大きな影響が出にくい。精度を下げれば、1 つの演算に必要な回路が小さくなり、メモリの使用量と転送量も減る。このため、世代を追うごとに、より低い精度の数値形式が導入された（:numref:`table-formats`）。

いずれの形式も、表の値に加えて符号部が 1 ビットある。低い精度で計算する場合は、重要な部分だけを高い精度で計算したり、値の大きさを調整する係数（スケーリング係数）を併用したりして、精度の低下を補う。このように複数の精度を組み合わせる手法を\ :term:`混合精度`\ 演算と呼ぶ。H100 で導入された Transformer Engine は、FP8 と FP16 を層ごとに自動的に使い分ける仕組みである\ [NVIDIA-Hopper]_。

なお、A100 では、行列の要素の一定の割合が 0 であることを前提に計算を省略する構造化スパース性（4 要素中 2 要素を 0 とする方式）にも対応した。

GPU の分割と大規模化
~~~~~~~~~~~~~~~~~~~~

GPU が大きくなるにつれて、1 つの GPU を複数の利用者で効率よく共有する機能と、多数の GPU を 1 つの巨大な計算資源として扱う機能の両方が求められるようになった。

A100 で導入された :term:`MIG`\ （Multi-Instance GPU）は、1 つの GPU を最大 7 つの独立したインスタンスに分割し、それぞれに演算器とメモリを割り当てる機能である\ [NVIDIA-Ampere]_。クラウドなどで、小規模な推論処理を多数同時に実行する用途に適する。

一方、大規模な学習のためには、多数の GPU を NVLink と専用のスイッチ（NVSwitch）で接続したシステムが製品化された。2024 年に発表された GB200 NVL72 は、72 基の Blackwell GPU と 36 基の Grace CPU を 1 つのラックに収め、ラック全体を NVLink で接続する。設計の単位は、1 つのチップから、ボード、さらにラック全体へと広がった。

大規模言語モデルの時代
----------------------

2017 年に発表された Transformer という構造は、行列の積を中心とする計算で構成されており、GPU との相性が非常に良かった。Transformer を基盤とする大規模言語モデル（LLM）は、モデルの規模と学習データを増やすほど性能が向上する傾向が知られるようになり、学習に用いる GPU の数は数千から数万基の規模に拡大した。2022 年 11 月の ChatGPT の公開以降、生成 AI への需要が急増し、データセンター向け GPU は世界的に供給不足となった。

LLM は、GPU に対して次のような要求をもたらした。

* メモリの容量と帯域幅：LLM の推論では、生成する単語（トークン）ごとに巨大なモデルの重みを読み出す必要があるため、演算性能よりもメモリ帯域幅が性能を制約しやすい。2023 年に発表された H200 は、H100 と同じ演算部に、より大容量で高速な HBM3e（141 GB、4.8 TB/s）を組み合わせた製品である。
* 低精度の演算：FP8 や FP4 を用いることで、メモリの使用量を減らしつつ演算性能を高める。
* GPU 間の通信性能：1 つのモデルを多数の GPU に分割して学習・推論するため、GPU 間の通信の帯域幅と遅延が全体の性能を左右する。

2024 年に発表された Blackwell 世代の B200 は、2 つの大きなダイを 1 つのパッケージに収め、両者を 10 TB/s の高速な接続で結んで 1 つの GPU として動作させる。トランジスタ数は合計 2,080 億個に達した。2025 年には、メモリを 288 GB に増やした Blackwell Ultra が登場した。NVIDIA は 2026 年に、HBM4 を採用した Rubin 世代の量産を開始し、同年後半から出荷を始めると表明している。

GPU 以外の AI 向けプロセッサ
----------------------------

深層学習の需要拡大に伴い、GPU 以外の専用プロセッサも登場した。Google は 2016 年に、自社のデータセンターで使用する深層学習専用のプロセッサ TPU（Tensor Processing Unit）を発表した。TPU は、行列の積に特化した大規模な演算回路（シストリックアレイ）を中心とする設計である。このほか、多くの新興企業やクラウド事業者が AI 向けの専用チップを開発している。

これらの専用プロセッサと比べた GPU の強みは、汎用性とソフトウェアの蓄積である。深層学習の手法は急速に変化しており、新しい手法が登場したときに、プログラム可能な GPU と成熟したソフトウェア基盤があればすぐに試すことができる。一方、GPU も Tensor コアのような専用回路の比重を高めており、GPU と専用プロセッサの境界は以前ほど明確ではなくなっている。

深層学習の時代の意義
--------------------

深層学習の時代に、GPU の主な用途はグラフィックスから AI へと移った。この変化は、GPU の設計に次のような影響を与えた。

* 汎用の演算器から、Tensor コアのような行列演算専用の回路へと重点が移った。
* 科学技術計算で重視された倍精度ではなく、FP16、FP8、FP4 といった低精度の演算性能が競われるようになった。
* メモリ帯域幅と GPU 間の通信性能が、演算性能と同等以上に重要になった。
* 設計の単位が、チップからパッケージ、ラック、データセンター全体へと広がった。

グラフィックス向けの GPU も、この時代の技術から大きな影響を受けている。次章では、同時期のグラフィックス技術の発展について述べる。
