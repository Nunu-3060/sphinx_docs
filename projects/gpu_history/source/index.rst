GPU の歴史
==========

本書は、GPU（Graphics Processing Unit）が 1999 年に登場してから 2026 年に至るまでの歴史を、エンジニア向けに技術的な観点から解説する文書である。製品の年代記ではなく、各時代に「何が求められ、何が変わり、次の時代に何を残したのか」を中心に記述する。

.. note::

   本書の内容は 2026 年時点の情報に基づいて執筆している。製品の仕様は各社の公称値であり、その後の発表によって変わる可能性がある。
