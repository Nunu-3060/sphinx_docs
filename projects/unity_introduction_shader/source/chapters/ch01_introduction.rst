第 1 章 はじめに
================

シェーダーとは
--------------

シェーダーは、GPU（Graphics Processing Unit）で実行される小さなプログラムである。画面に表示される 3D のオブジェクトは、すべてシェーダーによって「頂点をどこに置くか」と「各ピクセルを何色にするか」が決められている。Unity に用意されている標準のマテリアルも、内部では Unity が用意したシェーダーで描画されている。

シェーダーを自分で書けるようになると、標準のマテリアルではできない表現が可能になる。例えば、アニメ調の陰影、オブジェクトが燃え尽きるように消える演出、水面の波、画面全体の色調の変更などである。また、描画のしくみを理解すると、表示の不具合の原因を調べたり、描画を高速化したりするときにも役立つ。

本資料の目的
------------

本資料の目的は、次のことができるようになることである。

* 3D のオブジェクトが画面に表示されるまでのしくみを説明できる。
* URP 向けのシェーダーを ShaderLab と HLSL で一から書ける。
* テクスチャー、ライティング、影、透明、頂点アニメーションを扱える。
* リムライト、ディゾルブ、トゥーン、ポストエフェクトなどの基本的な表現を作れる。
* Shader Graph と手書きのシェーダーの対応を理解し、目的に応じて使い分けられる。

対象読者
--------

本資料は、次の知識がある人を対象とする。

* Unity Editor の基本操作（シーンの編集、GameObject とコンポーネントの操作、マテリアルの作成）ができる。
* C# の基本的な文法（変数、関数、クラス）が分かる。
* 高校で学ぶ程度の数学（三角関数、ベクトル）を知っている。

シェーダーやグラフィックスの知識は前提としない。必要な数学は第 2 章と第 3 章で説明する。

サンプルコードの使い方
----------------------

第 7 章以降の各章には、サンプルコードがある。サンプルコードは本文中に表示されており、各コードの下のリンクからファイルをダウンロードできる。すべてのサンプルをまとめた zip ファイルは、:doc:`../index` からダウンロードできる。

シェーダーのサンプルは、次の手順で使う。

#. シェーダーファイル（``.shader``）を、Unity のプロジェクトの ``Assets`` フォルダーの中にコピーする。
#. Project ウィンドウで右クリックし、:menuselection:`Create --> Material` でマテリアルを作成する。
#. マテリアルの Inspector ウィンドウで、:guilabel:`Shader` のドロップダウンから ``Introduction`` の下にあるシェーダーを選ぶ。
#. マテリアルを、Scene ビューのオブジェクトにドラッグ＆ドロップする。

サンプルのシェーダーは、``Introduction/Chapter07/UnlitColor`` のように、章の番号を含む名前にしている。C# のスクリプト（``.cs``）は、``Assets`` フォルダーにコピーしたあと、GameObject にアタッチして使う。
