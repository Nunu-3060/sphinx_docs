はじめに
========

本書の目的
----------

映画の CG、ゲーム、建築や製品のビジュアライゼーションなど、コンピューターで生成された画像は身の回りにあふれている。近年のこれらの画像の多くは、物理ベースレンダリング（Physically Based Rendering、PBR）と呼ばれる考え方に基づいて作られている。

本書の目的は、CG を専門としないエンジニアが PBR の全体像をつかみ、次のことができるようになることである。

* 「物理ベース」とは何を意味し、従来の手法と何が違うのかを説明できる。
* 放射輝度、BRDF、レンダリング方程式という PBR の中心概念を、数式と直感の両面から理解できる。
* モンテカルロ積分に基づくパストレーシングの仕組みを、実際に動くコードを通じて理解できる。
* ゲームエンジンや 3D モデルのファイル形式で使われるマテリアルのパラメーター（ベースカラー、メタリック、ラフネスなど）が、理論のどこに対応するのかを説明できる。

対象読者と前提知識
------------------

本書は、Python を使ったプログラミングの経験があり、CG は専門ではないエンジニアを対象とする。前提とする知識は次のとおりである。

* Python の基本的な文法と、NumPy の配列操作
* ベクトルの内積・外積、三角関数
* 微分・積分の基本（多重積分の意味がわかる程度）
* 確率の初歩（平均、分散）

立体角、確率密度関数、球面座標による積分など、CG で特に必要になる数学は本文と「:doc:`appendix_math`」で説明する。光学や物理学の専門知識は前提としない。

物理ベースレンダリングとは
--------------------------

レンダリング（rendering）とは、3 次元のシーンの記述（物体の形状、材質、光源、カメラ）から 2 次元の画像を計算する処理である。

初期の CG では、見た目がそれらしくなることを優先して、経験的な式で物体の明るさを計算していた。代表的なものが Phong の反射モデル [Phong1975]_ である。このような手法では、パラメーターに物理的な意味がないため、ある照明条件でうまく調整した材質が、別の照明条件では不自然に見えることが多かった。また、パラメーターの組み合わせによっては、物体が入射した光より多くの光を反射してしまうこともあった。

これに対して PBR では、光がどのように放射され、物体の表面でどのように反射・屈折し、カメラに届くのかを、物理法則に基づいてモデル化する。その結果、次のような利点が得られる。

照明条件に依存しない
   材質のパラメーターが物理的な性質（反射率や表面の粗さ）を表すため、照明を変えても材質を調整し直す必要がない。

エネルギーの保存
   表面は受け取った以上の光を反射しない。そのため、どのような照明の下でも明るさが破綻しにくい。

パラメーターの意味が明確
   「ラフネス 0.3 の金属」のように、材質を物理的な言葉で指定できる。複数の人が作った素材を 1 つのシーンに並べても、見た目の整合がとりやすい。

なお、PBR は物理現象を完全に再現することを意味しない。実際のレンダラーは、計算コストと精度のバランスをとるために多くの近似を用いる。PBR の本質は、近似を行う場合でも物理的な原理（エネルギー保存など）を守り、パラメーターの物理的な意味を保つことにある。

本書の構成
----------

本書は次のように構成されている。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 章
     - 内容
   * - 「:doc:`overview`」
     - 画像ができるまでの流れと、ラスタライズとレイトレーシングの違いを概観する。
   * - 「:doc:`light_and_color`」
     - 光の性質、色の表現、sRGB とリニアワークフロー、HDR を説明する。
   * - 「:doc:`radiometry`」
     - 光の量を表す物理量（放射束、放射照度、放射輝度など）を定義する。
   * - 「:doc:`light_matter`」
     - 反射・屈折・吸収と、フレネル反射率、金属と誘電体の違いを説明する。
   * - 「:doc:`brdf`」
     - 表面の反射特性を表す BRDF と、その物理的な条件を説明する。
   * - 「:doc:`microfacet`」
     - 粗い表面の反射を表すマイクロファセット理論と Cook-Torrance モデルを説明する。
   * - 「:doc:`rendering_equation`」
     - 光の伝わり方全体を表すレンダリング方程式を導入する。
   * - 「:doc:`monte_carlo`」
     - レンダリング方程式を数値的に解くためのモンテカルロ積分を説明する。
   * - 「:doc:`path_tracing`」
     - NumPy で書いたパストレーサーを読み解く。
   * - 「:doc:`practical_pbr`」
     - ゲームエンジンなどで使われる実用的な PBR のワークフローを説明する。
   * - 「:doc:`advanced`」
     - 本書で扱わなかった発展的な話題を紹介する。

前半（第 3 章から第 8 章）で理論を積み上げ、後半（第 9 章から第 11 章）でそれを計算に落とし込む構成になっている。主な用語は「:doc:`glossary`」にまとめてある。

サンプルコードの実行環境
------------------------

本書のサンプルコードは Python 3.11 以上で動作する。必要なライブラリは NumPy、Pillow、matplotlib の 3 つであり、次のコマンドでインストールできる。

.. code-block:: console
   :linenos:

   pip install numpy Pillow matplotlib

サンプルコードの一覧と実行方法は「:doc:`appendix_examples`」にまとめてある。
