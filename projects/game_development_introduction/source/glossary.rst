用語集
======

本書で使った用語を、アルファベット順、五十音順に並べる。

.. glossary::

   AABB
      Axis-Aligned Bounding Box の略。座標軸に平行な辺を持つ長方形（3D では直方体）で、当たり判定に広く使われる。重なりの判定が座標の大小比較だけで済み、計算が速い。

   FPS
      Frames Per Second の略。1 秒あたりに表示するフレームの数で、フレームレートの単位として使う。なお、ゲームのジャンルとしての FPS（First-Person Shooter、一人称視点のシューティングゲーム）とは別の意味である。

   GDD
      Game Design Document（ゲームデザインドキュメント）の略。ゲームのルール、操作、画面構成、数値の設定などをまとめた設計書。

   Git LFS
      Git Large File Storage の略。画像や音声などの大きなファイルの実体をリポジトリーの外に保存し、リポジトリーにはその参照だけを記録する Git の拡張機能。

   MVP
      Minimum Viable Product（実用最小限の製品）の略。必須の要素だけで作った、最低限遊べる状態のゲーム。

   WebAssembly
      ブラウザー上で高速に動作するプログラムの形式。pygbag は、Python の実行環境を WebAssembly に変換したものを使って、pygame-ce のゲームをブラウザーで動かす。

   アセット
      ゲームを構成する画像、音、フォント、データなどの素材の総称。

   当たり判定
      ゲーム中の物どうしが重なった（衝突した）かどうかを調べる処理。衝突判定とも呼ぶ。

   アルファ版
      主要な機能がひととおり遊べる段階の開発版。内容の追加はまだ続く。

   ウィッシュリスト
      Steam などで、気になるゲームを登録しておく機能。登録したゲームが発売されたりセールになったりすると通知が届く。

   ゲームエンジン
      描画、物理演算、音声、入力などの実行時の機能と、エディターや書き出し機能を一式そろえたゲーム制作用の統合環境。Unity、Unreal Engine、Godot など。

   ゲームジャム
      決められた期間（多くは 48 時間から数週間）とお題で、ゲームを作るイベント。

   ゲームループ
      入力、更新、描画を 1 秒間に数十回繰り返す、ゲームプログラムの中心となるループ。ループ 1 回分をフレームと呼ぶ。

   コアループ
      プレイヤーがゲーム中に何度も繰り返す、行動の流れ。ゲームの面白さの中心となる。

   コード署名
      実行ファイルに電子署名を付け、発行元と、改ざんされていないことを証明する仕組み。

   シーン
      タイトル画面、プレイ画面、結果画面のように、入力への反応や描く内容が異なる画面の単位。

   ジュース
      ルールを変えずに、効果音、パーティクル、画面の揺れなどで操作への反応を豊かにし、手触りを良くする演出のこと。英語の juice から。

   スコープ
      作ると決めた機能や内容の範囲。

   スコープクリープ
      制作の途中で、作る範囲（スコープ）が少しずつ膨らんでいく現象。個人開発でゲームが完成しない主な原因の一つ。

   ステートマシン
      システムが取り得る状態と、状態の間を移る規則（遷移）で振る舞いを表す考え方。状態機械とも呼ぶ。ゲームではシーンの切り替えやキャラクターの動作の管理に使う。

   ストアページ
      配布先に作る、ゲームを紹介するページ。説明文、スクリーンショット、動画、価格などを載せる。

   スプライト
      ゲーム画面の中で、位置を変えながら表示される個々の画像。

   すり抜け
      速く動く物が、1 フレームの間に薄い物の向こう側まで移動してしまい、当たり判定から漏れる現象。トンネリングとも呼ぶ。

   デルタタイム
      前のフレームから現在のフレームまでの経過時間。速度に掛けて移動量を求めることで、フレームレートに依存しない動きを実現する。

   バーティカルスライス
      ゲームの一部分だけを、製品と同じ品質まで作り込んだ開発版。

   バランス調整
      難易度や手応えを決める数値（敵の強さ、速さ、得点など）を調整する作業。

   パーティクル
      小さな粒を多数発生させて動かし、爆発、煙、火花などを表現する手法。

   ビルド
      プログラムとアセットをまとめて、配布や実行ができる形にする作業。また、その成果物。

   フレームレート
      1 秒間に処理・表示するフレームの数。単位は FPS。

   フレームワーク
      描画や入力などの基本機能を、プログラムから呼び出せる形で提供するライブラリー。ゲームの構造は開発者がコードで組み立てる。pygame-ce など。

   プレイテスト
      開発者以外の人にゲームを遊んでもらい、その様子を観察して問題点を見つけること。

   プロトタイプ
      核となる遊びが面白いかを確かめるために作る試作品。見た目は仮のものでよい。

   ベータ版
      内容がほぼ出そろい、不具合修正と調整を中心に進める段階の開発版。

   ポストモーテム
      制作が終わった後に、うまくいったこととうまくいかなかったことを振り返ること。また、その記録。

   レーティング
      ゲームの内容（暴力表現、性的表現など）に基づいて付けられる、対象年齢の区分。
