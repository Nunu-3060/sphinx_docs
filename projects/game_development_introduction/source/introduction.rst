はじめに
========

本書の目的
----------

ゲームを作ってみたいと考えたエンジニアが最初に戸惑うのは、プログラミングそのものよりも「何から始め、どの順に進め、どこで完成とするか」が見えないことである。業務のソフトウェア開発には要件定義・設計・実装・テスト・リリースという見慣れた流れがあるが、ゲーム制作には「面白さ」という測りにくい要件があり、遊んでみるまで良し悪しが分からないという独特の難しさがある。

本書の目的は、個人または数人の小規模チームで 2D ゲームを 1 本作り、公開するまでの流れを一通り示すことである。各工程で何を決め、何を作り、何に注意すればよいかを押さえておけば、より大きなゲームや別のゲームエンジンに取り組む際にも応用できる。

対象読者と前提知識
------------------

本書は次のような読者を想定している。

- Python で、クラス・関数・リストや辞書などを使ったプログラムを書ける。
- コマンドライン（PowerShell やターミナル）で、パッケージのインストールやスクリプトの実行ができる。
- ゲームを作った経験は無いか、ほとんど無い。

ゲーム固有の知識（ゲームループ、当たり判定、スプライトなど）は本文で説明する。数学は、三角関数とベクトルの初歩が分かれば十分である。

本書の構成
----------

本書は、ゲーム制作の工程の順に章を並べている。

.. list-table:: 各章の内容
   :header-rows: 1
   :widths: 30 70

   * - 章
     - 内容
   * - :doc:`overview`
     - ゲーム制作の工程と、小規模開発で意識すべきこと
   * - :doc:`planning`
     - アイデアをゲームの企画にまとめ、作る範囲を決める方法
   * - :doc:`engine_selection`
     - ゲームエンジンとフレームワークの種類、選定の基準
   * - :doc:`environment`
     - 本書のサンプルを動かすための開発環境の準備
   * - :doc:`programming_basics`
     - ゲームループ、デルタタイム、当たり判定などの基礎
   * - :doc:`practice`
     - ブロック崩しを 7 段階で作る実践
   * - :doc:`assets`
     - 画像・音・フォントの用意と、素材のライセンス
   * - :doc:`quality`
     - プレイテスト、バランス調整、デバッグ、手触りの改善
   * - :doc:`build`
     - 実行ファイルとブラウザー版の作成
   * - :doc:`release`
     - 配布先の選び方、ストアページ、宣伝
   * - :doc:`operation`
     - 公開後のアップデートと振り返り

ゲーム制作の流れを先に知りたい場合は、:doc:`overview`\ から順に読むとよい。とにかく手を動かしたい場合は、:doc:`environment`\ と\ :doc:`programming_basics`\ を読んでから\ :doc:`practice`\ に進み、ゲームが動いた後で前半の章に戻ってもよい。

動作環境
--------

本書のサンプルコードは次の環境で動作を確認している。

.. list-table:: 動作確認環境
   :header-rows: 1
   :widths: 30 70

   * - 項目
     - バージョン
   * - OS
     - Windows 11
   * - Python
     - 3.14（サンプルコードは Python 3.10 以降で動作する書き方をしている）
   * - pygame-ce
     - 2.5.8
   * - Pillow
     - 13.0.0（:doc:`assets`\ のスプライトシート生成で使用）
   * - PyInstaller
     - 6.22.3（:doc:`build`\ の実行ファイル作成で使用）

macOS や Linux でも同じコードで動作するはずだが、コマンドの書き方が異なる。本書では Windows のコマンドを示し、Python の起動には Windows 用の Python ランチャー（``py`` コマンド）を使う。macOS や Linux では ``py`` を ``python3`` に読み替えてほしい。
