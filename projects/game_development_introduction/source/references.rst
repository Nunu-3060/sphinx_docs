参考文献
========

書籍
----

.. list-table::
   :header-rows: 1
   :widths: 45 55

   * - 文献
     - 内容
   * - Jesse Schell 著、『ゲームデザインバイブル 第 2 版』、オライリー・ジャパン、2019 年（原著: *The Art of Game Design: A Book of Lenses*）
     - ゲームデザインを多数の観点（レンズ）から考えるための定番書。企画やバランス調整の考え方の参考になる
   * - Raph Koster 著、『「おもしろい」のゲームデザイン』、オライリー・ジャパン、2005 年（原著: *A Theory of Fun for Game Design*）
     - ゲームの面白さとは何かを、学習と熟達の観点から論じる
   * - Robert Nystrom 著、『ゲームプログラミングのデザインパターン』、インプレス、2015 年（原著: *Game Programming Patterns*）
     - ゲームループ、ステートマシンなど、ゲームのプログラムでよく使う設計を解説する。原著は Web 上で無料公開されている
   * - Steve Swink 著、*Game Feel: A Game Designer's Guide to Virtual Sensation*、Morgan Kaufmann、2008 年
     - 操作の手触り（ゲームフィール）を体系的に論じる
