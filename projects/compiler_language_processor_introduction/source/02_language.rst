################################################################
第 2 章 題材言語 Tiny の定義
################################################################

この章では、本書を通して処理系を作る言語 Tiny の仕様を定めます。Tiny は、処理系の各段階で考えるべき問題がひととおり現れ、それでいて実装が大きくなりすぎないように設計した言語です。

Tiny の概要
================================================================

まず、Tiny のプログラムの例を示します。

.. literalinclude:: ../examples/programs/fizzbuzz.tiny
   :language: tiny
   :linenos:
   :caption: programs/fizzbuzz.tiny

Tiny には次のような特徴があります。

* プログラムは関数定義の並びで、``main`` 関数から実行を始めます。``main`` は引数も戻り値も持ちません。組み込み関数と同じ名前の関数は定義できません。
* 値の型は、整数 ``int``、真偽値 ``bool``、文字列 ``str``、配列 ``[T]`` の 4 種類です。
* 変数は ``let`` で宣言します。型は初期値から決まりますが、``let a: [int] = [];`` のように明示することもできます。
* 関数の引数と戻り値には型を書きます。戻り値がない関数は ``->`` 以降を省略します。
* 制御構文は ``if`` / ``else`` と ``while`` だけです。
* 大域変数、浮動小数点数、クロージャ、例外はありません。

字句の規則
================================================================

Tiny のプログラムを構成する字句（:term:`トークン`）は次のとおりです。

.. list-table:: Tiny の字句
   :header-rows: 1
   :widths: 25 45 30

   * - 種類
     - 規則
     - 例
   * - 識別子
     - 英字または ``_`` で始まり、英数字または ``_`` が続く
     - ``x``、``fizz_buzz``、``a1``
   * - キーワード
     - ``let``、``fn``、``if``、``else``、``while``、``return``、``true``、``false``
     -
   * - 整数リテラル
     - 数字の並び（負の数は単項演算子 ``-`` で表す）
     - ``0``、``42``
   * - 文字列リテラル
     - ``"`` で囲み、``\n``、``\t``、``\"``、``\\`` のエスケープシーケンスを使える
     - ``"hello\n"``
   * - 演算子・区切り記号
     - ``+ - * / % == != < <= > >= && || ! = ( ) { } [ ] , ; : ->``
     -
   * - コメント
     - ``//`` から行末まで（字句としては読み飛ばす）
     - ``// コメント``

``int``、``bool``、``str`` はキーワードではなく、型を書く位置でだけ特別な意味を持つ識別子として扱います。

文法
================================================================

Tiny の文法を :term:`EBNF` で示します。EBNF は文法を記述するための記法で、本書では次の記号を使います。

.. list-table:: 本書で使う EBNF の記法
   :header-rows: 1
   :widths: 25 75

   * - 記法
     - 意味
   * - ``a = ... ;``
     - 記号 ``a`` を右辺のように定義する
   * - ``"fn"``
     - その文字列そのものの字句
   * - ``IDENT``、``INT``、``STRING``
     - それぞれ識別子、整数リテラル、文字列リテラルの字句
   * - ``a b``
     - ``a`` の後に ``b`` が続く
   * - ``a | b``
     - ``a`` または ``b``
   * - ``[ a ]``
     - ``a`` は省略できる（0 回または 1 回）
   * - ``{ a }``
     - ``a`` を 0 回以上繰り返す
   * - ``( a )``
     - まとめる

.. code-block:: text
   :linenos:
   :caption: Tiny の文法

   program    = { function } ;
   function   = "fn" IDENT "(" [ param { "," param } ] ")" [ "->" type ] block ;
   param      = IDENT ":" type ;
   type       = "int" | "bool" | "str" | "[" type "]" ;

   block      = "{" { statement } "}" ;
   statement  = block
              | "let" IDENT [ ":" type ] "=" expr ";"
              | if_stmt
              | "while" "(" expr ")" block
              | "return" [ expr ] ";"
              | expr "=" expr ";"
              | expr ";" ;
   if_stmt    = "if" "(" expr ")" block [ "else" ( block | if_stmt ) ] ;

   expr       = or_expr ;
   or_expr    = and_expr { "||" and_expr } ;
   and_expr   = eq_expr { "&&" eq_expr } ;
   eq_expr    = rel_expr { ( "==" | "!=" ) rel_expr } ;
   rel_expr   = add_expr { ( "<" | "<=" | ">" | ">=" ) add_expr } ;
   add_expr   = mul_expr { ( "+" | "-" ) mul_expr } ;
   mul_expr   = unary { ( "*" | "/" | "%" ) unary } ;
   unary      = ( "-" | "!" ) unary | postfix ;
   postfix    = primary { "(" [ expr { "," expr } ] ")" | "[" expr "]" } ;
   primary    = INT | STRING | "true" | "false" | IDENT
              | "(" expr ")" | "[" [ expr { "," expr } ] "]" ;

代入文 ``expr "=" expr ";"`` の左辺に書けるのは、変数（``x``）と添字式（``a[i]``）だけです。また、関数呼び出しの ``(`` の前に書けるのは関数名だけです。これらの制約は文法では表さず、構文解析器が検査します。

演算子の優先順位と結合性
================================================================

文法の ``or_expr`` から ``unary`` までの規則は、演算子の優先順位と結合性を表しています。表にまとめると次のようになります。

.. list-table:: 演算子の優先順位（上ほど強く結び付く）
   :header-rows: 1
   :widths: 30 40 30

   * - 演算子
     - 意味
     - 結合性
   * - ``f(...)``、``a[...]``
     - 関数呼び出し、添字
     - 左結合
   * - ``-``、``!``\ （単項）
     - 符号反転、論理否定
     - 右結合
   * - ``*``、``/``、``%``
     - 乗算、除算、剰余
     - 左結合
   * - ``+``、``-``
     - 加算（文字列の連結）、減算
     - 左結合
   * - ``<``、``<=``、``>``、``>=``
     - 大小比較
     - 左結合
   * - ``==``、``!=``
     - 等価比較
     - 左結合
   * - ``&&``
     - 論理積（短絡評価）
     - 左結合
   * - ``||``
     - 論理和（短絡評価）
     - 左結合

型
================================================================

.. list-table:: Tiny の型
   :header-rows: 1
   :widths: 20 50 30

   * - 型
     - 説明
     - リテラルの例
   * - ``int``
     - 整数（桁数の上限なし）
     - ``42``
   * - ``bool``
     - 真偽値
     - ``true``、``false``
   * - ``str``
     - 文字列（変更できない）
     - ``"abc"``
   * - ``[T]``
     - 要素の型が ``T`` の配列（要素の変更と追加ができる）
     - ``[1, 2, 3]``
   * - ``void``
     - 戻り値のない関数の戻り値の型（ソースコードには書かない）
     -

演算子に使える型は次のとおりです。

* ``+`` は ``int`` どうし（加算）または ``str`` どうし（連結）に使えます。
* ``-``、``*``、``/``、``%``、``<``、``<=``、``>``、``>=`` は ``int`` どうしに使えます。
* ``==`` と ``!=`` は同じ型どうしに使えます。配列の場合は要素を順に比較します。
* ``&&``、``||``、``!`` は ``bool`` に使えます。
* ``a[i]`` の ``a`` は配列または文字列、``i`` は ``int`` です。文字列の添字式は長さ 1 の文字列を返します。

組み込み関数
================================================================

.. list-table:: 組み込み関数
   :header-rows: 1
   :widths: 35 65

   * - 関数
     - 説明
   * - ``print(x, ...)``
     - 引数を空白で区切って表示し、改行する（引数の個数と型は自由）
   * - ``len(x)``
     - 配列または文字列の長さを ``int`` で返す
   * - ``push(a, x)``
     - 配列 ``a`` の末尾に ``x`` を追加する
   * - ``to_str(x)``
     - ``int``、``bool``、``str`` の値を文字列に変換する

意味についての補足
================================================================

文法と型だけでは決まらない、実行時の振る舞いを定めておきます。

* 整数の除算 ``/`` は 0 に向かって切り捨てます（``-7 / 2`` は ``-3``）。剰余 ``%`` は ``a == (a / b) * b + a % b`` を満たすように定めます（``-7 % 2`` は ``-1``）。これは C 言語や Java と同じで、Python の ``//`` と ``%`` とは負の数の扱いが異なります。
* 0 による除算や、範囲外の添字（負の添字を含む）は実行時エラーになります。
* ``&&`` と ``||`` は\ :term:`短絡評価`\ を行います。左辺で結果が決まる場合、右辺は評価しません。
* 配列は参照で扱います。関数に配列を渡して要素を変更すると、呼び出し元の配列も変わります。
* 変数の有効範囲（:term:`スコープ`）は、宣言した位置からそのブロックの終わりまでです。内側のブロックで同じ名前の変数を宣言すると、外側の変数は隠されます。
* 値を返す関数は、すべての実行経路が ``return`` 文で終わらなければなりません。

まとめ
================================================================

* Tiny は、整数・真偽値・文字列・配列・関数を持つ静的型付きの小さな言語です。
* 文法は EBNF で記述しました。演算子の優先順位と結合性は、文法の規則の階層で表されます。
* 文法で表せない制約（代入の左辺、型、``return`` の有無など）は、構文解析器と意味解析器で検査します。
