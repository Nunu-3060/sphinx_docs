################################################################
付録 B 用語集
################################################################

本書で使う主な用語をまとめます。英字で始まる用語を先に、その後に五十音順で並べています。

.. glossary::

   EBNF
      拡張バッカス・ナウア記法（Extended Backus-Naur Form）です。文法を記述するための記法で、省略可能な部分を ``[ ]``、繰り返しを ``{ }`` で表せます。

   JIT コンパイル
      プログラムの実行中に、頻繁に実行される部分を機械語にコンパイルする方式です。実行時に観測した情報を最適化に利用できます。

   LLVM
      SSA 形式の中間表現 LLVM IR を中心とするコンパイラ基盤です。多くの言語のコンパイラが、最適化とコード生成に利用しています。

   Pratt 構文解析
      演算子ごとに結合力を与え、式を 1 つの関数で解析する構文解析の手法です。演算子順位構文解析の一種です。

   SSA 形式
      静的単一代入形式（Static Single Assignment form）です。すべての変数がプログラム上でちょうど 1 か所でだけ代入される中間表現の形式です。

   Visitor パターン
      木構造のノードの種類ごとの処理を、ノードのクラスとは別のクラスにまとめるデザインパターンです。

   φ 関数
      SSA 形式で、制御フローの合流点に置く特別な命令です。直前にどの基本ブロックを実行したかに応じて値を選びます。

   曖昧な文法
      1 つの文に対して、2 つ以上の異なる構文木を作れる文法です。

   一時変数
      式を三番地コードに分解するときに、途中の計算結果を保持するためにコンパイラが導入する変数です。

   意味解析
      名前解決や型検査など、文法では表せない規則を検査する段階です。

   インタプリタ
      プログラムを読みながら、その場で実行する言語処理系です。

   エラー回復
      構文エラーなどを見つけた後も解析を続け、複数のエラーを報告できるようにすることです。

   仮想マシン
      実在の CPU ではなく、ソフトウェアで実現した仮想的な機械です。バイトコードを解釈して実行します。

   型検査
      式の型を求め、演算子・代入・関数呼び出しなどで型が正しく使われているかを検査することです。

   型付け規則
      式の型がどのように決まるかを、前提と結論の形で表した規則です。

   ガベージコレクション
      どこからも参照されなくなったヒープ上のオブジェクトを、処理系が自動的に回収するしくみです。GC と略します。

   環境
      インタプリタで、変数の名前と値の対応を保持するものです。

   干渉グラフ
      同時に生存する（干渉する）変数どうしを辺で結んだグラフです。レジスタ割り当てに使います。

   記号表
      名前と、その名前に関する情報（型など）の対応表です。

   木構造インタプリタ
      抽象構文木を直接たどって実行するインタプリタです。

   基本ブロック
      途中に分岐も合流もなく、先頭から末尾まで一直線に実行される命令の列です。

   共通部分式除去
      同じ値を計算する式が複数あるとき、2 回目以降を 1 回目の結果で置き換える最適化です。

   結合力
      Pratt 構文解析で、演算子が被演算子と結び付く強さを表す数値です。

   言語サーバ
      補完やエラー表示などの開発支援の機能を、LSP（Language Server Protocol）を通じてエディタに提供するプログラムです。

   言語処理系
      プログラミング言語で書かれたプログラムを実行したり、別の形式に変換したりするソフトウェアの総称です。

   構文解析
      トークンの列が文法に合っているかを調べ、プログラムの構造を木の形で明らかにする段階です。

   構文解析器生成系
      文法の定義から構文解析器を自動的に生成するツールです。yacc、Bison、ANTLR などがあります。

   構文木
      導出の過程を木で表したものです。文法の規則をそのまま反映します。具象構文木とも呼びます。

   コード生成
      中間表現から、機械語やバイトコードなどの目的コードを生成する段階です。

   コピー伝播
      ``x = y`` というコピーの後の ``x`` の使用を ``y`` に置き換える最適化です。

   コピーの合併
      コピー命令で結ばれた 2 つの変数に同じレジスタを割り当て、コピー命令を削除することです。

   コンパイラ
      プログラムを、実行前にまとめて別の言語（多くは機械語）に変換する言語処理系です。

   再帰下降構文解析
      非終端記号ごとに 1 つの関数を用意し、文法の規則をそのまま関数の処理として書き下す構文解析の手法です。

   最長一致
      字句解析で、トークンとして認められる最も長い字句を切り出すという規則です。

   最適化
      プログラムの意味を変えずに、より速く（あるいはより小さく）動くように書き換える処理です。

   三番地コード
      各命令が最大 3 つの番地（変数や定数）しか扱わない形式の中間表現です。

   支配
      入口から基本ブロック n に至るすべての経路が基本ブロック d を通るとき、d は n を支配するといいます。

   支配木
      各基本ブロックから、その直接支配ブロックへ辺を張って作る木です。

   支配辺境
      基本ブロック n が支配する範囲からちょうど一歩出たところにある基本ブロックの集合です。φ 関数を置く場所を決めるのに使います。

   字句
      ソースコード上の文字列のうち、トークン 1 つ分にあたる部分です。

   字句解析
      文字の列をトークンの列に変換する段階です。空白やコメントを取り除きます。

   字句解析器生成系
      トークンの正規表現から字句解析器を自動的に生成するツールです。lex、flex などがあります。

   実行時環境
      生成されたコードの実行を支えるしくみです。スタックフレーム、呼び出し規約、ヒープの管理などを含みます。

   スコープ
      変数などの名前の宣言が有効な範囲です。

   スタックフレーム
      関数呼び出し 1 回分の情報（局所変数、戻り番地など）をまとめたものです。

   スタックマシン
      命令の被演算子をスタックから取り出し、結果をスタックに積む方式の機械です。

   スピル
      レジスタが足りないときに、変数をメモリに置くことです。

   正規表現
      文字列の集合（パターン）を表す記法です。トークンの形を記述するのに使います。

   制御フローグラフ
      基本ブロックを節点とし、実行が移りうる関係を辺としたグラフです。CFG と略します。

   生存変数解析
      各点で、後で使われる可能性のある変数（生存している変数）を求めるデータフロー解析です。

   セルフホスティング
      ある言語のコンパイラを、その言語自身で書くことです。

   線形走査法
      命令を一列に並べ、変数の生存区間を順に処理してレジスタを割り当てる高速なレジスタ割り当ての手法です。

   短絡評価
      ``&&`` や ``||`` で、左辺だけで結果が決まる場合に右辺を評価しないことです。

   中間表現
      コンパイラの内部で、ソースコードと目的コードの中間に使うプログラムの表現です。IR と略します。

   抽象構文木
      構文木から、プログラムの意味に必要な情報だけを残した木です。AST と略します。

   定数畳み込み
      被演算子がすべて定数の演算を、コンパイル時に計算して結果の定数に置き換える最適化です。

   定数伝播
      定数が代入された変数の使用を、その定数に置き換える最適化です。

   ディスパッチ
      仮想マシンで、命令の種類に応じてその処理に分岐することです。

   データフロー解析
      制御フローグラフの各点で成り立つ事実を、方程式を立てて反復的に求める解析の手法です。

   トークン
      字句解析の結果として得られる、プログラムの最小単位です。種類と字句を持ちます。

   導出
      文法の開始記号から始めて、生成規則に従って非終端記号を置き換えていく操作です。

   名前解決
      プログラム中の名前が、どの宣言を指しているかを決めることです。

   バイトコード
      仮想マシンが実行する、仮想的な機械語の命令の列です。

   バックパッチ
      飛び先が未定のジャンプ命令を先に出力し、飛び先が決まった時点で書き換える技法です。

   左再帰
      生成規則の右辺の先頭に、左辺の非終端記号自身が現れることです。再帰下降構文解析では除去する必要があります。

   フェーズ
      コンパイラの処理を構成する段階です。字句解析、構文解析、意味解析などがあります。

   不要コード除去
      結果がどこからも使われない命令を削除する最適化です。

   文脈自由文法
      終端記号、非終端記号、生成規則、開始記号からなる文法です。プログラミング言語の文法の記述に使います。

   ベースポインタ
      スタック上で、実行中の関数のフレーム（局所変数の領域）の基準となる位置です。

   有限オートマトン
      有限個の状態と、入力に応じた状態の遷移からなる機械です。正規表現で表せるパターンを認識できます。

   呼び出し規約
      引数や戻り値の受け渡し方法、呼び出しの前後で保存すべきレジスタなど、関数呼び出しに関する約束事です。

   ルート
      ガベージコレクションで、プログラムが直接参照できる場所（局所変数、大域変数など）です。

   レジスタ割り当て
      中間表現の変数を、CPU の有限個のレジスタに割り当てることです。
