################################################################
コンパイラ・言語処理系入門
################################################################

本書は、Python などのプログラミング言語を使った経験があるエンジニアを対象に、コンパイラやインタプリタといった言語処理系のしくみを解説する入門書です。小さなプログラミング言語 Tiny を題材に、字句解析から構文解析、意味解析、インタプリタ、中間表現、最適化、仮想マシン、レジスタ割り当てまでを Python で実装しながら学びます。
