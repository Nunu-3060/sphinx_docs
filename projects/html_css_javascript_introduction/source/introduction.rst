はじめに
========

本資料の目的と対象読者
----------------------

本資料の目的は、HTML・CSS・JavaScript を使って、簡単な Web ページや Web アプリを自分で作れるようになることである。

対象読者は、Python などのプログラミング言語で簡単なプログラムを書いた経験がある人とする。変数、条件分岐、ループ、関数、クラスといった概念は既に理解しているものとして扱い、JavaScript の文法は Python との違いを中心に説明する。

一方で、Web 特有の仕組み（ブラウザがページを表示する流れ、DOM、イベント駆動、非同期処理、CSS のレイアウト）は、他の言語の経験だけでは推測しにくいため、詳しく説明する。

なお、本資料ではフレームワーク（React、Vue など）やビルドツール（npm、Vite など）は扱わない。ブラウザとテキストエディタだけで動かせる範囲に限定し、Web の基礎となる仕組みの理解を優先する。

HTML・CSS・JavaScript の役割分担
--------------------------------

Web ページは、役割の異なる 3 つの言語を組み合わせて作る。

.. list-table:: 3 つの言語の役割
   :header-rows: 1
   :widths: 20 20 60

   * - 言語
     - 役割
     - 例
   * - HTML
     - 構造
     - 「ここは見出し」「ここは段落」「ここはリンク」のように、文書の構造と意味を表す。
   * - CSS
     - 見た目
     - 文字の色や大きさ、余白、要素の並べ方（レイアウト）を指定する。
   * - JavaScript
     - 振る舞い
     - ボタンを押したときの処理や、サーバーからのデータ取得など、ページに動きを付ける。

HTML はプログラミング言語ではなく、文書の構造を記述するマークアップ言語である。CSS も同様に、見た目を宣言的に記述するスタイルシート言語である。条件分岐や繰り返しといった処理を記述できるのは、3 つのうち JavaScript だけである。

次の例は、3 つの言語を 1 つのファイルにまとめた最小限の Web ページである。

.. literalinclude:: ../examples/ch01/hello.html
   :language: html
   :caption: examples/ch01/hello.html

:download:`hello.html をダウンロード <../examples/ch01/hello.html>` ／ `ブラウザで表示 <examples/ch01/hello.html>`__

実際の開発では、HTML・CSS・JavaScript をそれぞれ別のファイルに分けることが多い。役割ごとにファイルを分けると、見た目だけ、あるいは動きだけを修正したいときに、該当するファイルだけを編集すればよい。

Web ページが表示されるまで
--------------------------

ブラウザのアドレスバーに URL を入力してから、ページが表示されるまでの流れは次のとおりである。

#. ブラウザが URL を解析し、接続先のサーバーを特定する。
#. ブラウザがサーバーに HTTP リクエストを送る。
#. サーバーが HTTP レスポンスとして HTML ファイルを返す。
#. ブラウザが HTML を先頭から解析し、DOM（Document Object Model）と呼ばれる木構造を作る。
#. HTML の中で参照されている CSS・JavaScript・画像などのファイルを、改めてサーバーに要求する。
#. CSS を適用して各要素の位置と大きさを計算し、画面に描画する。
#. JavaScript を実行する。JavaScript は DOM を書き換えることで、表示内容を変更できる。

ここで重要なのは、JavaScript はサーバーではなくブラウザ上で実行されるという点である。Python のプログラムは通常、Python を実行するコンピューター上で動くが、Web ページの JavaScript は、ページを閲覧している人のブラウザの中で動く。

URL の構成
~~~~~~~~~~

URL は次のような部分から構成される。ここでは ``https://example.com:443/docs/index.html?lang=ja#intro`` を例とする。

.. list-table:: URL の構成
   :header-rows: 1
   :widths: 25 30 45

   * - 部分
     - 例
     - 意味
   * - スキーム
     - ``https``
     - 通信の方式。``https`` は暗号化された HTTP である。
   * - ホスト
     - ``example.com``
     - 接続先のサーバーの名前。
   * - ポート
     - ``443``
     - 接続先のポート番号。``https`` の既定値は 443、``http`` の既定値は 80 であり、既定値の場合は省略できる。
   * - パス
     - ``/docs/index.html``
     - サーバー内のファイルやページの位置。
   * - クエリ文字列
     - ``?lang=ja``
     - サーバーに渡す追加の情報。``キー=値`` の組を ``&`` でつなぐ。
   * - フラグメント
     - ``#intro``
     - ページ内の位置。サーバーには送られず、ブラウザだけが使う。

開発環境の準備
--------------

本資料のサンプルを動かすには、次の 3 つがあればよい。

.. list-table:: 必要なもの
   :header-rows: 1
   :widths: 25 75

   * - 種類
     - 説明
   * - テキストエディタ
     - HTML・CSS・JavaScript のファイルを編集する。Visual Studio Code など、構文を色分けして表示できるものが便利である。ファイルの文字コードは UTF-8 で保存する。
   * - ブラウザ
     - Google Chrome、Microsoft Edge、Mozilla Firefox などの最新版を使う。
   * - Python
     - ローカルサーバーを起動するために使う（後述）。

開発者ツール
~~~~~~~~~~~~

主要なブラウザには、開発者ツールと呼ばれる機能が組み込まれている。F12 キー（macOS では Command + Option + I キー）で開く。主な機能は次のとおりである。

.. list-table:: 開発者ツールの主な機能
   :header-rows: 1
   :widths: 25 75

   * - タブ
     - 用途
   * - 要素（Elements）
     - 現在の DOM と、各要素に適用されている CSS を確認・一時的に変更する。
   * - コンソール（Console）
     - JavaScript のエラーや ``console.log`` の出力を確認する。JavaScript のコードを直接入力して実行することもできる。Python の対話モードに相当する。
   * - ネットワーク（Network）
     - ブラウザとサーバーの間でやり取りされたファイルと、その内容を確認する。

Web ページが思いどおりに動かないときは、まずコンソールにエラーが表示されていないかを確認するとよい。

ローカルサーバー
~~~~~~~~~~~~~~~~

HTML ファイルはダブルクリックするだけでもブラウザで開ける。このとき URL は ``file:///C:/...`` のように ``file://`` で始まる。

しかし、第 6 章で扱う JavaScript のモジュールや、第 8 章で扱う ``fetch`` によるファイルの取得は、``file://`` で開いたページでは動作しない。ブラウザのセキュリティ上の制約によるものである。そのため、これらのサンプルは、自分の PC 上で HTTP サーバー（ローカルサーバー）を起動し、``http://localhost:8000/`` のような URL で開く必要がある。

Python には、簡易的な HTTP サーバーが標準ライブラリとして含まれている。サンプルコードのフォルダーで次のコマンドを実行すると、そのフォルダーを公開するサーバーが起動する。

.. code-block:: console

   python -m http.server 8000

本資料では、Windows 環境でも JavaScript ファイルが正しく扱われるように設定したスクリプト ``serve.py`` を用意した。examples フォルダーの ch01 フォルダーで次のように実行し、ブラウザで ``http://localhost:8000/`` を開く。終了するには Ctrl + C キーを押す。

.. code-block:: console

   python serve.py
