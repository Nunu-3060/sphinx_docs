HTML & CSS & JavaScript 入門
============================

本資料は、Python などのプログラミング言語の経験がある人を対象に、Web ページを作るための 3 つの言語である HTML・CSS・JavaScript の基礎を解説する。

プログラミングの一般的な概念（変数、条件分岐、ループ、関数など）の説明は最小限にとどめ、Python との違いと Web 特有の仕組みに重点を置く。
